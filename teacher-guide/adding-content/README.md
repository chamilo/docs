# Adicionando Conteúdo

Esta seção aborda as ferramentas que você utiliza para adicionar conteúdo de aprendizado ao seu curso. O Chamilo oferece várias maneiras de disponibilizar material aos seus alunos:

* **[Documentos](documents.md)** — Faça upload de arquivos, crie páginas web e organize sua biblioteca de conteúdo
* **[Links](links.md)** — Compartilhe URLs de recursos externos, organizados por categoria
* **[Caminhos de Aprendizagem](learning-paths.md)** — Construa sequências estruturadas de conteúdo com pré-requisitos e acompanhamento de progresso
* **[Glossário](glossary.md)** — Defina termos-chave que os alunos podem consultar ao longo do curso
* **[Anúncios](announcements.md)** — Envie mensagens e atualizações para os alunos inscritos

Cada ferramenta está acessível a partir da grade de ferramentas na página inicial do curso. Clique no ícone da ferramenta para abri-la.
