# Liens

L’outil Liens vous permet de partager des URL utiles avec vos apprenants, organisées par catégorie.

## Ajouter un lien

1. Ouvrez l’outil **Liens** <img src="/.gitbook/assets/icons/mdi-link.svg" alt="Liens" data-size="line"> depuis la page d’accueil du cours
2. Cliquez sur **Ajouter un lien** <img src="/.gitbook/assets/icons/mdi-link-plus.svg" alt="Ajouter un lien" data-size="line">
3. Renseignez les informations :
   * **URL** — L’adresse web (par ex. `https://example.com/resource`)
   * **Nom du lien** — Un nom descriptif pour le lien
   * **Description** — Une explication facultative du contenu de la ressource
   * **Catégorie** — Affectez le lien à une catégorie pour l’organisation
   * **Cible** — Où s’ouvre le lien : `_self` (même fenêtre), `_blank` (nouvel onglet), `_parent` ou `_top`
   * **Afficher le lien sur la page d’accueil du cours** — Indique si vous souhaitez l’afficher comme icône d’outil sur la page d’accueil du cours
4. Enregistrez

## Organiser avec des catégories

Les catégories vous aident à regrouper les liens connexes :

1. Cliquez sur **Ajouter une catégorie**
2. Saisissez un **nom de catégorie** et une description facultative
3. Enregistrez

Les liens d’une même catégorie s’affichent ensemble, ce qui facilite la recherche de ressources pertinentes par les apprenants.

## Gérer les liens

* **Vérification des liens** <img src="/.gitbook/assets/icons/mdi-check-circle.svg" alt="Validité" data-size="line">  — Chamilo peut vérifier si les liens sont encore actifs ou rompus
* **Modifier** <img src="/.gitbook/assets/icons/mdi-pencil.svg" alt="Modifier" data-size="line"> — Mettre à jour l’URL, le titre ou la description du lien
* **Visibilité** <img src="/.gitbook/assets/icons/mdi-eye.svg" alt="Visibilité" data-size="line"> — Masquer ou afficher le lien aux apprenants
* **Supprimer** <img src="/.gitbook/assets/icons/mdi-delete.svg" alt="Supprimer" data-size="line"> — Retirer le lien

## Exporter les liens

Vous pouvez exporter votre collection de liens au format PDF. Recherchez l’option **Exporter** dans l’outil Liens.

## Conseils

* **Classer par thème** — Créez une catégorie pour chaque module ou semaine de votre cours
* **Ajouter des descriptions** — Aidez les apprenants à comprendre pourquoi un lien est pertinent avant de cliquer
* **Vérifier régulièrement** — Les liens web peuvent devenir obsolètes ou rompus avec le temps
