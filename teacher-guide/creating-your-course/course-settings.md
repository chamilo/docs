# Paramètres du cours

Les paramètres du cours vous permettent de contrôler le comportement de votre cours — qui peut y accéder, comment il apparaît et quelles fonctionnalités sont activées.

Pour accéder aux paramètres du cours, entrez dans votre cours et cliquez sur l’icône **Paramètres** <img src="/.gitbook/assets/icons/mdi-cog.svg" alt="Paramètres" data-size="line"> à côté du bouton **Passer en vue apprenant**.

## Paramètres généraux

### Informations du cours

* **Titre du cours** — Le nom d’affichage de votre cours
* **Langue du cours** — La langue principale de l’interface du cours
* **Catégorie du cours** — La catégorie sous laquelle le cours apparaît dans le catalogue
* **Image du cours** — Téléversez une miniature qui représente votre cours dans les listes de cours (elle sera redimensionnée selon le contexte)

Le code du cours (l’identifiant unique court) est défini à la création du cours et n’est pas modifiable depuis cette page.

Par défaut, tous les utilisateurs qui entrent dans votre cours voient l’ensemble de l’interface Chamilo dans la langue de votre cours. Il s’agit d’une fonctionnalité immersive. Les administrateurs peuvent modifier ce comportement, mais vous pouvez aussi le changer avec l’une des premières options : **Afficher le cours dans la langue de l’utilisateur** (réglée sur Non par défaut) si vous estimez que cela rend l’usage trop difficile pour vos utilisateurs.

Le département et l’URL du département sont des champs obsolètes. Ils ne sont conservés que pour des raisons de compatibilité héritée.

Si elle est activée, vous pouvez changer le style à l’intérieur de votre cours avec l’option **Feuilles de style**, en utilisant les feuilles de style existantes sur votre portail. Cette option est souvent désactivée par les administrateurs, pour un design global plus intégré.

### Quota disque

Chaque cours dispose d’une limite de stockage (quota disque) pour les fichiers téléversés. Le quota est défini par l’administrateur de la plateforme. Vous pouvez voir votre limite actuelle dans les paramètres du cours, et l’utilisation actuelle dans l’outil **Documents**.

> Si vous manquez d’espace, contactez l’administrateur de votre plateforme pour demander une augmentation de quota, ou supprimez les fichiers inutilisés de l’outil Documents.

### Visibilité du cours

![Les paramètres de visibilité du cours montrant les options public, ouvert, inscrit et fermé](/.gitbook/assets/course-settings-visibility.png)

Contrôlez qui peut accéder à votre cours :

| Paramètre | Description |
|---------|-------------|
| **Public** | Toute personne, y compris les visiteurs anonymes, peut accéder au cours |
| **Ouvert à la plateforme** | Tous les utilisateurs inscrits sur la plateforme peuvent accéder au cours |
| **Privé — accès accordé par des utilisateurs privilégiés** | Seuls les utilisateurs explicitement inscrits au cours peuvent y accéder |
| **Fermé** | Le cours est verrouillé ; personne ne peut y accéder excepté l’enseignant |

#### Paramètres d’inscription

Selon la configuration de votre plateforme, vous pourrez peut-être contrôler :

* **Autoriser l’auto-inscription** — Si les apprenants peuvent s’inscrire eux-mêmes via le catalogue des cours
* **Autoriser l’auto-désinscription** — Si les apprenants peuvent quitter le cours d’eux-mêmes
* **Mot de passe d’inscription** — Exiger un mot de passe pour l’auto-inscription (utile pour restreindre l’accès à un groupe spécifique) mais le niveau de sécurité est faible car le même mot de passe d’accès au cours est partagé entre tous les utilisateurs.

Ces paramètres ne concernent que l’auto-inscription. Pour une vue d’ensemble — y compris inscrire vous-même un utilisateur existant, ou inviter quelqu’un qui n’a pas encore de compte sur la plateforme — consultez [Inscrire des utilisateurs](../assessing-learners/subscribing-users.md).

### Paramètres des documents

Choisissez d’afficher ou de masquer les dossiers système dans l’outil **Documents** (masqués par défaut ; vous n’en avez généralement pas besoin et les afficher peut poser des problèmes avec le contenu masqué et les apprenants).

### Paramètres de notification par e-mail

Configurez la façon dont l’activité du cours déclenche des notifications :

* **Notifications par e-mail pour le nouveau contenu** — Notifier les utilisateurs inscrits lorsque vous ajoutez de nouveaux documents, des annonces ou d’autres contenus

### Paramètres du chat

Contrôlez l’affichage de l’outil **Chat**.

### Paramètres des parcours

* **Activer les thèmes du cours** — Permettre aux parcours de changer d’apparence (non recommandé pour une expérience utilisateur intégrée)
* **Lien de retour du parcours** — Décidez où les utilisateurs atterrissent lorsqu’ils cliquent sur l’icône **Accueil** dans un parcours : la liste des parcours, l’accueil du cours, *Mes cours*, *Mes sessions*, ou l’accueil du portail

### Paramètres de l’avancement thématique

Configurez l’affichage des messages d’avancement thématique sur la page d’accueil du cours.

### Paramètres du forum

Contrôlez le comportement de l’outil forum de ce cours.

### Paramètres des devoirs

* **Paramètre par défaut pour la visibilité des fichiers nouvellement déposés** — Décidez si les nouveaux documents téléversés par les apprenants dans l’outil **Devoirs** sont partagés avec tous les autres apprenants (Non par défaut)
* **Autoriser les apprenants à supprimer leurs propres publications** — Autoriser les apprenants à supprimer les devoirs qu’ils ont déjà téléversés (s’ils souhaitent téléverser une correction).

### Paramètres de lancement automatique

Un cours peut être configuré pour un comportement de lancement automatique, ce qui raccourcira le chemin des apprenants vers les parties importantes de votre cours. Si cette option est activée, les apprenants qui entrent dans votre cours seront envoyés directement vers l'outil sélectionné et ne verront pas la page d'accueil du cours comme étape intermédiaire. Vous pouvez même sélectionner des parcours d'apprentissage ou des exercices spécifiques à lancer à l'arrivée dans le cours. Dans ce cas, vous devez sélectionner l'option ici, puis aller à la liste des parcours d'apprentissage ou des exercices et cliquer sur l'icône fusée <img src="/.gitbook/assets/icons/mdi-rocket-launch.svg" alt="Lancement automatique" data-size="line"> sur l'élément sélectionné.

### Paramètres des assistants IA

Cette section n'apparaît que si votre administrateur a activé les outils d'IA sur la plateforme. Elle vous permet d'affiner la sélection des services d'assistance IA disponibles via les différents outils de votre plateforme Chamilo. Désactivez-les si vous ne souhaitez pas les utiliser, mais ce serait probablement une mauvaise idée car ils sont très puissants.

Ces fonctionnalités sont expliquées dans la section **Outils d'IA** de ce guide.

### Outils externes (LTI)

Si cette fonctionnalité est activée sur votre plateforme, Learning Tools Integration vous permet d'intégrer des activités externes compatibles à ce cours, sous forme d'icônes individuelles sur la page d'accueil du cours. Traiter de LTI dépasse le cadre de ce guide, mais il s'agit d'un système d'intégration puissant pour les enseignants.

### Autres

Des sections ou options supplémentaires peuvent apparaître sur cette page selon les options et les versions de Chamilo.
