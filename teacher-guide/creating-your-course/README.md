# Création de votre cours

Cette section explique comment créer un nouveau cours dans Chamilo et le configurer selon vos besoins.

## Création d'un nouveau cours

Pour créer un cours :

1. Cliquez sur **Mes cours** dans la barre latérale
2. Cliquez sur le bouton **Créer un cours** (généralement un livre vert <img src="/.gitbook/assets/icons/mdi-book-open-page-variant.svg" alt="Cours" data-size="line"> avec un signe +)
3. Remplissez le formulaire de création de cours :

![Le formulaire de création de cours avec les champs nom, catégorie, code et langue](/.gitbook/assets/course-creation-form.png)

| Champ | Obligatoire | Description |
|-------|----------|-------------|
| **Nom du cours** | Oui | Un titre court et descriptif pour votre cours (par ex. « Innovation Management ») |
| **Catégorie de cours** | Non | Sélectionnez une catégorie pour aider à organiser les cours sur la plateforme |
| **Code du cours** | Non | Un code court composé uniquement de lettres et de chiffres (40 caractères max.). S'il est laissé vide, un code est généré automatiquement à partir du nom du cours |
| **Langue** | Non | La langue principale du cours. Par défaut, votre langue actuelle |

Si cette option est activée, vous pourrez également trouver un paramètre **Salle par défaut** et la possibilité d'utiliser un **Modèle de cours** afin d'éviter de créer votre cours entièrement à partir de zéro.

4. Cliquez sur **Créer ce cours**

Vous serez redirigé vers la page d'accueil de votre nouveau cours. Un message de confirmation s'affichera : « Cours créé avec succès. »

## La page d'accueil du cours

Une fois votre cours créé, vous arrivez sur sa page d'accueil. Il s'agit du hub central de votre cours, où vous et vos apprenants accédez à tous les outils et contenus.

![La grille d'outils de la page d'accueil du cours montrant les outils disponibles avec icônes et bascules de visibilité](/.gitbook/assets/course-homepage-tool-grid.png)

La page d'accueil affiche :

* **Titre du cours** — Le nom de votre cours, affiché en haut.
* **Introduction du cours** — Une description facultative ou un message de bienvenue. Cliquez sur le bouton **+ Introduction du cours** pour en ajouter une, ou sur le bouton **Modifier l'introduction** <img src="/.gitbook/assets/icons/mdi-pencil.svg" alt="Modifier" data-size="line"> en haut pour la modifier. Elle prend en charge le texte enrichi avec images, liens et mise en forme.
* **Grille d'outils** — Une grille de tous les outils de cours disponibles, chacun présenté sous forme de carte avec une icône et un nom.

### Gestion de la visibilité des outils

En tant qu'enseignant, vous pouvez contrôler les outils que vos apprenants peuvent voir :

* Cliquez sur l'**icône œil** <img src="/.gitbook/assets/icons/mdi-eye.svg" alt="Visible" data-size="line"> à côté de n'importe quel outil pour le masquer aux apprenants. Les outils masqués affichent un **œil barré** <img src="/.gitbook/assets/icons/mdi-eye-off.svg" alt="Masqué" data-size="line"> et restent accessibles pour vous.
* Utilisez les boutons **Tout afficher** et **Tout masquer** pour modifier tous les outils en une fois
* Cliquez sur **Trier** pour activer le réordonnancement par glisser-déposer de la grille d'outils

### Vue étudiant

Cliquez sur le bouton **Vue étudiant** pour voir la page d'accueil du cours exactement comme un apprenant la verrait. Cela est utile pour vérifier que les outils masqués et le contenu non publié ne sont pas visibles. Cliquez à nouveau sur le bouton pour revenir à la vue enseignant.
