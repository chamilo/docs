# Glossário

Termos-chave utilizados ao longo deste guia.

| Termo | Definição |
|-------|-----------|
| **Avaliação** | Veja **Boletim de Notas** abaixo |
| **Tarefa** | Uma atividade na qual os alunos enviam arquivos ou textos para revisão e avaliação pelo professor. Também conhecida como "publicação do aluno" ou "trabalho". |
| **Lançamento Automático** | Uma funcionalidade que abre automaticamente uma ferramenta específica quando um aluno acessa um curso. |
| **Certificado** | Um documento gerado automaticamente quando um aluno atinge a pontuação mínima definida no boletim de notas. |
| **Curso** | Um contêiner para conteúdo de aprendizagem e ferramentas. Um curso pode incluir documentos, exercícios, fóruns, trilhas de aprendizagem e mais. |
| **Tutor do Curso** | Um papel de professor específico para sessões. Um tutor do curso gerencia um curso dentro de uma sessão. |
| **Quota de Disco** | O espaço máximo de armazenamento alocado para um curso para arquivos enviados. |
| **Inscrição** | O processo de registrar um usuário em um curso ou sessão, concedendo-lhe acesso ao conteúdo. Também conhecido como "subscrição". |
| **Exercício** | Um questionário ou teste contendo uma ou mais perguntas. Também referido como "teste" em alguns contextos. |
| **Fórum** | Uma ferramenta de discussão com conversas organizadas em categorias e tópicos. |
| **Boletim de Notas** | Uma ferramenta que agrega pontuações de exercícios, tarefas e outras atividades em uma nota unificada para cada aluno. |
| **Trilha de Aprendizagem** | Uma sequência estruturada de atividades de aprendizagem (documentos, exercícios, links) que os alunos seguem em uma ordem definida, opcionalmente com pré-requisitos. |
| **LTI** | Learning Tools Interoperability — um padrão que permite a integração de ferramentas de aprendizagem externas no Chamilo. |
| **SCORM** | Sharable Content Object Reference Model — um padrão para pacotes de conteúdo de e-learning. O Chamilo pode importar e reproduzir pacotes SCORM dentro de trilhas de aprendizagem. |
| **Sessão** | Uma edição limitada no tempo de um ou mais cursos atribuídos a um grupo específico de alunos. As sessões permitem reutilizar o mesmo conteúdo de curso para diferentes coortes. |
| **Tutor da Sessão** | Um papel de supervisão que oversee todos os cursos dentro de uma sessão. |
| **Habilidade** | Uma competência que pode ser vinculada a conquistas no boletim de notas. Quando um aluno obtém um certificado, as habilidades associadas são validadas. |
| **Pesquisa** | Uma ferramenta de questionário para coletar feedback, com vários tipos de perguntas e opções de respostas anônimas. |
| **Visibilidade** | Uma configuração que controla se uma ferramenta, documento ou atividade é visível para os alunos. Os professores sempre podem ver itens ocultos. |
