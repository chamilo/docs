# Glossario

Termini chiave utilizzati in questa guida.

| Termine | Definizione |
|---------|-------------|
| **Valutazione** | Vedi **Registro dei voti** di seguito |
| **Compito** | Un'attività in cui gli studenti inviano file o testo per la revisione e la valutazione da parte dell'insegnante. Conosciuto anche come "pubblicazione dello studente" o "lavoro". |
| **Avvio automatico** | Una funzionalità che apre automaticamente uno strumento specifico quando uno studente accede a un corso. |
| **Certificato** | Un documento generato automaticamente quando uno studente raggiunge il punteggio minimo definito nel registro dei voti. |
| **Corso** | Un contenitore per contenuti didattici e strumenti. Un corso può includere documenti, esercizi, forum, percorsi di apprendimento e altro ancora. |
| **Tutor del corso** | Un ruolo di insegnante specifico per le sessioni. Un tutor del corso gestisce un corso all'interno di una sessione. |
| **Quota disco** | Lo spazio di archiviazione massimo assegnato a un corso per i file caricati. |
| **Iscrizione** | Il processo di registrazione di un utente a un corso o a una sessione, che gli concede l'accesso ai contenuti. Conosciuto anche come "sottoscrizione". |
| **Esercizio** | Un quiz o un test contenente una o più domande. Riferito anche come "test" in alcuni contesti. |
| **Forum** | Uno strumento di discussione con conversazioni organizzate in categorie e argomenti. |
| **Registro dei voti** | Uno strumento che aggrega i punteggi di esercizi, compiti e altre attività in un voto unificato per ogni studente. |
| **Percorso di apprendimento** | Una sequenza strutturata di attività di apprendimento (documenti, esercizi, link) che gli studenti seguono in un ordine definito, opzionalmente con prerequisiti. |
| **LTI** | Learning Tools Interoperability — uno standard che consente di integrare strumenti di apprendimento esterni all'interno di Chamilo. |
| **SCORM** | Sharable Content Object Reference Model — uno standard per pacchetti di contenuti e-learning. Chamilo può importare e riprodurre pacchetti SCORM all'interno dei percorsi di apprendimento. |
| **Sessione** | Un'edizione limitata nel tempo di uno o più corsi assegnati a un gruppo specifico di studenti. Le sessioni consentono di riutilizzare lo stesso contenuto del corso per diverse coorti. |
| **Tutor della sessione** | Un ruolo di supervisione che sovrintende a tutti i corsi all'interno di una sessione. |
| **Competenza** | Una competenza che può essere collegata ai risultati nel registro dei voti. Quando uno studente ottiene un certificato, le competenze associate vengono validate. |
| **Sondaggio** | Uno strumento di questionario per raccogliere feedback, con vari tipi di domande e opzioni di risposta anonima. |
| **Visibilità** | Un'impostazione che controlla se uno strumento, un documento o un'attività è visibile agli studenti. Gli insegnanti possono sempre vedere gli elementi nascosti. |
