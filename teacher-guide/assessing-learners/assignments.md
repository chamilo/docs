# Devoirs

L'outil de devoirs (également appelé "publications des étudiants") vous permet de collecter les travaux des apprenants — essais, projets, rapports ou tout autre soumission sous forme de fichier — et de les noter.

## Créer un devoir

1. Ouvrez l'outil **Devoirs** <img src="/.gitbook/assets/icons/mdi-inbox-full.svg" alt="Devoirs" data-size="line"> depuis la page d'accueil du cours
2. Cliquez sur **Créer un devoir**
3. Remplissez les détails :
   * **Nom du devoir** — Le nom du devoir (par exemple, "Rapport de projet final")
   * **Description** — Instructions pour les apprenants, incluant ce qu'ils doivent soumettre et comment cela sera évalué (prend en charge le texte enrichi)
   * **Score maximum** — Sur quel total le devoir sera noté
   * **Ajouter au carnet de notes** — Ajouter comme élément évalué dans l'outil d'évaluation (carnet de notes), afin qu'il puisse contribuer à atteindre les objectifs du cours
   * **Date limite** — La date et l'heure officielles (publiées) après lesquelles les soumissions sont marquées comme en retard (les téléversements sont toujours acceptés)
   * **Se termine à (fermeture complète)** — La date et l'heure de coupure stricte après lesquelles aucun téléversement n'est possible
   * **Ajouter au calendrier** — Créer un événement pour référencer la date de soumission de ce devoir
   * **Type de soumission** — Choisissez entre **Autoriser uniquement du texte**, **Autoriser uniquement des fichiers**, ou **Autoriser des fichiers ou du texte en ligne**
4. Enregistrez

Une fois que vous avez créé un devoir, vous pouvez également :
* Téléverser des documents modèles depuis la page de détail du devoir
* Attribuer le devoir à des utilisateurs spécifiques (plutôt qu'à tous les utilisateurs du cours)

Et une fois que les apprenants ont soumis leurs devoirs, vous pouvez :
* Exporter une liste PDF des soumissions
* Afficher une liste des apprenants qui n'ont pas soumis leur devoir
* Télécharger tous les devoirs dans un gros fichier ZIP
* Téléverser toutes les corrections dans un gros fichier ZIP
* Supprimer toutes les corrections que vous avez soumises (cela ne supprime pas les soumissions des apprenants)

## Comment les apprenants soumettent-ils leurs travaux

Les apprenants ouvrent le devoir et :

1. Cliquent sur **Téléverser un fichier** ou sur le bouton de soumission
2. Sélectionnent un fichier depuis leur ordinateur (ou écrivent directement du texte, selon la configuration)
3. Ajoutent un commentaire optionnel
4. Soumettent

Les apprenants peuvent voir s'ils ont déjà soumis leur travail et, si cela est autorisé, mettre à jour leur soumission.

## Examiner les soumissions

![La liste des soumissions de devoirs affichant les noms des étudiants, les dates, les fichiers et l'état de la notation](/.gitbook/assets/assignments-submissions-list.png)

En tant qu'enseignant, ouvrez un devoir pour voir la liste de toutes les soumissions :

* **Nom de l'étudiant** — Qui a soumis
* **Date de soumission** — Quand le travail a été soumis
* **Fichier** — Télécharger le fichier soumis
* **Statut** — Si la soumission a été notée
* **Commentaires** — Tous les commentaires laissés par l'apprenant ou par vous

### Noter une soumission

![La vue de notation des devoirs avec saisie du score, champ de retour d'information et téléversement de fichier corrigé](/.gitbook/assets/assignment-grading-view.png)

1. Cliquez sur une soumission pour l'ouvrir
2. Examinez le fichier soumis
3. Entrez un **score**
4. Rédigez des **commentaires de retour** pour l'apprenant
5. Téléversez éventuellement un **fichier corrigé** en pièce jointe
6. Enregistrez

### Notation assistée par IA

Si des outils d'IA sont configurés sur votre plateforme, vous pourriez voir une option de **notation par IA** lors de l'examen des soumissions. Cela utilise un modèle d'IA pour suggérer un score et des commentaires pour les travaux ouverts. Consultez [Notation par IA](../ai-tools/ai-grading.md) pour plus de détails.

## Gérer les soumissions

Actions de groupe :
* **Télécharger le paquet de devoirs** — Télécharger toutes les soumissions sous forme d'un seul fichier ZIP pour un examen hors ligne
* **Téléverser le paquet de corrections** — Si vous avez téléchargé toutes les soumissions dans un seul fichier ZIP, édité les fichiers directement sur votre ordinateur et les avez à nouveau compressés, vous pouvez envoyer le ZIP comme un paquet de corrections. Ne modifiez pas les noms de fichiers, sinon cela ne fonctionnera pas.
* **Soumissions en retard** — Les soumissions après la date limite sont signalées mais peuvent toujours être acceptées selon vos paramètres

Actions sur une soumission individuelle :
* **Téléverser une correction** — Téléverser une correction pour un apprenant
* **Télécharger** — Télécharger la soumission d'un apprenant
* **Corriger et noter** — Ajouter une correction et une note à la soumission de l'apprenant
* **Modifier** — Modifier le titre du document ou les commentaires précédents sur la soumission
* **Déplacer** — Transférer une soumission entre les dossiers de devoirs (par exemple, si l'étudiant a soumis dans le mauvais devoir)
* **Visibilité** — Contrôler si les apprenants peuvent voir les soumissions des autres

## Lier au carnet de notes

Les scores des devoirs peuvent être inclus dans le carnet de notes du cours (outil "Évaluations"). Cela permet aux notes des devoirs de contribuer à la note globale de l'apprenant pour le cours et à l'éligibilité au certificat. Consultez [Carnet de notes](gradebook.md) pour plus de détails.

## Conseils

* **Soyez précis dans les instructions** — Décrivez clairement ce que les apprenants doivent soumettre, le format attendu et les critères d'évaluation
* **Fixez des délais réalistes** — Utilisez l'outil Agenda pour rendre les dates limites visibles dans le calendrier du cours
* **Utilisez la fonctionnalité de fichier corrigé** — Téléversez des versions annotées des travaux des étudiants afin qu'ils puissent voir vos corrections spécifiques
* **Activez la visibilité entre pairs avec prudence** — Permettre aux apprenants de voir les travaux des autres peut encourager l'apprentissage, mais cela peut ne pas être approprié pour tous les devoirs
