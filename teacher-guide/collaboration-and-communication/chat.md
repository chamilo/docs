# Chat

L'outil Chat permet la messagerie textuelle en temps réel au sein d'un cours. Il est utile pour une communication rapide, des sessions de questions-réponses en direct ou des discussions informelles.

## Utiliser le Chat

1. Ouvrez l'outil **Chat** depuis la page d'accueil du cours
2. Dans le panneau **Utilisateurs**, choisissez un utilisateur en ligne spécifique pour lui envoyer un message direct, ou utilisez l'onglet **Tous** pour vous adresser à tout le groupe
3. Saisissez votre message dans le champ de texte en bas et appuyez sur **Entrée** pour l'envoyer (**Maj+Entrée** pour une nouvelle ligne sans envoyer)

Une option **Aperçu** vous permet de vérifier la mise en forme avant l'envoi, et **Réinitialiser** efface le brouillon en cours.

## Fonctionnalités du Chat

* **Messagerie en temps réel** — Les messages apparaissent instantanément pour le ou les destinataires
* **Historique des messages** — Les messages précédents sont visibles lorsque vous entrez dans le chat
* **Présence des utilisateurs** — Le panneau Utilisateurs indique qui est actuellement en ligne dans le cours
* **Direct ou groupe** — Envoyez un message à un apprenant à la fois, ou diffusez à tout le monde via l'onglet **Tous**

## En tant qu'enseignant

En tant qu'enseignant du cours, vous pouvez :

* **Suivre les discussions** — Consulter l'historique du chat pour suivre l'engagement des apprenants
* **Retrouver les archives du chat dans Documents** — L'outil Chat recopie automatiquement les messages dans des fichiers HTML de l'outil Documents, organisés par jour et par portée (cours / session / groupe), de sorte que la conversation persiste au-delà de la session en direct

Si le paramètre de la plateforme « Restreindre le chat du cours aux tuteurs » est activé par l'administrateur, seuls les tuteurs peuvent discuter avec les apprenants ; sinon, toutes les personnes inscrites au cours peuvent participer.

## Conseils pour utiliser le Chat efficacement

* **Planifier des sessions de chat** — Informez à l'avance les apprenants des moments où vous serez disponible pour un chat en direct (utilisez l'outil Agenda)
* **Définir des règles de base** — Établissez des attentes pour une communication respectueuse
* **Utiliser pour les questions rapides** — Le chat convient mieux aux échanges courts ; utilisez le Forum pour des discussions plus longues et structurées

> Si votre plateforme dispose d'une visioconférence configurée (BigBlueButton ou Zoom), envisagez de l'utiliser pour les sessions en direct où la voix et la vidéo seraient plus efficaces. Voir [Visioconférence](video-conferencing.md).
