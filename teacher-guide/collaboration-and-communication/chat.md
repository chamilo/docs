# Chat

L'outil de chat permet des échanges de messages textuels en temps réel au sein d'un cours. Il est utile pour des communications rapides, des sessions de questions-réponses en direct ou des discussions informelles.

## Utilisation du Chat

1. Ouvrez l'outil **Chat** depuis la page d'accueil du cours
2. Tapez votre message dans le champ de texte en bas
3. Appuyez sur **Entrée** ou cliquez sur le bouton d'envoi pour publier

Tous les utilisateurs inscrits qui se trouvent actuellement dans la salle de chat peuvent voir les messages en temps réel.

## Fonctionnalités du Chat

* **Messagerie en temps réel** — Les messages apparaissent instantanément pour tous les participants
* **Historique des messages** — Les messages précédents sont visibles lorsque vous entrez dans le chat
* **Présence des utilisateurs** — Voyez qui est actuellement dans la salle de chat

## En tant qu'enseignant

En tant qu'enseignant du cours, vous pouvez :

* **Surveiller les discussions** — Consultez l'historique du chat pour suivre l'engagement des apprenants
* **Trouver les archives du chat dans Documents** — L'outil de chat duplique automatiquement les messages dans des fichiers HTML dans l'outil Documents, organisés par jour et par portée (cours / session / groupe), afin que la conversation persiste au-delà de la session en direct

Si le paramètre de la plateforme "restreindre le chat aux formateurs" est activé par l'administrateur, seuls les formateurs peuvent discuter avec les apprenants ; sinon, tous les inscrits au cours peuvent participer.

## Conseils pour utiliser le Chat efficacement

* **Planifiez des sessions de chat** — Informez les apprenants à l'avance de vos disponibilités pour un chat en direct (utilisez l'outil Agenda)
* **Établissez des règles de base** — Définissez des attentes pour une communication respectueuse
* **Utilisez pour des questions rapides** — Le chat est idéal pour des échanges courts ; utilisez le Forum pour des discussions plus longues et structurées

> Si votre plateforme a configuré la visioconférence (BigBlueButton ou Zoom), envisagez de l'utiliser pour des sessions en direct où la voix et la vidéo seraient plus efficaces. Voir [Visioconférence](video-conferencing.md).
