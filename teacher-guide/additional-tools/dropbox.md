# Dropbox

La Dropbox è uno strumento di scambio file che consente a te e ai tuoi studenti di condividere file tra di voi all'interno del corso.

> Per raccogliere lavori degli studenti da valutare, lo strumento [Compiti](../assessing-learners/assignments.md) è generalmente più appropriato, poiché include funzionalità di valutazione e feedback. La Dropbox è più adatta per la condivisione informale di file.

## Inviare un File

1. Apri lo strumento **Dropbox** dalla homepage del corso
2. Fai clic su **Condividi un nuovo file**
3. Seleziona il file da caricare
4. Scegli il/i **destinatario/i** — uno o più utenti iscritti o gruppi del corso
5. Invia

## Ricevere File

Quando qualcuno ti invia un file, questo appare nella tua casella di posta della Dropbox. Puoi:

* **Scaricare** il file
* **Aggiungere un commento** al file (dopo averlo ricevuto)
* **Spostare** il file in una delle tue categorie
* **Eliminare** il file dalla tua casella di posta

## Organizzare i File

Sia i file inviati che quelli ricevuti possono essere organizzati in **categorie** personalizzate (cartelle). Utilizza i controlli delle categorie nella barra degli strumenti della Dropbox per creare una categoria, quindi sposta i file al suo interno. Se l'impostazione della piattaforma "consenti sovrascrittura" è abilitata, reinviare un file con lo stesso nome ti permette di sovrascrivere la versione precedente.

Puoi anche scaricare in batch i file selezionati come ZIP.

## Come Insegnante

* Puoi inviare file a singoli studenti, gruppi di studenti o a tutti gli utenti iscritti
* Puoi visualizzare i file inviati a te dagli studenti
* Questo strumento è utile per condividere materiali supplementari, fornire documenti di feedback individuale o ricevere consegne informali
