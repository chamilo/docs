* **[Dropbox](dropbox.md)** — أداة بسيطة لتبادل الملفات بينك وبين متعلميك
* **[Portfolio](portfolio.md)** — دع المتعلمين لبناء وعرض محفظة أعمالهم
* **[Course Progress](course-progress.md)** — تحديد الأقسام التمثيلية وتتبع تسليم الدورة
