# 学習経路ジェネレーター

AIを活用した学習経路ジェネレーターは、構造化された学習シーケンスを自動的に作成するのに役立ちます。トピックと目標を提供すると、AIが学習経路の概要を生成し、セクションやコンテンツ項目を含めて、レビューやカスタマイズが可能です。

## 学習経路ジェネレーターへのアクセス

学習経路ジェネレーターは、新しい学習経路を作成する際に利用可能で、以下の条件を満たす必要があります：

1. プラットフォームレベルでAIアシスタントが有効になっている
2. コース設定で学習経路ジェネレーターが有効になっている
3. 少なくとも1つのAIテキストプロバイダーが設定されている

学習経路作成インターフェース内の**AIジェネレーター**セクションを探してください。

## 学習経路の生成方法

![トピック、目標、セクション数を入力するフィールドを含むAI学習経路ジェネレーターフォーム](/.gitbook/assets/ai-learning-path-generator.png)

1. AIジェネレーターフォームを開く
2. パラメータを設定する：
   * **トピック** — 学習経路の主題
   * **アイテム数** — 学習経路に含まれるコンテンツページの数
   * **ページごとの単語数** — 各ページのおおよその長さ
   * **各ページ後にテストを追加** — チェックを入れると、AIが各ページ後に小規模な多肢選択クイズも作成します（デフォルトで2問、最大5問に制限）
3. **生成**をクリックする
4. AIが学習経路を生成し、ページごとに1つのドキュメントアイテムと、必要に応じて各ページ後にクイズアイテムを含めます

## レビューとカスタマイズ

生成された学習経路は**出発点**です。以下の作業を行う必要があります：

* **構造のレビュー** — セクションが論理的な順序で配置されているか確認する
* **コンテンツの編集** — 生成されたテキストを修正し、独自の資料を追加し、不要なセクションを削除する
* **リソースの追加** — 独自のドキュメント、演習、リンク、その他のコンテンツを挿入する
* **前提条件の設定** — どのセクションを先に完了する必要があるかを設定する
* **評価の追加** — 理解度を確認するために適切な箇所に演習を追加する

## AI生成コンテンツの開示

AIによって生成されたコンテンツには、人工知能を使用して作成されたことを示す開示通知が付いています。この透明性は、学習者が教材の出所を理解するのに役立ちます。

## ヒント

* **広く始めてから絞り込む** — 最初に高レベルの構造を生成し、その後手動で詳細や特定のリソースを追加する
* **コース計画に活用する** — 生成されたコンテンツを直接使用しない場合でも、AIが提案する構造は計画ツールとして役立つ可能性がある
* **演習生成と組み合わせる** — 学習経路を生成した後、演習ジェネレーターを使用して各セクションの評価を作成する
