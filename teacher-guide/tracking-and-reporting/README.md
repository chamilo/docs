# Suivi et rapports

Chamilo suit l’activité des apprenants sur l’ensemble de la plateforme, vous offrant une vision détaillée de leur progression.

* **[Suivi des apprenants](learner-tracking.md)** — Surveillez l’activité individuelle de chaque apprenant : heures de connexion, temps passé, pages visitées et utilisation des outils
* **[Rapports de cours](course-reports.md)** — Consultez les données agrégées de tous les apprenants d’un cours
* **[Certificats et compétences](certificates-and-skills.md)** — Délivrez des certificats en fonction des scores du carnet de notes et validez les compétences acquises

## Accéder aux rapports

Depuis votre cours, cliquez sur l’outil **Suivi** <img src="/.gitbook/assets/icons/mdi-chart-box.svg" alt="Suivi" data-size="line"> sur la page d’accueil du cours. Vous pouvez également accéder aux rapports via le lien **Rapports** dans la barre latérale pour une vue d’ensemble multi-cours.

Les enseignants voient les données de rapport des cours qu’ils enseignent. Les tuteurs de session voient les données de tous les cours de leur session.
