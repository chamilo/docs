# Glossaire

Termes clés utilisés tout au long de ce guide.

| Terme | Définition |
|------|-----------|
| **Évaluation** | Voir **Carnet de notes** ci-dessous |
| **Devoir** | Une tâche consistant à déposer des fichiers ou du texte pour que votre enseignant les examine et les note. Également appelé « publication étudiante » ou « travail ». |
| **CAPTCHA** | Un défi (généralement la saisie de lettres déformées à partir d’une image) servant à confirmer que vous êtes une personne réelle, affiché sur certains formulaires de connexion, d’inscription et de mot de passe oublié. |
| **Catalogue** | La liste publique des cours (et des sessions) que vous pouvez parcourir et, dans certains cas, dans lesquels vous pouvez vous inscrire vous-même. Accessible via **Explorer plus de cours**. |
| **Certificat** | Un document généré automatiquement lorsque vous atteignez le score minimal défini dans le carnet de notes d’un cours. |
| **Cours** | Un conteneur pour les contenus et outils d’apprentissage. Un cours peut inclure des documents, des exercices, des forums, des parcours d’apprentissage, et davantage. |
| **Inscription** | Le fait d’être enregistré dans un cours ou une session, ce qui vous donne accès à son contenu. Également appelé « souscription ». |
| **Exercice** | Un quiz ou un test contenant une ou plusieurs questions. Également désigné comme un « test » dans certains contextes. |
| **Forum** | Un outil de discussion avec des conversations en fils, organisées en catégories et sujets. |
| **Carnet de notes** | Un outil qui agrège vos scores issus des exercices, des devoirs et d’autres activités en une note unifiée. |
| **Invitation** | Un lien à usage unique envoyé par un enseignant à votre adresse e-mail, vous permettant de vous inscrire et d’être automatiquement inscrit à un cours, même si l’inscription générale est fermée. |
| **Parcours d’apprentissage** | Une séquence structurée d’activités d’apprentissage (documents, exercices, liens) que vous suivez dans un ordre défini, parfois avec des prérequis. |
| **Auto-inscription** | La possibilité de créer votre propre compte via un formulaire d’inscription public, si elle est activée par l’administrateur de la plateforme. |
| **Session** | Une édition limitée dans le temps d’un ou plusieurs cours, attribuée à un groupe spécifique d’apprenants, par exemple un trimestre ou une cohorte. |
| **Compétence** | Une compétence liée aux réalisations du carnet de notes. L’obtention d’un certificat peut valider les compétences associées. |
| **Authentification à deux facteurs (2FA)** | Une étape de connexion supplémentaire utilisant un code temporaire issu d’une application d’authentification, en plus de votre mot de passe. |
| **Visibilité** | Un paramètre qui contrôle si un outil, un document ou une activité est affiché aux apprenants. Les enseignants peuvent toujours voir les éléments masqués. |
