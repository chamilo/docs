# Autres blocs d’administration

Le tableau de bord d’administration comporte quelques blocs supplémentaires qui ne sont pas tant des fonctionnalités configurables que des widgets d’information : une page de liens sortants, une inscription de vérification de version, et deux petits panneaux récupérant du contenu depuis chamilo.org. Ce chapitre explique ce qu’est chacun d’eux, d’où vient son contenu et — puisque certains le font — si des données quittent votre plateforme.

## Contenu abordé

* **[Liens Chamilo.org](chamilo-org-links.md)** — Une liste de favoris vers les ressources officielles de Chamilo ; n’envoie rien
* **[Vérification de version](version-check.md)** — Inscription optionnelle qui signale la version et l’utilisation de votre plateforme à chamilo.org, et vous indique si une mise à jour est due
* **[Support professionnel](professional-support.md)** — Un panneau en lecture seule décrivant les prestataires officiels de support Chamilo
* **[Actualités de Chamilo](news-from-chamilo.md)** — Un flux en lecture seule des annonces officielles, y compris les correctifs de sécurité et les nouvelles versions

Chaque page ci-dessous indique clairement ce qui, le cas échéant, est envoyé à chamilo.org, et pourquoi.
