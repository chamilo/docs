# 統合機能

Chamiloは、機能を拡張するためにいくつかのサードパーティサービスと統合しています。

これらの多くはプラグインを通じて有効化されます。このガイドの少し先にある対応するセクションを確認してください。

* **[ビデオ会議](video-conferencing.md)** — BigBlueButtonおよびZoom
* **[LTI 1.3](lti.md)** — 外部学習ツールとの接続
* **[xAPI](xapi.md)** — 学習体験の追跡
* **[OnlyOffice](onlyoffice.md)** — 共同ドキュメント編集
* **[AI設定](ai-configuration.md)** — AI搭載機能のためのAIプロバイダーの設定
