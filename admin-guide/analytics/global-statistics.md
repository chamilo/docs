# Global Statistics

Global Statistics is the platform statistics hub — a menu of platform-wide reports grouped by topic, rather than a single report.

## Accessing Global Statistics

From the administration panel, click **Analytics > Global statistics**.

## What It Shows

Opening the page with no report selected shows a menu of available statistics, grouped into:

* **Courses** — Course counts and tool usage across the platform
* **Users** — Logins by day/month/hour, active users, duplicate accounts, inactive ("zombie") accounts, and new registrations
* **System** — Disk and session-related statistics
* **Social** — Social network activity

Selecting a menu entry loads that specific statistic on the same page. Each is a platform-wide, admin-only view — there is no course or session scoping here; for that, see [Learning Analytics](learning-analytics.md).
