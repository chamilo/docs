# Classes / Groupes d'utilisateurs

Les classes dans le panneau d'administration sont des groupes à l'échelle de la plateforme utilisés pour organiser les utilisateurs à des fins de gestion. Elles se distinguent des groupes au niveau des cours (qui sont créés par les enseignants au sein d'un cours).

> Les groupes d'utilisateurs et les [Classes](../../admin-guide/sessions/classes.md) partagent la même interface. La seule différence réside dans le paramètre de **type de groupe** : choisissez "Classe" pour créer une classe (utilisée pour l'inscription en masse aux sessions), ou "Groupe d'utilisateurs" pour des groupes plus sociaux qui peuvent avoir leur propre espace dans le réseau social interne. Consultez [Classes](../../admin-guide/sessions/classes.md) pour plus de détails sur l'inscription aux sessions.

## Création d'un groupe

![Liste des groupes d'utilisateurs affichant les groupes disponibles avec leur nom, description et nombre de membres](/.gitbook/assets/admin-user-groups-list.png)

1. Depuis le panneau d'administration, accédez à **Classes**
2. Cliquez sur **Ajouter des classes**
3. Saisissez un **titre** et une **description** facultative
4. Cochez **Groupe social** si ce groupe sera un groupe social. Laissez décoché s'il s'agit d'une classe.
5. Ajoutez une URL de référence et une image/logo facultatifs.
6. Choisissez les **permissions** du groupe :
   * **Ouvert** — Tout utilisateur peut rejoindre le groupe
   * **Fermé** — Les utilisateurs doivent être ajoutés par un administrateur
7. Cochez si vous souhaitez que les membres puissent quitter la classe par eux-mêmes.
8. Enregistrez.

## Ajout de membres

1. Ouvrez la liste des classes/groupes d'utilisateurs
2. Cliquez sur l'icône utilisateur **Inscrire des utilisateurs à la classe**
3. Recherchez des utilisateurs par nom, nom d'utilisateur ou adresse e-mail
4. Sélectionnez les utilisateurs à ajouter en utilisant les flèches sur le côté droit
5. Cliquez sur le bouton de confirmation pour enregistrer

## Cas d'utilisation

* **Organisation par département** — Regrouper les utilisateurs par département ou équipe
* **Inscription en masse** — Ajouter tous les membres d'un groupe à un cours ou une session en une seule fois
* **Communication ciblée** — Envoyer des annonces à des groupes spécifiques
* **Rapports** — Voir la progression de la formation filtrée par groupe

## Gestion des groupes

* **Modifier** — Changer le nom, la description ou la visibilité du groupe
* **Gérer les membres** — Ajouter ou supprimer des membres
* **Supprimer** — Supprimer le groupe (cela ne supprime pas les comptes des membres)
