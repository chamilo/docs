# Classes

Les classes dans Chamilo sont des groupes d'utilisateurs prédéfinis qui peuvent être inscrits dans des sessions en tant qu'unité. Elles simplifient le processus d'inscription lorsque vous formez régulièrement les mêmes groupes de personnes.

> Les classes et les [Groupes d'utilisateurs](../../admin-guide/users/user-groups.md) partagent la même interface. La seule différence est le paramètre **type de groupe** : choisissez « Class » lors de la création du groupe. Tout le reste — gestion des membres, visibilité et l'interface elle-même — fonctionne de manière identique.

## Création d'une classe

1. Depuis le panneau d'administration, accédez à **Classes** (ou Groupes d'utilisateurs et sélectionnez le type « Class »)
2. Cliquez sur **Create a class**
3. Saisissez un **nom** (par ex. « Engineering Team », « New Hires March 2026 »)
4. Ajoutez des **membres** — recherchez et sélectionnez des utilisateurs
5. Enregistrez

## Utilisation des classes pour l'inscription

Lors de la création ou de la modification d'une session, vous pouvez inscrire une classe entière d'un coup au lieu d'ajouter les utilisateurs un par un :

1. Ouvrez les paramètres d'inscription de la session
2. Cliquez sur **Add a class**
3. Sélectionnez la classe
4. Tous les membres de la classe sont inscrits dans la session

## Gestion des classes

* **Edit** — Modifier le nom de la classe ou mettre à jour les membres
* **Add/remove members** — Tenir à jour la liste des membres de la classe
* **Delete** — Supprimer la classe (n'affecte pas les comptes des membres ni leurs inscriptions existantes)

## Conseils

* **Créer des classes pour les cohortes récurrentes** — Si vous dispensiez la même formation à différentes équipes, créez une classe pour chaque équipe
* **Mettre à jour avant chaque session** — Vérifiez les membres de la classe avant d'inscrire une classe dans une nouvelle session afin de garantir que la liste est à jour
* **Combiner avec l'import CSV** — Importez les membres d'une classe depuis un fichier CSV pour les grands groupes
