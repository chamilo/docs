# Multi-URL

La función multi-URL de Chamilo (también conocida como multi-tenant) permite ejecutar múltiples portales virtuales desde una única instalación de Chamilo. Cada portal tiene su propia URL, marca, usuarios, cursos y configuraciones, pero todos comparten la misma base de datos y código base.

* **[URLs de acceso](access-urls.md)** — Configurar y gestionar múltiples URLs de acceso
