# Multi-URL

Die Multi-URL-Funktion von Chamilo (auch als Multi-Tenant bezeichnet) ermöglicht es Ihnen, mehrere virtuelle Portale aus einer einzigen Chamilo-Installation zu betreiben. Jedes Portal hat seine eigene URL, sein eigenes Branding, seine eigenen Benutzer, Kurse und Einstellungen, teilt jedoch dieselbe Datenbank und denselben Codebasis.
