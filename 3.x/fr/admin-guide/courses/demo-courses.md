# Cours de démonstration

À partir de Chamilo 3.0.0, deux cours de démonstration sont installés sur chaque nouvelle plateforme. Ils montrent ce qu’il est possible de faire avec Chamilo, et ils sont utiles en eux-mêmes.

| Cours | Code | Utile pour |
|--------|------|------------|
| **AI Act** | `AIACT` | Toute organisation concernée par le règlement européen sur l’IA (AI Act). Fournit un parcours d’apprentissage *Sensibilisation à l’AI Act pour les organisations européennes*. |
| **Using Chamilo** | `USINGCHAMILO` | Toute organisation qui commence à utiliser Chamilo. Fournit un parcours d’apprentissage *Premiers pas avec Chamilo 3.0*. |

## Ce que vous obtenez

* **Les deux cours sont multilingues.** Chacun contient **26 versions linguistiques** de son contenu, principalement les langues des pays concernés par l’AI Act. Les apprenants voient la version correspondant à la langue de leur profil, grâce à la fonctionnalité de [contenu multilingue](../../teacher-guide/adding-content/multi-language-content.md) (le paramètre `translate_html`, activé par défaut depuis la version 3.0.0 ; voir [Paramètres de l’éditeur](../platform-settings/editor-settings.md)). Si vous désactivez ce paramètre, les apprenants verront toutes les versions linguistiques en même temps au lieu de la leur uniquement ; laissez-le donc activé si vous souhaitez utiliser ces cours.
* **Ils sont installés avec la plateforme.** Ils sont créés lors de l’installation, appartiennent au compte administrateur et apparaissent dans la liste des cours comme n’importe quel autre cours.
* **Ils sont ouverts aux utilisateurs connectés.** Leur visibilité est définie sur *Ouvert*, et seuls les outils **Description du cours** et **Parcours d’apprentissage** sont visibles sur la page d’accueil du cours.

![La page Mes cours, où le cours de démonstration AI Act apparaît sous forme de carte de cours](../../.gitbook/assets/demo-courses-list.png)

## Les utiliser

* Assurez-vous que le cours est visible, puis inscrivez les utilisateurs concernés, ou ajoutez-le au catalogue de cours, afin que les personnes puissent le trouver. Voir [Gérer les cours](managing-courses.md).
* Utilisez le cours *AI Act* pour former votre personnel à la sensibilisation à l’IA, et le cours *Using Chamilo* pour accompagner les nouveaux enseignants et apprenants.
* Copiez un cours (voir [Importation et exportation de cours](course-import-export.md)) avant de le modifier, afin de conserver l’original comme référence.

## Les masquer ou les supprimer

Si vous n’en avez pas besoin, ils peuvent être retirés sans aucun effet secondaire sur le reste de la plateforme :

* **Les masquer** : modifiez le cours et définissez sa visibilité sur **Masqué** (ou **Fermé**), ou retirez-le du catalogue de cours. Il reste sur la plateforme et peut être rétabli ultérieurement.
* **Les supprimer** : utilisez **Supprimer** dans la liste des cours. Comme pour tout cours, cette action est définitive ; envisagez donc d’exporter le cours au préalable si vous pourriez en avoir besoin plus tard.

{% hint style="info" %}
La suppression des cours de démonstration est sans risque, mais ils ne peuvent pas être réinstallés depuis l’interface par la suite. Les masquer est l’option réversible.
{% endhint %}

## Pourquoi les conserver ?

Même si votre organisation n’a pas besoin de la formation elle-même, ils constituent le moyen le plus rapide de montrer aux nouveaux enseignants à quoi ressemble un cours multilingue achevé, doté d’un parcours d’apprentissage. De nombreux administrateurs les conservent masqués pour les apprenants et visibles uniquement pour les enseignants à cette fin.
