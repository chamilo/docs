# Sessions

Les sessions constituent l'une des fonctionnalités les plus puissantes de Chamilo. Elles permettent de proposer les mêmes cours à différents groupes d'apprenants à des moments distincts, sans dupliquer le contenu des cours.

## Comprendre les sessions

Les sessions sont **facultatives**. Vous pouvez faire fonctionner votre portail en utilisant uniquement des cours, mais nous vous recommandons **vivement** d'envisager la complexité supplémentaire des sessions comme un moyen de réduire le travail de gestion à long terme.

Un **cours** contient le contenu (documents, exercices, parcours d'apprentissage). Une **session** attribue ce cours (ou plusieurs cours) à un groupe spécifique d'apprenants *pour une période donnée*.

Cette architecture signifie que :

* Les enseignants créent le contenu une seule fois dans le cours
* Les administrateurs créent des sessions pour diffuser ce contenu auprès de différentes cohortes
* Chaque session dispose de ses propres inscriptions, données de suivi et résultats
* Le contenu du cours de base est partagé, mais les tuteurs de session peuvent personnaliser certains éléments

## Quand utiliser les sessions

Utilisez les sessions lorsque :

* Vous dispensez la même formation à plusieurs reprises (par exemple, des sessions d'intégration mensuelles)
* Vous proposez des programmes organisés par cohortes (par exemple, des classes semestrielle)
* Vous avez besoin d'un suivi distinct pour chaque groupe d'apprenants
* Vous souhaitez que différents tuteurs gèrent différentes éditions du même cours
