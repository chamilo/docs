# Portfolio

L’outil portfolio permet aux apprenants de collecter et de présenter leurs travaux tout au long du cours. Il sert de portfolio numérique dans lequel les apprenants peuvent rassembler leurs meilleurs travaux, leurs réflexions et leurs réalisations.

## Fonctionnement des portfolios

Chaque apprenant dispose d’un portfolio personnel au sein du cours, dans lequel il peut :

* **Ajouter des éléments** — Rédiger des entrées textuelles avec l’éditeur de texte enrichi et joindre un ou plusieurs fichiers à chaque élément
* **Organiser le contenu** — Étiqueter les éléments afin de pouvoir les filtrer par thème
* **Partager de manière sélective** — Définir la visibilité de chaque élément : masqué, visible pour le cours, masqué sauf pour l’enseignant, ou partagé avec des utilisateurs sélectionnés lorsque le partage avancé est activé

## En tant qu’enseignant

Vous pouvez utiliser les portfolios pour :

* **L’apprentissage réflexif** — Demander aux apprenants de tenir un portfolio de réflexions sur leur parcours d’apprentissage
* **La démonstration de compétences** — Faire collecter par les apprenants des preuves de compétences et de connaissances
* **L’évaluation** — Examiner le contenu des portfolios dans le cadre de votre évaluation

Pour consulter le portfolio d’un apprenant, ouvrez l’outil portfolio et filtrez la liste des éléments par utilisateur.

Si le cours est configuré pour le permettre, vous pouvez noter les éléments du portfolio et les commentaires individuels — ces notes peuvent ensuite alimenter le carnet de notes. Vous pouvez également **mettre en évidence** les éléments auxquels vous souhaitez attirer l’attention, et marquer des éléments ou des commentaires comme **modèles** afin que vous (ou les apprenants) puissiez les réutiliser comme point de départ pour de nouvelles entrées. Les portfolios peuvent être exportés au format **PDF** ou **ZIP**.

## Conseils

* **Définir les attentes** — Indiquez aux apprenants quels types d’éléments inclure et comment organiser leur portfolio
* **Réviser régulièrement** — Consultez les portfolios périodiquement plutôt qu’uniquement à la fin du cours
* **Combiner avec les compétences** — Utilisez les portfolios en parallèle du système de compétences/certificats pour constituer un dossier de compétences complet
