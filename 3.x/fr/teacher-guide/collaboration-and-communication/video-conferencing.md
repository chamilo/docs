# Visioconférence

Chamilo s'intègre aux plateformes de visioconférence pour vous permettre d'animer des sessions en direct directement depuis votre cours. Les plateformes prises en charge incluent **BigBlueButton** et **Zoom**.

Pour un appel direct entre deux utilisateurs individuels dans le **chat flottant de la plateforme**, voir [Appels vidéo individuels](../../student-guide/video-calls.md). Cette fonctionnalité WebRTC est distincte des réunions de cours planifiées et ne nécessite pas de réunion BigBlueButton ou Zoom.

> La visioconférence doit être configurée par l'administrateur de votre plateforme. Si vous ne voyez pas l'outil de visioconférence dans votre cours, contactez votre administrateur.

## Démarrer une session vidéo

1. Ouvrez l'outil **Visioconférence** <img src="../../.gitbook/assets/icons/mdi-video.svg" alt="Vidéo" data-size="line"> depuis la page d'accueil du cours (ou depuis la barre latérale)
2. Cliquez sur **Démarrer une réunion** (ou sur un bouton similaire selon la plateforme configurée)
3. Une nouvelle salle de visioconférence s'ouvrira dans un nouvel onglet du navigateur

## Inviter les apprenants

Une fois la réunion en cours, les apprenants inscrits peuvent la rejoindre en :

* Cliquant sur le même outil **Visioconférence** dans la page d'accueil de leur cours
* Cliquant sur le lien de participation figurant dans une annonce ou un message que vous leur envoyez

## BigBlueButton

Si votre plateforme utilise le plugin BigBlueButton, la réunion elle-même se déroule dans BigBlueButton, où les fonctionnalités habituelles de conférence (audio/vidéo, partage d'écran, tableau blanc, chat en réunion, salles de sous-groupes) sont disponibles. Le plugin Chamilo ajoute spécifiquement :

* **Gestion des enregistrements** — Si l'enregistrement est activé par l'administrateur, les enregistrements réalisés pendant la session sont listés dans le cours afin que les apprenants puissent les revoir
* **Préchargement de documents de présentation** — Joignez un fichier de présentation à une réunion afin qu'il soit chargé dans BigBlueButton à l'ouverture de la salle
* **Intégration au calendrier** — Les réunions planifiées apparaissent dans l'agenda du cours
* **Salles de cours / de groupe / globales** — Animez une salle unique pour l'ensemble du cours, des salles de groupe distinctes ou une salle à l'échelle de la plateforme

## Intégration Zoom

Si votre plateforme utilise Zoom, les réunions sont créées et gérées via l'interface de Zoom. Chamilo fournit le point d'intégration permettant de lancer et de rejoindre les réunions depuis le cours.

## Conseils

* **Planifier à l'avance** — Utilisez l'outil Agenda pour planifier les sessions vidéo et envoyer des rappels
* **Tester votre configuration** — Vérifiez votre microphone et votre caméra avant la session
* **Enregistrer pour les apprenants absents** — Si l'enregistrement est activé, partagez le lien de l'enregistrement après la session pour les apprenants qui n'ont pas pu y assister
* **Combiner avec d'autres outils** — Partagez les fichiers de présentation dans Documents avant la session, puis poursuivez avec une discussion dans le Forum
