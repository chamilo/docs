# Votre profil

Votre profil dans Chamilo contient vos informations personnelles et vos préférences. Les autres utilisateurs de la plateforme peuvent voir certaines parties de votre profil selon vos paramètres de visibilité.

## Accéder à votre profil

Cliquez sur votre **avatar** dans le coin supérieur droit de la barre supérieure, puis sélectionnez **Profil** dans le menu déroulant. Vous pouvez également y accéder depuis la section **Réseau social** de la barre latérale.

![Le menu déroulant de l'avatar utilisateur affichant le profil, les paramètres du compte et les options de déconnexion](/.gitbook/assets/user-avatar-dropdown.png)

## Informations du profil

Votre page de profil peut afficher (selon la configuration) :

* **Avatar** — Votre photo de profil. Cliquez sur **Modifier le profil** pour la changer.
* **Nom complet** — Votre prénom et nom tels qu'ils sont enregistrés sur la plateforme.
* **E-mail** — Votre adresse e-mail. Les autres utilisateurs peuvent cliquer dessus pour vous envoyer un message dans Chamilo.
* **Langue** — Votre langue préférée.
* **Champs supplémentaires** — Selon la configuration de votre plateforme, vous pouvez voir des champs tels que le numéro de téléphone, l'identifiant Skype, le lien vers le profil LinkedIn, ou des champs personnalisés définis par votre administrateur.

## Modifier votre profil

Pour mettre à jour les informations de votre profil, cliquez sur **Modifier le profil**. Vous pouvez alors :

* Modifier votre nom, votre e-mail et votre mot de passe
* Téléverser ou changer votre avatar/photo
* Mettre à jour votre langue préférée
* Remplir les champs de profil supplémentaires (Skype, LinkedIn, etc.)
* Configurer les préférences de notification

Pour changer votre mot de passe, cliquez sur **Changer le mot de passe**. Pour des raisons de sécurité, vous devrez indiquer votre mot de passe actuel et votre nouveau mot de passe deux fois.

Si votre administrateur a activé l'option **authentification à deux facteurs** (`2fa_enable`) pour la plateforme, votre profil vous permettra d'activer la 2FA pour votre propre compte à l'aide d'une application d'authentification TOTP (Google Authenticator, Authy, 1Password, etc.). Une fois activée, le processus de connexion demandera le code à 6 chiffres basé sur le temps en plus de votre mot de passe.

## Données personnelles

Sous **Réseau social** > **Données personnelles**, vous pouvez consulter toutes les informations que Chamilo conserve à votre sujet. Cette section comprend :

* Un résumé de toutes les données collectées, organisées par catégorie
* Si votre organisation l'a activé, votre statut d'acceptation des **Conditions générales** de la plateforme
* Si votre organisation l'a activé, une option pour **retirer votre consentement** ou **supprimer le compte**, ce qui déclenchera une demande de suppression de compte que votre administrateur traitera

> Cette fonctionnalité est fournie afin de se conformer aux réglementations sur la protection des données. Contactez votre administrateur si vous avez des questions sur le traitement de vos données.
