# Cours de démonstration

À partir de Chamilo 3.0.0, chaque nouvelle installation est livrée avec deux cours prêts à l'emploi. Ils constituent à la fois des exemples de ce que vous pouvez créer avec Chamilo **et** des cours réellement utiles que vous pouvez proposer tels quels à vos collègues et à vos apprenants.

| Cours | Code | Public concerné |
|--------|------|---------------|
| **AI Act** | `AIACT` | Toute organisation concernée par le règlement européen sur l'IA (AI Act), dont le personnel doit acquérir une culture de l'IA et comprendre ses obligations. Le parcours d'apprentissage est *Sensibilisation au règlement sur l'IA pour les organisations européennes*. |
| **Utiliser Chamilo** | `USINGCHAMILO` | Toute organisation qui commence à utiliser Chamilo : enseignants, apprenants et administrateurs qui souhaitent une visite guidée de la plateforme. Le parcours d'apprentissage est *Premiers pas avec Chamilo 3.0*. |

Vous les trouverez dans le catalogue de cours et dans votre liste **Mes cours** si vous y avez été inscrit.

![La page Mes cours, où le cours de démonstration AI Act apparaît sous forme de carte de cours](../../.gitbook/assets/demo-courses-list.png)

## Multilingues par conception

Les deux cours sont disponibles en **26 langues**, principalement les langues des pays concernés par le règlement sur l'IA. Les apprenants n'ont rien à choisir : chaque personne voit automatiquement le cours dans la langue de son propre profil. Cela fonctionne grâce à la fonctionnalité de [contenu multilingue](../adding-content/multi-language-content.md), de sorte que le même cours (et le même parcours d'apprentissage) contient toutes les versions linguistiques à la fois.

![La page Description du cours du cours AI Act, telle qu'un apprenant la voit, en anglais](../../.gitbook/assets/demo-ai-act-description.png)

La même page pour un apprenant dont la langue du profil est l'espagnol :

![La même page Description du cours du cours AI Act, affichée en espagnol après que la langue du profil a été changée en espagnol](../../.gitbook/assets/demo-ai-act-description-es.png)

{% hint style="info" %}
Comme les versions linguistiques font partie du contenu, le cours continue de fonctionner dans la langue de l'apprenant, même si le cours lui-même a été créé dans une autre langue. Si votre propre langue ne figure pas parmi les 26, les apprenants verront le cours dans la langue par défaut du cours.
{% endhint %}

## Contenu des cours

Les deux cours sont construits autour d'un unique [parcours d'apprentissage](../adding-content/learning-paths.md) qui guide les apprenants pas à pas, avec des documents, des images et des mini-tests. La page d'accueil du cours est volontairement réduite pour les apprenants : seuls les outils **Description du cours** et **Parcours d'apprentissage** sont visibles.

![Le parcours d'apprentissage AI Act ouvert dans le visualiseur, avec la liste des modules et des mini-tests à gauche et le premier module à droite](../../.gitbook/assets/demo-ai-act-learning-path.png)

En tant qu'enseignant, vous pouvez les ouvrir pour voir comment un cours réel est structuré : comment un parcours d'apprentissage est organisé, comment le contenu est rédigé une seule fois pour de nombreuses langues, comment les tests servent à vérifier la compréhension, et comment la page d'accueil du cours peut rester minimale.

## Les utiliser dans votre organisation

* **Les proposer tels quels.** Demandez à votre administrateur de s'assurer que le cours est visible et inscrivez-y vos apprenants (voir [Inscription des utilisateurs](../assessing-learners/subscribing-users.md)). Le cours *AI Act* peut servir de formation à la culture de l'IA de votre organisation, et le cours *Utiliser Chamilo* de cours d'intégration pour les nouveaux enseignants et apprenants.
* **Les copier et les adapter.** Utilisez les outils de maintenance des cours pour créer une copie, puis modifiez cette copie afin d'y ajouter vos propres politiques, votre identité visuelle ou vos exemples. Conserver l'original intact vous permettra de comparer ultérieurement.
* **S'en inspirer.** Examinez la façon dont ils sont construits avant de commencer votre premier cours.

## Les masquer ou les supprimer

Vous n'êtes pas obligé de conserver ces cours. Votre administrateur peut les masquer du catalogue, modifier leur visibilité ou les supprimer complètement, sans affecter le reste de la plateforme. Voir [Cours de démonstration](../../admin-guide/courses/demo-courses.md) dans le Guide de l'administrateur.
