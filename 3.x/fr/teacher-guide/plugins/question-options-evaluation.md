# Évaluation des options de question

Évaluation des options de question <img src="../../.gitbook/assets/icons/mdi-calculator-variant.svg" alt="Évaluation des options de question" data-size="line"> vous permet d'appliquer une formule de notation négative (pénalité) au calcul du score d'un test, au lieu du comportement par défaut de Chamilo qui consiste simplement à additionner les bonnes réponses.

## Définir une formule

Une fois activée, une icône supplémentaire apparaît à côté de chaque test dans la liste de l'outil **Tests** du cours. En cliquant dessus, un petit formulaire s'ouvre dans lequel vous choisissez l'une des options suivantes :

* **Aucune formule** — notation normale de Chamilo (par défaut)
* **Recalculer les scores des questions** — redistribue la pondération des options sans pénalité
* **Réussites − Échecs**
* **Réussites − Échecs / 2**
* **Réussites − Échecs / 3**

La formule choisie s'applique uniquement à ce test précis.

> Ce paramètre ne modifie pas les pondérations des questions ou des réponses elles-mêmes — il change la manière dont le score final est calculé. Si le plugin est désactivé, ou si aucune formule n'est sélectionnée, Chamilo revient à son mode de notation d'origine.

## Conseils

* **Tester d'abord sur une copie** — Modifier une formule peut changer les scores que les étudiants obtiennent à ce test ; essayez-la sur un test dupliqué avant de l'appliquer à un test déjà en cours d'utilisation
* **Expliquer le changement aux étudiants** — Une formule de pénalité peut surprendre si les apprenants sont habitués à une notation fondée uniquement sur les bonnes réponses ; mentionnez-la dans vos consignes
