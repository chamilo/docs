# Positionnement

Le positionnement <img src="../../.gitbook/assets/icons/mdi-radar.svg" alt="Positionnement" data-size="line"> ajoute un processus d'auto-évaluation avant/après : choisissez un test comme **test initial** et un autre comme **test final** (souvent une copie du même test), et Chamilo affiche l'évolution du score de chaque apprenant entre les deux sur un graphique radar.

## Accéder à l'outil

Une fois activé, un outil **Positionnement** apparaît sur la page d'accueil de votre cours. Il répertorie les tests éligibles du cours avec les boutons **Sélectionner comme test initial** / **Sélectionner comme test final**, un raccourci vers les résultats de chaque test, et le graphique radar comparant les scores moyens initiaux et finaux.

## Quels tests sont éligibles

Seuls les tests qui remplissent ces trois critères apparaissent comme sélectionnables :

* Au moins 3 catégories de questions
* Le type de page de résultats du test est défini sur **radar**
* Une seule tentative est autorisée

Si un test que vous vous attendez à voir est absent de la liste, vérifiez d'abord ces trois paramètres sur ce test.

## Imposer l'ordre

Votre administrateur peut en outre configurer, à l'échelle de la plateforme :

* **Bloquer les autres outils du cours** jusqu'à ce que l'apprenant ait terminé le test initial
* Un **seuil de déverrouillage du test final** — un pourcentage moyen minimum d'achèvement du parcours d'apprentissage requis avant que le test final ne se déverrouille

## Conseils

* **Configurez tôt le type de résultat radar** — Comme l'éligibilité dépend des paramètres du test définis lors de sa création, prévoyez le positionnement avant de finaliser les catégories et le type de page de résultats de votre test, et non après
* **Utilisez une véritable copie pour le test final** — Comparer un test avec lui-même n'apporte pas grand-chose ; le test final doit couvrir les mêmes catégories pour que le graphique radar soit pertinent
