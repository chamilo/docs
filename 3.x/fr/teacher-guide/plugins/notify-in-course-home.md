# Notification sur la page d'accueil du cours

Notification sur la page d'accueil du cours <img src="../../.gitbook/assets/icons/mdi-bell-ring-outline.svg" alt="Notification sur la page d'accueil du cours" data-size="line"> vous permet d'afficher un avis en fenêtre contextuelle à toutes les personnes qui visitent la page d'accueil de votre cours — utile pour une annonce, un avis de lecture obligatoire ou une étape « cliquez ici pour continuer ».

## Définir une notification

Une fois la fonction activée, les **Paramètres** <img src="../../.gitbook/assets/icons/mdi-cog.svg" alt="Paramètres" data-size="line"> de votre cours comportent un bouton **Définir une notification sur la page d'accueil**. Il ouvre un formulaire dans lequel vous rédigez l'avis (texte enrichi) et pouvez éventuellement définir un **Lien d'expiration**.

* **Avec un lien d'expiration** — La fenêtre contextuelle affiche un bouton pointant vers ce lien et continue de réapparaître jusqu'à ce qu'un apprenant clique dessus
* **Sans lien** — L'avis réapparaît pour chaque visiteur, chaque fois qu'il ouvre la page d'accueil du cours

Utilisez **Supprimer la notification sur la page d'accueil du cours** pour la retirer.

## Conseils

* **Une seule notification par cours** — En créer une nouvelle remplace celle qui était déjà présente ; il n'est pas possible d'en mettre plusieurs en file d'attente
* **Prévisualisez votre mise en forme** — L'avis est affiché en HTML brut dans une fenêtre contextuelle ; vérifiez donc que le texte enrichi s'affiche comme vous l'attendez avant de le publier
* **Utilisez le lien d'expiration pour tout contenu limité dans le temps** — Sans lui, la même notification continue de s'afficher indéfiniment, ce qui peut devenir répétitif pour les apprenants qui reviennent
