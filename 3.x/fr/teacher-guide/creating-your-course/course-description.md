# Description du cours

L’outil **Description du cours** <img src="../../.gitbook/assets/icons/mdi-apple-safari.svg" alt="Course description" data-size="line"> vous permet de rédiger une description structurée et en plusieurs sections de votre cours — ses objectifs, sa méthodologie, ses supports, et plus encore. Contrairement au bandeau libre **Introduction du cours** de votre [page d’accueil du cours](README.md#the-course-homepage), que seuls vos apprenants inscrits voient, la description du cours est ce que les apprenants potentiels voient *avant* de s’inscrire, depuis le catalogue de cours.

Une fois inscrits, les apprenants peuvent toujours s’y référer depuis le cours — si vous laissez l’outil visible pour eux, c’est un endroit pratique pour consulter des informations pratiques telles que la structure générale du cours ou l’identité des enseignants, sans avoir à vous le demander directement. Les apprenants inscrits peuvent consulter les sections que vous avez rédigées, mais ne peuvent pas les ajouter, les modifier ni les supprimer.

## Accéder à l’outil

Ouvrez l’outil **Description du cours** <img src="../../.gitbook/assets/icons/mdi-apple-safari.svg" alt="Course description" data-size="line"> depuis la grille d’outils de la page d’accueil du cours.

## Les huit sections

Une description de cours se compose de jusqu’à huit sections indépendantes. Chacune est facultative — ne remplissez que celles qui sont pertinentes pour votre cours :

| Section | Question directrice |
|---------|-------------------|
| **Description** | Quel est l’objectif du cours ? Existe-t-il des prérequis ? Comment cette formation est-elle liée aux autres cours ? |
| **Objectifs** | Quels devraient être les résultats finaux une fois que l’apprenant a terminé le cours ? Quelles activités sont réalisées pendant le cours ? |
| **Thèmes** | Comment le cours progresse-t-il ? Où l’apprenant doit-il porter une attention particulière ? Existe-t-il des difficultés identifiables dans la compréhension de certains domaines ? Combien de temps faut-il consacrer aux différents domaines du cours ? |
| **Méthodologie** | Quelles méthodes et activités permettent d’atteindre les objectifs du cours ? Quel serait le calendrier ? |
| **Supports de cours** | Existe-t-il un manuel de cours, un recueil d’articles, une bibliographie, une liste de liens sur Internet ? |
| **Ressources** | Prenez en compte les cours, les tuteurs, un service d’assistance technique, les enseignants et/ou les supports disponibles. |
| **Évaluation** | Comment les apprenants seront-ils évalués ? Existe-t-il des stratégies à développer pour maîtriser le sujet ? |
| **Autre** | Tout ce qui ne correspond pas aux catégories ci-dessus. Vous pouvez ajouter autant de sections **Autre** que nécessaire, chacune avec son propre titre personnalisé. |

## Ajouter une section

1. Dans la barre d’outils de l’outil, cliquez sur l’icône du type de section que vous souhaitez rédiger
2. Chamilo affiche une boîte **Aide** avec la question directrice de cette section — utilisez-la pour décider de ce que vous allez écrire
3. Rédigez votre contenu dans l’éditeur de texte enrichi (prend en charge la mise en forme, les images, les liens, les vidéos intégrées et d’autres contenus enrichis). Si votre plateforme l’a activé, vous pouvez également rédiger plusieurs versions linguistiques de la même section, et chaque apprenant ne verra automatiquement que la sienne — voir [Contenu multilingue](../adding-content/multi-language-content.md).
4. Enregistrer

Chaque section que vous ajoutez apparaît sous forme de carte distincte dans l’outil. Utilisez les icônes **Modifier** <img src="../../.gitbook/assets/icons/mdi-pencil.svg" alt="Edit" data-size="line"> et **Supprimer** <img src="../../.gitbook/assets/icons/mdi-delete.svg" alt="Delete" data-size="line"> d’une carte pour la mettre à jour ou la retirer ultérieurement.

## Lien vers le catalogue de cours

C’est la principale raison de remplir une description de cours : elle alimente directement le catalogue **Explorer d’autres cours** que les visiteurs et les apprenants potentiels parcourent.

* Un cours **sans** section de description remplie s’affiche sous forme de carte simple dans le catalogue.
* Un cours avec **au moins une** section de description devient cliquable — cliquer sur son image, son titre ou son bouton d’information ouvre une fenêtre contextuelle détaillée listant chaque section que vous avez rédigée, dans le même ordre que ci-dessus.

Cela donne aux apprenants potentiels une base réelle pour décider de s’inscrire, au lieu d’un simple titre et d’une vignette.

> La disponibilité de cette fenêtre contextuelle dépend d’un paramètre à l’échelle de la plateforme. Si vos descriptions n’apparaissent pas aux apprenants potentiels dans le catalogue, demandez à votre administrateur de vérifier le paramètre **Afficher les descriptions de cours** (`show_courses_descriptions_in_catalog`) sous **Administration > Paramètres de configuration > Catalogue de cours**.

## Conseils

* **Donnez la priorité aux sections Description et Objectifs** — ce sont celles que la plupart des apprenants potentiels lisent en premier lorsqu’ils décident de s’inscrire.
* **Gardez-la à jour** — mettez à jour la description de votre cours chaque fois que le contenu du cours change de manière significative, afin que le catalogue reflète toujours ce que les apprenants obtiendront réellement.
* **Utilisez le contenu enrichi avec parcimonie** — les images et la mise en forme améliorent la lisibilité, mais une fenêtre contextuelle longue et encombrée peut être plus difficile à parcourir que quelques paragraphes clairs.
