# Tickets de support

L’outil **Tickets** est un système d’assistance intégré qui permet aux utilisateurs de soumettre des demandes de support et de suivre leur résolution. Selon la configuration de votre plateforme, vous pouvez l’utiliser en tant que **demandeur** (en soumettant des tickets pour vous-même ou pour vos apprenants) ou en tant qu’**agent de support** (en répondant aux tickets assignés à votre catégorie).

## Organisation du système

Les tickets appartiennent à des **projets**, eux-mêmes subdivisés en **catégories**. Chaque catégorie peut avoir un ou plusieurs agents de support qui lui sont assignés. Lorsqu’un ticket est soumis, il est automatiquement acheminé vers un agent disponible dans la catégorie sélectionnée.

Les catégories par défaut comprennent :

| Catégorie | Description |
|----------|-------------|
| Enrollment | Questions et problèmes relatifs à l’inscription à un cours ou à une session |
| General information | Questions générales sur la plateforme |
| Requests and paperwork | Demandes administratives et documentation |
| Academic Incidents | Problèmes liés aux examens, aux devoirs ou aux tâches |
| Virtual campus | Problèmes techniques avec la plateforme |
| Online evaluation | Problèmes concernant une évaluation de cours spécifique (nécessite la sélection d’un cours) |

## Accéder à l’outil Tickets

Si votre administrateur a activé le lien vers les tickets, une icône de ticket <img src="/.gitbook/assets/icons/mdi-ticket-account.svg" alt="Ticket" data-size="line"> apparaît dans la barre de navigation supérieure. Cliquez dessus pour accéder directement au formulaire de soumission de ticket.

Vous pouvez également accéder à vos tickets depuis le menu principal sous **Support** ou **Tickets**, selon la configuration de votre plateforme.

## Soumettre un ticket

Pour ouvrir une nouvelle demande de support :

1. Cliquez sur **New ticket** (ou sur l’icône de ticket dans la barre supérieure).
2. Sélectionnez la **catégorie** qui correspond le mieux à votre problème.
3. Si la catégorie l’exige (par exemple, Online evaluation), sélectionnez le **cours** concerné.
4. Saisissez un **objet** — un court résumé du problème.
5. Rédigez votre **message** décrivant le problème en détail.
6. Joignez éventuellement des fichiers (captures d’écran, documents) pour aider l’agent de support à comprendre le problème.
7. Cliquez sur **Submit**.

Le ticket se voit attribuer un identifiant et est acheminé vers un agent de support. Vous recevrez une notification lorsque l’agent répondra.

## Suivre vos tickets

Depuis la liste des tickets, vous pouvez voir tous les tickets que vous avez soumis et leur statut actuel :

| Statut | Signification |
|--------|---------|
| New | Vient d’être soumis, pas encore examiné |
| Pending | En cours d’examen par un agent de support |
| Unconfirmed | En attente de confirmation ou d’informations complémentaires |
| Forwarded | Transféré à une autre équipe ou à un autre agent |
| Closed | Résolu |

Cliquez sur n’importe quel ticket pour lire le fil de conversation complet et ajouter une réponse.

## Répondre à un ticket

Une fois un ticket ouvert, vous et l’agent de support échangez des messages au sein du même fil. Pour ajouter une réponse :

1. Ouvrez le ticket depuis votre liste.
2. Faites défiler jusqu’au champ de réponse en bas.
3. Rédigez votre réponse et joignez des fichiers si nécessaire.
4. Cliquez sur **Send**.

Les deux parties reçoivent des notifications lorsqu’un nouveau message est ajouté au fil.

## Traiter les tickets en tant qu’agent de support

Si votre administrateur vous a assigné à une ou plusieurs catégories de tickets, vous verrez les tickets entrants des apprenants ou des collègues dans votre file d’attente.

Pour répondre à un ticket assigné :

1. Ouvrez votre liste de tickets — les tickets assignés apparaissent aux côtés des tickets que vous avez soumis.
2. Cliquez sur un ticket pour lire le message du demandeur.
3. Rédigez une réponse et cliquez sur **Send**. Le statut du ticket se met à jour automatiquement.
4. Lorsque le problème est résolu, changez le statut en **Closed**.

Vous pouvez également modifier la **priorité** d’un ticket (Low, Normal, High) pour aider à trier votre file d’attente.

> L’accès aux catégories de tickets est contrôlé par l’administrateur de la plateforme. Si vous devez être ajouté comme agent de support pour une catégorie, contactez votre administrateur. Consultez le [paramétrage des tickets](../admin-guide/platform-settings/ticket-settings.md) du Guide administrateur pour les options de configuration.
