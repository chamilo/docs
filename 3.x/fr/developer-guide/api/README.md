# API

Chamilo 3.0 expose une API REST construite sur **API Platform 4**. L'API fournit un accès programmatique aux ressources de la plateforme et constitue la même API que celle utilisée par le frontend Vue.

* **[Authentification](authentication.md)** — Authentification basée sur des jetons JWT
* **[Référence des points de terminaison](endpoints-reference.md)** — Vue d'ensemble des ressources d'API disponibles
* **[Actions personnalisées](custom-actions.md)** — Points de terminaison spécialisés au-delà du CRUD standard
* **[Inscription des apprenants aux sessions](session-students.md)** — Ajouter/retirer des apprenants spécifiques d'une session avec des droits d'administrateur
* **[Abonnements aux classes](class-subscriptions.md)** — Lire/remplacer l'appartenance à une classe et les sessions/cours associés
* **[Administration des cours](course-administration.md)** — Mettre à jour les métadonnées des cours et supprimer des cours en tant qu'administrateur
* **[Webhooks](webhooks.md)** — Notifications événementielles vers des systèmes externes
