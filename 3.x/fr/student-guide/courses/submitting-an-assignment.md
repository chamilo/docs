# Soumettre un devoir

L'outil **Travaux** (parfois appelé « publications des étudiants » ou « travaux ») est l'endroit où vous remettez dissertations, projets, rapports ou tout autre travail sous forme de fichier ou de texte, afin que votre enseignant le note.

## Soumettre votre travail

Ouvrez l'outil **Travaux** <img src="../../.gitbook/assets/icons/mdi-inbox-full.svg" alt="Travaux" data-size="line"> depuis la page d'accueil du cours, puis ouvrez le devoir concerné. Lisez attentivement la description — elle contient les consignes de votre enseignant sur ce qu'il faut remettre et sur la manière dont le travail sera évalué. Ensuite :

1. Cliquez sur **Téléverser un fichier** (ou sur le bouton de remise)
2. Selon la configuration choisie par votre enseignant, sélectionnez un fichier depuis votre ordinateur, rédigez votre remise directement sous forme de texte, ou les deux
3. Ajoutez un commentaire facultatif à l'intention de votre enseignant
4. Envoyez

Une fois la remise effectuée, vous voyez une confirmation que votre travail a bien été transmis. Si votre enseignant l'autorise, vous pouvez modifier votre remise ultérieurement — sinon, votre première remise est définitive ; vérifiez donc soigneusement avant d'envoyer.

## Rédiger et remettre un texte en ligne

Si votre enseignant autorise les remises de texte, choisissez **Texte** lorsque les options fichier et texte sont toutes deux disponibles. Donnez un titre à la remise, rédigez votre réponse dans l'éditeur de texte enrichi, puis sélectionnez **Envoyer**. L'éditeur conserve la mise en forme prise en charge dans une remise HTML ; Chamilo assainit le contenu avant de le stocker sous forme de fichier `.html`.

Si votre enseignant n'autorise que les fichiers, vous ne verrez pas l'éditeur de texte. La remise reste soumise aux règles de date limite, de date butoir et de nombre de remises autorisées du devoir. Votre enseignant peut prévisualiser le contenu HTML lors de la correction. Voir [PR #9410](https://github.com/chamilo/chamilo-lms/pull/9410).

## Dates limites

Les devoirs peuvent comporter deux dates distinctes :

* Une **date limite** — après cette date, votre remise est encore acceptée, mais signalée comme en retard à votre enseignant
* Une **date butoir** — après cette date, toute remise devient impossible

Si un devoir apparaît dans l'Agenda, il s'agit généralement de sa date limite — il vaut la peine de vérifier également cet endroit si vous n'êtes pas certain de l'échéance.

## Consulter votre note et les commentaires

Une fois que votre enseignant a examiné votre remise, vous verrez votre **note** et les éventuels **commentaires de retour** qu'il a rédigés. Certains enseignants joignent également un **fichier corrigé** — une version annotée de ce que vous avez remis — vérifiez donc la présence d'une pièce jointe téléchargeable à côté de votre note. Si le devoir est lié au carnet de notes, votre note compte également dans la note globale du cours.

## Voir les autres remises

Par défaut, votre remise n'est visible que par vous et votre enseignant. Certains enseignants choisissent de rendre les remises visibles pour l'ensemble du cours — dans ce cas, vous pouvez également voir le travail de vos camarades (et eux, le vôtre).

## Conseils

* **Remettez avant la date limite, et non avant la date butoir** — une remise tardive est toujours enregistrée comme en retard, même si elle est acceptée.
* **Revenez après la date d'échéance** pour consulter votre note et les commentaires — la correction n'est pas nécessairement immédiate.
* **Si vous ne pouvez pas remettre du tout**, la date butoir de ce devoir est probablement dépassée — contactez votre enseignant si vous pensez qu'il s'agit d'une erreur.
