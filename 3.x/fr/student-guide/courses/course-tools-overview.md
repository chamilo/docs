# S'orienter dans un cours

Une fois un cours ouvert, vous verrez sa page d'accueil avec une grille d'icônes d'outils. Cette page explique ce que chaque outil signifie pour vous en tant qu'apprenant, et renvoie vers l'endroit où la fonctionnalité sous-jacente est décrite plus en détail.

Seuls les outils que votre enseignant a rendus visibles aux apprenants apparaissent dans votre grille — votre enseignant peut voir des outils supplémentaires, masqués, qui ne vous sont pas affichés. Si un outil que vous attendez n'est pas présent, il est peut-être simplement masqué, ou désactivé pour l'ensemble du cours ; demandez à votre enseignant.

## Outils que vous ne verrez pas — et un qui ne fonctionnera pas

Quelques entrées existent uniquement pour que les enseignants et les administrateurs de cours configurent le cours lui-même — les paramètres du cours, la maintenance du cours (sauvegarde/importation/exportation), l’éditeur de la page d’accueil du cours et (sur la plupart des plateformes) l’outil Blog se trouvent dans un menu « Plus d’actions » qui n’apparaît qu’aux personnes disposant de droits de modification sur le cours. En tant qu’apprenant, vous ne verrez pas du tout ce menu.

La tuile **Rapports** est un cas particulier : elle apparaît bien dans votre grille, mais elle ouvre la vue de suivi de toute la classe destinée aux enseignants ; cliquer dessus vous affiche donc un message d’accès refusé plutôt que quelque chose d’utile :

![Cliquer sur la tuile Rapports en tant qu’apprenant affiche un message d’accès refusé](../../.gitbook/assets/student-course-reporting-denied.png)

Pas d’inquiétude — votre propre progression est disponible ailleurs : depuis **Ma progression** dans la barre latérale principale (voir [Comprendre l’interface](../getting-started/understanding-the-interface.md) et [Ma progression](../my-progress.md)), ainsi que depuis les outils **Progression du cours** et **Évaluations** ci-dessus, qui affichent tous deux vos propres données.

Si votre cours a les fonctionnalités d’IA activées, vous remarquerez peut-être aussi que l’option « analyseur IA » de l’enseignant (utilisée pour préentraîner le Tuteur IA sur le contenu propre du cours) est différente du chat **Tuteur IA** destiné aux apprenants — voir [Chatbot Tuteur IA](ai-tutor.md).

## Conseils

* **Un outil manquant ?** Demandez à votre enseignant — il est très probablement masqué ou désactivé plutôt que défectueux.
* **La description du cours et les annonces** peuvent être entièrement désactivées par votre enseignant ; dans ce cas, elles n’apparaîtront pour personne, enseignant compris.
* **Tout ici peut varier selon le cours** — votre enseignant décide quels outils sont actifs et visibles pour chaque cours individuellement.
