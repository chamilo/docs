# Mon relevé de notes

Si votre plateforme a activé les relevés de notes académiques, vous pouvez consulter l'historique de vos cours terminés et certifiés, et télécharger un relevé non officiel. Votre établissement peut également délivrer des relevés officiels signés.

## Ouvrir votre relevé de notes

1. Connectez-vous et ouvrez **Mon relevé de notes** dans la navigation supérieure (lorsque cette option est disponible).
2. Ou accédez à `/transcript` sur votre portail Chamilo une fois connecté.
3. Consultez vos cours terminés, les codes de cours, les notes, les dates, les heures, la note globale et le GPA.
4. Sélectionnez **Télécharger le relevé non officiel** pour enregistrer un PDF de l'enregistrement actuel.

L'enregistrement est constitué à partir des certificats éligibles générés par l'évaluation racine (carnet de notes) des cours et des sessions auxquels vous êtes encore inscrit. Un cours peut être absent s'il n'a pas produit de certificat qualifiant. Si aucun cours ne remplit les conditions, Chamilo affiche **Aucun cours terminé pour le moment.**

Les lettres de note et la moyenne des points (GPA) dépendent du barème de notation configuré par votre établissement. Le GPA est calculé comme une moyenne non pondérée des points de note des cours listés, sauf si votre administrateur modifie la manière dont les cours et les notes sous-jacents sont enregistrés.

## Relevés officiels

Sous **Relevés officiels**, vous pouvez trouver les versions signées délivrées pour vous par le personnel autorisé, lorsqu'il en existe. Chaque version enregistre la date de délivrance et l'émetteur. Utilisez **Télécharger** pour obtenir son PDF et **Vérifier** pour contrôler la signature numérique sur sa page de vérification.

Une version officielle est un instantané de votre dossier au moment de sa délivrance. Elle n'est **pas** mise à jour automatiquement lorsque des notes ou des cours ultérieurs changent ; votre établissement peut délivrer une version plus récente. Le personnel autorisé peut révoquer une version antérieure, et sa page de vérification publique indiquera alors cette révocation.

Vous ne pouvez pas délivrer ni révoquer vous-même des relevés officiels. Adressez-vous à votre établissement si vous avez besoin d'un relevé signé nouveau ou corrigé. Partagez les liens publics de vérification avec discernement : une personne disposant du lien peut être en mesure de consulter les détails d'un relevé signé valide.

Si **Mon relevé de notes** est absent, cette fonctionnalité n'est peut-être pas activée sur votre portail. Pour la configuration administrative, voir [Relevés de notes académiques](../../admin-guide/users/academic-transcripts.md).
