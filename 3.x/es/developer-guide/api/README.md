# API

Chamilo 3.0 expone una API REST construida sobre **API Platform 4**. La API proporciona acceso programático a los recursos de la plataforma y es la misma API que utiliza el frontend Vue.

* **[Autenticación](authentication.md)** — Autenticación basada en tokens JWT
* **[Referencia de endpoints](endpoints-reference.md)** — Descripción general de los recursos de API disponibles
* **[Acciones personalizadas](custom-actions.md)** — Endpoints especializados más allá del CRUD estándar
* **[Webhooks](webhooks.md)** — Notificaciones basadas en eventos hacia sistemas externos
