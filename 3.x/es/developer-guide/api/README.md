# API

Chamilo 3.0 expone una API REST construida sobre **API Platform 4**. La API proporciona acceso programático a los recursos de la plataforma y es la misma API utilizada por el frontend de Vue.

* **[Autenticación](authentication.md)** — Autenticación basada en tokens JWT
* **[Referencia de endpoints](endpoints-reference.md)** — Visión general de los recursos de la API disponibles
* **[Acciones personalizadas](custom-actions.md)** — Endpoints especializados más allá del CRUD estándar
* **[Inscripción de estudiantes en sesiones](session-students.md)** — Añadir/eliminar estudiantes específicos de una sesión con permisos de administrador
* **[Suscripciones de clases](class-subscriptions.md)** — Leer/reemplazar la pertenencia a clases y las sesiones/cursos vinculados
* **[Administración de cursos](course-administration.md)** — Actualizar los metadatos de los cursos y eliminar cursos como administrador
* **[Webhooks](webhooks.md)** — Notificaciones basadas en eventos hacia sistemas externos
