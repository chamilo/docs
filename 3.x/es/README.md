# Documentación de Chamilo 3.0

Bienvenido a la documentación oficial de **Chamilo 3.0**, la plataforma de e-learning de código abierto.

Esta documentación está organizada en cuatro guías, cada una dirigida a un público específico:

* [**Guía del profesor**](teacher-guide/) — Para instructores y formadores: crear cursos, añadir contenido, evaluar a los alumnos y hacer seguimiento del progreso.
* [**Guía de administración**](admin-guide/) — Para administradores de la plataforma: instalar, configurar y gestionar la plataforma Chamilo.
* [**Guía del estudiante**](student-guide/) — Para alumnos: unirse a cursos, seguir itinerarios de aprendizaje, realizar pruebas y hacer seguimiento de su propio progreso.
* [**Guía del desarrollador**](developer-guide/) — Para desarrolladores: comprender la arquitectura, crear plugins, usar la API y contribuir al proyecto.

## Novedades de Chamilo 3.0

Chamilo 3.0 es una versión mayor centrada en la enseñanza asistida por IA, el refuerzo de la seguridad y una modernización completa del ecosistema de plugins:

* **Herramientas de enseñanza impulsadas por IA** — Un analizador de calidad de cursos, un tutor de IA que responde preguntas sobre el uso de la plataforma, un coach de IA de éxito del estudiante con recomendaciones personalizadas por alumno, generación por IA de ilustraciones de curso y pruebas rápidas, y calificación asistida por IA
* **Servidor Model Context Protocol (MCP)** — Permite a los clientes de IA crear y gestionar directamente cursos, pruebas, itinerarios de aprendizaje, encuestas y más
* **Refuerzo de la seguridad** — Supervisión nativa de la integridad de archivos, además de decenas de correcciones de control de acceso en cursos, sesiones y la API
* **Modernización completa del ecosistema de plugins** — Todos los plugins de la versión 1.11.x reactivados, con una interfaz de gestión de plugins rediseñada
* **URL jerárquicas y gestión multisitio** — Un panel multi-URL global, además de una gestión visual mediante mapa geográfico para branches y salas
* **Itinerarios de aprendizaje y pruebas mejorados** — Modo de prueba adaptativo progresivo, edición en vivo con OnlyOffice, delimitación adaptativa de zonas sensibles, y soporte ampliado de SCORM 2004
* **Evaluaciones y certificados** — Fechas de caducidad de certificados con recordatorios, y modos de calificación personalizables
* **REST API preparada para móviles** — Un backend modernizado pensado para aplicaciones móviles e integraciones de terceros
