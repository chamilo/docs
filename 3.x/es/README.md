# Documentación de Chamilo 3.0

Bienvenido a la documentación oficial de **Chamilo 3.0**, la plataforma de e-learning de código abierto.

Esta documentación está organizada en tres guías, cada una dirigida a un público específico:

* [**Guía del profesor**](teacher-guide/) — Para instructores y formadores: crear cursos, añadir contenido, evaluar a los alumnos y hacer seguimiento del progreso.
* [**Guía de administración**](admin-guide/) — Para administradores de la plataforma: instalar, configurar y gestionar la plataforma Chamilo.
* [**Guía del desarrollador**](developer-guide/) — Para desarrolladores: comprender la arquitectura, crear plugins, usar la API y contribuir al proyecto.

## Novedades de Chamilo 3.0

Chamilo 3.0 es una versión mayor con una interfaz completamente rediseñada y numerosas funcionalidades nuevas:

* **Interfaz moderna** — Desarrollada con Vue 3 y PrimeVue para una experiencia más rápida y receptiva
* **Herramientas impulsadas por IA** — Generar ejercicios, itinerarios de aprendizaje y obtener calificación asistida por IA
* **REST API** — REST API completa basada en API Platform con autenticación JWT
* **Nuevas opciones de autenticación** — OAuth2 (Azure, Keycloak, Facebook), aprovisionamiento de usuarios SCIM
* **LTI 1.3** — Conectar herramientas de aprendizaje externas de forma fluida
* **Almacenamiento en la nube** — Soporte nativo para Azure Blob, AWS S3 y Google Cloud Storage
* **Temas de color** — Personalización de la imagen de marca de la plataforma con soporte de temas
* **Integración con OnlyOffice** — Editar documentos de forma colaborativa dentro de la plataforma
