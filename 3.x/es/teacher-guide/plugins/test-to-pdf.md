# Test to PDF

Test to PDF <img src="../../.gitbook/assets/icons/mdi-file-pdf-box.svg" alt="Test to PDF" data-size="line"> exporta las preguntas de un test del curso a un PDF imprimible — solo preguntas, solo respuestas, o ambas juntas — útil para una versión en papel de un test.

## Acceso a la herramienta

Una vez habilitada, aparece una herramienta **Test to PDF** en la página de inicio de su curso, que enumera todos los tests del curso (o de la sesión). Cada fila ofrece tres acciones: **Download questions**, **Download answers** y **Download all**.

## Consejos

* **No todos los tipos de pregunta están soportados** — Solo un subconjunto de los tipos de pregunta de Chamilo (opción múltiple, verdadero/falso y formatos cerrados similares) se exportan correctamente; las preguntas abiertas o los tipos más complejos pueden no aparecer bien, o no aparecer en absoluto
* **Revise el resultado antes de imprimir un lote completo** — Revise el PDF generado de un test antes de imprimir en masa para una sesión de examen
