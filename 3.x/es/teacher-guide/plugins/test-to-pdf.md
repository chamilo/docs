# Test to PDF

Test to PDF <img src="../../.gitbook/assets/icons/mdi-file-pdf-box.svg" alt="Test to PDF" data-size="line"> exporta las preguntas de un ejercicio del curso a un PDF imprimible — solo las preguntas, solo las respuestas o ambas juntas — útil para disponer de una versión en papel de un ejercicio.

## Acceso a la herramienta

Una vez activada, aparece una herramienta **Test to PDF** en la página de inicio del curso, que enumera todos los ejercicios del curso (o de la sesión). Cada fila ofrece tres acciones: **Descargar preguntas**, **Descargar respuestas** y **Descargar todo**.

## Consejos

* **No se admiten todos los tipos de pregunta** — Solo un subconjunto de los tipos de pregunta de Chamilo (opción múltiple, verdadero/falso y formatos cerrados similares) se exporta correctamente; los tipos de pregunta abiertos o más complejos pueden no aparecer correctamente, o no aparecer en absoluto
* **Compruebe el resultado antes de imprimir un lote completo** — Revise el PDF generado de un ejercicio antes de imprimirlo en masa para una sesión de examen
