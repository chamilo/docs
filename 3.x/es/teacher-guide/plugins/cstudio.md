# Editor de contenido C-Studio

C-Studio <img src="/.gitbook/assets/icons/mdi-format-paint.svg" alt="C-Studio" data-size="line"> es un editor visual de contenido, de arrastrar y soltar, para itinerarios de aprendizaje. Permite crear páginas interactivas — bloques de texto, cuestionarios, actividades de arrastrar y soltar, completar huecos, imágenes con puntos calientes, tablas, audio y vídeo — sin escribir HTML, y exportar el resultado como un paquete SCORM.

## Acceso al editor

Una vez habilitado, C-Studio aparece como un tipo de contenido adicional al añadir un nuevo elemento a un **itinerario de aprendizaje**. Al seleccionarlo se abre el editor visual en lugar de los formularios de contenido habituales de Chamilo.

## Qué puede hacer

* Diseñar páginas con bloques de arrastrar y soltar y un selector visual de tema/color
* Añadir elementos interactivos: cuestionarios, arrastrar y soltar, imágenes con puntos calientes, tablas, audio y vídeo
* Utilizar asistentes de IA integrados para generar texto, imágenes o preguntas de cuestionario para una página
* Controlar el comportamiento de navegación de la página (ocultar el menú, desactivar el botón superior, reiniciar en cada intento)
* Exportar el contenido finalizado como un paquete SCORM, o publicarlo directamente como un elemento del itinerario de aprendizaje

## Consejos

* **Limpiar rastros sin perder contenido** — La acción «Limpiar rastros» del editor elimina el progreso guardado del alumno en una página de C-Studio; no elimina la página ni su contenido
* **Previsualizar antes de publicar** — Utilice la vista previa del editor para comprobar que los elementos interactivos se comportan como se espera antes de que los vean los alumnos
* **Revisar el contenido generado por IA** — Al igual que otras herramientas asistidas por IA en Chamilo, el texto, las imágenes y las preguntas de cuestionario generados son sugerencias para revisar y editar, no contenido definitivo
