# Seguimiento de estudiantes

El seguimiento de estudiantes <img src="/.gitbook/assets/icons/mdi-account-search.svg" alt="Seguimiento de estudiantes" data-size="line"> le permite conservar notas con marca de tiempo y etiquetas sobre el progreso y las dificultades de un alumno: un sistema ligero de notas de caso para registrar cómo evoluciona un estudiante a lo largo del tiempo.

## Acceso a la herramienta

Una vez habilitada, aparece una entrada **Seguimiento de estudiantes** en **Mi espacio** (su área de informes), que muestra una lista buscable de alumnos. Al abrir la página de detalle de un alumno y seleccionar su línea de tiempo de seguimiento se muestran todas las notas registradas sobre él, en orden.

> Esta herramienta solo está disponible para tutores de curso, gestores de RR. HH./formación (DRH) y administradores de la plataforma; no necesariamente para todos los roles de profesor.

## Añadir una nota

Desde la línea de tiempo de seguimiento de un alumno, haga clic en **Add follow-up note** y complete:

* Un título y contenido de texto enriquecido
* Etiquetas separadas por comas, para ayudarle a encontrar notas relacionadas más adelante
* **Private note** — restringe la visibilidad a administradores y otros cuidadores autorizados, en lugar de a todo el equipo docente

## Consejos

* **Use las etiquetas de forma coherente** — Un conjunto breve y coherente de etiquetas (p. ej., "attendance", "motivation", "technical-issue") hace que la línea de tiempo de un alumno sea mucho más fácil de revisar más adelante
* **Marque como privadas las notas sensibles** — Use la opción privada para todo lo que no deba ser visible para todo el equipo docente
* **Esta es una función en fase inicial** — Espere que esté menos pulida que las herramientas principales de Chamilo y que cambie a medida que madure
