# Portafolio

La herramienta de portafolio permite a los estudiantes recopilar y mostrar su trabajo a lo largo del curso. Sirve como un portafolio digital en el que los estudiantes pueden reunir sus mejores trabajos, reflexiones y logros.

## Cómo funcionan los portafolios

Cada estudiante tiene un portafolio personal dentro del curso en el que puede:

* **Añadir elementos** — Redactar entradas de texto con el editor de texto enriquecido y adjuntar uno o más archivos a cada elemento
* **Organizar el contenido** — Etiquetar los elementos para poder filtrarlos por tema
* **Compartir de forma selectiva** — Establecer la visibilidad de cada elemento: oculto, visible para el curso, oculto excepto para el profesor, o compartido con usuarios seleccionados cuando está habilitado el uso compartido avanzado

## Como profesor

Puede utilizar los portafolios para:

* **Aprendizaje reflexivo** — Pedir a los estudiantes que mantengan un portafolio de reflexiones sobre su proceso de aprendizaje
* **Demostración de competencias** — Hacer que los estudiantes recopilen evidencias de habilidades y conocimientos
* **Evaluación** — Revisar el contenido del portafolio como parte de su evaluación

Para ver el portafolio de un estudiante, abra la herramienta de portafolio y filtre la lista de elementos por usuario.

Si el curso está configurado para permitirlo, puede puntuar los elementos del portafolio y los comentarios individuales; estas puntuaciones pueden incorporarse después al libro de calificaciones. También puede **destacar** los elementos a los que desee llamar la atención, y marcar elementos o comentarios como **plantillas** para que usted (o los estudiantes) puedan reutilizarlos como punto de partida de nuevas entradas. Los portafolios se pueden exportar como **PDF** o **ZIP**.

## Consejos

* **Defina las expectativas** — Indique a los estudiantes qué tipos de elementos incluir y cómo organizar su portafolio
* **Revise con regularidad** — Consulte los portafolios periódicamente, no solo al final del curso
* **Combine con las competencias** — Utilice los portafolios junto con el sistema de competencias/certificados para crear un registro integral de competencias
