# Colaboración y comunicación

Chamilo ofrece varias herramientas para facilitar la interacción entre usted y sus alumnos, y entre los propios alumnos.

* **[Foros](forums.md)** — Debates en hilos organizados por categoría y tema
* **[Chat](chat.md)** — Mensajería de texto en tiempo real dentro de un curso
* **[Grupos](groups.md)** — Divida a los alumnos en grupos de trabajo con sus propias herramientas compartidas
* **[Wiki](wiki.md)** — Edición colaborativa de documentos
* **[Blog](blog.md)** — Blogs compartidos dentro del curso
* **[Videoconferencia](video-conferencing.md)** — Sesiones de vídeo en directo con BigBlueButton o Zoom

Estas herramientas están disponibles desde la página de inicio del curso. Algunas pueden estar ocultas de forma predeterminada: puede hacerlas visibles desde la cuadrícula de herramientas (consulte [Página de inicio del curso](../creating-your-course/course-homepage.md)).
