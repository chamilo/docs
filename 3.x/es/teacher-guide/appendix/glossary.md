# Glosario

Términos clave utilizados a lo largo de esta guía.

| Término | Definición |
|------|-----------|
| **Assessment** | Véase **Gradebook** más abajo |
| **Assignment** | Una tarea en la que los alumnos envían archivos o texto para su revisión y calificación por el docente. También conocida como "publicación de estudiante" o "trabajo". |
| **Auto-launch** | Una función que abre automáticamente una herramienta específica cuando un alumno entra en un curso. |
| **Certificate** | Un documento generado automáticamente cuando un alumno alcanza la puntuación mínima definida en el libro de calificaciones. |
| **Course** | Un contenedor de contenidos y herramientas de aprendizaje. Un curso puede incluir documentos, ejercicios, foros, itinerarios de aprendizaje y más. |
| **Course tutor** | Un rol docente específico de las sesiones. Un tutor de curso gestiona un curso dentro de una sesión. Denominado "course coach" en las versiones de Chamilo anteriores a la 3.0. |
| **Disk quota** | El espacio de almacenamiento máximo asignado a un curso para los archivos subidos. |
| **Enrollment** | El proceso de registrar a un usuario en un curso o sesión, otorgándole acceso a su contenido. También conocido como "suscripción". |
| **Exercise** | Un cuestionario o prueba que contiene una o más preguntas. También denominado "test" en algunos contextos. |
| **Forum** | Una herramienta de discusión con conversaciones encadenadas organizadas en categorías y temas. |
| **Gradebook** | Una herramienta que agrega las puntuaciones de ejercicios, tareas y otras actividades en una calificación unificada para cada alumno. |
| **Learning path** | Una secuencia estructurada de actividades de aprendizaje (documentos, ejercicios, enlaces) que los alumnos siguen en un orden definido, opcionalmente con prerrequisitos. |
| **LTI** | Learning Tools Interoperability — un estándar que permite incrustar herramientas de aprendizaje externas dentro de Chamilo. |
| **SCORM** | Sharable Content Object Reference Model — un estándar para paquetes de contenido de e-learning. Chamilo puede importar y reproducir paquetes SCORM dentro de los itinerarios de aprendizaje. |
| **Session** | Una edición acotada en el tiempo de uno o más cursos asignada a un grupo específico de alumnos. Las sesiones permiten reutilizar el mismo contenido del curso para distintas cohortes. |
| **Session tutor** | Un rol de supervisión que cubre todos los cursos de una sesión. Denominado "session coach" en las versiones de Chamilo anteriores a la 3.0. |
| **Skill** | Una competencia que puede vincularse a los logros del libro de calificaciones. Cuando un alumno obtiene un certificado, se validan las competencias asociadas. |
| **Survey** | Una herramienta de cuestionario para recoger opiniones, con diversos tipos de pregunta y opciones de respuesta anónima. |
| **Visibility** | Un ajuste que controla si una herramienta, documento o actividad es visible para los alumnos. Los docentes siempre pueden ver los elementos ocultos. |
