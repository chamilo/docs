# Cursos

Una vez que dispone de una cuenta, el siguiente paso es acceder a un curso y orientarse en él.

* **[Inscribirse en un curso](subscribing-to-a-course.md)** — Las distintas formas en que puede quedar matriculado en un curso
* **[Orientarse en un curso](course-tools-overview.md)** — Qué significa cada herramienta de la página de inicio del curso para usted como estudiante
* **[Seguir una ruta de aprendizaje](following-a-learning-path.md)** — Avanzar por una secuencia guiada de actividades
* **[Realizar pruebas](taking-tests.md)** — Qué esperar cuando su profesor asigna un cuestionario o un examen
* **[Entregar una tarea](submitting-an-assignment.md)** — Enviar archivos o texto para su calificación
* **[Usar el foro](using-the-forum.md)** — Publicar y responder en debates del curso organizados en hilos
* **[Usar la herramienta de chat](using-the-chat-tool.md)** — Mensajería en tiempo real dentro de un curso
* **[Chatbot de tutor de IA](ai-tutor.md)** — Obtener ayuda de un asistente de IA, si su plataforma lo ha habilitado

Estas páginas presuponen que ya dispone de una cuenta de Chamilo. Si no es así, consulte [Crear una cuenta](../getting-started/creating-an-account.md).
