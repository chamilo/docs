# Plantillas

Chamilo utiliza plantillas para certificados, documentos y correos electrónicos. Puede personalizar estas plantillas para que coincidan con la imagen corporativa y los requisitos de su organización.

## Plantillas de certificados

Las plantillas de certificados definen el diseño y el contenido de los certificados otorgados a los estudiantes que alcanzan los umbrales del libro de calificaciones.

### Personalización de una plantilla de certificado

Las plantillas de certificados utilizan HTML y CSS con variables de marcador de posición:

| Variable | Se sustituye por |
|----------|-------------|
| Student name | El nombre completo del estudiante |
| Course name | El nombre del curso |
| Date | La fecha en que se obtuvo el certificado |
| Score | La puntuación final del estudiante |
| Barcode | Un marcador de posición de código de barras (`((certificate_barcode))`) utilizado para la verificación |

### Carga de una plantilla

1. Acceda a la gestión de plantillas de certificados
2. Cargue o edite la plantilla HTML
3. Utilice las variables de marcador de posición donde deba aparecer el contenido dinámico
4. Guarde

## Plantillas de documentos

Los profesores pueden utilizar plantillas de documentos al crear contenido en la herramienta Documentos. Las plantillas proporcionan un diseño inicial para tipos de documentos habituales.

### Gestión de plantillas de documentos

1. Acceda a la gestión de plantillas en el panel de administración
2. Añada plantillas nuevas cargando archivos HTML
3. Las plantillas quedan disponibles para los profesores cuando crean documentos nuevos

## Consejos

* **Incluya su logotipo** — Añada el logotipo de su organización a las plantillas de certificados para un aspecto profesional
* **Pruebe con datos reales** — Previsualice los certificados con datos reales de estudiantes antes de desplegar la plantilla
* **Mantenga las plantillas sencillas** — Los diseños simples se imprimen mejor y lucen profesionales
