# Clases

Las clases en Chamilo son grupos predefinidos de usuarios que pueden inscribirse en sesiones como una unidad. Simplifican el proceso de inscripción cuando se forma regularmente a los mismos grupos de personas.

> Las clases y los [Grupos de usuarios](../../admin-guide/users/user-groups.md) comparten la misma interfaz. La única diferencia es el ajuste de **tipo de grupo**: elija «Clase» al crear el grupo. Todo lo demás — gestión de miembros, visibilidad y la propia interfaz — funciona de forma idéntica.

## Crear una clase

1. Desde el panel de administración, vaya a **Clases** (o a Grupos de usuarios y seleccione el tipo «Clase»)
2. Haga clic en **Crear una clase**
3. Introduzca un **nombre** (p. ej., «Equipo de ingeniería», «Nuevas contrataciones marzo 2026»)
4. Añada **miembros** — busque y seleccione usuarios
5. Guarde

## Usar clases para la inscripción

Al crear o editar una sesión, puede inscribir una clase completa de una vez en lugar de añadir usuarios de forma individual:

1. Abra la configuración de inscripción de la sesión
2. Haga clic en **Añadir una clase**
3. Seleccione la clase
4. Todos los miembros de la clase quedan inscritos en la sesión

## Gestionar clases

* **Editar** — Cambiar el nombre de la clase o actualizar la pertenencia
* **Añadir/quitar miembros** — Mantener actualizada la lista de la clase
* **Eliminar** — Quitar la clase (no afecta a las cuentas de los miembros ni a sus inscripciones existentes)

## Consejos

* **Cree clases para cohortes recurrentes** — Si imparte la misma formación a distintos equipos, cree una clase para cada equipo
* **Actualice antes de cada sesión** — Revise la pertenencia a la clase antes de inscribirla en una sesión nueva para asegurarse de que la lista está al día
* **Combine con la importación CSV** — Importe la pertenencia a la clase desde un archivo CSV para grupos grandes
