# Sesiones

Las sesiones son una de las funcionalidades más potentes de Chamilo. Permiten impartir los mismos cursos a distintos grupos de alumnos en momentos diferentes, sin duplicar el contenido del curso.

## Comprender las sesiones

Las sesiones son **opcionales**. Puede hacer funcionar su portal utilizando únicamente cursos, pero **realmente** le recomendamos que considere la complejidad adicional de las sesiones como una forma de ahorrar trabajo de gestión a largo plazo.

Un **curso** contiene el contenido (documentos, ejercicios, itinerarios de aprendizaje). Una **sesión** asigna ese curso (o varios cursos) a un grupo concreto de alumnos *durante un periodo de tiempo determinado*.

Esta arquitectura implica que:

* Los profesores crean el contenido una sola vez en el curso
* Los administradores crean sesiones para impartir ese contenido a distintas cohortes
* Cada sesión tiene su propia inscripción, datos de seguimiento y resultados
* El contenido base del curso se comparte, pero los tutores de la sesión pueden personalizar determinados elementos

## Cuándo utilizar sesiones

Utilice sesiones cuando:

* Imparta la misma formación varias veces (p. ej., sesiones mensuales de incorporación)
* Disponga de programas basados en cohortes (p. ej., clases por semestre)
* Necesite un seguimiento independiente por grupo de alumnos
* Desee que distintos tutores gestionen diferentes ediciones del mismo curso
