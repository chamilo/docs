# Sesiones

Las sesiones son una de las funcionalidades más potentes de Chamilo. Permiten impartir los mismos cursos a distintos grupos de estudiantes en momentos diferentes, sin duplicar el contenido del curso.

## Comprender las sesiones

Las sesiones son **opcionales**. Puede hacer que su portal funcione únicamente con cursos, pero **realmente** le recomendamos que considere la complejidad adicional de las sesiones como una forma de ahorrar trabajo de gestión a largo plazo.

Un **curso** contiene el contenido (documentos, ejercicios, itinerarios de aprendizaje). Una **sesión** asigna ese curso (o varios cursos) a un grupo específico de estudiantes *durante un periodo de tiempo determinado*.

Esta arquitectura implica:

* Los docentes crean el contenido una sola vez en el curso
* Los administradores crean sesiones para impartir ese contenido a distintas cohortes
* Cada sesión tiene su propia inscripción, datos de seguimiento y resultados
* El contenido base del curso se comparte, pero los tutores de la sesión pueden personalizar determinados elementos

## Cuándo utilizar las sesiones

Utilice las sesiones cuando:

* Imparta la misma formación varias veces (p. ej., sesiones mensuales de incorporación)
* Disponga de programas basados en cohortes (p. ej., clases semestrales)
* Necesite un seguimiento independiente por grupo de estudiantes
* Desee que distintos tutores gestionen distintas ediciones del mismo curso
