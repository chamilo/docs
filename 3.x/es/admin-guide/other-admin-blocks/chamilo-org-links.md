# Enlaces de Chamilo.org

El bloque **Chamilo.org** es una lista estática de enlaces salientes a recursos oficiales de Chamilo — nada más. No envía datos a ningún lugar; cada enlace abre un sitio externo de Chamilo o una página de documentación local incluida con su instalación.

## Contenido del bloque

| Enlace | Destino |
|------|-------------|
| Página principal de Chamilo | `chamilo.org` |
| Guías de usuario | `docs.chamilo.org` |
| Foro de Chamilo | GitHub Discussions de chamilo-lms |
| Guía de instalación | Local, `/documentation/installation_guide.html` |
| Cambios en la última versión | Local, `/documentation/changelog.html` |
| Lista de colaboradores | Local, `/documentation/credits.html` |
| Guía de seguridad | Local, `/documentation/security.html` |
| Guía de optimización | Local, `/documentation/optimization.html` |
| Proveedores oficiales de servicios de Chamilo | `chamilo.org/providers` |

Los enlaces «locales» apuntan a archivos de documentación incluidos con su propia instalación de Chamilo, por lo que se cargan desde su servidor, no desde chamilo.org.

## Propósito

Este bloque existe únicamente por conveniencia: acceso rápido a la documentación oficial del proyecto, al espacio de discusión de la comunidad y a la lista de proveedores de servicios homologados, sin necesidad de buscarlos.
