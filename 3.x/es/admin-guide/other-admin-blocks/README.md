# Otros bloques de administración

El panel de administración incluye algunos bloques más que no son tanto funciones configurables como widgets informativos: una página de enlaces salientes, un registro de comprobación de versión y dos paneles pequeños que extraen contenido de chamilo.org. Este capítulo explica qué es cada uno, de dónde proviene su contenido y —dado que algunos lo hacen— si algún dato sale de su plataforma.

## Contenido

* **[Enlaces de Chamilo.org](chamilo-org-links.md)** — Una lista de marcadores a recursos oficiales de Chamilo; no envía nada
* **[Comprobación de versión](version-check.md)** — Registro opcional que informa a chamilo.org de la versión y el uso de su plataforma, y le indica si corresponde una actualización
* **[Soporte profesional](professional-support.md)** — Un panel de solo lectura que describe a los proveedores oficiales de soporte de Chamilo
* **[Noticias de Chamilo](news-from-chamilo.md)** — Un canal de solo lectura de anuncios oficiales, incluidos parches de seguridad y nuevas versiones

Cada página siguiente indica con claridad qué, si acaso, se envía a chamilo.org, y por qué.
