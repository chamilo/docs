# Primeros pasos

Esta sección presenta la interfaz de administración de Chamilo 3.0 y le ayuda a orientarse.

## ¿Quién es un administrador?

Chamilo tiene varios niveles de roles administrativos:

| Role | Access |
|------|--------|
| **Administrator** | Acceso completo a todas las funciones de administración de la plataforma. También conocido como **Portal Administrator** |
| **Global Administrator** | Igual que Portal Administrator, con acceso a todas las URL de acceso en una configuración multi-URL (multi-tenant) |
| **Sessions Administrator** | Puede gestionar sesiones, inscribir usuarios en sesiones y acceder a la configuración relacionada con las sesiones |
| **Human Resources Manager** | Puede ver el progreso de los alumnos y los datos de seguimiento de los usuarios asignados |
| **Questions Manager** | Más que un administrador, un curador de contenidos; los gestores de preguntas tienen acceso a un banco global de preguntas para revisar su calidad |

Esta guía se centra principalmente en el rol de **Portal Administrator**, que tiene el acceso más amplio.

## Inicio de sesión

Los administradores inician sesión a través de la misma página de acceso que el resto de usuarios. Tras introducir sus credenciales, será dirigido (si no hay otra configuración) a la página de **Administration**. Una diferencia notable respecto a otros roles de usuario es la sección **Administration** en la barra lateral (no visible para otros roles).
