# Tickets

La entrada **Tickets** del bloque Analítica es un acceso directo al sistema de tickets de soporte de Chamilo: abre directamente la lista de tickets, no una página de ajustes.

## Acceso a los tickets

Desde el panel de administración, haga clic en **Analítica > Tickets**.

## Qué muestra

La lista de tickets donde se realiza el seguimiento y la respuesta de las solicitudes de soporte: el mismo sistema de tickets que se trata desde la perspectiva de un agente de soporte en la página [Tickets de soporte](../../teacher-guide/tickets.md) de la Guía del profesor.

Para configurar el propio sistema de tickets (categorías, prioridades, personal asignado), consulte [Configuración de tickets](../platform-settings/ticket-settings.md) en Ajustes de configuración.
