# Catálogo de informes

El Catálogo de informes no es un informe en sí mismo: es un directorio de todos los informes registrados en la plataforma, útil para comprender qué está disponible y quién puede verlo.

## Acceso al Catálogo de informes

Desde el panel de administración, haga clic en **Analítica > Catálogo de informes**.

## Qué muestra

* **Lista de informes** — El **ID de informe**, el título, la descripción y tanto la URL canónica como la URL heredada de cada informe registrado
* **Matriz de roles** — Una vista que muestra qué roles (Administrador del portal, Administrador global, Administrador de sesión, Docente, Responsable de recursos humanos, Jefe de estudiantes...) pueden acceder a cada informe
* **Categorías de permisos** — Los grupos de permisos en los que se organizan los informes (por ejemplo, `reports.platform`, `reports.learning_analytics`, `reports.export`, `reports.security`)

Utilice esta página cuando necesite determinar dónde se encuentra un informe concreto o si un rol determinado (por ejemplo, un Responsable de recursos humanos) tiene acceso a él, sin tener que comprobar cada informe de forma individual.

## Identificadores estables de informes

El catálogo incluye una columna **ID de informe**. Los ID identifican el informe con independencia de su título mostrado o de su ruta, que pueden cambiar tras la localización o las actualizaciones de la interfaz. El registro ampliado de Chamilo 3.1 incluye **103 ID de informe distintos**, entre ellos 27 informes modernos de Vue añadidos a la cobertura. Utilice el ID al comentar un informe con otro administrador o al enviar una incidencia técnica; utilice la matriz de roles por separado para comprobar el acceso.

Consulte [Mejoras del registro de informes #9299](https://github.com/chamilo/chamilo-lms/pull/9299).
