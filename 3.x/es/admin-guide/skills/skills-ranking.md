# Clasificación de competencias

La clasificación de competencias es un ranking de usuarios ordenado según el número de competencias que han adquirido.

## Acceso a la clasificación de competencias

Desde el panel de administración, haga clic en **Competencias > Clasificación de competencias**.

## Qué muestra

Para cada usuario activo, la clasificación muestra:

* **Competencias adquiridas** — Recuento total de competencias emitidas, utilizado para ordenar el ranking (de mayor a menor)
* **En aprendizaje actualmente** — El número de competencias vinculadas, a través del libro de calificaciones, a los cursos en los que el usuario está inscrito actualmente (directamente o a través de una sesión)

Utilice esta página para identificar de un vistazo a sus alumnos más destacados, o para evaluar la actividad global de adquisición de competencias en la plataforma.
