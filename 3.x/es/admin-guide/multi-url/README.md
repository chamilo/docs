# Multi-URL

La función multi-URL de Chamilo (también denominada multi-tenant) permite ejecutar varios portales virtuales desde una única instalación de Chamilo. Cada portal tiene su propia URL, identidad visual, usuarios, cursos y configuración, pero todos comparten la misma base de datos y el mismo código base.

* **[URLs de acceso](access-urls.md)** — Configurar y gestionar varias URLs de acceso
