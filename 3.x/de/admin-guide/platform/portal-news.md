# Portal-News

Trotz der Dashboard-Bezeichnung „Portal-News“ verwaltet dieses Werkzeug **Systemankündigungen** — plattformweite Nachrichten, die geplant, nach Rolle gezielt und optional per E-Mail versendet werden können.

## Zugriff auf Portal-News

Klicken Sie im Administrationsbereich auf **Plattform > Portal-News**.

## Eine Ankündigung erstellen

Jede Ankündigung umfasst:

* **Titel** und Rich-Text-**Inhalt**
* **Start- und Enddatum** — Standard ist heute bis 7 Tage später; die Ankündigung ist nur sichtbar, solange das aktuelle Datum in diesem Zeitraum liegt
* **Sprache** — eine bestimmte Sprache oder alle Sprachen
* **Rollen (Zielgruppe)** — einschließlich abgemeldeter Besucher, sodass Sie Ankündigungen an anonyme Nutzer, bestimmte angemeldete Rollen oder eine Mischung aus beidem richten können
* **Benutzergruppe** — optional die Ankündigung auf eine bestimmte Benutzergruppe beschränken
* **Karriere** — wenn die Einstellung **Globale Ankündigungen mit Karrieren und Promotionen verknüpfen** aktiviert ist, können Sie eine Ankündigung auch auf einen bestimmten Karriere-/Promotion-Pfad eingrenzen

## Versand per E-Mail

Über die reine Anzeige der Ankündigung hinaus können Sie:

* **Mail senden** — sendet die Ankündigung per E-Mail an alle in der Zielgruppe
* **Eine Test-E-Mail an mich selbst senden** — Vorschau dessen, was Empfänger erhalten, bevor Sie den Versand auslösen
* **Zum Kalender hinzufügen** — beim Erstellen einer Ankündigung verfügbar; verknüpft sie zusätzlich mit dem Kalender

## Geltungsbereich und Sichtbarkeit

Ankündigungen gelten pro Zugriffs-URL — bei einer Multi-URL-Installation (Multi-Portal) verwaltet jedes Portal seine eigenen News unabhängig. Die Admin-Liste zeigt pro Ankündigung einen Aktiv/Inaktiv-Indikator, der aus dem Datumsbereich berechnet wird; Ankündigungen können einzeln oder gesammelt bearbeitet oder gelöscht werden.
