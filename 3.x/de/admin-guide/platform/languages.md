# Sprachen

Dieses Werkzeug steuert, welche Oberflächensprachen Benutzer auswählen können — es verwaltet nicht die Übersetzungszeichenketten selbst (diese stammen aus den mit Chamilo ausgelieferten Sprachpaketen und sind hier nicht bearbeitbar).

## Sprachen aufrufen

Klicken Sie im Administrationsbereich auf **Plattform > Sprachen**.

## Was Sie tun können

* **Verfügbarkeit umschalten** — Aktivieren oder deaktivieren Sie jede der mitgelieferten Sprachen als Auswahl auf der Anmeldeseite und in den Profil-Einstellungen der Benutzer, mit einem einfachen Ein-/Ausschalter pro Zeile
* **Plattformstandard festlegen** — Wählen Sie, welche Sprache verwendet wird, wenn keine Benutzerpräferenz greift; der aktuelle Standard ist mit einem eigenen Symbol gekennzeichnet und kann nicht ausgeblendet werden
* **Alle außer dem Standard deaktivieren** — Eine einzelne Sammelaktion, um die Sprachauswahl auf nur die Standardprache Ihrer Plattform zu beschränken
* **Ursprünglichen Namen bearbeiten** — Passen Sie an, wie der eigene Name einer Sprache (ihr „Originalname“) in der Auswahl angezeigt wird

## Eine verwendete Sprache deaktivieren

Wenn Sie eine Sprache deaktivieren, die aktive Benutzer bereits als ihre Oberflächensprache gewählt haben, fordert Chamilo eine Bestätigung an und — sofern Sie bestätigen — migriert jeden betroffenen Benutzer zur Standardprache der Plattform. Es gibt keinen Zwischenzustand, in dem ein Benutzer eine nun ausgeblendete Sprache ausgewählt behält.

## Sprachen mit Schreibrichtung von rechts nach links

Sprachen mit Schreibrichtung von rechts nach links (etwa Arabisch, Hebräisch oder Persisch) schalten die Oberfläche bei Auswahl automatisch auf ein Layout von rechts nach links um — hierfür ist weder hier noch an anderer Stelle etwas zu konfigurieren. Die RTL-Unterstützung wurde in neueren Versionen deutlich verbessert.

## Subsprachen

Wenn die Einstellung **Allow sub-languages** aktiviert ist, erscheinen zusätzliche Aktionen zum Anlegen von „Subsprachen“ — partiellen Überschreibungen einer Elternsprache, historisch genutzt für regionale Dialekte oder organisationsspezifische Terminologieanpassungen. Dies ist eine Legacy-Funktion; die meisten Installationen benötigen sie nicht.
