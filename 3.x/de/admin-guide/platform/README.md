# Plattform

Der Block **Plattformverwaltung** auf dem Administrations-Dashboard bündelt portalweite Konfigurations- und Kommunikationswerkzeuge – von der vollständigen Einstellungsübersicht über Sprachen, öffentliche Ankündigungen und den globalen Kalender bis hin zum CMS-ähnlichen Seiten-System, mit dem Teile der öffentlich sichtbaren Inhalte Ihres Portals erstellt werden.

![Der Block Plattformverwaltung auf dem Administrations-Dashboard mit den Einträgen Konfigurationseinstellungen, Sprachen, Plugins, Regionen, Portalnachrichten, Globale Agenda, Seiten, Registrierungsseite festlegen, Extrafelder, Mehrfach-Zugriffs-URL konfigurieren, E-Mail-Vorlagen, Externe Tools (LTI), Kontaktformular-Kategorien und Systemvorlagen](../../.gitbook/assets/admin-platform-block.png)

## Zugriff auf den Plattform-Block

Im Administrationsbereich erscheint der Block **Plattformverwaltung** neben den anderen Dashboard-Blöcken. Klicken Sie auf einen der Links, um das entsprechende Werkzeug zu öffnen.

## Inhalt des Blocks

* **[Plattformeinstellungen](../platform-settings/README.md)** — Die vollständige Konfigurationseinstellungsübersicht (Portal, Kurse, Sessions, Benutzer, Sicherheit und mehr). Der Link „Konfigurationseinstellungen“ in diesem Block ist lediglich der Einstieg in dieses separate Kapitel.
* **[Sprachen](languages.md)** — Legen Sie fest, welche Oberflächensprachen den Benutzern zur Verfügung stehen, und setzen Sie die Standard-Plattformsprache
* **[Portalnachrichten](portal-news.md)** — Portalweite Ankündigungen (Systemankündigungen), zeitgesteuert und nach Rolle gezielt
* **[Globale Agenda](global-agenda.md)** — Portalweite Kalenderereignisse, für jeden Benutzer sichtbar, unabhängig von Kurs oder Session
* **[Seiten](pages.md)** — Das CMS-ähnliche Werkzeug hinter der Startseite, der Fußzeile und anderen öffentlichen Inhaltsblöcken Ihres Portals, einschließlich des Einleitungstextes der Registrierungsseite
* **[Plattformwerkzeuge](platform-tools.md)** — Extrafelder, E-Mail-Vorlagen, Kontaktformular-Kategorien und einige kleinere, bedingt angezeigte Elemente
* **Mehrfach-Zugriffs-URL konfigurieren** — Behandelt in [Zugriffs-URLs](../multi-url/access-urls.md), unter Multi-URL
* **Externe Tools (LTI)** — Behandelt in [LTI 1.3](../integrations/lti.md), unter Integrationen
