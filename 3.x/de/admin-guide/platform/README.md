# Plattform

Der Block **Plattformverwaltung** im Administrations-Dashboard bündelt portalweite Konfigurations- und Kommunikationswerkzeuge — von der vollständigen Einstellungsübersicht über Sprachen, öffentliche Ankündigungen und den globalen Kalender bis hin zum CMS-ähnlichen Seitensystem, mit dem Teile der öffentlich sichtbaren Inhalte Ihres Portals erstellt werden.

![Der Block Plattformverwaltung im Administrations-Dashboard mit den Einträgen Konfigurationseinstellungen, Sprachen, Plugins, Regionen, Portalnachrichten, Globale Agenda, Seiten, Registrierungsseite festlegen, Zusatzfelder, Mehrere Zugriffs-URLs konfigurieren, E-Mail-Vorlagen, Externe Werkzeuge (LTI), Kontaktformular-Kategorien und Systemvorlagen](../../.gitbook/assets/admin-platform-block.png)

## Zugriff auf den Plattform-Block

Im Administrationsbereich erscheint der Block **Plattformverwaltung** neben den anderen Dashboard-Blöcken. Klicken Sie auf einen der Links, um das entsprechende Werkzeug zu öffnen.

## Inhalt des Blocks

* **[Plattformeinstellungen](../platform-settings/README.md)** — Die vollständige Übersicht der Konfigurationseinstellungen (Portal, Kurse, Sitzungen, Benutzer, Sicherheit und mehr). Der Link „Konfigurationseinstellungen“ in diesem Block ist lediglich der Einstieg in dieses separate Kapitel.
* **[Sprachen](languages.md)** — Legen Sie fest, welche Oberflächensprachen den Benutzern zur Verfügung stehen, und bestimmen Sie die Standard-Sprache der Plattform
* **[Portalnachrichten](portal-news.md)** — Portalweite Ankündigungen (Systemankündigungen), zeitlich geplant und nach Rolle ausgerichtet
* **[Globale Agenda](global-agenda.md)** — Portalweite Kalenderereignisse, die für alle Benutzer unabhängig von Kurs oder Sitzung sichtbar sind
* **[Seiten](pages.md)** — Das CMS-ähnliche Werkzeug für die Startseite, die Fußzeile und weitere öffentliche Inhaltsblöcke Ihres Portals, einschließlich des Einleitungstextes der Registrierungsseite
* **[Plattformwerkzeuge](platform-tools.md)** — Zusatzfelder, E-Mail-Vorlagen, Kontaktformular-Kategorien und einige kleinere, bedingt angezeigte Elemente
* **Mehrere Zugriffs-URLs konfigurieren** — Beschrieben unter [Zugriffs-URLs](../multi-url/access-urls.md) im Abschnitt Multi-URL
* **Externe Werkzeuge (LTI)** — Beschrieben unter [LTI 1.3](../integrations/lti.md) im Abschnitt Integrationen
