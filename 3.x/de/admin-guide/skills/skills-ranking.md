# Kompetenzranking

Das Kompetenzranking ist eine Rangliste der Benutzer, geordnet nach der Anzahl der von ihnen erworbenen Kompetenzen.

## Zugriff auf das Kompetenzranking

Klicken Sie im Administrationsbereich auf **Kompetenzen > Kompetenzranking**.

## Angezeigte Informationen

Für jeden aktiven Benutzer zeigt das Ranking Folgendes:

* **Erworbene Kompetenzen** — Gesamtzahl der vergebenen Kompetenzen, nach der die Rangliste sortiert wird (höchste zuerst)
* **Derzeit im Lernen** — Die Anzahl der Kompetenzen, die über das Notenbuch mit Kursen verknüpft sind, in die der Benutzer derzeit eingeschrieben ist (direkt oder über eine Session)

Nutzen Sie diese Seite, um Ihre erfolgreichsten Lernenden auf einen Blick zu erkennen oder die gesamte Kompetenz-Erwerbsaktivität auf der Plattform einzuschätzen.
