# Tickets

Der Eintrag **Tickets** im Block Analytics ist eine Verknüpfung zum Support-Ticket-System von Chamilo — er öffnet direkt die Ticketliste, keine Einstellungsseite.

## Zugriff auf Tickets

Klicken Sie im Administrationsbereich auf **Analytics > Tickets**.

## Was angezeigt wird

Die Ticketliste, in der Supportanfragen nachverfolgt und beantwortet werden — dasselbe Ticket-System, das aus der Perspektive eines Support-Mitarbeiters auf der Seite [Support-Tickets](../../teacher-guide/tickets.md) im Lehrerhandbuch behandelt wird.

Zur Konfiguration des Ticket-Systems selbst (Kategorien, Prioritäten, zugewiesenes Personal) siehe [Ticket-Einstellungen](../platform-settings/ticket-settings.md) unter Konfigurationseinstellungen.
