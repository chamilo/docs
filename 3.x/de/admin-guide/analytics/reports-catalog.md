# Berichtskatalog

Der Berichtskatalog ist selbst kein Bericht — er ist ein Verzeichnis aller auf der Plattform registrierten Berichte und hilft dabei zu verstehen, was verfügbar ist und wer es einsehen kann.

## Zugriff auf den Berichtskatalog

Klicken Sie im Administrationsbereich auf **Analytics > Reports catalog**.

## Was angezeigt wird

* **Berichtsliste** — Titel, Beschreibung sowie die kanonische und die Legacy-URL jedes registrierten Berichts
* **Rollenmatrix** — Eine Ansicht, die zeigt, welche Rollen (Portal Administrator, Global Administrator, Session Administrator, Teacher, Human Resources Manager, Student Boss...) auf jeden Bericht zugreifen können
* **Berechtigungskategorien** — Die Berechtigungsgruppen, in die Berichte organisiert sind (zum Beispiel `reports.platform`, `reports.learning_analytics`, `reports.export`, `reports.security`)

Nutzen Sie diese Seite, wenn Sie herausfinden möchten, wo sich ein bestimmter Bericht befindet oder ob eine bestimmte Rolle (zum Beispiel ein Human Resources Manager) Zugriff darauf hat, ohne jeden Bericht einzeln prüfen zu müssen.
