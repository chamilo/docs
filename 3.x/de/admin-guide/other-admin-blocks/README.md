# Weitere Admin-Blöcke

Das Administrations-Dashboard enthält einige weitere Blöcke, die weniger konfigurierbare Funktionen als informative Widgets sind: eine Seite mit ausgehenden Links, eine Registrierung zur Versionsprüfung sowie zwei kleine Panels, die Inhalte von chamilo.org beziehen. Dieses Kapitel erläutert, worum es sich bei jedem handelt, woher die Inhalte stammen und — da dies bei einigen der Fall ist — ob Daten Ihre Plattform verlassen.

## Inhalt

* **[Chamilo.org-Links](chamilo-org-links.md)** — Eine Lesezeichenliste zu offiziellen Chamilo-Ressourcen; sendet nichts
* **[Versionsprüfung](version-check.md)** — Optionale Registrierung, die Version und Nutzung Ihrer Plattform an chamilo.org meldet und Sie informiert, wenn ein Update fällig ist
* **[Professioneller Support](professional-support.md)** — Ein schreibgeschütztes Panel mit Beschreibung der offiziellen Chamilo-Supportanbieter
* **[Nachrichten von Chamilo](news-from-chamilo.md)** — Ein schreibgeschützter Feed offizieller Ankündigungen, einschließlich Sicherheitspatches und neuer Releases

Jede der folgenden Seiten gibt klar an, was — falls überhaupt etwas — an chamilo.org gesendet wird und warum.
