# Chamilo.org-Links

Der Block **Chamilo.org** ist eine statische Liste ausgehender Links zu offiziellen Chamilo-Ressourcen – nichts weiter. Es werden keine Daten irgendwohin gesendet; jeder Link öffnet entweder eine externe Chamilo-Website oder eine lokale Dokumentationsseite, die mit Ihrer Installation ausgeliefert wird.

## Inhalt des Blocks

| Link | Ziel |
|------|-------------|
| Chamilo-Startseite | `chamilo.org` |
| Benutzerhandbücher | `docs.chamilo.org` |
| Chamilo-Forum | GitHub Discussions für chamilo-lms |
| Installationsanleitung | Lokal, `/documentation/installation_guide.html` |
| Änderungen in der letzten Version | Lokal, `/documentation/changelog.html` |
| Liste der Mitwirkenden | Lokal, `/documentation/credits.html` |
| Sicherheitsleitfaden | Lokal, `/documentation/security.html` |
| Optimierungsleitfaden | Lokal, `/documentation/optimization.html` |
| Offizielle Chamilo-Dienstleister | `chamilo.org/providers` |

Die „lokalen“ Links verweisen auf Dokumentationsdateien, die mit Ihrer Chamilo-Installation selbst gebündelt sind; sie werden daher von Ihrem eigenen Server geladen, nicht von chamilo.org.

## Zweck

Dieser Block dient ausschließlich der Bequemlichkeit – schneller Zugriff auf die offizielle Dokumentation des Projekts, den Community-Diskussionsbereich und die Liste geprüfter Dienstleister, ohne danach suchen zu müssen.
