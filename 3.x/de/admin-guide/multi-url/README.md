# Multi-URL

Die Multi-URL-Funktion von Chamilo (auch Multi-Tenant genannt) ermöglicht es, mehrere virtuelle Portale aus einer einzigen Chamilo-Installation zu betreiben. Jedes Portal verfügt über eine eigene URL, ein eigenes Branding, eigene Benutzer, Kurse und Einstellungen, teilt sich jedoch dieselbe Datenbank und denselben Codebestand.
