# Klassen

Klassen in Chamilo sind vordefinierte Gruppen von Benutzern, die als Einheit in Sitzungen eingeschrieben werden können. Sie vereinfachen den Einschreibeprozess, wenn Sie regelmäßig dieselben Personengruppen schulen.

> Klassen und [Benutzergruppen](../../admin-guide/users/user-groups.md) teilen dieselbe Oberfläche. Der einzige Unterschied ist die Einstellung **Gruppentyp**: wählen Sie beim Erstellen der Gruppe „Klasse“. Alles andere — Mitgliederverwaltung, Sichtbarkeit und die Oberfläche selbst — funktioniert identisch.

## Eine Klasse erstellen

1. Navigieren Sie im Administrationsbereich zu **Klassen** (oder Benutzergruppen und wählen Sie den Typ „Klasse“)
2. Klicken Sie auf **Klasse erstellen**
3. Geben Sie einen **Namen** ein (z. B. „Engineering Team“, „Neueinstellungen März 2026“)
4. Fügen Sie **Mitglieder** hinzu — suchen Sie Benutzer und wählen Sie sie aus
5. Speichern

## Klassen für die Einschreibung verwenden

Beim Erstellen oder Bearbeiten einer Sitzung können Sie eine gesamte Klasse auf einmal einschreiben, statt Benutzer einzeln hinzuzufügen:

1. Öffnen Sie die Einschreibungseinstellungen der Sitzung
2. Klicken Sie auf **Klasse hinzufügen**
3. Wählen Sie die Klasse
4. Alle Mitglieder der Klasse werden in die Sitzung eingeschrieben

## Klassen verwalten

* **Bearbeiten** — Den Klassennamen ändern oder die Mitgliedschaft aktualisieren
* **Mitglieder hinzufügen/entfernen** — Die Klassenliste aktuell halten
* **Löschen** — Die Klasse entfernen (betrifft weder die Benutzerkonten der Mitglieder noch deren bestehende Einschreibungen)

## Tipps

* **Klassen für wiederkehrende Kohorten anlegen** — Wenn Sie dieselbe Schulung für verschiedene Teams durchführen, legen Sie für jedes Team eine Klasse an
* **Vor jeder Sitzung aktualisieren** — Prüfen Sie die Klassenmitgliedschaft, bevor Sie eine Klasse in eine neue Sitzung einschreiben, damit die Liste aktuell ist
* **Mit CSV-Import kombinieren** — Importieren Sie die Klassenmitgliedschaft für große Gruppen aus einer CSV-Datei
