# Sitzungskategorien

Sitzungskategorien helfen dabei, Ihre Sitzungen zu organisieren, insbesondere wenn viele Sitzungen gleichzeitig laufen.

## Eine Kategorie erstellen

1. Navigieren Sie im Administrationsbereich zu **Sitzungskategorien**
2. Klicken Sie auf **Kategorie hinzufügen**
3. Geben Sie einen **Namen** und optional Start-/Enddaten ein
4. Speichern

## Anwendungsfälle

* **Nach Programm** — "Leadership Development", "Technical Training", "Onboarding"
* **Nach Zeitraum** — "Q1 2026", "Spring Semester", "July Batch"
* **Nach Abteilung** — "Engineering", "Sales", "Human Resources"

## Kategorien verwalten

* **Bearbeiten** — Ändern Sie den Kategorienamen oder die Daten
* **Sitzungen zuweisen** — Wählen Sie beim Erstellen oder Bearbeiten einer Sitzung deren Kategorie aus
* **Löschen** — Entfernen Sie eine Kategorie (Sitzungen in der Kategorie werden unkategorisiert)
