# Sessions

Sessions gehören zu den leistungsstärksten Funktionen von Chamilo. Sie ermöglichen es, dieselben Kurse zu unterschiedlichen Zeiten an verschiedene Lernergruppen auszuliefern, ohne Kursinhalte zu duplizieren.

## Sessions verstehen

Sessions sind **optional**. Sie können Ihr Portal allein mit Kursen betreiben, wir **empfehlen** jedoch nachdrücklich, die zusätzliche Komplexität von Sessions in Betracht zu ziehen, um langfristig Verwaltungsaufwand zu sparen.

Ein **Kurs** enthält die Inhalte (Dokumente, Übungen, Lernpfade). Eine **Session** weist diesen Kurs (oder mehrere Kurse) einer bestimmten Lernergruppe *für einen bestimmten Zeitraum* zu.

Diese Architektur bedeutet:

* Lehrende erstellen Inhalte einmal im Kurs
* Administratoren erstellen Sessions, um diese Inhalte an verschiedene Kohorten auszuliefern
* Jede Session verfügt über eigene Anmeldungen, Tracking-Daten und Ergebnisse
* Die Basis-Kursinhalte werden geteilt, Session-Tutoren können jedoch bestimmte Elemente anpassen

## Wann Sessions verwendet werden sollten

Verwenden Sie Sessions, wenn:

* Sie dieselbe Schulung mehrfach durchführen (z. B. monatliche Onboarding-Sessions)
* Sie kohortenbasierte Programme haben (z. B. semesterbasierte Klassen)
* Sie ein getrenntes Tracking pro Lernergruppe benötigen
* Unterschiedliche Tutoren verschiedene Durchführungen desselben Kurses betreuen sollen
