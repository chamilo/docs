# Sitzungen

Sitzungen gehören zu den leistungsstärksten Funktionen von Chamilo. Sie ermöglichen es, dieselben Kurse verschiedenen Gruppen von Lernenden zu unterschiedlichen Zeiten bereitzustellen, ohne die Kursinhalte zu duplizieren.

## Sitzungen verstehen

Sitzungen sind **optional**. Sie können Ihr Portal allein mit Kursen betreiben, wir empfehlen jedoch **nachdrücklich**, die zusätzliche Komplexität von Sitzungen in Betracht zu ziehen, um langfristig Verwaltungsaufwand zu sparen.

Ein **Kurs** enthält die Inhalte (Dokumente, Übungen, Lernpfade). Eine **Sitzung** weist diesen Kurs (oder mehrere Kurse) einer bestimmten Gruppe von Lernenden *für einen bestimmten Zeitraum* zu.

Diese Architektur bedeutet:

* Lehrkräfte erstellen Inhalte einmal im Kurs
* Administratoren erstellen Sitzungen, um diese Inhalte verschiedenen Kohorten bereitzustellen
* Jede Sitzung verfügt über eigene Einschreibungen, Tracking-Daten und Ergebnisse
* Die Basis-Kursinhalte werden geteilt, Sitzungstutoren können jedoch bestimmte Elemente anpassen

## Wann Sitzungen verwendet werden sollten

Verwenden Sie Sitzungen, wenn:

* Sie dieselbe Schulung mehrfach durchführen (z. B. monatliche Onboarding-Sitzungen)
* Sie kohortenbasierte Programme haben (z. B. semesterbasierte Klassen)
* Sie ein separates Tracking je Gruppe von Lernenden benötigen
* Sie möchten, dass unterschiedliche Tutoren verschiedene Ausgaben desselben Kurses verwalten
