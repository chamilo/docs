# Integrationen

Chamilo integriert sich mit mehreren Drittanbieterdiensten, um seine Funktionalität zu erweitern.

Die meisten davon werden über Plugins aktiviert. Prüfen Sie den entsprechenden Abschnitt etwas weiter hinten in diesem Leitfaden.

* **[Videokonferenzen](video-conferencing.md)** — BigBlueButton und Zoom
* **[LTI 1.3](lti.md)** — Externe Lernwerkzeuge anbinden
* **[xAPI](xapi.md)** — Nachverfolgung von Lernerfahrungen
* **[OnlyOffice](onlyoffice.md)** — Kollaborative Dokumentenbearbeitung
* **[KI-Konfiguration](ai-configuration.md)** — KI-Anbieter für KI-gestützte Funktionen einrichten
