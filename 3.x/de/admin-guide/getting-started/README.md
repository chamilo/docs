# Erste Schritte

Dieser Abschnitt stellt die Administrationsoberfläche von Chamilo 3.0 vor und hilft Ihnen bei der Orientierung.

## Wer ist ein Administrator?

Chamilo kennt mehrere Stufen administrativer Rollen:

| Rolle | Zugriff |
|------|--------|
| **Administrator** | Voller Zugriff auf alle Administrationsfunktionen der Plattform. Auch bekannt als **Portal-Administrator** |
| **Global Administrator** | Entspricht dem Portal-Administrator, mit Zugriff über alle Zugriffs-URLs in einer Multi-URL-Umgebung (Multi-Tenant) |
| **Sessions Administrator** | Kann Sitzungen verwalten, Benutzer in Sitzungen einschreiben und sitzungsbezogene Einstellungen aufrufen |
| **Human Resources Manager** | Kann Lernfortschritt und Tracking-Daten der zugewiesenen Benutzer einsehen |
| **Questions Manager** | Weniger ein Administrator als ein Inhaltskurator; Fragenmanager haben Zugriff auf eine globale Fragenbank, um die Qualität von Fragen zu prüfen |

Dieser Leitfaden konzentriert sich hauptsächlich auf die Rolle **Portal-Administrator**, die den umfassendsten Zugriff hat.

## Anmeldung

Administratoren melden sich über dieselbe Anmeldeseite an wie alle anderen Benutzer. Nach Eingabe Ihrer Zugangsdaten werden Sie (sofern keine andere Konfiguration vorliegt) zur Seite **Administration** weitergeleitet. Ein wesentlicher Unterschied zu anderen Benutzerrollen ist der Bereich **Administration** in der Seitenleiste (für andere Rollen nicht sichtbar).
