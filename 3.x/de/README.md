# Chamilo 3.0 Documentation

Willkommen bei der offiziellen Dokumentation für **Chamilo 3.0**, die Open-Source-E-Learning-Plattform.

Diese Dokumentation ist in vier Leitfäden gegliedert, die jeweils auf eine bestimmte Zielgruppe zugeschnitten sind:

* [**Lehrerleitfaden**](teacher-guide/) — Für Lehrende und Trainer: Kurse erstellen, Inhalte hinzufügen, Lernende bewerten und den Fortschritt verfolgen.
* [**Administrationsleitfaden**](admin-guide/) — Für Plattformadministratoren: die Chamilo-Plattform installieren, konfigurieren und verwalten.
* [**Leitfaden für Lernende**](student-guide/) — Für Lernende: Kursen beitreten, Lernpfaden folgen, Tests ablegen und den eigenen Fortschritt verfolgen.
* [**Entwicklerleitfaden**](developer-guide/) — Für Entwickler: die Architektur verstehen, Plugins erstellen, die API nutzen und zum Projekt beitragen.

## Was ist neu in Chamilo 3.0

Chamilo 3.0 ist eine Hauptversion mit Schwerpunkt auf KI-gestütztem Unterrichten, verstärkter Sicherheit und einer vollständig modernisierten Plugin-Landschaft:

* **KI-gestützte Unterrichtswerkzeuge** — Ein Kursqualitätsanalysator, ein KI-Tutor, der Fragen zur Plattformnutzung beantwortet, ein KI-Coach für den Lernerfolg mit individuellen Empfehlungen je Lernendem, KI-generierte Kursillustrationen und Schnelltests sowie KI-unterstützte Bewertung
* **Model Context Protocol (MCP)-Server** — Ermöglicht KI-Clients, Kurse, Tests, Lernpfade, Umfragen und mehr direkt zu erstellen und zu verwalten
* **Verstärkte Sicherheit** — Native Überwachung der Dateiintegrität sowie Dutzende Zugriffskontroll-Korrekturen bei Kursen, Sitzungen und der API
* **Vollständige Modernisierung der Plugin-Landschaft** — Alle Plugins aus 1.11.x wieder aktiviert, mit einer neu gestalteten Plugin-Verwaltungsoberfläche
* **Hierarchische URLs und Multi-Site-Verwaltung** — Ein globales Multi-URL-Panel sowie eine visuelle geografische Kartenverwaltung für Branches und Räume
* **Verbesserte Lernpfade und Tests** — Progressiver adaptiver Testmodus, Live-Bearbeitung mit OnlyOffice, adaptive Hotspot-Abgrenzung und erweiterte SCORM-2004-Unterstützung
* **Bewertungen und Zertifikate** — Ablaufdaten für Zertifikate mit Erinnerungen sowie anpassbare Bewertungsmodi
* **Mobilfreundliche REST API** — Ein modernisiertes Backend für mobile Apps und Integrationen von Drittanbietern
