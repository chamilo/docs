# Chamilo 3.0 Documentation

Willkommen bei der offiziellen Dokumentation für **Chamilo 3.0**, die Open-Source-E-Learning-Plattform.

Diese Dokumentation ist in drei Leitfäden gegliedert, die jeweils auf eine bestimmte Zielgruppe zugeschnitten sind:

* [**Lehrerleitfaden**](teacher-guide/) — Für Lehrende und Trainer: Kurse erstellen, Inhalte hinzufügen, Lernende bewerten und den Fortschritt verfolgen.
* [**Administrationsleitfaden**](admin-guide/) — Für Plattformadministratoren: die Chamilo-Plattform installieren, konfigurieren und verwalten.
* [**Entwicklerleitfaden**](developer-guide/) — Für Entwickler: die Architektur verstehen, Plugins erstellen, die API nutzen und zum Projekt beitragen.

## What's New in Chamilo 3.0

Chamilo 3.0 ist eine Major-Version mit einer vollständig neu gestalteten Oberfläche und vielen neuen Funktionen:

* **Modernes Interface** — Entwickelt mit Vue 3 und PrimeVue für eine schnellere, reaktionsschnellere Nutzung
* **KI-gestützte Werkzeuge** — Übungen und Lernpfade generieren sowie KI-unterstützte Bewertung nutzen
* **REST API** — Vollständige, auf API Platform basierende REST API mit JWT-Authentifizierung
* **Neue Authentifizierungsoptionen** — OAuth2 (Azure, Keycloak, Facebook), SCIM-Benutzerbereitstellung
* **LTI 1.3** — Externe Lernwerkzeuge nahtlos anbinden
* **Cloud-Speicher** — Native Unterstützung für Azure Blob, AWS S3 und Google Cloud Storage
* **Farbthemen** — Anpassbares Plattform-Branding mit Theme-Unterstützung
* **OnlyOffice-Integration** — Dokumente gemeinsam direkt in der Plattform bearbeiten
