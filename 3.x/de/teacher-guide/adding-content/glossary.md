# Glossar

Mit dem Glossar-Werkzeug können Sie Schlüsselbegriffe für Ihren Kurs definieren. Lernende können das Glossar durchsuchen, um während des Lernens Definitionen nachzuschlagen.

## Begriff hinzufügen

1. Öffnen Sie das Werkzeug **Glossar** <img src="../../.gitbook/assets/icons/mdi-alphabetical.svg" alt="Glossar" data-size="line"> auf der Kursstartseite
2. Klicken Sie auf **Neuen Glossarbegriff hinzufügen**
3. Geben Sie den **Begriff** und seine **Definition** ein (die Definition unterstützt Rich-Text-Formatierung)
4. Speichern

## Begriffe verwalten

* **Bearbeiten** <img src="../../.gitbook/assets/icons/mdi-pencil.svg" alt="Bearbeiten" data-size="line"> — Einen Begriff oder seine Definition aktualisieren
* **Löschen** <img src="../../.gitbook/assets/icons/mdi-delete.svg" alt="Löschen" data-size="line"> — Einen Begriff aus dem Glossar entfernen
* **Suchen** <img src="../../.gitbook/assets/icons/mdi-magnify.svg" alt="Suchen" data-size="line"> — Die Suchfunktion nutzen, um bestimmte Begriffe schnell zu finden

## Kategorien

Verwenden Sie **Kategorien verwalten**, um ein umfangreiches Glossar in benannte Gruppen zu gliedern. Auf der Kategorienseite können Sie Kategorien hinzufügen, bearbeiten und löschen. Wählen Sie beim Erstellen oder Bearbeiten eines Begriffs seine **Kategorie** aus, oder belassen Sie ihn bei **Keine Kategorie**.

Die Glossarliste gruppiert Begriffe nach Kategorie, und die Tabellenansicht zeigt die Kategorie in einer eigenen Spalte. Begriffe ohne Kategorie bleiben unter **Keine Kategorie** verfügbar.

## Importieren und Exportieren

Sie können Ihr Glossar mithilfe von Import und Export schneller aufbauen:

* **Importieren** <img src="../../.gitbook/assets/icons/mdi-database-import-outline.svg" alt="Importieren" data-size="line"> — Laden Sie eine Liste von Begriffen und Definitionen aus einer CSV- oder XLS-Datei hoch. Sie können auch „Vorhandene Begriffe aktualisieren“ aktivieren, um Definitionen für Begriffe zu überschreiben, die bereits im Glossar vorhanden sind.
* **Exportieren** <img src="../../.gitbook/assets/icons/mdi-file-export.svg" alt="Exportieren" data-size="line"> — Laden Sie das Glossar als CSV, Excel (XLS) oder PDF herunter, um es in einem anderen Kurs oder als Offline-Referenz zu verwenden. Sie können **Alle Kategorien** exportieren oder den Export auf eine Kategorie beschränken.

## Anzeigeoptionen

Das Glossar kann in zwei Formaten angezeigt werden, die über die Symbolleiste umgeschaltet werden:

* **Tabellenansicht** — Begriffe in einer Tabelle mit ihren Definitionen aufgelistet
* **Listenansicht** — Begriffe als einzelne, nacheinander angeordnete Bereiche dargestellt

## Tipps

* **Schrittweise aufbauen** — Fügen Sie Begriffe hinzu, wenn Sie sie in Ihrem Kurs einführen, anstatt alle auf einmal
* **Definitionen knapp halten** — Kurze, klare Definitionen sind nützlicher als ausführliche Erklärungen
* **Aus Lernpfaden verlinken** — Verweisen Sie in den Inhalten Ihrer Lernpfade auf Glossarbegriffe, um Lernende zur Nutzung des Glossars anzuregen
