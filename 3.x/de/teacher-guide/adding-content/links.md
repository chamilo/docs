# Links

Mit dem Links-Werkzeug können Sie nützliche URLs mit Ihren Lernenden teilen, geordnet nach Kategorien.

## Einen Link hinzufügen

1. Öffnen Sie das Werkzeug **Links** <img src="../../.gitbook/assets/icons/mdi-link.svg" alt="Links" data-size="line"> auf der Kursstartseite
2. Klicken Sie auf **Link hinzufügen** <img src="../../.gitbook/assets/icons/mdi-link-plus.svg" alt="Link hinzufügen" data-size="line">
3. Füllen Sie die Angaben aus:
   * **URL** — Die Webadresse (z. B. `https://example.com/resource`)
   * **Linkname** — Ein beschreibender Name für den Link
   * **Beschreibung** — Eine optionale Erläuterung, worum es bei der Ressource geht
   * **Kategorie** — Ordnen Sie den Link einer Kategorie zu, um ihn zu organisieren
   * **Ziel** — Wo der Link geöffnet wird: `_self` (gleiches Fenster), `_blank` (neuer Tab), `_parent` oder `_top`
   * **Link auf der Kursstartseite anzeigen** — Ob Sie ihn als Werkzeugsymbol auf der Kursstartseite anzeigen möchten
4. Speichern

## Mit Kategorien organisieren

Kategorien helfen Ihnen, verwandte Links zu gruppieren:

1. Klicken Sie auf **Kategorie hinzufügen**
2. Geben Sie einen **Kategorienamen** und eine optionale Beschreibung ein
3. Speichern

Links innerhalb einer Kategorie werden gemeinsam angezeigt, sodass Lernende relevante Ressourcen leicht finden können.

## Links verwalten

* **Linkprüfung** <img src="../../.gitbook/assets/icons/mdi-check-circle.svg" alt="Gültigkeit" data-size="line">  — Chamilo kann prüfen, ob Links noch aktiv oder defekt sind
* **Bearbeiten** <img src="../../.gitbook/assets/icons/mdi-pencil.svg" alt="Bearbeiten" data-size="line"> — Aktualisieren Sie die URL, den Titel oder die Beschreibung des Links
* **Sichtbarkeit** <img src="../../.gitbook/assets/icons/mdi-eye.svg" alt="Sichtbarkeit" data-size="line"> — Blenden Sie den Link für Lernende aus oder ein
* **Löschen** <img src="../../.gitbook/assets/icons/mdi-delete.svg" alt="Löschen" data-size="line"> — Entfernen Sie den Link

## Links exportieren

Sie können Ihre Linksammlung als PDF exportieren. Suchen Sie im Links-Werkzeug nach der Option **Exportieren**.

## Tipps

* **Nach Thema kategorisieren** — Erstellen Sie für jedes Modul oder jede Woche Ihres Kurses eine Kategorie
* **Beschreibungen hinzufügen** — Helfen Sie Lernenden zu verstehen, warum ein Link relevant ist, bevor sie ihn anklicken
* **Regelmäßig prüfen** — Weblinks können mit der Zeit veralten oder defekt werden
