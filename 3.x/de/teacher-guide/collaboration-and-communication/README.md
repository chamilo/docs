# Zusammenarbeit und Kommunikation

Chamilo stellt mehrere Werkzeuge bereit, die die Interaktion zwischen Ihnen und Ihren Lernenden sowie unter den Lernenden selbst ermöglichen.

* **[Foren](forums.md)** — Thread-basierte Diskussionen, organisiert nach Kategorie und Thema
* **[Chat](chat.md)** — Textnachrichten in Echtzeit innerhalb eines Kurses
* **[Gruppen](groups.md)** — Lernende in Arbeitsgruppen mit eigenen gemeinsamen Werkzeugen einteilen
* **[Wiki](wiki.md)** — Gemeinsames Bearbeiten von Dokumenten
* **[Blog](blog.md)** — Gemeinsames Bloggen innerhalb des Kurses
* **[Videokonferenz](video-conferencing.md)** — Live-Videositzungen mit BigBlueButton oder Zoom

Diese Werkzeuge sind über die Kursstartseite verfügbar. Einige können standardmäßig ausgeblendet sein — Sie können sie über das Werkzeugraster sichtbar machen (siehe [Kursstartseite](../creating-your-course/course-homepage.md)).
