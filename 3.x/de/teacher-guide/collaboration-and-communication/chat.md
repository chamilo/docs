# Chat

Das Chat-Tool ermöglicht Echtzeit-Textnachrichten innerhalb eines Kurses. Es eignet sich für schnelle Kommunikation, Live-Frage-und-Antwort-Runden oder informelle Diskussionen.

## Den Chat nutzen

1. Öffnen Sie das Tool **Chat** von der Kursstartseite aus
2. Wählen Sie im Bereich **Users** einen bestimmten online anwesenden Benutzer, um ihm direkt zu schreiben, oder nutzen Sie den Tab **All**, um die gesamte Gruppe anzusprechen
3. Geben Sie Ihre Nachricht in das Textfeld unten ein und drücken Sie **Enter**, um sie zu senden (**Shift+Enter** für eine neue Zeile ohne Senden)

Eine Option **Preview** ermöglicht die Prüfung der Formatierung vor dem Senden, und **Reset** löscht den aktuellen Entwurf.

## Chat-Funktionen

* **Echtzeit-Nachrichten** — Nachrichten erscheinen sofort beim Empfänger bzw. den Empfängern
* **Nachrichtenverlauf** — Frühere Nachrichten sind sichtbar, sobald Sie den Chat öffnen
* **Benutzerpräsenz** — Der Bereich Users zeigt, wer derzeit im Kurs online ist
* **Direkt oder Gruppe** — Schreiben Sie jeweils einem Lernenden, oder senden Sie über den Tab **All** an alle

## Als Lehrkraft

Als Kurslehrkraft können Sie:

* **Diskussionen überwachen** — Den Chatverlauf prüfen, um das Engagement der Lernenden nachzuvollziehen
* **Chat-Archive in Documents finden** — Das Chat-Tool spiegelt Nachrichten automatisch in HTML-Dateien im Tool Documents, organisiert nach Tag und nach Geltungsbereich (Kurs / Session / Gruppe), sodass die Unterhaltung über die Live-Sitzung hinaus erhalten bleibt

Wenn die Plattformeinstellung "Restrict course chat to tutors" vom Administrator aktiviert ist, können nur Tutoren mit Lernenden chatten; andernfalls können alle im Kurs Eingeschriebenen teilnehmen.

## Tipps für den effektiven Einsatz des Chats

* **Chat-Sitzungen planen** — Informieren Sie Lernende im Voraus, wann Sie für den Live-Chat erreichbar sind (nutzen Sie das Tool Agenda)
* **Grundregeln festlegen** — Erwartungen an respektvolle Kommunikation definieren
* **Für kurze Fragen nutzen** — Der Chat eignet sich am besten für kurze Austausche; nutzen Sie das Forum für längere, strukturierte Diskussionen

> Wenn auf Ihrer Plattform Videokonferenzen konfiguriert sind (BigBlueButton oder Zoom), sollten Sie diese für Live-Sitzungen in Betracht ziehen, bei denen Sprache und Video wirksamer wären. Siehe [Videokonferenzen](video-conferencing.md).
