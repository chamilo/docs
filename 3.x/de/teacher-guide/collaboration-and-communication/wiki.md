# Wiki

Das Wiki-Werkzeug ermöglicht es Ihnen und Ihren Lernenden, innerhalb des Kurses gemeinsam Webseiten zu erstellen und zu bearbeiten. Es eignet sich für Gruppenprojekte, gemeinsame Wissensbasen und kollaborative Schreibübungen.

## Funktionsweise des Wikis

Ein Wiki ist eine Sammlung miteinander verknüpfter Webseiten, die von allen Personen mit entsprechender Berechtigung bearbeitet werden können. In Chamilo gilt:

* Jeder Kurs hat ein eigenes Wiki
* Seiten können über wiki-typische Links miteinander verknüpft werden
* Alle Bearbeitungen werden in einer Versionshistorie festgehalten
* Frühere Versionen können verglichen und wiederhergestellt werden

## Eine Wiki-Seite erstellen

1. Öffnen Sie das Werkzeug **Wiki** auf der Kursstartseite
2. Klicken Sie auf **Add a new page**
3. Geben Sie einen **page title** ein
4. Verfassen Sie den Seiteninhalt mit dem Rich-Text-Editor
5. Speichern Sie

Um aus dem Editor heraus auf eine andere Wiki-Seite zu verlinken, erstellen Sie einen Link mit dem Titel der Zielseite.

## Seiten bearbeiten

Alle Personen mit Bearbeitungsrechten können eine Wiki-Seite ändern:

1. Öffnen Sie die Seite, die Sie bearbeiten möchten
2. Klicken Sie auf die Schaltfläche **Edit** <img src="../../.gitbook/assets/icons/mdi-pencil.svg" alt="Bearbeiten" data-size="line">
3. Nehmen Sie Ihre Änderungen im Editor vor
4. Fügen Sie optional unter **Comments** einen Eintrag hinzu, der beschreibt, was Sie geändert haben
5. Speichern Sie

## Versionshistorie

Jede Bearbeitung erzeugt eine neue Version. Sie können:

* **View history** — Eine Liste aller Versionen mit Zeitstempeln und Autorinnen bzw. Autoren einsehen
* **Compare versions** — Die Unterschiede zwischen zwei Versionen anzeigen
* **Restore a version** — Die Seite bei Bedarf auf eine frühere Version zurücksetzen

## Das Wiki verwalten

Als Kurslehrkraft können Sie:

* **View all pages** — Eine Liste aller Wiki-Seiten im Kurs anzeigen
* **Find orphan pages** — Seiten identifizieren, die von keiner anderen Seite verlinkt sind
* **Find wanted pages** — Seiten anzeigen, auf die verlinkt wird, die aber noch nicht existieren
* **Lock a page for editing** — Alle Bearbeitungen einer Seite sperren, während Sie sie fertigstellen
* **Toggle visibility** — Eine Seite vor Lernenden ausblenden
* **Delete pages** — Seiten entfernen, die nicht mehr benötigt werden
* **Monitor contributions** — Statistiken pro Nutzerin bzw. Nutzer prüfen: aktivste Bearbeitende, am häufigsten bearbeitete Seiten, am häufigsten besuchte Seiten
* **Export** — Eine Wiki-Seite als PDF exportieren oder in das Werkzeug Documents übertragen

## Tipps

* **Nutzen Sie das Wiki für Gruppenprojekte** — Weisen Sie jeder Gruppe eine Wiki-Seite zu, auf der sie ihr Ergebnis gemeinsam erarbeitet
* **Erstellen Sie eine Kurswissensbasis** — Bauen Sie ein Nachschlage-Wiki mit zentralen Konzepten auf und ermutigen Sie Lernende zum Mitwirken
* **Prüfen Sie die Bearbeitungshistorie** — Die Versionshistorie ermöglicht es Ihnen, individuelle Beiträge in der Gruppenarbeit zu bewerten
