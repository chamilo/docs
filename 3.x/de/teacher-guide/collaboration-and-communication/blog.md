# Blog

Das Blog-Werkzeug ermöglicht es Ihnen, innerhalb Ihres Kurses einen gemeinsamen Blog anzulegen. Lernende können Beiträge verfassen, Kommentare hinterlassen und an strukturierten Schreibaktivitäten teilnehmen.

## Einen Blog anlegen

1. Öffnen Sie das Werkzeug **Blog** von der Kursstartseite aus (unter dem Zahnrad-Symbol oben)
2. Klicken Sie auf **New project**
3. Geben Sie einen **Titel** und optional einen Untertitel ein
4. Speichern
5. Legen Sie fest, wann der Blog für Studierende verfügbar sein soll, indem Sie auf das Symbol **Show** (Auge) klicken

Sie können innerhalb eines einzelnen Kurses mehrere Blogs anlegen (z. B. einen pro Thema oder einen pro Gruppe).

## Blog-Beiträge verfassen

1. Öffnen Sie einen Blog
2. Klicken Sie auf **New post**
3. Geben Sie einen **Titel** ein und verfassen Sie den Beitragsinhalt mit dem Rich-Text-Editor
4. Speichern

Sowohl Lehrende als auch Lernende (abhängig von den Berechtigungen) können Beiträge erstellen.

## Kommentare und Bewertungen

Leserinnen und Leser können mit Blog-Beiträgen interagieren über:

* **Kommentare** — Feedback hinterlassen oder unter einem Beitrag eine Diskussion beginnen (Kommentare können auch als Antworten auf andere Kommentare verschachtelt werden)
* **Bewertungen** — Beiträge bewerten, um die am meisten geschätzten Beiträge hervorzuheben
* **Anhänge** — Sowohl Beiträge als auch Kommentare können Dateianhänge enthalten

## Blog-Aufgaben

Sie können innerhalb eines Blogs **Aufgaben** anlegen — konkrete Schreibaufträge, die Lernende als Blog-Beiträge erfüllen müssen. Dies eignet sich für:

* Reflexionstagebücher
* Wöchentliche Schreibaufgaben
* Projektfortschrittsberichte

## Den Blog verwalten

Als Lehrkraft können Sie:

* Beiträge und Kommentare **bearbeiten oder löschen** (das Löschen von Beiträgen ist auf die Autorin bzw. den Autor des Beitrags oder auf Lehrende beschränkt)
* **die Sichtbarkeit des Blogs umschalten**, um den Blog für Lernende ein- oder auszublenden
* **Aufgaben definieren** — Konkrete Schreibaufträge hinzufügen, die Lernende als Beiträge erfüllen sollen. Aufgaben können farblich gekennzeichnet werden, um die visuelle Gruppierung zu erleichtern.
