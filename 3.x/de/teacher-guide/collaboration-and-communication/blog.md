# Blog

Das Blog-Werkzeug ermöglicht es Ihnen, ein gemeinsames Blog innerhalb Ihres Kurses zu erstellen. Lernende können Beiträge verfassen, Kommentare hinterlassen und an strukturierten Schreibaktivitäten teilnehmen.

## Ein Blog erstellen

1. Öffnen Sie das Werkzeug **Blog** auf der Kursstartseite (unter dem Zahnradsymbol oben)
2. Klicken Sie auf **Neues Projekt**
3. Geben Sie einen **Titel** und optional einen Untertitel ein
4. Speichern
5. Legen Sie fest, wann es für Studierende verfügbar sein soll, indem Sie auf das Symbol **Anzeigen** (Auge) klicken

Sie können mehrere Blogs innerhalb eines einzelnen Kurses erstellen (z. B. eines pro Thema oder eines pro Gruppe).

## Kurs- und Sitzungsbereich

Blogs folgen genau dem Kurs-/Sitzungskontext, in dem sie erstellt wurden. Wenn Sie innerhalb einer Sitzung arbeiten, verfügt diese Sitzung über eigene Blog-Ressourcen und eine eigene Mitgliederliste: Blogs des Basiskurses werden nicht automatisch übernommen, und ein Blog aus einer Sitzung wird in einer anderen Sitzung nicht angezeigt.

Diese Trennung gilt auch für Beiträge, Kommentare, Aufgaben, Bewertungen und Anhänge, die zum Blog gehören. Kehren Sie zum gleichen Kurs-/Sitzungskontext zurück, wenn Sie ein Sitzungsblog verwalten.

## Blogbeiträge verfassen

1. Öffnen Sie ein Blog
2. Klicken Sie auf **Neuer Beitrag**
3. Geben Sie einen **Titel** ein und verfassen Sie den Beitragsinhalt mit dem Rich-Text-Editor
4. Speichern

Sowohl Lehrkräfte als auch Lernende (je nach Berechtigungen) können Beiträge erstellen.

## Kommentare und Bewertungen

Leserinnen und Leser können mit Blogbeiträgen interagieren über:

* **Kommentare** — Hinterlassen Sie Feedback oder starten Sie eine Diskussion unter einem Beitrag (Kommentare können auch als Antworten auf andere Kommentare verschachtelt werden)
* **Bewertungen** — Bewerten Sie Beiträge, um die geschätztesten Beiträge hervorzuheben
* **Anhänge** — Sowohl Beiträge als auch Kommentare können Dateianhänge enthalten

## Blog-Aufgaben

Sie können **Aufgaben** innerhalb eines Blogs erstellen — spezifische Schreibaufträge, die Lernende als Blogbeiträge erledigen müssen. Dies ist nützlich für:

* Reflexionstagebücher
* Wöchentliche Schreibaufgaben
* Projektfortschrittsberichte

## Das Blog verwalten

Als Lehrkraft können Sie:

* Beiträge und Kommentare **bearbeiten oder löschen** (das Löschen von Beiträgen ist auf die Autorin bzw. den Autor des Beitrags oder auf Lehrkräfte beschränkt)
* **Die Sichtbarkeit des Blogs umschalten**, um das Blog für Lernende ein- oder auszublenden
* **Aufgaben definieren** — Fügen Sie spezifische Schreibaufträge hinzu, die Lernende als Beiträge erledigen sollen. Aufgaben können farblich gekennzeichnet werden, um die visuelle Gruppierung zu erleichtern.
