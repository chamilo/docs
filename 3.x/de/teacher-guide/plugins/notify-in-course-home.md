# Hinweis auf der Kursstartseite

Hinweis auf der Kursstartseite <img src="/.gitbook/assets/icons/mdi-bell-ring-outline.svg" alt="Hinweis auf der Kursstartseite" data-size="line"> ermöglicht es Ihnen, allen Besuchern Ihrer Kursstartseite ein Popup-Hinweis anzuzeigen — nützlich für eine Ankündigung, einen Hinweis auf Pflichtlektüre oder eine „Hier klicken, um fortzufahren“-Sperre.

## Eine Benachrichtigung festlegen

Sobald die Funktion aktiviert ist, erscheint in den **Einstellungen** <img src="/.gitbook/assets/icons/mdi-cog.svg" alt="Einstellungen" data-size="line"> Ihres Kurses die Schaltfläche **Eine Benachrichtigung auf der Startseite festlegen**. Sie öffnet ein Formular, in dem Sie den Hinweis (Rich Text) verfassen und optional einen **Ablauf-Link** festlegen.

* **Mit Ablauf-Link** — Das Popup zeigt eine Schaltfläche, die auf diesen Link verweist, und erscheint so lange erneut, bis ein Lernender darauf klickt
* **Ohne Ablauf-Link** — Der Hinweis erscheint bei jedem Besuch der Kursstartseite erneut

Verwenden Sie **Benachrichtigung auf der Kursstartseite löschen**, um sie zu entfernen.

## Tipps

* **Nur ein Hinweis pro Kurs** — Das Anlegen eines neuen Hinweises ersetzt den vorherigen; mehrere Hinweise können nicht in eine Warteschlange gestellt werden
* **Formatierung vorab prüfen** — Der Hinweis wird als Roh-HTML in einem Popup angezeigt; prüfen Sie daher, ob der Rich Text wie erwartet dargestellt wird, bevor Sie ihn veröffentlichen
* **Ablauf-Link für zeitkritische Inhalte nutzen** — Ohne ihn erscheint derselbe Hinweis unbegrenzt erneut, was für wiederkehrende Lernende ermüdend werden kann
