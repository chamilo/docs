# Benachrichtigung auf der Kursstartseite

Benachrichtigung auf der Kursstartseite <img src="../../.gitbook/assets/icons/mdi-bell-ring-outline.svg" alt="Benachrichtigung auf der Kursstartseite" data-size="line"> ermöglicht es Ihnen, allen Besuchern Ihrer Kursstartseite einen Popup-Hinweis anzuzeigen — nützlich für eine Ankündigung, einen Hinweis auf Pflichtlektüre oder eine Sperre im Sinne von „Hier klicken, um fortzufahren“.

## Benachrichtigung festlegen

Sobald die Funktion aktiviert ist, erhält der Bereich **Einstellungen** <img src="../../.gitbook/assets/icons/mdi-cog.svg" alt="Einstellungen" data-size="line"> Ihres Kurses die Schaltfläche **Eine Benachrichtigung auf der Startseite festlegen**. Sie öffnet ein Formular, in dem Sie den Hinweis (Rich Text) verfassen und optional einen **Ablauf-Link** festlegen.

* **Mit Ablauf-Link** — Das Popup zeigt eine Schaltfläche, die auf diesen Link verweist, und erscheint so lange erneut, bis ein Lernender darauf klickt
* **Ohne Ablauf-Link** — Der Hinweis erscheint jedem Besucher erneut, jedes Mal, wenn die Kursstartseite geöffnet wird

Verwenden Sie **Benachrichtigung auf der Kursstartseite löschen**, um sie zu entfernen.

## Tipps

* **Nur ein Hinweis pro Kurs** — Das Erstellen eines neuen Hinweises ersetzt den bisherigen; mehrere Hinweise können nicht in eine Warteschlange gestellt werden
* **Formatierung vorab prüfen** — Der Hinweis wird in einem Popup als reines HTML angezeigt. Prüfen Sie daher, ob der Rich Text wie erwartet dargestellt wird, bevor Sie ihn veröffentlichen
* **Den Ablauf-Link für alles Zeitkritische verwenden** — Ohne ihn erscheint derselbe Hinweis unbegrenzt immer wieder, was für wiederkehrende Lernende schnell repetitiv werden kann
