# LTI 1.3 Advantage Provider

LTI 1.3 Advantage Provider <img src="../../.gitbook/assets/icons/mdi-swap-horizontal.svg" alt="LTI 1.3 Advantage Provider" data-size="line"> funktioniert umgekehrt zum [IMS/LTI-Client](ims-lti.md): Anstatt dass Chamilo ein externes Tool startet, ermöglicht es einem **externen LMS** (zum Beispiel einem anderen Chamilo-Portal oder einer anderen Plattform wie Moodle), eine Ihrer Übungen oder einen Ihrer Lernpfade so zu starten, als wäre es ein Tool innerhalb dieses anderen Systems, wobei die Noten an Chamilo zurückübermittelt werden.

## Was das für Sie bedeutet

Als Lehrkraft gibt es hier nichts zu konfigurieren. Ihr Administrator registriert, welche Ihrer Übungen oder Lernpfade auf diese Weise gestartet werden können und von welchen externen Plattformen, vollständig unter **Administration > LTI 1.3 Advantage Provider**.

Wenn Ihre Plattform dieses Plugin verwendet, bedeutet das lediglich, dass einige Ihrer Lernenden eine Ihrer Übungen oder einen Ihrer Lernpfade erreichen können, indem sie einen Link aus einem anderen System anklicken, anstatt sich direkt bei Chamilo anzumelden — die Erfahrung beim Absolvieren der Übung oder des Lernpfads selbst ändert sich nicht.
