# LTI 1.3 Advantage Provider

LTI 1.3 Advantage Provider <img src="../../.gitbook/assets/icons/mdi-swap-horizontal.svg" alt="LTI 1.3 Advantage Provider" data-size="line"> funktioniert umgekehrt zum [IMS/LTI Client](ims-lti.md): Statt dass Chamilo ein externes Tool startet, ermöglicht es einem **externen LMS** (zum Beispiel einem anderen Chamilo-Portal oder einer anderen Plattform wie Moodle), eine Ihrer Übungen oder Lernpfade so zu starten, als wäre sie ein Tool innerhalb dieses anderen Systems, wobei Noten an Chamilo zurückgegeben werden.

## Was das für Sie bedeutet

Als Lehrkraft müssen Sie hier nichts konfigurieren. Ihr Administrator registriert, welche Ihrer Übungen oder Lernpfade auf diese Weise gestartet werden können und von welchen externen Plattformen, vollständig unter **Administration > LTI 1.3 Advantage Provider**.

Wenn Ihre Plattform dieses Plugin verwendet, bedeutet das lediglich, dass einige Ihrer Studierenden eine Ihrer Übungen oder Lernpfade erreichen könnten, indem sie einen Link in einem anderen System anklicken, statt sich direkt bei Chamilo anzumelden — das Erlebnis beim Absolvieren der Übung oder des Lernpfads selbst ändert sich nicht.
