# Positionierung

Positionierung <img src="/.gitbook/assets/icons/mdi-radar.svg" alt="Positionierung" data-size="line"> fügt einen Vorher-/Nachher-Selbstbewertungsablauf hinzu: Wählen Sie einen Test als **Anfangstest** und einen anderen als **Abschlusstest** (häufig eine Kopie desselben Tests), und Chamilo zeigt die Punktzahländerung jedes Lernenden zwischen den beiden Tests in einem Netzdiagramm an.

## Zugriff auf das Werkzeug

Sobald es aktiviert ist, erscheint auf der Startseite Ihres Kurses ein Werkzeug **Positionierung**. Es listet die geeigneten Tests des Kurses mit den Schaltflächen **Als Anfangstest auswählen** / **Als Abschlusstest auswählen**, einer Verknüpfung zu den Ergebnissen jedes Tests und dem Netzdiagramm zum Vergleich der durchschnittlichen Anfangs- und Abschlusswerte auf.

## Welche Tests geeignet sind

Nur Tests, die alle drei der folgenden Kriterien erfüllen, erscheinen als auswählbar:

* Mindestens 3 Fragenkategorien
* Der Ergebnisseitentyp des Tests ist auf **radar** gesetzt
* Genau ein Versuch ist zulässig

Wenn ein Test, den Sie erwarten, in der Liste fehlt, prüfen Sie zuerst diese drei Einstellungen bei diesem Test.

## Durchsetzung der Reihenfolge

Ihr Administrator kann zusätzlich plattformweit konfigurieren:

* **Andere Kurswerkzeuge sperren**, bis der Lernende den Anfangstest abgeschlossen hat
* Eine **Freigabeschwelle für den Abschlusstest** — ein Mindestprozentsatz der durchschnittlichen Lernpfad-Abschlussquote, der erforderlich ist, bevor der Abschlusstest freigeschaltet wird

## Tipps

* **Den Radar-Ergebnistyp früh festlegen** — Da die Eignung von Testeinstellungen abhängt, die Sie beim Erstellen des Tests vornehmen, planen Sie die Positionierung, bevor Sie Kategorien und Ergebnisseitentyp Ihres Tests abschließen, nicht danach
* **Eine echte Kopie für den Abschlusstest verwenden** — Ein Test mit sich selbst zu vergleichen, sagt wenig aus; der Abschlusstest sollte dieselben Kategorien abdecken, damit das Netzdiagramm aussagekräftig ist
