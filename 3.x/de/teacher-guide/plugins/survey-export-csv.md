# Umfrage-Export CSV

Umfrage-Export CSV <img src="/.gitbook/assets/icons/mdi-file-delimited-outline.svg" alt="Umfrage-Export CSV" data-size="line"> fügt einen Ein-Klick-Export der Ergebnisse einer Umfrage in eine kompakte CSV-Datei hinzu, mit einer Zeile pro Befragtem und einer Spalte pro Frage.

## Eine Umfrage exportieren

Sobald aktiviert, erhält die Liste des **Umfrage**-Werkzeugs Ihres Kurses eine Spalte **Export** mit einem CSV-Symbol in jeder Umfragezeile. Klicken Sie darauf, um die Ergebnisse sofort herunterzuladen — ohne zusätzliche Schritte.

## Was in der Datei enthalten ist

* Anonyme Umfragen werden ohne Identitäts spalten exportiert
* Nicht anonyme Umfragen enthalten die Identität des Befragten neben den Antworten
* Ob unvollständige (nicht abgeschlossene) Antworten einbezogen werden, steuert Ihr Administrator, nicht dieser Export-Schaltfläche

## Tipps

* **Große Umfragen können einen Moment dauern** — Sehr große Antwortmengen können beim Export langsamer sein; dies ist eine Datenbank-Leistungsfrage, die Ihr Administrator bei Bedarf anpassen kann
* **Mit Umfrage-Export TXT kombinieren** — Wenn Sie auch das Plugin [Umfrage-Export TXT](survey-export-txt.md) aktiviert haben, sehen Sie zwei Export-Symbole; wählen Sie das Format, das zu Ihrer geplanten Datennutzung passt
