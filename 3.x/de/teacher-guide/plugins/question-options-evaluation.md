# Bewertung der Fragenoptionen

Bewertung der Fragenoptionen <img src="../../.gitbook/assets/icons/mdi-calculator-variant.svg" alt="Bewertung der Fragenoptionen" data-size="line"> ermöglicht es Ihnen, eine Formel mit negativer Bewertung (Abzug) auf die Punktzahl eines Tests anzuwenden, anstatt das Standardverhalten von Chamilo zu nutzen, bei dem lediglich die richtigen Antworten addiert werden.

## Eine Formel festlegen

Sobald die Funktion aktiviert ist, erscheint neben jedem Test in der Liste des Kurswerkzeugs **Tests** ein zusätzliches Symbol. Ein Klick darauf öffnet ein kleines Formular, in dem Sie eine der folgenden Optionen wählen:

* **Keine Formel** — normale Bewertung von Chamilo (Standard)
* **Fragenpunkte neu berechnen** — verteilt die Gewichtung der Optionen neu, ohne Abzug
* **Erfolge − Misserfolge**
* **Erfolge − Misserfolge / 2**
* **Erfolge − Misserfolge / 3**

Die gewählte Formel gilt nur für diesen speziellen Test.

> Diese Einstellung ändert nicht die Gewichtung der Fragen oder Antworten selbst — sie ändert, wie die Endpunktzahl berechnet wird. Ist das Plugin deaktiviert oder keine Formel ausgewählt, fällt Chamilo auf die ursprüngliche Bewertung zurück.

## Tipps

* **Zuerst an einer Kopie testen** — Das Ändern einer Formel kann die Punktzahlen verändern, die Lernende in diesem Test erhalten; testen Sie sie an einem duplizierten Test, bevor Sie sie auf einen laufenden Test anwenden
* **Die Änderung den Lernenden erklären** — Eine Abzugsformel kann überraschend sein, wenn Lernende an eine einfache Bewertung richtiger Antworten gewöhnt sind; erwähnen Sie sie in Ihren Anweisungen
