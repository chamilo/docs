# Bewertung der Fragenoptionen

Die Bewertung der Fragenoptionen <img src="../../.gitbook/assets/icons/mdi-calculator-variant.svg" alt="Bewertung der Fragenoptionen" data-size="line"> ermöglicht es Ihnen, auf die Bewertung eines Tests eine Formel für Negativbewertung (Punktabzug) anzuwenden, anstatt des Standardverhaltens von Chamilo, bei dem richtige Antworten einfach summiert werden.

## Formel festlegen

Sobald die Funktion aktiviert ist, erscheint neben jedem Test in der Liste des Kurswerkzeugs **Tests** ein zusätzliches Symbol. Ein Klick darauf öffnet ein kleines Formular, in dem Sie eine der folgenden Optionen auswählen:

* **Keine Formel** — normale Bewertung von Chamilo (Standard)
* **Fragenbewertungen neu berechnen** — verteilt die Gewichtung der Optionen ohne Punktabzug neu
* **Erfolge − Fehlversuche**
* **Erfolge − Fehlversuche / 2**
* **Erfolge − Fehlversuche / 3**

Die gewählte Formel gilt nur für diesen bestimmten Test.

> Diese Einstellung ändert nicht die Gewichtungen der Fragen oder Antworten selbst — sie ändert, wie die Endpunktzahl berechnet wird. Wenn das Plugin deaktiviert ist oder keine Formel ausgewählt wurde, verwendet Chamilo wieder die ursprüngliche Bewertung.

## Tipps

* **Zuerst an einer Kopie testen** — Das Ändern einer Formel kann die Punktzahlen verändern, die Lernende bei diesem Test erhalten; probieren Sie sie an einem Duplikat des Tests aus, bevor Sie sie auf einen aktiven Test anwenden
* **Erläutern Sie die Änderung den Lernenden** — Eine Formel mit Punktabzug kann überraschend sein, wenn Lernende an eine einfache Bewertung richtiger Antworten gewöhnt sind; erwähnen Sie sie in Ihren Anweisungen
