# H5P-Import

H5P-Import <img src="../../.gitbook/assets/icons/mdi-puzzle.svg" alt="H5P-Import" data-size="line"> ermöglicht es Ihnen, standardmäßige `.h5p`-Pakete mit interaktiven Inhalten (interaktives Video, Quiz, Präsentationen und andere H5P-Inhaltstypen) in einen Kurs zu übernehmen, wobei Versuche und Fortschritt der Lernenden ähnlich wie bei einem Chamilo-Test erfasst werden.

## Zugriff auf das Tool

Sobald aktiviert, erscheint auf der Kursstartseite ein Tool **H5P-Import**, das eine Tabelle der H5P-Pakete des Kurses mit Titel, Beschreibung und der Anzahl der Starts jedes Pakets anzeigt.

## Inhalte hinzufügen

* Klicken Sie auf **Hochladen** und wählen Sie eine `.h5p`-Datei mit Titel und Beschreibung aus, um sie zur Liste des Kurses hinzuzufügen
* Verwenden Sie in einem **Lernpfad** den H5P-Eintrag im Ressourcenpanel, um eines der hochgeladenen Pakete des Kurses direkt als Lernpfadelement einzufügen

## Tipps

* **Inhalte vor dem Hochladen gestalten** — Sie können ein H5P-Paket nach dem Hochladen nicht mehr bearbeiten; korrigieren Sie es in Ihrem H5P-Autorentool und laden Sie es erneut hoch, wenn Sie eine Änderung vornehmen müssen
* **Alles in der Liste des Tools ist standardmäßig für alle Studierenden sichtbar** — Wenn Sie die Sichtbarkeit einzeln steuern möchten, fügen Sie Pakete stattdessen über einen Lernpfad hinzu, wo Sie die Sichtbarkeit jedes Elements einzeln verwalten können
* **Dies ist eine Beta-Funktion** — Betrachten Sie sie als nutzbar, aber noch in der Entwicklung, und bewahren Sie eine Kopie Ihrer `.h5p`-Quelldateien auf, falls Sie sie erneut hochladen müssen
