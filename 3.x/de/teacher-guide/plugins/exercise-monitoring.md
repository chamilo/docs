# Exercise Monitoring

Exercise Monitoring <img src="../../.gitbook/assets/icons/mdi-camera.svg" alt="Exercise Monitoring" data-size="line"> nutzt die Webcam einer lernenden Person, um während eines Testversuchs Identitätsfotos aufzunehmen — ein Foto eines Ausweisdokuments und ein Foto des Gesichts — zu Zwecken der Prüfungsintegrität.

## Einen Test kennzeichnen

Öffnen Sie die Einstellungen des Tests und aktivieren Sie die Option **Exercise Monitoring**. Sobald der Test gekennzeichnet ist, sehen Lernende, die diesen Test absolvieren, ein kleines schwebendes Webcam-Widget und werden aufgefordert, die beiden Fotos vor oder während ihres Versuchs aufzunehmen.

## Aufnahmen prüfen

[inferred] Die aufgenommenen Fotos werden über den Berichtsbildschirm geprüft, der vom Plugin **[Exercise Focused](exercise-focused.md)** hinzugefügt wird, neben dem dieses Plugin entwickelt wurde — wenn auf Ihrer Plattform nur Exercise Monitoring und nicht Exercise Focused aktiviert ist, fragen Sie Ihren Administrator, wie die aufgenommenen Fotos in Ihrer Installation geprüft werden sollen.

## Wissenswertes

* **Hierbei werden sensible personenbezogene Daten verarbeitet** — Fotos von Ausweisdokumenten sind eine Datenkategorie, die viele Einrichtungen und Datenschutzvorschriften mit besonderer Sorgfalt behandeln. Klären Sie mit Ihrem Administrator, ob der Einsatz dieses Plugins den Datenschutzpflichten Ihrer Einrichtung entspricht, bevor Sie sich darauf verlassen
* **Fotos werden nur vorübergehend aufbewahrt** — Ihr Administrator legt eine Aufbewahrungsfrist fest, nach deren Ablauf die aufgenommenen Fotos automatisch gelöscht werden
* **Dies ist eine Funktion in einem frühen Stadium** — Rechnen Sie mit Unvollkommenheiten; prüfen Sie in einem Testlauf, ob der Aufnahmeablauf wie erwartet funktioniert, bevor Sie die Funktion für eine echte Prüfung einsetzen
