# Übungsüberwachung

Übungsüberwachung <img src="/.gitbook/assets/icons/mdi-camera.svg" alt="Übungsüberwachung" data-size="line"> verwendet die Webcam eines Studierenden, um während eines Testversuchs Identitätsfotos aufzunehmen — ein Foto eines Ausweisdokuments und ein Foto des Gesichts des Studierenden — zum Zweck der Prüfungsintegrität.

## Einen Test kennzeichnen

Öffnen Sie die Einstellungen des Tests und aktivieren Sie die Option **Exercise Monitoring**. Nach der Kennzeichnung sehen Studierende, die diesen Test versuchen, ein kleines schwebendes Webcam-Widget und werden aufgefordert, die beiden Fotos vor oder während ihres Versuchs aufzunehmen.

## Aufnahmen prüfen

[inferred] Aufgenommene Fotos werden über den Berichtsbildschirm geprüft, der vom Plugin **[Exercise Focused](exercise-focused.md)** hinzugefügt wird, das zusammen mit diesem Plugin entwickelt wurde — wenn auf Ihrer Plattform nur Exercise Monitoring aktiviert ist und nicht Exercise Focused, fragen Sie Ihren Administrator, wie aufgenommene Fotos in Ihrer Installation geprüft werden sollen.

## Wichtige Hinweise

* **Hierbei handelt es sich um sensible personenbezogene Daten** — Fotos von Ausweisdokumenten sind eine Datenkategorie, die viele Institutionen und Datenschutzvorschriften mit besonderer Sorgfalt behandeln. Klären Sie mit Ihrem Administrator, dass der Einsatz dieses Plugins den Datenschutzpflichten Ihrer Institution entspricht, bevor Sie sich darauf verlassen
* **Fotos werden vorübergehend gespeichert** — Ihr Administrator legt eine Aufbewahrungsfrist fest, nach der aufgenommene Fotos automatisch gelöscht werden
* **Dies ist eine Funktion im frühen Stadium** — Rechnen Sie mit Unvollkommenheiten; überprüfen Sie den Aufnahmeablauf in einem Testdurchlauf, bevor Sie ihn für eine echte Prüfung verwenden
