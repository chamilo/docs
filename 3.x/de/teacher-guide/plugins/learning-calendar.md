# Lernkalender

Der Lernkalender <img src="/.gitbook/assets/icons/mdi-calendar-text.svg" alt="Lernkalender" data-size="line"> unterstützt die Planung von Blended Learning oder ausbildungsähnlichen Formaten, die Präsenzzeiten mit praxisbezogenen Phasen außerhalb des Unterrichts kombinieren. Sie erstellen einen Kalender, in dem jeder Tag als **Belegt**, **Prüfung** oder **Frei** gekennzeichnet wird, weisen Lernende zu, und deren persönliche Agenda zeigt anschließend diese geplanten Tage an.

## Zugriff auf das Werkzeug

Sobald die Funktion aktiviert ist, erscheint in **Mein Bereich** (Ihrem Berichtsbereich) ein Symbol **Lernkalender**. Es öffnet eine Liste der von Ihnen erstellten Kalender mit Optionen zum Hinzufügen, Bearbeiten, Kopieren, Löschen und zum Zuweisen von Lernenden zu jedem Kalender.

## Einen Kalender erstellen

1. Einen neuen Kalender anlegen
2. Auf einen Tag klicken, um ihn durch **Belegt → Prüfung → Frei → leeren** zu schalten
3. Die Lernenden zuweisen, die diesem Kalender folgen sollen

Zugewiesene Lernende sehen die geplanten Tage in ihrer eigenen Agenda; die Berichte vergleichen geplante Tage mit dem tatsächlichen Abschluss ihrer Lernpfade.

## Tipps

* **Pro Lernendem jeweils nur ein Kalender** — Ein Lernender kann nur einem einzigen Kalender zugewiesen werden. Planen Sie daher nach Kohorten, statt mehrere Kalender auf eine Person zu legen
* **Dies ist eine Funktion im frühen Stadium** — Sie ist unabhängig von einem einzelnen Kurs. Erwarten Sie daher nicht denselben Reifegrad wie bei den zentralen Chamilo-Werkzeugen; prüfen Sie, ob sie zu Ihrem Ausbildungsformat passt, bevor Sie sich für eine echte Kohorte darauf stützen
