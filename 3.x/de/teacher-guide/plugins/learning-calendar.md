# Lernkalender

Lernkalender <img src="../../.gitbook/assets/icons/mdi-calendar-text.svg" alt="Lernkalender" data-size="line"> hilft bei der Planung von Blended-Learning- oder ausbildungsähnlichen Schulungen, die Präsenzzeit mit Praxis außerhalb des Standorts verbinden. Sie erstellen einen Kalender, in dem jeder Tag als **Belegt**, **Prüfung** oder **Frei** markiert wird, weisen Lernende zu, und deren persönliche Agenda zeigt dann diese geplanten Tage an.

## Zugriff auf das Werkzeug

Sobald es aktiviert ist, erscheint ein Symbol **Lernkalender** in **Mein Bereich** (Ihrem Berichtsbereich). Es öffnet eine Liste der von Ihnen erstellten Kalender mit Optionen zum Hinzufügen, Bearbeiten, Kopieren, Löschen und Zuweisen von Lernenden zu jedem Kalender.

## Einen Kalender erstellen

1. Erstellen Sie einen neuen Kalender
2. Klicken Sie auf einen Tag, um ihn durch **Belegt → Prüfung → Frei → löschen** zu schalten
3. Weisen Sie die Lernenden zu, die diesem Kalender folgen sollen

Zugewiesene Lernende sehen ihre geplanten Tage in ihrer eigenen Agenda, und die Berichte vergleichen geplante Tage mit dem tatsächlichen Abschluss ihrer Lernpfade.

## Tipps

* **Ein Kalender pro Lernendem gleichzeitig** — Ein Lernender kann nur einem einzigen Kalender zugewiesen werden. Planen Sie daher nach Kohorten, anstatt mehrere Kalender auf eine Person zu legen
* **Dies ist eine Funktion in einem frühen Stadium** — Sie ist unabhängig von einem einzelnen Kurs. Erwarten Sie daher nicht denselben Feinschliff wie bei den Kernwerkzeugen von Chamilo; prüfen Sie, ob sie zu Ihrem Schulungsformat passt, bevor Sie sich bei einer echten Kohorte darauf verlassen
