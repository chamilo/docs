# Rechtliche Kursvereinbarung

Das Plugin Rechtliche Kursvereinbarung <img src="../../.gitbook/assets/icons/mdi-file-check-outline.svg" alt="Rechtliche Kursvereinbarung" data-size="line"> verlangt von Studierenden, dass sie Nutzungsbedingungen bzw. einen rechtlichen Hinweis akzeptieren, bevor sie auf Ihren Kurs zugreifen können — nützlich für Einwilligungserklärungen, Nutzungsrichtlinien oder jeden Hinweis, dem Lernende formell zustimmen müssen.

## Für Ihren Kurs aktivieren

Die plattformweite Aktivierung des Plugins bewirkt allein noch nichts — Sie müssen es für jeden Kurs einschalten, in dem Sie es verwenden möchten:

1. Öffnen Sie die **Einstellungen** <img src="../../.gitbook/assets/icons/mdi-cog.svg" alt="Einstellungen" data-size="line"> Ihres Kurses
2. Aktivieren Sie im Bereich für den Kurszugriff **Rechtliche Bedingungen aktivieren**

Dadurch wird Ihrem Kurs das Werkzeug **Rechtliche Kursvereinbarung** hinzugefügt.

## Die Vereinbarung verfassen

Öffnen Sie das Werkzeug **Rechtliche Kursvereinbarung**, um:

* den Hinweistext zu verfassen (Rich-Text-Editor)
* optional eine herunterladbare Datei anzuhängen
* festzulegen, was beim Speichern geschieht: **Keine Benachrichtigung senden**, **Alle Benutzer per E-Mail benachrichtigen** oder **Alle Benutzer per E-Mail benachrichtigen und ihnen den Anhang senden**

## Annahme prüfen

Die **Benutzerliste** des Werkzeugs zeigt alle Studierenden und ob sie die Vereinbarung akzeptiert haben (über das Web oder per E-Mail), mit Aktionen zum erneuten Senden des Vereinbarungslinks oder zum Entfernen der aufgezeichneten Annahme eines Benutzers.

## Tipps

* **Kurs auf Privat setzen** — Dieses Plugin soll den Zugriff steuern; die Sichtbarkeit Öffentlich oder Offen widerspricht dieser Absicht
* **Bewusst aktualisieren** — Eine Änderung des Vereinbarungstextes macht frühere Annahmen nicht automatisch ungültig; verwenden Sie **Alle vorherigen Benutzervereinbarungen entfernen**, wenn alle die neue Version akzeptieren müssen
* **Hinweis kurz halten** — Ein langer Rechtstext wird eher überflogen als gelesen; verlinken Sie bei Bedarf auf ein vollständiges Richtliniendokument
