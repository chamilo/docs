# Test to PDF

Test to PDF <img src="../../.gitbook/assets/icons/mdi-file-pdf-box.svg" alt="Test to PDF" data-size="line"> exportiert die Fragen eines Kurstests in ein druckbares PDF — nur Fragen, nur Antworten oder beides zusammen — und eignet sich für eine Papierversion eines Tests.

## Zugriff auf das Werkzeug

Sobald es aktiviert ist, erscheint auf Ihrer Kursstartseite ein **Test to PDF**-Werkzeug, das alle Tests des Kurses (oder der Sitzung) auflistet. Jede Zeile bietet drei Aktionen: **Fragen herunterladen**, **Antworten herunterladen** und **Alles herunterladen**.

## Tipps

* **Nicht jeder Fragetyp wird unterstützt** — Nur eine Teilmenge der Fragetypen von Chamilo (Multiple Choice, Wahr/Falsch und ähnliche geschlossene Formate) wird sauber exportiert; offene oder komplexere Fragetypen erscheinen möglicherweise nicht korrekt oder gar nicht
* **Prüfen Sie die Ausgabe, bevor Sie eine ganze Charge drucken** — Überprüfen Sie das erzeugte PDF für einen Test, bevor Sie es für eine Prüfungssitzung in großer Stückzahl drucken
