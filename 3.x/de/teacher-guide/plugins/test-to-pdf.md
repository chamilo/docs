# Test to PDF

Test to PDF <img src="../../.gitbook/assets/icons/mdi-file-pdf-box.svg" alt="Test to PDF" data-size="line"> exportiert die Fragen eines Kurstests in ein druckbares PDF — nur Fragen, nur Antworten oder beides zusammen — nützlich für eine Papierfassung eines Tests.

## Zugriff auf das Werkzeug

Sobald aktiviert, erscheint auf Ihrer Kursstartseite ein Werkzeug **Test to PDF**, das jeden Test im Kurs (oder in der Session) auflistet. Jede Zeile bietet drei Aktionen: **Fragen herunterladen**, **Antworten herunterladen** und **Alles herunterladen**.

## Tipps

* **Nicht jeder Fragetyp wird unterstützt** — Nur eine Teilmenge der Fragetypen von Chamilo (Multiple Choice, Wahr/Falsch und ähnliche geschlossene Formate) wird sauber exportiert; offene oder komplexere Fragetypen erscheinen möglicherweise nicht korrekt, wenn überhaupt
* **Prüfen Sie die Ausgabe, bevor Sie einen ganzen Stapel drucken** — Sehen Sie sich das erzeugte PDF für einen Test an, bevor Sie für eine Prüfungssitzung in großer Stückzahl drucken
