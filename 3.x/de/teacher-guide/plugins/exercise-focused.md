# Exercise Focused

Exercise Focused <img src="../../.gitbook/assets/icons/mdi-eye-outline.svg" alt="Exercise Focused" data-size="line"> ist ein Hilfsmittel zur Betrugsprävention bei Prüfungen. Verliert der Browser einer lernenden Person während eines gekennzeichneten Tests den Fokus — etwa durch den Wechsel zu einem anderen Tab oder Fenster —, zeigt Chamilo eine Vollbildwarnung mit der Aufforderung zurückzukehren und kann den Versuch automatisch abgeben, wenn dies nicht geschieht.

## Einen Test kennzeichnen

Öffnen Sie die Einstellungen des Tests und aktivieren Sie die Option **Exercise Focused**. Sobald der Test gekennzeichnet ist, wird jeder Versuch auf Fokusverlust überwacht, und jedes Ereignis wird protokolliert.

## Was Lernende sehen

Verlässt eine überwachte lernende Person das Prüfungsfenster, erscheint ein Overlay mit der Aufforderung, zurückzukehren und den Test abzuschließen. Je nachdem, wie Ihr Administrator das Plugin konfiguriert hat, kann dies auch einen Countdown starten, der den Versuch automatisch abgibt, und/oder nach einer festgelegten Anzahl von Fokusverlust-Ereignissen automatisch abgeben.

## Ergebnisse überprüfen

Ein gekennzeichneter Test erhält ein Berichtssymbol, das einen Bericht mit drei Registerkarten öffnet:

* Eine Zusammenfassung nach Versuch
* Eine filterbare, durchsuchbare Ansicht mit Excel-Export
* Eine Registerkarte zur Zufallsstichprobe für die stichprobenartige Prüfung von Versuchen

## Tipps

* **Das Verhalten selbst gilt plattformweit** — Als Lehrkraft wählen Sie nur aus, welche Tests gekennzeichnet werden; die Dauer des Warn-Countdowns und die Anzahl der zulässigen Fokusverlust-Ereignisse vor der automatischen Abgabe werden einmalig von Ihrem Administrator festgelegt
* **Informieren Sie die Lernenden im Voraus** — Teilen Sie den Lernenden mit, dass ein Test auf diese Weise überwacht wird, bevor sie beginnen, damit eine Browser-Benachrichtigung oder ein versehentlicher Klick nicht ihren Versuch kostet
* **Es gilt nur für den standardmäßigen Testbildschirm** — Wenn Ihre Plattform Tests auf einem anderen Weg bereitstellt, greift die Erkennung von Fokusverlust dort möglicherweise nicht
