# Exercise Focused

Exercise Focused <img src="../../.gitbook/assets/icons/mdi-eye-outline.svg" alt="Exercise Focused" data-size="line"> ist eine Hilfsfunktion gegen Betrug bei Prüfungen. Verliert der Browser einer Lernenden Person während eines gekennzeichneten Tests den Fokus — etwa durch Wechsel zu einem anderen Tab oder Fenster —, zeigt Chamilo eine vollflächige Warnung mit der Aufforderung zur Rückkehr und kann den Versuch automatisch abgeben, wenn dies nicht geschieht.

## Einen Test kennzeichnen

Öffnen Sie die Einstellungen des Tests und aktivieren Sie die Option **Exercise Focused**. Nach der Kennzeichnung wird jeder Versuch in diesem Test auf Fokusverlust überwacht, und jedes Ereignis wird protokolliert.

## Was Lernende sehen

Verlässt eine überwachte Lernende Person das Prüfungsfenster, erscheint eine Überlagerung mit der Aufforderung, zurückzukehren und den Test abzuschließen. Je nach Konfiguration des Plugins durch Ihre Administration kann damit auch ein Countdown beginnen, der den Versuch automatisch abgibt, und/oder die automatische Abgabe nach einer festgelegten Anzahl von Fokusverlust-Ereignissen erfolgen.

## Ergebnisse prüfen

Ein gekennzeichneter Test erhält ein Berichtssymbol, das einen Bericht mit drei Registerkarten öffnet:

* Eine Zusammenfassung nach Versuch
* Eine filter- und durchsuchbare Ansicht mit Excel-Export
* Eine Registerkarte mit Zufallsstichproben zur stichprobenartigen Prüfung von Versuchen

## Tipps

* **Das Verhalten selbst gilt plattformweit** — Als Lehrkraft wählen Sie lediglich, welche Tests gekennzeichnet werden; die Länge des Warn-Countdowns und die Anzahl erlaubter Fokusverlust-Ereignisse vor der automatischen Abgabe werden einmalig von Ihrer Administration festgelegt
* **Informieren Sie Lernende im Voraus** — Teilen Sie den Lernenden mit, dass ein Test auf diese Weise überwacht wird, bevor sie beginnen, damit eine Browser-Benachrichtigung oder ein versehentlicher Klick nicht den Versuch kostet
* **Es gilt nur für die Standard-Testansicht** — Wenn Ihre Plattform Tests über einen anderen Weg ausliefert, greift die Erkennung von Fokusverlust dort möglicherweise nicht
