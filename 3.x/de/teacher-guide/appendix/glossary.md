# Glossar

Wichtige Begriffe, die in diesem Leitfaden verwendet werden.

| Begriff | Definition |
|------|-----------|
| **Assessment** | Siehe **Notenbuch** unten |
| **Aufgabe** | Eine Aufgabe, bei der Lernende Dateien oder Text zur Überprüfung und Bewertung durch die Lehrkraft einreichen. Auch bekannt als „student publication“ oder „work“. |
| **Auto-launch** | Eine Funktion, die automatisch ein bestimmtes Werkzeug öffnet, wenn eine lernende Person einen Kurs betritt. |
| **Zertifikat** | Ein Dokument, das automatisch erzeugt wird, wenn eine lernende Person die im Notenbuch festgelegte Mindestpunktzahl erreicht. |
| **Kurs** | Ein Container für Lerninhalte und Werkzeuge. Ein Kurs kann Dokumente, Übungen, Foren, Lernpfade und mehr enthalten. |
| **Kurstutor** | Eine Lehrkraftrolle, die spezifisch für Sitzungen ist. Ein Kurstutor verwaltet einen Kurs innerhalb einer Sitzung. In Chamilo-Versionen vor 3.0 als „course coach“ bezeichnet. |
| **Speicherkontingent** | Der maximale Speicherplatz, der einem Kurs für hochgeladene Dateien zugewiesen ist. |
| **Einschreibung** | Der Vorgang, eine Benutzerin oder einen Benutzer in einem Kurs oder einer Sitzung zu registrieren und ihr bzw. ihm Zugang zu den Inhalten zu geben. Auch bekannt als „subscription“. |
| **Übung** | Ein Quiz oder Test mit einer oder mehreren Fragen. In manchen Kontexten auch als „test“ bezeichnet. |
| **Forum** | Ein Diskussionswerkzeug mit verschachtelten Unterhaltungen, die in Kategorien und Themen organisiert sind. |
| **Notenbuch** | Ein Werkzeug, das Punkte aus Übungen, Aufgaben und anderen Aktivitäten zu einer einheitlichen Note für jede lernende Person zusammenfasst. |
| **Lernpfad** | Eine strukturierte Abfolge von Lernaktivitäten (Dokumente, Übungen, Links), die Lernende in einer festgelegten Reihenfolge durchlaufen, optional mit Voraussetzungen. |
| **LTI** | Learning Tools Interoperability — ein Standard, der es ermöglicht, externe Lernwerkzeuge in Chamilo einzubetten. |
| **SCORM** | Sharable Content Object Reference Model — ein Standard für E-Learning-Inhaltspakete. Chamilo kann SCORM-Pakete importieren und innerhalb von Lernpfaden abspielen. |
| **Sitzung** | Eine zeitlich begrenzte Ausgabe eines oder mehrerer Kurse, die einer bestimmten Gruppe von Lernenden zugewiesen ist. Sitzungen ermöglichen die Wiederverwendung derselben Kursinhalte für unterschiedliche Kohorten. |
| **Sitzungstutor** | Eine Aufsichtsrolle, die alle Kurse innerhalb einer Sitzung überwacht. In Chamilo-Versionen vor 3.0 als „session coach“ bezeichnet. |
| **Kompetenz** | Eine Kompetenz, die mit Leistungen im Notenbuch verknüpft werden kann. Wenn eine lernende Person ein Zertifikat erhält, werden zugehörige Kompetenzen bestätigt. |
| **Umfrage** | Ein Fragebogenwerkzeug zum Einholen von Feedback, mit verschiedenen Fragetypen und der Option anonymer Antworten. |
| **Sichtbarkeit** | Eine Einstellung, die steuert, ob ein Werkzeug, Dokument oder eine Aktivität für Lernende sichtbar ist. Lehrkräfte können ausgeblendete Elemente stets sehen. |
