# FAQ

## Allgemeine Fragen

**Wie greife ich auf meinen Kurs zu?**

Klicken Sie in der Seitenleiste auf **Meine Kurse** und anschließend auf den Kurs, den Sie öffnen möchten. Wenn Ihr Kurs Teil einer Session ist, klicken Sie zuerst auf **Meine Sessions** und wählen Sie dann die Session und den Kurs aus.

**Können meine Lernenden den Kurs über ein Mobiltelefon aufrufen?**

Ja. Chamilo 3.0 verfügt über eine responsive Oberfläche, die sich an alle Bildschirmgrößen anpasst. Lernende können jeden modernen Webbrowser auf einem Telefon, Tablet oder Computer verwenden.

**Welche Browser werden unterstützt?**

Chamilo 3.0 funktioniert mit allen gängigen modernen Browsern: Chrome, Firefox, Safari und Edge. Für die beste Erfahrung verwenden Sie die neueste Version Ihres Browsers.

## Inhalte und Kurse

**Wie erstelle ich eine Sicherungskopie meines Kurses?**

Gehen Sie zum Werkzeug **Wartung** in Ihrem Kurs (erreichbar über das Einstellungsmenü auf der Kursstartseite). Dort finden Sie Optionen zum Exportieren Ihrer Kursinhalte.

**Kann ich Inhalte von einem Kurs in einen anderen kopieren?**

Ja. Nutzen Sie die Import-/Exportfunktionen im Werkzeug Wartung, um Inhalte zwischen Kursen zu kopieren. Sie müssen zuerst einen leeren *Zielkurs* anlegen.

**Welche Dateiformate kann ich hochladen?**

Chamilo unterstützt die meisten gängigen Dateiformate: PDF, Word-Dokumente, PowerPoint-Präsentationen, Bilder (PNG, JPG, SVG, GIF), Audiodateien, Videodateien und viele weitere. Ihr Administrator kann bestimmte Dateitypen aus Sicherheitsgründen einschränken.

**Wie groß darf eine hochgeladene Datei maximal sein?**

Das hängt von der Serverkonfiguration ab. Ihr Administrator legt das Upload-Limit fest. Wenn Sie an ein Limit stoßen, wenden Sie sich an Ihren Administrator.

## Bewertung

**Können Übungen automatisch bewertet werden?**

Ja. Die meisten Fragetypen (Multiple Choice, Wahr/Falsch, Lückentext, Zuordnung) werden automatisch bewertet. Offene Fragen erfordern eine manuelle Bewertung, oder Sie können eine KI-gestützte Bewertung nutzen, sofern diese konfiguriert ist.

**Kann ich für Übungen eine Zeitbegrenzung festlegen?**

Ja. Beim Erstellen oder Bearbeiten einer Übung können Sie eine Zeitbegrenzung in Minuten festlegen. Lernende sehen dann einen Countdown-Timer.

**Können Lernende eine Übung wiederholen?**

Ja. Sie steuern die Anzahl der zulässigen Versuche in den Übungseinstellungen. Sie können unbegrenzte Versuche zulassen oder ein bestimmtes Maximum festlegen; dieses Maximum gilt jedoch für alle Nutzer in Ihrem Kurs (Sie können *neue* Versuche freigeben, indem Sie vorherige löschen, aber das wird nicht empfohlen, da es zu ungleichen Chancen zwischen den Nutzern führt und auf Plattformebene für die Prüfung protokolliert wird).

## Technische Probleme

**Ich sehe ein Werkzeug auf meiner Kursstartseite nicht. Wo ist es?**

Einige Werkzeuge können ausgeblendet sein. Als Lehrkraft können Sie ausgeblendete Werkzeuge einblenden, indem Sie nach Werkzeugen mit einem durchgestrichenen Augensymbol suchen. Wenn Sie ein bestimmtes Werkzeug überhaupt nicht finden, hat Ihr Plattformadministrator es möglicherweise auf Plattformebene deaktiviert.

**Meine Lernenden sagen, sie können nicht auf den Kurs zugreifen.**

Prüfen Sie die Sichtbarkeitseinstellungen des Kurses (Kurseinstellungen > Kurssichtbarkeit). Wenn „Nur registriert“ eingestellt ist, müssen Lernende ausdrücklich eingeschrieben sein. Prüfen Sie außerdem, ob sie ein aktives Konto auf der Plattform haben.
