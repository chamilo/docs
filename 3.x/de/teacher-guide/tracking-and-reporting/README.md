# Nachverfolgung und Berichte

Chamilo erfasst die Aktivitäten der Lernenden auf der gesamten Plattform und gibt Ihnen detaillierte Einblicke in den Lernfortschritt Ihrer Lernenden.

* **[Tracking der Lernenden](learner-tracking.md)** — Aktivitäten einzelner Lernender überwachen: Anmeldezeiten, verbrachte Zeit, besuchte Seiten und Werkzeugnutzung
* **[Kursberichte](course-reports.md)** — Aggregierte Daten aller Lernenden eines Kurses anzeigen
* **[Zertifikate und Kompetenzen](certificates-and-skills.md)** — Zertifikate auf Grundlage der Notenbuchergebnisse vergeben und erworbene Kompetenzen validieren

## Auf Berichte zugreifen

Klicken Sie in Ihrem Kurs auf der Kursstartseite auf das Werkzeug **Tracking** <img src="../../.gitbook/assets/icons/mdi-chart-box.svg" alt="Tracking" data-size="line">. Sie können die Berichterstattung auch über den Link **Berichte** in der Seitenleiste aufrufen, um eine kursübergreifende Übersicht zu erhalten.

Lehrkräfte sehen Berichtsdaten für die Kurse, die sie unterrichten. Sitzungstutoren sehen Daten für alle Kurse innerhalb ihrer Sitzung.
