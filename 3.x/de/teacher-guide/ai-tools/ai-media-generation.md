# KI-Mediengenerierung

Beim Bearbeiten eines Dokuments im Werkzeug **Dokumente** ermöglicht die Funktion zur KI-Mediengenerierung, ein **Bild** oder ein **kurzes Video** zur Veranschaulichung eines Absatzes zu erzeugen — direkt aus dem Rich-Text-Editor (WYSIWYG), ohne das Dokument zu verlassen.

## Voraussetzungen

* KI-Hilfen sind auf Plattformebene aktiviert
* Mindestens ein KI-Medienanbieter (Bild oder Video) ist vom Administrator konfiguriert
* Die Funktion ist in Ihrem Kurs zulässig (die Berechtigung auf Kursebene muss aktiviert sein)

## So erzeugen Sie ein Bild oder Video

1. Öffnen Sie ein Dokument im Werkzeug **Dokumente** <img src="../../.gitbook/assets/icons/mdi-bookshelf.svg" alt="Dokumente" data-size="line"> (erstellen Sie ein neues oder bearbeiten Sie ein vorhandenes)
2. Setzen Sie im Rich-Text-Editor den Cursor in den oder in die Nähe des Absatzes, den Sie veranschaulichen möchten
3. Öffnen Sie den Dialog **KI-Medien erzeugen** über die Editor-Symbolleiste
4. Beschreiben Sie, was die Medien zeigen sollen, oder verwenden Sie den ausgewählten Absatz als Prompt
5. Wählen Sie, ob ein **Bild** oder ein **Video** erzeugt werden soll
6. Klicken Sie auf **Erzeugen** und warten Sie, bis die KI das Ergebnis erstellt
7. Sehen Sie sich die erzeugten Medien in der Vorschau an und klicken Sie, wenn Sie zufrieden sind, auf **Einfügen**, um sie in das Dokument einzubetten

## Tipps

* **Formulieren Sie einen klaren Prompt** — Je genauer Ihre Beschreibung, desto relevanter das Ergebnis. Fügen Sie Stilhinweise hinzu (z. B. „Diagramm“, „Illustration“, „realistisches Foto“), sofern der Anbieter diese unterstützt
* **Prüfen Sie stets vor dem Einfügen** — Erzeugte Medien entsprechen möglicherweise nicht vollständig Ihrer Absicht; erzeugen Sie sie erneut oder passen Sie den Prompt an, falls erforderlich
* **Beachten Sie die Dateigrößen** — Erzeugte Bilder und Videos werden auf das Speicherkontingent des Kurses angerechnet. Entfernen Sie ungenutzte Medien aus der Dokumentenbibliothek, wenn der Speicherplatz begrenzt ist
* **Die Videoerzeugung dauert länger** — Die Erzeugung kurzer Videos kann deutlich mehr Zeit in Anspruch nehmen als die Bilderzeugung; planen Sie entsprechend, wenn eine Frist naht
