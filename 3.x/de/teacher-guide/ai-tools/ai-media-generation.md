# KI-Mediengenerierung

Beim Bearbeiten eines Dokuments im Tool **Dokumente** können Sie mit der Funktion zur KI-Mediengenerierung ein **Bild** oder ein **kurzes Video** zur Illustration eines Absatzes erzeugen — direkt aus dem Rich-Text-Editor (WYSIWYG), ohne das Dokument zu verlassen.

## Voraussetzungen

* KI-Helfer sind auf Plattformebene aktiviert
* Mindestens ein KI-Medienanbieter (Bild oder Video) ist vom Administrator konfiguriert
* Die Funktion ist in Ihrem Kurs zugelassen (die kursbezogene Berechtigung muss aktiviert sein)

## So generieren Sie ein Bild oder Video

1. Öffnen Sie ein Dokument im Tool **Dokumente** <img src="/.gitbook/assets/icons/mdi-bookshelf.svg" alt="Dokumente" data-size="line"> (erstellen Sie ein neues oder bearbeiten Sie ein vorhandenes)
2. Platzieren Sie im Rich-Text-Editor den Cursor in oder in der Nähe des Absatzes, den Sie illustrieren möchten
3. Öffnen Sie den Dialog **KI-Medien generieren** über die Editor-Symbolleiste
4. Beschreiben Sie, was das Medium zeigen soll, oder verwenden Sie den ausgewählten Absatz als Prompt
5. Wählen Sie, ob ein **Bild** oder ein **Video** generiert werden soll
6. Klicken Sie auf **Generieren** und warten Sie, bis die KI das Ergebnis erzeugt
7. Prüfen Sie die Vorschau des generierten Mediums und klicken Sie bei Zufriedenheit auf **Einfügen**, um es in das Dokument einzubetten

## Tipps

* **Schreiben Sie einen klaren Prompt** — Je genauer Ihre Beschreibung, desto relevanter das Ergebnis. Fügen Sie Stilhinweise hinzu (z. B. „Diagramm“, „Illustration“, „realistisches Foto“), sofern der Anbieter sie unterstützt
* **Prüfen Sie immer vor dem Einfügen** — Generierte Medien entsprechen möglicherweise nicht genau Ihrer Absicht; generieren Sie neu oder passen Sie den Prompt bei Bedarf an
* **Beachten Sie die Dateigrößen** — Generierte Bilder und Videos zählen zum Speicherkontingent des Kurses. Entfernen Sie ungenutzte Medien aus der Dokumentenbibliothek, wenn der Speicherplatz begrenzt ist
* **Die Videogenerierung dauert länger** — Die Erzeugung kurzer Videos kann deutlich mehr Zeit in Anspruch nehmen als die Bildgenerierung; planen Sie entsprechend, wenn Sie unter Zeitdruck stehen
