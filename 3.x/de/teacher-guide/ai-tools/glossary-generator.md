# Glossarbegriffe-Generator

Der KI-Glossarbegriffe-Generator hilft Ihnen, das Glossar Ihres Kurses schneller aufzubauen, indem er automatisch Begriffsdefinitionen zu einem Thema oder Fachgebiet erzeugt. Sie prüfen jeden vorgeschlagenen Begriff und jede Definition, bevor Sie etwas ins Glossar übernehmen.

## Zugriff auf den Glossarbegriffe-Generator

Der Generator steht im Werkzeug **Glossar** zur Verfügung, sofern:

1. KI-Helfer auf Plattformebene aktiviert sind
2. mindestens ein KI-Textanbieter konfiguriert ist

Öffnen Sie das Werkzeug **Glossar** <img src="/.gitbook/assets/icons/mdi-alphabetical.svg" alt="Glossar" data-size="line"> von der Kursstartseite und suchen Sie in der Symbolleiste nach der Schaltfläche **Mit KI erzeugen**.

## So erzeugen Sie Begriffe

1. Klicken Sie auf **Mit KI erzeugen**
2. Geben Sie ein **Thema oder Fachgebiet** ein — beschreiben Sie den Bereich, für den Sie Begriffe wünschen (z. B. „einführende organische Chemie“ oder „Projektmanagement-Methoden“)
3. Geben Sie optional die **Anzahl der Begriffe** an, die erzeugt werden sollen
4. Wählen Sie einen **KI-Anbieter**, falls mehr als einer konfiguriert ist
5. Klicken Sie auf **Erzeugen**

Die KI erzeugt eine Liste von Begriffen mit Definitionen, die Sie anschließend prüfen können.

## Begriffe prüfen und hinzufügen

Erzeugte Begriffe werden als Vorschläge angezeigt. Bevor Sie sie ins Glossar übernehmen:

* **Genauigkeit prüfen** — Stellen Sie sicher, dass die Definitionen für Ihr Kursniveau und den Kontext korrekt sind
* **Formulierung anpassen** — Passen Sie die Definition an Ihren Lehrstil oder die Konventionen des Kurses an
* **Duplikate entfernen** — Überspringen Sie Begriffe, die bereits im Glossar stehen oder außerhalb des Kursumfangs liegen
* **Auswahl treffen** — Wählen Sie, welche Begriffe importiert werden sollen; Sie müssen nicht alle übernehmen

Wenn Sie zufrieden sind, bestätigen Sie die Auswahl, und die Begriffe werden Ihrem Glossar hinzugefügt.

## Tipps

* **Seien Sie beim Thema konkret** — Breite Themen führen zu allgemeinen Definitionen; ein engeres Thema liefert kursrelevantere Begriffe
* **Immer prüfen** — KI-Definitionen können vereinfacht oder ungenau sein. Prüfen Sie jede Definition, bevor Sie sie für Lernende veröffentlichen
* **Nach dem Import bearbeiten** — Sie können die Definition eines Begriffs später jederzeit in der Glossarverwaltung aktualisieren
* **Mit manuellen Einträgen kombinieren** — Nutzen Sie den Generator für einen Ausgangsbestand und fügen Sie fachspezifische Begriffe anschließend manuell hinzu
