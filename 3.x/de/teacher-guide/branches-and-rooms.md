# Zweige und Räume

Chamilo enthält ein einfaches System für physische Standorte, das auf zwei Konzepten aufbaut: **Zweige** und **Räume**.

Ein **Zweig** steht für einen physischen Standort oder Campus — zum Beispiel eine Hauptniederlassung, ein regionales Schulungszentrum oder ein Universitätsgebäude. Zweige können verschachtelt werden (ein Gebäude kann Abteilungen enthalten, eine Stadt kann Gebäude enthalten). Jeder Zweig kann einen oder mehrere **Räume** enthalten, die einzelne Klassenzimmer oder Laborräume innerhalb dieses Zweigs darstellen.

Diese Funktion befindet sich noch in einem frühen Stadium. Der wichtigste praktische Nutzen besteht derzeit darin, einem Kurs eine Markierung für den physischen Standort zuzuweisen.

## Einen Raum einem Kurs zuweisen

Beim Anlegen eines Kurses erscheint im Formular zur Kurserstellung das Feld **Standardraum**, sofern Ihr Administrator bereits Räume eingerichtet hat. Wählen Sie den Raum, in dem der Kurs stattfindet.

Diese Angabe dient nur der Information — sie beeinflusst weder das Kursverhalten noch die Zugriffskontrolle. Sie dokumentiert lediglich, wo der Kurs physisch stattfindet, was Administratoren bei der Raumplanung und bei der Übersicht über die Raumnutzung über Kurse hinweg helfen kann.

Wenn auf Ihrer Plattform keine Räume konfiguriert wurden, erscheint das Feld nicht.

## Was Administratoren tun können

Die Verwaltung von Zweigen und Räumen liegt vollständig bei den Administratoren. Sie können:

- Zweige in einer Baumhierarchie anlegen und organisieren
- Räumen Zweigen hinzufügen, optional mit Geolokalisierung und IP-Bereichsdaten
- einsehen, welche Kurse welchem Raum zugeordnet sind
- den Belegungskalender eines Raums auf Basis von Anwesenheitseinträgen einsehen

Wenn Sie einen Raum anlegen lassen oder Ihren Kurs in einen anderen Raum verschieben müssen, wenden Sie sich an Ihren Plattformadministrator.
