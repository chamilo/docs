# Kursbeschreibung

Das Werkzeug **Kursbeschreibung** <img src="../../.gitbook/assets/icons/mdi-apple-safari.svg" alt="Kursbeschreibung" data-size="line"> ermöglicht es Ihnen, eine strukturierte, mehrteilige Beschreibung Ihres Kurses zu verfassen — mit Zielen, Methodik, Materialien und mehr. Im Gegensatz zum Freitext-Banner **Kurseinführung** auf Ihrer [Kursstartseite](README.md#the-course-homepage), das nur Ihre eingeschriebenen Lernenden sehen, ist die Kursbeschreibung das, was Interessierte *vor* der Einschreibung im Kurskatalog sehen.

Nach der Einschreibung können Lernende weiterhin darauf zurückgreifen — sofern Sie das Werkzeug für sie sichtbar lassen, ist es ein praktischer Ort, um Informationen wie den allgemeinen Aufbau des Kurses oder die Lehrenden nachzuschlagen, ohne Sie direkt fragen zu müssen. Eingeschriebene Lernende können die von Ihnen verfassten Abschnitte ansehen, aber nicht hinzufügen, bearbeiten oder löschen.

## Zugriff auf das Werkzeug

Öffnen Sie das Werkzeug **Kursbeschreibung** <img src="../../.gitbook/assets/icons/mdi-apple-safari.svg" alt="Kursbeschreibung" data-size="line"> über das Werkzeugraster auf der Kursstartseite.

## Die acht Abschnitte

Eine Kursbeschreibung besteht aus bis zu acht unabhängigen Abschnitten. Jeder ist optional — füllen Sie nur diejenigen aus, die für Ihren Kurs relevant sind:

| Abschnitt | Leitfrage |
|---------|-------------------|
| **Beschreibung** | Was ist das Ziel des Kurses? Gibt es Voraussetzungen? Wie hängt diese Schulung mit anderen Kursen zusammen? |
| **Lernziele** | Welche Ergebnisse sollen vorliegen, wenn die Lernenden den Kurs abgeschlossen haben? Welche Aktivitäten werden im Kurs durchgeführt? |
| **Themen** | Wie verläuft der Kurs? Worauf sollten die Lernenden besonders achten? Gibt es erkennbare Verständnisprobleme in einzelnen Bereichen? Wie viel Zeit sollte man den verschiedenen Bereichen des Kurses widmen? |
| **Methodik** | Welche Methoden und Aktivitäten helfen, die Ziele des Kurses zu erreichen? Wie sähe der Zeitplan aus? |
| **Kursmaterial** | Gibt es ein Kursbuch, eine Sammlung von Aufsätzen, eine Bibliografie, eine Liste von Links im Internet? |
| **Ressourcen** | Berücksichtigen Sie Kurse, Tutorinnen und Tutoren, einen technischen Helpdesk, Lehrende und/oder verfügbare Materialien. |
| **Bewertung** | Wie werden die Lernenden bewertet? Gibt es Strategien, die entwickelt werden sollten, um das Thema zu beherrschen? |
| **Sonstiges** | Alles, was nicht in die oben genannten Kategorien passt. Sie können so viele Abschnitte **Sonstiges** hinzufügen, wie Sie benötigen, jeweils mit einem eigenen Titel. |

## Einen Abschnitt hinzufügen

1. Klicken Sie in der Symbolleiste des Werkzeugs auf das Symbol für den Abschnittstyp, den Sie verfassen möchten
2. Chamilo zeigt ein Feld **Hilfe** mit der Leitfrage für diesen Abschnitt — nutzen Sie sie, um zu entscheiden, was Sie schreiben
3. Schreiben Sie Ihren Inhalt im Rich-Text-Editor (unterstützt Formatierung, Bilder, Links, eingebettete Videos und andere Rich-Inhalte). Wenn Ihre Plattform dies aktiviert hat, können Sie auch mehrere Sprachversionen desselben Abschnitts verfassen, sodass jede lernende Person automatisch nur ihre eigene sieht — siehe [Mehrsprachige Inhalte](../adding-content/multi-language-content.md).
4. Speichern

Jeder hinzugefügte Abschnitt erscheint als eigene Karte im Werkzeug. Verwenden Sie die Symbole **Bearbeiten** <img src="../../.gitbook/assets/icons/mdi-pencil.svg" alt="Bearbeiten" data-size="line"> und **Löschen** <img src="../../.gitbook/assets/icons/mdi-delete.svg" alt="Löschen" data-size="line"> auf einer Karte, um sie später zu aktualisieren oder zu entfernen.

## Verknüpfung mit dem Kurskatalog

Dies ist der Hauptgrund, eine Kursbeschreibung auszufüllen: Sie fließt direkt in den Katalog **Weitere Kurse entdecken** ein, den Besucherinnen und Besucher sowie Interessierte durchsuchen.

* Ein Kurs, bei dem **keine** Beschreibungsabschnitte ausgefüllt sind, erscheint im Katalog als einfache Karte.
* Ein Kurs mit **mindestens einem** Beschreibungsabschnitt wird anklickbar — ein Klick auf Bild, Titel oder Info-Schaltfläche öffnet ein detailliertes Popup, das alle von Ihnen verfassten Abschnitte in der oben gezeigten Reihenfolge auflistet.

So erhalten Interessierte eine echte Grundlage, um über eine Einschreibung zu entscheiden, statt nur eines Titels und einer Miniaturansicht.

> Ob dieses Popup überhaupt verfügbar ist, hängt von einer plattformweiten Einstellung ab. Wenn Ihre Beschreibungen für Interessierte im Katalog nicht erscheinen, bitten Sie Ihre Administration, die Einstellung **Kursbeschreibungen anzeigen** (`show_courses_descriptions_in_catalog`) unter **Administration > Konfigurationseinstellungen > Kurskatalog** zu prüfen.

## Tipps

* **Priorisieren Sie die Abschnitte Beschreibung und Lernziele** — diese lesen die meisten Interessierten zuerst, wenn sie über eine Einschreibung entscheiden.
* **Halten Sie sie aktuell** — aktualisieren Sie Ihre Kursbeschreibung, sobald sich die Kursinhalte wesentlich ändern, damit der Katalog stets widerspiegelt, was die Lernenden tatsächlich erhalten.
* **Setzen Sie Rich-Inhalte sparsam ein** — Bilder und Formatierung verbessern die Lesbarkeit, aber ein langes, überladenes Popup lässt sich schwerer überfliegen als einige klare Absätze.
