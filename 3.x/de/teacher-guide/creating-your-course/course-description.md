# Kursbeschreibung

Das Tool **Kursbeschreibung** <img src="/.gitbook/assets/icons/mdi-apple-safari.svg" alt="Kursbeschreibung" data-size="line"> ermöglicht es Ihnen, eine strukturierte, mehrteilige Beschreibung Ihres Kurses zu verfassen — Ziele, Methodik, Materialien und mehr. Im Gegensatz zum Freitext-Banner **Kurseinführung** auf Ihrer [Kursstartseite](README.md#the-course-homepage), das nur Ihre eingeschriebenen Lernenden sehen, ist die Kursbeschreibung das, was Interessierte *vor* der Einschreibung im Kurskatalog sehen.

Nach der Einschreibung können Lernende weiterhin darauf zugreifen — sofern Sie das Tool für sie sichtbar lassen, ist es ein praktischer Ort, um organisatorische Informationen wie den allgemeinen Kursaufbau oder die Lehrenden nachzuschlagen, ohne Sie direkt fragen zu müssen. Eingeschriebene Lernende können die von Ihnen verfassten Abschnitte einsehen, sie aber nicht hinzufügen, bearbeiten oder löschen.

## Zugriff auf das Tool

Öffnen Sie das Tool **Kursbeschreibung** <img src="/.gitbook/assets/icons/mdi-apple-safari.svg" alt="Kursbeschreibung" data-size="line"> über das Tool-Raster auf der Kursstartseite.

## Die acht Abschnitte

Eine Kursbeschreibung besteht aus bis zu acht unabhängigen Abschnitten. Jeder ist optional — füllen Sie nur die für Ihren Kurs relevanten aus:

| Abschnitt | Leitfrage |
|---------|-------------------|
| **Beschreibung** | Was ist das Ziel des Kurses? Gibt es Voraussetzungen? Wie ist diese Schulung mit anderen Kursen verknüpft? |
| **Lernziele** | Welche Ergebnisse sollen vorliegen, wenn der Lernende den Kurs abgeschlossen hat? Welche Aktivitäten finden während des Kurses statt? |
| **Themen** | Wie schreitet der Kurs voran? Worauf sollte der Lernende besonders achten? Gibt es erkennbare Verständnisschwierigkeiten in einzelnen Bereichen? Wie viel Zeit sollte man den verschiedenen Bereichen des Kurses widmen? |
| **Methodik** | Welche Methoden und Aktivitäten helfen, die Lernziele des Kurses zu erreichen? Wie sähe der Zeitplan aus? |
| **Kursmaterial** | Gibt es ein Lehrbuch, eine Sammlung von Aufsätzen, eine Bibliografie, eine Liste von Internetlinks? |
| **Ressourcen** | Berücksichtigen Sie die Kurse, Tutoren, einen technischen Helpdesk, Lehrende und/oder verfügbare Materialien. |
| **Bewertung** | Wie werden Lernende bewertet? Gibt es Strategien, die entwickelt werden müssen, um das Thema zu beherrschen? |
| **Sonstiges** | Alles, was nicht in die obigen Kategorien passt. Sie können so viele **Sonstiges**-Abschnitte hinzufügen, wie Sie benötigen, jeweils mit eigenem benutzerdefinierten Titel. |

## Einen Abschnitt hinzufügen

1. Klicken Sie in der Symbolleiste des Tools auf das Symbol für den Abschnittstyp, den Sie verfassen möchten
2. Chamilo zeigt ein **Hilfe**-Feld mit der Leitfrage für diesen Abschnitt — nutzen Sie es, um zu entscheiden, was Sie schreiben
3. Verfassen Sie Ihren Inhalt im Rich-Text-Editor (unterstützt Formatierung, Bilder, Links, eingebettetes Video und andere Rich-Inhalte). Wenn Ihre Plattform dies aktiviert hat, können Sie auch mehrere Sprachversionen desselben Abschnitts schreiben und jeder Lernende sieht automatisch nur die eigene — siehe [Mehrsprachige Inhalte](../adding-content/multi-language-content.md).
4. Speichern

Jeder hinzugefügte Abschnitt erscheint als eigene Karte im Tool. Nutzen Sie die Symbole **Bearbeiten** <img src="/.gitbook/assets/icons/mdi-pencil.svg" alt="Bearbeiten" data-size="line"> und **Löschen** <img src="/.gitbook/assets/icons/mdi-delete.svg" alt="Löschen" data-size="line"> auf einer Karte, um sie später zu aktualisieren oder zu entfernen.

## Verknüpfung mit dem Kurskatalog

Das ist der Hauptgrund, eine Kursbeschreibung auszufüllen: Sie fließt direkt in den Katalog **Weitere Kurse entdecken** ein, den Besucher und Interessierte durchsuchen.

* Ein Kurs **ohne** ausgefüllte Beschreibungsabschnitte erscheint als einfache Karte im Katalog.
* Ein Kurs mit **mindestens einem** Beschreibungsabschnitt wird anklickbar — ein Klick auf Bild, Titel oder Info-Schaltfläche öffnet ein detailliertes Popup mit allen von Ihnen verfassten Abschnitten, in der oben gezeigten Reihenfolge.

So erhalten Interessierte eine echte Grundlage für die Entscheidung zur Einschreibung, statt nur Titel und Vorschaubild.

> Ob dieses Popup überhaupt verfügbar ist, hängt von einer plattformweiten Einstellung ab. Wenn Ihre Beschreibungen für Interessierte im Katalog nicht erscheinen, bitten Sie Ihren Administrator, die Einstellung **Kursbeschreibungen anzeigen** (`show_courses_descriptions_in_catalog`) unter **Administration > Konfigurationseinstellungen > Kurskatalog** zu prüfen.

## Tipps

* **Priorisieren Sie die Abschnitte Beschreibung und Lernziele** — das lesen die meisten Interessierten zuerst, wenn sie über eine Einschreibung entscheiden.
* **Halten Sie sie aktuell** — aktualisieren Sie Ihre Kursbeschreibung, sobald sich der Kursinhalt wesentlich ändert, damit der Katalog stets widerspiegelt, was Lernende tatsächlich erhalten.
* **Setzen Sie Rich-Content sparsam ein** — Bilder und Formatierung verbessern die Lesbarkeit, aber ein langes, überladenes Popup ist schwerer zu überfliegen als einige klare Absätze.
