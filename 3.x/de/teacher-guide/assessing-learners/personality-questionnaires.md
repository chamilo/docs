# Persönlichkeitsfragebögen

Chamilo 3.1 enthält Fragebögen im Persönlichkeitsstil im modernen Tool **Umfragen**. Diese Fragebögen erzeugen ein **Präferenzprofil**, keine benotete Übung und keine klinische psychologische Beurteilung.

## Einen Fragebogen erstellen

1. Öffnen Sie das Tool Umfragen und erstellen Sie eine neue Umfrage.
2. Wählen Sie in der Konfiguration den Umfragetyp **Persönlichkeit**.
3. Öffnen Sie **Fragen bearbeiten** oder den Frageneditor der Umfrage.
4. Definieren Sie **Persönlichkeitskategorien**, bevor Sie Persönlichkeitsfragen hinzufügen. Jede Antwortoption muss einer Kategorie zugeordnet sein.
5. Fügen Sie Fragen hinzu, konfigurieren Sie deren Antworten und Kategoriezuordnungen und speichern Sie Ihre Änderungen.
6. Sehen Sie sich die Lernerfahrung in der Vorschau an, bevor Sie die Umfrage verteilen.

Es stehen vier Typen von Persönlichkeitsfragen zur Verfügung:

| Typ | Wie Lernende antworten |
| --- | --- |
| Persönlichkeitsauswahl | Wählen Sie unter kategoriezugeordneten Optionen |
| Persönlichkeitszustimmung | Geben Sie die Zustimmung zu den vorgelegten Aussagen an |
| Persönlichkeitsskala | Bewerten Sie Aussagen auf einer fünfstufigen Skala |
| Persönlichkeitsreihenfolge | Ordnen Sie Optionen von der am meisten bis zur am wenigsten bevorzugten |

Die Konfiguration umfasst die Antwortvalidierung und die kategoriebasierte Präferenzbewertung. Prüfen Sie die Optionen und Zuordnungen jeder Frage sorgfältig: Eine Option, die der falschen Kategorie zugeordnet ist, verändert das resultierende Profil.

## Ergebnisse anzeigen

Nach Abschluss des Fragebogens kann ein Lernender **Ihr Persönlichkeitsprofil** sehen, wenn die Umfrage Profildaten zurückgibt. Die Berichtsseite der Lehrkraft für Umfragen kann **Persönlichkeitsprofil — alle Lernenden** anzeigen. Die Ergebnisse werden mit Balken-/Radardiagrammen und Kategoriepunktzahlen dargestellt. Beim Duplizieren einer Umfrage bleibt die Konfiguration des Persönlichkeitsfragebogens erhalten.

## Notenbuch und Interpretation

Persönlichkeitsfragebögen können nicht über das Notenbuch wie gewöhnliche Bewertungen benotet werden. Erklären Sie den Lernenden, dass die Ergebnisse die Antworten auf die konfigurierten Kategorien widerspiegeln und keine Diagnose, keinen Bestanden-/Nicht-bestanden-Status und keinen validierten Persönlichkeitstest darstellen. Prüfen Sie die Einstellungen zu Datenschutz und Sichtbarkeit der Berichte, bevor Sie persönliche Antworten erfassen.
