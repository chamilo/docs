# Zusätzliche Werkzeuge

Neben den zentralen Werkzeugen für Inhalte, Bewertung und Zusammenarbeit bietet Chamilo mehrere zusätzliche Werkzeuge, mit denen Sie Ihren Kurs erweitern können.

* **[Agenda](agenda.md)** — Termine, Fristen und Erinnerungen für Ihren Kurs planen
* **[Notizbuch](notebook.md)** — Ein persönliches Notizwerkzeug für Lernende
* **[Dropbox](dropbox.md)** — Ein einfaches Werkzeug zum Dateiaustausch zwischen Ihnen und Ihren Lernenden
* **[Portfolio](portfolio.md)** — Lernende ein Portfolio ihrer Arbeiten erstellen und präsentieren lassen
* **[Kursfortschritt](course-progress.md)** — Thematische Abschnitte definieren und die Kursdurchführung nachverfolgen
