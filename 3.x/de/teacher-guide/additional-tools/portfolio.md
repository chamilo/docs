# Portfolio

Das Portfolio-Werkzeug ermöglicht es Lernenden, ihre Arbeiten während des Kurses zu sammeln und zu präsentieren. Es dient als digitales Portfolio, in dem Lernende ihre besten Arbeiten, Reflexionen und Leistungen zusammenstellen können.

## Funktionsweise von Portfolios

Jede lernende Person verfügt über ein persönliches Portfolio innerhalb des Kurses, in dem sie Folgendes tun kann:

* **Elemente hinzufügen** — Texteinträge mit dem Rich-Text-Editor verfassen und einem Element eine oder mehrere Dateien anhängen
* **Inhalte organisieren** — Elemente mit Tags versehen, damit sie nach Thema gefiltert werden können
* **Gezielt teilen** — Die Sichtbarkeit jedes Elements festlegen: verborgen, für den Kurs sichtbar, verborgen außer für die Lehrkraft oder – wenn die erweiterte Freigabe aktiviert ist – mit ausgewählten Nutzern geteilt

## Als Lehrkraft

Sie können Portfolios nutzen für:

* **Reflexives Lernen** — Lernende auffordern, ein Portfolio mit Reflexionen zu ihrem Lernweg zu führen
* **Kompetenznachweis** — Lernende Belege für Fähigkeiten und Wissen sammeln lassen
* **Bewertung** — Portfolio-Inhalte als Teil Ihrer Evaluation prüfen

Um das Portfolio einer lernenden Person anzuzeigen, öffnen Sie das Portfolio-Werkzeug und filtern Sie die Elementliste nach Nutzer.

Wenn der Kurs dies zulässt, können Sie Portfolio-Elemente und einzelne Kommentare bewerten – diese Bewertungen können anschließend in das Notenbuch einfließen. Sie können außerdem Elemente **hervorheben**, auf die Sie aufmerksam machen möchten, und Elemente oder Kommentare als **Vorlagen** markieren, damit Sie (oder Lernende) sie als Ausgangspunkt für neue Einträge wiederverwenden können. Portfolios können als **PDF** oder **ZIP** exportiert werden.

## Tipps

* **Erwartungen definieren** — Teilen Sie den Lernenden mit, welche Arten von Elementen sie aufnehmen und wie sie ihr Portfolio organisieren sollen
* **Regelmäßig prüfen** — Schauen Sie Portfolios regelmäßig durch, nicht nur am Ende des Kurses
* **Mit Kompetenzen kombinieren** — Nutzen Sie Portfolios zusammen mit dem Kompetenzen-/Zertifikatsystem, um eine umfassende Kompetenzdokumentation zu erstellen
