# Dropbox

Die Dropbox ist ein Werkzeug zum Dateiaustausch, mit dem Sie und Ihre Lernenden innerhalb des Kurses Dateien miteinander teilen können.

> Zum Einsammeln bewerteter studentischer Arbeiten ist das Werkzeug [Aufgaben](../assessing-learners/assignments.md) in der Regel besser geeignet, da es Funktionen zur Bewertung und zum Feedback umfasst. Die Dropbox eignet sich besser für den informellen Dateiaustausch.

## Eine Datei senden

1. Öffnen Sie das Werkzeug **Dropbox** auf der Kursstartseite
2. Klicken Sie auf **Neue Datei teilen**
3. Wählen Sie die hochzuladende Datei aus
4. Wählen Sie die **Empfänger** — einen oder mehrere eingeschriebene Benutzer oder Kursgruppen
5. Senden

## Dateien empfangen

Wenn Ihnen jemand eine Datei sendet, erscheint sie in Ihrem Dropbox-Posteingang. Sie können:

* Die Datei **herunterladen**
* Der Datei einen **Kommentar hinzufügen** (nachdem sie empfangen wurde)
* Die Datei in eine Ihrer Kategorien **verschieben**
* Die Datei aus Ihrem Posteingang **löschen**

## Dateien organisieren

Sowohl gesendete als auch empfangene Dateien können in benutzerdefinierten **Kategorien** (Ordnern) organisiert werden. Verwenden Sie die Kategorie-Steuerelemente in der Dropbox-Symbolleiste, um eine Kategorie zu erstellen, und verschieben Sie anschließend Dateien dorthin. Wenn die Plattformeinstellung „Überschreiben zulassen“ aktiviert ist, können Sie durch erneutes Senden einer Datei mit demselben Namen die vorherige Version überschreiben.

Sie können ausgewählte Dateien auch gesammelt als ZIP herunterladen.

## Als Lehrkraft

* Sie können Dateien an einzelne Lernende, Gruppen von Lernenden oder alle eingeschriebenen Benutzer senden
* Sie können Dateien anzeigen, die Lernende an Sie gesendet haben
* Dieses Werkzeug eignet sich zum Teilen ergänzender Materialien, zum Bereitstellen individueller Feedback-Dokumente oder zum Empfangen informeller Einreichungen

## Speicherlimits der Dropbox

Ein Administrator kann ein gesamtes Dropbox-Speicherkontingent pro Benutzer über alle Kurse hinweg sowie ein separates Kontingent für jeden Kurs, einschließlich Sitzungen, festlegen. Wenn eines der konfigurierten Kontingente überschritten würde, wird der Upload abgelehnt. Empfänger verursachen keine zweite Kontingentbelastung, nur weil eine Datei mit ihnen geteilt wurde.

Beide Limits sind standardmäßig auf `0` MB gesetzt, was unbegrenzt bedeutet. Die Dropbox-Limits sind unabhängig vom Kurskontingent für Dokumente. Siehe [Dropbox-Einstellungen](../../admin-guide/platform-settings/dropbox-settings.md) und [Speicherkontingente PR #9358](https://github.com/chamilo/chamilo-lms/pull/9358).
