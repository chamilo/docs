# Dropbox

Die Dropbox ist ein Dateiaustausch-Werkzeug, mit dem Sie und Ihre Lernenden innerhalb des Kurses Dateien miteinander teilen können.

> Zum Einsammeln benoteter Studierendenarbeiten ist das Werkzeug [Aufgaben](../assessing-learners/assignments.md) in der Regel besser geeignet, da es Bewertungs- und Feedback-Funktionen umfasst. Die Dropbox eignet sich besser für den informellen Dateiaustausch.

## Datei senden

1. Öffnen Sie das Werkzeug **Dropbox** auf der Kursstartseite
2. Klicken Sie auf **Neue Datei teilen**
3. Wählen Sie die hochzuladende Datei aus
4. Wählen Sie den bzw. die **Empfänger** — einen oder mehrere eingeschriebene Benutzer oder Kursgruppen
5. Senden

## Dateien empfangen

Wenn Ihnen jemand eine Datei sendet, erscheint sie in Ihrem Dropbox-Posteingang. Sie können:

* die Datei **herunterladen**
* der Datei einen **Kommentar hinzufügen** (nachdem sie empfangen wurde)
* die Datei in eine Ihrer Kategorien **verschieben**
* die Datei aus Ihrem Posteingang **löschen**

## Dateien organisieren

Sowohl gesendete als auch empfangene Dateien können in benutzerdefinierte **Kategorien** (Ordner) organisiert werden. Verwenden Sie die Kategorie-Steuerelemente in der Dropbox-Werkzeugleiste, um eine Kategorie zu erstellen, und verschieben Sie anschließend Dateien dorthin. Wenn die Plattformeinstellung "allow overwrite" aktiviert ist, können Sie durch erneutes Senden einer Datei mit demselben Namen die vorherige Version überschreiben.

Sie können ausgewählte Dateien auch gesammelt als ZIP herunterladen.

## Als Lehrkraft

* Sie können Dateien an einzelne Lernende, Gruppen von Lernenden oder alle eingeschriebenen Benutzer senden
* Sie können Dateien einsehen, die Ihnen von Lernenden gesendet wurden
* Dieses Werkzeug eignet sich zum Teilen ergänzender Materialien, zum Bereitstellen individueller Feedback-Dokumente oder zum Empfangen informeller Einreichungen
