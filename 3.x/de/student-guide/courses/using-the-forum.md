# Das Forum nutzen

Das Tool **Forum** beherbergt strukturierte, hierarchische Diskussionen innerhalb eines Kurses — ein guter Ort für Fragen und Gespräche, die organisiert und durchsuchbar bleiben sollen, im Gegensatz zum Echtzeit-[Chat](using-the-chat-tool.md).

## Orientierung

Öffnen Sie das Tool **Forum** <img src="../../.gitbook/assets/icons/mdi-comment-quote.svg" alt="Forum" data-size="line"> von der Kursstartseite aus. Foren sind in drei Ebenen organisiert:

1. **Kategorien** — grobe Gruppierungen (z. B. „Allgemeine Diskussionen“, „Fragen zu Modul 1“)
2. **Foren** — einzelne Diskussionsbereiche innerhalb einer Kategorie
3. **Themen (Threads)** — einzelne Gespräche innerhalb eines Forums, jeweils mit einer eigenen Kette von Antworten

## Beiträge verfassen

Öffnen Sie ein Forum und klicken Sie, um ein **neues Thema** zu starten, oder öffnen Sie ein bestehendes Thema, um zu **antworten**. Je nachdem, wie Ihre Lehrkraft das jeweilige Forum eingerichtet hat:

* Sie dürfen neue Themen selbst starten oder nicht — manche Foren sind nur für Antworten vorgesehen
* Sie können Ihre eigenen Beiträge nach dem Absenden bearbeiten oder nicht
* Beiträge müssen möglicherweise von einer Lehrkraft freigegeben werden, bevor sie sichtbar werden (ein **moderiertes** Forum) — in diesem Fall erscheint Ihr Beitrag nicht sofort; das ist zu erwarten
* In vollständig öffentlich zugänglichen Kursen kann ein Forum **anonymes Posten** erlauben — andernfalls werden Ihre Beiträge stets Ihnen zugeordnet

Threads können **flach**, **hierarchisch** oder **verschachtelt** angezeigt werden, abhängig von der Anzeigeeinstellung des Forums — das ändert nur die Darstellung der Antworten, nicht Ihre Möglichkeiten.

## Benachrichtigungen erhalten

Suchen Sie nach einem Schalter **Mich benachrichtigen** an einem Forum oder an einem einzelnen Thema, um E-Mail-Benachrichtigungen zu abonnieren, wenn jemand dort schreibt. Dies ist ein persönliches Abonnement — das Einschalten benachrichtigt niemanden sonst, und Sie können es jederzeit wieder ausschalten.

## Gruppen- und bewertete Foren

Ein Forum kann an eine bestimmte Kurs-**Gruppe** gebunden sein statt an den gesamten Kurs — in diesem Fall können nur die Mitglieder dieser Gruppe (oder, je nach Konfiguration, jedes Kursmitglied) darin lesen und schreiben. Manche Threads sind außerdem **benotet**: Ihre Lehrkraft legt eine Höchstpunktzahl für die Teilnahme an diesem Thread fest, die in Ihre Kursnote einfließen kann. Eine kleine Zahl von Threads kann sogar **peer-bewertet** sein, wobei Ihre Punktzahl teilweise von Bewertungen mindestens zweier anderer Lernender abhängt.

## Tipps

* **Nutzen Sie das Forum für alles, was bewahrt werden soll** — im Gegensatz zum Chat bleiben Forumsbeiträge nach Thema organisiert und sind später leicht wiederzufinden.
* **Abonnieren Sie Threads, die Ihnen wichtig sind**, statt manuell nachzuschauen.
* **Ein fehlender Button „neues Thema“** bedeutet in der Regel, dass das Forum nur für Antworten vorgesehen ist, nicht dass etwas defekt ist.
