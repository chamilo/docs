# Erste Schritte

Dieser Abschnitt hilft Ihnen, sich als Lernende bzw. Lernender in Chamilo 3.0 zurechtzufinden. Sie erfahren, wie Sie ein Konto erstellen (falls erforderlich), sich anmelden und sich in der Hauptbenutzeroberfläche orientieren.

## Anmeldung

Um auf Chamilo zuzugreifen, öffnen Sie Ihren Browser und rufen Sie die von Ihrer Einrichtung bereitgestellte URL auf (zum Beispiel `https://chamilo.yourschool.edu`). Geben Sie auf der Anmeldeseite Ihren Benutzernamen und Ihr Passwort ein und klicken Sie auf **Anmelden**.

Wenn Ihre Einrichtung eine externe Authentifizierung verwendet (etwa Azure, Keycloak oder ein universitäres Single-Sign-on-System), können unter dem Standard-Anmeldeformular zusätzliche Anmeldeschaltflächen erscheinen. Klicken Sie auf die passende Schaltfläche, um sich über den Identitätsanbieter Ihrer Einrichtung zu authentifizieren.

Wenn Sie noch kein Konto haben, siehe [Konto erstellen](creating-an-account.md).

> Wenn Sie Ihr Passwort vergessen haben, klicken Sie auf der Anmeldeseite auf den Link **Passwort vergessen?**. Den vollständigen Ablauf finden Sie unter [Passwort zurücksetzen](../account-and-security/resetting-your-password.md).

## Erster Eindruck

Nach der Anmeldung sehen Sie die Chamilo-Startseite, die in drei Hauptbereiche gegliedert ist: eine obere Leiste, eine Seitenleiste und einen Hauptinhaltsbereich. Diese werden ausführlich in [Die Benutzeroberfläche verstehen](understanding-the-interface.md) beschrieben.

Klicken Sie in der Seitenleiste auf **Meine Kurse**, um alle Kurse zu sehen, in denen Sie eingeschrieben sind. Jeder Kurs erscheint als Karte mit Bild, Titel und Schnellzugriffsaktionen.

Wenn Ihre Einrichtung **Sessions** (zeitlich begrenzte Ausbildungsperioden) verwendet, sehen Sie in der Seitenleiste außerdem den Link **Meine Sessions**, gegliedert in aktuelle, vergangene und bevorstehende Sessions. Eine Session ist eine geplante Ausgabe oder Kohorte eines oder mehrerer Kurse — dieselben Kursinhalte, die einer bestimmten Gruppe von Lernenden über einen bestimmten Zeitraum vermittelt werden.
