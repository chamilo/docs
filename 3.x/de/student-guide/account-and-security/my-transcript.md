# Mein Transcript

Wenn Ihre Plattform akademische Transcripts aktiviert hat, können Sie eine Übersicht Ihrer abgeschlossenen, zertifizierten Kurse einsehen und einen inoffiziellen Transcript herunterladen. Ihre Einrichtung kann außerdem unterzeichnete offizielle Transcripts ausstellen.

## Ihren Transcript öffnen

1. Melden Sie sich an und öffnen Sie **Mein Transcript** in der oberen Navigation (sofern diese Option verfügbar ist).
2. Oder rufen Sie `/transcript` in Ihrem Chamilo-Portal auf, während Sie angemeldet sind.
3. Prüfen Sie Ihre abgeschlossenen Kurse, Kurscodes, Noten, Daten, Stunden, die Gesamtnote und den GPA.
4. Wählen Sie **Inoffiziellen Transcript herunterladen**, um ein PDF der aktuellen Übersicht zu speichern.

Die Übersicht wird aus berechtigten Zertifikaten erstellt, die von der Stammbewertung (Gradebook) der Kurse und Sitzungen erzeugt werden, in denen Sie noch eingeschrieben sind. Ein Kurs kann fehlen, wenn er kein qualifizierendes Zertifikat erzeugt hat. Wenn keine Kurse die Voraussetzungen erfüllen, zeigt Chamilo **Noch kein abgeschlossener Kurs.** an.

Die Notenbuchstaben und der Notendurchschnitt hängen von der von Ihrer Einrichtung konfigurierten Notenskala ab. Der GPA wird als ungewichteter Durchschnitt der Notenpunkte der aufgeführten Kurse berechnet, sofern Ihr Administrator nicht ändert, wie die zugrunde liegenden Kurse und Noten erfasst werden.

## Offizielle Transcripts

Unter **Offizielle Transcripts** finden Sie unterzeichnete Versionen, die von autorisiertem Personal für Sie ausgestellt wurden, sofern solche vorhanden sind. Jede Version erfasst das Ausstellungsdatum und den Aussteller. Verwenden Sie **Herunterladen** für das PDF und **Überprüfen**, um die digitale Signatur auf der Verifizierungsseite zu prüfen.

Eine offizielle Version ist eine Momentaufnahme Ihrer Übersicht zum Zeitpunkt der Ausstellung. Sie wird **nicht** automatisch aktualisiert, wenn sich spätere Noten oder Kurse ändern; Ihre Einrichtung kann eine neuere Version ausstellen. Autorisiertes Personal kann eine ältere Version widerrufen; die öffentliche Verifizierungsseite zeigt dann diesen Widerruf an.

Sie können offizielle Transcripts nicht selbst ausstellen oder widerrufen. Wenden Sie sich an Ihre Einrichtung, wenn Sie einen neuen oder korrigierten unterzeichneten Transcript benötigen. Teilen Sie öffentliche Verifizierungslinks mit Bedacht: Personen mit dem Link können möglicherweise Details eines gültigen unterzeichneten Transcripts einsehen.

Wenn **Mein Transcript** fehlt, ist diese Funktion auf Ihrem Portal möglicherweise nicht aktiviert. Zur administrativen Einrichtung siehe [Akademische Transcripts](../../admin-guide/users/academic-transcripts.md).
