# Konto und Sicherheit

Ihr Chamilo-Konto gewährt Zugriff auf Ihre Kurse, Ihre Noten und Ihre persönlichen Daten — es lohnt sich, es sicher zu halten. Dieser Abschnitt behandelt die Kontoschutzfunktionen, denen Sie als Lernende oder Lernender begegnen können.

* **[Passwort zurücksetzen](resetting-your-password.md)** — Was zu tun ist, wenn Sie Ihr Passwort vergessen haben oder es ändern möchten
* **[Zwei-Faktor-Authentifizierung](two-factor-authentication.md)** — Fügen Sie Ihrem Konto eine zweite Schutzebene hinzu, sofern Ihr Administrator sie aktiviert hat
* **[CAPTCHA](captcha.md)** — Warum Sie auf den Formularen für Anmeldung, Registrierung oder vergessenes Passwort möglicherweise nachweisen müssen, dass Sie ein Mensch sind
* **[Mein Transcript](my-transcript.md)** — Abgeschlossene zertifizierte Kurse anzeigen und inoffizielle oder ausgestellte offizielle akademische Transcripts herunterladen

Nicht jede hier beschriebene Funktion ist auf Ihrer Plattform zwangsläufig aktiv — Administratoren können jede davon ein- oder ausschalten. Wenn etwas, das in diesem Abschnitt beschrieben wird, bei Ihnen nicht erscheint, wurde es wahrscheinlich nicht aktiviert.
