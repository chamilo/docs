# Konto und Sicherheit

Ihr Chamilo-Konto gewährt Zugriff auf Ihre Kurse, Ihre Noten und Ihre personenbezogenen Daten — es lohnt sich, es zu schützen. Dieser Abschnitt behandelt die Funktionen zum Kontoschutz, auf die Sie als Lernende bzw. Lernender stoßen können.

* **[Passwort zurücksetzen](resetting-your-password.md)** — Was zu tun ist, wenn Sie Ihr Passwort vergessen haben oder es ändern möchten
* **[Zwei-Faktor-Authentifizierung](two-factor-authentication.md)** — Fügen Sie Ihrem Konto eine zweite Schutzschicht hinzu, sofern Ihr Administrator sie aktiviert hat
* **[CAPTCHA](captcha.md)** — Warum Sie auf den Formularen für Anmeldung, Registrierung oder vergessenes Passwort aufgefordert werden können, nachzuweisen, dass Sie ein Mensch sind

Nicht jede hier beschriebene Funktion ist zwingend auf Ihrer Plattform aktiv — Administratoren können jede davon ein- oder ausschalten. Wenn etwas in diesem Abschnitt Beschriebenes bei Ihnen nicht erscheint, wurde es wahrscheinlich nicht aktiviert.
