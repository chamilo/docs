# Glossar

Wichtige Begriffe, die in diesem Leitfaden verwendet werden.

| Begriff | Definition |
|------|-----------|
| **Assessment** | Siehe **Notenbuch** weiter unten |
| **Aufgabe** | Eine Tätigkeit, bei der Sie Dateien oder Text einreichen, damit Ihre Lehrkraft sie prüft und bewertet. Auch bekannt als „Studentenveröffentlichung“ oder „Arbeit“. |
| **CAPTCHA** | Eine Herausforderung (typischerweise das Abtippen verzerrter Buchstaben aus einem Bild), mit der bestätigt wird, dass Sie eine echte Person sind; erscheint auf einigen Anmelde-, Registrierungs- und Passwort-vergessen-Formularen. |
| **Katalog** | Die öffentliche Auflistung von Kursen (und Sessions), die Sie durchsuchen und in manchen Fällen selbst belegen können. Erreichbar über **Weitere Kurse entdecken**. |
| **Zertifikat** | Ein Dokument, das automatisch erzeugt wird, wenn Sie die im Notenbuch eines Kurses festgelegte Mindestpunktzahl erreichen. |
| **Kurs** | Ein Behälter für Lerninhalte und Werkzeuge. Ein Kurs kann Dokumente, Übungen, Foren, Lernpfade und mehr enthalten. |
| **Einschreibung** | Die Registrierung in einem Kurs oder einer Session, die Ihnen Zugang zu dessen Inhalten gibt. Auch bekannt als „Abonnement“. |
| **Übung** | Ein Quiz oder Test mit einer oder mehreren Fragen. In manchen Kontexten auch als „Test“ bezeichnet. |
| **Forum** | Ein Diskussionswerkzeug mit verschachtelten Unterhaltungen, organisiert in Kategorien und Themen. |
| **Notenbuch** | Ein Werkzeug, das Ihre Punkte aus Übungen, Aufgaben und anderen Aktivitäten zu einer einheitlichen Note zusammenfasst. |
| **Einladung** | Ein einmaliger Link, den eine Lehrkraft an Ihre E-Mail-Adresse sendet und mit dem Sie sich registrieren und automatisch in einen Kurs eingeschrieben werden, auch wenn die allgemeine Registrierung geschlossen ist. |
| **Lernpfad** | Eine strukturierte Abfolge von Lernaktivitäten (Dokumente, Übungen, Links), die Sie in einer festgelegten Reihenfolge durchlaufen, manchmal mit Voraussetzungen. |
| **Selbstregistrierung** | Die Möglichkeit, über ein öffentliches Registrierungsformular ein eigenes Konto anzulegen, sofern dies vom Plattformadministrator aktiviert ist. |
| **Session** | Eine zeitlich begrenzte Ausgabe eines oder mehrerer Kurse, die einer bestimmten Gruppe von Lernenden zugeordnet ist, etwa einem Semester oder einer Kohorte. |
| **Kompetenz** | Eine mit Notenbuch-Leistungen verknüpfte Fähigkeit. Der Erwerb eines Zertifikats kann zugehörige Kompetenzen bestätigen. |
| **Zwei-Faktor-Authentifizierung (2FA)** | Ein zusätzlicher Anmeldeschritt mit einem zeitbasierten Code aus einer Authenticator-App, zusätzlich zu Ihrem Passwort. |
| **Sichtbarkeit** | Eine Einstellung, die steuert, ob ein Werkzeug, Dokument oder eine Aktivität für Lernende angezeigt wird. Lehrkräfte können ausgeblendete Elemente stets sehen. |
