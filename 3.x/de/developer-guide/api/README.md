# API

Chamilo 3.0 stellt eine REST-API bereit, die auf **API Platform 4** basiert. Die API ermöglicht den programmatischen Zugriff auf Plattformressourcen und ist dieselbe API, die vom Vue-Frontend verwendet wird.

* **[Authentifizierung](authentication.md)** — JWT-Token-basierte Authentifizierung
* **[Endpunktreferenz](endpoints-reference.md)** — Überblick über verfügbare API-Ressourcen
* **[Benutzerdefinierte Aktionen](custom-actions.md)** — Spezialisierte Endpunkte jenseits des standardmäßigen CRUD
* **[Einschreibung von Sitzungsteilnehmenden](session-students.md)** — Bestimmte Sitzungsteilnehmende mit Administratorrechten hinzufügen/entfernen
* **[Klassenabonnements](class-subscriptions.md)** — Klassenmitgliedschaft sowie verknüpfte Sitzungen/Kurse lesen/ersetzen
* **[Kursverwaltung](course-administration.md)** — Kursmetadaten aktualisieren und Kurse als Administrator löschen
* **[Webhooks](webhooks.md)** — Ereignisgesteuerte Benachrichtigungen an externe Systeme
