# API

Chamilo 3.0 stellt eine REST-API bereit, die auf **API Platform 4** aufbaut. Die API ermöglicht den programmatischen Zugriff auf Plattformressourcen und ist dieselbe API, die vom Vue-Frontend verwendet wird.

* **[Authentifizierung](authentication.md)** — JWT-tokenbasierte Authentifizierung
* **[Endpunkt-Referenz](endpoints-reference.md)** — Überblick über verfügbare API-Ressourcen
* **[Benutzerdefinierte Aktionen](custom-actions.md)** — Spezialisierte Endpunkte über das Standard-CRUD hinaus
* **[Webhooks](webhooks.md)** — Ereignisgesteuerte Benachrichtigungen an externe Systeme
