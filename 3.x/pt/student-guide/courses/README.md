# Cursos

Depois de ter uma conta, o passo seguinte é entrar num curso e orientar-se nele.

* **[Inscrever-se num Curso](subscribing-to-a-course.md)** — As diferentes formas de ficar inscrito num curso
* **[Orientar-se num Curso](course-tools-overview.md)** — O que cada ferramenta na página inicial do curso significa para si enquanto formando
* **[Seguir um Percurso de Aprendizagem](following-a-learning-path.md)** — Percorrer uma sequência guiada de atividades
* **[Realizar Testes](taking-tests.md)** — O que esperar quando o seu professor atribui um questionário ou exame
* **[Submeter um Trabalho](submitting-an-assignment.md)** — Entregar ficheiros ou texto para avaliação
* **[Utilizar o Fórum](using-the-forum.md)** — Publicar e responder em discussões em tópicos do curso
* **[Utilizar a Ferramenta de Chat](using-the-chat-tool.md)** — Mensagens em tempo real dentro de um curso
* **[Chatbot de Tutor de IA](ai-tutor.md)** — Obter ajuda de um assistente de IA, se a sua plataforma o tiver ativado

Estas páginas pressupõem que já tem uma conta Chamilo. Se não tiver, consulte [Criar uma Conta](../getting-started/creating-an-account.md).
