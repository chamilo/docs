# Glossário

Termos-chave utilizados ao longo deste guia.

| Termo | Definição |
|------|-----------|
| **Assessment** | Ver **Gradebook** abaixo |
| **Assignment** | Uma tarefa em que submete ficheiros ou texto para o professor rever e classificar. Também conhecida como "publicação do estudante" ou "trabalho". |
| **CAPTCHA** | Um desafio (normalmente escrever letras distorcidas de uma imagem) usado para confirmar que é uma pessoa real, apresentado em alguns formulários de início de sessão, de registo e de recuperação de palavra-passe. |
| **Catalog** | A listagem pública de cursos (e sessões) que pode consultar e, em alguns casos, inscrever-se por conta própria. Acedida através de **Explore more courses**. |
| **Certificate** | Um documento gerado automaticamente quando atinge a pontuação mínima definida no gradebook de um curso. |
| **Course** | Um contentor de conteúdos e ferramentas de aprendizagem. Um curso pode incluir documentos, exercícios, fóruns, percursos de aprendizagem e muito mais. |
| **Enrollment** | Estar registado num curso ou sessão, o que lhe dá acesso aos respetivos conteúdos. Também conhecido como "subscription". |
| **Exercise** | Um questionário ou teste com uma ou mais perguntas. Também referido como "test" em alguns contextos. |
| **Forum** | Uma ferramenta de discussão com conversas em tópicos organizadas em categorias e temas. |
| **Gradebook** | Uma ferramenta que agrega as suas pontuações de exercícios, trabalhos e outras atividades numa classificação unificada. |
| **Invitation** | Uma hiperligação de utilização única enviada por um professor para o seu endereço de correio eletrónico, permitindo-lhe registar-se e ficar automaticamente inscrito num curso, mesmo que o registo geral esteja encerrado. |
| **Learning path** | Uma sequência estruturada de atividades de aprendizagem (documentos, exercícios, ligações) que segue numa ordem definida, por vezes com pré-requisitos. |
| **Self-registration** | A possibilidade de criar a sua própria conta através de um formulário de registo público, se estiver ativado pelo administrador da plataforma. |
| **Session** | Uma edição limitada no tempo de um ou mais cursos atribuída a um grupo específico de aprendentes, como um período letivo ou uma coorte. |
| **Skill** | Uma competência associada a conquistas do gradebook. Obter um certificado pode validar as competências associadas. |
| **Two-factor authentication (2FA)** | Um passo extra de início de sessão que utiliza um código temporizado de uma aplicação autenticadora, além da sua palavra-passe. |
| **Visibility** | Uma definição que controla se uma ferramenta, documento ou atividade é apresentada aos aprendentes. Os professores podem sempre ver os itens ocultos. |
