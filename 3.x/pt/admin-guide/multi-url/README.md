# Multi-URL

A funcionalidade multi-URL do Chamilo (também designada multi-tenant) permite executar vários portais virtuais a partir de uma única instalação do Chamilo. Cada portal tem o seu próprio URL, identidade visual, utilizadores, cursos e definições, mas todos partilham a mesma base de dados e o mesmo código-fonte.
