# Integrações

O Chamilo integra-se com vários serviços de terceiros para alargar as suas funcionalidades.

A maioria destas integrações é ativada através de plugins. Consulte a secção correspondente um pouco mais adiante neste guia.

* **[Videoconferência](video-conferencing.md)** — BigBlueButton e Zoom
* **[LTI 1.3](lti.md)** — Ligar ferramentas de aprendizagem externas
* **[xAPI](xapi.md)** — Registo de experiências de aprendizagem
* **[OnlyOffice](onlyoffice.md)** — Edição colaborativa de documentos
* **[Configuração de IA](ai-configuration.md)** — Configurar fornecedores de IA para funcionalidades com inteligência artificial
