# Introdução

Esta secção apresenta a interface de administração do Chamilo 3.0 e ajuda-o a orientar-se.

## Quem é um administrador?

O Chamilo tem vários níveis de funções administrativas:

| Função | Acesso |
|------|--------|
| **Administrator** | Acesso total a todas as funcionalidades de administração da plataforma. Também conhecido como **Portal Administrator** |
| **Global Administrator** | Igual ao Portal Administrator, com acesso a todos os URLs de acesso numa configuração multi-URL (multi-inquilino) |
| **Sessions Administrator** | Pode gerir sessões, inscrever utilizadores em sessões e aceder a definições relacionadas com sessões |
| **Human Resources Manager** | Pode visualizar o progresso dos formandos e os dados de acompanhamento dos utilizadores atribuídos |
| **Questions Manager** | Menos um administrador do que um curador de conteúdos, os gestores de perguntas têm acesso a um banco global de perguntas para rever a qualidade das mesmas |

Este guia centra-se principalmente na função de **Portal Administrator**, que tem o acesso mais amplo.

## Início de sessão

Os administradores iniciam sessão através da mesma página de início de sessão que todos os outros utilizadores. Após introduzir as suas credenciais, será enviado (na ausência de outra configuração) para a página de **Administration**. Uma diferença notável em relação a outras funções de utilizador é a secção **Administration** na barra lateral (não visível para outras funções).
