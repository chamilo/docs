# Outros Blocos de Administração

O painel de administração possui mais alguns blocos que não são tanto funcionalidades configuráveis quanto widgets informativos: uma página de ligações de saída, um registo de verificação de versão e dois painéis pequenos que obtêm conteúdo de chamilo.org. Este capítulo explica o que é cada um, de onde vem o seu conteúdo e — uma vez que alguns o fazem — se algum dado sai da sua plataforma.

## O que é abrangido

* **[Ligações do Chamilo.org](chamilo-org-links.md)** — Uma lista de favoritos para recursos oficiais do Chamilo; não envia nada
* **[Verificação de versão](version-check.md)** — Registo opcional (opt-in) que reporta a versão e a utilização da sua plataforma ao chamilo.org e indica se está na hora de atualizar
* **[Suporte profissional](professional-support.md)** — Um painel somente leitura que descreve os fornecedores oficiais de suporte do Chamilo
* **[Notícias do Chamilo](news-from-chamilo.md)** — Um feed somente leitura de anúncios oficiais, incluindo correções de segurança e novas versões

Cada página abaixo declara claramente o que, se houver, é enviado ao chamilo.org, e porquê.
