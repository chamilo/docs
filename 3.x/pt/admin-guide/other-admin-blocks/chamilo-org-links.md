# Ligações Chamilo.org

O bloco **Chamilo.org** é uma lista estática de ligações de saída para recursos oficiais do Chamilo — nada mais. Não envia dados para lado nenhum; cada ligação abre um sítio externo do Chamilo ou uma página de documentação local incluída na sua instalação.

## O que está no bloco

| Ligação | Destino |
|------|-------------|
| Página inicial do Chamilo | `chamilo.org` |
| Guias do utilizador | `docs.chamilo.org` |
| Fórum do Chamilo | GitHub Discussions for chamilo-lms |
| Guia de instalação | Local, `/documentation/installation_guide.html` |
| Alterações na última versão | Local, `/documentation/changelog.html` |
| Lista de contribuidores | Local, `/documentation/credits.html` |
| Guia de segurança | Local, `/documentation/security.html` |
| Guia de otimização | Local, `/documentation/optimization.html` |
| Prestadores oficiais de serviços Chamilo | `chamilo.org/providers` |

As ligações «locais» apontam para ficheiros de documentação incluídos na própria instalação do Chamilo, pelo que são carregados a partir do seu servidor, e não de chamilo.org.

## Finalidade

Este bloco existe apenas por conveniência — acesso rápido à documentação oficial do projeto, ao espaço de discussão da comunidade e à lista de prestadores de serviços validados, sem necessidade de os procurar.
