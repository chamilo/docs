# Turmas / Grupos de utilizadores

As turmas no painel de administração são grupos de âmbito da plataforma, utilizados para organizar utilizadores para fins de gestão. Distinguem-se dos grupos ao nível do curso (criados pelos formadores dentro de um curso).

> Os grupos de utilizadores e as [Turmas](../../admin-guide/sessions/classes.md) partilham a mesma interface. A única diferença é a definição do **tipo de grupo**: escolha "Class" para criar uma turma (utilizada para inscrição em massa em sessões), ou "User group" para grupos mais sociais que podem ter o seu próprio espaço na rede social interna. Consulte [Turmas](../../admin-guide/sessions/classes.md) para mais pormenores sobre a inscrição em sessões.

## Criar um grupo

![A lista de grupos de utilizadores a mostrar os grupos disponíveis com nome, descrição e número de membros](../../.gitbook/assets/admin-user-groups-list.png)

1. No painel de administração, navegue até **Classes**
2. Clique em **Add classes**
3. Introduza um **title** e, opcionalmente, uma **description**
4. Marque **Social group** se se tratar de um grupo social. Deixe desmarcado se se tratar de uma turma.
5. Adicione um URL de referência opcional e uma imagem/logótipo.
6. Escolha as **permissions** do grupo:
   * **Open** — Qualquer utilizador pode aderir
   * **Closed** — Os utilizadores devem ser adicionados por um administrador
7. Marque se pretende que os membros possam sair da turma por si próprios.
8. Guarde.

## Adicionar membros

1. Abra a lista de turmas/grupos de utilizadores
2. Clique no ícone de utilizador **Subscribe users to class**
3. Pesquise utilizadores por nome, nome de utilizador ou e-mail
4. Selecione os utilizadores a adicionar, utilizando as setas do lado direito
5. Clique no botão de confirmação para guardar

## Casos de utilização

* **Organização por departamento** — Agrupar utilizadores por departamento ou equipa
* **Inscrição em massa** — Adicionar todos os membros de um grupo a um curso ou sessão de uma só vez
* **Comunicação direcionada** — Enviar anúncios a grupos específicos
* **Relatórios** — Ver o progresso da formação filtrado por grupo

## Gerir grupos

* **Edit** — Alterar o nome, a descrição ou a visibilidade do grupo
* **Manage members** — Adicionar ou remover membros
* **Delete** — Remover o grupo (não elimina as contas dos membros)
