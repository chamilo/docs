# Categorias de Cursos

As categorias de cursos ajudam a organizar o catálogo de cursos, facilitando que os formandos encontrem cursos relevantes.

## Criar uma Categoria

1. No painel de administração, navegue até **Categorias de cursos**
2. Clique em **Adicionar categoria**
3. Introduza:
   * **Código da categoria** — Um identificador único e curto
   * **Nome da categoria** — O nome a apresentar (p. ex., "Tecnologias da Informação", "Competências de Gestão")
   * **Permitir adicionar cursos nesta categoria?** — Se permite que os cursos definam esta como categoria, ou se serve apenas como nível intermédio numa hierarquia 
   * **Categoria pai** — (Opcional) Coloque esta categoria sob outra categoria para criar uma hierarquia
   * **Descrição** — (Opcional)
   * **Imagem** — (Opcional) Representará esta categoria, embora quase não seja mostrada em lado nenhum
4. Prima *Adicionar categoria*

O Chamilo cria 3 categorias por predefinição: *Language skills*, *PC Skills* e *Projects*. Estas podem ser renomeadas, removidas ou mantidas, consoante as suas necessidades.

## Hierarquia de Categorias

![A página de gestão de categorias de cursos a mostrar uma árvore aninhada de categorias](../../.gitbook/assets/admin-course-categories.png)

As categorias podem ser aninhadas para criar uma estrutura em árvore:

* Business
  * Management
  * Marketing
  * Finance
* Technology
  * Programming
  * Networking
  * Cybersecurity

Os formandos que consultam o catálogo de cursos podem navegar por esta hierarquia para encontrar cursos.

## Gerir Categorias

* **Editar** — Alterar o nome, o código ou o pai da categoria
* **Mover** — Alterar a posição de uma categoria na lista
* **Eliminar** — Remover uma categoria. Os cursos de uma categoria eliminada são movidos para "sem categoria".

## Sugestões

* **Mantenha a simplicidade** — Utilize categorias abrangentes que os formandos possam compreender de relance
* **Limite a profundidade** — Evite categorias profundamente aninhadas. Dois ou três níveis são geralmente suficientes.
* **Atribua categorias durante a criação do curso** — Incentive os formadores a selecionar uma categoria ao criar cursos, para que o catálogo se mantenha organizado
