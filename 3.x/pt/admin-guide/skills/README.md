# Competências

O bloco **Competências** no painel de administração agrupa as ferramentas para definir, organizar e acompanhar distintivos de competência («skills») em toda a plataforma. Uma competência pode ser atribuída automaticamente quando um formando atinge um limiar no boletim de notas, conclui cursos específicos, ou manualmente por um professor, e pode incluir um ícone no estilo de distintivo e um nível (por exemplo Bronze/Prata/Ouro).

![O bloco Competências no painel de administração, listando Roda de competências, Importação de competências, Gerir competências, Gerir níveis de competências, Ranking de competências e Competências e avaliações](../../.gitbook/assets/admin-skills-block.png)

O bloco só aparece se a definição **Enable skills tool** (`skill.allow_skills_tool`, em Configuration Settings > Skills) estiver ativada — está ativada por predefinição.

## Aceder ao bloco Competências

No painel de administração, o bloco **Competências** aparece juntamente com os outros blocos do painel. Clique em qualquer uma das ligações para abrir a ferramenta correspondente.

## O que contém o bloco

* **[Gerir competências](managing-skills.md)** — Criar competências, importá-las em massa e atribuir cada uma a uma escala de níveis
* **[Roda de competências](skills-wheel.md)** — Um mapa visual com zoom de toda a árvore de competências
* **[Ranking de competências](skills-ranking.md)** — Uma tabela de classificação de utilizadores pelas competências adquiridas
* **[Competências e avaliações](skills-assessments.md)** — Associar categorias do boletim de notas às competências que atribuem

## Definições relacionadas

Algumas outras definições em Configuration Settings > Skills alteram quem pode fazer o quê com este bloco:

* **Allow HR skills management** (`allow_hr_skills_management`) — Permite que utilizadores Human Resources Manager gerem competências juntamente com os administradores
* **Allow private skills** (`allow_private_skills`)
* **Teachers can assign skills** (`skills_teachers_can_assign_skills`)
* **Hide skill levels** (`hide_skill_levels`)
* **Show full skill name on skill wheel** (`show_full_skill_name_on_skill_wheel`)
