# Competências e Avaliações

É aqui que as competências se ligam ao livro de notas: é a ponte entre os resultados das avaliações e a atribuição automática de competências.

## Aceder a Competências e Avaliações

No painel de administração, clique em **Skills > Skills and assessments**.

## O que mostra

Uma lista de categorias do livro de notas, com controlos para ligar cada uma a uma competência. Uma vez ligada, qualquer formando que atinja o limiar de aprovação dessa categoria do livro de notas recebe automaticamente a competência associada — sem qualquer passo manual.

Esta é a forma recomendada de atribuir competências em escala: em vez de atribuir competências aos utilizadores um a um, ligue a categoria relevante do livro de notas uma vez e deixe que se aplique a todos os formandos que se qualificarem. Consulte [Livro de notas (Avaliações)](../platform-settings/gradebook-settings.md) para saber como as categorias e os limiares do livro de notas são configurados inicialmente.
