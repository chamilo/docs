# Ranking de Competências

O Ranking de Competências é um quadro de classificação de utilizadores ordenados pelo número de competências que adquiriram.

## Aceder ao Ranking de Competências

No painel de administração, clique em **Competências > Ranking de competências**.

## O Que Mostra

Para cada utilizador ativo, o ranking mostra:

* **Competências adquiridas** — Contagem total de competências emitidas, usada para ordenar o quadro de classificação (maior primeiro)
* **A aprender atualmente** — O número de competências associadas, através do caderno de avaliações, a cursos em que o utilizador está atualmente inscrito (diretamente ou através de uma sessão)

Utilize esta página para identificar de relance os seus formandos mais realizados, ou para avaliar a atividade geral de aquisição de competências na plataforma.
