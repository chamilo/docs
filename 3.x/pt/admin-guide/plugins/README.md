# Plugins

Os plugins alargam a funcionalidade do Chamilo sem modificar o código principal. O Chamilo 3.0 inclui mais de 50 plugins que podem ser ativados conforme necessário.

## O bloco Plugins

O painel de administração também tem o seu próprio bloco **Plugins**, distinto da gestão geral de plugins deste capítulo. Não lista todos os plugins instalados — apenas aqueles cuja configuração declara que devem aparecer na região do menu de administração, dando a cada um desses plugins um atalho direto para a sua própria página de administração no painel.

![O bloco Plugins no painel de administração, com atalhos para plugins instalados configurados para aparecer no menu de administração](/.gitbook/assets/admin-plugins-block.png)

Se um plugin que ativou não aparecer aqui, isso é esperado — significa que esse plugin em particular não se declarou para a região do menu de administração, e não que algo esteja avariado. Consulte [Gestão de plugins](managing-plugins.md) para a lista completa de plugins instalados, independentemente de aparecerem ou não no painel.
