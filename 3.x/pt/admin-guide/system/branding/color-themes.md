# Temas de Cores

O Chamilo 2.0 introduz um sistema de temas de cores que permite personalizar a aparência visual da plataforma.

## Como Funcionam os Temas

Os temas de cores definem a paleta utilizada em toda a interface do Chamilo — cores primárias, cores de destaque, fundos e cores de texto. Um tema está associado a um URL de acesso: num portal de URL único torna-se efetivamente o tema global e, numa configuração multi-URL, cada URL pode ter o seu próprio.

## Aplicar um Tema

![A página de temas de cores a mostrar os temas disponíveis com amostras de pré-visualização e um botão Aplicar](/.gitbook/assets/admin-color-themes.png)

1. No painel de administração, navegue até **Temas de cores**
2. Percorra os temas disponíveis
3. Selecione um tema e clique em **Aplicar**
4. O tema é aplicado imediatamente à plataforma

## Temas por URL

Numa configuração multi-URL, cada URL de acesso pode ter o seu próprio tema de cores. Isto permite que diferentes portais tenham identidades visuais distintas, partilhando a mesma instalação do Chamilo.

## Dicas

* **Alinhe com a sua marca** — Escolha ou personalize um tema que corresponda às cores da marca da sua organização
* **Teste a legibilidade** — Após aplicar um tema, verifique se o texto é legível sobre as cores de fundo, especialmente em situações de elevado contraste
* **Considere a acessibilidade** — Garanta contraste de cores suficiente para utilizadores com deficiências visuais
