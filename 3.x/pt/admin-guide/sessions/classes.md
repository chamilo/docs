# Turmas

As turmas no Chamilo são grupos predefinidos de utilizadores que podem ser inscritos em sessões como uma unidade. Simplificam o processo de inscrição quando forma regularmente os mesmos grupos de pessoas.

> As turmas e os [Grupos de utilizadores](../../admin-guide/users/user-groups.md) partilham a mesma interface. A única diferença é a definição do **tipo de grupo**: escolha "Class" ao criar o grupo. Tudo o resto — gestão de membros, visibilidade e a própria interface — funciona de forma idêntica.

## Criar uma turma

1. No painel de administração, navegue até **Classes** (ou User Groups e selecione o tipo "Class")
2. Clique em **Create a class**
3. Introduza um **nome** (por exemplo, "Engineering Team", "New Hires March 2026")
4. Adicione **membros** — pesquise e selecione utilizadores
5. Guarde

## Utilizar turmas para inscrição

Ao criar ou editar uma sessão, pode inscrever uma turma inteira de uma só vez, em vez de adicionar utilizadores individualmente:

1. Abra as definições de inscrição da sessão
2. Clique em **Add a class**
3. Selecione a turma
4. Todos os membros da turma são inscritos na sessão

## Gerir turmas

* **Edit** — Alterar o nome da turma ou atualizar a composição
* **Add/remove members** — Manter a lista da turma atualizada
* **Delete** — Remover a turma (não afeta as contas dos membros nem as respetivas inscrições existentes)

## Sugestões

* **Crie turmas para coortes recorrentes** — Se ministra a mesma formação a equipas diferentes, crie uma turma para cada equipa
* **Atualize antes de cada sessão** — Reveja a composição da turma antes de a inscrever numa nova sessão, para garantir que a lista está atualizada
* **Combine com importação CSV** — Importe a composição da turma a partir de um ficheiro CSV para grupos grandes
