# Carreiras e Promoções

O Chamilo inclui um sistema de gestão de carreiras que permite definir percursos formativos e acompanhar a progressão dos formandos através de programas estruturados.

## Carreiras

![A lista de carreiras a mostrar percursos de carreira definidos, com nome e descrição](../../.gitbook/assets/admin-careers-list.png)

Uma **carreira** representa um percurso formativo estruturado — uma sequência de etapas de formação que um formando segue para atingir um objetivo profissional.

### Criar uma carreira

1. No painel de administração, navegue até **Carreiras**
2. Clique em **Criar uma carreira**
3. Introduza um **nome** e uma **descrição**
4. Guarde

## Promoções

Uma **promoção** representa uma coorte ou turma de formandos a progredir numa carreira. Pense nela como um grupo de pessoas que percorre o mesmo percurso de carreira ao mesmo tempo.

### Ligação a sessões

Depois de criar uma promoção, associa-lhe sessões. Isto define a sequência de formação que o formando deve concluir.

Pode posteriormente replicar promoções para facilitar a criação da promoção seguinte com cópias das mesmas sessões, de modo que a próxima promoção possa ser construída instantaneamente.

### Criar uma promoção

1. Navegue até **Promoções**
2. Clique em **Criar uma promoção**
3. Introduza um **nome** e uma **descrição**
4. Associe-a a uma **carreira**
5. Atribua **sessões** à promoção
6. Guarde

## Como se articula

* Uma **carreira** define o percurso (por exemplo, «Certificação de Programador Júnior»)
* Uma **promoção** representa uma coorte (por exemplo, «Turma de março de 2026»)
* As **sessões** dentro da promoção disponibilizam o conteúdo formativo efetivo

## Sugestões

* **Utilize em programas estruturados** — Carreiras e promoções são especialmente úteis em programas de formação em várias etapas, em que os formandos progridem segundo uma sequência definida
* **Acompanhe a conclusão** — Utilize as ferramentas de relatórios para monitorizar o progresso das promoções nos respetivos percursos de carreira
