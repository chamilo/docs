## Compreender as sessões

As sessões são **opcionais**. Pode fazer o portal funcionar apenas com cursos, mas **recomendamos vivamente** que considere a complexidade adicional das sessões como forma de poupar trabalho de gestão a longo prazo.

Um **curso** contém o conteúdo (documentos, exercícios, percursos de aprendizagem). Uma **sessão** atribui esse curso (ou vários cursos) a um grupo específico de formandos *durante um período de tempo específico*.

Esta arquitetura significa que:

* Os formadores criam o conteúdo uma única vez no curso
* Os administradores criam sessões para disponibilizar esse conteúdo a diferentes coortes
* Cada sessão tem a sua própria inscrição, dados de acompanhamento e resultados
* O conteúdo base do curso é partilhado, mas os tutores da sessão podem personalizar determinados elementos

## Quando utilizar sessões

Utilize sessões quando:

* Disponibiliza a mesma formação várias vezes (por exemplo, sessões mensais de integração)
* Tem programas baseados em coortes (por exemplo, turmas por semestre)
* Necessita de acompanhamento separado por grupo de formandos
* Pretende que tutores diferentes geram edições distintas do mesmo curso
