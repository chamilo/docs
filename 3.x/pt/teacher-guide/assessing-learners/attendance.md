# Assiduidade

A ferramenta de assiduidade permite registar a presença dos formandos nas sessões de aula agendadas, presenciais ou em linha.

## Criar uma folha de assiduidade

1. Abra a ferramenta **Attendance** a partir da página inicial do curso
2. Clique em **Add attendance** para criar uma folha de assiduidade
3. Introduza um **Title** para a folha de assiduidade (por exemplo, "Semana 1 - Introdução")
4. Introduza uma **Description** (destina-se sobretudo ao seu uso — os formandos não verão a descrição)
5. Guarde

### Definições avançadas

1. **Require unique presence** permite considerar um formando como totalmente presente se tiver participado mesmo que apenas numa data da folha de assiduidade
2. **Gradebook options** permite decidir se a folha de assiduidade será classificada na ferramenta de avaliação (gradebook).

## Adicionar datas

Cada folha de assiduidade contém uma ou mais datas (sessões) nas quais se regista a presença:

1. Abra uma folha de assiduidade ou continue o processo de criação
2. Clique em **Add a date** <img src="../../.gitbook/assets/icons/mdi-calendar-plus.svg" alt="Adicionar data" data-size="line">
3. Selecione a data e a hora
4. Opcionalmente, assinale **Repeat date** para escolher uma lógica de repetição
5. Indique uma **Duration** em minutos para o evento (o valor predefinido é 60 minutos)
6. Opcionalmente, selecione um **Group** se esta data de assiduidade se aplicar apenas a um grupo de formandos
7. Guarde

Pode adicionar várias datas à mesma folha de assiduidade (por exemplo, todas as sessões de um mês).

## Registar a assiduidade

Para cada data, marque cada formando como:

* **Present** — O formando esteve presente (valor predefinido para todos os formandos)
* **Absent** — O formando não esteve presente

Clique na célula de estado junto ao nome de cada formando para alternar entre presente e ausente.

Por predefinição, todos os formandos são marcados como presentes, pois considera-se que é mais provável haver mais pessoas presentes do que ausentes.

Nota: Os administradores podem alterar a configuração do portal para permitir tipos de assiduidade mais alargados (atraso, ausência justificada, etc.), que podem refletir melhor os seus procedimentos. Nesse caso, um simples clique no campo de presença alternará entre todos os tipos de presença.

## Consultar relatórios de assiduidade

![A folha de assiduidade a mostrar uma tabela-resumo com formandos, datas e indicadores de presença](../../.gitbook/assets/attendance-sheet.png)

A ferramenta de assiduidade apresenta:

* Uma tabela-resumo com todos os formandos e todas as datas
* A percentagem de assiduidade de cada formando (sessões presentes / sessões totais)
* Indicadores com código de cores para uma leitura rápida

## Extra

As assiduidades dispõem de algumas funcionalidades alargadas que não são imediatamente visíveis:
* **Signatures** podem ser ativadas para que os formandos assinem a presença em aula através de um tablet manuseado pelo professor
* **Comments** podem ser adicionados pelo professor em cada assiduidade do estudante
* **PDF reports** podem ser extraídos para cumprir requisitos regulamentares

## Sugestões

* **Ligar ao progresso do curso** — Utilize os dados de assiduidade em conjunto com a ferramenta Course Progress para correlacionar a presença com a cobertura dos tópicos
* **Exportar dados** — Exporte a folha de assiduidade para os registos administrativos
* **Definir expectativas** — Se a assiduidade for obrigatória, comunique a política de forma clara na introdução do curso ou nos anúncios
