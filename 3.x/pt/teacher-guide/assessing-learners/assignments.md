# Trabalhos

A ferramenta de trabalhos (também chamada de «publicações dos alunos») permite recolher o trabalho dos formandos — ensaios, projetos, relatórios ou qualquer envio baseado em ficheiros — e classificá-lo.

## Criar um trabalho

1. Abra a ferramenta **Trabalhos** <img src="/.gitbook/assets/icons/mdi-inbox-full.svg" alt="Trabalhos" data-size="line"> a partir da página inicial do curso
2. Clique em **Criar um trabalho**
3. Preencha os detalhes:
   * **Nome do trabalho** — O nome do trabalho (p. ex., «Relatório do projeto final»)
   * **Descrição** — Instruções para os formandos, incluindo o que submeter e como será avaliado (suporta texto formatado)
   * **Pontuação máxima** — Sobre que total o trabalho será classificado
   * **Adicionar ao boletim** — Adicionar como item avaliado na ferramenta de avaliação (boletim), para que possa contribuir para os objetivos do curso
   * **Prazo** — A data e hora oficiais (publicadas) após as quais os envios são marcados como atrasados (os carregamentos continuam a ser aceites)
   * **Termina em (completamente encerrado)** — A data e hora limite rígidas após as quais nenhum carregamento é possível
   * **Adicionar ao calendário** — Criar um evento para referenciar a data de envio deste trabalho
   * **Tipo de envio** — Escolha entre **Permitir apenas texto**, **Permitir apenas ficheiros** ou **Permitir ficheiros ou texto em linha**
4. Guarde

Depois de criar um trabalho, também pode:
* Carregar documentos-modelo a partir da página de detalhe do trabalho
* Atribuir o trabalho a utilizadores específicos (em vez de a todos os utilizadores do curso)

E depois de os formandos terem submetido os seus trabalhos, pode:
* Exportar uma lista em PDF dos envios
* Mostrar uma lista apenas dos formandos que não submeteram o trabalho
* Descarregar todos os trabalhos num único ZIP grande
* Carregar todas as correções num único ZIP grande
* Eliminar todas as correções que submeteu (isto não elimina os envios dos formandos)

## Como os formandos submetem

Os formandos abrem o trabalho e:

1. Clicam em **Carregar ficheiro** ou no botão de envio
2. Selecionam um ficheiro no computador (ou escrevem texto diretamente, consoante a configuração)
3. Adicionam um comentário opcional
4. Submetem

Os formandos podem ver se já submeteram e, se for permitido, atualizar o envio.

## Rever os envios

![A lista de envios do trabalho, com nomes dos alunos, datas, ficheiros e estado da classificação](/.gitbook/assets/assignments-submissions-list.png)

Como professor, abra um trabalho para ver a lista de todos os envios:

* **Nome do aluno** — Quem submeteu
* **Data de envio** — Quando o trabalho foi submetido
* **Ficheiro** — Descarregar o ficheiro submetido
* **Estado** — Se o envio já foi classificado
* **Comentários** — Quaisquer comentários deixados pelo formando ou por si

### Classificar um envio

![A vista de classificação do trabalho, com campo de pontuação, campo de feedback e carregamento de ficheiro corrigido](/.gitbook/assets/assignment-grading-view.png)

1. Clique num envio para o abrir
2. Reveja o ficheiro submetido
3. Introduza uma **pontuação**
4. Escreva **comentários de feedback** para o formando
5. Opcionalmente, carregue um **ficheiro corrigido** como anexo
6. Guarde

### Classificação assistida por IA

Se as ferramentas de IA estiverem configuradas na sua plataforma, poderá ver uma opção de **classificação por IA** ao rever os envios. Esta opção utiliza um modelo de IA para sugerir uma pontuação e feedback para trabalhos de resposta aberta. Consulte [Classificação por IA](../ai-tools/ai-grading.md) para mais pormenores.

## Gerir os envios

Ações de grupo:
* **Descarregar pacote de trabalhos** — Descarregar todos os envios como um único ficheiro ZIP para revisão offline
* **Carregar pacote de correções** — Se descarregou todos os envios num único ficheiro ZIP, editou os ficheiros no computador e voltou a compactá-los, pode enviar o zip como um pacote de correções. Não altere os nomes dos ficheiros, senão não funcionará.
* **Envios atrasados** — Os envios após o prazo são assinalados, mas podem ainda ser aceites consoante as suas definições

Ações sobre um envio individual:
* **Carregar correção** — Carregar uma correção para um formando 
* **Descarregar** — Descarregar o envio de um formando
* **Corrigir e classificar** — Adicionar uma correção e uma classificação ao envio do formando 
* **Editar** — Editar o título do documento ou o feedback anterior no envio
* **Mover** — Transferir um envio entre pastas de trabalhos (p. ex., se o aluno submeteu no trabalho errado)
* **Visibilidade** — Controlar se os formandos podem ver os envios uns dos outros

## Ligação ao boletim

As pontuações dos trabalhos podem ser incluídas no boletim do curso (ferramenta «Avaliações»). Isto permite que as classificações dos trabalhos contribuam para a nota global do formando e para a elegibilidade ao certificado. Consulte [Boletim](gradebook.md) para mais pormenores.

## Dicas

* **Seja específico nas instruções** — Descreva claramente o que os formandos devem submeter, o formato esperado e os critérios de avaliação
* **Defina prazos realistas** — Utilize a ferramenta Agenda para tornar os prazos visíveis no calendário do curso
* **Utilize a funcionalidade de ficheiro corrigido** — Carregue versões anotadas do trabalho dos estudantes para que possam ver as suas correções específicas
* **Ative a visibilidade entre pares com cuidado** — Permitir que os formandos vejam o trabalho uns dos outros pode incentivar a aprendizagem, mas pode não ser adequado para todos os trabalhos
