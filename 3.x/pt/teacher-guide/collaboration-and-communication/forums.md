# Fóruns

A ferramenta de fórum permite-lhe alojar discussões estruturadas no seu curso. Os formandos podem publicar mensagens, responder uns aos outros e participar em conversas em cadeia.

## Estrutura do fórum

![A lista de categorias de fórum a mostrar categorias, fóruns e contagens de tópicos](/.gitbook/assets/forum-category-list.png)

Os fóruns no Chamilo estão organizados em três níveis:

1. **Categorias de fórum** — Agrupamentos de nível superior (p. ex., "Discussões gerais", "Perguntas do Módulo 1")
2. **Fóruns** — Quadros de discussão individuais dentro de uma categoria
3. **Tópicos (threads)** — Tópicos de discussão individuais dentro de um fórum, cada um com uma cadeia de respostas

## Criar uma categoria de fórum

1. Abra a ferramenta **Fóruns** <img src="/.gitbook/assets/icons/mdi-comment-quote.svg" alt="Forums" data-size="line"> a partir da página inicial do seu curso
2. Clique em **Adicionar uma categoria de fórum**
3. Introduza um **Nome da categoria** e, opcionalmente, uma descrição
4. Guarde

## Criar um fórum

Só pode adicionar um fórum depois de existir pelo menos uma categoria.

1. Dentro de uma categoria, clique em **Adicionar um fórum**
2. Preencha os dados básicos:
   * **Título** — O nome deste quadro de discussão
   * **Descrição** — Uma descrição opcional da finalidade do fórum
   * **Criar na categoria** — A categoria a que este fórum pertence
3. Abra **Definições avançadas** para configurar:
   * **Data de publicação** / **Data de encerramento** — Janela temporal opcional durante a qual o fórum está aberto
   * **Fórum moderado** — Exigir que as novas publicações sejam aprovadas por um professor antes de se tornarem visíveis
   * **Os formandos podem editar as suas próprias publicações?** — Permitir ou impedir que os formandos editem publicações após o envio
   * **Permitir que os utilizadores iniciem novos tópicos** — Quando definido como Não, os formandos só podem responder a tópicos existentes
   * **Tipo de vista predefinido** — Escolha como as publicações são apresentadas: **Plana**, **Em cadeia** ou **Aninhada**
   * **Para grupo** — Associar este fórum a um grupo do curso
   * **Acesso público / Acesso privado** — Para fóruns de grupo, decidir se qualquer membro do curso o pode ler ou apenas os membros do grupo
4. Guarde

Se a visibilidade do curso estiver definida como "Aberto ao mundo", o formulário também mostra uma opção **Permitir publicações anónimas?**. Esta opção fica oculta em cursos com visibilidade restrita.

## Gerir tópicos

Os formandos (e você) podem criar novos tópicos dentro de um fórum. Como professor, pode:

* **Fixar um tópico (mensagem permanente)** — Marcar um tópico como permanente ao criá-lo ou editá-lo para que apareça sempre no topo
* **Bloquear um tópico** — Impedir novas respostas
* **Editar ou eliminar publicações** — Moderar a discussão
* **Mover um tópico** — Transferir um tópico para um fórum diferente

## Pontuação do fórum

Ao criar um novo tópico como professor, pode ativar **Classificar este tópico** em Definições avançadas. Em seguida, define uma pontuação máxima, um cabeçalho de coluna para o livro de notas e um peso no relatório. Também pode ativar **Tópico pontuado pelos pares**, o que exige que cada formando avalie pelo menos dois outros formandos antes de a sua própria pontuação contar.

## Notificações

Cada fórum e tópico tem um interruptor **Notificar-me** que você e os seus formandos podem usar para subscrever notificações por correio eletrónico sobre novas publicações. As notificações são uma subscrição por utilizador e não são configuradas ao criar o fórum.
