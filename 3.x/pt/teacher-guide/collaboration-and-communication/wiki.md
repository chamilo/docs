# Wiki

A ferramenta wiki permite que você e os seus formandos criem e editem colaborativamente páginas web no interior do curso. É útil para projetos de grupo, bases de conhecimento partilhadas e exercícios de escrita colaborativa.

## Como Funciona a Wiki

Uma wiki é uma coleção de páginas web interligadas que qualquer pessoa com permissão pode editar. No Chamilo:

* Cada curso tem a sua própria wiki
* As páginas podem ser ligadas umas às outras através de ligações no estilo wiki
* Todas as edições são registadas com um histórico de revisões
* As versões anteriores podem ser comparadas e restauradas

## Criar uma Página Wiki

1. Abra a ferramenta **Wiki** a partir da página inicial do curso
2. Clique em **Add a new page**
3. Introduza um **page title**
4. Escreva o conteúdo da página utilizando o editor de texto formatado
5. Guarde

Para ligar a outra página wiki a partir do editor, crie uma ligação utilizando o título da página de destino.

## Editar Páginas

Qualquer pessoa com permissões de edição pode modificar uma página wiki:

1. Abra a página que pretende editar
2. Clique no botão **Edit** <img src="../../.gitbook/assets/icons/mdi-pencil.svg" alt="Editar" data-size="line">
3. Faça as suas alterações no editor
4. Adicione, opcionalmente, uma entrada de **Comments** a descrever o que alterou
5. Guarde

## Histórico de Revisões

Cada edição cria uma nova revisão. Pode:

* **View history** — Ver uma lista de todas as revisões com carimbos de data/hora e autores
* **Compare versions** — Ver o que mudou entre duas revisões
* **Restore a version** — Reverter a página para uma revisão anterior, se necessário

## Gerir a Wiki

Como professor do curso, pode:

* **View all pages** — Ver uma lista de todas as páginas wiki do curso
* **Find orphan pages** — Identificar páginas que não estão ligadas a partir de nenhuma outra página
* **Find wanted pages** — Ver páginas que estão ligadas mas que ainda não existem
* **Lock a page for editing** — Bloquear todas as edições numa página enquanto a finaliza
* **Toggle visibility** — Ocultar uma página dos formandos
* **Delete pages** — Remover páginas que já não são necessárias
* **Monitor contributions** — Rever estatísticas por utilizador: editores mais ativos, páginas mais editadas, páginas mais visitadas
* **Export** — Exportar uma página wiki para PDF, ou enviá-la para a ferramenta Documents

## Dicas

* **Use a wiki para projetos de grupo** — Atribua a cada grupo uma página wiki para construírem colaborativamente o seu entregável
* **Crie uma base de conhecimento do curso** — Construa uma wiki de referência com conceitos-chave e incentive os formandos a contribuir
* **Reveja o histórico de edições** — O histórico de revisões permite-lhe avaliar as contribuições individuais no trabalho colaborativo
