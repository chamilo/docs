# Chat

A ferramenta de chat disponibiliza mensagens de texto em tempo real no interior de um curso. É útil para comunicação rápida, sessões de perguntas e respostas ao vivo ou discussões informais.

## Utilizar o Chat

1. Abra a ferramenta **Chat** a partir da página inicial do curso
2. No painel **Users**, escolha um utilizador específico que esteja em linha para lhe enviar uma mensagem diretamente, ou utilize o separador **All** para se dirigir a todo o grupo
3. Escreva a sua mensagem no campo de texto na parte inferior e prima **Enter** para enviar (**Shift+Enter** para uma nova linha sem enviar)

Uma opção **Preview** permite verificar a formatação antes de enviar, e **Reset** limpa o rascunho atual.

## Funcionalidades do Chat

* **Mensagens em tempo real** — As mensagens aparecem instantaneamente para o(s) destinatário(s)
* **Histórico de mensagens** — As mensagens anteriores ficam visíveis quando entra no chat
* **Presença de utilizadores** — O painel Users mostra quem está atualmente em linha no curso
* **Direto ou de grupo** — Envie mensagens a um formando de cada vez, ou transmita a todos através do separador **All**

## Enquanto professor

Enquanto professor do curso, pode:

* **Monitorizar discussões** — Rever o histórico do chat para acompanhar o envolvimento dos formandos
* **Encontrar arquivos de chat em Documents** — A ferramenta de chat replica automaticamente as mensagens em ficheiros HTML na ferramenta Documents, organizados por dia e por âmbito (curso / sessão / grupo), de modo que a conversa persiste para além da sessão em direto

Se a definição da plataforma "Restrict course chat to tutors" estiver ativada pelo administrador, apenas os tutores podem conversar com os formandos; caso contrário, todos os inscritos no curso podem participar.

## Sugestões para utilizar o Chat de forma eficaz

* **Agende sessões de chat** — Informe os formandos com antecedência de quando estará disponível para chat em direto (utilize a ferramenta Agenda)
* **Defina regras de convivência** — Estabeleça expectativas de comunicação respeitosa
* **Utilize para perguntas rápidas** — O chat funciona melhor para trocas curtas; utilize o Forum para discussões mais longas e estruturadas

> Se a sua plataforma tiver videoconferência configurada (BigBlueButton ou Zoom), considere utilizá-la para sessões em direto em que voz e vídeo seriam mais eficazes. Consulte [Videoconferência](video-conferencing.md).
