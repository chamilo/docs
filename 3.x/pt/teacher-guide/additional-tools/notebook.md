# Caderno

O caderno é uma ferramenta pessoal de tomada de notas para os formandos. Cada formando tem o seu próprio caderno privado no curso.

## Como Funciona

O caderno é uma ferramenta simples em que os formandos podem:

* **Criar notas** — Escrever e guardar notas pessoais relacionadas com o conteúdo do curso
* **Organizar notas** — Rever, editar e eliminar as suas notas
* **Mantê-las privadas** — As notas são visíveis apenas para o formando que as criou

## Como Professor

Como professor, deve ter em conta que:

* O caderno é uma **ferramenta pessoal** — não pode ver as notas dos seus formandos
* É útil como **ferramenta de reflexão** — incentive os formandos a tomar notas enquanto estudam
* As notas são armazenadas no curso — não são partilhadas entre cursos

## Ativar o Caderno

A ferramenta caderno aparece na página inicial do curso se estiver ativada. Se não a vir, verifique se não está oculta (procure ferramentas ocultas na página inicial do curso).
