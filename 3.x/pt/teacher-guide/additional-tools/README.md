# Ferramentas Adicionais

Para além das ferramentas principais de conteúdo, avaliação e colaboração, o Chamilo oferece várias ferramentas adicionais que podem enriquecer o seu curso.

* **[Agenda](agenda.md)** — Agende eventos, prazos e lembretes para o seu curso
* **[Notebook](notebook.md)** — Uma ferramenta pessoal de tomada de notas para os formandos
* **[Dropbox](dropbox.md)** — Uma ferramenta simples de troca de ficheiros entre si e os seus formandos
* **[Portfolio](portfolio.md)** — Permita que os formandos construam e apresentem um portfólio do seu trabalho
* **[Course Progress](course-progress.md)** — Defina secções temáticas e acompanhe a entrega do curso
