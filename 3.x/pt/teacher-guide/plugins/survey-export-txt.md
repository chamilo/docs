# Exportação de Inquérito TXT

A Exportação de Inquérito TXT <img src="../../.gitbook/assets/icons/mdi-file-outline.svg" alt="Exportação de Inquérito TXT" data-size="line"> exporta os resultados de um inquérito para um ficheiro de texto simples legível — um bloco por respondente, listando cada pergunta, a(s) resposta(s) escolhida(s) e qualquer resposta em texto livre, em vez das linhas e colunas de um CSV.

## Exportar um Inquérito

Uma vez ativada, a lista da ferramenta **Inquérito** do seu curso passa a ter um ícone **Exportar** em cada linha de inquérito. Clique nele para descarregar os resultados como um ficheiro `.txt`.

## O que Contém o Ficheiro

* Os inquéritos anónimos mostram "Anonymous" em vez dos dados de identidade; os inquéritos não anónimos incluem o nome e o nome de utilizador do respondente
* As respostas de cada respondente são separadas por uma linha divisória, tornando o ficheiro fácil de ler de cima para baixo
* Se nenhuma resposta for elegível para exportação, o ficheiro indica-o simplesmente em vez de falhar

## Sugestões

* **Melhor para leitura, CSV para análise** — Utilize este formato quando pretender ler as respostas diretamente; utilize [Exportação de Inquérito CSV](survey-export-csv.md) se planear abrir os resultados numa folha de cálculo
