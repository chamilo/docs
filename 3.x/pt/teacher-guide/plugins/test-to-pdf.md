# Teste para PDF

Teste para PDF <img src="../../.gitbook/assets/icons/mdi-file-pdf-box.svg" alt="Teste para PDF" data-size="line"> exporta as perguntas de um teste do curso para um PDF imprimível — apenas perguntas, apenas respostas, ou ambas em conjunto — útil para uma versão em papel de um teste.

## Aceder à ferramenta

Uma vez ativada, a ferramenta **Teste para PDF** aparece na página inicial do seu curso, listando todos os testes do curso (ou da sessão). Cada linha oferece três ações: **Descarregar perguntas**, **Descarregar respostas** e **Descarregar tudo**.

## Dicas

* **Nem todos os tipos de pergunta são suportados** — Apenas um subconjunto dos tipos de pergunta do Chamilo (escolha múltipla, verdadeiro/falso e formatos fechados semelhantes) é exportado corretamente; perguntas de resposta aberta ou tipos mais complexos podem não aparecer corretamente, ou sequer aparecer
* **Verifique o resultado antes de imprimir um lote completo** — Reveja o PDF gerado de um teste antes de imprimir em massa para uma sessão de exame
