# Monitorização de Exercícios

A Monitorização de Exercícios <img src="../../.gitbook/assets/icons/mdi-camera.svg" alt="Monitorização de Exercícios" data-size="line"> utiliza a câmara web do estudante para capturar fotografias de identidade durante uma tentativa de teste — uma fotografia de um documento de identificação e uma fotografia do rosto do estudante — para fins de integridade do exame.

## Sinalizar um Teste

Abra as definições do teste e assinale a opção **Exercise Monitoring**. Uma vez sinalizado, os estudantes que tentam esse teste veem um pequeno widget flutuante da câmara web e são solicitados a capturar as duas fotografias antes ou durante a tentativa.

## Rever as Capturas

[inferred] As fotografias capturadas são revistas através do ecrã de relatórios adicionado pelo plugin **[Exercise Focused](exercise-focused.md)**, com o qual este plugin foi desenvolvido em paralelo — se a sua plataforma tiver apenas a Monitorização de Exercícios ativada e não o Exercise Focused, pergunte ao seu administrador como se pretende que as fotografias capturadas sejam revistas na sua instalação.

## Aspetos a Ter em Conta

* **Isto trata dados pessoais sensíveis** — as fotografias de documentos de identificação são uma categoria de dados que muitas instituições e regulamentações de privacidade tratam com especial cuidado. Confirme com o seu administrador que a utilização deste plugin se enquadra nas obrigações de proteção de dados da sua instituição antes de depender dele
* **As fotografias são retidas temporariamente** — o seu administrador define um período de retenção, após o qual as fotografias capturadas são automaticamente eliminadas
* **Esta é uma funcionalidade em fase inicial** — espere arestas por limar; verifique se o fluxo de captura funciona conforme esperado numa execução de teste antes de o utilizar num exame real
