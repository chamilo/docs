# Glossário

Termos-chave utilizados ao longo deste guia.

| Termo | Definição |
|------|-----------|
| **Avaliação** | Ver **Caderneta de notas** abaixo |
| **Trabalho** | Uma tarefa em que os formandos submetem ficheiros ou texto para revisão e classificação pelo professor. Também conhecido como "publicação do aluno" ou "work". |
| **Arranque automático** | Uma funcionalidade que abre automaticamente uma ferramenta específica quando um formando entra num curso. |
| **Certificado** | Um documento gerado automaticamente quando um formando atinge a pontuação mínima definida na caderneta de notas. |
| **Curso** | Um contentor de conteúdos e ferramentas de aprendizagem. Um curso pode incluir documentos, exercícios, fóruns, percursos de aprendizagem e muito mais. |
| **Tutor de curso** | Um papel de professor específico das sessões. Um tutor de curso gere um curso dentro de uma sessão. Designado "course coach" nas versões do Chamilo anteriores à 3.0. |
| **Quota de disco** | O espaço de armazenamento máximo atribuído a um curso para ficheiros carregados. |
| **Inscrição** | O processo de registar um utilizador num curso ou sessão, concedendo-lhe acesso aos respetivos conteúdos. Também conhecido como "subscrição". |
| **Exercício** | Um questionário ou teste que contém uma ou mais perguntas. Também referido como "teste" em alguns contextos. |
| **Fórum** | Uma ferramenta de discussão com conversas encadeadas organizadas em categorias e tópicos. |
| **Caderneta de notas** | Uma ferramenta que agrega pontuações de exercícios, trabalhos e outras atividades numa classificação unificada para cada formando. |
| **Percurso de aprendizagem** | Uma sequência estruturada de atividades de aprendizagem (documentos, exercícios, ligações) que os formandos seguem numa ordem definida, opcionalmente com pré-requisitos. |
| **LTI** | Learning Tools Interoperability — um padrão que permite incorporar ferramentas de aprendizagem externas no Chamilo. |
| **SCORM** | Sharable Content Object Reference Model — um padrão para pacotes de conteúdos de e-learning. O Chamilo pode importar e reproduzir pacotes SCORM dentro de percursos de aprendizagem. |
| **Sessão** | Uma edição limitada no tempo de um ou mais cursos atribuída a um grupo específico de formandos. As sessões permitem reutilizar o mesmo conteúdo de curso para diferentes coortes. |
| **Tutor de sessão** | Um papel de supervisão que acompanha todos os cursos de uma sessão. Designado "session coach" nas versões do Chamilo anteriores à 3.0. |
| **Competência** | Uma competência que pode ser associada a conquistas da caderneta de notas. Quando um formando obtém um certificado, as competências associadas são validadas. |
| **Inquérito** | Uma ferramenta de questionário para recolher feedback, com vários tipos de perguntas e opções de resposta anónima. |
| **Visibilidade** | Uma definição que controla se uma ferramenta, documento ou atividade está visível para os formandos. Os professores podem sempre ver os itens ocultos. |
