# Descrição do Curso

A ferramenta **Descrição do Curso** <img src="/.gitbook/assets/icons/mdi-apple-safari.svg" alt="Descrição do Curso" data-size="line"> permite redigir uma descrição estruturada, em várias secções, do seu curso — os seus objetivos, metodologia, materiais e muito mais. Ao contrário do banner de texto livre **Introdução ao curso** na [página inicial do curso](README.md#the-course-homepage), visível apenas para os formandos inscritos, a descrição do curso é o que os formandos potenciais veem *antes* de se inscreverem, a partir do catálogo de cursos.

Uma vez inscritos, os formandos podem continuar a consultá-la a partir do interior do curso — se deixar a ferramenta visível para eles, é um local conveniente para verificarem informações práticas, como a estrutura geral do curso ou quem são os professores, sem necessitarem de lhe perguntar diretamente. Os formandos inscritos podem visualizar as secções que escreveu, mas não as podem adicionar, editar ou eliminar.

## Aceder à Ferramenta

Abra a ferramenta **Descrição do Curso** <img src="/.gitbook/assets/icons/mdi-apple-safari.svg" alt="Descrição do Curso" data-size="line"> a partir da grelha de ferramentas da página inicial do curso.

## As Oito Secções

Uma descrição de curso é composta por até oito secções independentes. Cada uma é opcional — preencha apenas as relevantes para o seu curso:

| Secção | Pergunta orientadora |
|---------|-------------------|
| **Descrição** | Qual é o objetivo do curso? Existem pré-requisitos? Como se relaciona esta formação com outros cursos? |
| **Objetivos** | Quais devem ser os resultados finais quando o formando concluir o curso? Quais são as atividades realizadas durante o curso? |
| **Tópicos** | Como progride o curso? Onde deve o formando ter especial cuidado? Existem problemas identificáveis na compreensão de diferentes áreas? Quanto tempo se deve dedicar às diferentes áreas do curso? |
| **Metodologia** | Que métodos e atividades ajudam a alcançar os objetivos do curso? Qual seria o calendário? |
| **Material do curso** | Existe um livro do curso, uma coleção de artigos, uma bibliografia, uma lista de ligações na internet? |
| **Recursos** | Considere os cursos, tutores, um serviço de apoio técnico, professores e/ou materiais disponíveis. |
| **Avaliação** | Como serão avaliados os formandos? Existem estratégias a desenvolver para dominar o tópico? |
| **Outro** | Qualquer coisa que não se enquadre nas categorias acima. Pode adicionar tantas secções **Outro** quantas necessitar, cada uma com o seu próprio título personalizado. |

## Adicionar uma Secção

1. Na barra de ferramentas da ferramenta, clique no ícone do tipo de secção que pretende redigir
2. O Chamilo apresenta uma caixa de **Ajuda** com a pergunta orientadora dessa secção — utilize-a para decidir o que escrever
3. Escreva o conteúdo no editor de texto rico (suporta formatação, imagens, ligações, vídeo incorporado e outro conteúdo rico). Se a sua plataforma o tiver ativado, também pode redigir várias versões linguísticas da mesma secção e fazer com que cada formando veja automaticamente apenas a sua — consulte [Conteúdo Multilíngue](../adding-content/multi-language-content.md).
4. Guardar

Cada secção que adicionar aparece como o seu próprio cartão na ferramenta. Utilize os ícones **Editar** <img src="/.gitbook/assets/icons/mdi-pencil.svg" alt="Editar" data-size="line"> e **Eliminar** <img src="/.gitbook/assets/icons/mdi-delete.svg" alt="Eliminar" data-size="line"> num cartão para a atualizar ou remover mais tarde.

## Ligação ao Catálogo de Cursos

Esta é a principal razão para preencher uma descrição de curso: alimenta diretamente o catálogo **Explorar mais cursos** que visitantes e formandos potenciais consultam.

* Um curso **sem** secções de descrição preenchidas aparece como um cartão simples no catálogo.
* Um curso com **pelo menos uma** secção de descrição torna-se clicável — clicar na sua imagem, título ou botão de informação abre uma janela detalhada que lista todas as secções que escreveu, na mesma ordem apresentada acima.

Isto dá aos formandos potenciais uma base real para decidirem se se inscrevem, em vez de apenas um título e uma miniatura.

> A disponibilidade desta janela depende de uma definição ao nível da plataforma. Se as suas descrições não aparecerem aos formandos potenciais no catálogo, peça ao administrador para verificar a definição **Mostrar Descrições dos Cursos** (`show_courses_descriptions_in_catalog`) em **Administração > Definições de configuração > Catálogo de Cursos**.

## Dicas

* **Dê prioridade às secções Descrição e Objetivos** — são as que a maioria dos formandos potenciais lê primeiro ao decidir se se inscreve.
* **Mantenha-a atualizada** — atualize a descrição do curso sempre que o conteúdo do curso mudar significativamente, para que o catálogo reflita sempre o que os formandos irão efetivamente obter.
* **Use conteúdo rico com parcimónia** — imagens e formatação ajudam a legibilidade, mas uma janela longa e sobrecarregada pode ser mais difícil de percorrer do que alguns parágrafos claros.
