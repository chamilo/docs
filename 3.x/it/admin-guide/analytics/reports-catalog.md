# Catalogo dei report

Il Catalogo dei report non è un report in sé: è un elenco di tutti i report registrati sulla piattaforma, utile per capire cosa è disponibile e chi può visualizzarlo.

## Accesso al Catalogo dei report

Dal pannello di amministrazione, fare clic su **Analytics > Reports catalog**.

## Cosa mostra

* **Elenco dei report** — Titolo, descrizione e URL canonico e legacy di ogni report registrato
* **Matrice dei ruoli** — Una vista che indica quali ruoli (Portal Administrator, Global Administrator, Session Administrator, Teacher, Human Resources Manager, Student Boss...) possono accedere a ciascun report
* **Categorie di autorizzazione** — I gruppi di autorizzazioni in cui sono organizzati i report (ad esempio `reports.platform`, `reports.learning_analytics`, `reports.export`, `reports.security`)

Utilizzare questa pagina quando si cerca di capire dove si trova un report specifico, o se un determinato ruolo (ad esempio un Human Resources Manager) vi ha accesso, senza dover controllare ogni report singolarmente.
