# Plugin

I plugin estendono le funzionalità di Chamilo senza modificare il codice del nucleo. Chamilo 3.0 include oltre 50 plugin che possono essere attivati secondo necessità.

## Il blocco Plugin

Anche la dashboard di amministrazione dispone di un proprio blocco **Plugin**, distinto dalla gestione generale dei plugin trattata in questo capitolo. Non elenca tutti i plugin installati — solo quelli la cui configurazione dichiara che devono comparire nella regione del menu di amministrazione, fornendo a ciascuno di essi una scorciatoia diretta alla propria pagina di amministrazione proprio sulla dashboard.

![Il blocco Plugin sulla dashboard di amministrazione, con l'elenco delle scorciatoie ai plugin installati configurati per comparire nel menu di amministrazione](/.gitbook/assets/admin-plugins-block.png)

Se un plugin che hai attivato non compare qui, è un comportamento previsto — significa che quel particolare plugin non si è dichiarato per la regione del menu di amministrazione, non che qualcosa non funzioni. Consulta [Gestione dei plugin](managing-plugins.md) per l'elenco completo dei plugin installati, indipendentemente dal fatto che compaiano o meno sulla dashboard.
