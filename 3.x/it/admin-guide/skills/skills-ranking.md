# Classifica delle competenze

La classifica delle competenze è una classifica degli utenti ordinati in base al numero di competenze acquisite.

## Accesso alla classifica delle competenze

Dal pannello di amministrazione, fare clic su **Skills > Skills ranking**.

## Cosa mostra

Per ogni utente attivo, la classifica mostra:

* **Skills acquired** — Conteggio totale delle competenze rilasciate, utilizzato per ordinare la classifica (dal più alto al più basso)
* **Currently learning** — Il numero di competenze collegate, tramite il gradebook, ai corsi in cui l'utente è attualmente iscritto (direttamente o tramite una sessione)

Utilizzare questa pagina per individuare a colpo d'occhio i discenti più meritevoli, o per valutare l'attività complessiva di acquisizione delle competenze sulla piattaforma.
