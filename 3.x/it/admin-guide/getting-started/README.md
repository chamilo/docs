# Per iniziare

Questa sezione presenta l'interfaccia di amministrazione di Chamilo 3.0 e aiuta a orientarsi.

## Chi è un amministratore?

Chamilo prevede diversi livelli di ruoli amministrativi:

| Ruolo | Accesso |
|------|--------|
| **Administrator** | Accesso completo a tutte le funzionalità di amministrazione della piattaforma. Noto anche come **Portal Administrator** |
| **Global Administrator** | Come il Portal Administrator, con accesso a tutti gli URL di accesso in una configurazione multi-URL (multi-tenant) |
| **Sessions Administrator** | Può gestire le sessioni, iscrivere gli utenti alle sessioni e accedere alle impostazioni relative alle sessioni |
| **Human Resources Manager** | Può visualizzare i progressi degli studenti e i dati di tracciamento per gli utenti assegnati |
| **Questions Manager** | Più un curatore di contenuti che un amministratore: i questions manager hanno accesso a una banca domande globale per verificare la qualità delle domande |

Questa guida si concentra principalmente sul ruolo di **Portal Administrator**, che dispone dell'accesso più ampio.

## Accesso

Gli amministratori accedono tramite la stessa pagina di login di tutti gli altri utenti. Dopo aver inserito le credenziali, si viene reindirizzati (in assenza di altre configurazioni) alla pagina **Administration**. Una differenza notevole rispetto agli altri ruoli utente è la sezione **Administration** nella barra laterale (non visibile agli altri ruoli).
