# Multi-URL

La funzionalità multi-URL di Chamilo (detta anche multi-tenant) consente di gestire più portali virtuali da una singola installazione di Chamilo. Ogni portale ha il proprio URL, branding, utenti, corsi e impostazioni, ma tutti condividono lo stesso database e lo stesso codice.
