# Categorie di sessioni

Le categorie di sessioni aiutano a organizzare le sessioni, soprattutto quando ne sono attive molte contemporaneamente.

## Creazione di una categoria

1. Dal pannello di amministrazione, accedere a **Session categories**
2. Fare clic su **Add a category**
3. Inserire un **name** e, facoltativamente, le date di inizio/fine
4. Salvare

## Casi d'uso

* **Per programma** — "Leadership Development", "Technical Training", "Onboarding"
* **Per periodo** — "Q1 2026", "Spring Semester", "July Batch"
* **Per dipartimento** — "Engineering", "Sales", "Human Resources"

## Gestione delle categorie

* **Edit** — Modificare il nome o le date della categoria
* **Assign sessions** — Durante la creazione o la modifica di una sessione, selezionarne la categoria
* **Delete** — Rimuovere una categoria (le sessioni della categoria diventano non categorizzate)
