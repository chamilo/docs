# Collegamenti Chamilo.org

Il blocco **Chamilo.org** è un elenco statico di collegamenti in uscita verso le risorse ufficiali di Chamilo — nient’altro. Non invia dati da nessuna parte; ogni collegamento apre un sito Chamilo esterno oppure una pagina di documentazione locale inclusa nella vostra installazione.

## Contenuto del blocco

| Collegamento | Destinazione |
|------|-------------|
| Homepage di Chamilo | `chamilo.org` |
| Guide utente | `docs.chamilo.org` |
| Forum di Chamilo | GitHub Discussions per chamilo-lms |
| Guida all’installazione | Locale, `/documentation/installation_guide.html` |
| Modifiche nell’ultima versione | Locale, `/documentation/changelog.html` |
| Elenco dei contributori | Locale, `/documentation/credits.html` |
| Guida alla sicurezza | Locale, `/documentation/security.html` |
| Guida all’ottimizzazione | Locale, `/documentation/optimization.html` |
| Fornitori ufficiali di servizi Chamilo | `chamilo.org/providers` |

I collegamenti «locali» puntano ai file di documentazione inclusi nella vostra installazione di Chamilo, quindi vengono caricati dal vostro server, non da chamilo.org.

## Scopo

Questo blocco esiste unicamente per comodità — accesso rapido alla documentazione ufficiale del progetto, allo spazio di discussione della community e all’elenco dei fornitori di servizi verificati, senza doverli cercare.
