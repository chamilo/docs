# Glossario

Termini chiave utilizzati in questa guida.

| Termine | Definizione |
|------|-----------|
| **Assessment** | Vedere **Gradebook** di seguito |
| **Assignment** | Un compito in cui i discenti inviano file o testo per la revisione e la valutazione da parte del docente. Conosciuto anche come "student publication" o "work". |
| **Auto-launch** | Una funzionalità che apre automaticamente uno strumento specifico quando un discente entra in un corso. |
| **Certificate** | Un documento generato automaticamente quando un discente raggiunge il punteggio minimo definito nel gradebook. |
| **Course** | Un contenitore per contenuti didattici e strumenti. Un corso può includere documenti, esercizi, forum, learning path e altro. |
| **Course tutor** | Un ruolo docente specifico delle session. Un course tutor gestisce un corso all'interno di una session. Chiamato "course coach" nelle versioni di Chamilo precedenti alla 3.0. |
| **Disk quota** | Lo spazio di archiviazione massimo assegnato a un corso per i file caricati. |
| **Enrollment** | Il processo di registrazione di un utente in un corso o in una session, che gli dà accesso ai relativi contenuti. Conosciuto anche come "subscription". |
| **Exercise** | Un quiz o un test contenente una o più domande. In alcuni contesti indicato anche come "test". |
| **Forum** | Uno strumento di discussione con conversazioni in thread organizzate in categorie e argomenti. |
| **Gradebook** | Uno strumento che aggrega i punteggi di esercizi, assignment e altre attività in un voto unificato per ciascun discente. |
| **Learning path** | Una sequenza strutturata di attività di apprendimento (documenti, esercizi, collegamenti) che i discenti seguono in un ordine definito, eventualmente con prerequisiti. |
| **LTI** | Learning Tools Interoperability — uno standard che consente di incorporare strumenti di apprendimento esterni in Chamilo. |
| **SCORM** | Sharable Content Object Reference Model — uno standard per i pacchetti di contenuti e-learning. Chamilo può importare e riprodurre pacchetti SCORM all'interno dei learning path. |
| **Session** | Un'edizione a tempo determinato di uno o più corsi assegnata a un gruppo specifico di discenti. Le session consentono di riutilizzare gli stessi contenuti del corso per coorti diverse. |
| **Session tutor** | Un ruolo di supervisione che sovrintende a tutti i corsi all'interno di una session. Chiamato "session coach" nelle versioni di Chamilo precedenti alla 3.0. |
| **Skill** | Una competenza che può essere collegata ai risultati del gradebook. Quando un discente ottiene un certificate, le skill associate vengono convalidate. |
| **Survey** | Uno strumento questionario per raccogliere feedback, con vari tipi di domande e opzioni di risposta anonima. |
| **Visibility** | Un'impostazione che controlla se uno strumento, un documento o un'attività è visibile ai discenti. I docenti possono sempre vedere gli elementi nascosti. |
