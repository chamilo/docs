# Aggiungere contenuti

Questa sezione descrive gli strumenti che si utilizzano per aggiungere contenuti didattici al corso. Chamilo offre diversi modi per erogare materiale agli studenti:

* **[Documenti](documents.md)** — Caricare file, creare pagine web e organizzare la libreria dei contenuti
* **[Collegamenti](links.md)** — Condividere URL di risorse esterne, organizzati per categoria
* **[Percorsi formativi](learning-paths.md)** — Costruire sequenze strutturate di contenuti con prerequisiti e tracciamento dei progressi
* **[Glossario](glossary.md)** — Definire termini chiave a cui gli studenti possono fare riferimento durante il corso
* **[Annunci](announcements.md)** — Inviare messaggi e aggiornamenti agli studenti iscritti
* **[Contenuti multilingue](multi-language-content.md)** — Redigere più versioni linguistiche dello stesso contenuto e far visualizzare a ciascun studente solo la propria

Ogni strumento è accessibile dalla griglia degli strumenti nella homepage del corso. Fare clic sull'icona dello strumento per aprirlo.
