# Importazione H5P

Importazione H5P <img src="/.gitbook/assets/icons/mdi-puzzle.svg" alt="Importazione H5P" data-size="line"> consente di portare nel corso i pacchetti di contenuti interattivi standard `.h5p` (video interattivi, quiz, presentazioni e altri tipi di contenuto H5P), con i tentativi e i progressi degli studenti tracciati in modo analogo a un test di Chamilo.

## Accesso allo strumento

Una volta abilitato, sulla homepage del corso compare uno strumento **Importazione H5P**, che mostra una tabella dei pacchetti H5P del corso con titolo, descrizione e quante volte ciascuno è stato avviato.

## Aggiunta di contenuti

* Fare clic su **Carica** e scegliere un file `.h5p`, con un titolo e una descrizione, per aggiungerlo all'elenco del corso
* Da un **Percorso formativo**, usare la voce H5P del pannello delle risorse per inserire direttamente uno dei pacchetti caricati nel corso come elemento del percorso formativo

## Consigli

* **Progettare i contenuti prima del caricamento** — Non è possibile modificare un pacchetto H5P una volta caricato; correggerlo nello strumento di authoring H5P e ricaricarlo se è necessario apportare una modifica
* **Tutto ciò che è nell'elenco dello strumento è visibile a ogni studente per impostazione predefinita** — Se si desidera controllare la visibilità elemento per elemento, aggiungere i pacchetti tramite un Percorso formativo, dove è possibile gestire individualmente la visibilità di ciascun elemento
* **Si tratta di una funzionalità beta** — Considerarla utilizzabile ma ancora in fase di maturazione e conservare una copia dei file `.h5p` di origine nel caso sia necessario ricaricarli
