# Test to PDF

Test to PDF <img src="/.gitbook/assets/icons/mdi-file-pdf-box.svg" alt="Test to PDF" data-size="line"> esporta le domande di un test del corso in un PDF stampabile — solo domande, solo risposte, o entrambe insieme — utile per una versione cartacea di un test.

## Accesso allo strumento

Una volta abilitato, sulla homepage del corso compare uno strumento **Test to PDF**, che elenca ogni test del corso (o della sessione). Ogni riga offre tre azioni: **Download questions**, **Download answers** e **Download all**.

## Consigli

* **Non tutti i tipi di domanda sono supportati** — Solo un sottoinsieme dei tipi di domanda di Chamilo (scelta multipla, vero/falso e formati chiusi simili) viene esportato in modo corretto; le domande aperte o i tipi più complessi potrebbero non comparire correttamente, o non comparire affatto
* **Controllare l'output prima di stampare un intero lotto** — Esaminare il PDF generato per un test prima di stampare in massa per una sessione d'esame
