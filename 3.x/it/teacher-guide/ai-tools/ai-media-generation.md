# Generazione di media con l'IA

Quando si modifica un documento nello strumento **Documenti**, la funzione di generazione di media con l'IA consente di produrre un'**immagine** o un **video breve** per illustrare un paragrafo — direttamente dall'editor di testo avanzato (WYSIWYG), senza uscire dal documento.

## Requisiti

* Gli assistenti IA sono abilitati a livello di piattaforma
* Almeno un provider di media IA (immagine o video) è configurato dall'amministratore
* La funzione è consentita nel proprio corso (il permesso a livello di corso deve essere abilitato)

## Come generare un'immagine o un video

1. Aprire un documento nello strumento **Documenti** <img src="/.gitbook/assets/icons/mdi-bookshelf.svg" alt="Documenti" data-size="line"> (crearne uno nuovo o modificarne uno esistente)
2. Nell'editor di testo avanzato, posizionare il cursore nel paragrafo che si desidera illustrare o nelle sue vicinanze
3. Aprire la finestra di dialogo **Genera media con l'IA** dalla barra degli strumenti dell'editor
4. Descrivere ciò che si desidera che il media mostri, oppure usare il paragrafo selezionato come prompt
5. Scegliere se generare un'**immagine** o un **video**
6. Fare clic su **Genera** e attendere che l'IA produca il risultato
7. Anteprima del media generato e, se si è soddisfatti, fare clic su **Inserisci** per incorporarlo nel documento

## Consigli

* **Scrivere un prompt chiaro** — Quanto più specifica è la descrizione, tanto più pertinente sarà il risultato. Includere indicazioni di stile (ad es. "diagramma", "illustrazione", "foto realistica") se il provider le supporta
* **Rivedere sempre prima di inserire** — I media generati potrebbero non corrispondere perfettamente all'intento; rigenerare o modificare il prompt se necessario
* **Tenere presente le dimensioni dei file** — Le immagini e i video generati concorrono alla quota di archiviazione del corso. Rimuovere i media inutilizzati dalla libreria del documento se lo spazio è limitato
* **La generazione di video richiede più tempo** — La generazione di video brevi può richiedere significativamente più tempo rispetto alla generazione di immagini; pianificare di conseguenza se si è vicini a una scadenza
