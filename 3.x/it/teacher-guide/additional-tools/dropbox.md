# Dropbox

Il dropbox è uno strumento di scambio file che consente a te e ai tuoi studenti di condividere file tra voi all'interno del corso.

> Per raccogliere i lavori degli studenti da valutare, lo strumento [Compiti](../assessing-learners/assignments.md) è di solito più appropriato, in quanto include funzionalità di valutazione e feedback. Il dropbox è più adatto alla condivisione informale di file.

## Invio di un file

1. Apri lo strumento **Dropbox** dalla homepage del corso
2. Fai clic su **Share a new file**
3. Seleziona il file da caricare
4. Scegli il/i **destinatario/i** — uno o più utenti iscritti o gruppi del corso
5. Invia

## Ricezione dei file

Quando qualcuno ti invia un file, questo compare nella casella di ricezione del dropbox. Puoi:

* **Scaricare** il file
* **Aggiungere un commento** al file (dopo che è stato ricevuto)
* **Spostare** il file in una delle tue categorie
* **Eliminare** il file dalla casella di ricezione

## Organizzazione dei file

Sia i file inviati sia quelli ricevuti possono essere organizzati in **categorie** (cartelle) personalizzate. Usa i controlli delle categorie nella barra degli strumenti del dropbox per creare una categoria, quindi sposta i file al suo interno. Se l'impostazione della piattaforma "allow overwrite" è abilitata, il reinvio di un file con lo stesso nome consente di sovrascrivere la versione precedente.

Puoi anche scaricare in batch i file selezionati come ZIP.

## Come docente

* Puoi inviare file a singoli studenti, a gruppi di studenti o a tutti gli utenti iscritti
* Puoi visualizzare i file inviati a te dagli studenti
* Questo strumento è utile per condividere materiali integrativi, fornire documenti di feedback individuale o ricevere consegne informali
