# Notebook

Il notebook è uno strumento personale di presa di appunti per gli studenti. Ogni studente dispone del proprio notebook privato all'interno del corso.

## Come funziona

Il notebook è uno strumento semplice in cui gli studenti possono:

* **Creare note** — Scrivere e salvare note personali relative ai contenuti del corso
* **Organizzare le note** — Rivedere, modificare ed eliminare le proprie note
* **Mantenere la privacy** — Le note sono visibili solo allo studente che le ha create

## Come docente

Come docente, è importante sapere che:

* Il notebook è uno **strumento personale** — non è possibile vedere le note degli studenti
* È utile come **strumento di riflessione** — incoraggiate gli studenti a prendere appunti durante lo studio
* Le note sono memorizzate all'interno del corso — non sono condivise tra corsi diversi

## Abilitare il Notebook

Lo strumento notebook compare nella homepage del corso se è abilitato. Se non lo vedete, verificate che non sia nascosto (cercate gli strumenti nascosti nella homepage del corso).
