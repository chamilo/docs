# Strumenti aggiuntivi

Oltre agli strumenti principali di contenuti, valutazione e collaborazione, Chamilo offre diversi strumenti aggiuntivi che possono arricchire il vostro corso.

* **[Agenda](agenda.md)** — Pianificate eventi, scadenze e promemoria per il vostro corso
* **[Blocco note](notebook.md)** — Uno strumento personale di presa di appunti per i discenti
* **[Dropbox](dropbox.md)** — Un semplice strumento di scambio file tra voi e i vostri discenti
* **[Portfolio](portfolio.md)** — Consentite ai discenti di costruire e presentare un portfolio del proprio lavoro
* **[Avanzamento del corso](course-progress.md)** — Definite sezioni tematiche e monitorate l'erogazione del corso
