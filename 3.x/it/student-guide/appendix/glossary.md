# Glossario

Termini chiave utilizzati in questa guida.

| Termine | Definizione |
|------|-----------|
| **Assessment** | Vedere **Gradebook** di seguito |
| **Assignment** | Un compito in cui si inviano file o testo affinché il docente li esamini e li valuti. Conosciuto anche come "student publication" o "work". |
| **CAPTCHA** | Una verifica (in genere la digitazione di lettere distorte da un'immagine) usata per confermare che si è una persona reale, mostrata in alcuni moduli di accesso, registrazione e recupero password. |
| **Catalog** | L'elenco pubblico dei corsi (e delle sessioni) che è possibile sfogliare e, in alcuni casi, a cui iscriversi autonomamente. Accessibile tramite **Explore more courses**. |
| **Certificate** | Un documento generato automaticamente quando si raggiunge il punteggio minimo definito nel gradebook di un corso. |
| **Course** | Un contenitore di contenuti e strumenti di apprendimento. Un corso può includere documenti, esercizi, forum, learning path e altro. |
| **Enrollment** | L'essere registrati in un corso o in una sessione, con accesso ai relativi contenuti. Conosciuto anche come "subscription". |
| **Exercise** | Un quiz o una prova contenente una o più domande. In alcuni contesti indicato anche come "test". |
| **Forum** | Uno strumento di discussione con conversazioni a thread organizzate in categorie e argomenti. |
| **Gradebook** | Uno strumento che aggrega i punteggi di esercizi, assignment e altre attività in una valutazione unificata. |
| **Invitation** | Un collegamento monouso inviato da un docente all'indirizzo e-mail, che consente di registrarsi e di essere automaticamente iscritti a un corso, anche se la registrazione generale è chiusa. |
| **Learning path** | Una sequenza strutturata di attività di apprendimento (documenti, esercizi, collegamenti) da seguire in un ordine definito, a volte con prerequisiti. |
| **Self-registration** | La possibilità di creare un proprio account tramite un modulo di registrazione pubblico, se abilitato dall'amministratore della piattaforma. |
| **Session** | Un'edizione a tempo determinato di uno o più corsi assegnata a un gruppo specifico di studenti, ad esempio un periodo o una coorte. |
| **Skill** | Una competenza collegata ai risultati del gradebook. Il conseguimento di un certificate può convalidare le skill associate. |
| **Two-factor authentication (2FA)** | Un passaggio aggiuntivo di accesso che utilizza un codice basato sul tempo da un'app autenticatore, oltre alla password. |
| **Visibility** | Un'impostazione che controlla se uno strumento, un documento o un'attività è mostrato agli studenti. I docenti possono sempre vedere gli elementi nascosti. |
