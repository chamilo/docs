# Account e sicurezza

Il tuo account Chamilo dà accesso ai tuoi corsi, ai tuoi voti e ai tuoi dati personali — vale la pena tenerlo al sicuro. Questa sezione tratta le funzionalità di protezione dell’account che potresti incontrare come studente.

* **[Reimpostare la password](resetting-your-password.md)** — Cosa fare se dimentichi la password o vuoi cambiarla
* **[Autenticazione a due fattori](two-factor-authentication.md)** — Aggiungi un secondo livello di protezione al tuo account, se l’amministratore l’ha abilitata
* **[CAPTCHA](captcha.md)** — Perché potrebbe esserti chiesto di dimostrare di essere umano nei moduli di accesso, registrazione o password dimenticata

Non tutte le funzionalità descritte qui sono necessariamente attive sulla tua piattaforma — gli amministratori possono attivarle o disattivarle singolarmente. Se qualcosa descritto in questa sezione non compare per te, probabilmente non è stato abilitato.
