# Corsi

Una volta ottenuto un account, il passo successivo è accedere a un corso e orientarsi al suo interno.

* **[Iscriversi a un corso](subscribing-to-a-course.md)** — I diversi modi in cui è possibile risultare iscritti a un corso
* **[Orientarsi in un corso](course-tools-overview.md)** — Cosa significa ciascuno strumento nella homepage del corso per te come studente
* **[Seguire un percorso di apprendimento](following-a-learning-path.md)** — Procedere attraverso una sequenza guidata di attività
* **[Sostenere i test](taking-tests.md)** — Cosa aspettarsi quando il docente assegna un quiz o un esame
* **[Consegnare un compito](submitting-an-assignment.md)** — Inviare file o testo per la valutazione
* **[Usare il forum](using-the-forum.md)** — Pubblicare e rispondere nelle discussioni del corso organizzate in thread
* **[Usare lo strumento Chat](using-the-chat-tool.md)** — Messaggistica in tempo reale all'interno di un corso
* **[Chatbot tutor IA](ai-tutor.md)** — Ricevere aiuto da un assistente IA, se la piattaforma lo ha abilitato

Queste pagine presuppongono che tu abbia già un account Chamilo. In caso contrario, consulta [Creare un account](../getting-started/creating-an-account.md).
