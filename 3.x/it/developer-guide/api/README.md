# API

Chamilo 3.0 espone una REST API basata su **API Platform 4**. L'API fornisce accesso programmatico alle risorse della piattaforma ed è la stessa API utilizzata dal frontend Vue.

* **[Autenticazione](authentication.md)** — Autenticazione basata su token JWT
* **[Riferimento degli endpoint](endpoints-reference.md)** — Panoramica delle risorse API disponibili
* **[Azioni personalizzate](custom-actions.md)** — Endpoint specializzati oltre al CRUD standard
* **[Webhook](webhooks.md)** — Notifiche basate su eventi verso sistemi esterni
