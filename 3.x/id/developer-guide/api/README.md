# API

Chamilo 3.0 menyediakan REST API yang dibangun di atas **API Platform 4**. API ini memberikan akses terprogram ke sumber daya platform dan merupakan API yang sama yang digunakan oleh frontend Vue.

* **[Autentikasi](authentication.md)** — Autentikasi berbasis token JWT
* **[Referensi Endpoint](endpoints-reference.md)** — Ikhtisar sumber daya API yang tersedia
* **[Aksi Kustom](custom-actions.md)** — Endpoint khusus di luar CRUD standar
* **[Webhook](webhooks.md)** — Notifikasi berbasis peristiwa ke sistem eksternal
