# Mengikuti Learning Path

**Learning path** memandu Anda melalui rangkaian aktivitas terstruktur — dokumen, tes, tautan, dan lainnya — dalam urutan yang telah ditentukan pengajar. Pada banyak kursus, ini adalah alat utama (atau satu-satunya) yang benar-benar perlu Anda gunakan, karena dapat menggabungkan semua hal lain di dalamnya.

## Membuka Learning Path

Buka alat **Learning paths** <img src="/.gitbook/assets/icons/mdi-map-marker-path.svg" alt="Learning paths" data-size="line"> dari beranda kursus dan klik salah satunya untuk memulai. Jika pengajar mengaktifkan **auto-launch**, learning path mungkin terbuka secara otomatis segera setelah Anda masuk ke kursus.

![Daftar learning path untuk suatu kursus, masing-masing menampilkan progresnya sendiri](/.gitbook/assets/student-learning-paths-list.png)

## Bergerak Melalui Path

Di dalam learning path, Anda akan melihat:

* **Daftar item** (langkah) di sebuah panel, disusun ke dalam bagian yang mungkin dikelompokkan pengajar seperti bab
* **Konten item saat ini** di area utama — dokumen, tes tertanam, tautan, dan sebagainya

Saat Anda menyelesaikan item, item tersebut ditandai dengan tanda centang, dan **bilah progres** menampilkan persentase penyelesaian keseluruhan Anda untuk seluruh path. Jika Anda keluar dan kembali nanti, Anda melanjutkan tepat dari tempat Anda berhenti — tidak ada yang hilang.

## Item Terkunci dan Prasyarat

Beberapa item mungkin tampak **terkunci** hingga Anda memenuhi prasyarat yang ditetapkan pengajar — biasanya menyelesaikan item sebelumnya, atau mencapai skor minimum pada tes sebelumnya di path. Jika Anda tidak dapat membuka suatu langkah, periksa apakah langkah sebelumnya masih belum selesai.

## Tes dan Sertifikat di Dalam Path

Learning path dapat menyertakan tes sebagai salah satu langkahnya — mengerjakannya sama seperti yang dijelaskan di [Mengerjakan Tes](taking-tests.md). Beberapa path diakhiri dengan langkah **sertifikat**: mencapainya (setelah memenuhi persyaratan skor apa pun di sepanjang jalan) memicu sertifikat penyelesaian Anda, jika pengajar telah mengonfigurasinya untuk kursus.

## SCORM dan Konten Impor Lainnya

Beberapa item learning path tidak dibuat langsung di Chamilo, melainkan diimpor sebagai paket **SCORM**, paket **CMI5/xAPI**, atau dibuat dengan plugin C-Studio. Secara umum, item ini tampak dan berperilaku seperti konten interaktif lainnya — Chamilo melacak progres dan skor Anda melaluinya dengan cara yang sama, meskipun konten itu sendiri dibuat di tempat lain.

## Tips

* **Gunakan bilah progres** untuk memperkirakan seberapa banyak path yang tersisa.
* **Jangan khawatir kehilangan posisi Anda** — Chamilo mengingat persis di mana Anda berada dalam suatu path antar sesi.
* **Langkah terkunci biasanya berarti ada pekerjaan yang belum selesai lebih awal di path** — kembali dan periksa daripada menganggap akses ditolak karena kesalahan.
