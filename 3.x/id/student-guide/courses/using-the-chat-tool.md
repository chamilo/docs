# Menggunakan Alat Chat

Beberapa kursus menyertakan alat **Chat** — pesan teks waktu nyata yang terikat pada kursus tertentu, berguna untuk pertukaran cepat atau tanya jawab langsung saat pengajar sedang ada.

## Mengirim Pesan

Buka alat **Chat** <img src="../../.gitbook/assets/icons/mdi-chat-processing.svg" alt="Chat" data-size="line"> dari beranda kursus. Anda akan melihat daftar **Users** berisi semua orang yang sedang daring di kursus, masing-masing dengan tombol **Chat** sendiri, plus tab **All** untuk seluruh kelompok:

![Alat Chat kursus, menampilkan daftar pengguna daring dan kotak penyusunan pesan](../../.gitbook/assets/student-course-chat.png)

Pilih seseorang (atau **All**) dan ketik pesan Anda di kotak di bagian bawah. Tekan **Enter** untuk mengirim, atau **Shift+Enter** untuk memulai baris baru tanpa mengirim. Opsi **Preview** memungkinkan Anda memeriksa format sebelum mengirim, dan **Reset** menghapus apa yang telah Anda ketik.

## Jika Chat Dibatasi untuk Tutor

Administrator Anda dapat membatasi chat kursus sehingga hanya pengajar Anda (atau tutor kursus lainnya) yang dapat mengirim — dalam kasus itu, semua orang lain dapat membaca tetapi tidak berpartisipasi secara langsung. Jika Anda menemukan bahwa Anda tidak dapat mengirim pesan di chat suatu kursus, pengaturan ini adalah alasan yang paling mungkin, bukan sebuah bug.

## Jangan Bingung Dengan

Chamilo memiliki tiga fitur berbeda yang semuanya melibatkan pesan, dan mudah untuk mencampuradukkannya:

* **Alat Chat kursus ini** — waktu nyata, terikat pada satu kursus tertentu, hanya dapat diakses dari beranda kursus tersebut.
* **[Kotak Masuk](../inbox.md)** — pesan pribadi, asinkron dengan siapa pun di platform, tidak terkait dengan kursus tertentu.
* **Panel chat mengambang** (bagian bawah layar, tersedia hampir di mana-mana) — digunakan untuk pesan langsung dan untuk [AI Tutor](ai-tutor.md), independen dari alat kursus ini.

Jika Anda mencari salah satu dari dua yang lain, lihat halaman masing-masing.

## Tips

* **Gunakan untuk pertukaran langsung, pada saat itu juga** — untuk apa pun yang ingin Anda temukan lagi nanti, gunakan [Forum](using-the-forum.md) sebagai gantinya.
* **Periksa apakah sesi chat langsung dijadwalkan** — pengajar terkadang mengumumkan waktu tertentu mereka akan tersedia di chat kursus, sering melalui Agenda.
* **Jika kursus Anda memiliki konferensi video yang disiapkan**, pengajar Anda mungkin lebih memilih itu untuk sesi langsung daripada chat teks.
