# Akun dan Keamanan

Akun Chamilo Anda memberikan akses ke kursus, nilai, dan data pribadi Anda — layak untuk tetap dijaga keamanannya. Bagian ini membahas fitur perlindungan akun yang mungkin Anda temui sebagai peserta didik.

* **[Mengatur Ulang Kata Sandi Anda](resetting-your-password.md)** — Apa yang harus dilakukan jika Anda lupa kata sandi, atau ingin mengubahnya
* **[Autentikasi Dua Faktor](two-factor-authentication.md)** — Tambahkan lapisan perlindungan kedua pada akun Anda, jika administrator Anda telah mengaktifkannya
* **[CAPTCHA](captcha.md)** — Mengapa Anda mungkin diminta membuktikan bahwa Anda manusia pada formulir masuk, pendaftaran, atau lupa kata sandi

Tidak setiap fitur yang dijelaskan di sini tentu aktif pada platform Anda — administrator dapat mengaktifkan atau menonaktifkan masing-masing fitur. Jika sesuatu yang dijelaskan di bagian ini tidak muncul bagi Anda, kemungkinan fitur tersebut belum diaktifkan.
