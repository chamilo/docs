# Menambahkan Konten

Bagian ini membahas alat yang Anda gunakan untuk menambahkan konten pembelajaran ke kursus Anda. Chamilo menyediakan beberapa cara untuk menyampaikan materi kepada peserta didik Anda:

* **[Dokumen](documents.md)** — Unggah berkas, buat halaman web, dan atur pustaka konten Anda
* **[Tautan](links.md)** — Bagikan URL ke sumber daya eksternal, yang diorganisasi menurut kategori
* **[Learning Paths](learning-paths.md)** — Bangun urutan konten yang terstruktur dengan prasyarat dan pelacakan kemajuan
* **[Glosarium](glossary.md)** — Definisikan istilah-istilah kunci yang dapat dirujuk peserta didik sepanjang kursus
* **[Pengumuman](announcements.md)** — Kirim pesan dan pembaruan kepada peserta didik yang terdaftar
* **[Konten Multi-Bahasa](multi-language-content.md)** — Tulis beberapa versi bahasa dari konten yang sama dan biarkan setiap peserta didik hanya melihat bahasanya sendiri

Setiap alat dapat diakses dari kisi alat di beranda kursus. Klik ikon alat untuk membukanya.
