# Glosarium

Istilah-istilah kunci yang digunakan di seluruh panduan ini.

| Istilah | Definisi |
|------|-----------|
| **Assessment** | Lihat **Gradebook** di bawah |
| **Assignment** | Tugas di mana peserta didik mengirimkan berkas atau teks untuk ditinjau dan dinilai oleh pengajar. Juga dikenal sebagai "student publication" atau "work". |
| **Auto-launch** | Fitur yang secara otomatis membuka alat tertentu ketika peserta didik memasuki suatu kursus. |
| **Certificate** | Dokumen yang dihasilkan secara otomatis ketika peserta didik memenuhi skor minimum yang ditetapkan dalam gradebook. |
| **Course** | Wadah untuk konten pembelajaran dan alat. Suatu kursus dapat mencakup dokumen, latihan, forum, learning path, dan lainnya. |
| **Course tutor** | Peran pengajar yang khusus untuk sesi. Course tutor mengelola satu kursus dalam suatu sesi. Disebut "course coach" pada versi Chamilo sebelum 3.0. |
| **Disk quota** | Ruang penyimpanan maksimum yang dialokasikan untuk suatu kursus bagi berkas yang diunggah. |
| **Enrollment** | Proses mendaftarkan pengguna ke dalam suatu kursus atau sesi, sehingga mereka memperoleh akses ke kontennya. Juga dikenal sebagai "subscription". |
| **Exercise** | Kuis atau tes yang berisi satu atau lebih pertanyaan. Juga disebut "test" dalam beberapa konteks. |
| **Forum** | Alat diskusi dengan percakapan berantai yang diorganisasi ke dalam kategori dan topik. |
| **Gradebook** | Alat yang menggabungkan skor dari latihan, tugas, dan aktivitas lain menjadi nilai terpadu untuk setiap peserta didik. |
| **Learning path** | Urutan terstruktur aktivitas pembelajaran (dokumen, latihan, tautan) yang diikuti peserta didik dalam urutan yang ditentukan, secara opsional dengan prasyarat. |
| **LTI** | Learning Tools Interoperability — standar yang memungkinkan alat pembelajaran eksternal disematkan di dalam Chamilo. |
| **SCORM** | Sharable Content Object Reference Model — standar untuk paket konten e-learning. Chamilo dapat mengimpor dan memutar paket SCORM di dalam learning path. |
| **Session** | Edisi terbatas waktu dari satu atau lebih kursus yang ditetapkan untuk kelompok peserta didik tertentu. Sesi memungkinkan penggunaan ulang konten kursus yang sama untuk kohor yang berbeda. |
| **Session tutor** | Peran pengawasan yang mengawasi semua kursus dalam suatu sesi. Disebut "session coach" pada versi Chamilo sebelum 3.0. |
| **Skill** | Kompetensi yang dapat dikaitkan dengan pencapaian gradebook. Ketika peserta didik memperoleh sertifikat, skill terkait divalidasi. |
| **Survey** | Alat kuesioner untuk mengumpulkan umpan balik, dengan berbagai jenis pertanyaan dan opsi respons anonim. |
| **Visibility** | Pengaturan yang mengontrol apakah suatu alat, dokumen, atau aktivitas terlihat oleh peserta didik. Pengajar selalu dapat melihat item yang tersembunyi. |
