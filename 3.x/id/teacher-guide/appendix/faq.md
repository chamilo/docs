# FAQ

## Pertanyaan Umum

**Bagaimana cara mengakses kursus saya?**

Klik **My courses** di bilah sisi, lalu klik kursus yang ingin Anda buka. Jika kursus Anda merupakan bagian dari sesi, klik **My sessions** terlebih dahulu, lalu pilih sesi dan kursus.

**Dapatkah peserta didik mengakses kursus dari telepon seluler?**

Ya. Chamilo 3.0 memiliki antarmuka responsif yang menyesuaikan dengan semua ukuran layar. Peserta didik dapat menggunakan peramban web modern apa pun di telepon, tablet, atau komputer.

**Peramban apa yang didukung?**

Chamilo 3.0 berfungsi dengan semua peramban modern utama: Chrome, Firefox, Safari, dan Edge. Untuk pengalaman terbaik, gunakan versi terbaru peramban Anda.

## Konten dan Kursus

**Bagaimana cara membuat cadangan kursus saya?**

Buka alat **Maintenance** di kursus Anda (dapat diakses dari menu pengaturan di beranda kursus). Anda akan menemukan opsi untuk mengekspor konten kursus.

**Dapatkah saya menyalin konten dari satu kursus ke kursus lain?**

Ya. Gunakan fitur impor/ekspor kursus di alat Maintenance untuk menyalin konten antar kursus. Anda perlu membuat kursus *tujuan* kosong terlebih dahulu.

**Format berkas apa yang dapat saya unggah?**

Chamilo mendukung sebagian besar format berkas umum: PDF, dokumen Word, presentasi PowerPoint, gambar (PNG, JPG, SVG, GIF), berkas audio, berkas video, dan banyak lagi. Administrator Anda mungkin membatasi jenis berkas tertentu karena alasan keamanan.

**Berapa ukuran unggah berkas maksimum?**

Hal ini bergantung pada konfigurasi server Anda. Administrator Anda menetapkan batas unggah. Jika Anda menemui batas, hubungi administrator Anda.

## Penilaian

**Dapatkah latihan dinilai secara otomatis?**

Ya. Sebagian besar jenis soal (pilihan ganda, benar/salah, isian, pencocokan) dinilai secara otomatis. Soal terbuka memerlukan penilaian manual, atau Anda dapat menggunakan penilaian berbantuan AI jika dikonfigurasi.

**Dapatkah saya menetapkan batas waktu pada latihan?**

Ya. Saat membuat atau mengedit latihan, Anda dapat menetapkan batas waktu dalam menit. Peserta didik akan melihat penghitung mundur.

**Dapatkah peserta didik mengulang latihan?**

Ya. Anda mengontrol jumlah percobaan yang diizinkan di pengaturan latihan. Anda dapat mengizinkan percobaan tanpa batas atau menetapkan maksimum tertentu, tetapi maksimum ini berlaku untuk semua pengguna di kursus Anda (Anda dapat *membebaskan* percobaan baru dengan menghapus yang sebelumnya, tetapi ini tidak disarankan karena menghasilkan peluang yang tidak setara antar pengguna dan tercatat untuk audit di tingkat platform).

## Masalah Teknis

**Saya tidak dapat melihat suatu alat di beranda kursus. Di mana alat itu?**

Beberapa alat mungkin tersembunyi. Sebagai pengajar, Anda dapat menampilkan alat tersembunyi dengan mencari alat yang memiliki ikon mata dicoret. Jika Anda sama sekali tidak dapat menemukan alat tertentu, administrator platform mungkin telah menonaktifkannya di tingkat platform.

**Peserta didik saya mengatakan mereka tidak dapat mengakses kursus.**

Periksa pengaturan visibilitas kursus (Course Settings > Course Visibility). Jika diatur ke "Registered only," peserta didik harus didaftarkan secara eksplisit. Pastikan juga mereka memiliki akun aktif di platform.
