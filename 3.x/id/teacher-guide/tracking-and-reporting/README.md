# Pelacakan dan Pelaporan

Chamilo melacak aktivitas peserta didik di seluruh platform, memberikan Anda wawasan terperinci tentang bagaimana peserta didik Anda berkembang.

* **[Pelacakan Peserta Didik](learner-tracking.md)** — Pantau aktivitas individu peserta didik: waktu masuk, waktu yang dihabiskan, halaman yang dikunjungi, dan penggunaan alat
* **[Laporan Kursus](course-reports.md)** — Lihat data agregat di seluruh peserta didik dalam suatu kursus
* **[Sertifikat dan Keterampilan](certificates-and-skills.md)** — Berikan sertifikat berdasarkan skor buku nilai dan validasi keterampilan yang diperoleh

## Mengakses Laporan

Dari kursus Anda, klik alat **Pelacakan** <img src="../../.gitbook/assets/icons/mdi-chart-box.svg" alt="Pelacakan" data-size="line"> pada beranda kursus. Anda juga dapat mengakses pelaporan dari tautan **Pelaporan** di bilah sisi untuk ikhtisar lintas kursus.

Pengajar melihat data pelaporan untuk kursus yang mereka ajar. Tutor sesi melihat data di seluruh kursus dalam sesi mereka.
