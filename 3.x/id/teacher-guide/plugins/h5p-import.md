# Impor H5P

Impor H5P <img src="../../.gitbook/assets/icons/mdi-puzzle.svg" alt="Impor H5P" data-size="line"> memungkinkan Anda memasukkan paket konten interaktif `.h5p` standar (video interaktif, kuis, presentasi, dan jenis konten H5P lainnya) ke dalam kursus, dengan percobaan dan kemajuan peserta didik dilacak serupa dengan tes Chamilo.

## Mengakses Alat

Setelah diaktifkan, alat **Impor H5P** muncul di beranda kursus Anda, menampilkan tabel paket H5P kursus beserta judul, deskripsi, dan berapa kali masing-masing telah diluncurkan.

## Menambahkan Konten

* Klik **Unggah** dan pilih berkas `.h5p`, beserta judul dan deskripsi, untuk menambahkannya ke daftar kursus
* Dari **Learning Path**, gunakan entri H5P pada panel sumber daya untuk menyisipkan salah satu paket yang telah diunggah ke kursus secara langsung sebagai item learning path

## Tips

* **Rancang konten sebelum mengunggah** — Anda tidak dapat mengedit paket H5P setelah diunggah; perbaiki di alat authoring H5P Anda dan unggah ulang jika perlu membuat perubahan
* **Semua item di daftar alat terlihat oleh setiap siswa secara default** — Jika Anda ingin mengontrol visibilitas per item, tambahkan paket melalui Learning Path, di mana Anda dapat mengelola visibilitas setiap item secara individual
* **Ini adalah fitur beta** — Perlakukan sebagai fitur yang dapat digunakan tetapi masih berkembang, dan simpan salinan berkas sumber `.h5p` Anda jika perlu mengunggah ulang
