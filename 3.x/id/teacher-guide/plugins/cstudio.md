# Editor Konten C-Studio

C-Studio <img src="/.gitbook/assets/icons/mdi-format-paint.svg" alt="C-Studio" data-size="line"> adalah editor konten visual seret-dan-lepas untuk Learning Path. Editor ini memungkinkan Anda membangun halaman interaktif — blok teks, kuis, aktivitas seret-dan-lepas, isian rumpang, gambar hotspot, tabel, audio, dan video — tanpa menulis HTML sama sekali, lalu mengekspor hasilnya sebagai paket SCORM.

## Mengakses Editor

Setelah diaktifkan, C-Studio muncul sebagai jenis konten tambahan saat Anda menambahkan item baru ke **Learning Path**. Memilihnya akan membuka editor visual, bukan formulir konten biasa Chamilo.

## Apa yang Dapat Anda Lakukan

* Merancang halaman dengan blok seret-dan-lepas serta pemilih tema/warna visual
* Menambahkan elemen interaktif: kuis, seret-dan-lepas, gambar hotspot, tabel, audio, dan video
* Menggunakan bantuan AI bawaan untuk menghasilkan teks, gambar, atau pertanyaan kuis untuk suatu halaman
* Mengontrol perilaku navigasi halaman (menyembunyikan menu, menonaktifkan tombol atas, memulai ulang pada setiap percobaan)
* Mengekspor konten jadi sebagai paket SCORM, atau menerbitkannya langsung sebagai item learning path

## Tips

* **Membersihkan jejak tanpa kehilangan konten** — Tindakan "Clean traces" pada editor menghapus progres peserta didik yang tersimpan untuk halaman C-Studio; tindakan ini tidak menghapus halaman atau kontennya
* **Pratinjau sebelum menerbitkan** — Gunakan pratinjau editor untuk memeriksa bahwa elemen interaktif berperilaku sesuai harapan sebelum dilihat peserta didik
* **Tinjau konten yang dihasilkan AI** — Seperti alat bantu AI lainnya di Chamilo, teks, gambar, dan pertanyaan kuis yang dihasilkan adalah saran untuk ditinjau dan diedit, bukan konten final
