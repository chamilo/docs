# Generator Learning Path

AI Learning Path Generator membantu Anda membuat urutan pembelajaran terstruktur secara otomatis. Anda memberikan topik dan tujuan, lalu AI menghasilkan kerangka learning path dengan bagian-bagian dan item konten yang dapat Anda tinjau dan sesuaikan.

## Mengakses Learning Path Generator

Learning Path Generator tersedia saat membuat learning path baru, dengan syarat:

1. AI helpers diaktifkan di tingkat platform
2. Learning path generator diaktifkan di pengaturan kursus
3. Setidaknya satu penyedia teks AI dikonfigurasi

Cari bagian **AI Generator** di dalam antarmuka pembuatan learning path.

## Cara Menghasilkan Learning Path

![Formulir AI learning path generator dengan kolom untuk topik, tujuan, dan jumlah bagian](/.gitbook/assets/ai-learning-path-generator.png)

1. Buka formulir AI Generator
2. Konfigurasikan parameter:
   * **Topic** — Materi pokok untuk learning path
   * **Number of items** — Berapa banyak halaman konten yang harus dimiliki path
   * **Words count per page** — Perkiraan panjang setiap halaman
   * **Add test after each page** — Jika dicentang, AI juga membuat kuis pilihan ganda singkat setelah setiap halaman (default 2 pertanyaan, dibatasi maksimal 5)
3. Klik **Generate**
4. AI menghasilkan learning path dengan satu item dokumen per halaman dan, secara opsional, satu item kuis setelah masing-masing halaman

## Meninjau dan Menyesuaikan

Learning path yang dihasilkan adalah **titik awal**. Anda sebaiknya:

* **Tinjau struktur** — Periksa bahwa bagian-bagian tersusun dalam urutan yang logis
* **Edit konten** — Ubah teks yang dihasilkan, tambahkan materi Anda sendiri, dan hapus bagian yang tidak relevan
* **Tambahkan sumber daya** — Sisipkan dokumen, latihan, tautan, dan konten lain milik Anda
* **Atur prasyarat** — Konfigurasikan bagian mana yang harus diselesaikan sebelum bagian lain
* **Tambahkan asesmen** — Sertakan latihan pada titik yang tepat untuk memeriksa pemahaman

## Pengungkapan Konten yang Dihasilkan AI

Konten yang dihasilkan AI diberi label dengan pemberitahuan pengungkapan, yang menunjukkan bahwa konten tersebut dibuat menggunakan kecerdasan buatan. Transparansi ini membantu peserta didik memahami asal materi.

## Tips

* **Mulai secara luas, lalu perhalus** — Hasilkan struktur tingkat tinggi terlebih dahulu, lalu tambahkan detail dan sumber daya spesifik secara manual
* **Gunakan untuk perencanaan kursus** — Meskipun Anda tidak menggunakan konten yang dihasilkan secara langsung, struktur yang disarankan AI dapat menjadi alat perencanaan yang berguna
* **Gabungkan dengan pembuatan latihan** — Setelah menghasilkan learning path, gunakan Exercise Generator untuk membuat asesmen bagi setiap bagian
