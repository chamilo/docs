# Notebook

Notebook adalah alat pencatatan pribadi untuk peserta didik. Setiap peserta didik memiliki notebook pribadinya sendiri di dalam kursus.

## Cara Kerjanya

Notebook adalah alat sederhana di mana peserta didik dapat:

* **Membuat catatan** — Menulis dan menyimpan catatan pribadi terkait konten kursus
* **Mengorganisasi catatan** — Meninjau, mengedit, dan menghapus catatan mereka
* **Menjaganya tetap pribadi** — Catatan hanya terlihat oleh peserta didik yang membuatnya

## Sebagai Pengajar

Sebagai pengajar, Anda perlu menyadari bahwa:

* Notebook adalah **alat pribadi** — Anda tidak dapat melihat catatan peserta didik Anda
* Alat ini berguna sebagai **alat refleksi** — dorong peserta didik untuk mencatat sambil belajar
* Catatan disimpan di dalam kursus — catatan tidak dibagikan antar kursus

## Mengaktifkan Notebook

Alat notebook muncul di beranda kursus jika diaktifkan. Jika Anda tidak melihatnya, periksa apakah alat tersebut tidak disembunyikan (cari alat tersembunyi di beranda kursus).
