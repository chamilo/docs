# Kolaborasi dan Komunikasi

Chamilo menyediakan beberapa alat untuk memungkinkan interaksi antara Anda dan peserta didik, serta di antara para peserta didik itu sendiri.

* **[Forum](forums.md)** — Diskusi berantai yang diorganisasi menurut kategori dan topik
* **[Obrolan](chat.md)** — Pesan teks waktu nyata di dalam sebuah kursus
* **[Kelompok](groups.md)** — Membagi peserta didik ke dalam kelompok kerja dengan alat bersama mereka sendiri
* **[Wiki](wiki.md)** — Penyuntingan dokumen secara kolaboratif
* **[Blog](blog.md)** — Blogging bersama di dalam kursus
* **[Konferensi Video](video-conferencing.md)** — Sesi video langsung menggunakan BigBlueButton atau Zoom

Alat-alat ini tersedia dari beranda kursus. Beberapa mungkin tersembunyi secara default — Anda dapat membuatnya terlihat dari kisi alat (lihat [Beranda Kursus](../creating-your-course/course-homepage.md)).
