# Chat

Alat chat menyediakan pesan teks waktu nyata di dalam sebuah kursus. Alat ini berguna untuk komunikasi cepat, sesi tanya jawab langsung, atau diskusi informal.

## Menggunakan Chat

1. Buka alat **Chat** dari beranda kursus
2. Di panel **Users**, pilih pengguna daring tertentu untuk mengirim pesan secara langsung, atau gunakan tab **All** untuk menyapa seluruh kelompok
3. Ketik pesan Anda di kolom teks di bagian bawah lalu tekan **Enter** untuk mengirim (**Shift+Enter** untuk baris baru tanpa mengirim)

Opsi **Preview** memungkinkan Anda memeriksa pemformatan sebelum mengirim, dan **Reset** menghapus draf saat ini.

## Fitur Chat

* **Pesan waktu nyata** — Pesan muncul secara instan bagi penerima
* **Riwayat pesan** — Pesan sebelumnya terlihat saat Anda masuk ke chat
* **Kehadiran pengguna** — Panel Users menampilkan siapa yang sedang daring di kursus
* **Langsung atau kelompok** — Kirim pesan kepada satu peserta didik pada satu waktu, atau siarkan ke semua orang melalui tab **All**

## Sebagai Guru

Sebagai guru kursus, Anda dapat:

* **Memantau diskusi** — Meninjau riwayat chat untuk melacak keterlibatan peserta didik
* **Menemukan arsip chat di Documents** — Alat chat secara otomatis mencerminkan pesan ke berkas HTML di alat Documents, diorganisasikan menurut hari dan menurut cakupan (kursus / sesi / kelompok), sehingga percakapan tetap ada setelah sesi langsung berakhir

Jika pengaturan platform "Restrict course chat to tutors" diaktifkan oleh administrator, hanya tutor yang dapat mengobrol dengan peserta didik; jika tidak, semua orang yang terdaftar di kursus dapat berpartisipasi.

## Tips Menggunakan Chat secara Efektif

* **Jadwalkan sesi chat** — Beritahu peserta didik sebelumnya kapan Anda akan tersedia untuk chat langsung (gunakan alat Agenda)
* **Tetapkan aturan dasar** — Bangun harapan untuk komunikasi yang sopan
* **Gunakan untuk pertanyaan singkat** — Chat paling cocok untuk pertukaran singkat; gunakan Forum untuk diskusi yang lebih panjang dan terstruktur

> Jika platform Anda telah dikonfigurasi konferensi video (BigBlueButton atau Zoom), pertimbangkan untuk menggunakannya untuk sesi langsung di mana suara dan video akan lebih efektif. Lihat [Konferensi Video](video-conferencing.md).
