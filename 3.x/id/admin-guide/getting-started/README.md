# Memulai

Bagian ini memperkenalkan antarmuka administrasi Chamilo 3.0 dan membantu Anda berorientasi.

## Siapa Itu Administrator?

Chamilo memiliki beberapa tingkat peran administratif:

| Role | Access |
|------|--------|
| **Administrator** | Akses penuh ke semua fitur administrasi untuk platform. Juga dikenal sebagai **Portal Administrator** |
| **Global Administrator** | Sama seperti Portal Administrator, dengan akses di semua URL akses dalam pengaturan multi-URL (multi-tenant) |
| **Sessions Administrator** | Dapat mengelola sesi, mendaftarkan pengguna ke sesi, dan mengakses pengaturan terkait sesi |
| **Human Resources Manager** | Dapat melihat kemajuan peserta didik dan data pelacakan untuk pengguna yang ditugaskan |
| **Questions Manager** | Lebih merupakan kurator konten daripada administrator; questions manager memiliki akses ke bank soal global untuk meninjau kualitas soal |

Panduan ini berfokus terutama pada peran **Portal Administrator**, yang memiliki akses paling luas.

## Masuk

Administrator masuk melalui halaman login yang sama dengan semua pengguna lainnya. Setelah memasukkan kredensial Anda, Anda akan diarahkan (jika tidak ada konfigurasi lain) ke halaman **Administration**. Perbedaan yang mencolok dibanding peran pengguna lain adalah bagian **Administration** di bilah sisi (tidak terlihat oleh peran lain).
