# Kategori Sesi

Kategori sesi membantu mengorganisasi sesi Anda, terutama ketika banyak sesi berjalan secara bersamaan.

## Membuat Kategori

1. Dari panel administrasi, buka **Kategori sesi**
2. Klik **Tambah kategori**
3. Masukkan **nama** dan tanggal mulai/akhir opsional
4. Simpan

## Kasus Penggunaan

* **Berdasarkan program** — "Leadership Development", "Technical Training", "Onboarding"
* **Berdasarkan periode** — "Q1 2026", "Spring Semester", "July Batch"
* **Berdasarkan departemen** — "Engineering", "Sales", "Human Resources"

## Mengelola Kategori

* **Edit** — Ubah nama atau tanggal kategori
* **Tetapkan sesi** — Saat membuat atau mengedit sesi, pilih kategorinya
* **Hapus** — Hapus kategori (sesi dalam kategori menjadi tanpa kategori)
