# Plugin

Plugin memperluas fungsionalitas Chamilo tanpa mengubah kode inti. Chamilo 3.0 dilengkapi dengan lebih dari 50 plugin yang dapat diaktifkan sesuai kebutuhan.

## Blok Plugin

Dasbor administrasi juga memiliki blok **Plugin** tersendiri, terpisah dari pengelolaan plugin umum pada bab ini. Blok tersebut tidak menampilkan setiap plugin yang terpasang — hanya plugin yang konfigurasinya menyatakan bahwa plugin tersebut harus muncul di wilayah menu admin, sehingga setiap plugin semacam itu memiliki pintasan langsung ke halaman adminnya sendiri di dasbor.

![Blok Plugin pada dasbor administrasi, yang menampilkan pintasan ke plugin terpasang yang dikonfigurasi agar muncul di menu admin](../../.gitbook/assets/admin-plugins-block.png)

Jika plugin yang telah Anda aktifkan tidak muncul di sini, hal itu wajar — artinya plugin tersebut belum mendeklarasikan dirinya untuk wilayah menu admin, bukan karena ada yang rusak. Lihat [Mengelola Plugin](managing-plugins.md) untuk daftar lengkap plugin yang terpasang, terlepas dari apakah plugin tersebut muncul di dasbor.
