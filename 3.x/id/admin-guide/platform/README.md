# Platform

Blok **Pengelolaan Platform** pada dasbor administrasi mengelompokkan alat konfigurasi dan komunikasi di seluruh portal — mulai dari panel pengaturan lengkap hingga bahasa, pengumuman publik, kalender global, dan sistem Pages yang menyerupai CMS yang membangun bagian konten publik portal Anda.

![Blok Pengelolaan Platform pada dasbor administrasi, yang mencantumkan Configuration settings, Languages, Plugins, Regions, Portal news, Global agenda, Pages, Setting the registration page, Extra fields, Configure multiple access URL, Mail templates, External tools (LTI), Contact form categories, dan System templates](/.gitbook/assets/admin-platform-block.png)

## Mengakses Blok Platform

Dari panel administrasi, blok **Pengelolaan Platform** muncul bersama blok dasbor lainnya. Klik salah satu tautannya untuk membuka alat yang sesuai.

## Isi Blok

* **[Pengaturan Platform](../platform-settings/README.md)** — Panel pengaturan konfigurasi lengkap (portal, kursus, sesi, pengguna, keamanan, dan lainnya). Tautan "Configuration settings" pada blok ini hanyalah titik masuk ke bab terpisah tersebut.
* **[Bahasa](languages.md)** — Pilih bahasa antarmuka mana yang tersedia bagi pengguna, dan tetapkan bahasa default platform
* **[Berita Portal](portal-news.md)** — Pengumuman di seluruh platform (pengumuman sistem), dijadwalkan dan ditargetkan berdasarkan peran
* **[Agenda Global](global-agenda.md)** — Acara kalender di seluruh platform, terlihat oleh setiap pengguna terlepas dari kursus atau sesi
* **[Pages](pages.md)** — Alat menyerupai CMS di balik beranda portal, footer, dan blok konten publik lainnya, termasuk teks pengantar halaman pendaftaran
* **[Alat Platform](platform-tools.md)** — Extra fields, templat surel, kategori formulir kontak, dan beberapa item lebih kecil yang ditampilkan secara bersyarat
* **Configure multiple access URL** — Dibahas di [Access URLs](../multi-url/access-urls.md), di bawah Multi-URL
* **External tools (LTI)** — Dibahas di [LTI 1.3](../integrations/lti.md), di bawah Integrations
