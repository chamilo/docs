# Blok Admin Lainnya

Dasbor administrasi memiliki beberapa blok tambahan yang bukan fitur yang dapat dikonfigurasi, melainkan widget informasional: halaman tautan keluar, pendaftaran pemeriksaan versi, dan dua panel kecil yang menarik konten dari chamilo.org. Bab ini menjelaskan apa masing-masing blok itu, dari mana kontennya berasal, dan — karena beberapa di antaranya memang demikian — apakah ada data yang keluar dari platform Anda.

## Cakupan

* **[Tautan Chamilo.org](chamilo-org-links.md)** — Daftar bookmark ke sumber daya resmi Chamilo; tidak mengirim apa pun
* **[Pemeriksaan Versi](version-check.md)** — Pendaftaran opsional yang melaporkan versi dan penggunaan platform Anda ke chamilo.org, serta memberi tahu Anda jika sudah waktunya memperbarui
* **[Dukungan Profesional](professional-support.md)** — Panel hanya-baca yang menjelaskan penyedia dukungan resmi Chamilo
* **[Berita dari Chamilo](news-from-chamilo.md)** — Umpan hanya-baca berisi pengumuman resmi, termasuk patch keamanan dan rilis baru

Setiap halaman di bawah ini menyatakan secara jelas apa, jika ada, yang dikirim ke chamilo.org, dan mengapa.
