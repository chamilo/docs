# Tautan Chamilo.org

Blok **Chamilo.org** adalah daftar statis tautan keluar ke sumber daya resmi Chamilo — tidak lebih dari itu. Blok ini tidak mengirim data ke mana pun; setiap tautan membuka situs Chamilo eksternal atau halaman dokumentasi lokal yang disertakan dalam instalasi Anda.

## Isi Blok

| Tautan | Tujuan |
|------|-------------|
| Beranda Chamilo | `chamilo.org` |
| Panduan pengguna | `docs.chamilo.org` |
| Forum Chamilo | GitHub Discussions untuk chamilo-lms |
| Panduan instalasi | Lokal, `/documentation/installation_guide.html` |
| Perubahan pada versi terakhir | Lokal, `/documentation/changelog.html` |
| Daftar kontributor | Lokal, `/documentation/credits.html` |
| Panduan keamanan | Lokal, `/documentation/security.html` |
| Panduan pengoptimalan | Lokal, `/documentation/optimization.html` |
| Penyedia layanan resmi Chamilo | `chamilo.org/providers` |

Tautan "lokal" merujuk ke berkas dokumentasi yang dibundel bersama instalasi Chamilo Anda sendiri, sehingga dimuat dari server Anda, bukan dari chamilo.org.

## Tujuan

Blok ini ada semata-mata untuk kenyamanan — akses cepat ke dokumentasi resmi proyek, ruang diskusi komunitas, dan daftar penyedia layanan yang telah ditinjau, tanpa perlu mencarinya.
