# Integrasi

Chamilo terintegrasi dengan beberapa layanan pihak ketiga untuk memperluas fungsionalitasnya.

Sebagian besar diaktifkan melalui plugin. Periksa bagian terkait sedikit lebih jauh dalam panduan ini.

* **[Konferensi Video](video-conferencing.md)** — BigBlueButton dan Zoom
* **[LTI 1.3](lti.md)** — Hubungkan alat pembelajaran eksternal
* **[xAPI](xapi.md)** — Pelacakan pengalaman belajar
* **[OnlyOffice](onlyoffice.md)** — Penyuntingan dokumen kolaboratif
* **[Konfigurasi AI](ai-configuration.md)** — Siapkan penyedia AI untuk fitur bertenaga AI
