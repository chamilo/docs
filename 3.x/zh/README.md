# Chamilo 3.0 文档

欢迎阅读 **Chamilo 3.0** 官方文档。Chamilo 是一款开源电子学习平台。

本文档分为三份指南，分别面向特定读者：

* [**教师指南**](teacher-guide/) — 面向授课教师与培训师：创建课程、添加内容、评估学习者并跟踪进度。
* [**管理指南**](admin-guide/) — 面向平台管理员：安装、配置并管理 Chamilo 平台。
* [**开发者指南**](developer-guide/) — 面向开发者：理解架构、构建插件、使用 API 并为项目做贡献。

## Chamilo 3.0 的新特性

Chamilo 3.0 是一次重大版本发布，界面全面重新设计，并包含众多新功能：

* **现代化界面** — 基于 Vue 3 与 PrimeVue 构建，体验更快速、响应更灵敏
* **AI 驱动工具** — 生成练习、学习路径，并获得 AI 辅助评分
* **REST API** — 基于 API Platform 的完整 REST API，采用 JWT 身份验证
* **新的身份验证选项** — OAuth2（Azure、Keycloak、Facebook）、SCIM 用户配置
* **LTI 1.3** — 无缝连接外部学习工具
* **云存储** — 原生支持 Azure Blob、AWS S3 与 Google Cloud Storage
* **配色主题** — 支持主题，可自定义平台品牌形象
* **OnlyOffice 集成** — 在平台内协作编辑文档
