# 入门指南

本节帮助您熟悉 Chamilo 3.0。您将学习如何登录、浏览主界面以及配置个人资料。

## 登录

要访问 Chamilo，请打开浏览器并前往您所在机构提供的 URL（例如 `https://chamilo.yourschool.edu`）。在登录页面输入用户名和密码，然后点击 **登录**。

如果您的机构使用外部身份验证（例如 Azure、Keycloak 或大学单点登录系统），您可能会在标准登录表单下方看到额外的登录按钮。点击相应按钮，通过机构的身份提供方进行身份验证。

> 如果您忘记了密码，请点击登录页面上的 **忘记密码？** 链接。您将收到一封包含重置说明的电子邮件。

## 初次浏览

登录后，您将看到 Chamilo 首页。界面分为三个主要区域：

![显示系统公告和课程卡片的 Chamilo 首页](../../.gitbook/assets/home-page-teacher.png)

* **顶栏** — 显示平台徽标、您的收件箱（带有未读消息数量徽章）以及用户头像。点击头像可访问个人资料和账户设置。
* **侧边栏** — 左侧导航面板可让您快速访问课程、学期、日程、社交网络等。点击边缘的切换按钮即可将其折叠。
* **主内容区** — 显示当前页面内容。在首页上，您将看到系统公告和精选课程。

## 您的课程

在侧边栏中点击 **我的课程**，即可查看您作为教师或学生所加入的全部课程。每门课程以卡片形式显示：

![显示带缩略图和快捷操作的课程卡片的“我的课程”页面](../../.gitbook/assets/my-courses-list.png)

* 课程图片或缩略图
* 课程标题
* 快捷操作

如果您的机构使用 **学期**（有时间限制的培训周期），侧边栏中还会出现 **我的学期** 链接，并按当前、已结束和即将开始的学期进行组织。

Chamilo 中的学期是一种在不同时间向不同学习者群体提供同一门课程、而无需复制课程内容的方式。可将学期理解为课程的一次排期版本或同期学员群体。该主题稍后会详细介绍。
