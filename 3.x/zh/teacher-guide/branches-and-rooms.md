# 分支机构与教室

Chamilo 包含一套基于两个概念构建的基础物理位置系统：**分支机构（branches）** 与 **教室（rooms）**。

**分支机构** 表示一个实体场所或校区——例如总部办公室、区域培训中心或大学教学楼。分支机构可以嵌套（一栋楼可包含多个部门，一座城市可包含多栋建筑）。每个分支机构可包含一间或多间 **教室**，用于表示该分支机构内的独立教室或实验室空间。

此功能仍处于早期阶段。目前其主要实际用途是让您为课程附加物理位置标记。

## 为课程指定教室

创建课程时，如果管理员已配置教室，课程创建表单中会出现 **默认教室（Default room）** 字段。请选择该课程实际授课所在的教室。

此信息仅供参考——不会影响课程行为或访问控制。它只是记录课程的实体举办地点，有助于管理员管理教室排期，并查看各课程的教室占用情况。

如果平台尚未配置任何教室，该字段将不会显示。

## 管理员可以做什么

分支机构与教室的管理完全由管理员负责。他们可以：

- 以树状层级创建并组织分支机构
- 向分支机构添加教室，并可选择填写地理位置和 IP 范围数据
- 查看分配到每间教室的课程
- 根据出勤记录查看教室的占用日历

如果您需要创建教室，或需要将课程改到另一间教室，请联系平台管理员。
