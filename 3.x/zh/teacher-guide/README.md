# 教师指南

欢迎使用 Chamilo 3.0 教师指南。本指南面向授课教师、培训师以及所有负责通过 Chamilo 平台创建并交付学习内容的人员。

无论您是在开设第一门在线课程，还是在管理复杂的培训项目，本指南都将逐步介绍作为教师可用的各项功能。

## 您可以在 Chamilo 中做什么

作为 Chamilo 中的教师，您可以：

* **创建并组织课程**，使用灵活的主页和可自定义的工具
* **添加内容** — 上传文档、创建学习路径、构建术语表，并链接到外部资源
* **评估学习者** — 设计多种题型的练习、收集作业、开展调查并管理成绩
* **协作** — 设置论坛、小组作业、wiki、博客以及实时视频会话
* **跟踪进度** — 监控学习者活动、生成报告并颁发证书
* **使用 AI 工具** — 自动生成练习和学习路径，并获得 AI 辅助评分

## 本指南的组织结构

本指南遵循建设与运行课程的自然工作流程：

1. **入门** — 登录、浏览界面并设置个人资料
2. **创建课程** — 新建课程、配置设置并自定义主页
3. **添加内容** — 上传文档、组织学习路径并管理资源
4. **评估学习者** — 构建测验、收集作业、开展调查并设置成绩册
5. **协作与沟通** — 启用论坛、聊天、小组、wiki 和视频会议
6. **跟踪与报告** — 监控学习者进度并生成报告
7. **AI 工具** — 使用 AI 驱动功能生成内容并辅助评分
8. **其他工具** — 日程、笔记本、作品集等
