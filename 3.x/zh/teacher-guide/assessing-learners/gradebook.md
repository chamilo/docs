# 评估

评估（此前称为 *gradebook*）将来自测验、作业及其他计分活动的分数汇总为每位学习者表现的统一视图。它还控制证书的生成。

## 评估如何运作

评估是加权计分系统。您需要定义：

1. **哪些活动**计入成绩（测验、作业、考勤等）
2. **每项活动的权重**（其在最终成绩中所占比重）
3. **最低认证分数**（获得证书的门槛）
4. **每项活动的最低分数** — 成绩册中的每项活动都可以有各自的**最低分数**。学习者若在关键活动上低于该最低分，即使其总体加权总分原本足够高，也可能无法达成目标并获得证书。

活动可分为 2 种类型：
* **课堂活动**（或面授活动），成绩需从其他来源导入
* **在线活动**，从课程中选择，成绩通过在课程中完成该活动获得

Chamilo 根据这些权重计算每位学习者的总成绩。

## 设置评估

1. 从课程主页打开 **评估** <img src="../../.gitbook/assets/icons/mdi-certificate.svg" alt="成绩册" data-size="line"> 工具
2. 您将看到评估概览，初始为空

### 添加活动

1. 点击 **添加在线活动**
2. 选择类型：
   * **测验** — 关联课程中的特定练习
   * **作业** — 关联学生作品文件夹
   * **学习路径** — 关联学习路径完成情况
   * **考勤** — 关联考勤表
   * **论坛主题** — 关联论坛主题（需手动评分）
   * **问卷** — 关联问卷
3. 在所选类型中选择具体活动
4. 为该活动设置 **权重**（例如，期中考试 30%，期末项目 40%）
5. 如适用，设置 **最低分数**
6. 保存

所有活动的权重总和应为 100%。

### 子类别

对于复杂的评分方案，您可以创建 **子类别** 以将相关活动分组：

* **示例**：一个“作业”子类别（权重：30%），其中包含五项独立作业，每项占该子类别的 20%
* 子类别让您以层级方式组织评估，同时保持总体计算简单

## 查看成绩

![显示学习者姓名、活动分数和加权总分的成绩册概览表](../../.gitbook/assets/gradebook-overview.png)

评估以表格显示：

* 每位学习者的姓名
* 每项活动的分数
* 加权总分
* 该学习者是否有资格获得证书

您可以按任意列排序，以便快速识别表现优异或遇到困难的学习者。

### 分数分布图

在表格下方以及 **图形视图** 页面上，评估为每项活动绘制一张柱状图，并为总分再绘制一张。每张图都是柱状图：横轴按从低到高列出您的分数区间，每根柱的高度为该区间内的学习者人数。

**总分** 图还会标出班级平均分。红色圆点落在包含平均分的区间上，图例给出精确百分比。

这些图表仅在已设置分数显示规则时出现。如果您看到消息 *To view graph score rule must be enabled*，请先在评估的计分设置中定义区间。

## 证书

要启用证书生成：

1. 在评估设置中，设置 **最低认证分数**（例如 70%）
2. 当学习者的加权总分达到或超过该门槛（且未在任何单项最低分数上失败）时，即可下载证书
3. 证书由平台管理员配置的模板生成

一旦在根类别上启用 **生成证书**，就会出现 **证书有效期（天）** 字段。保持为 `0` 表示证书永不过期，或设置若干天数，证书将在该天数后过期 — Chamilo 随后可在到期日临近时提醒学习者，方式可以是自动（cron，由管理员配置）或从证书列表中手动操作。

![启用“生成证书”且“证书有效期（天）”字段设为 365 的类别编辑对话框](../../.gitbook/assets/gradebook-certificate-validity-field.png)

更多详情请参见 [证书与技能](../tracking-and-reporting/certificates-and-skills.md#certificate-validity-and-expiry)。

## 关联技能

您可以将 **技能** 与评估关联。当学习者达到完成评估所设定的目标时，可以获得证书、获得技能，或两者兼得。技能会显示在其社交网络空间的个人资料上。这会随时间积累能力记录。

## 导出成绩

点击 **导出** <img src="../../.gitbook/assets/icons/mdi-export.svg" alt="导出" data-size="line"> 按钮，可将成绩下载为电子表格。这适用于：

* 与行政系统共享成绩
* 在 Chamilo 之外进行额外分析
* 保存离线记录

## 提示

* **尽早规划权重** — 在课程开始时确定评分方案，以便学习者了解预期
* **复杂课程使用子类别** — 将作业、测验和参与情况归入清晰的类别
* **设定有意义的及格门槛** — 认证分数应反映实际能力，而不仅仅是参与度
* **定期检查** — 定期查看成绩册，确保所有活动均已正确关联且分数正在被记录
