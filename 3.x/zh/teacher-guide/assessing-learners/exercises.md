# 练习

练习工具（也称为“测验”）可让您创建带有自动评分的测验和考试。Chamilo 支持多种题型，从简单的选择题到交互式热点题。

## 创建练习

1. 从课程主页打开 **练习** <img src="../../.gitbook/assets/icons/mdi-order-bool-ascending-variant.svg" alt="练习" data-size="line"> 工具
2. 点击 **新建练习**
3. 输入 **标题** 以及可选的 **描述**
4. 配置练习设置（见下文）
5. 保存，然后添加题目

## 练习设置

![练习设置面板，包含显示、时间、尝试次数和反馈等选项](../../.gitbook/assets/exercise-settings.png)

### 显示与导航

| 设置 | 选项 | 说明 |
|---------|---------|-------------|
| **题目布局** | 全部显示在一页 / 每页一题 | 一次显示全部题目，或一次只显示一题 |
| **隐藏题目标题** | 是 / 否 | 是否向学习者显示题目标题 |
| **显示上一题按钮** | 是 / 否 | 允许学习者返回上一题 |
| **禁止向后导航** | 是 / 否 | 强制学习者按顺序作答，不得返回 |

### 时间与可用性

| 设置 | 说明 |
|---------|-------------|
| **时限** | 完成练习的最长时间（以分钟计）。学习者会看到倒计时 |
| **开始日期** | 练习对学习者开放的时间 |
| **结束日期** | 练习停止开放的时间 |

### 尝试次数与评分

| 设置 | 说明 |
|---------|-------------|
| **最大尝试次数** | 学习者可参加该练习的次数（0 = 不限次数） |
| **及格百分比** | 及格所需的最低分数（例如 70%）。未达到该阈值的学习者会看到失败提示 |
| **传递负分** | 个别题目的负分是否会使总分低于零 |

### 反馈

| 设置 | 选项 |
|---------|---------|
| **结束后** | 学习者提交后显示结果和正确答案 |
| **即时** | 每题作答后立即显示反馈（适用于学习型练习） |
| **考试模式** | 不显示任何反馈或结果 |

### 结果显示

控制学习者完成练习后看到的内容：

* 显示分数和预期答案
* 仅显示分数
* 显示分数及分类明细
* 显示在其他学习者中的排名
* 仅在最后一次尝试时显示
* 显示雷达图可视化

### 完成提示

* **成功提示** — 学习者及格时显示的自定义文本
* **失败提示** — 学习者未达到及格百分比时显示的自定义文本

### 题目随机化

| 设置 | 说明 |
|---------|-------------|
| **随机题目顺序** | 每次尝试打乱题目顺序 |
| **随机选项** | 打乱每道题内的选项顺序 |
| **按分类随机** | 从每个题目分类中随机抽取题目 |

您还可以配置将分类与随机化相结合的高级选题策略。

## 题型

![练习创建界面中可用题型概览](../../.gitbook/assets/exercise-question-types.png)

Chamilo 提供丰富的题型，分为以下几类：

### 单选

* **多项选择（单答案）** — 学习者从选项列表中选择一个正确答案
* **带图片的单答案** — 同上，但选项以图片形式显示

### 多选

* **多答案** — 学习者选择一个或多个正确答案
* **多答案（下拉菜单）** — 选项以下拉菜单形式呈现
* **判断题** — 一系列陈述，由学习者标记为正确或错误
* **带确信度的判断题** — 判断题并附加置信度，以实现更细致的评分

### 填空

* **填空** — 学习者补全文本中缺失的词语。创建题目时定义空缺处及可接受的答案。

### 匹配

* **匹配** — 学习者将两列中的项目对应连接
* **匹配（可拖放）** — 概念相同，但采用拖放界面
* **可拖放** — 将项目拖到正确位置

### 开放式

* **自由作答（论述）** — 学习者撰写文字回答。需要人工评分（或在已配置时使用 AI 辅助评分）
* **口头表达** — 学习者使用麦克风录制音频回答
* **上传答案** — 学习者上传文件作为答案

### 热点

* **热点** — 学习者点击图像上的特定区域作答
* **热点勾画** — 学习者在图像上勾画区域边界

### 计算题

* **计算答案** — 带公式和容差范围的数值题。适用于数学和科学课程。

### 特殊题型

* **阅读理解** — 基于阅读一段材料的测试
* **标注** — 教师上传一张图片，由学习者对其进行标注
* **在 Office 文档中作答** — 启用 OnlyOffice 插件后，学习者通过编辑嵌入的 Office 文档（Word、Excel、PowerPoint）来回答问题。其作答会作为单独文件保存在该练习下，以便与该次作答的其余部分一并审阅。

## 向练习添加题目

1. 打开练习并点击 **添加题目**
2. 选择题目类型
3. 输入 **题干**（支持含图片与格式的富文本）
4. 定义 **答案** 及其评分：
   * 为每个选项指定是否正确以及分值
   * 可为错误答案设置负分，以抑制猜测
5. 可选添加 **反馈** — 作答后向学习者显示的说明
6. 设置 **难度等级** 和 **类别**（便于随机抽题与报告）
7. 保存

## 题目类别

可将题目组织到类别中（例如“模块 1”“词汇”“进阶”）。类别适用于：

* 整理大型题库
* 按类别随机抽题（例如“从模块 1 抽 5 题，从模块 2 抽 3 题”）
* 在报告中按类别查看成绩细分

## 题目复用

同一课程内的练习可复用题目。添加题目时，可选择新建，或从题库中选择已有题目。

## 导入练习

Chamilo 支持从外部格式导入练习：

* **IMS QTI / Common Cartridge** — 标准的电子学习测验格式
* **Moodle format** — 从 Moodle 导出文件导入测验

要导入，请在练习工具中查找 **导入** 选项并上传文件。

## 提示

* **混合题型** — 将选择题、填空题与开放题结合，进行全面评估
* **使用类别** — 按主题组织题目，以便有针对性地随机抽题
* **设置及格百分比** — 给学习者明确目标，并通过成绩册将其与证书生成关联
* **练习使用即时反馈** — 创建带即时反馈的不计分练习，帮助学习者从错误中学习
* **随机化以保障诚信** — 启用题目顺序随机与选项随机，降低抄袭可能
