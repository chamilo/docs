# 订阅用户

在评估学习者之前，需要先将其订阅到您的课程。Chamilo 提供四种将人员加入课程的方式，具体取决于由谁执行订阅，以及该人员是否已拥有平台账户。

| 方法 | 由谁操作 | 是否需要已有账户？ |
|--------|-------------|------------------------------|
| [管理员注册](#administrator-enrollment) | 平台管理员 | 是 |
| [通过课程目录自助注册](#self-enrollment-via-the-course-catalog) | 学习者本人 | 是 |
| [通过用户工具手动注册](#manual-enrollment-via-the-users-tool) | 教师（或课程管理员） | 是 |
| [通过电子邮件邀请用户](#inviting-users-by-email) | 教师（或课程管理员） | **否** |

## 管理员注册

平台管理员可从管理面板直接将任何现有用户订阅到任何课程——适用于批量入职（例如导入班级名单），或教师本人没有管理注册权限的情况。请参阅管理指南中的 [课程](../../admin-guide/courses/README.md) 部分。

## 通过课程目录自助注册

如果您课程的 [可见性](../creating-your-course/course-settings.md#course-visibility) 允许，拥有平台账户的学习者可通过在 **探索更多课程** 中找到您的课程并点击加入来自行订阅——您无需采取任何操作。此功能是否可用，以及是否需要密码，由 [课程设置](../creating-your-course/course-settings.md#enrollment-settings) 中的 **注册设置** 控制。

## 通过用户工具手动注册

要订阅已拥有平台账户但尚未自行加入的人员，请打开课程的 **用户** 工具，并点击 **添加用户** <img src="../../.gitbook/assets/icons/mdi-account-plus.svg" alt="添加用户" data-size="line"> 图标。

1. 按姓名、用户名、电子邮件或官方代码搜索该人员
2. 在其行上点击 **注册**，或使用复选框选择多人，并通过 **操作** 菜单一次性全部注册

![在“将用户注册到课程”屏幕中的搜索结果，显示匹配的学习者和“注册”按钮](../../.gitbook/assets/course-users-subscribe-search.png)

结果中仅显示尚未订阅该课程的用户。

> 默认情况下，教师可以使用此图标。平台管理员可通过 **允许课程管理员进行用户课程订阅** 设置（`allow_user_course_subscription_by_course_admin`）将其限制为仅管理员可用——如果您看不到 **添加用户** 图标，请联系管理员。

## 通过电子邮件邀请用户

上述三种方法都假定该人员已拥有平台账户。**课程邀请** 适用于对方尚无账户的情况：您向某个电子邮件地址发送邀请，Chamilo 会向该人员发送一次性链接。打开该链接即可创建账户，注册完成后会自动订阅到您的课程——无需单独的注册步骤。

### 访问该工具

打开课程的 **用户** 工具，然后点击工具栏中 **添加用户** 旁边的 **通过电子邮件邀请** <img src="../../.gitbook/assets/icons/mdi-email-outline.svg" alt="通过电子邮件邀请" data-size="line"> 图标：

![用户工具工具栏，显示“添加用户”图标和“通过电子邮件邀请”图标](../../.gitbook/assets/course-users-invite-icon.png)

这将打开 **课程邀请** 页面。

### 谁可以发送邀请

* 平台管理员，始终可以。
* 在普通课程中（未在会话中打开）：教师以及对该课程具有编辑权限的其他用户。
* 在会话中：该会话的总教练，或会话管理员——而不是更广泛的课程教练群体，因为此处发送邀请会订阅到*整个会话*，而不仅仅是这一门课程。

### 发送邀请

1. 在 **通过电子邮件邀请** 表单中输入收件人的电子邮件地址
2. 点击 **发送邀请**

![课程邀请页面：通过电子邮件邀请的表单，以及已发送邀请及其状态的表格](../../.gitbook/assets/course-invitations-list.png)

您为此课程发送的每封邀请都会显示在表单下方，并带有其状态：

| 状态 | 含义 |
|--------|---------|
| **待处理** | 已发送，尚未使用。仍在有效期内。 |
| **已接受** | 收件人已注册并被订阅。 |
| **已撤销** | 您在其被使用前取消了它。 |

对于仍处于待处理状态的邀请，**操作** 列提供：

* **复制** <img src="../../.gitbook/assets/icons/mdi-content-copy.svg" alt="复制" data-size="line"> — 复制邀请链接，以便您更愿意自行分享（聊天、当面）而不是依赖电子邮件。
* **撤销** <img src="../../.gitbook/assets/icons/mdi-account-cancel.svg" alt="撤销" data-size="line"> — 立即取消邀请；该链接停止生效。已接受的邀请无法撤销。

> **受邀的电子邮件地址不得已在此平台上拥有账户。** 如果已有账户，发送邀请会失败，并提示您改为直接为该现有用户报名 — 通过上文的 [通过用户工具手动报名](#manual-enrollment-via-the-users-tool)。

### 会话中的邀请

如果您从正在会话中运行的课程打开用户工具，页面会显示提醒：该邀请适用于整个会话，而不仅仅是本课程：

> *本课程在会话中开放。在此发送邀请会将收件人订阅到整个会话，而不仅仅是本课程。*

这与 Chamilo 中其他地方的报名方式一致：您将某人订阅到整个会话，或订阅到独立课程，但绝不会将“此会话中的这一门课程”作为单独操作来订阅。

### 受邀者看到的内容

电子邮件包含指向注册页面的链接。打开该链接会：

* 预填并锁定电子邮件字段为您邀请的地址 — 他们无法使用该链接以不同地址注册。
* 允许他们完成注册 **即使当前平台范围内已禁用自行注册** — 前提是您的管理员已开启 **允许通过课程邀请链接注册** 设置（见下文）。若未开启，邀请链接仅在自行注册另行开放时才有帮助。
* 他们提交表单后立即将其订阅到您的课程（或会话），并为其登录。

该链接为一次性使用，并在 7 天后过期。如果过期或其目标邀请被撤销，打开它的效果如同该链接从未存在过。

> 平台范围的 **允许通过课程邀请链接注册** 设置（`registration.allow_invitation_registration`）决定了在关闭一般自行注册时，您的邀请链接能否打开注册。如果在原本封闭的平台上邀请似乎不起作用，请询问您的管理员。

## 提示

* **根据情况选择方法** — 对已在使用本平台的人员使用管理员报名或自行报名，对已知的现有用户使用手动报名，对外部访客、审阅者或任何尚未拥有账户的人使用邀请。
* **撤销您不再需要的邀请** — 旧的待处理邀请仍是有效、未使用的链接；如果预期收件人不再需要访问权限，或您不确定其是否已收到，请将其撤销。
* **如果某种方法似乎不可用，请与管理员确认** — 其中若干流程（手动报名、邀请、自行报名）可能在平台范围内被限制或禁用。
