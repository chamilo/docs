# 评估学习者

Chamilo 提供一套全面的工具，用于评估学习者的知识并跟踪其表现。

* **[订阅用户](subscribing-users.md)** — 首先将学习者纳入课程：管理员注册、自行注册、手动注册或电子邮件邀请
* **[练习](exercises.md)** — 创建测验与考试，支持多种题型、自动评分及详细反馈
* **[作业](assignments.md)** — 收集学习者的作业与项目，支持文件上传、同伴互评以及人工或 AI 辅助评分
* **[调查](surveys.md)** — 通过可自定义的问卷收集学习者反馈
* **[出勤](attendance.md)** — 跟踪学习者在课堂时段中的出勤情况
* **[成绩册](gradebook.md)** — 将练习、作业及其他活动的分数汇总为统一成绩，并颁发证书

**报告**工具仍然存在，但已移至课程首页顶部，以小型图表图标的形式供教师使用。这是获取整门课程及其学生进度信息的中心入口。

这些工具相互配合：练习分数与作业成绩可汇入成绩册，成绩册又可关联证书生成与技能验证。
