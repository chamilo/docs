# 调查问卷

调查问卷工具可让您创建问卷，以收集学习者的反馈。调查问卷适用于课程评估、需求调研和意见征询。

## 创建调查问卷

1. 从课程主页打开 **调查问卷** <img src="../../.gitbook/assets/icons/mdi-form-dropdown.svg" alt="调查问卷" data-size="line"> 工具
2. 点击 **创建调查问卷**
3. 填写调查问卷详细信息：
   * **代码** — 调查问卷的唯一代码。将用于邮件和链接。
   * **标题** — 调查问卷的名称
   * **副标题** — 可选的次级标题
   * **开始日期** — 调查问卷开放参与的起始时间
   * **结束日期** — 调查问卷开放参与的截止时间
   * **匿名** — 回复是匿名还是与个别学习者关联
   * **结果可见性** — 谁可以查看结果（仅辅导教师、辅导教师和学生、所有人）
   * **引言** — 在学习者开始填写调查问卷前向其显示的消息
   * **感谢消息** — 提交后显示的消息
4. 保存

### 高级设置

* **在评估工具中计分** — 是否将此调查问卷的作答状态纳入评估工具（成绩册）。已完成调查问卷者得 100%，其余人得 0%
* **父级调查问卷** — 目前基本未使用（遗留功能）
* **每页一题** — 题目的呈现方式
* **启用乱序模式** — 是否打乱题目顺序
* **显示题号** — 是否显示（自动生成的）题号

## 添加题目

调查问卷创建完成后，添加题目：

1. 选择题目类型：
   * **是/否** — 简单的二元选择
   * **单选题** — 从多个选项中选择一个答案
   * **多选题** — 从多个选项中选择一个或多个答案
   * **开放题** — 自由文本作答
   * **下拉列表** — 从下拉列表中选择
   * **百分比** — 选择一个百分比值
   * **评分** — 按数字量表评分
   * **注释** — 文本块（非题目），用于在题目之间添加说明
   * **带“其他”选项的单选题** — 从多个选项中选择一个答案，并提供备选填写
   * **选择性显示** — 特殊类型，允许您根据先前答案调整题目流程
   * **分页符** — 在题目流程中添加分页。仅当上一步**未**选择“每页一题”时才有用
2. 配置题目文本和答案选项
3. 保存

每道题目均可标记为必答。若不标记，跳过任何题目都将被视为可接受的行为。

## 发布调查问卷

添加完所有题目后：

1. 点击 **发布**
2. 选择收件人 — 选择特定学习者或小组（由您选择）。**添加学习者** 按钮可一次性添加全部学习者，且不会包含教师
3. 添加其他用户 — 允许您邀请 Chamilo 以外的用户参与调查问卷。他们将收到带链接的电子邮件，并在调查问卷详情中以其电子邮件地址显示
4. 邮件主题
5. 邮件正文 — 说明调查问卷的内容以及何时/如何作答
6. 提供多种重复邀请选项
7. 确认

学习者会收到完成调查问卷的邀请（以电子邮件形式）。

发布页面底部提供一个链接，用于邀请更多外部用户参与。使用此链接的参与者将不会被识别，并在调查问卷结果中显示为匿名。

## 查看结果

![各题目的图表及百分比分解的调查问卷结果](../../.gitbook/assets/survey-results-charts.png)

学习者作答后：

1. 打开调查问卷
2. 点击 **结果** 或 **报告**
3. 查看回复摘要：
   * 封闭题的图表和百分比
   * 开放题的个别文本回复
   * 完成率（受邀者中有多少人作答）

您可以将结果导出为电子表格以便进一步分析。

## 提示

* **尽量简短** — 学习者更有可能完成较短的调查问卷
* **使用匿名模式** — 为获得诚实反馈，请启用匿名回复
* **把握时机** — 在课程中期发送调查问卷以便调整，而不仅仅做课程结束评估
