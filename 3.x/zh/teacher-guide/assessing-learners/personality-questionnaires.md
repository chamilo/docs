# 性格问卷

Chamilo 3.1 在现代化的 **调查** 工具中包含性格风格问卷。这些问卷生成的是**偏好画像**，而非计分练习或临床心理评估。

## 创建问卷

1. 打开调查工具并创建新调查。
2. 在其配置中，选择 **性格** 调查类型。
3. 打开**编辑题目**或该调查的题目编辑器。
4. 在添加性格题目前，先定义**性格类别**。每个答案选项必须属于一个类别。
5. 添加题目，配置其答案与类别分配，然后保存更改。
6. 在分发调查之前，预览学习者体验。

可用的性格题目类型有四种：

| 类型 | 学习者如何作答 |
| --- | --- |
| 性格选择 | 在与类别关联的选项中进行选择 |
| 性格认同 | 表明对所呈现项目的认同程度 |
| 性格量表 | 以五点量表对项目进行评分 |
| 性格排序 | 将选项从最偏好到最不偏好进行排序 |

配置包含答案校验以及基于类别的偏好计分。请仔细检查每道题目的选项及其分配：与错误类别关联的选项会改变最终画像。

## 查看结果

完成问卷后，当调查返回画像数据时，学习者可以看到**您的性格画像**。教师的调查报告页面可以显示**性格画像 — 全体学习者**。结果以条形图/雷达图可视化及类别分数呈现。复制调查时会保留性格问卷配置。

## 成绩册与解读

性格问卷不能像普通测评那样通过成绩册进行评分。请向学习者说明，结果反映的是对已配置类别的作答情况，而非诊断、通过/未通过状态或经过验证的性格测试。在收集个人作答之前，请审阅隐私与报告可见性设置。
