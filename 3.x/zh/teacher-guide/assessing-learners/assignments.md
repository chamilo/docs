# 作业

作业工具（也称为“学生作品”）可让您收集学习者提交的作业——论文、项目、报告或任何基于文件的提交——并进行评分。

## 创建作业

1. 从课程主页打开 **作业** <img src="/.gitbook/assets/icons/mdi-inbox-full.svg" alt="作业" data-size="line"> 工具
2. 点击 **创建作业**
3. 填写详细信息：
   * **作业名称** — 作业的名称（例如，“期末项目报告”）
   * **描述** — 给学习者的说明，包括应提交的内容以及如何评价（支持富文本）
   * **最高分** — 作业将按何种总分进行评分
   * **添加到成绩册** — 作为评估（成绩册）工具中的一项已评价项目添加，以便其可计入达成课程目标
   * **截止日期** — 官方（已发布）的日期和时间，此后提交将被标记为迟交（仍接受上传）
   * **结束于（完全关闭）** — 硬性截止的日期和时间，此后无法再上传
   * **添加到日历** — 创建事件以引用此作业提交日期
   * **提交类型** — 在 **仅允许文本**、**仅允许文件** 或 **允许文件或在线文本** 之间选择
4. 保存

创建作业后，您还可以：
* 在作业详情页内上传模板文档
* 将作业分配给特定用户（而非课程的所有用户）

学习者提交作业后，您可以：
* 导出提交列表的 PDF
* 仅显示尚未提交作业的学习者列表
* 将所有作业下载为一个大 ZIP
* 将所有批改以一个大 ZIP 上传
* 删除您提交的所有批改（这不会删除学习者的提交）

## 学习者如何提交

学习者打开作业并：

1. 点击 **上传文件** 或提交按钮
2. 从计算机选择文件（或直接撰写文本，取决于配置）
3. 添加可选评论
4. 提交

学习者可以查看自己是否已提交，并且在允许的情况下更新提交。

## 审阅提交

![显示学生姓名、日期、文件和评分状态的作业提交列表](/.gitbook/assets/assignments-submissions-list.png)

作为教师，打开作业即可查看所有提交的列表：

* **学生姓名** — 提交者
* **提交日期** — 作业提交的时间
* **文件** — 下载所提交的文件
* **状态** — 该提交是否已评分
* **评论** — 学习者或您留下的任何评论

### 为提交评分

![带有分数输入、反馈字段和批改文件上传的作业评分视图](/.gitbook/assets/assignment-grading-view.png)

1. 点击某条提交以打开它
2. 审阅所提交的文件
3. 输入 **分数**
4. 为学习者撰写 **反馈评论**
5. 可选择上传 **批改文件** 作为附件
6. 保存

### AI 辅助评分

如果您的平台已配置 AI 工具，审阅提交时可能会看到 **AI 评分** 选项。它使用 AI 模型为开放式作业建议分数和反馈。详情请参阅 [AI 评分](../ai-tools/ai-grading.md)。

## 管理提交

批量操作：
* **下载作业包** — 将所有提交下载为单个 ZIP 文件以便离线审阅
* **上传批改包** — 如果您已将所有提交下载为单个 ZIP 文件，在计算机上就地编辑文件并再次压缩，则可将该 zip 作为批改包发送。请勿更改文件名，否则将无法生效。
* **迟交** — 截止日期之后的提交会被标记，但根据您的设置仍可能被接受

单条提交操作：
* **上传批改** — 为一名学习者上传批改
* **下载** — 下载一名学习者的提交
* **批改并评分** — 为学习者的提交添加批改和成绩
* **编辑** — 编辑文档标题或该提交上的先前反馈
* **移动** — 在作业文件夹之间转移提交（例如，学生提交到了错误的作业中）
* **可见性** — 控制学习者是否可以看到彼此的提交

## 关联到成绩册

作业分数可纳入课程成绩册（“评估”工具）。这样作业成绩可计入学习者的总体课程成绩以及证书资格。详情请参阅 [成绩册](gradebook.md)。

## 提示

* **说明务必具体** — 清楚描述学习者应提交的内容、预期格式以及评价标准
* **设定切实可行的截止日期** — 使用日程工具，使截止日期在课程日历中可见
* **使用已批改文件功能** — 上传学生作业的批注版本，以便他们查看您的具体修改
* **谨慎启用同伴可见性** — 允许学习者查看彼此的作业可以促进学习，但并非所有作业都适合这样做
