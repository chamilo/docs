# AI 工具箱

**AI 工具箱**是一项课程工具，可根据教师的说明生成交互式教育应用。Chamilo 将每个生成的应用打包为 **SCORM 1.2**，以便平台跟踪学习者的进度、分数和续学数据。

> 管理员必须在 **管理 > 配置设置 > AI 助手** 下同时启用 `ai_helpers.enable_ai_helpers` 和 `ai_helpers.toolbox`，并且至少配置一个文本 AI 提供方。

## 创建交互式应用

1. 在课程中打开 **AI 工具箱**。
2. 点击 **创建**。
3. 输入 **标题**，并可选择填写 **描述**。
4. 在 **应用应完成什么？** 中，描述您希望的完整活动。请包含学习目标、规则、关卡、计分方式，以及学习者完成时应发生的情况。
5. 当有多个可用选项时，选择 **AI 提供方**。
6. 点击 **生成**。

首次生成的内容会存储为 **版本 1**。它最初为草稿，因此您可以在向学习者公开之前进行预览。

## 改进与版本管理

打开应用的 **设置** 即可进行管理。您可以：

* 预览或下载当前应用；
* 使用 **用 AI 改进** 描述一项更改并生成新版本；
* 查看 **版本历史**；
* 预览、下载或恢复较早的版本；
* 发布或隐藏应用；
* 打开 **报告** 以查看学习者跟踪数据。

生成改进不会删除先前的版本。恢复较早的版本会使该版本再次成为当前版本。

## 将应用添加到学习路径

在 [学习路径构建器](../adding-content/learning-paths.md) 中，教师可以选择已生成的 AI 工具箱应用作为资源。该应用必须已有生成的版本，但教师将其添加到学习路径之前不必先发布。未发布的应用在发布之前仍对学习者不可用。

当获得授权的教师在 **预览模式** 中打开工具箱内容时，Chamilo 会显示 **“预览模式下不保存进度和分数。”** 以这种方式测试活动不会创建学习者跟踪记录，也不会更新分数。发布后，请使用正常的学习者体验来验证 SCORM 进度和分数。

## 生成校验与故障排除

AI 生成之后，Chamilo 会在使某个版本可用之前检查所生成应用的源代码。这包括 JavaScript 语法或结构检查，以及对不安全浏览器 API 的限制。如果校验失败，Chamilo 会要求 AI 提供方 **修复结果一次**；如果修复后的版本仍然失败，生成将停止并报错。校验成功并不能替代发布前对活动学习规则、无障碍访问和 SCORM 计分的测试。

如果生成报告 **HTTP 504**，则表示 Web 服务器或网关已停止等待该请求。这与 AI 文本提供方施加的超时不同。错误信息可能包含大致已用时间；请尝试更简单的活动请求，并请管理员检查网关、PHP/Web 服务器以及提供方的超时设置。提供方超时或速率限制错误则需要检查已配置的模型和提供方设置。出现错误后，不要假定应用已成功保存。

这些校验与诊断方面的改进是在 [PR #9198](https://github.com/chamilo/chamilo-lms/pull/9198) 中引入的。

## 学习者体验

学习者只能看到已发布的应用。他们可以从工具箱打开应用，从其最新的 SCORM 状态继续，并查看自己的 **进度** 和 **分数**。当允许新的尝试时，**再试一次** 会开始一次全新的尝试。

工具箱应用在受限的 iframe 中于学习路径运行时内运行，并将其 SCORM 状态报告回 Chamilo。它们由工具箱管理，而不是由常规的学习路径列表管理。

当启用相同的 AI 工具箱设置时，获得授权的 MCP 客户端也可以创建或更新工具箱应用。
