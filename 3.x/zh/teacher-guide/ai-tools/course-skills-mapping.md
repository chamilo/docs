# AI 辅助的课程技能映射

Chamilo 3.1 可为课程建议相关技能，并允许授权用户审核这些建议，并将其应用到技能参照表和成绩册。AI 建议**不会自动应用**；必须经过选择和批准。

## 生成建议

1. 打开相关课程的**AI 辅助技能映射**页面。应用程序路由为 `/course/{courseId}/skills`，其中 `{courseId}` 替换为实际课程 ID。
2. 如果课程属于某个会话，请在正确的会话上下文中打开该页面。
3. 选择一个可用的 **AI 提供方**。
4. 选择**为此课程建议技能**，并查看返回的结果。

AI 提供方必须由平台管理员提供并完成配置。建议可以引用**现有技能**条目，或在父技能下推荐**新技能**。每个条目可包含其描述、标准以及对该建议的说明。

## 审核与批准

1. 审慎阅读每条建议，并将其与课程目标和内容进行对照。
2. 仅使用复选框选择有效的技能。
3. 如果您拥有所需授权，请选择**将所选技能添加到参照表和成绩册**。
4. 在课程中核验生成的技能及其与成绩册的关联。

没有分配权限的用户可以查看建议，但无法附加这些建议。创建新技能需要平台管理员权限。建议可能会过期；如果应用程序报告先前的建议已不再有效，请重新生成一组建议。

## 良好实践

AI 生成的技能仅为候选方案，并非权威的课程要求。在批准之前，请审核措辞、重复项、父技能位置和标准。避免在 AI 提示中输入学习者的机密信息。
