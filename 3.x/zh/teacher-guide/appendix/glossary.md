# 术语表

本指南中使用的关键术语。

| 术语 | 定义 |
|------|-----------|
| **Assessment** | 参见下方的 **Gradebook** |
| **作业（Assignment）** | 学习者提交文件或文本供教师审阅与评分的任务。亦称为“学生作品”或“作业（work）”。 |
| **自动启动（Auto-launch）** | 学习者进入课程时自动打开特定工具的功能。 |
| **证书（Certificate）** | 当学习者达到成绩册中设定的最低分数时自动生成的文档。 |
| **课程（Course）** | 学习内容与工具的容器。一门课程可包含文档、练习、论坛、学习路径等。 |
| **课程辅导教师（Course tutor）** | 针对学期（session）的教师角色。课程辅导教师管理某一学期中的一门课程。在 Chamilo 3.0 之前的版本中称为“course coach”。 |
| **磁盘配额（Disk quota）** | 分配给一门课程用于上传文件的最大存储空间。 |
| **注册（Enrollment）** | 将用户登记到课程或学期中，使其获得内容访问权限的过程。亦称为“订阅（subscription）”。 |
| **练习（Exercise）** | 包含一道或多道题目的测验或考试。在某些语境中亦称为“测验（test）”。 |
| **论坛（Forum）** | 按分类与主题组织的、带有话题串的讨论工具。 |
| **成绩册（Gradebook）** | 将练习、作业及其他活动的分数汇总为每位学习者统一成绩的工具。 |
| **学习路径（Learning path）** | 由学习活动（文档、练习、链接）组成的结构化序列，学习者按既定顺序学习，并可设置先修条件。 |
| **LTI** | Learning Tools Interoperability（学习工具互操作性）——允许将外部学习工具嵌入 Chamilo 的标准。 |
| **SCORM** | Sharable Content Object Reference Model（可共享内容对象参考模型）——电子学习内容包标准。Chamilo 可在学习路径中导入并播放 SCORM 包。 |
| **学期（Session）** | 将一门或多门课程在特定时间段内分配给特定学习者群体的版本。学期允许将同一课程内容复用于不同批次的学习者。 |
| **学期辅导教师（Session tutor）** | 监督某一学期内所有课程的督导角色。在 Chamilo 3.0 之前的版本中称为“session coach”。 |
| **技能（Skill）** | 可与成绩册成就关联的能力。当学习者获得证书时，相关技能即被确认。 |
| **调查（Survey）** | 用于收集反馈的问卷工具，支持多种题型及匿名作答选项。 |
| **可见性（Visibility）** | 控制工具、文档或活动是否对学习者可见的设置。教师始终可以看到隐藏项目。 |
