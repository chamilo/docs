# 支持工单

**工单（Tickets）** 工具是内置的帮助台系统，用户可通过它提交支持请求并跟踪处理进度。根据平台配置，您既可以作为**请求人**（为自己或学习者提交工单），也可以作为**支持专员**（处理分配到您所属类别的工单）。

## 系统如何组织

工单归属于**项目**，项目再划分为**类别**。每个类别可指派一名或多名支持专员。提交工单后，系统会自动将其路由到所选类别中的可用专员。

默认类别包括：

| 类别 | 说明 |
|----------|-------------|
| Enrollment | 关于课程或学期注册的问题与故障 |
| General information | 平台一般性问题 |
| Requests and paperwork | 行政申请与文档相关事项 |
| Academic Incidents | 与考试、作业或任务相关的问题 |
| Virtual campus | 平台技术问题 |
| Online evaluation | 特定课程测评相关问题（需选择课程） |

## 访问工单工具

若管理员已启用工单链接，顶部导航栏会出现工单图标 <img src="/.gitbook/assets/icons/mdi-ticket-account.svg" alt="工单" data-size="line">。点击即可直接进入工单提交表单。

您也可以从主菜单的 **Support** 或 **Tickets** 进入工单（具体名称取决于平台配置）。

## 提交工单

要新建支持请求：

1. 点击 **New ticket**（或顶部栏中的工单图标）。
2. 选择最符合您问题的**类别**。
3. 若该类别有要求（例如 Online evaluation），请选择相关**课程**。
4. 输入**主题**——对问题的简短概括。
5. 撰写**消息**，详细描述问题。
6. 可选择附加文件（截图、文档），以便支持专员理解问题。
7. 点击 **Submit**。

工单会被分配一个 ID 并路由给支持专员。专员回复时，您将收到通知。

## 跟踪您的工单

在工单列表中，您可以查看自己提交的全部工单及其当前状态：

| 状态 | 含义 |
|--------|---------|
| New | 刚提交，尚未审阅 |
| Pending | 支持专员正在审阅 |
| Unconfirmed | 等待确认或补充信息 |
| Forwarded | 已转交其他团队或专员 |
| Closed | 已解决 |

点击任意工单可阅读完整对话线程并添加回复。

## 回复工单

工单打开后，您与支持专员在同一线程中交换消息。添加回复的步骤：

1. 从列表中打开该工单。
2. 滚动到底部的回复字段。
3. 撰写回复，必要时附加文件。
4. 点击 **Send**。

线程中新增消息时，双方都会收到通知。

## 作为支持专员处理工单

若管理员已将您指派到一个或多个工单类别，您将在队列中看到来自学习者或同事的待处理工单。

回复已分配工单的步骤：

1. 打开工单列表——已分配工单会与您自己提交的工单一并显示。
2. 点击工单阅读请求人的消息。
3. 撰写回复并点击 **Send**。工单状态会自动更新。
4. 问题解决后，将状态改为 **Closed**。

您还可以更改工单的**优先级**（Low、Normal、High），以便对队列进行分诊。

> 工单类别的访问权限由平台管理员控制。若需被添加为某类别的支持专员，请联系管理员。配置选项请参阅管理员指南中的 [Tickets Settings](../admin-guide/platform-settings/ticket-settings.md)。
