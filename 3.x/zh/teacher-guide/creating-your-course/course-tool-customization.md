# 自定义课程工具名称和图标

Chamilo 3.1 允许获得授权的课程编辑者自定义课程主页上某工具所显示的**名称**和 **SVG 图标**。这些更改仅作用于该课程，并保留现有工具的目标地址。

## 自定义工具

1. 以有权编辑课程的用户身份打开课程主页。
2. 在工具网格中启用**自定义**模式。
3. 打开要更改的工具的自定义表单。
4. 输入所需的**名称**，如有需要，选择一个**图标** SVG 文件。
5. 选择**保存**，并在主页网格中验证已更新的工具。

工具自定义不同于网格的**排序**、**全部显示**和**全部隐藏**模式。更改工具的标签或图标不会创建新工具、不会更改其底层 URL，也不会向学习者授予额外访问权限。

## SVG 要求与安全

请使用来自可信来源的 SVG 文件。Chamilo 会验证上传的 SVG 内容并拒绝不安全的文件。如果文件被拒绝，请将其简化或重新导出为干净的 SVG，而不是试图绕过验证。

请分别以教师和学生身份确认最终的图标和名称，并验证其他课程保持不变。除非学生拥有所需的课程编辑权限，否则无法自定义工具。
