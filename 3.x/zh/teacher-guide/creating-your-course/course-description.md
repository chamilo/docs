# 课程简介

**课程简介** <img src="../../.gitbook/assets/icons/mdi-apple-safari.svg" alt="课程简介" data-size="line"> 工具可让您撰写结构化、多章节的课程说明——包括目标、教学方法、教材等。与仅供已注册学员在[课程主页](README.md#the-course-homepage)上看到的自由文本**课程介绍**横幅不同，课程简介是潜在学员在注册*之前*从课程目录中看到的内容。

注册后，学员仍可在课程内查阅该简介——如果您将该工具保持对其可见，它便是学员查看课程总体结构或教师信息等实用内容的便捷位置，无需直接向您询问。已注册学员可以查看您撰写的各章节，但不能添加、编辑或删除它们。

## 访问该工具

从课程主页的工具网格中打开 **课程简介** <img src="../../.gitbook/assets/icons/mdi-apple-safari.svg" alt="课程简介" data-size="line"> 工具。

## 八个章节

课程简介最多由八个相互独立的章节组成。每一章均为可选——只需填写与您的课程相关的部分：

| 章节 | 引导性问题 |
|---------|-------------------|
| **描述** | 本课程的目标是什么？是否有先修要求？本培训与其他课程有何关联？ |
| **目标** | 学员完成课程后应达到怎样的成果？课程期间会开展哪些活动？ |
| **主题** | 课程如何推进？学员应特别注意哪些地方？不同领域是否存在可识别的理解难点？各部分应投入多少时间？ |
| **教学方法** | 哪些方法和活动有助于实现课程目标？时间安排会是怎样的？ |
| **课程材料** | 是否有教材、论文汇编、参考文献或互联网链接列表？ |
| **资源** | 考虑可用的课程、辅导教师、技术支持台、教师和/或材料。 |
| **考核** | 将如何评估学员？是否需要制定掌握该主题的策略？ |
| **其他** | 任何无法归入上述类别的内容。您可以根据需要添加任意数量的**其他**章节，每一章都有自定义标题。 |

## 添加章节

1. 在工具工具栏中，点击您要撰写的章节类型对应的图标
2. Chamilo 会显示一个**帮助**框，其中包含该章节的引导性问题——据此决定撰写内容
3. 在富文本编辑器中撰写内容（支持格式、图片、链接、嵌入视频及其他富内容）。如果平台已启用该功能，您还可以为同一章节撰写多个语言版本，并让每位学员自动只看到自己的语言版本——参见[多语言内容](../adding-content/multi-language-content.md)。
4. 保存

您添加的每个章节都会在工具中显示为独立卡片。使用卡片上的 **编辑** <img src="../../.gitbook/assets/icons/mdi-pencil.svg" alt="编辑" data-size="line"> 和 **删除** <img src="../../.gitbook/assets/icons/mdi-delete.svg" alt="删除" data-size="line"> 图标，可稍后更新或移除该章节。

## 与课程目录的关联

这是填写课程简介的主要原因：它会直接进入访客和潜在学员浏览的 **探索更多课程** 目录。

* **未**填写任何简介章节的课程在目录中显示为普通卡片。
* **至少填写一个**简介章节的课程变为可点击——点击其图片、标题或信息按钮会打开详细弹出窗口，按上述相同顺序列出您撰写的每一章节。

这为潜在学员提供了真实依据来决定是否注册，而不仅仅是标题和缩略图。

> 该弹出窗口是否可用取决于平台范围设置。如果您的简介未在目录中向潜在学员显示，请让管理员检查 **管理 > 配置设置 > 课程目录** 下的 **显示课程简介** 设置（`show_courses_descriptions_in_catalog`）。

## 提示

* **优先填写描述和目标章节** —— 这是大多数潜在学员在决定是否注册时首先阅读的内容。
* **保持更新** —— 课程内容发生重大变化时及时更新课程简介，使目录始终反映学员实际将获得的内容。
* **谨慎使用富内容** —— 图片和格式有助于可读性，但冗长、杂乱的弹出窗口可能比几段清晰文字更难浏览。
