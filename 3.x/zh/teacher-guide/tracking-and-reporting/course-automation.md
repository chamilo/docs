# 课程自动化（手动触发）

课程报告中的**自动化**部分允许获得授权的教师为课程的开始与结束配置操作。在当前的 Chamilo 3.1 实现中，这些操作是**手动触发**的：请勿假定它们会在某个日历日期自动运行，或通过 cron 自动运行。

## 配置操作

1. 以教师身份或另一名获准管理课程报告的用户身份打开课程。
2. 打开**报告**并找到**自动化**部分。
3. 选择事件（**课程立即开始**或**课程立即结束**）以及操作类型。
4. 提供该操作所需的目标，然后选择**添加操作**。
5. 查看**已配置的操作**列表；使用其**删除**操作移除不需要的条目。

支持的操作包括发布或隐藏课程资源、发送调查邀请、发放已有证书以及更改课程可见性。可用的资源、调查、成绩册选项和可见性取值取决于课程以及当前用户的权限。

## 运行已配置的事件

选择**课程立即开始**或**课程立即结束**并确认操作。检查所报告的结果。Chamilo 会跟踪已完成的执行、防止重复配置，并在后续运行中跳过已成功完成的操作。不应将再次点击视为重新发送已完成操作的方式。

对于证书发放，请先准备并测试相关证书。对于调查邀请，请确认调查已配置，且目标学习者属于当前课程或会话上下文。

## 重要限制

- 此界面提供的是**手动执行**，而非计划任务式自动化。
- 操作在当前课程/会话上下文中执行；在适用情况下，请分别测试两种上下文的访问权限与目标。
- 已成功完成的操作不会在后续运行中自动重复。
- 在该功能 PR 提交时，证书发放、课程可见性更改以及会话特定执行已通过代码审查，但未在该 PR 中进行功能验证。在实际依赖这些功能之前，请在您的安装环境中进行测试。
