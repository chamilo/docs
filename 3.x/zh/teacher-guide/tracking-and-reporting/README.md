# 跟踪与报告

Chamilo 会全程跟踪学习者在平台上的活动，帮助您深入了解学习者的学习进展。

* **[学习者跟踪](learner-tracking.md)** — 监控单个学习者的活动：登录时间、学习时长、访问的页面以及工具使用情况
* **[课程报告](course-reports.md)** — 查看课程中所有学习者的汇总数据
* **[证书与技能](certificates-and-skills.md)** — 根据成绩册分数颁发证书，并核验已获得的技能

## 访问报告

在课程中，点击课程主页上的 **跟踪** <img src="../../.gitbook/assets/icons/mdi-chart-box.svg" alt="跟踪" data-size="line"> 工具。您也可以通过侧边栏中的 **报告** 链接访问报告，以获得跨课程总览。

教师可查看其所授课程的报告数据。会话辅导教师可查看其所负责会话中全部课程的数据。
