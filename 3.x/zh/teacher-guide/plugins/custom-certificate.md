# 自定义证书

自定义证书 <img src="/.gitbook/assets/icons/mdi-certificate.svg" alt="自定义证书" data-size="line"> 插件可让您用自己的设计替换标准的[成绩册证书](../assessing-learners/gradebook.md)——包括徽标、印章、最多四张带说明文字的签名图片、背景图、边距，以及由占位符标签构成的内容。

## 在课程中启用

管理员启用该插件并设置默认模板后，可在每门课程的 **课程设置** 中开启：

* **Custom certificate enable in course** — 为本课程激活该功能
* **Use default custom certificate** — 使用平台默认模板，而不自行设计（这两项互斥；若同时启用，Chamilo 会发出警告）

启用后，课程中将出现 **证书设置** 工具，供您设计或编辑模板。

## 设计证书

证书编辑器使用标签，在生成学习者证书时替换为真实数据，例如 `((user_firstname))`、`((course_title))`、`((gradebook_grade))` 和 `((date_certificate))`。除内容外，您还可以设置：

* 最多三张徽标、一张印章图片和一张背景图
* 最多四张签名图片，每张可配独立说明文字
* 边距，以及证书上显示的颁发/签发日期与地点

使用 **Certificate** 预览设计，或使用 **Delete certificate** 删除课程的自定义模板。

## 提示

* **学生看到的流程不变** — 他们仍从成绩册以常规方式下载证书，只是使用您的模板
* **先预览再正式使用** — 用真实占位数据检查预览，以便在学习者开始生成证书前发现版式问题
* **与管理员协调** — 若希望使用全平台默认模板而非按课程单独设计，需先由管理员完成设置
