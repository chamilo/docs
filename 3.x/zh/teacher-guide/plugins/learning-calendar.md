# 学习日历

学习日历 <img src="/.gitbook/assets/icons/mdi-calendar-text.svg" alt="学习日历" data-size="line"> 用于规划混合式或学徒式培训，将课堂时间与场外实践相结合。您可创建日历，将每一天标记为 **忙碌**、**考试** 或 **空闲**，并将学习者分配到该日历；其个人日程随后会显示这些计划日期。

## 访问该工具

启用后，**我的空间**（您的报告区域）中会出现 **学习日历** 图标。它会打开您已创建的日历列表，并提供添加、编辑、复制、删除以及为每个日历分配学习者的选项。

## 构建日历

1. 创建新日历
2. 单击某一天，使其在 **忙碌 → 考试 → 空闲 → 清除** 之间循环
3. 分配应遵循此日历的学习者

被分配的学习者会在自己的日程中看到计划日期，报告功能则会将计划日期与其实际学习路径完成情况进行比较。

## 提示

* **每位学习者同一时间只能有一个日历** — 一名学习者只能被分配到一个日历，因此请按群体规划，而不是尝试为同一人叠加多个日历
* **这是早期阶段功能** — 它独立于任何单一课程，因此不要期望达到 Chamilo 核心工具同等的完善程度；在将其用于真实群体之前，请先确认它适合您的培训形式
