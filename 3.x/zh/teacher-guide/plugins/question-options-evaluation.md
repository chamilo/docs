# 题目选项评分

题目选项评分 <img src="/.gitbook/assets/icons/mdi-calculator-variant.svg" alt="题目选项评分" data-size="line"> 可让您对测验评分应用负分（扣分）公式，而不是采用 Chamilo 默认的仅将正确答案相加的方式。

## 设置公式

启用后，课程 **测验** 工具列表中每个测验旁会出现一个额外图标。点击后会打开一个小表单，供您选择以下之一：

* **无公式** — Chamilo 的常规评分（默认）
* **重新计算题目分数** — 重新分配选项权重，但不扣分
* **成功数 − 失败数**
* **成功数 − 失败数 / 2**
* **成功数 − 失败数 / 3**

所选公式仅应用于该特定测验。

> 此设置不会更改题目或答案本身的权重 — 它改变的是最终分数的计算方式。如果插件被禁用，或未选择公式，Chamilo 将回退到其原始评分方式。

## 提示

* **先在副本上测试** — 更改公式可能会改变学生在该测验上最终获得的分数；在将其应用于正式测验之前，请先在复制的测验上试用
* **向学生说明变更** — 如果学习者习惯于简单的正确答案计分，扣分公式可能会令人意外；请在说明中提及这一点
