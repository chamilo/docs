# 插件

除 Chamilo 内置工具外，平台管理员还可以安装并启用**插件**——这些可选功能可为课程增加新工具、设置或行为。插件默认关闭；只有管理员开启后才会出现，部分插件还需在具体课程中另行启用才会生效。

本节记录会直接改变**教师**操作体验的插件。若您在自己的课程中看不到此处描述的插件，多半是平台尚未启用——请向管理员咨询。

## 测评与测验

* **[专注测验](exercise-focused.md)** — 检测学生在测验期间是否离开考试窗口，并给出屏幕警告，可选自动提交
* **[测验监考](exercise-monitoring.md)** — 在受监考试中拍摄学生及其证件的网络摄像头照片
* **[测验签名](exercise-signature.md)** — 要求学生在完成测验后进行电子签名
* **[题目选项评分](question-options-evaluation.md)** — 对测验采用负分（扣分）计分公式，替代 Chamilo 默认计分
* **[定位测评](positioning.md)** — 用雷达图比较学习者在初始测验与最终测验上的前后得分
* **[测验转 PDF](test-to-pdf.md)** — 将测验题目和/或答案导出为可打印的 PDF

## 内容与创作

* **[C-Studio 内容编辑器](cstudio.md)** — 用可视化编辑器制作交互式学习路径页面（测验、拖放、热点图片等），无需编写 HTML
* **[H5P 导入](h5p-import.md)** — 将 H5P 交互内容包上传到课程或学习路径
* **ONLYOFFICE** — 在文档工具中创建并协同编辑真实的 Word、Excel 和 PowerPoint 文档；已在 [文档](../adding-content/documents.md#onlyoffice-integration) 中介绍

## 沟通与会议

* **视频会议（BigBlueButton）** 与 **Zoom 视频会议** — 在课程中开展实时视频会话；见 [视频会议](../collaboration-and-communication/video-conferencing.md)
* **[课程主页通知](notify-in-course-home.md)** — 向访问课程主页的所有人显示一次性弹出通知

## 证书与合规

* **[自定义证书](custom-certificate.md)** — 用您自己的设计、徽标和签名替换标准成绩册证书
* **[课程法律协议](course-legal-agreement.md)** — 要求学生在访问课程前接受条款/法律声明

## 跟踪与跟进

* **[学生跟进](student-follow-up.md)** — 记录关于学习者进度与困难的私密或共享带时间戳笔记
* **[学习日历](learning-calendar.md)** — 为混合式或学徒制课程规划学习者的忙碌/考试/空闲日
* **[教师笔记](teacher-notes.md)** — 在课程中为特定学习者保存仅教学团队可见的私密笔记

## 集成

* **[IMS/LTI 客户端](ims-lti.md)** — 从课程内部启动外部工具或内容提供方
* **[LTI 1.3 Advantage 提供方](lti-1-3-advantage-provider.md)** — 允许外部 LMS 启动您的某次测验或学习路径（由管理员配置，教师无需设置）

## 问卷导出

* **[问卷导出 CSV](survey-export-csv.md)** — 将问卷结果导出为紧凑的 CSV 文件
* **[问卷导出 TXT](survey-export-txt.md)** — 将问卷结果导出为便于阅读的文本文件
