# 测验监控

测验监控 <img src="../../.gitbook/assets/icons/mdi-camera.svg" alt="测验监控" data-size="line"> 在学生作答测验时使用其网络摄像头采集身份照片——身份证件照片和学生面部照片——用于考试诚信目的。

## 为测验启用标记

打开测验设置并勾选 **Exercise Monitoring** 选项。一旦启用，尝试该测验的学生会看到一个小型浮动网络摄像头控件，并被提示在作答前或作答过程中采集这两张照片。

## 审阅采集内容

[推断] 采集的照片通过 **[Exercise Focused](exercise-focused.md)** 插件所添加的报告界面进行审阅，本插件与该插件一并开发——如果您的平台仅启用了 Exercise Monitoring 而未启用 Exercise Focused，请向管理员询问在您的安装环境中应如何审阅采集的照片。

## 注意事项

* **本功能处理敏感个人数据** — 身份证件照片属于许多机构和隐私法规予以额外审慎对待的数据类别。在依赖本插件之前，请与管理员确认其使用符合贵机构的数据保护义务
* **照片为临时保留** — 管理员会设置保留期限，到期后采集的照片将自动删除
* **这是早期阶段功能** — 请预期存在不完善之处；在用于正式考试前，请先通过试运行验证采集流程是否按预期工作
