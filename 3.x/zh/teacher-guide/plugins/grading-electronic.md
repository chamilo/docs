# Grading Electronic

Grading Electronic <img src="../../.gitbook/assets/icons/mdi-export.svg" alt="Grading Electronic" data-size="line"> 可将已通过您课程的学员及其成绩册分数，导出为外部认证机构所导入的文件：固定格式的文本文件，或名册电子表格。

## 打开导出区块

启用后，课程**评估**（成绩册）工具的工具栏上会出现**导出**图标。单击该图标，可在同一页面显示 **Grading Electronic** 区块；再次单击即可将其隐藏。

该区块包含三个字段：

* **预览** — 默认处于勾选状态。勾选期间不会保存任何内容：该区块仅显示导出将包含的内容
* **日期范围** — 课程的开始日期与结束日期。开始日期写入文本文件的标题行，结束日期则为每位学员通过课程的日期
* **课程 ID** — 该课程在认证机构中的标识符。系统会预填上次导出所使用的值

## 预览导出

勾选**预览**时，该区块仅提供一个**预览**按钮。它会列出本课程（或您当前所在会话）的全部学员及其分数，并显示 **PASS** 或 **SKIP** 状态，同时展示文本文件的内容。只有达到成绩册及格标准的学员才会被标记为 **PASS**；其余学员不纳入导出。

## 生成文件

取消勾选**预览**后，**预览**按钮会被以下两个按钮取代：

* **生成 TXT** — 下载固定格式的文本文件：标题行包含提供方 ID、课程 ID 和开始日期，其后每位已通过的学员各占一行
* **生成 XLSX** — 下载名册电子表格：每位已通过的学员占一行，列依次为 **FireTRAQ ID**、**First Name**、**Last Name**、**Score**、**Grade**、**Date Earned** 和 **Comment**

除所生成的文件不同外，两个按钮的作用相同：它们会保存**课程 ID** 以供下次导出使用；若成绩册会生成证书，则为每位已通过的学员生成证书。

## 电子表格的内容

* **FireTRAQ ID** — 学员在认证机构的 ID，读取自其 `fcdice_or_acadis_student_id` 个人资料字段
* **Score** — 成绩册分数，以整数百分比表示（0 至 100），与成绩册的总权重无关
* **Grade** — 始终为 **Pass**，因为仅导出已通过的学员。若需编辑该文件，单元格仍提供 **Pass**、**Fail** 和 **Incomplete** 选项
* **Date Earned** — 日期范围的结束日期
* **Comment** — 留空

## 提示

* **请先核对学生 ID** — 个人资料中没有 ID 的学员仍会被导出，其 **FireTRAQ ID** 为空。请在生成文件之前使用预览找出这些学员
* **提供方 ID 与课程学时**来自课程的额外字段，由管理员在安装该插件时设置
