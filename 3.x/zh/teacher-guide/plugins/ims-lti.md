# IMS/LTI 客户端

IMS/LTI 客户端 <img src="../../.gitbook/assets/icons/mdi-link-variant.svg" alt="IMS/LTI 客户端" data-size="line"> 可让您通过 LTI 标准（1.1 与 1.3 版本）从课程内部启动外部工具或内容提供方——例如出版商的交互式教材、专用仿真工具，或其他支持 LTI 的平台。Chamilo 作为启动平台；外部服务即为“工具”。

## 访问该工具

启用后，课程的 **设置** <img src="../../.gitbook/assets/icons/mdi-cog.svg" alt="设置" data-size="line"> 中会出现 **配置外部工具** 按钮。您可以：

* **添加新的外部工具** — 自行注册：名称、启动 URL、LTI 版本，以及外部服务提供给您的凭据（LTI 1.3 的客户端 ID/密钥，或 LTI 1.1 的消费者密钥与密钥）
* **添加已有的全局工具** — 若管理员已注册平台级工具，可将其添加到课程中，而无需自行创建连接

添加后，该工具会作为常规工具/快捷方式出现在课程主页上。

## 可配置项

对于您自行注册的工具：可设置在 iframe 中打开还是在新窗口中打开、是否与外部服务共享学习者的姓名、电子邮件和头像、自定义启动参数，以及（针对 LTI 1.3）Deep Linking 支持。若该工具支持作业与成绩服务（Assignment and Grades Service），您还可以创建关联的成绩册列，使其回传的分数进入您的 Chamilo 成绩册。

对于从平台级“全局”定义添加的工具，您只能调整这些课程级的呈现与隐私选项——连接凭据本身归注册基础工具的人员所有（通常是管理员）。

## 提示

* **先向工具提供方获取凭据** — 注册新工具前，您需要启动 URL，以及 LTI 1.3 的客户端/密钥信息或 LTI 1.1 的消费者密钥与密钥
* **谨慎决定共享内容** — 仅在外部工具确实需要时，才启用与外部服务共享学习者的姓名、电子邮件或头像
* **向管理员了解全局工具** — 若同一外部工具用于多门课程，平台级注册可避免每位教师分别配置各自的连接
