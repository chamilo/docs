# 测验转 PDF

测验转 PDF <img src="../../.gitbook/assets/icons/mdi-file-pdf-box.svg" alt="测验转 PDF" data-size="line"> 可将课程测验中的题目导出为可打印的 PDF——仅题目、仅答案，或题目与答案一并导出——便于制作纸质版测验。

## 访问该工具

启用后，课程主页上会出现 **测验转 PDF** 工具，列出课程（或学期）中的全部测验。每一行提供三项操作：**下载题目**、**下载答案** 和 **全部下载**。

## 提示

* **并非所有题型均受支持** — 仅 Chamilo 中的部分题型（选择题、判断题及类似封闭式题型）能干净导出；开放题或更复杂的题型可能显示不正确，甚至完全无法显示
* **批量打印前请先检查输出** — 在为考试场次大批量打印之前，先审阅一份测验生成的 PDF
