# 文件投递箱

文件投递箱是一种文件交换工具，可让您与学习者在课程内相互共享文件。

> 若要收集需评分的学生作业，[作业](../assessing-learners/assignments.md)工具通常更为合适，因为它包含评分与反馈功能。文件投递箱更适合非正式的文件共享。

## 发送文件

1. 从课程主页打开 **文件投递箱** 工具
2. 点击 **共享新文件**
3. 选择要上传的文件
4. 选择 **接收者** — 一名或多名已注册用户或课程小组
5. 发送

## 接收文件

当有人向您发送文件时，该文件会出现在您的投递箱收件箱中。您可以：

* **下载** 该文件
* 对该文件 **添加评论**（在收到之后）
* 将文件 **移动** 到您的某个分类中
* 从收件箱中 **删除** 该文件

## 整理文件

已发送和已接收的文件都可以整理到自定义 **分类**（文件夹）中。使用投递箱工具栏中的分类控件创建分类，然后将文件移入其中。如果平台设置“允许覆盖”已启用，以相同名称重新发送文件即可覆盖先前版本。

您也可以将所选文件批量下载为 ZIP。

## 作为教师

* 您可以向个别学习者、学习者小组或所有已注册用户发送文件
* 您可以查看学习者发送给您的文件
* 此工具适用于共享补充材料、提供个性化反馈文档，或接收非正式提交内容
