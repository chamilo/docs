# 笔记本

笔记本是供学习者使用的个人笔记工具。每位学习者在课程中都拥有自己的私密笔记本。

## 工作原理

笔记本是一个简单的工具，学习者可以：

* **创建笔记** — 撰写并保存与课程内容相关的个人笔记
* **整理笔记** — 查看、编辑和删除自己的笔记
* **保持私密** — 笔记仅对创建该笔记的学习者可见

## 作为教师

作为教师，您应当了解：

* 笔记本是**个人工具** — 您无法查看学习者的笔记
* 它适合作为**反思工具** — 鼓励学习者在学习过程中记笔记
* 笔记存储在课程内 — 不会在不同课程之间共享

## 启用笔记本

如果已启用笔记本工具，它会显示在课程主页上。如果您看不到该工具，请检查它是否被隐藏（在课程主页上查找隐藏的工具）。
