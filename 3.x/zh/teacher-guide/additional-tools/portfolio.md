# 作品集

作品集工具让学习者在课程过程中收集并展示自己的作品。它相当于一份数字作品集，学习者可在其中汇编自己的优秀作品、反思与成果。

## 作品集如何运作

每位学习者在课程中都有一份个人作品集，可以：

* **添加条目** — 使用富文本编辑器撰写文字条目，并为每个条目附加一个或多个文件
* **组织内容** — 为条目添加标签，以便按主题筛选
* **选择性分享** — 设置每个条目的可见性：隐藏、对课程可见、仅对教师可见（对他人隐藏），或在启用高级分享时与选定用户共享

## 作为教师

您可以将作品集用于：

* **反思性学习** — 要求学习者维护一份关于其学习历程的反思作品集
* **能力展示** — 让学习者收集技能与知识的证据
* **评估** — 将作品集内容作为评价的一部分进行审阅

要查看某位学习者的作品集，请打开作品集工具，并按用户筛选条目列表。

如果课程配置允许，您可以为作品集条目及个别评论评分——这些分数随后可计入成绩册。您还可以**突出显示**希望引起注意的条目，并将条目或评论标记为**模板**，以便您（或学习者）将其作为新条目的起点重复使用。作品集可导出为 **PDF** 或 **ZIP**。

## 提示

* **明确期望** — 告知学习者应包含哪些类型的条目，以及如何组织其作品集
* **定期审阅** — 定期查看作品集，而不是仅在课程结束时查看
* **与技能结合** — 将作品集与技能/证书系统配合使用，以形成全面的能力记录
