# 日程

日程工具可让您在课程中安排活动与截止日期。活动会显示在日历上，供学习者查看。

## 查看日程

从课程主页打开 **日程** <img src="../../.gitbook/assets/icons/mdi-calendar-text.svg" alt="日程" data-size="line"> 工具。您可以通过三种模式查看活动：

![日历视图中的日程，显示课程活动与截止日期](../../.gitbook/assets/agenda-calendar-view.png)

* **日历视图** — 可视化的月/周/日日历
* **列表视图** — 以时间顺序列出活动
* **个人活动** — 筛选仅与您相关的活动

## 创建活动

1. 点击 **添加活动** <img src="../../.gitbook/assets/icons/mdi-calendar-plus.svg" alt="添加活动" data-size="line">
2. 填写活动详情：
   * **标题** — 活动的简短名称
   * **开始日期和时间**
   * **结束日期和时间**
   * **描述** — 补充说明（支持富文本）
3. 选择 **受众**：
   * **全部学习者** — 课程中所有已注册人员
   * **特定用户或小组** — 选择个别学习者或小组
4. 可选择设置 **提醒** <img src="../../.gitbook/assets/icons/mdi-alarm.svg" alt="提醒" data-size="line">，在活动开始前发送电子邮件通知（门户需由管理员配置 *cron*）
5. 点击色块为活动选择 **颜色**。该颜色会在日历的各视图（月、周、日）中高亮显示该活动，便于一眼区分不同活动——例如区分截止日期与常规课时，或在个人日程中区分来自不同课程的活动。

   ![活动创建表单中的颜色选择器](../../.gitbook/assets/agenda-event-color-picker.png)
6. 保存

所选颜色会反映在日历中该活动出现的所有位置：

![周视图中以所选颜色显示的活动](../../.gitbook/assets/agenda-event-color-result.png)

默认情况下，新活动会根据其上下文（课程、学期、个人或全局）获得一种颜色，但您可以用任意颜色覆盖它。

## 管理活动

* **编辑** <img src="../../.gitbook/assets/icons/mdi-pencil.svg" alt="编辑" data-size="line"> — 点击活动以修改其详情
* **删除** <img src="../../.gitbook/assets/icons/mdi-delete.svg" alt="删除" data-size="line"> — 从日历中移除活动
* **拖放** — 在日历视图中，拖动活动以重新安排时间

## 个人日程

您还可以从侧边栏访问 **个人日程**。个人日程会将您所有课程中的活动汇总到同一视图。学习者可在此查看其已注册全部课程的综合时间安排。

## 提示

* **设置截止日期** — 为作业截止日期和测验截止时间创建活动，以便学习者在日历中看到
* **使用提醒** — 为重要活动启用电子邮件提醒，帮助学习者跟上进度
* **与学期协调** — 若您在多个学期中授课，每个学期有各自的活动，仅对该学期的学习者可见。教师可查看其所在学期中其他课程的活动（作业、外出等），以免给学生造成过重负担。
