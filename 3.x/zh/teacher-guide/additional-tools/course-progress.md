# 课程进度

课程进度工具可帮助您定义课程的主题结构，并跟踪计划内容的实际讲授进度。

对学生而言，该工具对因病缺课数日的学习者尤为有用：他们可以了解已讲授的主题，以及其余同学在其缺席期间的进度。

## 工作原理

课程进度分为三层：

* **主题章节** — 课程的主要主题或模块
* **主题计划** — 每个章节中您计划讲授的内容。每条计划条目属于一组固定类型之一：**目标**、**待掌握技能**、**教学方法**、**基础设施**、**评估** 或 **其他**。
* **主题进展** — 各章节下的离散讲授记录，每条记录包含开始日期和持续小时数。在实际讲授后将进展标记为 **已完成**，以便对照计划跟踪真实进度。

## 设置课程进度

1. 从课程主页打开 **课程进度** 工具
2. 创建与课程主要主题或模块相对应的 **主题章节**
3. 在每个章节内，按类型添加 **计划** 条目，描述您打算讲授的内容
4. 在讲授内容时，添加带有日期和时长的 **主题进展**，并将其标记为已完成
5. 通过在 **课程设置** 部分（课程主页顶部的齿轮图标）更改相关设置，决定该信息在课程主页上的可见性

您可以选择将主题进展关联到考勤表，以便从其考勤记录中拉取开始日期。章节（及其计划和进展）也可以在同一课程/学期内 **复制**。

## 使用场景

* **跟踪教学计划** — 监控课程中哪些部分已讲授、哪些尚未讲授
* **考勤集成** — 课程进度可与考勤工具配合使用，将出勤情况与已覆盖主题相关联
* **报告** — 清晰查看课程讲授状态随时间的变化

## 面向学习者

学习者可以查看课程进度，以了解课程结构并查看目前已覆盖的主题。这对迟到加入或错过课次的学习者尤其有用。
