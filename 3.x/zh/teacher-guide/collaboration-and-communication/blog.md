# 博客

博客工具可让您在课程中创建共享博客。学习者可以撰写文章、发表评论，并参与结构化的写作活动。

## 创建博客

1. 从课程主页打开 **博客** 工具（位于顶部齿轮图标下）
2. 点击 **新建项目**
3. 输入 **标题** 及可选的副标题
4. 保存
5. 通过点击 **显示**（眼睛）图标，决定何时向学生开放

您可以在同一门课程中创建多个博客（例如，按主题或按小组各建一个）。

## 撰写博文

1. 打开一个博客
2. 点击 **新建文章**
3. 输入 **标题**，并使用富文本编辑器撰写文章内容
4. 保存

教师和学习者（取决于权限）均可创建文章。

## 评论与评分

读者可通过以下方式与博文互动：

* **评论** — 在文章下留下反馈或发起讨论（评论也可作为对其他评论的回复进行嵌套）
* **评分** — 为文章评分，以突出最受重视的贡献
* **附件** — 文章和评论均可附带文件附件

## 博客任务

您可以在博客中创建 **任务** — 学习者必须以博文形式完成的特定写作作业。这适用于：

* 反思日志
* 每周写作作业
* 项目进展报告

## 管理博客

作为教师，您可以：

* **编辑或删除** 文章和评论（删除文章仅限文章作者或教师）
* **切换博客可见性**，向学习者显示或隐藏博客
* **定义任务** — 添加学习者需以文章形式完成的特定写作作业。任务可进行颜色编码，以便更直观地分组。
