# 论坛

论坛工具可让您在课程中组织结构化讨论。学习者可以发帖、互相回复，并参与带层级的对话。

## 论坛结构

![论坛分类列表，显示分类、论坛及主题数量](/.gitbook/assets/forum-category-list.png)

Chamilo 中的论坛分为三个层级：

1. **论坛分类** — 顶层分组（例如“综合讨论”“模块 1 答疑”）
2. **论坛** — 某一分类下的各个讨论区
3. **主题（帖子串）** — 某一论坛内的各个讨论主题，每个主题都有一串回复

## 创建论坛分类

1. 从课程主页打开 **论坛** <img src="/.gitbook/assets/icons/mdi-comment-quote.svg" alt="论坛" data-size="line"> 工具
2. 点击 **添加论坛分类**
3. 输入 **分类名称** 及可选说明
4. 保存

## 创建论坛

至少存在一个分类后，才能添加论坛。

1. 在某一分类内，点击 **添加论坛**
2. 填写基本信息：
   * **标题** — 该讨论区的名称
   * **说明** — 可选，描述论坛用途
   * **创建到分类** — 该论坛所属的分类
3. 打开 **高级设置** 进行配置：
   * **发布日期** / **关闭日期** — 可选的论坛开放时间窗口
   * **需审核的论坛** — 新帖须经教师批准后才可见
   * **学习者能否编辑自己的帖子？** — 允许或禁止学习者在提交后编辑帖子
   * **允许用户发起新主题** — 设为“否”时，学习者只能回复已有主题
   * **默认视图类型** — 选择帖子显示方式：**平铺**、**主题串** 或 **嵌套**
   * **所属小组** — 将此论坛关联到课程小组
   * **公开访问 / 私密访问** — 针对小组论坛，决定任意课程成员均可阅读，还是仅小组成员可阅读
4. 保存

若课程可见性设为“对全世界开放”，表单还会显示 **允许匿名发帖？** 选项。可见性受限的课程中该选项会被隐藏。

## 管理主题

学习者和您都可以在论坛中创建新主题。作为教师，您可以：

* **置顶主题（置顶消息）** — 在创建或编辑时将主题标为置顶，使其始终显示在顶部
* **锁定主题** — 禁止继续回复
* **编辑或删除帖子** — 对讨论进行审核管理
* **移动主题** — 将主题转移到其他论坛

## 论坛评分

以教师身份创建新主题时，可在高级设置中启用 **为本主题评分**。随后可设置最高分、成绩册列标题以及报告中的权重。还可启用 **同伴互评本主题**，要求每位学习者至少为另外两名学习者评分后，其本人得分才计入。

## 通知

每个论坛和主题都有 **通知我** 开关，您和学习者可用它订阅新帖的电子邮件通知。通知是按用户订阅的，创建论坛时无需配置。
