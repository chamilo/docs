# 聊天

聊天工具可在课程内提供实时文字消息。它适用于快速沟通、实时问答或非正式讨论。

## 使用聊天

1. 从课程主页打开 **聊天** 工具
2. 在 **用户** 面板中，选择特定在线用户以直接向其发送消息，或使用 **全部** 选项卡面向整个小组
3. 在底部文本框中输入消息，按 **Enter** 发送（**Shift+Enter** 可换行而不发送）

**预览** 选项可让您在发送前检查格式，**重置** 可清除当前草稿。

## 聊天功能

* **实时消息** — 消息会立即显示给接收者
* **消息历史** — 进入聊天时可见先前的消息
* **用户在线状态** — 用户面板显示当前在课程中在线的人员
* **一对一或群组** — 可一次向一名学员发消息，或通过 **全部** 选项卡向所有人广播

## 作为教师

作为课程教师，您可以：

* **监控讨论** — 查看聊天历史以跟踪学员参与情况
* **在文档中查找聊天存档** — 聊天工具会自动将消息镜像为 HTML 文件，保存在文档工具中，按日期及范围（课程 / 学期 / 小组）组织，因此对话会在实时会话结束后继续保留

如果管理员启用了平台设置“将课程聊天限制为仅辅导教师”，则只有辅导教师可以与学员聊天；否则课程中所有已注册人员均可参与。

## 有效使用聊天的提示

* **安排聊天时段** — 提前告知学员您何时可进行实时聊天（使用日程工具）
* **设定基本规则** — 明确尊重沟通的期望
* **用于快速提问** — 聊天最适合简短交流；较长、结构化的讨论请使用论坛

> 如果您的平台已配置视频会议（BigBlueButton 或 Zoom），在语音和视频更有效的实时会话中可考虑使用该功能。请参阅 [视频会议](video-conferencing.md)。
