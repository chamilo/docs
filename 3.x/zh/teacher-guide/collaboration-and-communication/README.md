# 协作与交流

Chamilo 提供多种工具，便于您与学习者之间以及学习者彼此之间进行互动。

* **[论坛](forums.md)** — 按类别和主题组织的话题讨论
* **[聊天](chat.md)** — 课程内的实时文字消息
* **[小组](groups.md)** — 将学习者分成工作小组，并配备各自的共享工具
* **[Wiki](wiki.md)** — 协作式文档编辑
* **[博客](blog.md)** — 课程内的共享博客
* **[视频会议](video-conferencing.md)** — 使用 BigBlueButton 或 Zoom 的实时视频会话

这些工具可从课程主页访问。部分工具可能默认隐藏——您可在工具网格中将其设为可见（参见 [课程主页](../creating-your-course/course-homepage.md)）。
