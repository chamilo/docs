# 学习路径

学习路径可让您创建结构化的学习活动序列。学习路径会引导学习者按特定顺序浏览文档、练习、链接及其他资源，并可设置可选的先决条件和进度跟踪。

该工具可以说是使用最频繁的课程工具，因为它相当于许多其他工具的编排器，而且完全可以成为学习者面对的***唯一***工具。

## 为何使用学习路径？

在以下情况下，学习路径非常有用：

* **控制内容学习顺序** — 确保学习者在进入后续内容前先完成基础材料
* **跟踪进度** — 准确查看每位学习者在序列中的位置
* **设置先决条件** — 要求学习者通过某项练习后才能访问下一章节
* **授予完成认定** — 将学习路径完成情况与成绩册和证书关联
* **打包内容** — 创建学习者可按自己节奏完成的独立学习模块

## 创建学习路径

1. 从课程主页打开 **学习路径** <img src="/.gitbook/assets/icons/mdi-map-marker-path.svg" alt="学习路径" data-size="line"> 工具
2. 点击 **创建学习路径**
3. 输入 **标题** 及可选的描述
4. 保存 — 您将进入学习路径编辑器

## 学习路径编辑器

![左侧为项目树、右侧为内容预览的学习路径编辑器](/.gitbook/assets/learning-path-editor.png)

编辑器包含两个主要区域：

* **左侧面板** — 学习路径中的项目（步骤）列表，以树状结构显示
* **右侧面板** — 所选项目的内容

### 添加项目

点击 **添加项目** 并选择要添加的内容：

| 项目类型 | 说明 |
|-----------|-------------|
| **章节** | 用于将相关项目分组的标题（类似章标题）。章节本身不包含内容。 |
| **文档** | 来自课程“文档”工具的文件或网页 |
| **练习** | 来自“练习”工具的测验或测试 |
| **链接** | 外部 URL |
| **作业** | 来自“作业”工具的学生提交内容 |
| **论坛** | 指向课程论坛的链接 |
| **调查** | 指向调查的链接 |
| **证书** | 用于触发生成结业证书或授予技能的特殊页面 |

### 组织项目

* **拖放** 项目以重新排序
* 将项目向右拖动，使其 **嵌套** 在章节下
* **删除** 不再需要的项目

### 设置先决条件

先决条件可确保学习者在访问后续步骤前先完成特定步骤：

1. 在学习路径中选择一个项目
2. 打开其 **先决条件** 设置
3. 选择必须先完成的一个或多个前置项目
4. 对于练习，可以要求 **最低分数**（例如：“必须在测验 1 中至少获得 70% 才能访问模块 2”）

## 学习者体验

当学习者打开学习路径时：

* 他们会在左侧面板中看到项目列表
* 已完成的项目会标有勾选标记
* 未满足先决条件的项目会被锁定
* 进度会自动跟踪 — 如果学习者离开后再次返回，将从离开处继续
* 进度条显示总体完成百分比

## SCORM 内容

Chamilo 的学习路径工具可以导入 **SCORM 1.2** 包 — 这是使用最广泛的电子学习标准。上传 SCORM ZIP 文件后，Chamilo 将据此创建学习路径，并按照 SCORM 规范跟踪进度和分数。

导入 SCORM 包：

1. 在学习路径工具中，打开操作菜单并点击 **上传**
2. 上传 ZIP 文件
3. Chamilo 会自动解包并创建学习路径

### CMI5 / xAPI 包

CMI5 包（基于 xAPI 的现代 SCORM 继任标准）通过 **XApi** 插件提供支持。管理员启用该插件后，您可以导入 CMI5 包，学习者可从课程中启动；其语句会转发到已配置的 Learning Record Store。

## 使用 C-Studio 进行内容创作

*仅在管理员已启用 C-Studio 插件时可用。*

C-Studio 在学习路径内增加了内置的拖放式可视化编辑器，用于直接创建交互式内容 — 当您没有（或不想学习）Articulate 或 iSpring 等独立创作工具时，可作为导入 SCORM 包的替代方案。您可在 Chamilo 中逐页构建内容，其存储和跟踪方式与其他学习路径项目相同。

### 启动 C-Studio 项目

插件启用后，学习路径列表会在常规操作菜单旁显示一个额外按钮，标有“+”以及“Studio Tools”提示：

![学习路径列表中，C-Studio 的“Studio Tools”按钮显示在标准操作菜单旁](/.gitbook/assets/cstudio-lp-button.png)

点击即可开始。系统会提示您从头创建新项目，或导入已有项目：

![C-Studio 起始界面，提供创建新项目或导入已有项目的选项](/.gitbook/assets/cstudio-start-screen.png)

该界面目前仅提供法语，与平台或课程语言无关——这是当前所用插件版本的已知限制。为项目命名后，将直接进入编辑器。

### 编辑器

![C-Studio 可视化编辑器，显示页面画布、右侧工具面板以及左侧项目面板](/.gitbook/assets/cstudio-editor.png)

编辑器是按页构建的可视化编辑器：

* **左侧面板** — 项目中的页面，带“+”可添加更多页面，底部有 **Tools** 区域（Clean data、Preview、Colors、Options、Quit）
* **中间画布** — 正在编辑的页面；点击任意元素即可就地编辑
* **右侧面板** — 组件面板，可拖放到画布上

面板涵盖基础构建块（列、图片、音频、标题、文本、按钮、卡片），以及多种交互练习类型：**Drag Drop**、**Fill text**、**Hotspot Img**、**Mark Words**、**Find Words** 和 **Sort paragraphs**，另有用于嵌入外部内容的 **iframe** 块和 **Quiz** 块。

### 语言

C-Studio 自身界面首次打开时可能默认使用法语，与 Chamilo 界面语言或课程语言无关。若出现此情况，请前往 **File > UI language** 并选择您的语言——编辑器会立即重新加载，并记住您的选择。

![已打开的 File 菜单，显示“UI language”选项](/.gitbook/assets/cstudio-file-menu.png)

### 保存与导出

工作时使用 **File > Save**。**File > Export...** 会将项目打包为 SCORM 文件，供下载、备份，或通过 **Import...** 在其他位置复用。**File > Quit** 将返回学习路径列表，此时您的 C-Studio 项目会作为普通项目显示。

## 学习路径设置

配置学习路径的行为：

| 设置 | 说明 |
|---------|-------------|
| **可见性** | 对学习者隐藏或显示该学习路径 |
| **先决条件** | 要求先完成其他学习路径后才能学习本路径 |
| **自动启动** | 学习者进入课程时自动打开该学习路径 |
| **累计 SCORM 时间** | 是否跨多次会话累计学习时间 |

## 关联到成绩册

可将学习路径完成情况作为成绩册中的计分活动。这样，学习路径进度可计入学习者的课程总成绩及证书资格。

## 使用 AI

若管理员已启用 AI 辅助生成学习路径，您将在下拉操作菜单中看到 AI 生成选项。向 AI 提供尽可能精确的学习路径背景，指定页数及每页大致字数，并说明是否需要填充测验，然后启动。数分钟后，即可看到一份完整的、基于文本的学习路径。

编辑文档并用更多 AI 生成插图，只需稍作审阅即可分享给学习者。

## 提示

* **先拟大纲** — 在构建路径前规划好章节与条目
* **用章节作为章** — 将相关条目归入章节标题下，便于条理清晰
* **为测评设置先决条件** — 要求学习者先学习内容再参加测验
* **混合内容类型** — 结合阅读材料、视频、交互练习和外部资源，提升学习体验
* **检查学习者视图** — 使用“学生视图”功能，以学习者视角体验学习路径
* **用 SCORM 实现交互** — 若可使用 SCORM 创作工具（如 Articulate、iSpring 等），可制作丰富的交互内容并导入 Chamilo。若管理员已启用 C-Studio 插件，也可直接在 Chamilo 中构建类似交互内容——参见上文 [使用 C-Studio 进行内容创作](#content-authoring-with-c-studio)
