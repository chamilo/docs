# 数学公式

富文本编辑器可以排版数学公式。您使用 LaTeX 编写公式，学习者会在内容显示的任何位置看到渲染结果：文档、公告、练习、论坛、Wiki 页面，以及任何使用该编辑器的其他工具。

公式存储在内容本身之中，因此在复制或导出课程时会随课程一起迁移。

## 启用该功能

公式按钮默认关闭。平台管理员可在 **管理 > 配置设置 > 编辑器 > 启用 MathJax**（[`enabled_mathjax`](../../admin-guide/platform-settings/editor-settings.md)）下将其打开。

设置开启后，该按钮会出现在平台上的每一个编辑器中。无需按课程单独配置。

## 插入公式

1. 将光标放在公式应出现的位置
2. 单击编辑器工具栏中的 **插入公式** 按钮（Σ 图标）
3. 以 **LaTeX 代码** 输入公式
4. 在字段下方的预览框中检查渲染结果
5. 单击 **插入**

预览会在您输入时更新，因此可以在插入之前纠正错误。

## 编辑公式

在编辑器中单击该公式。将再次打开同一对话框，字段中显示您原来的 LaTeX 代码。修改后单击 **插入** 即可替换公式。

要删除公式，在编辑器中选中它并按 <kbd>Delete</kbd>，与其他元素相同。

## 编写 LaTeX

公式字段接受标准 LaTeX 数学记号。若干示例如下：

| 您输入的内容 | 学习者看到的内容 |
| --- | --- |
| `x = \frac{-b \pm \sqrt{b^2-4ac}}{2a}` | 二次方程求根公式 |
| `\sum_{i=1}^{n} i = \frac{n(n+1)}{2}` | 带上下限的求和 |
| `\int_{0}^{\infty} e^{-x} dx = 1` | 定积分 |
| `\alpha + \beta = \gamma` | 希腊字母 |
| `\begin{matrix} a & b \\ c & d \end{matrix}` | 矩阵 |

您也可以直接在编辑器中输入原始分隔符 `\(...\)`、`\[...\]` 或 `$$...$$`。编辑器在加载内容时会将它们转换为公式。

## 说明

* 公式库仅在实际包含公式的页面上加载，因此不含公式的页面不会变慢。
* 一切都在学习者的浏览器中渲染。平台不需要外部服务，即使安装环境无法访问互联网也能工作。
* 公式会保留其 LaTeX 源码。您随时可以重新打开并阅读当初所写内容，即使多年之后也是如此。
