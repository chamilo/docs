# 添加内容

本节介绍用于向课程添加学习内容的工具。Chamilo 提供多种方式向学习者交付材料：

* **[文档](documents.md)** — 上传文件、创建网页并组织您的内容库
* **[链接](links.md)** — 按类别分享指向外部资源的 URL
* **[学习路径](learning-paths.md)** — 构建带有先决条件和进度跟踪的结构化内容序列
* **[术语表](glossary.md)** — 定义学习者可在整个课程中查阅的关键术语
* **[公告](announcements.md)** — 向已注册的学习者发送消息和更新
* **[多语言内容](multi-language-content.md)** — 为同一内容编写多种语言版本，并让每位学习者仅看到自己的语言版本

每个工具均可从课程主页的工具网格中访问。单击工具图标即可打开。
