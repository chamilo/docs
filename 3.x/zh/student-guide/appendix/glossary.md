# 词汇表

本指南中使用的关键术语。

| 术语 | 定义 |
|------|-----------|
| **Assessment** | 参见下方的 **Gradebook** |
| **作业（Assignment）** | 一项任务，您提交文件或文本供教师审阅和评分。也称为“学生作品”或“作业（work）”。 |
| **CAPTCHA** | 一种验证挑战（通常是输入图片中扭曲的字母），用于确认您是真人，会显示在部分登录、注册和找回密码表单上。 |
| **课程目录（Catalog）** | 课程（及学期）的公开列表，您可以浏览，并在某些情况下自行注册。通过 **探索更多课程** 访问。 |
| **证书（Certificate）** | 当您达到课程成绩册中定义的最低分数时自动生成的文档。 |
| **课程（Course）** | 学习内容和工具的容器。一门课程可包含文档、练习、论坛、学习路径等。 |
| **注册（Enrollment）** | 被登记到某门课程或学期中，从而获得其内容的访问权限。也称为“订阅（subscription）”。 |
| **练习（Exercise）** | 包含一道或多道题目的测验或考试。在某些语境中也称为“测试（test）”。 |
| **论坛（Forum）** | 一种讨论工具，以分类和主题组织的线程式对话。 |
| **成绩册（Gradebook）** | 将练习、作业及其他活动的分数汇总为统一成绩的工具。 |
| **邀请（Invitation）** | 教师发送到您电子邮箱的一次性链接，使您能够注册并自动订阅某门课程，即使常规注册已关闭。 |
| **学习路径（Learning path）** | 按既定顺序进行的结构化学习活动序列（文档、练习、链接），有时带有先决条件。 |
| **自行注册（Self-registration）** | 若平台管理员已启用，可通过公开注册表单自行创建账户的能力。 |
| **学期（Session）** | 一门或多门课程面向特定学习者群体（如学期或班级）的有时限版本。 |
| **技能（Skill）** | 与成绩册成就关联的能力。获得证书可验证相关技能。 |
| **双因素认证（Two-factor authentication，2FA）** | 除密码外，使用身份验证器应用中基于时间的验证码进行的额外登录步骤。 |
| **可见性（Visibility）** | 控制某工具、文档或活动是否向学习者显示的设置。教师始终可以看到隐藏项目。 |
