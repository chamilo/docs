# 学生指南

欢迎阅读 Chamilo 3.0 学生指南。本指南面向学习者——即通过 Chamilo 平台修读课程的任何人，无论是学校课程、企业培训项目，还是开放在线课程。

无论您是首次使用 Chamilo，还是已经选修了多门课程，本指南都将帮助您熟悉平台、加入课程，并保障账户安全。

## 作为学生您可以做什么

作为 Chamilo 中的学习者，您可以：

* **创建账户**（若您的平台允许自行注册）并登录
* **加入课程**——通过公开目录、邀请，或由管理员或教师进行注册
* **使用课程工具学习**——阅读文档、跟随学习路径、参加练习、提交作业等
* **交流沟通**——使用论坛、聊天和小组与教师及其他学习者互动
* **跟踪个人进度**——查看成绩、完成状态和证书
* **向 AI Tutor 求助**（若您的平台已启用该功能）
* **保障账户安全**——重置忘记的密码并启用双因素认证

## 本指南的组织结构

1. **入门** — 创建账户（或登录），并了解总体界面
2. **课程** — 订阅课程，使用其工具（学习路径、测验、作业、论坛、聊天），并使用 AI Tutor
3. **收件箱** — 与平台其他用户收发私人消息
4. **社交网络** — 与其他用户建立联系（若管理员已启用此功能）
5. **我的进度** — 快速总览您在所有课程中的活动与成绩
6. **账户与安全** — 重置密码、启用双因素认证，并了解 CAPTCHA

本指南涵盖帮助您入门的核心内容，并将随时间扩展更多主题。
