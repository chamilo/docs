# 我的进度

**我的进度** 让你在一个页面上快速总览自己在所有已选课程中的活动与成绩——无需逐门打开课程即可了解当前状况。

## 如何进入

点击侧边栏中的 **报表** <img src="../.gitbook/assets/icons/mdi-chart-box.svg" alt="报表" data-size="line"> 将其展开，然后点击 **进度**。这是仅属于你本人的视图——始终只显示你自己的数据，不会显示同学的数据。

## 你会看到什么

一张列出你所在每门课程的表格，包含：

* **课程内用时**
* **进度** — 学习路径完成百分比
* **学习路径中的最佳成绩** 与 **非学习路径中的最佳成绩** — 你的最高成绩，按是否来自嵌入学习路径的测验或独立测验分别列出
* **最近登录** — 你上次访问该课程的时间

![“我的进度”表格，列出每门已选课程的用时、进度与最佳成绩](../.gitbook/assets/student-my-progress.png)

点击任一课程旁的 **详情** 按钮，即可在不离开本页的情况下展开三张子表：

* **测验** — 你的作答次数、最佳成绩，以及在同学中的排名（若教师显示排名）
* **学习路径** — 每条学习路径的用时、进度与成绩
* **已获得技能** — 你在该课程中获得的任何能力徽章

## 你的证书

证书不在本页——请在屏幕右上角头像菜单中的 **我的证书** 下查找。该处列出你已获得证书的每门课程与每个学期，含成绩、日期，以及 **查看** 或 **下载** 按钮。

![“我的证书”页面，课程证书与学期证书分表显示](../.gitbook/assets/student-my-certificates.png)

头像菜单中还有 **我的技能** 链接，列出你已获得的能力徽章——与上述两个页面均相互独立。

## 课程内的其他位置

若干相关数据位于课程内部，而非本页：

* **评估**（成绩册）工具显示你在该课程中的成绩，有时还会显示排名、最佳成绩与班级平均分（若教师启用了相应详细程度）。
* 在成绩册结果中，你可能还会看到针对已获得技能的 **导出徽章** 选项。

## 提示

* **与教师面谈前先查看“我的进度”** — 这是一次性了解你在所有课程中所处位置的最快方式。
* **用时与进度并非同一回事** — 你可能用时很多但进度有限，或反之；请将两者结合起来判断学习状况。
* **证书在另一个菜单中** — 查找证书时请记得查看头像下的“我的证书”链接，而不是本页。
