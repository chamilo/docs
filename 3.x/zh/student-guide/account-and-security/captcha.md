# CAPTCHA

CAPTCHA 是一种简单的验证挑战——通常是输入扭曲图像中显示的字母——用于确认填写表单的是真实的人，而非自动化软件。如果管理员已启用该功能，您可能会在**登录**、**注册**和**忘记密码**表单上遇到它。

## 它保护什么

CAPTCHA 用于阻止自动化脚本滥用这些表单：

* 在**登录表单**上，它能减缓“密码穷举”——即脚本快速猜测密码以闯入账户。
* 在**注册表单**上，它能防止机器人批量创建虚假账户。
* 在**忘记密码表单**上，它能防止对密码重置电子邮件系统的自动化滥用。

简而言之，它的存在是为了保护您的账户——以及账户背后的个人数据——免受自动化攻击，而不是为难真实用户。

## 您会看到什么

一张包含扭曲字母的小图像，并带有：

* 提示：如果无法辨认，可以点击图像加载新的一张。
* 图像下方的文本字段，标注要求输入您看到的字母。

如果输入不匹配，系统会要求您用新图像再试一次。

## 反复出错

管理员可以配置在账户被临时锁定之前允许的 CAPTCHA 错误次数，以及锁定时长。如果您在多次失败尝试后被锁定，请等待锁定期结束，或在需要尽快访问时联系管理员。

## 如果您看不到它

CAPTCHA 是可选的，且作用于整个平台——如果管理员未启用，您在任何地方都不会遇到它，即使其他方面与您所用平台相似的平台上也是如此。
