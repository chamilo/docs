# 我的成绩单

如果您的平台已启用学业成绩单，您可以查看已完成且已获证书的课程记录，并下载非正式成绩单。您的机构也可能签发已签名的正式成绩单。

## 打开成绩单

1. 登录后，从顶部导航打开**我的成绩单**（当此选项可用时）。
2. 或者在已登录状态下访问您的 Chamilo 门户上的 `/transcript`。
3. 查看已完成的课程、课程代码、成绩、日期、学时、总成绩和 GPA。
4. 选择**下载非正式成绩单**，将当前记录保存为 PDF。

该记录由您仍在注册的课程和会话中根评估（成绩册）所生成的合格证书构成。如果某门课程尚未生成符合条件的证书，则可能不会显示。如果没有符合条件的课程，Chamilo 会显示**尚无已完成的课程。**

成绩等级和平均绩点取决于您的机构所配置的评分量表。除非管理员更改了相关课程和成绩的记录方式，否则 GPA 按所列课程绩点的未加权平均值计算。

## 正式成绩单

在**正式成绩单**下，您可以找到授权人员为您签发的已签名版本（如有）。每个版本都会记录签发日期和签发人。使用**下载**获取其 PDF，使用**验证**在其验证页面上检查数字签名。

正式版本是签发时您记录的快照。当后续成绩或课程发生变化时，它**不会**自动更新；您的机构可以签发更新的版本。授权人员可以撤销较早的版本，届时其公开验证页面将显示该撤销。

您无法自行签发或撤销正式成绩单。如需新的或更正后的已签名成绩单，请联系您的机构。请谨慎分享公开验证链接：持有该链接的人可能能够查看有效已签名成绩单的详细信息。

如果缺少**我的成绩单**，则您的门户可能未启用此功能。有关管理设置，请参阅[学业成绩单](../../admin-guide/users/academic-transcripts.md)。
