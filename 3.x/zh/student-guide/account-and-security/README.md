# 账户与安全

您的 Chamilo 账户可访问您的课程、成绩和个人数据——值得妥善保护。本节介绍您作为学习者可能遇到的账户保护功能。

* **[重置密码](resetting-your-password.md)** — 忘记密码或想要更改密码时该怎么做
* **[双因素认证](two-factor-authentication.md)** — 在管理员已启用的情况下，为账户增加第二层保护
* **[验证码（CAPTCHA）](captcha.md)** — 为何在登录、注册或找回密码表单上可能被要求证明您是真人

此处描述的功能并非都会在您的平台上启用——管理员可以分别开启或关闭每一项。如果本节中描述的某项内容未出现，则很可能尚未启用。
