# 一对一视频通话

Chamilo 在**浮动平台聊天**中提供可选的**一对一视频通话**。它利用浏览器的 WebRTC 支持，连接两位正在使用 Chamilo 的用户。这与**课程聊天工具**以及通过 BigBlueButton 或 Zoom 创建的会议不同。

此功能针对 [issue #3777](https://github.com/chamilo/chamilo-lms/issues/3777) 引入并改进，相关 PR 为 [#9102](https://github.com/chamilo/chamilo-lms/pull/9102)、[#9110](https://github.com/chamilo/chamilo-lms/pull/9110)、[#9112](https://github.com/chamilo/chamilo-lms/pull/9112)、[#9127](https://github.com/chamilo/chamilo-lms/pull/9127) 和 [#9128](https://github.com/chamilo/chamilo-lms/pull/9128)。

## 开始之前

* 管理员必须允许使用浮动平台聊天，并将**在全局聊天中隐藏视频聊天选项**（`chat.hide_chat_video`）设为**否**。该选项默认处于隐藏状态。请参阅[聊天设置](../admin-guide/platform-settings/chat-settings.md)。
* 请使用支持 WebRTC 的浏览器，并授予摄像头和麦克风访问权限。浏览器媒体访问通常需要 HTTPS（或受信任的本地开发环境）。
* 请先登录，并将聊天状态设为**在线**。选择普通用户联系人；对于机器人，或在该功能被禁用时，不会显示视频按钮。
* 对方必须能够接收并接听通话。

## 发起通话

1. 打开 Chamilo 底部的**浮动聊天面板**（不是课程自身的聊天页面）。
2. 选择要联系的人。
3. 在会话标题栏中，点击**开始视频通话**摄像头图标。
4. 当浏览器询问时，授予摄像头和麦克风访问权限。
5. 在 Chamilo 等待对方时，通话显示**正在呼叫...**。对方接听后，状态会经过**正在连接...**，并在对等连接成功后变为**已连接**。

未接听的通话会超时，而不会无限期持续。如果对方拒绝或取消，聊天中会显示说明性状态消息。

## 接听与管理通话

当联系人来电时，浮动聊天会显示**来电视频通话**对话框。选择**接受**以加入，或选择**拒绝**以拒接。接受时也可能请求使用摄像头和麦克风的权限。

通话期间，您可以**静音或取消静音麦克风**、**打开或关闭摄像头**以及**挂断**。小预览窗口显示您的本地视频，主区域显示对方。关闭或结束通话会释放本地音视频流。

这是**两位用户之间的私人通话**，而不是面向整个课程的会议。若要举办带有录制或协作工具的预定小组会话，请使用贵机构的[视频会议](../teacher-guide/collaboration-and-communication/video-conferencing.md)集成。

## 如果无法进行视频通话

* **没有“开始视频通话”图标：** 请检查平台的 `chat.hide_chat_video` 设置、浮动聊天是否可用、您的在线状态以及浏览器对 WebRTC 的支持。
* **摄像头或麦克风错误：** 请在浏览器中允许媒体权限，并确认硬件存在且未被其他应用程序占用。
* **无人接听：** 请让联系人打开 Chamilo 并检查其可用性。呼出请求设有超时时间。
* **接听后连接失败：** 请尝试其他网络，并检查浏览器权限或防火墙限制。当前 WebRTC 实现使用公共 STUN 服务器，且未配置 TURN 中继，因此在受限网络上连接可能失败。如果视频信令失败，文字聊天仍可使用。

此直接通话功能无需配置 BigBlueButton 或 Zoom；这些集成提供的是另一种类型的会议。
