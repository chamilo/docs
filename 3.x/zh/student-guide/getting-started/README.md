# 入门指南

本节帮助您以学习者身份熟悉 Chamilo 3.0。您将了解如何创建账户（如有需要）、登录，以及如何在主界面中找到所需功能。

## 登录

要访问 Chamilo，请打开浏览器并前往您所在机构提供的 URL（例如 `https://chamilo.yourschool.edu`）。在登录页面输入用户名和密码，然后点击 **登录**。

如果您的机构使用外部身份验证（例如 Azure、Keycloak 或大学单点登录系统），您可能会在标准登录表单下方看到额外的登录按钮。点击相应按钮，通过您所在机构的身份提供方进行身份验证。

如果您还没有账户，请参阅 [创建账户](creating-an-account.md)。

> 如果您忘记了密码，请点击登录页面上的 **忘记密码？** 链接。完整流程请参阅 [重置密码](../account-and-security/resetting-your-password.md)。

## 初识界面

登录后，您将看到 Chamilo 首页，页面分为三个主要区域：顶栏、侧边栏和主内容区。这些内容在 [了解界面](understanding-the-interface.md) 中有详细说明。

在侧边栏中，点击 **我的课程** 即可查看您已注册的所有课程。每门课程以卡片形式显示，包含课程图片、标题和快捷操作。

如果您的机构使用 **学期**（有时间限制的培训周期），您还会在侧边栏中看到 **我的学期** 链接，并按当前、已结束和即将开始的学期进行组织。学期是一门或多门课程的计划开课批次或学习群体——即在特定时期内，将相同的课程内容提供给特定学习者群体。
