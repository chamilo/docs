# 创建账户

能否自行创建账户取决于平台的配置方式。本页说明自助注册表单的预期内容，以及该功能不可用时会发生什么。

## 若自助注册不可用

并非所有 Chamilo 平台都允许访客自行注册——学校或企业通常更倾向于直接为其成员创建账户，或将注册限制为收到特定邀请的人员。如果登录页上看不到 **注册**（或 **Register**）链接，原因即在于此。此时：

* 请向您的机构或平台管理员申请为您创建账户，或
* 向教师索取 **课程邀请**——发送到您电子邮箱的一次性链接，即使在普通注册已关闭的平台上，也能让您直接注册，并在完成后立即将您加入该教师的课程。从您这一侧的界面说明，请参见 [受邀者看到的内容](../../teacher-guide/assessing-learners/subscribing-users.md#what-the-invited-person-sees)。

## 填写注册表单

若已启用自助注册，请在登录页上点击 **注册**。根据管理员的配置，表单会要求填写以下部分或全部信息：

* 电子邮箱地址和/或用户名
* 名和姓
* 密码（输入时会显示强度指示器）
* 电话号码、语言、官方代码或出生日期
* 您所在平台特有的其他个人资料字段

不必担心您的表单与上述列表不同——管理员可以显示、隐藏或设为必填各个字段。

## 此表单仅创建学员账户

默认情况下，公开注册表单完全没有以教师身份注册的选项——通过该表单创建的每个账户都是学员账户。没有下拉菜单、复选框或已禁用选项暗示教师角色；该选择根本不是表单的一部分。

部分平台会启用带有两张卡片的 **“您想做什么？”** 步骤——**学习课程** 和 **教授课程**——但仅当管理员专门开启教师注册时才会出现。即便如此，选择教授课程也可能需要账户获得批准后才能获得教师权限。

![已启用教师自助注册的平台上的注册表单，显示“学习课程”/“教授课程”角色选择器](/.gitbook/assets/student-registration-form.png)

如果您需要教师账户却看不到此选项，请向平台管理员申请为您创建，或升级您现有的账户。

## 条款与条件及 CAPTCHA

根据平台配置，表单还可能包含：

* 表单底部附近的 **条款与条件** 复选框（“我已阅读并同意条款与条件”），其上方可滚动框中显示全文。
* 表单末尾的 **CAPTCHA** 验证，要求您输入图片中显示的字母。其用途请参见 [CAPTCHA](../account-and-security/captcha.md)。

在部分平台上，提交表单后会显示确认步骤（“您确认确实要订阅此平台。”），然后才会真正创建账户——这是防止误提交的保护措施，并非额外的审批步骤。

## 提交后会发生什么

根据管理员对注册的配置，会出现以下三种情况之一：

* **立即登录**——最常见的设置，尤其适用于开放平台。
* **账户需要审批**——账户已创建但处于禁用状态，直至管理员手动批准。批准后您会收到通知。
* **需要确认电子邮箱地址**——您将收到含确认链接的电子邮件；在点击该链接之前，账户处于禁用状态。

如果不确定适用于您的是哪一种，且注册后似乎没有任何反应，请检查收件箱（包括垃圾邮件）中是否有来自平台的邮件，或联系管理员。

## 提示

* **使用您经常查看的电子邮箱地址**——密码重置、课程邀请和账户确认都会发到该地址。
* **选择强密码**——表单上的强度指示器会在您输入时提供实时反馈。
* **完全无法注册？** 请联系管理您平台的人员——许多机构和公司平台会有意关闭自助注册。
