# 提交作业

**作业**工具（有时也称为“学生作品”或“work”）用于提交论文、项目、报告，或任何其他基于文件或文本的作业，供教师评分。

## 提交作业

从课程主页打开 **作业** <img src="/.gitbook/assets/icons/mdi-inbox-full.svg" alt="作业" data-size="line"> 工具，然后打开具体作业。请仔细阅读说明——其中包含教师关于提交内容及评分方式的要求。然后：

1. 点击 **上传文件**（或提交按钮）
2. 根据教师对该作业的配置，从计算机选择文件、直接以文本撰写提交内容，或两者兼用
3. 可为教师添加可选备注
4. 提交

提交后，您会看到作业已成功提交的确认信息。如果教师允许，您可以稍后更新提交内容——否则，首次提交即为最终版本，请在提交前仔细核对。

## 截止日期

作业可以有两个不同的日期：

* **截止日期** — 此日期之后，提交仍会被接受，但会向教师标记为迟交
* **硬性截止时间** — 此日期之后，将完全无法再提交

如果作业出现在日程中，通常对应的是截止日期——若不确定何时到期，也值得在日程中查看。

## 查看成绩与反馈

教师批改您的提交后，您将看到 **分数** 以及他们撰写的任何 **反馈意见**。有些教师还会附上 **批改文件**——即您所提交内容的批注版本——因此请在成绩旁查看是否有可下载的附件。如果该作业已关联成绩册，您的分数也会计入课程总成绩。

## 查看其他提交

默认情况下，您的提交仅对您和教师可见。有些教师会选择让全班都能看到提交内容——若如此，您或许也能看到同学的作业（他们也能看到您的）。

## 提示

* **在截止日期前提交，而不是等到硬性截止时间** — 即使迟交被接受，仍会记录为迟交。
* **截止日期过后再回来查看** 成绩与反馈——评分不一定即时完成。
* **如果完全无法提交**，该作业的硬性截止时间很可能已过——若您认为这是错误，请联系教师。
