# 使用聊天工具

部分课程包含 **聊天** 工具——与该特定课程绑定的实时文字消息，便于在教师在线时进行快速交流或现场问答。

## 发送消息

从课程主页打开 **聊天** <img src="../../.gitbook/assets/icons/mdi-chat-processing.svg" alt="聊天" data-size="line"> 工具。您会看到当前在该课程中在线的所有人的 **用户** 列表，每人旁都有各自的 **聊天** 按钮，另外还有面向全体的 **全部** 选项卡：

![课程聊天工具，显示在线用户列表和消息编辑框](../../.gitbook/assets/student-course-chat.png)

选择某人（或 **全部**），在底部输入框中输入消息。按 **Enter** 发送，或按 **Shift+Enter** 换行而不发送。**预览** 选项可在发送前检查格式，**重置** 会清空已输入内容。

## 若聊天仅限辅导教师使用

管理员可将课程聊天限制为仅教师（或其他课程辅导教师）可以发帖——此时其他人只能阅读，不能直接参与。如果您发现无法在某课程的聊天中发送消息，最可能是此设置所致，而非故障。

## 请勿与以下功能混淆

Chamilo 有三种都涉及消息的不同功能，容易混淆：

* **本课程聊天工具** — 实时、绑定某一特定课程，只能从该课程主页进入。
* **[收件箱](../inbox.md)** — 与平台上任何人之间的私密、异步消息，与任何特定课程无关。
* **浮动聊天面板**（屏幕底部，几乎随处可用）— 用于直接消息以及 [AI 辅导教师](ai-tutor.md)，独立于本课程工具。

如果您要找的是另外两种功能，请参阅各自页面。

## 提示

* **用于现场、即时交流** — 若希望日后还能查找内容，请改用 [论坛](using-the-forum.md)。
* **查看是否安排了实时聊天时段** — 教师有时会公布将在课程聊天中在线的具体时间，通常通过日程表发布。
* **如果课程已配置视频会议**，教师可能更倾向于用视频会议进行实时会话，而非文字聊天。
