# 在课程中找到方向

打开一门课程后，您会看到其首页上的工具图标网格。本页说明每个工具对您作为学习者意味着什么，并链接到更详细描述底层功能的位置。

只有教师对学习者可见的工具会出现在您的网格中——教师可能还会看到额外的、对您隐藏的工具。如果您期望的某个工具不在那里，它可能只是被隐藏了，或已对整门课程禁用；请询问您的教师。

![学习者所见的课程首页工具网格](../../.gitbook/assets/student-course-tool-grid.png)

## 你不会看到的工具——以及一个无法使用的工具

有些条目仅供教师和课程管理员配置课程本身——课程设置、课程维护（备份/导入/导出）、课程主页编辑器，以及（在大多数平台上）博客工具，都位于仅对拥有课程编辑权限的人显示的“更多操作”菜单中。作为学习者，你完全看不到该菜单。

**报告** 磁贴是一个特例：它会出现在你的网格中，但打开的是面向教师的全班跟踪视图，因此点击它会得到拒绝访问的提示，而不是任何有用的内容：

![以学习者身份点击报告磁贴会得到拒绝访问的提示](../../.gitbook/assets/student-course-reporting-denied.png)

不必担心——你自己的进度可在其他位置查看：主侧边栏中的 **我的进度**（参见 [了解界面](../getting-started/understanding-the-interface.md) 和 [我的进度](../my-progress.md)），以及上文的 **课程进度** 和 **评估** 工具，二者都会显示你自己的数据。

如果课程启用了 AI 功能，你可能还会注意到教师的“AI 分析器”选项（用于根据课程自身内容预训练 AI Tutor）与面向学习者的 **AI Tutor** 聊天不同——参见 [AI Tutor 聊天机器人](ai-tutor.md)。

## 提示

* **缺少某个工具？** 请询问你的教师——最有可能是被隐藏或禁用，而不是损坏。
* **课程简介和公告** 可由教师完全关闭；若如此，则对任何人（包括教师）都不会显示。
* **此处的一切都可能因课程而异**——教师会为每门课程单独决定哪些工具处于启用状态以及是否可见。
