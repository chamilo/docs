# 跟随学习路径

**学习路径**会引导你按教师设定的顺序完成一系列结构化活动——文档、测验、链接等。在许多课程中，它是你实际需要使用的主要（甚至唯一）工具，因为它可以把其他所有内容都打包在其中。

## 打开学习路径

从课程主页打开 **学习路径** <img src="../../.gitbook/assets/icons/mdi-map-marker-path.svg" alt="学习路径" data-size="line"> 工具，然后点击其中一条即可开始。如果教师启用了 **自动启动**，你一进入课程，学习路径就可能自动打开。

![某门课程的学习路径列表，每条路径显示各自的进度](../../.gitbook/assets/student-learning-paths-list.png)

## 在路径中前进

在学习路径内部，你会看到：

* 面板中的 **项目列表**（步骤），按教师可能像章节一样分组的小节组织
* 主区域中 **当前项目的内容**——文档、嵌入式测验、链接等

完成项目后，它们会标上勾选标记，**进度条**会显示整条路径的总体完成百分比。如果你离开后再回来，会精确从上次离开的位置继续——不会丢失任何内容。

## 锁定项目与先决条件

某些项目在满足教师设定的先决条件之前可能显示为 **锁定**——通常是完成更早的项目，或在路径中更早的测验上达到最低分数。如果无法打开某一步骤，请检查更早的步骤是否仍未完成。

## 路径中的测验与证书

学习路径可以将测验作为其中一个步骤——参加测验的方式与 [参加测验](taking-tests.md) 中所述相同。有些路径以 **证书** 步骤结束：到达该步骤（并满足沿途的任何分数要求）会触发你的结业证书（如果教师已为该课程配置了证书）。

## SCORM 及其他导入内容

某些学习路径项目并非直接在 Chamilo 中构建，而是作为 **SCORM** 包、**CMI5/xAPI** 包导入，或使用 C-Studio 插件构建。它们通常看起来和表现得与其他交互式内容一样——Chamilo 会以同样的方式跟踪你的进度和分数，即使内容本身是在其他地方创作的。

## 提示

* **使用进度条** 来衡量路径还剩多少内容。
* **不必担心丢失位置** —— Chamilo 会在会话之间精确记住你在路径中的位置。
* **锁定的步骤通常意味着路径中更早的工作尚未完成** —— 请返回检查，而不是假定访问被误拒。
