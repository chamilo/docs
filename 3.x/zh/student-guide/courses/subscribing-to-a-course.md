# 订阅课程

在访问课程内容之前，您需要先订阅（注册）该课程。根据平台设置的不同，订阅可通过几种方式完成——其中大多数无需您采取任何操作。

| 发生方式 | 您需要做的 |
|-----------------|----------------------|
| 管理员为您注册 | 无需操作——完成后课程会出现在 **我的课程** 中 |
| 教师手动为您注册 | 无需操作——同上 |
| 您通过课程目录自行注册 | 浏览 **探索更多课程**，然后点击加入 |
| 您收到课程邀请电子邮件 | 点击链接；若尚无账户则先注册 |

## 查看您的课程

随时点击侧边栏中的 **我的课程**，即可查看您当前已注册的全部课程。如果您期望的课程未列出，说明您尚未被订阅——请使用下列方法之一，或联系您的教师或管理员。

## 通过课程目录自行注册

如果课程的可见性允许，您可以自行订阅，无需等待他人：

1. 点击侧边栏中的 **探索更多课程**，打开课程目录。
2. 浏览或搜索您想加入的课程。
3. 点击课程打开详情，然后点击加入按钮。

![课程目录，每张课程卡片上有“订阅”按钮](/.gitbook/assets/student-course-catalogue.png)

您已注册的课程会显示 **进入课程**，而不是订阅按钮。

部分课程自行注册需要密码——如有需要，教师会另行告知。如果课程完全没有加入按钮，则该课程未开放自行注册；请让教师或管理员为您订阅。

如果您的平台使用 **学期（sessions）**，同样的思路适用于 **我的学期**——部分学期可能通过目录开放自行注册，不过更常见的是由管理员或学期导师管理，因为订阅学期会同时订阅其中的全部课程。

## 接受课程邀请

教师也可能不通过目录列出，而是通过电子邮件向您发送 **课程邀请**——这是唯一一种不要求您已有平台账户的方式。打开邮件中的链接将：

* 在注册表单上预填并锁定电子邮件字段为您的受邀地址。
* 即使平台当前关闭了一般自行注册，也允许您注册。
* 注册完成后自动将您订阅到该课程（若课程在某个学期中开放，则订阅整个学期），并为您登录。

该链接仅可使用一次，并在 7 天后过期——如果链接失效，请让邀请您的教师重新发送。有关此流程的更多细节，请参阅 [受邀者看到的内容](../../teacher-guide/assessing-learners/subscribing-users.md#what-the-invited-person-sees)；注册表单本身的外观请参阅 [创建账户](../getting-started/creating-an-account.md)。

## 提示

* **询问之前先查看“探索更多课程”** — 许多平台开放课程自行注册，因此您可能无需等待即可立即加入。
* **留意收件箱** — 课程邀请和账户审批通知都会通过电子邮件送达。
* **仍然无法进入？** 注册方式可能在全平台范围内被限制或禁用，因此如果以上方法均无效，您的教师或管理员始终可以直接为您订阅。
