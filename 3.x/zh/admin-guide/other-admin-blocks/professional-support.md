# 专业支持

专业支持是一个只读的小型面板，用于介绍官方 Chamilo 支持服务——如果您的组织需要超出社区支持范围的付费帮助，该面板会很有用。

## 显示内容及其来源

该面板从 `version.chamilo.org/c/support/latest.php` 获取内容，并按您平台的界面语言请求。平台唯一发送的信息是该语言代码——不会发送任何与平台使用情况或配置相关的信息。

## 用途

该面板具有信息介绍与推广性质：它引导管理员了解 Chamilo 的官方服务提供商（咨询、托管、定制开发以及认证支持），面向希望签约认证合作伙伴、而非仅依赖社区论坛的组织。另请参阅 [Chamilo.org 链接](chamilo-org-links.md)，该页面直接链接到官方提供商列表。
