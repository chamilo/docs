# 版本检查

版本检查会告知您当前的 Chamilo 安装是否为最新版本；若您选择加入，还会将您的平台注册到 Chamilo 项目，以便计入汇总使用统计。

## 两种检查级别

**未注册（默认状态）：** Chamilo 仍会尝试联系 `version.chamilo.org`，将您已安装的版本与最新发行版进行比较，所用信息仅限于请求本身——不会发送任何平台详情。该区块会显示一份注册表单，说明注册可带来的额外功能，以及一个 **“启用版本检查”** 按钮和一个 **“不在公开平台列表中显示本校区”** 复选框。

**已注册：** 点击“启用版本检查”只会切换两项本地设置——其本身并不会发送任何数据。此后，每当该仪表板区块加载时，您的平台都会向 `version.chamilo.org` 发送请求，其中包含：

| 发送的数据 | 所述用途 |
|-----------|-----------------|
| 您平台的 URL 与站点名称 | 标识正在签到的门户 |
| 管理员联系电子邮件 | 明确用于 Chamilo 团队就关键安全问题联系管理员 |
| 已安装版本 | 用于判断您是否为最新版本 |
| 课程、用户、活跃用户及学期数量 | 汇总为 `stats.chamilo.org` 上的非个人聚合统计 |
| 组织名称与界面语言 | 仅用于人口统计类汇总 |
| 管理员姓名 | 会被发送，但其用途在代码本身中并无明确说明 |
| 您服务器的 IP 地址 | 用于估算平台位置，以绘制全球安装分布图 |
| “不列出校区”标志、打包方以及唯一实例 ID | 控制您是否出现在公开目录中，并识别同一安装的重复签到 |

若您未勾选 **“不在公开平台列表中显示本校区”**，您的平台还会出现在 `version.chamilo.org/community.php` 的公开社区列表中。

## 访问版本检查

该区块直接显示在管理仪表板上——无需访问单独页面。

## 是否应当启用？

这是一项明确的选择加入机制，权衡也很直接：作为分享上述详情的交换，您会在有新版本（包括安全补丁）可用时自动收到通知，并贡献于 Chamilo 的公开采用统计。若您不愿分享任何平台详情，只需不要点击“启用版本检查”——基础的是否最新检查仍会在不注册的情况下运行。若您希望收到更新通知但不希望出现在公开列表中，请注册并勾选“不在公开平台列表中显示本校区”。
