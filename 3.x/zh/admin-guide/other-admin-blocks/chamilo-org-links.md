# Chamilo.org 链接

**Chamilo.org** 区块是指向官方 Chamilo 资源的静态外链列表——仅此而已。它不会向任何地方发送数据；每条链接要么打开外部 Chamilo 站点，要么打开随安装包附带的本地文档页面。

## 区块内容

| 链接 | 目标 |
|------|-------------|
| Chamilo 主页 | `chamilo.org` |
| 用户指南 | `docs.chamilo.org` |
| Chamilo 论坛 | chamilo-lms 的 GitHub Discussions |
| 安装指南 | 本地，`/documentation/installation_guide.html` |
| 上一版本变更 | 本地，`/documentation/changelog.html` |
| 贡献者名单 | 本地，`/documentation/credits.html` |
| 安全指南 | 本地，`/documentation/security.html` |
| 优化指南 | 本地，`/documentation/optimization.html` |
| Chamilo 官方服务提供商 | `chamilo.org/providers` |

“本地”链接指向随您的 Chamilo 安装本身捆绑的文档文件，因此它们从您自己的服务器加载，而不是从 chamilo.org 加载。

## 用途

此区块纯粹为方便而设——可快速访问项目的官方文档、社区讨论空间以及经过审核的服务提供商列表，无需另行搜索。
