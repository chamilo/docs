# 来自 Chamilo 的新闻

「来自 Chamilo 的新闻」是一个小型只读面板，用于拉取 Chamilo 协会的官方公告——您可在此获知新版本发布，更重要的是，获知您应当应用的安全补丁。

## 显示内容及其来源

该面板从 `version.chamilo.org/c/news/latest.php` 获取内容，并按您平台的界面语言请求。平台仅发送该语言代码——此功能不会将任何平台详情、使用数据或联系信息发送出您的服务器。

## 用途

这是 Chamilo 直接向管理员传达运营相关事项的渠道：新版本发布，以及——最重要的——**安全补丁**。及时应用安全补丁是保障平台安全最有效的措施之一（参见 [安全指南](../appendix/security-guide.md)），因此值得定期查看此面板，而不是仅在偶尔想起时才检查。

此信息源的加载独立于 [版本检查](version-check.md)——您无需注册平台即可查看。
