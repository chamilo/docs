# 其他管理区块

管理仪表盘上还有若干区块，它们并非可配置功能，而更像是信息类小组件：一个出站链接页面、一个版本检查注册，以及两个从 chamilo.org 拉取内容的小型面板。本章说明每一项的含义、内容来源，以及——由于其中部分会——是否有任何数据离开您的平台。

## 涵盖内容

* **[Chamilo.org 链接](chamilo-org-links.md)** — 指向官方 Chamilo 资源的书签列表；不发送任何数据
* **[版本检查](version-check.md)** — 可选注册，向 chamilo.org 报告您平台的版本与使用情况，并告知您是否需要更新
* **[专业支持](professional-support.md)** — 只读面板，介绍官方 Chamilo 支持提供商
* **[来自 Chamilo 的新闻](news-from-chamilo.md)** — 官方公告的只读动态，包括安全补丁与新版本发布

以下各页均会明确说明向 chamilo.org 发送了什么（如有），以及原因。
