# 用户画像

Chamilo 允许您定义自定义档案字段（扩展字段），以便在标准的姓名、电子邮件和角色之外采集更多用户信息。

## 扩展档案字段

![扩展档案字段列表，显示带有名称、类型和可见性设置的自定义字段](/.gitbook/assets/admin-extra-fields-list.png)

扩展字段可用于存储与您所在机构相关的元数据，例如：

* 员工编号
* 部门
* 职位
* 地点/办公室
* 电话号码
* 自定义标识符

## 创建扩展字段

1. 在管理面板中，转到 **Extra fields** 或 **Profile fields**
2. 点击 **Add**
3. 配置该字段：
   * **Name** — 向用户显示的字段标题
   * **Description** — 可选说明
   * **Helper text** — 将显示在包含该字段的任何表单中该字段下方
   * **Field type** — 文本、下拉、日期、复选框等
   * **Field label** — 字段的内部名称，用于插件集成
   * **Possible values** — 若该字段为在这些值之间进行选择的选择器
   * **Default value** — 可选的默认值
   * **Visible to self** — 该字段是否由用户本人在其用户档案上可见
   * **Visible to others** — 该字段是否对平台上的其他用户可见
   * **Can change** — 用户是否可以自行修改自己的该字段（或仅管理员可以修改）
   * **Filter** — 若为选择器类型字段，是否将其作为管理页面中的筛选条件（例如将用户注册到课程或学期）
   * **Order** — 若要管理字段的显示顺序，需为每个字段指定一个数字顺序
   * **Remove on anonymization** — 对隐私规则与法律很重要：若用户被匿名化但未被删除，该字段是否应被视为可能包含个人身份信息的数据？
4. 保存

## 字段类型

扩展字段引擎支持多种输入类型。常见类型包括：

| Type | Description |
|------|-------------|
| **Text** | 单行文本输入 |
| **Textarea** | 多行文本输入 |
| **Radio** | 单选单选按钮组 |
| **Dropdown / Dropdown multiple** | 预定义选项列表（单选或多选） |
| **Double select** | 两个相互依赖的下拉框（例如：国家 → 城市） |
| **Checkbox** | 是/否开关 |
| **Date / Date and time** | 日期或日期+时间选择器 |
| **Integer** | 数字输入 |
| **Tag** | 多个自由格式标签值 |
| **File** | 文件上传字段 |
| **Video URL** | 指向视频的 URL |
| **Mobile phone number** | 格式化的电话号码字段 |
| **Timezone** | 时区选择器 |
| **Social profile** | 指向社交网络档案的链接 |
| **Divider** | 表单内的视觉分隔符（无值） |

可用类型的确切集合取决于 Chamilo 版本；**Extra fields** 管理页面中的字段类型下拉列表是权威来源。

## 使用扩展字段

扩展字段会出现在：

* 用户创建（若对本人可见）和编辑表单中
* 用户档案页面上（若对本人可见）
* 用户导入中（可在 CSV 导入中包含扩展字段值）
* 导出和报表中（按扩展字段值筛选或分组）

## 提示

* **创建前先规划** — 在创建字段前明确所需信息，因为在已录入数据后更改字段类型可能带来问题
* **使用下拉框以保证一致性** — 当字段具有已知的可能值集合时，使用下拉框而非自由文本，以确保数据一致性
* **用于报表** — 扩展字段可用于筛选报表（例如：“显示部门 X 中已完成培训 Y 的所有用户”）
