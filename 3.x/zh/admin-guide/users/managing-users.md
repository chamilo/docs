# 管理用户

本页介绍创建、编辑和管理用户账户的日常操作。

## 用户列表

![用户列表，显示账户的姓名、电子邮件、角色和状态列](../../.gitbook/assets/admin-user-list.png)

在管理面板中，点击 **用户列表** 可查看平台上的所有用户。列表显示：

* 头像
* 姓名
* 用户名
* 电子邮件地址
* 角色
* 启用/停用状态
* 注册日期
* 上次登录日期

使用 **高级搜索** 工具，可按姓名、电子邮件、角色或其他条件查找特定用户。

## 创建用户

![用户创建表单，包含姓名、电子邮件、用户名、密码、角色和语言字段](../../.gitbook/assets/admin-user-create-form.png)

1. 在管理面板中点击 **添加用户**
2. 填写必填字段：
   * **名** 和 **姓**
   * **电子邮件** — 在平台上必须唯一
   * **用户名** — 登录名（必须唯一）
   * **密码** — 设置初始密码
   * **角色** — 选择用户的平台角色（学生、教师、管理员等）
   * **语言** — 用户首选的界面语言
3. 可选择填写其他字段：
   * 官方代码（例如组织内的唯一 ID）
   * 电话号码
   * 到期日期 — 在指定日期后自动停用账户
   * 启用/停用状态
   * 额外个人资料字段（如已配置）
4. 保存

## 导入用户

![用于上传包含用户数据的 CSV 或 XML 文件的用户导入界面](../../.gitbook/assets/admin-user-import.png)

如需批量创建用户，可以从文件导入用户：

1. 在管理面板中点击 **导入用户**
2. 上传包含用户数据的 **CSV** 或 **XML** 文件
3. 将文件列映射到 Chamilo 用户字段
4. 选择如何处理已有用户（更新或跳过）
5. 导入

导入文件至少应包含以下列：名、姓、电子邮件、用户名和密码。

注意：**Status** 列是 **Role** 的旧名称，仅接受少数几个值，例如 1 表示教师、5 表示学生。角色的进一步调整只能稍后通过手动编辑用户来完成。

## 导出用户

点击 **导出用户**，可将用户列表下载为 CSV 或 XML 文件。您可以按角色、注册日期或其他条件筛选要导出的用户。

## 编辑用户

在用户列表中点击用户姓名即可编辑其账户。您可以修改：

* 个人信息（姓名、电子邮件、电话）
* 角色
* 密码（重置）
* 启用/停用状态
* 到期日期
* 额外个人资料字段

## 删除用户

删除在平台上创建过内容的用户（通常是教师）时，系统可能会阻止您永久删除这些用户，并显示警告消息，说明该用户仍关联到某些资源。如果您确认删除，系统不会删除内容本身，而是将其挂接到一个中性用户（我们称之为“回退用户”），以保持数据一致性。

为避免这种情况，请查看用户详情，逐一删除其每门课程，然后再删除该用户。

## 用户操作

| 操作 | 说明 |
|--------|-------------|
| **停用** | 禁用用户账户但不删除。用户无法登录，但其数据予以保留。 |
| **启用** | 重新启用先前已停用的账户。 |
| **以此身份登录** | 以该用户身份登录平台（模拟登录）。适用于故障排查。 |
| **匿名化** | 按照欧盟 GDPR 的定义，擦除该账户的全部个人信息。 |
| **删除** | 软删除用户账户。使用 **已删除用户** 选项卡可永久删除账户及相关数据。 |

> **以此身份登录** 是一项强大功能。请负责任地使用，且仅用于正当的支持目的。

## 批量操作

在用户列表中选择多个用户以执行批量操作：

* 一次性启用或停用多个用户
* 删除多个用户
* 将用户分配到课程或学期

## 提示

* **大规模注册请使用 CSV 导入** — 在培训项目开始时为大量用户办理入职时，请准备 CSV 文件并批量导入
* **设置到期日期** — 对于临时用户（工作坊参与者、试用用户），设置到期日期以自动停用其账户
* **优先停用而非删除** — 用户离开时，请先停用其账户。这样可保留其培训记录。仅在确定不再需要数据时再删除。
