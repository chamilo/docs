# 学业成绩单

Chamilo 可根据学习者已完成且已获证书的课程生成**非官方学业成绩单**，并允许授权人员签发**经签署的官方成绩单**。此功能不同于单门课程证书或其可选的 Sepolia 测试网验证。

## 启用该功能

在 **管理 > 配置设置 > 证书** 中，启用 **学业成绩单**（`certificate.transcript_enabled`）。该功能默认处于禁用状态。请在 [证书设置](../platform-settings/certificate-settings.md#transcript_enabled) 中查看其他项目、评分等级、课程学时、学号、地址及签署人相关设置。

成绩单使用符合条件的课程和会话的**根成绩册类别**所生成的证书。它仅包含学习者在当前访问 URL 下仍已订阅的课程。没有符合条件证书的课程不会生成一行记录。

所显示的最终成绩是所列课程百分制分数的平均值；GPA 是映射后成绩点数的非加权平均值。二者均取决于查看或签发时纳入的课程。

## 成绩单列

| 列 | 内容 |
|--------|---------|
| **课程** | 课程代码，或课程的院系名称（`transcript_course_code_source`） |
| **说明** | 课程标题；若课程在会话中学习，还包括会话标题 |
| **注册** | 学习者订阅课程或会话的时间 |
| **要求学时** | `transcript_hours_extra_field` 中设置的课程附加字段值，或课程时长 |
| **完成日期** | 证书日期 |
| **已完成学时** | 学习者在课程中花费的时间；若启用 `transcript_completed_hours_are_required_hours`，则为要求学时 |
| **最终成绩** | 证书分数 |
| **等级** | 与该分数匹配的 `transcript_grading_scale` 字母等级 |

## 访问学习者的成绩单

1. 前往 **管理 > 用户 > 用户列表** 并找到该学习者。启用该功能后，授权管理员和会话管理员可使用 **成绩单** 操作。
2. 或者，从符合条件的学习者的全局报告详情页使用 **成绩单** 操作。
3. 查看学习者的课程列表、成绩、日期、学时、最终成绩和 GPA。
4. 选择 **下载非官方成绩单**，以根据学习者当前记录生成 PDF。

成绩单页面也可通过 `/transcript?userId=<user-id>` 直接访问，但仅限有权访问该学习者记录的人员。不得将知晓 URL 或用户 ID 视为授权：访问权限在服务器端进行校验。

学习者可以查看其**本人**的成绩单，但不能签发或撤销官方成绩单。授权签发人包括：

* 在其管理的用户/访问 URL 范围内行事的平台/门户管理员。
* 负责所跟踪学习者的人力资源经理。
* 对其所管理会话中已注册学习者负责的会话管理员。

这些权限按学习者逐一评估；仅拥有工作人员角色本身并不能授予访问每份成绩单的权限。

## 签发并验证官方成绩单

1. 在已授权学习者的成绩单页面上，核对当前显示的课程、成绩和个人信息。
2. 选择 **签发官方成绩单** 并确认。Chamilo 会保存该时刻信息的已签署快照。
3. 新条目将显示在 **官方成绩单** 下，并包含签发日期和签发人。
4. 使用 **下载** 获取官方 PDF，或使用 **验证** 打开公开验证页面。
5. 如有需要，授权签发人可以 **撤销** 该官方成绩单。届时验证页面将报告该成绩单已撤销。

每份已签发的成绩单均单独存储：签发较新版本不会悄然改写先前的已签署记录。验证链接遵循 `/transcripts/verify/<token>`，并同时提供 `.json` 响应。持有验证链接的人员无需登录即可核验有效性；请妥善控制这些链接，因为有效验证会公开已签署成绩单的详细信息。无效或已撤销的记录不会作为有效文件呈现。

![有效官方成绩单的公开验证页面，包含其详细信息和课程](../../.gitbook/assets/admin-transcript-verification.png)

官方成绩单由 Chamilo 使用机构的签名密钥进行数字签名。**它不是区块链交易**；Sepolia 功能记录的是成绩册证书凭证的另一套独立流程。

## 签名图像与签署人信息

平台管理员可在学习者成绩单页面的 **正式成绩单签名** 部分上传 **PNG 或 JPEG** 签名图像。该图像属于当前访问 URL，并用于正式 PDF。签署人姓名与职务来自 `certificate.transcript_signatory_name` 和 `certificate.transcript_signatory_title`。

仅平台管理员可管理签名图像；其他获授权的成绩单签发者不会自动获得此权限。请将机构的签名密钥与私有签名图像存储纳入门户的备份与访问控制流程加以保护。二者均保存在公共 Web 文件夹之外的 `var/certificate-issuer/` 中，并与同样用于签署成绩册证书凭证的密钥存放在一起：请将此文件夹纳入您的[备份](../maintenance/backups.md)，否则已签发的每份成绩单与凭证都将无法再被验证。

## 故障排除

* **成绩单链接缺失：** 请检查 `certificate.transcript_enabled` 以及当前用户的权限范围。
* **没有已完成的课程：** 学习者需要一份符合条件的根成绩册证书，以及在此访问 URL 上与之匹配的当前课程/会话注册。
* **学号、学时、成绩等级或项目名称不正确：** 在签发正式成绩单之前，请检查相应的 `certificate.transcript_*` 设置。
* **验证报告为已撤销或无效结果：** 请勿将该记录再次用作当前正式成绩单的证明；获授权人员可在适当时签发新的成绩单。
