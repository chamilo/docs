# 用户角色

Chamilo 采用基于角色的权限系统。每位用户会被分配一个角色，该角色决定其在平台上可见与可执行的操作。

## 平台级角色

这些角色控制对平台范围功能的访问：

| 角色 |  说明 |
|------|------------|
| **学员（学生）** | 默认角色。可报名课程、访问学习内容、提交作业并参加测验。 |
| **教师（培训师）** | 可创建和管理课程、添加内容、为学生评分，并查看课程级报表。 |
| **学期管理员** | 可创建和管理学期（即基于时间的课程包）、将用户编入学期并指定辅导教师。无法访问通用平台设置。 |
| **人力资源经理（HRM）** | 可查看所分配用户的跟踪与报表数据。适用于需要监督员工培训、但无需管理内容或平台的主管。 |
| **门户管理员** | 拥有全部平台管理功能的完整权限。可管理用户、课程、学期、插件及所有设置。 |
| **全局管理员** | 与门户管理员相同，但在多 URL（即多租户）环境中可访问所有访问 URL；若注册在非根 URL 上，则仅限于该 URL 分支。参见 [子树管理员](../multi-url/access-urls.md#subtree-administrators)。 |
| **匿名用户** | 面向未登录访客的特殊角色。在启用时，可访问公开课程与内容。 |

## 课程级角色

在课程内，用户具有特定角色：

| 角色 | 说明 |
|------|-------------|
| **学生** | 默认课程角色。可访问内容、参加测验、提交作业。 |
| **课程助理** | 在课程内拥有有限的管理权限。可协助管理内容并主持论坛。 |
| **教师** | 对课程拥有完全控制权：管理内容、工具、设置和报名。 |

## 学期级角色

在学期内，还存在额外角色：

| 角色 | 说明 |
|------|-------------|
| **学期辅导教师** | 监督学期内的全部课程。可查看该学期所有课程的跟踪数据。 |
| **课程辅导教师** | 在学期内教授特定课程。可管理该学期该课程的内容并跟踪学员。 |

说明：在 Chamilo 3.0 之前的版本中，此角色称为“coach”。自 Chamilo 3.0 起，平台界面与文档中已全面将“coach”替换为“tutor”——辅导教师是帮助学员完成课程的人，而非私人教练。`Configuration settings` 中的底层设置名称仍保留 “coach” 以保持向后兼容（例如 `add_users_by_coach`），但其标签现已显示为“tutor”。

## 分配角色

在管理面板中创建或编辑用户账户时，选择其平台级角色。课程与学期角色在将用户编入课程或学期时分配。

## 角色层级

权限较高的角色继承权限较低角色的能力：

* 管理员可执行教师能执行的全部操作
* 教师可执行学生能执行的全部操作
* 学期级角色（辅导教师）仅在其被分配的学期内提供额外能力

## 提示

* **遵循最小权限原则** — 为用户分配完成其任务所需的最低角色
* **使用学期管理员进行委派管理** — 若有员工需要管理培训学期而非整个平台，请授予其学期管理员角色，而非完整管理员权限
* **为主管使用 HRM** — 人力资源经理可监督培训进度，而无需获得修改课程或平台设置的权限
* **角色创建** — Chamilo 3.x 已具备创建新角色的内部结构，但该功能尚需更多测试方可广泛发布。可通过 [Chamilo 官方服务商](https://chamilo.org/providers) 启用。
