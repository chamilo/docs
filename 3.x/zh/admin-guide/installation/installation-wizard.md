# 安装向导

Chamilo 3.0 包含基于 Web 的安装向导，可引导您完成初始设置。首次访问平台时，向导会自动运行。

## 开始之前

请确保已满足以下先决条件：

1. 您的服务器满足全部 [服务器要求](server-requirements.md)。
2. 您已下载 Chamilo 的打包版本（zip 或 tar.gz）。
3. 您的 Web 服务器已配置为将 `public/` 目录作为文档根目录。
4. 您的 `.env` 文件已存在且为空（向导将引导完成数据库设置）。

## 第 1 步：安装语言

![安装向导第 1 步 — 语言选择](/.gitbook/assets/install-step1-language.png)

第一步可让您选择安装过程所用的语言。请从下拉列表中选择首选语言。

如果 Chamilo 检测到已有安装（用于升级），将显示迁移状态，并提供升级路径，而非全新安装。

## 第 2 步：要求检查

![安装向导第 2 步 — 要求检查，显示 PHP 版本、扩展和目录权限](/.gitbook/assets/install-step2-requirements.png)

向导会检查您的服务器环境：

* **PHP 版本** 为 8.3、8.4 或 8.5
* **所需 PHP 扩展** 已安装（intl、gd、curl、zip、mbstring、xml 等）
* **推荐的 PHP 设置** — 已配置 `date.timezone`，上传/内存限制充足
* **目录和文件权限** — `var/`、`config/` 和 `public/upload/` 可由 Web 服务器写入

如有任何要求未满足，向导会显示警告或错误。请在继续之前予以解决。

## 第 3 步：许可证

![安装向导第 3 步 — 接受许可证](/.gitbook/assets/install-step3-license.png)

此步骤显示 GNU/GPLv3 许可证。您必须勾选 **“I accept”** 复选框才能继续。

您还可以选择展开 **联系信息** 部分，提供有关您所在组织的详细信息（名称、电子邮件、公司、国家/地区）。此项为自愿填写，有助于 Chamilo 社区了解平台的使用者，同时也使我们能够*极少地*就您附近发生的活动与您联系。

## 第 4 步：数据库设置

![安装向导第 4 步 — 数据库连接配置](/.gitbook/assets/install-step4-database.png)

输入您的数据库连接详细信息：

| 字段 | 说明 |
|-------|-------------|
| **数据库主机** | 数据库服务器的主机名或 IP（例如 `localhost` 或 `127.0.0.1`） |
| **数据库端口** | 默认：MySQL/MariaDB 为 3306 |
| **数据库名称** | 要使用的数据库名称（仅限字母数字和下划线） |
| **数据库用户** | 对指定数据库拥有完整权限的数据库用户 |
| **数据库密码** | 该数据库用户的密码 |

单击 **检查数据库连接** 进行测试。在连接成功之前，向导不允许您继续。如果数据库已存在，将显示警告。

## 第 5 步：配置设置

![安装向导第 5 步 — 管理员账户、门户设置和电子邮件配置](/.gitbook/assets/install-step5-config.png)

此步骤将管理员账户创建、门户设置和电子邮件配置合并在一起。

### 管理员账户

| 字段 | 说明 |
|-------|-------------|
| **登录名** | 管理员用户名 |
| **密码** | 请选择强密码 — 此账户拥有完整的平台访问权限 |
| **名** | 管理员的名 |
| **姓** | 管理员的姓 |
| **电子邮件** | 用于系统通知和密码重置 |
| **电话** | 可选联系电话 |

这些管理员详细信息也将由 Chamilo 用于填充支持联系信息，因此请务必在安装完成后到设置中重新配置该项。

### 门户设置

| 字段 | 说明 |
|-------|-------------|
| **语言** | 默认界面语言 |
| **门户名称** | 您的平台名称（例如 “My Organization LMS”） |
| **公司简称** | 您所在组织的缩写名称 |
| **公司 URL** | 您所在组织的网站 |
| **加密方法** | 密码哈希算法 — 推荐使用 **bcrypt** |
| **允许自行注册** | 是 / 否 / 审批后 |
| **允许自行注册为培训师** | 是 / 否 |

### 电子邮件配置

电子邮件设置部分可让您配置邮件传输（SMTP、Amazon SES、Mailjet 等）并测试邮件投递。详情请参阅 [电子邮件配置](email-configuration.md)。

所有这些设置均可稍后在管理面板中更改。

## 第 6 步：安装前的最后检查

![安装向导第 6 步 — 安装前核对所有设置](/.gitbook/assets/install-step6-review.png)

本步骤会显示您所填写全部信息的摘要，供您核对：

* 管理员凭据（密码默认隐藏 — 点击眼睛图标可显示）
* 门户设置
* 数据库连接详情

请仔细核对，然后点击 **Install Chamilo** 执行安装。向导将创建所有数据库表、填充初始数据，并完成平台配置。

## 第 7 步：安装完成

![安装向导第 7 步 — 完成页面，含安全建议与门户链接](/.gitbook/assets/install-step7-complete.png)

安装成功完成后，向导会显示：

* **入门建议** — 建议创建您的第一门课程以探索平台（作为管理员，需从管理面板进行此操作）
* **安全建议**：
  * 将 `config/` 目录设为只读（`chmod 0555`）
  * 删除 `public/main/install/` 目录
* 一个**指向您门户的链接**，可使用刚刚创建的管理员凭据登录

## 安装之后

完成向导后：

* **移除或限制对安装程序的访问** -- 安装完成后不应再能访问向导。Chamilo 通常会自动锁定，但请确认再次访问安装 URL 会重定向到登录页。
* **配置邮件发送** -- 参见 [电子邮件配置](email-configuration.md)。
* **设置备份** -- 在添加内容之前，配置自动化的数据库与文件备份（Chamilo 不提供此方案，但复制 var/ 文件夹以及数据库是最重要的两项）。
* **检查安全设置** -- 参见 [安全设置](../platform-settings/security-settings.md)。

## 故障排除

| 问题 | 解决方案 |
|---------|----------|
| 访问安装 URL 出现空白页 | 检查 PHP 错误日志。临时在 .env 中将 `APP_ENV=dev` 以在浏览器中查看错误。 |
| 数据库连接失败 | 核对凭据，确认数据库已存在，并检查数据库服务器是否允许来自 Web 服务器主机的连接。 |
| 权限被拒绝错误 | 确保 Web 服务器用户对 `var/` 具有写权限。 |
| 资源未加载（无 CSS/JS） | 运行 `yarn install && yarn build` 以编译前端资源。 |
