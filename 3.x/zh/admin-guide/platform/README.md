# 平台

管理仪表盘上的 **平台管理** 区块汇总了门户范围的配置与沟通工具——从完整设置面板到语言、公共公告、全局日历，以及用于构建门户对外公开内容的类 CMS 页面系统。

![管理仪表盘上的平台管理区块，列出配置设置、语言、插件、区域、门户新闻、全局日程、页面、设置注册页、额外字段、配置多访问 URL、邮件模板、外部工具 (LTI)、联系表单分类和系统模板](../../.gitbook/assets/admin-platform-block.png)

## 访问平台区块

在管理面板中，**平台管理** 区块与其他仪表盘区块并列显示。点击其中任一链接即可打开对应工具。

## 区块内容

* **[平台设置](../platform-settings/README.md)** — 完整配置设置面板（门户、课程、学期、用户、安全等）。本区块中的“配置设置”链接只是进入该独立章节的入口。
* **[语言](languages.md)** — 选择向用户提供哪些界面语言，并设置平台默认语言
* **[门户新闻](portal-news.md)** — 平台范围公告（系统公告），可按角色定时发布并定向投放
* **[全局日程](global-agenda.md)** — 平台范围日历事件，对所有用户可见，与课程或学期无关
* **[页面](pages.md)** — 支撑门户首页、页脚及其他公开内容区块的类 CMS 工具，包括注册页的介绍文字
* **[平台工具](platform-tools.md)** — 额外字段、邮件模板、联系表单分类，以及若干较小的、按条件显示的项目
* **配置多访问 URL** — 见 [访问 URL](../multi-url/access-urls.md)，位于多 URL 章节下
* **外部工具 (LTI)** — 见 [LTI 1.3](../integrations/lti.md)，位于集成章节下
