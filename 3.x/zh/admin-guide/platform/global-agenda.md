# 全局日程

全局日程与课程日程和个人日程使用的是同一套日历工具，只是以平台范围模式打开：在此创建的事件不关联任何课程或会话，正因如此，所有已登录用户都能看到这些事件，而不仅限于某门课程或某个会话的成员。

## 访问全局日程

在管理面板中，点击 **平台 > 全局日程**。

## 与课程日程和会话日程的区别

日历事件的可见范围取决于它是否关联到课程或会话资源：

* **课程/会话事件** 仅对该课程或会话的已注册成员可见
* **全局事件** 没有此类关联，因此任何已登录用户都可以看到

除了上述范围差异外，全局事件支持与课程事件相同的功能：**重复**（按计划重复）、**文件附件** 和 **提醒**。

## 使用场景

将全局日程用于与任何特定课程无关的平台级日期——维护窗口、全机构截止日期、节假日或全公司活动——而无需在每门课程的日程中重复创建同一事件。
