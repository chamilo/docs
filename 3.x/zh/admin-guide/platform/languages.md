# 语言

此工具用于管理用户可选择的界面语言——它并不管理翻译字符串本身（翻译字符串来自随 Chamilo 一并提供的语言包，无法在此处编辑）。

## 访问语言设置

在管理面板中，点击 **平台 > 语言**。

## 您可以执行的操作

* **切换可用性** — 通过每行一个简单的开/关开关，启用或禁用各随附语言，使其出现在登录页和用户个人资料设置中供选择
* **设置平台默认语言** — 选择在没有用户偏好时使用的语言；当前默认语言会以专用图标标记，且无法隐藏
* **除默认语言外全部禁用** — 一项批量操作，将语言选择器精简为仅保留平台默认语言
* **编辑本地名称** — 调整某种语言在选择器中显示的自身名称（其“原始名称”）

## 禁用正在使用的语言

如果您禁用了活跃用户已选为界面语言的某种语言，Chamilo 会要求确认，并在您确认后将所有受影响用户迁移到平台默认语言。不会出现用户仍选中现已隐藏语言的中间状态。

## 从右到左的语言

从右到左的语言（如阿拉伯语、希伯来语或波斯语）在被选中时会自动将界面切换为从右到左布局——无需在此处或别处进行任何配置。近期版本中对 RTL 支持已有显著改进。

## 子语言

若启用了 **允许子语言** 设置，将出现用于创建“子语言”的额外操作——即对父语言的部分覆盖，历史上用于地区方言或组织特定术语调整。这是一项遗留功能；大多数安装无需使用。
