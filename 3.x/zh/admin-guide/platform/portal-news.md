# 门户新闻

尽管仪表盘上的标签为“门户新闻”，此工具实际管理的是**系统公告**——可按计划发布、按角色定向，并可选择通过电子邮件发送的全平台消息。

## 访问门户新闻

在管理面板中，点击 **平台 > 门户新闻**。

## 创建公告

每条公告包含：

* **标题** 与富文本 **内容**
* **开始与结束日期** — 默认从今天起至 7 天后；仅当当前日期落在此范围内时，公告才可见
* **语言** — 特定语言，或全部语言
* **角色（受众）** — 包括未登录访客，因此可将公告定向给匿名用户、特定已登录角色，或两者的组合
* **用户组** — 可选择将公告限制为特定用户组
* **职业路径** — 若启用了 **将全局公告与职业路径及晋升关联** 设置，还可将公告限定到特定职业路径/晋升路径

## 通过电子邮件发送

除在界面上显示公告外，您还可以：

* **发送邮件** — 将公告以电子邮件发送给目标受众中的所有人
* **向自己发送测试邮件** — 在正式发送前预览收件人将收到的内容
* **添加到日历** — 在创建公告时可用，同时将其关联到日历

## 范围与可见性

公告按访问 URL 划分范围——在多 URL（多门户）安装中，每个门户独立管理各自的新闻。管理员列表会根据日期范围显示每条公告的启用/停用指示，您可以单独或批量编辑或删除公告。
