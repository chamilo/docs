# 页面

页面是 Chamilo 内置的、类似 CMS 的工具，用于构成门户面向公众区域的内容块——首页、页脚、导航菜单及类似位置——而无需修改模板文件。

## 访问页面

在管理面板中，点击 **平台 > 页面**。

## 页面的工作方式

每个页面包含：

* **标题** 与富文本 **内容**
* **别名（slug）**，由标题自动生成
* **已启用** — 该页面当前是否可见
* **位置** — 在其分类内通过拖放排序
* **区域设置（Locale）** — 内容按语言区分：同一展示位置可为每种语言各有一页；若访客语言没有对应页面，站点将回退到平台默认语言
* **分类** — 决定页面在 *何处* 渲染（例如 `index`、`home`、`footer_public` 或 `menu_links`）；Chamilo 会自动创建所需分类

在多 URL（多门户）安装中，页面还按访问 URL 隔离，因此每个门户管理各自的内容。

## 注册介绍页

**平台 > 设置注册页面** 是进入同一页面系统的快捷方式，针对一个特定位置：显示在公开注册表单上方的介绍文字。仅限门户管理员使用。点击后将：

* 若您的访问 URL 与语言已存在介绍页，则打开该页进行编辑，或
* 即时创建该展示位置并直接进入内容创建

此处保存的内容会作为信息框直接渲染在注册表单上方——适合放置说明、贵机构特有条款，或潜在用户在注册前应阅读的背景信息。将其保持禁用（或从不创建）则显示无介绍文字的普通注册表单。
