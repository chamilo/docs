# 常见问题

面向 Chamilo 3.0 管理员的常见问题。

## 安装与设置

**问：Chamilo 3.0 需要哪个 PHP 版本？**
答：PHP 8.3、8.4 或 8.5。请参阅 [服务器要求](../installation/server-requirements.md)。

**问：我可以在共享主机上运行 Chamilo 吗？**
答：可以，但不推荐。Chamilo 3.0 需要 Composer、开发模式下的 Node.js，以及用于安装和维护的命令
行访问。VPS 或独立服务器能提供更好的体验。

**问：我应该使用哪种数据库？**
答：MySQL 8.0+ 或 MariaDB 10.4+ 是最常用且测试最充分的选择。

**问：我可以不通过命令行安装 Chamilo 吗？**
答：可以，如果您使用打包版本（.zip 或 .tar.gz）。否则，您需要通过命令行安装 Composer 依赖、构建前端资源并运行数据库迁移。基于 Web 的向导可处理数据库设置和初始配置，但在开发模式下，周边步骤仍需要 shell 访问权限。

## 用户与身份验证

**问：如何重置用户密码？**
答：前往 **管理 > 用户列表**，找到该用户，点击编辑并设置新密码。或者，用户可在登录页使用“忘记密码”链接（需已配置电子邮件）。

**问：可以批量导入用户吗？**
答：可以。前往 **管理 > 导入用户**，上传包含用户数据的 CSV 或 XML 文件。导入支持创建新用户以及更新现有用户。

**问：如何与 LDAP 或 Active Directory 集成？**
答：在身份验证配置中设置 LDAP。请参阅 [LDAP](../authentication/ldap.md)。用户会在登录时同步，或通过计划同步进行同步。

**问：用户可以同时属于多个学期（session）吗？**
答：可以。用户可同时注册任意数量的学期。每个学期独立跟踪进度。

## 课程与内容

**问：如何备份单个课程？**
答：在课程内前往 **维护 > 创建备份**。这将生成可下载的课程内容与设置归档。您可在同一或另一 Chamilo 实例上还原。

**问：可以复制课程吗？**
答：可以。使用 **管理 > 复制课程** 或课程内的课程维护工具。您可在课程之间复制内容，或基于现有课程创建新课程。

**问：支持哪些 SCORM 版本？**
答：Chamilo 支持 SCORM 1.2。SCORM 包作为学习路径导入。

**问：如何限制谁可以创建课程？**
答：前往 **管理 > 配置设置 > 课程**，并禁用 **允许非管理员（教师）创建新课程**（`allow_users_to_create_courses`）。禁用后，仅管理员可创建课程。或者，您可设置每位教师可创建的课程数量上限。

## 性能与维护

**问：平台很慢。应首先检查什么？**
答：按影响程度：(1) 确保 `.env` 中 `APP_ENV=prod` 且 `APP_DEBUG=0`。(2) 确认已启用 PHP OPcache。(3) 检查数据库性能。(4) 参阅 [性能调优](../platform-settings/performance-tuning.md)。

**问：如何清除缓存？**
答：在命令行运行 `php bin/console cache:clear --env=prod`。应用程序运行时请勿手动删除 `var/cache/` 目录。

**问：Chamilo 需要多少磁盘空间？**
答：应用程序本身未压缩约需 2 GB。总空间取决于上传内容（文档、视频、SCORM 包）。请监控磁盘使用并相应规划。

**问：如何设置自动备份？**
答：参阅 [备份](../maintenance/backups.md)。至少应安排每日数据库转储，并对上传目录进行定期文件级备份。

## 电子邮件

**问：用户收不到电子邮件。应检查什么？**
答：(1) 核实 `.env` 中的 `MAILER_DSN`。(2) 运行 `php bin/console mailer:test someone@example.com` 进行测试。(3) 检查垃圾邮件文件夹。(4) 核实 SPF/DKIM DNS 记录。参阅 [电子邮件配置](../installation/email-configuration.md)。

**问：可以使用 Gmail 发送电子邮件吗？**
答：可以，适用于小型平台或开发环境。请使用应用专用密码，并注意 Gmail 的每日发送限额（普通账户为 500 封/天）。

## 安全

**问：如何强制使用 HTTPS？**
答：将 Web 服务器配置为将 HTTP 重定向到 HTTPS。另外，在 **管理 > 配置设置 > 安全** 中启用“强制 HTTPS”设置。参阅 [安全设置](../platform-settings/security-settings.md)。

**问：如何阻止暴力破解登录攻击？**
答：在安全设置中配置最大登录尝试次数和 CAPTCHA。也可考虑在服务器层面使用 fail2ban 以获得额外保护。

**问：用户忘记密码且电子邮件不可用。如何帮助他们？**
答：作为管理员，直接编辑用户账户并设置新密码。前往 **管理 > 用户列表**，找到该账户并更新密码字段。

## 升级

**问：能否从 Chamilo 2.x 直接升级到 3.0？**
答：可以，但这是一次重大迁移，而非简单更新。请参阅 [升级](../installation/upgrading.md)。请务必先在预发布服务器上测试。

**问：升级到 3.0 后，我的插件还能用吗？**
答：不能。2.x 的插件与 3.0 不兼容，必须重写或替换为等效的 3.0 功能。
