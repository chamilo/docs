# 插件

插件可在不修改核心代码的情况下扩展 Chamilo 的功能。Chamilo 3.0 自带 50 余个插件，可按需启用。

## 插件区块

管理仪表盘也有独立的 **插件** 区块，与本章的通用插件管理分开。它并不列出所有已安装插件——仅列出那些在配置中声明应出现在管理菜单区域的插件，从而为每个此类插件在仪表盘上提供直达其管理页面的快捷入口。

![管理仪表盘上的插件区块，列出已配置为出现在管理菜单中的已安装插件的快捷方式](/.gitbook/assets/admin-plugins-block.png)

如果您已启用的某个插件未出现在此处，这是正常现象——表示该插件未声明自己属于管理菜单区域，并非系统故障。完整已安装插件列表（无论是否出现在仪表盘上）请参见 [管理插件](managing-plugins.md)。
