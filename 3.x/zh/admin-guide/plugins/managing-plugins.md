# 管理插件

## 访问插件管理器

![插件管理器，显示可用插件列表以及激活开关和配置选项](/.gitbook/assets/admin-plugin-manager.png)

在管理面板中，点击 **管理插件** 即可查看可用插件列表。

## 插件状态

每个插件具有以下两种状态之一：

* **已激活** — 插件已启用，其功能可在平台上使用
* **未激活** — 插件已安装但处于禁用状态

## 激活插件

1. 在列表中找到该插件
2. 点击 **安装**，然后点击 **启用** 或将其切换为开启
3. 配置插件设置（如适用，找到 **配置** 按钮）
4. 保存
5. 若 README 中有建议，请在特定 **区域** 中启用它

部分插件会为课程添加工具、为平台新增页面，或为现有功能提供额外能力。

## 配置插件

许多插件提供配置选项。激活插件后：

1. 点击该插件旁的 **配置** 按钮
2. 填写所需配置（API 密钥、URL、选项等）
3. 保存

## 停用插件

1. 在列表中找到该插件
2. 点击 **禁用** 或将其切换为关闭
3. 该插件的功能会立即从平台移除，但插件仍保持安装状态，并保留其配置，直至您将其 **卸载**

禁用插件不会删除其数据。若日后重新启用，数据仍然可用。

## 提示

* **仅激活所需插件** — 每个已激活的插件都会带来一定开销。请将未使用的插件保持为停用状态。
* **上线前先测试** — 请先在测试环境中激活新插件
* **检查兼容性** — 升级 Chamilo 后，请确认所有已激活插件仍能正常工作
