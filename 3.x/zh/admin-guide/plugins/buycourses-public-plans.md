# BuyCourses 公开方案与推广方案

**BuyCourses** 插件可以在展示公开免费方案的同时，显示指向外部产品的推广卡片。这与插件的付费课程/会话购买流程以及周期性服务付款配置相互独立。

## 配置公开方案

1. 打开 BuyCourses 管理区域及其公开方案卡片编辑器。
2. 在 **免费** 方案下，选择是否启用 **显示免费**。
3. 使用语言选项卡输入免费方案的翻译标题、说明和功能列表。
4. 按需添加推广卡片。配置每张卡片的启用状态、位置、目标 URL、可选图片 URL，以及翻译后的标题、说明、功能和按钮文本。
5. 保存后，使用可用的预览/目录链接，检查各已配置语言下的公开呈现效果。

编辑器会保存多种语言的翻译内容。推广卡片是**指向外部优惠的链接**，并不表示已完成付款，也不表示在 Chamilo 中自动订阅。

## 课程创建限制

免费方案使用平台的标准课程创建限制。BuyCourses 会区分标准课程配额与付费课程配额。若配置了有限上限，课程创建界面可以显示用量与进度；无限方案则无需百分比指示器。

请分别使用仅具有标准配额的账户和具有相应付费配额的账户测试这些限制。公开推广卡片绝不应绕过服务器端的课程创建权限。

## 付款行为

公开方案卡片不会取代 BTCPay、Stripe、PayPal 或插件既有的课程购买与周期性服务流程。请继续在现有 BuyCourses 配置中管理和测试支付网关。

请参阅 [BuyCourses：付款与周期性服务](buycourses.md)。实现：[PR #9369](https://github.com/chamilo/chamilo-lms/pull/9369)。
