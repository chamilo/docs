# 教室

管理后台仪表板上的 **教室** 区块用于管理 Chamilo 可跟踪的面授或混合式培训物理场所：校区（站点）、其中的教室，以及用于查找某一时刻空闲教室的工具。

![管理后台仪表板上的教室区块，列出校区、教室和教室空闲查询](../../.gitbook/assets/admin-rooms-block.png)

本章介绍管理员侧的校区与教室管理。面向教师的一侧——将教室分配给课程学期——请参见教师指南中的 [校区与教室](../../teacher-guide/branches-and-rooms.md)。

## 访问教室区块

在管理面板中，**教室** 区块与其他仪表板区块并列显示。单击其中任一链接即可打开相应工具。

## 区块内容

* **[管理教室](managing-rooms.md)** — 创建并组织校区（站点）以及各校区内的教室
* **[教室空闲查询](room-availability-finder.md)** — 查询在给定日期和时间范围内哪些教室空闲

## 多 URL 说明

在多 URL（多租户）安装中，校区和教室各自限定于单个访问 URL——它们不会在门户之间共享。
