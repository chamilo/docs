# 分支楼层平面图与教室地图

Chamilo 3.1 可将楼层平面图图像与分支关联，并使用交互式多边形在该图像上标注教室位置。此功能帮助学习者定位已分配的教室；它**不是**地理 GPS 地图。

## 附加分支楼层平面图

1. 打开 **分支** 的管理区域，并编辑目标分支。
2. 找到 **楼层平面图** 面板。
3. 选择或上传图像，然后选择 **附加楼层平面图**（若已存在，则选择 **更换楼层平面图**）。
4. 按要求保存或确认分支更改，然后验证楼层平面图图像是否加载。

若平面图不再有效，请在检查哪些教室引用该平面图后使用 **移除楼层平面图**。仅上传可信内容，并遵循分支管理界面的权限设置。

## 勾勒教室轮廓

1. 编辑分配给该分支的教室。
2. 在教室表单中找到 **楼层平面图上的教室**。
3. 使用多边形工具描绘教室边界。使用 **编辑** 调整顶点；所有点必须保持在图像范围内。
4. 选择 **保存教室区域**，然后保存教室表单以持久化更改。
5. 打开教室查看器以确认位置正确。若应移除映射，请使用 **清除教室区域**。

每个教室一次只能有一个可编辑的多边形。教室映射与分支级图像相互独立，因此更新图像后可能需要检查现有教室边界。

## 地图的显示位置

当在课程信息、日历事件和出勤相关流程中选择或显示教室时，授权用户可以查看教室楼层平面图。请使用实际查看该信息的角色验证可见性，尤其是学生和会话参与者。

分支和教室访问权限同样适用于楼层平面图资源。在多 URL 安装中，发布地图前请验证正确的门户/分支隔离。

请参阅 [管理教室](managing-rooms.md) 和 [教室可用性查找器](room-availability-finder.md)。实现：[PR #9321](https://github.com/chamilo/chamilo-lms/pull/9321)、[PR #9451](https://github.com/chamilo/chamilo-lms/pull/9451)。
