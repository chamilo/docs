# 教室空闲查询

教室空闲查询是一项排程工具：选择开始与结束日期/时间后，即可得知该时段内哪些教室空闲、哪些教室已被预订。

## 访问教室空闲查询

在管理面板中，点击 **教室 > 教室空闲查询**。

## 显示内容

选择开始与结束日期/时间后，系统会对照现有预订检查当前门户中的每一间教室，并分为两个列表：

* **可用教室** — 在所请求时段内空闲，显示其名称、校区、楼层和容量
* **占用教室** — 已被预订，显示冲突预订的标题及时间范围

教室被标为“占用”，是因为该时段已分配给考勤日历条目、课程，或特定的学期-课程组合——换言之，本功能检查的是通过考勤与学期工具产生的真实预订，而非独立的预约日历。因此，它适用于面授或混合（线下）学期制课程中实体教室的冲突检查。

要从教师端将教室分配给课程，请参阅教师指南中的 [校区与教室](../../teacher-guide/branches-and-rooms.md)。
