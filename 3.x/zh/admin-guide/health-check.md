# 健康检查

健康检查是管理仪表板上的一个小区块，会对您的安装运行若干实时检查，并标出需要关注的问题——无需翻阅配置文件即可发现常见的错误配置。

![管理仪表板上的健康检查区块，显示电子邮件设置、管理员 URL 分配以及文件权限检查的通过/失败状态](../.gitbook/assets/admin-health-check-block.png)

## 访问健康检查

在管理面板中，**健康检查**区块与其他仪表板区块并列显示——无需点击，结果会直接展示。

## 检查项

* **电子邮件设置** — 验证是否已配置邮件程序连接字符串以及“发件人”电子邮件/名称。若未配置，会链接到邮件设置以便修复。
* **所有 URL 均至少分配了一名管理员** — 在多 URL 安装中，检查每个访问 URL 是否至少有一名可对其进行管理的管理员。若某 URL 没有，会链接到访问 URL/用户分配页面。
* **`.env` 不可写** — `.env` 保存密钥，安装完成后不应可由 Web 服务器写入。若可写则标为错误；链接到安全指南。
* **`config/` 不可写** — 与 `.env` 相同的理由：正常运行时该目录不应可由 Web 写入。链接到安全指南。
* **`var/cache` 可写** — 相反的检查：Symfony 需要写入其缓存目录，因此若*不可*写则标为错误。链接到性能调优/优化指南。
* **安装文件夹不存在** — `public/main/install` 文件夹仅在安装期间需要，之后应删除。若仍存在则标为警告（而非硬性错误），因为其风险低于上述两项可写性检查。链接到安全指南。

## 如何处理

每项检查都会直接链接到修复相应问题的位置——设置页面或相关指南。请在安装完成后立即过一遍此列表，并在之后定期检查（例如在手动传输文件或更改权限之后），因为今天通过并不保证以后一直通过。若需这六项检查之外更全面的生产加固清单，请参阅[安全指南](appendix/security-guide.md)。
