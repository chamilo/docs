# 管理指南

欢迎使用 Chamilo 3.0 管理指南。本指南面向负责安装、配置和管理 Chamilo 实例的平台管理员。

## 作为管理员您可以做什么

作为 Chamilo 管理员，您可以管理：

* **安装与配置** — 在服务器上部署 Chamilo，配置存储、电子邮件和环境设置
* **用户** — 创建、导入并管理用户账户、角色和权限
* **课程与学期** — 监督课程创建、管理课程目录，并配置培训学期
* **平台** — 语言、门户新闻、全局日程以及 Pages CMS 工具
* **平台设置** — 配置门户行为、安全性、性能和功能可用性
* **分析** — 平台统计、学习分析以及企业/人力资源报告
* **技能** — 定义能力徽章并将其与成绩册结果关联
* **系统** — 服务器维护工具、自更新、存储检查和品牌定制
* **教室** — 管理实体场地和可预订的培训教室
* **安全** — 监控登录尝试、审查被标记的入侵尝试、检查密码强度并验证文件完整性
* **插件** — 安装、配置和管理平台扩展
* **身份认证** — 设置外部登录系统（OAuth2、LDAP、CAS、SCIM）
* **集成** — 将 Chamilo 连接到视频会议、LTI 工具、AI 提供商等
* **维护** — 执行备份、监控系统健康状况并管理存储

## 本指南的组织结构

1. **入门** — 管理界面概览
2. **安装** — 服务器要求、安装向导和初始配置
3. **用户** — 管理用户账户、角色、组和档案
4. **课程** — 管理课程、分类以及导入/导出
5. **学期** — 组织有时限的培训群体
6. **平台** — 语言、门户新闻、全局日程以及 Pages CMS 工具
7. **平台设置** — 配置平台的各个方面
8. **分析** — 统计、学习分析以及企业/人力资源报告
9. **技能** — 能力徽章和基于成绩册的奖励
10. **系统** — 服务器工具、自更新、存储检查和品牌定制
11. **教室** — 分支机构和可预订的培训教室
12. **安全** — 安全监控和审计工具
13. **插件** — 管理平台扩展
14. **健康检查** — 实时配置检查
15. **其他管理模块** — Chamilo.org 链接、版本检查、支持和新闻
16. **身份认证** — 设置外部身份认证提供商
17. **集成** — 连接第三方服务
18. **多 URL** — 从单一安装运行多个门户
19. **性能调优** — 针对速度和规模优化平台
20. **维护** — 备份、系统状态和清理
