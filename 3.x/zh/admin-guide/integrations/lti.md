# LTI 1.3

**LTI**（Learning Tools Interoperability，学习工具互操作性）是一项标准，允许将外部学习工具嵌入 Chamilo。1.3 是该标准最新且最安全的版本。

也可从管理仪表盘的 [平台](../platform/README.md) 区块进入本工具，对应名称为 **外部工具 (LTI)**。

## LTI 可以实现什么

借助 LTI，您可以在 Chamilo 课程中嵌入外部工具。例如：

* 交互式模拟
* 专业测评工具
* 内容创作工具
* 虚拟实验室
* 第三方内容库

外部工具会无缝显示在 Chamilo 界面中。

## 配置 LTI 工具

### 作为管理员

1. 在管理面板中进入 LTI 设置
2. **注册外部工具**，需提供：
   * **工具名称** — 描述性名称
   * **Login URL** — 外部工具的 OIDC 登录发起 URL
   * **Redirect URL** — 登录后工具返回的启动 URL
   * **Client ID** — 由工具供应商提供
   * **公钥集 URL（JWKS URL）** — 用于安全密钥交换的工具 JWKS 端点
3. 配置 **成绩回传** — 该工具是否可将成绩回传到 Chamilo
4. 保存

### 作为教师

管理员注册 LTI 工具后，教师可将其添加到课程中：

1. 在课程中查找添加外部工具的选项
2. 从已注册的 LTI 工具中选择
3. 该工具会作为课程工具出现在首页上

## 安全性

LTI 1.3 使用：

* **OAuth 2.0** 进行身份验证
* **JSON Web Tokens (JWT)** 进行消息签名
* **公钥/私钥对** 进行验证

这意味着凭据不会在 Chamilo 与外部工具之间直接共享。

## 成绩回传

LTI 工具可将成绩回传到 Chamilo，并可整合到课程成绩册中。此项在注册时按工具进行配置。

## 提示

* **确认工具兼容性** — 确保外部工具支持 LTI 1.3（而不仅仅是旧版本）
* **在沙箱中测试** — 在生产环境使用前，先在测试课程中测试 LTI 集成
* **监控性能** — 外部工具会增加网络依赖。请确保该工具响应及时且稳定可靠。
