# xAPI

**xAPI**（Experience API，亦称 Tin Can API）是用于跟踪学习体验的标准。Chamilo 既可以生成也可以消费 xAPI 语句。

## xAPI 的作用

xAPI 以**语句**形式跟踪学习活动，格式为：“主体对客体执行了动词。”例如：

* “Jane 完成了模块 1”
* “John 在期末考试中获得 85% 的分数”
* “Maria 观看了介绍视频”

这些语句存储在**学习记录存储（LRS）**中，从而提供学习活动的完整记录。

## 配置

1. 在平台设置中配置 **LRS 端点**：
   * **LRS URL** — 学习记录存储的地址
   * **LRS 身份验证** — 向 LRS 发送数据所用的凭据
2. 为所需活动启用 xAPI 跟踪

## Chamilo 通过 xAPI 跟踪的内容

Chamilo 可为以下内容生成 xAPI 语句：

* 课程访问与完成
* 测验尝试与分数
* 学习路径项目进度
* 作品集项目

其他工具（如文档和论坛）目前不会由该插件作为 xAPI 事件发出。

## 使用场景

* **跨平台跟踪** — 在单一 LRS 中跟踪多个工具与平台上的学习活动
* **高级分析** — 使用 LRS 分析工具生成超出 Chamilo 内置报告范围的洞察
* **合规报告** — 为监管要求生成培训完成情况的审计轨迹
