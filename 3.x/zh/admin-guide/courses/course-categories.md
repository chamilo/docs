# 课程分类

课程分类有助于组织课程目录，使学习者更容易找到相关课程。

## 创建分类

1. 从管理面板进入 **课程分类**
2. 点击 **添加分类**
3. 输入：
   * **分类代码** — 简短的唯一标识符
   * **分类名称** — 显示名称（例如，“信息技术”、“管理技能”）
   * **允许在此分类中添加课程？** — 是否允许将课程设置为此分类，或仅作为层级结构中的中间层级
   * **父分类** — （可选）将此分类置于另一分类之下以创建层级
   * **描述** — （可选）
   * **图片** — （可选）用于代表此分类，尽管几乎不会在任何地方显示
4. 点击 *添加分类*

Chamilo 默认创建 3 个分类：*Language skills*、*PC Skills* 和 *Projects*。可根据需要重命名、删除或保留这些分类。

## 分类层级

![课程分类管理页面，显示嵌套的分类树](../../.gitbook/assets/admin-course-categories.png)

分类可以嵌套以创建树状结构：

* 商务
  * 管理
  * 市场营销
  * 财务
* 技术
  * 编程
  * 网络
  * 网络安全

浏览课程目录的学习者可以通过此层级导航以查找课程。

## 管理分类

* **编辑** — 更改分类名称、代码或父分类
* **移动** — 更改分类在列表中的位置
* **删除** — 移除分类。已删除分类中的课程将移至“未分类”。

## 提示

* **保持简洁** — 使用学习者一眼就能理解的宽泛分类
* **限制深度** — 避免过深的嵌套分类。两到三层通常已足够。
* **在创建课程时指定分类** — 鼓励教师在创建课程时选择分类，以便目录保持有序
