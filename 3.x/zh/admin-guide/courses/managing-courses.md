# 管理课程

作为管理员，您可以管理平台上的所有课程，无论它们由谁创建。

## 课程列表

![课程列表，显示所有课程的标题、代码、分类、已注册用户及可见性状态](../../.gitbook/assets/admin-course-list.png)

在管理面板中，点击 **课程列表** 即可查看所有课程。列表显示：

* 课程标题和代码
* 语言
* 分类
* 可见性状态

使用 **高级搜索** 工具查找特定课程。

## 创建课程

作为管理员，您可以创建课程并将其分配给任意教师：

1. 在管理面板中点击 **添加课程**
2. 填写课程详细信息（标题、代码、分类、语言）
3. 为课程指定教师
4. 保存

注意：在 Chamilo 1.11.x 中，课程代码会作为课程 URL 的一部分显示，且创建后无法更改。该行为从 2.x 起已改变。课程代码不再出现在 URL 中，未来版本可能允许教师事后修改课程代码，因为它对平台已不再那么关键。

## 管理现有课程

在列表中找到课程，即可在 *操作* 列中使用管理选项：

* **信息** — 显示有关该课程的信息 
* **课程主页** — 直接进入该课程的主页 
* **报告** — 查看参与度和成绩数据
* **编辑** — 更改课程标题、分类、可见性及其他设置
* **创建备份** — 进入课程的维护部分，您可以在此创建副本并执行其他操作
* **添加到目录** — 将该课程添加到课程目录
* **删除** — 永久删除该课程及其全部内容

> 删除课程将永久移除全部内容、学习者数据、成绩和跟踪信息。建议先导出课程作为备份。

## 批量操作

在列表中选择多门课程，可执行批量操作，例如删除。要导出课程，请进入该课程并使用 **维护** 工具 — 管理课程列表上没有批量导出操作。

## 课程可见性设置

管理员可以覆盖教师设置的可见性：

| 可见性 | 效果 |
|-----------|--------|
| **公开** | 所有人可访问，包括匿名访客 |
| **开放** | 所有已登录用户可访问 |
| **私密** | 仅已注册用户可访问该课程 |
| **关闭** | 任何人都无法访问该课程（教师和管理员除外） |
| **隐藏** | 任何人都无法查看或访问该课程（管理员除外） |
