# 全局课程设置策略

平台管理员可以为课程设置定义集中式默认值，并控制教师是否可以覆盖这些默认值。策略适用于现有课程功能，同时保留兼容的课程特定配置。

## 打开策略页面

在**主访问 URL** 上，打开**管理 > 设置 > 课程设置**，或在您的安装中导航至 `/admin/settings/course-settings`。此管理页面仅供主访问 URL 上的授权平台管理员使用。请勿使用次级门户编辑全局策略。

## 配置策略

1. 如需查找特定的课程设置键，请使用**搜索**字段。
2. 对于每项设置，请核对其标题下方显示的确切变量名。
3. 选中或清除**可在课程中编辑**，以控制课程编辑者是否可以更改该设置。
4. 选择或输入**平台默认值**。部分设置提供允许值下拉列表；其他设置接受文本输入。
5. 保存更改，并在测试课程中验证实际行为。

在不同类别中复用同一变量名的设置会在必要时分别显示。请勿假定两个外观相似的名称控制同一课程功能。

## 使用两种角色进行验证

作为管理员，请确认已存储的默认值及其是否可编辑。作为课程教师，请打开相应的课程设置，并检查实际值与编辑限制是否与策略一致。在可能的情况下，同时测试现有课程和新课程。

更改全局默认值可能会影响许多课程。在禁用教师覆盖之前，请评估其影响，并记录先前的策略值，以便在需要时恢复。
