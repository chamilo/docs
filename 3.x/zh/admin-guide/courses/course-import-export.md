# 课程导入与导出

Chamilo 支持导入和导出课程，用于备份、迁移和内容共享。

这些功能位于课程内部，在课程主页顶部齿轮图标下的 **维护** 工具中。

## 导出课程

教师可以从课程维护工具中导出自己的课程。作为管理员，您可以导出任意课程：

1. 进入该课程
2. 打开 **课程维护** 工具
3. 选择 **创建备份**
4. 选择要包含的内容（内容、用户数据等）
5. 下载导出文件

导出会生成一个包含课程文档、练习、论坛、学习路径及配置的压缩包。

## 导入课程

要从 Chamilo 导出文件导入课程：

1. 进入该课程
2. 打开 **课程维护** 工具
3. 在 **导入备份** 部分，上传导出文件
4. 选择要包含的内容（内容、用户数据等）
5. 配置导入选项：
   * 是否覆盖现有内容
   * 是否包含用户数据
6. 执行导入

## 复制课程

要将另一门课程的内容复制到您的课程中，需要先准备好源课程和目标课程。

1. 进入目标课程
2. 打开 **课程维护** 工具
3. 在 **复制课程** 部分，选择 **源** 课程
4. 确认选项
5. 点击 **继续** 并按提示操作

## Common Cartridge

Chamilo 支持 **IMS Common Cartridge 1.3**（IMS CC 1.3）标准，以便与其他学习管理系统互操作。您可以：

* **导入** Common Cartridge 包（.imscc 文件）
* 以 Common Cartridge 格式 **导出** 课程内容

这样即可与支持 Common Cartridge 标准的其他平台（Moodle、Canvas、Blackboard 等）交换内容。

## 回收课程

课程回收功能仅保留课程外壳，并清除其内容。

## 删除课程

这将彻底删除您的课程，包括全部内容以及其中的用户活动。

要永久删除课程：

1. 进入目标课程
2. 打开 **课程维护** 工具
3. 在 **彻底删除此课程** 部分，手动输入课程代码以确认操作意图
4. 确认

随后您会被重定向到门户首页，因为该课程已不存在。

## Moodle 导入

Chamilo 可以导入来自 **Moodle** 的课程备份。导入器会将 Moodle 的内容结构转换为 Chamilo 格式，包括测验、文档和课程设置。

> **仍在完善中。** 尽管已覆盖相当广泛的基础内容，Moodle 导入器目前尚未覆盖每一种 Moodle 活动类型和内容格式。请将其视为起点，导入完成后可能仍需手动调整。若发现导入或导出中有失败或缺失的元素，请通过我们的 [Github space](https://github.com/chamilo/chamilo-lms/issues) 向我们报告：点击顶部的 **New issue**，并尽可能提供详细信息（若备份不涉密，也可附上课程备份本身）。

## 提示

* **定期备份** — 鼓励教师定期导出课程作为备份
* **测试导入** — 从其他平台导入内容时，先在试用课程中测试导入，以确认一切均已正确迁移
* **内容可移植性** — 需要与其他 LMS 平台共享内容时，请使用 Common Cartridge 格式
