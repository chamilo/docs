# 演示课程

自 Chamilo 3.0.0 起，每个新平台都会安装两门演示课程。它们展示了 Chamilo 能够实现的功能，并且本身也具有实用价值。

| 课程 | 代码 | 适用对象 |
|--------|------|------------|
| **AI Act** | `AIACT` | 任何与欧洲《人工智能法案》相关的组织。提供一条 *面向欧洲组织的人工智能法案认知* 学习路径。 |
| **Using Chamilo** | `USINGCHAMILO` | 任何开始使用 Chamilo 的组织。提供一条 *Chamilo 3.0 入门* 学习路径。 |

## 您将获得什么

* **两门课程均为多语言课程。** 每门课程的内容均包含 **26 种语言版本**，主要为受《人工智能法案》影响的国家所使用的语言。借助[多语言内容](../../teacher-guide/adding-content/multi-language-content.md)功能（`translate_html` 设置，自 3.0.0 起默认启用；参见[编辑器设置](../platform-settings/editor-settings.md)），学习者会看到与其个人资料语言相匹配的版本。如果关闭该设置，学习者将同时看到所有语言版本，而不是仅看到自己的语言版本，因此若要使用这些课程，请保持该设置处于启用状态。
* **它们随平台一同安装。** 它们在安装过程中创建，归管理员账户所有，并像其他课程一样出现在课程列表中。
* **它们对已登录用户开放。** 其可见性设置为 *开放*，课程主页上仅显示 **课程描述** 和 **学习路径** 工具。

![“我的课程”页面，其中 AI Act 演示课程以课程卡片形式显示](../../.gitbook/assets/demo-courses-list.png)

## 如何使用

* 确保课程可见，然后为相关用户注册，或将其添加到课程目录中，以便人们能够找到它。参见[管理课程](managing-courses.md)。
* 使用 *AI Act* 课程对员工进行人工智能认知培训，使用 *Using Chamilo* 课程帮助新教师和学习者入门。
* 在修改课程之前先复制课程（参见[课程导入与导出](course-import-export.md)），以便保留原始版本作为参考。

## 隐藏或删除

如果不需要它们，可以将其移除，而不会对平台的其余部分产生任何副作用：

* **隐藏**：编辑课程并将其可见性设置为 **隐藏**（或 **关闭**），或将其从课程目录中移除。它仍保留在平台上，以后可以恢复。
* **删除**：在课程列表中使用 **删除**。与任何课程一样，此操作是永久性的，因此如果以后可能需要，请考虑先导出课程。

{% hint style="info" %}
删除演示课程是安全的，但之后无法从界面重新安装。隐藏是可逆的选项。
{% endhint %}

## 为什么要保留它们？

即使您的组织本身不需要这些培训，它们也是向新教师展示一门已完成的、带有学习路径的多语言课程是什么样子的最快方式。许多管理员会将其对学习者隐藏，仅对教师可见，以便用于这一目的。
