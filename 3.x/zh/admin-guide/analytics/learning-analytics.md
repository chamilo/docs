# 学习分析

学习分析是 Chamilo 的经典跟踪仪表板（历史上称为“MySpace”或“Reporting”）。它是跟踪学习者、课程和学期表现的主要下钻工具。

## 访问学习分析

在管理面板中，点击 **分析 > 学习分析**。

## 显示内容

* **概览计数** — 学生、教师和人力资源用户的数量；已分配的课程和学期
* **下钻视图** — 分别针对用户、课程和学期的视图，各自显示平均花费时间、平均分数和进度
* **CSV 导出** — 导出当前视图以供离线分析

与全局统计不同，此视图的范围会随查看者角色而调整：全局管理员看到的是全平台数据，而教师或学期导师在自己的课程中打开等效视图时，只能看到自己的课程和学期。作为管理员通过此仪表板入口进入时，您获得的是全平台视图。
