# 报表目录

报表目录本身并不是一份报表——它是平台上已注册全部报表的目录，有助于了解有哪些报表可用以及谁可以查看它们。

## 访问报表目录

在管理面板中，点击 **分析 > 报表目录**。

## 显示内容

* **报表列表** — 每份已注册报表的标题、描述，以及其规范 URL 与旧版 URL
* **角色矩阵** — 展示哪些角色（门户管理员、全局管理员、会话管理员、教师、人力资源经理、学生主管……）可以访问每份报表的视图
* **权限类别** — 报表所属的权限分组（例如 `reports.platform`、`reports.learning_analytics`、`reports.export`、`reports.security`）

当您需要查明某份具体报表的位置，或某个角色（例如人力资源经理）是否有权访问该报表，而又不想逐一检查每份报表时，请使用此页面。
