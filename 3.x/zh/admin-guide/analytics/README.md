# 分析

管理仪表板上的 **分析** 区块汇总了平台范围统计、学习分析、企业/人力资源报告以及批量导出工具。根据您的 Chamilo 版本，该区块在仪表板上可能显示为 **“跟踪”** —— 无论标签如何，都是同一区块。本指南始终称之为分析，以免与 [跟踪设置](../platform-settings/tracking-settings.md) 混淆；后者是单独的设置类别，用于控制记录哪些内容，而非报告本身。

## 访问分析

在管理面板中，**分析** 区块与其他仪表板区块并列显示。单击其中任一链接即可打开相应报告。

## 区块内容

* **[全局统计](global-statistics.md)** — 平台范围统计：课程、用户、登录、学期以及磁盘使用情况
* **[报告目录](reports-catalog.md)** — 浏览所有已注册报告、谁可以访问以及原因
* **[学习分析](learning-analytics.md)** — 经典跟踪仪表板：用户、课程和学期下钻，含学习时长与平均分数
* **[企业报告](corporate-reports.md)** — 季度汇总、教师工时跟踪以及面向人力资源的课程/用户报告
* **[工单](tickets.md)** — 直接跳转到支持工单列表

## 谁可以访问

这些报告大多需要 **门户管理员** 权限。企业报告是例外 —— 它也对 **人力资源经理** 和 **学生主管** 角色开放，因为该报告正是为这些受众设计的。
