# 支持机器人（决策树助手）

**支持机器人**是基于固定决策树构建的可配置帮助助手。它在 [PR #9224](https://github.com/chamilo/chamilo-lms/pull/9224) 中实现，对应 [issue #8754](https://github.com/chamilo/chamilo-lms/issues/8754)。它**不是生成式 AI 聊天机器人**：管理员编写问题及可选答案，引导用户获得说明、打开页面或创建支持工单。

## 启用

1. 在**管理 > 配置设置 > 工单**中，启用 `ticket.ticket_support_bot_enabled`（默认禁用）。
2. 打开**管理 > 支持机器人**，创建一棵**草稿**决策树。提供标题，并至少包含一个带选项的入口节点。
3. 在每个节点定义问题或信息，并将选项链接到下一步操作。
4. 发布一棵有效的树。只有已发布、且具有有效入口节点和可选选项的树才对用户可用。

引擎会为当前访问 URL 选择已发布的树，因此其可用性以门户为范围。管理员必须拥有 `ROLE_ADMIN` 才能管理决策树。

## 设计支持流程

每个选项可执行以下四种操作之一：

| 操作 | 结果 |
| --- | --- |
| **转到另一个节点** | 在同一棵树中的另一个问题处继续对话 |
| **打开链接** | 使用同站相对路径链接到 Chamilo 页面，例如 `/tickets` |
| **结束对话** | 将问题标记为已解决，并可选择显示结束消息 |
| **创建支持工单** | 将对话升级到工单系统 |

对于工单升级，请选择一个**默认工单项目**以及属于该项目的类别。需要课程的类别不能用于此支持机器人升级。所创建的工单包含用户的决策树对话记录，以便支持人员查看导致升级的选择。

编辑器会在发布前验证树结构。**已发布**和**已归档**版本为只读；使用**复制**可创建新的可编辑草稿。发布替代版本会将同一范围内先前已发布的版本归档。在列表中，管理员还可以导入或导出决策树，并查看其对话历史。已发布的树必须先归档才能删除，且具有对话历史的树无法删除。

## 导入示例并查看对话

打开**管理 > 支持机器人**并选择**导入**。导入对话框提供**下载 JSON 示例**和**下载 CSV 示例**。下载示例后，将其问题和选项替换为您自己的内容，然后选择编辑后的 `.json` 或 `.csv` 文件并导入。每棵导入的树都以**新草稿**开始；请审阅后在准备就绪时明确发布。

这些示例不要求已存在工单项目。如果您的工作流需要创建工单，请在导入后配置所需的项目和符合条件的类别。

在树列表中，使用**查看对话**可检查特定树的对话日志，包括对话计数为零的树。对话历史仍限定于相关用户和门户。参见 [PR #9419](https://github.com/chamilo/chamilo-lms/pull/9419)。

## 用户如何访问

当该设置已开启且门户具有有效的已发布树时，已登录用户会在停靠聊天中看到**支持机器人**联系人。他们通过选择所提供的选项作答。机器人可以结束对话、打开同站页面，或创建工单并显示其链接。先前对话结束后，用户可以开始新的对话。

这与**AI 导师**不同，后者回答开放式学习问题。支持机器人仅遵循管理员配置的路径和选项。

## 故障排除与安全

* **聊天中没有机器人：** 请核实工单设置、当前门户是否已发布决策树，以及其入口节点是否具有选项。
* **无法发布：** 请检查草稿中缺失的节点、未解析的目标节点以及无效操作。
* **无法创建工单：** 请检查所选工单项目和类别。不要使用需要课程的工单类别。
* **缺少较早的对话：** 管理员可以从相应的树查看对话历史；对话与用户和访问 URL 相关联。

有关相关设置，请参见[工单设置](platform-settings/ticket-settings.md)。
