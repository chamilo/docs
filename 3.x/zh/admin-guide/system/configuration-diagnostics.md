# 安全配置诊断导出

Chamilo 3.1 提供可下载的 JSON 报告，用于诊断配置问题，且不会有意导出机密设置值。该报告仅限于**当前访问 URL**，并要求具备管理员角色。

## 下载报告

1. 在要检查的门户上打开**管理 > 设置**。
2. 选择**下载用于调试的配置**。
3. 安全保存生成的 `chamilo-configuration-dump.json` 文件。
4. **在将文件发送给任何人之前，请审阅整个文件**，即使它看起来已被脱敏。

报告包含导出时间戳、访问 URL 范围、已脱敏的平台设置，以及插件的安装/启用状态和已脱敏的插件配置。这是只读导出；下载不会更改系统设置。

## 机密性与访问 URL 边界

敏感值由脱敏层进行遮盖。除非明确归类为可安全导出，否则插件设置默认视为机密。即便如此，设置名称、插件名称及其他诊断元数据仍可能泄露实现细节，因此仅应将文件分发给可信的支持人员。

在多 URL 安装中，后端会检查解析后的访问 URL 是否与请求主机匹配，而不会静默导出其他门户的配置。下载前请确认门户地址。

## 故障排除

如果无法导出，请确保该账户具有管理员权限，且所请求的门户解析到其自身的访问 URL。查看 Web 服务器和应用程序日志时，不要将凭据或个人信息复制到支持工单中。

请参阅[系统工具](system-tools.md)和[安全设置](../platform-settings/security-settings.md)。实现：[PR #9476](https://github.com/chamilo/chamilo-lms/pull/9476)。
