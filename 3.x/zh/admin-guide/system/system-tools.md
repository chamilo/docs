# 系统工具

本页介绍“系统”区块中的维护与检查实用工具。

## 清理临时文件

**系统 > 清理临时文件** 会显示当前存在多少临时上传文件及其占用空间，然后允许你清除它们——可以全部清除，也可以只清除超过可配置时长的文件。试运行模式可先预览将被删除的内容。同一操作还会清除过期的遗留构建文件，并重新生成已编译的 CSS 资源。

此操作会有意跳过 Symfony 自身的缓存目录（`var/cache/dev`、`var/cache/prod`、`var/cache/test` 以及缓存池）——它只清理最终落在 `var/cache/` 其他位置的零散文件。它**不会**拾取你在 `.env` 或 `config/` 下所做的更改（例如启用 API 文档——参见 [启用 API 文档](../installation/configuration.md#enable-the-api-documentation)）。为此，你需要通过 shell 运行 `php bin/console cache:clear`。

## 系统更新

**系统 > 系统更新** 可直接从管理面板运行 Chamilo 的自更新流程，由一系列离散、可恢复的步骤组成：

1. **状态** — 报告已安装版本，以及更新/暂存/备份目录的位置，还有当前使用的受信任签名密钥
2. **检查** — 从已配置的更新源查询是否有更新版本可用
3. **验证** — 下载更新包及其签名，并根据清单校验和与受信任公钥进行核对
4. **预检** — 在改动任何内容之前验证系统要求与兼容性
5. **暂存** — 将已验证的软件包解压到隔离的暂存目录；此时线上安装尚未发生任何更改
6. **应用计划** — 基于暂存包构建要添加、替换或删除的文件差异
7. **应用文件** — 将文件复制到位。此步骤需要明确确认，并为每个被覆盖的文件创建备份，同时创建锁文件以阻止第二次更新并发运行
8. **迁移安全 / 应用后检查** — 验证待执行的数据库迁移及应用后状态
9. **运行应用后操作** — 执行应用后控制台命令（例如数据库迁移），但仅当服务器配置允许从界面运行它们时，并且仅在你输入明确确认短语并确认已完成备份之后

长时间运行的步骤会报告进度，因此页面可在其完成期间安全保持打开。签名验证、先暂存再应用、覆盖前备份、并发锁，以及数据库更改前的键入确认，这些组合旨在使该流程在没有 shell 访问的情况下也能安全运行——但开始前仍建议进行手动备份；参见 [备份](../maintenance/backups.md)。

## 文件信息

**系统 > 文件信息** 列出每一个已上传的资源文件，可按名称搜索，显示其物理路径、是否为孤立文件（未关联到任何课程或学期），以及有多少处引用了它。在此可将孤立文件附加到某资源、解除附加或删除——便于追踪并清理已不再属于任何课程的存储。

## 按类型查看资源

**系统 > 按类型查看资源** 允许你选择一种资源类型，并查看跨所有课程和学期的该类型条目汇总数量与列表、创建时间，以及（如适用）与之关联的用户。可用于回答诸如“全平台有多少个论坛”或“哪些课程的文档最多”等问题。

## 图标列表

**系统 > 图标列表** 是 Chamilo 内置图标集的可浏览目录，按类别分组。主要在开发插件或主题、需要确认图标确切名称时有用，但在此作为通用参考公开。

## 仅开发环境工具

本区块中还可能出现另外两项，但仅当服务器存在 `tests/` 目录时——这通常只出现在开发或 QA 安装中，绝不会出现在生产环境：

* **数据填充器** 生成大量虚假用户、课程和在线用户记录，用于负载或 QA 测试。
* **电子邮件测试器** 通过平台已配置的邮件程序发送一封真实测试邮件，以确认 SMTP/邮件设置确实可用，并显示最近的发送失败（如有）。

如果你看不到这两个链接，这是预期行为——说明你的安装没有 `tests/` 目录，这对生产平台而言是正常且正确的状态。
