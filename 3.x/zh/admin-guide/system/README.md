# 系统

管理仪表板上的 **系统** 区块汇集了服务器级维护工具、自更新工作流、存储/资源检查实用程序以及平台品牌设置。

![管理仪表板上的系统区块，列出清理临时文件、系统状态、系统更新、颜色、文件信息、按类型划分的资源和图标列表](../../.gitbook/assets/admin-system-block.png)

## 访问系统区块

在管理面板中，**系统** 区块与其他仪表板区块并列显示。单击其中任一链接即可打开相应工具。

## 区块内容

* **[系统工具](system-tools.md)** — 清理临时文件、运行自更新工作流、检查已存储的文件和资源，以及浏览内置图标集
* **系统状态** — 见维护部分中的 [系统状态](../maintenance/system-status.md)
* **[品牌](branding/README.md)** — 颜色主题（该区块中的“颜色”链接打开同一颜色主题页面）、门户自定义和模板

另外两项 — **数据填充器** 和 **电子邮件测试器** — 仅在服务器存在 `tests/` 目录时出现，这属于开发/QA 环境，而非生产环境。它们不会出现在典型的生产安装中；其功能说明见 [系统工具](system-tools.md#development-only-tools)。
