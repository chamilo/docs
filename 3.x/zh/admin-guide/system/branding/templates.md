# 模板

Chamilo 使用模板来生成证书、文档和电子邮件。您可以自定义这些模板，以符合本机构的品牌形象与要求。

## 证书模板

证书模板定义向达到成绩册阈值的学习者颁发的证书的版式与内容。

### 自定义证书模板

证书模板使用 HTML 和 CSS，并配合占位变量：

| 变量 | 替换为 |
|----------|-------------|
| Student name | 学习者的全名 |
| Course name | 课程名称 |
| Date | 获得证书的日期 |
| Score | 学习者的最终成绩 |
| Barcode | 用于核验的条码占位符（`((certificate_barcode))`） |

### 上传模板

1. 进入证书模板管理
2. 上传或编辑 HTML 模板
3. 在需要显示动态内容的位置使用占位变量
4. 保存

## 文档模板

教师在“文档”工具中创建内容时可以使用文档模板。模板为常见文档类型提供起始版式。

### 管理文档模板

1. 在管理面板中进入模板管理
2. 通过上传 HTML 文件添加新模板
3. 教师创建新文档时即可使用这些模板

## 提示

* **加入徽标** — 在证书模板中加入本机构徽标，使外观更专业
* **用真实数据测试** — 在部署模板前，使用实际学习者数据预览证书
* **保持模板简洁** — 简洁的设计更便于打印，也更显专业
