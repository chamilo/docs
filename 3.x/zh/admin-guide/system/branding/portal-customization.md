# 门户自定义

自定义 Chamilo 平台的外观以及向用户展示的信息。

## 平台标识

![门户自定义页面，显示平台名称、徽标和机构等标识设置](/.gitbook/assets/admin-portal-customization.png)

配置门户的基本标识：

* **平台名称** — 显示在浏览器标题栏及整个界面中的名称
* **机构名称** — 您所在组织的名称
* **机构 URL** — 指向您所在组织网站的链接
* **平台徽标** — 上传您所在组织的徽标（显示在顶部栏中）

## 提示

* **保持首页简洁** — 首页内容过多会令人应接不暇。应聚焦于必要公告和课程入口。
* **定期更新** — 保持系统公告为最新，并移除过时内容
* **上传高质量徽标** — 徽标是最醒目的品牌元素之一。请使用清晰、尺寸合适的图像。
