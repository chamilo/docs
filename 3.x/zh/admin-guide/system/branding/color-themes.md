# 颜色主题

Chamilo 2.0 引入了颜色主题系统，可用于自定义平台的视觉外观。

## 主题的工作原理

颜色主题定义了 Chamilo 界面所使用的调色板——主色、强调色、背景色和文本颜色。主题与访问 URL 关联：在单 URL 门户中，它实际上成为全局主题；在多 URL 环境中，每个 URL 可以拥有各自的主题。

## 应用主题

![颜色主题页面，显示带预览色块的可用主题以及“应用”按钮](/.gitbook/assets/admin-color-themes.png)

1. 从管理面板进入 **颜色主题**
2. 浏览可用主题
3. 选择一个主题并点击 **应用**
4. 主题会立即应用到平台

## 按 URL 的主题

在多 URL 环境中，每个访问 URL 可以拥有自己的颜色主题。这样不同门户可以拥有各自的视觉标识，同时共享同一套 Chamilo 安装。

## 提示

* **契合品牌** — 选择或自定义与组织品牌色相符的主题
* **测试可读性** — 应用主题后，检查文本在背景色上是否清晰可读，尤其是在高对比度场景中
* **考虑无障碍** — 确保色彩对比度足以满足视力障碍用户的需求
