# 登录尝试

登录尝试报告会记录失败的登录尝试，并提供图表，帮助您发现暴力破解或凭据填充模式。

## 访问登录尝试

在管理面板中，单击 **安全 > 登录尝试**。

## 显示内容

![登录尝试页面，显示按日尝试次数、热门 IP、按月失败尝试、成功与失败登录、按小时尝试次数以及每日唯一 IP 的图表，其后为失败登录尝试表格](../../.gitbook/assets/admin-security-login-attempts.png)

* **按日尝试次数（最近 7 天）** — 失败尝试的每日计数
* **热门 IP（最近 30 天）** — 产生尝试次数最多的 IP 地址
* **按月失败尝试（最近 12 个月）** — 更长期的趋势
* **成功与失败（最近 30 天）** — 成功登录与失败登录的每日明细
* **按小时尝试次数（最近 7 天）** — 一天中的时段分布，有助于发现自动化/脚本化尝试
* **每日唯一 IP（最近 30 天）** — 每天有多少个不同的 IP 尝试登录
* **失败登录尝试表格** — 每一次失败尝试，包含日期、IP 地址以及所尝试的用户名

使用图表上方的 **用户名**、**IP** 和日期范围字段筛选报告。

## 相关设置

本报告是监控工具；实际的暴力破解防护在 [安全设置](../platform-settings/security-settings.md) 中配置：

* **锁定前最大登录尝试次数** (`login_max_attempt_before_blocking_account`) — 失败次数过多时锁定账户
* **验证码** (`allow_captcha`) 和 **验证码错误允许次数** (`captcha_number_mistakes_to_block_account`) — 减缓自动化尝试，并锁定持续验证码失败的账户

另请参阅 [安全指南](../appendix/security-guide.md)，了解服务器级暴力破解防护（fail2ban）。
