# 活动审计

活动审计报告可让您按事件类型筛选并浏览重要的管理与平台活动。它与此前可通过 **跟踪 > 管理活动审计** 访问的底层报告相同；现已从安全模块直接链接，因为它主要是一项安全与问责工具。

## 访问活动审计

在管理面板中，点击 **安全 > 活动审计**。

## 显示内容

![活动审计页面列出课程、学期、用户、社交、消息、资源、Wiki 及其他等事件类型类别，每一类均可展开为具体事件类型](../../.gitbook/assets/admin-security-activities-audit.png)

事件按类别分组：

* **课程** — 课程的创建、删除及设置变更
* **学期** — 学期与学期类别的创建、删除及选课变更
* **用户** — 账户创建、删除、密码更新、字段变更等
* **社交** — 社交群组的创建、删除及成员变更
* **消息** — 消息数据变更与删除
* **资源** — 资源及资源链接的创建与删除
* **Wiki** — Wiki 页面浏览
* **其他** — 其余全部内容，包括插件活动、成绩册锁定、练习尝试删除、强制登录尝试以及平台级设置变更

点击某个事件类型标签（例如 **尝试强制登录**）可将报告筛选为匹配条目的表格。也可使用事件类型列表上方的 **搜索** 字段按关键词直接搜索。

## 使用场景

* 调查谁删除了课程、学期或用户账户，以及何时删除
* 确认某项具体管理变更（设置更新、插件安装）是否由预期的管理员执行
* 结合 [登录尝试](login-attempts.md) 报告跟进 **尝试强制登录** 事件
