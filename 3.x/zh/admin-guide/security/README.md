# 安全

管理仪表板上的 **安全** 区块汇总了平台内置的安全监控与审计工具。它与 [安全设置](../platform-settings/security-settings.md) 相互独立：后者用于配置安全*策略*（密码规则、验证码、HTTP 安全标头等）——而本区块提供的是用于监视平台可疑活动与非预期变更的*报告与工具*。

![管理仪表板上的安全区块，列出活动审计、登录尝试、简易 IDS、密码强度检查器和文件完整性](../../.gitbook/assets/admin-security-block.png)

该区块在 Chamilo 2.0 中引入，最初包含四项工具，并在 Chamilo 3.0 中扩展了第五项：**文件完整性**。

## 访问安全区块

在管理面板中，**安全** 区块与其他仪表板区块（用户、课程、平台管理、系统等）并列显示。单击其中任一链接即可打开对应工具。

## 区块内容

* **[活动审计](activities-audit.md)** — 按事件类型浏览重要的管理与平台事件（用户、课程、学期及其他变更）
* **[登录尝试](login-attempts.md)** — 查看失败与成功的登录尝试，含图表及可搜索日志
* **[简易 IDS](simple-ids.md)** — 查看由 Chamilo 内置轻量级入侵检测系统标记的请求
* **[密码强度检查器](password-strength-checker.md)** — 扫描活跃用户中与常用密码列表匹配的密码
* **[文件完整性](file-integrity.md)** *（Chamilo 3.0 新增）* — 检测已安装文件中的非预期新增、修改、删除或权限变更

## 谁可以访问

全部五项工具均需 **门户管理员** 权限。文件完整性的扫描、暂停与重新建立基线操作还需 **全局管理员** 权限；暂停告警或建立新基线时需重新输入您本人的密码——详见 [文件完整性](file-integrity.md#actions)。
