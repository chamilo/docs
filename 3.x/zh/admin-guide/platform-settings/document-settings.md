# 文档设置

课程 **文档** 工具的行为——上传、允许的扩展名、共享与模板。

可在 **管理 > 配置设置 > 文档** 下访问这些设置。此分类包含 **29 项设置**，下方列出平台设置固件（`SettingsCurrentFixtures.php`）中附带的标题与说明。

> 代码中的变量名以等宽字体显示。在通过 API 编写脚本，或需要通过编辑 [`config/settings_override.yaml`](https://github.com/chamilo/chamilo-lms/wiki/Configurations#configsettings_overridesyaml) 在全局层面更改这些设置时，请使用该名称。

## 设置

### `access_url_specific_files`

**启用 URL 专用文件**

在多 URL 配置中启用此功能后，您可以进入主 URL，并为任意文件（在文档工具中）提供 URL 专用版本。从其他 URL 查看时，原文件将被替代版本替换。这样您可以进一步自定义每个 URL，同时仍可多次复用同一课程。

*默认值：`false`*

### `default_document_quotum`

**默认硬盘空间**

一门课程可用的磁盘空间是多少？您可通过以下路径覆盖特定课程的配额：平台管理 > 课程 > 修改

*默认值：`1000`*


### `default_group_quotum`

**小组可用磁盘空间**

小组文档工具默认可用的硬盘空间是多少？

*默认值：`250`*


### `documents_custom_cloud_link_list`

**为云链接设置严格的主机列表**

文档工具可以集成指向云端文件的链接。云服务列表受限于硬编码列表，但您可以定义将包含自有服务/URL 列表的 ‘links’ 数组。此处定义的列表将替换默认列表。

### `documents_default_visibility_defined_in_course`

**在课程中定义文档可见性**

所有课程的默认文档可见性

*默认值：`false`*

### `documents_hide_download_icon`

**隐藏文档下载图标**

在文档工具中，对用户隐藏下载图标。

*默认值：`false`*


### `enable_x_sendfile_headers`

**启用 X-sendfile 头**

如果您已在 Web 服务器层面启用 X-sendfile，并希望添加浏览器所需的头信息以便其识别，请启用此项。

*默认值：`false`*

### `group_category_document_access`

**启用小组分类内文档的共享选项**

启用后，管理员可按分类为文档小组设置文档访问与共享权限。

*默认值：`false`*


### `group_document_access`

**启用小组文档的共享选项**

启用后，可在小组级别配置文档共享与访问权限。

*默认值：`false`*


### `pdf_export_watermark_by_course`

**启用按课程定义水印**

启用此选项后，教师可为其课程中的文档定义自己的水印。

*默认值：`false`*


### `pdf_export_watermark_enable`

**在 PDF 导出中启用水印**

启用此选项后，您可以上传一张图片或一段文本，系统将自动将其作为水印添加到所有文档的 PDF 导出中。

*默认值：`false`*

### `pdf_export_watermark_text`

**PDF 水印文本**

此文本将作为水印添加到导出为 PDF 的文档中。

### `permanently_remove_deleted_files`

**已删除文件无法恢复**

在文档工具中删除文件将永久删除该文件。该文件无法恢复

*默认值：`false`*

### `permissions_for_new_directories`

**新目录的权限**

能够定义分配给每个新创建目录的权限设置，有助于提高安全性，防范黑客向门户上传危险内容的攻击。默认设置（0770）应足以使服务器获得合理的保护级别。给定格式使用 UNIX 术语：所有者-组-其他人，以及读-写-执行权限。

*默认值：`0770`*


### `permissions_for_new_files`

**新文件的权限**

能够定义分配给每个新创建文件的权限设置，有助于提高安全性，防范黑客向门户上传危险内容的攻击。默认设置（0550）应足以使服务器获得合理的保护级别。给定格式使用 UNIX 术语：所有者-组-其他人，以及读-写-执行权限。如果您使用 Oogie，请注意启动 LibreOffice 的用户必须能够在课程文件夹中写入文件。

*默认值：`0660`*


### `send_notification_when_document_added`

**添加文档时向学生发送通知**

每当有人在文档工具中创建新项目时，向用户发送通知。

*默认值：`false`*

### `show_default_folders`

**在文档工具中显示包含系统默认提供的多媒体资源的所有文件夹**

包含系统默认提供文件的多媒体文件夹，按视频、音频、图像和 Flash 动画等类别组织，供课程使用。即使您在文档工具中将其设为不可见，仍可在平台网页编辑器中使用这些资源。

*默认值：`true`*

### `show_documents_preview`

**显示文档预览**

在文档工具中显示文档预览可避免仅为查看文档而加载新页面，但在某些较旧的浏览器或较窄的屏幕上可能不稳定。

*默认值：`false`*

### `show_users_folders`

**在文档工具中显示用户文件夹**

此选项允许您向教师显示或隐藏系统为每位访问文档工具或通过网页编辑器发送文件的用户所生成的文件夹。如果向教师显示这些文件夹，教师可决定是否对学习者可见，并使每位学习者在课程中拥有专属空间，不仅可存储文档，还可创建和编辑网页并导出为 PDF、绘图、制作个人网页模板、发送文件，以及创建、移动和删除目录与文件，并从自己的文件夹制作安全副本。每位课程用户都将拥有完整的文档管理器。另外请注意，任何用户都可以将文档工具中任意文件夹内可见的文件（无论是否为其所有者）复制到其作品集或社交网络的个人文档区域，以便在其他课程中使用。

*默认值：`true`*

### `students_download_folders`

**允许学习者下载目录**

允许学习者将文档工具中的完整目录打包并下载

*默认值：`true`*


### `students_export2pdf`

**允许学习者在文档和 Wiki 工具中将网页文档导出为 PDF 格式**

此功能默认启用，但在服务器过载滥用或特定学习环境中，可能希望对所有课程禁用该功能。

*默认值：`true`*

### `thematic_pdf_orientation`

**课程进度的 PDF 方向**

在课程进度工具中，您可以打印各要素的 PDF。设置为 “portrait” 或 “landscape”（技术术语）以更改方向。

*默认值：`landscape`*


### `upload_extensions_blacklist`

**黑名单 - 设置**

黑名单用于通过删除（或重命名）扩展名出现在下方黑名单中的任何文件来过滤文件扩展名。扩展名应不含前导点（.），并以分号（;）分隔，例如：exe;com;bat;scr;php。无扩展名的文件会被接受。字母大小写无关。

### `upload_extensions_list_type`

**文档上传的过滤类型**

选择使用黑名单还是白名单过滤。更多详情请参见下方黑名单或白名单说明。

*默认值：`blacklist`*


### `upload_extensions_replace_by`

**替换扩展名**

输入您希望用于替换过滤器检测到的危险扩展名的扩展名。仅在选择通过替换进行过滤时需要。

*默认值：`dangerous`*


### `upload_extensions_skip`

**过滤行为（跳过/重命名）**

如果选择跳过，经黑名单或白名单过滤的文件将不会上传到系统。如果选择重命名，其扩展名将被扩展名替换设置中定义的扩展名所替换。请注意，重命名并不能真正保护您，并且在存在多个同名但扩展名不同的文件时可能导致名称冲突。

*默认值：`true`*


### `upload_extensions_whitelist`

**白名单 - 设置**

白名单用于通过删除（或重命名）扩展名*未*出现在下方白名单中的任何文件来过滤文件扩展名。一般认为这是更安全但限制更严的过滤方式。扩展名应不含前导点（.），并以分号（;）分隔，例如：htm;html;txt;doc;xls;ppt;jpg;jpeg;gif;sxw。无扩展名的文件会被接受。字母大小写无关。

### `users_copy_files`

**允许用户将课程中的文件复制到个人文件区**

允许用户将课程中的文件复制到个人文件区，该区域可通过社交网络查看，或在用户不在课程中时通过 HTML 编辑器查看

*默认值：`true`*


### `video_features`

**视频功能**

可为 Chamilo 中的视频播放器启用的额外功能数组。选项包括 “speed”，允许您更改视频的播放速度。
