# 课程班分类

课程班分类有助于组织您的课程班，尤其是在同时运行大量课程班时。

## 创建分类

1. 从管理面板进入 **课程班分类**
2. 点击 **添加分类**
3. 输入 **名称** 以及可选的开始/结束日期
4. 保存

## 使用场景

* **按项目** — “领导力发展”、“技术培训”、“入职培训”
* **按时段** — “2026 年第一季度”、“春季学期”、“七月批次”
* **按部门** — “工程”、“销售”、“人力资源”

## 管理分类

* **编辑** — 更改分类名称或日期
* **分配课程班** — 在创建或编辑课程班时，选择其所属分类
* **删除** — 移除分类（该分类下的课程班将变为未分类）
