# 班级

Chamilo 中的班级是预定义的用户组，可以作为一个整体注册到学期中。当您经常对同一批人员进行培训时，它们可以简化注册流程。

> 班级与[用户组](../../admin-guide/users/user-groups.md)共用同一界面。唯一的区别是**组类型**设置：创建组时选择“班级”。其余一切——成员管理、可见性以及界面本身——均完全相同。

## 创建班级

1. 从管理面板导航至 **班级**（或用户组并选择“班级”类型）
2. 点击 **创建班级**
3. 输入**名称**（例如：“工程团队”、“2026 年 3 月新员工”）
4. 添加**成员**——搜索并选择用户
5. 保存

## 使用班级进行注册

创建或编辑学期时，您可以一次性注册整个班级，而无需逐个添加用户：

1. 打开学期注册设置
2. 点击 **添加班级**
3. 选择班级
4. 该班级的所有成员均被注册到该学期

## 管理班级

* **编辑** — 更改班级名称或更新成员资格
* **添加/移除成员** — 保持班级名册为最新
* **删除** — 移除班级（不影响成员账户或其现有注册）

## 提示

* **为周期性群体创建班级** — 如果您为不同团队开展相同培训，请为每个团队创建一个班级
* **每次学期前更新** — 在将班级注册到新学期之前，检查班级成员资格，确保名册为最新
* **与 CSV 导入结合** — 从 CSV 文件导入班级成员资格，适用于大型群体
