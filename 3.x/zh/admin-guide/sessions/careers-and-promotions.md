# 职业路径与晋升批次

Chamilo 包含一套职业路径管理系统，可用于定义培训路径，并跟踪学习者在结构化项目中的进展。

## 职业路径

![职业路径列表，显示已定义的职业路径名称与描述](/.gitbook/assets/admin-careers-list.png)

**职业路径（career）** 表示一条结构化的培训路径——学习者为达成职业目标而遵循的一系列培训步骤。

### 创建职业路径

1. 在管理面板中，进入 **Careers**
2. 点击 **Create a career**
3. 输入 **name** 和 **description**
4. 保存

## 晋升批次

**晋升批次（promotion）** 表示沿某条职业路径推进的一届或一批学习者。可以将其理解为同一时间走同一条职业路径的一组人员。

### 关联到课程期次

创建晋升批次后，将其与课程期次（sessions）关联。由此定义学习者必须完成的培训顺序。

之后可以复制晋升批次，以便用相同课程期次的副本创建下一届晋升批次，从而快速搭建下一届。

### 创建晋升批次

1. 进入 **Promotions**
2. 点击 **Create a promotion**
3. 输入 **name** 和 **description**
4. 将其关联到一条 **career**
5. 为该晋升批次分配 **sessions**
6. 保存

## 三者如何配合

* **职业路径** 定义路径本身（例如：“初级开发者认证”）
* **晋升批次** 表示一届学员（例如：“2026 年 3 月班”）
* 晋升批次中的 **课程期次** 提供实际培训内容

## 使用提示

* **用于结构化项目** — 当学习者需按既定顺序完成多阶段培训时，职业路径与晋升批次最为有用
* **跟踪完成情况** — 使用报表工具监控各晋升批次在其职业路径上的进展
