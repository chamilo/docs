## 理解课程班

课程班是**可选的**。您可以仅使用课程来运行门户，但我们**强烈**建议您考虑课程班带来的额外复杂性，以此作为长期节省管理工作的方式。

**课程**承载内容（文档、练习、学习路径）。**课程班**将该课程（或多门课程）分配给特定的学习者群体，*并限定在特定时间段内*。

这种架构意味着：

* 教师在课程中一次性创建内容
* 管理员创建课程班，将该内容交付给不同的学员批次
* 每个课程班拥有各自的注册、跟踪数据和成绩
* 基础课程内容是共享的，但课程班辅导教师可以自定义某些元素

## 何时使用课程班

在以下情况下使用课程班：

* 您多次提供相同的培训（例如，每月入职课程班）
* 您拥有基于学员批次的项目（例如，按学期划分的班级）
* 您需要对每组学习者进行单独跟踪
* 您希望不同的辅导教师管理同一课程的不同版本
