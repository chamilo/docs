# 管理培训班

## 创建培训班

![培训班创建表单，包含名称、日期、导师、分类和可见性等字段](/.gitbook/assets/admin-session-create-form.png)

1. 在管理面板中，点击 **创建培训班**
2. 填写培训班详细信息：
   * **培训班名称** — 描述性名称（例如，“2026 年春季入职培训”）
   * **开始和结束日期** — 培训班运行时间（可选 — 培训班可以不设结束时间）。共有 3 组日期：用于显示的日期、用于限制学员访问的日期，以及用于限制导师访问的日期
   * **培训班导师** — 负责整个培训班的人员
   * **分类** — 分配到某个培训班分类以便组织
   * **可见性** — 控制访问和列表显示行为
3. **添加课程** — 选择一门或多门课程纳入该培训班
4. **注册学员** — 添加单个用户或用户班级
5. **指定课程导师** — 为每门课程指定一名教师（课程导师）
6. 保存

## 培训班日期

培训班支持灵活的日期配置：

| 日期 | 用途 |
|------|---------|
| **显示开始/结束** | 培训班在学员列表中出现的时间 |
| **访问开始/结束** | 学员实际可以访问培训班内容的时间 |
| **导师访问开始/结束** | 导师可以访问培训班的时间（通常早于学员访问开始，并晚于学员访问结束） |

这样可以在学员进入之前准备培训班，并在培训班结束后仍保持导师访问权限，以便评分和生成报告。

## 培训班列表

![培训班列表，显示所有培训班的名称、日期、课程数量、学员数量和状态](/.gitbook/assets/admin-session-list.png)

培训班列表显示所有培训班，包含：

* 培训班名称
* 开始和结束日期
* 状态（进行中、即将开始、已结束）

使用搜索和筛选，可按名称、日期、分类或状态查找培训班。

## 编辑培训班

点击某个培训班进行编辑：

* 更改日期、名称或分类
* 添加或移除课程
* 更改课程导师
* 添加或移除学员
* 查看该培训班的跟踪数据

## 注册用户

![培训班注册界面，用于添加单个用户、班级或通过 CSV 导入](/.gitbook/assets/admin-session-enrollment.png)

可通过以下方式将用户注册到培训班：

* **单独注册** — 搜索并添加单个用户
* **班级注册** — 一次性添加整个班级（预先定义的用户组）
* **CSV 导入** — 上传包含用户-培训班对应关系的文件

## 培训班访问

学员通过侧边栏中的 **我的培训班** 访问其培训班。培训班按以下方式组织：

* **当前培训班** — 当前进行中
* **过往培训班** — 已结束
* **即将开始的培训班** — 尚未开始

## 提示

* **仔细规划日期** — 确保导师访问日期覆盖并超出学员日期，以便导师进行准备和跟进
* **使用班级进行重复注册** — 如果经常注册相同的用户组，请创建班级并将其分配到培训班
* **保持培训班井然有序** — 使用分类和清晰的命名规范，便于管理
