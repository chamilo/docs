# 管理技能

本页介绍用于构建平台技能目录的三个仪表板入口：批量导入技能、管理技能定义本身，以及将每项技能分配到等级量表。

## 技能导入

**技能 > 技能导入** 允许您通过 CSV 或 XML 文件批量创建技能层级，而无需逐一创建技能。每一行至少需要 `id`、`parent_id`（用于构建树）和 `title`。可使用示例模板作为文件基础。

## 管理技能

**技能 > 管理技能** 是主要的技能目录：创建、编辑、启用/禁用和删除技能。每项技能包含标题、简短代码、描述、图标，以及可选的标准说明（学习者需要做什么才能获得该技能）。技能可以嵌套——一项技能可以拥有子技能——这正是 [技能轮盘](skills-wheel.md) 所可视化的内容。

## 管理技能等级

**技能 > 管理技能等级** 是一个独立的较小界面：它列出已有技能，并允许您将每一项分配到一个 **等级配置**——一组已命名、有序的等级（例如 铜/银/金），用于衡量该技能。简而言之：使用 **管理技能** 定义技能*是什么*，使用 **管理技能等级** 定义它按何种量表衡量。

## 技能如何授予

技能通过以下几种途径之一授予用户（记录为已颁发技能，并带有日期）：

* 自动授予，当学习者达到成绩册类别的阈值时——在 [技能与评估](skills-assessments.md) 页面配置
* 自动授予，在完成该技能所关联的特定课程时
* 手动授予，由教师（若已启用 **教师可分配技能**）或管理员执行
