# 技能

管理仪表板上的 **技能** 区块汇集了用于在整个平台上定义、组织和跟踪能力徽章（“技能”）的工具。技能可在学习者达到成绩册阈值、完成特定课程时自动授予，也可由教师手动授予，并可附带徽章样式图标和等级（例如铜/银/金）。

![管理仪表板上的技能区块，列出技能轮盘、技能导入、管理技能、管理技能等级、技能排名以及技能与评估](../../.gitbook/assets/admin-skills-block.png)

仅当 **启用技能工具** 设置（`skill.allow_skills_tool`，位于配置设置 > 技能）已开启时，整个区块才会显示——该设置默认启用。

## 访问技能区块

在管理面板中，**技能** 区块与其他仪表板区块并列显示。单击其中任一链接即可打开相应工具。

## 区块内容

* **[管理技能](managing-skills.md)** — 创建技能、批量导入，并将每一项技能分配到等级量表
* **[技能轮盘](skills-wheel.md)** — 整个技能树的可缩放可视化地图
* **[技能排名](skills-ranking.md)** — 按已获得技能排列的用户排行榜
* **[技能与评估](skills-assessments.md)** — 将成绩册类别与其所授予的技能关联

## 相关设置

配置设置 > 技能下的其他若干设置会改变谁可以对本区块执行哪些操作：

* **允许人力资源技能管理** (`allow_hr_skills_management`) — 允许人力资源经理用户与管理员一同管理技能
* **允许私有技能** (`allow_private_skills`)
* **教师可以分配技能** (`skills_teachers_can_assign_skills`)
* **隐藏技能等级** (`hide_skill_levels`)
* **在技能轮盘上显示完整技能名称** (`show_full_skill_name_on_skill_wheel`)
