# 问卷模板

管理员可以构建可复用的问卷，并将其提供给教师，或直接分配给课程与课程期次。此功能在 [PR #9208](https://github.com/chamilo/chamilo-lms/pull/9208) 中实现，对应 [issue #8760](https://github.com/chamilo/chamilo-lms/issues/8760)。

## 创建与维护模板

1. 在管理面板中，打开 **问卷模板**，然后选择 **创建**。
2. 输入标题及可选的副标题；配置匿名性、题目布局、随机排序、时长、引言与致谢文本。
3. 保存后，在模板的题目编辑器中添加或编辑可复用题目。
4. 若希望教师能够查看并复用该模板，请启用 **作为模板可见**。不可见的模板仍可供管理员使用。

模板属于当前访问 URL。仅平台管理员可以创建、编辑或删除主模板。教师可以使用可见模板，但不能更改其主定义。

## 在课程或课程期次中复用模板

在已获授权的课程或课程期次中，教师创建新问卷时可以选择一个可见模板。其结果是该课程情境下的一份问卷，而不是对可复用主模板的修改。教师可以审阅题目，并按常规的发布与邀请流程继续操作。

在管理端的模板列表中，管理员也可以将模板直接分配给选定的 **课程**，并可选择该课程下的某个 **课程期次**。Chamilo 会检查该课程是否属于当前门户，以及所选课程期次是否确实包含该课程。教师界面不能用于将模板分配给他人的课程或课程期次。

仅因问卷由模板创建，并不会自动发布；邀请参与者之前请先审阅。标准问卷流程请参见 [问卷](../teacher-guide/assessing-learners/surveys.md)。

## 对教师或辅导教师隐藏敏感结果

编辑实际问卷时，平台管理员可以启用 **对教师/辅导教师隐藏结果**。此按问卷设置的限制适用于敏感问卷，例如对教学人员的评价。教师和辅导教师仍可查看回复数量并发送提醒，但 **无法打开报告视图或导出结果**。平台管理员仍可访问报告，但须受其他平台设置的约束。

此选项不同于常规的 **结果可见性** 字段，也不同于全平台的 **隐藏问卷报告按钮** 设置。只有管理员可以更改受限结果标志。

## 权限与范围

* **管理员：** 管理模板、设置模板可见性、分配给符合条件的课程/课程期次，并控制受限结果访问。
* **教师 / 课程期次教师：** 仅可在其已获授权的课程情境中查看并实例化可见模板。
* **访问 URL：** 模板目录与分配均强制使用当前访问 URL；其他门户的模板不能跨边界实例化。

若教师看不到模板，请检查 **作为模板可见** 及其课程/课程期次情境。若模板无法实例化，请检查全局问卷创建限制以及目标课程/课程期次。
