# 管理界面概览

管理面板是您管理 Chamilo 平台的指挥中心。点击侧边栏中的 **管理** <img src="../../.gitbook/assets/icons/mdi-cogs.svg" alt="管理" data-size="line"> 即可进入。

## 管理仪表盘

![管理仪表盘，显示用户、课程、学期和设置等功能区块](../../.gitbook/assets/admin-dashboard-overview.png)

管理仪表盘按功能区块组织。每个区块归集相关的管理工具：

### 用户

* **用户列表** — 查看、搜索、编辑并管理平台上的所有用户
* **添加用户** — 创建单个用户账户
* **班级** — 管理用户班级，以便批量学期注册

详情请参阅 [用户](../users/README.md) 章节。

### 课程

* **课程列表** — 查看并管理平台上的所有课程
* **创建课程** — 创建一门新课程
* **课程分类** — 将课程组织到分类中，供课程目录使用

详情请参阅 [课程](../courses/README.md) 章节。

### 学期

* **学期列表** — 查看并管理培训学期
* **创建学期** — 设置包含课程与注册的新学期
* **学期分类** — 将学期组织到分类中
* **职业与晋级** — 管理职业路径与晋级工作流

详情请参阅 [学期](../sessions/README.md) 章节。

### 平台

* **配置设置**、**语言**、**门户新闻**、**全局日程**、**页面**、**扩展字段**、**邮件模板**、**联系表单分类** 等 — 详情请参阅 [平台](../platform/README.md) 章节。“配置设置”链接是进入独立 [平台设置](../platform-settings/README.md) 章节的入口。

### 分析

* **全局统计**、**报表目录**、**学习分析**、**季度报表**、**教师工时报表**、**企业报表**、**特殊导出**、**工单** — 平台统计与报表；详情请参阅 [分析](../analytics/README.md) 章节

### 技能

* **技能轮盘**、**技能导入**、**管理技能**、**管理技能等级**、**技能排名**、**技能与测评** — 与成绩册结果关联的能力徽章；详情请参阅 [技能](../skills/README.md) 章节

### 系统

* **清理临时文件**、**系统状态**、**系统更新**、**颜色**、**文件信息**、**按类型的资源**、**图标列表** — 服务器维护、自更新与品牌定制；详情请参阅 [系统](../system/README.md) 章节

### 教室

* **分支机构**、**教室**、**教室可用性查找器** — 实体场地与可预订培训教室；详情请参阅 [教室](../rooms/README.md) 章节

### 安全

* **活动审计**、**登录尝试**、**简易 IDS**、**密码强度检查器**、**文件完整性** — 安全监控与审计工具；详情请参阅 [安全](../security/README.md) 章节

### 插件

* 指向已安装且声明了管理菜单页的插件的快捷方式，以及常规插件管理 — 详情请参阅 [插件](../plugins/README.md) 章节

### 健康检查

* 实时通过/失败检查（邮件设置、管理 URL 分配、文件权限）— 详情请参阅 [健康检查](../health-check.md) 页面

### 其他区块

* **Chamilo.org**、**版本检查**、**专业支持**、**来自 Chamilo 的新闻** — 从 Chamilo 项目拉取内容的链接与状态面板；详情请参阅 [其他管理区块](../other-admin-blocks/README.md)

本指南各对应章节对每一部分均有详细说明。

OAuth2、LDAP、CAS 及其他外部身份验证提供方等身份验证方法不在管理仪表盘中配置，而是在 `config/authentication.yaml` 中配置。
