# 入门

本节介绍 Chamilo 3.0 管理界面，并帮助您熟悉环境。

## 谁是管理员？

Chamilo 具有若干层级的管理角色：

| 角色 | 权限 |
|------|--------|
| **Administrator** | 对平台全部管理功能拥有完整访问权限。亦称为 **Portal Administrator** |
| **Global Administrator** | 与 Portal Administrator 相同，但在多 URL（多租户）部署中可访问所有访问 URL |
| **Sessions Administrator** | 可管理学期（session）、将用户注册到学期，并访问与学期相关的设置 |
| **Human Resources Manager** | 可查看所分配用户的学习进度与跟踪数据 |
| **Questions Manager** | 更接近内容策展人而非管理员；题目管理员可访问全局题库以审核题目质量 |

本指南主要面向权限最广的 **Portal Administrator** 角色。

## 登录

管理员通过与其他所有用户相同的登录页登录。输入凭据后，在未做其他配置的情况下，您将被转到 **Administration** 页面。与其他用户角色的一个显著区别是侧边栏中的 **Administration** 区域（其他角色不可见）。
