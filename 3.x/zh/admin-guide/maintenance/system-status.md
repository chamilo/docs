# 系统状态

系统状态页面可帮助您验证 Chamilo 服务器是否配置正确，并识别潜在问题。

## 访问系统状态

在管理面板中，点击 **系统状态**（或 **系统信息**）。

## 显示内容

![系统状态页面，显示 PHP 配置、数据库状态、文件权限和服务器信息](../../.gitbook/assets/admin-system-status.png)

### PHP 配置

* **PHP 版本** — Chamilo 3.0 支持 PHP 8.3、8.4 和 8.5
* **必需扩展** — 检查所有必要的 PHP 扩展是否已安装
* **PHP 设置** — 验证内存限制、上传限制和执行时间等重要 PHP 设置

### 数据库状态

* **数据库连接** — 确认数据库可访问
* **数据库版本** — 显示数据库服务器版本

### 文件权限

* **可写目录** — 检查 Chamilo 能否写入所需目录（缓存、上传、日志）

### 服务器信息

* **操作系统** — 服务器操作系统详情
* **Web 服务器** — Apache、Nginx 或其他
* **磁盘空间** — 可用存储空间

## 建议检查

请定期执行以下检查：

* **安装之后** — 验证所有要求均已满足
* **升级之后** — 确保 PHP 版本和扩展仍然兼容
* **出现问题时** — 排查问题时首先检查系统状态
