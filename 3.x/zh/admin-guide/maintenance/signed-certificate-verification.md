# 签名证书验证

Chamilo 可为成绩册证书签发**数字签名凭证**，并可选择将凭证指纹锚定到 **Sepolia Ethereum 测试网络**。签名与验证页面不同于普通的 PDF 证书。

## 启用签名凭证

在 **管理 > 配置设置 > 证书** 下，若机构打算使用此功能，请启用 `certificate.blockchain_verification_enabled`。该选项默认处于禁用状态。门户必须使用 HTTPS 才能签发凭证。

## 学习者同意优先

证书持有者打开 **我的证书**，并明确选择 **批准发布**。该同意涵盖一份可公开验证的凭证，其中显示持有者姓名、课程、分数和签发日期，以及可选的 Sepolia 上的 SHA-256 指纹。批准并非自动完成。学习者日后可以选择 **撤回同意**；撤回会影响验证页面所显示的有效性，但**无法抹除已确认的区块链指纹**。

## 签发、验证与撤销

已直接通过身份验证的平台管理员可在成绩册的 **证书** 列表中，于持有者同意后签发签名凭证。生成的验证链接使用 `/certificates/verify/{token}`；同时也可获得 `.json` 验证响应。该页面会检查加密签名、同意状态、撤销状态、到期情况，以及底层证书信息是否仍与已签名来源一致。

若凭证被撤销、同意被撤回、证书发生变更或签名无效，验证程序会显示相应状态，而不会报告为有效凭证。

## 可选的 Sepolia 锚定

管理员可使用受支持的浏览器钱包选择 **锚定到 Sepolia 测试网**，或选择 **确认现有 Sepolia 交易** 以核对待处理交易。钱包必须连接到 Sepolia（链 ID `11155111`）。应用程序使用服务器配置的 **HTTPS Sepolia RPC 端点**（`CHAMILO_CERTIFICATE_SEPOLIA_RPC_URL`）确认交易。不接受请求中提供的 RPC URL。

仅锚定凭证指纹；个人数据不会作为交易数据提交。Sepolia 是**测试网**。其记录与可用性不得被表述为生产级公共区块链保障。请安全存储机构密钥与 RPC 配置，并规划密钥恢复与凭证撤销流程。
