# 备份

定期备份对于保护您的 Chamilo 数据至关重要。本页说明需要备份的内容以及如何备份。

## 需要备份的内容

### 1. 数据库

Chamilo 数据库包含所有平台数据：用户、课程、跟踪、成绩、消息和设置。这是最关键的备份组件。

**如何备份：**

```bash
mysqldump -u username -p chamilo_database > chamilo_backup_$(date +%Y%m%d).sql
```

### 2. 文件

Chamilo 将上传的文件（文档、图片、SCORM 包）存储在文件系统中。需要备份的关键目录：

* `var/` — 上传的文件和资源
* `public/plugin/` — 插件文件（仅当您添加了自定义插件时）

如果您使用云存储（S3、Azure Blob），请确保已启用云服务提供商的备份/版本控制。

### 3. 配置

* `.env` — 您的环境配置
* `config/` — 任何自定义配置文件

## 备份计划

| 组件 | 建议频率 |
|-----------|---------------------|
| 数据库 | 每日 |
| 文件 | 每日或每周（取决于上传活动） |
| 配置 | 每次配置变更之后 |

## 恢复

要从备份恢复：

1. 从 SQL 转储恢复数据库
2. 恢复文件目录
3. 恢复配置文件
4. 清除 Symfony 缓存：`php bin/console cache:clear`

## 提示

* **自动化备份** — 使用 cron 作业自动运行备份
* **异地存储** — 将备份副本保存在独立服务器或云存储上
* **测试恢复** — 定期测试能否成功从备份恢复
* **记录流程** — 保留书面的恢复流程说明，以便团队中任何人都能执行
