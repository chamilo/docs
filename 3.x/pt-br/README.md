# Documentação do Chamilo 3.0

Bem-vindo à documentação oficial do **Chamilo 3.0**, a plataforma de e-learning de código aberto.

Esta documentação está organizada em três guias, cada um voltado a um público específico:

* [**Guia do Professor**](teacher-guide/) — Para instrutores e formadores: criar cursos, adicionar conteúdo, avaliar aprendizes e acompanhar o progresso.
* [**Guia de Administração**](admin-guide/) — Para administradores da plataforma: instalar, configurar e gerenciar a plataforma Chamilo.
* [**Guia do Desenvolvedor**](developer-guide/) — Para desenvolvedores: compreender a arquitetura, criar plugins, usar a API e contribuir com o projeto.

## Novidades no Chamilo 3.0

O Chamilo 3.0 é uma versão principal, com interface completamente redesenhada e muitos recursos novos:

* **Interface moderna** — Construída com Vue 3 e PrimeVue para uma experiência mais rápida e responsiva
* **Ferramentas com IA** — Gerar exercícios, percursos de aprendizagem e obter correção assistida por IA
* **REST API** — REST API completa baseada em API Platform, com autenticação JWT
* **Novas opções de autenticação** — OAuth2 (Azure, Keycloak, Facebook), provisionamento de usuários SCIM
* **LTI 1.3** — Conectar ferramentas de aprendizagem externas de forma integrada
* **Armazenamento em nuvem** — Suporte nativo a Azure Blob, AWS S3 e Google Cloud Storage
* **Temas de cores** — Identidade visual da plataforma personalizável, com suporte a temas
* **Integração OnlyOffice** — Editar documentos de forma colaborativa dentro da plataforma
