# Competências e Avaliações

É aqui que as competências se conectam ao boletim de notas: é a ponte entre os resultados das avaliações e a concessão automática de competências.

## Acessando Competências e Avaliações

No painel de administração, clique em **Skills > Skills and assessments**.

## O Que É Exibido

Uma lista de categorias do boletim de notas, com controles para vincular cada uma a uma competência. Uma vez vinculado, qualquer aluno que atingir o limiar de aprovação dessa categoria do boletim de notas recebe automaticamente a competência associada — sem etapa manual.

Esta é a forma recomendada de conceder competências em escala: em vez de atribuir competências aos usuários um a um, vincule a categoria relevante do boletim de notas uma única vez e deixe que ela se aplique a todos os alunos que se qualificarem. Consulte [Boletim de notas (Avaliações)](../platform-settings/gradebook-settings.md) para saber como as categorias e os limiares do boletim de notas são configurados inicialmente.
