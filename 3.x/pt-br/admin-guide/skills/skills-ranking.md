# Ranking de Competências

O Ranking de Competências é um quadro de líderes de usuários ordenados pela quantidade de competências que adquiriram.

## Acessando o Ranking de Competências

No painel de administração, clique em **Skills > Skills ranking**.

## O Que Ele Mostra

Para cada usuário ativo, o ranking mostra:

* **Skills acquired** — Contagem total de competências emitidas, usada para ordenar o quadro de líderes (maior primeiro)
* **Currently learning** — O número de competências vinculadas, por meio do boletim (gradebook), aos cursos em que o usuário está atualmente matriculado (diretamente ou por meio de uma sessão)

Use esta página para identificar de relance seus aprendizes mais realizados, ou para avaliar a atividade geral de aquisição de competências na plataforma.
