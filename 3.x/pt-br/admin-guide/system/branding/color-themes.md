# Temas de Cores

O Chamilo 2.0 introduz um sistema de temas de cores que permite personalizar a aparência visual da plataforma.

## Como os Temas Funcionam

Os temas de cores definem a paleta utilizada em toda a interface do Chamilo — cores primárias, cores de destaque, fundos e cores de texto. Um tema é associado a uma URL de acesso: em um portal de URL única, ele se torna efetivamente o tema global; em uma configuração de múltiplas URLs, cada URL pode ter o seu próprio.

## Aplicando um Tema

![A página de temas de cores mostrando os temas disponíveis com amostras de pré-visualização e um botão Aplicar](/.gitbook/assets/admin-color-themes.png)

1. No painel de administração, navegue até **Temas de cores**
2. Percorra os temas disponíveis
3. Selecione um tema e clique em **Aplicar**
4. O tema é aplicado imediatamente à plataforma

## Temas por URL

Em uma configuração de múltiplas URLs, cada URL de acesso pode ter o seu próprio tema de cores. Isso permite que portais diferentes tenham identidades visuais distintas, compartilhando a mesma instalação do Chamilo.

## Dicas

* **Alinhe-se à sua marca** — Escolha ou personalize um tema que corresponda às cores da marca da sua organização
* **Teste a legibilidade** — Após aplicar um tema, verifique se o texto é legível sobre as cores de fundo, especialmente em situações de alto contraste
* **Considere a acessibilidade** — Garanta contraste de cores suficiente para usuários com deficiência visual
