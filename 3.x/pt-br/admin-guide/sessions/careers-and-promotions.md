# Carreiras e Promoções

O Chamilo inclui um sistema de gestão de carreiras que permite definir percursos de formação e acompanhar a progressão dos aprendizes em programas estruturados.

## Carreiras

![A lista de carreiras mostrando percursos de carreira definidos, com nome e descrição](/.gitbook/assets/admin-careers-list.png)

Uma **carreira** representa um percurso de formação estruturado — uma sequência de etapas de formação que o aprendiz segue para alcançar um objetivo profissional.

### Criar uma carreira

1. No painel de administração, navegue até **Carreiras**
2. Clique em **Criar uma carreira**
3. Informe um **nome** e uma **descrição**
4. Salve

## Promoções

Uma **promoção** representa uma coorte ou turma de aprendizes que avançam em uma carreira. Pense nela como um grupo de pessoas que percorre o mesmo percurso de carreira ao mesmo tempo.

### Vincular a sessões

Após criar uma promoção, você vincula sessões a ela. Isso define a sequência de formação que o aprendiz deve concluir.

Posteriormente, você pode replicar promoções para facilitar a criação da próxima promoção com cópias das mesmas sessões, de modo que a próxima promoção possa ser montada instantaneamente.

### Criar uma promoção

1. Navegue até **Promoções**
2. Clique em **Criar uma promoção**
3. Informe um **nome** e uma **descrição**
4. Vincule-a a uma **carreira**
5. Atribua **sessões** à promoção
6. Salve

## Como tudo se encaixa

* Uma **carreira** define o percurso (por exemplo, "Certificação de Desenvolvedor Júnior")
* Uma **promoção** representa uma coorte (por exemplo, "Turma de março de 2026")
* As **sessões** dentro da promoção entregam o conteúdo de formação propriamente dito

## Dicas

* **Use em programas estruturados** — Carreiras e promoções são mais úteis em programas de formação em várias etapas, nos quais os aprendizes avançam por uma sequência definida
* **Acompanhe a conclusão** — Use as ferramentas de relatórios para monitorar como as promoções estão avançando em seus percursos de carreira
