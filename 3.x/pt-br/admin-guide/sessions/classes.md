# Turmas

Turmas no Chamilo são grupos predefinidos de usuários que podem ser matriculados em sessões como uma unidade. Elas simplificam o processo de matrícula quando você treina regularmente os mesmos grupos de pessoas.

> Turmas e [Grupos de usuários](../../admin-guide/users/user-groups.md) compartilham a mesma interface. A única diferença é a configuração de **tipo de grupo**: escolha "Turma" ao criar o grupo. Todo o restante — gerenciamento de membros, visibilidade e a própria interface — funciona de forma idêntica.

## Criar uma turma

1. No painel de administração, navegue até **Turmas** (ou Grupos de usuários e selecione o tipo "Turma")
2. Clique em **Criar uma turma**
3. Informe um **nome** (por exemplo, "Equipe de Engenharia", "Novos contratados março de 2026")
4. Adicione **membros** — pesquise e selecione usuários
5. Salve

## Usar turmas para matrícula

Ao criar ou editar uma sessão, você pode matricular uma turma inteira de uma só vez, em vez de adicionar usuários individualmente:

1. Abra as configurações de matrícula da sessão
2. Clique em **Adicionar uma turma**
3. Selecione a turma
4. Todos os membros da turma são matriculados na sessão

## Gerenciar turmas

* **Editar** — Alterar o nome da turma ou atualizar a composição
* **Adicionar/remover membros** — Manter a lista da turma atualizada
* **Excluir** — Remover a turma (não afeta as contas dos membros nem as matrículas já existentes)

## Dicas

* **Crie turmas para coortes recorrentes** — Se você oferece o mesmo treinamento para equipes diferentes, crie uma turma para cada equipe
* **Atualize antes de cada sessão** — Revise a composição da turma antes de matriculá-la em uma nova sessão para garantir que a lista esteja atualizada
* **Combine com importação CSV** — Importe a composição da turma a partir de um arquivo CSV para grupos grandes
