# Sessões

Sessões são um dos recursos mais poderosos do Chamilo. Elas permitem oferecer os mesmos cursos a diferentes grupos de alunos em momentos distintos, sem duplicar o conteúdo do curso.

## Compreendendo as sessões

As sessões são **opcionais**. Você pode fazer o portal funcionar apenas com cursos, mas **realmente** recomendamos considerar a complexidade extra das sessões como forma de economizar trabalho de gestão a longo prazo.

Um **curso** contém o conteúdo (documentos, exercícios, percursos de aprendizagem). Uma **sessão** atribui esse curso (ou vários cursos) a um grupo específico de alunos *por um período determinado*.

Essa arquitetura significa que:

* Os professores criam o conteúdo uma única vez no curso
* Os administradores criam sessões para oferecer esse conteúdo a diferentes coortes
* Cada sessão tem sua própria matrícula, dados de acompanhamento e resultados
* O conteúdo-base do curso é compartilhado, mas os tutores da sessão podem personalizar determinados elementos

## Quando usar sessões

Use sessões quando:

* Você oferece a mesma formação várias vezes (por exemplo, sessões mensais de integração)
* Você tem programas baseados em coortes (por exemplo, turmas por semestre)
* Você precisa de acompanhamento separado por grupo de alunos
* Você deseja que tutores diferentes gerenciem edições distintas do mesmo curso
