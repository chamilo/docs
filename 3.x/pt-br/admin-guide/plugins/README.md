# Plugins

Plugins estendem a funcionalidade do Chamilo sem modificar o código-fonte. O Chamilo 3.0 inclui mais de 50 plugins que podem ser ativados conforme a necessidade.

## O bloco Plugins

O painel de administração também possui o próprio bloco **Plugins**, separado da gestão geral de plugins deste capítulo. Ele não lista todos os plugins instalados — apenas aqueles cuja configuração declara que devem aparecer na região de menu administrativo, oferecendo a cada um desses plugins um atalho direto para a respectiva página de administração no próprio painel.

![O bloco Plugins no painel de administração, listando atalhos para plugins instalados configurados para aparecer no menu administrativo](/.gitbook/assets/admin-plugins-block.png)

Se um plugin que você ativou não aparecer aqui, isso é esperado — significa que aquele plugin em particular não se declarou para a região de menu administrativo, e não que algo esteja quebrado. Consulte [Gerenciando plugins](managing-plugins.md) para a lista completa de plugins instalados, independentemente de aparecerem ou não no painel.
