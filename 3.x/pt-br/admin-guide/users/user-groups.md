# Turmas / Grupos de usuários

Turmas no painel de administração são grupos de toda a plataforma usados para organizar usuários para fins de gerenciamento. Elas são distintas dos grupos no nível do curso (que são criados por professores dentro de um curso).

> Grupos de usuários e [Turmas](../../admin-guide/sessions/classes.md) compartilham a mesma interface. A única diferença é a configuração de **tipo de grupo**: escolha "Class" para criar uma turma (usada para inscrição em massa em sessões), ou "User group" para grupos mais sociais que podem ter o próprio espaço na rede social interna. Consulte [Turmas](../../admin-guide/sessions/classes.md) para detalhes sobre a inscrição em sessões.

## Criando um grupo

![A lista de grupos de usuários mostrando os grupos disponíveis com nome, descrição e número de membros](/.gitbook/assets/admin-user-groups-list.png)

1. No painel de administração, navegue até **Turmas**
2. Clique em **Add classes**
3. Informe um **título** e, opcionalmente, uma **descrição**
4. Marque **Social group** se este for um grupo social. Deixe desmarcado se for uma turma.
5. Adicione um URL de referência opcional e uma imagem/logotipo.
6. Escolha as **permissões** do grupo:
   * **Open** — Qualquer usuário pode ingressar
   * **Closed** — Os usuários devem ser adicionados por um administrador
7. Marque se deseja que os membros possam sair da turma por conta própria.
8. Salve.

## Adicionando membros

1. Abra a lista de turmas/grupos de usuários
2. Clique no ícone de usuário **Subscribe users to class**
3. Pesquise usuários por nome, nome de usuário ou e-mail
4. Selecione os usuários a adicionar, usando as setas do lado direito
5. Clique no botão de confirmação para salvar

## Casos de uso

* **Organização por departamento** — Agrupar usuários por departamento ou equipe
* **Inscrição em massa** — Adicionar todos os membros de um grupo a um curso ou sessão de uma só vez
* **Comunicação direcionada** — Enviar anúncios a grupos específicos
* **Relatórios** — Visualizar o progresso da capacitação filtrado por grupo

## Gerenciando grupos

* **Edit** — Alterar o nome, a descrição ou a visibilidade do grupo
* **Manage members** — Adicionar ou remover membros
* **Delete** — Remover o grupo (não exclui as contas dos membros)
