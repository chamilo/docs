# Tickets

A entrada **Tickets** no bloco Analytics é um atalho para o sistema de tickets de suporte do Chamilo — ela abre diretamente a lista de tickets, não uma página de configurações.

## Acessando Tickets

No painel de administração, clique em **Analytics > Tickets**.

## O que é exibido

A lista de tickets em que as solicitações de suporte são acompanhadas e respondidas — o mesmo sistema de tickets abordado na perspectiva do agente de suporte na página [Tickets de suporte](../../teacher-guide/tickets.md) do Guia do Professor.

Para configurar o próprio sistema de tickets (categorias, prioridades, equipe atribuída), consulte [Configurações de tickets](../platform-settings/ticket-settings.md) em Configurações da plataforma.
