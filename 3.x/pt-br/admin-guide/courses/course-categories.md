# Categorias de Cursos

As categorias de cursos ajudam a organizar o catálogo de cursos, facilitando que os aprendizes encontrem cursos relevantes.

## Criando uma Categoria

1. No painel de administração, navegue até **Course categories**
2. Clique em **Add category**
3. Informe:
   * **Category code** — Um identificador único e curto
   * **Category name** — O nome de exibição (por exemplo, "Information Technology", "Management Skills")
   * **Allow adding courses in this category?** — Se permite que os cursos definam esta como categoria, ou se serve apenas como um nível intermediário em uma hierarquia 
   * **Parent category** — (Opcional) Coloque esta categoria sob outra categoria para criar uma hierarquia
   * **Description** — (Opcional)
   * **Image** — (Opcional) Representará esta categoria, embora quase não seja exibida em nenhum lugar
4. Pressione *Add category*

O Chamilo cria 3 categorias por padrão: *Language skills*, *PC Skills* e *Projects*. Elas podem ser renomeadas, removidas ou mantidas, conforme as suas necessidades.

## Hierarquia de Categorias

![A página de gerenciamento de categorias de cursos mostrando uma árvore aninhada de categorias](/.gitbook/assets/admin-course-categories.png)

As categorias podem ser aninhadas para criar uma estrutura em árvore:

* Business
  * Management
  * Marketing
  * Finance
* Technology
  * Programming
  * Networking
  * Cybersecurity

Os aprendizes que navegam no catálogo de cursos podem percorrer essa hierarquia para encontrar cursos.

## Gerenciando Categorias

* **Edit** — Altere o nome, o código ou a categoria pai
* **Move** — Altere a posição de uma categoria na lista
* **Delete** — Remova uma categoria. Os cursos de uma categoria excluída são movidos para "uncategorized."

## Dicas

* **Mantenha a simplicidade** — Use categorias amplas que os aprendizes possam compreender de relance
* **Limite a profundidade** — Evite categorias profundamente aninhadas. Dois ou três níveis costumam ser suficientes.
* **Atribua categorias durante a criação do curso** — Incentive os professores a selecionar uma categoria ao criar cursos, para que o catálogo permaneça organizado
