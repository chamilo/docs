# Multi-URL

O recurso de multi-URL do Chamilo (também chamado de multi-tenant) permite executar vários portais virtuais a partir de uma única instalação do Chamilo. Cada portal tem sua própria URL, identidade visual, usuários, cursos e configurações, mas todos compartilham o mesmo banco de dados e o mesmo código-fonte.
