# Primeiros Passos

Esta seção apresenta a interface de administração do Chamilo 3.0 e ajuda você a se orientar.

## Quem é um Administrador?

O Chamilo possui vários níveis de papéis administrativos:

| Papel | Acesso |
|------|--------|
| **Administrador** | Acesso total a todos os recursos de administração da plataforma. Também conhecido como **Administrador do Portal** |
| **Administrador Global** | Igual ao Administrador do Portal, com acesso a todos os URLs de acesso em uma configuração multi-URL (multi-tenant) |
| **Administrador de Sessões** | Pode gerenciar sessões, matricular usuários em sessões e acessar configurações relacionadas a sessões |
| **Gestor de Recursos Humanos** | Pode visualizar o progresso dos alunos e os dados de acompanhamento dos usuários atribuídos |
| **Gestor de Questões** | Menos um administrador do que um curador de conteúdo, os gestores de questões têm acesso a um banco global de questões para revisar a qualidade das questões |

Este guia concentra-se principalmente no papel de **Administrador do Portal**, que possui o acesso mais amplo.

## Entrando no Sistema

Os administradores entram pela mesma página de login que todos os outros usuários. Após inserir suas credenciais, você será enviado (na ausência de outra configuração) para a página de **Administração**. Uma diferença notável em relação a outros papéis de usuário é a seção **Administração** na barra lateral (não visível para outros papéis).
