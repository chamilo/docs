# Outros Blocos de Administração

O painel de administração possui mais alguns blocos que não são tanto recursos configuráveis quanto widgets informativos: uma página de links de saída, um registro de verificação de versão e dois painéis pequenos que extraem conteúdo de chamilo.org. Este capítulo explica o que cada um é, de onde vem o conteúdo e — já que alguns o fazem — se algum dado sai da sua plataforma.

## O que é abordado

* **[Links do Chamilo.org](chamilo-org-links.md)** — Uma lista de favoritos para recursos oficiais do Chamilo; não envia nada
* **[Verificação de Versão](version-check.md)** — Registro opcional que informa a versão e o uso da sua plataforma ao chamilo.org e indica se você precisa de uma atualização
* **[Suporte Profissional](professional-support.md)** — Um painel somente leitura que descreve os provedores oficiais de suporte do Chamilo
* **[Notícias do Chamilo](news-from-chamilo.md)** — Um feed somente leitura de anúncios oficiais, incluindo correções de segurança e novos lançamentos

Cada página abaixo declara claramente o que, se houver, é enviado ao chamilo.org, e por quê.
