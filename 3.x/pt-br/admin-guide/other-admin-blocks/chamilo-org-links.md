# Links do Chamilo.org

O bloco **Chamilo.org** é uma lista estática de links de saída para recursos oficiais do Chamilo — nada além disso. Ele não envia dados a lugar nenhum; cada link abre um site externo do Chamilo ou uma página de documentação local incluída na sua instalação.

## O que há no bloco

| Link | Destino |
|------|-------------|
| Página inicial do Chamilo | `chamilo.org` |
| Guias do usuário | `docs.chamilo.org` |
| Fórum do Chamilo | GitHub Discussions do chamilo-lms |
| Guia de instalação | Local, `/documentation/installation_guide.html` |
| Alterações na última versão | Local, `/documentation/changelog.html` |
| Lista de colaboradores | Local, `/documentation/credits.html` |
| Guia de segurança | Local, `/documentation/security.html` |
| Guia de otimização | Local, `/documentation/optimization.html` |
| Prestadores oficiais de serviços do Chamilo | `chamilo.org/providers` |

Os links “locais” apontam para arquivos de documentação empacotados com a própria instalação do Chamilo, portanto são carregados a partir do seu servidor, e não de chamilo.org.

## Finalidade

Este bloco existe apenas por conveniência — acesso rápido à documentação oficial do projeto, ao espaço de discussão da comunidade e à lista de prestadores de serviços homologados, sem precisar procurá-los.
