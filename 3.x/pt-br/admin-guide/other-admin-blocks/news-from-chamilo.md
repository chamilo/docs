# Notícias da Chamilo

Notícias da Chamilo é um pequeno painel somente leitura que obtém anúncios oficiais da Chamilo Association — é aqui que você fica sabendo de um novo lançamento ou, o que é mais importante, de um patch de segurança que deve ser aplicado.

## O que é exibido e de onde vem

O painel busca o conteúdo em `version.chamilo.org/c/news/latest.php`, solicitando-o no idioma da interface da sua plataforma. A única informação enviada pela plataforma é esse código de idioma — nenhum detalhe da plataforma, dado de uso ou informação de contato sai do seu servidor por causa deste recurso.

## Finalidade

Este é o canal da Chamilo para alcançar os administradores diretamente sobre o que importa operacionalmente: lançamentos de novas versões e — o mais importante — **patches de segurança**. Como aplicar patches de segurança com rapidez é uma das medidas mais eficazes para manter a plataforma segura (consulte o [Guia de Segurança](../appendix/security-guide.md)), vale a pena olhar este painel periodicamente, em vez de conferir apenas quando você se lembrar.

Este feed é carregado de forma independente da [Verificação de versão](version-check.md) — você não precisa registrar a plataforma para vê-lo.
