# Notificar na Página Inicial do Curso

Notificar na Página Inicial do Curso <img src="/.gitbook/assets/icons/mdi-bell-ring-outline.svg" alt="Notificar na Página Inicial do Curso" data-size="line"> permite exibir um aviso em popup para todos que visitam a página inicial do seu curso — útil para um anúncio, um aviso de leitura obrigatória ou um bloqueio do tipo “clique aqui para continuar”.

## Definindo uma Notificação

Uma vez habilitada, as **Configurações** <img src="/.gitbook/assets/icons/mdi-cog.svg" alt="Configurações" data-size="line"> do seu curso passam a ter um botão **Definir uma notificação na página inicial**. Ele abre um formulário no qual você redige o aviso (texto rico) e, opcionalmente, define um **Link de expiração**.

* **Com um link de expiração** — O popup exibe um botão apontando para esse link e continua reaparecendo até que o aluno clique nele
* **Sem um** — O aviso reaparece para cada visitante, toda vez que ele abre a página inicial do curso

Use **Excluir notificação na página inicial do curso** para removê-la.

## Dicas

* **Apenas um aviso por curso** — Criar um novo substitui o que estava lá antes; não há como enfileirar vários
* **Pré-visualize a formatação** — O aviso é exibido como HTML bruto em um popup, portanto verifique se o texto rico é renderizado da forma esperada antes de publicá-lo
* **Use o link de expiração para qualquer conteúdo com prazo** — Sem ele, o mesmo aviso continua aparecendo indefinidamente, o que pode se tornar repetitivo para alunos que retornam
