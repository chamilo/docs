# Exportação de Pesquisa CSV

Survey Export CSV <img src="../../.gitbook/assets/icons/mdi-file-delimited-outline.svg" alt="Exportação de Pesquisa CSV" data-size="line"> adiciona a exportação com um clique dos resultados de uma pesquisa para um arquivo CSV compacto, com uma linha por respondente e uma coluna por pergunta.

## Exportando uma Pesquisa

Uma vez habilitado, a lista da ferramenta **Pesquisa** do seu curso ganha uma coluna **Exportar** com um ícone CSV em cada linha de pesquisa. Clique nele para baixar os resultados imediatamente — sem etapas extras.

## O que há no Arquivo

* Pesquisas anônimas são exportadas sem colunas de identidade
* Pesquisas não anônimas incluem a identidade do respondente junto com as respostas
* Se respostas incompletas (não finalizadas) são incluídas é controlado pelo seu administrador, não por este botão de exportação

## Dicas

* **Pesquisas grandes podem demorar um momento** — Conjuntos de respostas muito grandes podem ser mais lentos para exportar; isso é uma consideração de desempenho do banco de dados que seu administrador pode ajustar se necessário
* **Combine com Survey Export TXT** — Se você também tiver o plugin [Survey Export TXT](survey-export-txt.md) habilitado, verá dois ícones de exportação; escolha o formato que melhor se adequar a como você planeja usar os dados
