# Teste para PDF

Teste para PDF <img src="../../.gitbook/assets/icons/mdi-file-pdf-box.svg" alt="Teste para PDF" data-size="line"> exporta as questões de um teste do curso para um PDF imprimível — somente questões, somente respostas, ou ambos juntos — útil para uma versão em papel de um teste.

## Acessando a ferramenta

Uma vez habilitada, uma ferramenta **Teste para PDF** aparece na página inicial do seu curso, listando todos os testes do curso (ou da sessão). Cada linha oferece três ações: **Baixar questões**, **Baixar respostas** e **Baixar tudo**.

## Dicas

* **Nem todos os tipos de questão são suportados** — Apenas um subconjunto dos tipos de questão do Chamilo (múltipla escolha, verdadeiro/falso e formatos fechados semelhantes) é exportado corretamente; questões abertas ou tipos mais complexos podem não aparecer corretamente, ou sequer aparecer
* **Verifique o resultado antes de imprimir um lote completo** — Revise o PDF gerado de um teste antes de imprimir em massa para uma sessão de exame
