# Exportação de Pesquisa TXT

A Exportação de Pesquisa TXT <img src="/.gitbook/assets/icons/mdi-file-outline.svg" alt="Exportação de Pesquisa TXT" data-size="line"> exporta os resultados de uma pesquisa para um arquivo de texto simples legível por humanos — um bloco por respondente, listando cada pergunta, a(s) resposta(s) escolhida(s) e qualquer resposta em texto aberto, em vez das linhas e colunas de um CSV.

## Exportando uma Pesquisa

Uma vez habilitada, a lista da ferramenta **Pesquisa** do seu curso passa a ter um ícone **Exportar** em cada linha de pesquisa. Clique nele para baixar os resultados como um arquivo `.txt`.

## O que Há no Arquivo

* Pesquisas anônimas exibem "Anonymous" em vez dos dados de identidade; pesquisas não anônimas incluem o nome e o nome de usuário do respondente
* As respostas de cada respondente são separadas por uma linha divisória, tornando o arquivo fácil de ler de cima para baixo
* Se nenhuma resposta se qualificar para exportação, o arquivo simplesmente informa isso em vez de falhar

## Dicas

* **Melhor para leitura, CSV para análise** — Use este formato quando quiser ler as respostas diretamente; use [Exportação de Pesquisa CSV](survey-export-csv.md) se pretender abrir os resultados em uma planilha
