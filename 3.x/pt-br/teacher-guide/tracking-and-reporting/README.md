# Acompanhamento e Relatórios

O Chamilo registra a atividade dos alunos em toda a plataforma, oferecendo a você insights detalhados sobre o progresso dos seus alunos.

* **[Acompanhamento do aluno](learner-tracking.md)** — Monitore a atividade individual do aluno: horários de login, tempo gasto, páginas visitadas e uso das ferramentas
* **[Relatórios do curso](course-reports.md)** — Visualize dados agregados de todos os alunos de um curso
* **[Certificados e competências](certificates-and-skills.md)** — Emita certificados com base nas notas do boletim e valide as competências adquiridas

## Acessando os relatórios

No seu curso, clique na ferramenta **Acompanhamento** <img src="../../.gitbook/assets/icons/mdi-chart-box.svg" alt="Acompanhamento" data-size="line"> na página inicial do curso. Você também pode acessar os relatórios pelo link **Relatórios** na barra lateral, para uma visão geral entre cursos.

Os professores veem os dados de relatórios dos cursos que ministram. Os tutores de sessão veem os dados de todos os cursos da sua sessão.
