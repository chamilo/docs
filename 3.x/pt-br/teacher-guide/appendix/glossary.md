# Glossário

Termos-chave utilizados ao longo deste guia.

| Termo | Definição |
|------|-----------|
| **Avaliação** | Consulte **Boletim de notas** abaixo |
| **Tarefa** | Uma atividade em que os alunos enviam arquivos ou texto para revisão e correção pelo professor. Também conhecida como "publicação do aluno" ou "trabalho". |
| **Auto-launch** | Recurso que abre automaticamente uma ferramenta específica quando o aluno entra em um curso. |
| **Certificado** | Documento gerado automaticamente quando o aluno atinge a pontuação mínima definida no boletim de notas. |
| **Curso** | Um contêiner para conteúdo de aprendizagem e ferramentas. Um curso pode incluir documentos, exercícios, fóruns, percursos de aprendizagem e muito mais. |
| **Tutor do curso** | Papel de professor específico de sessões. Um tutor do curso gerencia um curso dentro de uma sessão. Chamado de "course coach" nas versões do Chamilo anteriores à 3.0. |
| **Cota de disco** | O espaço máximo de armazenamento alocado a um curso para arquivos enviados. |
| **Matrícula** | O processo de registrar um usuário em um curso ou sessão, concedendo-lhe acesso ao conteúdo. Também conhecido como "inscrição". |
| **Exercício** | Um questionário ou prova contendo uma ou mais questões. Também referido como "teste" em alguns contextos. |
| **Fórum** | Ferramenta de discussão com conversas em tópicos organizadas em categorias e assuntos. |
| **Boletim de notas** | Ferramenta que agrega pontuações de exercícios, tarefas e outras atividades em uma nota unificada para cada aluno. |
| **Percurso de aprendizagem** | Sequência estruturada de atividades de aprendizagem (documentos, exercícios, links) que os alunos seguem em uma ordem definida, opcionalmente com pré-requisitos. |
| **LTI** | Learning Tools Interoperability — um padrão que permite incorporar ferramentas de aprendizagem externas no Chamilo. |
| **SCORM** | Sharable Content Object Reference Model — um padrão para pacotes de conteúdo de e-learning. O Chamilo pode importar e reproduzir pacotes SCORM dentro de percursos de aprendizagem. |
| **Sessão** | Uma edição limitada no tempo de um ou mais cursos atribuída a um grupo específico de alunos. As sessões permitem reutilizar o mesmo conteúdo do curso para diferentes turmas. |
| **Tutor da sessão** | Papel de supervisão que acompanha todos os cursos de uma sessão. Chamado de "session coach" nas versões do Chamilo anteriores à 3.0. |
| **Competência** | Uma habilidade que pode ser vinculada a conquistas do boletim de notas. Quando o aluno obtém um certificado, as competências associadas são validadas. |
| **Pesquisa** | Ferramenta de questionário para coleta de feedback, com diversos tipos de pergunta e opções de resposta anônima. |
| **Visibilidade** | Configuração que controla se uma ferramenta, documento ou atividade é visível para os alunos. Os professores sempre podem ver itens ocultos. |
