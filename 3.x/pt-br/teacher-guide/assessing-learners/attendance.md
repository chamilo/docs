# Frequência

A ferramenta de frequência permite registrar a presença dos alunos nas sessões de aula agendadas, presenciais ou online.

## Criando uma Folha de Frequência

1. Abra a ferramenta **Attendance** na página inicial do curso
2. Clique em **Add attendance** para criar uma folha de frequência
3. Informe um **Title** para a folha de frequência (por exemplo, "Semana 1 - Introdução")
4. Informe uma **Description** (destina-se principalmente ao seu uso — os alunos não verão a descrição)
5. Salve

### Configurações avançadas

1. **Require unique presence** permite considerar o aluno como totalmente presente se ele participou mesmo que de apenas uma data da folha de frequência
2. **Gradebook options** permite decidir se a folha de frequência será pontuada na ferramenta de avaliação (gradebook).

## Adicionando datas

Cada folha de frequência contém uma ou mais datas (sessões) nas quais você registra a presença:

1. Abra uma folha de frequência ou continue o processo de criação
2. Clique em **Add a date** <img src="/.gitbook/assets/icons/mdi-calendar-plus.svg" alt="Adicionar data" data-size="line">
3. Selecione a data e a hora
4. Opcionalmente, marque **Repeat date** para escolher uma lógica de repetição
5. Informe uma **Duration** em minutos para o evento (o padrão é 60 minutos)
6. Opcionalmente, selecione um **Group** se esta data de frequência se aplicar apenas a um grupo de alunos
7. Salve

Você pode adicionar várias datas à mesma folha de frequência (por exemplo, todas as sessões de um mês).

## Registrando a Frequência

Para cada data, marque cada aluno como:

* **Present** — O aluno compareceu (valor padrão para todos os alunos)
* **Absent** — O aluno não compareceu

Clique na célula de status ao lado do nome de cada aluno para alternar entre presente e ausente.

Por padrão, todos os alunos são marcados como presentes, pois consideramos que as chances são de haver mais pessoas presentes do que ausentes.

Observação: os administradores podem alterar a configuração do portal para permitir tipos de frequência mais amplos (atrasado, ausente com justificativa etc.), que podem refletir melhor seus procedimentos. Nesse caso, apenas clicar no campo de presença alternará entre todos os tipos de presença.

## Visualizando Relatórios de Frequência

![A folha de frequência mostrando uma tabela-resumo com alunos, datas e indicadores de presença](/.gitbook/assets/attendance-sheet.png)

A ferramenta de frequência mostra:

* Uma tabela-resumo com todos os alunos e todas as datas
* O percentual de frequência de cada aluno (sessões presentes / sessões totais)
* Indicadores com código de cores para facilitar a leitura

## Extra

As frequências possuem alguns recursos estendidos que não ficam visíveis de imediato:
* **Signatures** podem ser habilitadas para que os alunos assinem a frequência em sala por meio de um tablet manuseado pelo professor
* **Comments** podem ser adicionados pelo professor em cada frequência do aluno
* **PDF reports** podem ser extraídos para atender à regulamentação

## Dicas

* **Vincule ao progresso do curso** — Use os dados de frequência juntamente com a ferramenta Course Progress para correlacionar presença com a cobertura dos tópicos
* **Exporte os dados** — Exporte a folha de frequência para registros administrativos
* **Defina expectativas** — Se a frequência for obrigatória, comunique a política com clareza na introdução do curso ou nos avisos
