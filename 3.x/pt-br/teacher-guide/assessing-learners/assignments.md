# Tarefas

A ferramenta de tarefas (também chamada de "publicações dos alunos") permite coletar trabalhos dos aprendizes — redações, projetos, relatórios ou qualquer envio baseado em arquivo — e avaliá-los.

## Criando uma Tarefa

1. Abra a ferramenta **Tarefas** <img src="../../.gitbook/assets/icons/mdi-inbox-full.svg" alt="Tarefas" data-size="line"> na página inicial do curso
2. Clique em **Criar uma tarefa**
3. Preencha os detalhes:
   * **Nome da tarefa** — O nome da tarefa (por exemplo, "Relatório do Projeto Final")
   * **Descrição** — Instruções para os aprendizes, incluindo o que enviar e como será avaliado (suporta texto rico)
   * **Pontuação máxima** — Sobre qual total a tarefa será avaliada
   * **Adicionar ao boletim** — Adicionar como item avaliado na ferramenta de avaliação (boletim), para que possa fazer parte do alcance dos objetivos do curso
   * **Prazo** — A data e hora oficiais (publicadas) após as quais os envios são marcados como atrasados (os uploads ainda são aceitos)
   * **Termina em (completamente fechado)** — A data e hora limite rígidas após as quais nenhum upload é possível
   * **Adicionar ao calendário** — Criar um evento para referenciar esta data de envio da tarefa
   * **Tipo de envio** — Escolha entre **Permitir apenas texto**, **Permitir apenas arquivos** ou **Permitir arquivos ou texto online**
4. Salve

Depois de criar uma tarefa, você também pode:
* Enviar documentos modelo a partir da página de detalhes da tarefa
* Atribuir a tarefa a usuários específicos (em vez de a todos os usuários do curso)

E depois que os aprendizes tiverem enviado suas tarefas, você pode:
* Exportar uma lista em PDF dos envios
* Mostrar uma lista apenas dos aprendizes que não enviaram a tarefa
* Baixar todas as tarefas em um ZIP grande
* Enviar todas as correções em um ZIP grande
* Excluir todas as correções que você enviou (isso não exclui os envios dos aprendizes)

## Como os Aprendizes Enviam

Os aprendizes abrem a tarefa e:

1. Clicam em **Enviar arquivo** ou no botão de envio
2. Selecionam um arquivo do computador (ou escrevem texto diretamente, conforme a configuração)
3. Adicionam um comentário opcional
4. Enviam

Os aprendizes podem ver se já enviaram e, se permitido, atualizar o envio.

## Revisando Envios

![A lista de envios da tarefa mostrando nomes dos alunos, datas, arquivos e status de avaliação](../../.gitbook/assets/assignments-submissions-list.png)

Como professor, abra uma tarefa para ver a lista de todos os envios:

* **Nome do aluno** — Quem enviou
* **Data de envio** — Quando o trabalho foi enviado
* **Arquivo** — Baixar o arquivo enviado
* **Status** — Se o envio foi avaliado
* **Comentários** — Quaisquer comentários deixados pelo aprendiz ou por você

### Avaliando um Envio

![A visualização de avaliação da tarefa com campo de pontuação, campo de feedback e envio de arquivo corrigido](../../.gitbook/assets/assignment-grading-view.png)

1. Clique em um envio para abri-lo
2. Revise o arquivo enviado
3. Informe uma **pontuação**
4. Escreva **comentários de feedback** para o aprendiz
5. Opcionalmente, envie um **arquivo corrigido** como anexo
6. Salve

### Avaliação Assistida por IA

Se ferramentas de IA estiverem configuradas na sua plataforma, você poderá ver uma opção de **Avaliação por IA** ao revisar envios. Isso usa um modelo de IA para sugerir uma pontuação e um feedback para trabalhos abertos. Consulte [Avaliação por IA](../ai-tools/ai-grading.md) para detalhes.

## Gerenciando Envios

Ações em grupo:
* **Baixar pacote de tarefas** — Baixar todos os envios como um único arquivo ZIP para revisão offline
* **Enviar pacote de correções** — Se você baixou todos os envios em um único arquivo ZIP, editou os arquivos no computador e compactou novamente, pode enviar o zip como um pacote de correções. Não altere os nomes dos arquivos, senão não funcionará.
* **Envios atrasados** — Envios após o prazo são sinalizados, mas ainda podem ser aceitos conforme suas configurações

Ações em envios individuais:
* **Enviar correção** — Enviar uma correção para um aprendiz 
* **Baixar** — Baixar o envio de um aprendiz
* **Corrigir e avaliar** — Adicionar uma correção e uma nota ao envio do aprendiz 
* **Editar** — Editar o título do documento ou o feedback anterior no envio
* **Mover** — Transferir um envio entre pastas de tarefas (por exemplo, se o aluno enviou na tarefa errada)
* **Visibilidade** — Controlar se os aprendizes podem ver os envios uns dos outros

## Vinculação ao Boletim

As pontuações das tarefas podem ser incluídas no boletim do curso (ferramenta "Avaliações"). Isso permite que as notas das tarefas contribuam para a nota geral do aprendiz no curso e para a elegibilidade ao certificado. Consulte [Boletim](gradebook.md) para detalhes.

## Dicas

* **Seja específico nas instruções** — Descreva claramente o que os alunos devem enviar, o formato esperado e os critérios de avaliação
* **Defina prazos realistas** — Use a ferramenta Agenda para tornar os prazos visíveis no calendário do curso
* **Use o recurso de arquivo corrigido** — Envie versões anotadas do trabalho dos alunos para que eles possam ver suas correções específicas
* **Ative a visibilidade entre pares com cuidado** — Permitir que os alunos vejam o trabalho uns dos outros pode incentivar a aprendizagem, mas pode não ser adequado para todas as tarefas
