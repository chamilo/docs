# Pesquisas

A ferramenta de pesquisas permite criar questionários para coletar feedback dos seus alunos. As pesquisas são úteis para avaliações de curso, diagnósticos de necessidades e enquetes de opinião.

## Criando uma pesquisa

1. Abra a ferramenta **Pesquisas** <img src="../../.gitbook/assets/icons/mdi-form-dropdown.svg" alt="Pesquisas" data-size="line"> na página inicial do curso
2. Clique em **Criar pesquisa**
3. Preencha os detalhes da pesquisa:
   * **Código** — Este é um código exclusivo da pesquisa. Será usado em e-mails e links.
   * **Título** — O nome da pesquisa
   * **Subtítulo** — Um cabeçalho secundário opcional
   * **Data de início** — A partir de quando esta pesquisa estará aberta à participação
   * **Data de término** — Até quando esta pesquisa estará aberta à participação
   * **Anônima** — Se as respostas são anônimas ou vinculadas a alunos individuais
   * **Visibilidade dos resultados** — Quem pode ver os resultados (somente o tutor, tutor e alunos, todos)
   * **Introdução** — Uma mensagem exibida aos alunos antes de iniciarem a pesquisa
   * **Mensagem de agradecimento** — Uma mensagem exibida após o envio
4. Salve

### Configurações avançadas

* **Nota na ferramenta de avaliação** — Se o estado de resposta desta pesquisa deve ser incluído na ferramenta de avaliação (boletim). Quem tiver concluído a pesquisa recebe 100%; os demais recebem 0%
* **Pesquisa pai** — Não é realmente usada neste momento (recurso legado)
* **Uma pergunta por página** — Estilo de apresentação das perguntas
* **Ativar modo de embaralhamento** — Se as perguntas devem ser embaralhadas
* **Mostrar número da pergunta** — Se devem ser exibidos os números (gerados automaticamente) das perguntas

## Adicionando perguntas

Depois que a pesquisa for criada, adicione perguntas:

1. Escolha o tipo de pergunta:
   * **Sim/Não** — Uma escolha binária simples
   * **Múltipla escolha** — Selecione uma resposta entre várias opções
   * **Múltiplas respostas** — Selecione uma ou mais respostas entre várias opções
   * **Dissertativa** — Resposta em texto livre
   * **Lista suspensa** — Selecione em uma lista suspensa
   * **Porcentagem** — Escolha um valor percentual
   * **Pontuação** — Avalie em uma escala numérica
   * **Comentário** — Um bloco de texto (não é uma pergunta) para adicionar instruções entre as perguntas
   * **Múltipla escolha com opção "outro"** — Selecione uma resposta entre várias opções, com uma alternativa
   * **Exibição seletiva** — Tipo especial que permite adaptar o fluxo das perguntas com base em respostas anteriores
   * **Quebra de página** — Adicione quebras de página no fluxo das perguntas. Só é útil se "Uma pergunta por página" **não** tiver sido selecionada na etapa anterior
2. Configure o texto da pergunta e as opções de resposta
3. Salve

Cada pergunta pode ser marcada como obrigatória. Se você não marcar, pular qualquer pergunta será um comportamento aceitável.

## Publicando uma pesquisa

Depois de adicionar todas as perguntas:

1. Clique em **Publicar**
2. Escolha os destinatários — Selecione alunos ou grupos específicos (você os seleciona). O botão **Adicionar alunos** adiciona todos os alunos de uma só vez e deixa os professores de fora
3. Adicionar usuários adicionais — Permite convidar usuários de fora do Chamilo para participar da pesquisa. Eles receberão um e-mail com um link e aparecerão pelo endereço de e-mail nos detalhes da pesquisa
4. Assunto do e-mail
5. Texto do e-mail — Explique do que se trata a pesquisa e quando/como responder
6. Estão disponíveis diferentes opções para repetir os convites
7. Confirme

Os alunos recebem um convite (por e-mail) para preencher a pesquisa.

Há um link na parte inferior da página de publicação para convidar ainda mais usuários externos a participar. Os participantes que usarem este link não serão identificados e aparecerão como anônimos nos resultados da pesquisa.

## Visualizando resultados

![Resultados da pesquisa com gráficos e detalhamento percentual para cada pergunta](../../.gitbook/assets/survey-results-charts.png)

Depois que os alunos tiverem respondido:

1. Abra a pesquisa
2. Clique em **Resultados** ou **Relatório**
3. Visualize os resumos das respostas:
   * Gráficos e porcentagens para perguntas fechadas
   * Respostas individuais em texto para perguntas dissertativas
   * Taxa de conclusão (quantos convidados responderam)

Você pode exportar os resultados para uma planilha para análise posterior.

## Dicas

* **Seja breve** — Os alunos têm mais probabilidade de concluir pesquisas mais curtas
* **Use o modo anônimo** — Para um feedback honesto, ative as respostas anônimas
* **Escolha o momento certo** — Envie pesquisas no meio do curso para fazer ajustes, e não apenas avaliações de fim de curso
