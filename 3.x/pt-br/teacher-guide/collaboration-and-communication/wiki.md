# Wiki

A ferramenta wiki permite que você e seus alunos criem e editem páginas da web de forma colaborativa no curso. É útil para projetos em grupo, bases de conhecimento compartilhadas e exercícios de escrita colaborativa.

## Como o Wiki Funciona

Uma wiki é uma coleção de páginas da web interligadas que qualquer pessoa com permissão pode editar. No Chamilo:

* Cada curso tem sua própria wiki
* As páginas podem ser vinculadas umas às outras usando links no estilo wiki
* Todas as edições são rastreadas com um histórico de revisões
* Versões anteriores podem ser comparadas e restauradas

## Criando uma Página Wiki

1. Abra a ferramenta **Wiki** na página inicial do curso
2. Clique em **Adicionar uma nova página**
3. Insira um **título da página**
4. Escreva o conteúdo da página usando o editor de texto rico
5. Salve

Para vincular a outra página wiki a partir do editor, crie um link usando o título da página de destino.

## Editando Páginas

Qualquer pessoa com permissões de edição pode modificar uma página wiki:

1. Abra a página que deseja editar
2. Clique no botão **Editar** <img src="/.gitbook/assets/icons/mdi-pencil.svg" alt="Editar" data-size="line">
3. Faça suas alterações no editor
4. Adicione uma entrada opcional de **Comentários** descrevendo o que você alterou
5. Salve

## Histórico de Revisões

Cada edição cria uma nova revisão. Você pode:

* **Ver histórico** — Ver uma lista de todas as revisões com carimbos de data/hora e autores
* **Comparar versões** — Ver o que mudou entre duas revisões
* **Restaurar uma versão** — Reverter a página para uma revisão anterior, se necessário

## Gerenciando a Wiki

Como professor do curso, você pode:

* **Ver todas as páginas** — Ver uma lista de todas as páginas wiki do curso
* **Encontrar páginas órfãs** — Identificar páginas que não estão vinculadas a partir de nenhuma outra página
* **Encontrar páginas desejadas** — Ver páginas que estão vinculadas, mas ainda não existem
* **Bloquear uma página para edição** — Bloquear todas as edições em uma página enquanto você a finaliza
* **Alternar visibilidade** — Ocultar uma página dos alunos
* **Excluir páginas** — Remover páginas que não são mais necessárias
* **Monitorar contribuições** — Revisar estatísticas por usuário: editores mais ativos, páginas mais editadas, páginas mais visitadas
* **Exportar** — Exportar uma página wiki para PDF, ou enviá-la para a ferramenta Documentos

## Dicas

* **Use a wiki para projetos em grupo** — Atribua a cada grupo uma página wiki para construir colaborativamente seu entregável
* **Crie uma base de conhecimento do curso** — Construa uma wiki de referência com conceitos-chave e incentive os alunos a contribuir
* **Revise o histórico de edições** — O histórico de revisões permite avaliar as contribuições individuais no trabalho colaborativo
