# Chat

A ferramenta de chat oferece mensagens de texto em tempo real dentro de um curso. É útil para comunicação rápida, sessões de perguntas e respostas ao vivo ou discussões informais.

## Usando o Chat

1. Abra a ferramenta **Chat** na página inicial do curso
2. No painel **Users**, escolha um usuário online específico para enviar uma mensagem diretamente, ou use a aba **All** para se dirigir a todo o grupo
3. Digite sua mensagem no campo de texto na parte inferior e pressione **Enter** para enviar (**Shift+Enter** para uma nova linha sem enviar)

Uma opção **Preview** permite verificar a formatação antes de enviar, e **Reset** limpa o rascunho atual.

## Recursos do Chat

* **Mensagens em tempo real** — As mensagens aparecem instantaneamente para o(s) destinatário(s)
* **Histórico de mensagens** — Mensagens anteriores ficam visíveis ao entrar no chat
* **Presença de usuários** — O painel Users mostra quem está online no curso no momento
* **Direto ou em grupo** — Envie mensagem a um aprendiz por vez, ou transmita a todos pela aba **All**

## Como professor

Como professor do curso, você pode:

* **Monitorar discussões** — Revisar o histórico do chat para acompanhar o engajamento dos aprendizes
* **Encontrar arquivos do chat em Documents** — A ferramenta de chat espelha automaticamente as mensagens em arquivos HTML na ferramenta Documents, organizados por dia e por escopo (curso / sessão / grupo), de modo que a conversa persista além da sessão ao vivo

Se a configuração da plataforma "Restrict course chat to tutors" estiver habilitada pelo administrador, apenas tutores podem conversar com os aprendizes; caso contrário, todos os inscritos no curso podem participar.

## Dicas para usar o Chat de forma eficaz

* **Agende sessões de chat** — Informe os aprendizes com antecedência quando você estará disponível para chat ao vivo (use a ferramenta Agenda)
* **Defina regras básicas** — Estabeleça expectativas para uma comunicação respeitosa
* **Use para perguntas rápidas** — O chat funciona melhor para trocas curtas; use o Fórum para discussões mais longas e estruturadas

> Se a sua plataforma tiver videoconferência configurada (BigBlueButton ou Zoom), considere usá-la para sessões ao vivo em que voz e vídeo seriam mais eficazes. Consulte [Videoconferência](video-conferencing.md).
