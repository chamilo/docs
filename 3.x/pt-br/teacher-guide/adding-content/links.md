# Links

A ferramenta de links permite compartilhar URLs úteis com os seus alunos, organizadas por categoria.

## Adicionando um Link

1. Abra a ferramenta **Links** <img src="/.gitbook/assets/icons/mdi-link.svg" alt="Links" data-size="line"> na página inicial do curso
2. Clique em **Add a link** <img src="/.gitbook/assets/icons/mdi-link-plus.svg" alt="Adicionar link" data-size="line">
3. Preencha os detalhes:
   * **URL** — O endereço web (ex.: `https://example.com/resource`)
   * **Link name** — Um nome descritivo para o link
   * **Description** — Uma explicação opcional sobre o conteúdo do recurso
   * **Category** — Atribua o link a uma categoria para organização
   * **Target** — Onde o link é aberto: `_self` (mesma janela), `_blank` (nova aba), `_parent` ou `_top`
   * **Show link on course homepage** — Se você deseja exibi-lo como um ícone de ferramenta na página inicial do curso
4. Salve

## Organizando com Categorias

As categorias ajudam a agrupar links relacionados:

1. Clique em **Add a category**
2. Informe um **category name** e uma descrição opcional
3. Salve

Os links de uma categoria são exibidos juntos, o que facilita aos alunos encontrar os recursos relevantes.

## Gerenciando Links

* **Link checking** <img src="/.gitbook/assets/icons/mdi-check-circle.svg" alt="Validade" data-size="line">  — O Chamilo pode verificar se os links ainda estão ativos ou quebrados
* **Edit** <img src="/.gitbook/assets/icons/mdi-pencil.svg" alt="Editar" data-size="line"> — Atualize a URL, o título ou a descrição do link
* **Visibility** <img src="/.gitbook/assets/icons/mdi-eye.svg" alt="Visibilidade" data-size="line"> — Oculte ou mostre o link aos alunos
* **Delete** <img src="/.gitbook/assets/icons/mdi-delete.svg" alt="Excluir" data-size="line"> — Remova o link

## Exportando Links

Você pode exportar a sua coleção de links para PDF. Procure a opção **Export** na ferramenta de links.

## Dicas

* **Categorize by topic** — Crie uma categoria para cada módulo ou semana do seu curso
* **Add descriptions** — Ajude os alunos a entender por que um link é relevante antes de clicarem nele
* **Check regularly** — Links da web podem ficar desatualizados ou quebrados com o tempo
