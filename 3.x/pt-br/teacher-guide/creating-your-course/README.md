# Criando o Seu Curso

Esta seção explica como criar um novo curso no Chamilo e configurá-lo de acordo com as suas necessidades.

## Criando um Novo Curso

Para criar um curso:

1. Clique em **Meus cursos** na barra lateral
2. Clique no botão **Criar curso** (geralmente um livro verde <img src="../../.gitbook/assets/icons/mdi-book-open-page-variant.svg" alt="Cursos" data-size="line"> com um sinal de +)
3. Preencha o formulário de criação do curso:

![O formulário de criação de curso com campos para nome, categoria, código e idioma](../../.gitbook/assets/course-creation-form.png)

| Campo | Obrigatório | Descrição |
|-------|----------|-------------|
| **Nome do curso** | Sim | Um título curto e descritivo para o seu curso (por exemplo, "Gestão da Inovação") |
| **Categoria do curso** | Não | Selecione uma categoria para ajudar a organizar os cursos na plataforma |
| **Código do curso** | Não | Um código curto usando apenas letras e números (máximo de 40 caracteres). Se deixado em branco, um código é gerado automaticamente a partir do nome do curso |
| **Idioma** | Não | O idioma principal do curso. O padrão é o seu idioma atual |

Se estiver habilitado, você também pode encontrar uma configuração de **Sala padrão** e a possibilidade de usar um **Modelo de curso** para evitar criar o curso inteiramente do zero.

4. Clique em **Criar este curso**

Você será redirecionado para a página inicial do seu novo curso. Uma mensagem de confirmação será exibida: "Curso criado com sucesso."

## A Página Inicial do Curso

Depois que o curso é criado, você chega à sua página inicial. Este é o hub central do seu curso, onde você e os seus alunos acessam todas as ferramentas e o conteúdo.

![A grade de ferramentas da página inicial do curso mostrando as ferramentas disponíveis com ícones e interruptores de visibilidade](../../.gitbook/assets/course-homepage-tool-grid.png)

A página inicial exibe:

* **Título do curso** — O nome do seu curso, mostrado no topo.
* **Introdução do curso** — Uma descrição ou mensagem de boas-vindas opcional. Clique no botão **+ Introdução do curso** para adicionar uma, ou no botão **Editar introdução** <img src="../../.gitbook/assets/icons/mdi-pencil.svg" alt="Editar" data-size="line"> no topo para modificá-la. Isso admite texto rico com imagens, links e formatação.
* **Grade de ferramentas** — Uma grade de todas as ferramentas de curso disponíveis, cada uma mostrada como um cartão com um ícone e um nome.

### Gerenciando a Visibilidade das Ferramentas

Como professor, você pode controlar quais ferramentas os seus alunos podem ver:

* Clique no **ícone de olho** <img src="../../.gitbook/assets/icons/mdi-eye.svg" alt="Visível" data-size="line"> ao lado de qualquer ferramenta para ocultá-la dos alunos. Ferramentas ocultas mostram um **olho riscado** <img src="../../.gitbook/assets/icons/mdi-eye-off.svg" alt="Oculto" data-size="line"> e continuam acessíveis para você.
* Use os botões **Mostrar todas** e **Ocultar todas** para alterar todas as ferramentas de uma vez
* Clique em **Ordenar** para habilitar a reordenação da grade de ferramentas por arrastar e soltar

### Visão do Aluno

Clique no botão **Visão do aluno** para ver a página inicial do curso exatamente como um aluno a veria. Isso é útil para verificar se ferramentas ocultas e conteúdo não publicado não estão visíveis. Clique no botão novamente para voltar à visão do professor.
