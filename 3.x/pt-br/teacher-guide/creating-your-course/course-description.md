# Descrição do curso

A ferramenta **Descrição do curso** <img src="../../.gitbook/assets/icons/mdi-apple-safari.svg" alt="Descrição do curso" data-size="line"> permite redigir uma descrição estruturada, em várias seções, do seu curso — objetivos, metodologia, materiais e muito mais. Ao contrário do banner de texto livre **Introdução do curso** na [página inicial do curso](README.md#the-course-homepage), visível apenas aos alunos matriculados, a descrição do curso é o que os interessados veem *antes* de se matricular, no catálogo de cursos.

Depois de matriculados, os alunos ainda podem consultá-la de dentro do curso — se você deixar a ferramenta visível para eles, é um lugar conveniente para verificar informações práticas, como a estrutura geral do curso ou quem são os professores, sem precisar perguntar diretamente. Os alunos matriculados podem visualizar as seções que você escreveu, mas não podem adicioná-las, editá-las ou excluí-las.

## Acessando a ferramenta

Abra a ferramenta **Descrição do curso** <img src="../../.gitbook/assets/icons/mdi-apple-safari.svg" alt="Descrição do curso" data-size="line"> na grade de ferramentas da página inicial do curso.

## As oito seções

Uma descrição de curso é composta de até oito seções independentes. Cada uma é opcional — preencha apenas as relevantes para o seu curso:

| Seção | Pergunta orientadora |
|---------|-------------------|
| **Descrição** | Qual é o objetivo do curso? Há pré-requisitos? Como esta formação se relaciona com outros cursos? |
| **Objetivos** | Quais devem ser os resultados ao final, quando o aluno concluir o curso? Quais atividades são realizadas durante o curso? |
| **Tópicos** | Como o curso avança? Onde o aluno deve ter atenção especial? Há problemas identificáveis de compreensão em diferentes áreas? Quanto tempo se deve dedicar às diferentes áreas do curso? |
| **Metodologia** | Quais métodos e atividades ajudam a alcançar os objetivos do curso? Qual seria o cronograma? |
| **Material do curso** | Há um livro do curso, uma coletânea de artigos, uma bibliografia, uma lista de links na internet? |
| **Recursos** | Considere os cursos, tutores, um suporte técnico, professores e/ou materiais disponíveis. |
| **Avaliação** | Como os alunos serão avaliados? Há estratégias a desenvolver para dominar o tema? |
| **Outros** | Qualquer coisa que não se enquadre nas categorias acima. Você pode adicionar quantas seções **Outros** precisar, cada uma com seu próprio título personalizado. |

## Adicionando uma seção

1. Na barra de ferramentas da ferramenta, clique no ícone do tipo de seção que deseja redigir
2. O Chamilo exibe uma caixa de **Ajuda** com a pergunta orientadora daquela seção — use-a para decidir o que escrever
3. Escreva o conteúdo no editor de texto rico (suporta formatação, imagens, links, vídeo incorporado e outros conteúdos ricos). Se a plataforma tiver o recurso habilitado, você também pode escrever várias versões em idiomas da mesma seção e fazer com que cada aluno veja automaticamente apenas a sua — consulte [Conteúdo multilíngue](../adding-content/multi-language-content.md).
4. Salve

Cada seção que você adiciona aparece como um cartão próprio na ferramenta. Use os ícones **Editar** <img src="../../.gitbook/assets/icons/mdi-pencil.svg" alt="Editar" data-size="line"> e **Excluir** <img src="../../.gitbook/assets/icons/mdi-delete.svg" alt="Excluir" data-size="line"> em um cartão para atualizá-lo ou removê-lo depois.

## Ligação com o catálogo de cursos

Esta é a principal razão para preencher uma descrição de curso: ela alimenta diretamente o catálogo **Explorar mais cursos**, que visitantes e interessados navegam.

* Um curso **sem** seções de descrição preenchidas aparece como um cartão simples no catálogo.
* Um curso com **pelo menos uma** seção de descrição torna-se clicável — clicar na imagem, no título ou no botão de informações abre um popup detalhado listando todas as seções que você escreveu, na mesma ordem mostrada acima.

Isso dá aos interessados uma base real para decidir se devem se matricular, em vez de apenas um título e uma miniatura.

> A disponibilidade desse popup depende de uma configuração da plataforma. Se suas descrições não aparecerem para os interessados no catálogo, peça ao administrador que verifique a configuração **Show Course Descriptions** (`show_courses_descriptions_in_catalog`) em **Administração > Configurações > Catálogo de cursos**.

## Dicas

* **Priorize as seções Descrição e Objetivos** — são as que a maioria dos interessados lê primeiro ao decidir se deve se matricular.
* **Mantenha-a atualizada** — atualize a descrição do curso sempre que o conteúdo mudar de forma significativa, para que o catálogo reflita o que os alunos realmente receberão.
* **Use conteúdo rico com parcimônia** — imagens e formatação ajudam a leitura, mas um popup longo e sobrecarregado pode ser mais difícil de percorrer do que alguns parágrafos claros.
