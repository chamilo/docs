# Ferramentas adicionais

Além das ferramentas principais de conteúdo, avaliação e colaboração, o Chamilo oferece várias ferramentas adicionais que podem aprimorar o seu curso.

* **[Agenda](agenda.md)** — Agende eventos, prazos e lembretes para o seu curso
* **[Caderno](notebook.md)** — Uma ferramenta pessoal de anotações para os alunos
* **[Dropbox](dropbox.md)** — Uma ferramenta simples de troca de arquivos entre você e seus alunos
* **[Portfólio](portfolio.md)** — Permita que os alunos construam e apresentem um portfólio do seu trabalho
* **[Progresso do curso](course-progress.md)** — Defina seções temáticas e acompanhe a entrega do curso
