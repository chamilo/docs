# Caderno

O caderno é uma ferramenta pessoal de anotações para os alunos. Cada aluno possui o seu próprio caderno privado dentro do curso.

## Como funciona

O caderno é uma ferramenta simples na qual os alunos podem:

* **Criar anotações** — Escrever e salvar anotações pessoais relacionadas ao conteúdo do curso
* **Organizar anotações** — Revisar, editar e excluir suas anotações
* **Mantê-las privadas** — As anotações são visíveis apenas para o aluno que as criou

## Como professor

Como professor, você deve ter em mente que:

* O caderno é uma **ferramenta pessoal** — você não pode ver as anotações dos seus alunos
* É útil como **ferramenta de reflexão** — incentive os alunos a fazer anotações enquanto estudam
* As anotações são armazenadas no curso — elas não são compartilhadas entre cursos

## Ativando o Caderno

A ferramenta caderno aparece na página inicial do curso se estiver ativada. Se você não a vir, verifique se ela não está oculta (procure as ferramentas ocultas na página inicial do curso).
