# Dropbox

O dropbox é uma ferramenta de troca de arquivos que permite a você e aos seus alunos compartilhar arquivos uns com os outros dentro do curso.

> Para recolher trabalhos avaliados dos alunos, a ferramenta [Tarefas](../assessing-learners/assignments.md) costuma ser mais adequada, pois inclui recursos de avaliação e feedback. O dropbox é mais indicado para o compartilhamento informal de arquivos.

## Enviando um arquivo

1. Abra a ferramenta **Dropbox** na página inicial do curso
2. Clique em **Share a new file**
3. Selecione o arquivo a ser enviado
4. Escolha o(s) **destinatário(s)** — um ou mais usuários inscritos ou grupos do curso
5. Envie

## Recebendo arquivos

Quando alguém envia um arquivo para você, ele aparece na caixa de entrada do dropbox. Você pode:

* **Baixar** o arquivo
* **Adicionar um comentário** ao arquivo (depois de tê-lo recebido)
* **Mover** o arquivo para uma das suas categorias
* **Excluir** o arquivo da sua caixa de entrada

## Organizando arquivos

Tanto os arquivos enviados quanto os recebidos podem ser organizados em **categorias** (pastas) personalizadas. Use os controles de categoria na barra de ferramentas do dropbox para criar uma categoria e, em seguida, mover arquivos para ela. Se a configuração da plataforma "allow overwrite" estiver habilitada, reenviar um arquivo com o mesmo nome permite substituir a versão anterior.

Você também pode baixar em lote os arquivos selecionados como um ZIP.

## Como professor

* Você pode enviar arquivos para alunos individuais, grupos de alunos ou todos os usuários inscritos
* Você pode visualizar os arquivos enviados a você pelos alunos
* Esta ferramenta é útil para compartilhar materiais complementares, fornecer documentos de feedback individual ou receber envios informais
