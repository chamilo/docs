# Enviando uma Tarefa

A ferramenta **Tarefas** (às vezes chamada de "publicações de alunos" ou "trabalhos") é o local em que você entrega redações, projetos, relatórios ou qualquer outro trabalho baseado em arquivo ou em texto para que o professor avalie.

## Enviando o seu trabalho

Abra a ferramenta **Tarefas** <img src="../../.gitbook/assets/icons/mdi-inbox-full.svg" alt="Tarefas" data-size="line"> na página inicial do curso e, em seguida, abra a tarefa específica. Leia a descrição com atenção — ela contém as instruções do professor sobre o que enviar e como o trabalho será avaliado. Depois:

1. Clique em **Upload file** (ou no botão de envio)
2. Conforme a configuração definida pelo professor, selecione um arquivo no computador, redija o envio diretamente como texto, ou ambos
3. Adicione um comentário opcional para o professor
4. Envie

Após o envio, você verá a confirmação de que o trabalho foi recebido. Se o professor permitir, você poderá atualizar o envio mais tarde — caso contrário, o primeiro envio é definitivo, portanto verifique tudo com cuidado antes de enviar.

## Prazos

As tarefas podem ter duas datas diferentes:

* Um **prazo** — após essa data, o envio ainda é aceito, mas é marcado como atrasado para o professor
* Um **corte rígido** — após essa data, o envio deixa de ser possível

Se uma tarefa estiver visível na Agenda, essa data costuma ser o prazo — vale a pena conferir também ali se você não tiver certeza de quando algo vence.

## Recebendo a nota e o feedback

Quando o professor revisar o seu envio, você verá a **nota** e quaisquer **comentários de feedback** que ele tenha escrito. Alguns professores também anexam um **arquivo corrigido** — uma versão anotada do que você enviou — portanto, verifique se há um anexo para download junto com a nota. Se a tarefa estiver vinculada ao gradebook, a nota também conta para a nota geral do curso.

## Visualizando outros envios

Por padrão, o seu envio é visível apenas para você e para o professor. Alguns professores optam por tornar os envios visíveis para todo o curso — nesse caso, você poderá ver também o trabalho dos colegas (e eles, o seu).

## Dicas

* **Envie antes do prazo, não do corte rígido** — um envio atrasado continua registrado como atrasado mesmo que seja aceito.
* **Volte a conferir após a data de vencimento** para ver a nota e o feedback — a correção não é necessariamente instantânea.
* **Se você não conseguir enviar de forma alguma**, o corte rígido dessa tarefa provavelmente já passou — entre em contato com o professor se achar que isso é um erro.
