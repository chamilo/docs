# Rum

Blocket **Rum** på administrationspanelen hanterar de fysiska platser som Chamilo kan följa för utbildning på plats eller blandad utbildning: filialer (platser), rummen i dem och ett verktyg för att ta reda på vilka rum som är lediga vid en given tidpunkt.

![Blocket Rum på administrationspanelen, med Filialer, Rum och Sök rumstillgänglighet](/.gitbook/assets/admin-rooms-block.png)

Detta kapitel behandlar administrationen av filialer och rum. För lärarsidan — att tilldela ett rum till en kurssession — se [Filialer och rum](../../teacher-guide/branches-and-rooms.md) i Lärarguiden.

## Åtkomst till blocket Rum

Från administrationspanelen visas blocket **Rum** tillsammans med de övriga panelblocken. Klicka på någon av dess länkar för att öppna motsvarande verktyg.

## Vad som ingår i blocket

* **[Hantera rum](managing-rooms.md)** — Skapa och organisera filialer (platser) och rummen i varje filial
* **[Sök rumstillgänglighet](room-availability-finder.md)** — Kontrollera vilka rum som är lediga för ett visst datum och tidsintervall

## Anmärkning om multi-URL

I en installation med multi-URL (multi-tenant) är filialer och rum avgränsade till en enda åtkomst-URL vardera — de delas aldrig mellan portaler.
