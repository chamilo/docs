# Komma igång

Det här avsnittet presenterar administrationsgränssnittet i Chamilo 3.0 och hjälper dig att orientera dig.

## Vem är en administratör?

Chamilo har flera nivåer av administrativa roller:

| Roll | Åtkomst |
|------|--------|
| **Administratör** | Full åtkomst till alla administrationsfunktioner för plattformen. Kallas även **portaladministratör** |
| **Global administratör** | Samma som portaladministratör, med åtkomst över alla åtkomst-URL:er i en konfiguration med flera URL:er (flera hyresgäster) |
| **Sessionsadministratör** | Kan hantera sessioner, skriva in användare i sessioner och komma åt sessionsrelaterade inställningar |
| **Personalansvarig** | Kan visa lärandeframsteg och spårningsdata för tilldelade användare |
| **Frågeansvarig** | Mindre av en administratör än en innehållskurator; frågeansvariga har åtkomst till en global frågebank för att granska frågors kvalitet |

Den här guiden fokuserar främst på rollen **portaladministratör**, som har den bredaste åtkomsten.

## Logga in

Administratörer loggar in via samma inloggningssida som alla andra användare. Efter att du har angett dina uppgifter skickas du (om ingen annan konfiguration finns) till sidan **Administration**. En märkbar skillnad jämfört med andra användarroller är avsnittet **Administration** i sidofältet (inte synligt för andra roller).
