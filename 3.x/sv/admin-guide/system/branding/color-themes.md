# Färgteman

Chamilo 2.0 introducerar ett system för färgteman som låter dig anpassa plattformens visuella utseende.

## Hur teman fungerar

Färgteman definierar paletten som används i hela Chamilo-gränssnittet — primärfärger, accentfärger, bakgrunder och textfärger. Ett tema är kopplat till en åtkomst-URL: i en portal med en enda URL blir det i praktiken det globala temat, och i en konfiguration med flera URL:er kan varje URL ha sitt eget.

## Att tillämpa ett tema

![Sidan för färgteman som visar tillgängliga teman med förhandsvisningsrutor och en knappen Tillämpa](/.gitbook/assets/admin-color-themes.png)

1. Från administrationspanelen, gå till **Färgteman**
2. Bläddra bland de tillgängliga temana
3. Välj ett tema och klicka på **Tillämpa**
4. Temat tillämpas omedelbart på plattformen

## Teman per URL

I en konfiguration med flera URL:er kan varje åtkomst-URL ha sitt eget färgtema. Det gör att olika portaler kan ha distinkta visuella identiteter samtidigt som de delar samma Chamilo-installation.

## Tips

* **Matcha ditt varumärke** — Välj eller anpassa ett tema som matchar din organisations varumärkesfärger
* **Testa läsbarheten** — Efter att du har tillämpat ett tema, kontrollera att texten är läsbar mot bakgrundsfärgerna, särskilt i situationer med hög kontrast
* **Tänk på tillgänglighet** — Säkerställ tillräcklig färgkontrast för användare med nedsatt syn
