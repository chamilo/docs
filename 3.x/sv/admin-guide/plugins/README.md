# Tillägg

Tillägg utökar Chamilos funktionalitet utan att kärnkoden ändras. Chamilo 3.0 levereras med mer än 50 tillägg som kan aktiveras vid behov.

## Blocket Tillägg

Administrationspanelen har också ett eget **Tillägg**-block, skilt från den allmänna tilläggshanteringen i detta kapitel. Det listar inte varje installerat tillägg — endast de vars konfiguration anger att de ska visas i administrationsmenyn, vilket ger varje sådant tillägg en direkt genväg till dess egen administrationssida direkt på panelen.

![Blocket Tillägg på administrationspanelen, med genvägar till installerade tillägg som är konfigurerade att visas i administrationsmenyn](/.gitbook/assets/admin-plugins-block.png)

Om ett tillägg du har aktiverat inte visas här är det förväntat — det betyder att just det tillägget inte har deklarerat sig för administrationsmenyn, inte att något är fel. Se [Hantera tillägg](managing-plugins.md) för den fullständiga listan över installerade tillägg oavsett om de visas på panelen.
