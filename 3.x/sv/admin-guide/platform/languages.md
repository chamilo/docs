# Språk

Det här verktyget styr vilka gränssnittsspråk användare kan välja bland — det hanterar inte själva översättningssträngarna (de kommer från språkpaketen som medföljer Chamilo, inte från något som kan redigeras här).

## Åtkomst till Språk

Från administrationspanelen klickar du på **Plattform > Språk**.

## Vad du kan göra

* **Växla tillgänglighet** — Aktivera eller inaktivera vart och ett av de medföljande språken som val på inloggningssidan och i användarprofilinställningarna, med en enkel på/av-knapp per rad
* **Ange plattformens standardspråk** — Välj vilket språk som används när ingen användarpreferens gäller; det aktuella standardspråket är markerat med en egen ikon och kan inte döljas
* **Inaktivera alla utom standardspråket** — En enda massåtgärd för att begränsa språkvalaren till enbart plattformens standardspråk
* **Redigera det inhemska namnet** — Justera hur ett språks eget namn visas (dess "ursprungliga namn") i valaren

## Inaktivera ett språk som används

Om du inaktiverar ett språk som aktiva användare redan har valt som sitt gränssnittsspråk ber Chamilo om bekräftelse och — om du bekräftar — flyttar varje berörd användare till plattformens standardspråk. Det finns inget mellantillstånd där en användare lämnas med ett nu dolt språk valt.

## Höger-till-vänster-språk

Höger-till-vänster-språk (som arabiska, hebreiska eller persiska) växlar automatiskt gränssnittet till en höger-till-vänster-layout när de väljs — det finns inget att konfigurera här eller någon annanstans för att detta ska ske. RTL-stödet har förbättrats avsevärt i senare versioner.

## Underspråk

Om inställningen **Tillåt underspråk** är aktiverad visas ytterligare åtgärder för att skapa "underspråk" — partiella åsidosättningar av ett föräldraspråk, historiskt använda för regionala dialekter eller organisationsspecifika terminologijusteringar. Detta är en äldre funktion; de flesta installationer behöver den inte.
