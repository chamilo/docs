# Plattform

Blocket **Plattformshantering** på administrationspanelen samlar konfigurations- och kommunikationsverktyg för hela portalen — allt från den fullständiga inställningspanelen till språk, publika meddelanden, den globala kalendern och det CMS-liknande sidssystemet som bygger delar av portalens publika innehåll.

![Blocket Plattformshantering på administrationspanelen, med Configuration settings, Languages, Plugins, Regions, Portal news, Global agenda, Pages, Setting the registration page, Extra fields, Configure multiple access URL, Mail templates, External tools (LTI), Contact form categories och System templates](/.gitbook/assets/admin-platform-block.png)

## Åtkomst till plattformsblocket

Från administrationspanelen visas blocket **Plattformshantering** tillsammans med de övriga panelblocken. Klicka på någon av dess länkar för att öppna motsvarande verktyg.

## Vad som ingår i blocket

* **[Plattformsinställningar](../platform-settings/README.md)** — Den fullständiga konfigurationspanelen (portal, kurser, sessioner, användare, säkerhet med mera). Länken "Configuration settings" i detta block är helt enkelt ingången till det separata kapitlet.
* **[Språk](languages.md)** — Välj vilka gränssnittsspråk som ska vara tillgängliga för användare och ange plattformens standardspråk
* **[Portalnyheter](portal-news.md)** — Plattformsövergripande meddelanden (systemmeddelanden), schemalagda och riktade efter roll
* **[Global agenda](global-agenda.md)** — Plattformsövergripande kalenderhändelser, synliga för varje användare oavsett kurs eller session
* **[Sidor](pages.md)** — Det CMS-liknande verktyget bakom portalens startsida, sidfot och andra publika innehållsblock, inklusive introduktionstexten på registreringssidan
* **[Plattformsverktyg](platform-tools.md)** — Extrafält, e-postmallar, kategorier för kontaktformulär och några mindre, villkorligt visade objekt
* **Configure multiple access URL** — Behandlas i [Access URLs](../multi-url/access-urls.md), under Multi-URL
* **External tools (LTI)** — Behandlas i [LTI 1.3](../integrations/lti.md), under Integrations
