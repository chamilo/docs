# Kompetenshjul

Kompetenshjulet är ett zoomningsbart, hjulliknande diagram över hela kompetens­trädet — ett visuellt alternativ till att bläddra i den platta listan i [Hantera kompetenser](managing-skills.md).

## Öppna kompetenshjulet

Från administrationspanelen klickar du på **Kompetenser > Kompetenshjul**.

![Sidan Kompetenshjul, som visar sökfältet i sidopanelen, förklaringen och hela kompetens­trädet som ett segmenterat hjul](../../.gitbook/assets/admin-skills-wheel.png)

## Vad det visar

Varje segment i hjulet är en kompetens som kan expanderas till dess underordnade kompetenser. Ett segment visar om kompetensen har en kopplad betygsbok (se [Kompetenser och bedömningar](skills-assessments.md)) och, när en viss användare visas, om den användaren redan har uppnått den.

Klicka på ett segment för att zooma in och visa dess underordnade kompetenser; klicka på den centrala cirkeln för att zooma ut igen.

![Hjulet inzoomat på grenen "Idiomas", som visar dess språkliga underkompetenser](../../.gitbook/assets/admin-skills-wheel-zoom.png)

Högerklicka på ett segment för att öppna dess detaljer: beskrivning, överordnad kompetens och de kurser (om några) som ger den. Från den här dialogrutan kan administratörer också redigera kompetensen, skapa en underordnad kompetens under den eller lägga till den i profilsökningen som beskrivs nedan.

![Dialogrutan för kompetensdetaljer för "Conflict Management", som visar dess beskrivning och åtgärderna Redigera, Skapa underordnad kompetens och Lägg till kompetens i sökprofil](../../.gitbook/assets/admin-skills-wheel-detail.png)

Administratörer och användare med rollen Human Resources Manager får också en profilsökning här: kompetenser kan grupperas i "profiler" (uppsättningar kompetenser som förväntas för en given roll eller arbetsbeskrivning), och den här sidan låter dig söka efter användare vars förvärvade kompetenser matchar en given profil — användbart för att identifiera vem som är redo för en roll, eller var luckorna finns i ett team.
