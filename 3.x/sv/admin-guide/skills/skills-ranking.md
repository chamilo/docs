# Kompetensranking

Kompetensranking är en topplista över användare sorterade efter hur många kompetenser de har förvärvat.

## Åtkomst till kompetensranking

Från administrationspanelen klickar du på **Kompetenser > Kompetensranking**.

## Vad den visar

För varje aktiv användare visar rankingen:

* **Förvärvade kompetenser** — Totalt antal utfärdade kompetenser, som används för att sortera topplistan (högst först)
* **Lär sig för närvarande** — Antalet kompetenser som via betygsboken är kopplade till kurser som användaren för närvarande är inskriven i (direkt eller via en session)

Använd den här sidan för att snabbt identifiera era mest framstående elever, eller för att bedöma den övergripande aktiviteten kring kompetensförvärv på plattformen.
