# Integrationer

Chamilo integreras med flera tredjepartstjänster för att utöka funktionaliteten.

De flesta av dessa aktiveras via plugins. Se motsvarande avsnitt lite längre fram i den här guiden.

* **[Videokonferens](video-conferencing.md)** — BigBlueButton och Zoom
* **[LTI 1.3](lti.md)** — Anslut externa lärverktyg
* **[xAPI](xapi.md)** — Spårning av lärupplevelser
* **[OnlyOffice](onlyoffice.md)** — Kollaborativ dokumentredigering
* **[AI-konfiguration](ai-configuration.md)** — Konfigurera AI-leverantörer för AI-drivna funktioner
