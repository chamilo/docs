# Analys

Blocket **Analys** på administrationspanelen samlar plattformsövergripande statistik, lärandeanalys, företags-/HR-rapportering och verktyg för massexport. Beroende på din Chamilo-version kan detta block vara märkt **"Tracking"** på själva panelen — det är samma block oavsett. Den här guiden kallar det Analys genomgående för att undvika förväxling med [Tracking-inställningar](../platform-settings/tracking-settings.md), den separata inställningskategorin som styr vad som registreras snarare än rapporterna själva.

## Åtkomst till Analys

Från administrationspanelen visas blocket **Analys** tillsammans med de övriga panelblocken. Klicka på någon av dess länkar för att öppna motsvarande rapport.

## Vad som finns i blocket

* **[Global statistik](global-statistics.md)** — Plattformsövergripande statistik: kurser, användare, inloggningar, sessioner och diskutrymme
* **[Rapportkatalog](reports-catalog.md)** — Bläddra bland varje registrerad rapport, vem som kan komma åt den och varför
* **[Lärandeanalys](learning-analytics.md)** — Den klassiska tracking-panelen: nedborrning på användare, kurs och session med tidsåtgång och poängmedelvärden
* **[Företagsrapporter](corporate-reports.md)** — Kvartalsöversikter, lärares tidsspårning och HR-orienterad kurs-/användarrapportering
* **[Ärenden](tickets.md)** — Gå direkt till listan över supportärenden

## Vem som kan komma åt det

De flesta av dessa rapporter kräver åtkomst som **Portaladministratör**. Företagsrapporten är undantaget — den är även öppen för rollerna **Human Resources Manager** och **Student Boss**, eftersom den är byggd specifikt för den målgruppen.
