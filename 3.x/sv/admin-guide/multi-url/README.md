# Multi-URL

Chamilos multi-URL-funktion (även kallad multi-tenant) gör det möjligt att köra flera virtuella portaler från en enda Chamilo-installation. Varje portal har sin egen URL, varumärkesprofil, användare, kurser och inställningar, men de delar alla samma databas och kodbas.

* **[Åtkomst-URL:er](access-urls.md)** — Konfigurera och hantera flera åtkomst-URL:er
