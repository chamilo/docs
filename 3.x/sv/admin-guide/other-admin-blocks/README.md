# Övriga administratörsblock

Administrationspanelen har några ytterligare block som inte är konfigurerbara funktioner utan snarare informationswidgetar: en sida med utgående länkar, en versionskontrollregistrering och två små paneler som hämtar innehåll från chamilo.org. Detta kapitel förklarar vad var och en är, var innehållet kommer ifrån och — eftersom vissa av dem gör det — om någon data lämnar din plattform.

## Vad som täcks

* **[Länkar till Chamilo.org](chamilo-org-links.md)** — En bokmärkeslista till officiella Chamilo-resurser; skickar ingenting
* **[Versionskontroll](version-check.md)** — Valfri registrering som rapporterar din plattforms version och användning till chamilo.org, och talar om för dig om det är dags för en uppdatering
* **[Professionell support](professional-support.md)** — En skrivskyddad panel som beskriver officiella Chamilo-supportleverantörer
* **[Nyheter från Chamilo](news-from-chamilo.md)** — Ett skrivskyddat flöde av officiella meddelanden, inklusive säkerhetsuppdateringar och nya versioner

Varje sida nedan anger tydligt vad, om något, som skickas till chamilo.org, och varför.
