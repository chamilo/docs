# Chamilo.org-länkar

Blocket **Chamilo.org** är en statisk lista med utgående länkar till officiella Chamilo-resurser — inget mer. Det skickar ingen data någonstans; varje länk öppnar antingen en extern Chamilo-webbplats eller en lokal dokumentationssida som medföljer din installation.

## Vad som finns i blocket

| Länk | Destination |
|------|-------------|
| Chamilo startsida | `chamilo.org` |
| Användarguider | `docs.chamilo.org` |
| Chamilo-forum | GitHub Discussions för chamilo-lms |
| Installationsguide | Lokal, `/documentation/installation_guide.html` |
| Ändringar i senaste versionen | Lokal, `/documentation/changelog.html` |
| Lista över medverkande | Lokal, `/documentation/credits.html` |
| Säkerhetsguide | Lokal, `/documentation/security.html` |
| Optimeringsguide | Lokal, `/documentation/optimization.html` |
| Officiella tjänsteleverantörer för Chamilo | `chamilo.org/providers` |

De "lokala" länkarna pekar på dokumentationsfiler som medföljer din Chamilo-installation, så de läses in från din egen server, inte från chamilo.org.

## Syfte

Detta block finns enbart för bekvämlighet — snabb åtkomst till projektets officiella dokumentation, communityns diskussionsutrymme och listan över granskade tjänsteleverantörer, utan att behöva söka efter dem.
