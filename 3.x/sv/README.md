# Chamilo 3.0-dokumentation

Välkommen till den officiella dokumentationen för **Chamilo 3.0**, den öppna e-lärplattformen.

Denna dokumentation är indelad i fyra guider, var och en anpassad för en specifik målgrupp:

* [**Lärarguide**](teacher-guide/) — För instruktörer och utbildare: skapa kurser, lägg till innehåll, bedöm deltagare och följ upp framsteg.
* [**Administrationsguide**](admin-guide/) — För plattformsadministratörer: installera, konfigurera och hantera Chamilo-plattformen.
* [**Studentguide**](student-guide/) — För deltagare: gå med i kurser, följ lärstigar, gör tester och följ dina egna framsteg.
* [**Utvecklarguide**](developer-guide/) — För utvecklare: förstå arkitekturen, bygg plugins, använd API:et och bidra till projektet.

## Nyheter i Chamilo 3.0

Chamilo 3.0 är en större utgåva med fokus på AI-stödd undervisning, stärkt säkerhet och ett helt moderniserat plugin-ekosystem:

* **AI-drivna undervisningsverktyg** — En kurskvalitetsanalysator, en AI-handledare som svarar på frågor om plattformen, en Student Success Coach med rekommendationer per deltagare, AI-genererade kursillustrationer och snabba tester samt AI-assisterad bedömning
* **Model Context Protocol (MCP)-server** — Låter AI-klienter skapa och hantera kurser, tester, lärstigar, enkäter med mera direkt
* **Stärkt säkerhet** — Inbyggd File Integrity Monitoring samt dussintals åtkomstkontrollfixar i kurser, sessioner och API:et
* **Full modernisering av plugin-ekosystemet** — Varje plugin från 1.11.x återaktiverad, med ett omdesignat gränssnitt för pluginhantering
* **Hierarkiska URL:er och hantering av flera sajter** — En global panel för flera URL:er samt visuell geografisk karthantering för filialer och rum
* **Förbättrade lärstigar och övningar** — Progressiv adaptiv testning, OnlyOffice-redigering i körtid, adaptiv hotspot-avgränsning och utökat SCORM 2004-stöd
* **Betygsbok och certifikat** — Utgångsdatum för certifikat med påminnelser och anpassningsbara betygsättningslägen
* **Mobilredo REST API** — En moderniserad backend byggd för mobilappar och tredjepartsintegrationer
