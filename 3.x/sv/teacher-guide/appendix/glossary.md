# Ordlista

Nyckeltermer som används genomgående i den här guiden.

| Term | Definition |
|------|-----------|
| **Bedömning** | Se **Betygsbok** nedan |
| **Uppgift** | En uppgift där deltagare lämnar in filer eller text för granskning och bedömning av läraren. Kallas även "student publication" eller "work". |
| **Auto-launch** | En funktion som automatiskt öppnar ett visst verktyg när en deltagare går in i en kurs. |
| **Intyg** | Ett dokument som genereras automatiskt när en deltagare uppnår den minimipoäng som definierats i betygsboken. |
| **Kurs** | En behållare för lärinnehåll och verktyg. En kurs kan innehålla dokument, övningar, forum, lärstigar med mera. |
| **Kursmentor** | En lärarroll som är specifik för sessioner. En kursmentor hanterar en kurs inom en session. Kallades "course coach" i Chamilo-versioner före 3.0. |
| **Diskkvot** | Det maximala lagringsutrymme som tilldelas en kurs för uppladdade filer. |
| **Inskrivning** | Processen att registrera en användare i en kurs eller session och ge hen åtkomst till innehållet. Kallas även "subscription". |
| **Övning** | Ett quiz eller ett test som innehåller en eller flera frågor. Kallas i vissa sammanhang även "test". |
| **Forum** | Ett diskussionsverktyg med trådade samtal organiserade i kategorier och ämnen. |
| **Betygsbok** | Ett verktyg som sammanställer poäng från övningar, uppgifter och andra aktiviteter till ett enhetligt betyg för varje deltagare. |
| **Lärstig** | En strukturerad sekvens av läraktiviteter (dokument, övningar, länkar) som deltagare följer i en given ordning, valfritt med förkunskapskrav. |
| **LTI** | Learning Tools Interoperability — en standard som gör det möjligt att bädda in externa lärverktyg i Chamilo. |
| **SCORM** | Sharable Content Object Reference Model — en standard för e-lärandepaketerat innehåll. Chamilo kan importera och spela upp SCORM-paket i lärstigar. |
| **Session** | En tidsbegränsad utgåva av en eller flera kurser som tilldelas en specifik grupp deltagare. Sessioner gör det möjligt att återanvända samma kursinnehåll för olika kohorter. |
| **Sessionsmentor** | En övervakande roll som har uppsikt över alla kurser inom en session. Kallades "session coach" i Chamilo-versioner före 3.0. |
| **Färdighet** | En kompetens som kan kopplas till prestationer i betygsboken. När en deltagare erhåller ett intyg valideras tillhörande färdigheter. |
| **Enkät** | Ett frågeformulärsverktyg för att samla in återkoppling, med olika frågetyper och möjlighet till anonyma svar. |
| **Synlighet** | En inställning som styr om ett verktyg, dokument eller en aktivitet är synlig för deltagare. Lärare kan alltid se dolda objekt. |
