# Samarbete och kommunikation

Chamilo tillhandahåller flera verktyg för att möjliggöra interaktion mellan dig och dina deltagare, samt mellan deltagarna själva.

* **[Forum](forums.md)** — Trådade diskussioner organiserade efter kategori och ämne
* **[Chatt](chat.md)** — Textmeddelanden i realtid inom en kurs
* **[Grupper](groups.md)** — Dela in deltagare i arbetsgrupper med egna delade verktyg
* **[Wiki](wiki.md)** — Gemensam dokumentredigering
* **[Blogg](blog.md)** — Gemensam bloggning inom kursen
* **[Videokonferens](video-conferencing.md)** — Livesessioner med video via BigBlueButton eller Zoom

Dessa verktyg är tillgängliga från kursens startsida. Vissa kan vara dolda som standard — du kan göra dem synliga från verktygsrutnätet (se [Kursens startsida](../creating-your-course/course-homepage.md)).
