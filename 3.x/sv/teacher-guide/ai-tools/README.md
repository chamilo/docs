# AI-verktyg

Chamilo 3.0 introducerar AI-drivna verktyg som hjälper dig att skapa innehåll snabbare och ge personligt stöd till dina deltagare. Dessa funktioner använder stora språkmodeller (som OpenAI:s GPT, Google Gemini, Mistral eller andra) för att generera pedagogiskt innehåll och assistera vid bedömning.

> AI-verktyg måste konfigureras av din plattformsadministratör innan de blir tillgängliga. Se avsnittet [AI-konfiguration](../../admin-guide/integrations/ai-configuration.md) i administrationsguiden för installationsdetaljer.

## Tillgängliga AI-verktyg

* **[AI-tutor](ai-tutor.md)** — En AI-chattbot som deltagare kan interagera med för kursrelaterade frågor
* **[Övningsgenerator](exercise-generator.md)** — Generera automatiskt quizfrågor från ditt kursinnehåll eller en ämnesbeskrivning
* **[Generator för lärstigar](learning-path-generator.md)** — Skapa strukturerade lärsekvenser från ett ämne eller en uppsättning mål
* **[AI-bedömning](ai-grading.md)** — Få AI-assisterad utvärdering av öppna svar och studentinlämningar
* **[Generator för ordlistetermer](glossary-generator.md)** — Generera automatiskt termdefinitioner för din kursordlista
* **[AI-mediagenerering](ai-media-generation.md)** — Generera bilder och korta videor från rich-text-redigeraren när du skapar dokument
* **[Generator för kursbild](course-picture-generator.md)** — Generera en miniatyrbild för kursen direkt från skärmen för kursinställningar

## Så fungerar AI-verktyg

När AI-verktyg är aktiverade visas de i relevanta sammanhang:

* **Övningsgeneratorn** visas när du skapar eller redigerar övningar, och även som en snabbåtgärd på dokument i Dokument-verktyget
* **Generatorn för lärstigar** visas när du skapar lärstigar
* Alternativet **AI-bedömning** visas i arbetsflödet för rättning av uppgifter
* **AI-tutorn** är tillgänglig för deltagare i kursen
* **Generatorn för ordlistetermer** visas i verktygsfältet för Ordlista-verktyget
* Dialogen **AI-mediagenerering** visas i rich-text-redigeraren när du skapar eller redigerar dokument
* **Generatorn för kursbild** visas bredvid fältet för kursbild i Kursinställningar

Allt AI-genererat innehåll presenteras som ett **förslag** som du kan granska, redigera och ändra innan publicering. Du har alltid sista ordet om vad dina deltagare ser.
