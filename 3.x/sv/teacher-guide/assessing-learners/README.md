# Bedömning av deltagare

Chamilo tillhandahåller en omfattande uppsättning verktyg för att utvärdera deltagarnas kunskaper och följa deras prestationer.

* **[Prenumeration av användare](subscribing-users.md)** — Få in deltagare i din kurs från början: administratörsinskrivning, självinskrivning, manuell inskrivning eller e-postinbjudningar
* **[Övningar](exercises.md)** — Skapa quiz och tester med en mängd olika frågetyper, automatisk rättning och detaljerad återkoppling
* **[Uppgifter](assignments.md)** — Samla in hemuppgifter och projekt från deltagare, med stöd för filuppladdningar, kamratgranskning och manuell eller AI-assisterad rättning
* **[Enkäter](surveys.md)** — Samla in återkoppling från deltagare via anpassningsbara frågeformulär
* **[Närvaro](attendance.md)** — Följ deltagarnas närvaro vid lektionstillfällen
* **[Betygsbok](gradebook.md)** — Kombinera poäng från övningar, uppgifter och andra aktiviteter till ett samlat betyg och utfärda certifikat

Verktyget **Rapportering** finns fortfarande kvar men har flyttats till toppen av kurssidan för läraren, som en liten diagramikon. Detta är den centrala platsen för att komma åt information om framsteg för hela kursen och dess studenter.

Dessa verktyg samverkar: poäng från övningar och betyg från uppgifter kan matas in i Betygsboken, som kan kopplas till certifikatgenerering och validering av färdigheter.
