# Närvaro

Närvaroverktyget låter dig följa upp elevers närvaro vid schemalagda lektionstillfällen, oavsett om de är på plats eller online.

## Skapa ett närvaroprotokoll

1. Öppna verktyget **Närvaro** från kurssidan
2. Klicka på **Lägg till närvaro** för att skapa ett närvaroprotokoll
3. Ange en **Titel** för närvaroprotokollet (t.ex. "Vecka 1 - Introduktion")
4. Ange en **Beskrivning** (denna är mestadels för ditt eget bruk – eleverna ser inte beskrivningen)
5. Spara

### Avancerade inställningar

1. **Kräv unik närvaro** gör att du kan räkna en elev som helt närvarande om han/hon deltog även vid endast ett datum i närvaroprotokollet
2. **Betygsboksalternativ** låter dig välja att bedöma närvaroprotokollet i bedömningsverktyget (betygsboken).

## Lägga till datum

Varje närvaroprotokoll innehåller ett eller flera datum (tillfällen) där du registrerar närvaro:

1. Öppna ett närvaroprotokoll eller fortsätt med skapandeprocessen
2. Klicka på **Lägg till ett datum** <img src="/.gitbook/assets/icons/mdi-calendar-plus.svg" alt="Lägg till datum" data-size="line">
3. Välj datum och tid
4. Markera valfritt **Upprepa datum** för att välja en upprepningslogik
5. Ange en **Varaktighet** i minuter för tillfället (standard är 60 minuter)
6. Välj valfritt en **Grupp** om detta närvarodatum endast gäller en grupp elever
7. Spara

Du kan lägga till flera datum i samma närvaroprotokoll (t.ex. alla tillfällen under en månad).

## Registrera närvaro

För varje datum markerar du varje elev som:

* **Närvarande** — Eleven deltog (standardvärde för alla elever)
* **Frånvarande** — Eleven deltog inte

Klicka på statuscellen bredvid varje elevs namn för att växla mellan närvarande och frånvarande.

Som standard markeras alla elever som närvarande, eftersom vi utgår från att det oftast är fler närvarande än frånvarande.

Obs: Administratörer kan ändra portalens konfiguration så att du kan välja mer utökade närvarotyper (försenad, frånvarande med giltig frånvaro, etc.), som bättre kan spegla era rutiner. I så fall växlar ett klick i närvarofältet mellan alla närvarotyper.

## Visa närvarorapporter

![Närvaroprotokollet som visar en sammanfattningstabell med elever, datum och närvaroindikatorer](/.gitbook/assets/attendance-sheet.png)

Närvaroverktyget visar:

* En sammanfattningstabell med alla elever och alla datum
* Varje elevs närvaroprocent (närvarande tillfällen / totalt antal tillfällen)
* Färgkodade indikatorer för enkel överblick

## Extra

Närvaro har några utökade funktioner som inte syns direkt:
* **Signaturer** kan aktiveras så att elever kan signera sin närvaro i klassrummet via en surfplatta som läraren hanterar
* **Kommentarer** kan läggas till av läraren för varje elevs närvaro
* **PDF-rapporter** kan exporteras för att uppfylla regelverk

## Tips

* **Koppla till kursframsteg** — Använd närvarodata tillsammans med verktyget Kursframsteg för att korrelera närvaro med täckning av ämnen
* **Exportera data** — Exportera närvaroprotokollet för administrativa register
* **Sätt förväntningar** — Om närvaro är obligatorisk, kommunicera policyn tydligt i din kursintroduktion eller i meddelanden
