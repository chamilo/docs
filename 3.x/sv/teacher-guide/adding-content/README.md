# Lägga till innehåll

Det här avsnittet beskriver de verktyg du använder för att lägga till lärinnehåll i din kurs. Chamilo erbjuder flera sätt att leverera material till dina deltagare:

* **[Dokument](documents.md)** — Ladda upp filer, skapa webbsidor och organisera ditt innehållsbibliotek
* **[Länkar](links.md)** — Dela URL:er till externa resurser, organiserade efter kategori
* **[Inlärningsvägar](learning-paths.md)** — Bygg strukturerade innehållssekvenser med förkunskapskrav och uppföljning av framsteg
* **[Ordlista](glossary.md)** — Definiera nyckeltermer som deltagarna kan referera till under hela kursen
* **[Meddelanden](announcements.md)** — Skicka meddelanden och uppdateringar till dina registrerade deltagare
* **[Flerspråkigt innehåll](multi-language-content.md)** — Skriv flera språkversioner av samma innehåll och låt varje deltagare endast se sin egen

Varje verktyg nås från verktygsrutnätet på kursens startsida. Klicka på verktygets ikon för att öppna det.
