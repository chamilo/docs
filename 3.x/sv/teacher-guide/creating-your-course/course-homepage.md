# Kurssida

Kurssidan är den första sidan som dina deltagare ser när de går in i en kurs. Den här sidan beskriver hur du anpassar den för att skapa en engagerande ingångspunkt.

## Kursintroduktion

Kursintroduktionen är ett område med rich text som visas högst upp på startsidan, ovanför verktygsrutnätet. Använd den för att:

* Välkomna dina deltagare
* Beskriva kursens mål
* Ge instruktioner för att komma igång
* Bädda in bilder, videor eller länkar

Så här redigerar du introduktionen:

1. Klicka på knappen **Redigera introduktion** <img src="/.gitbook/assets/icons/mdi-pencil.svg" alt="Redigera" data-size="line">
2. Använd rich text-redigeraren för att skriva ditt innehåll
3. Spara dina ändringar

Om ingen introduktion har skapats ännu visas en knapp för att **Skapa en introduktion**.

Dessutom har verktygen **Uppföljning** och **Underhåll** flyttats till toppen av sidan under statistik- och kugghjulsikonerna för att ta bort verktyg som aldrig visas för deltagarna från listan.

## Organisera verktyg

### Ändra ordning

1. Klicka på knappen **Sortera** högst upp i verktygsrutnätet
2. Dra och släpp verktyg för att ändra deras ordning
3. Den nya ordningen sparas automatiskt

### Dölja och visa

* Klicka på **synlighetsikonen** på ett verktyg för att växla mellan synligt och dolt för deltagare
* Använd **Visa alla** eller **Dölj alla** för massändringar
* Dolda verktyg förblir tillgängliga för dig som lärare — de är bara dolda för deltagarna

![Kurssidan som den ser ut för en student, där dolda verktyg inte syns](/.gitbook/assets/course-homepage-student-view.png)

## Funktioner för automatisk start

Du kan konfigurera vissa verktyg så att de startas automatiskt när en deltagare går in i kursen. Om det är aktiverat visas en avisering högst upp på kurssidan som anger vilken automatisk start som är aktiv:

* Automatisk start av dokument — Öppnar ett visst dokument automatiskt
* Automatisk start av övning — Startar ett test omedelbart
* Automatisk start av inlärningsväg — Startar en inlärningsväg vid kursinträde
* Automatisk start av forum — Öppnar forumet direkt
