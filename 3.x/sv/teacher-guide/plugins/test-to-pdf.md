# Test till PDF

Test till PDF <img src="../../.gitbook/assets/icons/mdi-file-pdf-box.svg" alt="Test till PDF" data-size="line"> exporterar ett kurstests frågor till en utskrivbar PDF — endast frågor, endast svar, eller båda tillsammans — användbart för en pappersversion av ett test.

## Åtkomst till verktyget

När det är aktiverat visas ett verktyg **Test till PDF** på din kursstartsida, som listar varje test i kursen (eller sessionen). Varje rad erbjuder tre åtgärder: **Ladda ner frågor**, **Ladda ner svar** och **Ladda ner allt**.

## Tips

* **Inte alla frågetyper stöds** — Endast en delmängd av Chamilos frågetyper (flerval, sant/falskt och liknande slutna format) exporteras rent; öppna eller mer komplexa frågetyper kanske inte visas korrekt, om de alls visas
* **Kontrollera utdata innan du skriver ut en hel sats** — Granska den genererade PDF-filen för ett test innan massutskrift inför en tentamenssession
