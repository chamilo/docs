# Positionering

Positionering <img src="../../.gitbook/assets/icons/mdi-radar.svg" alt="Positionering" data-size="line"> lägger till ett arbetsflöde för självbedömning före/efter: välj ett test som **inledande test** och ett annat som **avslutande test** (ofta en kopia av samma test), och Chamilo visar varje deltagares poängförändring mellan de två på ett radardiagram.

## Åtkomst till verktyget

När det är aktiverat visas ett **Positionering**-verktyg på kursens startsida. Det listar kursens behöriga tester med knapparna **Välj som inledande test** / **Välj som avslutande test**, en genväg till varje tests resultat och radardiagrammet som jämför genomsnittliga inledande och avslutande poäng.

## Vilka tester som är behöriga

Endast tester som uppfyller alla tre av dessa kriterier visas som valbara:

* Minst 3 frågekategorier
* Testets resultatsidestyp är inställd på **radar**
* Exakt ett försök är tillåtet

Om ett test som du förväntar dig att se saknas i listan, kontrollera först dessa tre inställningar på det testet.

## Genomdrivande av ordningen

Din administratör kan dessutom konfigurera, plattformsövergripande:

* **Blockera andra kursverktyg** tills deltagaren har slutfört det inledande testet
* Ett **Upplåsningströskelvärde för avslutande test** — en minsta genomsnittlig slutförandeprocent för lärstig som krävs innan det avslutande testet låses upp

## Tips

* **Ställ in radartypen för resultat tidigt** — Eftersom behörighet beror på testinställningar som görs när du skapar testet, planera för Positionering innan du färdigställer testets kategorier och resultatsidestyp, inte efteråt
* **Använd en äkta kopia för det avslutande testet** — Att jämföra ett test mot sig själv säger inte mycket; det avslutande testet bör täcka samma kategorier så att radardiagrammet blir meningsfullt
