# Utvärdering av frågealternativ

Utvärdering av frågealternativ <img src="/.gitbook/assets/icons/mdi-calculator-variant.svg" alt="Utvärdering av frågealternativ" data-size="line"> låter dig tillämpa en formel för negativ poängsättning (straffpoäng) på ett tests poängberäkning, i stället för Chamilos standardbeteende att bara summera korrekta svar.

## Ange en formel

När funktionen är aktiverad visas en extra ikon bredvid varje test i kursens lista i verktyget **Tester**. Om du klickar på den öppnas ett litet formulär där du väljer ett av följande:

* **Ingen formel** — Chamilos vanliga poängsättning (standard)
* **Räkna om frågepoäng** — Omfördelar vikterna för alternativen utan straffpoäng
* **Rätt − Fel**
* **Rätt − Fel / 2**
* **Rätt − Fel / 3**

Den valda formeln gäller endast för det specifika testet.

> Den här inställningen ändrar inte själva vikterna för frågor eller svar — den ändrar hur slutpoängen beräknas. Om tillägget är inaktiverat, eller om ingen formel är vald, återgår Chamilo till sin ursprungliga poängsättning.

## Tips

* **Testa först på en kopia** — Att byta formel kan ändra de poäng som studenterna får på testet; prova på ett duplicerat test innan du tillämpar det på ett aktivt test
* **Förklara ändringen för studenterna** — En straffformel kan överraska om deltagarna är vana vid enkel poängsättning för korrekta svar; nämn det i dina instruktioner
