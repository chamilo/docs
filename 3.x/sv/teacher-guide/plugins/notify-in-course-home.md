# Meddela på kurssidan

Meddela på kurssidan <img src="../../.gitbook/assets/icons/mdi-bell-ring-outline.svg" alt="Meddela på kurssidan" data-size="line"> låter dig visa ett popup-meddelande för alla som besöker din kurssida — användbart för ett tillkännagivande, ett meddelande om obligatorisk läsning eller en grind av typen "klicka här för att fortsätta".

## Ställa in en avisering

När funktionen är aktiverad får kursens **Inställningar** <img src="../../.gitbook/assets/icons/mdi-cog.svg" alt="Inställningar" data-size="line"> en knapp **Ange en avisering på startsidan**. Den öppnar ett formulär där du skriver meddelandet (rich text) och valfritt anger en **Utgångslänk**.

* **Med en utgångslänk** — Popup-fönstret visar en knapp som pekar på den länken och fortsätter att visas tills en deltagare klickar på den
* **Utan en** — Meddelandet visas för varje besökare, varje gång de öppnar kurssidan

Använd **Ta bort avisering på kurssidan** för att ta bort den.

## Tips

* **Endast ett meddelande per kurs** — Om du skapar ett nytt ersätts det som fanns tidigare; det går inte att köa flera
* **Förhandsgranska formateringen** — Meddelandet visas som rå HTML i ett popup-fönster, så kontrollera att rich text återges som du förväntar dig innan du publicerar det
* **Använd utgångslänken för allt som är tidskänsligt** — Utan den fortsätter samma meddelande att dyka upp i oändlighet, vilket kan bli repetitivt för återkommande deltagare
