# Juridiskt avtal för kurs

Tillägget Juridiskt avtal för kurs <img src="../../.gitbook/assets/icons/mdi-file-check-outline.svg" alt="Juridiskt avtal för kurs" data-size="line"> kräver att studenter godkänner villkor/ett juridiskt meddelande innan de kan komma åt din kurs — användbart för samtyckesformulär, användningspolicyer eller vilket meddelande som helst som du behöver att deltagare formellt godkänner.

## Aktivera det för din kurs

Att aktivera tillägget för hela plattformen gör ingenting i sig — du måste fortfarande slå på det för varje kurs där du vill använda det:

1. Öppna kursens **Inställningar** <img src="../../.gitbook/assets/icons/mdi-cog.svg" alt="Inställningar" data-size="line">
2. I avsnittet för kursåtkomst, kryssa i **Aktivera juridiska villkor**

Detta lägger till verktyget **Juridiskt avtal för kurs** i din kurs.

## Skriva avtalet

Öppna verktyget **Juridiskt avtal för kurs** för att:

* Skriva meddelandetexten (rich text-redigerare)
* Valfritt bifoga en nedladdningsbar fil
* Välja vad som händer vid sparande: **Skicka inte avisering**, **Avisera alla användare via e-post** eller **Avisera alla användare via e-post och skicka dem bilagan**

## Granska godkännanden

Verktygets **Användarlista** visar varje student och om de har godkänt avtalet (via webben eller via e-post), med åtgärder för att skicka om avtalslänken eller ta bort en användares registrerade godkännande.

## Tips

* **Sätt kursen till Privat** — Detta tillägg är avsett att styra åtkomst; synlighet som Offentlig eller Öppen motverkar den avsikten
* **Uppdatera medvetet** — Att ändra avtalstexten ogiltigförklarar inte automatiskt tidigare godkännanden; använd **Ta bort alla tidigare användaravtal** om du behöver att alla godkänner den nya versionen
* **Håll meddelandet kort** — En lång juridisk text är mer sannolik att ögnas igenom än att läsas; länka till ett fullständigt policydokument om du har ett
