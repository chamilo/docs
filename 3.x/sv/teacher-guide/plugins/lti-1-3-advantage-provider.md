# LTI 1.3 Advantage Provider

LTI 1.3 Advantage Provider <img src="../../.gitbook/assets/icons/mdi-swap-horizontal.svg" alt="LTI 1.3 Advantage Provider" data-size="line"> fungerar tvärtom jämfört med [IMS/LTI Client](ims-lti.md): i stället för att Chamilo startar ett externt verktyg låter det ett **externt LMS** (till exempel en annan Chamilo-portal, eller en annan plattform som Moodle) starta en av dina övningar eller lärstigar som om det vore ett verktyg inuti det andra systemet, med betyg som skickas tillbaka till Chamilo.

## Vad det här betyder för dig

Det finns inget att konfigurera här som lärare. Din administratör registrerar vilka av dina övningar eller lärstigar som kan startas på detta sätt, och av vilka externa plattformar, helt från **Administration > LTI 1.3 Advantage Provider**.

Om din plattform använder detta tillägg innebär det helt enkelt att vissa av dina studenter kan nå en av dina övningar eller lärstigar genom att klicka på en länk från ett annat system, i stället för att logga in i Chamilo direkt — själva upplevelsen av att genomföra övningen eller lärstigen förändras inte.

## Tips

* **Fråga din administratör om du är nyfiken** — Om du vill veta om något av ditt innehåll exponeras på detta sätt kan din administratör tala om för dig vilka aktiviteter som är registrerade
