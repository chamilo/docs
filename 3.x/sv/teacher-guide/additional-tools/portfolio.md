# Portfolio

Verktyget Portfolio låter deltagare samla och visa upp sitt arbete under kursens gång. Det fungerar som en digital portfolio där deltagare kan sammanställa sitt bästa arbete, reflektioner och prestationer.

## Så fungerar portföljer

Varje deltagare har en personlig portfolio i kursen där de kan:

* **Lägga till objekt** — Skriva textinlägg med den rika textredigeraren och bifoga en eller flera filer till varje objekt
* **Organisera innehåll** — Märka objekt så att de kan filtreras efter ämne
* **Dela selektivt** — Ställa in synligheten för varje objekt: dold, synlig för kursen, dold utom för läraren, eller delad med utvalda användare när avancerad delning är aktiverad

## Som lärare

Du kan använda portföljer för:

* **Reflekterande lärande** — Be deltagare att föra en portfolio med reflektioner över sin läranderesa
* **Kompetensvisning** — Låt deltagare samla evidens för färdigheter och kunskaper
* **Bedömning** — Granska portföljinnehåll som en del av din utvärdering

För att visa en deltagares portfolio öppnar du portföljverktyget och filtrerar objektlistan efter användare.

Om kursen är konfigurerad för det kan du poängsätta portföljobjekt och enskilda kommentarer — dessa poäng kan sedan föras in i betygsboken. Du kan också **markera** objekt som du vill uppmärksamma, och märka objekt eller kommentarer som **mallar** så att du (eller deltagare) kan återanvända dem som utgångspunkt för nya inlägg. Portföljer kan exporteras som **PDF** eller **ZIP**.

## Tips

* **Definiera förväntningar** — Berätta för deltagarna vilka typer av objekt som ska ingå och hur de ska organisera sin portfolio
* **Granska regelbundet** — Kontrollera portföljer periodiskt i stället för bara i slutet av kursen
* **Kombinera med färdigheter** — Använd portföljer tillsammans med systemet för färdigheter/intyg för att skapa en heltäckande kompetensdokumentation
