# Anteckningsbok

Anteckningsboken är ett personligt verktyg för anteckningar för deltagare. Varje deltagare har sin egen privata anteckningsbok i kursen.

## Så fungerar det

Anteckningsboken är ett enkelt verktyg där deltagare kan:

* **Skapa anteckningar** — Skriva och spara personliga anteckningar relaterade till kursinnehållet
* **Organisera anteckningar** — Granska, redigera och ta bort sina anteckningar
* **Hålla dem privata** — Anteckningar är endast synliga för den deltagare som skapade dem

## Som lärare

Som lärare bör du vara medveten om att:

* Anteckningsboken är ett **personligt verktyg** — du kan inte se dina deltagares anteckningar
* Den är användbar som ett **reflektionsverktyg** — uppmuntra deltagare att föra anteckningar medan de studerar
* Anteckningar lagras i kursen — de delas inte mellan kurser

## Aktivera anteckningsboken

Verktyget Anteckningsbok visas på kursens startsida om det är aktiverat. Om du inte ser det, kontrollera att det inte är dolt (leta efter dolda verktyg på kursens startsida).
