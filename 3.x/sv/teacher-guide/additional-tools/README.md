# Ytterligare verktyg

Utöver de grundläggande verktygen för innehåll, bedömning och samarbete erbjuder Chamilo flera ytterligare verktyg som kan förstärka din kurs.

* **[Agenda](agenda.md)** — Schemalägg händelser, deadlines och påminnelser för din kurs
* **[Notebook](notebook.md)** — Ett personligt anteckningsverktyg för deltagare
* **[Dropbox](dropbox.md)** — Ett enkelt verktyg för filutbyte mellan dig och dina deltagare
* **[Portfolio](portfolio.md)** — Låt deltagare bygga och visa upp en portfolio av sitt arbete
* **[Course Progress](course-progress.md)** — Definiera tematiska avsnitt och följ upp kursens genomförande
