# Din profil

Din profil i Chamilo innehåller din personliga information och dina inställningar. Andra användare på plattformen kan se delar av din profil beroende på dina synlighetsinställningar.

## Öppna din profil

Klicka på din **avatar** i det övre högra hörnet av den övre listen och välj sedan **Profil** i rullgardinsmenyn. Du kan också öppna den från avsnittet **Socialt nätverk** i sidofältet.

![Användarens avatarrullgardinsmeny som visar profil, kontoinställningar och utloggningsalternativ](../../.gitbook/assets/user-avatar-dropdown.png)

## Profilinformation

Din profilsida kan visa (beroende på konfiguration):

* **Avatar** — Din profilbild. Klicka på **Redigera profil** för att ändra den.
* **Fullständigt namn** — Ditt för- och efternamn som det är registrerat på plattformen.
* **E-post** — Din e-postadress. Andra användare kan klicka på den för att skicka ett meddelande till dig i Chamilo.
* **Språk** — Ditt föredragna språk.
* **Ytterligare fält** — Beroende på plattformens konfiguration kan du se fält som telefonnummer, Skype-namn, länk till LinkedIn-profil eller anpassade fält som definierats av din administratör.

## Redigera din profil

För att uppdatera din profilinformation klickar du på **Redigera profil**. Här kan du:

* Ändra namn, e-post och lösenord
* Ladda upp eller byta avatar/bild
* Uppdatera ditt föredragna språk
* Fylla i ytterligare profilfält (Skype, LinkedIn osv.)
* Konfigurera aviseringsinställningar

För att byta lösenord klickar du på **Byt lösenord**. Av säkerhetsskäl måste du ange ditt nuvarande lösenord och ditt nya lösenord två gånger.

Om din administratör har aktiverat alternativet **tvåfaktorsautentisering** (`2fa_enable`) för plattformen kan du i din profil slå på 2FA för ditt eget konto med en TOTP-autentiseringsapp (Google Authenticator, Authy, 1Password osv.). När det är aktiverat kommer inloggningsflödet att begära den tidsbaserade 6-siffriga koden utöver ditt lösenord.

## Personuppgifter

Under **Socialt nätverk** > **Personuppgifter** kan du granska all information som Chamilo lagrar om dig. Det här avsnittet innehåller:

* En sammanfattning av all insamlad data, organiserad efter kategori
* Om det är aktiverat av din organisation, din acceptansstatus för plattformens **Villkor**
* Om det är aktiverat av din organisation, ett alternativ att **återkalla ditt samtycke** eller **radera konto**, vilket utlöser en begäran om kontoradering som din administratör behandlar

> Den här funktionen tillhandahålls för att uppfylla dataskyddsregler. Kontakta din administratör om du har frågor om hur dina uppgifter hanteras.
