# Komma igång

Det här avsnittet hjälper dig att orientera dig i Chamilo 3.0. Du lär dig hur du loggar in, navigerar i huvudgränssnittet och konfigurerar din profil.

## Logga in

För att komma åt Chamilo öppnar du webbläsaren och går till den URL som din institution har angett (till exempel `https://chamilo.yourschool.edu`). Ange ditt användarnamn och lösenord på inloggningssidan och klicka på **Logga in**.

Om din institution använder extern autentisering (till exempel Azure, Keycloak eller ett universitets system för enkel inloggning) kan du se ytterligare inloggningsknappar under det vanliga inloggningsformuläret. Klicka på lämplig knapp för att autentisera via institutionens identitetsleverantör.

> Om du har glömt ditt lösenord klickar du på länken **Glömt lösenordet?** på inloggningssidan. Du får ett e-postmeddelande med instruktioner för att återställa det.

## Första intrycket

Efter inloggning ser du Chamilo-startsida. Gränssnittet är indelat i tre huvudområden:

![Chamilo-startsida som visar systemmeddelanden och kurskort](/.gitbook/assets/home-page-teacher.png)

* **Övre fältet** — Visar plattformens logotyp, din meddelandeinkorg (med en badge som visar olästa meddelanden) och din användaravatar. Klicka på din avatar för att komma åt din profil och kontoinställningar.
* **Sidofältet** — Den vänstra navigeringspanelen ger snabb åtkomst till dina kurser, sessioner, agenda, sociala nätverk med mera. Du kan fälla ihop den genom att klicka på växlingen vid kanten.
* **Huvudinnehållsområdet** — Här visas innehållet på den aktuella sidan. På startsidan ser du systemmeddelanden och dina utvalda kurser.

## Dina kurser

Klicka på **Mina kurser** i sidofältet för att se alla kurser du är inskriven i som lärare eller student. Varje kurs visas som ett kort med:

![Sidan Mina kurser som visar kurskort med miniatyrbilder och snabbåtgärder](/.gitbook/assets/my-courses-list.png)

* Kursens bild eller miniatyr
* Kurstiteln
* Snabbåtgärder

Om din institution använder **sessioner** (tidsbegränsade utbildningsperioder) ser du även en länk **Mina sessioner** i sidofältet, organiserad i aktuella, tidigare och kommande sessioner.

Sessioner i Chamilo är ett sätt att leverera samma kurs till olika grupper av deltagare vid olika tidpunkter, utan att duplicera kursinnehållet. Tänk på en session som en schemalagd utgåva eller kohort av en kurs. Mer om det ämnet senare.
