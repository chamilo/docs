# Hitta rätt i en kurs

När du öppnar en kurs ser du dess startsida med ett rutnät av verktygsikoner. Den här sidan förklarar vad varje verktyg betyder för dig som deltagare, och länkar till var den underliggande funktionen beskrivs mer i detalj.

Endast verktyg som din lärare har gjort synliga för deltagare visas i ditt rutnät — din lärare kan se ytterligare, dolda verktyg som inte visas för dig. Om ett verktyg du förväntar dig saknas kan det helt enkelt vara dolt, eller inaktiverat för hela kursen; fråga din lärare.

## Verktyg du inte ser — och ett som inte fungerar

Några poster finns bara för lärare och kursadministratörer så att de kan konfigurera själva kursen — kursinställningar, kursunderhåll (säkerhetskopiering/import/export), redigeraren för kursens startsida och (på de flesta plattformar) Blogg-verktyget ligger i en meny "Fler åtgärder" som bara visas för personer med redigeringsrättigheter på kursen. Som deltagare ser du inte den här menyn alls.

Rutan **Rapportering** är ett specialfall: den visas i ditt rutnät, men den öppnar spårningsvyn för hela klassen som är avsedd för lärare, så om du klickar på den får du ett meddelande om nekad åtkomst i stället för något användbart:

![Om du klickar på rutan Rapportering som deltagare visas ett meddelande om nekad åtkomst](../../.gitbook/assets/student-course-reporting-denied.png)

Oroa dig inte — din egen utveckling finns tillgänglig på andra ställen: från **Min utveckling** i det huvudsakliga sidofältet (se [Förstå gränssnittet](../getting-started/understanding-the-interface.md) och [Min utveckling](../my-progress.md)), och från verktygen **Kursutveckling** och **Bedömningar** ovan, som båda visar dina egna data.

Om din kurs har AI-funktioner aktiverade kan du också märka att en lärares alternativ "AI-analysator" (används för att förträna AI-handledaren på kursens eget innehåll) skiljer sig från den **AI-handledare**-chatt som deltagare ser — se [AI-handledare-chatbot](ai-tutor.md).

## Tips

* **Saknas ett verktyg?** Fråga din lärare — det är mest troligt dolt eller inaktiverat snarare än trasigt.
* **Kursbeskrivning och meddelanden** kan stängas av helt av din lärare; i så fall visas de inte för någon, inte ens för läraren.
* **Allt här kan variera mellan kurser** — din lärare avgör vilka verktyg som är aktiva och synliga för varje kurs individuellt.
