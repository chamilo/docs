# CAPTCHA

CAPTCHA är en enkel utmaning — vanligtvis att skriva de bokstäver som visas i en förvrängd bild — som används för att bekräfta att det är en verklig person, inte automatiserad programvara, som fyller i ett formulär. Om din administratör har aktiverat det kan du stöta på det på formulären för **inloggning**, **registrering** och **glömt lösenord**.

## Vad det skyddar

CAPTCHA finns för att stoppa automatiserade skript från att missbruka dessa formulär:

* På **inloggningsformuläret** saktar det ner "lösenordshammring" — ett skript som snabbt gissar lösenord för att ta sig in på ett konto.
* På **registreringsformuläret** förhindrar det att robotar masskapar falska konton.
* På formuläret för **glömt lösenord** förhindrar det automatiserat missbruk av e-postsystemet för lösenordsåterställning.

Kort sagt finns det för att skydda ditt konto — och dina personuppgifter bakom det — mot automatiserade attacker, inte för att försvåra livet för verkliga användare.

## Vad du kommer att se

En liten bild med förvrängda bokstäver, med:

* En ledtråd om att du kan klicka på bilden för att ladda en ny om du inte kan läsa den.
* Ett textfält under den, märkt för att du ska ange de bokstäver du ser.

Om din inmatning inte stämmer kommer du att uppmanas att försöka igen med en ny bild.

## Upprepade misstag

Din administratör kan konfigurera en gräns för hur många CAPTCHA-misstag som tillåts innan ett konto tillfälligt låses, och för hur länge. Om du blir utelåst efter flera misslyckade försök, vänta tills låsningsperioden har passerat, eller kontakta din administratör om du behöver åtkomst tidigare.

## Om du inte ser det

CAPTCHA är valfritt och gäller för hela plattformen — om din administratör inte har aktiverat det kommer du helt enkelt inte att stöta på det någonstans, ens på plattformar som i övrigt liknar din.
