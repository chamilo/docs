# Mitt studieutdrag

Om din plattform har aktiverat akademiska studieutdrag kan du visa en förteckning över dina avslutade, certifierade kurser och ladda ner ett inofficiellt studieutdrag. Din institution kan också utfärda signerade officiella studieutdrag.

## Öppna ditt studieutdrag

1. Logga in och öppna **Mitt studieutdrag** från den övre navigeringen (när det här alternativet är tillgängligt).
2. Eller besök `/transcript` på din Chamilo-portal medan du är inloggad.
3. Granska dina avslutade kurser, kurskoder, betyg, datum, timmar, slutbetyg och GPA.
4. Välj **Ladda ner inofficiellt studieutdrag** för att spara en PDF av den aktuella förteckningen.

Förteckningen byggs upp av giltiga certifikat som genereras av rotbedömningen (betygsboken) för kurser och sessioner där du fortfarande är registrerad. En kurs kan saknas om den inte har producerat ett kvalificerande certifikat. Om inga kurser kvalificerar sig visar Chamilo **Ingen avslutad kurs ännu.**

Bokstavsbetygen och betygsmedelvärdet beror på din institutions konfigurerade betygsskala. GPA beräknas som ett oviktat medelvärde av betygspoängen för de listade kurserna, om inte din administratör ändrar hur de underliggande kurserna och betygen registreras.

## Officiella studieutdrag

Under **Officiella studieutdrag** kan du hitta signerade versioner som utfärdats åt dig av behörig personal, när sådana finns. Varje version registrerar utfärdandedatum och utfärdare. Använd **Ladda ner** för dess PDF och **Verifiera** för att kontrollera den digitala signaturen på dess verifieringssida.

En officiell version är en ögonblicksbild av din förteckning när den utfärdades. Den uppdateras **inte** automatiskt när senare betyg eller kurser ändras; din institution kan utfärda en nyare version. Behörig personal kan återkalla en äldre version, och dess offentliga verifieringssida visar då återkallelsen.

Du kan inte själv utfärda eller återkalla officiella studieutdrag. Fråga din institution om du behöver ett nytt eller korrigerat signerat studieutdrag. Dela offentliga verifieringslänkar med omdöme: någon med länken kan kunna se uppgifter om ett giltigt signerat studieutdrag.

Om **Mitt studieutdrag** saknas kanske den här funktionen inte är aktiverad på din portal. För administrativ konfiguration, se [Akademiska studieutdrag](../../admin-guide/users/academic-transcripts.md).
