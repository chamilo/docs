# Konto och säkerhet

Ditt Chamilo-konto ger åtkomst till dina kurser, dina betyg och dina personuppgifter — det är värt att hålla det säkert. Det här avsnittet tar upp de kontoskyddsfunktioner du kan stöta på som deltagare.

* **[Återställa ditt lösenord](resetting-your-password.md)** — Vad du ska göra om du glömt ditt lösenord eller vill byta det
* **[Tvåfaktorsautentisering](two-factor-authentication.md)** — Lägg till ett extra skyddslager för ditt konto, om administratören har aktiverat det
* **[CAPTCHA](captcha.md)** — Varför du kan bli ombedd att bevisa att du är en människa på inloggnings-, registrerings- eller glömt-lösenord-formulären

Alla funktioner som beskrivs här är inte nödvändigtvis aktiva på din plattform — administratörer kan slå på eller av var och en av dem. Om något som beskrivs i det här avsnittet inte visas för dig har det troligen inte aktiverats.
