# Ordlista

Nyckeltermer som används i den här guiden.

| Term | Definition |
|------|-----------|
| **Assessment** | Se **Gradebook** nedan |
| **Assignment** | En uppgift där du lämnar in filer eller text som din lärare ska granska och betygsätta. Kallas även "student publication" eller "work". |
| **CAPTCHA** | En utmaning (vanligtvis att skriva förvrängda bokstäver från en bild) som används för att bekräfta att du är en verklig person, visas på vissa inloggnings-, registrerings- och glömt-lösenord-formulär. |
| **Catalog** | Den publika förteckningen över kurser (och sessioner) som du kan bläddra i och, i vissa fall, självregistrera dig till. Nås via **Explore more courses**. |
| **Certificate** | Ett dokument som genereras automatiskt när du uppnår minimipoängen som definierats i en kurs gradebook. |
| **Course** | En behållare för lärandeinnehåll och verktyg. En kurs kan innehålla dokument, övningar, forum, lärstigar med mera. |
| **Enrollment** | Att vara registrerad i en kurs eller session, vilket ger dig åtkomst till dess innehåll. Kallas även "subscription". |
| **Exercise** | Ett quiz eller ett test som innehåller en eller flera frågor. Kallas även "test" i vissa sammanhang. |
| **Forum** | Ett diskussionsverktyg med trådade samtal organiserade i kategorier och ämnen. |
| **Gradebook** | Ett verktyg som sammanställer dina poäng från övningar, uppgifter och andra aktiviteter till ett enhetligt betyg. |
| **Invitation** | En engångslänk som skickas av en lärare till din e-postadress, så att du kan registrera dig och automatiskt bli prenumererad på en kurs, även om den allmänna registreringen är stängd. |
| **Learning path** | En strukturerad sekvens av lärandeaktiviteter (dokument, övningar, länkar) som du följer i en definierad ordning, ibland med förkunskapskrav. |
| **Self-registration** | Möjligheten att skapa ett eget konto via ett publikt registreringsformulär, om det är aktiverat av plattformsadministratören. |
| **Session** | En tidsbunden utgåva av en eller flera kurser som tilldelas en specifik grupp av lärande, till exempel en termin eller en kohort. |
| **Skill** | En kompetens kopplad till prestationer i gradebook. Att erhålla ett certifikat kan validera tillhörande skills. |
| **Two-factor authentication (2FA)** | Ett extra inloggningssteg med en tidsbaserad kod från en autentiseringsapp, utöver ditt lösenord. |
| **Visibility** | En inställning som styr om ett verktyg, dokument eller en aktivitet visas för lärande. Lärare kan alltid se dolda objekt. |
