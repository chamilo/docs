# Komma igång

Det här avsnittet hjälper dig att orientera dig i Chamilo 3.0 som deltagare. Du lär dig hur du skapar ett konto (om det behövs), loggar in och hittar runt i huvudgränssnittet.

## Logga in

För att komma åt Chamilo öppnar du webbläsaren och går till den URL som din institution har angett (till exempel `https://chamilo.yourschool.edu`). Ange ditt användarnamn och lösenord på inloggningssidan och klicka på **Logga in**.

Om din institution använder extern autentisering (till exempel Azure, Keycloak eller ett universitets system för enkel inloggning) kan du se extra inloggningsknappar under det vanliga inloggningsformuläret. Klicka på rätt knapp för att autentisera via institutionens identitetsleverantör.

Om du inte har ett konto ännu, se [Skapa ett konto](creating-an-account.md).

> Om du har glömt ditt lösenord klickar du på länken **Glömt ditt lösenord?** på inloggningssidan. Se [Återställa ditt lösenord](../account-and-security/resetting-your-password.md) för hela processen.

## Första intrycket

Efter inloggning ser du Chamilo-startsida, indelad i tre huvudområden: ett övre fält, ett sidofält och ett huvudinnehållsområde. Dessa beskrivs i detalj i [Förstå gränssnittet](understanding-the-interface.md).

Från sidofältet klickar du på **Mina kurser** för att se alla kurser du är registrerad på. Varje kurs visas som ett kort med bild, titel och snabba åtgärder.

Om din institution använder **sessioner** (tidsbegränsade utbildningsperioder) ser du även en länk **Mina sessioner** i sidofältet, indelad i aktuella, tidigare och kommande sessioner. En session är en schemalagd omgång eller kohort av en eller flera kurser — samma kursinnehåll som ges till en specifik grupp deltagare under en specifik period.
