# API

Chamilo 3.0 exponerar ett REST-API byggt på **API Platform 4**. API:et ger programmatisk åtkomst till plattformens resurser och är samma API som används av Vue-frontend.

* **[Autentisering](authentication.md)** — JWT-tokenbaserad autentisering
* **[Referens för slutpunkter](endpoints-reference.md)** — Översikt över tillgängliga API-resurser
* **[Anpassade åtgärder](custom-actions.md)** — Specialiserade slutpunkter utöver standard-CRUD
* **[Webhooks](webhooks.md)** — Händelsestyrda aviseringar till externa system
