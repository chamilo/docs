# Multi-URL

De multi-URL-functie van Chamilo (ook wel multi-tenant genoemd) stelt u in staat om meerdere virtuele portalen vanuit één Chamilo-installatie te draaien. Elk portaal heeft een eigen URL, huisstijl, gebruikers, cursussen en instellingen, maar ze delen allemaal dezelfde database en codebase.

* **[Toegangs-URL's](access-urls.md)** — Meerdere toegangs-URL's configureren en beheren
