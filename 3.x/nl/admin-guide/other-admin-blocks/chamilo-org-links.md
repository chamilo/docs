# Chamilo.org-koppelingen

Het blok **Chamilo.org** is een statische lijst van uitgaande koppelingen naar officiële Chamilo-bronnen — niets meer. Het verstuurt nergens gegevens; elke koppeling opent een externe Chamilo-site of een lokale documentatiepagina die bij uw installatie is meegeleverd.

## Wat zit er in het blok

| Koppeling | Bestemming |
|------|-------------|
| Chamilo-startpagina | `chamilo.org` |
| Gebruikershandleidingen | `docs.chamilo.org` |
| Chamilo-forum | GitHub Discussions voor chamilo-lms |
| Installatiehandleiding | Lokaal, `/documentation/installation_guide.html` |
| Wijzigingen in de laatste versie | Lokaal, `/documentation/changelog.html` |
| Lijst van bijdragers | Lokaal, `/documentation/credits.html` |
| Beveiligingshandleiding | Lokaal, `/documentation/security.html` |
| Optimalisatiehandleiding | Lokaal, `/documentation/optimization.html` |
| Officiële Chamilo-dienstverleners | `chamilo.org/providers` |

De "lokale" koppelingen wijzen naar documentatiebestanden die bij uw Chamilo-installatie zelf horen, zodat ze vanaf uw eigen server worden geladen, niet vanaf chamilo.org.

## Doel

Dit blok bestaat puur voor het gemak — snelle toegang tot de officiële documentatie van het project, de communitydiscussieruimte en de lijst van goedgekeurde dienstverleners, zonder dat u ernaar hoeft te zoeken.
