# Integraties

Chamilo integreert met verschillende diensten van derden om de functionaliteit uit te breiden.

De meeste hiervan worden ingeschakeld via plugins. Raadpleeg het betreffende hoofdstuk iets verderop in deze gids.

* **[Videoconferentie](video-conferencing.md)** — BigBlueButton en Zoom
* **[LTI 1.3](lti.md)** — Externe leermiddelen koppelen
* **[xAPI](xapi.md)** — Tracking van leerervaringen
* **[OnlyOffice](onlyoffice.md)** — Collaboratief documenten bewerken
* **[AI-configuratie](ai-configuration.md)** — AI-providers instellen voor AI-gestuurde functies
