# Verklarende woordenlijst

Belangrijke termen die in deze gids worden gebruikt.

| Term | Definitie |
|------|-----------|
| **Assessment** | Zie **Gradebook** hieronder |
| **Assignment** | Een taak waarbij cursisten bestanden of tekst indienen ter beoordeling en cijfergeving door de docent. Ook bekend als "student publication" of "work". |
| **Auto-launch** | Een functie die automatisch een specifiek hulpmiddel opent wanneer een cursist een cursus binnenkomt. |
| **Certificate** | Een document dat automatisch wordt gegenereerd wanneer een cursist de minimale score behaalt die in het gradebook is vastgelegd. |
| **Course** | Een container voor leerinhoud en hulpmiddelen. Een cursus kan documenten, oefeningen, forums, leerpaden en meer bevatten. |
| **Course tutor** | Een docentenrol die specifiek is voor sessies. Een course tutor beheert één cursus binnen een sessie. In Chamilo-versies vóór 3.0 aangeduid als "course coach". |
| **Disk quota** | De maximale opslagruimte die aan een cursus is toegewezen voor geüploade bestanden. |
| **Enrollment** | Het proces waarbij een gebruiker wordt ingeschreven in een cursus of sessie, waardoor toegang tot de inhoud wordt verleend. Ook bekend als "subscription". |
| **Exercise** | Een quiz of toets met een of meer vragen. In sommige contexten ook aangeduid als "test". |
| **Forum** | Een discussiehulpmiddel met hiërarchische gesprekken, georganiseerd in categorieën en onderwerpen. |
| **Gradebook** | Een hulpmiddel dat scores van oefeningen, opdrachten en andere activiteiten samenvoegt tot één cijfer per cursist. |
| **Learning path** | Een gestructureerde reeks leeractiviteiten (documenten, oefeningen, links) die cursisten in een vastgelegde volgorde volgen, optioneel met vereisten. |
| **LTI** | Learning Tools Interoperability — een standaard waarmee externe leerhulpmiddelen in Chamilo kunnen worden ingebed. |
| **SCORM** | Sharable Content Object Reference Model — een standaard voor e-learninginhoudspakketten. Chamilo kan SCORM-pakketten importeren en afspelen binnen leerpaden. |
| **Session** | Een in de tijd begrensde editie van een of meer cursussen, toegewezen aan een specifieke groep cursisten. Sessies maken het mogelijk dezelfde cursusinhoud te hergebruiken voor verschillende cohorten. |
| **Session tutor** | Een toezichthoudende rol die alle cursussen binnen een sessie overziet. In Chamilo-versies vóór 3.0 aangeduid als "session coach". |
| **Skill** | Een competentie die kan worden gekoppeld aan prestaties in het gradebook. Wanneer een cursist een certificaat behaalt, worden de bijbehorende skills gevalideerd. |
| **Survey** | Een vragenlijsthulpmiddel voor het verzamelen van feedback, met verschillende vraagtypen en opties voor anonieme antwoorden. |
| **Visibility** | Een instelling die bepaalt of een hulpmiddel, document of activiteit zichtbaar is voor cursisten. Docenten kunnen verborgen items altijd zien. |
