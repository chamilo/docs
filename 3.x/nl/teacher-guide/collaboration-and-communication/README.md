# Samenwerking en communicatie

Chamilo biedt verschillende tools om interactie mogelijk te maken tussen u en uw cursisten, en tussen cursisten onderling.

* **[Forums](forums.md)** — Discussies in threads, georganiseerd per categorie en onderwerp
* **[Chat](chat.md)** — Realtime tekstberichten binnen een cursus
* **[Groepen](groups.md)** — Verdeel cursisten in werkgroepen met hun eigen gedeelde tools
* **[Wiki](wiki.md)** — Gezamenlijk documenten bewerken
* **[Blog](blog.md)** — Gedeeld bloggen binnen de cursus
* **[Videoconferentie](video-conferencing.md)** — Live videosessies met BigBlueButton of Zoom

Deze tools zijn beschikbaar vanaf de cursushomepage. Sommige kunnen standaard verborgen zijn — u kunt ze zichtbaar maken via het toolraster (zie [Cursushomepage](../creating-your-course/course-homepage.md)).
