# Inhoud toevoegen

Dit gedeelte behandelt de tools waarmee u leerinhoud aan uw cursus toevoegt. Chamilo biedt verschillende manieren om materiaal aan uw cursisten te leveren:

* **[Documenten](documents.md)** — Bestanden uploaden, webpagina's maken en uw inhoudsbibliotheek organiseren
* **[Links](links.md)** — URL's naar externe bronnen delen, georganiseerd per categorie
* **[Leerpaden](learning-paths.md)** — Gestructureerde reeksen inhoud opbouwen met vereisten en voortgangsregistratie
* **[Woordenlijst](glossary.md)** — Kernbegrippen definiëren waar cursisten gedurende de cursus naar kunnen verwijzen
* **[Aankondigingen](announcements.md)** — Berichten en updates versturen naar uw ingeschreven cursisten
* **[Meertalige inhoud](multi-language-content.md)** — Meerdere taalversies van dezelfde inhoud schrijven en elke cursist alleen de eigen versie laten zien

Elke tool is toegankelijk via het toolraster op de startpagina van de cursus. Klik op het pictogram van de tool om deze te openen.
