# Extra tools

Naast de kerntools voor inhoud, beoordeling en samenwerking biedt Chamilo verschillende extra tools die uw cursus kunnen verrijken.

* **[Agenda](agenda.md)** — Plan evenementen, deadlines en herinneringen voor uw cursus
* **[Notebook](notebook.md)** — Een persoonlijke notitietool voor cursisten
* **[Dropbox](dropbox.md)** — Een eenvoudige tool voor bestandsuitwisseling tussen u en uw cursisten
* **[Portfolio](portfolio.md)** — Laat cursisten een portfolio van hun werk opbouwen en presenteren
* **[Course Progress](course-progress.md)** — Definieer thematische secties en volg de voortgang van de cursuslevering
