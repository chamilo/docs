# API

Chamilo 3.0 stelt een REST API beschikbaar die is gebouwd op **API Platform 4**. De API biedt programmatische toegang tot platformresources en is dezelfde API die door de Vue-frontend wordt gebruikt.

* **[Authenticatie](authentication.md)** — Authenticatie op basis van JWT-tokens
* **[Referentie van endpoints](endpoints-reference.md)** — Overzicht van beschikbare API-resources
* **[Aangepaste acties](custom-actions.md)** — Gespecialiseerde endpoints buiten standaard CRUD
* **[Inschrijving van sessieleerlingen](session-students.md)** — Specifieke sessieleerlingen toevoegen/verwijderen met beheerdersrechten
* **[Klasinschrijvingen](class-subscriptions.md)** — Klaslidmaatschap en gekoppelde sessies/cursussen lezen/vervangen
* **[Cursusbeheer](course-administration.md)** — Cursusmetadata bijwerken en cursussen verwijderen als beheerder
* **[Webhooks](webhooks.md)** — Gebeurtenisgestuurde meldingen naar externe systemen
