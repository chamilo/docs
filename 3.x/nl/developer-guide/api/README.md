# API

Chamilo 3.0 biedt een REST API die is gebouwd op **API Platform 4**. De API geeft programmatische toegang tot platformbronnen en is dezelfde API die door de Vue-frontend wordt gebruikt.

* **[Authenticatie](authentication.md)** — JWT-tokengebaseerde authenticatie
* **[Endpointsreferentie](endpoints-reference.md)** — Overzicht van beschikbare API-bronnen
* **[Aangepaste acties](custom-actions.md)** — Gespecialiseerde endpoints naast standaard CRUD
* **[Webhooks](webhooks.md)** — Gebeurtenisgestuurde meldingen naar externe systemen
