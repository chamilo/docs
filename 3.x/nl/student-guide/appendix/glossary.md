# Verklarende woordenlijst

Belangrijke termen die in deze gids worden gebruikt.

| Term | Definitie |
|------|-----------|
| **Assessment** | Zie **Gradebook** hieronder |
| **Assignment** | Een taak waarbij u bestanden of tekst indient zodat uw docent ze kan beoordelen en cijferen. Ook bekend als "student publication" of "work". |
| **CAPTCHA** | Een uitdaging (meestal het overtypen van vervormde letters uit een afbeelding) om te bevestigen dat u een echt persoon bent, weergegeven op sommige inlog-, registratie- en wachtwoordvergeten-formulieren. |
| **Catalog** | De openbare lijst van cursussen (en sessies) die u kunt doorbladeren en waarin u zich in sommige gevallen zelf kunt inschrijven. Bereikbaar via **Explore more courses**. |
| **Certificate** | Een document dat automatisch wordt gegenereerd wanneer u de minimale score behaalt die in het gradebook van een cursus is vastgelegd. |
| **Course** | Een container voor leermateriaal en tools. Een cursus kan documenten, oefeningen, forums, leerpaden en meer bevatten. |
| **Enrollment** | Ingeschreven zijn in een cursus of sessie, waardoor u toegang krijgt tot de inhoud. Ook bekend als "subscription". |
| **Exercise** | Een quiz of toets met een of meer vragen. In sommige contexten ook aangeduid als "test". |
| **Forum** | Een discussietool met gesprekken in threads, georganiseerd in categorieën en onderwerpen. |
| **Gradebook** | Een tool die uw scores van oefeningen, opdrachten en andere activiteiten samenvoegt tot één cijfer. |
| **Invitation** | Een eenmalige link die een docent naar uw e-mailadres stuurt, zodat u zich kunt registreren en automatisch wordt ingeschreven voor een cursus, zelfs als algemene registratie gesloten is. |
| **Learning path** | Een gestructureerde reeks leeractiviteiten (documenten, oefeningen, links) die u in een vastgestelde volgorde volgt, soms met vereisten. |
| **Self-registration** | De mogelijkheid om via een openbaar registratieformulier zelf een account aan te maken, indien dit door de platformbeheerder is ingeschakeld. |
| **Session** | Een in de tijd begrensde editie van een of meer cursussen, toegewezen aan een specifieke groep lerenden, zoals een semester of cohort. |
| **Skill** | Een competentie die gekoppeld is aan prestaties in het gradebook. Het behalen van een certificaat kan bijbehorende skills valideren. |
| **Two-factor authentication (2FA)** | Een extra aanmeldingsstap met een tijdgebonden code uit een authenticator-app, naast uw wachtwoord. |
| **Visibility** | Een instelling die bepaalt of een tool, document of activiteit voor lerenden zichtbaar is. Docenten kunnen verborgen items altijd zien. |
