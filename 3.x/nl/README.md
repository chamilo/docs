# Chamilo 3.0-documentatie

Welkom bij de officiële documentatie van **Chamilo 3.0**, het open-source e-learningplatform.

Deze documentatie is onderverdeeld in drie handleidingen, elk afgestemd op een specifiek publiek:

* [**Handleiding voor docenten**](teacher-guide/) — Voor docenten en trainers: cursussen aanmaken, inhoud toevoegen, lerenden beoordelen en voortgang volgen.
* [**Handleiding voor beheer**](admin-guide/) — Voor platformbeheerders: het Chamilo-platform installeren, configureren en beheren.
* [**Handleiding voor ontwikkelaars**](developer-guide/) — Voor ontwikkelaars: de architectuur begrijpen, plugins bouwen, de API gebruiken en bijdragen aan het project.

## Wat is nieuw in Chamilo 3.0

Chamilo 3.0 is een grote release met een volledig herontworpen interface en veel nieuwe functies:

* **Moderne interface** — Gebouwd met Vue 3 en PrimeVue voor een snellere, meer responsieve ervaring
* **AI-gestuurde tools** — Genereer oefeningen, leerpaden en krijg AI-ondersteunde beoordeling
* **REST API** — Volledige REST API op basis van API Platform met JWT-authenticatie
* **Nieuwe authenticatieopties** — OAuth2 (Azure, Keycloak, Facebook), SCIM-gebruikersvoorziening
* **LTI 1.3** — Koppel externe leermiddelen naadloos
* **Cloudopslag** — Native ondersteuning voor Azure Blob, AWS S3 en Google Cloud Storage
* **Kleurthema's** — Aanpasbare platformhuisstijl met themaondersteuning
* **OnlyOffice-integratie** — Bewerk documenten gezamenlijk binnen het platform
