# Kurssit

Kun sinulla on tili, seuraava vaihe on päästä kurssille ja opetella liikkumaan siellä.

* **[Kurssille ilmoittautuminen](subscribing-to-a-course.md)** — Eri tavat, joilla voit päätyä ilmoittautuneeksi kurssille
* **[Kurssilla liikkuminen](course-tools-overview.md)** — Mitä kukin kurssin etusivun työkalu merkitsee sinulle oppijana
* **[Oppimispolun seuraaminen](following-a-learning-path.md)** — Eteneminen ohjatussa toimintosarjassa
* **[Testien tekeminen](taking-tests.md)** — Mitä odottaa, kun opettajasi antaa tentin tai kokeen
* **[Tehtävän palauttaminen](submitting-an-assignment.md)** — Tiedostojen tai tekstin palauttaminen arvioitavaksi
* **[Foorumin käyttäminen](using-the-forum.md)** — Viestien lähettäminen ja niihin vastaaminen ketjutetuissa kurssikeskusteluissa
* **[Chat-työkalun käyttäminen](using-the-chat-tool.md)** — Reaaliaikainen viestintä kurssilla
* **[AI-tutor-chatbot](ai-tutor.md)** — Avun saaminen tekoälyavustajalta, jos alustallasi se on otettu käyttöön

Nämä sivut olettavat, että sinulla on jo Chamilo-tili. Jos sinulla ei ole, katso [Tilin luominen](../getting-started/creating-an-account.md).
