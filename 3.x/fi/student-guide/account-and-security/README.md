# Tili ja tietoturva

Chamilo-tilisi antaa pääsyn kursseihisi, arvosanoihisi ja henkilötietoihisi — sen suojaaminen kannattaa. Tässä osiossa käsitellään tilin suojausominaisuuksia, joihin voit oppijana törmätä.

* **[Salasanan palauttaminen](resetting-your-password.md)** — Mitä tehdä, jos unohdat salasanasi tai haluat vaihtaa sen
* **[Kaksivaiheinen tunnistautuminen](two-factor-authentication.md)** — Lisää tiliisi toinen suojauskerros, jos ylläpitäjä on ottanut sen käyttöön
* **[CAPTCHA](captcha.md)** — Miksi sinua saatetaan pyytää todistamaan olevasi ihminen kirjautumis-, rekisteröitymis- tai unohtuneen salasanan lomakkeilla

Kaikki tässä kuvatut ominaisuudet eivät välttämättä ole käytössä alustallasi — ylläpitäjät voivat ottaa kunkin niistä käyttöön tai pois käytöstä. Jos jokin tässä osiossa kuvattu ei näy sinulle, sitä ei todennäköisesti ole otettu käyttöön.
