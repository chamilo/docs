# Opiskelijan opas

Tervetuloa Chamilo 3.0 -opiskelijan oppaaseen. Tämä opas on tarkoitettu oppijoille — kaikille, jotka osallistuvat kursseille Chamilo-alustan kautta, olipa kyseessä koulu, yrityksen koulutusohjelma tai avoin verkkokurssi.

Olitpa Chamilossa ensimmäistä kertaa tai jo ilmoittautunut useille kursseille, tämä opas auttaa sinua liikkumaan alustalla, liittymään kursseille ja pitämään tilisi turvassa.

## Mitä opiskelijana voit tehdä

Chamilon oppijana voit:

* **Luoda tilin** (jos alustasi sallii itseilmoittautumisen) ja kirjautua sisään
* **Liittyä kursseille** — julkisen katalogin, kutsun tai ylläpitäjän tai opettajan tekemän ilmoittautumisen kautta
* **Käyttää kurssityökaluja** — lukea dokumentteja, seurata oppimispolkuja, tehdä harjoituksia, palauttaa tehtäviä ja muuta
* **Viestiä** — käyttää foorumeita, chattia ja ryhmiä vuorovaikutukseen opettajien ja muiden oppijoiden kanssa
* **Seurata omaa edistymistäsi** — nähdä pisteesi, suoritustilanteesi ja todistuksesi
* **Saada apua tekoälytutoriilta**, jos alustallasi on se käytössä
* **Pitää tilisi turvassa** — nollata unohtunut salasana ja ottaa käyttöön kaksivaiheinen tunnistautuminen

## Miten tämä opas on järjestetty

1. **Aloittaminen** — Luo tilisi (tai kirjaudu sisään) ja tutustu yleiseen käyttöliittymään
2. **Kurssit** — Ilmoittaudu kurssille, käytä sen työkaluja (oppimispolut, testit, tehtävät, foorumi, chat) ja käytä tekoälytutoria
3. **Saapuneet** — Lähetä ja vastaanota yksityisviestejä muiden alustan käyttäjien kanssa
4. **Sosiaalinen verkosto** — Yhdistä muihin käyttäjiin, jos ylläpitäjäsi on ottanut tämän ominaisuuden käyttöön
5. **Oma edistyminen** — Saat nopean yleiskuvan omasta toiminnastasi ja tuloksistasi kaikilla kursseillasi
6. **Tili ja tietoturva** — Nollaa salasanasi, ota käyttöön kaksivaiheinen tunnistautuminen ja ymmärrä CAPTCHA

Tämä opas kattaa olennaiset asiat, jotta pääset alkuun. Se laajenee ajan myötä kattamaan lisää aiheita.

Aloitetaan.
