# Sanasto

Tässä oppaassa käytetyt keskeiset termit.

| Termi | Määritelmä |
|------|-----------|
| **Assessment** | Katso **Gradebook** alla |
| **Assignment** | Tehtävä, jossa lähetät tiedostoja tai tekstiä opettajan arvioitavaksi ja arvosteltavaksi. Tunnetaan myös nimillä "student publication" tai "work". |
| **CAPTCHA** | Haaste (tyypillisesti vääristyneiden kirjainten kirjoittaminen kuvasta), jolla varmistetaan, että olet oikea henkilö. Näytetään joissakin kirjautumis-, rekisteröitymis- ja salasanan palautuslomakkeissa. |
| **Catalog** | Julkinen kurssien (ja sessioiden) listaus, jota voit selata ja johon voit joissakin tapauksissa ilmoittautua itse. Käytetään kohdasta **Explore more courses**. |
| **Certificate** | Asiakirja, joka luodaan automaattisesti, kun saavutat kurssin gradebookissa määritellyn vähimmäispistemäärän. |
| **Course** | Oppimissisällön ja työkalujen säiliö. Kurssi voi sisältää dokumentteja, harjoituksia, foorumeita, oppimispolkuja ja muuta. |
| **Enrollment** | Rekisteröityminen kurssille tai sessioon, mikä antaa pääsyn sen sisältöön. Tunnetaan myös nimellä "subscription". |
| **Exercise** | Tietovisa tai testi, joka sisältää yhden tai useamman kysymyksen. Joissakin yhteyksissä kutsutaan myös nimellä "test". |
| **Forum** | Keskustelutyökalu, jossa ketjutetut keskustelut on järjestetty kategorioihin ja aiheisiin. |
| **Gradebook** | Työkalu, joka kokoaa pisteesi harjoituksista, tehtävistä ja muista aktiviteeteista yhtenäiseksi arvosanaksi. |
| **Invitation** | Opettajan sähköpostiisi lähettämä kertakäyttöinen linkki, jonka avulla voit rekisteröityä ja tulla automaattisesti tilatuksi kurssille, vaikka yleinen rekisteröityminen olisi suljettu. |
| **Learning path** | Oppimisaktiviteettien (dokumentit, harjoitukset, linkit) jäsennelty jakso, jota noudatat määritellyssä järjestyksessä, joskus ennakkovaatimuksin. |
| **Self-registration** | Mahdollisuus luoda oma tili julkisella rekisteröitymislomakkeella, jos alustan ylläpitäjä on sen ottanut käyttöön. |
| **Session** | Yhden tai useamman kurssin aikarajattu toteutus, joka on osoitettu tietylle oppijaryhmälle, esimerkiksi lukukaudelle tai kohortille. |
| **Skill** | Gradebook-saavutuksiin sidottu osaaminen. Sertifikaatin ansaitseminen voi vahvistaa siihen liittyvät taidot. |
| **Two-factor authentication (2FA)** | Lisävaihe kirjautumisessa, jossa käytetään todennussovelluksen aikaperusteista koodia salasanan lisäksi. |
| **Visibility** | Asetus, joka määrittää, näytetäänkö työkalu, dokumentti tai aktiviteetti oppijoille. Opettajat näkevät aina piilotetut kohteet. |
