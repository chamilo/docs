# Integraatiot

Chamilo integroituu useisiin kolmannen osapuolen palveluihin toimintojensa laajentamiseksi.

Useimmat näistä otetaan käyttöön liitännäisten kautta. Katso vastaava osio hieman myöhemmin tästä oppaasta.

* **[Videoneuvottelu](video-conferencing.md)** — BigBlueButton ja Zoom
* **[LTI 1.3](lti.md)** — Yhdistä ulkoisia oppimistyökaluja
* **[xAPI](xapi.md)** — Oppimiskokemusten seuranta
* **[OnlyOffice](onlyoffice.md)** — Yhteistoiminnallinen asiakirjojen muokkaus
* **[Tekoälyn määritys](ai-configuration.md)** — Määritä tekoälypalveluntarjoajat tekoälypohjaisia ominaisuuksia varten
