# Muut ylläpitolohkot

Ylläpidon kojitusnäkymässä on muutama lohko, jotka eivät niinkään ole määritettäviä ominaisuuksia vaan tiedottavia widgettejä: sivu lähteville linkeille, version tarkistuksen rekisteröinti sekä kaksi pientä paneelia, jotka noutavat sisältöä osoitteesta chamilo.org. Tässä luvussa selitetään, mitä kukin niistä on, mistä sen sisältö tulee ja — koska osa niistä niin tekee — lähteekö alustaltasi mitään tietoja.

## Mitä käsitellään

* **[Chamilo.org-linkit](chamilo-org-links.md)** — Kirjanmerkkilista virallisiin Chamilo-resursseihin; ei lähetä mitään
* **[Version tarkistus](version-check.md)** — Valinnainen rekisteröinti, joka ilmoittaa alustasi version ja käytön osoitteeseen chamilo.org ja kertoo, onko päivitys ajankohtainen
* **[Ammatillinen tuki](professional-support.md)** — Vain luku -paneeli, joka kuvaa virallisia Chamilo-tukipalvelujen tarjoajia
* **[Uutisia Chamilolta](news-from-chamilo.md)** — Vain luku -syöte virallisista tiedotteista, mukaan lukien tietoturvakorjaukset ja uudet julkaisut

Jokainen alla oleva sivu kertoo selvästi, mitä — jos mitään — lähetetään osoitteeseen chamilo.org ja miksi.
