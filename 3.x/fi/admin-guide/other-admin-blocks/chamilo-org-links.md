# Chamilo.org-linkit

**Chamilo.org**-lohko on staattinen luettelo ulospäin vievistä linkeistä virallisiin Chamilo-resursseihin — ei muuta. Se ei lähetä tietoja minnekään; jokainen linkki avaa joko ulkoisen Chamilo-sivuston tai asennuksesi mukana toimitetun paikallisen dokumentaatiosivun.

## Mitä lohkossa on

| Linkki | Kohde |
|------|-------------|
| Chamilo-kotisivu | `chamilo.org` |
| Käyttöoppaat | `docs.chamilo.org` |
| Chamilo-foorumi | GitHub Discussions chamilo-lms:lle |
| Asennusopas | Paikallinen, `/documentation/installation_guide.html` |
| Muutokset viimeisessä versiossa | Paikallinen, `/documentation/changelog.html` |
| Avustajien luettelo | Paikallinen, `/documentation/credits.html` |
| Tietoturvaopas | Paikallinen, `/documentation/security.html` |
| Optimointiopas | Paikallinen, `/documentation/optimization.html` |
| Chamilon viralliset palveluntarjoajat | `chamilo.org/providers` |

”Paikalliset” linkit osoittavat Chamilo-asennuksesi mukana tuleviin dokumentaatiotiedostoihin, joten ne latautuvat omalta palvelimeltasi, ei chamilo.orgista.

## Tarkoitus

Tämä lohko on olemassa pelkästään mukavuuden vuoksi — nopea pääsy projektin viralliseen dokumentaatioon, yhteisön keskustelutilaan ja hyväksyttyjen palveluntarjoajien luetteloon ilman, että niitä tarvitsee etsiä.
