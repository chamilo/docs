# Taitojen sijoitus

Taitojen sijoitus on käyttäjien tulostaulu, joka on järjestetty sen mukaan, kuinka monta taitoa he ovat hankkineet.

## Taitojen sijoituksen avaaminen

Hallintapaneelista valitse **Skills > Skills ranking**.

## Mitä se näyttää

Jokaiselle aktiiviselle käyttäjälle sijoitus näyttää:

* **Hankitut taidot** — Myönnettyjen taitojen kokonaismäärä, jota käytetään tulostaulun järjestämiseen (korkein ensin)
* **Oppii tällä hetkellä** — Niiden taitojen määrä, jotka on arviointikirjan kautta sidottu kursseihin, joille käyttäjä on tällä hetkellä ilmoittautunut (suoraan tai session kautta)

Käytä tätä sivua nähdäksesi yhdellä silmäyksellä taitavimmat oppijasi tai arvioidaksesi taitojen hankinnan kokonaisaktiivisuutta alustalla.
