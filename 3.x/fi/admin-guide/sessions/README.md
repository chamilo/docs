# Istunnot

Istunnot ovat yksi Chamilon tehokkaimmista ominaisuuksista. Niiden avulla voit tarjota samoja kursseja eri oppijaryhmille eri aikoina ilman, että kurssisisältöä tarvitsee monistaa.

## Istuntojen ymmärtäminen

Istunnot ovat **valinnaisia**. Portaali voi toimia pelkillä kursseilla, mutta suosittelemme **vahvasti** ottamaan huomioon istuntojen lisämonimutkaisuuden tapana säästää hallintatyötä pitkällä aikavälillä.

**Kurssi** sisältää sisällön (asiakirjat, harjoitukset, oppimispolut). **Istunto** kohdistaa kyseisen kurssin (tai useita kursseja) tietylle oppijaryhmälle *tietylle ajanjaksolle*.

Tämä arkkitehtuuri tarkoittaa, että:

* Opettajat luovat sisällön kerran kurssille
* Ylläpitäjät luovat istuntoja toimittaakseen kyseisen sisällön eri kohorteille
* Jokaisella istunnolla on oma ilmoittautumisensa, seurantatietonsa ja tuloksensa
* Peruskurssin sisältö on jaettu, mutta istuntotutorit voivat mukauttaa tiettyjä elementtejä

## Milloin istuntoja kannattaa käyttää

Käytä istuntoja, kun:

* Tarjoat samaa koulutusta useita kertoja (esim. kuukausittaiset perehdytysistunnot)
* Sinulla on kohorttipohjaisia ohjelmia (esim. lukukausipohjaiset luokat)
* Tarvitset erillisen seurannan oppijaryhmää kohden
* Haluat eri tutoreiden hallinnoivan saman kurssin eri versioita
