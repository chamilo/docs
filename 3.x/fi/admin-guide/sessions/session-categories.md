# Istuntokategoriat

Istuntokategoriat auttavat organisoimaan istuntoja, erityisesti kun useita istuntoja on käynnissä samanaikaisesti.

## Kategorian luominen

1. Siirry hallintapaneelista kohtaan **Istuntokategoriat**
2. Napsauta **Lisää kategoria**
3. Anna **nimi** ja valinnaiset alku-/loppupäivämäärät
4. Tallenna

## Käyttötapaukset

* **Ohjelman mukaan** — "Leadership Development", "Technical Training", "Onboarding"
* **Jakson mukaan** — "Q1 2026", "Spring Semester", "July Batch"
* **Osaston mukaan** — "Engineering", "Sales", "Human Resources"

## Kategorioiden hallinta

* **Muokkaa** — Muuta kategorian nimeä tai päivämääriä
* **Määritä istuntoja** — Kun luot tai muokkaat istuntoa, valitse sen kategoria
* **Poista** — Poista kategoria (kategoriassa olevat istunnot jäävät ilman kategoriaa)
