# Alusta

Hallintapaneelin **Alustan hallinta** -lohko kokoaa portaalinlaajuiset määritys- ja viestintätyökalut — kaiken täydellisestä asetuspaneelista kieliin, julkisiin ilmoituksiin, globaaliin kalenteriin ja CMS-tyyppiseen Sivut-järjestelmään, jolla rakennetaan osia portaalin julkisesta sisällöstä.

## Alustalohkon avaaminen

Hallintapaneelissa **Alustan hallinta** -lohko näkyy muiden kojitusnäkymän lohkojen rinnalla. Avaa vastaava työkalu napsauttamalla mitä tahansa sen linkeistä.

## Mitä lohkossa on

* **[Alustan asetukset](../platform-settings/README.md)** — Täydellinen määritysasetusten paneeli (portaali, kurssit, istunnot, käyttäjät, tietoturva ja muuta). Tämän lohkon ”Määritysasetukset”-linkki on vain sisäänkäynti kyseiseen erilliseen lukuun.
* **[Kielet](languages.md)** — Valitse, mitkä käyttöliittymän kielet ovat käyttäjien saatavilla, ja aseta alustan oletuskieli
* **[Portaalin uutiset](portal-news.md)** — Portaalinlaajuiset ilmoitukset (järjestelmäilmoitukset), aikataulutetut ja roolin mukaan kohdennetut
* **[Globaali agenda](global-agenda.md)** — Portaalinlaajuiset kalenteritapahtumat, jotka näkyvät kaikille käyttäjille kurssista tai istunnosta riippumatta
* **[Sivut](pages.md)** — CMS-tyyppinen työkalu portaalin etusivun, alatunnisteen ja muiden julkisten sisältölohkojen takana, mukaan lukien rekisteröintisivun johdantoteksti
* **[Alustatyökalut](platform-tools.md)** — Lisäkentät, sähköpostimallit, yhteydenottolomakkeen luokat ja muutama pienempi, ehdollisesti näytettävä kohde
* **Usean käyttö-URL:n määritys** — Käsitelty kohdassa [Käyttö-URL:t](../multi-url/access-urls.md), Multi-URL:n alla
* **Ulkoiset työkalut (LTI)** — Käsitelty kohdassa [LTI 1.3](../integrations/lti.md), Integraatiot-osiossa
