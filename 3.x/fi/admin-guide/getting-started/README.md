# Aloittaminen

Tämä osio esittelee Chamilo 3.0:n hallintakäyttöliittymän ja auttaa sinua orientoitumaan.

## Kuka on ylläpitäjä?

Chamilossa on useita hallinnollisia rooleja:

| Rooli | Käyttöoikeus |
|------|--------|
| **Administrator** | Täysi pääsy kaikkiin alustan hallintaominaisuuksiin. Tunnetaan myös nimellä **Portal Administrator** |
| **Global Administrator** | Sama kuin Portal Administrator, mutta pääsy kaikkiin käyttö-URL-osoitteisiin multi-URL- (multi-tenant) -asennuksessa |
| **Sessions Administrator** | Voi hallita sessioita, ilmoittaa käyttäjiä sessioihin ja käyttää sessioihin liittyviä asetuksia |
| **Human Resources Manager** | Voi tarkastella oppijoiden edistymistä ja seurantatietoja osoitetuille käyttäjille |
| **Questions Manager** | Enemmän sisällön kuratoija kuin ylläpitäjä; kysymysten hallinnoijilla on pääsy globaaliin kysymyspankkiin kysymysten laadun tarkistamiseksi |

Tämä opas keskittyy ensisijaisesti **Portal Administrator** -rooliin, jolla on laajin käyttöoikeus.

## Kirjautuminen

Ylläpitäjät kirjautuvat saman kirjautumissivun kautta kuin kaikki muutkin käyttäjät. Tunnusten syöttämisen jälkeen sinut ohjataan (ellei muuta ole määritetty) **Administration**-sivulle. Merkittävä ero muihin käyttäjärooleihin on sivupalkin **Administration**-osio (ei näy muille rooleille).
