# Multi-URL

Chamilon multi-URL-ominaisuus (kutsutaan myös multi-tenantiksi) mahdollistaa useiden virtuaalisten portaalien ajamisen yhdestä Chamilo-asennuksesta. Jokaisella portaalilla on oma URL-osoitteensa, brändäyksensä, käyttäjänsä, kurssinsa ja asetuksensa, mutta ne kaikki jakavat saman tietokannan ja koodipohjan.
