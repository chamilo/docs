# Tiketit

**Tiketit**-kohta Analytics-lohkossa on oikopolku Chamilon tukitikettijärjestelmään — se avaa suoraan tikettilistan, ei asetus sivua.

## Tikettien avaaminen

Hallintapaneelista napsauta **Analytics > Tiketit**.

## Mitä se näyttää

Tikettilista, jossa tukipyyntöjä seurataan ja niihin vastataan — sama tikettijärjestelmä, jota käsitellään tukihenkilön näkökulmasta opettajan oppaan sivulla [Tukitiketit](../../teacher-guide/tickets.md).

Itse tikettijärjestelmän määrittämiseen (kategoriat, prioriteetit, määritetyt henkilöt) katso [Tikettiasetukset](../platform-settings/ticket-settings.md) kohdasta Configuration Settings.
