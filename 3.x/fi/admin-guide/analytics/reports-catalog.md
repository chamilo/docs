# Raporttikatalogi

Raporttikatalogi ei ole itse raportti — se on hakemisto kaikista alustalle rekisteröidyistä raporteista, ja se auttaa ymmärtämään, mitä on saatavilla ja kuka voi nähdä sen.

## Raporttikatalogin avaaminen

Hallintapaneelista valitse **Analytics > Reports catalog**.

## Mitä se näyttää

* **Raporttiluettelo** — Jokaisen rekisteröidyn raportin otsikko, kuvaus sekä sen kanoninen ja vanha URL
* **Roolimatriisi** — Näkymä, joka näyttää, mitkä roolit (Portal Administrator, Global Administrator, Session Administrator, Teacher, Human Resources Manager, Student Boss...) voivat käyttää kutakin raporttia
* **Käyttöoikeusluokat** — Käyttöoikeusryhmät, joihin raportit on organisoitu (esimerkiksi `reports.platform`, `reports.learning_analytics`, `reports.export`, `reports.security`)

Käytä tätä sivua, kun haluat selvittää, missä tietty raportti sijaitsee tai onko tietyllä roolilla (esimerkiksi Human Resources Manager) pääsy siihen, ilman että sinun tarvitsee tarkistaa jokaista raporttia erikseen.
