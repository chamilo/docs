# Analytiikka

Hallintapaneelin **Analytiikka**-lohko kokoaa yhteen koko alustan tilastot, oppimisanalytiikan, yritys-/HR-raportoinnin ja joukkovientityökalut. Chamilo-versiostasi riippuen tämä lohko voi olla merkitty hallintapaneelissa nimellä **"Seuranta"** — kyseessä on joka tapauksessa sama lohko. Tässä oppaassa sitä kutsutaan Analytiikaksi sekaannusten välttämiseksi [Seuranta-asetusten](../platform-settings/tracking-settings.md) kanssa, joka on erillinen asetusluokka, joka ohjaa mitä tallennetaan eikä itse raportteja.

## Analytiikan käyttäminen

Hallintapaneelissa **Analytiikka**-lohko näkyy muiden hallintapaneelin lohkojen rinnalla. Avaa vastaava raportti napsauttamalla mitä tahansa sen linkeistä.

## Mitä lohkossa on

* **[Yleiset tilastot](global-statistics.md)** — Koko alustan tilastot: kurssit, käyttäjät, kirjautumiset, istunnot ja levytila
* **[Raporttiluettelo](reports-catalog.md)** — Selaa kaikkia rekisteröityjä raportteja, kuka niihin pääsee ja miksi
* **[Oppimisanalytiikka](learning-analytics.md)** — Perinteinen seurantapaneeli: käyttäjä-, kurssi- ja istuntokohtaiset tarkennukset käytettyyn aikaan ja pistemäärien keskiarvoihin
* **[Yritysraportit](corporate-reports.md)** — Neljännesvuosittaiset yhteenvedot, opettajien ajan seuranta ja HR-orientoitunut kurssi-/käyttäjäraportointi
* **[Tiketit](tickets.md)** — Siirry suoraan tukitikettien luetteloon

## Kuka siihen pääsee

Useimmat näistä raporteista edellyttävät **portaalin ylläpitäjän** oikeuksia. Yritysraportti on poikkeus — se on avoinna myös **henkilöstöjohtajan** ja **opiskelijapomon** rooleille, koska se on rakennettu nimenomaan tälle kohderyhmälle.
