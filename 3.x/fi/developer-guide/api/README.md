# API

Chamilo 3.0 tarjoaa REST-rajapinnan, joka on rakennettu **API Platform 4**:n päälle. Rajapinta antaa ohjelmallisen pääsyn alustan resursseihin, ja se on sama rajapinta, jota Vue-käyttöliittymä käyttää.

* **[Todennus](authentication.md)** — JWT-tunnisteisiin perustuva todennus
* **[Päätepisteiden viite](endpoints-reference.md)** — Yleiskatsaus käytettävissä olevista API-resursseista
* **[Mukautetut toiminnot](custom-actions.md)** — Erikoistuneet päätepisteet tavanomaisen CRUD:n lisäksi
* **[Webhookit](webhooks.md)** — Tapahtumapohjaiset ilmoitukset ulkoisiin järjestelmiin
