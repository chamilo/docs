# Sanasto

Tässä oppaassa käytetyt keskeiset termit.

| Termi | Määritelmä |
|------|-----------|
| **Arviointi** | Katso **Arvosanakirja** alla |
| **Tehtävä** | Tehtävä, jossa oppijat palauttavat tiedostoja tai tekstiä opettajan tarkastettavaksi ja arvosteltavaksi. Tunnetaan myös nimillä "opiskelijajulkaisu" tai "työ". |
| **Automaattinen käynnistys** | Ominaisuus, joka avaa automaattisesti tietyn työkalun, kun oppija siirtyy kurssille. |
| **Todistus** | Asiakirja, joka luodaan automaattisesti, kun oppija saavuttaa arvosanakirjassa määritellyn vähimmäispistemäärän. |
| **Kurssi** | Säiliö oppimissisällölle ja työkaluille. Kurssi voi sisältää dokumentteja, harjoituksia, foorumeita, oppimispolkuja ja muuta. |
| **Kurssin tuutori** | Opettajarooli, joka liittyy sessioihin. Kurssin tuutori hallinnoi yhtä kurssia session sisällä. Chamilo-versioissa ennen 3.0 kutsuttu nimellä "course coach". |
| **Levykiintiö** | Kurssille ladatuille tiedostoille varattu enimmäistallennustila. |
| **Ilmoittautuminen** | Prosessi, jossa käyttäjä rekisteröidään kurssille tai sessioon, jolloin hän saa pääsyn sen sisältöön. Tunnetaan myös nimellä "tilaus". |
| **Harjoitus** | Kysely tai testi, joka sisältää yhden tai useamman kysymyksen. Joissakin yhteyksissä kutsutaan myös "testiksi". |
| **Foorumi** | Keskustelutyökalu, jossa ketjutetut keskustelut on järjestetty kategorioihin ja aiheisiin. |
| **Arvosanakirja** | Työkalu, joka kokoaa pisteet harjoituksista, tehtävistä ja muista aktiviteeteista yhtenäiseksi arvosanaksi kullekin oppijalle. |
| **Oppimispolku** | Jäsennelty oppimisaktiviteettien (dokumentit, harjoitukset, linkit) jakso, jota oppijat seuraavat määritellyssä järjestyksessä, valinnaisesti esitietovaatimuksin. |
| **LTI** | Learning Tools Interoperability — standardi, jonka avulla ulkoisia oppimistyökaluja voidaan upottaa Chamiloon. |
| **SCORM** | Sharable Content Object Reference Model — standardi e-oppimisen sisältöpaketeille. Chamilo voi tuoda ja toistaa SCORM-paketteja oppimispoluissa. |
| **Sessio** | Yhden tai useamman kurssin aikarajoitteinen toteutus, joka on osoitettu tietylle oppijaryhmälle. Sessiot mahdollistavat saman kurssisisällön uudelleenkäytön eri kohorteille. |
| **Session tuutori** | Valvontarooli, joka valvoo kaikkia session kursseja. Chamilo-versioissa ennen 3.0 kutsuttu nimellä "session coach". |
| **Taito** | Kompetenssi, joka voidaan liittää arvosanakirjan saavutuksiin. Kun oppija saa todistuksen, siihen liittyvät taidot vahvistetaan. |
| **Kysely** | Kyselytyökalu palautteen keräämiseen, erilaisilla kysymystyypeillä ja anonyymeillä vastausvaihtoehdoilla. |
| **Näkyvyys** | Asetus, joka määrittää, onko työkalu, dokumentti tai aktiviteetti oppijoiden nähtävissä. Opettajat näkevät aina piilotetut kohteet. |
