# Yhteistyö ja viestintä

Chamilo tarjoaa useita työkaluja, jotka mahdollistavat vuorovaikutuksen sinun ja oppijoidesi välillä sekä oppijoiden kesken.

* **[Foorumit](forums.md)** — Ketjutetut keskustelut, jotka on järjestetty kategorioittain ja aiheittain
* **[Chat](chat.md)** — Reaaliaikainen tekstiviestintä kurssin sisällä
* **[Ryhmät](groups.md)** — Jaa oppijat työryhmiin, joilla on omat jaetut työkalunsa
* **[Wiki](wiki.md)** — Yhteisöllinen asiakirjojen muokkaus
* **[Blogi](blog.md)** — Jaettu bloggaaminen kurssin sisällä
* **[Videoneuvottelu](video-conferencing.md)** — Live-videoistunnot BigBlueButtonilla tai Zoomilla

Nämä työkalut ovat käytettävissä kurssin etusivulta. Jotkin niistä voivat olla oletuksena piilotettuja — voit tehdä ne näkyviksi työkaluruudukosta (ks. [Kurssin etusivu](../creating-your-course/course-homepage.md)).
