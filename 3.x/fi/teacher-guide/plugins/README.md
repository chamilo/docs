# Lisäosat

Chamiloon sisäänrakennettujen työkalujen lisäksi alustan ylläpitäjä voi asentaa ja ottaa käyttöön **lisäosia** — valinnaisia ominaisuuksia, jotka lisäävät kursseihin uusia työkaluja, asetuksia tai toimintaa. Lisäosat ovat oletuksena pois päältä; kukin niistä näkyy vasta, kun ylläpitäjä on ottanut sen käyttöön, ja osa vaikuttaa vasta sen jälkeen, kun otat ne käyttöön myös tietyssä kurssissa.

Tässä osiossa kuvataan lisäosat, jotka muuttavat jotain, minkä **opettaja** kohtaa suoraan. Jos et näe täällä kuvattua lisäosaa omissa kursseissasi, se ei todennäköisesti ole käytössä alustallasi — kysy ylläpitäjältäsi.

* **[Exercise Focused](exercise-focused.md)** — Tunnista, milloin opiskelija poistuu tentti-ikkunasta kokeen aikana, näytöllä näkyvällä varoituksella ja valinnaisella automaattisella lähetyksellä
* **[Exercise Monitoring](exercise-monitoring.md)** — Tallenna verkkokamerakuvia opiskelijasta ja hänen henkilötodistuksestaan valvotun tenttiyrityksen aikana
* **[Exercise Signature](exercise-signature.md)** — Vaadi opiskelijoita allekirjoittamaan sähköisesti kokeen suorittamisen jälkeen
* **[Question Options Evaluation](question-options-evaluation.md)** — Käytä kokeessa negatiivisen pisteytyksen (rangaistus) kaavaa Chamilon oletuspisteytyksen sijaan
* **[Positioning](positioning.md)** — Vertaa oppijan alku- ja loppukokeen pistemääriä tutka- eli sädekaaviolla
* **[Test to PDF](test-to-pdf.md)** — Vie kokeen kysymykset ja/tai vastaukset tulostettavaan PDF-tiedostoon
