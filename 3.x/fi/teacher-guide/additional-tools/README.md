# Lisätyökalut

Ydinsisällön, arvioinnin ja yhteistyötyökalujen lisäksi Chamilo tarjoaa useita lisätyökaluja, joilla voit rikastaa kurssiasi.

* **[Agenda](agenda.md)** — Aikatauluta tapahtumia, määräaikoja ja muistutuksia kurssillesi
* **[Notebook](notebook.md)** — Oppijoiden henkilökohtainen muistiinpanotyökalu
* **[Dropbox](dropbox.md)** — Yksinkertainen tiedostojen vaihtotyökalu sinun ja oppijoidesi välillä
* **[Portfolio](portfolio.md)** — Anna oppijoiden koota ja esitellä työnsä portfoliona
* **[Course Progress](course-progress.md)** — Määritä temaattiset osiot ja seuraa kurssin etenemistä
