# Seuranta ja raportointi

Chamilo seuraa oppijan toimintaa koko alustalla ja antaa yksityiskohtaista tietoa oppijoiden edistymisestä.

* **[Oppijan seuranta](learner-tracking.md)** — Seuraa yksittäisen oppijan toimintaa: kirjautumisajat, käytetty aika, vieraillut sivut ja työkalujen käyttö
* **[Kurssiraportit](course-reports.md)** — Tarkastele koottua dataa kaikista kurssin oppijoista
* **[Todistukset ja taidot](certificates-and-skills.md)** — Myönnä todistuksia arviointikirjan pisteiden perusteella ja vahvista hankitut taidot

## Raporttien avaaminen

Kurssiltasi klikkaa **Seuranta**-työkalua <img src="../../.gitbook/assets/icons/mdi-chart-box.svg" alt="Seuranta" data-size="line"> kurssin etusivulla. Raportointiin pääset myös sivupalkin **Raportointi**-linkistä, jolloin näet yleiskuvan useista kursseista.

Opettajat näkevät raportointitiedot opettamistaan kursseista. Istunnon tuutorit näkevät tiedot kaikista istuntoonsa kuuluvista kursseista.
