# Sisällön lisääminen

Tässä osiossa käsitellään työkaluja, joilla lisäät oppimissisältöä kurssillesi. Chamilo tarjoaa useita tapoja toimittaa materiaalia oppijoille:

* **[Dokumentit](documents.md)** — Lataa tiedostoja, luo verkkosivuja ja järjestä sisältökirjastosi
* **[Linkit](links.md)** — Jaa URL-osoitteita ulkoisiin resursseihin, järjestettyinä kategorioittain
* **[Oppimispolut](learning-paths.md)** — Rakenna jäsenneltyjä sisältöjaksoja edellytyksineen ja edistymisen seurannalla
* **[Sanasto](glossary.md)** — Määrittele keskeiset termit, joihin oppijat voivat viitata koko kurssin ajan
* **[Ilmoitukset](announcements.md)** — Lähetä viestejä ja päivityksiä ilmoittautuneille oppijoillesi
* **[Monikielinen sisältö](multi-language-content.md)** — Kirjoita samasta sisällöstä useita kieliversioita ja näytä kullekin oppijalle vain hänen omansa

Jokainen työkalu on käytettävissä kurssin etusivun työkaluruudukosta. Avaa työkalu napsauttamalla sen kuvaketta.
