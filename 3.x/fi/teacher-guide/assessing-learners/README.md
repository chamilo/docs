# Oppijoiden arviointi

Chamilo tarjoaa kattavan työkaluvalikoiman oppijoiden tietojen arviointiin ja suoritusten seurantaan.

* **[Käyttäjien liittäminen](subscribing-users.md)** — Saat oppijat kurssillesi: ylläpitäjän tekemä ilmoittautuminen, itseilmoittautuminen, manuaalinen ilmoittautuminen tai sähköpostikutsut
* **[Harjoitukset](exercises.md)** — Luo tenttejä ja testejä monenlaisilla kysymystyypeillä, automaattisella arvostelulla ja yksityiskohtaisella palautteella
* **[Tehtävät](assignments.md)** — Kerää oppijoilta kotitehtäviä ja projekteja; tuki tiedostojen latauksille, vertaisarvioinnille sekä manuaaliselle tai tekoälyavusteiselle arvostelulle
* **[Kyselyt](surveys.md)** — Kerää oppijoilta palautetta muokattavilla kyselylomakkeilla
* **[Läsnäolo](attendance.md)** — Seuraa oppijoiden läsnäoloa oppitunneilla
* **[Arviointikirja](gradebook.md)** — Yhdistä harjoitusten, tehtävien ja muiden aktiviteettien pisteet yhtenäiseksi arvosanaksi ja myönnä todistuksia

**Raportointi**-työkalu on edelleen käytettävissä, mutta se on siirretty opettajalle kurssin etusivun yläosaan pienenä kaaviokuvakkeena. Tämä on keskeinen paikka koko kurssin ja sen opiskelijoiden edistymistietojen tarkasteluun.

Nämä työkalut toimivat yhdessä: harjoitusten pisteet ja tehtävien arvosanat voivat siirtyä arviointikirjaan, joka voidaan kytkeä todistusten luomiseen ja taitojen vahvistamiseen.
