# توثيق Chamilo 3.0

مرحبًا بكم في التوثيق الرسمي لـ **Chamilo 3.0**، منصة التعلّم الإلكتروني مفتوحة المصدر.

يُنظَّم هذا التوثيق في ثلاثة أدلة، كلٌّ منها موجَّه إلى جمهور محدّد:

* [**دليل المعلّم**](teacher-guide/) — للمدرّسين والمدربين: إنشاء المقررات، وإضافة المحتوى، وتقييم المتعلمين، وتتبع التقدّم.
* [**دليل الإدارة**](admin-guide/) — لمسؤولي المنصة: تثبيت منصة Chamilo وتكوينها وإدارتها.
* [**دليل المطوّر**](developer-guide/) — للمطوّرين: فهم البنية المعمارية، وبناء الإضافات، واستخدام الـ API، والمساهمة في المشروع.

## ما الجديد في Chamilo 3.0

Chamilo 3.0 إصدار رئيسي بواجهة معاد تصميمها بالكامل والعديد من الميزات الجديدة:

* **واجهة حديثة** — مبنية بـ Vue 3 وPrimeVue لتجربة أسرع وأكثر استجابة
* **أدوات مدعومة بالذكاء الاصطناعي** — توليد التمارين ومسارات التعلّم والحصول على تصحيح بمساعدة الذكاء الاصطناعي
* **REST API** — REST API كامل مبني على API Platform مع مصادقة JWT
* **خيارات مصادقة جديدة** — OAuth2 (Azure، Keycloak، Facebook)، وتوفير المستخدمين عبر SCIM
* **LTI 1.3** — ربط أدوات التعلّم الخارجية بسلاسة
* **تخزين سحابي** — دعم أصلي لـ Azure Blob وAWS S3 وGoogle Cloud Storage
* **سمات الألوان** — تخصيص هوية المنصة البصرية مع دعم السمات
* **تكامل OnlyOffice** — تحرير المستندات بشكل تعاوني داخل المنصة
