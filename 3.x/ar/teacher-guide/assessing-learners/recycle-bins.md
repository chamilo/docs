# سلال المحذوفات للتمارين ومسارات التعلم

يمكن لـ Chamilo 3.1 أرشفة محاولات التمارين المحذوفة وبيانات تتبّع مسارات التعلم حتى يتمكن المعلمون المصرّح لهم من استعادتها، وفقًا لضوابط الاحتفاظ والوصول المُعدّة. تحمي سلال المحذوفات بيانات التتبّع؛ وهي ليست بديلًا عن النسخ الاحتياطية لقاعدة البيانات.

## استعادة محاولة تمرين

1. افتح صفحة **التقارير** الخاصة بالتمرين المتأثر مع تحديد المقرر أو الجلسة الصحيحة.
2. اختر **سلة المحذوفات** لعرض المحاولات المؤرشفة.
3. حدّد المتعلّم والمحاولة التي تحتاج إلى استعادتها.
4. اختر **استعادة**، ثم أكّد، وحدّث التقرير للتحقق من الإجابات والدرجات.

يجب أن تكون لديك صلاحية إدارة نتائج التمارين. قد تُحظر الاستعادة عندما يكون التمرين مقفلًا بواسطة دفتر الدرجات (Gradebook) أو عندما تقيّد المنصة وصول المعلمين إلى النتائج.

## استعادة تقدّم مسار التعلم

1. افتح شاشة تقارير مسار التعلم ذات الصلة للمقرر/الجلسة المقصودين.
2. افتح **سلة المحذوفات** الخاصة بها.
3. حدّد تقدّم المتعلّم المؤرشف واختر **استعادة**.
4. تحقق من تقدّم الدرس المستعاد ومحاولات التمارين المرتبطة به.

عندما تكون محاولة تمرين جزءًا من أرشيف مسار تعلّم معلّق، استعد أرشيف مسار التعلم أولًا. تُحظر الاستعادة الفردية عمدًا لمنع عدم اتساق التقدّم.

## الاحتفاظ والتنظيف (المسؤولون)

يتحكم الإعداد `tracking.recycle_bin_retention_hours` في المدة التي تبقى فيها الأرشيفات مؤهلة للاستعادة. القيمة الافتراضية الأولية هي **30 يومًا** (720 ساعة). يجب على التثبيتات القائمة مزامنة الإعداد الجديد عبر ترحيل settings-upsert الخاص بالمشروع قبل توقع ظهوره في واجهة الإدارة.

معاينة عملية تنظيف دون حذف أي شيء:

```bash
php bin/console chamilo:recycle-bin:purge
```

يتطلب الحذف الدائم خيارًا صريحًا:

```bash
php bin/console chamilo:recycle-bin:purge --execute
```

يدعم الأمر `--hours` (تجاوز مدة الاحتفاظ)، و`--scan-limit`، و`--after-lp-id`، و`--after-exercise-id` للمعالجة المتحكَّم بها. لا تجدول تشغيله إلا بعد التحقق من سياسة الاحتفاظ وترتيبات النسخ الاحتياطي. **لا يوجد جدول تنظيف تلقائي ضمني** لمجرد تفعيل الميزة.
