# تقييم المتعلمين

يوفر Chamilo مجموعة شاملة من الأدوات لتقييم معرفة المتعلمين وتتبع أدائهم.

* **[تسجيل المستخدمين](subscribing-users.md)** — إدخال المتعلمين إلى مقررك أولاً: تسجيل المسؤول، أو التسجيل الذاتي، أو التسجيل اليدوي، أو دعوات البريد الإلكتروني
* **[التمارين](exercises.md)** — إنشاء اختبارات قصيرة واختبارات بأنواع أسئلة متنوعة، وتصحيح تلقائي، وملاحظات تفصيلية
* **[الواجبات](assignments.md)** — جمع الواجبات المنزلية والمشاريع من المتعلمين، مع دعم رفع الملفات، ومراجعة الأقران، والتصحيح اليدوي أو بمساعدة الذكاء الاصطناعي
* **[الاستبيانات](surveys.md)** — جمع ملاحظات المتعلمين عبر استبيانات قابلة للتخصيص
* **[الحضور](attendance.md)** — تتبع حضور المتعلمين في الحصص الصفية
* **[دفتر الدرجات](gradebook.md)** — دمج الدرجات من التمارين والواجبات والأنشطة الأخرى في درجة موحّدة، ومنح الشهادات

لا تزال أداة **التقارير** موجودة لكنها نُقلت إلى أعلى الصفحة الرئيسية للمقرر بالنسبة للمعلم، على شكل أيقونة مخطط صغيرة. هذا هو المكان المركزي للوصول إلى معلومات التقدم للمقرر بأكمله وطلابه.

تعمل هذه الأدوات معاً: يمكن أن تغذي درجات التمارين ودرجات الواجبات دفتر الدرجات، الذي يمكن ربطه بإصدار الشهادات والتحقق من المهارات.
