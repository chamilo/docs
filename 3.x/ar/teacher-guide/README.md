# دليل المعلم

مرحبًا بك في دليل المعلم لـ Chamilo 3.0. صُمّم هذا الدليل للمدرّسين والمدربين وكل من يتولى إنشاء المحتوى التعليمي وتقديمه عبر منصة Chamilo.

سواء كنت بصدد إعداد أول مقرر إلكتروني لك أو إدارة برنامج تدريبي معقّد، سيرشدك هذا الدليل عبر كل ميزة متاحة لك كمعلم.

## ما يمكنك فعله باستخدام Chamilo

بصفتك معلمًا في Chamilo، يمكنك:

* **إنشاء المقررات وتنظيمها** بصفحة رئيسية مرنة وأدوات قابلة للتخصيص
* **إضافة المحتوى** — رفع المستندات، وإنشاء مسارات التعلم، وبناء المعاجم، والربط بالموارد الخارجية
* **تقييم المتعلمين** — تصميم تمارين بأنواع أسئلة متعددة، وجمع الواجبات، وإجراء الاستبيانات، وإدارة الدرجات
* **التعاون** — إعداد المنتديات، والعمل الجماعي، والويكي، والمدونات، وجلسات الفيديو المباشرة
* **تتبع التقدم** — مراقبة نشاط المتعلمين، وإنشاء التقارير، ومنح الشهادات
* **استخدام أدوات الذكاء الاصطناعي** — توليد التمارين ومسارات التعلم تلقائيًا، والحصول على تصحيح بمساعدة الذكاء الاصطناعي

## كيف نُظّم هذا الدليل

يتبع هذا الدليل سير العمل الطبيعي لبناء المقرر وتشغيله:

1. **البدء** — تسجيل الدخول، والتنقل في الواجهة، وإعداد ملفك الشخصي
2. **إنشاء مقررك** — إنشاء مقرر جديد، وضبط إعداداته، وتخصيص الصفحة الرئيسية
3. **إضافة المحتوى** — رفع المستندات، وتنظيم مسارات التعلم، وإدارة الموارد
4. **تقييم المتعلمين** — بناء الاختبارات، وجمع الواجبات، وإجراء الاستبيانات، وإعداد دفتر الدرجات
5. **التعاون والتواصل** — تفعيل المنتديات، والدردشة، والمجموعات، والويكي، ومؤتمرات الفيديو
6. **التتبع وإعداد التقارير** — مراقبة تقدم المتعلمين وإنشاء التقارير
7. **أدوات الذكاء الاصطناعي** — استخدام الميزات المدعومة بالذكاء الاصطناعي لتوليد المحتوى والمساعدة في التصحيح
8. **أدوات إضافية** — الأجندة، والمفكرة، والمحفظة، والمزيد
