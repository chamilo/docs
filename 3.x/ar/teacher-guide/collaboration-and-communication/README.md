# التعاون والتواصل

يوفر Chamilo عدة أدوات لتمكين التفاعل بينك وبين المتعلمين، وكذلك فيما بين المتعلمين أنفسهم.

* **[المنتديات](forums.md)** — مناقشات مترابطة منظمة حسب الفئة والموضوع
* **[الدردشة](chat.md)** — مراسلة نصية فورية داخل الدورة
* **[المجموعات](groups.md)** — تقسيم المتعلمين إلى مجموعات عمل مزودة بأدوات مشتركة خاصة بها
* **[Wiki](wiki.md)** — تحرير تعاوني للمستندات
* **[المدونة](blog.md)** — تدوين مشترك داخل الدورة
* **[مؤتمرات الفيديو](video-conferencing.md)** — جلسات فيديو مباشرة باستخدام BigBlueButton أو Zoom

تتوفر هذه الأدوات من الصفحة الرئيسية للدورة. قد تكون بعضها مخفية افتراضيًا — يمكنك إظهارها من شبكة الأدوات (انظر [الصفحة الرئيسية للدورة](../creating-your-course/course-homepage.md)).
