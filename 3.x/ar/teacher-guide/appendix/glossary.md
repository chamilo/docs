# المسرد

المصطلحات الأساسية المستخدمة في هذا الدليل.

| المصطلح | التعريف |
|------|-----------|
| **Assessment** | انظر **دفتر الدرجات** أدناه |
| **Assignment** | مهمة يقدّم فيها المتعلمون ملفات أو نصًا لمراجعة المعلم وتقديره. تُعرف أيضًا باسم "منشور الطالب" أو "العمل". |
| **Auto-launch** | ميزة تفتح أداة معيّنة تلقائيًا عند دخول المتعلم إلى مقرر دراسي. |
| **Certificate** | مستند يُنشأ تلقائيًا عندما يحقق المتعلم الحد الأدنى من الدرجة المحدد في دفتر الدرجات. |
| **Course** | حاوية لمحتوى التعلّم والأدوات. يمكن أن يتضمن المقرر الدراسي مستندات وتمارين ومنتديات ومسارات تعلّم وغير ذلك. |
| **Course tutor** | دور معلم خاص بالجلسات. يدير مدرّس المقرر مقررًا دراسيًا واحدًا ضمن جلسة. كان يُسمى "course coach" في إصدارات Chamilo قبل 3.0. |
| **Disk quota** | الحد الأقصى لمساحة التخزين المخصصة لمقرر دراسي للملفات المرفوعة. |
| **Enrollment** | عملية تسجيل مستخدم في مقرر دراسي أو جلسة، مما يمنحه الوصول إلى محتواها. تُعرف أيضًا باسم "الاشتراك". |
| **Exercise** | اختبار قصير أو اختبار يحتوي على سؤال واحد أو أكثر. يُشار إليه أيضًا باسم "test" في بعض السياقات. |
| **Forum** | أداة نقاش بمحادثات مترابطة منظمة في فئات وموضوعات. |
| **Gradebook** | أداة تجمع الدرجات من التمارين والواجبات والأنشطة الأخرى في درجة موحّدة لكل متعلم. |
| **Learning path** | تسلسل منظّم لأنشطة التعلّم (مستندات، تمارين، روابط) يتبعه المتعلمون بترتيب محدد، مع إمكانية وجود متطلبات مسبقة. |
| **LTI** | Learning Tools Interoperability — معيار يتيح تضمين أدوات التعلّم الخارجية داخل Chamilo. |
| **SCORM** | Sharable Content Object Reference Model — معيار لحزم محتوى التعلّم الإلكتروني. يمكن لـ Chamilo استيراد حزم SCORM وتشغيلها ضمن مسارات التعلّم. |
| **Session** | نسخة محدودة زمنيًا لمقرر دراسي واحد أو أكثر تُسند إلى مجموعة محددة من المتعلمين. تتيح الجلسات إعادة استخدام محتوى المقرر نفسه لأفواج مختلفة. |
| **Session tutor** | دور إشرافي يتولى متابعة جميع المقررات ضمن جلسة. كان يُسمى "session coach" في إصدارات Chamilo قبل 3.0. |
| **Skill** | كفاءة يمكن ربطها بإنجازات دفتر الدرجات. عندما يحصل المتعلم على شهادة، تُعتمد المهارات المرتبطة بها. |
| **Survey** | أداة استبيان لجمع الملاحظات، بأنواع أسئلة متنوعة وخيارات إجابات مجهولة الهوية. |
| **Visibility** | إعداد يتحكم في ما إذا كانت أداة أو مستند أو نشاط مرئيًا للمتعلمين. يمكن للمعلمين دائمًا رؤية العناصر المخفية. |
