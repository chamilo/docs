# إضافة المحتوى

يغطي هذا القسم الأدوات التي تستخدمها لإضافة محتوى تعليمي إلى مقررك. يوفّر Chamilo عدة طرق لتقديم المواد إلى المتعلمين:

* **[المستندات](documents.md)** — ارفع الملفات، وأنشئ صفحات ويب، ونظّم مكتبة المحتوى الخاصة بك
* **[الروابط](links.md)** — شارك عناوين URL لموارد خارجية، منظّمة حسب الفئة
* **[مسارات التعلم](learning-paths.md)** — ابنِ تسلسلات منظمة من المحتوى مع متطلبات سابقة وتتبع للتقدم
* **[المسرد](glossary.md)** — عرّف المصطلحات الأساسية التي يمكن للمتعلمين الرجوع إليها طوال المقرر
* **[الإعلانات](announcements.md)** — أرسل رسائل وتحديثات إلى المتعلمين المسجّلين لديك
* **[المحتوى متعدد اللغات](multi-language-content.md)** — اكتب عدة نسخ لغوية لنفس المحتوى ودع كل متعلم يرى نسخته فقط

يمكن الوصول إلى كل أداة من شبكة أدوات الصفحة الرئيسية للمقرر. انقر أيقونة الأداة لفتحها.
