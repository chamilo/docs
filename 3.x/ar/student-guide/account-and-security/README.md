# الحساب والأمان

يمنح حسابك في Chamilo إمكانية الوصول إلى مقرراتك ودرجاتك وبياناتك الشخصية — لذا يستحق أن يبقى آمناً. يغطي هذا القسم ميزات حماية الحساب التي قد تواجهها بصفتك متعلماً.

* **[إعادة تعيين كلمة المرور](resetting-your-password.md)** — ما الذي تفعله إذا نسيت كلمة المرور، أو أردت تغييرها
* **[المصادقة الثنائية](two-factor-authentication.md)** — أضف طبقة حماية ثانية لحسابك، إذا كان المسؤول قد فعّلها
* **[CAPTCHA](captcha.md)** — لماذا قد يُطلب منك إثبات أنك إنسان في نماذج تسجيل الدخول أو التسجيل أو استعادة كلمة المرور

ليست كل ميزة موصوفة هنا نشطة بالضرورة على منصتك — يمكن للمسؤولين تشغيل كل منها أو إيقافها. إذا لم يظهر لك شيء موصوف في هذا القسم، فمن المرجح أنه لم يُفعَّل.
