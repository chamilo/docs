# المسرد

المصطلحات الرئيسية المستخدمة في هذا الدليل.

| المصطلح | التعريف |
|------|-----------|
| **Assessment** | انظر **Gradebook** أدناه |
| **Assignment** | مهمة تقدّم فيها ملفات أو نصاً ليراجعها المعلّم ويقيّمها. تُعرف أيضاً باسم "منشور الطالب" أو "العمل". |
| **CAPTCHA** | تحدٍّ (عادةً كتابة أحرف مشوّهة من صورة) يُستخدم للتأكد من أنك شخص حقيقي، ويظهر في بعض نماذج تسجيل الدخول والتسجيل واستعادة كلمة المرور. |
| **Catalog** | القائمة العامة للمقررات (والجلسات) التي يمكنك تصفحها، وفي بعض الحالات التسجيل الذاتي فيها. يُوصَل إليها عبر **استكشف المزيد من المقررات**. |
| **Certificate** | مستند يُنشأ تلقائياً عند تحقيقك الحد الأدنى من الدرجة المحدد في دفتر درجات المقرر. |
| **Course** | حاوية لمحتوى التعلّم والأدوات. يمكن أن يتضمن المقرر وثائق وتمارين ومنتديات ومسارات تعلّم والمزيد. |
| **Enrollment** | التسجيل في مقرر أو جلسة، مما يمنحك الوصول إلى محتواه. يُعرف أيضاً باسم "الاشتراك". |
| **Exercise** | اختبار قصير أو امتحان يحتوي على سؤال واحد أو أكثر. يُشار إليه أيضاً باسم "اختبار" في بعض السياقات. |
| **Forum** | أداة نقاش بمحادثات مترابطة منظّمة في فئات ومواضيع. |
| **Gradebook** | أداة تجمع درجاتك من التمارين والواجبات والأنشطة الأخرى في درجة موحّدة. |
| **Invitation** | رابط لمرة واحدة يرسله المعلّم إلى عنوان بريدك الإلكتروني، يتيح لك التسجيل والاشتراك تلقائياً في مقرر، حتى إذا كان التسجيل العام مغلقاً. |
| **Learning path** | تسلسل منظّم لأنشطة التعلّم (وثائق، تمارين، روابط) تتبعه بترتيب محدد، وأحياناً مع متطلبات مسبقة. |
| **Self-registration** | القدرة على إنشاء حسابك الخاص عبر نموذج تسجيل عام، إذا فعّله مسؤول المنصة. |
| **Session** | نسخة محدودة زمنياً لمقرر واحد أو أكثر تُسند إلى مجموعة محددة من المتعلمين، مثل فصل دراسي أو دفعة. |
| **Skill** | كفاءة مرتبطة بإنجازات دفتر الدرجات. الحصول على شهادة يمكن أن يصادق على المهارات المرتبطة بها. |
| **Two-factor authentication (2FA)** | خطوة تسجيل دخول إضافية تستخدم رمزاً زمنياً من تطبيق مصادقة، بالإضافة إلى كلمة المرور. |
| **Visibility** | إعداد يتحكم في ما إذا كانت أداة أو وثيقة أو نشاط تظهر للمتعلمين. يمكن للمعلّمين دائماً رؤية العناصر المخفية. |
