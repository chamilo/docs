# الواجهة الأمامية

الواجهة الأمامية في Chamilo 3.0 هي تطبيق صفحة واحدة (SPA) مبني على Vue 3 يتواصل مع الخلفية عبر REST API.

* **[مكونات Vue](vue-components.md)** — المكونات القابلة لإعادة الاستخدام في `assets/vue/components/`
* **[العروض والتوجيه](views-and-routing.md)** — عروض الصفحات في `assets/vue/views/` وإعداد Vue Router
* **[إدارة الحالة](state-management.md)** — مخازن Pinia لحالة التطبيق
* **[نظام البناء](build-system.md)** — Webpack Encore وTailwind ومسار البناء
