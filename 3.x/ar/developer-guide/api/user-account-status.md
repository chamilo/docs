# حالة حساب المستخدم

حقل `active` للمستخدم هو حالة الحساب. يقوم المسؤول بحظر حساب أو إلغاء حظره عن طريق تغييره باستخدام `PATCH /api/users/{id}`. يحل هذا محل حقل `active` في خدمة الويب `webservices/api/v2.php` للإصدار 1.11.x.

## القيم

| `active` | المعنى |
|----------|---------|
| `1` | نشط: يمكن للمستخدم تسجيل الدخول |
| `0` | غير نشط: الحساب محظور |
| `-1` | مُعطَّل تلقائيًا بواسطة المنصة |
| `-2` | محذوف (في سلة المهملات) |

يمكن لواجهة API تعيين `1` أو `0` فقط. يتم الحذف عبر `DELETE /api/users/{id}`، واستعادة حساب محذوف عبر سلة المهملات في الإدارة.

## قراءة الحالة

يُعاد `active` بواسطة `GET /api/users/{id}` وبواسطة `GET /api/users?username=...`.

```http
GET /api/users/42
Authorization: Bearer <token>
Accept: application/json
```

```json
{ "id": 42, "username": "jdupont", "active": 1 }
```

## تغيير الحالة

```http
PATCH /api/users/42
Authorization: Bearer <token>
Content-Type: application/merge-patch+json
Accept: application/json

{ "active": 0 }
```

الاستجابة هي المستخدم المحدَّث. أرسل `{ "active": 1 }` لإلغاء حظر الحساب. يمكن إرسال `active` مع حقول أخرى للمستخدم.

## الوصول

| المستدعي | المسموح |
|--------|---------|
| `ROLE_ADMIN` | أي مستخدم يجوز له تعديله، باستثناء حسابه الخاص |
| أي مستخدم آخر | غير مسموح، حتى على حسابه الخاص |

لا يُرفض إرسال القيمة الحالية أبدًا، لذا لا يُحظر عميل يعيد إرسال المستخدم بالكامل.

## الأخطاء

| الحالة | متى |
|--------|------|
| `400` | قيمة غير `0` أو `1` |
| `401` | لا توجد بيانات اعتماد أو أنها غير صالحة |
| `403` | المستدعي ليس مسؤولًا، أو يغيّر حالته الخاصة |
| `404` | المستخدم غير موجود |
