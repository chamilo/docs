# واجهة برمجة تطبيقات عضوية الصفوف والتسجيل

للتكاملات، يوفّر Chamilo نقاط نهاية لقراءة ومزامنة الأعضاء والجلسات والمقررات المرتبطة بـ**صف** قائم. الصف هو `Usergroup` من نوع *الصف العادي*؛ ولا تنطبق هذه المسارات على المجموعات الاجتماعية.

بخلاف واجهة برمجة تطبيقات طلاب الجلسة، فإن إجراءات `PUT` الثلاثة الخاصة بالصف **تستبدل القائمة المحددة بالكامل**. تُزال المعرّفات المحذوفة من تلك العلاقة. اقرأ القائمة الحالية قبل تحديثها، وتجنّب استخدام `PUT` لإضافة عضو واحد فقط ما لم تُرسل أيضًا كل من يجب أن يبقوا.

## التفويض

تتطلب جميع المسارات أدناه دور المنصة المصادق عليه `ROLE_ADMIN`. يجب أن يكون الصف المستهدف متاحًا في عنوان URL للوصول الحالي. يُرجع الصف المفقود أو الخارج عن النطاق `404`؛ ويُرجع مجموعة المستخدمين التي ليست صفًا عاديًا `409 Conflict`.

يتحقق المتحكم من وجود معرّفات المستخدمين والمقررات والجلسات المُرسلة. في تثبيت متعدد عناوين URL، تُصفّى **معرّفات المقررات والجلسات** المُرسلة وفق البوابة الحالية؛ غير أن التنفيذ الحالي **لا** يطبّق مرشح البوابة نفسه على **معرّفات المستخدمين**. يجب ألا يتعامل المكاملون مع نقطة النهاية هذه بوصفها ضمانًا لعزل المستخدمين على مستوى البوابة. راجع ملاحظات مراجعة التسليم بشأن هذا الاعتبار الأمني المعلّق.

## قراءة علاقات الصف

```http
GET /api/usergroups/31/subscriptions
Authorization: Bearer <admin-token>
```

مثال على الاستجابة:

```json
{
  "userIds": [17, 23],
  "sessionIds": [42],
  "courseIds": [8, 11]
}
```

## استبدال قائمة علاقة واحدة

| الطريقة | نقطة النهاية | خاصية الطلب |
|--------|----------|------------------|
| `PUT` | `/api/usergroups/{id}/users` | `userIds` |
| `PUT` | `/api/usergroups/{id}/sessions` | `sessionIds` |
| `PUT` | `/api/usergroups/{id}/courses` | `courseIds` |

على سبيل المثال، لتعيين قائمة الصف الكاملة:

```http
PUT /api/usergroups/31/users
Authorization: Bearer <admin-token>
Content-Type: application/json
```

```json
{ "userIds": [17, 23, 29] }
```

مثال على الاستجابة:

```json
{
  "success": true,
  "applied": [17, 23, 29],
  "ignored": []
}
```

يسرد `applied` المعرّفات المقبولة، وليس بالضرورة المعرّفات المضافة حديثًا. يحدد `ignored` المعرّفات المطلوبة التي تعذّر تطبيقها (على سبيل المثال، معرّف غير معروف أو مقرر/جلسة خارج البوابة الحالية). تُحذف القيم غير الموجبة، وتُزال التكرارات، ويُرجع JSON المشوّه أو خاصية طلب ليست مصفوفة `400`.

لاستبدال الجلسات المرتبطة بدلًا من ذلك، استدعِ `PUT /api/usergroups/31/sessions` مع `{ "sessionIds": [42, 57] }`. لاستبدال المقررات المرتبطة، استدعِ `PUT /api/usergroups/31/courses` مع `{ "courseIds": [8, 11] }`.

**مهم:** يطبّق Chamilo هذه التغييرات عبر أساليب المزامنة في `UsergroupHelper`. قد يؤدي تغيير قائمة الصف أو ارتباطات الجلسات/المقررات الخاصة به أيضًا إلى تغيير التسجيلات ذات الصلة. لا تتلاعب بجداول علاقات مجموعات المستخدمين مباشرة، وراجع أثر استبدال القوائم قبل تشغيل تكامل إنتاجي.

للاطلاع على الواجهة والمفهوم، انظر [الصفوف](../../admin-guide/sessions/classes.md). لإضافة متعلمين محددين إلى جلسة واحدة أو إزالتهم منها *دون* استبدال جميع الأعضاء، استخدم [واجهة برمجة تطبيقات تسجيل طلاب الجلسة](session-students.md).
