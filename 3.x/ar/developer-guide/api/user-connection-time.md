# وقت اتصال المستخدم

يعيد `GET /api/users/{id}/connection-time` إجمالي الوقت الذي قضاه المستخدم متصلاً بالمنصة. وهو يحل محل إجراء `get_user_total_connexion_time` في خدمة الويب `webservices/api/v2.php` للإصدار 1.11.x، ويمكن تقييده بفترة زمنية.

## الوصول

| المستدعي | مسموح |
|--------|---------|
| `ROLE_ADMIN` | أي مستخدم لعنوان URL للوصول الحالي |
| أي مستخدم مصادق عليه | وقت اتصاله الخاص فقط |
| أي شخص آخر | `403 Forbidden` |

يأخذ نقطة النهاية المعرّف الرقمي للمستخدم. للبدء من اسم مستخدم، ابحث عن المستخدم أولاً باستخدام `GET /api/users?username=...`.

## الطلب

```http
GET /api/users/42/connection-time?startDate=2026-10-01T00:00:00%2B02:00&endDate=2026-12-15T23:59:59%2B01:00
Authorization: Bearer <token>
```

| معامل الاستعلام | مطلوب | الوصف |
|-----------------|----------|-------------|
| `startDate` | لا | تاريخ ووقت بصيغة ISO 8601. تُحتسب فقط الاتصالات التي **بدأت** في هذه اللحظة أو بعدها. |
| `endDate` | لا | تاريخ ووقت بصيغة ISO 8601، وليس قبل `startDate`. تُحتسب فقط الاتصالات التي **انتهت** في هذه اللحظة أو قبلها. |

من دون أي من المعاملين، يُحتسب كل اتصال. مع `startDate` فقط، تُحتسب الاتصالات ابتداءً من ذلك التاريخ دون حد للنهاية. مع `endDate` فقط، تُحتسب الاتصالات حتى ذلك التاريخ دون حد للبداية.

لا يُحتسب الاتصال الذي يتداخل مع حد (على سبيل المثال اتصال بدأ قبل `startDate`) على الإطلاق: لا تُقسَّم أوقات الاتصال أبداً. وهذه هي القاعدة نفسها لمرشح الفترة المخصصة في تقارير الإصدار 1.11.x.

أدرج إزاحة المنطقة الزمنية. في عنوان URL، يجب ترميز `+` على هيئة `%2B`. تُقرأ القيمة التي لا تتضمن إزاحة وفق المنطقة الزمنية للخادم.

## الاستجابة

```json
{
  "id": 42,
  "username": "jdupont",
  "totalConnectionTime": 5025,
  "totalConnectionTimeFormatted": "01:23:45"
}
```

| الحقل | الوصف |
|-------|-------------|
| `totalConnectionTime` | الإجمالي بالثواني |
| `totalConnectionTimeFormatted` | الإجمالي نفسه بصيغة `HH:MM:SS`، وهي الصيغة التي كانت تعيدها خدمة الويب في الإصدار 1.11.x. يمكن أن تتجاوز الساعات 24. |

## الأخطاء

| الحالة | متى |
|--------|------|
| `400` | تاريخ يتعذر تحليله، أو `endDate` قبل `startDate` |
| `401` | بيانات اعتماد غير موجودة أو غير صالحة |
| `403` | المستدعي ليس مسؤولاً ولا المستخدم المعني |
| `404` | المستخدم غير موجود، أو لا ينتمي إلى عنوان URL للوصول الحالي |

## كيفية حساب الوقت

الإجمالي هو مجموع `logout_date − login_date` على صفوف المستخدم في جدول `track_e_login`.

يبدأ الاتصال عند تسجيل الدخول ويُمدَّد ما دام المستخدم نشطاً: ترسل الصفحة التي فتحها المستخدم إشارة حضور كل دقيقة ما دام تبويبها ظاهراً، كما كان يفعل كل عرض صفحة في Chamilo 1.11.x. بعد خمول أطول من عمر الجلسة، يفتح النشاط التالي اتصالاً جديداً، فلا يُحتسب فاصل الخمول. ويُغلق تسجيل الخروج الاتصال الحالي. لا يُضاف الوقت الذي يقضيه المسؤول باستخدام **تسجيل الدخول بصفة** إلى المستخدم.

> **ملاحظة:** قد لا يكون لاتصالات سُجّلت قبل استعادة هذا التتبع تاريخ تسجيل خروج. وتُحتسب صفراً، لذلك قد تكون الإجماليات للفترات السابقة للترقية أقل من الوقت الفعلي الذي قُضي.
