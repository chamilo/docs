# دليل المطوّر

مرحبًا بكم في دليل المطوّر لـ Chamilo 3.0. هذا الدليل موجَّه إلى المطوّرين الذين يرغبون في فهم معمارية Chamilo، وتوسيع المنصة عبر الإضافات، واستخدام الـ API، وتخصيص الواجهة، أو المساهمة في المشروع.

## نظرة سريعة على المعمارية

بُني Chamilo 3.0 على:

* **الخلفية (Backend)**: Symfony 7.4 (PHP 8.3–8.5) مع Doctrine ORM و API Platform 4
* **الواجهة الأمامية (Frontend)**: Vue 3 مع PrimeVue، وإدارة الحالة عبر Pinia، و Vue Router
* **نظام البناء**: Webpack 5 عبر Symfony Webpack Encore، مع Tailwind CSS
* **المصادقة**: رموز JWT (lexik/jwt-authentication-bundle)
* **تخزين الملفات**: Flysystem (يدعم التخزين المحلي، و AWS S3، و Azure Blob، و Google Cloud)

يُنظَّم مصدر الشيفرة في ثلاثة حزم Symfony:

| الحزمة | الغرض |
|--------|---------|
| **CoreBundle** | نواة المنصة: المستخدمون، الإعدادات، الموارد، الإدارة، مزوّدو الذكاء الاصطناعي، الأمن |
| **CourseBundle** | ميزات خاصة بالمقررات: المستندات، التمارين، مسارات التعلّم، المنتديات، وغيرها |
| **LtiBundle** | تكامل LTI 1.3 لأدوات التعلّم الخارجية |

## تنظيم هذا الدليل

1. **البدء** — المكدس التقني، إعداد بيئة التطوير، بنية المشروع
2. **الخلفية (Backend)** — معمارية Symfony، الكيانات، نظام الموارد، المتحكّمات، الإعدادات
3. **API** — REST API عبر API Platform، مصادقة JWT، الإجراءات المخصّصة
4. **الواجهة الأمامية (Frontend)** — مكوّنات Vue، العروض، التوجيه، إدارة الحالة، نظام البناء
5. **السمات (Theming)** — سمات الألوان، CSS/Tailwind، قوالب Twig
6. **الإضافات (Plugins)** — معمارية الإضافات وتطويرها
7. **المساهمة** — اصطلاحات الترميز، سير عمل git، الاختبار
