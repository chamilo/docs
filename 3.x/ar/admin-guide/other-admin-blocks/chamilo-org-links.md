# روابط Chamilo.org

كتلة **Chamilo.org** قائمة ثابتة من الروابط الصادرة إلى موارد Chamilo الرسمية — لا أكثر. لا ترسل أي بيانات إلى أي مكان؛ كل رابط يفتح إما موقعاً خارجياً لـ Chamilo أو صفحة توثيق محلية مرفقة مع تثبيتك.

## ما الذي تحتويه الكتلة

| الرابط | الوجهة |
|------|-------------|
| الصفحة الرئيسية لـ Chamilo | `chamilo.org` |
| أدلة المستخدم | `docs.chamilo.org` |
| منتدى Chamilo | GitHub Discussions لـ chamilo-lms |
| دليل التثبيت | محلي، `/documentation/installation_guide.html` |
| التغييرات في الإصدار الأخير | محلي، `/documentation/changelog.html` |
| قائمة المساهمين | محلي، `/documentation/credits.html` |
| دليل الأمان | محلي، `/documentation/security.html` |
| دليل التحسين | محلي، `/documentation/optimization.html` |
| مزودو الخدمات الرسميون لـ Chamilo | `chamilo.org/providers` |

تشير الروابط «المحلية» إلى ملفات التوثيق المرفقة مع تثبيت Chamilo نفسه، لذا تُحمَّل من خادمك أنت، وليس من chamilo.org.

## الغرض

توجد هذه الكتلة للتيسير فحسب — وصول سريع إلى التوثيق الرسمي للمشروع، ومساحة نقاش المجتمع، وقائمة مزودي الخدمات المعتمدين، دون الحاجة إلى البحث عنها.
