# الدعم الاحترافي

الدعم الاحترافي لوحة صغيرة للقراءة فقط تصف خدمات دعم Chamilo الرسمية — مفيدة إذا احتاجت منظمتك مساعدة مدفوعة تتجاوز دعم المجتمع.

## ما الذي تعرضه ومن أين تأتي

تجلب اللوحة المحتوى من `version.chamilo.org/c/support/latest.php`، وتطلبه بلغة واجهة منصتك. الشيء الوحيد الذي ترسله منصتك هو رمز تلك اللغة — لا شيء عن استخدام منصتك أو إعداداتها.

## الغرض

هذه اللوحة إعلامية وترويجية: توجّه المسؤولين نحو مزودي خدمات Chamilo الرسميين (الاستشارات، والاستضافة، والتطوير المخصص، والدعم المعتمد) للمنظمات التي تريد شريكًا متعاقدًا ومعتمدًا بدل الاعتماد فقط على منتديات المجتمع. انظر أيضًا [روابط Chamilo.org](chamilo-org-links.md)، التي تربط مباشرة بقائمة المزودين الرسميين.
