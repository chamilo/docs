# البدء

يقدّم هذا القسم واجهة إدارة Chamilo 3.0 ويساعدك على التوجّه فيها.

## من هو المسؤول؟

يضم Chamilo عدة مستويات من أدوار الإدارة:

| الدور | الصلاحيات |
|------|--------|
| **المسؤول** | وصول كامل إلى جميع ميزات الإدارة للمنصة. يُعرف أيضًا باسم **مسؤول البوابة** |
| **المسؤول العام** | مطابق لمسؤول البوابة، مع وصول عبر جميع عناوين URL للوصول في إعداد متعدد عناوين URL (متعدد المستأجرين) |
| **مسؤول الجلسات** | يمكنه إدارة الجلسات، وتسجيل المستخدمين في الجلسات، والوصول إلى الإعدادات المتعلقة بالجلسات |
| **مدير الموارد البشرية** | يمكنه عرض تقدّم المتعلمين وبيانات التتبع للمستخدمين المعيَّنين |
| **مدير الأسئلة** | أقل من كونه مسؤولًا وأكثر كونه منسّق محتوى؛ يتمتع مديرو الأسئلة بوصول إلى بنك أسئلة عام لمراجعة جودة الأسئلة |

يركّز هذا الدليل أساسًا على دور **مسؤول البوابة**، الذي يتمتع بأوسع صلاحيات الوصول.

## تسجيل الدخول

يسجّل المسؤولون الدخول عبر صفحة تسجيل الدخول نفسها التي يستخدمها جميع المستخدمين الآخرين. بعد إدخال بيانات الاعتماد، سيتم توجيهك (في غياب إعدادات أخرى) إلى صفحة **الإدارة**. ومن الفروقات البارزة عن أدوار المستخدمين الأخرى قسم **الإدارة** في الشريط الجانبي (غير ظاهر للأدوار الأخرى).
