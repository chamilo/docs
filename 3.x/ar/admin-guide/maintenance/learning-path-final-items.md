# إكمال عناصر مسار التعلّم النهائية العالقة

لا تُحتسب الخطوة الأخيرة في مسار التعلّم — صفحة «تهانينا» التي تضم كتل الشهادة والمهارة — مكتملة إلا عندما يفتحها المتعلّم فعليًا. أما المتعلّم الذي يُنهي كل الخطوات الأخرى دون النقر للوصول إلى تلك الصفحة الأخيرة فيبقى عالقًا دون 100% إلى الأبد، وبما أن أهلية شهادة الإنجاز (ومنح المهارة) مشروطة ببلوغ مسار التعلّم 100%، فإنه لا يتلقّى شهادة أو مهارة كان قد استحقها بخلاف ذلك.

```bash
php bin/console chamilo:learning-path:complete-final-items [options]
```

لكل مسار تعلّم على المنصة تكون خطوته الأخيرة من النوع **Final item**، يتحقق الأمر من كل متعلّم لديه محاولة قيد التقدّم (أقل من 100%) وقد أكمل كل الخطوات الأخرى — عبر كل مقرر وكل جلسة تعيد استخدام مسار التعلّم. وإذا انطبق ذلك، يُكمل العنصر النهائي نيابةً عنه تمامًا كما لو أنه فتحه بنفسه: يسجّل عرض العنصر نفسه، ويُجري إعادة حساب التقدّم نفسها، ويُطلق توليد الشهادة ومنح المهارة نفسيهما اللذين كانت ستُطلقهما زيارة حقيقية.

ومثل `chamilo:gradebook:process-achievement-certificates` (انظر
[شهادات الإنجاز](achievement-certificates.md))، يعمل على دفعات محدودة، ويدعم التشغيل التجريبي، ويمكن استئنافه بأمان إذا انقطع — فالمتعلّم الذي اكتمل عنصره النهائي أصلًا لا يُمس مرة أخرى في تشغيل لاحق.

## الخيارات

| Option                 | Purpose                                                                                                            |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------- |
| `--dry-run`             | التقييم والإبلاغ دون إكمال أي شيء. شغّل هذا الخيار أولًا دائمًا.                                           |
| `--sender-id=<id>`      | معرّف مسؤول المنصة النشط، ويُستخدم بوصفه منشئ المورد عندما يؤدي إكمال عنصر نهائي إلى توليد شهادة أو منح مهارة. مطلوب للتنفيذ الحقيقي (غير التجريبي). |
| `--limit=<n>`           | الحد الأقصى للعناصر النهائية المكتملة (أو المُبلَّغ عنها في التشغيل التجريبي) في تشغيل واحد. `0` = بلا حد. الافتراضي `500`.              |
| `--scan-limit=<n>`      | الحد الأقصى لسجلات تقدّم المتعلّمين التي تُمسح في تشغيل واحد، عبر كل مسارات التعلّم. `0` = بلا حد. الافتراضي `5000`. |
| `--batch-size=<n>`      | سجلات تقدّم المتعلّمين المحمّلة في كل دفعة قاعدة بيانات، ضمن مسار تعلّم واحد. الافتراضي `50`.                       |
| `--lp-batch-size=<n>`   | مسارات التعلّم المحمّلة في كل دفعة قاعدة بيانات. الافتراضي `50`.                                                            |
| `--after-lp-id=<id>`    | استئناف المسح بعد معرّف مسار التعلّم هذا.                                                                       |

## أمثلة

شغّل أولًا تشغيلًا تجريبيًا للمنصة بأكملها، لمعرفة من سيُكمَل:

```bash
php bin/console chamilo:learning-path:complete-final-items --dry-run
```

تشغيل حقيقي، مع المسؤول ذي المعرّف 1 بوصفه منشئ المورد:

```bash
php bin/console chamilo:learning-path:complete-final-items --sender-id=1
```

استئناف تشغيل منقطع بعد مسار التعلّم 480:

```bash
php bin/console chamilo:learning-path:complete-final-items --sender-id=1 --after-lp-id=480
```

## رموز الخروج

يخرج الأمر بحالة فشل إذا فشل فعليًا إكمال عنصر نهائي واحد على الأقل
أثناء تشغيل حقيقي — ويسمّي جدول الملخص مسار التعلّم والمتعلّم والسبب؛ ويحتوي
سجل التطبيق على الاستثناء الكامل. أما استبعاد متعلّم استبعادًا صحيحًا (لأن العنصر النهائي مكتمل أصلًا، أو
لأن خطوة أخرى ما زالت غير مكتملة) فليس خطأً ولا يتسبب أبدًا في رمز خروج يدل على الفشل.

## درجة دفتر العلامات بعد الإكمال

الدرجة المعروضة لمسار التعلّم في جدول دفتر العلامات لا تُخزَّن أبدًا — بل تُحسب مباشرة
من تقدّم المتعلّم الحالي في كل مرة تُحمَّل فيها الصفحة، لذا تعكس 100% فورًا،
من دون أي خطوة إضافية.

أما **شهادة** المتعلّم، إذا كانت موجودة أصلًا قبل بلوغه 100% (مع درجة أقدم وأدنى
مدمجة فيها)، فلا تُحدَّث درجتها المخزّنة وHTML المعروض إلا إذا نجح إعادة توليد الشهادة
نفسه عندما يُكمل هذا الأمر عنصره النهائي — وهو الاستدعاء نفسه الذي كانت ستُطلقه
زيارة فعلية. وإذا فشل توليد الشهادة لأي سبب (انظر
[شهادات الإنجاز](achievement-certificates.md) للأسباب الشائعة، مثل أذونات تخزين
الملفات)، فإن تقدّم المتعلّم يبلغ 100% بشكل صحيح ويظل جدول دفتر العلامات
يعرض ذلك — وتبقى شهادته وحدها تعرض الدرجة القديمة، وبما أن الأمر لا
يعيد زيارة متعلّم بلغ 100% أصلًا، فلن يعيد المحاولة في تشغيل لاحق. أعد توليد تلك الشهادة
يدويًا (إجراء **Generate** في قائمة الشهادات) بعد إصلاح المشكلة الأساسية.

يوجد `--sender-id` تحديدًا لتجنّب سبب شائع لذلك الفشل: فإكمال عنصر
نهائي خارج طلب حقيقي لا يوفّر مستخدمًا مسجّل الدخول لتسجيله بوصفه
منشئ مورد الشهادة، ويفشل التوليد تمامًا من دونه.
