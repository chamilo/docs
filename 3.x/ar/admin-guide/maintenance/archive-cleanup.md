# تنظيف الأرشيف

مع مرور الوقت، تتراكم في Chamilo ملفات مؤقتة في دليلي الذاكرة المؤقتة والأرشيف. يمنع التنظيف المنتظم مشكلات مساحة القرص.

## ما يمكن تنظيفه

* **ملفات الرفع المؤقتة** — ملفات تُنشأ أثناء التصدير والاستيراد والعمليات الأخرى، بالإضافة إلى ملفات بناء الواجهة الأمامية القديمة الراكدة
* **ذاكرة Symfony المؤقتة للتطبيق** — الحاوية المُجمَّعة، والإعدادات المخزَّنة مؤقتًا، وبيانات التوجيه. هذا *غير* مشمول بإجراء لوحة الإدارة أدناه — انظر [من سطر الأوامر](#from-the-command-line).
* **بيانات الجلسات** — ملفات جلسات PHP المنتهية الصلاحية
* **ملفات السجلات** — ملفات السجلات القديمة التي لم تعد مطلوبة

## تنفيذ التنظيف

### من لوحة الإدارة

انتقل إلى **النظام > تنظيف الملفات المؤقتة** في لوحة الإدارة (انظر [أدوات النظام](../system/system-tools.md#clean-temporary-files)). يعرض التقرير عدد الملفات المؤقتة الموجودة ومقدار المساحة التي تستخدمها، ثم يتيح لك حذف الكل أو الملفات الأقدم من عمر محدد فقط، مع معاينة تشغيل تجريبي. كما يمسح ملفات البناء القديمة الراكدة ويعيد توليد أصول CSS المُجمَّعة.

يستثني هذا الإجراء عمدًا أدلة الذاكرة المؤقتة الخاصة بـ Symfony (`var/cache/dev` و`var/cache/prod` و`var/cache/test` ومجمعات الذاكرة المؤقتة)، لذا لن يجعل تغييرًا في `.env` أو `config/` ساري المفعول — استخدم سطر الأوامر لذلك.

### من سطر الأوامر

لمزيد من التحكم، ولمسح ذاكرة Symfony المؤقتة للتطبيق فعليًا، استخدم أوامر وحدة تحكم Symfony:

```bash
# Clear the Symfony cache
php bin/console cache:clear

# Clear only the production cache
php bin/console cache:clear --env=prod
```

## نصائح

* **جدولة عمليات تنظيف منتظمة** — أعد مهمة cron أسبوعية أو شهرية لمسح الملفات المؤقتة
* **مراقبة استخدام القرص** — راقب حجم الدليل `var/`، إذ ينمو مع ملفات الذاكرة المؤقتة والسجلات
* **الحذر مع السجلات** — قبل حذف ملفات السجلات، تحقق مما إذا كانت تحتوي على معلومات قد تحتاجها لاستكشاف الأخطاء وإصلاحها
