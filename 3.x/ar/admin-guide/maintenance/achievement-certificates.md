# شهادات الإنجاز (التوليد على دفعات)

يمكن لـ Chamilo توليد شهادة إنجاز المقرر تلقائيًا لكل طالب أكمله — داخل المقرر الأساسي وداخل أي جلسة تعيد استخدامه — دون أن يضطر المعلّم إلى فتح كل مقرر على حدة. يغطي هذا الأمران في وحدة التحكم: أحدهما لمقرر واحد والآخر للمنصة بأكملها، وليس أي منهما عملية ثقيلة على قاعدة البيانات تحتاج إلى متابعة مستمرة: يعمل كلاهما على دفعات محدودة، ويدعمان التشغيل التجريبي، ويمكن استئنافهما بأمان إذا انقطعا.

## أمر على مستوى المنصة

```bash
php bin/console chamilo:gradebook:process-achievement-certificates [options]
```

لكل مقرر يمتلك فئة دفتر درجات جذرية مؤهلة — من المستوى الأعلى، وليست فئة فرعية، مع تفعيل **Generate certificates** — يقيّم الأمر كل طالب مسجّل لا يملك بالفعل شهادة لتلك الفئة، ويولّد شهادة لكل من استوفى شرط الإكمال. يمكن للمقرر أن يساهم بـ **أكثر من سياق واحد**: تسجيله الأساسي، وبشكل منفصل، سياق واحد لكل جلسة تعيد استخدامه، لأن الجلسة يمكن أن تمتلك فئة جذرية خاصة بها وعتبة نجاح خاصة بها.

يُتخطى المقرر، أو أحد سياقات جلساته — ولا يُعامل كخطأ — عندما لا يكون مؤهلًا للمعالجة الآلية: لا توجد قاعدة إكمال مُعدّة، أو يوجد أكثر من فئة جذرية مؤهلة لذلك السياق (حالة غامضة تحتاج إلى اختيار يدوي)، أو محتوى إشعار الشهادة مفقود. يلخّص ملخص التشغيل في النهاية عدد السياقات التي وقعت في كل حالة، فلا يُتخطى شيء دون أن يُعرض.

### مصدر الإكمال

* `--completion-mode=course-rule` (الافتراضي): يستخدم قاعدة الإكمال المُعدّة للمقرر.
* `--completion-mode=gradebook`: يستخدم درجة دفتر الدرجات الأصلية مباشرة لذلك السياق بدلًا من ذلك.
  لا يتأهل في هذا الوضع إلا سياق يمتلك فئة جذرية مؤهلة واحدة بالضبط — أما السياق الذي يمتلك عدة فئات فيُتخطى ويُبلَّغ عنه، لمعالجته بشكل فردي بدلًا من ذلك (انظر أدناه).

### خيارات الأمان

| الخيار                     | الغرض                                                                                                                                 |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `--dry-run`                 | التقييم والإبلاغ دون إنشاء شهادات أو إرسال إشعارات. شغّل هذا دائمًا أولًا.                                      |
| `--send-notification`       | مطلوب للتنفيذ الفعلي (غير التجريبي). يرسل الرسالة الداخلية والبريد الإلكتروني المُعدَّين للمقرر بعد إنشاء كل شهادة. |
| `--sender-id=<id>`          | مسؤول المنصة النشط المستخدم بوصفه مُرسِل الإشعار. مطلوب مع `--send-notification`.                            |
| `--limit=<n>`                | الحد الأقصى للشهادات المُولَّدة (أو، في التشغيل التجريبي، المُبلَّغ عنها) في تشغيل واحد. `0` = غير محدود. الافتراضي `100`.                                    |
| `--scan-limit=<n>`           | الحد الأقصى للطلاب المُقيَّمين في تشغيل واحد، عبر كل المقررات والجلسات. `0` = غير محدود. الافتراضي `1000`.                                 |
| `--batch-size=<n>`           | الطلاب المحمَّلون لكل دفعة من قاعدة البيانات ضمن سياق مقرر/جلسة واحد. الافتراضي `25`.                                                     |
| `--course-batch-size=<n>`    | المقررات المحمَّلة لكل دفعة من قاعدة البيانات. الافتراضي `50`.                                                                                         |
| `--after-course-id=<id>`     | استئناف المسح بعد معرّف المقرر هذا. آمن لإعادة الاستخدام بعد تشغيل منقطع — لا يعيد المقرر أبدًا توليد شهادة لطالب يملك واحدة بالفعل. |
| `--user-id=<id>`             | تقييد التشغيل بطالب واحد، يُفحص عبر كل مقرر وجلسة مؤهلين — مفيد للتحقق من السلوك قبل تشغيل على مستوى المنصة. |
| `--regenerate-empty`         | معالجة الطلاب الذين يوجد سجل شهادتهم لكن دون ملف شهادة مخزَّن — على سبيل المثال بعد توليد فشل في منتصفه — وتوليد تلك الشهادة مرة أخرى. لا يُمس الطلاب الذين لديهم شهادة مكتملة أبدًا. |

### أمثلة

نفّذ أولاً تشغيلاً تجريبياً (dry-run) على المنصة بأكملها، لمعرفة ما سيُولَّد:

```bash
php bin/console chamilo:gradebook:process-achievement-certificates --dry-run
```

تشغيل فعلي، مع إشعار الطلاب، والمسؤول ذو المعرّف 1 بوصفه المُرسِل:

```bash
php bin/console chamilo:gradebook:process-achievement-certificates \
  --send-notification --sender-id=1
```

استئناف تشغيل متوقف بعد المقرر 480:

```bash
php bin/console chamilo:gradebook:process-achievement-certificates \
  --send-notification --sender-id=1 --after-course-id=480
```

إعادة توليد الشهادات التي يوجد سجلّها لكن لم يُخزَّن ملفها قط (نفّذ أولاً تشغيلاً تجريبياً
لسردها):

```bash
php bin/console chamilo:gradebook:process-achievement-certificates \
  --regenerate-empty --dry-run
php bin/console chamilo:gradebook:process-achievement-certificates \
  --regenerate-empty --send-notification --sender-id=1
```

### الجدولة كمهمة cron

```cron
# Every night at 2 AM
0 2 * * * php /path/to/chamilo/bin/console chamilo:gradebook:process-achievement-certificates --send-notification --sender-id=1 -e prod --no-interaction >> /path/to/chamilo/var/log/achievement-certificates.log 2>&1
```

## معالجة مقرر واحد على حدة

يوفّر الأمر `chamilo:migration:process-achievement-certificates --course-id=<id>` خيارات التشغيل التجريبي نفسها،
وخيارات الإشعار والترقيم على صفحات، مثل الأمر على مستوى المنصة، مع اقتصار النطاق على المقرر الأساسي فقط
(وليس جلساته)، ومع خيار صريح `--category-id` لإزالة الالتباس عندما يكون للمقرر أكثر من
فئة جذر مؤهلة واحدة:

```bash
php bin/console chamilo:migration:process-achievement-certificates \
  --course-id=42 --category-id=7 --dry-run
```

استخدمه لاختبار مقرر واحد قبل تشغيل على مستوى المنصة، أو لمعالجة مقرر أبلغ التشغيل على مستوى المنصة
أنه تُخطّي بسبب فئة ملتبسة.

## رموز الخروج

يخرج كلا الأمرين بحالة فشل إذا فشل فعلياً توليد شهادة واحدة على الأقل
أثناء تشغيل حقيقي (راجع `var/log/dev.log` — أو سجل الإنتاج المكافئ — لمعرفة الخطأ
الأساسي). السياقات التي تُخطّى لأسباب بنيوية (عدم وجود قاعدة، أو فئة ملتبسة، أو نقص في إعداد
الإشعارات) لا تتسبب في رمز خروج يدل على الفشل؛ بل تُذكر في الملخص بدلاً من ذلك.

## ذو صلة: متعلمون عالقون دون 100% في مسار تعلّم متطلب سابق

إذا كانت قاعدة إكمال مقرر ما تشترط أن يبلغ مسار التعلّم 100%، فإن المتعلم الذي أنهى كل
خطوة لكنه لم يفتح قط صفحة «تهانينا» النهائية في المسار يبقى عالقاً دون 100% بقليل ولا يصبح
مؤهلاً هنا أبداً. راجع
[إكمال العناصر النهائية العالقة في مسار التعلّم](learning-path-final-items.md) — نفّذه أولاً إذا
كان الطلاب يفتقدون شهادات تتوقع أنهم استحقوها.

## مستبدل: سكربت cron القديم

لم يعد يُوصى باستخدام `public/main/cron/add_gradebook_certificates.php`. فهو يحمّل كل
نتيجة من دفتر الدرجات على المنصة إلى الذاكرة في استعلام واحد غير محدود ولا يحررها أبداً
أثناء الحلقة، لذا قد يستنفد الذاكرة في نسخة تضم عدداً غير هيّن من المقررات أو
التمارين، ولا يرسل أبداً إشعار «لقد حصلت على شهادة». استخدم بدلاً منه
`chamilo:gradebook:process-achievement-certificates`.
