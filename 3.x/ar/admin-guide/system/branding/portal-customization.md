# تخصيص البوابة

خصّص مظهر منصة Chamilo الخاصة بك والمعلومات المعروضة للمستخدمين.

## هوية المنصة

![صفحة تخصيص البوابة تعرض إعدادات هوية المنصة للاسم والشعار والمؤسسة](../../../.gitbook/assets/admin-portal-customization.png)

قم بتكوين الهوية الأساسية لبوابتك:

* **اسم المنصة** — الاسم المعروض في عنوان المتصفح وفي جميع أنحاء الواجهة
* **اسم المؤسسة** — اسم منظمتك
* **عنوان URL للمؤسسة** — رابط إلى موقع منظمتك الإلكتروني
* **شعار المنصة** — ارفع شعار منظمتك (يُعرض في الشريط العلوي)

## نصائح

* **حافظ على الصفحة الرئيسية نظيفة** — قد يكون المحتوى الزائد في الصفحة الرئيسية مربكًا. ركّز على الإعلانات الأساسية والوصول إلى المقررات.
* **حدّث بانتظام** — أبقِ إعلانات النظام محدّثة وأزل الإعلانات القديمة
* **ارفع شعارًا عالي الجودة** — الشعار أحد أبرز عناصر الهوية البصرية. استخدم صورة واضحة بالحجم المناسب.
