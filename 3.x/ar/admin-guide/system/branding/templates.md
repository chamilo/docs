# القوالب

يستخدم Chamilo قوالب للشهادات والمستندات ورسائل البريد الإلكتروني. يمكنك تخصيص هذه القوالب لتتوافق مع هوية مؤسستك ومتطلباتها.

## قوالب الشهادات

تحدد قوالب الشهادات تخطيط ومحتوى الشهادات الممنوحة للمتعلمين الذين يستوفون عتبات دفتر الدرجات.

### تخصيص قالب شهادة

تستخدم قوالب الشهادات HTML و CSS مع متغيرات نائبة:

| المتغير | يُستبدل بـ |
|----------|-------------|
| Student name | الاسم الكامل للمتعلم |
| Course name | اسم المقرر |
| Date | تاريخ الحصول على الشهادة |
| Score | الدرجة النهائية للمتعلم |
| Barcode | عنصر نائب للرمز الشريطي (`((certificate_barcode))`) يُستخدم للتحقق |

### رفع قالب

1. انتقل إلى إدارة قوالب الشهادات
2. ارفع قالب HTML أو حرّره
3. استخدم المتغيرات النائبة حيث ينبغي أن يظهر المحتوى الديناميكي
4. احفظ

## قوالب المستندات

يمكن للمعلمين استخدام قوالب المستندات عند إنشاء المحتوى في أداة المستندات. توفر القوالب تخطيطًا ابتدائيًا لأنواع المستندات الشائعة.

### إدارة قوالب المستندات

1. انتقل إلى إدارة القوالب في لوحة الإدارة
2. أضف قوالب جديدة برفع ملفات HTML
3. تصبح القوالب متاحة للمعلمين عند إنشاء مستندات جديدة

## نصائح

* **ضمّن شعارك** — أضف شعار مؤسستك إلى قوالب الشهادات لإضفاء مظهر احترافي
* **اختبر ببيانات حقيقية** — عاين الشهادات ببيانات متعلمين فعلية قبل نشر القالب
* **حافظ على بساطة القوالب** — التصاميم البسيطة تطبع بشكل أفضل وتبدو احترافية
