# النظام

تجمع كتلة **النظام** في لوحة تحكم الإدارة أدوات الصيانة على مستوى الخادم، وسير عمل التحديث الذاتي، وأدوات فحص التخزين/الموارد، وعلامة المنصة التجارية.

![كتلة النظام في لوحة تحكم الإدارة، وتسرد تنظيف الملفات المؤقتة، وحالة النظام، وتحديث النظام، والألوان، ومعلومات الملفات، والموارد حسب النوع، وقائمة الأيقونات](/.gitbook/assets/admin-system-block.png)

## الوصول إلى كتلة النظام

من لوحة الإدارة، تظهر كتلة **النظام** إلى جانب كتل لوحة التحكم الأخرى. انقر أيًا من روابطها لفتح الأداة المقابلة.

## ما الذي تتضمنه الكتلة

* **[أدوات النظام](system-tools.md)** — تنظيف الملفات المؤقتة، وتشغيل سير عمل التحديث الذاتي، وفحص الملفات والموارد المخزّنة، وتصفح مجموعة الأيقونات المضمّنة
* **حالة النظام** — مغطاة في [حالة النظام](../maintenance/system-status.md)، ضمن الصيانة
* **[العلامة التجارية](branding/README.md)** — سمات الألوان (يفتح رابط "الألوان" في الكتلة صفحة سمات الألوان نفسها)، وتخصيص البوابة، والقوالب

عنصران إضافيان — **Data filler** و**E-mail tester** — يظهران فقط عندما يحتوي الخادم على مجلد `tests/`، وهو إعداد تطوير/ضمان جودة وليس إعداد إنتاج. لن يظهرا في تثبيت إنتاج نموذجي؛ انظر [أدوات النظام](system-tools.md#development-only-tools) لمعرفة ما يفعلانه عند وجودهما.
