# فئات الجلسات

تساعد فئات الجلسات على تنظيم جلساتك، خاصة عندما يكون لديك العديد من الجلسات قيد التشغيل في الوقت نفسه.

## إنشاء فئة

1. من لوحة الإدارة، انتقل إلى **فئات الجلسات**
2. انقر **إضافة فئة**
3. أدخل **اسماً** وتواريخ بداية/نهاية اختيارية
4. احفظ

## حالات الاستخدام

* **حسب البرنامج** — "Leadership Development"، "Technical Training"، "Onboarding"
* **حسب الفترة** — "Q1 2026"، "Spring Semester"، "July Batch"
* **حسب القسم** — "Engineering"، "Sales"، "Human Resources"

## إدارة الفئات

* **تعديل** — تغيير اسم الفئة أو التواريخ
* **تعيين الجلسات** — عند إنشاء جلسة أو تعديلها، حدد فئتها
* **حذف** — إزالة فئة (تصبح الجلسات الموجودة في الفئة غير مصنفة)
