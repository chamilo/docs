# المسرد

المصطلحات الأساسية المستخدمة في إدارة Chamilo 3.0.

## مفاهيم المنصة

| المصطلح | التعريف |
|------|------------|
| **Access URL** | في إعداد متعدد عناوين URL، يُعد كل عنوان وصول بوابة افتراضية منفصلة تشترك في نفس تثبيت Chamilo وقاعدة البيانات. يمكن أن يكون لكل عنوان علامته التجارية ومستخدموه ودوراته وإعداداته الخاصة. |
| **Course** | الحاوية الأساسية للمحتوى في Chamilo. تحتوي الدورة على مواد التعلم والتمارين والمنتديات وأدوات أخرى. يمكن أن توجد الدورات بشكل مستقل أو تُسند إلى جلسات. |
| **Session** | نسخة محدودة زمنيًا من دورة واحدة أو أكثر. تتيح الجلسات تقديم نفس محتوى الدورة لمجموعات مختلفة من المتعلمين مع تتبّع منفصل ومدرّبين مستقلين. |
| **Learning path** | تسلسل منظّم لعناصر المحتوى (مستندات، تمارين، روابط، وحدات SCORM) يوجّه المتعلمين عبر المادة بترتيب محدد. |
| **Gradebook** | أداة تجميع تجمع الدرجات من التمارين والواجبات والأنشطة الأخرى في درجة نهائية مرجّحة للدورة. |
| **Skill** | كفاءة أو شارة يمكن منحها للمتعلمين عند إكمال دورات أو تمارين محددة أو بلوغ عتبات دفتر الدرجات. |
| **Extra field** | حقل بيانات مخصص يضيفه المسؤولون إلى المستخدمين أو الدورات أو الجلسات لالتقاط بيانات وصفية خاصة بالمؤسسة. |
| **Plugin** | إضافة توسّع وظائف Chamilo دون تعديل الشيفرة الأساسية. يمكن للإضافات أن تضيف صفحات أو أدوات أو تكاملات. |
| **Catalog** | قائمة قابلة للتصفح بالدورات المتاحة حيث يمكن للمستخدمين عرض الأوصاف والتسجيل الذاتي. |

## أدوار المستخدمين

| المصطلح | التعريف |
|------|------------|
| **Learner (Student)** | الدور الافتراضي للمستخدم. يمكنه التسجيل في الدورات واستهلاك المحتوى. |
| **Teacher (Trainer)** | يمكنه إنشاء الدورات وإدارتها وإضافة المحتوى وتقييم المتعلمين. |
| **Session administrator** | يمكنه إنشاء الجلسات والتسجيلات وإدارتها. |
| **Human Resources Manager (HRM)** | يمكنه عرض بيانات التتبّع والتقارير للمستخدمين المعيَّنين. |
| **Portal administrator** | وصول كامل إلى جميع ميزات إدارة المنصة. |
| **Global administrator** | مسؤول بوابة يتمتع بالوصول عبر جميع عناوين الوصول في إعداد متعدد عناوين URL. |
| **Tutor** | دور على مستوى الجلسة. يشرف مدرّبو الجلسة على جميع الدورات في الجلسة؛ ويدير مدرّبو الدورة دورة محددة داخل الجلسة. كان يُسمّى "coach" في إصدارات Chamilo قبل 3.0. |

## المعايير والبروتوكولات

| المصطلح | التعريف |
|------|------------|
| **SCORM** | Sharable Content Object Reference Model. معيار تغليف للتعلم الإلكتروني يتيح استيراد الدورات وتتبعها. يدعم Chamilo الإصدارين SCORM 1.2 و2004. |
| **xAPI (Tin Can API)** | مواصفة للتعلم الإلكتروني لتتبع تجارب التعلم. أوسع من SCORM، ويمكنها تسجيل أنشطة تحدث خارج نظام إدارة التعلم. تُخزَّن عبارات xAPI في مخزن سجلات التعلم (LRS). |
| **LTI** | Learning Tools Interoperability. معيار من IMS Global يتيح تضمين أدوات ومحتوى خارجيين داخل نظام إدارة التعلم. يدعم Chamilo الإصدارين LTI 1.1 و1.3 كمستهلك وكمزوّد. |
| **SCIM** | System for Cross-domain Identity Management. معيار لأتمتة توفير المستخدمين وإلغائه بين مزوّدي الهوية والتطبيقات. |
| **OAuth2** | إطار تفويض يتيح لتطبيقات الطرف الثالث الوصول إلى Chamilo نيابة عن المستخدم دون مشاركة كلمات المرور. يُستخدم للوصول إلى API وتكاملات تسجيل الدخول الموحد. |
| **LDAP** | Lightweight Directory Access Protocol. بروتوكول للوصول إلى خدمات الدليل (مثل Active Directory) لمصادقة المستخدمين ومزامنة بيانات الحسابات. |
| **CAS** | Central Authentication Service. بروتوكول تسجيل دخول موحد يتيح للمستخدمين المصادقة مرة واحدة والوصول إلى تطبيقات متعددة. |
| **JWT** | JSON Web Token. تنسيق رمز مضغوط وموقَّع يُستخدم لمصادقة API وإدارة الجلسات. |
| **SAML** | Security Assertion Markup Language. معيار قائم على XML لتبادل بيانات المصادقة بين مزوّد هوية ومزوّد خدمة. |

## المصطلحات التقنية

| المصطلح | التعريف |
|------|------------|
| **Symfony** | إطار عمل PHP الذي بُني عليه Chamilo 3.0. يوفّر Symfony التوجيه، وحقن التبعيات، وORM (Doctrine)، والقوالب (Twig)، وبُنى تحتية أخرى. |
| **Doctrine** | مُخطِّط الكائنات العلائقي (ORM) الذي يستخدمه Chamilo للتفاعل مع قاعدة البيانات. يربط Doctrine كائنات PHP بجداول قاعدة البيانات. |
| **Twig** | محرك القوالب الذي يستخدمه Symfony وChamilo لعرض HTML. |
| **Flysystem** | طبقة تجريد لنظام الملفات في PHP. يستخدم Chamilo Flysystem لدعم التخزين المحلي، وAmazon S3، وAzure Blob، وGoogle Cloud Storage بشكل قابل للتبادل. |
| **Composer** | مدير تبعيات PHP. يُستخدم لتثبيت مكتبات PHP الخاصة بـ Chamilo وتحديثها. |
| **Mailer DSN** | اسم مصدر البيانات لنقل البريد الإلكتروني. سلسلة اتصال تُخبر Symfony بكيفية إرسال الرسائل (مثلاً عبر SMTP أو Amazon SES أو Mailjet). |
| **OPcache** | ذاكرة التخزين المؤقت المدمجة لشيفرة التشغيل في PHP. تُجمّع سكربتات PHP إلى بايت كود وتخزّنها في الذاكرة، مما يحسّن الأداء بشكل كبير. |
| **APCu** | امتداد PHP يوفّر ذاكرة تخزين مؤقت على مستوى المستخدم في الذاكرة. يستخدمه Symfony لتخزين البيانات الوصفية والإعدادات مؤقتاً. |

## الاختصارات

| الاختصار | الصيغة الكاملة |
|---------|-----------|
| **LMS** | نظام إدارة التعلم (Learning Management System) |
| **LRS** | مخزن سجلات التعلم (لبيانات xAPI) |
| **SSO** | تسجيل الدخول الموحّد (Single Sign-On) |
| **CSV** | قيم مفصولة بفواصل (تُستخدم لاستيراد المستخدمين/المقررات) |
| **API** | واجهة برمجة التطبيقات (Application Programming Interface) |
| **REST** | نقل الحالة التمثيلية (أسلوب معمارية API) |
| **GDPR** | اللائحة العامة لحماية البيانات (قانون خصوصية البيانات في الاتحاد الأوروبي) |
| **HSTS** | أمان النقل الصارم عبر HTTP |
| **CDN** | شبكة توصيل المحتوى |
| **DNS** | نظام أسماء النطاقات |
| **SPF** | إطار سياسة المُرسِل (مصادقة البريد الإلكتروني) |
| **DKIM** | البريد المعرَّف بمفاتيح النطاق (مصادقة البريد الإلكتروني) |
| **DMARC** | المصادقة والإبلاغ والتوافق المستندة إلى النطاق للرسائل |
