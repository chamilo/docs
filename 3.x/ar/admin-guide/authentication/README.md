# المصادقة

يدعم Chamilo طرائق مصادقة متعددة، بدءًا من نظام اسم المستخدم/كلمة المرور المدمج وصولًا إلى حلول تسجيل الدخول الموحّد للمؤسسات.

## ملف الإعداد

تُضبط جميع طرائق المصادقة الخارجية في `config/authentication.yaml`. ويُوفَّر قالب في `config/authentication.dist.yaml`. الهيكل العام هو:

```yaml
parameters:
  authentication:
    <access_url_id>:
      <auth_method>:
        <provider_name>:
          <config_key>: <value>
```

بعد تحرير الملف، امسح الذاكرة المؤقتة ثم جهّزها:

```bash
php bin/console cache:clear
php bin/console cache:warmup
```

تظهر أزرار تسجيل الدخول الخارجية في صفحة تسجيل الدخول بعد تحديث الذاكرة المؤقتة.

## الطرائق المدعومة

* **[OAuth2](oauth2.md)** — Azure AD وKeycloak وFacebook ومزوّدو OAuth2 العامّون
* **[Azure Entra ID](azure-entra-id.md)** — إعداد مفصّل لـ Azure/Entra ID: تسجيل التطبيق، وتعيين الأدوار حسب المجموعات، والمصادقة بالشهادات، وأوامر مزامنة المستخدمين/المجموعات
* **[LDAP](ldap.md)** — المصادقة مقابل خادم LDAP أو Active Directory
* **[CAS](cas.md)** — خدمة المصادقة المركزية (قديمة، غير فعّالة في 3.x)
* **[SCIM](scim.md)** — توفير المستخدمين آليًا من مزوّدي الهوية الخارجيين
* **[إعداد SSO](sso-configuration.md)** — استكشاف الأخطاء والملاحظات المشتركة بين الطرائق

## المصادقة الافتراضية

يستخدم Chamilo افتراضيًا نظامه الداخلي — يسجّل المستخدمون الدخول باسم مستخدم وكلمة مرور مخزَّنين في قاعدة بيانات Chamilo. الطرائق الخارجية إضافية: يبقى نموذج تسجيل الدخول القياسي متاحًا إلى جانب أي مزوّدين مُعدّين.

## مرجع إضافي
