# المنصة

تجمع كتلة **إدارة المنصة** في لوحة تحكم الإدارة أدوات الإعداد والتواصل على مستوى البوابة بالكامل — من لوحة الإعدادات الكاملة إلى اللغات، والإعلانات العامة، والتقويم العام، ونظام الصفحات الشبيه بنظام إدارة المحتوى الذي يبني أجزاء المحتوى العام لبوابتك.

![كتلة إدارة المنصة في لوحة تحكم الإدارة، وتسرد إعدادات التكوين، واللغات، والإضافات، والمناطق، وأخبار البوابة، والأجندة العامة، والصفحات، وتعيين صفحة التسجيل، والحقول الإضافية، وتكوين عناوين URL متعددة للوصول، وقوالب البريد، والأدوات الخارجية (LTI)، وفئات نموذج الاتصال، وقوالب النظام](/.gitbook/assets/admin-platform-block.png)

## الوصول إلى كتلة المنصة

من لوحة الإدارة، تظهر كتلة **إدارة المنصة** إلى جانب كتل لوحة التحكم الأخرى. انقر أيًا من روابطها لفتح الأداة المقابلة.

## ما الذي تتضمنه الكتلة

* **[إعدادات المنصة](../platform-settings/README.md)** — لوحة إعدادات التكوين الكاملة (البوابة، والدورات، والجلسات، والمستخدمون، والأمان، والمزيد). رابط «إعدادات التكوين» في هذه الكتلة هو ببساطة نقطة الدخول إلى ذلك الفصل المنفصل.
* **[اللغات](languages.md)** — اختر لغات الواجهة المتاحة للمستخدمين، وعيّن اللغة الافتراضية للمنصة
* **[أخبار البوابة](portal-news.md)** — إعلانات على مستوى المنصة (إعلانات النظام)، مجدولة ومستهدفة حسب الدور
* **[الأجندة العامة](global-agenda.md)** — أحداث تقويم على مستوى المنصة، مرئية لكل مستخدم بغض النظر عن الدورة أو الجلسة
* **[الصفحات](pages.md)** — الأداة الشبيهة بنظام إدارة المحتوى وراء الصفحة الرئيسية للبوابة، والتذييل، وكتل المحتوى العام الأخرى، بما في ذلك النص التمهيدي لصفحة التسجيل
* **[أدوات المنصة](platform-tools.md)** — الحقول الإضافية، وقوالب البريد، وفئات نموذج الاتصال، وبعض العناصر الأصغر التي تظهر بشروط
* **تكوين عناوين URL متعددة للوصول** — مغطى في [عناوين URL للوصول](../multi-url/access-urls.md)، ضمن تعدد عناوين URL
* **الأدوات الخارجية (LTI)** — مغطى في [LTI 1.3](../integrations/lti.md)، ضمن التكاملات
