# عناوين URL المتعددة

تتيح ميزة عناوين URL المتعددة في Chamilo (وتُسمّى أيضًا متعدد المستأجرين) تشغيل عدة بوابات افتراضية من تثبيت Chamilo واحد. لكل بوابة عنوان URL خاص بها، وهوية بصرية، ومستخدمون، ومقررات، وإعدادات، لكنها جميعًا تشترك في قاعدة البيانات نفسها وفي قاعدة الشيفرة نفسها.

* **[عناوين URL للوصول](access-urls.md)** — تكوين وإدارة عناوين URL متعددة للوصول
