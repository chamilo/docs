# المهارات

تجمع كتلة **المهارات** في لوحة تحكم الإدارة الأدوات اللازمة لتعريف شارات الكفاءة («المهارات») وتنظيمها وتتبعها عبر المنصة. يمكن منح المهارة تلقائيًا عندما يبلغ المتعلم عتبة في دفتر الدرجات، أو عند إكمال مقررات محددة، أو يدويًا من قِبل المعلم، ويمكن أن تحمل أيقونة بأسلوب الشارة ومستوى (مثل برونزي/فضي/ذهبي).

![كتلة المهارات في لوحة تحكم الإدارة، وتسرد عجلة المهارات، واستيراد المهارات، وإدارة المهارات، وإدارة مستويات المهارات، وترتيب المهارات، والمهارات والتقييمات](../../.gitbook/assets/admin-skills-block.png)

لا تظهر الكتلة بأكملها إلا إذا كان إعداد **Enable skills tool** (`skill.allow_skills_tool`، ضمن Configuration Settings > Skills) مفعّلًا — وهو مفعّل افتراضيًا.

## الوصول إلى كتلة المهارات

من لوحة الإدارة، تظهر كتلة **المهارات** إلى جانب كتل لوحة التحكم الأخرى. انقر أيًا من روابطها لفتح الأداة المقابلة.

## ما الذي تتضمنه الكتلة

* **[إدارة المهارات](managing-skills.md)** — إنشاء المهارات، واستيرادها بالجملة، وتعيين كل منها إلى مقياس مستويات
* **[عجلة المهارات](skills-wheel.md)** — خريطة بصرية قابلة للتكبير لشجرة المهارات بأكملها
* **[ترتيب المهارات](skills-ranking.md)** — لوحة صدارة للمستخدمين حسب المهارات المكتسبة
* **[المهارات والتقييمات](skills-assessments.md)** — ربط فئات دفتر الدرجات بالمهارات التي تمنحها

## الإعدادات ذات الصلة

تغيّر بعض الإعدادات الأخرى ضمن Configuration Settings > Skills من يمكنه فعل ماذا بهذه الكتلة:

* **Allow HR skills management** (`allow_hr_skills_management`) — يتيح لمستخدمي مدير الموارد البشرية إدارة المهارات إلى جانب المسؤولين
* **Allow private skills** (`allow_private_skills`)
* **Teachers can assign skills** (`skills_teachers_can_assign_skills`)
* **Hide skill levels** (`hide_skill_levels`)
* **Show full skill name on skill wheel** (`show_full_skill_name_on_skill_wheel`)
