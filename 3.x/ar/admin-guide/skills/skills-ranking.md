# تصنيف المهارات

تصنيف المهارات هو لوحة صدارة للمستخدمين مرتبة حسب عدد المهارات التي اكتسبوها.

## الوصول إلى تصنيف المهارات

من لوحة الإدارة، انقر **المهارات > تصنيف المهارات**.

## ما الذي يعرضه

لكل مستخدم نشط، يعرض التصنيف:

* **المهارات المكتسبة** — العدد الإجمالي للمهارات المُصدَرة، ويُستخدم لترتيب لوحة الصدارة (الأعلى أولاً)
* **قيد التعلّم حالياً** — عدد المهارات المرتبطة، عبر دفتر الدرجات، بالمقررات التي يسجّل فيها المستخدم حالياً (مباشرة أو عبر جلسة)

استخدم هذه الصفحة لتحديد أبرز المتعلمين إنجازاً بنظرة سريعة، أو لتقييم نشاط اكتساب المهارات عموماً عبر المنصة.
