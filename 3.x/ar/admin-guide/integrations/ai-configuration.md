# إعداد الذكاء الاصطناعي

يتضمن Chamilo 3.0 ميزات مدعومة بالذكاء الاصطناعي تتطلب إعدادًا قبل أن تصبح متاحة للمعلمين والمتعلمين.

## مزودو الذكاء الاصطناعي المدعومون

يدعم Chamilo عدة مزودين للذكاء الاصطناعي:

| المزود | القدرات |
|----------|-------------|
| **DeepSeek** | توليد النصوص |
| **Google Gemini** | توليد النصوص والصور والفيديو |
| **Grok** | توليد النصوص والصور والفيديو |
| **Mistral** | توليد النصوص |
| **OpenAI** | توليد النصوص والصور والفيديو |

يمكن إعداد كل مزود لأنواع مختلفة من مهام الذكاء الاصطناعي:

* **Text** — يُستخدم لتوليد التمارين، وتوليد مسارات التعلم، والتقييم بالذكاء الاصطناعي، ومساعد الذكاء الاصطناعي
* **Image** — يُستخدم لتوليد الصور بالذكاء الاصطناعي
* **Video** — يُستخدم لتوليد الفيديو بالذكاء الاصطناعي (حيث يكون مدعومًا)
* **Document** — يُستخدم لتحليل المستندات بالذكاء الاصطناعي

## خطوات الإعداد

### 1. الحصول على مفاتيح API

سجّل حسابًا لدى مزود الذكاء الاصطناعي الذي اخترته واحصل على مفتاح API:

* **DeepSeek**: [platform.deepseek.com](https://platform.deepseek.com/)
* **Google Gemini**: Google AI Studio أو Google Cloud
* **Grok**: [console.x.ai](https://console.x.ai/)
* **Mistral**: [console.mistral.ai](https://console.mistral.ai/)
* **OpenAI**: [platform.openai.com](https://platform.openai.com/)

### 2. إعداد المزودين في Chamilo

![صفحة إعداد مساعدي الذكاء الاصطناعي تعرض إعدادات المزود مع حقول مفتاح API والنموذج ونقطة النهاية](/.gitbook/assets/admin-ai-helpers-config.png)

في إعدادات المنصة، انتقل إلى قسم **AI Helpers**:

1. **Enable AI helpers** — فعّل ميزات الذكاء الاصطناعي على مستوى المنصة بالكامل
2. **Configure AI providers** — أضف مزودًا واحدًا أو أكثر مع:
   * **Provider name** (deepseek, gemini, grok, mistral, openai)
   * **API key** — مفتاح API الخاص بك للمزود
   * **Model** — النموذج المحدد المراد استخدامه (مثل `gpt-4`، `gemini-pro`، `mistral-large`)
   * **API URL** — عنوان URL لنقطة النهاية (مُعد مسبقًا للمزودين القياسيين)

يمكنك إعداد عدة مزودين. يصبح المزود الأول في الإعداد هو الافتراضي.

### 3. تفعيل الميزات لكل مقرر

يمكن تفعيل ميزات الذكاء الاصطناعي أو تعطيلها على مستوى المقرر. يمكن للمعلمين تبديل:

* **AI Tutor chatbot** — مساعد الذكاء الاصطناعي للمتعلمين
* **Assignment grader** — توصية تقييم مولَّدة بالذكاء الاصطناعي
* **Exercise generator** — أسئلة اختبار مولَّدة بالذكاء الاصطناعي
* **Learning path generator** — تسلسلات تعلم مولَّدة بالذكاء الاصطناعي
* **Image/Video generator** — صور وفيديوهات مولَّدة بالذكاء الاصطناعي في المستندات

يتيح ذلك للمقررات المختلفة استخدام إعدادات ذكاء اصطناعي مختلفة وفقًا لاحتياجاتها.

## اعتبارات التكلفة

ترتبط استدعاءات AI API بتكاليف. ضع في اعتبارك:

* **Setting usage limits** — راقب وحدّ من استخدام AI API للتحكم في التكاليف
* **Choosing models wisely** — قد تكون النماذج الأصغر والأقل تكلفة كافية للعديد من المهام التعليمية
* **Tracking usage** — يسجّل Chamilo طلبات الذكاء الاصطناعي لمساعدتك على مراقبة الاستهلاك

## نصائح

* **Start with one provider** — أعد واختبر مزودًا واحدًا قبل إضافة المزيد
* **Test with a course** — فعّل ميزات الذكاء الاصطناعي في مقرر تجريبي أولًا للتحقق من أنها تعمل كما هو متوقع
* **Communicate with teachers** — أخبر المعلمين بالميزات المتاحة للذكاء الاصطناعي وكيفية استخدامها
* **Monitor quality** — راجع بانتظام المحتوى المولَّد بالذكاء الاصطناعي للتأكد من أنه يلبي معاييرك التعليمية
