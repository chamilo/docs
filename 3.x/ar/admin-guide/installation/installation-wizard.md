# معالج التثبيت

يتضمن Chamilo 3.0 معالج تثبيت قائمًا على الويب يرشدك خلال الإعداد الأولي. يعمل المعالج تلقائيًا عند الوصول إلى المنصة لأول مرة.

## قبل أن تبدأ

تأكد من استيفاء المتطلبات المسبقة التالية:

1. يستوفي خادمك جميع [متطلبات الخادم](server-requirements.md).
2. قمت بتنزيل نسخة معبأة (zip أو tar.gz) من Chamilo.
3. خادم الويب لديك مُهيأ ليخدم الدليل `public/` كجذر للمستندات.
4. ملف `.env` موجود وهو فارغ (سيرشدك المعالج إلى إعداد قاعدة البيانات).

## الخطوة 1: لغة التثبيت

![معالج التثبيت الخطوة 1 — اختيار اللغة](/.gitbook/assets/install-step1-language.png)

تتيح لك الخطوة الأولى اختيار لغة عملية التثبيت. اختر لغتك المفضلة من القائمة المنسدلة.

إذا اكتشف Chamilo تثبيتًا موجودًا (للترقية)، فسيعرض حالة الترحيل ويعرض مسار ترقية بدلًا من تثبيت جديد.

## الخطوة 2: التحقق من المتطلبات

![معالج التثبيت الخطوة 2 — التحقق من المتطلبات يعرض إصدار PHP والإضافات وصلاحيات الأدلة](/.gitbook/assets/install-step2-requirements.png)

يتحقق المعالج من بيئة الخادم لديك:

* **إصدار PHP** هو 8.3 أو 8.4 أو 8.5
* **إضافات PHP المطلوبة** مثبتة (intl, gd, curl, zip, mbstring, xml, إلخ)
* **إعدادات PHP الموصى بها** — `date.timezone` مُهيأ، وحدود رفع/ذاكرة كافية
* **صلاحيات الأدلة والملفات** — `var/` و`config/` و`public/upload/` قابلة للكتابة من قِبل خادم الويب

إذا لم تُستوفَ أي متطلبات، يعرض المعالج تحذيرات أو أخطاء. عالجها قبل المتابعة.

## الخطوة 3: الترخيص

![معالج التثبيت الخطوة 3 — قبول الترخيص](/.gitbook/assets/install-step3-license.png)

تعرض هذه الخطوة ترخيص GNU/GPLv3. يجب تحديد مربع **"أوافق"** للمتابعة.

اختياريًا، يمكنك توسيع قسم **معلومات الاتصال** لتقديم تفاصيل عن منظمتك (الاسم، البريد الإلكتروني، الشركة، البلد). هذا طوعي ويساعد مجتمع Chamilo على فهم من يستخدم المنصة، لكنه سيسمح لنا أيضًا بالاتصال بك *نادرًا جدًا* بشأن فعاليات قريبة منك.

## الخطوة 4: إعدادات قاعدة البيانات

![معالج التثبيت الخطوة 4 — تهيئة اتصال قاعدة البيانات](/.gitbook/assets/install-step4-database.png)

أدخل تفاصيل اتصال قاعدة البيانات:

| الحقل | الوصف |
|-------|-------------|
| **مضيف قاعدة البيانات** | اسم المضيف أو عنوان IP لخادم قاعدة البيانات (مثل `localhost` أو `127.0.0.1`) |
| **منفذ قاعدة البيانات** | الافتراضي: 3306 لـ MySQL/MariaDB |
| **اسم قاعدة البيانات** | اسم قاعدة البيانات المراد استخدامها (أحرف أبجدية رقمية وشرطات سفلية فقط) |
| **مستخدم قاعدة البيانات** | مستخدم قاعدة بيانات بصلاحيات كاملة على قاعدة البيانات المحددة |
| **كلمة مرور قاعدة البيانات** | كلمة مرور مستخدم قاعدة البيانات |

انقر **التحقق من اتصال قاعدة البيانات** للاختبار. لن يسمح لك المعالج بالمتابعة حتى ينجح الاتصال. إذا كانت قاعدة البيانات موجودة مسبقًا، يُعرض تحذير.

## الخطوة 5: إعدادات التهيئة

![معالج التثبيت الخطوة 5 — حساب المسؤول وإعدادات البوابة وتهيئة البريد الإلكتروني](/.gitbook/assets/install-step5-config.png)

تجمع هذه الخطوة بين إنشاء حساب المسؤول وإعدادات البوابة وتهيئة البريد الإلكتروني.

### حساب المسؤول

| الحقل | الوصف |
|-------|-------------|
| **اسم الدخول** | اسم مستخدم المسؤول |
| **كلمة المرور** | اختر كلمة مرور قوية — لهذا الحساب وصول كامل إلى المنصة |
| **الاسم الأول** | الاسم الأول للمسؤول |
| **اسم العائلة** | اسم عائلة المسؤول |
| **البريد الإلكتروني** | يُستخدم لإشعارات النظام وإعادة تعيين كلمات المرور |
| **الهاتف** | رقم اتصال اختياري |

ستُستخدم تفاصيل المسؤول هذه أيضًا من قِبل Chamilo لتعبئة تفاصيل جهة اتصال الدعم، لذا تأكد من إعادة تهيئتها في الإعدادات بعد انتهاء التثبيت.

### إعدادات البوابة

| الحقل | الوصف |
|-------|-------------|
| **اللغة** | لغة الواجهة الافتراضية |
| **اسم البوابة** | اسم منصتك (مثل "My Organization LMS") |
| **الاسم المختصر للشركة** | الاسم المختصر لمنظمتك |
| **عنوان URL للشركة** | موقع منظمتك على الويب |
| **طريقة التشفير** | خوارزمية تجزئة كلمة المرور — يُوصى بـ **bcrypt** |
| **السماح بالتسجيل الذاتي** | نعم / لا / بعد الموافقة |
| **السماح بالتسجيل الذاتي كمدرب** | نعم / لا |

### تهيئة البريد الإلكتروني

يتيح لك قسم إعدادات البريد تهيئة نقل البريد (SMTP، Amazon SES، Mailjet، إلخ) واختبار تسليم البريد. راجع [تهيئة البريد الإلكتروني](email-configuration.md) للتفاصيل.

يمكن تغيير جميع هذه الإعدادات لاحقًا من لوحة الإدارة.

## الخطوة 6: التحقق الأخير قبل التثبيت

![معالج التثبيت الخطوة 6 — مراجعة جميع الإعدادات قبل التثبيت](/.gitbook/assets/install-step6-review.png)

تعرض هذه الخطوة ملخصًا لكل ما أدخلته للمراجعة:

* بيانات اعتماد المسؤول (كلمة المرور مخفية افتراضيًا — انقر أيقونة العين لإظهارها)
* إعدادات البوابة
* تفاصيل اتصال قاعدة البيانات

راجع بعناية، ثم انقر **Install Chamilo** لتنفيذ التثبيت. ينشئ المعالج جميع جداول قاعدة البيانات، ويملأ البيانات الأولية، ويهيئ المنصة.

## الخطوة 7: اكتمل التثبيت

![معالج التثبيت الخطوة 7 — الاكتمال مع نصائح أمنية ورابط البوابة](/.gitbook/assets/install-step7-complete.png)

بعد اكتمال التثبيت بنجاح، يعرض المعالج:

* **نصائح البدء** — يقترح إنشاء مقررك الأول لاستكشاف المنصة (بصفتك مسؤولًا، تحتاج إلى القيام بذلك من لوحة الإدارة)
* **توصيات أمنية**:
  * اجعل الدليل `config/` للقراءة فقط (`chmod 0555`)
  * احذف الدليل `public/main/install/`
* **رابط إلى بوابتك** لتسجيل الدخول ببيانات اعتماد المسؤول التي أنشأتها للتو

## ما بعد التثبيت

بعد إكمال المعالج:

* **أزل مثبّت التثبيت أو قيّد الوصول إليه** -- يجب ألا يكون المعالج قابلاً للوصول بعد التثبيت. عادةً ما يقفل Chamilo ذلك تلقائيًا، لكن تحقق من أن إعادة زيارة عنوان URL للتثبيت تعيد التوجيه إلى صفحة تسجيل الدخول.
* **هيئ تسليم البريد الإلكتروني** -- انظر [تهيئة البريد الإلكتروني](email-configuration.md).
* **أعد النسخ الاحتياطي** -- قبل إضافة المحتوى، هيئ نسخًا احتياطيًا آليًا لقاعدة البيانات والملفات (لا يوفّر Chamilo حلًا لذلك، لكن نسخ المجلد var/ وقاعدة البيانات هما العنصران الأهم).
* **راجع إعدادات الأمان** -- انظر [إعدادات الأمان](../platform-settings/security-settings.md).

## استكشاف الأخطاء وإصلاحها

| المشكلة | الحل |
|---------|----------|
| صفحة فارغة عند عنوان URL للتثبيت | تحقق من سجلات أخطاء PHP. غيّر مؤقتًا إلى `APP_ENV=dev` في .env لعرض الأخطاء في المتصفح. |
| فشل اتصال قاعدة البيانات | تحقق من بيانات الاعتماد، وتأكد من وجود قاعدة البيانات، وتحقق من أن خادم قاعدة البيانات يسمح بالاتصالات من مضيف خادم الويب. |
| أخطاء رفض الإذن | تأكد من أن `var/` قابل للكتابة من قبل مستخدم خادم الويب. |
| الأصول لا تُحمَّل (لا CSS/JS) | نفّذ `yarn install && yarn build` لتجميع أصول الواجهة الأمامية. |
