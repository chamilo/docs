# التثبيت

يغطي هذا القسم كل ما تحتاج إليه لتثبيت Chamilo 3.0 وإعداده على خادمك.

Chamilo 3.0 تطبيق PHP مبني على إطار Symfony. يمكن تشغيله على معظم الخوادم المستندة إلى Linux، وقد ثُبِّت ويعمل على Windows Server مع IIS، ويدعم خلفيات MySQL وMariaDB.

## خطوات التثبيت

1. **[متطلبات الخادم](server-requirements.md)** — تحقق من أن خادمك يستوفي الحد الأدنى من المتطلبات
2. **[معالج التثبيت](installation-wizard.md)** — شغّل معالج التثبيت المستند إلى الويب
3. **[الإعداد](configuration.md)** — اضبط متغيرات البيئة وإعدادات Symfony
4. **[التخزين السحابي](cloud-storage.md)** — إعداد خلفيات التخزين السحابي (اختياري)
5. **[إعداد البريد الإلكتروني](email-configuration.md)** — ضبط تسليم البريد الإلكتروني
6. **[الترقية](upgrading.md)** — الترقية من إصدار سابق

## نظرة عامة سريعة

عملية التثبيت الأساسية هي:

1. تنزيل شيفرة مصدر Chamilo أو استنساخها
2. تثبيت اعتماديات PHP باستخدام Composer عند التحضير من المصدر
3. تثبيت اعتماديات JavaScript باستخدام npm/yarn وبناء أصول الواجهة الأمامية
4. إنشاء ملف `.env` فارغ لتخزين بيانات اعتماد قاعدة البيانات والإعدادات الأخرى لاحقًا
5. تغيير الأذونات (قابلة للكتابة بواسطة خادم الويب) على *var/* و*config/* و*.env*
6. تشغيل معالج التثبيت المستند إلى الويب
7. الاتصال بحساب المسؤول الأول
8. إعادة الأذونات على *config/* و*.env*

توجد تعليمات مفصّلة لكل خطوة في الصفحات المرتبطة أعلاه.
