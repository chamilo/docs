# متطلبات الخادم

قبل تثبيت Chamilo 3.0، تحقق من أن خادمك يستوفي المتطلبات التالية.

## متطلبات البرمجيات

### PHP

| المتطلب | الحد الأدنى | الموصى به |
|-------------|---------|-------------|
| **إصدار PHP** | 8.3 | 8.5 |

### امتدادات PHP المطلوبة

| الامتداد | الغرض |
|-----------|---------|
| **bcmath** | حسابات بدقة اعتباطية |
| **ctype** | التحقق من نوع المحارف |
| **curl** | طلبات HTTP (تكاملات API، الخدمات الخارجية) |
| **dom**، **libxml**، **simplexml**، **xml**، **xmlreader** | تحليل XML ومعالجة DOM (SCORM، RSS، SOAP، LTI) |
| **exif** | قراءة بيانات تعريف الصور (مثل التوجيه التلقائي للصور المرفوعة) |
| **fileinfo** | اكتشاف نوع MIME للملفات المرفوعة |
| **gd** | معالجة الصور (الصور المصغرة، CAPTCHA) |
| **iconv** | تحويل مجموعات المحارف |
| **intl** | التدويل (تنسيق التواريخ والأرقام والسلاسل) |
| **json** | ترميز/فك ترميز JSON |
| **ldap** | موصل LDAP. رغم أنك على الأرجح لن تستخدم LDAP، فإن Chamilo يتطلبه |
| **mbstring** | معالجة السلاسل متعددة البايتات (دعم UTF-8) |
| **openssl** | العمليات التشفيرية (HTTPS، تجزئة كلمات المرور، رموز JWT) |
| **pdo**، بالإضافة إلى **pdo_mysql** أو **pdo_pgsql** | الاتصال بقاعدة البيانات (ثبّت المشغّل المطابق لقاعدة بياناتك) |
| **soap** | معالجة خدمات SOAP على الويب |
| **zip** | التعامل مع أرشيفات ZIP (حزم SCORM، الاستيراد/التصدير بالجملة) |
| **zlib** | الضغط المستخدم داخليًا من عدة تبعيات |
| **apcu** | التخزين المؤقت على مستوى المستخدم (موصى به، يُتحقق منه لكن لا يُفرض من المثبّت) |
| **opcache** | التخزين المؤقت للشيفرة التنفيذية (موصى به بشدة للأداء، يُتحقق منه لكن لا يُفرض من المثبّت) |
| **xapian** | البحث بالنص الكامل (اختياري، فقط إذا كنت تستخدم البحث) |

### قاعدة البيانات

| قاعدة البيانات | الإصدار الأدنى | الموصى به |
|----------|-----------------|-------------|
| **MariaDB** | 10.0 | 10.4 أو أعلى |
| **MySQL** | 5.7 | 8.0 أو أعلى |

إصدارات MariaDB الأقدم من 10.2.2 (وإصدارات MySQL الأقدم من 5.7) تحتاج إلى تفعيل دعم الفهارس/البادئات الكبيرة يدويًا في إعدادات الخادم قبل تثبيت Chamilo.

### خادم الويب

| الخادم | ملاحظات |
|--------|-------|
| **Apache** | يتطلب تفعيل `mod_rewrite` (و`ssl` و`headers` و`expires`). يوفّر Chamilo نموذج vhost في `public/main/install/apache.dist.conf`. |
| **Nginx** | يتطلب إعدادًا يدويًا لإعادة كتابة عناوين URL — لا يوفّر Chamilo نموذج إعداد Nginx. راجع وثائق Symfony الخاصة بـ Nginx للحصول على إعداد مرجعي. |

### أدوات البناء

| الأداة | الغرض |
|------|---------|
| **Composer** (^2.8) | إدارة تبعيات PHP. مطلوبة لتثبيت مكتبات PHP الخاصة بـ Chamilo. |
| **Node.js** (20+ LTS) | بيئة تشغيل JavaScript. مطلوبة لبناء أصول الواجهة الأمامية. |
| **Yarn** (^4، عبر Corepack) | مدير حزم JavaScript المستخدم لبناء أصول الواجهة الأمامية (`yarn install`، `yarn encore production`). |

## متطلبات العتاد

| المورد | الحد الأدنى | الموصى به |
|----------|---------|-------------|
| **RAM** | 4 GB | 8 GB أو أكثر (بناء أصول الواجهة الأمامية من المصدر يحتاج إلى 4 GB على الأقل بمفرده) |
| **CPU** | 2 vCPUs | نواتان أو أكثر |
| **مساحة القرص** | 4 GB (التطبيق فقط) | 20+ GB (بما في ذلك المحتوى المرفوع)؛ البناء من المصدر يحتاج إلى نحو 10 GB حرة أثناء البناء |
| **نوع القرص** | HDD | SSD (يحسّن أداء قاعدة البيانات والذاكرة المؤقتة بشكل ملحوظ) |

هذه أرقام أساسية من دليل التثبيت الخاص بـ Chamilo. تعتمد المتطلبات الفعلية على عدد المستخدمين المتزامنين وحجم المحتوى المستضاف.

## نظام التشغيل

| نظام التشغيل | ملاحظات |
|----|-------|
| **Linux** | موصى به. Ubuntu 24.04 LTS+، أو Debian 12+، أو AlmaLinux 9+، أو ما يعادلها. |
| **Windows** | ممكن لكنه غير مختبَر بدقة. استخدم WSL2 للتطوير. |
| **macOS** | للتطوير فقط / غير مختبَر. |

## متطلبات الشبكة

* اسم نطاق يشير إلى خادمك.
* شهادة SSL/TLS لـ HTTPS (Let's Encrypt يوفّر شهادات مجانية).
* وصول SMTP صادر إذا كنت ترسل البريد الإلكتروني مباشرة (أو استخدم خدمة بريد إلكتروني تابعة لطرف ثالث).
* المنفذ 443 (HTTPS) واختياريًا المنفذ 80 (HTTP، لإعادة التوجيه إلى HTTPS).

## التحقق من المتطلبات

بعد وضع مصدر Chamilo على خادمك، يمكنك التحقق من إعداد PHP مباشرة:

```bash
php -m          # List installed extensions
php -i          # Full PHP info
```

## نصائح

* **استخدم PHP-FPM** مع Apache أو Nginx لأداء أفضل من mod_php.
* **افصل قاعدة بياناتك** على خادم مخصص للمنصات التي تتوقع أكثر من 500 مستخدم متزامن.
* **استخدم تخزين SSD** -- تستفيد التطبيقات كثيفة الاعتماد على قاعدة البيانات مثل Chamilo بشكل كبير من سرعة إدخال/إخراج القرص.
