# ملف تعريف المستخدم

يتيح لك Chamilo تعريف حقول ملف تعريف مخصصة (حقول إضافية) لالتقاط معلومات إضافية عن المستخدمين تتجاوز الاسم والبريد الإلكتروني والدور القياسية.

## الحقول الإضافية لملف التعريف

![قائمة الحقول الإضافية لملف التعريف تعرض حقولاً مخصصة مع الاسم والنوع وإعدادات الرؤية](../../.gitbook/assets/admin-extra-fields-list.png)

تتيح لك الحقول الإضافية تخزين بيانات وصفية خاصة بمؤسستك، مثل:

* رقم الموظف
* القسم
* المسمى الوظيفي
* الموقع/المكتب
* رقم الهاتف
* معرّفات مخصصة

## إنشاء الحقول الإضافية

1. من لوحة الإدارة، انتقل إلى **Extra fields** أو **Profile fields**
2. انقر **Add**
3. اضبط الحقل:
   * **Name** — عنوان الحقل المعروض للمستخدمين
   * **Description** — وصف اختياري
   * **Helper text** — يُعرض أسفل الحقل في أي نموذج يتضمنه
   * **Field type** — نص، قائمة منسدلة، تاريخ، خانة اختيار، إلخ.
   * **Field label** — الاسم الداخلي للحقل، لتكامل الإضافات 
   * **Possible values** — إذا كان الحقل محدِّداً بين تلك القيم 
   * **Default value** — قيمة افتراضية اختيارية
   * **Visible to self** — ما إذا كان الحقل مرئياً على ملف تعريف المستخدم من قِبل المستخدم نفسه
   * **Visible to others** — ما إذا كان الحقل مرئياً للمستخدمين الآخرين على المنصة
   * **Can change** — ما إذا كان المستخدم يستطيع تغيير حقله بنفسه (أو ما إذا كان المسؤولون وحدهم يستطيعون ذلك)
   * **Filter** — إذا كان هذا حقلاً من نوع المحدِّد، ما إذا كان يُدرَج كمرشِّح في الصفحات الإدارية (مثلاً للاشتراك بالمستخدمين في الدورات أو الجلسات)
   * **Order** — إذا أردت إدارة ترتيب عرض الحقول، فسيتعين عليك إعطاء ترتيباً رقمياً لكل حقل
   * **Remove on anonymization** — مهم لقواعد وقوانين الخصوصية: إذا تم إخفاء هوية المستخدم دون حذفه، هل ينبغي اعتبار هذا الحقل حاملاً محتملاً لبيانات تعريف شخصية؟ 
4. احفظ

## أنواع الحقول

يدعم محرك الحقول الإضافية مجموعة واسعة من أنواع الإدخال. تشمل الأنواع الشائعة:

| النوع | الوصف |
|------|-------------|
| **Text** | إدخال نصي بسطر واحد |
| **Textarea** | إدخال نصي متعدد الأسطر |
| **Radio** | مجموعة أزرار اختيار أحادية |
| **Dropdown / Dropdown multiple** | قائمة خيارات محددة مسبقاً (اختيار واحد أو متعدد) |
| **Double select** | قائمتان منسدلتان مرتبطتان (مثلاً، الدولة → المدينة) |
| **Checkbox** | مفتاح نعم/لا |
| **Date / Date and time** | منتقي تاريخ أو تاريخ+وقت |
| **Integer** | إدخال رقمي |
| **Tag** | قيم وسوم حرة متعددة |
| **File** | حقل رفع ملف |
| **Video URL** | عنوان URL يشير إلى فيديو |
| **Mobile phone number** | حقل رقم هاتف منسَّق |
| **Timezone** | منتقي منطقة زمنية |
| **Social profile** | رابط إلى ملف تعريف على شبكة اجتماعية |
| **Divider** | فاصل مرئي داخل النموذج (بدون قيمة) |

تعتمد المجموعة الدقيقة للأنواع القابلة للاستخدام على إصدار Chamilo؛ والقائمة المنسدلة لنوع الحقل في صفحة إدارة **Extra fields** هي المصدر المعتمد.

## استخدام الحقول الإضافية

تظهر الحقول الإضافية:

* في نماذج إنشاء المستخدم (إذا كانت مرئية للذات) وتحريره
* في صفحات ملف تعريف المستخدم (إذا كانت مرئية للذات)
* في استيراد المستخدمين (يمكنك تضمين قيم الحقول الإضافية في استيرادات CSV)
* في التصديرات والتقارير (التصفية أو التجميع حسب قيم الحقول الإضافية)

## نصائح

* **خطّط قبل الإنشاء** — حدّد المعلومات التي تحتاجها قبل إنشاء الحقول، إذ إن تغيير أنواع الحقول بعد إدخال البيانات قد يكون إشكالياً
* **استخدم القوائم المنسدلة للاتساق** — عندما يكون للحقل مجموعة معروفة من القيم الممكنة، استخدم قائمة منسدلة بدلاً من النص الحر لضمان اتساق البيانات
* **استخدمها للتقارير** — الحقول الإضافية مفيدة لتصفية التقارير (مثلاً، "عرض جميع المستخدمين في القسم X الذين أكملوا التدريب Y")
