# إعدادات البحث

تكوين نظام البحث بالنص الكامل (Xapian).

يمكنك الوصول إلى هذه الإعدادات ضمن **الإدارة > إعدادات التكوين > البحث**. تحتوي هذه الفئة على **3 إعدادات**، مُدرجة أدناه مع العنوان والتعليق المُضمَّنين في تجهيزات إعدادات المنصة (`SettingsCurrentFixtures.php`).

> يُعرض اسم المتغير في الشيفرة بخط أحادي المسافة. استخدمه عند البرمجة النصية عبر واجهة API أو عندما تحتاج إلى تغيير تلك الإعدادات على المستوى العام عبر تحرير [`config/settings_override.yaml`](https://github.com/chamilo/chamilo-lms/wiki/Configurations#configsettings_overridesyaml).

## الإعدادات

### `search_enabled`

**ميزة البحث بالنص الكامل**

اختر «نعم» لتفعيل هذه الميزة. وهي تعتمد بدرجة كبيرة على امتداد Xapian لـ PHP، لذا لن تعمل إذا لم يكن هذا الامتداد مثبتًا على خادمك، بالإصدار 1.x كحد أدنى.

*القيمة الافتراضية: `false`*


### `search_prefilter_prefix`

**حقل محدد للتصفية المسبقة**

يتيح لك هذا الخيار اختيار الحقل المحدد لاستخدامه في نوع البحث بالتصفية المسبقة.

### `search_show_unlinked_results`

**البحث بالنص الكامل: إظهار النتائج غير المرتبطة**

عند عرض نتائج البحث بالنص الكامل، ما الذي ينبغي فعله بالنتائج غير المتاحة للمستخدم الحالي؟

*القيمة الافتراضية: `true`*
