# إعدادات خدمات الويب

تهيئة خدمات الويب القديمة SOAP / REST (منفصلة عن نقاط نهاية API Platform الحديثة).

يمكنك الوصول إلى هذه الإعدادات من **الإدارة > إعدادات التهيئة > خدمات الويب**. تحتوي هذه الفئة على **7 إعدادات**، مدرجة أدناه مع العنوان والتعليق كما وردا في تجهيزات إعدادات المنصة (`SettingsCurrentFixtures.php`).

> يظهر اسم المتغير في الشفرة بخط أحادي المسافة. استخدمه عند البرمجة النصية عبر واجهة البرمجة أو عندما تحتاج إلى تغيير تلك الإعدادات على المستوى العام بتحرير [`config/settings_override.yaml`](https://github.com/chamilo/chamilo-lms/wiki/Configurations#configsettings_overridesyaml).

## الإعدادات

### `allow_download_documents_by_api_key`

**السماح بتنزيل مستندات المقرر بمفتاح API**

تنزيل المستندات مع التحقق من مفتاح REST API للمستخدم

*القيمة الافتراضية: `false`*


### `disable_webservices`

**تعطيل خدمات الويب**

إذا كنت لا تستخدم خدمات الويب، فعّل هذا الخيار لتجنب أي مخاطر أمنية غير ضرورية.

*القيمة الافتراضية: `false`*


### `messaging_allow_send_push_notification`

**السماح بإشعارات الدفع لتطبيق Chamilo Messaging للجوال**

إرسال إشعارات الدفع عبر Google's Firebase Console

*القيمة الافتراضية: `false`*


### `messaging_gdc_api_key`

**مفتاح الخادم في Firebase Console للمراسلة السحابية**

مفتاح الخادم (الرمز القديم) من بيانات اعتماد المشروع

### `messaging_gdc_project_number`

**معرّف المُرسِل في Firebase Console للمراسلة السحابية**

يلزمك تسجيل مشروع على <a href='https://console.firebase.google.com/'>Google Firebase Console</a>

### `webservice_enable_adminonly_api`

**تمكين خدمات الويب المخصصة للمسؤولين فقط**

بعض خدمات REST مُعلَّمة للمسؤولين فقط وهي معطّلة افتراضيًا. فعّل هذه الميزة لمنح الوصول إلى خدمات الويب هذه (للمستخدمين الذين لديهم بيانات اعتماد المسؤول، بطبيعة الحال).

*القيمة الافتراضية: `false`*

### `webservice_return_user_field`

**حقل المستخدم الذي ترجعه خدمات الويب**

اطلب من خدمات REST (v2.php) إرجاع معرّف آخر للحقول المرتبطة بمعرّف المستخدم. يفيد ذلك إذا كان النظام الخارجي لا يتعامل فعليًا مع معرّفات المستخدم كما هي في Chamilo، إذ يساعد النظام الخارجي على مطابقة بيانات المستخدم المُرجَعة مع بيانات خارجية معروفة لدى Chamilo. على سبيل المثال، إذا كنت تستخدم نظام مصادقة خارجيًا، يمكنك إرجاع الحقل الإضافي المستخدم لمطابقة المستخدم مع نظام المصادقة الخارجي بدلًا من user.id.

*القيمة الافتراضية: `oauth2_id`*
