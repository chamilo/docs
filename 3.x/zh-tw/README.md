# Chamilo 3.0 說明文件

歡迎使用開源數位學習平台 **Chamilo 3.0** 的官方說明文件。

本文件分為三份指南，分別針對不同對象：

* [**教師指南**](teacher-guide/) — 適用於講師與培訓人員：建立課程、新增內容、評量學習者並追蹤進度。
* [**管理指南**](admin-guide/) — 適用於平台管理員：安裝、設定並管理 Chamilo 平台。
* [**開發者指南**](developer-guide/) — 適用於開發者：了解架構、建置外掛、使用 API，並為專案貢獻。

## Chamilo 3.0 的新功能

Chamilo 3.0 是一次重大版本更新，介面全面重新設計，並新增許多功能：

* **現代化介面** — 以 Vue 3 與 PrimeVue 打造，體驗更快速、反應更靈敏
* **AI 驅動工具** — 產生練習、學習路徑，並獲得 AI 輔助評分
* **REST API** — 完整以 API Platform 為基礎的 REST API，並採用 JWT 驗證
* **新的驗證選項** — OAuth2（Azure、Keycloak、Facebook）、SCIM 使用者佈建
* **LTI 1.3** — 無縫連接外部學習工具
* **雲端儲存** — 原生支援 Azure Blob、AWS S3 與 Google Cloud Storage
* **色彩主題** — 可自訂平台品牌識別，並支援主題
* **OnlyOffice 整合** — 在平台內協同編輯文件
