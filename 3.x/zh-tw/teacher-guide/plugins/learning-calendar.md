# 學習行事曆

學習行事曆 <img src="../../.gitbook/assets/icons/mdi-calendar-text.svg" alt="學習行事曆" data-size="line"> 有助於規劃混合式或學徒制訓練，將課堂時間與場外實作結合。您可建立行事曆，將每一天標示為 **忙碌**、**考試** 或 **空閒**，再指派學習者；其個人議程便會顯示這些規劃日期。

## 存取此工具

啟用後，**我的空間**（您的報表區域）會出現 **學習行事曆** 圖示。它會開啟您已建立的行事曆清單，並提供新增、編輯、複製、刪除，以及將學習者指派至各行事曆的選項。

## 建立行事曆

1. 建立新的行事曆
2. 點選某一天，使其依序循環：**忙碌 → 考試 → 空閒 → 清除**
3. 指派應遵循此行事曆的學習者

被指派的學習者會在自己的議程上看到規劃日期，報表則會將規劃日期與其實際學習路徑完成情況進行比對。

## 提示

* **每位學習者同一時間僅能有一份行事曆** — 學習者只能被指派至單一行事曆，因此請以班級／群體為單位規劃，而非嘗試為同一人疊加多份行事曆
* **此為早期功能** — 它獨立於任何單一課程，因此請勿期待與 Chamilo 核心工具同等的完整度；在實際班級／群體中依賴此功能前，請先確認是否符合您的訓練形式
