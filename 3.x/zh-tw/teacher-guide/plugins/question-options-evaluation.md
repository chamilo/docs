# 題目選項評分

題目選項評分 <img src="/.gitbook/assets/icons/mdi-calculator-variant.svg" alt="題目選項評分" data-size="line"> 可讓您對測驗計分套用負分（扣分）公式，而非採用 Chamilo 預設僅加總正確答案的計分方式。

## 設定公式

啟用後，課程的 **測驗** 工具清單中，每個測驗旁會多出一個圖示。點選後會開啟一個小型表單，您可從下列選項擇一：

* **不使用公式** — Chamilo 的一般計分（預設）
* **重新計算題目分數** — 重新分配選項權重，但不扣分
* **答對數 − 答錯數**
* **答對數 − 答錯數 / 2**
* **答對數 − 答錯數 / 3**

所選公式僅套用至該特定測驗。

> 此設定不會變更題目或答案本身的權重 — 它改變的是最終分數的計算方式。若外掛停用，或未選擇公式，Chamilo 會回復為原本的計分方式。

## 提示

* **先在副本上測試** — 變更公式可能改變學生在該測驗上的最終分數；請先在複製的測驗上試用，再套用至正式測驗
* **向學生說明變更** — 若學習者習慣單純依正確答案計分，扣分公式可能令人意外；請在說明中提及
