# 外掛程式

除了 Chamilo 內建的工具外，您的平台管理員還可以安裝並啟用**外掛程式**——這些選用功能可為課程新增工具、設定或行為。外掛程式預設為關閉；只有在管理員開啟後才會出現，且部分外掛程式還需您在特定課程中另行啟用才會生效。

本節說明會直接改變**教師**操作體驗的外掛程式。若您在自己的課程中看不到此處所述的外掛程式，很可能尚未在您的平台上啟用——請洽詢管理員。

## 評量與測驗

* **[Exercise Focused](exercise-focused.md)** — 偵測學生在測驗期間離開考試視窗，並顯示螢幕警告，可選擇自動繳交
* **[Exercise Monitoring](exercise-monitoring.md)** — 在受監考試嘗試期間擷取學生的網路攝影機照片及其證件
* **[Exercise Signature](exercise-signature.md)** — 要求學生在完成測驗後進行電子簽名
* **[Question Options Evaluation](question-options-evaluation.md)** — 對測驗套用負分（扣分）計分公式，取代 Chamilo 的預設計分方式
* **[Positioning](positioning.md)** — 以雷達圖比較學習者在初始測驗與最終測驗的前後分數
* **[Test to PDF](test-to-pdf.md)** — 將測驗的題目及／或答案匯出為可列印的 PDF

## 內容與編輯

* **[C-Studio Content Editor](cstudio.md)** — 以視覺化編輯器建立互動式學習路徑頁面（測驗、拖放、熱點圖片等），無需撰寫 HTML
* **[H5P Import](h5p-import.md)** — 將 H5P 互動內容套件上傳至課程或學習路徑
* **ONLYOFFICE** — 從「文件」工具建立並共同編輯真實的 Word、Excel 與 PowerPoint 文件；已於 [文件](../adding-content/documents.md#onlyoffice-integration) 中說明

## 溝通與視訊會議

* **視訊會議（BigBlueButton）** 與 **Zoom 視訊會議** — 從課程中進行即時視訊會議；已於 [視訊會議](../collaboration-and-communication/video-conferencing.md) 中說明
* **[Notify in Course Home](notify-in-course-home.md)** — 向造訪課程首頁的所有人顯示一次性彈出通知

## 證書與合規

* **[Custom Certificate](custom-certificate.md)** — 以您自訂的設計、標誌與簽名取代標準成績簿證書
* **[Course Legal Agreement](course-legal-agreement.md)** — 要求學生在進入課程前接受條款／法律聲明

## 追蹤與後續關懷

* **[Student Follow-up](student-follow-up.md)** — 針對學習者的進度與困難，保存私人或共享的附時間戳記備註
* **[Learning Calendar](learning-calendar.md)** — 為混成或學徒制課程規劃學習者的忙碌／考試／空閒日
* **[Teacher Notes](teacher-notes.md)** — 針對課程中特定學習者保存私人備註，僅教學團隊可見

## 整合

* **[IMS/LTI Client](ims-lti.md)** — 從課程內啟動外部工具或內容提供者
* **[LTI 1.3 Advantage Provider](lti-1-3-advantage-provider.md)** — 讓外部 LMS 啟動您的某一測驗或學習路徑（由管理員設定，教師無需設定）

## 問卷匯出

* **[Survey Export CSV](survey-export-csv.md)** — 將問卷結果匯出為精簡的 CSV 檔
* **[Survey Export TXT](survey-export-txt.md)** — 將問卷結果匯出為人類可讀的文字檔
