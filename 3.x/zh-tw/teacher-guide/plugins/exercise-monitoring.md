# 測驗監考

測驗監考 <img src="/.gitbook/assets/icons/mdi-camera.svg" alt="測驗監考" data-size="line"> 會在測驗作答期間使用學生的網路攝影機擷取身分照片——身分證件照片與學生臉部照片——以維護考試誠信。

## 為測驗加上標記

開啟該測驗的設定並勾選 **測驗監考** 選項。標記後，嘗試該測驗的學生會看到一個小型浮動網路攝影機小工具，並會被提示在作答前或作答期間擷取這兩張照片。

## 審閱擷取內容

[推斷] 擷取的照片會透過 **[專注測驗](exercise-focused.md)** 外掛所新增的報表畫面進行審閱；本外掛即與該外掛一併開發——若您的平台僅啟用測驗監考而未啟用專注測驗，請向管理員詢問在您的安裝環境中應如何審閱擷取的照片。

## 須知事項

* **此功能處理敏感個人資料** — 身分證件照片屬於許多機構與隱私法規特別審慎對待的資料類別。在依賴此外掛之前，請與管理員確認其使用符合貴機構的資料保護義務
* **照片僅暫時保留** — 管理員會設定保留期限，期限過後擷取的照片會自動刪除
* **此為早期階段功能** — 預期仍有不完善之處；在用於正式考試前，請先以測試流程驗證擷取流程是否符合預期
