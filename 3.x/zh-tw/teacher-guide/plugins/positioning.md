# 定位

定位 <img src="../../.gitbook/assets/icons/mdi-radar.svg" alt="定位" data-size="line"> 提供前後自我評量工作流程：選取一份測驗作為**初始測驗**，另一份作為**最終測驗**（通常為同一測驗的複本），Chamilo 會以雷達圖顯示每位學習者兩次測驗之間的分數變化。

## 存取此工具

啟用後，課程首頁會出現**定位**工具。它會列出課程中符合條件的測驗，並提供**選為初始測驗**／**選為最終測驗**按鈕、進入各測驗成績的捷徑，以及比較平均初始分數與最終分數的雷達圖。

## 哪些測驗符合條件

僅同時符合以下三項條件的測驗會顯示為可選項目：

* 至少有 3 個題目類別
* 測驗的結果頁類型設為 **radar**
* 僅允許一次作答

若您預期會出現的測驗未出現在清單中，請先檢查該測驗的這三項設定。

## 強制執行順序

管理員還可在整個平台額外設定：

* **封鎖其他課程工具**，直到學習者完成初始測驗
* **結束測驗解鎖門檻** — 最終測驗解鎖前，學習路徑完成百分比須達到的最低平均值

## 提示

* **及早設定雷達結果類型** — 由於是否符合條件取決於建立測驗時的設定，請在最終確定測驗類別與結果頁類型之前規劃定位功能，而非之後
* **最終測驗請使用真正的複本** — 將測驗與自身比較意義不大；最終測驗應涵蓋相同類別，雷達圖才有意義
