# 自訂證書

自訂證書 <img src="/.gitbook/assets/icons/mdi-certificate.svg" alt="自訂證書" data-size="line"> 外掛可讓您以自己的設計取代標準的 [成績簿證書](../assessing-learners/gradebook.md)——標誌、印章、最多四張附說明文字的簽名圖片、背景圖、邊界，以及由預留標籤組成的內容。

## 為您的課程啟用

管理員啟用此外掛並設定預設範本後，請從 **課程設定** 依課程開啟：

* **Custom certificate enable in course** — 為此課程啟用此功能
* **Use default custom certificate** — 使用平台的預設範本，而非自行設計（這兩個選項互斥；若嘗試同時啟用，Chamilo 會提出警告）

這會在您的課程中提供 **證書設定** 工具，供您設計或編輯範本。

## 設計證書

證書編輯器使用標籤，在產生學習者證書時會替換為實際資料，例如 `((user_firstname))`、`((course_title))`、`((gradebook_grade))` 與 `((date_certificate))`。除內容外，您還可以設定：

* 最多三個標誌、一張印章圖片與一張背景圖
* 最多四張簽名圖片，各有獨立說明文字
* 邊界，以及證書上顯示的核發／發出日期與地點

使用 **Certificate** 預覽您的設計，或使用 **Delete certificate** 移除課程的自訂範本。

## 提示

* **學生不會看到任何不同之處** — 他們仍從成績簿以平常方式下載證書；只是改用您的範本
* **依賴前請先預覽** — 以實際預留資料檢查預覽，以便在學習者開始產生證書前發現版面問題
* **與管理員協調** — 若您希望使用全平台預設範本，而非依課程個別設計，須先由管理員設定
