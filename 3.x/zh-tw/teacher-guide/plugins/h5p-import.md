# H5P 匯入

H5P 匯入 <img src="../../.gitbook/assets/icons/mdi-puzzle.svg" alt="H5P 匯入" data-size="line"> 可讓您將標準 `.h5p` 互動內容套件（互動影片、測驗、簡報及其他 H5P 內容類型）帶入課程，學習者的作答次數與進度會以類似 Chamilo 測驗的方式加以追蹤。

## 存取此工具

啟用後，課程首頁會出現 **H5P 匯入** 工具，以表格顯示該課程的 H5P 套件，包含標題、說明，以及各套件被啟動的次數。

## 新增內容

* 按一下 **上傳** 並選擇 `.h5p` 檔案，填寫標題與說明，即可將其加入課程清單
* 在 **學習路徑** 中，可透過資源面板的 H5P 項目，將課程中已上傳的套件直接插入為學習路徑項目

## 提示

* **上傳前先完成內容設計** — 套件一旦上傳即無法編輯；若需修改，請在 H5P 編輯工具中修正後重新上傳
* **工具清單中的所有項目預設對每位學生可見** — 若要逐項控制可見性，請改由學習路徑新增套件，以便個別管理每個項目的可見性
* **此為測試版功能** — 可視為已可使用但仍在成熟中，請自行保留原始 `.h5p` 檔案副本，以備需要重新上傳
