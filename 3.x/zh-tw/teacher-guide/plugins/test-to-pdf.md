# 測驗轉 PDF

測驗轉 PDF <img src="../../.gitbook/assets/icons/mdi-file-pdf-box.svg" alt="測驗轉 PDF" data-size="line"> 可將課程測驗的題目匯出為可列印的 PDF——僅題目、僅答案，或兩者一併匯出——便於製作紙本測驗。

## 存取此工具

啟用後，課程首頁會出現 **測驗轉 PDF** 工具，列出該課程（或班級）中的每一份測驗。每一列提供三項操作：**下載題目**、**下載答案**，以及 **全部下載**。

## 提示

* **並非所有題型皆受支援** — 僅 Chamilo 部分題型（選擇題、是非題及類似封閉式題型）能正確匯出；開放式或較複雜的題型可能無法正確顯示，甚至完全不會出現
* **大量列印前請先檢查輸出** — 在為考試場次大量列印前，請先檢視一份測驗所產生的 PDF
