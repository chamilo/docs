# 課程說明

**課程說明** <img src="/.gitbook/assets/icons/mdi-apple-safari.svg" alt="課程說明" data-size="line"> 工具可讓您撰寫結構化、多區塊的課程說明——包含目標、教學方法、教材等。與僅供已註冊學習者在[課程首頁](README.md#the-course-homepage)看到的自由文字**課程簡介**橫幅不同，課程說明是準學習者在報名前，從課程目錄中所看到的內容。

一旦註冊，學習者仍可在課程內回頭參閱——若您讓此工具對他們可見，這會是他們查詢實務資訊（例如課程整體結構或教師是誰）的便利位置，而無須直接詢問您。已註冊學習者可檢視您撰寫的區塊，但無法新增、編輯或刪除。

## 存取此工具

從課程首頁的工具格中開啟 **課程說明** <img src="/.gitbook/assets/icons/mdi-apple-safari.svg" alt="課程說明" data-size="line"> 工具。

## 八個區塊

課程說明最多由八個獨立區塊組成。每一項皆為選填——只需填寫與您課程相關的部分：

| 區塊 | 引導問題 |
|---------|-------------------|
| **說明** | 課程目標為何？是否有先修條件？此訓練與其他課程如何連結？ |
| **目標** | 學習者完成課程後應達到什麼成果？課程進行期間會執行哪些活動？ |
| **主題** | 課程如何推進？學習者應特別留意何處？不同領域是否有可辨識的理解困難？各領域應投入多少時間？ |
| **教學方法** | 哪些方法與活動有助達成課程目標？時程為何？ |
| **課程教材** | 是否有教科書、論文集、書目或網際網路上的連結清單？ |
| **資源** | 考量可用的課程、導師、技術支援台、教師及／或教材。 |
| **評量** | 學習者將如何被評量？是否有需發展以掌握主題的策略？ |
| **其他** | 任何不屬於上述類別的內容。您可依需要新增任意數量的**其他**區塊，每一個都有自訂標題。 |

## 新增區塊

1. 在工具列中，點選您要撰寫的區塊類型圖示
2. Chamilo 會顯示該區塊的**說明**方塊，內含引導問題——可用來決定要寫什麼
3. 在富文字編輯器中撰寫內容（支援格式、圖片、連結、嵌入影片及其他豐富內容）。若平台已啟用，您也可為同一區塊撰寫多種語言版本，讓每位學習者自動只看到自己的語言——請參閱[多語言內容](../adding-content/multi-language-content.md)。
4. 儲存

您新增的每個區塊會以獨立卡片顯示在工具中。使用卡片上的 **編輯** <img src="/.gitbook/assets/icons/mdi-pencil.svg" alt="編輯" data-size="line"> 與 **刪除** <img src="/.gitbook/assets/icons/mdi-delete.svg" alt="刪除" data-size="line"> 圖示，即可稍後更新或移除。

## 連結至課程目錄

這是填寫課程說明的主要原因：它會直接餵入訪客與準學習者瀏覽的 **探索更多課程** 目錄。

* **沒有**填寫任何說明區塊的課程，在目錄中顯示為一般卡片。
* **至少有一個**說明區塊的課程會變成可點選——點選其圖片、標題或資訊按鈕，會開啟詳細彈出視窗，依上述相同順序列出您撰寫的每個區塊。

這讓準學習者有實際依據決定是否報名，而不只是標題與縮圖。

> 此彈出視窗是否可用，取決於全平台設定。若您的說明未出現在目錄中給準學習者，請請管理員檢查 **顯示課程說明** 設定（`show_courses_descriptions_in_catalog`），位於 **管理 > 組態設定 > 課程目錄**。

## 提示

* **優先填寫說明與目標區塊**——這是多數準學習者決定是否報名時最先閱讀的內容。
* **保持最新**——課程內容有重大變更時請更新課程說明，讓目錄始終反映學習者實際會獲得的內容。
* **謹慎使用豐富內容**——圖片與格式有助閱讀，但冗長、雜亂的彈出視窗可能比幾段清楚的文字更難掃讀。
