# 自訂課程工具名稱與圖示

Chamilo 3.1 允許獲授權的課程編輯者自訂課程首頁上工具所顯示的**名稱**與 **SVG 圖示**。這些變更僅限於該課程範圍，並保留既有的工具目的地。

## 自訂工具

1. 以獲准編輯課程的使用者身分開啟課程首頁。
2. 在工具格線中啟用**自訂**模式。
3. 開啟您要變更之工具的自訂表單。
4. 輸入所需的**名稱**，並在需要時選取 **圖示** SVG 檔案。
5. 選取**儲存**，並在首頁格線中確認已更新的工具。

工具自訂有別於格線的**排序**、**全部顯示**與**全部隱藏**模式。變更工具的標籤或圖示不會建立新工具、變更其底層 URL，也不會授予學習者額外的存取權限。

## SVG 需求與安全性

請使用來自可信來源的 SVG 檔案。Chamilo 會驗證上傳的 SVG 內容，並拒絕不安全的檔案。若檔案遭拒，請簡化或重新匯出為乾淨的 SVG，而不要嘗試繞過驗證。

請分別以教師與學生身分確認產生的圖示與名稱，並驗證其他課程維持不變。除非學生具備所需的課程編輯權限，否則無法自訂工具。
