# AI 輔助課程技能對應

Chamilo 3.1 可建議與課程相關的技能，並讓獲授權的使用者檢視這些建議，再將其套用至技能參照表與 Gradebook。AI 建議**不會自動套用**；必須經過選取與核准。

## 產生建議

1. 開啟相關課程的 **AI 輔助技能對應** 頁面。應用程式路由為 `/course/{courseId}/skills`，其中 `{courseId}` 須以實際課程 ID 取代。
2. 若課程屬於某個場次（session），請在正確的場次情境中開啟此頁面。
3. 選擇可用的 **AI 提供者**。
4. 選取 **為此課程建議技能**，並檢視回傳的結果。

AI 提供者必須由平台管理人員提供並完成設定。建議可參照 **既有技能** 項目，或在上層技能之下推薦 **新技能**。每個項目可包含其說明、準則，以及對該建議的解釋。

## 檢視與核准

1. 審慎閱讀每項建議，並與課程目標及內容加以比對。
2. 僅使用核取方塊選取有效的技能。
3. 若您具備所需授權，請選擇 **將所選技能新增至參照表與 Gradebook**。
4. 在課程中驗證所產生的技能及其與 Gradebook 的關聯。

不具備指派權限的使用者可以檢視建議，但無法附加這些建議。建立新技能需要平台管理員權限。建議可能會過期；若應用程式回報先前的建議已不再有效，請重新產生一組建議。

## 良好實務

AI 產生的技能僅為候選項目，並非具權威性的課程要求。核准前請檢視用詞、重複情形、上層技能的放置位置以及準則。請避免在 AI 提示中輸入學習者的機密資訊。
