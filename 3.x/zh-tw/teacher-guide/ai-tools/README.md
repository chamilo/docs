# AI 工具

Chamilo 3.0 導入了 AI 驅動的工具，協助您更快建立內容，並為學習者提供個人化支援。這些功能使用大型語言模型（例如 OpenAI 的 GPT、Google Gemini、Mistral 或其他模型）來產生教育內容並協助評分。

> AI 工具必須由平台管理員完成設定後才會可用。設定細節請參閱管理指南中的 [AI Configuration](../../admin-guide/integrations/ai-configuration.md) 一節。

## 可用的 AI 工具

* **[AI Tutor](ai-tutor.md)** — 學習者可與之互動、詢問課程相關問題的 AI 聊天機器人
* **[Exercise Generator](exercise-generator.md)** — 根據課程內容或主題描述自動產生測驗題目
* **[Learning Path Generator](learning-path-generator.md)** — 根據主題或一組學習目標建立結構化的學習序列
* **[AI Grading](ai-grading.md)** — 針對開放式作答與學生繳交內容提供 AI 輔助評量
* **[Glossary Terms Generator](glossary-generator.md)** — 自動為課程詞彙表產生詞條定義
* **[AI Media Generation](ai-media-generation.md)** — 在建立文件時，於富文字編輯器中產生圖片與短影片
* **[Course Picture Generator](course-picture-generator.md)** — 直接從課程設定畫面產生課程縮圖

## AI 工具如何運作

啟用 AI 工具後，它們會出現在相關情境中：

* **Exercise Generator** 會在建立或編輯練習時出現，也會作為文件工具中文件的快捷操作
* **Learning Path Generator** 會在建立學習路徑時出現
* **AI Grading** 選項會出現在作業批改流程中
* **AI Tutor** 可供學習者在課程內使用
* **Glossary Terms Generator** 會出現在詞彙表工具的工具列中
* **AI Media Generation** 對話方塊會在建立或編輯文件時出現於富文字編輯器中
* **Course Picture Generator** 會出現在課程設定中課程圖片欄位旁

所有 AI 產生的內容皆以**建議**形式呈現，您可在發布前檢視、編輯與修改。學習者最終看到的內容，一律由您決定。
