# 評量學習者

Chamilo 提供一套完整的工具，用以評量學習者的知識並追蹤其表現。

* **[訂閱使用者](subscribing-users.md)** — 首先讓學習者進入您的課程：管理員註冊、自行註冊、手動註冊，或電子郵件邀請
* **[練習](exercises.md)** — 建立包含多種題型、自動評分與詳細回饋的測驗與考試
* **[作業](assignments.md)** — 向學習者收取作業與專題，支援檔案上傳、同儕互評，以及手動或 AI 輔助評分
* **[問卷](surveys.md)** — 透過可自訂的問卷蒐集學習者回饋
* **[出席](attendance.md)** — 追蹤學習者在課堂時段的出席情況
* **[成績單](gradebook.md)** — 將練習、作業及其他活動的分數整合成統一成績，並核發證書

**報表**工具仍然存在，但已移至教師課程首頁頂端，以小型圖表圖示呈現。這是存取整門課程及其學生進度資訊的核心位置。

這些工具可相互搭配：練習分數與作業成績可匯入成績單，成績單又可連結至證書產生與技能驗證。
