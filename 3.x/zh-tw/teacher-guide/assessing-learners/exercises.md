# 練習

練習工具（亦稱為「測驗」）可讓您建立具自動評分功能的小考與考試。Chamilo 支援多種題型，從簡單的單選題到互動式熱點題皆可。

## 建立練習

1. 從課程首頁開啟 **練習** <img src="/.gitbook/assets/icons/mdi-order-bool-ascending-variant.svg" alt="練習" data-size="line"> 工具
2. 點選 **新增練習**
3. 輸入 **標題** 與選填的 **說明**
4. 設定練習選項（見下文）
5. 儲存後再新增題目

## 練習設定

![練習設定面板，包含顯示、時間、作答次數與回饋等選項](/.gitbook/assets/exercise-settings.png)

### 顯示與導覽

| 設定 | 選項 | 說明 |
|---------|---------|-------------|
| **題目版面** | 全部顯示於同一頁 / 每頁一題 | 一次顯示所有題目，或一次只顯示一題 |
| **隱藏題目標題** | 是 / 否 | 是否向學習者顯示題目標題 |
| **顯示上一題按鈕** | 是 / 否 | 允許學習者返回先前題目 |
| **禁止向後導覽** | 是 / 否 | 強制學習者依序作答且不得返回 |

### 時間與可用性

| 設定 | 說明 |
|---------|-------------|
| **時間限制** | 完成練習的最長時間（以分鐘計）。學習者會看到倒數計時器 |
| **開始日期** | 練習開始對學習者開放的時間 |
| **結束日期** | 練習停止開放的時間 |

### 作答次數與計分

| 設定 | 說明 |
|---------|-------------|
| **最多次數** | 學習者可作答此練習的次數（0 = 不限次數） |
| **及格百分比** | 及格所需的最低分數（例如 70%）。未達此門檻的學習者會看到不及格訊息 |
| **傳遞負分** | 個別題目的負分是否會使總分低於零 |

### 回饋

| 設定 | 選項 |
|---------|---------|
| **結束時** | 學習者繳交後顯示結果與正確答案 |
| **立即** | 每題作答後立即顯示回饋（適合學習型練習） |
| **考試模式** | 不顯示任何回饋或結果 |

### 結果顯示

控制學習者完成練習後所見內容：

* 顯示分數與預期答案
* 僅顯示分數
* 顯示分數並依類別細分
* 顯示與其他學習者的排名
* 僅在最後一次作答時顯示
* 顯示雷達圖視覺化

### 完成訊息

* **成功訊息** — 學習者及格時顯示的自訂文字
* **失敗訊息** — 學習者未達及格百分比時顯示的自訂文字

### 題目隨機化

| 設定 | 說明 |
|---------|-------------|
| **隨機題目順序** | 每次作答時打亂題目順序 |
| **隨機答案** | 打亂各題內的答案選項 |
| **依類別隨機** | 從各題目類別中隨機選取題目 |

您也可以設定結合類別與隨機化的進階選題策略。

## 題型

![練習建立介面中可用題型總覽](/.gitbook/assets/exercise-question-types.png)

Chamilo 提供豐富的題型，並分為數個類別：

### 單選

* **選擇題（單一答案）** — 學習者從選項清單中選出一個正確答案
* **含圖片的單一答案** — 同上，但答案選項以圖片顯示

### 複選

* **複選答案** — 學習者選出一個或多個正確答案
* **複選答案（下拉選單）** — 答案選項以下拉選單呈現
* **是非題** — 一系列陳述，由學習者標示為正確或錯誤
* **含確定程度的是非題** — 是非題並附加信心程度，可進行更細緻的計分

### 填空

* **填空題** — 學習者補全文本中缺少的字詞。建立題目時由您定義空格與可接受的答案。

### 配對

* **配對題** — 學習者將兩欄中的項目互相連接
* **配對題（可拖曳）** — 概念相同，但使用拖放介面
* **可拖曳** — 將項目拖曳至正確位置

### 開放式

* **自由作答（申論）** — 學習者撰寫文字回應。需人工評分（若已設定，亦可使用 AI 輔助評分）
* **口語表達** — 學習者使用麥克風錄製音訊回應
* **上傳答案** — 學習者上傳檔案作為答案

### 熱點

* **熱點** — 學習者點選影像上的特定區域作答
* **熱點描繪** — 學習者在影像上繪製區域邊界

### 計算題

* **計算答案** — 含公式與容許誤差範圍的數值題。適用於數學與科學課程。

### 特殊題型

* **閱讀理解** — 以閱讀一段文章為基礎的測驗
* **註解** — 教師上傳一張圖片，由學習者在其上進行註解
* **以 Office 文件作答** — 啟用 OnlyOffice 外掛時，學習者透過編輯內嵌的 Office 文件（Word、Excel、PowerPoint）作答。其作答會另存為獨立檔案，置於該練習之下，以便與該次作答的其餘內容一併檢閱。

## 將題目加入練習

1. 開啟練習並點選 **新增題目**
2. 選擇題型
3. 輸入 **題目文字**（支援含圖片與格式的富文字）
4. 定義 **答案** 及其計分：
   * 針對每個答案選項，指定是否正確以及可獲得多少分數
   * 可對錯誤答案給予負分，以抑制猜測
5. 可選擇加入 **回饋** — 學習者作答後顯示的說明
6. 設定 **難度等級** 與 **類別**（有助於隨機抽題與報表）
7. 儲存

## 題目類別

您可將題目整理成類別（例如「單元 1」、「詞彙」、「進階」）。類別適用於：

* 整理大型題庫
* 依類別啟用隨機抽題（例如「從單元 1 抽 5 題、從單元 2 抽 3 題」）
* 在報表中依類別檢視分數細項

## 題目重複使用

同一課程內的練習可重複使用題目。新增題目時，您可選擇建立新題，或從題庫選取既有題目。

## 匯入練習

Chamilo 支援從外部格式匯入練習：

* **IMS QTI / Common Cartridge** — 標準的數位學習測驗格式
* **Moodle format** — 從 Moodle 匯出檔匯入測驗

若要匯入，請在練習工具中尋找 **匯入** 選項並上傳您的檔案。

## 提示

* **混合題型** — 結合選擇題、填空題與開放式題目，以進行較全面的評量
* **使用類別** — 依主題整理題目，以便進行針對性的隨機抽題
* **設定及格百分比** — 給予學習者明確目標，並可透過成績簿連結至證書產生
* **練習時使用即時回饋** — 建立不計分、具即時回饋的練習，協助學習者從錯誤中學習
* **隨機化以維護誠信** — 啟用題目順序隨機與答案隨機，以降低抄襲機會
