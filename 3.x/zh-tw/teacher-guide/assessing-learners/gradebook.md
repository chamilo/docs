# 評量

評量（先前稱為 *gradebook*）會將測驗、作業及其他計分活動的分數彙整為每位學習者表現的統一檢視，並控制證書的產生。

## 評量如何運作

評量是加權計分系統。您需定義：

1. **哪些活動**計入成績（測驗、作業、出席等）
2. **各活動的權重**（對最終成績的佔比）
3. **最低發證分數**（取得證書的門檻）
4. **各活動的最低分數** — 成績簿中的每項活動皆可設定自己的**最低分數**。學習者若在關鍵活動上低於此最低分，即使加權總分已達標，仍可能無法達成目標並取得證書。

活動可分為 2 種類型：
* **課堂活動**（或實體活動），成績需自其他來源匯入
* **線上活動**，自課程中選取，成績透過完成課程內該活動取得

Chamilo 會依這些權重計算每位學習者的總成績。

## 設定評量

1. 自課程首頁開啟 **評量** <img src="/.gitbook/assets/icons/mdi-certificate.svg" alt="成績簿" data-size="line"> 工具
2. 您會看到評量總覽，一開始為空白

### 新增活動

1. 點選 **新增線上活動**
2. 選擇類型：
   * **測驗** — 連結課程中的特定練習
   * **作業** — 連結學員繳交資料夾
   * **學習路徑** — 連結學習路徑完成度
   * **出席** — 連結出席表
   * **論壇討論串** — 連結論壇討論串（需手動評分）
   * **問卷** — 連結問卷
3. 在所選類型中選取特定活動
4. 為此活動設定**權重**（例如期中考 30%、期末專題 40%）
5. 如適用，設定**最低分數**
6. 儲存

所有活動的權重總和應為 100%。

### 子類別

若評分架構較複雜，可建立**子類別**以群組相關活動：

* **範例**：一個「作業」子類別（權重：30%），內含五份個別作業，各佔該子類別的 20%
* 子類別可讓您以階層方式組織評量，同時維持整體計算簡潔

## 檢視成績

![成績簿總覽表格，顯示學習者姓名、活動分數與加權總分](/.gitbook/assets/gradebook-overview.png)

評量會顯示一張表格，內容包括：

* 每位學習者的姓名
* 各活動分數
* 加權總分
* 該學習者是否符合發證資格

您可依任一欄排序，快速找出表現優異或需要協助的學習者。

### 分數分布圖表

表格下方以及**圖形檢視**頁面上，評量會為每項活動繪製一張長條圖，另加一張總分圖。每張皆為直條圖：橫軸由低至高列出分數區間，直條高度為該區間的學習者人數。

**總分**圖表也會標示班級平均。紅色標記落在包含平均分數的區間，圖例會給出精確百分比。

這些圖表僅在已設定分數顯示規則時出現。若看到訊息 *To view graph score rule must be enabled*，請先在評量的計分設定中定義區間。

## 證書

若要啟用證書產生：

1. 在評量設定中，設定**最低發證分數**（例如 70%）
2. 當學習者的加權總分達到或超過此門檻（且未低於任何活動的最低分數）時，即可下載證書
3. 證書依平台管理員設定的範本產生

在根類別啟用 **產生證書** 後，會出現 **證書有效期（天）** 欄位。維持 `0` 表示證書永不逾期；或設定天數，逾期後證書失效 — Chamilo 可在到期日前提醒學習者，可自動（cron，由管理員設定）或自證書清單手動提醒。

![類別編輯對話框，已啟用產生證書，且證書有效期（天）設為 365](/.gitbook/assets/gradebook-certificate-validity-field.png)

詳見 [證書與技能](../tracking-and-reporting/certificates-and-skills.md#certificate-validity-and-expiry)。

## 連結技能

您可將**技能**與評量關聯。當學習者達成完成評量所設目標時，可取得證書、技能，或兩者皆有。技能會顯示於其社群網路空間的個人檔案，長期累積能力紀錄。

## 匯出成績

點選 **匯出** <img src="/.gitbook/assets/icons/mdi-export.svg" alt="匯出" data-size="line"> 按鈕，即可將成績下載為試算表。此功能適用於：

* 與行政系統分享成績
* 在 Chamilo 以外進行額外分析
* 保存離線紀錄

## 提示

* **及早規劃權重** — 在課程開始時即定義評分方案，讓學習者知道預期內容
* **複雜課程使用子類別** — 將作業、測驗與參與度歸入清楚的類別
* **設定有意義的及格門檻** — 認證分數應反映實際能力，而非僅是參與
* **定期檢查** — 定期檢視成績簿，確保所有活動皆已正確連結，且分數正在被記錄
