# 人格問卷

Chamilo 3.1 在現代化的 **問卷調查** 工具中包含人格風格問卷。這些問卷會產生**偏好剖析**，而非評分練習或臨床心理評估。

## 建立問卷

1. 開啟問卷調查工具並建立新問卷。
2. 在其設定中，選擇 **人格** 問卷類型。
3. 開啟**編輯題目**或問卷的題目編輯器。
4. 在新增人格題目前，先定義**人格類別**。每個答案選項都必須屬於某個類別。
5. 新增題目、設定其答案與類別指派，並儲存變更。
6. 在發放問卷前，先預覽學習者體驗。

可用的人格題型有四種：

| 類型 | 學習者如何作答 |
| --- | --- |
| 人格選擇 | 在與類別關聯的選項中選擇 |
| 人格同意度 | 表示對所呈現項目的同意程度 |
| 人格量表 | 以五點量表評定項目 |
| 人格排序 | 將選項由最偏好到最不偏好排序 |

設定包含答案驗證與以類別為基礎的偏好計分。請仔細檢查每道題目的選項與指派：若選項關聯到錯誤的類別，將會改變所產生的剖析。

## 檢視結果

完成問卷後，當問卷回傳剖析資料時，學習者可以看到**您的人格剖析**。教師的問卷報告頁面可以顯示**人格剖析 — 所有學習者**。結果以長條圖／雷達圖視覺化及類別分數呈現。複製問卷會保留人格問卷的設定。

## 成績簿與詮釋

人格問卷無法像一般評量那樣透過成績簿評分。請向學習者說明，結果反映的是對所設定類別的回應，而非診斷、及格／不及格狀態或經過驗證的人格測驗。在蒐集個人回應之前，請檢視隱私與報告可見性設定。
