# 練習與學習路徑的回收桶

Chamilo 3.1 可封存已刪除的練習作答紀錄與學習路徑追蹤資料，以便經授權的教師在設定的保留期限與存取控制範圍內還原這些資料。回收桶用於保護追蹤資料，不能取代資料庫備份。

## 還原練習作答紀錄

1. 在已選取正確課程或場次的情況下，開啟受影響練習的 **報表** 頁面。
2. 選取 **回收桶** 以顯示已封存的作答紀錄。
3. 找出需要復原的學習者與作答紀錄。
4. 選取 **還原**，確認後重新整理報表，以核對答案與分數。

您必須具備管理練習成績的權限。若練習已被成績簿（Gradebook）鎖定，或平台限制教師存取成績，則可能無法還原。

## 還原學習路徑進度

1. 開啟目標課程／場次的相關學習路徑報表畫面。
2. 開啟其 **回收桶**。
3. 選取該學習者已封存的進度，並 **還原**。
4. 檢查已還原的課程進度與相關練習作答紀錄。

若某次練習作答屬於待處理的學習路徑封存，請先還原該學習路徑封存。系統會刻意阻擋個別還原，以避免進度不一致。

## 保留與清理（管理員）

設定 `tracking.recycle_bin_retention_hours` 控制封存資料可復原的時間長度。初始預設值為 **30 天**（720 小時）。既有安裝必須先透過專案的 settings-upsert 遷移同步此新設定，管理介面才會顯示該項目。

預覽清理作業且不刪除任何資料：

```bash
php bin/console chamilo:recycle-bin:purge
```

永久刪除必須明確指定選項：

```bash
php bin/console chamilo:recycle-bin:purge --execute
```

此指令支援 `--hours`（覆寫保留期限）、`--scan-limit`、`--after-lp-id` 與 `--after-exercise-id`，以便受控處理。請僅在確認保留政策與備份安排後再排程執行。僅因功能已啟用，並**不會隱含自動清除排程**。
