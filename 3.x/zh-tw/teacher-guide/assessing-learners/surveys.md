# 問卷調查

問卷調查工具可讓您建立問卷，以蒐集學習者的回饋。問卷調查適用於課程評鑑、需求評估與意見調查。

## 建立問卷調查

1. 從課程首頁開啟 **問卷調查** <img src="../../.gitbook/assets/icons/mdi-form-dropdown.svg" alt="問卷調查" data-size="line"> 工具
2. 點選 **建立問卷調查**
3. 填寫問卷調查詳細資料：
   * **代碼** — 此為問卷調查的唯一代碼。將用於郵件與連結。
   * **標題** — 問卷調查的名稱
   * **副標題** — 選填的次要標題
   * **開始日期** — 此問卷調查自何時起開放參與
   * **結束日期** — 此問卷調查開放參與至何時為止
   * **匿名** — 回應是否匿名，或與個別學習者連結
   * **結果可見性** — 誰可以查看結果（僅導師、導師與學生、所有人）
   * **簡介** — 學習者開始問卷調查前顯示的訊息
   * **感謝訊息** — 提交後顯示的訊息
4. 儲存

### 進階設定

* **計入評量工具成績** — 是否將此問卷調查的作答狀態納入評量工具（成績簿）。已完成問卷調查者得 100%，其餘得 0%
* **上層問卷調查** — 目前實際上並未使用（舊版功能）
* **每頁一題** — 題目的呈現方式
* **啟用隨機模式** — 是否打亂題目順序
* **顯示題號** — 是否顯示（自動產生的）題號

## 新增題目

問卷調查建立後，即可新增題目：

1. 選擇題型：
   * **是／否** — 簡單的二元選擇
   * **單選** — 從多個選項中選擇一個答案
   * **複選** — 從多個選項中選擇一個或多個答案
   * **開放題** — 自由文字回應
   * **下拉選單** — 從下拉清單中選擇
   * **百分比** — 選擇百分比數值
   * **評分** — 以數字量表評分
   * **註解** — 文字區塊（非題目），用於在題目之間加入說明
   * **含「其他」選項的單選** — 從多個選項中選擇一個答案，並提供替代選項
   * **選擇性顯示** — 特殊類型，可依先前答案調整後續題目流程
   * **分頁** — 在題目流程中加入分頁。僅在前一步**未**選取「每頁一題」時才有用
2. 設定題目文字與答案選項
3. 儲存

每道題目皆可標示為必填。若未標示，略過任何題目皆屬可接受的行為。

## 發佈問卷調查

新增所有題目後：

1. 點選 **發佈**
2. 選擇收件者 — 選取特定學習者或群組（由您選取）。**新增學習者** 按鈕可一次加入所有學習者，並將教師排除在外
3. 新增其他使用者 — 可邀請 Chamilo 以外的使用者參與問卷調查。他們將收到含連結的電子郵件，並以其電子郵件地址顯示於問卷調查詳細資料中
4. 郵件主旨
5. 郵件內文 — 說明問卷調查內容以及何時／如何作答
6. 提供重複邀請的不同選項
7. 確認

學習者會收到邀請（以電子郵件形式）以完成問卷調查。

發佈頁面底部提供連結，可邀請更多外部使用者參與。使用此連結的參與者將無法被識別，並在問卷調查結果中顯示為匿名。

## 檢視結果

![各題的圖表與百分比明細之問卷調查結果](../../.gitbook/assets/survey-results-charts.png)

學習者回應後：

1. 開啟問卷調查
2. 點選 **結果** 或 **報告**
3. 檢視回應摘要：
   * 封閉題的圖表與百分比
   * 開放題的個別文字回應
   * 完成率（受邀者中有多少人已回應）

您可將結果匯出為試算表，以便進一步分析。

## 提示

* **力求精簡** — 學習者較可能完成較短的問卷調查
* **使用匿名模式** — 為獲得誠實回饋，請啟用匿名回應
* **掌握時機** — 於課程中期發送問卷調查以便調整，而非僅在課程結束時評鑑
