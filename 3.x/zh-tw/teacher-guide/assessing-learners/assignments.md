# 作業

作業工具（亦稱為「學生作品」）可讓您收集學習者的作品——論文、專題、報告或任何以檔案為基礎的繳交——並進行評分。

## 建立作業

1. 從課程首頁開啟 **作業** <img src="/.gitbook/assets/icons/mdi-inbox-full.svg" alt="作業" data-size="line"> 工具
2. 點選 **建立作業**
3. 填寫詳細資料：
   * **作業名稱** — 作業的名稱（例如「期末專題報告」）
   * **說明** — 給學習者的指示，包括應繳交的內容以及評分方式（支援富文字）
   * **最高分數** — 作業評分所依據的總分
   * **加入成績簿** — 加入評量（成績簿）工具中作為評分項目，以便納入達成課程目標的一部分
   * **截止日期** — 正式（公布）的日期與時間，此後繳交會被標示為遲交（仍可上傳）
   * **結束於（完全關閉）** — 硬性截止的日期與時間，此後無法再上傳
   * **加入行事曆** — 建立事件以標示此作業繳交日期
   * **繳交類型** — 選擇 **僅允許文字**、**僅允許檔案**，或 **允許檔案或線上文字**
4. 儲存

建立作業後，您還可以：
* 在作業詳細頁面內上傳範本文件
* 將作業指派給特定使用者（而非課程中的所有使用者）

學習者繳交作業後，您可以：
* 匯出繳交清單的 PDF
* 顯示尚未繳交作業的學習者清單
* 以大型 ZIP 下載所有作業
* 以大型 ZIP 上傳所有批改
* 刪除您已提交的所有批改（不會刪除學習者的繳交）

## 學習者如何繳交

學習者開啟作業並：

1. 點選 **上傳檔案** 或繳交按鈕
2. 從電腦選取檔案（或依設定直接撰寫文字）
3. 加入選填的註解
4. 繳交

學習者可查看自己是否已繳交，若允許，亦可更新繳交內容。

## 審閱繳交

![作業繳交清單，顯示學生姓名、日期、檔案與評分狀態](/.gitbook/assets/assignments-submissions-list.png)

身為教師，開啟作業即可查看所有繳交清單：

* **學生姓名** — 繳交者
* **繳交日期** — 作品繳交時間
* **檔案** — 下載已繳交的檔案
* **狀態** — 該繳交是否已評分
* **註解** — 學習者或您留下的任何註解

### 為繳交評分

![作業評分畫面，含分數輸入、回饋欄位與批改檔案上傳](/.gitbook/assets/assignment-grading-view.png)

1. 點選一筆繳交以開啟
2. 審閱已繳交的檔案
3. 輸入 **分數**
4. 為學習者撰寫 **回饋註解**
5. 可選擇上傳 **批改檔案** 作為附件
6. 儲存

### AI 輔助評分

若平台已設定 AI 工具，審閱繳交時可能會看到 **AI 評分** 選項。此功能使用 AI 模型為開放式作業建議分數與回饋。詳情請參閱 [AI 評分](../ai-tools/ai-grading.md)。

## 管理繳交

群組動作：
* **下載作業套件** — 將所有繳交下載為單一 ZIP 檔，以便離線審閱
* **上傳批改套件** — 若您已將所有繳交下載為單一 ZIP 檔，在電腦上就地編輯檔案後再次壓縮，即可將該 zip 作為批改套件傳送。請勿變更檔名，否則將無法運作。
* **遲交** — 截止日期後的繳交會被標示，但依您的設定仍可能被接受

個別繳交動作：
* **上傳批改** — 為單一學習者上傳批改
* **下載** — 下載單一學習者的繳交
* **批改並評分** — 為學習者的繳交加入批改與成績
* **編輯** — 編輯文件標題或該繳交先前的回饋
* **移動** — 在作業資料夾之間轉移繳交（例如學生繳到錯誤的作業）
* **可見性** — 控制學習者是否能看到彼此的繳交

## 連結至成績簿

作業分數可納入課程成績簿（「評量」工具）。這可讓作業成績計入學習者的整體課程成績與證書資格。詳情請參閱 [成績簿](gradebook.md)。

## 提示

* **指示務必具體** — 清楚說明學習者應繳交的內容、預期格式與評分標準
* **設定務實的截止日期** — 使用議程工具，讓截止日期顯示在課程行事曆中
* **善用已批改檔案功能** — 上傳學生作業的註解版本，讓他們能看到您的具體修正
* **謹慎啟用同儕可見性** — 允許學習者查看彼此的作業有助於學習，但並非所有作業都適合這麼做
