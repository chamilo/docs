# 分校與教室

Chamilo 內建一套以兩個概念為核心的基本實體位置系統：**分校（branches）** 與 **教室（rooms）**。

**分校** 代表實體據點或校區——例如總部、區域訓練中心或大學建築。分校可以巢狀組織（一棟建築可包含多個部門，一座城市可包含多棟建築）。每個分校可包含一間或多間 **教室**，代表該分校內的個別課堂或實驗室空間。

此功能仍處於早期階段。目前最主要的實際用途，是讓您能為課程附加實體位置標記。

## 為課程指定教室

建立課程時，若管理員已設定教室，課程建立表單中會出現 **預設教室（Default room）** 欄位。請選擇該課程實際進行的教室。

此資訊僅供參考——不會影響課程行為或存取控制。它只是記錄課程實體舉辦地點，有助於管理員管理教室排程，並檢視各課程的教室占用情況。

若平台尚未設定任何教室，此欄位將不會顯示。

## 管理員可以做什麼

分校與教室的管理完全由管理員負責。他們可以：

- 以樹狀階層建立並組織分校
- 將教室加入分校，並可選擇性地加入地理位置與 IP 範圍資料
- 檢視各教室已指定的課程
- 依出席紀錄檢視教室的占用行事曆

若您需要建立教室，或需要將課程改到其他教室，請聯絡平台管理員。
