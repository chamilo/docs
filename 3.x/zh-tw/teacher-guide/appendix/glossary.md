# 詞彙表

本指南中使用的關鍵術語。

| 術語 | 定義 |
|------|-----------|
| **評量** | 請參閱下方的 **成績簿** |
| **作業** | 學習者提交檔案或文字供教師審閱與評分的任務。亦稱為「學生作品」或「work」。 |
| **自動啟動** | 學習者進入課程時自動開啟特定工具的功能。 |
| **證書** | 當學習者達到成績簿中所定義的最低分數時自動產生的文件。 |
| **課程** | 學習內容與工具的容器。課程可包含文件、練習、論壇、學習路徑等。 |
| **課程導師** | 專屬於期程的教師角色。課程導師管理期程中的一門課程。在 Chamilo 3.0 之前的版本中稱為「course coach」。 |
| **磁碟配額** | 分配給課程用於上傳檔案的最大儲存空間。 |
| **註冊** | 將使用者登記至課程或期程、使其得以存取內容的程序。亦稱為「subscription」。 |
| **練習** | 包含一題或多題的測驗。在某些情境中亦稱為「test」。 |
| **論壇** | 以分類與主題組織的討論工具，採串接式對話。 |
| **成績簿** | 將練習、作業及其他活動的分數彙整為每位學習者統一成績的工具。 |
| **學習路徑** | 學習活動（文件、練習、連結）的結構化序列，學習者依既定順序進行，可選擇性地設定先決條件。 |
| **LTI** | Learning Tools Interoperability — 允許將外部學習工具嵌入 Chamilo 的標準。 |
| **SCORM** | Sharable Content Object Reference Model — 電子學習內容套件的標準。Chamilo 可在學習路徑中匯入並播放 SCORM 套件。 |
| **期程** | 指派給特定學習者群體、具時限的一門或多門課程版本。期程可讓相同課程內容重複用於不同學員群。 |
| **期程導師** | 監督期程內所有課程的督導角色。在 Chamilo 3.0 之前的版本中稱為「session coach」。 |
| **技能** | 可與成績簿成就連結的能力。當學習者獲得證書時，相關技能即獲驗證。 |
| **問卷** | 用於蒐集回饋的問卷工具，提供多種題型與匿名作答選項。 |
| **可見性** | 控制工具、文件或活動是否對學習者可見的設定。教師始終能看見隱藏項目。 |
