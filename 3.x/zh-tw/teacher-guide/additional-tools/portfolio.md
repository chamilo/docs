# 作品集

作品集工具讓學習者能在課程期間收集並展示自己的作品。它作為數位作品集，學習者可彙整最佳作品、反思與成就。

## 作品集如何運作

每位學習者在課程中都有個人作品集，可進行以下操作：

* **新增項目** — 使用富文字編輯器撰寫文字條目，並為每個項目附加一個或多個檔案
* **組織內容** — 為項目加上標籤，以便依主題篩選
* **選擇性分享** — 設定每個項目的可見性：隱藏、對課程可見、僅教師可見（對其他人隱藏），或在啟用進階分享時與選定使用者分享

## 身為教師

您可將作品集用於：

* **反思學習** — 請學習者維護一份關於學習歷程的反思作品集
* **能力展現** — 讓學習者收集技能與知識的證據
* **評量** — 將作品集內容納入您的評量

若要檢視學習者的作品集，請開啟作品集工具，並依使用者篩選項目清單。

若課程設定允許，您可為作品集項目與個別評論評分——這些分數可再匯入成績簿。您也可以**標示重點**以引起注意的項目，並將項目或評論標記為**範本**，以便您（或學習者）作為新條目的起點重複使用。作品集可匯出為 **PDF** 或 **ZIP**。

## 提示

* **明確期望** — 告知學習者應納入哪些類型的項目，以及如何組織其作品集
* **定期檢視** — 定期查看作品集，而非僅在課程結束時檢視
* **結合技能** — 將作品集與技能／證書系統搭配使用，以建立完整的能力紀錄
