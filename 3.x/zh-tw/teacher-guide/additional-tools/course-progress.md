# 課程進度

課程進度工具可協助您定義課程的主題結構，並追蹤已規劃內容的實際授課進度。

對學生而言，這項工具特別實用：若因病缺課數日，即可得知已講授哪些主題，以及其餘同學在其缺席期間的進度。

## 運作方式

課程進度分為三層：

* **主題單元** — 課程的主要主題或模組
* **主題計畫** — 各單元預計涵蓋的內容。每筆計畫項目屬於固定類型之一：**目標**、**待習得技能**、**教學方法**、**基礎設施**、**評量**或**其他**。
* **主題進展** — 各單元下的個別授課紀錄，每筆皆有開始日期與時數。授課完成後將進展標示為**已完成**，即可對照計畫追蹤實際進度。

## 設定課程進度

1. 從課程首頁開啟**課程進度**工具
2. 建立對應課程主要主題或模組的**主題單元**
3. 在各單元內依類型新增**計畫**項目，說明預計涵蓋的內容
4. 授課時新增**主題進展**（含日期與時數），並標示為已完成
5. 於**課程設定**區段（課程首頁頂端的齒輪圖示）調整相關設定，決定該資訊在課程首頁上的可見性

您可選擇將主題進展連結至出席表，使其開始日期取自出席紀錄。單元（含其計畫與進展）亦可在同一課程／期次內**複製**。

## 使用情境

* **追蹤教學計畫** — 掌握課程哪些部分已授課、哪些尚未進行
* **與出席整合** — 課程進度可與出席工具並用，將出席情況與已涵蓋主題相互對應
* **報表** — 清楚掌握課程授課狀態隨時間的變化

## 對學習者

學習者可檢視課程進度，以了解課程結構並得知目前已涵蓋哪些主題。對遲到加入或錯過課堂的學習者特別有幫助。
