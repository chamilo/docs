# Dropbox

檔案交換箱（Dropbox）是一種檔案交換工具，讓您與學習者能在課程內互相分享檔案。

> 若要收集需評分的學生作業，通常較適合使用[作業](../assessing-learners/assignments.md)工具，因為該工具包含評分與回饋功能。Dropbox 較適合非正式的檔案分享。

## 傳送檔案

1. 從課程首頁開啟 **Dropbox** 工具
2. 點選 **Share a new file**
3. 選取要上傳的檔案
4. 選擇 **收件者** — 一位或多位已註冊使用者或課程群組
5. 傳送

## 接收檔案

當有人傳送檔案給您時，該檔案會出現在您的 Dropbox 收件匣中。您可以：

* **下載** 檔案
* **新增註解** 至檔案（在收到之後）
* **移動** 檔案至您的其中一個類別
* 從收件匣 **刪除** 檔案

## 整理檔案

已傳送與已接收的檔案皆可整理至自訂 **類別**（資料夾）。使用 Dropbox 工具列中的類別控制項來建立類別，再將檔案移入其中。若平台設定「allow overwrite」已啟用，以相同檔名重新傳送檔案即可覆寫先前版本。

您也可以將選取的檔案批次下載為 ZIP。

## 身為教師

* 您可以將檔案傳送給個別學習者、學習者群組，或所有已註冊使用者
* 您可以檢視學習者傳送給您的檔案
* 此工具適用於分享補充教材、提供個別回饋文件，或接收非正式繳交內容
