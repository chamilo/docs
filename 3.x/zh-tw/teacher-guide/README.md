# 教師指南

歡迎使用 Chamilo 3.0 教師指南。本指南專為講師、培訓人員，以及任何負責透過 Chamilo 平台建立與提供學習內容的人員而設計。

無論您是正在建立第一門線上課程，或是管理複雜的培訓計畫，本指南都將逐步引導您了解身為教師可使用的每一項功能。

## 您能以 Chamilo 做什麼

身為 Chamilo 的教師，您可以：

* **建立與組織課程**，具備彈性的首頁與可自訂的工具
* **新增內容** — 上傳文件、建立學習路徑、建置詞彙表，以及連結外部資源
* **評量學習者** — 設計含多種題型的練習、收集作業、進行問卷調查，以及管理成績
* **協作** — 設定論壇、小組作業、wiki、部落格與即時視訊會議
* **追蹤進度** — 監控學習者活動、產生報表，以及頒發證書
* **使用 AI 工具** — 自動產生練習與學習路徑，並獲得 AI 輔助評分

## 本指南的組織方式

本指南依循建立與經營課程的自然工作流程：

1. **開始使用** — 登入、瀏覽介面，以及設定您的個人資料
2. **建立您的課程** — 建立新課程、設定其組態，以及自訂首頁
3. **新增內容** — 上傳文件、組織學習路徑，以及管理資源
4. **評量學習者** — 建立測驗、收集作業、進行問卷調查，以及設定成績簿
5. **協作與溝通** — 啟用論壇、聊天、小組、wiki 與視訊會議
6. **追蹤與報表** — 監控學習者進度並產生報表
7. **AI 工具** — 使用 AI 驅動功能來產生內容並協助評分
8. **其他工具** — 行事曆、筆記本、作品集等
