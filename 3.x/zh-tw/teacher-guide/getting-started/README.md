# 開始使用

本節協助您熟悉 Chamilo 3.0。您將學習如何登入、瀏覽主要介面，以及設定個人檔案。

## 登入

若要存取 Chamilo，請開啟瀏覽器並前往貴機構提供的網址（例如 `https://chamilo.yourschool.edu`）。在登入頁面輸入使用者名稱與密碼，然後點選 **Sign in**。

若貴機構使用外部驗證（例如 Azure、Keycloak 或大學單一登入系統），您可能會在標準登入表單下方看到額外的登入按鈕。請點選適當的按鈕，透過貴機構的身分提供者進行驗證。

> 若您忘記密碼，請點選登入頁面上的 **Forgot password?** 連結。您將收到一封含重設指示的電子郵件。

## 初次瀏覽

登入後，您將看到 Chamilo 首頁。介面分為三個主要區域：

![顯示系統公告與課程卡片的 Chamilo 首頁](../../.gitbook/assets/home-page-teacher.png)

* **頂部列** — 顯示平台標誌、您的訊息收件匣（附有未讀訊息徽章），以及您的使用者頭像。點選頭像可進入個人檔案與帳戶設定。
* **側邊欄** — 左側導覽面板可讓您快速存取課程、場次、行事曆、社群網路等。您可點選邊緣的切換鈕將其收合。
* **主要內容區** — 顯示目前頁面內容。在首頁上，您會看到系統公告與精選課程。

## 您的課程

從側邊欄點選 **My courses**，即可查看您以教師或學生身分註冊的所有課程。每門課程以卡片呈現，顯示：

![顯示含縮圖與快捷操作之課程卡片的「我的課程」頁面](../../.gitbook/assets/my-courses-list.png)

* 課程圖片或縮圖
* 課程標題
* 快捷操作

若貴機構使用 **sessions**（有時限的訓練期間），側邊欄中也會出現 **My sessions** 連結，並依目前、過去與即將開始的場次分類。

Chamilo 中的場次（session）是一種在不同時間、向不同學習者群體提供同一門課程的方式，而無須複製課程內容。可將場次視為課程的排定版本或同期學員群。後續章節將進一步說明。
