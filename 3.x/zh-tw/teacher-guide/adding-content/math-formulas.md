# 數學公式

所見即所得編輯器可排版數學公式。您以 LaTeX 撰寫公式，學習者會在內容顯示之處看到渲染結果：文件、公告、練習、論壇、wiki 頁面，以及任何使用該編輯器的工具。

公式儲存在內容本身之中，因此在複製或匯出課程時會一併帶走。

## 啟用此功能

公式按鈕預設為關閉。平台管理員可在 **管理 > 組態設定 > 編輯器 > 啟用 MathJax**（[`enabled_mathjax`](../../admin-guide/platform-settings/editor-settings.md)）開啟。

設定開啟後，按鈕會出現在平台上的每個編輯器中。無需依課程另行設定。

## 插入公式

1. 將游標放在公式應出現的位置
2. 點選編輯器工具列中的 **插入公式** 按鈕（Σ 圖示）
3. 以 **LaTeX 程式碼** 輸入公式
4. 在欄位下方的預覽框中檢查渲染結果
5. 點選 **插入**

預覽會在您輸入時更新，因此可在插入前修正錯誤。

## 編輯公式

在編輯器中點選該公式。相同對話框會再次開啟，欄位中為您原本的 LaTeX 程式碼。修改後點選 **插入** 即可取代公式。

若要刪除公式，在編輯器中選取它並按下 <kbd>Delete</kbd>，與其他元素相同。

## 撰寫 LaTeX

公式欄位接受標準 LaTeX 數學記法。若干範例如下：

| 您輸入的內容 | 學習者看到的內容 |
| --- | --- |
| `x = \frac{-b \pm \sqrt{b^2-4ac}}{2a}` | 二次公式 |
| `\sum_{i=1}^{n} i = \frac{n(n+1)}{2}` | 帶上下限的求和 |
| `\int_{0}^{\infty} e^{-x} dx = 1` | 定積分 |
| `\alpha + \beta = \gamma` | 希臘字母 |
| `\begin{matrix} a & b \\ c & d \end{matrix}` | 矩陣 |

您也可以直接在編輯器中輸入原始分隔符號 `\(...\)`、`\[...\]` 或 `$$...$$`。編輯器載入內容時會將它們轉換為公式。

## 注意事項

* 公式函式庫僅在實際含有公式的頁面載入，因此不含公式的頁面不會變慢。
* 一切皆在學習者的瀏覽器中渲染。平台不需外部服務，即使安裝環境無法連線網際網路也能運作。
* 公式會保留其 LaTeX 原始碼。即使多年之後，您仍可重新開啟並閱讀當初撰寫的內容。
