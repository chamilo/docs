# 多語系內容

Chamilo 讓您能在**同一個欄位中撰寫同一份內容的多種語言版本**——例如課程說明區塊、文件、測驗題目、問卷——並讓每位學習者自動只看到以其自身語言撰寫的版本。這就是 **translate_html** 功能，名稱來自控管此功能的平台設定。

此功能涉及三種不同角色，各自看到不同面向：

* **您的管理員**必須先在整個平台啟用此功能，之後任何人才能使用。
* **您（教師）**使用富文字編輯器中的按鈕撰寫不同語言版本。
* **學習者**在完全不知情的情況下受益——他們只會看到自己語言的內容，無需尋找或切換任何設定。

## 啟用此功能

這是管理員的工作，而非教師的工作。在 **管理 > 組態設定 > 編輯器** 底下，必須啟用 **支援多語系 HTML 內容** 設定（`translate_html`）。如果您在編輯器工具列中看不到下方所述的 **Lang ISO** 按鈕，幾乎可以確定就是這個原因——請向管理員詢問。完整設定說明請見 [編輯器設定](../../admin-guide/platform-settings/editor-settings.md)。自 v3.0.0 起，此設定預設為啟用（此版本之前並非如此），除非您是從先前已停用該設定的版本升級而來。

再次關閉此設定並不會刪除或破壞已以此方式撰寫的任何內容——請見下方 [學習者會看到什麼](#what-learners-see)。

## 撰寫多語系內容

只要您使用完整的富文字編輯器，即可使用此功能：[課程說明](../creating-your-course/course-description.md) 區塊、[文件](documents.md)、測驗與問卷題目等。

1. 照常以您的預設語言撰寫（或貼上）內容。
2. 選取該段文字，然後點選編輯器工具列中的 **Lang ISO** 按鈕。

![富文字編輯器工具列，靠近開頭處可見「Lang ISO」按鈕](/.gitbook/assets/teacher-multilang-editor.png)

3. 從選單中選擇您剛才撰寫所用的語言——清單涵蓋平台上所有已啟用的語言。若所需語言未列出，請使用底部的 **Custom Chamilo ISO code...** 並自行輸入（例如 `en_US`、`fr_FR`、`es`）。

![已開啟的「Lang ISO」選單，列出所有已啟用的平台語言，以及「Add translation to...」與自訂代碼選項](/.gitbook/assets/teacher-multilang-lang-menu.png)

4. Chamilo 會以該語言標籤包住您的選取範圍。接著在其後方撰寫（或貼上）下一種語言的版本，選取它，再以不同語言重複相同步驟。

您想涵蓋多少種語言都可以繼續下去。所有版本都存在同一個欄位中——編輯時，您會看到每種語言版本依序堆疊；只有當有人實際*檢視*該頁面時，Chamilo 才會隱藏其餘內容，只留下適用於該使用者的那一種語言（見下文）。

### AI 輔助翻譯

若管理員已設定 AI 文字提供者，同一個 **Lang ISO** 選單頂端也會提供 **Add translation to...**。這會將您現有的內容傳送至已設定的 AI 模型，並插入您所選語言的新自動翻譯區塊（若平台允許，也可一次插入其餘所有語言）——您不必親自撰寫。既有的語言區塊不會被更動，且清單會排除已存在的語言，因此重複使用不會產生重複內容。

與任何 AI 產生的內容一樣，請校對結果——這是快速取得您可能不會說的語言之紮實初稿的方式，而非取代審閱。

## 學習者會看到什麼

每位學習者只會看到恰好一種語言版本：Chamilo 會先嘗試其介面語言；若您的區塊皆不符合，則回退至課程本身的語言，再回退至平台預設語言；若這些都不符合，則顯示您碰巧最先撰寫的那種語言，而不會讓內容空白。這一切皆自動發生——學習者無需設定任何項目，您也無需針對個別學習者設定。

### 幕後運作原理

若您曾開啟多語系欄位的**原始碼**檢視（編輯器工具列中的 `<>` 按鈕），會看到每個語言版本以如下方式包覆：

![原始碼檢視，顯示以 lang="en_US" class="mce-translatehtml" 開頭的區塊](/.gitbook/assets/teacher-multilang-source-view.png)

每個版本會包在 `<div class="mce-translatehtml" lang="...">` 之中（若是短的行內片語而非整段區塊，則為 `<span>`）——Chamilo 正是依此 `lang` 屬性比對檢視者的語言，以決定要顯示的內容。若您正在檢查頁面原始碼或排查顯示異常的內容，值得認得這個特定的 class 名稱：**`mce-translatehtml`** 就是要尋找的標記。

這也說明了為何在平台設定中停用 `translate_html` 不會破壞既有內容：該設定只控制編輯器中是否出現 **Lang ISO** *編寫*按鈕。上述*顯示端*篩選會無條件執行，因此即使管理員之後關閉了編寫按鈕，先前撰寫的多語系內容仍會為每位檢視者正確篩選。

## 標題並非以此方式運作

課程標題、文件標題、測驗標題——這些都是純文字欄位，而非富文字，因此無法容納上述帶 `lang` 標記的標記語法。無論檢視者是誰，它們都維持單一、中性的值，即使您已在其下的內容中撰寫了多個語言版本。

唯一例外：若管理員已針對您正在處理的特定標題欄位啟用**將標題儲存為 HTML**（`save_titles_as_html`，同樣位於**管理 > 組態設定 > 編輯器**），該欄位也會成為真正的 HTML 欄位，即可套用上述相同的 **Lang ISO** 技巧。此做法並不常見，多半用於測驗題目——平台上大多數標題仍維持純文字。

## 提示

* **將來源語言放在最前面** — 把平台最常用的語言放在欄位最前方；若之後忘記為較少見的語言加上標記，這會是最自然的後援。
* **不要巢狀語言區塊** — 將每個版本寫成獨立、依序排列的區塊；不支援把一個包在另一個裡面，且當您插入新標記時，編輯器會主動解開巢狀標記。
* **某個語言下某區段看起來是空的**，通常表示從未為該語言（或其展開後的課程／平台預設後援）標記過區塊——請在原始碼檢視中核對實際存在的語言。
