# 學習路徑

學習路徑可讓您建立結構化的學習活動序列。學習路徑會引導學習者依特定順序瀏覽文件、練習、連結及其他資源，並可選擇設定先決條件與進度追蹤。

此工具可說是課程中最常使用的工具，因為它能作為許多其他工具的編排器，而且往往可以成為學習者所面對的***唯一***工具。

## 為何使用學習路徑？

當您希望達成以下目標時，學習路徑會很有用：

* **控制內容的閱讀順序** — 確保學習者先完成基礎教材再繼續進階內容
* **追蹤進度** — 精確掌握每位學習者在序列中的位置
* **設定先決條件** — 要求學習者通過練習後才能進入下一單元
* **授予完成證明** — 將學習路徑完成情況連結至成績簿與證書
* **封裝內容** — 建立學習者可依自己步調完成的獨立學習模組

## 建立學習路徑

1. 從課程首頁開啟 **學習路徑** <img src="/.gitbook/assets/icons/mdi-map-marker-path.svg" alt="學習路徑" data-size="line"> 工具
2. 點選 **建立學習路徑**
3. 輸入**標題**及選填的說明
4. 儲存 — 系統會帶您進入學習路徑編輯器

## 學習路徑編輯器

![左側為項目樹、右側為內容預覽的學習路徑編輯器](/.gitbook/assets/learning-path-editor.png)

編輯器主要分為兩個區域：

* **左側面板** — 學習路徑中的項目（步驟）清單，以樹狀結構顯示
* **右側面板** — 所選項目的內容

### 新增項目

點選 **新增項目** 並選擇要加入的類型：

| 項目類型 | 說明 |
|-----------|-------------|
| **區段** | 用來群組相關項目的標題（類似章節標題）。區段本身不含內容。 |
| **文件** | 來自課程「文件」工具的檔案或網頁 |
| **練習** | 來自「練習」工具的測驗或考試 |
| **連結** | 外部 URL |
| **作業** | 來自「作業」工具的學生繳交項目 |
| **論壇** | 指向課程論壇的連結 |
| **問卷** | 指向問卷的連結 |
| **證書** | 用於觸發產生完成證書或授予技能的特殊頁面 |

### 整理項目

* **拖放**項目以重新排序
* 將項目向右拖曳，即可**巢狀置於**區段之下
* **刪除**不再需要的項目

### 設定先決條件

先決條件可確保學習者在進入後續步驟前先完成特定步驟：

1. 在學習路徑中選取一個項目
2. 開啟其**先決條件**設定
3. 選擇必須先完成的前項
4. 對於練習，您可以要求**最低分數**（例如：「必須在測驗 1 獲得至少 70% 才能進入模組 2」）

## 學習者體驗

當學習者開啟學習路徑時：

* 他們會在左側面板看到項目清單
* 已完成的項目會以核取記號標示
* 未滿足先決條件的項目會被鎖定
* 進度會自動追蹤 — 若學習者離開後再回來，會從上次離開的位置繼續
* 進度列會顯示整體完成百分比

## SCORM 內容

Chamilo 的學習路徑工具可匯入 **SCORM 1.2** 套件 — 這是最廣泛使用的數位學習標準。上傳 SCORM ZIP 檔後，Chamilo 會據此建立學習路徑，並依 SCORM 規範追蹤進度與分數。

匯入 SCORM 套件的步驟：

1. 在學習路徑工具中，開啟動作選單並點選 **上傳**
2. 上傳 ZIP 檔
3. Chamilo 會自動解壓縮並建立學習路徑

### CMI5 / xAPI 套件

CMI5 套件（以 xAPI 為基礎、作為 SCORM 現代後繼標準）可透過 **XApi** 外掛支援。管理員啟用此外掛後，您即可匯入 CMI5 套件，學習者可從課程中啟動；其陳述會轉送到已設定的 Learning Record Store。

## 使用 C-Studio 編寫內容

*若管理員已啟用 C-Studio 外掛即可使用。*

C-Studio 在學習路徑內提供內建的拖放式視覺編輯器，可直接建立互動內容 — 當您沒有（或不想學習）Articulate 或 iSpring 等獨立編寫工具時，可作為匯入 SCORM 套件的替代方案。您可在 Chamilo 中逐頁建立內容，其儲存與追蹤方式與其他學習路徑項目相同。

### 開始 C-Studio 專案

外掛啟用後，學習路徑清單會在一般動作選單旁多出一個按鈕，標示為「+」，工具提示為「Studio Tools」：

![學習路徑清單在標準動作選單旁顯示 C-Studio「Studio Tools」按鈕](/.gitbook/assets/cstudio-lp-button.png)

點選即可開始。系統會請您從頭建立新專案，或匯入既有專案：

![C-Studio 起始畫面，提供建立新專案或匯入既有專案](/.gitbook/assets/cstudio-start-screen.png)

此畫面目前僅提供法文，與平台或課程語言無關——這是目前所用外掛版本的已知限制。為專案命名後，會直接進入編輯器。

### 編輯器

![C-Studio 視覺編輯器，顯示頁面畫布、右側工具面板與左側專案面板](/.gitbook/assets/cstudio-editor.png)

編輯器是逐頁的視覺建構工具：

* **左側面板** — 專案中的頁面，可用「+」新增，底部有 **Tools** 區段（Clean data、Preview、Colors、Options、Quit）
* **中央畫布** — 正在建構的頁面；點選任一元素即可就地編輯
* **右側面板** — 元件面板，可拖曳到畫布上

面板涵蓋基本建構區塊（欄位、圖片、音訊、標題、文字、按鈕、卡片），以及多種互動練習類型：**Drag Drop**、**Fill text**、**Hotspot Img**、**Mark Words**、**Find Words** 與 **Sort paragraphs**，另有用於嵌入外部內容的 **iframe** 區塊，以及 **Quiz** 區塊。

### 語言

C-Studio 自身介面首次開啟時可能預設為法文，與 Chamilo 介面語言或課程語言無關。若是如此，請前往 **File > UI language** 並選擇您的語言——編輯器會立即重新載入，之後會記住您的選擇。

![開啟的 File 選單，顯示「UI language」選項](/.gitbook/assets/cstudio-file-menu.png)

### 儲存與匯出

工作時請使用 **File > Save**。**File > Export...** 會將專案打包為 SCORM 檔案，可供下載、備份，或透過 **Import...** 在其他地方重複使用。**File > Quit** 會返回學習路徑清單，此時您的 C-Studio 專案會以一般項目顯示。

## 學習路徑設定

設定學習路徑的行為：

| 設定 | 說明 |
|---------|-------------|
| **可見性** | 對學習者隱藏或顯示學習路徑 |
| **先決條件** | 要求先完成其他學習路徑才能進入此路徑 |
| **自動啟動** | 學習者進入課程時自動開啟此學習路徑 |
| **累計 SCORM 時間** | 是否跨多次工作階段累計時間 |

## 連結至成績簿

您可將學習路徑完成情況納入成績簿作為計分活動。如此一來，學習路徑進度可計入學員的整體課程成績與證書資格。

## 使用 AI

若管理員已啟用 AI 輔助學習路徑產生功能，您會在下拉動作選單中看到 AI 產生器選項。盡可能精確地提供學習路徑脈絡，指定頁數與每頁大約字數，再告知是否要填入測驗並啟動。數分鐘後，您即可看到一份完整、以文字為主的學習路徑。

編輯文件並以更多 AI 產生插圖後，只需稍作審閱即可與學習者分享。

## 提示

* **先擬大綱** — 在建構路徑前先規劃章節與項目
* **以區段作為章節** — 將相關項目歸入區段標題下，以利清晰呈現
* **為評量設定先決條件** — 要求學習者先研讀內容再參加測驗
* **混合內容類型** — 結合閱讀教材、影片、互動練習與外部資源，打造吸引人的學習體驗
* **檢查學習者檢視** — 使用學生檢視功能，以學習者角度體驗學習路徑
* **以 SCORM 增加互動性** — 若您可使用 SCORM 編輯工具（如 Articulate、iSpring 或類似工具），可建立豐富的互動內容並匯入 Chamilo。若管理員已啟用 C-Studio 外掛，您也可直接在 Chamilo 中建立類似的互動內容——請參閱上方 [以 C-Studio 進行內容編輯](#content-authoring-with-c-studio)
