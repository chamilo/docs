# 新增內容

本節說明您用來將學習內容加入課程的各項工具。Chamilo 提供多種方式，將教材傳遞給學習者：

* **[文件](documents.md)** — 上傳檔案、建立網頁，並整理您的內容資料庫
* **[連結](links.md)** — 分享外部資源的網址，並依類別整理
* **[學習路徑](learning-paths.md)** — 建立具先修條件與進度追蹤的結構化內容序列
* **[詞彙表](glossary.md)** — 定義關鍵詞彙，供學習者在課程中隨時查閱
* **[公告](announcements.md)** — 向已註冊的學習者發送訊息與更新
* **[多語內容](multi-language-content.md)** — 撰寫同一內容的多種語言版本，讓每位學習者只看到自己的語言

每項工具均可從課程首頁的工具格點進入。點選該工具的圖示即可開啟。
