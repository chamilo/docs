# 支援工單

**Tickets** 工具是內建的服務台系統，讓使用者提交支援請求並追蹤處理進度。依平台設定，您可能以**申請人**身分（為自己或學習者提交工單）或**支援專員**身分（回覆指派至您所屬類別的工單）使用此功能。

## 系統如何組織

工單隸屬於**專案**，專案再細分為**類別**。每個類別可指派一名或多名支援專員。提交工單後，系統會自動將其轉派給所選類別中可用的專員。

預設類別包括：

| 類別 | 說明 |
|----------|-------------|
| Enrollment | 關於課程或場次註冊的問題與狀況 |
| General information | 一般平台問題 |
| Requests and paperwork | 行政申請與文件 |
| Academic Incidents | 與考試、作業或任務相關的問題 |
| Virtual campus | 平台技術問題 |
| Online evaluation | 特定課程評量的問題（需選擇課程） |

## 存取工單工具

若管理員已啟用工單連結，頂部導覽列會出現工單圖示 <img src="/.gitbook/assets/icons/mdi-ticket-account.svg" alt="工單" data-size="line">。點選即可直接前往工單提交表單。

您也可以從主選單的 **Support** 或 **Tickets** 存取工單，實際名稱依平台設定而定。

## 提交工單

若要開啟新的支援請求：

1. 點選 **New ticket**（或頂部列的工單圖示）。
2. 選擇最符合您問題的**類別**。
3. 若該類別有此要求（例如 Online evaluation），請選擇相關**課程**。
4. 輸入**主旨**——問題的簡短摘要。
5. 撰寫**訊息**，詳細描述問題。
6. 可選擇附加檔案（螢幕截圖、文件），協助支援專員了解問題。
7. 點選 **Submit**。

工單會獲派 ID 並轉派給支援專員。專員回覆時您會收到通知。

## 追蹤您的工單

在工單清單中，您可查看自己提交的所有工單及其目前狀態：

| 狀態 | 意義 |
|--------|---------|
| New | 剛提交，尚未審閱 |
| Pending | 支援專員正在審閱 |
| Unconfirmed | 等待確認或補充資訊 |
| Forwarded | 已轉交其他團隊或專員 |
| Closed | 已解決 |

點選任一工單即可閱讀完整對話串並新增回覆。

## 回覆工單

工單開啟後，您與支援專員會在同一對話串中交換訊息。若要新增回覆：

1. 從清單開啟該工單。
2. 捲動至底部的回覆欄位。
3. 撰寫回覆，必要時附加檔案。
4. 點選 **Send**。

對話串新增訊息時，雙方都會收到通知。

## 以支援專員身分處理工單

若管理員已將您指派至一個或多個工單類別，佇列中會顯示來自學習者或同事的待處理工單。

若要回覆已指派的工單：

1. 開啟您的工單清單——已指派工單會與您提交的工單一併顯示。
2. 點選工單以閱讀申請人的訊息。
3. 撰寫回覆並點選 **Send**。工單狀態會自動更新。
4. 問題解決後，將狀態改為 **Closed**。

您也可以變更工單的**優先順序**（Low、Normal、High），以便整理佇列。

> 工單類別的存取權限由平台管理員控管。若您需要被新增為某類別的支援專員，請聯絡管理員。設定選項請參閱管理員指南的 [Tickets Settings](../admin-guide/platform-settings/ticket-settings.md)。
