# 課程自動化（手動觸發）

課程報告的 **自動化** 區段可讓獲授權的教師設定課程開始與結束時的動作。在目前的 Chamilo 3.1 實作中，這些動作是**手動觸發**的：請勿假設它們會在行事曆日期或透過 cron 自動執行。

## 設定動作

1. 以教師身分，或另一位獲准管理課程報告的使用者身分開啟課程。
2. 開啟 **報告**，並找到 **自動化** 區段。
3. 選取事件（**課程現在開始** 或 **課程現在結束**）以及動作類型。
4. 提供該動作所需的目標，然後選取 **新增動作**。
5. 檢視 **已設定的動作** 清單；以其 **刪除** 動作移除不需要的項目。

支援的動作包括發佈或隱藏課程資源、傳送問卷邀請、發放既有證書，以及變更課程可見性。可用的資源、問卷、Gradebook 選項與可見性值，取決於課程以及目前使用者的權限。

## 執行已設定的事件

選擇 **課程現在開始** 或 **課程現在結束**，並確認操作。檢視回報的結果。Chamilo 會追蹤已完成的執行、防止重複設定，並在後續執行時略過已成功完成的動作。不應將再次點選視為重新傳送已完成動作的方式。

若要發放證書，請先準備並測試相關證書。若要傳送問卷邀請，請確認問卷已設定，且預定的學習者屬於目前的課程或場次情境。

## 重要限制

- 此介面提供**手動執行**，而非排程自動化。
- 動作在目前的課程／場次情境中運作；如適用，請針對兩種情境測試存取權與目標。
- 已成功完成的動作不會在後續執行時自動重複。
- 在此功能的 PR 當時，證書發放、課程可見性變更與場次專屬執行已通過程式碼審查，但未在該 PR 中進行功能驗證。在實際依賴這些功能之前，請先在您的安裝環境中測試。
