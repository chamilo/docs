# 追蹤與報表

Chamilo 會全程追蹤學習者在平台上的活動，讓您深入了解學習者的進度。

* **[學習者追蹤](learner-tracking.md)** — 監控個別學習者的活動：登入時間、花費時間、造訪頁面與工具使用情形
* **[課程報表](course-reports.md)** — 檢視課程中所有學習者的彙總資料
* **[證書與技能](certificates-and-skills.md)** — 依成績冊分數核發證書，並驗證已習得的技能

## 存取報表

在課程中，於課程首頁點選 **追蹤** <img src="../../.gitbook/assets/icons/mdi-chart-box.svg" alt="追蹤" data-size="line"> 工具。您也可以從側邊欄的 **報表** 連結進入，以取得跨課程總覽。

教師可查看其所授課程的報表資料。班次導師可查看其所屬班次內所有課程的資料。
