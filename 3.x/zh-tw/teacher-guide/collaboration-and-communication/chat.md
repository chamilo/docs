# 聊天

聊天工具可在課程內提供即時文字訊息功能。適用於快速溝通、即時問答，或非正式討論。

## 使用聊天

1. 從課程首頁開啟 **聊天** 工具
2. 在 **使用者** 面板中，選擇特定線上使用者以直接傳訊，或使用 **全部** 分頁向整組發送
3. 在底部文字欄輸入訊息，按 **Enter** 傳送（**Shift+Enter** 可換行而不傳送）

**預覽** 選項可在傳送前檢查格式，**重設** 則會清除目前草稿。

## 聊天功能

* **即時傳訊** — 訊息會立即顯示給收件者
* **訊息紀錄** — 進入聊天時可看到先前的訊息
* **使用者線上狀態** — 使用者面板會顯示目前在課程中線上的人員
* **一對一或群組** — 可一次傳訊給一位學習者，或透過 **全部** 分頁廣播給所有人

## 身為教師

身為課程教師，您可以：

* **監看討論** — 檢視聊天紀錄以掌握學習者參與情形
* **在文件中找到聊天封存** — 聊天工具會自動將訊息鏡像為 HTML 檔，存放於文件工具中，並依日期與範圍（課程／場次／群組）整理，因此對話會在即時階段結束後仍持續保存

若管理員已啟用平台設定「將課程聊天限制為僅限導師」，則僅導師可與學習者聊天；否則課程中所有已註冊者皆可參與。

## 有效使用聊天的建議

* **安排聊天時段** — 事先告知學習者您何時可進行即時聊天（可使用議程工具）
* **訂定基本規則** — 建立尊重溝通的期望
* **用於快速提問** — 聊天最適合簡短交流；較長、有結構的討論請使用論壇

> 若您的平台已設定視訊會議（BigBlueButton 或 Zoom），在語音與視訊會更有效的即時場次中，可考慮改用該功能。請參閱 [視訊會議](video-conferencing.md)。
