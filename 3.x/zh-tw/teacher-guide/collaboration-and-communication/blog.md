# 部落格

部落格工具可讓您在課程中建立共用部落格。學習者可以撰寫文章、留下留言，並參與結構化的寫作活動。

## 建立部落格

1. 從課程首頁開啟 **部落格** 工具（位於頂端齒輪圖示下方）
2. 點選 **新增專案**
3. 輸入 **標題** 及選用的副標題
4. 儲存
5. 點選 **顯示**（眼睛）圖示，決定何時要讓學生可以使用

您可以在單一課程中建立多個部落格（例如每個主題一個，或每個小組一個）。

## 撰寫部落格文章

1. 開啟一個部落格
2. 點選 **新增文章**
3. 輸入 **標題**，並使用富文字編輯器撰寫文章內容
4. 儲存

教師與學習者（視權限而定）皆可建立文章。

## 留言與評分

讀者可透過以下方式與部落格文章互動：

* **留言** — 在文章下方留下回饋或展開討論（留言亦可串接為對其他留言的回覆）
* **評分** — 為文章評分，以凸顯最受重視的貢獻
* **附件** — 文章與留言皆可附加檔案

## 部落格任務

您可以在部落格中建立 **任務** — 學習者必須以部落格文章完成的特定寫作作業。這適用於：

* 反思日誌
* 每週寫作作業
* 專案進度報告

## 管理部落格

身為教師，您可以：

* **編輯或刪除** 文章與留言（刪除文章僅限文章作者或教師）
* **切換部落格可見性**，對學習者顯示或隱藏部落格
* **定義任務** — 新增學習者應以文章完成的特定寫作作業。任務可加上顏色編碼，以便視覺分組。
