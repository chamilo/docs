# 討論區

討論區工具可讓您在課程中舉辦結構化討論。學習者可以張貼訊息、互相回覆，並進行串接式對話。

## 討論區結構

![顯示類別、討論區與主題數量的討論區類別清單](/.gitbook/assets/forum-category-list.png)

Chamilo 中的討論區分為三個層級：

1. **討論區類別** — 最上層分組（例如「一般討論」、「單元 1 問題」）
2. **討論區** — 類別內的個別討論看板
3. **主題（討論串）** — 討論區內的個別討論主題，各自包含一連串回覆

## 建立討論區類別

1. 從課程首頁開啟 **討論區** <img src="/.gitbook/assets/icons/mdi-comment-quote.svg" alt="討論區" data-size="line"> 工具
2. 點選 **新增討論區類別**
3. 輸入 **類別名稱** 及選填的說明
4. 儲存

## 建立討論區

必須至少已有一個類別，才能新增討論區。

1. 在類別中點選 **新增討論區**
2. 填寫基本資料：
   * **標題** — 此討論看板的名稱
   * **說明** — 選填，說明討論區用途
   * **建立於類別** — 此討論區所屬的類別
3. 開啟 **進階設定** 以設定：
   * **發布日期** / **關閉日期** — 選填的討論區開放時段
   * **審核式討論區** — 新貼文須經教師核准後才會顯示
   * **學習者可以編輯自己的貼文嗎？** — 允許或禁止學習者在送出後編輯貼文
   * **允許使用者發起新討論串** — 設為否時，學習者只能回覆既有討論串
   * **預設檢視類型** — 選擇貼文顯示方式：**平面**、**串接** 或 **巢狀**
   * **用於小組** — 將此討論區附加至課程小組
   * **公開存取 / 私人存取** — 針對小組討論區，決定任何課程成員皆可閱讀，或僅限小組成員
4. 儲存

若課程可見性設為「對全世界開放」，表單還會顯示 **允許匿名貼文？** 選項。可見性受限的課程中會隱藏此選項。

## 管理主題

學習者（以及您）可以在討論區內建立新主題。身為教師，您可以：

* **置頂主題（置頂訊息）** — 建立或編輯討論串時將其標為置頂，使其始終顯示在最上方
* **鎖定主題** — 禁止繼續回覆
* **編輯或刪除貼文** — 審核討論內容
* **移動主題** — 將主題轉移至其他討論區

## 討論區評分

教師建立新討論串時，可在進階設定中啟用 **為此討論串評分**。接著設定最高分數、成績單的欄位標題，以及報表中的權重。您也可以啟用 **由同儕為討論串評分**，這會要求每位學習者至少為另外兩位學習者評分後，自己的分數才會計入。

## 通知

每個討論區與討論串都有 **通知我** 開關，您與學習者可用來訂閱新貼文的電子郵件通知。通知為每位使用者各自的訂閱，並非在建立討論區時設定。
