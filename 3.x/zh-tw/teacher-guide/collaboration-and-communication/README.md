# 協作與溝通

Chamilo 提供多項工具，讓您與學習者之間，以及學習者彼此之間能夠互動。

* **[論壇](forums.md)** — 依類別與主題組織的討論串
* **[聊天](chat.md)** — 課程內的即時文字訊息
* **[小組](groups.md)** — 將學習者分成工作小組，並各自擁有共用工具
* **[Wiki](wiki.md)** — 協作式文件編輯
* **[部落格](blog.md)** — 課程內的共用部落格
* **[視訊會議](video-conferencing.md)** — 使用 BigBlueButton 或 Zoom 進行即時視訊課程

這些工具可從課程首頁使用。部分工具可能預設為隱藏 — 您可從工具格狀檢視中將其設為可見（請參閱 [課程首頁](../creating-your-course/course-homepage.md)）。
