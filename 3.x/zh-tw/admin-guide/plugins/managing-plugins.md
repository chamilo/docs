# 管理外掛程式

## 存取外掛程式管理員

![外掛程式管理員顯示可用外掛程式清單，含啟用開關與設定選項](/.gitbook/assets/admin-plugin-manager.png)

在管理面板中，點選 **Manage plugins** 即可查看可用外掛程式清單。

## 外掛程式狀態

每個外掛程式有下列兩種狀態之一：

* **Active** — 外掛程式已啟用，其功能可在平台上使用
* **Inactive** — 外掛程式已安裝但已停用

## 啟用外掛程式

1. 在清單中找到該外掛程式
2. 點選 **Install**，然後點選 **Enable** 或將其切換為開啟
3. 設定外掛程式選項（如適用，請尋找 **Configure** 按鈕）
4. 儲存
5. 若 README 中有建議，請在特定 **region** 中啟用

部分外掛程式會為課程新增工具、為平台新增頁面，或為既有功能提供額外能力。

## 設定外掛程式

許多外掛程式具有設定選項。啟用外掛程式後：

1. 點選該外掛程式旁的 **Configure** 按鈕
2. 填寫必要設定（API 金鑰、URL、選項等）
3. 儲存

## 停用外掛程式

1. 在清單中找到該外掛程式
2. 點選 **Disable** 或將其切換為關閉
3. 該外掛程式的功能會立即從平台移除，但外掛程式仍保持安裝狀態，並保留其設定，直到您執行 **Uninstall**

停用外掛程式不會刪除其資料。若之後再次啟用，資料仍然可用。

## 提示

* **僅啟用所需項目** — 每個啟用中的外掛程式都會增加一些負擔。請將未使用的外掛程式保持停用。
* **上線前先測試** — 請先在測試環境中啟用新外掛程式
* **檢查相容性** — 升級 Chamilo 後，請確認所有啟用中的外掛程式仍能正常運作
