# BuyCourses 公開與促銷方案

**BuyCourses** 外掛可顯示公開的免費方案，並搭配導向外部產品的促銷卡片。此功能與外掛的付費課程／場次購買流程及定期服務付款設定相互獨立。

## 設定公開方案

1. 開啟 BuyCourses 管理區域及其公開方案卡片編輯器。
2. 在 **免費** 方案下，選擇是否啟用 **顯示免費**。
3. 使用語言分頁輸入免費方案的翻譯標題、說明與功能清單。
4. 視需要新增促銷卡片。設定每張卡片的啟用狀態、位置、目標 URL、選用的圖片 URL，以及翻譯後的標題、說明、功能與按鈕文字。
5. 儲存後，使用可用的預覽／目錄連結，檢查各已設定語言的公開呈現方式。

編輯器會儲存多種語言的翻譯內容。促銷卡片是**通往外部優惠的連結**，並非已完成付款的證明，也不會在 Chamilo 中自動建立訂閱。

## 課程建立限制

免費方案使用平台的標準課程建立限制。BuyCourses 會區分標準課程配額與付費課程配額。若已設定有限上限，課程建立介面可顯示使用量與進度；無限方案則不需要百分比指示器。

請分別以僅具標準配額的帳號，以及具有適用付費配額的帳號測試這些限制。公開促銷卡片絕不應繞過伺服器端的課程建立權限。

## 付款行為

公開方案卡片不會取代 BTCPay、Stripe、PayPal，或此外掛既有的課程購買與定期服務流程。請繼續在現有的 BuyCourses 設定中管理並測試付款閘道。
