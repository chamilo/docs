# 外掛程式

外掛程式可在不修改核心程式碼的情況下擴充 Chamilo 的功能。Chamilo 3.0 內建超過 50 個外掛程式，可依需求啟用。

## 外掛程式區塊

管理儀表板另有獨立的 **外掛程式** 區塊，與本章的一般外掛程式管理分開。它不會列出所有已安裝的外掛程式——僅列出其設定宣告應出現在管理選單區域的外掛程式，讓這類外掛程式在儀表板上直接捷徑至各自的管理頁面。

![管理儀表板上的外掛程式區塊，列出已設定為出現在管理選單中之已安裝外掛程式的捷徑](../../.gitbook/assets/admin-plugins-block.png)

若您已啟用的外掛程式未出現在此處，這是預期行為——表示該外掛程式並未宣告自己屬於管理選單區域，並非系統故障。請參閱 [管理外掛程式](managing-plugins.md) 以取得完整的已安裝外掛程式清單，無論它們是否出現在儀表板上。
