# 常見問題

Chamilo 3.0 管理員常見問題。

## 安裝與設定

**問：Chamilo 3.0 需要哪個 PHP 版本？**
答：PHP 8.3、8.4 或 8.5。請參閱 [伺服器需求](../installation/server-requirements.md)。

**問：我可以在共用主機上執行 Chamilo 嗎？**
答：可行但不建議。Chamilo 3.0 需要 Composer、開發模式下的 Node.js，以及用於安裝與維護的命令列存取。VPS 或專用伺服器能提供更好的使用體驗。

**問：應該使用哪種資料庫？**
答：MySQL 8.0+ 或 MariaDB 10.4+ 最常使用，測試也最完整。

**問：可以不透過命令列安裝 Chamilo 嗎？**
答：可以，若您使用套件版本（.zip 或 .tar.gz）。否則，您需要命令列來安裝 Composer 相依套件、建置前端資產，以及執行資料庫遷移。網頁精靈可處理資料庫設定與初始組態，但週邊步驟在開發模式下需要 shell 存取。

## 使用者與驗證

**問：如何重設使用者密碼？**
答：前往 **管理 > 使用者清單**，找到該使用者，點選編輯並設定新密碼。或者，使用者可在登入頁使用「忘記密碼」連結（若已設定電子郵件）。

**問：可以批次匯入使用者嗎？**
答：可以。前往 **管理 > 匯入使用者**，上傳含使用者資料的 CSV 或 XML 檔。匯入支援建立新使用者與更新既有使用者。

**問：如何與 LDAP 或 Active Directory 整合？**
答：在驗證組態中設定 LDAP。請參閱 [LDAP](../authentication/ldap.md)。使用者會在登入時同步，或透過排程同步。

**問：使用者可以同時屬於多個課程期程嗎？**
答：可以。使用者可同時註冊任意數量的課程期程。每個課程期程獨立追蹤進度。

## 課程與內容

**問：如何備份單一課程？**
答：在課程內前往 **維護 > 建立備份**。這會產生可下載的課程內容與設定封存檔。您可在同一或不同的 Chamilo 實例上還原。

**問：可以複製課程嗎？**
答：可以。使用 **管理 > 複製課程** 或課程內的課程維護工具。您可在課程之間複製內容，或從既有課程建立新課程。

**問：支援哪些 SCORM 版本？**
答：Chamilo 支援 SCORM 1.2。SCORM 套件會以學習路徑形式匯入。

**問：如何限制誰可以建立課程？**
答：前往 **管理 > 組態設定 > 課程**，停用 **允許非管理員（教師）建立新課程**（`allow_users_to_create_courses`）。停用後，僅管理員可建立課程。或者，您可設定每位教師可建立的課程數量上限。

## 效能與維護

**問：平台很慢。應先檢查什麼？**
答：依影響程度：(1) 確認 `.env` 中 `APP_ENV=prod` 且 `APP_DEBUG=0`。(2) 確認已啟用 PHP OPcache。(3) 檢查資料庫效能。(4) 請參閱 [效能調校](../platform-settings/performance-tuning.md)。

**問：如何清除快取？**
答：從命令列執行 `php bin/console cache:clear --env=prod`。應用程式執行中請勿手動刪除 `var/cache/` 目錄。

**問：Chamilo 需要多少磁碟空間？**
答：應用程式本身未壓縮約需 2 GB。總空間取決於上傳內容（文件、影片、SCORM 套件）。請監控磁碟用量並據此規劃。

**問：如何設定自動備份？**
答：請參閱 [備份](../maintenance/backups.md)。至少應排程每日資料庫傾印，並定期對上傳目錄進行檔案層級備份。

## 電子郵件

**問：使用者收不到電子郵件。應檢查什麼？**
答：(1) 確認 `.env` 中的 `MAILER_DSN`。(2) 執行 `php bin/console mailer:test someone@example.com` 進行測試。(3) 檢查垃圾郵件資料夾。(4) 確認 SPF/DKIM DNS 紀錄。請參閱 [電子郵件組態](../installation/email-configuration.md)。

**問：可以用 Gmail 寄送電子郵件嗎？**
答：可以，適用於小型平台或開發環境。請使用應用程式密碼，並注意 Gmail 每日寄送上限（一般帳號為每日 500 封）。

## 安全性

**問：如何強制使用 HTTPS？**
答：設定網頁伺服器將 HTTP 重新導向至 HTTPS。另外，在 **管理 > 組態設定 > 安全性** 啟用「強制 HTTPS」設定。請參閱 [安全性設定](../platform-settings/security-settings.md)。

**問：如何阻擋暴力破解登入攻擊？**
答：在安全性設定中設定最大登入嘗試次數與 CAPTCHA。亦可考慮在伺服器層級使用 fail2ban 以加強防護。

**問：使用者忘記密碼且電子郵件無法使用。我該如何協助？**
答：以管理員身分直接編輯該使用者帳號並設定新密碼。前往 **管理 > 使用者清單**，找到該帳號並更新密碼欄位。

## 升級

**Q: 我可以直接從 Chamilo 2.x 升級到 3.0 嗎？**
A: 可以，但這是一次重大遷移，而非單純的更新。請參閱 [升級](../installation/upgrading.md)。務必先在預備伺服器上測試。

**Q: 升級到 3.0 後，我的外掛還能運作嗎？**
A: 不能。2.x 的外掛與 3.0 不相容，必須改寫，或以 3.0 的等效功能取代。
