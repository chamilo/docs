# 管理指南

歡迎使用 Chamilo 3.0 管理指南。本指南專為負責安裝、設定與管理 Chamilo 實例的平台管理員而設計。

## 管理員可以做什麼

身為 Chamilo 管理員，您可管理：

* **安裝與設定** — 在伺服器上安裝 Chamilo，設定儲存、電子郵件與環境選項
* **使用者** — 建立、匯入並管理使用者帳號、角色與權限
* **課程與會期** — 監督課程建立、管理課程目錄，並設定培訓會期
* **平台** — 語言、入口網站新聞、全域行事曆，以及 Pages CMS 工具
* **平台設定** — 設定入口網站行為、安全性、效能與功能可用性
* **分析** — 平台統計、學習分析，以及企業／人資報表
* **技能** — 定義能力徽章並將其連結至成績簿結果
* **系統** — 伺服器維護工具、自我更新、儲存檢查與品牌識別
* **教室** — 管理實體場地與可預約的培訓教室
* **安全性** — 監控登入嘗試、檢視標記的入侵嘗試、檢查密碼強度，並驗證檔案完整性
* **外掛** — 安裝、設定並管理平台擴充功能
* **驗證** — 設定外部登入系統（OAuth2、LDAP、CAS、SCIM）
* **整合** — 將 Chamilo 連接至視訊會議、LTI 工具、AI 供應商等
* **維護** — 執行備份、監控系統健康狀態並管理儲存空間

## 本指南的組織方式

1. **入門** — 管理介面概覽
2. **安裝** — 伺服器需求、安裝精靈與初始設定
3. **使用者** — 管理使用者帳號、角色、群組與個人資料
4. **課程** — 管理課程、類別與匯入／匯出
5. **會期** — 組織有時限的培訓群體
6. **平台** — 語言、入口網站新聞、全域行事曆，以及 Pages CMS 工具
7. **平台設定** — 設定平台的各個面向
8. **分析** — 統計、學習分析，以及企業／人資報表
9. **技能** — 能力徽章與由成績簿驅動的獎勵
10. **系統** — 伺服器工具、自我更新、儲存檢查與品牌識別
11. **教室** — 分校與可預約的培訓教室
12. **安全性** — 安全監控與稽核工具
13. **外掛** — 管理平台擴充功能
14. **健康檢查** — 即時設定檢查
15. **其他管理區塊** — Chamilo.org 連結、版本檢查、支援與新聞
16. **驗證** — 設定外部驗證供應商
17. **整合** — 連接第三方服務
18. **Multi-URL** — 從單一安裝執行多個入口網站
19. **效能調校** — 針對速度與規模最佳化平台
20. **維護** — 備份、系統狀態與清理
