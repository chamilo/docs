# 技能與評量

此處是技能與成績簿的連結點：它是評量結果與自動授予技能之間的橋樑。

## 存取技能與評量

在管理面板中，點選 **Skills > Skills and assessments**。

## 顯示內容

成績簿類別清單，並提供將各類別連結至技能的控制項。一旦連結，任何達到該成績簿類別及格門檻的學習者，都會自動獲得對應技能——無需手動操作。

這是大規模授予技能的建議方式：與其逐一為使用者指派技能，不如一次連結相關成績簿類別，即可套用至所有符合資格的學習者。成績簿類別與門檻的初始設定，請參閱 [Gradebook (Assessments)](../platform-settings/gradebook-settings.md)。
