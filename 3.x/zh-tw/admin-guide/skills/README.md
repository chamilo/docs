# 技能

管理儀表板上的 **技能** 區塊，彙整了用於在整個平台上定義、組織與追蹤能力徽章（「技能」）的工具。技能可在學習者達到成績簿門檻、完成特定課程時自動授予，或由教師手動授予，並可附帶徽章樣式圖示與等級（例如銅／銀／金）。

![管理儀表板上的技能區塊，列出技能輪盤、技能匯入、管理技能、管理技能等級、技能排名，以及技能與評量](../../.gitbook/assets/admin-skills-block.png)

整個區塊僅在 **啟用技能工具** 設定（`skill.allow_skills_tool`，位於組態設定 > 技能）開啟時才會顯示——預設為啟用。

## 存取技能區塊

在管理面板中，**技能** 區塊會與其他儀表板區塊並列顯示。點選其中任一連結即可開啟對應工具。

## 區塊內容

* **[管理技能](managing-skills.md)** — 建立技能、大量匯入，並將每一項指派至等級量表
* **[技能輪盤](skills-wheel.md)** — 整個技能樹的可縮放視覺地圖
* **[技能排名](skills-ranking.md)** — 依已取得技能排列的使用者排行榜
* **[技能與評量](skills-assessments.md)** — 將成績簿類別連結至其所授予的技能

## 相關設定

組態設定 > 技能底下的其他幾項設定，會改變誰能對此區塊執行哪些操作：

* **允許人力資源技能管理** (`allow_hr_skills_management`) — 讓人力資源管理員使用者可與管理員一同管理技能
* **允許私人技能** (`allow_private_skills`)
* **教師可指派技能** (`skills_teachers_can_assign_skills`)
* **隱藏技能等級** (`hide_skill_levels`)
* **在技能輪盤上顯示完整技能名稱** (`show_full_skill_name_on_skill_wheel`)
