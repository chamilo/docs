# 課程匯入與匯出

Chamilo 支援匯入與匯出課程，以利備份、遷移與內容分享。

這些功能位於課程內部，在課程首頁頂端齒輪圖示下的 **維護** 工具中。

## 匯出課程

教師可從課程維護工具匯出自己的課程。身為管理員，您可以匯出任何課程：

1. 進入該課程
2. 開啟 **課程維護** 工具
3. 選擇 **建立備份**
4. 選擇要包含的項目（內容、使用者資料等）
5. 下載匯出檔案

匯出會產生一個套件，內含該課程的文件、測驗、論壇、學習路徑與設定。

## 匯入課程

若要從 Chamilo 匯出檔匯入課程：

1. 進入該課程
2. 開啟 **課程維護** 工具
3. 在 **匯入備份** 區段上傳匯出檔案
4. 選擇要包含的項目（內容、使用者資料等）
5. 設定匯入選項：
   * 是否覆寫既有內容
   * 是否包含使用者資料
6. 執行匯入

## 複製課程

若要將另一門課程的內容複製到您的課程，必須先備妥來源課程與目的地課程。

1. 進入目的地課程
2. 開啟 **課程維護** 工具
3. 在 **複製課程** 區段選擇 **來源** 課程
4. 確認選項
5. 按一下 **繼續** 並依指示操作

## Common Cartridge

Chamilo 支援 **IMS Common Cartridge 1.3**（IMS CC 1.3）標準，以便與其他學習管理系統互通。您可以：

* **匯入** Common Cartridge 套件（.imscc 檔案）
* 以 Common Cartridge 格式 **匯出** 課程內容

如此即可與支援 Common Cartridge 標準的其他平台（Moodle、Canvas、Blackboard 等）交換內容。

## 回收課程

課程回收功能僅保留課程外殼，並清除其內容。

## 刪除課程

此操作會徹底清除您的課程，包含所有內容以及其中的使用者活動。

若要永久刪除課程：

1. 進入目的地課程
2. 開啟 **課程維護** 工具
3. 在 **完全刪除此課程** 區段，手動輸入課程代碼以確認您的意圖
4. 確認

之後您會被重新導向至入口網站首頁，因為該課程已不存在。

## Moodle 匯入

Chamilo 可匯入來自 **Moodle** 的課程備份。匯入程式會將 Moodle 的內容結構轉換為 Chamilo 格式，包含測驗、文件與課程設定。

> **開發中。** 雖然已涵蓋相當廣泛的範圍，Moodle 匯入程式目前尚未涵蓋每一種 Moodle 活動類型與內容格式。請將其視為起點，匯入完成後可能仍需手動調整。若您發現匯入或匯出有任何失敗或缺失的元素，請透過我們的 [Github space](https://github.com/chamilo/chamilo-lms/issues) 回報，點選頂端的 **New issue**，並提供盡可能詳細的資訊（若非機密，亦請附上課程備份本身）。

## 提示

* **定期備份** — 鼓勵教師定期匯出課程作為備份
* **測試匯入** — 從其他平台匯入內容時，請先在試用課程中測試匯入，以確認一切皆正確轉移
* **內容可攜性** — 需要與其他 LMS 平台分享內容時，請使用 Common Cartridge 格式
