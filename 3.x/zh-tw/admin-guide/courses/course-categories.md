# 課程類別

課程類別有助於整理課程目錄，讓學習者更容易找到相關課程。

## 建立類別

1. 從管理面板前往 **課程類別**
2. 按一下 **新增類別**
3. 輸入：
   * **類別代碼** — 簡短且唯一的識別碼
   * **類別名稱** — 顯示名稱（例如「資訊科技」、「管理技能」）
   * **允許在此類別中新增課程？** — 是否允許課程將此設為類別，或僅作為階層中的中間層級
   * **上層類別** — （選填）將此類別置於另一個類別之下以建立階層
   * **說明** — （選填）
   * **圖片** — （選填）將代表此類別，雖然幾乎不會顯示在任何地方
4. 按下 *新增類別*

Chamilo 預設會建立 3 個類別：*Language skills*、*PC Skills* 與 *Projects*。可依需求重新命名、移除或保留。

## 類別階層

![顯示巢狀類別樹狀結構的課程類別管理頁面](../../.gitbook/assets/admin-course-categories.png)

類別可以巢狀化以建立樹狀結構：

* 商業
  * 管理
  * 行銷
  * 財務
* 科技
  * 程式設計
  * 網路
  * 資安

瀏覽課程目錄的學習者可透過此階層導覽以尋找課程。

## 管理類別

* **編輯** — 變更類別名稱、代碼或上層類別
* **移動** — 變更類別在清單中的位置
* **刪除** — 移除類別。已刪除類別中的課程會移至「未分類」。

## 提示

* **保持簡單** — 使用學習者一眼就能理解的廣泛類別
* **限制深度** — 避免過深的巢狀類別。兩到三層通常已足夠。
* **在建立課程時指定類別** — 鼓勵教師在建立課程時選擇類別，讓目錄保持井然有序
