# 管理課程

身為管理員，您可以管理平台上的所有課程，無論課程是由誰建立的。

## 課程清單

![課程清單顯示所有課程的標題、代碼、類別、已註冊使用者與可見性狀態](/.gitbook/assets/admin-course-list.png)

從管理面板點選 **課程清單** 即可查看所有課程。清單會顯示：

* 課程標題與代碼
* 語言
* 類別
* 可見性狀態

使用 **進階搜尋** 工具可找出特定課程。

## 建立課程

身為管理員，您可以建立課程並指派給任何教師：

1. 從管理面板點選 **新增課程**
2. 填寫課程詳細資料（標題、代碼、類別、語言）
3. 為課程指派教師
4. 儲存

注意：在 Chamilo 1.11.x 中，課程代碼會顯示為課程 URL 的一部分，且在課程建立後無法變更。此行為自 2.x 起已改變。課程代碼不再顯示於 URL 中，未來版本可能允許教師事後修改課程代碼，因為它對平台而言已變得較不重要。

## 管理既有課程

在清單中找到課程，即可在 *動作* 欄使用管理選項：

* **資訊** — 顯示課程相關資訊 
* **課程首頁** — 直接帶您前往該課程的首頁 
* **報表** — 查看參與度與表現資料
* **編輯** — 變更課程標題、類別、可見性及其他設定
* **建立備份** — 前往課程的維護區段，您可在此建立複本並執行其他操作
* **加入目錄** — 將此課程加入課程目錄
* **刪除** — 永久移除課程及其所有內容

> 刪除課程會永久移除所有內容、學習者資料、成績與追蹤資訊。建議先匯出課程作為備份。

## 批次操作

在清單中選取多門課程即可執行批次動作，例如刪除。若要匯出課程，請進入該課程並使用 **維護** 工具——管理課程清單上沒有批次匯出動作。

## 課程可見性設定

管理員可以覆寫教師所設定的可見性：

| 可見性 | 效果 |
|-----------|--------|
| **公開** | 所有人皆可存取，包括匿名訪客 |
| **開放** | 所有已登入使用者皆可存取 |
| **私人** | 僅已註冊使用者可存取該課程 |
| **關閉** | 無人可存取該課程（教師與管理員除外） |
| **隱藏** | 無人可檢視或存取該課程（管理員除外） |
