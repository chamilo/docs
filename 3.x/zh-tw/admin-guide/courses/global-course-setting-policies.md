# 全域課程設定原則

平台管理員可以為課程設定定義集中式預設值，並控制教師是否可以覆寫這些設定。這些原則適用於既有課程功能，同時保留相容的課程專屬組態。

## 開啟原則頁面

在**主要存取 URL** 上，開啟 **管理 > 設定 > 課程設定**，或前往您安裝環境中的 `/admin/settings/course-settings`。此管理頁面僅供主要存取 URL 上已授權的平台管理員使用。請勿使用次要入口網站編輯全域原則。

## 設定原則

1. 若需要特定的課程設定鍵，請使用 **搜尋** 欄位。
2. 針對每項設定，請核對其標題下方顯示的確切變數名稱。
3. 選取或清除 **可在課程中編輯**，以控制課程編輯者是否可以變更該設定。
4. 選擇或輸入 **平台預設值**。部分設定提供允許值下拉選單；其他設定則接受文字。
5. 儲存變更，並在測試課程中驗證實際行為。

在不同類別中重複使用相同變數名稱的設定，會在必要時分別顯示。請勿假設兩個外觀相似的名稱控制相同的課程功能。

## 以兩種角色驗證

以管理員身分確認已儲存的預設值及其是否可編輯。以課程教師身分開啟對應的課程設定，並檢查實際值與編輯限制是否符合原則。請盡可能同時測試既有課程與新課程。

變更全域預設值可能影響許多課程。在停用教師的覆寫權限之前，請先評估其影響，並記錄先前的原則值，以便必要時還原。
