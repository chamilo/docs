# 系統狀態

系統狀態頁面可協助您確認 Chamilo 伺服器已正確設定，並找出潛在問題。

## 存取系統狀態

在管理面板中，點選 **系統狀態**（或 **系統資訊**）。

## 顯示內容

![系統狀態頁面，顯示 PHP 設定、資料庫狀態、檔案權限與伺服器資訊](../../.gitbook/assets/admin-system-status.png)

### PHP 設定

* **PHP 版本** — Chamilo 3.0 支援 PHP 8.3、8.4 與 8.5
* **必要擴充套件** — 檢查所有必要的 PHP 擴充套件是否已安裝
* **PHP 設定值** — 驗證重要的 PHP 設定，例如記憶體上限、上傳上限與執行時間

### 資料庫狀態

* **資料庫連線** — 確認資料庫可存取
* **資料庫版本** — 顯示資料庫伺服器版本

### 檔案權限

* **可寫入目錄** — 檢查 Chamilo 能否寫入必要目錄（快取、上傳、日誌）

### 伺服器資訊

* **作業系統** — 伺服器作業系統詳細資訊
* **網頁伺服器** — Apache、Nginx 或其他
* **磁碟空間** — 可用儲存空間

## 建議檢查項目

請定期執行下列檢查：

* **安裝完成後** — 確認所有需求皆已滿足
* **升級之後** — 確保 PHP 版本與擴充套件仍相容
* **發生問題時** — 疑難排解時請先檢查系統狀態
