# 備份

定期備份對於保護您的 Chamilo 資料至關重要。本頁說明應備份的內容以及備份方式。

## 應備份的內容

### 1. 資料庫

Chamilo 資料庫包含所有平台資料：使用者、課程、追蹤紀錄、成績、訊息與設定。這是最關鍵、必須備份的元件。

**備份方式：**

```bash
mysqldump -u username -p chamilo_database > chamilo_backup_$(date +%Y%m%d).sql
```

### 2. 檔案

Chamilo 將上傳的檔案（文件、圖片、SCORM 套件）儲存在檔案系統中。需要備份的主要目錄：

* `var/` — 上傳的檔案與資源
* `public/plugin/` — 外掛檔案（僅在您有新增自訂外掛時）

若您使用雲端儲存（S3、Azure Blob），請確認已啟用雲端供應商的備份／版本控制功能。

### 3. 組態

* `.env` — 您的環境組態
* `config/` — 任何自訂組態檔

## 備份時程

| 元件 | 建議頻率 |
|-----------|---------------------|
| 資料庫 | 每日 |
| 檔案 | 每日或每週（視上傳活動而定） |
| 組態 | 每次組態變更之後 |

## 還原

從備份還原：

1. 從 SQL dump 還原資料庫
2. 還原檔案目錄
3. 還原組態檔
4. 清除 Symfony 快取：`php bin/console cache:clear`

## 建議

* **自動化備份** — 使用 cron jobs 自動執行備份
* **異地存放** — 將備份副本存放於另一台伺服器或雲端儲存
* **測試還原** — 定期測試能否成功從備份還原
* **記錄流程** — 撰寫還原流程說明，讓團隊中任何人都能執行
