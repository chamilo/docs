# 已簽署憑證驗證

Chamilo 可為成績簿證書核發**數位簽署憑證**，並可選擇將憑證指紋錨定於 **Sepolia Ethereum 測試網路**。簽章與驗證頁面有別於一般 PDF 證書。

## 啟用已簽署憑證

在 **管理 > 組態設定 > 證書** 下，若貴機構打算使用此功能，請啟用 `certificate.blockchain_verification_enabled`。此功能預設為停用。入口網站必須使用 HTTPS 才能核發憑證。

## 學習者同意為先

證書持有者開啟 **我的證書**，並明確選擇 **核准發布**。同意範圍涵蓋一份可公開驗證的憑證，其中顯示持有者姓名、課程、分數與核發日期，並可選擇包含 Sepolia 上的 SHA-256 指紋。核准並非自動進行。學習者日後可選擇 **撤回同意**；撤回會影響驗證頁面所顯示的有效性，但**無法抹除已確認的區塊鏈指紋**。

## 核發、驗證與撤銷

經直接驗證身分的平台管理員，可在持有者同意後，使用成績簿的 **證書** 清單核發已簽署憑證。產生的驗證連結使用 `/certificates/verify/{token}`；亦提供 `.json` 驗證回應。該頁面會檢查密碼學簽章、同意、撤銷、到期，以及底層證書資訊是否仍與已簽署來源相符。

若憑證遭撤銷、同意被撤回、證書內容變更，或簽章無效，驗證器會指出該狀態，而非回報為有效憑證。

## 選用的 Sepolia 錨定

管理員可使用支援的瀏覽器錢包選擇 **錨定至 Sepolia 測試網**，或選擇 **確認既有 Sepolia 交易** 以核對待處理交易。錢包必須連線至 Sepolia（鏈 ID `11155111`）。應用程式使用伺服器設定的 **HTTPS Sepolia RPC 端點**（`CHAMILO_CERTIFICATE_SEPOLIA_RPC_URL`）確認交易。不接受由請求提供的 RPC URL。

僅錨定憑證指紋；個人資料不會作為交易資料提交。Sepolia 為**測試網**。其紀錄與可用性不得被表述為生產等級的公開區塊鏈保證。請安全儲存機構金鑰與 RPC 組態，並規劃金鑰復原與憑證撤銷程序。
