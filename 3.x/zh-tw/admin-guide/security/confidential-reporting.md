# 機密舉報

Chamilo 提供一項可選的**機密舉報**工作流程，供使用者向獲授權的調查人員提交對另一位使用者的關切事項。此功能並非一般的支援工單工具，亦非公開討論論壇。

## 啟用此功能

開啟**管理 > 組態設定 > 安全性**，並設定下列項目：

| 設定 | 預設值 | 用途 |
|---|---|---|
| `security.confidential_reporting_enabled` | `false` | 啟用機密舉報工作流程 |
| `security.confidential_reporting_min_reporters` | `2` | 調查案件對調查人員可見之前，所需的不同舉報人數下限（2–10） |
| `security.confidential_reporting_attachments_enabled` | `true` | 允許附加證據 |
| `security.confidential_reporting_notifications_enabled` | `false` | 對符合資格的調查顯示內部指示（不傳送電子郵件） |

部署時亦須確認伺服器的機密舉報加密與私有儲存已就緒。Chamilo 使用 PHP Sodium 加密函式與一把私有加密金鑰；**請妥善保存並備份該金鑰**。遺失金鑰可能導致已儲存的舉報無法讀取。請勿將金鑰複製到 Git 儲存庫。在確認私有金鑰儲存與所需的資料庫遷移均已正常運作之前，請勿啟用此功能。

## 提交舉報

1. 直接登入 Chamilo，並開啟**機密舉報**（須已為該入口網站啟用）。
2. 選擇相關人員，輸入主旨並描述事件。
3. 若已啟用附件，可加入證據。
4. 決定調查人員是否可查看您在此特定舉報中的**姓名與電子郵件**。此授權日後可以撤回。
5. 送出舉報。使用**我的機密舉報**追蹤案件，並與調查人員交換訊息。

舉報人的身分**預設不會向調查人員顯示**。此為保密控制措施，並非對系統營運者保證絕對匿名。

## 調查權限與門檻

調查需要專用的 `welfare:investigate` 權限，以及符合資格的管理員或人力資源角色。僅當針對同一對象的**不同舉報人**人數達到所設定的數量後，案件才可供調查。調查人員不得調查關於自己的舉報。人力資源的存取範圍僅限於該人力資源主管所追蹤的使用者。

調查人員可透過**機密調查**檢視符合資格的案件、審閱證據並交換訊息。未達門檻或未獲授權的案件不會透過調查 API 揭露。管理上的**模擬登入**並不提供機密舉報的存取權。

## 隱私與營運注意事項

舉報與所附證據包含敏感個人資料。請限制調查人員權限、限制備份存取、訂定適當的組織保存政策，並以分開的舉報人、對象與調查人員帳號測試此工作流程。避免將完整舉報複製到技術日誌或問題追蹤系統。
