# 活動稽核

「活動稽核」報表可讓您依事件類型篩選，瀏覽重要的管理與平台活動。此報表與先前可從 **追蹤 > 管理活動稽核** 進入的底層報表相同；現在也直接從「安全性」區塊連結，因為它主要是安全性與課責工具。

## 存取活動稽核

在管理面板中，點選 **安全性 > 活動稽核**。

## 顯示內容

![活動稽核頁面列出事件類型類別，例如課程、時段、使用者、社交、訊息、資源、Wiki 與其他，每一類皆可展開為個別事件類型](/.gitbook/assets/admin-security-activities-audit.png)

事件依類別分組：

* **課程** — 課程建立、刪除與設定變更
* **時段** — 時段與時段類別的建立、刪除與註冊變更
* **使用者** — 帳號建立、刪除、密碼更新、欄位變更等
* **社交** — 社交群組建立、刪除與成員變更
* **訊息** — 訊息資料變更與刪除
* **資源** — 資源與資源連結的建立與刪除
* **Wiki** — Wiki 頁面檢視
* **其他** — 其餘項目，包括外掛活動、成績簿鎖定、練習作答刪除、強制登入嘗試，以及平台層級設定變更

點選事件類型晶片（例如 **嘗試強制登入**）即可將報表篩選為符合條件的項目表格。您也可以使用事件類型清單上方的 **搜尋** 欄位，直接以關鍵字搜尋。

## 使用情境

* 調查是誰刪除了課程、時段或使用者帳號，以及何時刪除
* 確認特定管理變更（設定更新、外掛安裝）是否由預期的管理員執行
* 搭配 [登入嘗試](login-attempts.md) 報表，追蹤 **嘗試強制登入** 事件
