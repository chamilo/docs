# 安全性

管理儀表板上的 **安全性** 區塊彙整了平台內建的安全性監控與稽核工具。它與 [安全性設定](../platform-settings/security-settings.md) 分開：後者設定安全性*政策*（密碼規則、CAPTCHA、HTTP 安全性標頭等）——此區塊則提供*報表與工具*，用以監看平台上的可疑活動與非預期變更。

![管理儀表板上的安全性區塊，列出活動稽核、登入嘗試、簡易 IDS、密碼強度檢查器與檔案完整性](../../.gitbook/assets/admin-security-block.png)

此區塊於 Chamilo 2.0 推出時包含四項工具，並於 Chamilo 3.0 新增第五項：**檔案完整性**。

## 存取安全性區塊

在管理面板中，**安全性** 區塊會與其他儀表板區塊（使用者、課程、平台管理、系統等）並列顯示。點選其中任一連結即可開啟對應工具。

## 區塊內容

* **[活動稽核](activities-audit.md)** — 依事件類型瀏覽重要的管理與平台事件（使用者、課程、工作階段及其他變更）
* **[登入嘗試](login-attempts.md)** — 檢視失敗與成功的登入嘗試，含圖表與可搜尋的紀錄
* **[簡易 IDS](simple-ids.md)** — 查看由 Chamilo 內建輕量入侵偵測系統標記的請求
* **[密碼強度檢查器](password-strength-checker.md)** — 掃描作用中使用者是否使用常見密碼清單中的密碼
* **[檔案完整性](file-integrity.md)** *（Chamilo 3.0 新增）* — 偵測已安裝檔案中非預期的新增、修改、刪除或權限變更

## 誰可以存取

全部五項工具皆需 **入口網站管理員** 權限。檔案完整性的掃描、暫停與重新建立基準線動作另外需要 **全域管理員** 權限，且暫停警示或建立新基準線時必須重新輸入您自己的密碼——詳見 [檔案完整性](file-integrity.md#actions)。
