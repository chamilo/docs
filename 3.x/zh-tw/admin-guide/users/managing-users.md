# 管理使用者

本頁說明建立、編輯與管理使用者帳號的日常作業。

## 使用者清單

![使用者清單，顯示帳號的姓名、電子郵件、角色與狀態欄](/.gitbook/assets/admin-user-list.png)

在管理面板中，點選 **User list** 即可查看平台上的所有使用者。清單會顯示：

* 頭像
* 姓名
* 使用者名稱
* 電子郵件地址
* 角色
* 啟用／停用狀態
* 註冊日期
* 最後登入日期

使用 **Advanced search** 工具，可依姓名、電子郵件、角色或其他條件尋找特定使用者。

## 建立使用者

![使用者建立表單，包含姓名、電子郵件、使用者名稱、密碼、角色與語言欄位](/.gitbook/assets/admin-user-create-form.png)

1. 在管理面板中點選 **Add a user**
2. 填寫必填欄位：
   * **First name** 與 **Last name**
   * **Email** — 在平台上必須是唯一的
   * **Username** — 登入名稱（必須是唯一的）
   * **Password** — 設定初始密碼
   * **Roles** — 選取使用者的平台角色（學生、教師、管理員等）
   * **Language** — 使用者偏好的介面語言
3. 可選擇填寫其他欄位：
   * 正式代碼（例如機構內的唯一識別碼）
   * 電話號碼
   * 到期日 — 於指定日期後自動停用帳號
   * 啟用／停用狀態
   * 額外個人資料欄位（若已設定）
4. 儲存

## 匯入使用者

![用於上傳含使用者資料之 CSV 或 XML 檔案的使用者匯入介面](/.gitbook/assets/admin-user-import.png)

若需大量建立使用者，可從檔案匯入：

1. 在管理面板中點選 **Import users**
2. 上傳含使用者資料的 **CSV** 或 **XML** 檔案
3. 將檔案欄位對應至 Chamilo 使用者欄位
4. 選擇如何處理既有使用者（更新或略過）
5. 匯入

匯入檔案至少應包含以下欄位：名字、姓氏、電子郵件、使用者名稱與密碼。

注意：**Status** 欄是 **Role** 的舊稱，僅接受少數值，例如 1 代表教師、5 代表學生。角色的進一步調整只能之後以手動編輯使用者的方式完成。

## 匯出使用者

點選 **Export users**，即可將使用者清單下載為 CSV 或 XML 檔案。您可依角色、註冊日期或其他條件篩選要匯出的使用者。

## 編輯使用者

在使用者清單中點選使用者的姓名即可編輯其帳號。您可以修改：

* 個人資訊（姓名、電子郵件、電話）
* 角色
* 密碼（重設）
* 啟用／停用狀態
* 到期日
* 額外個人資料欄位

## 刪除使用者

刪除曾在平台上建立內容的使用者（通常是教師）時，系統可能會阻止您永久刪除，並顯示警告訊息，說明該使用者仍連結至部分資源。若您確認刪除，系統不會刪除內容本身，而是將內容掛到中性使用者（我們稱之為「Fallback user」），以維持資料一致性。

若要避免此情況，請先查看使用者詳細資料，逐一刪除其課程，再刪除該使用者。

## 使用者動作

| 動作 | 說明 |
|--------|-------------|
| **Deactivate** | 停用使用者帳號但不刪除。使用者無法登入，但其資料會保留。 |
| **Activate** | 重新啟用先前已停用的帳號。 |
| **Login as** | 以該使用者身分登入平台（模擬登入）。適用於疑難排解。 |
| **Anonymize** | 依歐盟 GDPR 的定義，清除該帳號的所有個人資訊。 |
| **Delete** | 軟刪除使用者帳號。請使用 **Deleted users** 分頁永久刪除帳號及相關資料。 |

> **Login as** 是功能強大的功能。請負責任地使用，且僅用於正當的支援目的。

## 批次作業

在使用者清單中選取多位使用者，即可執行批次動作：

* 一次啟用或停用多位使用者
* 刪除多位使用者
* 將使用者指派至課程或 session

## 提示

* **大量註冊請使用 CSV 匯入** — 在培訓計畫開始時為大量使用者辦理入學時，請準備 CSV 檔並批次匯入
* **設定到期日** — 對於臨時使用者（工作坊學員、試用使用者），請設定到期日以自動停用其帳號
* **優先停用而非刪除** — 當使用者離職時，請先停用其帳號。如此可保留其培訓紀錄。僅在確定不再需要資料時才刪除。
