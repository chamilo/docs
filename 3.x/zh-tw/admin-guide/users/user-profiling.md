# 使用者剖析

Chamilo 允許您定義自訂剖析欄位（額外欄位），以擷取標準姓名、電子郵件與角色以外的使用者額外資訊。

## 額外剖析欄位

![額外剖析欄位清單，顯示自訂欄位的名稱、類型與可見性設定](/.gitbook/assets/admin-extra-fields-list.png)

額外欄位可讓您儲存組織專屬的中繼資料，例如：

* 員工編號
* 部門
* 職稱
* 地點／辦公室
* 電話號碼
* 自訂識別碼

## 建立額外欄位

1. 從管理面板前往 **Extra fields** 或 **Profile fields**
2. 按一下 **Add**
3. 設定該欄位：
   * **Name** — 顯示給使用者的欄位標題
   * **Description** — 選填說明
   * **Helper text** — 將顯示於任何包含此欄位之表單中該欄位下方
   * **Field type** — 文字、下拉選單、日期、核取方塊等
   * **Field label** — 欄位的內部名稱，供外掛整合使用
   * **Possible values** — 若該欄位為從這些值中選取的選擇器
   * **Default value** — 選填的預設值
   * **Visible to self** — 該欄位是否可由使用者本人在其使用者剖析中看見
   * **Visible to others** — 該欄位是否對平台上的其他使用者可見
   * **Can change** — 使用者是否可自行變更自己的欄位（或僅管理員可變更）
   * **Filter** — 若此為選擇器類型欄位，是否將其納入管理頁面的篩選條件（例如將使用者註冊至課程或場次）
   * **Order** — 若您要管理欄位的顯示順序，必須為每個欄位指定數字順序
   * **Remove on anonymization** — 對隱私規則與法規相當重要：若使用者被匿名化但未被刪除，此欄位是否應視為可能持有個人可識別資料？
4. 儲存

## 欄位類型

額外欄位引擎支援廣泛的輸入類型。常見類型包括：

| Type | Description |
|------|-------------|
| **Text** | 單行文字輸入 |
| **Textarea** | 多行文字輸入 |
| **Radio** | 單選圓鈕群組 |
| **Dropdown / Dropdown multiple** | 預先定義選項清單（單選或多選） |
| **Double select** | 兩個相依的下拉選單（例如：國家 → 城市） |
| **Checkbox** | 是／否切換 |
| **Date / Date and time** | 日期或日期＋時間選擇器 |
| **Integer** | 數值輸入 |
| **Tag** | 多個自由格式標籤值 |
| **File** | 檔案上傳欄位 |
| **Video URL** | 指向影片的 URL |
| **Mobile phone number** | 格式化的電話號碼欄位 |
| **Timezone** | 時區選擇器 |
| **Social profile** | 社群網路剖析連結 |
| **Divider** | 表單內的視覺分隔（無值） |

可用類型的確切集合取決於 Chamilo 版本；**Extra fields** 管理頁面中的欄位類型下拉選單為準確來源。

## 使用額外欄位

額外欄位會出現於：

* 使用者建立（若對本人可見）與編輯表單
* 使用者剖析頁面（若對本人可見）
* 使用者匯入（您可在 CSV 匯入中包含額外欄位值）
* 匯出與報表（依額外欄位值篩選或分組）

## 提示

* **建立前先規劃** — 在建立欄位前先定義您需要哪些資訊，因為資料輸入後再變更欄位類型可能會造成問題
* **使用下拉選單以維持一致性** — 當欄位有已知的可能值集合時，請使用下拉選單而非自由文字，以確保資料一致性
* **用於報表** — 額外欄位有助於篩選報表（例如：「顯示部門 X 中已完成訓練 Y 的所有使用者」）
