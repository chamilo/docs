# 使用者角色

Chamilo 採用以角色為基礎的權限系統。每位使用者會被指派一個角色，該角色決定其在平台上可檢視與執行的內容。

## 平台層級角色

這些角色控制對全平台功能的存取：

| 角色 |  說明 |
|------|------------|
| **學習者（學生）** | 預設角色。可報名課程、存取學習內容、繳交作業並參加測驗。 |
| **教師（培訓者）** | 可建立與管理課程、新增內容、為學員評分，並檢視課程層級報表。 |
| **會期管理員** | 可建立與管理會期（即依時間包裝的課程套件）、將使用者報名至會期，並指派導師。無法存取一般平台設定。 |
| **人力資源管理員（HRM）** | 可檢視所指派使用者的追蹤與報表資料。適用於需監督員工訓練、但不管理內容或平台的主管。 |
| **入口網站管理員** | 可完整存取所有平台管理功能。可管理使用者、課程、會期、外掛以及所有設定。 |
| **全域管理員** | 與入口網站管理員相同，但在多 URL（即多租戶）環境中可跨所有存取 URL 進行存取；若註冊於非根 URL，則範圍僅限該 URL 的分支。請參閱 [子樹管理員](../multi-url/access-urls.md#subtree-administrators)。 |
| **匿名** | 供未登入訪客使用的特殊角色。若已啟用，可存取公開課程與內容。 |

## 課程層級角色

在課程內，使用者具有特定角色：

| 角色 | 說明 |
|------|-------------|
| **學生** | 預設課程角色。可存取內容、參加測驗、繳交作業。 |
| **課程助理** | 在課程內具有有限的管理權限。可協助管理內容並審核論壇。 |
| **教師** | 對課程擁有完整控制權：管理內容、工具、設定與報名。 |

## 會期層級角色

在會期內，另有下列角色：

| 角色 | 說明 |
|------|-------------|
| **會期導師** | 監督會期內的所有課程。可檢視該會期所有課程的追蹤資料。 |
| **課程導師** | 在會期內教授特定課程。可管理該課程內容，並追蹤該會期中該課程的學習者。 |

注意：此角色在 Chamilo 3.0 之前的版本中稱為「coach」。自 Chamilo 3.0 起，平台介面與文件中已全面以「tutor」（導師）取代「coach」——導師是協助學習者完成課程的人，而非私人教練。`Configuration settings` 中底層設定名稱為向後相容仍含有「coach」（例如 `add_users_by_coach`），但其標籤現已顯示為「tutor」。

## 指派角色

在管理面板中建立或編輯使用者帳號時，您可選擇其平台層級角色。課程與會期角色則在將使用者報名至課程或會期時指派。

## 角色階層

權限較高的角色會繼承權限較低角色的能力：

* 管理員可執行教師能執行的一切操作
* 教師可執行學生能執行的一切操作
* 會期層級角色（導師）僅在其所指派的會期內提供額外能力

## 提示

* **採用最小權限原則** — 僅指派使用者執行其任務所需的最低角色
* **以會期管理員進行委派管理** — 若有人員需管理訓練會期但不需管理整個平台，請給予會期管理員角色，而非完整管理員權限
* **以 HRM 供主管使用** — 人力資源管理員可監督訓練進度，而無須擁有修改課程或平台設定的權限
* **角色建立** — Chamilo 3.x 已具備建立新角色的內部結構，但該功能尚需更多測試才能廣泛釋出。可透過 [Chamilo 官方供應商](https://chamilo.org/providers) 啟用。
