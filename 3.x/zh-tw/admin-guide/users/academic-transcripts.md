# 學術成績單

Chamilo 可根據學習者已完成且已取得證書的課程產生**非正式學術成績單**，並允許授權人員核發**正式簽署成績單**。此功能與單一課程證書或其選用的 Sepolia 測試網驗證並不相同。

## 啟用此功能

在 **管理 > 組態設定 > 證書** 中，啟用 **學術成績單**（`certificate.transcript_enabled`）。此功能預設為停用。請在 [證書設定](../platform-settings/certificate-settings.md#transcript_enabled) 中檢視其他學程、評分量表、課程時數、學號、地址與簽署人設定。

成績單使用符合資格的課程與學習時段之**根成績簿類別**所產生的證書。其中僅包含學習者在目前存取 URL 範圍內仍訂閱的課程。沒有符合資格證書的課程不會產生一列資料。

顯示的最終成績為所列課程百分比分數的平均值；GPA 為對應成績點數的未加權平均值。兩者皆取決於檢視或核發當下所包含的課程。

## 成績單欄位

| 欄位 | 內容 |
|--------|---------|
| **課程** | 課程代碼，或課程的系所名稱（`transcript_course_code_source`） |
| **說明** | 課程標題；若課程是在學習時段中修習，則同時包含學習時段標題 |
| **註冊** | 學習者訂閱課程或學習時段的時間 |
| **規定時數** | `transcript_hours_extra_field` 所設定之課程額外欄位的值，或課程時長 |
| **完成日期** | 證書日期 |
| **已完成時數** | 學習者在課程中所花費的時間；若已啟用 `transcript_completed_hours_are_required_hours`，則為規定時數 |
| **最終成績** | 證書分數 |
| **等級** | 與該分數相符的 `transcript_grading_scale` 字母等級 |

## 存取學習者的成績單

1. 前往 **管理 > 使用者 > 使用者清單** 並找到該學習者。功能啟用後，授權的管理員與學習時段管理員可使用 **成績單** 動作。
2. 或者，從符合資格之學習者的全域報告詳細頁面使用 **成績單** 動作。
3. 檢視學習者的課程清單、成績、日期、時數、最終成績與 GPA。
4. 選取 **下載非正式成績單**，以根據學習者目前紀錄產生 PDF。

成績單頁面亦可由獲授權存取該學習者紀錄的人員直接透過 `/transcript?userId=<user-id>` 開啟。請勿將知悉 URL 或使用者 ID 視為授權：存取權限會在伺服器端檢查。

學習者可以檢視**自己的**成績單，但無法核發或撤銷正式成績單。授權核發者包括：

* 在其管理的使用者／存取 URL 範圍內行事的平台／入口網站管理員。
* 負責其所追蹤學習者的人力資源管理員。
* 負責其管理之學習時段中已註冊學習者的學習時段管理員。

這些權限會依個別學習者評估；僅具有職員角色本身並不授予存取每一份成績單的權限。

## 核發與驗證正式成績單

1. 在獲授權學習者的成績單頁面上，檢查目前顯示的課程、成績與個人資訊。
2. 選取 **核發正式成績單** 並確認。Chamilo 會儲存該時刻資訊的已簽署快照。
3. 新項目會出現在 **正式成績單** 之下，並顯示核發日期與核發者。
4. 使用 **下載** 取得正式 PDF，或使用 **驗證** 開啟公開驗證頁面。
5. 如有需要，授權核發者可以 **撤銷** 該正式成績單。驗證頁面隨後會顯示該成績單已撤銷。

每一份已核發的成績單都會分別儲存：核發較新版本不會悄悄改寫先前的已簽署紀錄。驗證連結遵循 `/transcripts/verify/<token>`，並同時提供 `.json` 回應。持有驗證連結者無需登入即可檢查有效性；請妥善控管這些連結，因為有效的驗證會揭露已簽署的成績單詳細資訊。無效或已撤銷的紀錄不會被呈現為有效文件。

![有效正式成績單的公開驗證頁面，包含其詳細資訊與課程](../../.gitbook/assets/admin-transcript-verification.png)

正式成績單由 Chamilo 使用機構的簽署金鑰進行數位簽署。**這並非區塊鏈交易**；Sepolia 功能所記載的是成績簿證書憑證的另一套獨立流程。

## 簽名影像與簽署人詳細資料

平台管理員可在學習者成績單頁面的 **正式成績單簽名** 區段上傳 **PNG 或 JPEG** 簽名影像。該影像屬於目前的存取 URL，並用於正式 PDF。簽署人姓名與職稱來自 `certificate.transcript_signatory_name` 與 `certificate.transcript_signatory_title`。

僅平台管理員可管理簽名影像；其他獲授權的成績單核發者不會自動取得此權限。請將機構的簽署金鑰與私有簽名影像儲存納入入口網站的備份與存取控制程序加以保護。兩者皆存放於公開網頁資料夾之外的 `var/certificate-issuer/`，並與同樣用於簽署成績冊證書憑證的金鑰一併保存：請將此資料夾納入您的[備份](../maintenance/backups.md)，否則所有已核發的成績單與憑證將無法再被驗證。

## 疑難排解

* **成績單連結遺失：** 請檢查 `certificate.transcript_enabled` 以及目前使用者的範圍。
* **沒有已完成的課程：** 學習者需要一份符合資格的根成績冊證書，以及與此存取 URL 相符的目前課程／場次註冊。
* **學號、時數、成績字母或學程名稱不正確：** 在核發正式成績單之前，請檢視特定的 `certificate.transcript_*` 設定。
* **驗證回報已撤銷或無效的結果：** 請勿再將該紀錄用作目前正式成績單的證明；授權人員可在適當時核發新的成績單。
