# 班級／使用者群組

管理面板中的班級是平台層級的群組，用於管理目的組織使用者。它們與課程層級的群組（由教師在課程內建立）不同。

> 使用者群組與 [班級](../../admin-guide/sessions/classes.md) 共用同一介面。唯一差異是 **群組類型** 設定：選擇「班級」以建立班級（用於批次工作階段註冊），或選擇「使用者群組」以建立較具社交性質、可在內部社交網路擁有專屬空間的群組。工作階段註冊的詳細說明請參閱 [班級](../../admin-guide/sessions/classes.md)。

## 建立群組

![使用者群組清單，顯示可用群組的名稱、說明與成員人數](../../.gitbook/assets/admin-user-groups-list.png)

1. 從管理面板前往 **班級**
2. 點選 **新增班級**
3. 輸入 **標題** 與選填的 **說明**
4. 若此群組將作為社交群組，請勾選 **社交群組**。若將作為班級，則保持未勾選。
5. 可選填參考 URL 與圖片／標誌。
6. 選擇群組 **權限**：
   * **開放** — 任何使用者皆可加入
   * **封閉** — 使用者必須由管理員加入
7. 勾選是否允許成員自行離開班級。
8. 儲存。

## 新增成員

1. 開啟班級／使用者群組清單
2. 點選使用者圖示 **將使用者註冊至班級**
3. 依姓名、使用者名稱或電子郵件搜尋使用者
4. 選取要新增的使用者，使用右側箭頭操作
5. 點選確認按鈕以儲存

## 使用情境

* **部門組織** — 依部門或團隊將使用者分組
* **批次註冊** — 一次將群組所有成員加入課程或工作階段
* **定向溝通** — 向特定群組發送公告
* **報表** — 依群組篩選檢視訓練進度

## 管理群組

* **編輯** — 變更群組名稱、說明或可見性
* **管理成員** — 新增或移除成員
* **刪除** — 移除群組（不會刪除成員帳號）
