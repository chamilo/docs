# 健康檢查

健康檢查是管理儀表板上的一個小型區塊，會對您的安裝執行若干即時檢查，並標示任何需要注意的項目——無需翻閱設定檔即可發現常見的錯誤設定。

## 存取健康檢查

在管理面板中，**健康檢查**區塊會與其他儀表板塊並排顯示——無需點選，結果會直接呈現。

## 檢查項目

* **電子郵件設定** — 驗證是否已設定郵件程式連線字串以及「寄件者」電子郵件／名稱。若尚未設定，會連結至郵件設定以便修正。
* **所有 URL 皆至少指派一名管理員** — 在多 URL 安裝中，檢查每個存取 URL 是否至少有一名可管理該 URL 的管理員。若有未指派者，會連結至存取 URL／使用者指派頁面。
* **`.env` 不可寫入** — `.env` 存放機密資訊，安裝完成後不應由網頁伺服器寫入。若可寫入則標示為錯誤；並連結至安全性指南。
* **`config/` 不可寫入** — 理由與 `.env` 相同：在正常運作時，此目錄不應可由網頁寫入。會連結至安全性指南。
* **`var/cache` 可寫入** — 相反的檢查：Symfony 需要寫入其快取目錄，因此若*無法*寫入則標示為錯誤。會連結至效能調校／最佳化指南。
* **安裝資料夾不存在** — `public/main/install` 資料夾僅在安裝期間需要，之後應予移除。若仍存在則標示為警告（而非嚴重錯誤），因為其風險嚴重度低於上述兩項可寫入性檢查。會連結至安全性指南。

## 應如何處理

每項檢查都會直接連結至您可修正根本問題的位置——設定頁面或相關指南。請在安裝完成後立即依此清單檢查，之後也應定期執行（例如在手動傳輸檔案或變更權限之後），因為今日通過並不保證之後仍會通過。若需這六項檢查以外更完整的正式環境強化清單，請參閱[安全性指南](appendix/security-guide.md)。
