# 專業支援

專業支援是一個小型唯讀面板，說明官方 Chamilo 支援服務——若貴機構需要超出社群支援範圍的付費協助，此面板相當實用。

## 顯示內容與資料來源

此面板會從 `version.chamilo.org/c/support/latest.php` 擷取內容，並依您平台的介面語言提出請求。平台僅會傳送該語言代碼——不會傳送任何與平台使用情況或設定相關的資訊。

## 用途

此面板屬資訊性與推廣性質：它引導管理員前往 Chamilo 的官方服務供應商（諮詢、主機代管、客製開發與認證支援），適合希望與簽約、經認證的合作夥伴合作，而非僅依賴社群論壇的機構。另請參閱 [Chamilo.org 連結](chamilo-org-links.md)，該頁面會直接連至官方供應商清單。
