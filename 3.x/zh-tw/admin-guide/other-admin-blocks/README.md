# 其他管理區塊

管理儀表板還有幾個區塊，與其說是可設定的功能，不如說是資訊小工具：一頁對外連結、版本檢查註冊，以及兩個從 chamilo.org 擷取內容的小型面板。本章說明每一項的用途、內容來源，以及——因為其中部分確實會——是否有任何資料會離開您的平台。

## 涵蓋內容

* **[Chamilo.org 連結](chamilo-org-links.md)** — 官方 Chamilo 資源的書籤清單；不傳送任何資料
* **[版本檢查](version-check.md)** — 選擇加入的註冊，會向 chamilo.org 回報您平台的版本與使用情況，並告知您是否該進行更新
* **[專業支援](professional-support.md)** — 唯讀面板，說明官方 Chamilo 支援供應商
* **[來自 Chamilo 的新聞](news-from-chamilo.md)** — 官方公告的唯讀摘要，包括安全性修補與新版本發行

以下各頁會清楚說明（若有的話）會傳送哪些資料到 chamilo.org，以及原因。
