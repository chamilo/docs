# 來自 Chamilo 的消息

「來自 Chamilo 的消息」是一個唯讀的小型面板，會從 Chamilo Association 擷取官方公告——您可在此得知新版本發行，更重要的是，得知您應套用的安全性修補程式。

## 顯示內容與來源

此面板會從 `version.chamilo.org/c/news/latest.php` 擷取內容，並以您平台介面語言提出請求。平台送出的僅有該語言代碼——此功能不會將任何平台詳情、使用資料或聯絡資訊傳出您的伺服器。

## 用途

這是 Chamilo 直接向管理員傳達營運上重要事項的管道：新版本發行，以及——最重要的——**安全性修補程式**。及時套用安全性修補程式是保護平台安全最有效的做法之一（請參閱[安全性指南](../appendix/security-guide.md)），因此值得定期查看此面板，而不是等到碰巧想起時才檢查。

此動態消息的載入獨立於[版本檢查](version-check.md)——您不必註冊平台即可查看。
