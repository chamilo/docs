# 版本檢查

版本檢查會告訴您目前的 Chamilo 安裝是否為最新版本；若您選擇加入，還會將您的平台向 Chamilo 專案註冊，以便納入彙總使用統計。

## 兩種檢查層級

**未註冊（預設狀態）：** Chamilo 仍會嘗試連線 `version.chamilo.org`，將您已安裝的版本與最新發行版比對，僅使用該請求本身——不會傳送任何平台詳細資料。此區塊會顯示一份註冊表單，說明註冊可帶來的額外功能，以及「**啟用版本檢查**」按鈕與「**從公開平台清單中隱藏校園**」核取方塊。

**已註冊：** 點選「啟用版本檢查」只會切換兩項本機設定——本身並不會傳送任何資料。此後，每當此儀表板區塊載入時，您的平台會向 `version.chamilo.org` 傳送包含下列內容的請求：

| 傳送的資料 | 所述用途 |
|-----------|-----------------|
| 您平台的 URL 與網站名稱 | 識別是哪個入口網站正在回報 |
| 管理員聯絡電子郵件 | 明確供 Chamilo 團隊在發生重大安全性問題時聯繫管理員 |
| 已安裝版本 | 用以判斷您是否為最新版本 |
| 課程、使用者、作用中使用者與工作階段數量 | 彙整為非個人化的統計資料，置於 `stats.chamilo.org` |
| 機構名稱與介面語言 | 僅供人口統計彙總 |
| 管理員姓名 | 會被傳送，但其用途在程式碼本身並未清楚記載 |
| 您伺服器的 IP 位址 | 用以概略推估平台位置，繪製全球安裝地圖 |
| 「不要列出校園」旗標、打包者，以及唯一執行個體 ID | 控制您是否出現在公開目錄中，並識別同一安裝的重複回報 |

若您未勾選「**從公開平台清單中隱藏校園**」，您的平台也會出現在 `version.chamilo.org/community.php` 的公開社群清單中。

## 存取版本檢查

此區塊直接顯示於管理儀表板上——無需前往其他頁面。

## 是否應該啟用？

這是明確的選擇加入機制，取捨也很直接：以分享上述詳細資料為代價，您會在有新版本（含安全性修補）時自動收到通知，並貢獻 Chamilo 的公開採用統計。若您不願分享任何平台詳細資料，只要不要點選「啟用版本檢查」即可——基本的是否最新檢查仍會在未註冊的情況下執行。若您想收到更新通知但不想被公開列出，請註冊並勾選「從公開平台清單中隱藏校園」。
