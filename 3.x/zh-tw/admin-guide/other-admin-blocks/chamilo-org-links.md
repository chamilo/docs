# Chamilo.org 連結

**Chamilo.org** 區塊是一份靜態的對外連結清單，指向官方 Chamilo 資源——僅此而已。它不會向任何地方傳送資料；每一個連結不是開啟外部 Chamilo 網站，就是開啟隨您安裝套件附帶的本機說明文件頁面。

## 區塊內容

| 連結 | 目的地 |
|------|-------------|
| Chamilo 首頁 | `chamilo.org` |
| 使用者指南 | `docs.chamilo.org` |
| Chamilo 論壇 | chamilo-lms 的 GitHub Discussions |
| 安裝指南 | 本機，`/documentation/installation_guide.html` |
| 最新版本變更 | 本機，`/documentation/changelog.html` |
| 貢獻者名單 | 本機，`/documentation/credits.html` |
| 安全性指南 | 本機，`/documentation/security.html` |
| 最佳化指南 | 本機，`/documentation/optimization.html` |
| Chamilo 官方服務供應商 | `chamilo.org/providers` |

「本機」連結指向隨您的 Chamilo 安裝本身一併提供的說明文件，因此會從您自己的伺服器載入，而非從 chamilo.org 載入。

## 用途

此區塊純粹為求便利而設——可快速存取專案的官方說明文件、社群討論空間，以及經過審核的服務供應商清單，無需另行搜尋。
