# 開始使用

本節介紹 Chamilo 3.0 管理介面，協助您熟悉環境。

## 誰是管理員？

Chamilo 具有多個層級的管理角色：

| 角色 | 權限 |
|------|--------|
| **Administrator** | 對平台所有管理功能擁有完整存取權。亦稱為 **Portal Administrator** |
| **Global Administrator** | 與 Portal Administrator 相同，但在多網址（多租戶）環境中可存取所有存取 URL |
| **Sessions Administrator** | 可管理課程期、將使用者註冊至課程期，並存取與課程期相關的設定 |
| **Human Resources Manager** | 可檢視所指派使用者的學習進度與追蹤資料 |
| **Questions Manager** | 較接近內容策展者而非管理員；題目管理員可存取全域題庫以審核題目品質 |

本指南主要著重於權限最廣的 **Portal Administrator** 角色。

## 登入

管理員與其他使用者使用相同的登入頁面。輸入憑證後（若無其他設定），您將被導向 **Administration** 頁面。與其他使用者角色的明顯差異，是側邊欄中的 **Administration** 區塊（其他角色無法看見）。
