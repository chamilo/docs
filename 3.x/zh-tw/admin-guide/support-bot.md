# 支援機器人（決策樹助理）

**支援機器人**是以固定決策樹建置的可設定說明助理。它於 [PR #9224](https://github.com/chamilo/chamilo-lms/pull/9224) 中實作，以處理 [issue #8754](https://github.com/chamilo/chamilo-lms/issues/8754)。它**並非生成式 AI 聊天機器人**：管理員撰寫問題與可選答案，引導使用者前往說明、頁面或支援工單。

## 啟用

1. 在**管理 > 組態設定 > 工單**中，啟用 `ticket.ticket_support_bot_enabled`（預設為停用）。
2. 開啟**管理 > 支援機器人**，並建立**草稿**決策樹。提供標題，以及至少一個含選項的進入節點。
3. 在每個節點定義問題或資訊，並將選項連結至下一個動作。
4. 發佈有效的決策樹。只有已發佈、且具有有效進入節點與可選選項的決策樹，才會提供給使用者。

引擎會為目前的存取 URL 選取已發佈的決策樹；因此其可用性以入口網站為範圍。管理員必須具備 `ROLE_ADMIN` 才能管理決策樹。

## 設計支援流程

每個選項可執行下列四種動作之一：

| 動作 | 結果 |
| --- | --- |
| **前往另一個節點** | 在同一決策樹中的另一個問題繼續對話 |
| **開啟連結** | 使用同站相對路徑連結至 Chamilo 頁面，例如 `/tickets` |
| **結束對話** | 將問題標示為已解決，並可選擇顯示結束訊息 |
| **建立支援工單** | 將對話升級至工單系統 |

若要升級為工單，請選取**預設工單專案**，以及屬於該專案的類別。需要課程的類別不能用於此支援機器人升級。所建立的工單會包含使用者的決策樹對話紀錄，因此支援人員可以看到導致升級的選擇。

編輯器會在發佈前驗證決策樹結構。**已發佈**與**已封存**版本為唯讀；請使用**複製**建立新的可編輯草稿。發佈替代版本時，會封存同一範圍內先前已發佈的版本。在清單中，管理員也可以匯入或匯出決策樹，並檢閱其對話歷程。已發佈的決策樹必須先封存才能刪除，而具有對話歷程的決策樹無法刪除。

## 匯入範例與檢閱對話

開啟**管理 > 支援機器人**並選取**匯入**。匯入對話方塊提供**下載 JSON 範例**與**下載 CSV 範例**。下載範例後，將其中的問題與選項替換為您自己的內容，然後選取編輯後的 `.json` 或 `.csv` 檔案並匯入。每個匯入的決策樹都會以**新草稿**開始；請檢閱後，在準備就緒時明確發佈。

這些範例不需要既有的工單專案。若您的工作流程應建立工單，請在匯入後設定所需的專案與符合資格的類別。

在決策樹清單中，使用**檢視對話**可檢查特定決策樹的對話紀錄，包括對話次數為零的決策樹。對話歷程仍限定於相關使用者與入口網站。請參閱 [PR #9419](https://github.com/chamilo/chamilo-lms/pull/9419)。

## 使用者如何存取

當此設定已開啟，且入口網站具有有效的已發佈決策樹時，已登入的使用者會在停駐聊天中看到**支援機器人**聯絡人。他們透過選擇所提供的選項來回答。機器人可以解決對話、開啟同站頁面，或建立工單並顯示其連結。先前的對話結束後，使用者可以開始新的對話。

這與**AI 導師**不同；AI 導師回應開放式的學習問題。支援機器人只遵循管理員所設定的路徑與選項。

## 疑難排解與安全性

* **聊天中沒有機器人：**請確認工單設定、目前入口網站已發佈決策樹，以及其進入節點具有選項。
* **無法發佈：**請檢查草稿中缺少的節點、未解析的目的地節點與無效動作。
* **無法建立工單：**請檢查所選的工單專案與類別。請勿使用需要課程的工單類別。
* **缺少較舊的對話：**管理員可從對應的決策樹檢閱對話歷程；對話會繫結至使用者與存取 URL。

相關設定請參閱[工單設定](platform-settings/ticket-settings.md)。
