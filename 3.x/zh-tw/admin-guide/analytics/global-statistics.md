# 全域統計

全域統計是平台統計中樞——依主題分組的平台層級報表選單，而非單一報表。

## 存取全域統計

在管理面板中，點選 **Analytics > Global statistics**。

## 組織方式

開啟頁面且尚未選取報表時，會顯示可用統計選單，分為課程、使用者、系統、社交與 Session。選取選單項目後，該特定報表會載入同一頁面。每一項皆為平台層級、僅管理員可見的檢視——此處沒有課程或 session 範圍；相關內容請見 [學習分析](learning-analytics.md)。

## 課程

* **Courses** — 課程總數，依課程類別細分
* **Tools access** — 平台層級的工具存取事件計數（公告、文件、論壇、測驗、聊天等）
* **Tool-based resource count** — 選取一或多個工具，查看使用它們的每一門課程／session，含資源數量與最後更新日期，並依使用量排序
* **Latest access** — 課程及其最後存取日期，僅限在可設定天數內造訪過者（預設 60 天）
* **Number of courses by language** — 依介面語言分組的課程
* **Courses usage** — 各課程在滾動期間（今天、本週、本月、6 個月、1 年、2 年、全部時間）的造訪次數，區分為 session 內與 session 外造訪

## 使用者

* **Number of users** — 平台層級的講師與學習者總數，以及依課程類別的相同細分
* **Logins** — 今天、最近 7 天、最近 31 天與全部時間的登入次數，含總登入次數與不重複使用者；可依最短 session 時長篩選
* **Logins (Month)** — 相同登入資料依曆月加總，涵蓋全部歷史
* **Logins (Day)** — 依星期幾加總的登入次數，另含僅最近 7 天的細分
* **Logins (Hour)** — 依一天中各小時加總的登入次數，另含僅最近 24 小時的細分
* **Number of users (Picture)** — 已上傳個人資料圖片的有效帳號數量，相對於尚未上傳者
* **Logins by date** — 每位使用者在所選日期範圍內的總連線時間（登入至登出），可匯出為 XLS
* **Not logged in for some time** — 在尾隨時間窗（今天、7 天、31 天、6 個月）內未曾登入的使用者數量，以及從未登入過的數量
* **Zombies** — 最後登入日期在您所選截止日期當天或之前的帳號（沒有固定門檻——每次由您指定日期），可選擇僅限有效帳號，並可直接對列出的帳號啟用、停用或刪除
* **Users statistics** — 在所選日期範圍內註冊的使用者，含完整個人資料與摘要圖表，可匯出為 XLS
* **Users online** — 目前線上使用者與目前正在作答測驗的使用者即時計數，各以四個時間窗顯示（3、5、30 與 120 分鐘）
* **New users registrations** — 所選日期範圍內的新註冊（範圍為一個月或以內時為每日，否則為每月並可向下展開），以及各帳號建立者的細分
* **Course/Session subscriptions by day** — 所選日期範圍內每日的訂閱與取消訂閱
* **Duplicate users** — 找出共用相同姓名、電子郵件或所選個人資料欄位值的帳號；可停用、啟用或合併重複項——合併會永久刪除併入您保留帳號的那些帳號

## 系統

* **Portal user session stats** — 依存取 URL（多 URL 入口網站）、session 與課程細分的使用者數量網格，適用於所選日期範圍，可匯出為 XLS

同樣出現在系統底下的 **Quarterly report** 項目，另於 [企業報表](corporate-reports.md) 說明。

## 社交

* **Number of messages received** — 每位使用者收到的內部訊息數量
* **Number of messages sent** — 每位使用者傳送的內部訊息數量
* **Contacts count** — 每位使用者的社交網路聯絡人數量（不含人力資源／主管類型關係）

## Session

* **Sessions by date** — 在所選日期範圍內開始或結束的 session（可選擇依狀態篩選）：數量、每週平均 session 數、每個 session 平均使用者數、每位導師平均 session 數、依類別／語言／狀態的細分，以及各課程的 session 數量表
