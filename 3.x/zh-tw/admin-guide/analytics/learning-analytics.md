# 學習分析

學習分析是 Chamilo 的經典追蹤儀表板（歷史上稱為「MySpace」或「Reporting」）。它是用來深入追蹤學習者、課程與工作階段表現的主要工具。

## 存取學習分析

從管理面板點選 **Analytics > Learning analytics**。

## 顯示內容

* **總覽計數** — 學生、教師與人力資源使用者人數；已指派的課程與工作階段
* **向下鑽取** — 分別針對使用者、課程與工作階段的檢視，各自顯示平均花費時間、平均分數與進度
* **CSV 匯出** — 匯出目前檢視以供離線分析

與全域統計不同，此檢視的範圍會依檢視者角色調整：全域管理員可看到整個平台的資料，而教師或工作階段導師在自己的課程中開啟對應檢視時，僅能看到自己的課程與工作階段。以管理員身分使用此儀表板入口時，您會取得整個平台的檢視。

## 相關內容
