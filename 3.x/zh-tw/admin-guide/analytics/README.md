# 分析

管理儀表板上的 **分析** 區塊彙整全平台統計、學習分析、企業／人資報表，以及批次匯出工具。依 Chamilo 版本不同，此區塊在儀表板上可能標示為 **「追蹤」**——兩者實為同一區塊。本指南一律稱為分析，以免與 [追蹤設定](../platform-settings/tracking-settings.md) 混淆；後者是獨立的設定類別，控制記錄哪些資料，而非報表本身。

## 存取分析

在管理面板中，**分析** 區塊與其他儀表板區塊並列。點選其中任一連結即可開啟對應報表。

## 區塊內容

* **[全域統計](global-statistics.md)** — 全平台統計：課程、使用者、登入、工作階段與磁碟用量
* **[報表目錄](reports-catalog.md)** — 瀏覽所有已註冊報表、誰可存取及其原因
* **[學習分析](learning-analytics.md)** — 經典追蹤儀表板：使用者、課程與工作階段下鑽，含花費時間與分數平均值
* **[企業報表](corporate-reports.md)** — 季度摘要、教師時數追蹤，以及以人資為導向的課程／使用者報表
* **[工單](tickets.md)** — 直接跳至支援工單清單

## 誰可以存取

這些報表大多需要 **入口網站管理員** 權限。企業報表是例外——亦開放給 **人力資源經理** 與 **學員主管** 角色，因為該報表即為該族群所設計。
