# 管理課程期別

## 建立課程期別

![課程期別建立表單，包含名稱、日期、導師、類別與可見性等欄位](../../.gitbook/assets/admin-session-create-form.png)

1. 從管理面板點選 **建立課程期別**
2. 填寫課程期別詳細資料：
   * **課程期別名稱** — 具描述性的名稱（例如：「2026 年春季新人訓練」）
   * **開始與結束日期** — 課程期別進行的時間（選填 — 課程期別可為無期限）。共有 3 組日期：顯示用日期、限制學員存取的日期，以及限制導師存取的日期
   * **課程期別導師** — 負責監督整個課程期別的人員
   * **類別** — 指派至課程期別類別以便組織管理
   * **可見性** — 控制存取與列表顯示行為
3. **新增課程** — 選取一門或多門課程納入此課程期別
4. **註冊學員** — 新增個別使用者或使用者班級
5. **指派課程導師** — 為每門課程指派教師（課程導師）
6. 儲存

## 課程期別日期

課程期別支援彈性的日期設定：

| 日期 | 用途 |
|------|---------|
| **顯示開始／結束** | 課程期別出現在學員列表中的時間 |
| **存取開始／結束** | 學員實際可存取課程期別內容的時間 |
| **導師存取開始／結束** | 導師可存取課程期別的時間（通常早於學員存取開始，並晚於學員存取結束） |

如此可在學員進入前先準備課程期別，並在課程期別結束後仍維持導師存取權限，以便評分與產生報表。

## 課程期別列表

![課程期別列表，顯示所有課程期別的名稱、日期、課程數量、學員數量與狀態](../../.gitbook/assets/admin-session-list.png)

課程期別列表會顯示所有課程期別，包含：

* 課程期別名稱
* 開始與結束日期
* 狀態（進行中、即將開始、已結束）

使用搜尋與篩選，依名稱、日期、類別或狀態尋找課程期別。

## 編輯課程期別

點選課程期別即可編輯：

* 變更日期、名稱或類別
* 新增或移除課程
* 變更課程導師
* 新增或移除學員
* 檢視該課程期別的追蹤資料

## 註冊使用者

![課程期別註冊介面，用於新增個別使用者、班級，或透過 CSV 匯入](../../.gitbook/assets/admin-session-enrollment.png)

您可以透過下列方式將使用者註冊至課程期別：

* **個別註冊** — 搜尋並新增個別使用者
* **班級註冊** — 一次新增多個預先定義使用者所組成的整個班級
* **CSV 匯入** — 上傳含有使用者與課程期別對應關係的檔案

## 課程期別存取

學員可透過側邊欄的 **我的課程期別** 存取其課程期別。課程期別會整理為：

* **目前課程期別** — 目前進行中
* **過去課程期別** — 已結束
* **即將開始的課程期別** — 尚未開始

## 提示

* **謹慎規劃日期** — 確保導師存取日期涵蓋學員日期之外，以便導師進行設定與後續追蹤
* **以班級處理重複註冊** — 若經常註冊相同群組，請建立班級並將其指派至課程期別
* **維持課程期別井然有序** — 使用類別與清楚的命名慣例，以便管理
