# 課程期別

課程期別是 Chamilo 最強大的功能之一。它們讓您能在不同時間、向不同學習者群體提供相同課程，而無須複製課程內容。

## 瞭解課程期別

課程期別是**選用的**。您可以僅使用課程就讓入口網站運作，但我們**強烈**建議您考慮課程期別所帶來的額外複雜度，作為長期節省管理工作的方式。

**課程**保存內容（文件、練習、學習路徑）。**課程期別**則將該課程（或數門課程）指派給特定學習者群體，*並限定於特定時段*。

此架構意味著：

* 教師在課程中一次建立內容
* 管理員建立課程期別，將該內容提供給不同群體
* 每個課程期別都有各自的註冊、追蹤資料與成績
* 基礎課程內容為共用，但課程期別導師可自訂部分元素

## 何時使用課程期別

在下列情況使用課程期別：

* 您多次提供相同培訓（例如每月入職課程期別）
* 您有以群體為基礎的學程（例如學期制班級）
* 您需要針對各學習者群體分開追蹤
* 您希望不同導師管理同一課程的不同版本
