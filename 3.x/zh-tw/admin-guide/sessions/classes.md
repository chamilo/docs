# 班級

Chamilo 中的班級是預先定義的使用者群組，可作為一個整體註冊至課程期。當您經常為同一批人員提供訓練時，班級可簡化註冊流程。

> 班級與 [使用者群組](../../admin-guide/users/user-groups.md) 共用同一介面。唯一差異是 **群組類型** 設定：建立群組時請選擇「班級」。其餘部分——成員管理、可見性以及介面本身——運作方式完全相同。

## 建立班級

1. 從管理面板前往 **班級**（或使用者群組並選擇「班級」類型）
2. 點選 **建立班級**
3. 輸入 **名稱**（例如「工程團隊」、「2026 年 3 月新進人員」）
4. 新增 **成員** — 搜尋並選取使用者
5. 儲存

## 使用班級進行註冊

建立或編輯課程期時，您可以一次註冊整個班級，而不必逐一新增使用者：

1. 開啟課程期註冊設定
2. 點選 **新增班級**
3. 選取班級
4. 該班級的所有成員都會註冊至該課程期

## 管理班級

* **編輯** — 變更班級名稱或更新成員資格
* **新增／移除成員** — 維持班級名冊為最新狀態
* **刪除** — 移除班級（不影響成員帳號或其既有註冊）

## 提示

* **為重複出現的學員群組建立班級** — 若您為不同團隊開設相同訓練，請為每個團隊建立一個班級
* **每次課程期前先更新** — 將班級註冊至新課程期前，請先檢視班級成員，以確保名冊為最新
* **搭配 CSV 匯入** — 對大型群組，可從 CSV 檔匯入班級成員
