# 課程類別

課程類別有助於整理您的課程，尤其是在同時進行多個課程時。

## 建立類別

1. 從管理面板前往 **課程類別**
2. 點選 **新增類別**
3. 輸入**名稱**以及選填的開始／結束日期
4. 儲存

## 使用情境

* **依計畫** — 「領導力發展」、「技術訓練」、「新人導入」
* **依期間** — 「2026 年第一季」、「春季學期」、「七月梯次」
* **依部門** — 「工程」、「業務」、「人力資源」

## 管理類別

* **編輯** — 變更類別名稱或日期
* **指派課程** — 建立或編輯課程時，選取其類別
* **刪除** — 移除類別（該類別中的課程將變為未分類）
