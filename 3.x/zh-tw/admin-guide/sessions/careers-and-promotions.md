# 職涯與晉升班

Chamilo 內建職涯管理系統，可讓您定義培訓路徑，並透過結構化課程追蹤學習者的進度。

## 職涯

![職涯清單，顯示已定義的職涯路徑及其名稱與說明](../../.gitbook/assets/admin-careers-list.png)

**職涯**代表一條結構化的培訓路徑——學習者為達成專業目標所依循的一連串培訓步驟。

### 建立職涯

1. 從管理面板前往 **Careers**
2. 按一下 **Create a career**
3. 輸入 **name** 與 **description**
4. 儲存

## 晉升班

**晉升班**代表一群正在同一職涯中前進的學習者（同期或梯次）。可將其視為同一時間走同一職涯路徑的一組人員。

### 連結至課程期別

建立晉升班後，請將課程期別連結至該晉升班。此舉定義學習者必須完成的培訓順序。

之後您可以複製晉升班，協助以相同課程期別的複本建立下一屆晉升班，讓下一屆能立即建置完成。

### 建立晉升班

1. 前往 **Promotions**
2. 按一下 **Create a promotion**
3. 輸入 **name** 與 **description**
4. 將其連結至一個 **career**
5. 將 **sessions** 指派給該晉升班
6. 儲存

## 彼此如何搭配

* **職涯**定義路徑（例如「初階開發人員認證」）
* **晉升班**代表一個同期（例如「2026 年 3 月班」）
* 晉升班內的 **Sessions** 提供實際培訓內容

## 提示

* **適用於結構化課程** — 職涯與晉升班最適合多階段培訓課程，學習者依既定順序前進
* **追蹤完成情形** — 使用報表工具監控各晉升班在職涯路徑上的進度
