# 安全組態診斷匯出

Chamilo 3.1 提供可下載的 JSON 報告，用於診斷組態問題，且不會刻意匯出機密設定值。此報告僅限於**目前的存取 URL**，並需要管理員角色。

## 下載報告

1. 在您要檢查的入口網站上開啟**管理 > 設定**。
2. 選取**下載組態以供除錯**。
3. 安全地儲存產生的 `chamilo-configuration-dump.json` 檔案。
4. **在將檔案傳送給任何人之前，請先檢閱整份檔案**，即使它看起來已經過淨化處理。

報告包含匯出時間戳記、存取 URL 範圍、已淨化的平台設定，以及外掛程式的安裝／啟用狀態與已淨化的外掛程式組態。此為唯讀匯出；下載不會變更系統設定。

## 機密性與存取 URL 邊界

敏感值會由淨化層遮罩。外掛程式設定預設視為機密，除非明確分類為可安全匯出。即便如此，設定名稱、外掛程式名稱及其他診斷中繼資料仍可能揭露實作細節，因此請僅將檔案分發給受信任的支援人員。

在多 URL 安裝環境中，後端會檢查解析後的存取 URL 是否與請求主機相符，而非靜默匯出另一個入口網站的組態。下載前請確認入口網站位址。

## 疑難排解

若無法匯出，請確認帳戶具有管理員權限，且所請求的入口網站會解析至其自身的存取 URL。檢閱網頁伺服器與應用程式日誌時，請勿將憑證或個人資訊複製到支援工單中。
