# 系統工具

本頁說明「系統」區塊中的維護與檢查公用程式。

## 清理暫存檔案

**系統 > 清理暫存檔案** 會顯示目前有多少暫存上傳檔案及其佔用空間，並讓您清除它們——可全部清除，或僅清除超過可設定保存期限的檔案。試跑（dry-run）模式可先預覽將會刪除的內容。同一操作也會清除過期的舊版建置檔案，並重新產生已編譯的 CSS 資產。

此操作刻意略過 Symfony 本身的快取目錄（`var/cache/dev`、`var/cache/prod`、`var/cache/test` 以及 cache pools）——只會清理落在 `var/cache/` 其他位置的散落檔案。它**不會**套用您在 `.env` 或 `config/` 下所做的變更（例如啟用 API 文件——請參閱 [啟用 API 文件](../installation/configuration.md#enable-the-api-documentation)）。若要套用那些變更，您需要透過 shell 執行 `php bin/console cache:clear`。

## 系統更新

**系統 > 系統更新** 可直接從管理面板執行 Chamilo 的自我更新流程，分為一連串可中斷後續跑的獨立步驟：

1. **狀態** — 回報已安裝版本，以及更新／暫存／備份目錄的位置，並顯示目前使用的受信任簽署金鑰
2. **檢查** — 向已設定的更新來源查詢是否有較新版本
3. **驗證** — 下載更新套件及其簽章，並以清單校驗碼與受信任公鑰進行核對
4. **預檢** — 在動到任何內容之前，驗證系統需求與相容性
5. **暫存** — 將已驗證的套件解壓到隔離的暫存目錄；正式安裝此時尚未變更
6. **套用計畫** — 依暫存套件建立要新增、取代或移除的檔案差異
7. **套用檔案** — 將檔案複製到位。此步驟需明確確認，並會為每個被覆寫的檔案建立備份，同時建立鎖定檔以防止第二次更新同時執行
8. **遷移安全／套用後檢查** — 驗證待執行的資料庫遷移與安裝後狀態
9. **執行套用後作業** — 執行套用後的主控台命令（例如資料庫遷移），但僅在伺服器設定允許從 UI 執行時進行，且須先輸入明確確認片語，並確認已完成備份

長時間步驟會回報進度，因此可在完成前安全地保持頁面開啟。簽章驗證、先暫存再套用、覆寫前備份、並行鎖定，以及資料庫變更前的輸入確認，這些機制旨在讓此流程即使沒有 shell 存取也能安全執行——但開始前仍建議先手動備份；請參閱 [備份](../maintenance/backups.md)。

## 檔案資訊

**系統 > 檔案資訊** 會列出每一個已上傳的資源檔案，可依名稱搜尋，並顯示其實體路徑、是否為孤立檔案（未連結至任何課程或工作階段），以及被多少處所參照。您可在此將孤立檔案附加至資源、解除附加，或刪除它——適合用來追查並清理已不再屬於任何課程的儲存空間。

## 依類型檢視資源

**系統 > 依類型檢視資源** 可讓您選擇一種資源類型，並在所有課程與工作階段中查看該類型項目的彙總數量與清單、建立時間，以及（若適用）相關聯的使用者。可用來回答例如「整個平台有多少個論壇」或「哪些課程擁有最多文件」這類問題。

## 圖示清單

**系統 > 圖示清單** 是 Chamilo 內建圖示集的可瀏覽目錄，依類別分組。主要在開發外掛或佈景主題、需要確認圖示確切名稱時有用，此處則作為一般參考公開。

## 僅開發環境工具

此區塊還可能出現另外兩個項目，但僅在伺服器存在 `tests/` 目錄時才會顯示——通常只會出現在開發或 QA 安裝，絕不會出現在正式環境：

* **資料填入器** 會產生大量假使用者、課程與線上使用者紀錄，供負載或 QA 測試使用。
* **電子郵件測試器** 會透過平台已設定的郵件程式寄出一封真實測試郵件，以確認 SMTP／郵件設定確實可用，並顯示最近的寄送失敗（若有）。

若您看不到這兩個連結，屬正常現象——代表您的安裝沒有 `tests/` 目錄，這正是正式平台應有的正確狀態。
