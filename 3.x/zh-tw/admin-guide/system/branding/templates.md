# 範本

Chamilo 使用範本處理證書、文件與電子郵件。您可自訂這些範本，以符合貴機構的品牌形象與需求。

## 證書範本

證書範本定義頒發給達到成績簿門檻之學習者的證書版面與內容。

### 自訂證書範本

證書範本使用 HTML 與 CSS，並搭配預留變數：

| 變數 | 取代為 |
|----------|-------------|
| Student name | 學習者的全名 |
| Course name | 課程名稱 |
| Date | 取得證書的日期 |
| Score | 學習者的最終分數 |
| Barcode | 用於驗證的條碼預留位置（`((certificate_barcode))`） |

### 上傳範本

1. 前往證書範本管理
2. 上傳或編輯 HTML 範本
3. 在應顯示動態內容之處使用預留變數
4. 儲存

## 文件範本

教師在「文件」工具中建立內容時可使用文件範本。範本為常見文件類型提供起始版面。

### 管理文件範本

1. 在管理面板中前往範本管理
2. 透過上傳 HTML 檔案新增範本
3. 教師建立新文件時即可使用這些範本

## 提示

* **加入您的標誌** — 在證書範本中加入貴機構標誌，呈現專業外觀
* **以真實資料測試** — 部署範本前，先以實際學習者資料預覽證書
* **保持範本簡潔** — 簡潔設計較利於列印，外觀也更專業
