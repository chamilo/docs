# 色彩主題

Chamilo 2.0 導入了色彩主題系統，讓您自訂平台的視覺外觀。

## 主題運作方式

色彩主題定義 Chamilo 介面所使用的色盤——主色、強調色、背景色與文字顏色。主題會關聯至一個存取 URL：在單一 URL 入口網站中，它實際上會成為全域主題；在多 URL 設定中，每個 URL 可以擁有各自的主題。

## 套用主題

![色彩主題頁面，顯示可用主題、預覽色塊與「套用」按鈕](../../../.gitbook/assets/admin-color-themes.png)

1. 從管理面板前往 **色彩主題**
2. 瀏覽可用主題
3. 選取一個主題並點選 **套用**
4. 主題會立即套用至平台

## 依 URL 設定主題

在多 URL 設定中，每個存取 URL 可以擁有各自的色彩主題。這讓不同入口網站在共用同一套 Chamilo 安裝的同時，仍能擁有獨特的視覺識別。

## 提示

* **符合品牌形象** — 選擇或自訂符合貴機構品牌色彩的主題
* **測試可讀性** — 套用主題後，請檢查文字在背景色上是否清晰可讀，尤其是在高對比情境中
* **考量無障礙** — 確保色彩對比足以滿足視覺障礙使用者的需求
