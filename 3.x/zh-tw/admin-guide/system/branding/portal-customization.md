# 入口網站自訂

自訂您的 Chamilo 平台外觀，以及向使用者顯示的資訊。

## 平台識別

![入口網站自訂頁面，顯示平台名稱、標誌與機構等識別設定](../../../.gitbook/assets/admin-portal-customization.png)

設定入口網站的基本識別資訊：

* **平台名稱** — 顯示於瀏覽器標題列及整個介面中的名稱
* **機構名稱** — 貴組織的名稱
* **機構 URL** — 連至貴組織網站的連結
* **平台標誌** — 上傳貴組織的標誌（顯示於頂端列）

## 提示

* **保持首頁簡潔** — 首頁內容過多可能令人不知所措。請聚焦於必要公告與課程存取。
* **定期更新** — 維持系統公告為最新狀態，並移除過時內容
* **上傳高品質標誌** — 標誌是最顯眼的品牌元素之一。請使用清晰、尺寸適當的影像。
