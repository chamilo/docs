# 系統

管理儀表板上的 **系統** 區塊彙整伺服器層級維護工具、自我更新工作流程、儲存／資源檢查公用程式，以及平台品牌設定。

![管理儀表板上的系統區塊，列出清理暫存檔、系統狀態、系統更新、顏色、檔案資訊、依類型分類的資源，以及圖示清單](/.gitbook/assets/admin-system-block.png)

## 存取系統區塊

在管理面板中，**系統** 區塊會與其他儀表板區塊並列顯示。點選其中任一連結即可開啟對應工具。

## 區塊內容

* **[系統工具](system-tools.md)** — 清理暫存檔、執行自我更新工作流程、檢查已儲存的檔案與資源，以及瀏覽內建圖示集
* **系統狀態** — 說明見維護章節中的 [系統狀態](../maintenance/system-status.md)
* **[品牌設定](branding/README.md)** — 色彩主題（區塊中的「顏色」連結會開啟同一頁「色彩主題」）、入口網站自訂與範本

另外兩項 — **資料填入器** 與 **電子郵件測試器** — 僅在伺服器存在 `tests/` 目錄時才會顯示，此為開發／品保環境，而非正式環境。一般正式安裝不會出現這些項目；其功能說明請見 [系統工具](system-tools.md#development-only-tools)。
