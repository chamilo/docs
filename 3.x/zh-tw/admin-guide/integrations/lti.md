# LTI 1.3

**LTI**（Learning Tools Interoperability，學習工具互通性）是一項標準，可讓外部學習工具嵌入 Chamilo。1.3 版是該標準最新且最安全的版本。

此工具亦可從管理儀表板的 [平台](../platform/README.md) 區塊進入，名稱為 **外部工具（LTI）**。

## LTI 可實現的功能

透過 LTI，您可將外部工具嵌入 Chamilo 課程。例如：

* 互動式模擬
* 專業評量工具
* 內容編輯工具
* 虛擬實驗室
* 第三方內容資料庫

外部工具會無縫顯示於 Chamilo 介面中。

## 設定 LTI 工具

### 以管理員身分

1. 前往管理面板中的 LTI 設定
2. **註冊外部工具**，並提供：
   * **工具名稱** — 具描述性的名稱
   * **登入 URL** — 外部工具的 OIDC 登入起始 URL
   * **重新導向 URL** — 工具在登入後返回的啟動 URL
   * **Client ID** — 由工具供應商提供
   * **公開金鑰集 URL（JWKS URL）** — 工具用於安全金鑰交換的 JWKS 端點
3. 設定 **成績回傳（grade passback）** — 工具是否可將成績傳回 Chamilo
4. 儲存

### 以教師身分

管理員註冊 LTI 工具後，教師即可將其加入課程：

1. 在課程中尋找新增外部工具的選項
2. 從已註冊的 LTI 工具中選取
3. 該工具會以課程工具的形式顯示於首頁

## 安全性

LTI 1.3 使用：

* **OAuth 2.0** 進行驗證
* **JSON Web Tokens（JWT）** 進行訊息簽署
* **公開／私密金鑰對** 進行驗證

這表示憑證絕不會在 Chamilo 與外部工具之間直接共享。

## 成績回傳

LTI 工具可將成績傳回 Chamilo，並可整合至課程成績簿。此功能於註冊時依個別工具設定。

## 提示

* **確認工具相容性** — 確保外部工具支援 LTI 1.3（而非僅支援舊版）
* **在沙盒中測試** — 在正式環境使用前，先於測試課程中測試 LTI 整合
* **監控效能** — 外部工具會增加網路相依性。請確保該工具回應迅速且穩定可靠。
