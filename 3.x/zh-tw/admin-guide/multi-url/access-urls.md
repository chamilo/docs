# 存取網址

存取網址可讓單一 Chamilo 安裝同時提供多個獨立入口網站。

此工具亦可從管理儀表板的 [平台](../platform/README.md) 區塊進入，名稱為 **設定多重存取網址**。


## 使用情境

* **多租戶部署** — 在單一伺服器上為不同機構託管各自獨立的訓練入口網站
* **部門入口網站** — 為各部門提供專屬品牌入口網站（例如 `hr.training.company.com`、`it.training.company.com`）
* **區域入口網站** — 為不同地區或語言提供獨立入口網站

## 運作方式

每個存取網址都是同一套 Chamilo 安裝的獨立進入點：

* 使用者可被指派至一個或多個存取網址
* 課程與時段隸屬於特定存取網址
* 平台設定可依存取網址個別自訂
* 品牌識別與主題可依網址而異
* 某一入口網站的使用者無法看到另一入口網站的使用者或課程（除非明確共用）

## 設定

### 啟用多重網址

必須在 Chamilo 組態中啟用多重網址（通常於環境設定中）。此步驟通常在初始安裝時完成。

### 建立存取網址

1. 從管理面板前往 **存取網址**
2. 按一下 **新增網址**
3. 輸入網址（例如 `https://portal2.yoursite.com`）與說明
4. 可選擇 **上層網址**，將此網址巢狀於另一網址之下 — 請參閱下方 [網址階層](#url-hierarchy)
5. 儲存

### 指派使用者與課程

* **使用者** — 將使用者指派至特定存取網址。一位使用者可隸屬多個網址。
* **課程** — 將課程指派至特定存取網址
* **時段** — 將時段指派至特定存取網址

### 依網址的設定

每個存取網址可擁有各自的：

* **色彩主題** — 不同的視覺品牌
* **平台名稱與標誌** — 自訂識別
* **設定覆寫** — 部分平台設定可依網址自訂

## 網址階層

存取網址可組織成上層／下層樹狀結構，而非平面清單。建立或編輯網址時，不受限制的全域管理員（請參閱下方 [子樹管理員](#subtree-administrators)）可將任何其他網址選為其 **上層網址**：

![編輯網址對話方塊，上層網址下拉選單已開啟，列出可作為上層的其他存取網址](/.gitbook/assets/admin-access-url-parent-select.png)

* 下拉選單絕不會提供正在編輯的網址，或其任何下層網址，作為可能的上層 — 以避免形成循環。無論介面顯示為何，後端都會再次驗證此規則。
* 若建立網址時未選擇上層，則預設為 **僅登入網址**（若存在，請參閱上方 [依網址的設定](#per-url-settings)），否則為第一個存取網址 — 與本功能出現前的預設行為相同。
* 樹狀結構最頂層的網址 — 沒有上層者 — 即為該樹的 **根**。單一 Chamilo 安裝可託管多個獨立的樹。

凡列出存取網址之處 — 多重網址儀表板與存取網址管理頁面 — 樹狀結構以縮排呈現，上層網址緊接其下層（同層依字母排序），而非另設「上層」欄：

![存取網址清單顯示一個根網址及其兩個下層網址，其中一個下層網址另有自己的下層網址，以縮排反映階層](/.gitbook/assets/admin-access-url-hierarchy-list.png)

## 子樹管理員

網址階層亦決定 [全域管理員](../users/user-roles.md) 可管理的範圍：

* 註冊於某棵樹 **根** 網址者為 **不受限制**：可管理每一個存取網址，與本功能出現前完全相同。
* 僅註冊於 **非根** 網址者為 **受限範圍**：多重網址與存取網址頁面僅顯示該網址及其下層，且多重網址儀表板上的登入圖表顯示「登入（您的網址）」而非「登入（所有網址合計）」。

無論範圍為何，下列操作仍僅保留給 **不受限制** 的全域管理員 — 受限範圍管理員即使針對自己子樹內的網址亦無法執行：

* 建立新的存取網址
* 編輯存取網址本身的網址、說明或上層
* 啟用或停用存取網址
* 刪除存取網址（整個安裝的根網址任何人皆無法刪除）
* 一次將自己註冊至每一個存取網址

受限範圍管理員仍可管理指派給其 subt 子樹內網址的一切 — 使用者、課程、時段、品牌與設定 — 只是不能管理存取網址項目本身。

## 提示

* **儘早決定** — 若選擇多網址設定，應在 Chamilo 專案一開始就決定，因為這需要讓第一個網址盡量保持內容空白。事後啟用多網址較為困難（需要手動變更資料庫）。
* **規劃網址結構** — 在建立存取網址前先決定網址配置，因為之後變更網址會影響所有既有連結與書籤
* **DNS 設定** — 每個存取網址都必須解析到同一台 Chamilo 伺服器。請據此設定 DNS 紀錄。
* **全域管理員** — 使用 Global Administrator 角色以跨所有存取網址進行管理。若僅要委派單一分支的管理，請在非根網址上註冊該管理員 — 請參閱 [Subtree Administrators](#subtree-administrators)
