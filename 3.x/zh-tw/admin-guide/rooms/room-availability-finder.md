# 教室可用性查詢工具

教室可用性查詢工具是一套排程工具：選定開始與結束的日期／時間後，即可得知該時段內哪些教室空閒、哪些教室已被預訂。

## 存取教室可用性查詢工具

在管理面板中，點選 **Rooms > Room availability finder**。

## 顯示內容

選定開始與結束的日期／時間後，系統會針對目前入口網站上的每一間教室核對既有預訂，並分成兩個清單：

* **Available rooms** — 在所請求時段內空閒，並顯示其名稱、分校、樓層與容納人數
* **Occupied rooms** — 已被預訂，並顯示衝突預訂的名稱與時間範圍

教室會被標示為「已佔用」，是因為該時段已指派給出缺席追蹤行事曆項目、課程，或特定的 session-course 配對——換言之，本工具檢查的是透過出缺席與 session 工具所建立的實際預訂，而非另一套獨立的預約行事曆。因此，它是針對實體教室（用於面授或混成（實體）session 課程）的衝突檢查器。

若要從教師端將教室指派給課程，請參閱教師指南中的 [分校與教室](../../teacher-guide/branches-and-rooms.md)。
