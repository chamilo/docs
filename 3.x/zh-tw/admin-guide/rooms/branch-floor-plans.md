# 分校平面圖與教室地圖

Chamilo 3.1 可將平面圖影像與分校關聯，並以互動式多邊形在該影像上標示教室位置。此功能協助學習者找到指定教室；它**不是**地理 GPS 地圖。

## 附加分校平面圖

1. 開啟 **Branches**（分校）的管理區域，並編輯目標分校。
2. 找到 **Floor plan**（平面圖）面板。
3. 選擇或上傳影像，然後選取 **Attach floor plan**（附加平面圖）（若已存在則選 **Change floor plan**（變更平面圖））。
4. 依需要儲存或確認分校變更，然後確認平面圖影像已載入。

若平面圖已不再有效，請先確認哪些教室參照該平面圖，再使用 **Remove floor plan**（移除平面圖）。僅上傳可信內容，並遵循分校管理畫面的權限設定。

## 描繪教室範圍

1. 編輯指派給該分校的教室。
2. 在教室表單中找到 **Room on floor plan**（平面圖上的教室）。
3. 使用多邊形工具描繪教室邊界。使用 **Edit**（編輯）調整頂點；所有點必須位於影像範圍內。
4. 選取 **Save room area**（儲存教室區域），然後儲存教室表單以保留變更。
5. 開啟教室檢視器以確認位置正確。若應移除對應，請使用 **Clear room area**（清除教室區域）。

每個教室一次只能有一個可編輯的多邊形。教室對應與分校層級的影像是分開的，因此更新影像後可能需要檢查既有的教室邊界。

## 地圖顯示位置

授權使用者在課程資訊、行事曆事件及出席相關流程中選取或顯示教室時，可以檢視教室平面圖。請以實際會檢視這些資訊的角色驗證可見性，尤其是學生與場次參與者。

分校與教室的存取權限同樣適用於平面圖資源。在多 URL 安裝環境中，發布地圖前請確認入口網站／分校隔離設定正確。
