# 教室

管理儀表板上的 **教室** 區塊，用於管理 Chamilo 可追蹤的實體場地，以支援面授或混成訓練：分校（據點）、其中的教室，以及查詢特定時段哪些教室空閒的工具。

![管理儀表板上的教室區塊，列出分校、教室與教室可用性查詢](/.gitbook/assets/admin-rooms-block.png)

本章說明管理員端對分校與教室的管理。教師端——將教室指派給課程場次——請參閱教師指南中的 [分校與教室](../../teacher-guide/branches-and-rooms.md)。

## 存取教室區塊

在管理面板中，**教室** 區塊會與其他儀表板區塊並列顯示。點選其中任一連結即可開啟對應工具。

## 區塊內容

* **[管理教室](managing-rooms.md)** — 建立並組織分校（據點），以及各分校內的教室
* **[教室可用性查詢](room-availability-finder.md)** — 查詢特定日期與時段內哪些教室空閒

## 多網址注意事項

在多網址（多租戶）安裝中，分校與教室各自限定於單一存取網址——絕不會跨入口網站共用。
