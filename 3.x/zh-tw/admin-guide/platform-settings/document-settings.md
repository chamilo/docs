# 文件設定

課程 **文件** 工具的行為——上傳、允許的副檔名、分享與範本。

可於 **管理 > 組態設定 > 文件** 存取這些設定。此分類包含 **29 項設定**，以下列出平台設定 fixtures（`SettingsCurrentFixtures.php`）中隨附的標題與說明。

> 程式碼中的變數名稱以等寬字體顯示。透過 API 撰寫指令碼，或需以編輯 [`config/settings_override.yaml`](https://github.com/chamilo/chamilo-lms/wiki/Configurations#configsettings_overridesyaml) 的方式在全域層級變更這些設定時，請使用該名稱。

## 設定

### `access_url_specific_files`

**啟用 URL 專屬檔案**

在多 URL 組態中啟用此功能後，您可前往主要 URL，並為任何檔案（於文件工具中）提供 URL 專屬版本。從不同 URL 檢視時，原始檔案將由替代版本取代。這讓您能進一步自訂各 URL，同時享有多次重複使用相同課程的優點。

*預設值：`false`*

### `default_document_quotum`

**預設硬碟空間**

課程可用的磁碟空間為何？您可透過：平台管理 > 課程 > 修改，覆寫特定課程的配額

*預設值：`1000`*


### `default_group_quotum`

**群組可用磁碟空間**

群組文件工具的預設硬碟空間為何？

*預設值：`250`*


### `documents_custom_cloud_link_list`

**為雲端連結設定嚴格主機清單**

文件工具可整合雲端檔案連結。雲端服務清單限於硬編碼清單，但您可定義將包含自有服務／URL 清單的 ‘links’ 陣列。此處定義的清單將取代預設清單。

### `documents_default_visibility_defined_in_course`

**於課程中定義文件可見性**

所有課程的預設文件可見性

*預設值：`false`*

### `documents_hide_download_icon`

**隱藏文件下載圖示**

在文件工具中，對使用者隱藏下載圖示。

*預設值：`false`*


### `enable_x_sendfile_headers`

**啟用 X-sendfile 標頭**

若您已在網頁伺服器層級啟用 X-sendfile，並希望加入瀏覽器所需的標頭，請啟用此項。

*預設值：`false`*

### `group_category_document_access`

**啟用群組類別內文件的分享選項**

啟用後，管理員可依類別為文件群組設定文件存取與分享權限。

*預設值：`false`*


### `group_document_access`

**啟用群組文件的分享選項**

啟用後，可在群組層級設定文件分享與存取權限。

*預設值：`false`*


### `pdf_export_watermark_by_course`

**啟用依課程定義浮水印**

啟用此選項後，教師可為其課程中的文件定義自己的浮水印。

*預設值：`false`*


### `pdf_export_watermark_enable`

**啟用 PDF 匯出浮水印**

啟用此選項後，您可上傳影像或文字，系統會自動將其作為浮水印加入所有文件的 PDF 匯出。

*預設值：`false`*

### `pdf_export_watermark_text`

**PDF 浮水印文字**

此文字將作為浮水印加入匯出為 PDF 的文件。

### `permanently_remove_deleted_files`

**已刪除檔案無法還原**

在文件工具中刪除檔案會永久刪除該檔案。檔案無法還原

*預設值：`false`*

### `permissions_for_new_directories`

**新目錄的權限**

能夠定義指派給每個新建立目錄的權限設定，有助於提升安全性，防範駭客上傳危險內容至您的入口網站。預設設定（0770）應足以為伺服器提供合理的保護等級。給定格式使用 UNIX 的擁有者-群組-其他人，以及讀取-寫入-執行權限術語。

*預設值：`0770`*


### `permissions_for_new_files`

**新檔案的權限**

能夠定義指派給每個新建立檔案的權限設定，有助於提升安全性，防範駭客上傳危險內容至您的入口網站。預設設定（0550）應足以為伺服器提供合理的保護等級。給定格式使用 UNIX 的擁有者-群組-其他人，以及讀取-寫入-執行權限術語。若您使用 Oogie，請注意啟動 LibreOffice 的使用者必須能在課程資料夾中寫入檔案。

*預設值：`0660`*


### `send_notification_when_document_added`

**新增文件時傳送通知給學生**

每當有人在文件工具中建立新項目時，向使用者傳送通知。

*預設值：`false`*

### `show_default_folders`

**在文件工具中顯示所有包含系統預設多媒體資源的資料夾**

包含系統預設提供之檔案的多媒體資料夾，依影片、音訊、影像與 Flash 動畫等類別整理，供課程使用。即使您將其在文件工具中設為不可見，仍可在平台網頁編輯器中使用這些資源。

*預設值：`true`*

### `show_documents_preview`

**顯示文件預覽**

在文件工具中顯示文件預覽，可避免僅為檢視文件而載入新頁面，但在部分較舊的瀏覽器或較窄的螢幕上可能不穩定。

*預設值：`false`*

### `show_users_folders`

**在文件工具中顯示使用者資料夾**

此選項可讓您向教師顯示或隱藏系統為每位造訪文件工具或透過網頁編輯器傳送檔案的使用者所產生的資料夾。若向教師顯示這些資料夾，教師可決定是否讓學習者看見，並讓每位學習者在課程中擁有專屬空間，不僅可儲存文件，還可建立與編輯網頁、匯出為 PDF、繪圖、製作個人網頁範本、傳送檔案，以及建立、移動與刪除目錄與檔案，並為其資料夾製作安全備份。課程中的每位使用者都擁有完整的文件管理員。另請注意，任何使用者都可將文件工具中任何資料夾內可見的檔案（無論是否為擁有者）複製到其作品集或社群網路的個人文件區，以便在其他課程中使用。

*預設值：`true`*

### `students_download_folders`

**允許學習者下載目錄**

允許學習者從文件工具將整個目錄打包並下載

*預設值：`true`*


### `students_export2pdf`

**允許學習者在文件與 Wiki 工具中將網頁文件匯出為 PDF 格式**

此功能預設為啟用，但若發生伺服器過載濫用，或特定學習環境有需要，可能希望對所有課程停用。

*預設值：`true`*

### `thematic_pdf_orientation`

**課程進度的 PDF 方向**

在課程進度工具中，您可列印各元素的 PDF。設定為 ‘portrait’ 或 ‘landscape’（技術用語）以變更方向。

*預設值：`landscape`*


### `upload_extensions_blacklist`

**黑名單 - 設定**

黑名單用於依副檔名篩選檔案，移除（或重新命名）副檔名列於下方黑名單中的任何檔案。副檔名應不含前導點（.），並以分號（;）分隔，例如：exe;com;bat;scr;php。無副檔名的檔案會被接受。大小寫（大寫／小寫）無關。

### `upload_extensions_list_type`

**文件上傳的篩選類型**

您要使用黑名單或白名單篩選。詳情請參閱下方黑名單或白名單說明。

*預設值：`blacklist`*


### `upload_extensions_replace_by`

**取代用副檔名**

輸入您要用來取代篩選器偵測到之危險副檔名的副檔名。僅在您選擇以取代方式篩選時才需要。

*預設值：`dangerous`*


### `upload_extensions_skip`

**篩選行為（略過／重新命名）**

若選擇略過，經黑名單或白名單篩選的檔案將不會上傳至系統。若選擇重新命名，其副檔名將被取代為「取代用副檔名」設定中所定義者。請注意，重新命名並不能真正保護您，且若存在多個同名但副檔名不同的檔案，可能造成名稱衝突。

*預設值：`true`*


### `upload_extensions_whitelist`

**白名單 - 設定**

白名單用於依副檔名篩選檔案，移除（或重新命名）副檔名*未*列於下方白名單中的任何檔案。一般認為這是較安全但較嚴格的篩選方式。副檔名應不含前導點（.），並以分號（;）分隔，例如：htm;html;txt;doc;xls;ppt;jpg;jpeg;gif;sxw。無副檔名的檔案會被接受。大小寫（大寫／小寫）無關。

### `users_copy_files`

**允許使用者將課程中的檔案複製到個人檔案區**

允許使用者將課程中的檔案複製到個人檔案區，可透過社群網路檢視，或在離開課程時透過 HTML 編輯器使用

*預設值：`true`*


### `video_features`

**影片功能**

可為 Chamilo 中的影片播放器啟用的額外功能陣列。選項包括 'speed'，可讓您變更影片播放速度。
