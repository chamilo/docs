# 問卷範本

系統管理員可以建立可重複使用的問卷，提供給教師使用，或直接指派給課程與會期。此功能於 [PR #9208](https://github.com/chamilo/chamilo-lms/pull/9208) 中實作，以解決 [issue #8760](https://github.com/chamilo/chamilo-lms/issues/8760)。

## 建立與維護範本

1. 在管理面板中，開啟 **問卷範本**，然後選擇 **建立**。
2. 輸入標題與選填的副標題；設定匿名性、題目版面配置、隨機排序、時長、引言與致謝文字。
3. 儲存後，在範本的題目編輯器中新增或編輯可重複使用的題目。
4. 若希望教師能夠看見並重複使用，請啟用 **顯示為範本**。未顯示的範本仍可供系統管理員使用。

範本屬於目前的存取 URL。僅平台管理員可以建立、編輯或刪除主範本。教師可以使用已顯示的範本，但無法變更其主定義。

## 在課程或會期中重複使用範本

在已授權的課程或會期中，教師建立新問卷時可以選擇已顯示的範本。結果是該課程情境中的一份問卷，而非對可重複使用主範本的修改。教師可以檢視題目，並依循一般的發佈與邀請流程。

在管理範本清單中，系統管理員也可以將範本直接指派給所選的 **課程**，並可選擇該課程的其中一個 **會期**。Chamilo 會檢查該課程是否屬於目前入口網站，以及所選會期是否確實包含該課程。教師介面無法用來將範本指派給他人的課程或會期。

新問卷不會僅因從範本建立而自動發佈；邀請參與者之前請先檢視。標準問卷流程請參閱 [問卷](../teacher-guide/assessing-learners/surveys.md)。

## 對教師或導師隱藏敏感結果

編輯實際問卷時，平台管理員可以啟用 **對教師／導師隱藏結果**。此項針對個別問卷的限制適用於敏感問卷，例如對教學人員的評鑑。教師與導師仍可檢視回應數量並傳送提醒，但 **無法開啟報表檢視或匯出結果**。平台管理員仍保有報表存取權，但須受其他平台設定限制。

此選項不同於一般的 **結果可見性** 欄位，也不同於全平台的 **隱藏問卷報表按鈕** 設定。僅管理員可以變更受限結果旗標。

## 權限與範圍

* **系統管理員：** 管理範本、設定範本可見性、指派給符合資格的課程／會期，以及控制受限結果存取。
* **教師／會期教師：** 僅能在其已授權的課程情境中看見並實例化已顯示的範本。
* **存取 URL：** 範本目錄與指派會強制套用目前的存取 URL；其他入口網站的範本無法跨越邊界進行實例化。

若範本未向教師顯示，請檢查 **顯示為範本** 及其課程／會期情境。若範本無法實例化，請檢查全域問卷建立限制以及預定的目標課程／會期。
