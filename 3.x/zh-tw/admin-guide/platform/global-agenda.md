# 全域行事曆

全域行事曆與課程及個人行事曆所使用的日曆工具相同，但以平台層級模式開啟：在此建立的活動不附加任何課程或工作階段，正因如此，所有已登入使用者皆可看見，而非僅限特定課程或工作階段的成員。

## 存取全域行事曆

在管理面板中，點選 **平台 > 全域行事曆**。

## 與課程及工作階段行事曆的差異

日曆活動的範圍取決於是否連結至課程或工作階段資源：

* **課程／工作階段活動**僅限該課程或工作階段的已註冊成員可見
* **全域活動**沒有此類連結，因此任何已登入使用者皆可看見

除了範圍差異外，全域活動支援與課程活動相同的功能：**重複發生**（依排程重複）、**檔案附件**與**提醒**。

## 使用情境

請將全域行事曆用於與特定課程無關的平台層級日期——維護時段、全機構截止日期、假日或全公司活動——而不必在每個課程的行事曆中重複建立相同活動。
