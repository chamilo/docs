# 平台

管理儀表板上的 **平台管理** 區塊彙整了整個入口網站層級的設定與溝通工具——從完整設定面板、語言、公開公告、全域行事曆，到以類似 CMS 方式建置入口網站對外公開內容的「頁面」系統。

![管理儀表台上的平台管理區塊，列出組態設定、語言、外掛、區域、入口網站新聞、全域議程、頁面、設定註冊頁面、額外欄位、設定多重存取 URL、郵件範本、外部工具 (LTI)、聯絡表單類別，以及系統範本](/.gitbook/assets/admin-platform-block.png)

## 存取平台區塊

在管理面板中，**平台管理** 區塊會與其他儀表台區塊並列顯示。點選其中任一連結即可開啟對應工具。

## 區塊內容

* **[平台設定](../platform-settings/README.md)** — 完整的組態設定面板（入口網站、課程、時段、使用者、安全性等）。此區塊的「組態設定」連結只是進入該獨立章節的入口。
* **[語言](languages.md)** — 選擇使用者可使用的介面語言，並設定平台預設語言
* **[入口網站新聞](portal-news.md)** — 全平台公告（系統公告），可排程並依角色鎖定對象
* **[全域議程](global-agenda.md)** — 全平台行事曆事件，無論課程或時段，所有使用者皆可見
* **[頁面](pages.md)** — 類似 CMS 的工具，用於入口網站首頁、頁尾及其他公開內容區塊，包含註冊頁面的介紹文字
* **[平台工具](platform-tools.md)** — 額外欄位、郵件範本、聯絡表單類別，以及若干較小、依條件顯示的項目
* **設定多重存取 URL** — 說明見 [存取 URL](../multi-url/access-urls.md)，位於 Multi-URL 之下
* **外部工具 (LTI)** — 說明見 [LTI 1.3](../integrations/lti.md)，位於 Integrations 之下
