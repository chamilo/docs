# 頁面

頁面是 Chamilo 內建、類似 CMS 的工具，用來管理構成入口網站對外公開區域的內容區塊——首頁、頁尾、導覽選單及類似位置——而無須修改範本檔案。

## 存取頁面

在管理面板中，點選 **平台 > 頁面**。

## 頁面如何運作

每個頁面包含：

* **標題** 與富文字 **內容**
* **slug**，由標題自動產生
* **啟用** — 該頁面目前是否可見
* **位置** — 在所屬分類內以拖放方式排序
* **地區設定** — 內容依語言分開：同一放置位置可為每種語言各有一頁，若訪客語言沒有對應頁面，網站會回退至平台預設語言
* **分類** — 決定頁面*呈現於何處*（例如 `index`、`home`、`footer_public` 或 `menu_links`）；Chamilo 會自動建立所需分類

在多網址（多入口網站）安裝中，頁面亦依存取網址區隔，因此每個入口網站各自管理自己的內容。

## 註冊介紹頁

**平台 > 設定註冊頁面** 是進入同一套頁面系統的捷徑，專門對應一個放置位置：公開註冊表單上方顯示的介紹文字。僅限入口網站管理員使用。點選後會：

* 若您的存取網址與語言已有介紹頁，則開啟該頁進行編輯，或
* 即時建立該放置位置，並直接帶您建立其內容

您在此儲存的內容會以資訊框形式直接呈現於註冊表單上方——適合放置說明、貴機構專屬條款，或準使用者在註冊前應閱讀的背景資訊。若保持停用（或從未建立），則顯示沒有介紹文字的一般註冊表單。
