# 語言

此工具用來管理使用者可選擇的介面語言——並不管理翻譯字串本身（那些來自 Chamilo 隨附的語言套件，無法在此編輯）。

## 存取語言設定

在管理面板中，點選 **平台 > 語言**。

## 您可以執行的操作

* **切換可用性** — 以每列一個簡單的開／關開關，啟用或停用各隨附語言，使其成為登入頁面與使用者個人資料設定中的選項
* **設定平台預設語言** — 選擇在沒有使用者偏好時所使用的語言；目前的預設語言會以專屬圖示標示，且無法隱藏
* **停用預設以外的所有語言** — 單一批次動作，將語言選擇器精簡為僅剩平台的預設語言
* **編輯原生名稱** — 調整語言在選擇器中顯示的自身名稱（其「原始名稱」）

## 停用正在使用中的語言

若您停用作用中使用者已選為介面語言的語言，Chamilo 會要求確認，且——若您確認——會將所有受影響的使用者遷移至平台預設語言。不會出現使用者仍選著現已隱藏語言的部分狀態。

## 由右至左語言

由右至左語言（例如阿拉伯文、希伯來文或波斯文）在選取後會自動將介面切換為由右至左版面——無需在此處或其他地方進行任何設定。近期版本已大幅改進 RTL 支援。

## 子語言

若已啟用 **允許子語言** 設定，會出現用於建立「子語言」的額外動作——對父語言的部分覆寫，過去用於地區方言或機構專用術語調整。這是舊版功能；大多數安裝不需要它。
