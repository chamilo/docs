# 一對一視訊通話

Chamilo 在**浮動平台聊天**中提供選用的**一對一視訊通話**。它使用瀏覽器的 WebRTC 支援，讓兩位正在使用 Chamilo 的使用者互相連線。這與**課程聊天工具**，以及以 BigBlueButton 或 Zoom 建立的會議不同。

此功能因 [issue #3777](https://github.com/chamilo/chamilo-lms/issues/3777) 而引入並改進，相關 PR 為 [#9102](https://github.com/chamilo/chamilo-lms/pull/9102)、[#9110](https://github.com/chamilo/chamilo-lms/pull/9110)、[#9112](https://github.com/chamilo/chamilo-lms/pull/9112)、[#9127](https://github.com/chamilo/chamilo-lms/pull/9127) 與 [#9128](https://github.com/chamilo/chamilo-lms/pull/9128)。

## 開始之前

* 管理員必須允許使用浮動平台聊天，並將**在全域聊天中隱藏視訊聊天選項**（`chat.hide_chat_video`）設為**否**。此選項預設為隱藏。請參閱[聊天設定](../admin-guide/platform-settings/chat-settings.md)。
* 請使用支援 WebRTC 的瀏覽器，並授予相機與麥克風存取權限。瀏覽器的媒體存取通常需要 HTTPS（或受信任的本機開發環境）。
* 請先登入，並將聊天狀態設為**線上**。請選擇一般使用者聯絡人；若對方為機器人，或此功能已停用，則不會顯示視訊按鈕。
* 對方必須能夠接收並接受通話。

## 開始通話

1. 開啟 Chamilo 底部的**浮動聊天面板**（不是課程本身的聊天頁面）。
2. 選取您要聯絡的人。
3. 在對話標題列中，點選**開始視訊通話**相機圖示。
4. 當瀏覽器詢問時，授予相機與麥克風存取權限。
5. 在 Chamilo 等待對方時，通話會顯示**通話中...**。對方接受後，狀態會經由**連線中...**，並在對等連線成功後變更為**已連線**。

未接聽的通話會逾時，而不會無限期持續。若對方拒絕或取消，聊天會顯示說明狀態的訊息。

## 接聽與管理通話

當聯絡人來電時，浮動聊天會顯示**來電視訊通話**對話框。選擇**接受**以加入，或選擇**拒絕**以婉拒。接受時也可能會要求授予相機與麥克風使用權限。

通話期間，您可以**將麥克風靜音或取消靜音**、**開啟或關閉相機**，以及**掛斷**。小型預覽會顯示您的本機視訊，主要區域則顯示對方。關閉或結束通話會釋放本機的音訊／視訊串流。

這是**兩位使用者之間的私人通話**，而非全課程會議。若要舉辦具錄製或協作工具的排程群組會議，請使用貴機構的[視訊會議](../teacher-guide/collaboration-and-communication/video-conferencing.md)整合。

## 若無法使用視訊通話

* **沒有開始視訊通話圖示：** 請檢查平台的 `chat.hide_chat_video` 設定、浮動聊天是否可用、您的線上狀態，以及瀏覽器的 WebRTC 支援。
* **相機或麥克風錯誤：** 請在瀏覽器中允許媒體權限，並確認硬體存在且未被其他應用程式佔用。
* **無人接聽：** 請請聯絡人開啟 Chamilo 並確認其可用性。撥出請求設有逾時。
* **接受後連線失敗：** 請嘗試其他網路，並檢查瀏覽器權限或防火牆限制。目前的 WebRTC 實作使用公開的 STUN 伺服器，且未設定 TURN 中繼，因此在限制較嚴的網路上連線可能失敗。若視訊訊號傳遞失敗，文字聊天仍可使用。

此直接通話功能無需設定 BigBlueButton 或 Zoom；這些整合提供的是另一種類型的會議。
