# 社群網路

Chamilo 內建社群網路，讓您可與平台上的其他使用者連線——獨立於任何特定課程。您是否能使用此功能完全取決於管理員：預設為開啟，但可於整個平台關閉。

## 您是否擁有存取權限

在側邊欄中點選 **社群網路** <img src="../.gitbook/assets/icons/mdi-sitemap-outline.svg" alt="社群網路" data-size="line"> 以展開，然後點選 **首頁**。若完全沒有此選項，表示管理員已為您的平台停用此功能——並非您這邊缺少任何設定。

同一展開區塊也會列出 **訊息**、**我的好友**、**社群群組**——以及較為出乎意料的 **我的檔案**（您的個人檔案儲存空間）與 **個人資料**（平台所持有關於您之個人資料的匯出）。後兩者並非社群功能；只是被歸入側邊欄的這個區塊。

## 您的社群牆

進入後，您的 **牆** 會顯示您與已連線對象的活動動態。您可以發佈更新，並且——若管理員已啟用——可對連線對象的貼文按讚或倒讚，以及留言。

![社群牆，含貼文編輯器以及社群、好友與技能面板](../.gitbook/assets/student-social-wall.png)

## 與他人連線

您可以搜尋其他使用者並傳送連線請求。身為 **學習者，您只能與其他學習者連線**——無法向教師傳送連線請求。教師則可以向您傳送請求。在部分平台上，管理員會將教師設定為自動成為每位學習者的好友，雙方皆無需提出請求——若您看到教師已列為連線對象而您並未提出請求，原因即在此。

## 從社群網路傳送訊息

貼文與連線屬於社群面向；傳送私人訊息則由平台獨立的 [收件匣](inbox.md) 處理——社群網路會連結至該功能，而非另有獨立的訊息系統。

## 社群群組

您可以加入圍繞共同興趣建立的既有 **社群群組**，並且——若管理員允許學習者建立群組——自行建立群組。社群群組為平台層級，與課程本身的 **群組** 工具無關（請參閱 [認識課程介面](courses/course-tools-overview.md)）；加入或在社群群組發文，不會影響您已註冊的任何課程。

## 提示

* **不要預期能自行將教師加為好友**——僅能由教師端發起，除非管理員已設定自動連線。
* **社群群組與課程群組互不相關**——請勿將課程專案群組與同名的社群網路群組混淆。
* **看不到按讚或倒讚？** 管理員可於整個平台啟用，或僅部分停用（只保留「按讚」）該功能。
