# 帳號與安全性

您的 Chamilo 帳號可讓您存取課程、成績與個人資料——值得妥善保護。本節說明學習者可能會遇到的帳號保護功能。

* **[重設密碼](resetting-your-password.md)** — 忘記密碼或想變更密碼時該怎麼做
* **[雙因素驗證](two-factor-authentication.md)** — 若管理員已啟用，可為帳號再加一層保護
* **[CAPTCHA](captcha.md)** — 為何在登入、註冊或忘記密碼表單上可能會被要求證明您是真人

此處說明的功能並非都會在您的平台上啟用——管理員可分別開啟或關閉各項功能。若本節所述內容未出現，多半是尚未啟用。
