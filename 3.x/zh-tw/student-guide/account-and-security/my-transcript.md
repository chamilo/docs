# 我的成績單

若您的平台已啟用學業成績單，您可以檢視已完成且已取得證書之課程的紀錄，並下載非正式成績單。您的機構也可能核發經簽署的正式成績單。

## 開啟您的成績單

1. 登入後，從頂端導覽列開啟 **我的成績單**（若此選項可用）。
2. 或在已登入狀態下，前往您的 Chamilo 入口網站的 `/transcript`。
3. 檢視您已完成的課程、課程代碼、成績、日期、時數、總成績與 GPA。
4. 選取 **下載非正式成績單**，以儲存目前紀錄的 PDF。

此紀錄是根據您仍在修讀的課程與場次之根評估（gradebook）所產生的符合資格證書所建立。若某課程尚未產生符合資格的證書，則可能不會出現。若沒有任何課程符合資格，Chamilo 會顯示 **尚無已完成的課程。**

成績等第與平均績點取決於您機構所設定的評分量表。除非管理員變更底層課程與成績的記錄方式，否則 GPA 是以所列課程績點的未加權平均計算。

## 正式成績單

在 **正式成績單** 下，若有經授權人員為您核發的簽署版本，即可在此找到。每個版本都會記錄核發日期與核發者。使用 **下載** 取得其 PDF，並使用 **驗證** 在其驗證頁面檢查數位簽章。

正式版本是核發當時您紀錄的快照。後續成績或課程變更時，它**不會**自動更新；您的機構可以核發較新的版本。授權人員可以撤銷較舊的版本，其公開驗證頁面隨後會顯示該撤銷狀態。

您無法自行核發或撤銷正式成績單。若需要新的或更正後的簽署成績單，請向您的機構提出。請審慎分享公開驗證連結：持有該連結的人可能得以查看有效簽署成績單的詳細內容。

若缺少 **我的成績單**，表示您的入口網站可能尚未啟用此功能。關於管理設定，請參閱 [學業成績單](../../admin-guide/users/academic-transcripts.md)。
