# CAPTCHA

CAPTCHA 是一種簡單的挑戰——通常是輸入扭曲圖片中顯示的字母——用來確認填寫表單的是真人，而非自動化軟體。若管理員已啟用此功能，您可能會在**登入**、**註冊**與**忘記密碼**表單上遇到它。

## 它保護什麼

CAPTCHA 的存在是為了阻止自動化指令碼濫用這些表單：

* 在**登入表單**上，它會減緩「密碼轟炸」——指令碼快速猜測密碼以闖入帳號。
* 在**註冊表單**上，它可防止機器人大量建立假帳號。
* 在**忘記密碼表單**上，它可防止自動化濫用密碼重設電子郵件系統。

簡而言之，它是為了保護您的帳號——以及帳號背後的個人資料——免於自動化攻擊，而非為難真正的使用者。

## 您會看到什麼

一張含有扭曲字母的小圖，並附有：

* 提示：若無法辨識，可點擊圖片載入新的一張。
* 其下方有一個文字欄位，標示請輸入您所看到的字母。

若輸入不符，系統會請您以新圖片再試一次。

## 重複錯誤

管理員可設定允許的 CAPTCHA 錯誤次數上限，以及超過後帳號暫時鎖定的時長。若您因多次失敗而被鎖定，請等待鎖定期間結束，或在需要儘早存取時聯絡管理員。

## 若您沒有看到它

CAPTCHA 為選用功能且套用於整個平台——若管理員尚未啟用，您在任何地方都不會遇到它，即使其他方面與您的平台類似。
