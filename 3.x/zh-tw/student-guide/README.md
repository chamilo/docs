# 學生指南

歡迎使用 Chamilo 3.0 學生指南。本指南專為學習者而設計——無論是透過學校、企業培訓計畫，或開放線上課程，凡在 Chamilo 平台上修課的任何人。

無論這是您第一次使用 Chamilo，或已報名多門課程，本指南都將協助您熟悉操作、加入課程，並確保帳號安全。

## 身為學生您可以做什麼

作為 Chamilo 的學習者，您可以：

* **建立帳號**（若您的平台允許自行註冊）並登入
* **加入課程**——透過公開目錄、邀請，或由管理員或教師為您註冊
* **使用課程工具**——閱讀文件、跟隨學習路徑、參加練習、繳交作業等
* **溝通交流**——使用論壇、聊天與群組，與教師及其他學習者互動
* **追蹤個人進度**——查看分數、完成狀態與證書
* **向 AI Tutor 求助**（若您的平台已啟用此功能）
* **確保帳號安全**——重設忘記的密碼並啟用雙因素驗證

## 本指南的組織方式

1. **Getting Started** — 建立帳號（或登入），並了解一般介面
2. **Courses** — 訂閱課程、使用其工具（學習路徑、測驗、作業、論壇、聊天），並使用 AI Tutor
3. **Inbox** — 與其他平台使用者收發私人訊息
4. **Social Network** — 與其他使用者連結（若管理員已啟用此功能）
5. **My Progress** — 快速總覽您在所有課程中的活動與成果
6. **Account and Security** — 重設密碼、啟用雙因素驗證，並了解 CAPTCHA

本指南涵蓋入門所需的基本內容，日後將逐步擴充更多主題。
