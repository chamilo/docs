# 詞彙表

本指南中使用的關鍵術語。

| 術語 | 定義 |
|------|-----------|
| **評量** | 請參閱下方的 **成績簿** |
| **作業** | 您提交檔案或文字供教師審閱與評分的任務。亦稱為「學生作品」或「work」。 |
| **CAPTCHA** | 一種挑戰（通常是從圖片中輸入扭曲的字母），用來確認您是真人，會出現在部分登入、註冊與忘記密碼表單上。 |
| **目錄** | 課程（及期別）的公開清單，您可瀏覽，並在某些情況下自行註冊。可透過 **探索更多課程** 進入。 |
| **證書** | 當您達到課程成績簿中所定義的最低分數時，系統自動產生的文件。 |
| **課程** | 學習內容與工具的容器。課程可包含文件、練習、論壇、學習路徑等。 |
| **註冊** | 被登記至某課程或期別，從而取得其內容的存取權。亦稱為「訂閱」。 |
| **練習** | 包含一題或多題的測驗或考試。在某些情境中亦稱為「test」。 |
| **論壇** | 討論工具，以分類與主題組織的串接式對話。 |
| **成績簿** | 將您在練習、作業及其他活動中的分數彙整為統一成績的工具。 |
| **邀請** | 教師寄至您電子郵件地址的一次性連結，讓您得以註冊並自動訂閱某課程，即使一般註冊已關閉。 |
| **學習路徑** | 學習活動（文件、練習、連結）的結構化序列，您依既定順序進行，有時設有先決條件。 |
| **自行註冊** | 若平台管理員已啟用，您可透過公開註冊表單自行建立帳號。 |
| **期別** | 一門或多門課程的時限版本，指派給特定學習者群體，例如學期或同屆。 |
| **技能** | 與成績簿成就連結的能力。取得證書可驗證相關技能。 |
| **雙因素驗證（2FA）** | 除密碼外，額外使用驗證器應用程式產生的時基代碼進行登入的步驟。 |
| **可見性** | 控制工具、文件或活動是否對學習者顯示的設定。教師一律可看見隱藏項目。 |
