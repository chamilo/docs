# 在課程中找到方向

開啟課程後，您會看到課程首頁，其上有工具圖示網格。本頁說明各項工具對學習者的意義，並連結至更詳細描述該功能的位置。

只有教師對學習者設為可見的工具會出現在您的網格中——教師可能會看到額外、對您隱藏的工具。若您預期的工具不在其中，可能只是被隱藏，或已對整個課程停用；請向教師詢問。

## 您不會看到的工具——以及一個無法使用的工具

有些項目僅供教師與課程管理員用來設定課程本身——課程設定、課程維護（備份／匯入／匯出）、課程首頁編輯器，以及（在大多數平台上）部落格工具，都位於僅對擁有課程編輯權限的人顯示的「更多動作」選單中。身為學習者，您完全不會看到此選單。

**報表**圖塊是特例：它確實會出現在您的格線中，但會開啟供教師使用的全班追蹤檢視，因此點選後會得到拒絕存取的訊息，而非任何有用內容：

![以學習者身分點選報表圖塊會出現拒絕存取訊息](../../.gitbook/assets/student-course-reporting-denied.png)

別擔心——您自己的進度可在其他地方取得：從主側邊欄的 **我的進度**（請參閱 [了解介面](../getting-started/understanding-the-interface.md) 與 [我的進度](../my-progress.md)），以及上方的 **課程進度** 與 **評量** 工具，兩者都會顯示您自己的資料。

若您的課程已啟用 AI 功能，您也可能注意到教師的「AI 分析器」選項（用來以課程本身的內容預先訓練 AI 導師）與學習者面向的 **AI 導師** 聊天不同——請參閱 [AI 導師聊天機器人](ai-tutor.md)。

## 提示

* **少了某個工具？** 請詢問您的教師——最有可能是被隱藏或停用，而非故障。
* **課程說明與公告** 可由教師完全關閉；若如此，任何人（包括教師）都不會看到它們。
* **此處的一切都可能因課程而異**——教師會針對每門課程個別決定哪些工具為啟用且可見。
