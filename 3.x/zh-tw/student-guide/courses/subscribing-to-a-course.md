# 訂閱課程

在您能夠存取課程內容之前，必須先訂閱（註冊）該課程。依平台設定不同，這可能以幾種方式發生——其中大多數完全不需要您採取任何動作。

| 發生方式 | 您需要做的事 |
|-----------------|----------------------|
| 管理員為您註冊 | 無需任何操作——完成後課程會出現在 **我的課程** 中 |
| 教師手動為您註冊 | 無需任何操作——同上 |
| 您透過課程目錄自行註冊 | 瀏覽 **探索更多課程**，然後點選加入 |
| 您收到電子郵件課程邀請 | 點選連結；若尚未有帳號則進行註冊 |

## 查看您的課程

隨時點選側邊欄中的 **我的課程**，即可查看您目前已註冊的所有課程。若您預期會出現的課程未列出，表示您尚未被訂閱——請使用下列其中一種方法，或聯絡您的教師或管理員。

## 透過課程目錄自行註冊

若課程的可見性允許，您可以自行訂閱，無需等待他人：

1. 點選側邊欄中的 **探索更多課程** 以開啟課程目錄。
2. 瀏覽或搜尋您想加入的課程。
3. 點選課程以開啟其詳細資料，然後點選加入按鈕。

![課程目錄，每張課程卡片上皆有訂閱按鈕](/.gitbook/assets/student-course-catalogue.png)

您已註冊的課程會顯示 **前往課程**，而非訂閱按鈕。

部分課程自行註冊時需要密碼——若是如此，教師會另行提供給您。若課程完全沒有加入按鈕，表示該課程未開放自行註冊；請改請教師或管理員為您訂閱。

若您的平台使用 **sessions**，同樣的概念也適用於 **我的 sessions**——部分 session 可能透過目錄開放自行註冊，不過這通常由管理員或 session 導師管理，因為訂閱一個 session 會同時訂閱其中的每一門課程。

## 接受課程邀請

教師也可能不以目錄列出的方式，而是透過電子郵件傳送 **課程邀請**——這是唯一不要求您事先擁有平台帳號的方法。開啟電子郵件中的連結會：

* 在註冊表單上將電子郵件欄位預先填入並鎖定為您受邀的地址。
* 即使平台目前關閉一般自行註冊，仍允許您註冊。
* 在您完成註冊後立即自動將您訂閱至該課程（若該課程是在某個 session 中開放，則訂閱整個 session），並為您登入。

該連結為一次性使用，並於 7 天後過期——若無法使用，請請邀請您的教師重新傳送。此流程的更多細節請參閱 [受邀者所見畫面](../../teacher-guide/assessing-learners/subscribing-users.md#what-the-invited-person-sees)，註冊表單本身的外觀請參閱 [建立帳號](../getting-started/creating-an-account.md)。

## 提示

* **詢問前先查看「探索更多課程」** — 許多平台會開放課程自行註冊，因此您可能無需等待任何人即可立即加入。
* **留意您的收件匣** — 課程邀請與帳號核准通知都會以電子郵件寄達。
* **仍然無法進入？** 註冊方式可能在整個平台層級被限制或停用，因此若以上方法皆無效，您的教師或管理員隨時可以直接為您訂閱。
