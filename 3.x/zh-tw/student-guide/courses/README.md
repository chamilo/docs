# 課程

一旦您擁有帳號，下一步就是進入課程並熟悉其中的操作。

* **[訂閱課程](subscribing-to-a-course.md)** — 您可能被納入某門課程的各種方式
* **[熟悉課程介面](course-tools-overview.md)** — 課程首頁上各項工具對學習者的意義
* **[跟隨學習路徑](following-a-learning-path.md)** — 依引導順序完成一連串活動
* **[參加測驗](taking-tests.md)** — 教師指派小考或考試時您可以預期的內容
* **[繳交作業](submitting-an-assignment.md)** — 繳交檔案或文字以供評分
* **[使用論壇](using-the-forum.md)** — 在課程討論串中發文與回覆
* **[使用聊天工具](using-the-chat-tool.md)** — 在課程內進行即時訊息交流
* **[AI 導師聊天機器人](ai-tutor.md)** — 若平台已啟用，可向 AI 助理尋求協助

這些頁面假設您已擁有 Chamilo 帳號。若尚未擁有，請參閱 [建立帳號](../getting-started/creating-an-account.md)。
