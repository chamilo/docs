# 繳交作業

**作業**工具（有時稱為「學生作品」或「work」）是您繳交論文、專題、報告，或其他任何檔案型或文字型作業，供教師評分的地方。

## 繳交您的作業

從課程首頁開啟 **作業** <img src="../../.gitbook/assets/icons/mdi-inbox-full.svg" alt="作業" data-size="line"> 工具，然後開啟特定作業。請仔細閱讀說明——其中包含教師關於應繳交內容及評分方式的指示。接著：

1. 點選 **上傳檔案**（或繳交按鈕）
2. 視教師如何設定該作業而定，從電腦選取檔案、直接以文字撰寫繳交內容，或兩者皆可
3. 可選擇為教師加上註解
4. 繳交

繳交後，您可以看到作業已成功送出的確認。若教師允許，您之後可以更新繳交內容——否則第一次繳交即為最終版本，因此請在繳交前再次檢查。

## 截止日期

作業可以有兩個不同的日期：

* **截止日期** — 此日期之後，您的繳交仍會被接受，但會向教師標示為遲交
* **硬性截止** — 此日期之後，將完全無法再繳交

若作業顯示在行事曆中，那通常就是其截止日期——若不確定何時到期，也值得到該處查看。

## 取得成績與回饋

教師審閱您的繳交內容後，您會看到 **分數** 以及他們撰寫的任何 **回饋意見**。有些教師也會附加 **批改檔案**——即您所繳交內容的註解版本——因此請一併檢查成績旁是否有可下載的附件。若作業已連結至成績簿，您的分數也會計入整體課程成績。

## 查看其他繳交內容

預設情況下，您的繳交內容僅您與教師可見。有些教師會選擇讓全班都能看到繳交內容——若如此，您或許也能看到同學的作業（他們也能看到您的）。

## 提示

* **請在截止日期前繳交，而非等到硬性截止** — 即使遲交仍被接受，仍會被記錄為遲交。
* **到期日之後請再回來查看** 成績與回饋——評分不一定會立即完成。
* **若完全無法繳交**，該作業的硬性截止很可能已過——若您認為這是錯誤，請聯絡教師。
