# 使用聊天工具

部分課程包含 **聊天** 工具——與該特定課程綁定的即時文字訊息，適合在教師在場時進行快速交流或即時問答。

## 傳送訊息

從課程首頁開啟 **聊天** <img src="../../.gitbook/assets/icons/mdi-chat-processing.svg" alt="聊天" data-size="line"> 工具。您會看到目前在該課程中上線的所有人的 **使用者** 清單，每人各有自己的 **聊天** 按鈕，以及供全體使用的 **全部** 分頁：

![課程聊天工具，顯示線上使用者清單與訊息撰寫區](../../.gitbook/assets/student-course-chat.png)

選擇某人（或 **全部**），在底部方塊中輸入訊息。按 **Enter** 傳送，或按 **Shift+Enter** 換行而不傳送。**預覽** 選項可讓您在傳送前檢查格式，**重設** 則會清除您已輸入的內容。

## 若聊天僅限導師使用

您的管理員可限制課程聊天，使僅教師（或其他課程導師）能發文——在此情況下，其他人可閱讀但無法直接參與。若您發現無法在某課程的聊天中傳送訊息，最可能的原因是此設定，而非錯誤。

## 請勿與下列功能混淆

Chamilo 有三種都涉及訊息的不同功能，很容易混淆：

* **本課程聊天工具** — 即時、綁定單一特定課程，僅能從該課程首頁進入。
* **[收件匣](../inbox.md)** — 與平台上任何人的私人、非同步訊息，與任何特定課程無關。
* **浮動聊天面板**（螢幕底部，幾乎隨處可用）— 用於直接訊息與 [AI 導師](ai-tutor.md)，獨立於本課程工具。

若您要找的是另外兩者之一，請參閱其各自頁面。

## 提示

* **用於當下即時交流** — 若日後還想再找到內容，請改用 [論壇](using-the-forum.md)。
* **確認是否排定即時聊天時段** — 教師有時會宣布特定時間會在課程聊天中上線，通常透過行事曆公告。
* **若課程已設定視訊會議**，教師可能較偏好以視訊會議進行即時時段，而非文字聊天。
