# 跟隨學習路徑

**學習路徑**會引導您依教師所定義的順序，完成一組結構化的活動——文件、測驗、連結等。在許多課程中，這是您實際最常（甚至唯一）需要使用的工具，因為它可以把其他所有內容都包在其中。

## 開啟學習路徑

從課程首頁開啟 **學習路徑** <img src="/.gitbook/assets/icons/mdi-map-marker-path.svg" alt="學習路徑" data-size="line"> 工具，然後點選其中一項即可開始。若教師已啟用 **自動啟動**，您一進入課程，學習路徑就可能自動開啟。

![課程的學習路徑清單，每一項皆顯示各自的進度](/.gitbook/assets/student-learning-paths-list.png)

## 在路徑中移動

在學習路徑內，您會看到：

* 側邊面板中的 **項目清單**（步驟），可能依教師分組，類似章節
* 主區域中 **目前項目的內容**——文件、內嵌測驗、連結等

完成項目後會標上核取記號，**進度列**則顯示整條路徑的整體完成百分比。若您離開後稍後再回來，會從上次離開的位置繼續——不會遺失任何進度。

## 鎖定項目與先決條件

部分項目可能顯示為 **鎖定**，直到您滿足教師設定的先決條件——通常是完成較早的項目，或在路徑較前面的測驗達到最低分數。若無法開啟某個步驟，請檢查較早的項目是否尚未完成。

## 路徑中的測驗與證書

學習路徑可將測驗作為其中一個步驟——作答方式與 [參加測驗](taking-tests.md) 所述相同。部分路徑會以 **證書** 步驟作結：到達該步驟（並已滿足沿途任何分數要求）即會觸發完成證書（若教師已為課程設定）。

## SCORM 與其他匯入內容

部分學習路徑項目並非直接在 Chamilo 中建立，而是以 **SCORM** 套件、**CMI5/xAPI** 套件匯入，或使用 C-Studio 外掛建立。這些內容通常看起來與其他互動內容無異——即使內容本身在其他地方製作，Chamilo 仍會以相同方式追蹤您的進度與分數。

## 提示

* **善用進度列** 來掌握路徑還剩多少。
* **不必擔心找不到進度**——Chamilo 會在各次工作階段之間記住您在路徑中的確切位置。
* **鎖定的步驟通常代表路徑較前面還有未完成的工作**——請先回頭檢查，而不要假設是誤被拒絕存取。
