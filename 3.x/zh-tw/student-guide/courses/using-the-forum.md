# 使用論壇

**論壇**工具可在課程中承載結構化、具討論串的討論——適合需要保持條理且便於搜尋的提問與對話，這與即時的 [聊天](using-the-chat-tool.md) 不同。

## 熟悉介面

從課程首頁開啟 **論壇** <img src="/.gitbook/assets/icons/mdi-comment-quote.svg" alt="論壇" data-size="line"> 工具。論壇分為三個層級：

1. **類別** — 較廣泛的分組（例如「一般討論」、「單元 1 提問」）
2. **論壇** — 類別內的個別討論看板
3. **主題（討論串）** — 論壇內的個別對話，各自有一連串回覆

## 發文

開啟論壇並點選以開始**新主題**，或開啟既有主題以**回覆**。視教師對該論壇的設定而定：

* 您可能可以或不可以自行開始新主題——部分論壇僅允許回覆
* 您可能可以或不可以在送出後編輯自己的文章
* 文章可能需經教師核准後才會顯示（**審核制**論壇）——若是如此，您的文章不會立即出現，這是正常現象
* 在完全對公眾開放的課程中，論壇可能允許**匿名發文**——否則您的文章一律會標示為您所發

討論串可依論壇的顯示設定以**平面**、**討論串**或**巢狀**方式呈現——這只會改變回覆的版面配置，不會改變您能做的操作。

## 接收通知

在論壇或個別主題上尋找 **通知我** 開關，以訂閱有人發文時的電子郵件通知。這是個人訂閱——開啟後不會通知其他人，您也可以隨時再關閉。

## 小組與計分論壇

論壇可能綁定特定課程**小組**，而非整門課程——若是如此，僅該小組成員（或依設定，任何課程成員）可閱讀並發文。部分討論串也會**評分**：教師會為該討論串的參與設定最高分數，並可能計入您的課程成績。少數討論串甚至可能是**同儕評分**，您的分數部分取決於至少兩位其他學習者的評等。

## 小提示

* **值得保留的內容請使用論壇** — 與聊天不同，論壇文章依主題整理，之後也容易再找到。
* **訂閱您在意的討論串**，而不要手動一再回來查看。
* **找不到「新主題」按鈕** 通常表示該論壇僅允許回覆，並非系統故障。
