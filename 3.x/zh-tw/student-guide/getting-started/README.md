# 開始使用

本節協助您以學習者身分熟悉 Chamilo 3.0。您將學習如何建立帳號（如有需要）、登入，以及在主要介面中找到所需功能。

## 登入

若要存取 Chamilo，請開啟瀏覽器並前往貴機構提供的 URL（例如 `https://chamilo.yourschool.edu`）。在登入頁面輸入您的使用者名稱與密碼，然後點選 **Sign in**。

若貴機構使用外部驗證（例如 Azure、Keycloak 或大學單一登入系統），您可能會在標準登入表單下方看到額外的登入按鈕。請點選適當的按鈕，透過貴機構的身分提供者進行驗證。

若您尚未擁有帳號，請參閱 [建立帳號](creating-an-account.md)。

> 若您忘記密碼，請在登入頁面點選 **Forgot your password?** 連結。完整流程請參閱 [重設密碼](../account-and-security/resetting-your-password.md)。

## 初次瀏覽

登入後，您將看到 Chamilo 首頁，分為三個主要區域：頂端列、側邊欄與主要內容區。詳細說明請見 [認識介面](understanding-the-interface.md)。

在側邊欄中，點選 **My courses** 即可查看您已註冊的所有課程。每門課程會以卡片呈現，顯示其圖片、標題與快捷操作。

若貴機構使用 **sessions**（有時限的訓練期間），側邊欄中還會出現 **My sessions** 連結，並依進行中、已結束與即將開始的 session 分類。Session 是一門或多門課程的排程梯次或同期群體——相同的課程內容，在特定期間內提供給特定學習者群體。
