# API

Chamilo 3.0 stiller en REST API til rådighed, bygget på **API Platform 4**. API'en giver programmatisk adgang til platformens ressourcer og er den samme API, som Vue-frontend'en bruger.

* **[Autentificering](authentication.md)** — JWT-tokenbaseret autentificering
* **[Reference til endepunkter](endpoints-reference.md)** — Oversigt over tilgængelige API-ressourcer
* **[Tilpassede handlinger](custom-actions.md)** — Specialiserede endepunkter ud over standard CRUD
* **[Webhooks](webhooks.md)** — Hændelsesdrevne notifikationer til eksterne systemer
