# Chamilo 3.0-dokumentation

Velkommen til den officielle dokumentation for **Chamilo 3.0**, den open source e-læringsplatform.

Denne dokumentation er opdelt i fire vejledninger, hver tilpasset en specifik målgruppe:

* [**Lærervejledning**](teacher-guide/) — Til undervisere og trænere: opret kurser, tilføj indhold, vurder kursister og følg fremgang.
* [**Administrationsvejledning**](admin-guide/) — Til platformadministratorer: installer, konfigurer og administrer Chamilo-platformen.
* [**Studievejledning**](student-guide/) — Til kursister: tilmeld dig kurser, følg læringsstier, tag tests og følg din egen fremgang.
* [**Udviklervejledning**](developer-guide/) — Til udviklere: forstå arkitekturen, byg plugins, brug API'et og bidrag til projektet.

## Nyheder i Chamilo 3.0

Chamilo 3.0 er en større udgivelse med fokus på AI-understøttet undervisning, sikkerhedshærdning og et fuldt moderniseret plugin-økosystem:

* **AI-drevne undervisningsværktøjer** — En kursuskvalitetsanalysator, en AI-tutor der besvarer spørgsmål om platformen, en Student Success Coach med anbefalinger pr. kursist, AI-genererede kursusillustrationer og hurtige tests samt AI-assisteret bedømmelse
* **Model Context Protocol (MCP)-server** — Lader AI-klienter oprette og administrere kurser, tests, læringsstier, spørgeskemaer og mere direkte
* **Sikkerhedshærdning** — Indbygget File Integrity Monitoring plus dusinvis af adgangskontrolrettelser på tværs af kurser, sessioner og API'et
* **Fuld modernisering af plugin-økosystemet** — Alle plugins fra 1.11.x genaktiveret, med en redesignet grænseflade til plugin-administration
* **Hierarkiske URL'er og administration af flere sites** — Et globalt multi-URL-panel plus visuel geografisk kortadministration for afdelinger og rum
* **Forbedrede læringsstier og øvelser** — Progressiv adaptiv testning, OnlyOffice-redigering i runtime, adaptiv hotspot-afgrænsning og udvidet SCORM 2004-understøttelse
* **Karakterbog og certifikater** — Udløbsdatoer for certifikater med påmindelser og tilpasselige bedømmelsestilstande
* **Mobilklar REST API** — En moderniseret backend bygget til mobilapps og tredjepartsintegrationer
