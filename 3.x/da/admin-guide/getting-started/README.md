# Kom godt i gang

Dette afsnit introducerer administrationsgrænsefladen i Chamilo 3.0 og hjælper dig med at finde rundt.

## Hvem er en administrator?

Chamilo har flere niveauer af administrative roller:

| Rolle | Adgang |
|------|--------|
| **Administrator** | Fuld adgang til alle administrationsfunktioner for platformen. Også kendt som **portaladministrator** |
| **Global administrator** | Samme som portaladministrator, med adgang på tværs af alle adgangs-URL'er i en opsætning med flere URL'er (multi-tenant) |
| **Sessionsadministrator** | Kan administrere sessioner, tilmelde brugere til sessioner og tilgå sessionsrelaterede indstillinger |
| **HR-ansvarlig** | Kan se kursisters fremgang og sporingsdata for tildelte brugere |
| **Spørgsmålsansvarlig** | Mindre en administrator end en indholdskurator; spørgsmålsansvarlige har adgang til en global spørgsmålsbank for at gennemgå spørgsmålenes kvalitet |

Denne vejledning fokuserer primært på rollen **portaladministrator**, som har den bredeste adgang.

## Log ind

Administratorer logger ind via den samme login-side som alle andre brugere. Efter at have indtastet dine legitimationsoplysninger sendes du (hvis der ikke er anden konfiguration) til siden **Administration**. En bemærkelsesværdig forskel i forhold til andre brugerroller er sektionen **Administration** i sidebjælken (ikke synlig for andre roller).
