# Platform

Blokken **Platformadministration** på administrationsdashboardet samler portalomfattende konfigurations- og kommunikationsværktøjer — alt fra det fulde indstillingspanel til sprog, offentlige meddelelser, den globale kalender og det CMS-lignende Pages-system, der opbygger dele af portalens offentligt synlige indhold.

## Adgang til platformblokken

Fra administrationspanelet vises blokken **Platformadministration** sammen med de øvrige dashboardblokke. Klik på et af dens links for at åbne det tilsvarende værktøj.

## Indholdet af blokken

* **[Platformindstillinger](../platform-settings/README.md)** — Det fulde konfigurationsindstillingspanel (portal, kurser, sessioner, brugere, sikkerhed m.m.). Blokkens link "Konfigurationsindstillinger" er blot indgangen til det separate kapitel.
* **[Sprog](languages.md)** — Vælg, hvilke grænsefladesprog der er tilgængelige for brugerne, og angiv platformens standard
* **[Portalnyheder](portal-news.md)** — Portalomfattende meddelelser (systemmeddelelser), planlagt og målrettet efter rolle
* **[Global agenda](global-agenda.md)** — Portalomfattende kalenderbegivenheder, synlige for alle brugere uanset kursus eller session
* **[Pages](pages.md)** — Det CMS-lignende værktøj bag portalens startside, sidefod og andre offentlige indholdsblokke, herunder introduktionsteksten på registreringssiden
* **[Platformværktøjer](platform-tools.md)** — Ekstra felter, mailskabeloner, kategorier til kontaktformular og nogle få mindre, betinget viste elementer
* **Konfigurer flere adgangs-URL'er** — Behandles i [Adgangs-URL'er](../multi-url/access-urls.md) under Multi-URL
* **Eksterne værktøjer (LTI)** — Behandles i [LTI 1.3](../integrations/lti.md) under Integrationer
