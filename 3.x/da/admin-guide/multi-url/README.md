# Multi-URL

Chamilos multi-URL-funktion (også kaldet multi-tenant) giver dig mulighed for at køre flere virtuelle portaler fra en enkelt Chamilo-installation. Hver portal har sin egen URL, branding, brugere, kurser og indstillinger, men de deler alle den samme database og kodebase.

* **[Adgangs-URL'er](access-urls.md)** — Konfigurer og administrer flere adgangs-URL'er
