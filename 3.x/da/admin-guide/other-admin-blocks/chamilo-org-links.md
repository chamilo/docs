# Chamilo.org-links

Blokken **Chamilo.org** er en statisk liste over udgående links til officielle Chamilo-ressourcer — intet andet. Den sender ingen data nogen steder hen; hvert link åbner enten et eksternt Chamilo-site eller en lokal dokumentationsside, der følger med din installation.

## Hvad indeholder blokken

| Link | Destination |
|------|-------------|
| Chamilo-hjemmeside | `chamilo.org` |
| Brugervejledninger | `docs.chamilo.org` |
| Chamilo-forum | GitHub Discussions for chamilo-lms |
| Installationsvejledning | Lokal, `/documentation/installation_guide.html` |
| Ændringer i seneste version | Lokal, `/documentation/changelog.html` |
| Bidragyderliste | Lokal, `/documentation/credits.html` |
| Sikkerhedsvejledning | Lokal, `/documentation/security.html` |
| Optimeringsvejledning | Lokal, `/documentation/optimization.html` |
| Officielle Chamilo-tjenesteudbydere | `chamilo.org/providers` |

De "lokale" links peger på dokumentationsfiler, der er bundtet med selve din Chamilo-installation, så de indlæses fra din egen server, ikke fra chamilo.org.

## Formål

Denne blok findes udelukkende for bekvemmelighedens skyld — hurtig adgang til projektets officielle dokumentation, fællesskabets diskussionsrum og listen over godkendte tjenesteudbydere, uden at man behøver at søge efter dem.
