# Administrationsvejledning

Velkommen til administrationsvejledningen til Chamilo 3.0. Denne vejledning er beregnet til platformadministratorer, der er ansvarlige for at installere, konfigurere og administrere en Chamilo-instans.

## Hvad du kan gøre som administrator

Som Chamilo-administrator administrerer du:

* **Installation og konfiguration** — Installer Chamilo på din server, og konfigurer lager, e-mail og miljøindstillinger
* **Brugere** — Opret, importer og administrer brugerkonti, roller og tilladelser
* **Kurser og sessioner** — Overvåg oprettelse af kurser, administrer kursuskataloget, og konfigurer uddannelsessessioner
* **Platform** — Sprog, portalnyheder, den globale kalender og værktøjet Pages CMS
* **Platformindstillinger** — Konfigurer portalens adfærd, sikkerhed, ydeevne og tilgængelighed af funktioner
* **Analyse** — Platformstatistik, læringsanalyse og virksomheds-/HR-rapportering
* **Kompetencer** — Definer kompetencebadges, og knyt dem til resultater i karakterbogen
* **System** — Værktøjer til servervedligeholdelse, selvopdatering, inspektion af lager og branding
* **Lokaler** — Administrer fysiske lokaliteter og bookbare undervisningslokaler
* **Sikkerhed** — Overvåg login-forsøg, gennemgå markerede indbrudsforsøg, tjek adgangskodestyrke, og verificer filintegritet
* **Plugins** — Installer, konfigurer og administrer platformudvidelser
* **Autentificering** — Opsæt eksterne loginsystemer (OAuth2, LDAP, CAS, SCIM)
* **Integrationer** — Forbind Chamilo med videokonference, LTI-værktøjer, AI-udbydere og mere
* **Vedligeholdelse** — Udfør sikkerhedskopiering, overvåg systemets tilstand, og administrer lager

## Sådan er denne vejledning opbygget

1. **Kom godt i gang** — Et overblik over administrationsgrænsefladen
2. **Installation** — Serverkrav, installationsguide og indledende konfiguration
3. **Brugere** — Administration af brugerkonti, roller, grupper og profiler
4. **Kurser** — Administration af kurser, kategorier og import/eksport
5. **Sessioner** — Organisering af tidsbegrænsede uddannelseskohorter
6. **Platform** — Sprog, portalnyheder, den globale kalender og værktøjet Pages CMS
7. **Platformindstillinger** — Konfiguration af alle aspekter af platformen
8. **Analyse** — Statistik, læringsanalyse og virksomheds-/HR-rapportering
9. **Kompetencer** — Kompetencebadges og tildelinger baseret på karakterbogen
10. **System** — Serverværktøjer, selvopdatering, inspektion af lager og branding
11. **Lokaler** — Afdelinger og bookbare undervisningslokaler
12. **Sikkerhed** — Værktøjer til sikkerhedsovervågning og revision
13. **Plugins** — Administration af platformudvidelser
14. **Sundhedstjek** — Live konfigurationskontroller
15. **Øvrige administrationsblokke** — Links til Chamilo.org, versionskontrol, support og nyheder
16. **Autentificering** — Opsætning af eksterne autentificeringsudbydere
17. **Integrationer** — Tilslutning af tredjepartstjenester
18. **Multi-URL** — Drift af flere portaler fra én installation
19. **Ydelsesoptimering** — Optimering af platformen med henblik på hastighed og skalering
20. **Vedligeholdelse** — Sikkerhedskopier, systemstatus og oprydning
