# Integrationer

Chamilo integrerer med flere tredjepartstjenester for at udvide funktionaliteten.

De fleste af disse aktiveres via plugins. Se det tilsvarende afsnit lidt længere fremme i denne vejledning.

* **[Videokonference](video-conferencing.md)** — BigBlueButton og Zoom
* **[LTI 1.3](lti.md)** — Tilslut eksterne læringsværktøjer
* **[xAPI](xapi.md)** — Sporing af læringsoplevelser
* **[OnlyOffice](onlyoffice.md)** — Samarbejdende dokumentredigering
* **[AI-konfiguration](ai-configuration.md)** — Opsæt AI-udbydere til AI-drevne funktioner
