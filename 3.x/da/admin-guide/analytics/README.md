# Analyse

Blokken **Analyse** på administrationsdashboardet samler platformdækkende statistikker, læringsanalyse, virksomheds-/HR-rapportering og værktøjer til masseeksport. Afhængigt af din Chamilo-version kan denne blok være mærket **"Tracking"** på selve dashboardet — det er den samme blok uanset. Denne vejledning kalder den Analyse hele vejen igennem for at undgå forveksling med [Tracking-indstillinger](../platform-settings/tracking-settings.md), den separate indstillingskategori, der styrer, hvad der registreres, frem for selve rapporterne.

## Adgang til Analyse

Fra administrationspanelet vises blokken **Analyse** sammen med de øvrige dashboardblokke. Klik på et af dens links for at åbne den tilsvarende rapport.

## Hvad blokken indeholder

* **[Global statistik](global-statistics.md)** — Platformdækkende statistikker: kurser, brugere, logins, sessioner og diskforbrug
* **[Rapportkatalog](reports-catalog.md)** — Gennemse alle registrerede rapporter, hvem der kan tilgå dem, og hvorfor
* **[Læringsanalyse](learning-analytics.md)** — Det klassiske tracking-dashboard: drill-downs for bruger, kursus og session med tidsforbrug og scoregennemsnit
* **[Virksomhedsrapporter](corporate-reports.md)** — Kvartalsvise oversigter, sporing af lærertid og HR-orienteret kursus-/brugerrapportering
* **[Tickets](tickets.md)** — Gå direkte til listen over supporttickets

## Hvem kan tilgå den

De fleste af disse rapporter kræver adgang som **Portal Administrator**. Virksomhedsrapporten er undtagelsen — den er også åben for rollerne **Human Resources Manager** og **Student Boss**, da den er bygget specifikt til den målgruppe.
