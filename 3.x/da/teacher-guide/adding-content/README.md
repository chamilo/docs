# Tilføjelse af indhold

Dette afsnit dækker de værktøjer, du bruger til at tilføje læringsindhold til dit kursus. Chamilo giver flere måder at levere materiale til dine kursister:

* **[Dokumenter](documents.md)** — Upload filer, opret websider, og organiser dit indholdsbibliotek
* **[Links](links.md)** — Del URL'er til eksterne ressourcer, organiseret efter kategori
* **[Læringsstier](learning-paths.md)** — Byg strukturerede indholdssekvenser med forudsætninger og fremdriftssporing
* **[Ordliste](glossary.md)** — Definer nøglebegreber, som kursister kan slå op i hele kurset
* **[Meddelelser](announcements.md)** — Send beskeder og opdateringer til dine tilmeldte kursister
* **[Flersproget indhold](multi-language-content.md)** — Skriv flere sprogversioner af det samme indhold, og lad hver kursist kun se sin egen

Hvert værktøj er tilgængeligt fra værktøjsgitteret på kursets startside. Klik på værktøjets ikon for at åbne det.
