# Yderligere værktøjer

Ud over de centrale værktøjer til indhold, vurdering og samarbejde tilbyder Chamilo flere yderligere værktøjer, der kan styrke dit kursus.

* **[Agenda](agenda.md)** — Planlæg begivenheder, frister og påmindelser for dit kursus
* **[Notesbog](notebook.md)** — Et personligt noteværktøj til kursister
* **[Dropbox](dropbox.md)** — Et enkelt værktøj til filudveksling mellem dig og dine kursister
* **[Portefølje](portfolio.md)** — Lad kursister opbygge og fremvise en portefølje af deres arbejde
* **[Kursusfremgang](course-progress.md)** — Definer tematiske afsnit og følg kursusafviklingen
