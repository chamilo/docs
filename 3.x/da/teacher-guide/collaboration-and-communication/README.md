# Samarbejde og kommunikation

Chamilo stiller flere værktøjer til rådighed, som muliggør interaktion mellem dig og dine kursister samt mellem kursisterne indbyrdes.

* **[Fora](forums.md)** — Trådede diskussioner organiseret efter kategori og emne
* **[Chat](chat.md)** — Tekstbeskeder i realtid inden for et kursus
* **[Grupper](groups.md)** — Opdel kursister i arbejdsgrupper med deres egne delte værktøjer
* **[Wiki](wiki.md)** — Samarbejdende dokumentredigering
* **[Blog](blog.md)** — Delt blogging inden for kurset
* **[Videokonference](video-conferencing.md)** — Live-videosessioner med BigBlueButton eller Zoom

Disse værktøjer er tilgængelige fra kursets startside. Nogle kan være skjult som standard — du kan gøre dem synlige fra værktøjsgitteret (se [Kursets startside](../creating-your-course/course-homepage.md)).
