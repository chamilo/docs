# Sporing og rapportering

Chamilo sporer kursisternes aktivitet på hele platformen og giver dig detaljeret indsigt i, hvordan dine kursister skrider frem.

* **[Kursistsporing](learner-tracking.md)** — Overvåg den enkelte kursists aktivitet: logintidspunkter, tidsforbrug, besøgte sider og brug af værktøjer
* **[Kursusrapporter](course-reports.md)** — Se aggregerede data for alle kursister på et kursus
* **[Certifikater og færdigheder](certificates-and-skills.md)** — Udsted certifikater baseret på karakterbogsresultater og valider erhvervede færdigheder

## Adgang til rapporter

Fra dit kursus klikker du på værktøjet **Tracking** <img src="/.gitbook/assets/icons/mdi-chart-box.svg" alt="Tracking" data-size="line"> på kursets startside. Du kan også få adgang til rapportering via linket **Reporting** i sidepanelet for et overblik på tværs af kurser.

Undervisere ser rapporteringsdata for de kurser, de underviser i. Sessionsvejledere ser data på tværs af alle kurser i deres session.
