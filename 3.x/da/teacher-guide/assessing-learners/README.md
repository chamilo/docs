# Vurdering af kursister

Chamilo tilbyder et omfattende sæt værktøjer til at evaluere dine kursisters viden og følge deres præstationer.

* **[Tilmelding af brugere](subscribing-users.md)** — Få kursister ind på dit kursus i første omgang: administratorindskrivning, selvtilmelding, manuel tilmelding eller e-mailinvitationer
* **[Øvelser](exercises.md)** — Opret quizzer og tests med en række forskellige spørgsmålstyper, automatisk bedømmelse og detaljeret feedback
* **[Opgaver](assignments.md)** — Indsaml hjemmearbejde og projekter fra kursister, med understøttelse af filupload, peer review og manuel eller AI-assisteret bedømmelse
* **[Spørgeskemaer](surveys.md)** — Indhent feedback fra kursister via tilpasselige spørgeskemaer
* **[Fremmøde](attendance.md)** — Registrer kursisters tilstedeværelse i undervisningssessioner
* **[Karakterbog](gradebook.md)** — Kombiner scorer fra øvelser, opgaver og andre aktiviteter til en samlet karakter, og tildel certifikater

Værktøjet **Rapportering** er stadig til stede, men er flyttet til toppen af kursets startside for underviseren som et lille diagramikon. Dette er det centrale sted til at tilgå fremdriftsoplysninger for hele kurset og dets studerende.

Disse værktøjer arbejder sammen: øvelsesscorer og opgavekarakterer kan indgå i Karakterbogen, som kan knyttes til certifikatgenerering og validering af kompetencer.
