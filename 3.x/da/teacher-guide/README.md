# Lærervejledning

Velkommen til lærervejledningen til Chamilo 3.0. Denne vejledning er beregnet til undervisere, trænere og alle, der er ansvarlige for at oprette og formidle læringsindhold via Chamilo-platformen.

Uanset om du opretter dit første onlinekursus eller administrerer et komplekst uddannelsesprogram, vil denne vejledning føre dig gennem alle de funktioner, der er tilgængelige for dig som lærer.

## Hvad du kan gøre med Chamilo

Som lærer i Chamilo kan du:

* **Oprette og organisere kurser** med en fleksibel startside og tilpasselige værktøjer
* **Tilføje indhold** — uploade dokumenter, oprette læringsstier, opbygge glossarer og linke til eksterne ressourcer
* **Vurdere dine kursister** — designe øvelser med flere spørgsmålstyper, indsamle afleveringer, gennemføre spørgeskemaer og administrere karakterer
* **Samarbejde** — oprette fora, gruppearbejde, wikier, blogs og live videosessioner
* **Følge fremgang** — overvåge kursisternes aktivitet, generere rapporter og udstede certifikater
* **Bruge AI-værktøjer** — generere øvelser og læringsstier automatisk og få AI-assisteret bedømmelse

## Hvordan denne vejledning er opbygget

Denne vejledning følger den naturlige arbejdsgang ved at opbygge og gennemføre et kursus:

1. **Kom godt i gang** — Log ind, naviger i grænsefladen, og opsæt din profil
2. **Opret dit kursus** — Opret et nyt kursus, konfigurér indstillingerne, og tilpas startsiden
3. **Tilføj indhold** — Upload dokumenter, organisér læringsstier, og administrer ressourcer
4. **Vurder kursister** — Byg tests, indsaml afleveringer, gennemfør spørgeskemaer, og opsæt karakterbogen
5. **Samarbejde og kommunikation** — Aktivér fora, chat, grupper, wiki og videokonference
6. **Opfølgning og rapportering** — Overvåg kursisternes fremgang, og generer rapporter
7. **AI-værktøjer** — Brug AI-drevne funktioner til at generere indhold og assistere med bedømmelse
8. **Yderligere værktøjer** — Agenda, notesbog, portfolio og mere

Lad os komme i gang.
