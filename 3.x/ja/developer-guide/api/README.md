# API

Chamilo 3.0 は **API Platform 4** 上に構築された REST API を公開しています。この API はプラットフォームのリソースへのプログラム的なアクセスを提供し、Vue フロントエンドが使用する API と同じものです。

* **[認証](authentication.md)** — JWT トークンベースの認証
* **[エンドポイントリファレンス](endpoints-reference.md)** — 利用可能な API リソースの概要
* **[カスタムアクション](custom-actions.md)** — 標準 CRUD を超える専用エンドポイント
* **[Webhook](webhooks.md)** — 外部システムへのイベント駆動型通知
