# ユーザーアカウントの状態

ユーザーの `active` フィールドはアカウントの状態です。管理者は `PATCH /api/users/{id}` でこの値を変更することで、アカウントをブロックまたはブロック解除します。これは 1.11.x の `webservices/api/v2.php` ウェブサービスの `active` フィールドに代わるものです。

## 値

| `active` | 意味 |
|----------|---------|
| `1` | 有効: ユーザーはログインできます |
| `0` | 無効: アカウントはブロックされています |
| `-1` | プラットフォームによって自動的に無効化 |
| `-2` | 削除済み（ゴミ箱内） |

API が設定できるのは `1` または `0` のみです。削除は `DELETE /api/users/{id}` を通じて行い、削除済みアカウントの復元は管理画面のゴミ箱から行います。

## 状態の読み取り

`active` は `GET /api/users/{id}` および `GET /api/users?username=...` によって返されます。

```http
GET /api/users/42
Authorization: Bearer <token>
Accept: application/json
```

```json
{ "id": 42, "username": "jdupont", "active": 1 }
```

## 状態の変更

```http
PATCH /api/users/42
Authorization: Bearer <token>
Content-Type: application/merge-patch+json
Accept: application/json

{ "active": 0 }
```

レスポンスは更新後のユーザーです。アカウントのブロックを解除するには `{ "active": 1 }` を送信します。`active` はユーザーの他のフィールドと一緒に送信できます。

## アクセス

| 呼び出し元 | 許可される操作 |
|--------|---------|
| `ROLE_ADMIN` | 自身のアカウントを除き、編集可能な任意のユーザー |
| その他のユーザー | 自身のアカウントであっても許可されません |

現在の値を送信することは拒否されないため、ユーザー全体を送り返すクライアントがブロックされることはありません。

## エラー

| ステータス | 発生条件 |
|--------|------|
| `400` | `0` または `1` 以外の値 |
| `401` | 認証情報がない、または無効 |
| `403` | 呼び出し元が管理者ではない、または自身の状態を変更する |
| `404` | ユーザーが存在しない |
