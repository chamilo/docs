# クラス所属と登録 API

連携のために、Chamilo は既存の**クラス**に関連付けられたメンバー、セッション、コースを読み取り、同期するためのエンドポイントを提供します。クラスは *通常クラス* タイプの `Usergroup` です。これらのルートはソーシャルグループには**適用されません**。

セッション受講者 API とは異なり、3 つのクラス `PUT` アクションは**指定されたリスト全体を置き換えます**。省略された ID はその関係から削除されます。更新前に既存のリストを読み取り、残すべき全員も送信しない限り、メンバーを 1 人だけ追加するために `PUT` を使用しないでください。

## 認可

以下のすべてのルートには、認証済みプラットフォームの `ROLE_ADMIN` ロールが必要です。対象クラスは現在のアクセス URL で利用可能でなければなりません。存在しない、またはスコープ外のクラスは `404` を返します。通常クラスではないユーザーグループは `409 Conflict` を返します。

コントローラーは、送信されたユーザー、コース、セッションの ID が存在することを確認します。マルチ URL インストールでは、送信された**コースおよびセッション ID** は現在のポータルにフィルタされます。ただし、現在の実装では**ユーザー ID** に同じポータルフィルタを**適用しません**。連携側は、このエンドポイントをユーザーレベルのポータル分離の保証として扱ってはなりません。この未解決のセキュリティ上の考慮事項については、デリバリーレビューノートを参照してください。

## クラス関係の読み取り

```http
GET /api/usergroups/31/subscriptions
Authorization: Bearer <admin-token>
```

応答例:

```json
{
  "userIds": [17, 23],
  "sessionIds": [42],
  "courseIds": [8, 11]
}
```

## 1 つの関係リストの置き換え

| メソッド | エンドポイント | リクエストプロパティ |
|--------|----------|------------------|
| `PUT` | `/api/usergroups/{id}/users` | `userIds` |
| `PUT` | `/api/usergroups/{id}/sessions` | `sessionIds` |
| `PUT` | `/api/usergroups/{id}/courses` | `courseIds` |

たとえば、クラス名簿全体を設定するには次のようにします。

```http
PUT /api/usergroups/31/users
Authorization: Bearer <admin-token>
Content-Type: application/json
```

```json
{ "userIds": [17, 23, 29] }
```

応答例:

```json
{
  "success": true,
  "applied": [17, 23, 29],
  "ignored": []
}
```

`applied` は受理された ID を列挙しますが、必ずしも新たに追加された ID ではありません。`ignored` は適用できなかった要求 ID を示します（たとえば、不明な ID、または現在のポータル外のコース／セッション）。正でない値は省略され、重複は削除されます。不正な JSON、または配列ではないリクエストプロパティは `400` を返します。

代わりにリンクされたセッションを置き換えるには、`{ "sessionIds": [42, 57] }` を指定して `PUT /api/usergroups/31/sessions` を呼び出します。リンクされたコースを置き換えるには、`{ "courseIds": [8, 11] }` を指定して `PUT /api/usergroups/31/courses` を呼び出します。

**重要:** Chamilo は `UsergroupHelper` の同期メソッドを介してこれらの変更を適用します。クラス名簿、またはそのセッション／コースの紐付けを変更すると、関連する登録も変わることがあります。ユーザーグループ関係テーブルを直接操作せず、本番連携を実行する前にリスト置き換えの影響を確認してください。

インターフェースと概念については、[クラス](../../admin-guide/sessions/classes.md) を参照してください。すべてのメンバーを置き換え*ずに*、1 つのセッションから特定の学習者を追加または削除するには、[セッション受講者登録 API](session-students.md) を使用してください。
