# ユーザー接続時間

`GET /api/users/{id}/connection-time` は、ユーザーがプラットフォームに接続していた合計時間を返します。1.11.x の `webservices/api/v2.php` ウェブサービスの `get_user_total_connexion_time` アクションを置き換えるものであり、期間を指定して制限できます。

## アクセス

| 呼び出し元 | 許可される範囲 |
|--------|---------|
| `ROLE_ADMIN` | 現在のアクセス URL に属する任意のユーザー |
| 認証済みの任意のユーザー | 自身の接続時間のみ |
| それ以外 | `403 Forbidden` |

このエンドポイントはユーザーの数値 ID を受け取ります。ユーザー名から始める場合は、まず `GET /api/users?username=...` でユーザーを検索してください。

## リクエスト

```http
GET /api/users/42/connection-time?startDate=2026-10-01T00:00:00%2B02:00&endDate=2026-12-15T23:59:59%2B01:00
Authorization: Bearer <token>
```

| クエリパラメーター | 必須 | 説明 |
|-----------------|----------|-------------|
| `startDate` | いいえ | ISO 8601 の日時。この時点以降に**開始した**接続のみが集計されます。 |
| `endDate` | いいえ | ISO 8601 の日時。`startDate` より前であってはなりません。この時点以前に**終了した**接続のみが集計されます。 |

いずれのパラメーターも指定しない場合、すべての接続が集計されます。`startDate` のみを指定した場合、その日付以降の接続が終了制限なしで集計されます。`endDate` のみを指定した場合、その日付までの接続が開始制限なしで集計されます。

境界と重なる接続（たとえば `startDate` より前に開始したもの）は、まったく集計されません。接続時間は分割されません。これは 1.11.x のレポートにおけるカスタム期間フィルターと同じ規則です。

タイムゾーンのオフセットを含めてください。URL では `+` を `%2B` としてエンコードする必要があります。オフセットのない値は、サーバーのタイムゾーンで解釈されます。

## レスポンス

```json
{
  "id": 42,
  "username": "jdupont",
  "totalConnectionTime": 5025,
  "totalConnectionTimeFormatted": "01:23:45"
}
```

| フィールド | 説明 |
|-------|-------------|
| `totalConnectionTime` | 合計（秒） |
| `totalConnectionTimeFormatted` | 同じ合計を `HH:MM:SS` で表したもの。1.11.x のウェブサービスが返していた形式です。時間は 24 を超えることがあります。 |

## エラー

| ステータス | 発生条件 |
|--------|------|
| `400` | 解析できない日付、または `endDate` が `startDate` より前である場合 |
| `401` | 資格情報が存在しない、または無効である場合 |
| `403` | 呼び出し元が管理者でも対象ユーザーでもない場合 |
| `404` | ユーザーが存在しない、または現在のアクセス URL に属していない場合 |

## 時間の算出方法

合計は、`track_e_login` テーブル内の当該ユーザーの行について、`logout_date − login_date` を合計したものです。

接続はログイン時に開始され、ユーザーがアクティブである間延長されます。ユーザーが開いているページは、タブが表示されている間、1 分ごとにプレゼンス信号を送信します。これは Chamilo 1.11.x ですべてのページ閲覧が行っていた動作と同じです。セッションの有効期間より長い非アクティブ状態の後に次の操作が行われると、新しい接続が開始されるため、アイドル期間は集計されません。ログアウトすると現在の接続は終了します。管理者が **Login as** を使用して費やした時間は、ユーザーには加算されません。

> **注:** この追跡が復元される前に記録された接続には、ログアウト日時がない場合があります。それらはゼロとして集計されるため、アップグレード前の期間の合計は、実際に費やした時間より小さくなることがあります。
