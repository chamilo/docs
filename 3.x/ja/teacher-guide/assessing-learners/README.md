# 学習者の評価

Chamilo は、学習者の知識を評価し、成績を追跡するための包括的なツールセットを提供します。

* **[ユーザーの登録](subscribing-users.md)** — まず学習者をコースに参加させます。管理者による登録、自己登録、手動登録、またはメール招待
* **[演習](exercises.md)** — 多様な問題タイプ、自動採点、詳細なフィードバックを備えたクイズとテストを作成します
* **[課題](assignments.md)** — 学習者から宿題やプロジェクトを収集します。ファイルアップロード、相互評価、手動または AI 支援による採点に対応します
* **[アンケート](surveys.md)** — カスタマイズ可能な質問票で学習者からフィードバックを収集します
* **[出席](attendance.md)** — 授業セッションにおける学習者の出席を記録します
* **[成績表](gradebook.md)** — 演習、課題、その他の活動の得点を統合した成績にまとめ、修了証を発行します

**レポート** ツールは引き続き利用できますが、教師向けにコースホームページの上部へ、小さなチャートアイコンとして移動しています。ここが、コース全体とその学生の進捗情報にアクセスする中心的な場所です。

これらのツールは連携して動作します。演習の得点と課題の成績は成績表に反映でき、成績表は修了証の発行およびスキルの認定に結びつけることができます。
