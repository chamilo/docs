# 演習と学習パスのごみ箱

Chamilo 3.1 では、削除された演習の受験記録と学習パスの追跡データをアーカイブし、権限のある教員が、設定された保持期間とアクセス制御の範囲内で復元できるようにします。ごみ箱は追跡データを保護するものであり、データベースのバックアップの代替にはなりません。

## 演習の受験記録を復元する

1. 対象の演習の **Reporting** ページを、正しいコースまたはセッションを選択した状態で開きます。
2. **Recycle bin** を選択し、アーカイブされた受験記録を表示します。
3. 復元が必要な学習者と受験記録を特定します。
4. **Restore** を選択して確認し、レポートを更新して解答と得点を確認します。

演習結果を管理する権限が必要です。演習が Gradebook によってロックされている場合、またはプラットフォームが教員による結果へのアクセスを制限している場合、復元がブロックされることがあります。

## 学習パスの進捗を復元する

1. 対象のコース／セッションについて、該当する学習パスのレポート画面を開きます。
2. その **Recycle bin** を開きます。
3. 学習者のアーカイブされた進捗を選択し、**Restore** します。
4. 復元されたレッスンの進捗と、関連する演習の受験記録を確認します。

演習の受験記録が保留中の学習パスのアーカイブに含まれている場合は、先に学習パスのアーカイブを復元してください。進捗の不整合を防ぐため、個別の復元は意図的にブロックされます。

## 保持とクリーンアップ（管理者）

設定 `tracking.recycle_bin_retention_hours` は、アーカイブが復元対象として残る期間を制御します。初期の既定値は **30 日**（720 時間）です。既存のインストールでは、管理画面に表示されることを期待する前に、プロジェクトの settings-upsert マイグレーションを通じて新しい設定を同期する必要があります。

何も削除せずにクリーンアップをプレビューします。

```bash
php bin/console chamilo:recycle-bin:purge
```

完全な削除には、明示的なオプションが必要です。

```bash
php bin/console chamilo:recycle-bin:purge --execute
```

このコマンドは、制御された処理のために `--hours`（保持期間の上書き）、`--scan-limit`、`--after-lp-id`、`--after-exercise-id` をサポートします。保持ポリシーとバックアップの手配を確認した後にのみ、スケジュールしてください。この機能が有効になっているという理由だけで、**暗黙の自動パージスケジュールは存在しません**。
