# パーソナリティ質問票

Chamilo 3.1 では、モダンな **アンケート** ツールにパーソナリティ形式の質問票が含まれています。これらの質問票は、採点付きの演習や臨床的な心理評価ではなく、**選好プロファイル**を生成します。

## 質問票を作成する

1. アンケートツールを開き、新しいアンケートを作成します。
2. その設定で、**パーソナリティ**のアンケート種別を選択します。
3. **質問を編集**、またはアンケートの質問エディターを開きます。
4. パーソナリティ質問を追加する前に、**パーソナリティカテゴリー**を定義します。各回答選択肢は、いずれかのカテゴリーに属している必要があります。
5. 質問を追加し、回答とカテゴリーの割り当てを設定して、変更を保存します。
6. アンケートを配布する前に、学習者の体験をプレビューします。

利用できるパーソナリティ質問の種別は4つです。

| 種別 | 学習者の回答方法 |
| --- | --- |
| パーソナリティ選択 | カテゴリーに関連付けられた選択肢から選ぶ |
| パーソナリティ同意 | 提示された項目への同意を示す |
| パーソナリティ尺度 | 5段階尺度で項目を評価する |
| パーソナリティ順序 | 最も好ましいものから最も好ましくないものへ選択肢を順位付けする |

設定には、回答の検証と、カテゴリーに基づく選好スコアリングが含まれます。各質問の選択肢と割り当てを慎重に確認してください。誤ったカテゴリーに関連付けられた選択肢は、結果として得られるプロファイルを変えてしまいます。

## 結果を表示する

質問票の完了後、アンケートがプロファイルデータを返す場合、学習者は **あなたのパーソナリティプロファイル** を確認できます。教員のアンケート報告ページでは、**パーソナリティプロファイル — 全学習者** を表示できます。結果は、棒グラフ／レーダーによる可視化とカテゴリースコアで提示されます。アンケートを複製すると、パーソナリティ質問票の設定は保持されます。

## Gradebook と解釈

パーソナリティ質問票は、通常の評価のように Gradebook を通じて採点することはできません。結果は、設定されたカテゴリーへの回答を反映するものであり、診断、合格／不合格の状態、または妥当性が検証された性格検査ではないことを、学習者に説明してください。個人の回答を収集する前に、プライバシーと報告の表示設定を確認してください。
