# Hot Potatoes アクティビティ

Chamilo 3.1 は、Hot Potatoes の HTML アクティビティを最新の演習ツールへインポートすること、および個々のアクティビティを学習パス内で使用することをサポートしています。

## アクティビティをインポートする

1. コースの **演習** ツールを開き、**Hot Potatoes** に移動します。
2. **Hot Potatoes のインポート** で、Hot Potatoes の **ZIP** パッケージ、または単体の **HTML** エクスポートを選択します。
3. アクティビティがリンクされた画像、メディア、その他のファイルに依存する場合は、それらのアセットを ZIP に含めてください。
4. **インポート** を選択し、インポートしたアクティビティが正しく開き、表示されることを確認します。

## アクティビティの管理と再利用

Hot Potatoes の一覧から、**開く** でアクティビティをプレビューし、**編集** でタイトルを変更し、**公開** または **非表示** で表示を制御し、許可されている場合は **削除** で削除します。学習パスビルダーでは、リソースの中に個々の Hot Potatoes アクティビティを含めることができます。

## 学習者の試行を確認する

**試行** アクションは、教員が確認するための追跡された試行を表示します。教員は、確認済みの百分率スコアを 0 から 100 の範囲で割り当てることができます。画面には現在、最新の 100 件までの試行が表示されます。学習者を評価する際は、アクティビティの実際の表示結果を裏付けとなる証拠として使用してください。

**自動採点および成績表との同期は実装されていません。** Hot Potatoes パッケージ自体が表示するスコアを、サーバー側で検証済みの成績として扱ってはなりません。教員が確認した結果は、別に保存されます。

## トラブルシューティング

メディアが見つからない場合は、リンクされたすべてのアセットを ZIP に含めてアクティビティを再エクスポートしてください。HTML エクスポートがローカルコンピューターでは動作するが Chamilo では動作しない場合は、外部ファイル参照または互換性のない埋め込みコンテンツがないか確認してください。アクティビティの表示は、教員アカウントだけでなく学生アカウントでもテストしてください。
