# 課題

課題ツール（「学生の提出物」とも呼ばれます）では、学習者から課題（エッセイ、プロジェクト、レポート、またはファイルによる提出物）を収集し、採点できます。

## 課題の作成

1. コースホームページから **課題** <img src="/.gitbook/assets/icons/mdi-inbox-full.svg" alt="課題" data-size="line"> ツールを開く
2. **課題を作成** をクリックする
3. 詳細を入力する:
   * **課題名** — 課題の名前（例: 「最終プロジェクトレポート」）
   * **説明** — 学習者向けの指示。提出内容と評価方法を含めます（リッチテキスト対応）
   * **最高得点** — 課題を何点満点で採点するか
   * **成績表に追加** — 評価（成績表）ツールの評価項目として追加し、コース目標の達成に含められるようにします
   * **締切** — 提出が遅延としてフラグされる公式（公開）の日時（アップロード自体は引き続き受け付けられます）
   * **終了日時（完全に閉鎖）** — これ以降アップロードができなくなる最終締切の日時
   * **カレンダーに追加** — この課題の提出日を参照するイベントを作成します
   * **提出タイプ** — **テキストのみ許可**、**ファイルのみ許可**、または **ファイルまたはオンラインテキストを許可** から選択します
4. 保存する

課題を作成したあと、次のこともできます:
* 課題の詳細ページからテンプレート文書をアップロードする
* 課題を特定のユーザーに割り当てる（コースの全ユーザーではなく）

学習者が課題を提出したあと、次のことができます:
* 提出物のPDF一覧をエクスポートする
* 未提出の学習者のみの一覧を表示する
* すべての課題を大きなZIPでダウンロードする
* すべての添削を大きなZIPでアップロードする
* 提出したすべての添削を削除する（学習者の提出物は削除されません）

## 学習者の提出方法

学習者は課題を開き、次の手順で提出します:

1. **ファイルをアップロード** または提出ボタンをクリックする
2. コンピューターからファイルを選択する（または設定に応じてテキストを直接入力する）
3. 任意のコメントを追加する
4. 提出する

学習者は、すでに提出済みかどうかを確認でき、許可されている場合は提出物を更新できます。

## 提出物の確認

![学生名、日付、ファイル、採点状況を示す課題提出一覧](/.gitbook/assets/assignments-submissions-list.png)

教師として課題を開くと、すべての提出物の一覧が表示されます:

* **学生名** — 提出者
* **提出日** — 提出された日時
* **ファイル** — 提出されたファイルをダウンロード
* **ステータス** — 提出物が採点済みかどうか
* **コメント** — 学習者またはあなたが残したコメント

### 提出物の採点

![得点入力、フィードバック欄、添削ファイルのアップロードがある課題採点画面](/.gitbook/assets/assignment-grading-view.png)

1. 提出物をクリックして開く
2. 提出されたファイルを確認する
3. **得点** を入力する
4. 学習者向けの **フィードバックコメント** を書く
5. 任意で **添削ファイル** を添付としてアップロードする
6. 保存する

### AI支援による採点

プラットフォームでAIツールが設定されている場合、提出物の確認時に **AI採点** オプションが表示されることがあります。これはAIモデルを使い、記述式の課題に対して得点とフィードバックを提案します。詳細は [AI採点](../ai-tools/ai-grading.md) を参照してください。

## 提出物の管理

グループ操作:
* **課題パッケージをダウンロード** — すべての提出物を1つのZIPファイルとしてダウンロードし、オフラインで確認します
* **添削パッケージをアップロード** — すべての提出物を1つのZIPファイルでダウンロードし、コンピューター上でファイルをその場で編集して再度ZIPにした場合、そのZIPを添削パッケージとして送信できます。ファイル名を変更すると動作しません。
* **遅延提出** — 締切後の提出はフラグされますが、設定によっては引き続き受け付けられる場合があります

個別の提出物に対する操作:
* **添削をアップロード** — 1人の学習者向けの添削をアップロードする
* **ダウンロード** — 1人の学習者の提出物をダウンロードする
* **添削と採点** — 学習者の提出物に添削と成績を追加する
* **編集** — 文書タイトルまたは提出物に対する以前のフィードバックを編集する
* **移動** — 提出物を課題フォルダー間で移す（例: 学生が誤った課題に提出した場合）
* **公開設定** — 学習者が互いの提出物を見られるかどうかを制御する

## 成績表との連携

課題の得点は、コースの成績表（「評価」ツール）に含めることができます。これにより、課題の成績が学習者の総合的なコース成績および修了証の対象に反映されます。詳細は [成績表](gradebook.md) を参照してください。

## ヒント

* **指示は具体的に書く** — 学習者が提出すべき内容、期待される形式、評価基準を明確に説明する
* **現実的な締切を設定する** — アジェンダツールを使い、コースカレンダー上で締切を見えるようにする
* **添削済みファイル機能を使う** — 学生の提出物に注釈を付けた版をアップロードし、具体的な修正点を確認できるようにする
* **相互閲覧は慎重に有効化する** — 学習者同士が互いの提出物を見られるようにすると学びを促す一方、すべての課題に適しているとは限らない
