# 用語集

本ガイド全体で使用される主な用語です。

| 用語 | 定義 |
|------|-----------|
| **Assessment** | 下記の **Gradebook** を参照 |
| **Assignment** | 学習者がファイルまたはテキストを提出し、教師が確認・採点する課題。「student publication」または「work」とも呼ばれます。 |
| **Auto-launch** | 学習者がコースに入ったときに、特定のツールを自動的に開く機能です。 |
| **Certificate** | 学習者がグレードブックで定義された最低得点を満たしたときに自動生成される文書です。 |
| **Course** | 学習コンテンツとツールを格納する入れ物です。コースにはドキュメント、演習、フォーラム、ラーニングパスなどを含めることができます。 |
| **Course tutor** | セッションに固有の教師ロールです。コースチューターは、セッション内の1つのコースを管理します。Chamilo 3.0より前のバージョンでは「course coach」と呼ばれていました。 |
| **Disk quota** | アップロードされたファイルに対してコースに割り当てられる最大ストレージ容量です。 |
| **Enrollment** | ユーザーをコースまたはセッションに登録し、そのコンテンツへのアクセスを付与するプロセスです。「subscription」とも呼ばれます。 |
| **Exercise** | 1問以上の設問を含むクイズまたはテストです。文脈によっては「test」とも呼ばれます。 |
| **Forum** | カテゴリとトピックに整理されたスレッド形式の会話を行うディスカッションツールです。 |
| **Gradebook** | 演習、課題、その他の活動の得点を集約し、各学習者の統一された成績にするツールです。 |
| **Learning path** | 学習活動（ドキュメント、演習、リンク）を定義された順序で学習者がたどる構造化された一連の流れで、必要に応じて前提条件を設定できます。 |
| **LTI** | Learning Tools Interoperability — 外部の学習ツールを Chamilo 内に埋め込むことを可能にする標準です。 |
| **SCORM** | Sharable Content Object Reference Model — eラーニングコンテンツパッケージの標準です。Chamilo は SCORM パッケージをインポートし、ラーニングパス内で再生できます。 |
| **Session** | 特定の学習者グループに割り当てられた、1つ以上のコースの期間限定の実施単位です。セッションにより、同じコースコンテンツを異なるコホートで再利用できます。 |
| **Session tutor** | セッション内のすべてのコースを監督する役割です。Chamilo 3.0より前のバージョンでは「session coach」と呼ばれていました。 |
| **Skill** | グレードブックの達成と関連付けられるコンピテンシーです。学習者が証明書を取得すると、関連するスキルが認定されます。 |
| **Survey** | フィードバックを収集するためのアンケートツールで、さまざまな設問タイプと匿名回答オプションがあります。 |
| **Visibility** | ツール、ドキュメント、または活動が学習者に表示されるかどうかを制御する設定です。教師は非表示の項目も常に見ることができます。 |
