# コース自動化（手動トリガー）

コースレポートの **自動化** セクションでは、権限のある教師がコースの開始時と終了時のアクションを設定できます。現在の Chamilo 3.1 の実装では、アクションは **手動でトリガー** されます。カレンダー上の日付や cron によって自動実行されるとは考えないでください。

## アクションの設定

1. 教師、またはコースレポートの管理が許可された別のユーザーとしてコースを開きます。
2. **レポート** を開き、**自動化** セクションを見つけます。
3. イベント（**コースが今開始する** または **コースが今終了する**）とアクションの種類を選択します。
4. そのアクションに必要な対象を指定し、**アクションを追加** を選択します。
5. **設定済みアクション** の一覧を確認し、不要な項目はその **削除** アクションで削除します。

サポートされるアクションには、コースリソースの公開または非表示、アンケート招待の送信、既存の修了証の交付、コースの公開設定の変更が含まれます。利用可能なリソース、アンケート、Gradebook のオプション、公開設定の値は、コースと現在のユーザーの権限によって異なります。

## 設定したイベントの実行

**コースが今開始する** または **コースが今終了する** を選択し、操作を確定します。報告された結果を確認してください。Chamilo は完了した実行を追跡し、重複した設定を防ぎ、後続の実行ではすでに正常に完了したアクションをスキップします。2回目のクリックを、完了済みのアクションを再送する手段として扱わないでください。

修了証を交付する場合は、まず該当する修了証を準備してテストしてください。アンケート招待の場合は、アンケートが設定されていること、および対象の学習者が現在のコースまたはセッションのコンテキストに属していることを確認してください。

## 重要な制限事項

- このインターフェースが提供するのは **手動実行** であり、スケジュールされた自動化ではありません。
- アクションは現在のコース／セッションのコンテキスト内で動作します。該当する場合は、両方のコンテキストについてアクセスと対象をテストしてください。
- 正常に完了したアクションは、後の実行で自動的に繰り返されません。
- この機能の PR の時点では、修了証の交付、コースの公開設定の変更、セッション固有の実行はコードレビュー済みでしたが、その PR では機能検証されていませんでした。運用で依存する前に、ご利用の環境でテストしてください。
