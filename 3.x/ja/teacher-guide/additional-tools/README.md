# 追加ツール

コアとなるコンテンツ、評価、コラボレーションの各ツールに加え、Chamilo にはコースをさらに充実させるための追加ツールがいくつか用意されています。

* **[アジェンダ](agenda.md)** — コースのイベント、締切、リマインダーをスケジュールする
* **[ノートブック](notebook.md)** — 学習者向けの個人用メモツール
* **[ドロップボックス](dropbox.md)** — あなたと学習者の間でファイルをやり取りするシンプルなツール
* **[ポートフォリオ](portfolio.md)** — 学習者が自身の成果物のポートフォリオを作成し、公開できるようにする
* **[コース進捗](course-progress.md)** — テーマ別セクションを定義し、コースの実施状況を追跡する
