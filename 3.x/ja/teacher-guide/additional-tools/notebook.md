# ノートブック

ノートブックは、学習者向けの個人用メモツールです。各学習者は、コース内に自分専用の非公開ノートブックを持ちます。

## 仕組み

ノートブックは、学習者が次のことができるシンプルなツールです。

* **ノートの作成** — コース内容に関連する個人的なメモを書いて保存する
* **ノートの整理** — メモを確認、編集、削除する
* **非公開の維持** — メモは作成した学習者本人にのみ表示される

## 教師として

教師として、次の点を把握しておく必要があります。

* ノートブックは**個人用ツール**です — 学習者のメモを見ることはできません
* **振り返りのツール**として有用です — 学習中にメモを取るよう学習者に促してください
* メモはコース内に保存されます — コース間では共有されません

## ノートブックの有効化

ノートブックツールは有効になっている場合、コースホームページに表示されます。表示されない場合は、非表示になっていないか確認してください（コースホームページの非表示ツールを確認します）。
