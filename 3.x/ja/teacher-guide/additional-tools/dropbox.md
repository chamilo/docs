# ドロップボックス

ドロップボックスは、コース内であなたと学習者が互いにファイルを共有できるファイル交換ツールです。

> 採点対象の学習者の提出物を集める場合は、採点とフィードバックの機能が含まれる [課題](../assessing-learners/assignments.md) ツールの方が通常は適しています。ドロップボックスは、非公式なファイル共有に向いています。

## ファイルの送信

1. コースホームページから **ドロップボックス** ツールを開く
2. **新しいファイルを共有** をクリックする
3. アップロードするファイルを選択する
4. **受信者** を選ぶ — 登録済みユーザーまたはコースグループを1人（1つ）以上
5. 送信する

## ファイルの受信

誰かがファイルを送信すると、ドロップボックスの受信トレイに表示されます。次の操作ができます。

* ファイルを **ダウンロード** する
* ファイルに **コメントを追加** する（受信後）
* ファイルをいずれかのカテゴリへ **移動** する
* 受信トレイからファイルを **削除** する

## ファイルの整理

送信済み・受信済みのファイルは、いずれもカスタム **カテゴリ**（フォルダ）に整理できます。ドロップボックスのツールバーにあるカテゴリ操作を使ってカテゴリを作成し、ファイルをその中へ移動します。プラットフォーム設定の「上書きを許可」が有効な場合、同じ名前のファイルを再送信すると、以前のバージョンを上書きできます。

選択したファイルを ZIP として一括ダウンロードすることもできます。

## 教師として

* 個々の学習者、学習者グループ、または登録済みの全ユーザーにファイルを送信できます
* 学習者から自分宛てに送信されたファイルを確認できます
* このツールは、補足資料の共有、個別のフィードバック文書の提供、非公式な提出物の受け取りに役立ちます
