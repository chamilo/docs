# ポートフォリオ

ポートフォリオツールは、学習者がコース全体を通じて成果物を収集し、提示できるようにします。学習者が優れた成果、振り返り、達成内容をまとめるデジタルポートフォリオとして機能します。

## ポートフォリオの仕組み

各学習者はコース内に個人用ポートフォリオを持ち、次のことができます。

* **項目の追加** — リッチテキストエディタでテキストエントリを作成し、各項目に1つ以上のファイルを添付する
* **コンテンツの整理** — 項目にタグを付け、トピックで絞り込めるようにする
* **選択的な共有** — 各項目の公開範囲を設定する：非表示、コースに公開、教師以外には非表示、または高度な共有が有効な場合は選択したユーザーと共有

## 教師として

ポートフォリオは次の用途に使えます。

* **振り返り学習** — 学習の過程についての振り返りをポートフォリオに蓄積するよう学習者に求める
* **コンピテンシーの実証** — スキルと知識の証拠を学習者に収集させる
* **評価** — 評価の一環としてポートフォリオの内容を確認する

学習者のポートフォリオを見るには、ポートフォリオツールを開き、項目一覧をユーザーで絞り込みます。

コースの設定で許可されている場合、ポートフォリオの項目と個別のコメントに点数を付けられます。これらの点数は成績表に反映できます。注目させたい項目を**ハイライト**したり、項目やコメントを**テンプレート**としてマークし、自分（または学習者）が新しいエントリの出発点として再利用したりすることもできます。ポートフォリオは **PDF** または **ZIP** としてエクスポートできます。

## ヒント

* **期待を明確にする** — どのような項目を含め、ポートフォリオをどのように整理するかを学習者に伝える
* **定期的に確認する** — コース終了時だけでなく、定期的にポートフォリオを確認する
* **スキルと組み合わせる** — スキル／証明書システムとポートフォリオを併用し、包括的なコンピテンシー記録を作成する
