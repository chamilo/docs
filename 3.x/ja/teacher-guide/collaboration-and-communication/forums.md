# フォーラム

フォーラムツールを使うと、コース内で構造化された議論を開催できます。学習者はメッセージを投稿し、互いに返信し、スレッド形式の会話に参加できます。

## フォーラムの構造

![カテゴリ、フォーラム、トピック数を示すフォーラムカテゴリ一覧](/.gitbook/assets/forum-category-list.png)

Chamilo のフォーラムは次の3つのレベルで構成されます。

1. **フォーラムカテゴリ** — 最上位のグループ（例：「一般的な議論」「モジュール1の質問」）
2. **フォーラム** — カテゴリ内の個々の議論ボード
3. **トピック（スレッド）** — フォーラム内の個々の議論トピック。それぞれに返信の連鎖があります

## フォーラムカテゴリの作成

1. コースホームページから **フォーラム** <img src="/.gitbook/assets/icons/mdi-comment-quote.svg" alt="フォーラム" data-size="line"> ツールを開きます
2. **フォーラムカテゴリを追加** をクリックします
3. **カテゴリ名** と任意の説明を入力します
4. 保存します

## フォーラムの作成

フォーラムを追加できるのは、少なくとも1つのカテゴリが存在する場合のみです。

1. カテゴリ内で **フォーラムを追加** をクリックします
2. 基本情報を入力します:
   * **タイトル** — この議論ボードの名前
   * **説明** — フォーラムの目的の任意の説明
   * **作成先カテゴリ** — このフォーラムが属するカテゴリ
3. **詳細設定** を開いて次を設定します:
   * **公開日** / **終了日** — フォーラムが開いている任意の期間
   * **モデレート付きフォーラム** — 新しい投稿が教師の承認後に表示されるようにする
   * **学習者は自分の投稿を編集できますか？** — 送信後の投稿編集を許可または禁止する
   * **ユーザーに新しいスレッドの開始を許可する** — 「いいえ」にすると、学習者は既存スレッドへの返信のみ可能です
   * **デフォルトの表示形式** — 投稿の表示方法を選択します: **フラット**、**スレッド**、または **入れ子**
   * **グループ用** — このフォーラムをコースグループに関連付ける
   * **公開アクセス / 非公開アクセス** — グループフォーラムの場合、コースの任意のメンバーが読めるか、グループメンバーのみかを決めます
4. 保存します

コースの公開設定が「世界に公開」の場合、フォームに **匿名投稿を許可しますか？** オプションも表示されます。このオプションは、公開が制限されたコースでは非表示です。

## トピックの管理

学習者（および教師）は、フォーラム内で新しいトピックを作成できます。教師としてできることは次のとおりです。

* **トピックをピン留めする（固定メッセージ）** — 作成時または編集時にスレッドを固定としてマークし、常に先頭に表示する
* **トピックをロックする** — これ以上の返信を防ぐ
* **投稿の編集または削除** — 議論をモデレートする
* **トピックを移動する** — トピックを別のフォーラムへ移す

## フォーラムの採点

教師として新しいスレッドを作成するとき、詳細設定で **このスレッドを採点する** を有効にできます。その後、最高点、成績表の列見出し、レポート内の重みを設定します。**スレッドをピア評価する** を有効にすることもでき、その場合、各学習者は自分の得点が計上される前に、少なくとも他の2人の学習者を評価する必要があります。

## 通知

各フォーラムおよびスレッドには **通知する** トグルがあり、教師と学習者が新しい投稿のメール通知を購読できます。通知はユーザーごとの購読であり、フォーラム作成時には設定しません。
