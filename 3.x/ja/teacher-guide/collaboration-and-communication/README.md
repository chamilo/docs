# コラボレーションとコミュニケーション

Chamilo には、あなたと学習者の間、および学習者同士のやり取りを可能にするツールがいくつか用意されています。

* **[フォーラム](forums.md)** — カテゴリとトピックで整理されたスレッド型の議論
* **[チャット](chat.md)** — コース内でのリアルタイムテキストメッセージング
* **[グループ](groups.md)** — 学習者を作業グループに分け、それぞれに共有ツールを持たせる
* **[Wiki](wiki.md)** — 共同での文書編集
* **[ブログ](blog.md)** — コース内での共有ブログ
* **[ビデオ会議](video-conferencing.md)** — BigBlueButton または Zoom を使ったライブビデオセッション

これらのツールはコースホームページから利用できます。一部は既定で非表示になっている場合があります。ツールグリッドから表示できます（[コースホームページ](../creating-your-course/course-homepage.md) を参照）。
