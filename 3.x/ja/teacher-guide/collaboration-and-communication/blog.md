# ブログ

ブログツールを使うと、コース内に共有ブログを作成できます。学習者は投稿を書き、コメントを残し、構造化されたライティング活動に取り組むことができます。

## ブログの作成

1. コースホームページから（上部の歯車アイコンの下）**ブログ**ツールを開きます
2. **新しいプロジェクト**をクリックします
3. **タイトル**と任意のサブタイトルを入力します
4. 保存します
5. **表示**（目）アイコンをクリックして、学習者に公開するタイミングを決めます

1つのコース内に複数のブログを作成できます（例：トピックごと、またはグループごと）。

## ブログ投稿の作成

1. ブログを開きます
2. **新しい投稿**をクリックします
3. **タイトル**を入力し、リッチテキストエディターで投稿本文を書きます
4. 保存します

教師と学習者の両方（権限による）が投稿を作成できます。

## コメントと評価

読者は次の方法でブログ投稿に関与できます。

* **コメント** — 投稿の下にフィードバックを残したり、議論を始めたりします（コメントは他のコメントへの返信としてスレッド化することもできます）
* **評価** — 投稿を評価し、最も価値のある貢献を際立たせます
* **添付ファイル** — 投稿とコメントの両方にファイルを添付できます

## ブログのタスク

ブログ内に**タスク**を作成できます。学習者がブログ投稿として完了すべき具体的なライティング課題です。次のような用途に適しています。

* 振り返りジャーナル
* 週次のライティング課題
* プロジェクトの進捗報告

## ブログの管理

教師として、次のことができます。

* 投稿とコメントの**編集または削除**（投稿の削除は投稿者本人または教師に制限されます）
* **ブログの表示／非表示の切り替え**により、学習者からブログを表示または非表示にします
* **タスクの定義** — 学習者が投稿として完了することが期待される具体的なライティング課題を追加します。タスクは視覚的なグループ化を容易にするため色分けできます。
