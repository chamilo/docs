# サポートチケット

**チケット**ツールは、ユーザーがサポート依頼を送信し、その解決状況を追跡できる組み込みのヘルプデスクシステムです。プラットフォームの設定に応じて、**依頼者**（自身または学習者に代わってチケットを送信する）として使う場合と、**サポート担当者**（自分のカテゴリに割り当てられたチケットに対応する）として使う場合があります。

## システムの構成

チケットは**プロジェクト**に属し、さらに**カテゴリ**に分かれます。各カテゴリには、1人以上のサポート担当者を割り当てることができます。チケットが送信されると、選択したカテゴリの対応可能な担当者に自動的に振り分けられます。

既定のカテゴリは次のとおりです。

| カテゴリ | 説明 |
|----------|-------------|
| Enrollment | コースまたはセッションの登録に関する質問と問題 |
| General information | プラットフォーム全般に関する質問 |
| Requests and paperwork | 事務的な依頼と書類 |
| Academic Incidents | 試験、課題、またはタスクに関する問題 |
| Virtual campus | プラットフォームの技術的な問題 |
| Online evaluation | 特定のコース評価に関する問題（コースの選択が必要） |

## チケットツールへのアクセス

管理者がチケットリンクを有効にしている場合、上部ナビゲーションバーにチケットアイコン <img src="/.gitbook/assets/icons/mdi-ticket-account.svg" alt="チケット" data-size="line"> が表示されます。クリックすると、チケット送信フォームに直接移動します。

プラットフォームの設定によっては、メインメニューの **サポート** または **チケット** からも自分のチケットにアクセスできます。

## チケットの送信

新しいサポート依頼を開く手順は次のとおりです。

1. **新規チケット**（または上部バーのチケットアイコン）をクリックします。
2. 問題に最も近い**カテゴリ**を選択します。
3. カテゴリで必要な場合（例: Online evaluation）、該当する**コース**を選択します。
4. **件名**を入力します。問題の短い要約です。
5. 問題を詳しく説明する**メッセージ**を記入します。
6. 必要に応じて、サポート担当者が問題を把握しやすいようファイル（スクリーンショット、文書）を添付します。
7. **送信**をクリックします。

チケットに ID が割り当てられ、サポート担当者に振り分けられます。担当者が返信すると通知を受け取ります。

## チケットの追跡

チケット一覧から、自分が送信したすべてのチケットと現在のステータスを確認できます。

| ステータス | 意味 |
|--------|---------|
| New | 送信直後で、まだ確認されていない |
| Pending | サポート担当者が確認中 |
| Unconfirmed | 確認または追加情報を待っている |
| Forwarded | 別のチームまたは担当者に転送された |
| Closed | 解決済み |

任意のチケットをクリックすると、会話スレッド全体を読み、返信を追加できます。

## チケットへの返信

チケットが開いている間、依頼者とサポート担当者は同じスレッド内でメッセージをやり取りします。返信を追加する手順は次のとおりです。

1. 一覧からチケットを開きます。
2. 下部の返信欄までスクロールします。
3. 返信を記入し、必要に応じてファイルを添付します。
4. **送信**をクリックします。

スレッドに新しいメッセージが追加されると、双方に通知が届きます。

## サポート担当者としてのチケット対応

管理者が1つ以上のチケットカテゴリにあなたを割り当てている場合、学習者または同僚からの着信チケットがキューに表示されます。

割り当てられたチケットに対応する手順は次のとおりです。

1. チケット一覧を開きます。割り当てられたチケットは、自分が送信したチケットと並んで表示されます。
2. チケットをクリックし、依頼者のメッセージを読みます。
3. 返信を記入して **送信** をクリックします。チケットのステータスは自動的に更新されます。
4. 問題が解決したら、ステータスを **Closed** に変更します。

キューの優先順位付けのため、チケットの**優先度**（Low、Normal、High）を変更することもできます。

> チケットカテゴリへのアクセスは、プラットフォーム管理者が制御します。あるカテゴリのサポート担当者として追加する必要がある場合は、管理者に連絡してください。設定オプションについては、管理者ガイドの [チケット設定](../admin-guide/platform-settings/ticket-settings.md) を参照してください。
