# コースツールの名前とアイコンをカスタマイズする

Chamilo 3.1 では、権限を持つコース編集者が、コースホームページに表示されるツールの**名前**と**SVG アイコン**をカスタマイズできます。これらの変更は当該コースに限定され、既存のツールの遷移先は維持されます。

## ツールをカスタマイズする

1. コースを編集できるユーザーとして、コースホームページを開きます。
2. ツールグリッドで**カスタマイズ**モードを有効にします。
3. 変更するツールのカスタマイズフォームを開きます。
4. 希望する**名前**を入力し、必要に応じて**アイコン**の SVG ファイルを選択します。
5. **保存**を選択し、ホームページのグリッドで更新されたツールを確認します。

ツールのカスタマイズは、グリッドの**並べ替え**、**すべて表示**、**すべて非表示**の各モードとは異なります。ツールのラベルやアイコンを変更しても、新しいツールは作成されず、基になる URL は変わらず、学習者に追加のアクセス権が付与されることもありません。

## SVG の要件とセキュリティ

信頼できる提供元の SVG ファイルを使用してください。Chamilo はアップロードされた SVG の内容を検証し、安全でないファイルを拒否します。ファイルが拒否された場合は、検証を回避しようとせず、簡素化するか、クリーンな SVG として再エクスポートしてください。

結果として表示されるアイコンと名前を、教員と学習者の両方の立場で確認し、別のコースが変更されていないことも確認してください。学習者は、必要なコース編集権限を持たない限り、ツールをカスタマイズできません。

[コースホームページ](course-homepage.md)を参照してください。実装: [PR #9374](https://github.com/chamilo/chamilo-lms/pull/9374)。
