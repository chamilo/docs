# コース説明

**コース説明** <img src="../../.gitbook/assets/icons/mdi-apple-safari.svg" alt="コース説明" data-size="line"> ツールでは、コースの目標、方法論、教材などについて、複数セクションからなる構造化された説明を作成できます。[コースホームページ](README.md#the-course-homepage) 上の自由記述の **コース紹介** バナーは登録済み学習者にしか表示されませんが、コース説明は、コースカタログから、登録前の見込み学習者に表示される内容です。

登録後も、学習者はコース内からこの説明を参照できます。ツールを学習者に表示したままにしておけば、コースの全体構成や担当教員など実務的な情報を、直接尋ねることなく確認できる便利な場所になります。登録済み学習者は作成したセクションを閲覧できますが、追加・編集・削除はできません。

## ツールへのアクセス

コースホームページのツールグリッドから **コース説明** <img src="../../.gitbook/assets/icons/mdi-apple-safari.svg" alt="コース説明" data-size="line"> ツールを開きます。

## 8つのセクション

コース説明は最大8つの独立したセクションで構成されます。いずれも任意です。コースに関連するものだけ記入してください。

| セクション | 指針となる問い |
|---------|-------------------|
| **説明** | コースの目標は何か。前提条件はあるか。この研修は他のコースとどのように結びついているか。 |
| **目標** | 学習者がコースを修了したときの成果は何か。コース中に行う活動は何か。 |
| **トピック** | コースはどのように進むか。学習者が特に注意すべき箇所はどこか。理解しにくい領域として特定できる問題はあるか。コースの各領域にどの程度の時間を割くべきか。 |
| **方法論** | コースの目標達成を助ける方法と活動は何か。スケジュールはどうなるか。 |
| **コース教材** | 教科書、論文集、参考文献、インターネット上のリンク一覧はあるか。 |
| **リソース** | コース、チューター、技術ヘルプデスク、教員、利用可能な教材などを検討する。 |
| **評価** | 学習者はどのように評価されるか。トピックを習得するために開発すべき戦略はあるか。 |
| **その他** | 上記のカテゴリに当てはまらないもの。独自のタイトルを付けた **その他** セクションを必要な数だけ追加できます。 |

## セクションの追加

1. ツールのツールバーで、作成したいセクション種別のアイコンをクリックします
2. Chamilo がそのセクションの指針となる問いを含む **ヘルプ** ボックスを表示します。何を書くかの判断に使ってください
3. リッチテキストエディタで内容を作成します（書式、画像、リンク、埋め込み動画などのリッチコンテンツに対応）。プラットフォームで有効な場合、同じセクションを複数言語で作成し、各学習者には自分の言語だけが自動表示されるようにできます。[多言語コンテンツ](../adding-content/multi-language-content.md) を参照してください。
4. 保存します

追加した各セクションは、ツール内でそれぞれ独立したカードとして表示されます。後から更新または削除するには、カード上の **編集** <img src="../../.gitbook/assets/icons/mdi-pencil.svg" alt="編集" data-size="line"> および **削除** <img src="../../.gitbook/assets/icons/mdi-delete.svg" alt="削除" data-size="line"> アイコンを使用します。

## コースカタログへの連携

コース説明を記入する主な理由はこれです。訪問者や見込み学習者が閲覧する **さらにコースを探す** カタログに直接反映されます。

* 説明セクションが **1つも** 記入されていないコースは、カタログ上で普通のカードとして表示されます。
* 説明セクションが **少なくとも1つ** あるコースはクリック可能になります。画像、タイトル、または情報ボタンをクリックすると、上記と同じ順序ですべてのセクションを列挙した詳細ポップアップが開きます。

これにより、見込み学習者はタイトルとサムネイルだけでなく、登録するかどうかを判断する実質的な根拠を得られます。

> このポップアップが利用できるかどうかは、プラットフォーム全体の設定に依存します。カタログで見込み学習者に説明が表示されない場合は、管理者に **管理 > 設定 > コースカタログ** の **コース説明を表示** 設定（`show_courses_descriptions_in_catalog`）を確認するよう依頼してください。

## ヒント

* **説明と目標のセクションを優先する** — 登録を決める際、見込み学習者の多くが最初に読む内容です。
* **最新の状態を保つ** — コース内容が大きく変わったらコース説明を更新し、カタログが学習者が実際に得る内容を常に反映するようにします。
* **リッチコンテンツは控えめに** — 画像や書式は読みやすさに役立ちますが、長く雑然としたポップアップは、明確な数段落よりもスキャンしにくくなります。
