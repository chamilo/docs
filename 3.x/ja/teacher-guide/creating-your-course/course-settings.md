# コース設定

コース設定では、コースの動作（誰がアクセスできるか、どのように表示されるか、どの機能を有効にするか）を制御できます。

コース設定にアクセスするには、コースに入り、**学生ビューに切り替え**ボタンの横にある**設定** <img src="../../.gitbook/assets/icons/mdi-cog.svg" alt="設定" data-size="line"> アイコンをクリックします。

## 一般設定

### コース情報

* **コースタイトル** — コースの表示名
* **コース言語** — コースインターフェースの主言語
* **コースカテゴリ** — カタログ上でコースが表示されるカテゴリ
* **コース画像** — コース一覧でコースを表すサムネイルをアップロードします（コンテキストに応じてリサイズされます）

コースコード（短い一意の識別子）はコース作成時に設定され、このページからは編集できません。

既定では、コースに入ったすべてのユーザーは、Chamilo のインターフェース全体をコースの言語で表示します。これは没入型の機能です。管理者はこの動作を変更できますが、ユーザーにとって難しすぎると判断する場合は、最初のオプションのひとつである**ユーザーの言語でコースを表示**（既定は「いいえ」）でも変更できます。

学科および学科 URL は非推奨のフィールドです。レガシーサポートのためにのみ維持されています。

有効な場合、ポータル上の既存のスタイルシートを使って、**スタイルシート**オプションでコース内のスタイルを切り替えられます。このオプションは、より統合された全体デザインのため、管理者によって無効化されていることがよくあります。

### ディスククォータ

各コースには、アップロードファイル用のストレージ上限（ディスククォータ）があります。クォータはプラットフォーム管理者が設定します。現在の上限はコース設定で、現在の使用量は**ドキュメント**ツールで確認できます。

> 容量が不足している場合は、プラットフォーム管理者にクォータの増加を依頼するか、ドキュメントツールから未使用のファイルを削除してください。

### コースの公開範囲

![公開、オープン、登録済み、非公開のオプションを示すコース公開範囲設定](../../.gitbook/assets/course-settings-visibility.png)

コースにアクセスできるユーザーを制御します。

| 設定 | 説明 |
|---------|-------------|
| **公開** | 匿名の訪問者を含め、誰でもコースにアクセスできます |
| **プラットフォームにオープン** | プラットフォーム上の登録済みユーザー全員がコースにアクセスできます |
| **非公開 — 特権ユーザーがアクセスを付与** | コースに明示的に登録されたユーザーのみがアクセスできます |
| **閉鎖** | コースはロックされ、教師以外は誰もアクセスできません |

#### 登録設定

プラットフォームの構成によっては、次を制御できる場合があります。

* **自己登録を許可** — 学習者がコースカタログから自分で登録できるかどうか
* **自己登録解除を許可** — 学習者が自分でコースを離脱できるかどうか
* **登録パスワード** — 自己登録にパスワードを要求します（特定グループへのアクセス制限に有用）が、同じコースアクセス用パスワードが全ユーザーで共有されるため、セキュリティレベルは低くなります。

これらの設定は自己登録のみを対象とします。既存ユーザーを自分で登録する、またはまだプラットフォームアカウントを持たない人を招待するなど、全体像については [ユーザーの登録](../assessing-learners/subscribing-users.md) を参照してください。

### ドキュメント設定

**ドキュメント**ツール内のシステムフォルダを表示するか非表示にするかを選択します（既定は非表示です。ほとんどの場合は不要であり、表示すると非表示コンテンツや学習者に関する問題を引き起こす可能性があります）。

### メール通知設定

コース活動が通知をどのようにトリガーするかを設定します。

* **新しいコンテンツのメール通知** — 新しいドキュメント、お知らせ、その他のコンテンツを追加したときに登録ユーザーに通知します

### チャット設定

**チャット**ツールの表示方法を制御します。

### 学習パス設定

* **コーステーマを有効化** — 学習パスが外観を変更できるようにします（統合されたユーザー体験には推奨されません）
* **学習パスの戻りリンク** — 学習パス内の**ホーム**アイコンをクリックしたときにユーザーが移動する先を決めます。学習パス一覧、コースホーム、*マイコース*、*マイセッション*、またはポータルホーム

### テーマ進行設定

テーマ進行メッセージがコースホームページにどのように表示されるかを設定します。

### フォーラム設定

このコースのフォーラムツールの動作を制御します。

### 課題設定

* **新規投稿ファイルの公開範囲の既定設定** — **課題**ツールで学習者がアップロードした新しいドキュメントを他のすべての学習者と共有するかどうかを決めます（既定は「いいえ」）
* **学習者が自分の投稿を削除することを許可** — 学習者がすでにアップロードした課題を削除できるようにします（訂正版をアップロードしたい場合など）。

### 自動起動の設定

コースには自動起動の動作を設定でき、学習者がコースの重要な部分に到達するまでの経路を短縮できます。有効にすると、コースに入った学習者は選択したツールへ直接送られ、中間ステップとしてコースホームページは表示されません。到着時に起動する特定のラーニングパスや演習を選択することもできます。その場合は、ここで該当オプションを選択したうえで、ラーニングパスまたは演習の一覧に移動し、対象項目のロケット <img src="../../.gitbook/assets/icons/mdi-rocket-launch.svg" alt="自動起動" data-size="line"> アイコンをクリックしてください。

### AIヘルパーの設定

このセクションは、管理者がプラットフォームでAIツールを有効にしている場合にのみ表示されます。Chamiloプラットフォームの各種ツールを通じて利用できるAIヘルパーサービスの選択を細かく調整できます。使いたくない場合は無効にできますが、非常に強力な機能であるため、無効化はおそらく得策ではありません。

これらの機能については、本ガイドの **AI Tools** セクションで説明しています。

### 外部ツール（LTI）

プラットフォームで有効になっている場合、Learning Tools Integrationにより、互換性のある外部アクティビティを、コースホームページ上の個別アイコンとしてこのコースに統合できます。LTIの詳細な説明はこのガイドの範囲外ですが、教員にとって強力な統合システムです。

### その他

Chamiloのオプションやバージョンによっては、このページに追加のセクションや項目が表示される場合があります。
