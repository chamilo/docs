# コースの作成

このセクションでは、Chamilo で新しいコースを作成し、ニーズに合わせて設定する方法を説明します。

## 新しいコースの作成

コースを作成するには:

1. サイドバーの **マイコース** をクリックします
2. **コースを作成** ボタン（通常は緑の本 <img src="/.gitbook/assets/icons/mdi-book-open-page-variant.svg" alt="コース" data-size="line"> アイコンに + 記号）をクリックします
3. コース作成フォームに入力します:

![名前、カテゴリ、コード、言語のフィールドがあるコース作成フォーム](/.gitbook/assets/course-creation-form.png)

| フィールド | 必須 | 説明 |
|-------|----------|-------------|
| **コース名** | はい | コースの短くわかりやすいタイトル（例: 「イノベーション・マネジメント」） |
| **コースカテゴリ** | いいえ | プラットフォーム上でコースを整理するためのカテゴリを選択します |
| **コースコード** | いいえ | 英数字のみの短いコード（最大40文字）。空欄の場合、コース名から自動生成されます |
| **言語** | いいえ | コースの主言語。現在の言語が既定値になります |

有効になっている場合、**デフォルトルーム** の設定や、ゼロからコースを作成しなくて済むよう **コーステンプレート** を使うオプションも表示されることがあります。

4. **このコースを作成** をクリックします

新しいコースのホームページにリダイレクトされます。確認メッセージ「コースが正常に作成されました。」が表示されます。

## コースホームページ

コースが作成されると、そのホームページに移動します。ここはコースの中心となるハブで、あなたと学習者がすべてのツールとコンテンツにアクセスする場所です。

![アイコンと表示切替のある利用可能なコースツールを示すコースホームページのツールグリッド](/.gitbook/assets/course-homepage-tool-grid.png)

ホームページには次のものが表示されます:

* **コースタイトル** — コース名。上部に表示されます。
* **コース紹介** — 任意の説明または歓迎メッセージ。**+ コース紹介** ボタンをクリックして追加するか、上部の **紹介を編集** <img src="/.gitbook/assets/icons/mdi-pencil.svg" alt="編集" data-size="line"> ボタンで変更します。画像、リンク、書式を含むリッチテキストに対応しています。
* **ツールグリッド** — 利用可能なすべてのコースツールのグリッド。それぞれアイコンと名前のカードとして表示されます。

### ツールの表示の管理

教師として、学習者にどのツールを見せるかを制御できます:

* 任意のツールの横にある **目のアイコン** <img src="/.gitbook/assets/icons/mdi-eye.svg" alt="表示" data-size="line"> をクリックすると、学習者から非表示になります。非表示のツールは **斜線入りの目** <img src="/.gitbook/assets/icons/mdi-eye-off.svg" alt="非表示" data-size="line"> になり、あなたは引き続きアクセスできます。
* **すべて表示** および **すべて非表示** ボタンですべてのツールを一度に変更します
* **並べ替え** をクリックすると、ツールグリッドのドラッグアンドドロップによる並べ替えが可能になります

### 学生ビュー

**学生ビュー** ボタンをクリックすると、学習者に見えるとおりのコースホームページを確認できます。非表示のツールや未公開コンテンツが見えないことを確認するのに便利です。もう一度ボタンをクリックすると教師ビューに戻ります。
