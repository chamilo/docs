# ブランチとルーム

Chamilo には、**ブランチ** と **ルーム** という 2 つの概念を中心とした、基本的な物理的所在地システムが含まれています。

**ブランチ** は、本社、地域研修センター、大学の建物など、物理的な拠点やキャンパスを表します。ブランチは入れ子にできます（建物に部署を含めたり、都市に建物を含めたりできます）。各ブランチには 1 つ以上の **ルーム** を含めることができ、ルームはそのブランチ内の個々の教室や実習室を表します。

この機能はまだ初期段階です。現時点での主な実用的な用途は、コースに物理的な所在地マーカーを付与することです。

## コースへのルームの割り当て

コースを作成する際、管理者がすでにルームを設定している場合、コース作成フォームに **Default room** フィールドが表示されます。コースが実施されるルームを選択してください。

この情報は参考用であり、コースの動作やアクセス制御には影響しません。単にコースが物理的に開催される場所を記録するもので、管理者がルームのスケジュールを管理したり、コース全体のルーム使用状況を確認したりするのに役立ちます。

プラットフォームにルームが設定されていない場合、このフィールドは表示されません。

## 管理者ができること

ブランチとルームの管理は、すべて管理者が行います。管理者は次のことができます。

- ツリー階層でブランチを作成・整理する
- ブランチにルームを追加する（任意で地理位置情報と IP 範囲データを付与）
- 各ルームに割り当てられているコースを確認する
- 出席記録に基づくルームの使用カレンダーを確認する

ルームの作成や、コースを別のルームへ移す必要がある場合は、プラットフォーム管理者に連絡してください。
