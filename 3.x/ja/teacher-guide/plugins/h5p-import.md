# H5P Import

H5P Import <img src="/.gitbook/assets/icons/mdi-puzzle.svg" alt="H5P Import" data-size="line"> を使うと、標準の `.h5p` インタラクティブコンテンツパッケージ（インタラクティブ動画、クイズ、プレゼンテーション、その他の H5P コンテンツタイプ）をコースに取り込み、学習者の試行と進捗を Chamilo のテストと同様に追跡できます。

## Accessing the Tool

有効化すると、コースホームページに **H5P import** ツールが表示され、コース内の H5P パッケージの一覧テーブル（タイトル、説明、各パッケージの起動回数）が示されます。

## Adding Content

* **Upload** をクリックし、`.h5p` ファイルをタイトルと説明とともに選択して、コースの一覧に追加します
* **Learning Path** から、リソースパネルの H5P エントリを使い、コースにアップロード済みのパッケージをラーニングパス項目として直接挿入します

## Tips

* **アップロード前にコンテンツを設計する** — アップロード後の H5P パッケージは編集できません。変更が必要な場合は H5P オーサリングツールで修正し、再アップロードしてください
* **ツールの一覧にあるものはすべて、既定ですべての学生に表示されます** — 項目ごとに表示を制御したい場合は、代わりに Learning Path 経由でパッケージを追加し、各項目の表示を個別に管理してください
* **これはベータ機能です** — 利用可能ではあるもののまだ成熟途上として扱い、再アップロードが必要になる場合に備え、元の `.h5p` ファイルのコピーを保管してください
