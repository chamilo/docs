# 学習カレンダー

学習カレンダー <img src="../../.gitbook/assets/icons/mdi-calendar-text.svg" alt="学習カレンダー" data-size="line"> は、教室での時間と現場での実習を組み合わせたブレンド型または徒弟制スタイルの研修を計画するのに役立ちます。各日を **Busy**、**Exam**、または **Free** としてマークしたカレンダーを作成し、学習者を割り当てると、学習者の個人アジェンダにそれらの予定日が表示されます。

## ツールへのアクセス

有効化すると、**My Space**（レポート領域）に **学習カレンダー** アイコンが表示されます。作成したカレンダーの一覧が開き、追加、編集、コピー、削除、および各カレンダーへの学習者の割り当てが行えます。

## カレンダーの作成

1. 新しいカレンダーを作成する
2. 日付をクリックして **Busy → Exam → Free → クリア** の順に切り替える
3. このカレンダーに従う学習者を割り当てる

割り当てられた学習者は、自身のアジェンダ上で予定日を確認できます。レポートでは、予定日と実際のラーニングパス完了状況が比較されます。

## ヒント

* **学習者あたり同時に1つのカレンダー** — 学習者は1つのカレンダーにしか割り当てられないため、1人に複数のカレンダーを重ねるのではなく、コホート単位で計画してください
* **初期段階の機能です** — 特定のコースには依存しないため、Chamilo の中核ツールと同程度の完成度は期待しないでください。実際のコホートで利用する前に、研修形式に合うかどうかを確認してください
