# 教師メモ

教師メモ <img src="../../.gitbook/assets/icons/mdi-notebook-outline.svg" alt="教師メモ" data-size="line"> は、コースの指導チームが特定の学習者についてのメモ（進捗の観察、リマインダーなど、公開ツールには書きたくない内容）を書き留めるための非公開ノートブックです。学習者はこのツールとその内容を見ることはありません。

> [ノートブック](../additional-tools/notebook.md) ツールと混同しないでください。そちらは学習者向けの個人ノートブックであり、教師メモは別の、教師専用のツールです。

## ツールへのアクセス

有効にすると、コースホームページに **教師メモ** ツールが表示され、教師およびコース管理者（および DRH）が利用できます。

## 使い方

* 学生でメモを絞り込むか、**すべての学生** を表示する
* **個人ノートブックに新しいメモを追加**し、任意で特定の学習者に紐付ける
* 自分のメモを編集または削除する
* 作成日、更新日、またはタイトルでメモを並べ替える

## ヒント

* **関連する場合はメモを学習者に紐付ける** — 学生が割り当てられていないメモは見失いやすいため、特定の学習者についての内容であれば必ずその学習者に紐付けてください
* **共同教師と調整する** — ノートブックは指導チーム全体で共有されるため、簡単な取り決め（例: 自分の名前で署名する）を決めておくと、メモの帰属が分かりやすくなります
