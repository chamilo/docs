# コースホームでの通知

コースホームでの通知 <img src="../../.gitbook/assets/icons/mdi-bell-ring-outline.svg" alt="コースホームでの通知" data-size="line"> は、コースホームページを訪れるすべての人にポップアップ通知を表示します。お知らせ、必読の案内、「続行するにはここをクリック」といったゲートとして役立ちます。

## 通知の設定

有効にすると、コースの **設定** <img src="../../.gitbook/assets/icons/mdi-cog.svg" alt="設定" data-size="line"> に **ホームページに通知を1件設定** ボタンが追加されます。開くフォームで通知文（リッチテキスト）を作成し、任意で **有効期限リンク** を設定できます。

* **有効期限リンクあり** — ポップアップにそのリンク先のボタンが表示され、学習者がクリックするまで繰り返し表示されます
* **なし** — コースホームページを開くたびに、すべての訪問者に通知が再表示されます

削除するには **コースホームページの通知を削除** を使用します。

## ヒント

* **コースあたり通知は1件のみ** — 新しい通知を作成すると、以前のものは置き換えられます。複数件をキューに入れる方法はありません
* **書式をプレビューする** — 通知はポップアップ内で生の HTML として表示されるため、公開前にリッチテキストが意図どおりに描画されるか確認してください
* **期限のある内容には有効期限リンクを使う** — リンクがないと、同じ通知が無期限にポップアップし続け、再訪する学習者には繰り返しになってしまいます
