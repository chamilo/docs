# 設問オプション評価

設問オプション評価 <img src="/.gitbook/assets/icons/mdi-calculator-variant.svg" alt="設問オプション評価" data-size="line"> では、正解を単純に合計する Chamilo の既定の動作ではなく、テストの採点に減点（ペナルティ）の計算式を適用できます。

## 計算式の設定

有効にすると、コースの **テスト** ツール一覧の各テストの横に追加のアイコンが表示されます。クリックすると小さなフォームが開き、次のいずれかから選択します。

* **計算式なし** — Chamilo の通常の採点（既定）
* **設問スコアの再計算** — ペナルティなしで選択肢の配点を再配分
* **成功 − 失敗**
* **成功 − 失敗 / 2**
* **成功 − 失敗 / 3**

選択した計算式は、その特定のテストにのみ適用されます。

> この設定は設問や解答そのものの配点を変更するものではなく、最終スコアの算出方法を変更します。プラグインが無効である場合、または計算式が選択されていない場合、Chamilo は元の採点に戻ります。

## ヒント

* **まずコピーで試す** — 計算式を変更すると、そのテストで学習者が得るスコアが変わる可能性があります。本番のテストに適用する前に、複製したテストで試してください
* **学習者に変更を説明する** — 単純な正解採点に慣れている学習者にとって、ペナルティ計算式は意外に感じられることがあります。指示文で言及してください
