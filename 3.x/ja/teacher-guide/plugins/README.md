# プラグイン

Chamilo に組み込まれているツールに加え、プラットフォーム管理者は **プラグイン** をインストールして有効化できます。プラグインは、コースに新しいツール、設定、または動作を追加するオプション機能です。プラグインは既定ではオフです。管理者が有効化した後にのみ表示され、一部は特定のコースでも有効化した後に初めて機能します。

本節では、**教師** が直接操作する内容を変えるプラグインを説明します。ご自身のコースにここで説明されているプラグインが表示されない場合、プラットフォームで有効化されていない可能性が高いので、管理者にお問い合わせください。

## 評価とテスト

* **[Exercise Focused](exercise-focused.md)** — テスト中に学生が試験ウィンドウを離れたことを検出し、画面上の警告と任意の自動提出を行う
* **[Exercise Monitoring](exercise-monitoring.md)** — 監視付きテスト受験中に、学生とその身分証明書のウェブカメラ写真を撮影する
* **[Exercise Signature](exercise-signature.md)** — テスト完了後に学生に電子署名を求める
* **[Question Options Evaluation](question-options-evaluation.md)** — Chamilo の既定の採点ではなく、減点（ペナルティ）採点式をテストに適用する
* **[Positioning](positioning.md)** — 初回テストと最終テストの前後スコアをレーダーチャートで比較する
* **[Test to PDF](test-to-pdf.md)** — テストの設問および／または解答を印刷可能な PDF に書き出す

## コンテンツと作成

* **[C-Studio Content Editor](cstudio.md)** — HTML を書かずに、ビジュアルエディターでインタラクティブなラーニングパスのページ（クイズ、ドラッグアンドドロップ、ホットスポット画像など）を作成する
* **[H5P Import](h5p-import.md)** — H5P インタラクティブコンテンツパッケージをコースまたはラーニングパスにアップロードする
* **ONLYOFFICE** — ドキュメントツールから Word、Excel、PowerPoint 文書を作成・共同編集する。すでに [ドキュメント](../adding-content/documents.md#onlyoffice-integration) で説明しています

## コミュニケーションと会議

* **Videoconferencing (BigBlueButton)** および **Zoom Videoconferencing** — コースからライブビデオセッションを実施する。[ビデオ会議](../collaboration-and-communication/video-conferencing.md) で説明しています
* **[Notify in Course Home](notify-in-course-home.md)** — コースホームページを訪れた全員に、一度限りのポップアップ通知を表示する

## 証明書とコンプライアンス

* **[Custom Certificate](custom-certificate.md)** — 標準の成績表証明書を、独自のデザイン、ロゴ、署名に置き換える
* **[Course Legal Agreement](course-legal-agreement.md)** — コースにアクセスする前に、学生に利用規約／法的通知への同意を求める

## 追跡とフォローアップ

* **[Student Follow-up](student-follow-up.md)** — 学習者の進捗や困難についての、非公開または共有のタイムスタンプ付きメモを残す
* **[Learning Calendar](learning-calendar.md)** — ブレンド型または徒弟制スタイルのコースで、学習者の多忙日／試験日／空き日を計画する
* **[Teacher Notes](teacher-notes.md)** — コース内の特定の学習者についての非公開メモを残す。指導チームのみ閲覧可能

## 連携

* **[IMS/LTI Client](ims-lti.md)** — コース内から外部ツールまたはコンテンツプロバイダーを起動する
* **[LTI 1.3 Advantage Provider](lti-1-3-advantage-provider.md)** — 外部 LMS から自コースの演習またはラーニングパスを起動できるようにする（管理者が設定。教師側の設定は不要）

## アンケートの書き出し

* **[Survey Export CSV](survey-export-csv.md)** — アンケート結果をコンパクトな CSV ファイルに書き出す
* **[Survey Export TXT](survey-export-txt.md)** — アンケート結果を人が読みやすいテキストファイルに書き出す
