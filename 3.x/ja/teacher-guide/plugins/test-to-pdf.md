# テストのPDF出力

テストのPDF出力 <img src="../../.gitbook/assets/icons/mdi-file-pdf-box.svg" alt="テストのPDF出力" data-size="line"> は、コース内テストの設問を印刷可能なPDFとして書き出します。設問のみ、解答のみ、またはその両方をまとめて出力でき、テストの紙版として役立ちます。

## ツールへのアクセス

有効化すると、コースホームページに **テストのPDF出力** ツールが表示され、コース（またはセッション）内のすべてのテストが一覧されます。各行には **設問をダウンロード**、**解答をダウンロード**、**すべてダウンロード** の3つの操作があります。

## ヒント

* **すべての設問タイプが対応しているわけではありません** — Chamiloの設問タイプのうち一部（多肢選択、正誤、および類似のクローズド形式）のみがきれいに書き出されます。記述式やより複雑な設問タイプは、正しく表示されないか、まったく表示されない場合があります
* **まとめて印刷する前に出力を確認してください** — 試験セッション向けに大量印刷する前に、1つのテストで生成されたPDFを確認してください
