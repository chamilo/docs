# 用語集用語ジェネレーター

AI用語集用語ジェネレーターは、トピックや主題領域から用語の定義を自動生成することで、コース用語集の作成を迅速化します。用語集に追加する前に、提案された各用語と定義を確認できます。

## 用語集用語ジェネレーターへのアクセス

ジェネレーターは **用語集** ツールから利用できます。ただし、次の条件を満たす必要があります。

1. プラットフォームレベルでAIヘルパーが有効になっていること
2. 少なくとも1つのAIテキストプロバイダーが設定されていること

コースホームページから **用語集** <img src="/.gitbook/assets/icons/mdi-alphabetical.svg" alt="用語集" data-size="line"> ツールを開き、ツールバーの **AIで生成** ボタンを探します。

## 用語の生成方法

1. **AIで生成** をクリックします
2. **トピックまたは主題領域** を入力します — 用語を生成したい領域を記述します（例：「有機化学入門」や「プロジェクトマネジメント手法」）
3. 必要に応じて生成する **用語数** を指定します
4. 複数のプロバイダーが設定されている場合は **AIプロバイダー** を選択します
5. **生成** をクリックします

AIは、確認できる用語と定義の一覧を生成します。

## 用語の確認と追加

生成された用語は提案として表示されます。用語集に追加する前に、次を行ってください。

* **正確性の確認** — 定義がコースのレベルと文脈に対して正しいかを検証します
* **表現の編集** — 指導スタイルやコースの慣例に合わせて定義を調整します
* **重複の除外** — 既に用語集にある用語や、コースの範囲外の用語はスキップします
* **追加する項目の選択** — 取り込む用語を選びます。すべてを受け入れる必要はありません

内容に問題がなければ選択を確定すると、用語が用語集に追加されます。

## ヒント

* **トピックを具体的に** — 広いトピックでは一般的な定義になり、狭いトピックではコースに関連する用語が増えます
* **必ず確認する** — AIの定義は簡略化されていたり不正確な場合があります。学習者に公開する前にそれぞれ確認してください
* **取り込み後に編集する** — 用語の定義は、用語集の管理画面から後でいつでも更新できます
* **手動入力と組み合わせる** — ジェネレーターで出発点となる一式を得てから、専門分野固有の用語を手動で追加します
