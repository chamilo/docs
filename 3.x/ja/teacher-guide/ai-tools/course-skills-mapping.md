# AI支援によるコースのスキルマッピング

Chamilo 3.1では、コースに関連するスキルを提案し、権限を持つユーザーがそれらの提案を確認して、スキル参照体系およびGradebookに適用できます。AIによる提案は**自動的には適用されません**。選択して承認する必要があります。

## 提案の生成

1. 対象コースの**AI支援スキルマッピング**ページを開きます。アプリケーションのルートは `/course/{courseId}/skills` であり、`{courseId}` は実際のコースIDに置き換えます。
2. コースがセッションに属している場合は、正しいセッションのコンテキストでページを開きます。
3. 利用可能な**AIプロバイダー**を選択します。
4. **このコースのスキルを提案**を選択し、返された結果を確認します。

AIプロバイダーは、プラットフォーム管理者が利用可能にし、設定しておく必要があります。提案は**既存スキル**の項目を参照することも、親スキルの下に**新規スキル**を推奨することもできます。各項目には、その説明、基準、および提案の説明を含めることができます。

## 確認と承認

1. 各提案を批判的に読み、コースの目標および内容と比較します。
2. チェックボックスを使用して、妥当なスキルのみを選択します。
3. 必要な権限がある場合は、**選択したスキルを参照体系とGradebookに追加**を選択します。
4. コース内で、結果として得られたスキルとGradebookの関連付けを確認します。

割り当て権限を持たないユーザーは提案を確認できますが、それらを関連付けることはできません。新規スキルの作成には、プラットフォーム管理者の権限が必要です。提案は期限切れになることがあります。以前の提案がもはや有効ではないとアプリケーションが報告した場合は、新しい提案セットを生成してください。

## 推奨される実践

AIが生成したスキルは候補であり、権威あるカリキュラム要件ではありません。承認前に、文言、重複、親スキルの配置、および基準を確認してください。AIへのプロンプトに、学習者の機密情報を入力しないでください。
