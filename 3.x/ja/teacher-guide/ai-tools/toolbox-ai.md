# AI ツールボックス

**AI ツールボックス**は、教員の指示からインタラクティブな教育用アプリケーションを生成するコースツールです。Chamilo は生成された各アプリケーションを **SCORM 1.2** としてパッケージ化するため、学習者の進捗、スコア、再開データはプラットフォームによって追跡されます。

> 管理者は、**管理 > 設定 > AI ヘルパー** で `ai_helpers.enable_ai_helpers` と `ai_helpers.toolbox` の両方を有効にし、少なくとも 1 つのテキスト AI プロバイダーを設定する必要があります。

## インタラクティブなアプリケーションの作成

1. コースで **AI ツールボックス** を開きます。
2. **作成** をクリックします。
3. **タイトル** を入力し、必要に応じて **説明** を入力します。
4. **アプリケーションは何をすべきですか？** に、作成したい活動の全体を記述します。学習目標、ルール、レベル、採点、および学習者が終了したときに何が起こるべきかを含めてください。
5. 複数のプロバイダーが利用可能な場合は、**AI プロバイダー** を選択します。
6. **生成** をクリックします。

最初の生成結果は **バージョン 1** として保存されます。最初は下書きとして開始されるため、学習者に公開する前にプレビューできます。

## 改善とバージョン管理

アプリケーションの **設定** を開いて管理します。次の操作ができます。

* 現在のアプリケーションをプレビューまたはダウンロードする。
* **AI で改善** を使用して変更内容を記述し、新しいバージョンを生成する。
* **バージョン履歴** を確認する。
* 以前のバージョンをプレビュー、ダウンロード、または復元する。
* アプリケーションを公開または非表示にする。
* **レポート** を開いて学習者の追跡状況を確認する。

改善を生成しても、以前のバージョンは削除されません。以前のバージョンを復元すると、そのバージョンが再び現在のバージョンになります。

## 学習パスへのアプリケーションの追加

[学習パスビルダー](../adding-content/learning-paths.md) では、教員は生成された AI ツールボックスのアプリケーションをリソースとして選択できます。アプリケーションには生成済みのバージョンが必要ですが、教員が学習パスに追加する前に公開されている必要はありません。未公開のアプリケーションは、公開されるまで学習者には利用できません。

権限のある教員が **プレビューモード** でツールボックスのコンテンツを開くと、Chamilo は **「プレビューモードでは進捗とスコアは保存されません。」** と表示します。この方法で活動をテストしても、学習者の追跡は作成されず、スコアも更新されません。公開後に SCORM の進捗とスコアを確認するには、通常の学習者体験を使用してください。

## 生成の検証とトラブルシューティング

AI による生成後、Chamilo はバージョンを利用可能にする前に、生成されたアプリケーションのソースを確認します。これには、JavaScript の構文または構造のチェックと、安全でないブラウザ API に対する制限が含まれます。検証に失敗した場合、Chamilo は AI プロバイダーに **結果を 1 回修復する** よう依頼します。修復されたバージョンでも失敗した場合、生成はエラーで停止します。検証に成功しても、公開前に活動の学習ルール、アクセシビリティ、および SCORM の採点をテストする代わりにはなりません。

生成で **HTTP 504** が報告された場合、Web サーバーまたはゲートウェイがリクエストの待機を停止したことを意味します。これは、AI テキストプロバイダーによって課されるタイムアウトとは異なります。エラーにはおおよその経過時間が含まれることがあります。より単純な活動のリクエストを試し、管理者にゲートウェイ、PHP/Web サーバー、およびプロバイダーのタイムアウトを確認するよう依頼してください。プロバイダーのタイムアウトまたはレート制限のエラーの場合は、代わりに設定済みのモデルとプロバイダー設定を確認する必要があります。エラーの後にアプリケーションが正常に保存されたと想定しないでください。

これらの検証および診断の改善は、[PR #9198](https://github.com/chamilo/chamilo-lms/pull/9198) で導入されました。

## 学習者の体験

学習者には、公開されたアプリケーションのみが表示されます。ツールボックスから、アプリケーションを開き、最新の SCORM 状態から再開し、**進捗** と **スコア** を確認できます。新しい試行が許可されている場合、**再試行** で新しい試行が開始されます。

ツールボックスのアプリケーションは、制限付き iframe 内の学習パスランタイムで実行され、SCORM の状態を Chamilo に報告します。これらは通常の学習パス一覧ではなく、ツールボックスから管理されます。

同じ AI ツールボックスの設定が有効になっている場合、権限のある MCP クライアントもツールボックスのアプリケーションを作成または更新できます。
