# 教師ガイド

Chamilo 3.0 教師ガイドへようこそ。本ガイドは、講師、トレーナー、および Chamilo プラットフォームを通じて学習コンテンツの作成と提供を担当するすべての方を対象としています。

初めてのオンラインコースを開設する場合でも、複雑な研修プログラムを運営する場合でも、本ガイドでは教師として利用できるすべての機能を順を追って説明します。

## Chamilo でできること

Chamilo の教師として、次のことができます。

* **コースの作成と整理** — 柔軟なホームページとカスタマイズ可能なツール
* **コンテンツの追加** — ドキュメントのアップロード、ラーニングパスの作成、用語集の構築、外部リソースへのリンク
* **学習者の評価** — 複数の問題タイプによる演習の設計、課題の収集、アンケートの実施、成績の管理
* **協働** — フォーラム、グループワーク、Wiki、ブログ、ライブビデオセッションの設定
* **進捗の追跡** — 学習者の活動の監視、レポートの生成、修了証の授与
* **AI ツールの利用** — 演習とラーニングパスの自動生成、AI 支援による採点

## 本ガイドの構成

本ガイドは、コースの構築と運営の自然なワークフローに沿っています。

1. **はじめに** — ログイン、インターフェースの操作、プロフィールの設定
2. **コースの作成** — 新規コースの作成、設定の構成、ホームページのカスタマイズ
3. **コンテンツの追加** — ドキュメントのアップロード、ラーニングパスの整理、リソースの管理
4. **学習者の評価** — テストの作成、課題の収集、アンケートの実施、成績簿の設定
5. **協働とコミュニケーション** — フォーラム、チャット、グループ、Wiki、ビデオ会議の有効化
6. **追跡とレポート** — 学習者の進捗の監視とレポートの生成
7. **AI ツール** — AI 機能を用いたコンテンツ生成と採点支援
8. **その他のツール** — アジェンダ、ノートブック、ポートフォリオなど

それでは始めましょう。
