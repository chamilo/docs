# 数式

リッチテキストエディターでは数式を組版できます。LaTeX で数式を記述すると、学習者にはコンテンツが表示されるあらゆる場所（文書、お知らせ、演習、フォーラム、Wiki ページ、およびエディターを使用するその他のツール）でレンダリングされた形で表示されます。

数式はコンテンツ自体の中に保存されるため、コースをコピーまたはエクスポートする際にも一緒に移動します。

## 機能の有効化

数式ボタンは既定ではオフです。プラットフォーム管理者が **管理 > 設定 > エディター > MathJax を有効にする**（[`enabled_mathjax`](../../admin-guide/platform-settings/editor-settings.md)）でオンにします。

設定がオンになると、プラットフォーム上のすべてのエディターにボタンが表示されます。コースごとの設定は不要です。

## 数式の挿入

1. 数式を置く位置にカーソルを置く
2. エディターツールバーの **数式を挿入** ボタン（Σ アイコン）をクリックする
3. **LaTeX コード** で数式を入力する
4. フィールド下のプレビューボックスでレンダリング結果を確認する
5. **挿入** をクリックする

入力中にプレビューが更新されるため、挿入前に誤りを修正できます。

## 数式の編集

エディター内の数式をクリックします。同じダイアログが再び開き、フィールドに元の LaTeX コードが表示されます。変更して **挿入** をクリックすると、数式が置き換わります。

数式を削除するには、エディターで選択し、他の要素と同様に <kbd>Delete</kbd> を押します。

## LaTeX の記述

数式フィールドには標準の LaTeX 数学記法を入力します。いくつかの例：

| 入力内容 | 学習者に表示されるもの |
| --- | --- |
| `x = \frac{-b \pm \sqrt{b^2-4ac}}{2a}` | 二次方程式の解の公式 |
| `\sum_{i=1}^{n} i = \frac{n(n+1)}{2}` | 上下限付きの和 |
| `\int_{0}^{\infty} e^{-x} dx = 1` | 定積分 |
| `\alpha + \beta = \gamma` | ギリシャ文字 |
| `\begin{matrix} a & b \\ c & d \end{matrix}` | 行列 |

生の区切り記号 `\(...\)`、`\[...\]`、または `$$...$$` をエディターに直接入力することもできます。エディターはコンテンツの読み込み時にそれらを数式に変換します。

## 注意事項

* 数式ライブラリは、実際に数式を含むページでのみ読み込まれるため、数式のないページが遅くなることはありません。
* すべて学習者のブラウザーでレンダリングされます。プラットフォームは外部サービスを必要とせず、インターネットに接続できないインストールでも動作します。
* 数式は LaTeX ソースを保持します。何年後でも再度開いて、記述した内容を確認できます。
