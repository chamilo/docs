# コンテンツの追加

このセクションでは、コースに学習コンテンツを追加するために使用するツールについて説明します。Chamilo では、学習者に教材を提供するいくつかの方法があります。

* **[ドキュメント](documents.md)** — ファイルのアップロード、Web ページの作成、コンテンツライブラリの整理
* **[リンク](links.md)** — 外部リソースへの URL をカテゴリ別に整理して共有
* **[ラーニングパス](learning-paths.md)** — 前提条件と進捗追跡を備えた、構造化されたコンテンツのシーケンスを構築
* **[用語集](glossary.md)** — 学習者がコース全体で参照できる重要な用語を定義
* **[お知らせ](announcements.md)** — 登録済みの学習者にメッセージや更新情報を送信
* **[多言語コンテンツ](multi-language-content.md)** — 同じコンテンツの複数の言語版を作成し、各学習者には自分の言語のみを表示

各ツールは、コースホームページのツールグリッドから利用できます。ツールのアイコンをクリックして開きます。
