# プラットフォーム

管理ダッシュボードの **プラットフォーム管理** ブロックは、ポータル全体の設定とコミュニケーションツールをまとめたものです。設定パネル全体から言語、公開お知らせ、グローバルカレンダー、ポータルの公開向けコンテンツの一部を構築する CMS に近い Pages システムまでが含まれます。

![管理ダッシュボードのプラットフォーム管理ブロック。Configuration settings、Languages、Plugins、Regions、Portal news、Global agenda、Pages、Setting the registration page、Extra fields、Configure multiple access URL、Mail templates、External tools (LTI)、Contact form categories、System templates が一覧表示されている](/.gitbook/assets/admin-platform-block.png)

## プラットフォームブロックへのアクセス

管理パネルでは、**プラットフォーム管理** ブロックが他のダッシュボードブロックと並んで表示されます。いずれかのリンクをクリックすると、対応するツールが開きます。

## ブロックの内容

* **[プラットフォーム設定](../platform-settings/README.md)** — 設定パネル全体（ポータル、コース、セッション、ユーザー、セキュリティなど）。このブロックの「Configuration settings」リンクは、その別章への入口にすぎません。
* **[言語](languages.md)** — ユーザーが利用できるインターフェース言語を選び、プラットフォームのデフォルトを設定します
* **[ポータルニュース](portal-news.md)** — プラットフォーム全体のお知らせ（システムお知らせ）。スケジュール設定とロールによる対象指定が可能です
* **[グローバルアジェンダ](global-agenda.md)** — プラットフォーム全体のカレンダーイベント。コースやセッションに関係なくすべてのユーザーに表示されます
* **[Pages](pages.md)** — ポータルのホームページ、フッター、その他の公開コンテンツブロック（登録ページの導入文を含む）を支える CMS に近いツールです
* **[プラットフォームツール](platform-tools.md)** — Extra fields、メールテンプレート、お問い合わせフォームのカテゴリ、および条件付きで表示されるいくつかの小さな項目
* **Configure multiple access URL** — Multi-URL の [Access URLs](../multi-url/access-urls.md) で扱います
* **External tools (LTI)** — Integrations の [LTI 1.3](../integrations/lti.md) で扱います
