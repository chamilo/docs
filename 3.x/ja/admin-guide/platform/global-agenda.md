# グローバルアジェンダ

グローバルアジェンダは、コースおよび個人のアジェンダで使用されるものと同じカレンダーツールを、プラットフォーム全体のモードで開いたものです。ここで作成されたイベントにはコースやセッションが紐づいていないため、コースやセッションのメンバーだけでなく、ログインしているすべてのユーザーに表示されます。

## グローバルアジェンダへのアクセス

管理パネルから、**プラットフォーム > グローバルアジェンダ** をクリックします。

## コースおよびセッションのアジェンダとの違い

カレンダーイベントの範囲は、コースまたはセッションのリソースにリンクされているかどうかによって決まります。

* **コース／セッションのイベント** は、そのコースまたはセッションに登録されているメンバーに限定されます
* **グローバルイベント** にはそのようなリンクがないため、ログインしているすべてのユーザーが閲覧できます

このスコープの違いを除けば、グローバルイベントはコースイベントと同じ機能をサポートします。**繰り返し**（スケジュールに沿った繰り返し）、**ファイル添付**、**リマインダー** です。

## 利用例

グローバルアジェンダは、特定のコースに紐づかないプラットフォーム全体の日付（メンテナンスウィンドウ、組織全体の締切、休日、全社イベントなど）に使用し、同じイベントをすべてのコースのアジェンダに重複して登録しないようにします。
