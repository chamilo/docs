# はじめに

このセクションでは、Chamilo 3.0 の管理画面を紹介し、全体の把握を助けます。

## 管理者とは誰か？

Chamilo には、いくつかのレベルの管理ロールがあります。

| ロール | アクセス |
|------|--------|
| **Administrator** | プラットフォームのすべての管理機能へのフルアクセス。**Portal Administrator** とも呼ばれます |
| **Global Administrator** | Portal Administrator と同じですが、マルチ URL（マルチテナント）構成におけるすべてのアクセス URL にアクセスできます |
| **Sessions Administrator** | セッションの管理、セッションへのユーザー登録、セッション関連の設定へのアクセスが可能です |
| **Human Resources Manager** | 担当ユーザーの学習進捗とトラッキングデータを閲覧できます |
| **Questions Manager** | 管理者というよりコンテンツキュレーターに近く、設問の品質を確認するためのグローバルな問題バンクにアクセスできます |

本ガイドでは、最も広いアクセス権限を持つ **Portal Administrator** ロールを主に扱います。

## ログイン

管理者は、他のすべてのユーザーと同じログインページからログインします。資格情報を入力すると、（他の設定がない場合）**Administration** ページに移動します。他のユーザーロールとの顕著な違いは、サイドバーに **Administration** セクションがあることです（他のロールには表示されません）。
