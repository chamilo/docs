# システム

管理ダッシュボードの **システム** ブロックは、サーバーレベルのメンテナンスツール、自己更新ワークフロー、ストレージ／リソース検査ユーティリティ、およびプラットフォームのブランディングをまとめています。

![管理ダッシュボードのシステムブロック。一時ファイルのクリーンアップ、システムステータス、システム更新、色、ファイル情報、種類別リソース、アイコン一覧を表示](../../.gitbook/assets/admin-system-block.png)

## システムブロックへのアクセス

管理パネルから、**システム** ブロックは他のダッシュボードブロックと並んで表示されます。いずれかのリンクをクリックすると、対応するツールが開きます。

## ブロックの内容

* **[システムツール](system-tools.md)** — 一時ファイルのクリーンアップ、自己更新ワークフローの実行、保存済みファイルとリソースの検査、組み込みアイコンセットの閲覧
* **システムステータス** — メンテナンス配下の [システムステータス](../maintenance/system-status.md) で扱います
* **[ブランディング](branding/README.md)** — カラーテーマ（ブロックの「色」リンクは同じカラーテーマページを開きます）、ポータルのカスタマイズ、テンプレート

追加の 2 項目 — **データフィラー** と **Eメールテスター** — は、サーバーに `tests/` ディレクトリが存在する場合にのみ表示されます。これは開発／QA 向けの構成であり、本番環境ではありません。一般的な本番インストールでは表示されません。存在する場合の動作については [システムツール](system-tools.md#development-only-tools) を参照してください。
