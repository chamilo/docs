# カラーテーマ

Chamilo 2.0 では、プラットフォームの見た目をカスタマイズできるカラーテーマシステムが導入されています。

## テーマの仕組み

カラーテーマは、Chamilo のインターフェース全体で使われるパレット（プライマリカラー、アクセントカラー、背景色、テキスト色）を定義します。テーマはアクセス URL に関連付けられます。単一 URL のポータルでは実質的にグローバルテーマとなり、マルチ URL 構成では URL ごとに独自のテーマを持てます。

## テーマの適用

![利用可能なテーマ、プレビュー用スウォッチ、適用ボタンが表示されたカラーテーマのページ](/.gitbook/assets/admin-color-themes.png)

1. 管理パネルから **カラーテーマ** に移動します
2. 利用可能なテーマを閲覧します
3. テーマを選択し、**適用** をクリックします
4. テーマはプラットフォームに直ちに適用されます

## URL ごとのテーマ

マルチ URL 構成では、各アクセス URL に独自のカラーテーマを設定できます。これにより、同じ Chamilo インストールを共有しながら、ポータルごとに異なるビジュアルアイデンティティを持たせることができます。

## ヒント

* **ブランドに合わせる** — 組織のブランドカラーに合うテーマを選択またはカスタマイズしてください
* **可読性を確認する** — テーマ適用後、特にコントラストが高い場面で、背景色に対してテキストが読みやすいか確認してください
* **アクセシビリティを考慮する** — 視覚に障害のある利用者のため、十分な色のコントラストを確保してください
