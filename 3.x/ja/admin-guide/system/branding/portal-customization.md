# ポータルのカスタマイズ

Chamilo プラットフォームの外観と、ユーザーに表示される情報をカスタマイズします。

## プラットフォームのアイデンティティ

![名前、ロゴ、機関向けのプラットフォームアイデンティティ設定を示すポータルカスタマイズページ](/.gitbook/assets/admin-portal-customization.png)

ポータルの基本的なアイデンティティを設定します。

* **プラットフォーム名** — ブラウザのタイトルおよびインターフェース全体に表示される名前
* **機関名** — 組織の名称
* **機関 URL** — 組織のウェブサイトへのリンク
* **プラットフォームロゴ** — 組織のロゴをアップロードします（上部バーに表示されます）

## ヒント

* **ホームページをすっきり保つ** — ホームページにコンテンツが多すぎると圧倒されやすくなります。重要なお知らせとコースへのアクセスに焦点を当ててください。
* **定期的に更新する** — システムお知らせを最新の状態に保ち、古いものは削除してください
* **高品質なロゴをアップロードする** — ロゴは最も目立つブランディング要素のひとつです。鮮明で適切なサイズの画像を使用してください。
