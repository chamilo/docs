# テンプレート

Chamilo は、修了証、ドキュメント、メールにテンプレートを使用します。組織のブランディングや要件に合わせて、これらのテンプレートをカスタマイズできます。

## 修了証テンプレート

修了証テンプレートは、成績表のしきい値を満たした学習者に授与される修了証のレイアウトと内容を定義します。

### 修了証テンプレートのカスタマイズ

修了証テンプレートは、プレースホルダー変数を含む HTML と CSS を使用します。

| 変数 | 置換される内容 |
|----------|-------------|
| Student name | 学習者の氏名 |
| Course name | コース名 |
| Date | 修了証を取得した日付 |
| Score | 学習者の最終スコア |
| Barcode | 検証に使用するバーコードのプレースホルダー（`((certificate_barcode))`） |

### テンプレートのアップロード

1. 修了証テンプレート管理に移動します
2. HTML テンプレートをアップロードまたは編集します
3. 動的な内容を表示する箇所にプレースホルダー変数を使用します
4. 保存します

## ドキュメントテンプレート

教師は、ドキュメントツールでコンテンツを作成する際にドキュメントテンプレートを使用できます。テンプレートは、一般的なドキュメント種別の開始レイアウトを提供します。

### ドキュメントテンプレートの管理

1. 管理パネルのテンプレート管理に移動します
2. HTML ファイルをアップロードして新しいテンプレートを追加します
3. 教師が新しいドキュメントを作成するときに、テンプレートが利用可能になります

## ヒント

* **ロゴを含める** — プロフェッショナルな見た目にするため、修了証テンプレートに組織のロゴを追加します
* **実データでテストする** — テンプレートを展開する前に、実際の学習者データで修了証をプレビューします
* **テンプレートはシンプルに保つ** — シンプルなデザインの方が印刷しやすく、プロフェッショナルに見えます
