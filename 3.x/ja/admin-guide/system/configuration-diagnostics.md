# 安全な設定診断エクスポート

Chamilo 3.1 は、機密性のある設定値を意図的にエクスポートすることなく、設定上の問題を診断するためのダウンロード可能な JSON レポートを提供します。このレポートは**現在のアクセス URL** に限定され、管理者ロールが必要です。

## レポートのダウンロード

1. 検査するポータルで **管理 > 設定** を開きます。
2. **デバッグ用設定のダウンロード** を選択します。
3. 生成された `chamilo-configuration-dump.json` ファイルを安全に保存します。
4. サニタイズ済みに見える場合でも、**誰かに送信する前にファイル全体を確認してください**。

レポートには、エクスポートのタイムスタンプ、アクセス URL の範囲、サニタイズされたプラットフォーム設定、およびプラグインのインストール／有効状態とサニタイズされたプラグイン設定が含まれます。これは読み取り専用のエクスポートであり、ダウンロードしてもシステム設定は変更されません。

## 機密性とアクセス URL の境界

機密性のある値は、サニタイズ層によって伏せられます。プラグイン設定は、安全なエクスポート向けに明示的に分類されていない限り、既定で機密として扱われます。それでも、設定名、プラグイン名、その他の診断メタデータから実装の詳細が明らかになる可能性があるため、ファイルは信頼できるサポート担当者にのみ配布してください。

複数 URL のインストールでは、バックエンドは、別のポータルの設定を黙ってエクスポートするのではなく、解決されたアクセス URL がリクエストのホストと一致することを確認します。ダウンロードする前に、ポータルのアドレスを確認してください。

## トラブルシューティング

エクスポートを利用できない場合は、アカウントに管理者権限があること、および要求されたポータルが自身のアクセス URL に解決されることを確認してください。サポートチケットには認証情報や個人情報をコピーせずに、Web サーバーとアプリケーションのログを確認してください。

[システムツール](system-tools.md) および [セキュリティ設定](../platform-settings/security-settings.md) を参照してください。実装: [PR #9476](https://github.com/chamilo/chamilo-lms/pull/9476)。
