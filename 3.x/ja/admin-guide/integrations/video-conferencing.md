# ビデオ会議

Chamilo はビデオ会議プラットフォームと連携し、コース内でライブセッションを実施できます。

## 対応プラットフォーム

### BigBlueButton

**BigBlueButton**（BBB）は、オンライン学習向けに設計されたオープンソースの Web 会議システムです。Chamilo で最も一般的に利用されるビデオ会議ソリューションです。

#### 設定

1. 別サーバーに BigBlueButton をインストールする（[BigBlueButton ドキュメント](https://docs.bigbluebutton.org/) を参照）
2. BBB サーバー上で bbb-conf --salt を実行し、連携に必要な情報を取得する
3. Chamilo のプラットフォーム設定の **Plugins** で、Videoconference プラグインをインストールし、設定を入力する:
   * **BBB server URL** — BBB サーバーのアドレス
   * **BBB salt/secret** — BBB サーバーの API シークレット
4. 保存する
5. Videoconference プラグインを **有効化** する
6. 一部の特別な機能は管理者向けのため、*admin_page* リージョンで有効化してください

#### Chamilo で利用できる機能

* コース内から会議の開始／参加
* コースごとの会議室の自動作成
* 会議の録画（有効な場合）
* 画面共有、ホワイトボード、ブレイクアウトルーム
* ビデオと並行したチャット

### Zoom

Chamilo は **Zoom** とも連携してビデオ会議を利用できます。

#### 設定

1. Zoom Marketplace で Zoom アプリを作成する
2. Chamilo で Zoom API の認証情報を設定する
3. Zoom 連携を有効化する

#### 動作の仕組み

Zoom を設定すると、教員はコース内から Zoom 会議を作成・開始できます。学習者は Chamilo のインターフェースから参加します。

## BBB と Zoom の選択

| 機能 | BigBlueButton | Zoom |
|---------|--------------|------|
| コスト | 無料（オープンソース）。ただし自前のサーバーが必要 | Zoom のサブスクリプションが必要 |
| ホスティング | セルフホスト | Zoom によるクラウドホスト |
| 連携の深さ | 深い（LMS 利用向けに構築） | 標準 |
| 録画 | サーバー側。自前のインフラに保存 | Zoom クラウドまたはローカル |
| ホワイトボード | 内蔵 | 内蔵 |
| ブレイクアウトルーム | あり | あり |

## ヒント

* **BBB は別サーバー** — 最良のパフォーマンスのため、BigBlueButton は Chamilo と同じサーバーではなく、専用サーバーで稼働させてください
* **授業前にテスト** — ライブセッションの前に、必ずビデオ会議の設定をテストしてください
* **帯域の確認** — 想定される同時利用者数に、サーバーとネットワークが対応できることを確認してください
