# LTI 1.3

**LTI**（Learning Tools Interoperability）は、外部の学習ツールを Chamilo 内に埋め込むための標準規格です。バージョン 1.3 は、この標準の最新かつ最も安全なバージョンです。

このツールは、管理ダッシュボードの [プラットフォーム](../platform/README.md) ブロックからも、**外部ツール（LTI）** としてアクセスできます。

## LTI でできること

LTI を使うと、外部ツールを Chamilo のコース内に埋め込めます。例:

* インタラクティブなシミュレーション
* 専門的な評価ツール
* コンテンツ作成ツール
* バーチャルラボ
* サードパーティのコンテンツライブラリ

外部ツールは、Chamilo のインターフェース内にシームレスに表示されます。

## LTI ツールの設定

### 管理者として

1. 管理パネルの LTI 設定に移動します
2. 次の情報を入力して **外部ツールを登録** します:
   * **ツール名** — 分かりやすい名前
   * **Login URL** — 外部ツールの OIDC ログイン開始 URL
   * **Redirect URL** — ログイン後にツールが戻る起動 URL
   * **Client ID** — ツールベンダーから提供されます
   * **Public keyset URL (JWKS URL)** — セキュリティキー交換用のツールの JWKS エンドポイント
3. **成績のパスバック** を設定します — ツールが成績を Chamilo に送り返せるかどうか
4. 保存します

### 教師として

管理者が LTI ツールを登録すると、教師はコースに追加できます:

1. コース内で、外部ツールを追加するオプションを探します
2. 登録済みの LTI ツールから選択します
3. ツールがホームページ上のコースツールとして表示されます

## セキュリティ

LTI 1.3 は次を使用します:

* 認証のための **OAuth 2.0**
* メッセージ署名のための **JSON Web Tokens (JWT)**
* 検証のための **公開鍵／秘密鍵ペア**

これにより、資格情報は Chamilo と外部ツールの間で直接共有されることはありません。

## 成績のパスバック

LTI ツールは成績を Chamilo に送り返すことができ、コースの成績簿に統合できます。これは登録時にツールごとに設定します。

## ヒント

* **ツールの互換性を確認する** — 外部ツールが LTI 1.3 をサポートしていることを確認してください（古いバージョンのみではないこと）
* **サンドボックスでテストする** — 本番で使う前に、テストコースで LTI 連携をテストしてください
* **パフォーマンスを監視する** — 外部ツールはネットワーク依存を増やします。ツールが応答性と信頼性を備えていることを確認してください。
