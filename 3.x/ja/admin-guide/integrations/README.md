これらの多くはプラグインを通じて有効化されます。本ガイドの少し先にある該当セクションをご確認ください。

* **[ビデオ会議](video-conferencing.md)** — BigBlueButton および Zoom
* **[LTI 1.3](lti.md)** — 外部学習ツールの接続
* **[xAPI](xapi.md)** — 学習体験のトラッキング
* **[OnlyOffice](onlyoffice.md)** — 共同ドキュメント編集
* **[AI 設定](ai-configuration.md)** — AI 搭載機能向けの AI プロバイダーの設定
