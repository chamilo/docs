# xAPI

**xAPI**（Experience API、Tin Can API としても知られる）は、学習体験を追跡するための標準です。Chamilo は xAPI ステートメントの生成と取り込みの両方に対応しています。

## xAPI の役割

xAPI は学習活動を「Actor が Object に対して Verb を行った」という形式の **ステートメント** として追跡します。例:

* 「Jane が Module 1 を完了した」
* 「John が Final Exam で 85% を得点した」
* 「Maria が Introduction Video を視聴した」

これらのステートメントは **Learning Record Store (LRS)** に保存され、学習活動の包括的な記録を提供します。

## 設定

1. プラットフォーム設定で **LRS エンドポイント** を設定します:
   * **LRS URL** — Learning Record Store のアドレス
   * **LRS authentication** — LRS へデータを送信するための認証情報
2. 対象の活動について xAPI 追跡を有効にします

## Chamilo が xAPI で追跡する内容

Chamilo は次の項目について xAPI ステートメントを生成できます:

* コースへのアクセスと完了
* 演習の受験と得点
* 学習パス項目の進捗
* ポートフォリオ項目

その他のツール（ドキュメントやフォーラムなど）は、現在プラグインから xAPI イベントとしては発行されません。

## 利用事例

* **クロスプラットフォーム追跡** — 複数のツールやプラットフォームにわたる学習活動を、単一の LRS で追跡する
* **高度な分析** — LRS の分析ツールを用い、Chamilo 組み込みレポートを超える洞察を得る
* **コンプライアンス報告** — 規制要件に対応するため、研修完了の監査証跡を生成する
