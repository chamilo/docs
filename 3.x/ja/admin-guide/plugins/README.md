# プラグイン

プラグインは、コアコードを変更することなく Chamilo の機能を拡張します。Chamilo 3.0 には、必要に応じて有効化できる 50 を超えるプラグインが同梱されています。

## プラグインブロック

管理ダッシュボードには、本章の一般的なプラグイン管理とは別に、独自の **プラグイン** ブロックもあります。インストール済みのすべてのプラグインが一覧表示されるわけではなく、設定で管理メニュー領域に表示するよう宣言されているものだけが対象となり、そのような各プラグインについて、ダッシュボード上からそれぞれの管理ページへ直接ショートカットできます。

![管理ダッシュボード上のプラグインブロック。管理メニューに表示するよう設定されたインストール済みプラグインへのショートカットが一覧表示されています](/.gitbook/assets/admin-plugins-block.png)

有効化したプラグインがここに表示されない場合でも、それは想定どおりの動作です。そのプラグインが管理メニュー領域向けに自身を宣言していないという意味であり、不具合ではありません。ダッシュボードに表示されるかどうかにかかわらず、インストール済みプラグインの完全な一覧については、[プラグインの管理](managing-plugins.md) を参照してください。
