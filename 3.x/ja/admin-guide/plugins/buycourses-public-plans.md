# BuyCourses の公開プランとプロモーションプラン

**BuyCourses** プラグインは、外部の提供内容へ誘導するプロモーションカードと並べて、公開の無料プランを表示できます。これは、プラグインの有料コース／セッション購入フローおよび定期サービス決済の設定とは別の機能です。

## 公開プランの設定

1. BuyCourses の管理領域と、その公開プランカードエディターを開きます。
2. **Free** プランの下で、**Show free** を有効にするかどうかを選択します。
3. 言語タブを使用して、無料プランの翻訳済みタイトル、説明、機能一覧を入力します。
4. 必要に応じてプロモーションカードを追加します。各カードの有効状態、位置、ターゲット URL、任意の画像 URL、および翻訳済みのタイトル、説明、機能、ボタンテキストを設定します。
5. 保存し、利用可能なプレビュー／カタログリンクを使用して、設定済みの各言語での公開表示を確認します。

エディターは、複数言語の翻訳済みコンテンツを保存します。プロモーションカードは**外部オファーへのリンク**であり、完了した支払いの証明や、Chamilo における自動サブスクリプションではありません。

## コース作成の上限

無料プランは、プラットフォームの標準的なコース作成上限を使用します。BuyCourses は、標準のコース作成枠と有料のコース作成枠を区別します。有限の上限が設定されている場合、コース作成インターフェースは使用状況と進捗を表示できます。無制限プランでは、パーセンテージ表示は不要です。

標準枠のみを持つアカウントと、該当する有料枠を持つアカウントで上限をテストしてください。公開プロモーションカードが、サーバー側のコース作成権限を回避することはあってはなりません。

## 決済の動作

公開プランカードは、BTCPay、Stripe、PayPal、またはプラグインに確立されているコース購入および定期サービスフローに代わるものではありません。既存の BuyCourses 設定で決済ゲートウェイの管理とテストを継続してください。

[BuyCourses: 決済と定期サービス](buycourses.md)を参照してください。実装: [PR #9369](https://github.com/chamilo/chamilo-lms/pull/9369)。
