# サポートボット（決定木アシスタント）

**サポートボット**は、固定の決定木から構築される設定可能なヘルプアシスタントです。[issue #8754](https://github.com/chamilo/chamilo-lms/issues/8754) に対応するため、[PR #9224](https://github.com/chamilo/chamilo-lms/pull/9224) で実装されました。これは**生成AIチャットボットではありません**。管理者が質問と選択可能な回答を作成し、利用者を説明、ページ、またはサポートチケットへ導きます。

## 有効化する

1. **管理 > 設定 > チケット** で、`ticket.ticket_support_bot_enabled` を有効にします（既定では無効）。
2. **管理 > サポートボット** を開き、**下書き**の決定木を作成します。タイトルと、選択肢を持つエントリーノードを少なくとも1つ指定します。
3. 各ノードの質問または情報を定義し、選択肢を次のアクションにリンクします。
4. 有効なツリーを公開します。有効なエントリーノードと選択可能な選択肢を持つ公開済みツリーのみが利用者に提供されます。

エンジンは現在のアクセスURLに対応する公開済みツリーを選択します。したがって、その利用可否はポータル単位です。ツリーを管理するには、管理者に `ROLE_ADMIN` が必要です。

## サポートフローを設計する

各選択肢は、次の4つのアクションのいずれかを実行できます。

| アクション | 結果 |
| --- | --- |
| **別のノードへ移動** | 同じツリー内の別の質問で会話を続ける |
| **リンクを開く** | 同一サイトの相対パスを使って Chamilo ページへリンクする（例: `/tickets`） |
| **会話を終了** | 問題を解決済みとしてマークし、必要に応じて終了メッセージを表示する |
| **サポートチケットを作成** | 会話をチケットシステムへエスカレーションする |

チケットへのエスカレーションでは、**既定のチケットプロジェクト**と、そのプロジェクトに属するカテゴリを選択します。コースが必須のカテゴリは、このサポートボットのエスカレーションには使用できません。作成されたチケットには利用者の決定木の記録が含まれるため、サポート担当者はエスカレーションに至った選択を確認できます。

エディターは公開前にツリー構造を検証します。**公開済み**および**アーカイブ済み**のバージョンは読み取り専用です。新しい編集可能な下書きを作成するには **複製** を使用します。代替版を公開すると、同じスコープで以前に公開されていたバージョンがアーカイブされます。一覧から、管理者はツリーのインポートまたはエクスポート、および会話履歴の確認もできます。公開済みツリーは削除前にアーカイブする必要があり、会話履歴のあるツリーは削除できません。

## 例のインポートと会話の確認

**管理 > サポートボット** を開き、**インポート** を選択します。インポートダイアログには **JSON の例をダウンロード** と **CSV の例をダウンロード** があります。サンプルをダウンロードし、質問と選択肢を独自のものに置き換えてから、編集した `.json` または `.csv` ファイルを選択してインポートします。インポートされたすべてのツリーは **新しい下書き** として開始されます。内容を確認し、準備ができたら明示的に公開してください。

例には既存のチケットプロジェクトは不要です。ワークフローでチケットを作成する場合は、インポート後に必要なプロジェクトと使用可能なカテゴリを設定してください。

ツリー一覧で **会話を表示** を使用すると、会話数がゼロのツリーを含め、特定のツリーの会話ログを確認できます。会話履歴は、該当する利用者とポータルの範囲に限定されます。[PR #9419](https://github.com/chamilo/chamilo-lms/pull/9419) を参照してください。

## 利用者のアクセス方法

設定が有効で、ポータルに有効な公開済みツリーがある場合、サインインした利用者はドックされたチャットに **サポートボット** の連絡先を表示します。利用者は提示された選択肢を選んで回答します。ボットは会話を解決したり、同一サイトのページを開いたり、チケットを作成してそのリンクを表示したりできます。利用者は、以前の会話が終了した後に新しい会話を開始できます。

これは、自由形式の学習に関する質問に応答する **AIチューター** とは別の機能です。サポートボットは、管理者が設定した経路と選択肢のみに従います。

## トラブルシューティングとセキュリティ

* **チャットにボットが表示されない:** チケット設定、現在のポータル向けにツリーが公開されていること、およびそのエントリーノードに選択肢があることを確認してください。
* **公開できない:** 下書き内の欠落ノード、未解決の宛先ノード、無効なアクションを確認してください。
* **チケットを作成できない:** 選択したチケットプロジェクトとカテゴリを確認してください。コース必須のチケットカテゴリは使用しないでください。
* **過去の会話が見つからない:** 管理者は対応するツリーから会話履歴を確認できます。会話は利用者とアクセスURLに紐づいています。

関連する設定については、[チケット設定](platform-settings/ticket-settings.md) を参照してください。
