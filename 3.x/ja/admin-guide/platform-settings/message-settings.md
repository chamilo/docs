# メッセージング設定

**メッセージング / 受信箱** システムの動作です。

これらの設定には **管理 > 設定 > メッセージング** からアクセスします。このカテゴリには **7 件の設定** が含まれ、以下にプラットフォームの設定フィクスチャ（`SettingsCurrentFixtures.php`）に同梱されているタイトルとコメントとともに示します。

> コード上の変数名は等幅フォントで示しています。API 経由でスクリプトする場合や、[`config/settings_override.yaml`](https://github.com/chamilo/chamilo-lms/wiki/Configurations#configsettings_overridesyaml) を編集してグローバルに変更する場合に使用してください。

## 設定

### `allow_message_tool`

**内部メッセージングツール**

内部メッセージングツールを有効にすると、ユーザーはプラットフォーム上の他のユーザーにメッセージを送信でき、メッセージ受信箱を利用できます。

*デフォルト: `true`*

### `allow_send_message_to_all_platform_users`

**プラットフォーム上の任意のユーザーへのメッセージ送信を許可**

友人や現在オンラインのユーザーに限らず、プラットフォーム上の任意のユーザーにメッセージを送信できるようにします。

*デフォルト: `false`*

### `allow_user_message_tracking`

**管理者が個人メッセージを閲覧できる**

教師と学習者の間の個人メッセージを管理者が閲覧できるようにします。プライバシー保護に影響する可能性があるため、利用規約に注記を含めてください。

*デフォルト: `false`*


### `filter_interactivity_messages`

**教師はセッション期間内のみ学習者のメッセージにアクセスできる**

教師と学習者の間のメッセージを、セッションの開始日と終了日の間に限定してフィルタします。

*デフォルト: `false`*


### `message_max_upload_filesize`

**メッセージにおける最大アップロードファイルサイズ**

メッセージングツールにおけるファイルアップロードの最大サイズ（バイト単位）

*デフォルト: `20971520`*

### `private_messages_about_user`

**学習者に関する教師間のプライベートメッセージを許可**

当該ユーザーのトラッキングページから、教師／上司がそのユーザーについてメッセージをやり取りできるようにします。

*デフォルト: `false`*


### `private_messages_about_user_visible_to_user`

**学習者が自分に関する教師間のメッセージを閲覧できるようにする**

ユーザーに関するメッセージのやり取りが有効な場合、このオプションにより該当ユーザーがそのメッセージを閲覧できるようにします。組織が遵守する必要のある透明性の規則に対応するためです。

*デフォルト: `false`*
