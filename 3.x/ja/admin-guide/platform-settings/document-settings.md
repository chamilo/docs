# ドキュメント設定

コースの **ドキュメント** ツールの動作 — アップロード、許可する拡張子、共有、テンプレート。

これらの設定は **管理 > 設定 > ドキュメント** からアクセスします。このカテゴリには **29 件の設定** があり、以下にプラットフォームの設定フィクスチャ（`SettingsCurrentFixtures.php`）に同梱されているタイトルとコメントとともに列挙します。

> コード上の変数名は等幅で示しています。API 経由でスクリプトする場合や、[`config/settings_override.yaml`](https://github.com/chamilo/chamilo-lms/wiki/Configurations#configsettings_overridesyaml) を編集してグローバルに変更する場合に使用してください。

## 設定

### `access_url_specific_files`

**URL 固有ファイルを有効にする**

マルチ URL 構成でこの機能を有効にすると、メイン URL に移動し、任意のファイル（ドキュメントツール内）の URL 固有バージョンを提供できます。別の URL から閲覧する際、元のファイルは代替ファイルに置き換えられます。同じコースを何度も再利用しつつ、各 URL をさらにカスタマイズできます。

*デフォルト: `false`*

### `default_document_quotum`

**デフォルトのハードディスク容量**

コースで利用可能なディスク容量はどの程度ですか。特定のコースのクォータは次から上書きできます: プラットフォーム管理 > コース > 変更

*デフォルト: `1000`*


### `default_group_quotum`

**グループで利用可能なディスク容量**

グループのドキュメントツールで利用可能なデフォルトのハードディスク容量はどの程度ですか。

*デフォルト: `250`*


### `documents_custom_cloud_link_list`

**クラウドリンクのホストを厳格なリストに制限する**

ドキュメントツールはクラウド上のファイルへのリンクを統合できます。クラウドサービスの一覧はハードコードされたリストに限定されていますが、独自のサービス／URL の一覧を含む ‘links’ 配列を定義できます。ここで定義した一覧はデフォルトの一覧を置き換えます。

### `documents_default_visibility_defined_in_course`

**コースで定義するドキュメントの可視性**

全コースのデフォルトのドキュメント可視性

*デフォルト: `false`*

### `documents_hide_download_icon`

**ドキュメントのダウンロードアイコンを非表示にする**

ドキュメントツールで、ユーザーからダウンロードアイコンを非表示にします。

*デフォルト: `false`*


### `enable_x_sendfile_headers`

**X-sendfile ヘッダーを有効にする**

Web サーバーレベルで X-sendfile が有効になっており、ブラウザーがそれを利用するために必要なヘッダーを追加したい場合に有効にします。

*デフォルト: `false`*

### `group_category_document_access`

**グループカテゴリ内ドキュメントの共有オプションを有効にする**

有効にすると、管理者はカテゴリごとにドキュメントグループのアクセスと共有権限を設定できます。

*デフォルト: `false`*


### `group_document_access`

**グループドキュメントの共有オプションを有効にする**

有効にすると、ドキュメントの共有とアクセス権限をグループレベルで設定できます。

*デフォルト: `false`*


### `pdf_export_watermark_by_course`

**コースごとの透かし定義を有効にする**

このオプションを有効にすると、教師は自分のコース内のドキュメントに独自の透かしを定義できます。

*デフォルト: `false`*


### `pdf_export_watermark_enable`

**PDF エクスポートの透かしを有効にする**

このオプションを有効にすると、画像またはテキストをアップロードでき、システム上のドキュメントのすべての PDF エクスポートに透かしとして自動的に追加されます。

*デフォルト: `false`*

### `pdf_export_watermark_text`

**PDF 透かしテキスト**

このテキストは、ドキュメントの PDF エクスポートに透かしとして追加されます。

### `permanently_remove_deleted_files`

**削除したファイルは復元できない**

ドキュメントツールでファイルを削除すると、完全に削除されます。ファイルは復元できません

*デフォルト: `false`*

### `permissions_for_new_directories`

**新規ディレクトリのパーミッション**

新規作成するすべてのディレクトリに割り当てるパーミッションを定義できることで、ハッカーが危険なコンテンツをポータルにアップロードする攻撃に対するセキュリティを向上できます。デフォルト設定（0770）で、サーバーに妥当な保護レベルを与えるのに十分です。指定形式は UNIX の Owner-Group-Others と Read-Write-Execute の用語を使用します。

*デフォルト: `0770`*


### `permissions_for_new_files`

**新規ファイルのパーミッション**

新規作成するすべてのファイルに割り当てるパーミッションを定義できることで、ハッカーが危険なコンテンツをポータルにアップロードする攻撃に対するセキュリティを向上できます。デフォルト設定（0550）で、サーバーに妥当な保護レベルを与えるのに十分です。指定形式は UNIX の Owner-Group-Others と Read-Write-Execute の用語を使用します。Oogie を使用する場合は、LibreOffice を起動するユーザーがコースフォルダにファイルを書き込めるよう注意してください。

*デフォルト: `0660`*


### `send_notification_when_document_added`

**ドキュメント追加時に学生へ通知を送信する**

誰かがドキュメントツールに新しい項目を作成するたびに、ユーザーへ通知を送信します。

*デフォルト: `false`*

### `show_default_folders`

**ドキュメントツールに、デフォルトで提供されるマルチメディアリソースを含むすべてのフォルダを表示する**

デフォルトで提供されるファイルを含むマルチメディアファイルフォルダは、ビデオ、音声、画像、Flashアニメーションのカテゴリに整理されており、コース内で利用できます。ドキュメントツール上では非表示にしても、プラットフォームのWebエディタではこれらのリソースを引き続き使用できます。

*デフォルト: `true`*

### `show_documents_preview`

**ドキュメントのプレビューを表示する**

ドキュメントツールでドキュメントのプレビューを表示すると、ドキュメントを表示するためだけに新しいページを読み込む必要がなくなります。ただし、一部の古いブラウザや画面幅が狭い環境では不安定になることがあります。

*デフォルト: `false`*

### `show_users_folders`

**ドキュメントツールにユーザーフォルダを表示する**

このオプションでは、ドキュメントツールを訪問した各ユーザー、またはWebエディタ経由でファイルを送信した各ユーザーに対してシステムが生成するフォルダを、教師に表示するか非表示にするかを設定できます。これらのフォルダを教師に表示すると、教師は学習者に対してフォルダを表示するかどうかを切り替えられ、各学習者がコース内に専用の場所を持てるようになります。そこではドキュメントの保存だけでなく、Webページの作成・編集、PDFへのエクスポート、描画、個人用Webテンプレートの作成、ファイルの送信、ディレクトリやファイルの作成・移動・削除、フォルダからのセキュリティコピーの作成も可能です。コースの各ユーザーは、完全なドキュメントマネージャを利用できます。また、どのユーザーも、ドキュメントツール内の任意のフォルダ（所有者であるかどうかにかかわらず）から表示可能なファイルを、ポートフォリオまたはソーシャルネットワークの個人ドキュメント領域にコピーでき、他のコースでも利用できるようになります。

*デフォルト: `true`*

### `students_download_folders`

**学習者によるディレクトリのダウンロードを許可する**

学習者がドキュメントツールからディレクトリ全体をパックしてダウンロードできるようにします。

*デフォルト: `true`*


### `students_export2pdf`

**学習者がドキュメントツールおよびWikiツールでWebドキュメントをPDF形式にエクスポートすることを許可する**

この機能はデフォルトで有効ですが、サーバー過負荷の乱用がある場合や、特定の学習環境では、すべてのコースで無効にしたい場合があります。

*デフォルト: `true`*

### `thematic_pdf_orientation`

**コース進捗のPDF向き**

コース進捗ツールでは、各要素のPDFを印刷できます。変更するには「portrait」または「landscape」（技術用語）を設定します。

*デフォルト: `landscape`*


### `upload_extensions_blacklist`

**ブラックリスト - 設定**

ブラックリストは、下記のブラックリストに含まれる拡張子のファイルを削除（または名前変更）することで、ファイル拡張子をフィルタリングするために使用されます。拡張子は先頭のドット（.）なしで記述し、セミコロン（;）で区切ります。例:  exe;com;bat;scr;php。拡張子のないファイルは受け入れられます。大文字・小文字は区別されません。

### `upload_extensions_list_type`

**ドキュメントアップロード時のフィルタリングの種類**

ブラックリストまたはホワイトリストによるフィルタリングのどちらを使用するかを指定します。詳細は下記のブラックリストまたはホワイトリストの説明を参照してください。

*デフォルト: `blacklist`*


### `upload_extensions_replace_by`

**置換用拡張子**

フィルタで検出された危険な拡張子を置き換えるために使用する拡張子を入力します。置換によるフィルタを選択した場合にのみ必要です。

*デフォルト: `dangerous`*


### `upload_extensions_skip`

**フィルタリングの動作（スキップ/名前変更）**

スキップを選択した場合、ブラックリストまたはホワイトリストでフィルタされたファイルはシステムにアップロードされません。名前変更を選択した場合、拡張子は拡張子置換設定で定義されたものに置き換えられます。名前変更は実際には保護にはならず、同じ名前で異なる拡張子のファイルが複数存在する場合に名前の衝突を引き起こす可能性があることに注意してください。

*デフォルト: `true`*


### `upload_extensions_whitelist`

**ホワイトリスト - 設定**

ホワイトリストは、下記のホワイトリストに*含まれない*拡張子のファイルを削除（または名前変更）することで、ファイル拡張子をフィルタリングするために使用されます。一般に、より安全ですが制限の強いフィルタリング手法と見なされます。拡張子は先頭のドット（.）なしで記述し、セミコロン（;）で区切ります。例:  htm;html;txt;doc;xls;ppt;jpg;jpeg;gif;sxw。拡張子のないファイルは受け入れられます。大文字・小文字は区別されません。

### `users_copy_files`

**ユーザーがコースから個人ファイル領域へファイルをコピーすることを許可する**

ユーザーがコースから個人ファイル領域へファイルをコピーできるようにします。個人ファイル領域は、ソーシャルネットワーク経由、またはコース外でHTMLエディタ経由で表示されます。

*デフォルト: `true`*


### `video_features`

**ビデオ機能**

Chamiloのビデオプレーヤーで有効にできる追加機能の配列です。オプションには、ビデオの再生速度を変更できる「speed」が含まれます。
