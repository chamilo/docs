# フォーラム設定

コースの **フォーラム** ツールの動作です。

これらの設定には **管理 > 設定 > フォーラム** からアクセスします。このカテゴリには **9 件の設定** があり、以下にプラットフォームの設定フィクスチャ（`SettingsCurrentFixtures.php`）に同梱されているタイトルとコメントとともに示します。

> コード上の変数名は等幅で示しています。API 経由でスクリプトを書く場合や、[`config/settings_override.yaml`](https://github.com/chamilo/chamilo-lms/wiki/Configurations#configsettings_overridesyaml) を編集してグローバルにこれらの設定を変更する必要がある場合に使用してください。

## 設定

### `allow_forum_category_language_filter`

**フォーラムカテゴリの言語フィルター**

フォーラム表示に言語フィルターを追加し、特定の言語で設定されたカテゴリのみを表示します。`forum_category` エンティティの「language」追加フィールドの使用が必要です。

*デフォルト: `false`*

### `allow_forum_post_revisions`

**フォーラム投稿のレビュー**

このオプションを有効にすると、フォーラム内の自分の投稿に対してレビューまたは翻訳を依頼できるようになります。十分に設定すれば、語学学習フォーラムで他のユーザーと協働するために利用できます。

*デフォルト: `false`*

### `community_managers_user_list`

**コミュニティマネージャー一覧**

グローバルフォーラムとして指定された特別なコースにおいて、コミュニティマネージャーとみなすユーザー ID の配列を指定します。コミュニティマネージャーはグローバルフォーラムで追加の権限を持ちます。

### `default_forum_view`

**デフォルトのフォーラム表示**

新しいフォーラムを作成する際のデフォルトの選択肢です。ただし、各トレーナーは個々のフォーラムごとに異なる表示を選択できます。

*デフォルト: `flat`*

### `display_groups_forum_in_general_tool`

**一般フォーラムにグループフォーラムを表示**

コースレベルのフォーラムツールにグループフォーラムを表示します。このオプションはデフォルトで有効です（この場合、グループフォーラム個別の可視性は追加の条件として機能します）。無効にすると、公開かどうかにかかわらず、グループフォーラムはグループツール経由でのみ表示されます。

*デフォルト: `true`*

### `forum_fold_categories`

**フォーラムカテゴリの折りたたみ**

フォーラムカテゴリの折りたたみ／展開を有効にする視覚効果です。

*デフォルト: `false`*

### `global_forums_course_id`

**コースをグローバルフォーラムとして使用**

グローバルフォーラムとして使用するために予約したコースのコース ID（数値）を設定します。これにより、ソーシャルネットワークの「ソーシャルグループ」リンクが、そのコースのフォーラムへのリンクに置き換わります。

*デフォルト: `0`*

### `hide_forum_post_revision_language`

**フォーラム投稿レビューの言語を非表示**

フォーラム投稿のレビューに言語を割り当てる機能を非表示にします。

*デフォルト: `false`*

### `subscribe_users_to_forum_notifications_also_in_base_course`

**ベースコースからのフォーラム通知も対象**

このオプションを有効にすると、セッション経由でコースを受講している場合でも、ベースコースのフォーラムからの通知を有効にします。

*デフォルト: `false`*
