# 管理者の身元設定

プラットフォーム管理者の身元および連絡先情報です。これらの値は、プラットフォームのフッターおよび一部のシステム生成メールに表示されます。

これらの設定には **管理 > 設定 > 管理者の身元** からアクセスします。このカテゴリには **12 件の設定** が含まれ、以下にプラットフォームの設定フィクスチャ（`SettingsCurrentFixtures.php`）に同梱されているタイトルとコメントとともに示します。

> コード上の変数名は等幅で示しています。API 経由でスクリプトする場合や、[`config/settings_override.yaml`](https://github.com/chamilo/chamilo-lms/wiki/Configurations#configsettings_overridesyaml) を編集してグローバルに変更する場合に使用してください。

## 設定

### `administrator_email`

**ポータル管理者: メール**

プラットフォーム管理者のメールアドレス（フッター左側に表示されます）

### `administrator_name`

**ポータル管理者: 名**

プラットフォーム管理者の名（フッター左側に表示されます）

### `administrator_phone`

**ポータル管理者: 電話番号**

プラットフォーム管理者の電話番号（フッター左側に表示されます）

### `administrator_surname`

**ポータル管理者: 姓**

プラットフォーム管理者の姓（フッター左側に表示されます）

### `chamilo_latest_news`

**最新ニュース**

セキュリティ脆弱性やイベントを含む Chamilo の最新ニュースを、管理パネル内で直接取得します。これらのニュースは管理ページを読み込むたびに Chamilo ニュースサーバーで確認され、管理者にのみ表示されます。

*デフォルト: `true`*

### `chamilo_support`

**Chamilo サポートブロック**

プロ向けのヒントと、公式サービスプロバイダーへプロフェッショナルサポートを依頼する簡単な手段を、Chamilo の開発元から直接取得します。このブロックは管理ページに表示され、管理者にのみ見え、管理ページを読み込むたびに更新されます。

*デフォルト: `true`*

### `max_anonymous_users`

**複数の匿名ユーザー**

このオプションを有効にすると、匿名ユーザー向けに複数のシステムユーザーを許可します。一部のコースの公開ショールームとして本プラットフォームを利用する場合に有用です。複数の匿名ユーザーを用意することで、体験期間中のトラッキングが複数ユーザーに対して機能し、データが混在しません（混在するとユーザーが混乱する可能性があります）。

*デフォルト: `0`*

### `redirect_admin_to_courses_list`

**管理者をコース一覧へリダイレクト**

既定の動作では、管理者は管理パネルへ直接送られます（教師と学生はコース一覧またはプラットフォームのホームページへ送られます）。有効にすると、管理者も自身のコース一覧へリダイレクトされます。

*デフォルト: `false`*

### `send_inscription_notification_to_general_admin_only`

**新規ユーザーをグローバル管理者のみに通知**

有効にすると、新規ユーザー登録に関するメール通知はすべての管理者ではなく、グローバル管理者のみが受け取ります。

*デフォルト: `false`*

### `show_link_request_hrm_user`

**ユーザーと HRM の紐付け依頼リンクを表示**

プロフィールページに、人事担当者がユーザーアカウントとの紐付けを依頼できるリンクを表示します。

*デフォルト: `false`*

### `user_status_option_only_for_admin_enabled`

**一般ユーザーからロールを非表示**

このオプションが true で、次の配列で対応するロールが 'true' に設定されている場合、ユーザーのロールを非表示にできます。

*デフォルト: `false`*

### `user_status_option_show_only_for_admin`

**一般ユーザーに非表示にするロールを定義**

'true' に設定されたロールは管理者にのみ表示されます。他のユーザーはそれらを見ることはできません。
