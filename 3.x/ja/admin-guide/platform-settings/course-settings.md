# コース設定

プラットフォーム全体のコースに適用される既定値とポリシー — 公開範囲、作成権限、利用可能なツール、学習者の権限など。

これらの設定は **管理 > 設定 > コース** からアクセスします。このカテゴリには **45 件の設定** があり、以下にプラットフォームの設定フィクスチャ（`SettingsCurrentFixtures.php`）に同梱されているタイトルとコメントとともに列挙します。

> コード上の変数名は等幅フォントで示しています。API 経由でスクリプトする場合や、[`config/settings_override.yaml`](https://github.com/chamilo/chamilo-lms/wiki/Configurations#configsettings_overridesyaml) を編集してグローバルに変更する場合に使用してください。

## 設定

### `active_tools_on_create`

**コース作成時に有効なツール**

コース作成後に *有効* になるツールを選択します。

*既定値:*
```
agenda,announcement,attendance,bbb,blog,chat,course_description,course_progress,customcertificate,document,dropbox,forum,global,glossary,gradebook,group,learnpath,link,mobidico,notebook,notebookteacher,portfolio,positioning,quiz,student_publication,survey,test2pdf,tracking,user,wiki,zoom
```

### `allow_base_course_category`

**トップ URL のコースカテゴリを使用する**

マルチ URL 環境で、管理者と教師がトップ URL のカテゴリを子 URL のコースに割り当てられるようにします。

*既定値: `false`*

### `allow_course_theme`

**コーステーマを許可する**

コースのグラフィカルテーマを許可し、コースで使用するスタイルシートを、Chamilo で利用可能な任意のスタイルシートに変更できるようにします。ユーザーがコースに入ると、コースのスタイルシートがユーザー自身のスタイルシートおよびプラットフォームの既定スタイルシートより優先されます。

*既定値: `true`*

### `allow_public_course_with_no_terms_conditions`

**利用規約付きの公開コースへのアクセス**

このオプションを有効にすると、コースが公開可視で利用規約がある場合、コースが公開である間はそれらの規約が無効になります。

*既定値: `false`*

### `block_registered_users_access_to_open_course_contents`

**認証済みユーザーの公開コースへのアクセスをブロックする**

公開コースのみを表示します。登録ユーザーが各コースに登録していない限り、「オープン」可視性のコースにアクセスできないようにします。

*既定値: `false`*

### `breadcrumbs_course_homepage`

**コースホームページのパンくずリスト**

パンくずリストは、通常ページ左上にある横方向のリンクナビゲーションです。このオプションは、コースのホームページのパンくずリストに表示する内容を選択します。

*既定値: `course_title`*

### `course_about_teacher_name_hide`

**コース詳細ページでコース教師情報を非表示にする**

コース詳細ページで、教師情報を非表示にします。

*既定値: `false`*

### `course_category_code_to_use_as_model`

**コーステンプレートを 1 つのコースカテゴリに制限する**

コーステンプレートとして使用するカテゴリコードを指定します。コース作成時のドロップダウンにはそれらのコースのみが表示され、ユーザーはコースカタログからこのカテゴリのコースを見られません。

### `course_configuration_tool_extra_fields_to_show_and_edit`

**コース設定に表示する追加フィールド**

この配列で定義したフィールドが、コース設定ページに表示されます。

### `course_creation_by_teacher_extra_fields_to_show`

**コース作成フォームに表示する追加フィールド**

この配列で定義したフィールドが、コース作成フォームの追加フィールドとして表示されます。

### `course_creation_donate_link`

**コース作成ページの寄付リンク**

寄付メッセージがリンクするページ（完全な URL）。

### `course_creation_donate_message_show`

**コース作成ページに寄付メッセージを表示する**

教師向けのコース作成ページに、プロジェクトへの寄付を求めるメッセージボックスを追加します。

*既定値: `false`*

### `course_creation_form_hide_course_code`

**コース作成フォームからコースコード欄を削除する**

指定しない場合、コースコードは既定でコースタイトルに基づいて生成されるため、このオプションを有効にするとコース作成フォームからコード欄を完全に削除できます。

*既定値: `false`*

### `course_creation_form_set_course_category_mandatory`

**コースカテゴリを必須にする**

コース作成時に、コースカテゴリを必須設定にします。

*既定値: `false`*

### `course_creation_form_set_extra_fields_mandatory`

**コース作成フォームで必須にする追加フィールド**

この配列で定義したフィールドが、コース作成フォームで必須になります。

### `course_creation_splash_screen`

**コースのスプラッシュ画面**

新しいコースを作成するときにスプラッシュ画面を表示します。

*既定値: `true`*

### `course_creation_use_template`

**新規コースにテンプレートコースを使用する**

プラットフォーム上で作成されるすべての新規コースに、同じテンプレートコース（データベース上のコース数値 ID で識別）を使用する場合に設定します。適切に計画しないと、この設定はディスク使用量に大きな影響を与える可能性がある点に注意してください。テンプレートコースは、教師がコースバックアップツールでコースをコピーした場合と同様に使用されるため、ユーザーコンテンツはコピーされず、教師用教材のみがコピーされます。その他のコースバックアップの規則もすべて適用されます。無効にする場合は空のままにするか、0 に設定してください。

### `course_creation_user_course_extra_field_relation_to_prefill`

**ユーザーのフィールドでコースフィールドを事前入力する**

空でない場合、コース作成処理はユーザープロファイル内の一部のフィールドを参照し、コースに自動入力します。たとえば、デジタルマーケティングを専門とする教師は、作成する各コースに「デジタルマーケティング」フラグを自動的に設定できます。

### `course_hide_tools`

**教師からツールを非表示にする**

教師から非表示にしたいツールをチェックします。これにより、そのツールへのアクセスが禁止されます。

### `course_images_in_courses_list`

**コースのカスタムアイコン**

コース一覧で、デフォルトの緑色の黒板アイコンの代わりにコース画像をコースアイコンとして使用します。

*デフォルト: `true`*

### `course_log_default_extra_fields`

**コース統計ページでデフォルト表示するユーザー追加フィールド**

メインのコース統計ページでデフォルト表示したい追加フィールドの内部 ID を、この配列で設定します。

### `course_log_hide_columns`

**コースログから列を非表示にする**

この配列により、メインのコース統計ページおよび合計時間レポートで非表示にする列を設定できます。

### `course_sequence_valid_only_in_same_session`

**前提条件を同一セッション内でのみ検証する**

有効にすると、コースは現在のセッション内で合格した場合にのみ検証済みとみなされます。無効にすると、他のセッションで合格したコースも、依存するコースのロックを解除します。

*デフォルト: `false`*


### `course_student_info`

**コースの受講者情報の表示**

「マイコース」／「マイセッション」ページで、受講者のスコア、進捗、および／または修了証の取得に関する追加情報を表示します。

### `course_validation`

**コースの承認**

「コースの承認」機能が有効な場合、教師は単独でコースを作成できません。教師はコース申請を記入します。プラットフォーム管理者が申請を確認し、承認または却下します。<br />この機能は自動メール送信に依存します。Chamilo がメールサーバーにアクセスし、専用のメールアカウントを使用するよう設定してください。

*デフォルト: `false`*


### `course_validation_terms_and_conditions_url`

**コース承認 - 利用規約へのリンク**

コース申請を行う際に有効な「利用規約」文書の URL です。ここにアドレスが設定されている場合、ユーザーはコース申請を送信する前にこれらの利用規約を読み、同意する必要があります。<br />Chamilo の「利用規約」モジュールを有効にし、その URL を使用したい場合は、この設定を空のままにしてください。

### `courses_default_creation_visibility`

**デフォルトのコース公開範囲**

新規コース作成時のデフォルトのコース公開範囲です。

*デフォルト: `2`*


### `display_coursecode_in_courselist`

**コース名にコードを表示する**

コース一覧にコースコードを表示します。

*デフォルト: `false`*


### `display_teacher_in_courselist`

**コース名に教師を表示する**

コース一覧に教師を表示します。

*デフォルト: `true`*


### `enable_tool_introduction`

**ツール紹介を有効にする**

各ツールのホームページで紹介文を有効にします。

*デフォルト: `false`*


### `enable_unsubscribe_button_on_my_course_page`

**「マイコース」に登録解除ボタンを表示する**

「マイコース」ページに、コースの登録を解除するボタンを追加します。

*デフォルト: `false`*

### `example_material_course_creation`

**コース作成時のサンプル教材**

新規コース作成時にサンプル教材を自動的に作成します。

*デフォルト: `true`*


### `hide_course_rating`

**コース評価を非表示にする**

コース評価機能は、デフォルトで複数の場所に表示されます。不要な場合は、このオプションを有効にしてください。

*デフォルト: `false`*

### `hide_course_sidebar`

**サイドバーのコースブロックを非表示にする**

左メニューが表示される画面で、「コース」セクションを表示しません。

*デフォルト: `true`*

### `multiple_access_url_show_shared_course_marker`

**マルチ URL 共有コースマーカーを表示する**

URL 間で共有されているコースにリンクアイコンを追加し、ユーザー（特に教師）がコースコンテンツを編集する際に特別な注意が必要であることを知らせます。

*デフォルト: `false`*

### `my_courses_show_courses_in_user_language_only`

**ユーザーの言語のコースのみ表示する**

有効にすると、ユーザーの言語に設定されていないコースはすべて非表示になります。

*デフォルト: `false`*

### `profiling_filter_adding_users`

**コース登録時にプロフィール項目でユーザーを絞り込む**

教師が、コースへユーザーを登録するページで、追加項目に基づいてユーザーを絞り込めるようにします。

*デフォルト: `false`*


### `resource_sequence_show_dependency_in_course_intro`

**コース紹介に依存関係を表示する**

コースまたはセッションでリソースの順序付けを使用している場合、コースのホームページにそのコースの依存関係を表示します。

*デフォルト: `false`*

### `scorm_cumulative_session_time`

**SCORMの累積セッション時間**

有効にすると、SCORMラーニングパスのセッション時間は累積されます。無効の場合は、最後の更新時刻からのみ計測されます。これはグローバル設定です。新しいラーニングパスの作成時に使用されますが、その後は各ラーニングパスごとに再定義できます。

*デフォルト: `true`*


### `send_email_to_admin_when_create_course`

**コース作成時のメール通知**

教師が新しいコースを作成するたびに、プラットフォーム管理者へメールを送信します。

*デフォルト: `false`*


### `show_course_duration`

**コース期間を表示する**

コースカタログおよびコース一覧で、コースタイトルの横にコース期間を表示します。

*デフォルト: `false`*

### `show_navigation_menu`

**コースナビゲーションメニューを表示する**

ツールへのアクセスを迅速にするナビゲーションメニューを表示します。

*デフォルト: `false`*


### `show_toolshortcuts`

**ツールショートカット**

バナーにツールショートカットを表示しますか？

*デフォルト: `false`*

### `student_view_enabled`

**学習者ビューを有効にする**

教師または管理者が、学習者と同じようにコースを閲覧できる学習者ビューを有効にします。

*デフォルト: `true`*


### `view_grid_courses`

**グリッドレイアウトでコースを表示する**

1行に複数のコースを並べるレイアウトでコースを表示します。無効の場合は、1行に1コースのレイアウトになります。

*デフォルト: `true`*
