# プラットフォーム設定

プラットフォーム全体の識別情報と動作 — 機関名、タイムゾーン、登録ポリシー、オンラインユーザー、パフォーマンスフラグ。

これらの設定には **管理 > 設定 > プラットフォーム** からアクセスします。このカテゴリには **29 件の設定** が含まれ、以下にプラットフォームの設定フィクスチャ（`SettingsCurrentFixtures.php`）に同梱されているタイトルとコメントとともに示します。

> コード上の変数名は等幅フォントで示しています。API 経由でスクリプトする場合や、[`config/settings_override.yaml`](https://github.com/chamilo/chamilo-lms/wiki/Configurations#configsettings_overridesyaml) を編集してグローバルに変更する場合に使用してください。

## 設定

### `allow_my_files`

**「マイファイル」セクションを有効にする**

ユーザーがプラットフォーム上の個人領域にファイルをアップロードできるようにします。

*デフォルト: `true`*

### `chamilo_database_version`

**Chamilo が使用するデータベーススキーマの現在のバージョン**

Chamilo コアのバージョンと照合するため、現在の DB バージョンを表示します。

### `cookie_warning`

**Cookie プライバシー通知**

有効にすると、プラットフォーム上部にバナーを表示し、ユーザー体験の提供に必要な Cookie を使用していることをユーザーに確認してもらいます。バナーはユーザーが簡単に承認して非表示にできます。これにより Chamilo は EU のウェブ Cookie 規制に準拠できます。

*デフォルト: `false`*

### `disable_copy_paste`

**コピー＆ペーストを無効にする**

有効にすると、可能な限りコピー＆ペーストの仕組みを無効にします。制限の厳しい試験環境で有用です。

*デフォルト: `false`*

### `donotlistcampus`

**このキャンパスを chamilo.org に掲載しない**

既定では、Chamilo ポータルは chamilo.org の公開リストに自動登録されます。使用されるのはこのポータルに付けたタイトルのみです（URL や個人データは含まれません）。ポータルのタイトルが表示されないようにするには、このボックスをオンにします。

*デフォルト: `false`*

### `generate_random_login`

**ランダムなユーザー名を生成する**

ユーザーをインポートする（バッチ処理）際、ユーザー名にランダムな文字列を自動生成します。無効の場合、ユーザー名は氏名、またはメールアドレスの接頭辞に基づいて生成されます。

*デフォルト: `false`*

### `hosting_limit_identical_email`

**同一メールアドレスの使用を制限する**

同一のメールアドレスを共有できるアカウントの最大数です。制限を無効にするには 0 に設定します。

*デフォルト: `0`*

### `hosting_limit_users_per_course`

**コースあたりのユーザー数のグローバル上限**

プラットフォーム上の任意の 1 コースに登録できるユーザー（教員を含む）のグローバルな最大数を定義します。制限を無効にするには 0 に設定します。オープンなポータルでコースが過負荷になるのを防ぐのに役立ちます。

*デフォルト: `0`*

### `institution`

**組織名**

組織の名称（ヘッダー右側に表示されます）

*デフォルト: `Chamilo.org`*


### `institution_address`

**機関の住所**

住所

### `institution_url`

**組織の URL（ウェブアドレス）**

機関の URL（ヘッダー右側に表示されるリンク）

*デフォルト: `http://www.chamilo.org`*


### `max_courses_per_user`

**ユーザーあたりのコース数の上限**

教員／トレーナーが作成できるコースの最大数です。制限を無効にするには 0 に設定します。BuyCourses サービスの購入によりユーザー単位で上書きできます。

*デフォルト: `0`*

### `notification_event`

**学生とのより効果的なコミュニケーションチャネルとして通知ツールを有効にする**

重要なプラットフォームイベントに対するポップアップまたはシステム通知を有効にします。

*デフォルト: `false`*

### `pdf_img_dpi`

**PDF エクスポート解像度**

生成される PDF ファイルの解像度（ドット毎インチ、dpi）です。デフォルトは 96 です。値を上げると解像度の高い PDF になりますが、ファイルサイズと生成時間も増加します。

*デフォルト: `96`*

### `platform_logo_url`

**代替プラットフォームロゴの URL**

（リモートの可能性もある）URL を読み込んで Chamilo ロゴを置き換えます。セキュリティポリシーで許可されていることを確認してください。

*デフォルト: `https://chamilo.org`*


### `portfolio_advanced_sharing`

**ポートフォリオの高度な共有を有効にする**

ポートフォリオの投稿とコメントを誰が閲覧できるかを決めます。

*デフォルト: `false`*

### `portfolio_show_base_course_post_in_sessions`

**セッションコースでベースコースの投稿を表示する**

ポートフォリオの投稿とコメントを誰が閲覧できるかを決めます。

*デフォルト: `false`*

### `push_notification_settings`

**プッシュ通知設定（JSON）**

プッシュ通知連携用の JSON 設定です。

### `server_type`

**サーバータイプ**

環境の種類を定義します。「prod」（通常の本番）、「validation」（本番と同様だが統計を報告しない）、または「test」（未翻訳文字列の表示などの開発者ツール付きデバッグモード）。

*デフォルト: `prod`*

### `session_admin_access_to_all_users_on_all_urls`

**セッション管理者がすべての URL 上のすべてのユーザーを閲覧できるようにする**

有効にすると、セッション管理者は現在の URL に関係なく、すべてのアクセス URL からユーザーを検索・一覧表示できます。

*デフォルト: `false`*

### `site_name`

**Eラーニングポータル名**

Chamilo ポータルの名前です（ヘッダーに表示されます）

*Default: `Chamilo site`*


### `timepicker_increment`

**タイムピッカーの増分**

タイムピッカーウィジェットで日時を選択する際の最小時間増分（分単位）です。例えば、課題の提出、テストの利用可能期間、セッションの開始時刻などでは、5分または15分未満の増分はあまり有用でない場合があります。

*Default: `15`*

### `timezone`

**デフォルトのタイムゾーン**

このポータルのデフォルトタイムゾーンを選択します。機能が有効な場合、新規ユーザー、または特定のタイムゾーンをまだ設定していないユーザーに対してタイムゾーンを設定するのに役立ちます。タイムゾーンにより、画面上のすべての時刻関連情報が各ユーザー固有のタイムゾーンで表示されます。

*Default: `Europe/Paris`*


### `unoconv_binaries`

**UNO コンバーターのバイナリ**

追加のエクスポート機能を有効にするため、UNO コンバーターライブラリへのシステムパスを指定します。

*Default: `/usr/bin/unoconv`*


### `use_career_external_id_as_identifier_in_diagrams`

**ダイアグラムで外部キャリア ID を使用する**

キャリアダイアグラムを使用する場合、内部キャリア ID の代わりに追加フィールドを表示します。

*Default: `false`*

### `use_custom_pages`

**カスタムページを使用する**

この機能を有効にすると、ロールごとに特定のログインページを設定できます

*Default: `false`*

### `use_virtual_keyboard`

**仮想キーボードを使用する**

仮想キーボードを表示します。学生がキーボードを持たない物理的な教室で、カンニングを制限するための制限付き試験を設定する場合に有用です。

*Default: `false`*

### `user_status_show_option`

**ロールの表示オプション**

そのロールを表示するか非表示にするかを定義する、role => true/false の配列です。

### `user_status_show_options_enabled`

**ロールの選択的表示**

どのロールを明確に表示し、どれを非表示にするかを配列で定義する機能を有効にします。

*Default: `false`*
