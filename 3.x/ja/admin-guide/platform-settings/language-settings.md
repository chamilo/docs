# 言語設定

利用可能な言語、既定言語、および Chamilo がどの言語を表示するかを決定する仕組みについて説明します。

これらの設定には **管理 > 設定 > 言語** からアクセスします。このカテゴリには **13 件の設定** があり、以下にプラットフォームの設定フィクスチャ（`SettingsCurrentFixtures.php`）に同梱されているタイトルとコメントとともに示します。

> コード上の変数名は等幅フォントで示しています。API 経由でスクリプトを書く場合や、[`config/settings_override.yaml`](https://github.com/chamilo/chamilo-lms/wiki/Configurations#configsettings_overridesyaml) を編集してグローバルにこれらの設定を変更する場合に使用してください。

## 設定

### `allow_course_multiple_languages`

**複数言語コース**

複数の言語で管理されるコースを有効にします。このオプションは、コースページ内に言語セレクターを追加して利用者が簡単に切り替えられるようにし、リモート管理手続きを可能にする 'multiple_language' 追加フィールドをコースに追加します。

*既定値: `false`*


### `allow_use_sub_language`

**下位言語の定義と使用を許可**

このオプションを有効にすると、プラットフォームのインターフェースで使用される各言語用語について、既存の言語を基に拡張した新しい言語としてバリエーションを定義できるようになります。このオプションは管理パネルの言語セクションにあります。

*既定値: `false`*

### `auto_detect_language_custom_pages`

**カスタムページでの言語自動検出を有効化**

カスタムページを使用している場合、利用者のブラウザー言語でページを表示する言語検出器をそこに置くには有効にし、既定のプラットフォーム言語に強制するには無効にします。

*既定値: `true`*


### `language_by_resource` **v3**

**リソースごとの言語**

個々のリソースに特定の言語を割り当てることを許可します。

*既定値: `false`*

### `language_flags_by_country`

**言語フラグ**

言語に国旗を使用します。一部の言語は特定の国に厳密に結びついておらず、一部の利用者に不満を与える可能性があるため、既定では有効になっていません。

*既定値: `false`*


### `language_priority_1`

**最優先言語**

複数の言語コンテキストが設定されている場合に選択される第一言語です。

*既定値: `course_lang`*


### `language_priority_2`

**第二優先言語**

第一優先が利用できない、またはコンテキスト外である場合の二次フォールバック言語です。

*既定値: `user_profil_lang`*


### `language_priority_3`

**第三優先言語**

より高い優先度が失敗した場合の三次言語フォールバックです。

*既定値: `user_selected_lang`*


### `language_priority_4`

**第四優先言語**

優先順位における最後の言語フォールバックオプションです。

*既定値: `platform_lang`*


### `platform_language`

**既定のプラットフォーム言語**

利用者の言語が設定されていない場合に既定で使用される主要言語です。

*既定値: `en`*


### `show_different_course_language`

**コース言語を表示**

ホームページのコース一覧で、コースタイトルの横に各コースの言語を表示します

*既定値: `true`*


### `show_language_selector_in_menu`

**メインメニューの言語スイッチャー**

メインメニューに言語セレクターを表示し、利用者の言語設定を直ちに更新します。学習者が学習のために言語を切り替える必要がある多言語ポータルで有用です。

*既定値: `true`*


### `template_activate_language_filter`

**複数言語の文書テンプレート**

文書テンプレート（プラットフォームまたはコースレベル）を特定の言語向けに設定できるようにします。

*既定値: `false`*
