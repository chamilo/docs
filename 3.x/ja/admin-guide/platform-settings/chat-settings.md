# チャット設定

コースの **チャット** ツールの動作です。

これらの設定には **管理 > 設定 > チャット** からアクセスします。このカテゴリには **5 件の設定** が含まれ、以下にプラットフォームの設定フィクスチャ（`SettingsCurrentFixtures.php`）に同梱されているタイトルとコメントとともに示します。

> コード上の変数名は等幅フォントで示しています。API 経由でスクリプトを書く場合や、[`config/settings_override.yaml`](https://github.com/chamilo/chamilo-lms/wiki/Configurations#configsettings_overridesyaml) を編集してグローバルに設定を変更する場合に使用してください。

## 設定

### `allow_global_chat`

**グローバルチャットを許可**

ユーザー同士でチャットできます

*デフォルト: `false`*

### `course_chat_restrict_to_coach`

**コースチャットをチューターに制限**

学生がコース内で話せる相手をチューターのみに制限します（他の学生とは話せません）。

*デフォルト: `false`*

### `hide_chat_video`

**グローバルチャットのビデオチャットオプションを非表示**

有効にすると、ビデオチャット機能は無効になり、グローバルチャットツールでは利用できなくなります。

*デフォルト: `true`*

### `save_private_conversations_in_documents`

**プライベート会話をドキュメントに保存**

有効にすると、1対1のプライベートチャットメッセージがコースのチャット履歴ドキュメントに複製されます。プライバシーの観点から無効のままにすることを推奨します。

*デフォルト: `false`*

### `show_chat_folder`

**チャット会話の履歴フォルダを表示**

チャットで行われたすべてのセッションを含むフォルダを教師に表示します。教師は学習者に対して表示／非表示を切り替え、リソースとして利用できます

*デフォルト: `true`*
