# Chamilo からのニュース

Chamilo からのニュースは、Chamilo Association からの公式お知らせを取得する小さな読み取り専用パネルです。新しいリリースや、とりわけ適用すべきセキュリティパッチについて知る場所です。

## 表示内容と取得元

このパネルは `version.chamilo.org/c/news/latest.php` からコンテンツを取得し、プラットフォームのインターフェース言語で要求します。プラットフォームが送信するのはその言語コードのみです。この機能のために、プラットフォームの詳細、利用データ、連絡先情報がサーバーから外部に出ることはありません。

## 目的

これは、運用上重要な事柄について管理者に直接届ける Chamilo のチャネルです。新しいバージョンのリリース、そして最も重要なのは **セキュリティパッチ** です。セキュリティパッチを速やかに適用することは、プラットフォームを安全に保つうえで最も効果的な対策の一つです（[セキュリティガイド](../appendix/security-guide.md) を参照）。思い出したときだけ確認するのではなく、このパネルを定期的に確認する価値があります。

このフィードは [バージョンチェック](version-check.md) とは独立して読み込まれます。表示するためにプラットフォームを登録する必要はありません。
