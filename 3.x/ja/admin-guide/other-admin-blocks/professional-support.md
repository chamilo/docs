# プロフェッショナルサポート

プロフェッショナルサポートは、公式の Chamilo サポートサービスを説明する小さな読み取り専用パネルです。コミュニティサポートを超えた有償の支援が組織に必要な場合に役立ちます。

## 表示内容と取得元

このパネルは `version.chamilo.org/c/support/latest.php` からコンテンツを取得し、プラットフォームのインターフェース言語で要求します。プラットフォームが送信するのはその言語コードのみであり、利用状況や設定に関する情報は一切送信されません。

## 目的

このパネルは情報提供および案内を目的としており、コミュニティフォーラムのみに頼るのではなく、契約に基づく認定パートナーを求める組織向けに、Chamilo の公式サービスプロバイダー（コンサルティング、ホスティング、カスタム開発、認定サポート）へ管理者を案内します。公式プロバイダー一覧へ直接リンクする [Chamilo.org Links](chamilo-org-links.md) も参照してください。
