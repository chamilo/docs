# バージョンチェック

バージョンチェックは、お使いの Chamilo インストールが最新かどうかを知らせます。オプトインした場合は、プラットフォームを Chamilo プロジェクトに登録し、集計利用統計に含めることができます。

## 2つのチェックレベル

**未登録（デフォルト状態）:** Chamilo は引き続き `version.chamilo.org` に接続し、インストール済みバージョンを最新リリースと比較しようとします。送信されるのはリクエストそのものだけで、プラットフォームの詳細は送られません。ブロックには、登録によって何が追加されるかを説明する登録フォームに加え、**「バージョンチェックを有効にする」** ボタンと **「キャンパスを公開プラットフォーム一覧から非表示にする」** チェックボックスが表示されます。

**登録済み:** 「バージョンチェックを有効にする」をクリックすると、ローカル設定が2つ切り替わるだけであり、それ自体では何も送信されません。それ以降、このダッシュボードブロックが読み込まれるたびに、プラットフォームは次の内容を含むリクエストを `version.chamilo.org` に送信します。

| 送信されるデータ | 記載されている目的 |
|-----------|-----------------|
| プラットフォームの URL とサイト名 | どのポータルがチェックインしているかを識別する |
| 管理者の連絡先メールアドレス | 重大なセキュリティ問題について Chamilo チームが管理者に連絡できるようにするため（明示的） |
| インストール済みバージョン | 最新かどうかを判定するため |
| コース数、ユーザー数、アクティブユーザー数、セッション数 | `stats.chamilo.org` で個人を特定しない集計統計にまとめるため |
| 組織名とインターフェース言語 | 人口統計的な集計のみ |
| 管理者名 | 送信されるが、コード自体では目的が明確に文書化されていない |
| サーバーの IP アドレス | インストールの世界地図向けにプラットフォームの所在地を概算するため |
| 「キャンパスを一覧に載せない」フラグ、パッケージャー、一意のインスタンス ID | 公開ディレクトリに表示するかどうかを制御し、同一インストールからの繰り返しチェックインを識別する |

**「キャンパスを公開プラットフォーム一覧から非表示にする」** をオフのままにすると、プラットフォームは `version.chamilo.org/community.php` の公開コミュニティ一覧にも表示されます。

## バージョンチェックへのアクセス

このブロックは管理ダッシュボードに直接表示されます。別ページへ移動する必要はありません。

## 有効にすべきか

これは明示的なオプトインであり、トレードオフは単純です。上記の詳細を共有する代わりに、新しいバージョン（セキュリティパッチを含む）が利用可能になったときの自動通知を受け取り、Chamilo の公開導入統計に貢献できます。プラットフォームの詳細を一切共有したくない場合は、「バージョンチェックを有効にする」をクリックしなければ十分です。基本的な最新チェックは登録なしでも実行されます。更新通知は欲しいが公開一覧には載せたくない場合は、登録したうえで「キャンパスを公開プラットフォーム一覧から非表示にする」にチェックを入れてください。
