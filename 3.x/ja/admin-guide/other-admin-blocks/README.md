# その他の管理ブロック

管理ダッシュボードには、設定可能な機能というより情報ウィジェットに近いブロックがいくつかあります。外部リンクのページ、バージョンチェック登録、および chamilo.org からコンテンツを取得する 2 つの小さなパネルです。本章では、それぞれが何であるか、コンテンツの出所、そして一部についてはプラットフォームからデータが送信されるかどうかを説明します。

## 対象内容

* **[Chamilo.org リンク](chamilo-org-links.md)** — 公式 Chamilo リソースへのブックマーク一覧。何も送信しません
* **[バージョンチェック](version-check.md)** — プラットフォームのバージョンと利用状況を chamilo.org に報告し、更新が必要かどうかを知らせるオプトイン登録
* **[プロフェッショナルサポート](professional-support.md)** — 公式の Chamilo サポート提供者を説明する読み取り専用パネル
* **[Chamilo からのニュース](news-from-chamilo.md)** — セキュリティパッチや新リリースを含む公式発表の読み取り専用フィード

以下の各ページでは、chamilo.org に送信されるもの（ある場合）とその理由を明確に述べます。
