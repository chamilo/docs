# コースのインポートとエクスポート

Chamilo は、バックアップ、移行、コンテンツ共有を目的としたコースのインポートおよびエクスポートに対応しています。

これらの機能はコース内にあり、コースホームページ上部の歯車アイコンからアクセスできる **メンテナンス** ツールに配置されています。

## コースのエクスポート

教師は、コースのメンテナンスツールから自身のコースをエクスポートできます。管理者は任意のコースをエクスポートできます。

1. コースに入る
2. **コースメンテナンス** ツールにアクセスする
3. **バックアップを作成** を選択する
4. 含める内容（コンテンツ、ユーザーデータなど）を選択する
5. エクスポートファイルをダウンロードする

エクスポートでは、コースのドキュメント、演習、フォーラム、ラーニングパス、設定を含むパッケージが作成されます。

## コースのインポート

Chamilo のエクスポートファイルからコースをインポートするには:

1. コースに入る
2. **コースメンテナンス** ツールにアクセスする
3. **バックアップのインポート** セクションで、エクスポートファイルをアップロードする
4. 含める内容（コンテンツ、ユーザーデータなど）を選択する
5. インポートオプションを設定する:
   * 既存コンテンツを上書きするかどうか
   * ユーザーデータを含めるかどうか
6. インポートを実行する

## コースのコピー

別のコースの内容を自分のコースにコピーするには、あらかじめコピー元コースとコピー先コースを作成しておく必要があります。

1. コピー先コースに入る
2. **コースメンテナンス** ツールにアクセスする
3. **コースのコピー** セクションで **コピー元** コースを選択する
4. オプションを確認する
5. **続行** をクリックし、指示に従う

## Common Cartridge

Chamilo は、他の学習管理システムとの相互運用性のために **IMS Common Cartridge 1.3**（IMS CC 1.3）規格に対応しています。次の操作が可能です。

* Common Cartridge パッケージ（.imscc ファイル）の **インポート**
* Common Cartridge 形式でのコースコンテンツの **エクスポート**

これにより、Common Cartridge 規格に対応する他のプラットフォーム（Moodle、Canvas、Blackboard など）とのコンテンツ交換が可能になります。

## コースのリサイクル

コースのリサイクル機能は、コースの枠組みだけを残し、その内容を消去できるようにするものです。

## コースの削除

これにより、コースとそのすべてのコンテンツ、およびその中のユーザー活動が完全に消去されます。

コースを完全に削除するには:

1. 対象のコースに入る
2. **コースメンテナンス** ツールにアクセスする
3. **このコースを完全に削除** セクションで、意図を確認するためにコースコードを手動で入力する
4. 確定する

コースはもはや存在しないため、その後ポータルのホームページにリダイレクトされます。

## Moodle のインポート

Chamilo は **Moodle** からのコースバックアップをインポートできます。インポーターは、クイズ、ドキュメント、コース設定を含め、Moodle のコンテンツ構造を Chamilo の形式に変換します。

> **作業進行中。** すでに幅広い範囲をカバーしていますが、Moodle インポーターは現時点ですべての Moodle アクティビティタイプおよびコンテンツ形式をカバーしているわけではありません。インポート完了後に手動調整が必要になる場合がある出発点として扱ってください。インポートまたはエクスポートで失敗・欠落している要素を発見した場合は、上部の **New issue** をクリックし、できるだけ詳しい情報（機密でない場合はコースバックアップ自体を含む）を添えて、[Github space](https://github.com/chamilo/chamilo-lms/issues) からご報告ください。

## ヒント

* **定期的なバックアップ** — 教師に、バックアップとしてコースを定期的にエクスポートするよう促す
* **インポートのテスト** — 他のプラットフォームからコンテンツをインポートする場合は、すべてが正しく転送されたことを確認するため、まず試験用コースでインポートをテストする
* **コンテンツの可搬性** — 他の LMS プラットフォームとコンテンツを共有する必要がある場合は、Common Cartridge 形式を使用する
