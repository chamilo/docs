# デモコース

Chamilo 3.0.0 以降、すべての新規プラットフォームには2つのデモンストレーションコースがインストールされます。これらは Chamilo で何ができるかを示すものであり、それ自体としても有用です。

| コース | コード | 用途 |
|--------|------|------------|
| **AI Act** | `AIACT` | 欧州 AI Act に関係するあらゆる組織。*AI Act Awareness for European Organizations* 学習パスを提供します。 |
| **Using Chamilo** | `USINGCHAMILO` | Chamilo の利用を開始するあらゆる組織。*Getting Started with Chamilo 3.0* 学習パスを提供します。 |

## 含まれる内容

* **両コースは多言語対応です。** それぞれにコンテンツの**26言語版**が含まれており、そのほとんどは AI Act の対象国の言語です。学習者には、[多言語コンテンツ](../../teacher-guide/adding-content/multi-language-content.md)機能（`translate_html` 設定。3.0.0 以降は既定で有効。詳細は [エディター設定](../platform-settings/editor-settings.md) を参照）により、自身のプロフィール言語に一致する版が表示されます。この設定をオフにすると、学習者には自分の言語版だけでなく、すべての言語版が一度に表示されるため、これらのコースを利用する場合は有効のままにしてください。
* **プラットフォームとともにインストールされます。** インストール時に作成され、管理者アカウントが所有者となり、他のコースと同様にコース一覧に表示されます。
* **ログイン済みユーザーに公開されています。** 公開設定は *公開（Open）* に設定されており、コースのホームページには **コース説明（Course description）** と **学習パス（Learning paths）** ツールのみが表示されます。

![マイコースページ。AI Act のデモコースがコースカードとして表示されている](../../.gitbook/assets/demo-courses-list.png)

## 利用方法

* コースが表示されていることを確認したうえで、該当するユーザーを登録するか、コースカタログに追加して、利用者が見つけられるようにします。詳細は [コースの管理](managing-courses.md) を参照してください。
* *AI Act* コースは職員の AI に関する意識向上研修に、*Using Chamilo* コースは新しい教員と学習者のオンボーディングに利用します。
* 変更する前にコースを複製し（[コースのインポートとエクスポート](course-import-export.md) を参照）、原本を参照用に残してください。

## 非表示または削除

不要な場合は、プラットフォームの他の部分に副作用を及ぼすことなく取り除くことができます。

* **非表示にする**: コースを編集し、公開設定を **非表示（Hidden）**（または **非公開（Closed）**）にするか、コースカタログから削除します。コースはプラットフォーム上に残り、後から元に戻せます。
* **削除する**: コース一覧の **削除（Delete）** を使用します。他のコースと同様にこの操作は恒久的であるため、後で必要になる可能性がある場合は、先にコースをエクスポートすることを検討してください。

{% hint style="info" %}
デモコースの削除は安全ですが、その後インターフェイスから再インストールすることはできません。非表示にする方法であれば、元に戻すことができます。
{% endhint %}

## 残しておく理由

組織として研修自体が不要であっても、完成した多言語の学習パス付きコースがどのようなものかを新しい教員に示す最も手早い方法です。多くの管理者は、この目的のために、学習者には非表示にし、教員にのみ表示したままにしています。
