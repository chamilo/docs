# グローバルコース設定ポリシー

プラットフォーム管理者は、コース設定の一元的な既定値を定義し、教員がそれらを上書きできるかどうかを制御できます。ポリシーは、互換性のあるコース固有の設定を維持しつつ、既存のコース機能に適用されます。

## ポリシーページを開く

**メインアクセスURL**で、**管理 > 設定 > コース設定**を開くか、インストール環境の`/admin/settings/course-settings`に移動します。この管理ページは、メインアクセスURL上の権限を持つプラットフォーム管理者専用です。グローバルポリシーの編集にセカンダリポータルを使用しないでください。

## ポリシーを設定する

1. 特定のコース設定キーが必要な場合は、**検索**フィールドを使用します。
2. 各設定について、見出しの下に表示される正確な変数名を確認します。
3. **コース内で編集可能**を選択または解除して、コース編集者がその設定を変更できるかどうかを制御します。
4. **プラットフォームの既定値**を選択または入力します。一部の設定では許可値のドロップダウンが提供され、その他はテキストを受け付けます。
5. 変更を保存し、テストコースで実際の動作を確認します。

異なるカテゴリで同じ変数名を再利用する設定は、必要に応じて別々に表示されます。見た目が似た2つの名前が同じコース機能を制御すると想定しないでください。

## 2つのロールで確認する

管理者として、保存された既定値と、それが編集可能かどうかを確認します。コースの教員として、対応するコース設定を開き、有効な値と編集制限がポリシーと一致することを確認します。可能な場合は、既存のコースと新しいコースの両方でテストします。

グローバルな既定値を変更すると、多くのコースに影響する可能性があります。教員による上書きを無効にする前にその影響を確認し、必要に応じて復元できるよう、以前のポリシー値を記録してください。
