# コースの管理

管理者は、作成者に関係なく、プラットフォーム上のすべてのコースを管理できます。

## コース一覧

![タイトル、コード、カテゴリ、登録ユーザー、公開状態を表示するすべてのコースの一覧](/.gitbook/assets/admin-course-list.png)

管理パネルから **Course list** をクリックすると、すべてのコースが表示されます。一覧には次の情報が含まれます。

* コースのタイトルとコード
* 言語
* カテゴリ
* 公開状態

特定のコースを探すには、**Advanced search** ツールを使用します。

## コースの作成

管理者はコースを作成し、任意の教師に割り当てることができます。

1. 管理パネルから **Add course** をクリックします
2. コースの詳細（タイトル、コード、カテゴリ、言語）を入力します
3. コースに教師を割り当てます
4. 保存します

注: Chamilo 1.11.x では、コースコードがコース URL の一部として表示され、コース作成後に変更することはできませんでした。この動作は 2.x 以降で変わりました。コースコードは URL に表示されなくなり、プラットフォームにとって重要性が下がったため、将来のバージョンでは教師が後からコースコードを変更できるようになる可能性があります。

## 既存コースの管理

一覧からコースを探し、*Actions* 列の管理オプションにアクセスします。

* **Information** — コースに関する情報を表示します
* **Course home** — コースのホームページに直接移動します
* **Reporting** — エンゲージメントとパフォーマンスのデータを確認します
* **Edit** — コースのタイトル、カテゴリ、公開状態、その他の設定を変更します
* **Create a backup** — コースのメンテナンスセクションに移動し、コピーの作成などを行えます
* **Add to catalogue** — このコースをコースカタログに追加します
* **Delete** — コースとそのすべてのコンテンツを完全に削除します

> コースを削除すると、すべてのコンテンツ、学習者データ、成績、追跡情報が永久に削除されます。まずバックアップとしてコースをエクスポートすることを検討してください。

## 一括操作

一覧で複数のコースを選択し、削除などの一括操作を実行できます。コースをエクスポートするには、コースに入り **Maintenance** ツールを使用します。管理画面のコース一覧には一括エクスポート操作はありません。

## コースの公開設定

管理者は、教師が設定した公開状態を上書きできます。

| 公開状態 | 効果 |
|-----------|--------|
| **Public** | 匿名の訪問者を含むすべての人がアクセスできます |
| **Open** | ログイン済みのすべてのユーザーがアクセスできます |
| **Private** | 登録済みのユーザーのみがコースにアクセスできます |
| **Closed** | 教師と管理者を除き、誰もコースにアクセスできません |
| **Hidden** | 管理者を除き、誰もコースを閲覧・アクセスできません |
