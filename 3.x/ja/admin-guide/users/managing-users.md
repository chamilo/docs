# ユーザーの管理

このページでは、ユーザーアカウントの作成、編集、管理といった日常的な作業について説明します。

## ユーザー一覧

![名前、メール、ロール、ステータスの列を持つアカウントが表示されたユーザー一覧](../../.gitbook/assets/admin-user-list.png)

管理パネルから **ユーザー一覧** をクリックすると、プラットフォーム上の全ユーザーが表示されます。一覧には次の項目が表示されます。

* アバター
* 氏名
* ユーザー名
* メールアドレス
* ロール
* 有効／無効のステータス
* 登録日
* 最終ログイン日

**詳細検索** ツールを使って、氏名、メール、ロールなどの条件で特定のユーザーを探せます。

## ユーザーの作成

![氏名、メール、ユーザー名、パスワード、ロール、言語のフィールドがあるユーザー作成フォーム](../../.gitbook/assets/admin-user-create-form.png)

1. 管理パネルから **ユーザーを追加** をクリックします
2. 必須フィールドを入力します:
   * **名** および **姓**
   * **メール** — プラットフォーム上で一意である必要があります
   * **ユーザー名** — ログイン名（一意である必要があります）
   * **パスワード** — 初期パスワードを設定します
   * **ロール** — ユーザーのプラットフォームロール（受講者、講師、管理者など）を選択します
   * **言語** — ユーザーが希望するインターフェース言語
3. 必要に応じて追加フィールドを入力します:
   * 公式コード（例: 組織内の一意な ID）
   * 電話番号
   * 有効期限 — 指定日以降にアカウントを自動的に無効化します
   * 有効／無効のステータス
   * 追加プロフィールフィールド（設定されている場合）
4. 保存します

## ユーザーのインポート

![ユーザーデータを含む CSV または XML ファイルをアップロードするユーザーインポート画面](../../.gitbook/assets/admin-user-import.png)

ユーザーを一括作成する場合は、ファイルからインポートできます。

1. 管理パネルから **ユーザーをインポート** をクリックします
2. ユーザーデータを含む **CSV** または **XML** ファイルをアップロードします
3. ファイルの列を Chamilo のユーザーフィールドに対応付けます
4. 既存ユーザーの扱い（更新またはスキップ）を選択します
5. インポートします

インポートファイルには、少なくとも次の列が必要です: 名、姓、メール、ユーザー名、パスワード。

注: **Status** 列は **Role** の旧称であり、講師は 1、受講者は 5 など、限られた値のみ受け付けます。ロールの細かい調整は、後からユーザーを編集して手動で行う必要があります。

## ユーザーのエクスポート

**ユーザーをエクスポート** をクリックすると、ユーザー一覧を CSV または XML ファイルとしてダウンロードできます。ロール、登録日などの条件で、エクスポートするユーザーを絞り込めます。

## ユーザーの編集

ユーザー一覧でユーザー名をクリックすると、アカウントを編集できます。次の項目を変更できます。

* 個人情報（氏名、メール、電話）
* ロール
* パスワード（リセット）
* 有効／無効のステータス
* 有効期限
* 追加プロフィールフィールド

## ユーザーの削除

プラットフォーム上でコンテンツを作成したユーザー（多くの場合は講師）を削除しようとすると、システムが恒久的な削除を拒否し、そのユーザーが一部のリソースにまだ紐づいている旨の警告を表示することがあります。削除を確定しても、コンテンツ自体は削除されず、データの整合性のため中立的なユーザー（「フォールバックユーザー」と呼びます）に紐づけられます。

これを避けるには、ユーザーの詳細を確認し、担当コースを一つずつ削除してから、ユーザーを削除してください。

## ユーザー操作

| 操作 | 説明 |
|--------|-------------|
| **無効化** | アカウントを削除せずに無効にします。ユーザーはログインできませんが、データは保持されます。 |
| **有効化** | 以前に無効化したアカウントを再度有効にします。 |
| **代理ログイン** | このユーザーとしてプラットフォームにログインします（なりすまし）。トラブルシューティングに便利です。 |
| **匿名化** | EU の GDPR で定義される、アカウントの個人情報をすべて消去します。 |
| **削除** | ユーザーアカウントを論理削除します。**削除済みユーザー** タブから、アカウントと関連データを恒久的に削除できます。 |

> **代理ログイン** は強力な機能です。正当なサポート目的に限り、責任を持って使用してください。

## 一括操作

ユーザー一覧で複数のユーザーを選択し、一括操作を実行できます。

* 複数ユーザーの一括有効化または無効化
* 複数ユーザーの削除
* コースまたはセッションへのユーザー割り当て

## ヒント

* **大規模な登録には CSV インポートを使う** — 研修プログラム開始時に多数のユーザーを受け入れる場合は、CSV ファイルを用意して一括インポートします
* **有効期限を設定する** — 一時的なユーザー（ワークショップ参加者、試用ユーザーなど）には有効期限を設定し、アカウントを自動的に無効化します
* **削除より無効化を優先する** — ユーザーが離任したときは、まずアカウントを無効化します。これにより研修記録が保持されます。データが不要であると確信できる場合にのみ削除してください。
