# ユーザープロファイリング

Chamilo では、標準の氏名、メールアドレス、ロールを超えてユーザーに関する追加情報を取得するため、カスタムのプロフィールフィールド（エクストラフィールド）を定義できます。

## エクストラプロフィールフィールド

![名前、タイプ、表示設定を持つカスタムフィールドが表示されたエクストラプロフィールフィールドの一覧](/.gitbook/assets/admin-extra-fields-list.png)

エクストラフィールドを使うと、組織固有のメタデータを保存できます。例:

* 従業員 ID
* 部署
* 役職
* 所在地／オフィス
* 電話番号
* カスタム識別子

## エクストラフィールドの作成

1. 管理パネルから **Extra fields** または **Profile fields** に移動します
2. **Add** をクリックします
3. フィールドを設定します:
   * **Name** — ユーザーに表示されるフィールドのタイトル
   * **Description** — 任意の説明
   * **Helper text** — 当該フィールドを含む任意のフォームで、フィールドの下に表示されるテキスト
   * **Field type** — テキスト、ドロップダウン、日付、チェックボックスなど
   * **Field label** — プラグイン連携用のフィールド内部名
   * **Possible values** — セレクター型フィールドの場合、選択可能な値
   * **Default value** — 任意のデフォルト値
   * **Visible to self** — ユーザー自身のプロフィール上で、本人にフィールドを表示するかどうか
   * **Visible to others** — プラットフォーム上の他のユーザーにフィールドを表示するかどうか
   * **Can change** — ユーザーが自身のフィールドを自分で変更できるか（管理者のみが変更できるか）
   * **Filter** — セレクター型フィールドの場合、管理画面（例: コースやセッションへのユーザー登録）でフィルターとして含めるかどうか
   * **Order** — フィールドの表示順を管理したい場合、各フィールドに数値の順序を指定する必要があります
   * **Remove on anonymization** — プライバシー規則・法令上重要です。ユーザーが削除されず匿名化された場合、このフィールドを個人識別情報の潜在的な保持者とみなすかどうか
4. 保存します

## フィールドタイプ

エクストラフィールドエンジンは幅広い入力タイプをサポートします。よく使われるものは次のとおりです。

| Type | Description |
|------|-------------|
| **Text** | 1行のテキスト入力 |
| **Textarea** | 複数行のテキスト入力 |
| **Radio** | 単一選択のラジオグループ |
| **Dropdown / Dropdown multiple** | 事前定義された選択肢のリスト（単一または複数選択） |
| **Double select** | 連動する2つのドロップダウン（例: 国 → 都市） |
| **Checkbox** | はい／いいえのトグル |
| **Date / Date and time** | 日付、または日付＋時刻のピッカー |
| **Integer** | 数値入力 |
| **Tag** | 複数の自由形式タグ値 |
| **File** | ファイルアップロードフィールド |
| **Video URL** | 動画を指す URL |
| **Mobile phone number** | 書式付き電話番号フィールド |
| **Timezone** | タイムゾーンピッカー |
| **Social profile** | ソーシャルネットワークのプロフィールへのリンク |
| **Divider** | フォーム内の視覚的な区切り（値なし） |

利用可能なタイプの正確な集合は Chamilo のバージョンに依存します。**Extra fields** 管理ページのフィールドタイプドロップダウンが正となります。

## エクストラフィールドの利用

エクストラフィールドは次の場所に表示されます。

* ユーザー作成（本人に表示する場合）および編集フォーム
* ユーザープロフィールページ（本人に表示する場合）
* ユーザーインポート（CSV インポートにエクストラフィールドの値を含められます）
* エクスポートおよびレポート（エクストラフィールドの値でフィルターまたはグループ化）

## ヒント

* **作成前に計画する** — データ入力後にフィールドタイプを変更すると問題になり得るため、フィールドを作成する前に必要な情報を定義してください
* **一貫性のためにドロップダウンを使う** — 取り得る値が既知の集合である場合、データの一貫性を確保するため、自由テキストではなくドロップダウンを使用してください
* **レポートに活用する** — エクストラフィールドはレポートのフィルターに有用です（例: 「部署 X のユーザーのうち、研修 Y を完了した全員を表示」）
