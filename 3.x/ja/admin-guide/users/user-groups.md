# クラス / ユーザーグループ

管理パネルのクラスは、管理目的でユーザーを整理するために用いるプラットフォーム全体のグループです。コース内で教師が作成するコースレベルのグループとは異なります。

> ユーザーグループと[クラス](../../admin-guide/sessions/classes.md)は同じインターフェースを共有します。唯一の違いは**グループタイプ**の設定です。「クラス」を選ぶとクラス（セッションへの一括登録に使用）が作成され、「ユーザーグループ」を選ぶと内部ソーシャルネットワーク上に独自のスペースを持てる、よりソーシャルなグループが作成されます。セッション登録の詳細については[クラス](../../admin-guide/sessions/classes.md)を参照してください。

## グループの作成

![名前、説明、メンバー数が表示された利用可能なグループのユーザーグループ一覧](../../.gitbook/assets/admin-user-groups-list.png)

1. 管理パネルから **クラス** に移動します
2. **クラスを追加** をクリックします
3. **タイトル** と任意の **説明** を入力します
4. ソーシャルグループにする場合は **ソーシャルグループ** にチェックを入れます。クラスにする場合はチェックを外したままにします。
5. 任意の参照 URL と画像／ロゴを追加します。
6. グループの **権限** を選択します:
   * **オープン** — どのユーザーでも参加できます
   * **クローズド** — 管理者によってユーザーを追加する必要があります
7. メンバーが自分でクラスを離脱できるようにするかどうかをチェックします。
8. 保存します。

## メンバーの追加

1. クラス／ユーザーグループの一覧を開きます
2. ユーザーアイコン **クラスにユーザーを登録** をクリックします
3. 名前、ユーザー名、またはメールでユーザーを検索します
4. 右側の矢印を使って追加するユーザーを選択します
5. 確認ボタンをクリックして保存します

## ユースケース

* **部門の整理** — 部門やチームごとにユーザーをグループ化します
* **一括登録** — グループの全メンバーを一度にコースまたはセッションに追加します
* **対象を絞ったコミュニケーション** — 特定のグループにアナウンスを送信します
* **レポート** — グループで絞り込んだ研修進捗を表示します

## グループの管理

* **編集** — グループ名、説明、または公開設定を変更します
* **メンバーの管理** — メンバーを追加または削除します
* **削除** — グループを削除します（メンバーのアカウントは削除されません）
