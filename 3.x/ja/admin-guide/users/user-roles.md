# ユーザーロール

Chamilo はロールベースの権限システムを使用します。各ユーザーには、プラットフォーム上で閲覧・実行できる内容を決定するロールが割り当てられます。

## プラットフォームレベルのロール

これらのロールは、プラットフォーム全体の機能へのアクセスを制御します。

| ロール |  説明 |
|------|------------|
| **Learner（学習者 / 学生）** | デフォルトのロールです。コースへの登録、学習コンテンツへのアクセス、課題の提出、演習の受験ができます。 |
| **Teacher（教師 / トレーナー）** | コースの作成と管理、コンテンツの追加、学生の採点、コースレベルのレポートの閲覧ができます。 |
| **Sessions Administrator（セッション管理者）** | セッション（期間に基づくコースパッケージ）の作成と管理、セッションへのユーザー登録、チューターの割り当てができます。一般的なプラットフォーム設定にはアクセスできません。 |
| **Human Resources Manager（HRM / 人事管理者）** | 割り当てられたユーザーのトラッキングおよびレポートデータを閲覧できます。コンテンツやプラットフォームを管理せず、従業員研修を監視する必要がある上司向けです。 |
| **Portal Administrator（ポータル管理者）** | すべてのプラットフォーム管理機能にフルアクセスできます。ユーザー、コース、セッション、プラグイン、すべての設定を管理できます。 |
| **Global Administrator（グローバル管理者）** | ポータル管理者と同様ですが、マルチ URL（マルチテナント）構成ではすべてのアクセス URL にアクセスできます。ルート以外の URL に登録されている場合は、その URL のブランチにスコープされます。[Subtree Administrators](../multi-url/access-urls.md#subtree-administrators) を参照してください。 |
| **Anonymous（匿名）** | ログインしていない訪問者向けの特別なロールです。有効になっている場合、公開コースおよびコンテンツにアクセスできます。 |

## コースレベルのロール

コース内では、ユーザーは次のロールを持ちます。

| ロール | 説明 |
|------|-------------|
| **Student（学生）** | デフォルトのコースロールです。コンテンツへのアクセス、演習の受験、課題の提出ができます。 |
| **Course assistant（コースアシスタント）** | コース内で限定的な管理権限を持ちます。コンテンツの管理補助やフォーラムのモデレーションができます。 |
| **Teacher（教師）** | コースを完全に制御できます。コンテンツ、ツール、設定、登録を管理できます。 |

## セッションレベルのロール

セッション内では、追加のロールがあります。

| ロール | 説明 |
|------|-------------|
| **Session tutor（セッションチューター）** | セッション内のすべてのコースを監督します。セッション内のすべてのコースにわたるトラッキングを閲覧できます。 |
| **Course tutor（コースチューター）** | セッション内の特定のコースを担当します。そのセッションにおける当該コースのコンテンツ管理と学習者のトラッキングができます。 |

注: このロールは Chamilo 3.0 より前のバージョンでは「coach」と呼ばれていました。Chamilo 3.0 以降、プラットフォームのインターフェースおよびドキュメント全体で「coach」は「tutor」に置き換えられています。チューターはコースを通じて学習者を支援する人であり、個人コーチではありません。`Configuration settings` 内の設定名は後方互換性のため依然として「coach」を含みます（例: `add_users_by_coach`）が、ラベルは「tutor」と表示されます。

## ロールの割り当て

管理パネルでユーザーアカウントを作成または編集する際に、プラットフォームレベルのロールを選択します。コースおよびセッションのロールは、コースまたはセッションにユーザーを登録するときに割り当てます。

## ロールの階層

権限の高いロールは、権限の低いロールの機能を継承します。

* 管理者は教師ができるすべてのことを実行できます
* 教師は学生ができるすべてのことを実行できます
* セッションレベルのロール（チューター）は、割り当てられたセッション内でのみ追加の機能を提供します

## ヒント

* **最小権限の原則を用いる** — ユーザーには、業務の遂行に必要な最小限のロールを割り当てます
* **委任管理には Sessions Administrators を用いる** — プラットフォーム全体ではなく研修セッションの管理が必要なスタッフには、フル管理者アクセスではなく Sessions Administrator ロールを付与します
* **上司には HRM を用いる** — Human Resources Manager は、コースやプラットフォーム設定を変更する権限なしに研修の進捗を監視できます
* **ロールの作成** — Chamilo 3.x は新しいロール作成のための内部構造を備えていますが、広く公開するにはさらなるテストが不足しています。[Official providers of Chamilo](https://chamilo.org/providers) を通じて有効化できます。
