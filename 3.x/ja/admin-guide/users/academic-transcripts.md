# 成績証明書

Chamiloは、学習者が修了し認定を受けたコースから**非公式の成績証明書**を作成し、権限を持つスタッフが**公式の署名付き成績証明書**を発行できるようにします。この機能は、個別のコース修了証や、その任意のSepoliaテストネット検証とは別のものです。

## 機能を有効にする

**管理 > 構成設定 > 修了証**で、**成績証明書**（`certificate.transcript_enabled`）を有効にします。既定では無効です。プログラム、評価尺度、コース時間、学籍番号、住所、署名者に関する追加設定は、[修了証の設定](../platform-settings/certificate-settings.md#transcript_enabled)で確認してください。

成績証明書は、対象となるコースおよびセッションの**ルート成績表カテゴリ**が生成した修了証を使用します。現在のアクセスURL内にあり、学習者がまだ登録しているコースのみが含まれます。対象となる修了証がないコースは行として含まれません。

表示される最終成績は、一覧に含まれるコースの百分率得点の平均です。GPAは、対応付けられたグレードポイントの加重なし平均です。いずれも、閲覧時または発行時に含まれるコースに依存します。

## 成績証明書の列

| 列 | 内容 |
|--------|---------|
| **コース** | コースコード、またはコースの学科名（`transcript_course_code_source`） |
| **説明** | コースタイトル。セッション内で受講したコースの場合はセッションタイトルも含む |
| **登録** | 学習者がコースまたはセッションに登録した日時 |
| **必要時間** | `transcript_hours_extra_field`で設定されたコース追加フィールドの値、またはコース期間 |
| **修了日** | 修了証の日付 |
| **修了時間** | 学習者がコースに費やした時間。`transcript_completed_hours_are_required_hours`が有効な場合は必要時間 |
| **最終成績** | 修了証の得点 |
| **評価** | その得点に対応する`transcript_grading_scale`の文字評価 |

## 学習者の成績証明書にアクセスする

1. **管理 > ユーザー > ユーザー一覧**に移動し、学習者を探します。機能が有効な場合、権限を持つ管理者およびセッション管理者には**成績証明書**アクションが表示されます。
2. または、対象となる学習者のグローバルレポート詳細ページから**成績証明書**アクションを使用します。
3. 学習者のコース一覧、評価、日付、時間、最終成績、GPAを確認します。
4. 学習者の現在の記録から作成されたPDFを取得するには、**非公式の成績証明書をダウンロード**を選択します。

成績証明書ページは、その学習者の記録へのアクセスを許可されたユーザーに対して、`/transcript?userId=<user-id>`からも直接利用できます。URLやユーザーIDを知っていることを権限とみなさないでください。アクセスはサーバー側で確認されます。

学習者は**自分自身**の成績証明書を閲覧できますが、公式の成績証明書を発行または取り消すことはできません。発行を許可されるのは次のとおりです。

* 管理対象のユーザー／アクセスURLの範囲内で操作するプラットフォーム／ポータル管理者。
* 担当する学習者に対する人事管理者。
* 自ら管理するセッションに登録されている学習者に対するセッション管理者。

これらの権限は学習者ごとに評価されます。スタッフの役割を持っているだけでは、すべての成績証明書へのアクセスは付与されません。

## 公式の成績証明書を発行して検証する

1. 権限のある学習者の成績証明書ページで、現在表示されているコース、成績、個人情報を確認します。
2. **公式の成績証明書を発行**を選択して確定します。Chamiloは、その時点の情報の署名付きスナップショットを保存します。
3. 新しい項目が、発行日および発行者とともに**公式の成績証明書**の下に表示されます。
4. 公式PDFを取得するには**ダウンロード**を、公開検証ページを開くには**検証**を使用します。
5. 必要に応じて、権限のある発行者はその公式の成績証明書を**取り消し**できます。その後、検証ページでは取り消されたことが表示されます。

発行された成績証明書はそれぞれ個別に保存されます。新しい版を発行しても、以前の署名済み記録が暗黙的に書き換えられることはありません。検証リンクは`/transcripts/verify/<token>`の形式であり、`.json`応答も提供します。検証リンクを持つ人は、サインインせずに有効性を確認できます。有効な検証では署名済み成績証明書の詳細が開示されるため、これらのリンクは適切に管理してください。無効または取り消された記録は、有効な文書としては提示されません。

![有効な公式成績証明書の公開検証ページ。詳細とコースが表示されている](../../.gitbook/assets/admin-transcript-verification.png)

公式の成績証明書は、機関の署名鍵を用いてChamiloによりデジタル署名されます。**これはブロックチェーン取引ではありません**。Sepolia機能は、成績表の修了証資格情報に関する別のプロセスを文書化しています。

## 署名画像と署名者の詳細

プラットフォーム管理者は、学習者の成績証明書ページの **公式成績証明書の署名** セクションに、**PNG または JPEG** の署名画像をアップロードできます。この画像は現在のアクセス URL に属し、公式 PDF で使用されます。署名者の氏名と肩書は、`certificate.transcript_signatory_name` および `certificate.transcript_signatory_title` から取得されます。

署名画像を管理できるのはプラットフォーム管理者のみです。他の権限を持つ成績証明書発行者には、この権限は自動的には付与されません。機関の署名鍵と非公開の署名画像ストレージは、ポータルのバックアップおよびアクセス制御手順の一環として保護してください。これらはいずれも公開 Web フォルダーの外、`var/certificate-issuer/` に、成績表証明書の資格情報にも署名する鍵とともに保管されます。このフォルダーを[バックアップ](../maintenance/backups.md)に含めてください。含めないと、すでに発行済みのすべての成績証明書と資格情報を検証できなくなります。

## トラブルシューティング

* **成績証明書のリンクが表示されない:** `certificate.transcript_enabled` と現在のユーザーのスコープを確認してください。
* **修了済みコースがない:** 学習者には、条件を満たすルート成績表の証明書と、このアクセス URL 上で一致する現在のコース／セッションへの登録が必要です。
* **学籍番号、時間数、成績評価、またはプログラム名が正しくない:** 公式成績証明書を発行する前に、該当する `certificate.transcript_*` 設定を確認してください。
* **検証で失効または無効と報告される:** その記録を現行の公式成績証明書の証明として再利用しないでください。権限のある担当者は、適切な場合に新しい証明書を発行できます。
