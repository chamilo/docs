# ログイン試行

ログイン試行レポートは、失敗したログイン試行の記録を表示し、ブルートフォースやクレデンシャルスタッフィングのパターンを把握するためのチャートを提供します。

## ログイン試行へのアクセス

管理パネルから、**セキュリティ > ログイン試行** をクリックします。

## 表示内容

![日別試行、上位IP、月別失敗試行、成功対失敗ログイン、時間別試行、日別ユニークIPのチャートと、その後に失敗したログイン試行の表を示すログイン試行ページ](../../.gitbook/assets/admin-security-login-attempts.png)

* **日別試行（過去7日間）** — 失敗した試行の日次件数
* **上位IP（過去30日間）** — 最も多くの試行を発生させたIPアドレス
* **月別失敗試行（過去12か月）** — より長期の傾向
* **成功対失敗（過去30日間）** — 成功したログインと失敗したログインの日次内訳
* **時間別試行（過去7日間）** — 時間帯の分布。自動化／スクリプトによる試行の把握に有用
* **日別ユニークIP（過去30日間）** — 各日にログインを試みた異なるIPの数
* **失敗したログイン試行の表** — 失敗したすべての試行。日付、IPアドレス、試されたユーザー名を含む

チャート上部の **ユーザー名**、**IP**、日付範囲のフィールドを使ってレポートを絞り込めます。

## 関連設定

このレポートは監視ツールです。実際のブルートフォース対策は [セキュリティ設定](../platform-settings/security-settings.md) で構成します。

* **ロックダウン前の最大ログイン試行回数** (`login_max_attempt_before_blocking_account`) — 失敗試行が多すぎるとアカウントをロックします
* **CAPTCHA** (`allow_captcha`) および **CAPTCHA誤入力の許容回数** (`captcha_number_mistakes_to_block_account`) — 自動化された試行を遅らせ、CAPTCHAに繰り返し失敗するアカウントをロックします

サーバーレベルのブルートフォース対策（fail2ban）については、[セキュリティガイド](../appendix/security-guide.md) も参照してください。
