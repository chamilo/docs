# アクティビティ監査

アクティビティ監査レポートでは、イベント種別で絞り込んだ重要な管理およびプラットフォーム上のアクティビティを閲覧できます。これは以前 **トラッキング > 管理アクティビティ監査** から到達できたものと同じ基盤レポートです。主にセキュリティと説明責任のためのツールであるため、現在はセキュリティブロックからも直接リンクされています。

## アクティビティ監査へのアクセス

管理パネルから **セキュリティ > アクティビティ監査** をクリックします。

## 表示内容

![コース、セッション、ユーザー、ソーシャル、メッセージ、リソース、Wiki、その他などのイベント種別カテゴリが一覧され、それぞれを展開して個別のイベント種別を表示できるアクティビティ監査ページ](../../.gitbook/assets/admin-security-activities-audit.png)

イベントは次のカテゴリにグループ化されます。

* **コース** — コースの作成、削除、設定変更
* **セッション** — セッションおよびセッションカテゴリの作成、削除、登録変更
* **ユーザー** — アカウントの作成、削除、パスワード更新、フィールド変更など
* **ソーシャル** — ソーシャルグループの作成、削除、メンバーシップ変更
* **メッセージ** — メッセージデータの変更および削除
* **リソース** — リソースおよびリソースリンクの作成と削除
* **Wiki** — Wiki ページの閲覧
* **その他** — プラグインのアクティビティ、成績表のロック、演習受験の削除、強制ログイン試行、プラットフォームレベルの設定変更など、上記以外のすべて

イベント種別のチップ（例: **強制ログイン試行**）をクリックすると、一致するエントリの表にレポートを絞り込めます。イベント種別一覧の上にある **検索** フィールドで、キーワードによる直接検索もできます。

## ユースケース

* コース、セッション、またはユーザーアカウントを誰がいつ削除したかを調査する
* 特定の管理上の変更（設定の更新、プラグインのインストール）が想定どおりの管理者によって行われたかを確認する
* [ログイン試行](login-attempts.md) レポートとあわせて **強制ログイン試行** イベントを追跡する
