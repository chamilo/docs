# セキュリティ

管理ダッシュボードの **セキュリティ** ブロックは、プラットフォームに組み込まれたセキュリティ監視および監査ツールをまとめたものです。[セキュリティ設定](../platform-settings/security-settings.md) とは別であり、そちらはセキュリティ *ポリシー*（パスワード規則、CAPTCHA、HTTP セキュリティヘッダーなど）を設定します。このブロックは、不審な活動や望ましくない変更をプラットフォーム上で監視する *レポートとツール* を提供します。

![管理ダッシュボードのセキュリティブロック。アクティビティ監査、ログイン試行、Simple IDS、パスワード強度チェッカー、ファイル整合性を一覧表示](/.gitbook/assets/admin-security-block.png)

このブロックは Chamilo 2.0 で 4 つのツールとともに導入され、Chamilo 3.0 で 5 つ目の **ファイル整合性** が追加されました。

## セキュリティブロックへのアクセス

管理パネルでは、**セキュリティ** ブロックは他のダッシュボードブロック（ユーザー、コース、プラットフォーム管理、システムなど）と並んで表示されます。いずれかのリンクをクリックすると、対応するツールが開きます。

## ブロックの内容

* **[アクティビティ監査](activities-audit.md)** — 重要な管理およびプラットフォームイベント（ユーザー、コース、セッション、その他の変更）をイベント種別ごとに閲覧します
* **[ログイン試行](login-attempts.md)** — 失敗および成功したログイン試行を、チャートと検索可能なログで確認します
* **[Simple IDS](simple-ids.md)** — Chamilo 組み込みの軽量侵入検知システムによってフラグが付けられたリクエストを確認します
* **[パスワード強度チェッカー](password-strength-checker.md)** — よく使われるパスワードのリストと一致するパスワードを持つアクティブユーザーをスキャンします
* **[ファイル整合性](file-integrity.md)** *（Chamilo 3.0 で新規）* — インストール済みファイルにおける予期しない追加、変更、削除、または権限変更を検出します

## アクセスできるユーザー

5 つのツールすべてに **ポータル管理者** のアクセスが必要です。ファイル整合性のスキャン、一時停止、再ベースライン操作には加えて **グローバル管理者** のアクセスが必要であり、アラートの一時停止または新しいベースラインの確立には自身のパスワードの再入力が必要です。詳細は [ファイル整合性](file-integrity.md#actions) を参照してください。
