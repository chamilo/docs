# レポートカタログ

レポートカタログはレポートそのものではなく、プラットフォームに登録されているすべてのレポートのディレクトリです。利用可能なレポートと、誰がそれを閲覧できるかを把握するのに役立ちます。

## レポートカタログへのアクセス

管理パネルから、**Analytics > Reports catalog** をクリックします。

## 表示内容

* **レポート一覧** — 登録されている各レポートのタイトル、説明、および正規 URL とレガシー URL
* **ロールマトリックス** — 各レポートにどのロール（Portal Administrator、Global Administrator、Session Administrator、Teacher、Human Resources Manager、Student Boss など）がアクセスできるかを示すビュー
* **権限カテゴリ** — レポートが分類されている権限グループ（例: `reports.platform`、`reports.learning_analytics`、`reports.export`、`reports.security`）

特定のレポートの所在を調べたいときや、あるロール（例: Human Resources Manager）がそのレポートにアクセスできるかどうかを、個々のレポートを確認せずに把握したいときに、このページを利用します。
