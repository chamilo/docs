# グローバル統計

グローバル統計は、プラットフォーム統計のハブです。単一のレポートではなく、トピック別にグループ化されたプラットフォーム全体のレポートのメニューです。

## グローバル統計へのアクセス

管理パネルから、**分析 > グローバル統計** をクリックします。

## 構成

レポートを選択せずにページを開くと、利用可能な統計のメニューが表示され、コース、ユーザー、システム、ソーシャル、セッションにグループ化されています。メニュー項目を選択すると、同じページにそのレポートが読み込まれます。いずれもプラットフォーム全体の管理者専用ビューであり、コースやセッションによるスコープはありません。コースやセッション単位の分析については、[ラーニングアナリティクス](learning-analytics.md) を参照してください。

## コース

* **コース** — コースの総数。コースカテゴリ別に内訳表示
* **ツールアクセス** — ツールアクセスイベントのプラットフォーム全体の件数（お知らせ、ドキュメント、フォーラム、クイズ、チャットなど）
* **ツール別リソース数** — 1つ以上のツールを選び、それらを使用しているすべてのコース/セッションを、リソース数と最終更新日とともに使用量順で表示
* **最終アクセス** — 最終アクセス日付きのコース。設定可能な日数以内に訪問されたものに限定（既定は60日）
* **言語別コース数** — インターフェース言語別にグループ化したコース
* **コース利用状況** — ローリング期間（今日、今週、今月、6か月、1年、2年、全期間）ごとのコース別訪問数。セッション内とセッション外の訪問に分割

## ユーザー

* **ユーザー数** — プラットフォーム全体のトレーナーと学習者の総数、およびコースカテゴリごとの同じ内訳
* **ログイン** — 今日、過去7日、過去31日、全期間のログイン数。総ログイン数とユニークユーザーの両方。最小セッション時間でフィルタ可能
* **ログイン（月）** — 全履歴にわたるカレンダー月ごとの同じログインデータの合計
* **ログイン（日）** — 曜日ごとのログイン合計、および過去7日のみの別内訳
* **ログイン（時）** — 時刻ごとのログイン合計、および過去24時間のみの別内訳
* **ユーザー数（写真）** — プロフィール写真をアップロードしたアクティブアカウント数と、していないアカウント数
* **日付別ログイン** — 選択した日付範囲における各ユーザーの総接続時間（ログインからログアウトまで）。XLS にエクスポート可能
* **一定期間ログインしていない** — 後続ウィンドウ（今日、7日、31日、6か月）内にログインしていないユーザー数、および一度もログインしていないユーザー数
* **ゾンビ** — 最終ログインが指定したカットオフ日以前のアカウント（固定のしきい値はなく、毎回日付を選びます）。任意でアクティブアカウントに限定。一覧のアカウントを直接有効化、無効化、または削除するボタンあり
* **ユーザー統計** — 選択した日付範囲内に登録されたユーザー。完全なプロフィール詳細と要約チャート付き。XLS にエクスポート可能
* **オンラインユーザー** — 現在オンラインのユーザー数と、現在クイズを受験中のユーザー数のライブ件数。それぞれ4つの時間窓（3、5、30、120分）で表示
* **新規ユーザー登録** — 選択した日付範囲の新規登録（範囲が1か月以下なら日次、それ以外は月次でドリルダウン可能）。各アカウントの作成者の内訳も表示
* **日別コース/セッション登録** — 選択した日付範囲における日ごとの登録と登録解除
* **重複ユーザー** — 同じ氏名、メール、または選択したプロフィールフィールド値を共有するアカウントを検出。重複の無効化、有効化、または統合（マージ）が可能。マージすると、残すアカウントに統合されたアカウントは永久に削除されます

## システム

* **ポータルユーザーセッション統計** — 選択した日付範囲について、アクセス URL（マルチ URL ポータルの場合）、セッション、コース別に内訳したユーザー数のグリッド。XLS にエクスポート可能

システム配下にも表示される **四半期レポート** の項目は、[コーポレートレポート](corporate-reports.md) で別途説明しています。

## ソーシャル

* **受信メッセージ数** — ユーザーごとの内部メッセージ受信数
* **送信メッセージ数** — ユーザーごとの内部メッセージ送信数
* **連絡先数** — ユーザーごとのソーシャルネットワーク連絡先（HR/スーパーバイザー型の関係は除く）

## セッション

* **日付別セッション** — 選択した日付範囲内に開始または終了するセッション（任意でステータスでフィルタ）：件数、週あたり平均セッション数、セッションあたり平均ユーザー数、チューターあたり平均セッション数、カテゴリ/言語/ステータス別内訳、コースごとのセッション数テーブル
