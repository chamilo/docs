# ラーニングアナリティクス

ラーニングアナリティクスは、Chamilo のクラシックなトラッキングダッシュボードです（歴史的には「MySpace」または「Reporting」と呼ばれていました）。学習者、コース、セッションのパフォーマンスを追跡するための主要なドリルダウンツールです。

## ラーニングアナリティクスへのアクセス

管理パネルから、**Analytics > Learning analytics** をクリックします。

## 表示内容

* **概要件数** — 学生、教師、人事担当ユーザーの人数、割り当てられたコースとセッション
* **ドリルダウン** — ユーザー、コース、セッションごとの個別ビュー。それぞれ平均滞在時間、平均スコア、進捗を表示
* **CSV エクスポート** — 現在のビューをオフライン分析用にエクスポート

グローバル統計とは異なり、このビューの範囲は閲覧者の役割に応じて変わります。グローバル管理者はプラットフォーム全体のデータを見ますが、教師やセッションチューターが自身のコース内で同等のビューを開いた場合は、自分のコースとセッションのみが表示されます。管理者としてこのダッシュボード項目を使用する場合は、プラットフォーム全体のビューが得られます。

## 関連

学習者のパフォーマンスではなく作業負荷に焦点を当てたレポートについては、教師時間レポートを含む [コーポレートレポート](corporate-reports.md) を参照してください。
