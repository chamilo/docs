# 分析

管理ダッシュボードの **分析** ブロックは、プラットフォーム全体の統計、ラーニングアナリティクス、企業／人事向けレポート、一括エクスポートツールをまとめています。Chamilo のバージョンによっては、ダッシュボード上でこのブロックが **「トラッキング」** と表示されることがありますが、どちらも同じブロックです。本ガイドでは、記録内容を制御する別カテゴリである [トラッキング設定](../platform-settings/tracking-settings.md) との混同を避けるため、一貫して「分析」と呼びます。

## 分析へのアクセス

管理パネルでは、**分析** ブロックが他のダッシュボードブロックと並んで表示されます。いずれかのリンクをクリックすると、対応するレポートが開きます。

## ブロックの内容

* **[グローバル統計](global-statistics.md)** — プラットフォーム全体の統計：コース、ユーザー、ログイン、セッション、ディスク使用量
* **[レポートカタログ](reports-catalog.md)** — 登録されているすべてのレポート、アクセス可能なユーザー、その理由を閲覧
* **[ラーニングアナリティクス](learning-analytics.md)** — 従来のトラッキングダッシュボード：ユーザー、コース、セッションのドリルダウン、滞在時間とスコア平均
* **[コーポレートレポート](corporate-reports.md)** — 四半期サマリー、教師の時間追跡、人事向けのコース／ユーザーレポート
* **[チケット](tickets.md)** — サポートチケット一覧へ直接移動

## アクセスできるユーザー

これらのレポートのほとんどは **ポータル管理者** の権限が必要です。例外はコーポレートレポートで、対象ユーザー向けに設計されているため、**人事マネージャー** および **学生ボス** のロールでも利用できます。
