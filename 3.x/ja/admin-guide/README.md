# 管理ガイド

Chamilo 3.0 管理ガイドへようこそ。本ガイドは、Chamilo インスタンスのインストール、設定、運用を担当するプラットフォーム管理者向けに作成されています。

## 管理者としてできること

Chamilo の管理者として、次の項目を管理します。

* **インストールと設定** — サーバー上に Chamilo をセットアップし、ストレージ、メール、環境設定を構成する
* **ユーザー** — ユーザーアカウント、ロール、権限の作成、インポート、管理
* **コースとセッション** — コース作成の監督、コースカタログの管理、トレーニングセッションの設定
* **プラットフォーム** — 言語、ポータルニュース、グローバルアジェンダ、Pages CMS ツール
* **プラットフォーム設定** — ポータルの動作、セキュリティ、パフォーマンス、機能の利用可否の設定
* **分析** — プラットフォーム統計、ラーニングアナリティクス、企業／人事向けレポート
* **スキル** — コンピテンシーバッジの定義と成績表（グレードブック）結果への紐付け
* **システム** — サーバーメンテナンスツール、セルフアップデート、ストレージ検査、ブランディング
* **ルーム** — 物理的な拠点と予約可能なトレーニングルームの管理
* **セキュリティ** — ログイン試行の監視、フラグ付き侵入試行の確認、パスワード強度のチェック、ファイル整合性の検証
* **プラグイン** — プラットフォーム拡張機能のインストール、設定、管理
* **認証** — 外部ログインシステム（OAuth2、LDAP、CAS、SCIM）の設定
* **連携** — ビデオ会議、LTI ツール、AI プロバイダーなどへの Chamilo の接続
* **メンテナンス** — バックアップの実施、システムの健全性監視、ストレージ管理

## 本ガイドの構成

1. **はじめに** — 管理インターフェースの概要
2. **インストール** — サーバー要件、インストールウィザード、初期設定
3. **ユーザー** — ユーザーアカウント、ロール、グループ、プロフィールの管理
4. **コース** — コース、カテゴリ、インポート／エクスポートの管理
5. **セッション** — 期間限定のトレーニングコホートの編成
6. **プラットフォーム** — 言語、ポータルニュース、グローバルアジェンダ、Pages CMS ツール
7. **プラットフォーム設定** — プラットフォームのあらゆる側面の設定
8. **分析** — 統計、ラーニングアナリティクス、企業／人事向けレポート
9. **スキル** — コンピテンシーバッジと成績表に基づく授与
10. **システム** — サーバーツール、セルフアップデート、ストレージ検査、ブランディング
11. **ルーム** — 拠点と予約可能なトレーニングルーム
12. **セキュリティ** — セキュリティ監視と監査ツール
13. **プラグイン** — プラットフォーム拡張機能の管理
14. **ヘルスチェック** — ライブ構成チェック
15. **その他の管理ブロック** — Chamilo.org リンク、バージョン確認、サポート、ニュース
16. **認証** — 外部認証プロバイダーの設定
17. **連携** — サードパーティサービスの接続
18. **マルチ URL** — 単一インストールから複数ポータルを運用する
19. **パフォーマンスチューニング** — 速度とスケールに向けたプラットフォームの最適化
20. **メンテナンス** — バックアップ、システムステータス、クリーンアップ

## 管理パネルへのアクセス
