# ブランチのフロアプランと教室マップ

Chamilo 3.1 では、フロアプランの画像をブランチに関連付け、その画像上の教室の位置をインタラクティブなポリゴンで示すことができます。この機能は、学習者が割り当てられた教室を見つけるのに役立ちます。地理的な GPS マップでは**ありません**。

## ブランチのフロアプランを添付する

1. **ブランチ**の管理画面を開き、対象のブランチを編集します。
2. **フロアプラン**パネルを探します。
3. 画像を選択またはアップロードし、**フロアプランを添付**（既に存在する場合は **フロアプランを変更**）を選択します。
4. 必要に応じてブランチの変更を保存または確定し、フロアプランの画像が読み込まれることを確認します。

プランがもはや有効でない場合は、どの教室がそれを参照しているかを確認したうえで、**フロアプランを削除**を使用します。信頼できるコンテンツのみをアップロードし、ブランチ管理画面の権限に従ってください。

## 教室の輪郭を描く

1. そのブランチに割り当てられた教室を編集します。
2. 教室フォームで **フロアプラン上の教室** を探します。
3. ポリゴンツールを使用して教室の境界をなぞります。頂点を調整するには **編集** を使用します。すべての点は画像の範囲内に収まっている必要があります。
4. **教室エリアを保存** を選択し、変更を保存するために教室フォームを保存します。
5. 教室ビューアーを開き、位置が正しいことを確認します。マッピングを削除する場合は、**教室エリアをクリア** を使用します。

1つの教室に対して、同時に編集できるポリゴンは1つです。教室のマッピングはブランチレベルの画像とは独立しているため、画像を更新した場合は、既存の教室の境界を確認する必要があることがあります。

## マップの表示箇所

権限を持つユーザーは、コース情報、カレンダーのイベント、出席関連のフローで教室が選択または表示されるときに、教室のフロアプランを閲覧できます。実際に情報を閲覧するロール、特に学生とセッション参加者を用いて、表示を確認してください。

ブランチおよび教室のアクセス権限は、フロアプランのリソースにも適用されます。マルチ URL のインストールでは、マップを公開する前に、正しいポータル／ブランチの分離を確認してください。

[教室の管理](managing-rooms.md)および[教室空き状況ファインダー](room-availability-finder.md)を参照してください。実装: [PR #9321](https://github.com/chamilo/chamilo-lms/pull/9321)、[PR #9451](https://github.com/chamilo/chamilo-lms/pull/9451)。
