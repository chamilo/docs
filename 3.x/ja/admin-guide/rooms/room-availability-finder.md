# 教室空き状況ファインダー

教室空き状況ファインダーはスケジューリングツールです。開始と終了の日時を指定すると、その時間帯に空いている教室とすでに予約されている教室を表示します。

## 教室空き状況ファインダーへのアクセス

管理パネルから **Rooms > Room availability finder** をクリックします。

## 表示内容

開始と終了の日時を選択すると、現在のポータル上のすべての教室が既存の予約と照合され、次の2つのリストに分けられます。

* **Available rooms** — 指定した時間帯で空いている教室。タイトル、ブランチ、階、定員とともに表示されます
* **Occupied rooms** — すでに予約されている教室。競合する予約のタイトルと時間範囲が表示されます

教室が「occupied」になるのは、その時間帯に出欠追跡カレンダーのエントリ、コース、または特定のセッションとコースの組み合わせに割り当てられているためです。つまり、別の予約カレンダーではなく、出欠およびセッションのツールで行われた実際の予約を確認します。これにより、教室またはブレンド型（対面）のセッションベースコースで使用する物理教室の競合チェッカーとして機能します。

教師側からコースに教室を割り当てる方法については、教師ガイドの [ブランチと教室](../../teacher-guide/branches-and-rooms.md) を参照してください。
