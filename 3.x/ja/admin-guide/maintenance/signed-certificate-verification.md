# 署名付き証明書の検証

Chamiloは、成績表の証明書に対して**デジタル署名付き資格情報**を発行でき、任意で資格情報のフィンガープリントを**Sepolia Ethereumテストネットワーク**にアンカーできます。署名および検証ページは、通常のPDF証明書とは異なります。

## 署名付き資格情報を有効にする

**管理 > 設定 > 証明書**で、所属機関がこの機能を使用する場合は `certificate.blockchain_verification_enabled` を有効にしてください。既定では無効です。資格情報を発行するには、ポータルでHTTPSを使用する必要があります。

## 学習者の同意が前提です

証明書の所有者は**マイ証明書**を開き、明示的に**公開を承認**を選択します。同意の対象は、保有者の氏名、コース、得点、発行日を示す公開検証可能な資格情報、および任意でSepolia上のSHA-256フィンガープリントです。承認は自動では行われません。学習者は後から**同意を撤回**を選択できます。撤回は検証ページに表示される有効性に影響しますが、**すでに確定したブロックチェーン上のフィンガープリントを消去することはできません**。

## 発行、検証、失効

直接認証されたプラットフォーム管理者は、所有者が同意した後、成績表の**証明書**一覧から署名付き資格情報を発行できます。生成される検証リンクは `/certificates/verify/{token}` を使用します。`.json` 形式の検証レスポンスも利用できます。このページでは、暗号署名、同意、失効、有効期限、および基となる証明書情報が署名済みのソースと一致しているかどうかを確認します。

資格情報が失効している、同意が撤回されている、証明書が変更されている、または署名が無効である場合、検証機能は有効な資格情報として報告する代わりに、その状態を示します。

## 任意のSepoliaアンカリング

管理者は、対応するブラウザウォレットを使用して**Sepoliaテストネットにアンカー**を選択するか、保留中のトランザクションを照合するために**既存のSepoliaトランザクションを確認**を選択できます。ウォレットはSepolia（チェーンID `11155111`）に接続されている必要があります。アプリケーションは、サーバーで設定された**HTTPS Sepolia RPCエンドポイント**（`CHAMILO_CERTIFICATE_SEPOLIA_RPC_URL`）を使用してトランザクションを確認します。リクエストで指定されたRPC URLは受け付けられません。

アンカーされるのは資格情報のフィンガープリントのみであり、個人データはトランザクションデータとして送信されません。Sepoliaは**テストネット**です。その記録と可用性を、本番品質のパブリックブロックチェーン保証として提示してはなりません。機関の鍵とRPC設定は安全に保管し、鍵の復旧と資格情報の失効手順を計画してください。
