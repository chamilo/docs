# 完了しない学習パス最終項目の処理

学習パスの最終ステップである「Congratulations」ページには、修了証とスキルのブロックが配置されています。このページは、学習者が実際に開いた時点で初めて完了とみなされます。他のすべてのステップを終えていても、その最終ページまで進まない学習者は、進捗が100%の直前で止まったままになります。修了証の取得資格（およびスキルの付与）は学習パスが100%に達することを条件としているため、本来は獲得している修了証やスキルを受け取れません。

```bash
php bin/console chamilo:learning-path:complete-final-items [options]
```

プラットフォーム上のすべての学習パスのうち、最終ステップの種別が **Final item** であるものについて、このコマンドは進捗中（100%未満）の各学習者を確認します。対象は、その学習パスを再利用するすべてのコースおよびすべてのセッションにわたり、他のすべてのステップを完了している学習者です。条件を満たす場合、学習者自身がその項目を開いた場合とまったく同じように最終項目を完了させます。同じ項目閲覧を記録し、同じ進捗の再計算を実行し、実際の訪問時と同じ修了証の生成とスキルの付与を起動します。

`chamilo:gradebook:process-achievement-certificates`（[Achievement Certificates](achievement-certificates.md) を参照）と同様に、このコマンドは上限付きのバッチで動作し、ドライランに対応し、中断されても安全に再開できます。最終項目がすでに完了している学習者は、後続の実行で再び処理されることはありません。

## オプション

| Option                 | Purpose                                                                                                            |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------- |
| `--dry-run`             | 何も完了させずに評価と報告のみを行います。必ず最初に実行してください。                                           |
| `--sender-id=<id>`      | 有効なプラットフォーム管理者の ID。最終項目の完了によって修了証の生成またはスキルの付与が起動される際、リソースの作成者として使用されます。実際の実行（ドライラン以外）では必須です。 |
| `--limit=<n>`           | 1回の実行で完了させる（ドライランでは報告する）最終項目の最大数。`0` は無制限。既定値は `500`。              |
| `--scan-limit=<n>`      | 1回の実行で、すべての学習パスにわたって走査する学習者進捗レコードの最大数。`0` は無制限。既定値は `5000`。 |
| `--batch-size=<n>`      | 1つの学習パス内で、データベースの1バッチあたりに読み込む学習者進捗レコード数。既定値は `50`。                       |
| `--lp-batch-size=<n>`   | データベースの1バッチあたりに読み込む学習パス数。既定値は `50`。                                                            |
| `--after-lp-id=<id>`    | この学習パス ID の後から走査を再開します。                                                                       |

## 例

まずプラットフォーム全体をドライランし、誰が完了対象になるかを確認します。

```bash
php bin/console chamilo:learning-path:complete-final-items --dry-run
```

実際の実行。リソースの作成者として ID 1 の管理者を指定します。

```bash
php bin/console chamilo:learning-path:complete-final-items --sender-id=1
```

学習パス 480 の後から、中断された実行を再開します。

```bash
php bin/console chamilo:learning-path:complete-final-items --sender-id=1 --after-lp-id=480
```

## 終了コード

実際の実行中に、少なくとも1つの最終項目の完了が失敗した場合、コマンドは失敗ステータスで終了します。概要テーブルには学習パス、学習者、および理由が示され、アプリケーションログには例外の全文が記録されます。正しく除外された学習者（最終項目がすでに完了している、または別のステップが未完了である）はエラーではなく、失敗の終了コードの原因にはなりません。

## 完了後の Gradebook スコア

Gradebook テーブルに表示される学習パスのスコアは保存されません。ページが読み込まれるたびに、学習者の現在の進捗からその場で計算されるため、追加の手順なしで直ちに100%が反映されます。

学習者の**修了証**が、100%に達する前にすでに存在していた場合（古い、より低いスコアが埋め込まれている場合）、保存済みスコアと描画された HTML が更新されるのは、このコマンドが最終項目を完了させたときに修了証の再生成自体が成功した場合に限られます。これは実際の訪問が起動するのと同じ呼び出しです。何らかの理由で修了証の生成に失敗した場合（よくある原因については [Achievement Certificates](achievement-certificates.md) を参照。例: ファイルストレージの権限）、学習者の進捗は正しく100%に達し、Gradebook テーブルにもそれが表示されます。更新されないのは修了証だけで、古いスコアが表示されたままになります。このコマンドはすでに100%の学習者を再訪しないため、後続の実行で再試行しません。根本原因を修正したうえで、その修了証を手動で再生成してください（Certificates 一覧の **Generate** 操作）。

`--sender-id` は、この失敗のよくある原因の1つを避けるために用意されています。実際のリクエストの外で最終項目を完了させると、修了証リソースの作成者として記録するログイン中のユーザーが存在せず、作成者がいないと生成は直ちに失敗します。
