# システムステータス

システムステータスページは、Chamilo サーバーが正しく設定されていることを確認し、潜在的な問題を特定するのに役立ちます。

## システムステータスへのアクセス

管理パネルから、**システムステータス**（または **システム情報**）をクリックします。

## 表示内容

![PHP の設定、データベースの状態、ファイルの権限、サーバー情報を示すシステムステータスページ](/.gitbook/assets/admin-system-status.png)

### PHP の設定

* **PHP version** — Chamilo 3.0 は PHP 8.3、8.4、および 8.5 をサポートします
* **Required extensions** — 必要な PHP 拡張機能がすべてインストールされていることを確認します
* **PHP settings** — メモリ制限、アップロード制限、実行時間など、重要な PHP 設定を検証します

### データベースの状態

* **Database connection** — データベースにアクセスできることを確認します
* **Database version** — データベースサーバーのバージョンを表示します

### ファイルの権限

* **Writable directories** — Chamilo が必要なディレクトリ（cache、uploads、logs）に書き込めることを確認します

### サーバー情報

* **Operating system** — サーバー OS の詳細
* **Web server** — Apache、Nginx、またはその他
* **Disk space** — 利用可能なストレージ

## 推奨される確認

次の確認を定期的に実施してください。

* **インストール後** — すべての要件が満たされていることを確認します
* **アップグレード後** — PHP のバージョンと拡張機能が引き続き互換性があることを確認します
* **問題が発生したとき** — トラブルシューティングの際は、まずシステムステータスを確認します
