# セッションカテゴリ

セッションカテゴリは、特に多数のセッションを同時に運用している場合に、セッションの整理に役立ちます。

## カテゴリの作成

1. 管理パネルから **セッションカテゴリ** に移動します
2. **カテゴリを追加** をクリックします
3. **名前** と、任意で開始日／終了日を入力します
4. 保存します

## 利用例

* **プログラム別** — 「リーダーシップ開発」「技術研修」「オンボーディング」
* **期間別** — 「2026年第1四半期」「春学期」「7月バッチ」
* **部署別** — 「エンジニアリング」「営業」「人事」

## カテゴリの管理

* **編集** — カテゴリ名または日付を変更します
* **セッションの割り当て** — セッションの作成時または編集時に、そのカテゴリを選択します
* **削除** — カテゴリを削除します（当該カテゴリ内のセッションは未分類になります）
