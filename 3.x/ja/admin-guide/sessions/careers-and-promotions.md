# キャリアとプロモーション

Chamilo には、学習パスを定義し、構造化されたプログラムを通じた学習者の進捗を追跡できるキャリア管理システムが含まれています。

## キャリア

![名前と説明付きで定義されたキャリアパスを示すキャリア一覧](/.gitbook/assets/admin-careers-list.png)

**キャリア**は、構造化された学習パスを表します。学習者が職業上の目標を達成するためにたどる一連の学習ステップです。

### キャリアの作成

1. 管理パネルから **Careers** に移動します
2. **Create a career** をクリックします
3. **name** と **description** を入力します
4. 保存します

## プロモーション

**プロモーション**は、キャリアを進む学習者のコホート（一括の集団）を表します。同じキャリアパスを同時に進む人々のグループと考えてください。

### セッションとの関連付け

プロモーションを作成したら、セッションを関連付けます。これにより、学習者が完了すべき学習の順序が定義されます。

後からプロモーションを複製し、同じセッションのコピーで次のプロモーションを作成できるようにできます。次のプロモーションをすぐに構築できます。

### プロモーションの作成

1. **Promotions** に移動します
2. **Create a promotion** をクリックします
3. **name** と **description** を入力します
4. **career** に関連付けます
5. プロモーションに **sessions** を割り当てます
6. 保存します

## 全体の関係

* **キャリア**はパスを定義します（例：「ジュニア開発者認定」）
* **プロモーション**はコホートを表します（例：「2026年3月クラス」）
* プロモーション内の **セッション**が実際の学習コンテンツを提供します

## ヒント

* **構造化されたプログラムに使う** — キャリアとプロモーションは、学習者が定義された順序で進む多段階の研修プログラムで最も有用です
* **完了状況を追跡する** — レポートツールを使い、プロモーションがキャリアパスをどのように進んでいるかを監視します
