# セッションの管理

## セッションの作成

![名前、日付、チューター、カテゴリ、公開設定のフィールドがあるセッション作成フォーム](/.gitbook/assets/admin-session-create-form.png)

1. 管理パネルから **セッションを作成** をクリックします
2. セッションの詳細を入力します:
   * **セッション名** — 分かりやすい名前（例: 「2026年春 オンボーディング」）
   * **開始日と終了日** — セッションの実施期間（任意 — 終了日なしのセッションも可能です）。日付は3種類あります: 表示用の日付、学習者のアクセス制限用の日付、チューターのアクセス制限用の日付
   * **セッションチューター** — セッション全体を監督する担当者
   * **カテゴリ** — 整理のためセッションカテゴリに割り当てます
   * **公開設定** — アクセスと一覧表示の動作を制御します
3. **コースを追加** — セッションに含めるコースを1つ以上選択します
4. **学習者を登録** — 個別ユーザーまたはユーザークラスを追加します
5. **コースチューターを割り当て** — 各コースに教師（コースチューター）を割り当てます
6. 保存します

## セッションの日付

セッションでは柔軟な日付設定が可能です:

| 日付 | 目的 |
|------|---------|
| **表示の開始/終了** | 学習者の一覧にセッションが表示される期間 |
| **アクセスの開始/終了** | 学習者が実際にセッションのコンテンツにアクセスできる期間 |
| **チューターアクセスの開始/終了** | チューターがセッションにアクセスできる期間（多くの場合、学習者のアクセスより前に始まり、後まで続きます） |

これにより、学習者が参加する前にセッションを準備し、終了後も採点やレポートのためにチューターのアクセスを維持できます。

## セッション一覧

![名前、日付、コース数、学習者数、ステータスが表示されたすべてのセッションの一覧](/.gitbook/assets/admin-session-list.png)

セッション一覧には、次の情報とともにすべてのセッションが表示されます:

* セッション名
* 開始日と終了日
* ステータス（進行中、今後、過去）

検索とフィルターを使い、名前、日付、カテゴリ、ステータスでセッションを探せます。

## セッションの編集

セッションをクリックして編集します:

* 日付、名前、またはカテゴリの変更
* コースの追加または削除
* コースチューターの変更
* 学習者の追加または削除
* セッションのトラッキングデータの表示

## ユーザーの登録

![個別ユーザー、クラスの追加、または CSV によるインポート用のセッション登録画面](/.gitbook/assets/admin-session-enrollment.png)

セッションへのユーザー登録は次の方法で行えます:

* **個別登録** — 個別ユーザーを検索して追加します
* **クラス登録** — クラス（事前定義されたユーザーのグループ）全体を一度に追加します
* **CSV インポート** — ユーザーとセッションの割り当てを記載したファイルをアップロードします

## セッションへのアクセス

学習者はサイドバーの **マイセッション** から自分のセッションにアクセスします。セッションは次のように整理されます:

* **現在のセッション** — 現在進行中
* **過去のセッション** — 終了済み
* **今後のセッション** — まだ開始していない

## ヒント

* **日付は慎重に計画する** — チューターが準備とフォローアップを行えるよう、チューターのアクセス期間が学習者の期間より長く続くようにします
* **繰り返し登録にはクラスを使う** — 同じグループを頻繁に登録する場合は、クラスを作成してセッションに割り当てます
* **セッションを整理しておく** — カテゴリと分かりやすい命名規則を使い、管理しやすくします
