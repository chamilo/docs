# スキルと評価

ここではスキルが成績表と結び付きます。評価結果とスキルの自動付与をつなぐ橋渡しです。

## スキルと評価へのアクセス

管理パネルから **Skills > Skills and assessments** をクリックします。

## 表示内容

成績表カテゴリの一覧と、それぞれをスキルに関連付けるための操作が表示されます。関連付けると、その成績表カテゴリの合格しきい値に達した学習者には、手動操作なしで対応するスキルが自動的に付与されます。

これはスキルを大規模に付与する推奨方法です。ユーザー一人ひとりにスキルを割り当てるのではなく、該当する成績表カテゴリを一度関連付けるだけで、条件を満たしたすべての学習者に適用されます。成績表カテゴリとしきい値の設定については、[Gradebook (Assessments)](../platform-settings/gradebook-settings.md) を参照してください。
