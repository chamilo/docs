# スキル

管理ダッシュボードの **スキル** ブロックは、プラットフォーム全体でコンピテンシーバッジ（「スキル」）を定義・整理・追跡するためのツールをまとめています。スキルは、学習者が成績表のしきい値に達したとき、特定のコースを完了したときに自動で付与されるほか、教師が手動で付与することもでき、バッジ風のアイコンとレベル（例: Bronze/Silver/Gold）を持たせることができます。

![管理ダッシュボードのスキルブロック。スキルホイール、スキルのインポート、スキルの管理、スキルレベルの管理、スキルランキング、スキルと評価が一覧表示されています](/.gitbook/assets/admin-skills-block.png)

このブロック全体は、**スキルツールを有効にする** 設定（`skill.allow_skills_tool`、設定 > スキル）がオンの場合にのみ表示されます。既定では有効です。

## スキルブロックへのアクセス

管理パネルでは、**スキル** ブロックが他のダッシュボードブロックと並んで表示されます。いずれかのリンクをクリックすると、対応するツールが開きます。

## ブロックの内容

* **[スキルの管理](managing-skills.md)** — スキルの作成、一括インポート、各スキルへのレベル尺度の割り当て
* **[スキルホイール](skills-wheel.md)** — スキルツリー全体のズーム可能な視覚マップ
* **[スキルランキング](skills-ranking.md)** — 獲得スキルによるユーザーのリーダーボード
* **[スキルと評価](skills-assessments.md)** — 成績表カテゴリと、それが付与するスキルの関連付け

## 関連設定

設定 > スキル にある他のいくつかの設定で、このブロックで誰が何をできるかが変わります。

* **HR によるスキル管理を許可** (`allow_hr_skills_management`) — 人事マネージャーユーザーが管理者と並んでスキルを管理できるようにします
* **非公開スキルを許可** (`allow_private_skills`)
* **教師がスキルを割り当て可能** (`skills_teachers_can_assign_skills`)
* **スキルレベルを非表示** (`hide_skill_levels`)
* **スキルホイールでスキルのフルネームを表示** (`show_full_skill_name_on_skill_wheel`)
