# スキルホイール

スキルホイールは、スキルツリー全体をズーム可能なホイール型の図で表示するものです。[スキルの管理](managing-skills.md) のフラットな一覧を閲覧する代わりの視覚的な手段です。

## スキルホイールへのアクセス

管理パネルから **Skills > Skills wheel** をクリックします。

![スキルホイールのページ。検索サイドバー、凡例、セグメント化されたホイールとして表示されたスキルツリー全体](../../.gitbook/assets/admin-skills-wheel.png)

## 表示内容

ホイールの各セグメントはスキルであり、子スキルへと展開できます。セグメントは、そのスキルに成績表がリンクされているかどうか（[スキルと評価](skills-assessments.md) を参照）を示し、特定のユーザーを表示している場合は、そのユーザーがすでに達成しているかどうかも示します。

セグメントをクリックするとズームインして子スキルが表示されます。中央の円をクリックするとズームアウトします。

![「Idiomas」ブランチにズームしたホイール。言語のサブスキルが表示されている](../../.gitbook/assets/admin-skills-wheel-zoom.png)

セグメントを右クリックすると詳細が開きます。説明、親スキル、およびそれを付与するコース（ある場合）です。このダイアログから、管理者はそのスキルの編集、その下への子スキルの作成、または後述のプロファイル検索への追加もできます。

![「Conflict Management」のスキル詳細ダイアログ。説明と、編集、子スキルの作成、検索プロファイルへのスキル追加の操作が表示されている](../../.gitbook/assets/admin-skills-wheel-detail.png)

管理者および Human Resources Manager ユーザーは、ここでもプロファイル検索を利用できます。スキルは「プロファイル」（特定の役割や職務記述に期待されるスキルの集合）にグループ化でき、このページでは取得済みスキルが指定したプロファイルに一致するユーザーを検索できます。役割の準備ができている人の特定や、チーム全体のギャップの把握に役立ちます。
