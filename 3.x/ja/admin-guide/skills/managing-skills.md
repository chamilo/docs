# スキルの管理

このページでは、プラットフォームのスキルカタログを構築するために使用する3つのダッシュボード項目について説明します。スキルの一括インポート、スキル定義そのものの管理、および各スキルへのレベル尺度の割り当てです。

## Skills Import

**Skills > Skills import** では、スキルを1つずつ作成する代わりに、CSV または XML ファイルからスキル階層を一括作成できます。各行には、最低限 `id`、`parent_id`（ツリーを構築するため）、および `title` が必要です。ファイル作成の基になるサンプルテンプレートが用意されています。

## Manage Skills

**Skills > Manage skills** はメインのスキルカタログです。スキルの作成、編集、有効化/無効化、削除を行います。各スキルにはタイトル、短いコード、説明、アイコン、および任意の達成条件の説明（学習者がスキルを獲得するために行う必要があること）があります。スキルは入れ子にできます。スキルは子スキルを持つことができ、それが [Skills Wheel](skills-wheel.md) で可視化されます。

## Manage Skills Levels

**Skills > Manage skills levels** は、より小さな独立した画面です。既存のスキルを一覧表示し、それぞれに **level profile**（名前付きの順序付きレベルセット。例: Bronze/Silver/Gold）を割り当て、そのスキルの測定基準とします。要するに、**Manage skills** でスキルが*何であるか*を定義し、**Manage skills levels** でどの尺度で測定するかを定義します。

## スキルの付与方法

スキルは、次のいずれかの経路でユーザーに付与されます（発行済みスキルとして日付とともに記録されます）。
