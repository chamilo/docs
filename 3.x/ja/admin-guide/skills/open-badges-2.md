# Open Badges 2.0 の発行と検証

Chamilo 3.1 は、習得したスキルに対して **Open Badges 2.0** の資格情報を公開できます。これには、PNG メタデータに焼き込まれたアサーションを含むバッジ画像も含まれます。バッジの検証には、公開されたバッジ、アサーション、および発行者のエンドポイントを使用します。

## 発行者とスキルの設定

1. プラットフォームの**機関名**と有効な**管理者連絡先メールアドレス**を設定します。いずれも発行者プロファイルで必須です。
2. スキルにタイトル、説明、およびバッジの基準を設定します。
3. 必要に応じて、有効な PNG バッジ画像を添付します。スキルにカスタムアセットがない場合、Chamilo は既定のバッジ画像を使用することもできます。
4. 通常のスキルワークフローを通じて、学習者へのスキルの付与または習得の検証を行います。

資格情報は、習得済みスキルの関連に依存します。取り消された、またはもはや習得されていないスキルのアサーションは、取り消されたものとして報告されます。スキルおよびバッジのリソースは、適切なアクセス URL にスコープされます。

## 公開検証データ

各発行には、ホストされたアサーションがあります。関連する URL はアプリケーションの公開ルートから導出され、次のものが含まれます。

- `main/skills/assertion.php?issue=<issue-id>` — 特定のスキル発行に対する JSON アサーション。
- `main/skills/class.php?id=<skill-id>` — 基準および発行者参照を含むバッジクラスのメタデータ。
- `main/skills/issuer.php` — 発行機関のプロファイル。
- `main/skills/image.php?id=<skill-id>` — バッジ画像リソース。

生成される正確な URL は、インストールの公開ベースパスに依存します。アサーションには、平文のメールアドレスを公開する代わりに、受信者のメールアドレスのソルト付きハッシュが含まれ、発行者と習得したスキルを識別します。バッジ PNG には、`openbadges` iTXt チャンク内にアサーションを含めることができます。

## 発行済みバッジの検証

ログイン済みセッションなしで、ホストされたアサーション、バッジクラス、および発行者のエンドポイントを開きます。これらは一貫してリンクされた資格情報を返す必要があります。スキルでサポートされているエクスポートフローを通じて発行済み PNG をダウンロードし、埋め込まれたアサーションがホストされた表現と一致することを確認します。スキルが取り消されている場合は、検証がその取り消し状態を反映していることを確認します。

視覚的なバッジの図柄のみを含む PNG は、有効な資格情報を**証明しません**。Open Badges 2.0 の発行を、関連のない証明書または署名付き PDF の機能と混同しないでください。

[スキルの管理](managing-skills.md)および[署名付き証明書の検証](../maintenance/signed-certificate-verification.md)を参照してください。実装: [PR #9346](https://github.com/chamilo/chamilo-lms/pull/9346)。
