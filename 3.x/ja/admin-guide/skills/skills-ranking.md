# スキルランキング

スキルランキングは、習得したスキルの数に基づいてユーザーを並べたリーダーボードです。

## スキルランキングへのアクセス

管理パネルから、**スキル > スキルランキング** をクリックします。

## 表示内容

アクティブな各ユーザーについて、ランキングには次の情報が表示されます。

* **習得スキル** — 発行されたスキルの合計数。リーダーボードの並び順に使用されます（多い順）
* **現在学習中** — 成績表を通じて、ユーザーが現在登録しているコース（直接登録またはセッション経由）に紐づくスキルの数

このページを使って、最も成果を上げている学習者を一目で把握したり、プラットフォーム全体のスキル習得の活動状況を把握したりできます。
