# Chamilo 3.0 Documentation

**Chamilo 3.0**（オープンソースの e ラーニングプラットフォーム）の公式ドキュメントへようこそ。

本ドキュメントは、対象読者ごとに分かれた 3 つのガイドで構成されています。

* [**Teacher Guide**](teacher-guide/) — 講師・トレーナー向け：コースの作成、コンテンツの追加、学習者の評価、進捗の追跡。
* [**Administration Guide**](admin-guide/) — プラットフォーム管理者向け：Chamilo プラットフォームのインストール、設定、運用。
* [**Developer Guide**](developer-guide/) — 開発者向け：アーキテクチャの理解、プラグインの構築、API の利用、プロジェクトへの貢献。

## What's New in Chamilo 3.0

Chamilo 3.0 は、インターフェースを全面的に刷新し、多くの新機能を備えたメジャーリリースです。

* **Modern interface** — Vue 3 と PrimeVue で構築され、より高速でレスポンシブな体験を提供
* **AI-powered tools** — 演習やラーニングパスの生成、AI 支援による採点
* **REST API** — JWT 認証を備えた API Platform ベースのフル REST API
* **New authentication options** — OAuth2（Azure、Keycloak、Facebook）、SCIM によるユーザープロビジョニング
* **LTI 1.3** — 外部学習ツールとのシームレスな接続
* **Cloud storage** — Azure Blob、AWS S3、Google Cloud Storage のネイティブ対応
* **Color themes** — テーマ対応によるカスタマイズ可能なプラットフォームブランディング
* **OnlyOffice integration** — プラットフォーム内での共同ドキュメント編集
