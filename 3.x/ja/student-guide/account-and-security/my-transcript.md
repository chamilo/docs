# 成績証明書

プラットフォームで成績証明書機能が有効になっている場合、修了し認定されたコースの記録を確認し、非公式の成績証明書をダウンロードできます。所属機関が署名付きの公式成績証明書を発行することもあります。

## 成績証明書を開く

1. サインインし、上部ナビゲーションから **成績証明書** を開きます（このオプションが利用可能な場合）。
2. または、サインインした状態で Chamilo ポータルの `/transcript` にアクセスします。
3. 修了したコース、コースコード、成績、日付、時間数、総合評価、GPA を確認します。
4. **非公式成績証明書をダウンロード** を選択し、現在の記録の PDF を保存します。

この記録は、現在も登録しているコースおよびセッションのルート評価（成績表）によって生成された、対象となる修了証から作成されます。適格な修了証が生成されていない場合、コースが表示されないことがあります。対象となるコースがない場合、Chamilo は **修了したコースはまだありません。** と表示します。

評価の文字および成績平均点（GPA）は、所属機関が設定した評価尺度に依存します。GPA は、管理者が基となるコースおよび成績の記録方法を変更しない限り、一覧に表示されたコースのグレードポイントの非加重平均として算出されます。

## 公式成績証明書

**公式成績証明書** の下に、権限のある職員が発行した署名付き版がある場合、それらを確認できます。各版には発行日と発行者が記録されています。PDF を取得するには **ダウンロード** を、検証ページでデジタル署名を確認するには **検証** を使用します。

公式版は、発行時点の記録のスナップショットです。その後の成績やコースの変更によって **自動的には更新されません**。所属機関は新しい版を発行できます。権限のある職員は古い版を取り消すことができ、その場合、公開検証ページに取り消しが表示されます。

公式成績証明書を自分で発行または取り消すことはできません。新規または訂正された署名付き成績証明書が必要な場合は、所属機関に依頼してください。公開検証リンクは慎重に共有してください。リンクを持つ人は、有効な署名付き成績証明書の詳細を閲覧できる場合があります。

**成績証明書** が表示されない場合、この機能がポータルで有効になっていない可能性があります。管理設定については、[成績証明書](../../admin-guide/users/academic-transcripts.md) を参照してください。
