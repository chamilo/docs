# アカウントとセキュリティ

Chamilo アカウントは、コース、成績、個人データへのアクセスを提供します。安全に保つ価値があります。このセクションでは、学習者として遭遇する可能性のあるアカウント保護機能について説明します。

* **[パスワードのリセット](resetting-your-password.md)** — パスワードを忘れた場合、または変更したい場合の手順
* **[二要素認証](two-factor-authentication.md)** — 管理者が有効にしている場合、アカウントに第二の保護層を追加します
* **[CAPTCHA](captcha.md)** — ログイン、登録、またはパスワード紛失フォームで人間であることを証明するよう求められる理由

ここに記載されている機能のすべてが、ご利用のプラットフォームで必ずしも有効になっているわけではありません。管理者はそれぞれをオンまたはオフにできます。このセクションで説明されているものが表示されない場合、有効になっていない可能性が高いです。
