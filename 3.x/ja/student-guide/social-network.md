# ソーシャルネットワーク

Chamilo には、特定のコースとは独立して、プラットフォーム上の他のユーザーとつながるための組み込みソーシャルネットワークが含まれています。利用できるかどうかは、すべて管理者の設定次第です。既定では有効ですが、プラットフォーム全体で無効にすることもできます。

## アクセスできるかどうか

サイドバーの **ソーシャルネットワーク** <img src="../.gitbook/assets/icons/mdi-sitemap-outline.svg" alt="ソーシャルネットワーク" data-size="line"> をクリックして展開し、**ホーム** をクリックします。この項目がまったく表示されない場合は、管理者がプラットフォームで無効にしています。ご自身の操作に問題があるわけではありません。

同じ展開セクションには **メッセージ**、**マイフレンド**、**ソーシャルグループ** も並びます。やや意外なことに、**マイファイル**（個人用ファイルストレージ）と **個人データ**（プラットフォームが保持しているご自身の個人データのエクスポート）もここにあります。後者の2つはソーシャル機能ではなく、サイドバーのこの部分にまとめられているだけです。

## ソーシャルウォール

入ると、**ウォール** にはご自身とつながっている人々のアクティビティフィードが表示されます。更新を投稿でき、管理者が有効にしている場合は、つながっている人の投稿に「いいね」や「よくないね」、コメントができます。

![投稿作成欄と、コミュニティ・フレンド・スキルのパネルがあるソーシャルウォール](../.gitbook/assets/student-social-wall.png)

## 他のユーザーとのつながり

他のユーザーを検索し、つながりリクエストを送信できます。**学習者は他の学習者としかつながれません**。教師へつながりリクエストを送ることはできません。一方、教師から学習者へは送信できます。一部のプラットフォームでは、管理者が教師をすべての学習者のフレンドとして自動表示するよう設定しており、どちらもリクエストする必要がありません。依頼していないのに教師がすでにつながりとして表示されている場合は、これが理由です。

## ソーシャルネットワークからのメッセージ

投稿とつながりはソーシャル側の機能です。誰かにプライベートメッセージを送る処理は、プラットフォームの別機能である [受信箱](inbox.md) が担当します。ソーシャルネットワークは独自のメッセージングシステムを持たず、受信箱へ連携します。

## ソーシャルグループ

共通の関心事を軸にした既存の **ソーシャルグループ** に参加でき、管理者が学習者によるグループ作成を許可している場合は、自分でグループを始めることもできます。ソーシャルグループはプラットフォーム全体のもので、コース固有の **グループ** ツールとは無関係です（[コース内の操作](courses/course-tools-overview.md) を参照）。ソーシャルグループへの参加や投稿は、受講中のどのコースにも影響しません。

## ヒント

* **教師を自分からフレンド追加できるとは思わないでください** — 逆方向にしか機能しません。管理者が自動つながりを設定している場合を除きます。
* **ソーシャルグループとコースグループは無関係です** — 同じ名前でも、コースのプロジェクトグループとソーシャルネットワークのグループを混同しないでください。
* **「いいね」や「よくないね」が見えない？** 管理者は、その機能をプラットフォーム全体で有効にしたり、部分的に無効にしたり（「いいね」のみ残す）できます。
