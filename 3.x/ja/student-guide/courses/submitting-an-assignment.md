# 課題の提出

**課題**ツール（「学生の提出物」や「work」と呼ばれることもあります）は、エッセイ、プロジェクト、レポート、その他ファイル形式またはテキスト形式の成果物を、教員が採点できるように提出する場所です。

## 成果物の提出

コースホームページから **課題** <img src="../../.gitbook/assets/icons/mdi-inbox-full.svg" alt="課題" data-size="line"> ツールを開き、該当の課題を開きます。説明をよく読んでください。提出すべき内容と評価方法についての教員の指示が記載されています。その後、次の手順で進めます。

1. **ファイルをアップロード**（または提出ボタン）をクリックします
2. 教員が課題をどのように設定したかに応じて、コンピュータからファイルを選択するか、提出内容をテキストとして直接入力するか、またはその両方を行います
3. 教員向けの任意のコメントを追加します
4. 提出します

提出が完了すると、成果物が正常に送信されたことの確認が表示されます。教員が許可している場合は、後から提出内容を更新できます。許可されていない場合は、最初の提出が最終となるため、提出前に必ず再確認してください。

## 締切

課題には、次の2種類の日付が設定されることがあります。

* **締切** — この日付を過ぎても提出は受け付けられますが、教員には遅延としてフラグが付けられます
* **最終締切** — この日付を過ぎると、提出そのものができなくなります

課題がアジェンダに表示されている場合、それは通常その締切です。いつまでに提出すべきか不明なときは、そちらも確認する価値があります。

## 成績とフィードバックの確認

教員が提出物を確認すると、**得点**と、教員が書いた**フィードバックコメント**が表示されます。教員によっては**添削済みファイル**（提出した内容に注釈を付けた版）を添付することもあります。成績の横にダウンロード可能な添付ファイルがないか確認してください。課題が成績表に連携されている場合、その得点はコース全体の成績にも反映されます。

## 他の提出物の閲覧

既定では、提出物は自分と教員にのみ表示されます。教員によっては、コース全体に提出物を公開することがあります。その場合、クラスメートの成果物を閲覧できることがあります（相手もあなたの成果物を閲覧できます）。

## ヒント

* **最終締切ではなく、締切前に提出する** — 受け付けられても、遅延提出は遅延として記録されます。
* **締切日の後に、成績とフィードバックを再確認する** — 採点は必ずしも即時ではありません。
* **まったく提出できない場合**、その課題の最終締切が過ぎている可能性が高いです。誤りだと思われる場合は教員に連絡してください。
