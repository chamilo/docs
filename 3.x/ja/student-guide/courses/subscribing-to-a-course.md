# コースへの登録

コースのコンテンツにアクセスするには、そのコースに登録（受講登録）されている必要があります。プラットフォームの設定によっては、いくつかの方法があります。その多くは、あなた側での操作を一切必要としません。

| 登録のされ方 | あなたが行うこと |
|-----------------|----------------------|
| 管理者が登録する | 何も不要 — 完了するとコースが **マイコース** に表示されます |
| 教師が手動で登録する | 何も不要 — 上記と同じです |
| コースカタログから自己登録する | **さらにコースを探す** を閲覧し、参加をクリックします |
| メールでコース招待を受け取る | リンクをクリックします。アカウントがない場合は登録します |

## 自分のコースを確認する

サイドバーの **マイコース** をクリックすると、現在登録されているすべてのコースをいつでも確認できます。期待しているコースが一覧にない場合は、まだ登録されていません。以下のいずれかの方法を使うか、教師または管理者に連絡してください。

## コースカタログからの自己登録

コースの公開設定が許可している場合、他の人を待たずに自分で登録できます。

1. サイドバーの **さらにコースを探す** をクリックして、コースカタログを開きます。
2. 参加したいコースを閲覧または検索します。
3. コースをクリックして詳細を開き、参加ボタンをクリックします。

![各コースカードに「登録」ボタンがあるコースカタログ](../../.gitbook/assets/student-course-catalogue.png)

すでに登録済みのコースでは、登録ボタンの代わりに **コースへ移動** が表示されます。

自己登録にパスワードが必要なコースもあります。その場合、教師が別途共有しています。参加ボタンがまったく表示されないコースは、自己登録が開かれていません。教師または管理者に登録を依頼してください。

プラットフォームで **セッション** を使用している場合、同じ考え方は **マイセッション** にも当てはまります。カタログから自己登録できるセッションもありますが、セッションへの登録はその中のすべてのコースへの登録になるため、管理者またはセッションチューターが管理することが一般的です。

## コース招待の承諾

カタログ掲載の代わりに、教師がメールで **コース招待** を送る場合があります。これは、すでにプラットフォームアカウントを持っている必要がない唯一の方法です。メール内のリンクを開くと、次のようになります。

* 登録フォームのメール欄が、招待されたアドレスで事前入力され、ロックされます。
* プラットフォームで一般の自己登録が現在閉じられていても、登録できます。
* 登録を完了するとすぐに、そのコース（コースがセッション内で開かれている場合はセッション全体）に自動登録され、サインインします。

リンクは一度限りで、7日後に期限切れになります。動作しなくなった場合は、招待した教師に新しいリンクの送信を依頼してください。この流れの詳細は [招待された人が見る画面](../../teacher-guide/assessing-learners/subscribing-users.md#what-the-invited-person-sees) を、登録フォーム自体の見た目は [アカウントの作成](../getting-started/creating-an-account.md) を参照してください。

## ヒント

* **依頼する前に「さらにコースを探す」を確認する** — 多くのプラットフォームではコースの自己登録が開かれているため、誰かを待たずにすぐ参加できる場合があります。
* **受信トレイを確認する** — コース招待とアカウント承認の通知はどちらもメールで届きます。
* **それでも入れない場合は？** 登録方法はプラットフォーム全体で制限または無効化されていることがあります。上記のいずれも機能しない場合は、教師または管理者が直接登録できます。
