# ラーニングパスの受講

**ラーニングパス**は、教師が定めた順序で、ドキュメント、テスト、リンクなどの一連の学習活動を案内します。多くのコースでは、他のすべてを内部にまとめられるため、実際に使う主な（あるいは唯一の）ツールになります。

## ラーニングパスを開く

コースホームページから **ラーニングパス** <img src="/.gitbook/assets/icons/mdi-map-marker-path.svg" alt="ラーニングパス" data-size="line"> ツールを開き、開始したいものをクリックします。教師が **自動起動** を有効にしている場合、コースに入るとラーニングパスが自動的に開くことがあります。

![コースのラーニングパス一覧。それぞれに進捗が表示されている](/.gitbook/assets/student-learning-paths-list.png)

## パス内の移動

ラーニングパスの中では、次のものが表示されます。

* パネル内の**項目（ステップ）の一覧**。教師が章のようにグループ化したセクションに整理されている場合があります
* メイン領域の**現在の項目の内容** — ドキュメント、埋め込みテスト、リンクなど

項目を完了するとチェックマークが付き、**進捗バー**でパス全体の完了率が表示されます。途中で離れて後から戻っても、中断した場所から正確に再開でき、内容は失われません。

## ロックされた項目と前提条件

一部の項目は、教師が設定した前提条件を満たすまで**ロック**されていることがあります。通常は、先行する項目の完了や、パスの前半のテストで最低点に達することです。ステップを開けない場合は、前の項目が未完了でないか確認してください。

## パス内のテストと修了証

ラーニングパスのステップのひとつとしてテストを含めることができます。受験の手順は [テストの受験](taking-tests.md) と同じです。一部のパスは**修了証**のステップで終わります。そこに到達する（途中の得点要件を満たしている）と、教師がコース用に設定していれば修了証が発行されます。

## SCORM とその他のインポートコンテンツ

一部のラーニングパス項目は Chamilo 上で直接作成されたものではなく、**SCORM** パッケージ、**CMI5/xAPI** パッケージ、または C-Studio プラグインで作成されたものをインポートしたものです。見た目や操作は他のインタラクティブコンテンツとほぼ同じで、コンテンツ自体は別の場所で作成されていても、Chamilo は進捗と得点を同様に追跡します。

## ヒント

* **進捗バー**で、パスの残り量を把握しましょう。
* **場所を失う心配は不要です** — Chamilo はセッション間でパス内の位置を正確に記憶します。
* **ロックされたステップは、多くの場合パスの前半に未完了の作業があることを意味します** — 誤ってアクセスが拒否されたと思わず、戻って確認してください。
