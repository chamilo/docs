# コース

アカウントを取得したら、次のステップはコースに入り、その中を案内できるようになることです。

* **[コースへの登録](subscribing-to-a-course.md)** — コースに登録されるさまざまな方法
* **[コース内の案内](course-tools-overview.md)** — 学習者として、コースホームページ上の各ツールが何を意味するか
* **[ラーニングパスの受講](following-a-learning-path.md)** — 案内された一連の活動を進めること
* **[テストの受験](taking-tests.md)** — 教師がクイズや試験を割り当てたときに期待できること
* **[課題の提出](submitting-an-assignment.md)** — 採点のためにファイルやテキストを提出すること
* **[フォーラムの利用](using-the-forum.md)** — スレッド形式のコースディスカッションへの投稿と返信
* **[チャットツールの利用](using-the-chat-tool.md)** — コース内でのリアルタイムメッセージング
* **[AIチューターチャットボット](ai-tutor.md)** — プラットフォームで有効になっている場合、AIアシスタントから支援を受けること

これらのページは、すでに Chamilo アカウントをお持ちであることを前提としています。お持ちでない場合は、[アカウントの作成](../getting-started/creating-an-account.md) を参照してください。
