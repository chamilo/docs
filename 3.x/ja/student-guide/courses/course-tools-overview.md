# コース内の案内

コースを開くと、ツールアイコンのグリッドが表示されたホームページが表示されます。このページでは、学習者であるあなたにとって各ツールが何を意味するかを説明し、基盤となる機能がより詳しく記述されている箇所へのリンクを示します。

学習者向けに教師が表示可能にしたツールだけがグリッドに表示されます。教師には、あなたには表示されない追加の非表示ツールが見える場合があります。期待するツールがない場合は、単に非表示になっているか、コース全体で無効になっている可能性があります。教師に確認してください。

![学習者から見たコースホームページのツールグリッド](../../.gitbook/assets/student-course-tool-grid.png)

## 表示されないツール — および動作しないツール

いくつかの項目は、教師およびコース管理者がコース自体を設定するためだけに存在します。コース設定、コースのメンテナンス（バックアップ／インポート／エクスポート）、コースホームページエディター、そして（ほとんどのプラットフォームでは）ブログツールは、コースの編集権限を持つ人にだけ表示される「その他の操作」メニューにあります。学習者として、このメニューはまったく表示されません。

**レポート**タイルは特殊なケースです。グリッドには表示されますが、教師向けのクラス全体のトラッキング画面が開くため、クリックすると有用な内容ではなくアクセス拒否のメッセージが表示されます。

![学習者としてレポートタイルをクリックするとアクセス拒否のメッセージが表示される](../../.gitbook/assets/student-course-reporting-denied.png)

心配はいりません。ご自身の進捗は別の場所で確認できます。メインサイドバーの **マイ進捗**（[インターフェースを理解する](../getting-started/understanding-the-interface.md) および [マイ進捗](../my-progress.md) を参照）、および上記の **コース進捗** と **評価** ツールから確認でき、いずれもご自身のデータが表示されます。

コースで AI 機能が有効になっている場合、教師向けの「AI アナライザー」オプション（コース自身のコンテンツで AI Tutor を事前学習させるために使用）が、学習者向けの **AI Tutor** チャットとは異なることにも気づくかもしれません。[AI Tutor チャットボット](ai-tutor.md) を参照してください。

## ヒント

* **ツールが見つからない？** 教師に尋ねてください。壊れているのではなく、非表示または無効になっている可能性が高いです。
* **コース説明とお知らせ** は教師が完全にオフにできます。その場合、教師を含め誰にも表示されません。
* **ここにあるものはすべてコースごとに異なります** — どのツールを有効にし、表示するかは、教師がコースごとに個別に決定します。
