# フォーラムの利用

**フォーラム**ツールは、コース内で構造化されたスレッド形式の議論を行う場です。リアルタイムの[チャット](using-the-chat-tool.md)とは異なり、整理され検索しやすい形で残したい質問や会話に適しています。

## 画面の見方

コースホームページから **フォーラム** <img src="../../.gitbook/assets/icons/mdi-comment-quote.svg" alt="フォーラム" data-size="line"> ツールを開きます。フォーラムは次の3階層で構成されます。

1. **カテゴリ** — 広いグループ分け（例：「一般的な議論」「モジュール1の質問」）
2. **フォーラム** — カテゴリ内の個々の掲示板
3. **トピック（スレッド）** — フォーラム内の個々の会話。それぞれに返信の連鎖があります

## 投稿

フォーラムを開き、**新しいトピック**を開始するか、既存のトピックを開いて**返信**します。教員がそのフォーラムをどのように設定したかによって、次のように異なります。

* 自分で新しいトピックを開始できる場合とできない場合があります。一部のフォーラムは返信のみです
* 送信後に自分の投稿を編集できる場合とできない場合があります
* 投稿が公開される前に教員の承認が必要な場合があります（**モデレート**されたフォーラム）。その場合、投稿はすぐには表示されません。これは想定どおりの動作です
* 一般に完全公開されているコースでは、フォーラムが**匿名投稿**を許可することがあります。それ以外では、投稿は常にあなたに帰属します

スレッドの表示は、フォーラムの表示設定に応じて **フラット**、**スレッド**、または **入れ子** になります。これは返信の並び方だけが変わるもので、できる操作は変わりません。

## 通知を受け取る

フォーラムまたは個々のトピックにある **通知する** トグルを探し、誰かが投稿したときにメール通知を受け取るよう購読します。これは個人の購読です。オンにしても他の人には通知されず、いつでもオフにできます。

## グループと採点付きフォーラム

フォーラムはコース全体ではなく、特定のコース**グループ**に紐づいている場合があります。その場合、そのグループのメンバーだけ（または設定によってはコースの任意のメンバー）が閲覧・投稿できます。一部のスレッドは**採点**されます。教員がそのスレッドへの参加に対する満点を設定し、コースの成績に算入されることがあります。ごく一部のスレッドは**ピア採点**で、少なくとも他の2人の学習者からの評価がスコアの一部になる場合があります。

## ヒント

* **残しておく価値のある内容はフォーラムを使う** — チャットと異なり、フォーラムの投稿はトピックごとに整理され、後から探しやすいです。
* **手動で確認し続けるのではなく、関心のあるスレッドを購読する。**
* **「新しいトピック」ボタンがない**場合は、通常そのフォーラムが返信のみであり、不具合ではありません。
