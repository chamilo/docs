# はじめに

このセクションでは、学習者として Chamilo 3.0 の基本的な使い方を把握できるようにします。必要に応じたアカウント作成、ログイン、メイン画面の操作方法を学びます。

## ログイン

Chamilo にアクセスするには、ブラウザーを開き、所属機関から案内された URL（例: `https://chamilo.yourschool.edu`）に移動します。ログインページでユーザー名とパスワードを入力し、**Sign in** をクリックします。

所属機関が外部認証（Azure、Keycloak、大学のシングルサインオンなど）を利用している場合、標準のログインフォームの下に追加のログインボタンが表示されることがあります。該当するボタンをクリックし、所属機関の ID プロバイダーで認証してください。

まだアカウントをお持ちでない場合は、[アカウントの作成](creating-an-account.md) を参照してください。

> パスワードを忘れた場合は、ログインページの **Forgot your password?** リンクをクリックしてください。手順の全体は [パスワードのリセット](../account-and-security/resetting-your-password.md) を参照してください。

## 最初の画面

ログイン後、Chamilo のホームページが表示されます。画面はトップバー、サイドバー、メインコンテンツ領域の 3 つの主要なエリアで構成されています。詳細は [インターフェースの理解](understanding-the-interface.md) で説明します。

サイドバーから **My courses** をクリックすると、受講中のすべてのコースが表示されます。各コースは、画像、タイトル、クイックアクセス用の操作を示すカードとして表示されます。

所属機関が **sessions**（期間限定の研修期間）を利用している場合、サイドバーに **My sessions** リンクも表示され、現在、過去、今後のセッションに整理されます。セッションとは、1 つ以上のコースの予定された実施回またはコホートであり、同じコース内容を特定の学習者グループに特定の期間にわたって提供するものです。
