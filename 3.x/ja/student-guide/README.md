# 学生ガイド

Chamilo 3.0 学生ガイドへようこそ。本ガイドは学習者向けです。学校、企業研修、公開オンラインコースなど、Chamilo プラットフォーム上でコースを受講するすべての方を対象としています。

Chamilo を初めて利用する場合でも、すでに複数のコースに登録している場合でも、本ガイドは画面の操作、コースへの参加、アカウントの安全な管理に役立ちます。

## 学生としてできること

Chamilo の学習者として、次のことができます。

* **アカウントの作成**（プラットフォームが自己登録を許可している場合）とサインイン
* **コースへの参加** — 公開カタログ、招待、または管理者・教師による登録
* **コースツールの利用** — ドキュメントの閲覧、ラーニングパスの受講、演習の受験、課題の提出など
* **コミュニケーション** — フォーラム、チャット、グループを使って教師や他の学習者と交流
* **自身の進捗の確認** — 得点、完了状況、修了証の確認
* **AI Tutor からの支援**（プラットフォームで有効になっている場合）
* **アカウントの安全な管理** — パスワードの再設定と二要素認証の有効化

## 本ガイドの構成

1. **はじめに** — アカウントの作成（またはログイン）と、全体的な画面構成の理解
2. **コース** — コースへの登録、各種ツール（ラーニングパス、テスト、課題、フォーラム、チャット）の利用、AI Tutor の活用
3. **受信箱** — 他のプラットフォーム利用者とのプライベートメッセージの送受信
4. **ソーシャルネットワーク** — 管理者がこの機能を有効にしている場合の、他の利用者とのつながり
5. **マイ進捗** — 登録しているすべてのコースにおける自身の活動と結果の概要
6. **アカウントとセキュリティ** — パスワードの再設定、二要素認証の有効化、CAPTCHA の理解
