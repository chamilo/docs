# 用語集

本ガイド全体で使用される主な用語です。

| 用語 | 定義 |
|------|-----------|
| **Assessment** | 下記の **Gradebook** を参照 |
| **Assignment** | 教師が確認・採点するためにファイルまたはテキストを提出する課題。「student publication」または「work」とも呼ばれます。 |
| **CAPTCHA** | 実在の人物であることを確認するためのチャレンジ（通常は画像内の歪んだ文字を入力する形式）で、一部のログイン、登録、パスワード再発行フォームに表示されます。 |
| **Catalog** | 閲覧でき、場合によっては自己登録できるコース（およびセッション）の公開一覧です。**Explore more courses** からアクセスします。 |
| **Certificate** | コースの成績表で定義された最低得点を満たしたときに自動生成される文書です。 |
| **Course** | 学習コンテンツとツールを収める入れ物です。コースにはドキュメント、演習、フォーラム、ラーニングパスなどを含めることができます。 |
| **Enrollment** | コースまたはセッションに登録され、そのコンテンツにアクセスできる状態です。「subscription」とも呼ばれます。 |
| **Exercise** | 1問以上の設問を含むクイズまたはテストです。文脈によっては「test」とも呼ばれます。 |
| **Forum** | カテゴリとトピックに整理されたスレッド形式の会話を行うディスカッションツールです。 |
| **Gradebook** | 演習、課題、その他の活動からの得点を集約し、統一された成績にするツールです。 |
| **Invitation** | 教師がメールアドレス宛に送る一度限りのリンクで、一般登録が閉じている場合でも登録し、コースに自動的に登録されます。 |
| **Learning path** | 学習活動（ドキュメント、演習、リンク）を定められた順序で進める構造化された一連の流れで、前提条件が付くこともあります。 |
| **Self-registration** | プラットフォーム管理者が有効にしている場合、公開登録フォームから自分でアカウントを作成できる機能です。 |
| **Session** | 学期やコホートなど、特定の学習者グループに割り当てられた、1つ以上のコースの期間限定の実施単位です。 |
| **Skill** | 成績表の達成と結び付いたコンピテンシーです。証明書の取得により、関連するスキルが認定されることがあります。 |
| **Two-factor authentication (2FA)** | パスワードに加え、認証アプリからの時間ベースのコードを用いる追加のサインイン手順です。 |
| **Visibility** | ツール、ドキュメント、または活動を学習者に表示するかどうかを制御する設定です。教師は非表示の項目も常に見ることができます。 |
