# API

Chamilo 3.0 exposes a REST API built on **API Platform 4**. The API provides programmatic access to platform resources and is the same API used by the Vue frontend.

* **[Authentication](authentication.md)** — JWT token-based authentication
* **[Endpoints Reference](endpoints-reference.md)** — Overview of available API resources
* **[Custom Actions](custom-actions.md)** — Specialized endpoints beyond standard CRUD
* **[Session Student Enrollment](session-students.md)** — Add/remove specific session learners with administrator permissions
* **[Class Subscriptions](class-subscriptions.md)** — Read/replace class membership and linked sessions/courses
* **[Course Administration](course-administration.md)** — Update course metadata and delete courses as an administrator
* **[Webhooks](webhooks.md)** — Event-driven notifications to external systems
