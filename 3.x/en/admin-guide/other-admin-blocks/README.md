# Other Admin Blocks

The administration dashboard has a few more blocks that aren't configurable features so much as informational widgets: a page of outbound links, a version-check registration, and two small panels pulling content from chamilo.org. This chapter explains what each one is, where its content comes from, and — since some of them do — whether any data leaves your platform.

## What's Covered

* **[Chamilo.org Links](chamilo-org-links.md)** — A bookmarks list to official Chamilo resources; sends nothing
* **[Version Check](version-check.md)** — Opt-in registration that reports your platform's version and usage to chamilo.org, and tells you if you're due for an update
* **[Professional Support](professional-support.md)** — A read-only panel describing official Chamilo support providers
* **[News from Chamilo](news-from-chamilo.md)** — A read-only feed of official announcements, including security patches and new releases

Each page below states plainly what, if anything, is sent to chamilo.org, and why.
