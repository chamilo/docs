# Chamilo 3.0 Documentation

Welcome to the official documentation for **Chamilo 3.0**, the open-source e-learning platform.

This documentation is organized into four guides, each tailored to a specific audience:

* [**Teacher Guide**](teacher-guide/) — For instructors and trainers: create courses, add content, assess learners, and track progress.
* [**Administration Guide**](admin-guide/) — For platform administrators: install, configure, and manage the Chamilo platform.
* [**Student Guide**](student-guide/) — For learners: join courses, follow learning paths, take tests, and track your own progress.
* [**Developer Guide**](developer-guide/) — For developers: understand the architecture, build plugins, use the API, and contribute to the project.

## What's New in Chamilo 3.0

Chamilo 3.0 is a major release focused on AI-assisted teaching, security hardening, and a fully modernized plugin ecosystem:

* **AI-powered teaching tools** — A course quality analyzer, an AI tutor that answers platform questions, a Student Success Coach with per-learner recommendations, AI-generated course illustrations and quick tests, and AI-assisted grading
* **Model Context Protocol (MCP) server** — Lets AI clients create and manage courses, tests, learning paths, surveys, and more directly
* **Security hardening** — Native File Integrity Monitoring plus dozens of access-control fixes across courses, sessions, and the API
* **Full plugin ecosystem modernization** — Every plugin from 1.11.x re-enabled, with a redesigned plugins management interface
* **Hierarchical URLs and multi-site management** — A global multi-URL panel plus visual geographical map management for branches and rooms
* **Enhanced learning paths and exercises** — Progressive adaptive testing, OnlyOffice runtime editing, adaptive hotspot delineation, and expanded SCORM 2004 support
* **Gradebook and certificates** — Certificate expiry dates with reminders and customizable grading modes
* **Mobile-ready REST API** — A modernized backend built for mobile apps and third-party integrations
