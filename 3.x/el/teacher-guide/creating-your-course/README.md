# Δημιουργία του Μαθήματός σας

Αυτή η ενότητα εξηγεί πώς να δημιουργήσετε ένα νέο μάθημα στο Chamilo και να το διαμορφώσετε σύμφωνα με τις ανάγκες σας.

## Δημιουργία νέου μαθήματος

Για να δημιουργήσετε ένα μάθημα:

1. Κάντε κλικ στο **Τα μαθήματά μου** στην πλαϊνή γραμμή
2. Κάντε κλικ στο κουμπί **Δημιουργία μαθήματος** (συνήθως ένα πράσινο βιβλίο <img src="../../.gitbook/assets/icons/mdi-book-open-page-variant.svg" alt="Μαθήματα" data-size="line"> με σύμβολο +)
3. Συμπληρώστε τη φόρμα δημιουργίας μαθήματος:

![Η φόρμα δημιουργίας μαθήματος με πεδία για όνομα, κατηγορία, κωδικό και γλώσσα](../../.gitbook/assets/course-creation-form.png)

| Πεδίο | Υποχρεωτικό | Περιγραφή |
|-------|----------|-------------|
| **Όνομα μαθήματος** | Ναι | Ένας σύντομος, περιγραφικός τίτλος για το μάθημά σας (π.χ. «Διαχείριση Καινοτομίας») |
| **Κατηγορία μαθήματος** | Όχι | Επιλέξτε μια κατηγορία για να βοηθήσετε στην οργάνωση των μαθημάτων στην πλατφόρμα |
| **Κωδικός μαθήματος** | Όχι | Ένας σύντομος κωδικός που χρησιμοποιεί μόνο γράμματα και αριθμούς (μέγ. 40 χαρακτήρες). Αν μείνει κενό, δημιουργείται αυτόματα από το όνομα του μαθήματος |
| **Γλώσσα** | Όχι | Η κύρια γλώσσα του μαθήματος. Προεπιλογή είναι η τρέχουσα γλώσσα σας |

Αν είναι ενεργοποιημένο, ενδέχεται επίσης να βρείτε μια ρύθμιση **Προεπιλεγμένη αίθουσα** και τη δυνατότητα χρήσης **Προτύπου μαθήματος** ώστε να μην δημιουργήσετε το μάθημά σας εξ ολοκλήρου από την αρχή.

4. Κάντε κλικ στο **Δημιουργία αυτού του μαθήματος**

Θα ανακατευθυνθείτε στην αρχική σελίδα του νέου μαθήματός σας. Θα εμφανιστεί μήνυμα επιβεβαίωσης: «Το μάθημα δημιουργήθηκε με επιτυχία.»

## Η αρχική σελίδα του μαθήματος

Μόλις δημιουργηθεί το μάθημά σας, μεταβαίνετε στην αρχική του σελίδα. Αυτός είναι ο κεντρικός κόμβος του μαθήματος, όπου εσείς και οι εκπαιδευόμενοι αποκτάτε πρόσβαση σε όλα τα εργαλεία και το περιεχόμενο.

![Το πλέγμα εργαλείων της αρχικής σελίδας του μαθήματος που εμφανίζει τα διαθέσιμα εργαλεία με εικονίδια και διακόπτες ορατότητας](../../.gitbook/assets/course-homepage-tool-grid.png)

Η αρχική σελίδα εμφανίζει:

* **Τίτλος μαθήματος** — Το όνομα του μαθήματός σας, εμφανίζεται στην κορυφή.
* **Εισαγωγή μαθήματος** — Προαιρετική περιγραφή ή μήνυμα καλωσορίσματος. Κάντε κλικ στο κουμπί **+ Εισαγωγή μαθήματος** για να προσθέσετε μία, ή στο κουμπί **Επεξεργασία εισαγωγής** <img src="../../.gitbook/assets/icons/mdi-pencil.svg" alt="Επεξεργασία" data-size="line"> στην κορυφή για να την τροποποιήσετε. Υποστηρίζει εμπλουτισμένο κείμενο με εικόνες, συνδέσμους και μορφοποίηση.
* **Πλέγμα εργαλείων** — Ένα πλέγμα όλων των διαθέσιμων εργαλείων μαθήματος, καθένα ως κάρτα με εικονίδιο και όνομα.

### Διαχείριση ορατότητας εργαλείων

Ως εκπαιδευτής, μπορείτε να ελέγχετε ποια εργαλεία βλέπουν οι εκπαιδευόμενοι:

* Κάντε κλικ στο **εικονίδιο ματιού** <img src="../../.gitbook/assets/icons/mdi-eye.svg" alt="Ορατό" data-size="line"> δίπλα σε οποιοδήποτε εργαλείο για να το αποκρύψετε από τους εκπαιδευόμενους. Τα κρυφά εργαλεία εμφανίζουν **μάτι με διαγραφή** <img src="../../.gitbook/assets/icons/mdi-eye-off.svg" alt="Κρυφό" data-size="line"> και παραμένουν προσβάσιμα σε εσάς.
* Χρησιμοποιήστε τα κουμπιά **Εμφάνιση όλων** και **Απόκρυψη όλων** για να αλλάξετε όλα τα εργαλεία ταυτόχρονα
* Κάντε κλικ στο **Ταξινόμηση** για να ενεργοποιήσετε την αναδιάταξη του πλέγματος εργαλείων με μεταφορά και απόθεση

### Προβολή εκπαιδευόμενου

Κάντε κλικ στο κουμπί **Προβολή εκπαιδευόμενου** για να δείτε την αρχική σελίδα του μαθήματος ακριβώς όπως θα την έβλεπε ένας εκπαιδευόμενος. Αυτό είναι χρήσιμο για να επαληθεύσετε ότι τα κρυφά εργαλεία και το μη δημοσιευμένο περιεχόμενο δεν είναι ορατά. Κάντε ξανά κλικ στο κουμπί για να επιστρέψετε στην προβολή εκπαιδευτή.
