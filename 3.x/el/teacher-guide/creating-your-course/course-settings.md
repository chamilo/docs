# Ρυθμίσεις μαθήματος

Οι ρυθμίσεις μαθήματος σάς επιτρέπουν να ελέγχετε τη συμπεριφορά του μαθήματός σας — ποιος μπορεί να έχει πρόσβαση σε αυτό, πώς εμφανίζεται και ποιες λειτουργίες είναι ενεργοποιημένες.

Για να αποκτήσετε πρόσβαση στις ρυθμίσεις μαθήματος, εισέλθετε στο μάθημά σας και κάντε κλικ στο εικονίδιο **Ρυθμίσεις** <img src="../../.gitbook/assets/icons/mdi-cog.svg" alt="Ρυθμίσεις" data-size="line"> δίπλα στο κουμπί **Εναλλαγή σε προβολή μαθητή**.

## Γενικές ρυθμίσεις

### Πληροφορίες μαθήματος

* **Τίτλος μαθήματος** — Το εμφανιζόμενο όνομα του μαθήματός σας
* **Γλώσσα μαθήματος** — Η κύρια γλώσσα για το περιβάλλον του μαθήματος
* **Κατηγορία μαθήματος** — Η κατηγορία στην οποία εμφανίζεται το μάθημα στον κατάλογο
* **Εικόνα μαθήματος** — Ανεβάστε μια μικρογραφία που αντιπροσωπεύει το μάθημά σας στις λίστες μαθημάτων (θα αλλάξει μέγεθος ανάλογα με το πλαίσιο)

Ο κωδικός μαθήματος (το σύντομο μοναδικό αναγνωριστικό) ορίζεται κατά τη δημιουργία του μαθήματος και δεν είναι επεξεργάσιμος από αυτή τη σελίδα.

Από προεπιλογή, όλοι οι χρήστες που εισέρχονται στο μάθημά σας θα βλέπουν ολόκληρο το περιβάλλον του Chamilo στη γλώσσα του μαθήματός σας. Πρόκειται για μια λειτουργία εμβύθισης. Οι διαχειριστές μπορούν να αλλάξουν αυτή τη συμπεριφορά, αλλά μπορείτε επίσης να την αλλάξετε με μία από τις πρώτες επιλογές: **Εμφάνιση μαθήματος στη γλώσσα του χρήστη** (ορίζεται σε Όχι από προεπιλογή) εάν πιστεύετε ότι αυτό δυσκολεύει υπερβολικά τους χρήστες σας.

Το τμήμα και το URL τμήματος είναι καταργημένα πεδία. Διατηρούνται μόνο για λόγους υποστήριξης παλαιών εγκαταστάσεων.

Εάν είναι ενεργοποιημένη, μπορείτε να αλλάξετε το στυλ μέσα στο μάθημά σας με την επιλογή **Φύλλα στυλ**, χρησιμοποιώντας υπάρχοντα φύλλα στυλ στην πύλη σας. Αυτή η επιλογή συχνά απενεργοποιείται από τους διαχειριστές, για έναν πιο ενιαίο συνολικό σχεδιασμό.

### Όριο δίσκου

Κάθε μάθημα έχει όριο αποθήκευσης (όριο δίσκου) για τα αρχεία που ανεβαίνουν. Το όριο ορίζεται από τον διαχειριστή της πλατφόρμας. Μπορείτε να δείτε το τρέχον όριό σας στις ρυθμίσεις μαθήματος και την τρέχουσα χρήση στο εργαλείο **Έγγραφα**.

> Εάν εξαντλείται ο χώρος σας, επικοινωνήστε με τον διαχειριστή της πλατφόρμας για να ζητήσετε αύξηση του ορίου ή αφαιρέστε αχρησιμοποίητα αρχεία από το εργαλείο Έγγραφα.

### Ορατότητα μαθήματος

![Οι ρυθμίσεις ορατότητας μαθήματος που εμφανίζουν τις επιλογές δημόσιο, ανοιχτό, εγγεγραμμένοι και κλειστό](../../.gitbook/assets/course-settings-visibility.png)

Ελέγξτε ποιος μπορεί να έχει πρόσβαση στο μάθημά σας:

| Ρύθμιση | Περιγραφή |
|---------|-------------|
| **Δημόσιο** | Οποιοσδήποτε, συμπεριλαμβανομένων ανώνυμων επισκεπτών, μπορεί να έχει πρόσβαση στο μάθημα |
| **Ανοιχτό στην πλατφόρμα** | Όλοι οι εγγεγραμμένοι χρήστες της πλατφόρμας μπορούν να έχουν πρόσβαση στο μάθημα |
| **Ιδιωτικό — πρόσβαση χορηγείται από προνομιούχους χρήστες** | Μόνο οι χρήστες που έχουν εγγραφεί ρητά στο μάθημα μπορούν να έχουν πρόσβαση σε αυτό |
| **Κλειστό** | Το μάθημα είναι κλειδωμένο· κανείς δεν μπορεί να έχει πρόσβαση εκτός από τον διδάσκοντα |

#### Ρυθμίσεις εγγραφής

Ανάλογα με τη διαμόρφωση της πλατφόρμας σας, ενδέχεται να μπορείτε να ελέγχετε:

* **Να επιτρέπεται η αυτοεγγραφή** — Εάν οι εκπαιδευόμενοι μπορούν να εγγραφούν μόνοι τους μέσω του καταλόγου μαθημάτων
* **Να επιτρέπεται η αυτοαπεγγραφή** — Εάν οι εκπαιδευόμενοι μπορούν να αποχωρήσουν από το μάθημα μόνοι τους
* **Κωδικός πρόσβασης εγγραφής** — Απαίτηση κωδικού πρόσβασης για αυτοεγγραφή (χρήσιμο για περιορισμό της πρόσβασης σε συγκεκριμένη ομάδα), αλλά το επίπεδο ασφάλειας είναι χαμηλό καθώς ο ίδιος κωδικός πρόσβασης στο μάθημα κοινοποιείται σε όλους τους χρήστες.

Αυτές οι ρυθμίσεις καλύπτουν μόνο την αυτοεγγραφή. Για την πλήρη εικόνα — συμπεριλαμβανομένης της εγγραφής ενός υπάρχοντος χρήστη από εσάς ή της πρόσκλησης κάποιου που δεν έχει ακόμη λογαριασμό στην πλατφόρμα — δείτε [Εγγραφή χρηστών](../assessing-learners/subscribing-users.md).

### Ρυθμίσεις εγγράφων

Επιλέξτε αν θα εμφανίζονται ή θα αποκρύπτονται οι φάκελοι συστήματος στο εργαλείο **Έγγραφα** (κρυφοί από προεπιλογή· στις περισσότερες περιπτώσεις δεν τους χρειάζεστε πραγματικά και η εμφάνισή τους ενδέχεται να προκαλέσει προβλήματα με κρυφό περιεχόμενο και εκπαιδευόμενους).

### Ρυθμίσεις ειδοποιήσεων e-mail

Διαμορφώστε πώς η δραστηριότητα του μαθήματος ενεργοποιεί ειδοποιήσεις:

* **Ειδοποιήσεις email για νέο περιεχόμενο** — Ειδοποίηση των εγγεγραμμένων χρηστών όταν προσθέτετε νέα έγγραφα, ανακοινώσεις ή άλλο περιεχόμενο

### Ρυθμίσεις συνομιλίας

Ελέγξτε πώς θα εμφανίζεται το εργαλείο **Συνομιλία**.

### Ρυθμίσεις μαθησιακής διαδρομής

* **Ενεργοποίηση θεμάτων μαθήματος** — Να επιτρέπεται στις μαθησιακές διαδρομές να αλλάζουν εμφάνιση (δεν συνιστάται για ενιαία εμπειρία χρήστη)
* **Σύνδεσμος επιστροφής μαθησιακής διαδρομής** — Αποφασίστε πού καταλήγουν οι χρήστες όταν κάνουν κλικ στο εικονίδιο **Αρχική** σε μια μαθησιακή διαδρομή: στη λίστα μαθησιακών διαδρομών, στην αρχική σελίδα του μαθήματος, στα *Τα μαθήματά μου*, στις *Οι συνεδρίες μου* ή στην αρχική σελίδα της πύλης

### Ρυθμίσεις θεματικής προόδου

Διαμορφώστε πώς θα εμφανίζονται τα μηνύματα θεματικής προόδου στην αρχική σελίδα του μαθήματος.

### Ρυθμίσεις φόρουμ

Ελέγξτε τη συμπεριφορά στο εργαλείο φόρουμ αυτού του μαθήματος.

### Ρυθμίσεις εργασιών

* **Προεπιλεγμένη ρύθμιση για την ορατότητα των νεοαναρτημένων αρχείων** — Αποφασίστε αν τα νέα έγγραφα που ανεβάζουν οι εκπαιδευόμενοι στο εργαλείο **Εργασίες** κοινοποιούνται σε όλους τους άλλους εκπαιδευόμενους (Όχι από προεπιλογή)
* **Να επιτρέπεται στους εκπαιδευόμενους να διαγράφουν τις δικές τους δημοσιεύσεις** — Να επιτρέπεται στους εκπαιδευόμενους να διαγράφουν τις εργασίες που έχουν ήδη ανεβάσει (σε περίπτωση που θέλουν να ανεβάσουν μια διόρθωση).

### Ρυθμίσεις αυτόματης εκκίνησης

Ένα μάθημα μπορεί να ρυθμιστεί ώστε να έχει συμπεριφορά αυτόματης εκκίνησης, η οποία θα συντομεύσει τη διαδρομή των εκπαιδευόμενων προς τα σημαντικά μέρη του μαθήματός σας. Εάν ενεργοποιηθεί, οι εκπαιδευόμενοι που εισέρχονται στο μάθημά σας θα αποστέλλονται απευθείας στο επιλεγμένο εργαλείο και δεν θα βλέπουν την αρχική σελίδα του μαθήματος ως ενδιάμεσο βήμα. Μπορείτε ακόμη να επιλέξετε συγκεκριμένες διαδρομές μάθησης ή ασκήσεις για εκκίνηση κατά την άφιξη στο μάθημα. Σε αυτή την περίπτωση, πρέπει να επιλέξετε την επιλογή εδώ, στη συνέχεια να μεταβείτε στη λίστα διαδρομών μάθησης ή ασκήσεων και να κάνετε κλικ στο εικονίδιο πυραύλου <img src="../../.gitbook/assets/icons/mdi-rocket-launch.svg" alt="Αυτόματη εκκίνηση" data-size="line"> στο επιλεγμένο στοιχείο.

### Ρυθμίσεις βοηθών ΤΝ

Αυτή η ενότητα εμφανίζεται μόνο εάν ο διαχειριστής σας έχει ενεργοποιήσει εργαλεία ΤΝ στην πλατφόρμα. Σας επιτρέπει να βελτιώσετε την επιλογή των υπηρεσιών βοηθών ΤΝ που είναι διαθέσιμες μέσω διαφορετικών εργαλείων της πλατφόρμας Chamilo. Απενεργοποιήστε τα εάν δεν θέλετε να τα χρησιμοποιήσετε, αλλά αυτό πιθανότατα θα ήταν κακή ιδέα, καθώς είναι πολύ ισχυρά.

Αυτά τα χαρακτηριστικά εξηγούνται στην ενότητα **Εργαλεία ΤΝ** αυτού του οδηγού.

### Εξωτερικά εργαλεία (LTI)

Εάν είναι ενεργοποιημένο στην πλατφόρμα σας, το Learning Tools Integration σας επιτρέπει να ενσωματώσετε εξωτερικές, συμβατές δραστηριότητες σε αυτό το μάθημα, ως μεμονωμένα εικονίδια στην αρχική σελίδα του μαθήματος. Η συζήτηση του LTI είναι εκτός του πεδίου αυτού του οδηγού, αλλά πρόκειται για ένα ισχυρό σύστημα ενσωμάτωσης για εκπαιδευτικούς.

### Άλλα

Επιπλέον ενότητες ή επιλογές ενδέχεται να εμφανιστούν σε αυτή τη σελίδα ανάλογα με τις επιλογές και τις εκδόσεις του Chamilo.
