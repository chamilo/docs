# Περιγραφή μαθήματος

Το εργαλείο **Περιγραφή μαθήματος** <img src="/.gitbook/assets/icons/mdi-apple-safari.svg" alt="Περιγραφή μαθήματος" data-size="line"> σας επιτρέπει να συντάξετε μια δομημένη, πολυτμηματική περιγραφή του μαθήματός σας — τους στόχους, τη μεθοδολογία, τα υλικά και άλλα. Σε αντίθεση με το ελεύθερο κείμενο του banner **Εισαγωγή μαθήματος** στην [αρχική σελίδα του μαθήματος](README.md#the-course-homepage), το οποίο βλέπουν μόνο οι εγγεγραμμένοι εκπαιδευόμενοι, η περιγραφή μαθήματος είναι αυτό που βλέπουν οι υποψήφιοι εκπαιδευόμενοι *πριν* εγγραφούν, από τον κατάλογο μαθημάτων.

Μετά την εγγραφή, οι εκπαιδευόμενοι μπορούν να ανατρέχουν σε αυτήν από μέσα στο μάθημα — αν αφήσετε το εργαλείο ορατό σε αυτούς, αποτελεί ένα βολικό σημείο για να ελέγχουν πρακτικές πληροφορίες όπως η γενική δομή του μαθήματος ή ποιοι είναι οι διδάσκοντες, χωρίς να χρειάζεται να σας ρωτήσουν απευθείας. Οι εγγεγραμμένοι εκπαιδευόμενοι μπορούν να δουν τις ενότητες που συντάξατε αλλά δεν μπορούν να τις προσθέσουν, να τις επεξεργαστούν ή να τις διαγράψουν.

## Πρόσβαση στο εργαλείο

Ανοίξτε το εργαλείο **Περιγραφή μαθήματος** <img src="/.gitbook/assets/icons/mdi-apple-safari.svg" alt="Περιγραφή μαθήματος" data-size="line"> από το πλέγμα εργαλείων της αρχικής σελίδας του μαθήματος.

## Οι οκτώ ενότητες

Μια περιγραφή μαθήματος αποτελείται από έως οκτώ ανεξάρτητες ενότητες. Καθεμία είναι προαιρετική — συμπληρώστε μόνο όσες σχετίζονται με το μάθημά σας:

| Ενότητα | Κατευθυντήρια ερώτηση |
|---------|-------------------|
| **Περιγραφή** | Ποιος είναι ο στόχος του μαθήματος; Υπάρχουν προαπαιτούμενα; Πώς συνδέεται αυτή η κατάρτιση με άλλα μαθήματα; |
| **Στόχοι** | Ποια πρέπει να είναι τα τελικά αποτελέσματα όταν ο εκπαιδευόμενος ολοκληρώσει το μάθημα; Ποιες είναι οι δραστηριότητες που πραγματοποιούνται κατά τη διάρκεια του μαθήματος; |
| **Θέματα** | Πώς εξελίσσεται το μάθημα; Πού πρέπει ο εκπαιδευόμενος να δώσει ιδιαίτερη προσοχή; Υπάρχουν αναγνωρίσιμα προβλήματα στην κατανόηση διαφορετικών περιοχών; Πόσο χρόνο πρέπει να αφιερώσει κανείς στις διαφορετικές περιοχές του μαθήματος; |
| **Μεθοδολογία** | Ποιες μέθοδοι και δραστηριότητες βοηθούν στην επίτευξη των στόχων του μαθήματος; Ποιο θα ήταν το χρονοδιάγραμμα; |
| **Υλικό μαθήματος** | Υπάρχει βιβλίο μαθήματος, συλλογή άρθρων, βιβλιογραφία, λίστα συνδέσμων στο διαδίκτυο; |
| **Πόροι** | Λάβετε υπόψη τα μαθήματα, τους επιβλέποντες, ένα τεχνικό helpdesk, τους διδάσκοντες και/ή τα διαθέσιμα υλικά. |
| **Αξιολόγηση** | Πώς θα αξιολογηθούν οι εκπαιδευόμενοι; Υπάρχουν στρατηγικές που πρέπει να αναπτυχθούν για την κατάκτηση του θέματος; |
| **Άλλο** | Οτιδήποτε δεν εντάσσεται στις παραπάνω κατηγορίες. Μπορείτε να προσθέσετε όσες ενότητες **Άλλο** χρειάζεστε, καθεμία με τον δικό της προσαρμοσμένο τίτλο. |

## Προσθήκη ενότητας

1. Στη γραμμή εργαλείων του εργαλείου, κάντε κλικ στο εικονίδιο για τον τύπο ενότητας που θέλετε να συντάξετε
2. Το Chamilo εμφανίζει ένα πλαίσιο **Βοήθεια** με την κατευθυντήρια ερώτηση για την ενότητα αυτή — χρησιμοποιήστε το για να αποφασίσετε τι θα γράψετε
3. Γράψτε το περιεχόμενό σας στον επεξεργαστή εμπλουτισμένου κειμένου (υποστηρίζει μορφοποίηση, εικόνες, συνδέσμους, ενσωματωμένο βίντεο και άλλο εμπλουτισμένο περιεχόμενο). Αν η πλατφόρμα σας το έχει ενεργοποιημένο, μπορείτε επίσης να γράψετε αρκετές γλωσσικές εκδόσεις της ίδιας ενότητας και κάθε εκπαιδευόμενος να βλέπει αυτόματα μόνο τη δική του — δείτε [Πολυγλωσσικό περιεχόμενο](../adding-content/multi-language-content.md).
4. Αποθήκευση

Κάθε ενότητα που προσθέτετε εμφανίζεται ως δική της κάρτα στο εργαλείο. Χρησιμοποιήστε τα εικονίδια **Επεξεργασία** <img src="/.gitbook/assets/icons/mdi-pencil.svg" alt="Επεξεργασία" data-size="line"> και **Διαγραφή** <img src="/.gitbook/assets/icons/mdi-delete.svg" alt="Διαγραφή" data-size="line"> σε μια κάρτα για να την ενημερώσετε ή να την αφαιρέσετε αργότερα.

## Σύνδεση με τον κατάλογο μαθημάτων

Αυτός είναι ο κύριος λόγος να συμπληρώσετε μια περιγραφή μαθήματος: τροφοδοτεί απευθείας τον κατάλογο **Εξερευνήστε περισσότερα μαθήματα** που περιηγούνται οι επισκέπτες και οι υποψήφιοι εκπαιδευόμενοι.

* Ένα μάθημα **χωρίς** συμπληρωμένες ενότητες περιγραφής εμφανίζεται ως απλή κάρτα στον κατάλογο.
* Ένα μάθημα με **τουλάχιστον μία** ενότητα περιγραφής γίνεται κλικαρίσιμο — το κλικ στην εικόνα, τον τίτλο ή το κουμπί πληροφοριών ανοίγει ένα λεπτομερές αναδυόμενο παράθυρο που παραθέτει κάθε ενότητα που συντάξατε, με την ίδια σειρά που εμφανίζεται παραπάνω.

Αυτό δίνει στους υποψήφιους εκπαιδευόμενους μια πραγματική βάση για να αποφασίσουν αν θα εγγραφούν, αντί για απλώς έναν τίτλο και μια μικρογραφία.

> Το αν αυτό το αναδυόμενο παράθυρο είναι διαθέσιμο εξαρτάται από μια ρύθμιση σε επίπεδο πλατφόρμας. Αν οι περιγραφές σας δεν εμφανίζονται στους υποψήφιους εκπαιδευόμενους στον κατάλογο, ζητήστε από τον διαχειριστή σας να ελέγξει τη ρύθμιση **Show Course Descriptions** (`show_courses_descriptions_in_catalog`) στην ενότητα **Administration > Configuration settings > Course Catalog**.

## Συμβουλές

* **Δώστε προτεραιότητα στις ενότητες Περιγραφή και Στόχοι** — αυτές είναι που διαβάζουν πρώτα οι περισσότεροι υποψήφιοι εκπαιδευόμενοι όταν αποφασίζουν αν θα εγγραφούν.
* **Διατηρήστε την ενημερωμένη** — ενημερώνετε την περιγραφή του μαθήματος όποτε το περιεχόμενο του μαθήματος αλλάζει σημαντικά, ώστε ο κατάλογος να αντικατοπτρίζει πάντα αυτό που θα λάβουν πραγματικά οι εκπαιδευόμενοι.
* **Χρησιμοποιήστε εμπλουτισμένο περιεχόμενο με φειδώ** — οι εικόνες και η μορφοποίηση βοηθούν την αναγνωσιμότητα, αλλά ένα μακρύ, φορτωμένο αναδυόμενο παράθυρο μπορεί να είναι δυσκολότερο να σαρωθεί από μερικές σαφείς παραγράφους.
