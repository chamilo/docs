# Dropbox

Το dropbox είναι ένα εργαλείο ανταλλαγής αρχείων που σας επιτρέπει, εσάς και τους εκπαιδευόμενούς σας, να μοιράζεστε αρχεία μεταξύ σας εντός του μαθήματος.

> Για τη συλλογή βαθμολογημένων εργασιών των εκπαιδευόμενων, το εργαλείο [Αναθέσεις](../assessing-learners/assignments.md) είναι συνήθως καταλληλότερο, καθώς περιλαμβάνει λειτουργίες βαθμολόγησης και ανατροφοδότησης. Το dropbox είναι καταλληλότερο για ανεπίσημη ανταλλαγή αρχείων.

## Αποστολή αρχείου

1. Ανοίξτε το εργαλείο **Dropbox** από την αρχική σελίδα του μαθήματος
2. Κάντε κλικ στην επιλογή **Share a new file**
3. Επιλέξτε το αρχείο προς μεταφόρτωση
4. Επιλέξτε τον/τους **παραλήπτη(-ες)** — έναν ή περισσότερους εγγεγραμμένους χρήστες ή ομάδες του μαθήματος
5. Αποστολή

## Λήψη αρχείων

Όταν κάποιος σας στέλνει ένα αρχείο, εμφανίζεται στα εισερχόμενα του dropbox σας. Μπορείτε:

* να **κατεβάσετε** το αρχείο
* να **προσθέσετε σχόλιο** στο αρχείο (αφού έχει ληφθεί)
* να **μετακινήσετε** το αρχείο σε μία από τις κατηγορίες σας
* να **διαγράψετε** το αρχείο από τα εισερχόμενά σας

## Οργάνωση αρχείων

Τόσο τα απεσταλμένα όσο και τα ληφθέντα αρχεία μπορούν να οργανωθούν σε προσαρμοσμένες **κατηγορίες** (φακέλους). Χρησιμοποιήστε τα στοιχεία ελέγχου κατηγοριών στη γραμμή εργαλείων του dropbox για να δημιουργήσετε μια κατηγορία και στη συνέχεια να μετακινήσετε αρχεία σε αυτήν. Εάν η ρύθμιση πλατφόρμας "allow overwrite" είναι ενεργοποιημένη, η εκ νέου αποστολή αρχείου με το ίδιο όνομα σας επιτρέπει να αντικαταστήσετε την προηγούμενη έκδοση.

Μπορείτε επίσης να κατεβάσετε μαζικά επιλεγμένα αρχεία ως ZIP.

## Ως εκπαιδευτής

* Μπορείτε να στέλνετε αρχεία σε μεμονωμένους εκπαιδευόμενους, σε ομάδες εκπαιδευόμενων ή σε όλους τους εγγεγραμμένους χρήστες
* Μπορείτε να βλέπετε αρχεία που σας έχουν στείλει οι εκπαιδευόμενοι
* Το εργαλείο αυτό είναι χρήσιμο για την κοινοποίηση συμπληρωματικού υλικού, την παροχή εξατομικευμένων εγγράφων ανατροφοδότησης ή τη λήψη ανεπίσημων υποβολών
