# Χαρτοφυλάκιο

Το εργαλείο χαρτοφυλακίου επιτρέπει στους εκπαιδευόμενους να συλλέγουν και να παρουσιάζουν την εργασία τους καθ’ όλη τη διάρκεια του μαθήματος. Λειτουργεί ως ψηφιακό χαρτοφυλάκιο όπου οι εκπαιδευόμενοι μπορούν να συγκεντρώσουν την καλύτερη εργασία τους, τους στοχασμούς και τα επιτεύγματά τους.

## Πώς λειτουργούν τα χαρτοφυλάκια

Κάθε εκπαιδευόμενος διαθέτει ένα προσωπικό χαρτοφυλάκιο εντός του μαθήματος, όπου μπορεί να:

* **Προσθέτει στοιχεία** — Να συντάσσει καταχωρίσεις κειμένου με τον επεξεργαστή εμπλουτισμένου κειμένου και να επισυνάπτει ένα ή περισσότερα αρχεία σε κάθε στοιχείο
* **Οργανώνει το περιεχόμενο** — Να επισημαίνει στοιχεία με ετικέτες ώστε να μπορούν να φιλτράρονται ανά θέμα
* **Κοινοποιεί επιλεκτικά** — Να ορίζει την ορατότητα κάθε στοιχείου: κρυφό, ορατό στο μάθημα, κρυφό εκτός από τον εκπαιδευτή, ή κοινοποιημένο σε επιλεγμένους χρήστες όταν είναι ενεργοποιημένη η προηγμένη κοινοποίηση

## Ως εκπαιδευτής

Μπορείτε να χρησιμοποιήσετε τα χαρτοφυλάκια για:

* **Αναστοχαστική μάθηση** — Να ζητήσετε από τους εκπαιδευόμενους να διατηρούν ένα χαρτοφυλάκιο στοχασμών σχετικά με τη μαθησιακή τους διαδρομή
* **Απόδειξη ικανοτήτων** — Να έχουν οι εκπαιδευόμενοι συλλέξει τεκμήρια δεξιοτήτων και γνώσεων
* **Αξιολόγηση** — Να εξετάζετε το περιεχόμενο του χαρτοφυλακίου ως μέρος της αξιολόγησής σας

Για να δείτε το χαρτοφυλάκιο ενός εκπαιδευόμενου, ανοίξτε το εργαλείο χαρτοφυλακίου και φιλτράρετε τη λίστα στοιχείων ανά χρήστη.

Εάν το μάθημα έχει ρυθμιστεί ώστε να το επιτρέπει, μπορείτε να βαθμολογήσετε στοιχεία χαρτοφυλακίου και μεμονωμένα σχόλια — αυτές οι βαθμολογίες μπορούν στη συνέχεια να τροφοδοτήσουν το βαθμολόγιο. Μπορείτε επίσης να **επισημάνετε** στοιχεία στα οποία θέλετε να τραβήξετε την προσοχή και να χαρακτηρίσετε στοιχεία ή σχόλια ως **πρότυπα**, ώστε εσείς (ή οι εκπαιδευόμενοι) να μπορείτε να τα επαναχρησιμοποιήσετε ως σημείο εκκίνησης για νέες καταχωρίσεις. Τα χαρτοφυλάκια μπορούν να εξαχθούν ως **PDF** ή **ZIP**.

## Συμβουλές

* **Ορίστε προσδοκίες** — Πείτε στους εκπαιδευόμενους τι είδους στοιχεία να συμπεριλάβουν και πώς να οργανώσουν το χαρτοφυλάκιό τους
* **Εξετάζετε τακτικά** — Ελέγχετε τα χαρτοφυλάκια περιοδικά και όχι μόνο στο τέλος του μαθήματος
* **Συνδυάστε με δεξιότητες** — Χρησιμοποιήστε τα χαρτοφυλάκια παράλληλα με το σύστημα δεξιοτήτων/πιστοποιητικών για να δημιουργήσετε ένα ολοκληρωμένο αρχείο ικανοτήτων
