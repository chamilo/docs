# Επιπλέον Εργαλεία

Πέρα από τα βασικά εργαλεία περιεχομένου, αξιολόγησης και συνεργασίας, το Chamilo προσφέρει αρκετά επιπλέον εργαλεία που μπορούν να ενισχύσουν το μάθημά σας.

* **[Ημερολόγιο](agenda.md)** — Προγραμματίστε εκδηλώσεις, προθεσμίες και υπενθυμίσεις για το μάθημά σας
* **[Σημειωματάριο](notebook.md)** — Ένα προσωπικό εργαλείο λήψης σημειώσεων για τους εκπαιδευόμενους
* **[Dropbox](dropbox.md)** — Ένα απλό εργαλείο ανταλλαγής αρχείων μεταξύ εσάς και των εκπαιδευομένων σας
* **[Χαρτοφυλάκιο](portfolio.md)** — Επιτρέψτε στους εκπαιδευόμενους να δημιουργήσουν και να παρουσιάσουν ένα χαρτοφυλάκιο της εργασίας τους
* **[Πρόοδος Μαθήματος](course-progress.md)** — Ορίστε θεματικές ενότητες και παρακολουθήστε την παράδοση του μαθήματος
