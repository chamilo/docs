# Συνεδρίες

Οι συνεδρίες στο Chamilo είναι ένας τρόπος να παραδοθεί το ίδιο μάθημα σε διαφορετικές ομάδες εκπαιδευομένων σε διαφορετικές χρονικές περιόδους, χωρίς να αντιγραφεί το περιεχόμενο του μαθήματος. Σκεφτείτε τη συνεδρία ως μια προγραμματισμένη έκδοση ή ομάδα (cohort) ενός μαθήματος.

## Πώς λειτουργούν οι συνεδρίες

Ένα **μάθημα** είναι ένα δοχείο περιεχομένου και εργαλείων. Μια **συνεδρία** αναθέτει αυτό το μάθημα σε μια συγκεκριμένη ομάδα εκπαιδευομένων για μια συγκεκριμένη χρονική περίοδο. Αυτό σημαίνει ότι:

* Το ίδιο μάθημα μπορεί να επαναχρησιμοποιηθεί σε πολλαπλές συνεδρίες
* Κάθε συνεδρία έχει τους δικούς της εγγεγραμμένους εκπαιδευόμενους και τις δικές της ημερομηνίες έναρξης/λήξης
* Κάθε συνεδρία έχει τα δικά της αποτελέσματα — οι βαθμοί, η πρόοδος και τα δεδομένα παρακολούθησης διατηρούνται χωριστά ανά συνεδρία
* Το βασικό περιεχόμενο του μαθήματος είναι κοινό, αλλά οι εκπαιδευτές μπορούν να προσαρμόσουν ορισμένα στοιχεία ανά συνεδρία

## Οι συνεδρίες σας

Από την πλαϊνή γραμμή, κάντε κλικ στο **Οι συνεδρίες μου** για να δείτε τις συνεδρίες σας. Οργανώνονται σε τρεις προβολές:

![Η σελίδα Οι συνεδρίες μου που εμφανίζει προβολές τρεχουσών, παρελθουσών και επερχόμενων συνεδριών](/.gitbook/assets/my-sessions-list.png)

* **Τρέχουσες συνεδρίες** — Συνεδρίες που είναι αυτή τη στιγμή ενεργές
* **Παρελθούσες συνεδρίες** — Συνεδρίες που έχουν ολοκληρωθεί
* **Επερχόμενες συνεδρίες** — Συνεδρίες που δεν έχουν ξεκινήσει ακόμη

Κάθε συνεδρία εμφανίζει τα μαθήματα που περιέχει. Κάντε κλικ σε ένα μάθημα εντός μιας συνεδρίας για να αποκτήσετε πρόσβαση σε αυτό.

## Διδασκαλία σε μια συνεδρία

Όταν εισέρχεστε σε ένα μάθημα μέσω μιας συνεδρίας, η εμπειρία είναι παρόμοια με ένα κανονικό μάθημα, με ορισμένες διαφορές:

* Το **όνομα της συνεδρίας** εμφανίζεται δίπλα στον τίτλο του μαθήματος, ώστε να γνωρίζετε πάντα σε ποια συνεδρία εργάζεστε
* Τα δεδομένα των εκπαιδευομένων (πρόοδος, βαθμοί, υποβολές) είναι ειδικά για αυτή τη συνεδρία
* Ορισμένες ρυθμίσεις (όπως η δυνατότητα αλλαγής της ορατότητας των εργαλείων) ενδέχεται να είναι κλειδωμένες από τον διαχειριστή συνεδρίας

## Ρόλοι συνεδρίας

Οι συνεδρίες εισάγουν πρόσθετους ρόλους:

| Ρόλος | Περιγραφή |
|------|-------------|
| **Διαχειριστής συνεδρίας** | Διαχειρίζεται τη δημιουργία και τη διαμόρφωση των συνεδριών |
| **Καθηγητής συνεδρίας** | Επιβλέπει όλα τα μαθήματα εντός μιας συνεδρίας (μπορεί να έχει πρόσβαση στην παρακολούθηση σε όλα τα μαθήματα) |
| **Καθηγητής μαθήματος** | Διδάσκει ένα συγκεκριμένο μάθημα εντός μιας συνεδρίας |

Αν σας έχει ανατεθεί ο ρόλος **καθηγητή μαθήματος** σε μια συνεδρία, μπορείτε να διαχειριστείτε το περιεχόμενο αυτού του μαθήματος και να παρακολουθήσετε την πρόοδο των εκπαιδευομένων της συνεδρίας.

> Οι συνεδρίες διαχειρίζονται συνήθως από διαχειριστές. Αν χρειάζεται να δημιουργήσετε ή να τροποποιήσετε μια συνεδρία, επικοινωνήστε με τον διαχειριστή της πλατφόρμας ή τον διαχειριστή συνεδρίας.
