# Εισιτήρια Υποστήριξης

Το εργαλείο **Tickets** είναι ένα ενσωματωμένο σύστημα helpdesk που επιτρέπει στους χρήστες να υποβάλλουν αιτήματα υποστήριξης και να παρακολουθούν την επίλυσή τους. Ανάλογα με τη διαμόρφωση της πλατφόρμας σας, μπορείτε να το χρησιμοποιείτε ως **αιτών** (υποβάλλοντας εισιτήρια για τον εαυτό σας ή τους εκπαιδευόμενούς σας) ή ως **πράκτορας υποστήριξης** (απαντώντας σε εισιτήρια που έχουν ανατεθεί στην κατηγορία σας).

## Πώς είναι οργανωμένο το σύστημα

Τα εισιτήρια ανήκουν σε **έργα**, τα οποία υποδιαιρούνται περαιτέρω σε **κατηγορίες**. Κάθε κατηγορία μπορεί να έχει έναν ή περισσότερους πράκτορες υποστήριξης ανατεθειμένους σε αυτήν. Όταν υποβάλλεται ένα εισιτήριο, δρομολογείται αυτόματα σε έναν διαθέσιμο πράκτορα στην επιλεγμένη κατηγορία.

Οι προεπιλεγμένες κατηγορίες περιλαμβάνουν:

| Κατηγορία | Περιγραφή |
|----------|-------------|
| Enrollment | Ερωτήσεις και ζητήματα σχετικά με την εγγραφή σε μάθημα ή συνεδρία |
| General information | Γενικές ερωτήσεις για την πλατφόρμα |
| Requests and paperwork | Διοικητικά αιτήματα και τεκμηρίωση |
| Academic Incidents | Ζητήματα σχετικά με εξετάσεις, εργασίες ή καθήκοντα |
| Virtual campus | Τεχνικά ζητήματα με την πλατφόρμα |
| Online evaluation | Ζητήματα με συγκεκριμένη αξιολόγηση μαθήματος (απαιτείται επιλογή μαθήματος) |

## Πρόσβαση στο εργαλείο εισιτηρίων

Εάν ο διαχειριστής σας έχει ενεργοποιήσει τον σύνδεσμο εισιτηρίων, εμφανίζεται ένα εικονίδιο εισιτηρίου <img src="../.gitbook/assets/icons/mdi-ticket-account.svg" alt="Εισιτήριο" data-size="line"> στην επάνω γραμμή πλοήγησης. Κάντε κλικ σε αυτό για να μεταβείτε απευθείας στη φόρμα υποβολής εισιτηρίου.

Μπορείτε επίσης να αποκτήσετε πρόσβαση στα εισιτήριά σας από το κύριο μενού στην ενότητα **Support** ή **Tickets**, ανάλογα με τη διαμόρφωση της πλατφόρμας σας.

## Υποβολή εισιτηρίου

Για να ανοίξετε ένα νέο αίτημα υποστήριξης:

1. Κάντε κλικ στο **New ticket** (ή στο εικονίδιο εισιτηρίου στην επάνω γραμμή).
2. Επιλέξτε την **κατηγορία** που ταιριάζει καλύτερα στο ζήτημά σας.
3. Εάν η κατηγορία το απαιτεί (για παράδειγμα, Online evaluation), επιλέξτε το σχετικό **μάθημα**.
4. Εισαγάγετε ένα **θέμα** — μια σύντομη περίληψη του ζητήματος.
5. Γράψτε το **μήνυμά** σας περιγράφοντας το πρόβλημα λεπτομερώς.
6. Προαιρετικά επισυνάψτε αρχεία (στιγμιότυπα οθόνης, έγγραφα) για να βοηθήσετε τον πράκτορα υποστήριξης να κατανοήσει το ζήτημα.
7. Κάντε κλικ στο **Submit**.

Στο εισιτήριο αποδίδεται ένα αναγνωριστικό και δρομολογείται σε έναν πράκτορα υποστήριξης. Θα λάβετε ειδοποίηση όταν απαντήσει ο πράκτορας.

## Παρακολούθηση των εισιτηρίων σας

Από τη λίστα εισιτηρίων μπορείτε να δείτε όλα τα εισιτήρια που έχετε υποβάλει και την τρέχουσα κατάστασή τους:

| Κατάσταση | Σημασία |
|--------|---------|
| New | Μόλις υποβλήθηκε, δεν έχει ακόμη εξεταστεί |
| Pending | Εξετάζεται από πράκτορα υποστήριξης |
| Unconfirmed | Αναμονή επιβεβαίωσης ή πρόσθετων πληροφοριών |
| Forwarded | Μεταφέρθηκε σε άλλη ομάδα ή πράκτορα |
| Closed | Επιλύθηκε |

Κάντε κλικ σε οποιοδήποτε εισιτήριο για να διαβάσετε ολόκληρο το νήμα συνομιλίας και να προσθέσετε απάντηση.

## Απάντηση σε εισιτήριο

Μόλις ένα εισιτήριο είναι ανοιχτό, εσείς και ο πράκτορας υποστήριξης ανταλλάσσετε μηνύματα στο ίδιο νήμα. Για να προσθέσετε απάντηση:

1. Ανοίξτε το εισιτήριο από τη λίστα σας.
2. Κάντε κύλιση στο πεδίο απάντησης στο κάτω μέρος.
3. Γράψτε την απάντησή σας και επισυνάψτε αρχεία εάν χρειάζεται.
4. Κάντε κλικ στο **Send**.

Και τα δύο μέρη λαμβάνουν ειδοποιήσεις όταν προστίθεται νέο μήνυμα στο νήμα.

## Διαχείριση εισιτηρίων ως πράκτορας υποστήριξης

Εάν ο διαχειριστής σας σας έχει αναθέσει σε μία ή περισσότερες κατηγορίες εισιτηρίων, θα βλέπετε εισερχόμενα εισιτήρια από εκπαιδευόμενους ή συναδέλφους στην ουρά σας.

Για να απαντήσετε σε ένα ανατεθειμένο εισιτήριο:

1. Ανοίξτε τη λίστα εισιτηρίων σας — τα ανατεθειμένα εισιτήρια εμφανίζονται μαζί με τα εισιτήρια που έχετε υποβάλει.
2. Κάντε κλικ σε ένα εισιτήριο για να διαβάσετε το μήνυμα του αιτούντος.
3. Γράψτε μια απάντηση και κάντε κλικ στο **Send**. Η κατάσταση του εισιτηρίου ενημερώνεται αυτόματα.
4. Όταν το ζήτημα επιλυθεί, αλλάξτε την κατάσταση σε **Closed**.

Μπορείτε επίσης να αλλάξετε την **προτεραιότητα** ενός εισιτηρίου (Low, Normal, High) για να βοηθήσετε στην ταξινόμηση της ουράς σας.

> Η πρόσβαση στις κατηγορίες εισιτηρίων ελέγχεται από τον διαχειριστή της πλατφόρμας. Εάν χρειάζεται να προστεθείτε ως πράκτορας υποστήριξης για μια κατηγορία, επικοινωνήστε με τον διαχειριστή σας. Δείτε τον Οδηγό διαχειριστή [Tickets Settings](../admin-guide/platform-settings/ticket-settings.md) για επιλογές διαμόρφωσης.
