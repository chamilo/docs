# Παρακολούθηση και Αναφορές

Το Chamilo παρακολουθεί τη δραστηριότητα των εκπαιδευομένων σε όλη την πλατφόρμα, προσφέροντάς σας λεπτομερή εικόνα για την πρόοδό τους.

* **[Παρακολούθηση εκπαιδευομένων](learner-tracking.md)** — Παρακολουθήστε την ατομική δραστηριότητα των εκπαιδευομένων: χρόνους σύνδεσης, χρόνο που αφιερώθηκε, σελίδες που επισκέφθηκαν και χρήση εργαλείων
* **[Αναφορές μαθήματος](course-reports.md)** — Δείτε συγκεντρωτικά δεδομένα για όλους τους εκπαιδευόμενους ενός μαθήματος
* **[Πιστοποιητικά και δεξιότητες](certificates-and-skills.md)** — Απονείμετε πιστοποιητικά βάσει βαθμολογιών του βαθμολογίου και επικυρώστε τις αποκτηθείσες δεξιότητες

## Πρόσβαση στις αναφορές

Από το μάθημά σας, κάντε κλικ στο εργαλείο **Παρακολούθηση** <img src="/.gitbook/assets/icons/mdi-chart-box.svg" alt="Παρακολούθηση" data-size="line"> στην αρχική σελίδα του μαθήματος. Μπορείτε επίσης να αποκτήσετε πρόσβαση στις αναφορές από τον σύνδεσμο **Αναφορές** στην πλαϊνή γραμμή για μια επισκόπηση σε πολλά μαθήματα.

Οι εκπαιδευτές βλέπουν δεδομένα αναφορών για τα μαθήματα που διδάσκουν. Οι επιβλέποντες συνεδρίας βλέπουν δεδομένα σε όλα τα μαθήματα της συνεδρίας τους.
