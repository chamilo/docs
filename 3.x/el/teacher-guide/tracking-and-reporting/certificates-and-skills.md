# Πιστοποιητικά και Δεξιότητες

Το Chamilo σάς επιτρέπει να απονέμετε πιστοποιητικά σε εκπαιδευόμενους που πληρούν συγκεκριμένα κριτήρια επίτευξης και να επικυρώνετε δεξιότητες που συνδέονται με αυτές τις επιτεύξεις.

## Πώς λειτουργούν τα πιστοποιητικά

Τα πιστοποιητικά συνδέονται με τις **Αξιολογήσεις** (που ονομάζονται επίσης Gradebook). Όταν ο βαθμός ενός εκπαιδευόμενου ισούται ή υπερβαίνει το ελάχιστο όριο που ορίζετε, ένα πιστοποιητικό γίνεται διαθέσιμο για λήψη.

Η ροή εργασίας είναι:

1. Ρυθμίστε τις [Αξιολογήσεις](../assessing-learners/gradebook.md) με τις ασκήσεις, τις εργασίες και τις άλλες βαθμολογούμενες δραστηριότητές σας
2. Ορίστε μια **ελάχιστη βαθμολογία πιστοποίησης** (π.χ. 70%)
3. Όταν ένας εκπαιδευόμενος φτάσει αυτή τη βαθμολογία, μπορεί να κατεβάσει το πιστοποιητικό του (είτε μέσα στο ίδιο το εργαλείο Αξιολογήσεων, είτε από ένα μονοπάτι μάθησης αν έχετε ρυθμίσει το τελικό βήμα για αυτό). Ως εκπαιδευτής, μπορείτε επίσης να χρησιμοποιήσετε την ενέργεια **Generate certificates** στο gradebook για να δημιουργήσετε τα PDF μαζικά για όλους τους επιλέξιμους εκπαιδευόμενους.

## Πρότυπα πιστοποιητικών

Τα πιστοποιητικά χρησιμοποιούν πρότυπα που ορίζει ο διαχειριστής της πλατφόρμας. Το πρότυπο συνήθως περιλαμβάνει:

* Το όνομα του εκπαιδευόμενου
* Το όνομα του μαθήματος
* Την ημερομηνία ολοκλήρωσης
* Τη βαθμολογία που επιτεύχθηκε
* Έναν κωδικό QR ή URL για διαδικτυακή επαλήθευση

## Ισχύς και λήξη πιστοποιητικών

Τα πιστοποιητικά μπορούν να ρυθμιστούν ώστε να λήγουν μετά από δεδομένο αριθμό ημερών. Στις ρυθμίσεις των [Αξιολογήσεων](../assessing-learners/gradebook.md) για την ριζική κατηγορία, μόλις ενεργοποιηθεί το **Generate certificates**, εμφανίζεται ένα πεδίο **Certificate validity (days)**. Αφήστε το στο `0` (η προεπιλογή) για πιστοποιητικά που δεν λήγουν ποτέ, ή ορίστε έναν αριθμό ημερών ώστε το πιστοποιητικό να λήγει τόσες ημέρες μετά την έκδοσή του.

Η ημερομηνία λήξης κάθε πιστοποιητικού υπολογίζεται αυτόματα από αυτή τη ρύθμιση όταν δημιουργείται (ή αναδημιουργείται) — δεν την ορίζετε πιστοποιητικό προς πιστοποιητικό. Η λίστα **Certificates** εμφανίζει μια στήλη **Expiry date** για κάθε εκπαιδευόμενο, με την ένδειξη **Never expires** όταν δεν ισχύει περίοδος ισχύος.

Αν η κατηγορία δεν έχει ρυθμισμένη περίοδο ισχύος, μπορείτε ακόμη να ορίσετε (ή να αλλάξετε) χειροκίνητα την ημερομηνία λήξης ενός μεμονωμένου εκπαιδευόμενου: κάντε κλικ στο μολύβι **Edit expiry date** δίπλα στην καταχώρισή του και επιλέξτε μια ημερομηνία. Αυτό το κουμπί είναι διαθέσιμο μόνο όταν η ίδια η κατηγορία δεν έχει περίοδο ισχύος — μόλις οριστεί περίοδος ισχύος, οι ημερομηνίες λήξης διαχειρίζονται αυτόματα και δεν μπορούν πλέον να επεξεργαστούν πιστοποιητικό προς πιστοποιητικό.

![Η λίστα πιστοποιητικών που εμφανίζει τη στήλη ημερομηνίας λήξης για τρεις εκπαιδευόμενους](../../.gitbook/assets/gradebook-certificates-expiry-dates.png)

### Υπενθύμιση εκπαιδευομένων για επερχόμενη ή παρελθούσα λήξη

Ανοίξτε τη λίστα **Certificates** για την αξιολόγησή σας και κάντε κλικ στο κουμπί **Expiring certificates** <img src="../../.gitbook/assets/icons/mdi-calendar-clock.svg" alt="Expiring certificates" data-size="line"> για να δείτε ποια πιστοποιητικά εκπαιδευομένων έχουν λήξει ή πρόκειται να λήξουν. Η σελίδα εμφανίζει, ανά εκπαιδευόμενο: την **Expiry date** του πιστοποιητικού, την **Status** του (**Expired** ή **Expiring soon**) και πότε στάλθηκε **Last reminder sent** σχετικά με αυτό (ή **Never**). Χρησιμοποιήστε το **Days ahead** για να διευρύνετε ή να περιορίσετε πόσο μακριά στο μέλλον κοιτάζει το «λήγει σύντομα».

![Η σελίδα λήγοντων πιστοποιητικών που παραθέτει ένα ληγμένο και ένα που πρόκειται να λήξει](../../.gitbook/assets/gradebook-certificate-expirations.png)

Για να ειδοποιήσετε τους εκπαιδευόμενους οι ίδιοι:

1. Επιλέξτε τους εκπαιδευόμενους που θέλετε να υπενθυμίσετε (ή επιλέξτε όλους)
2. Κάντε κλικ στο **Send notification**
3. Ελέγξτε την προεπισκόπηση του ηλεκτρονικού μηνύματος που θα σταλεί — εμφανίζονται ξεχωριστές προεπισκοπήσεις για τη διατύπωση «λήγει σύντομα» και «έληξε», ανάλογα με το σε ποια περίπτωση εμπίπτουν οι επιλεγμένοι εκπαιδευόμενοι
4. Επιβεβαιώστε κάνοντας ξανά κλικ στο **Send notification** στο παράθυρο διαλόγου

![Το παράθυρο επιβεβαίωσης αποστολής ειδοποίησης με προεπισκόπηση της διατύπωσης των μηνυμάτων για λήγοντα και ληγμένα πιστοποιητικά](../../.gitbook/assets/gradebook-certificate-expiry-notification.png)

Κάθε εκπαιδευόμενος ειδοποιείται στη δική του ρυθμισμένη γλώσσα, τόσο μέσω ηλεκτρονικού ταχυδρομείου όσο και μέσω εσωτερικού μηνύματος του Chamilo. Η εκ νέου αποστολή για το ίδιο πιστοποιητικό και την ίδια ημερομηνία λήξης είναι ασφαλής — το Chamilo παρακολουθεί τι έχει ήδη σταλεί ανά πιστοποιητικό και δεν θα στείλει ανεπιθύμητες διπλές υπενθυμίσεις, εκτός αν τις στείλετε ρητά ξανά.

Οι διαχειριστές μπορούν επίσης να προγραμματίσουν τις ίδιες υπενθυμίσεις αυτόματα, σε επαναλαμβανόμενη βάση, χωρίς να χρειάζεται ένας εκπαιδευτής να τις ενεργοποιήσει χειροκίνητα — δείτε [Ρυθμίσεις εργασιών Cron](../../admin-guide/platform-settings/crons-settings.md#certificate-expiry-reminders).

## Δεξιότητες

Οι δεξιότητες αντιπροσωπεύουν ικανότητες που αποκτούν οι εκπαιδευόμενοι. Στο Chamilo:

* Οι δεξιότητες μπορούν να συνδεθούν με επιτεύξεις του gradebook
* Όταν ένας εκπαιδευόμενος αποκτά πιστοποιητικό, οποιεσδήποτε συνδεδεμένες δεξιότητες επικυρώνονται αυτόματα
* Οι δεξιότητες συσσωρεύονται στο προφίλ του εκπαιδευόμενου, δημιουργώντας ένα αρχείο ικανοτήτων
* Οι δεξιότητες μπορούν να οργανωθούν ιεραρχικά (π.χ. «Ανάλυση δεδομένων» κάτω από «Ερευνητικές μέθοδοι»)
* Οι δεξιότητες μπορούν να αξιολογηθούν περαιτέρω από ομοτίμους (αξιολόγηση 360°)

## Προβολή κατάστασης πιστοποιητικών και δεξιοτήτων

Ως εκπαιδευτής, μπορείτε να δείτε:

* Ποιοι εκπαιδευόμενοι έχουν αποκτήσει πιστοποιητικά στο μάθημά σας
* Ποιες δεξιότητες έχουν επικυρωθεί
* Την πρόοδο των εκπαιδευομένων προς το όριο πιστοποίησης
* Ποια πιστοποιητικά έχουν λήξει ή πρόκειται να λήξουν σύντομα, και αν έχει ήδη σταλεί υπενθύμιση για αυτά

Οι εκπαιδευόμενοι μπορούν να δουν τα δικά τους πιστοποιητικά και τις επικυρωμένες δεξιότητες από το προφίλ τους, και μπορούν να έχουν πρόσβαση στον Τροχό Δεξιοτήτων για να ελέγξουν ποιες δεξιότητες έχουν ζήτηση στον οργανισμό τους.

## Συμβουλές

* **Ορίστε σαφείς προσδοκίες** — Πείτε στους εκπαιδευόμενους στην αρχή του μαθήματος τι πρέπει να επιτύχουν για να αποκτήσουν πιστοποιητικό
* **Χρησιμοποιήστε ουσιαστικά ονόματα δεξιοτήτων** — Οι δεξιότητες πρέπει να περιγράφουν τι μπορεί να κάνει ο εκπαιδευόμενος, όχι απλώς το όνομα του μαθήματος
* **Συνδυάστε με χαρτοφυλάκια** — Ενθαρρύνετε τους εκπαιδευόμενους να προσθέτουν τα πιστοποιητικά τους στο χαρτοφυλάκιό τους
* **Επεκτείνετε τα πιστοποιητικά** — Ζητήστε από τον διαχειριστή σας να ενεργοποιήσει το πρόσθετο [Custom Certificate](../plugins/custom-certificate.md) για να αξιοποιήσετε ακόμη μεγαλύτερη ισχύ προτύπων πιστοποιητικών
* **Ορίστε περίοδο ισχύος για πιστοποιήσεις που σχετίζονται με συμμόρφωση** — Αν μια πιστοποίηση χρειάζεται περιοδική ανανέωση (π.χ. εκπαίδευση ασφάλειας), ορίστε την **Ισχύ πιστοποιητικού (ημέρες)** ώστε οι εκπαιδευόμενοι να λαμβάνουν υπενθύμιση πριν λήξει
