# Ημερολόγιο Μάθησης

Το Ημερολόγιο Μάθησης <img src="../../.gitbook/assets/icons/mdi-calendar-text.svg" alt="Ημερολόγιο Μάθησης" data-size="line"> βοηθά στον σχεδιασμό μικτής κατάρτισης ή κατάρτισης τύπου μαθητείας που συνδυάζει χρόνο στην τάξη με πρακτική εκτός χώρου. Δημιουργείτε ένα ημερολόγιο χαρακτηρίζοντας κάθε ημέρα ως **Απασχολημένη**, **Εξέταση** ή **Ελεύθερη**, αναθέτετε εκπαιδευόμενους σε αυτό και το προσωπικό τους πρόγραμμα εμφανίζει τότε αυτές τις προγραμματισμένες ημέρες.

## Πρόσβαση στο εργαλείο

Μόλις ενεργοποιηθεί, εμφανίζεται ένα εικονίδιο **Ημερολόγιο μάθησης** στον χώρο **Ο χώρος μου** (την περιοχή αναφορών σας). Ανοίγει μια λίστα με τα ημερολόγια που έχετε δημιουργήσει, με επιλογές για προσθήκη, επεξεργασία, αντιγραφή, διαγραφή και ανάθεση εκπαιδευομένων σε καθένα από αυτά.

## Δημιουργία ημερολογίου

1. Δημιουργήστε ένα νέο ημερολόγιο
2. Κάντε κλικ σε μια ημέρα για να την εναλλάξετε μεταξύ **Απασχολημένη → Εξέταση → Ελεύθερη → εκκαθάριση**
3. Αναθέστε τους εκπαιδευόμενους που πρέπει να ακολουθούν αυτό το ημερολόγιο

Οι ανατεθειμένοι εκπαιδευόμενοι βλέπουν τις προγραμματισμένες ημέρες τους στο δικό τους πρόγραμμα και οι αναφορές συγκρίνουν τις προγραμματισμένες ημέρες με την πραγματική ολοκλήρωση των διαδρομών μάθησής τους.

## Συμβουλές

* **Ένα ημερολόγιο ανά εκπαιδευόμενο κάθε φορά** — Ένας εκπαιδευόμενος μπορεί να ανατεθεί μόνο σε ένα ημερολόγιο, επομένως σχεδιάστε γύρω από ομάδες (cohorts) αντί να προσπαθείτε να επιθέσετε πολλά ημερολόγια σε ένα άτομο
* **Πρόκειται για λειτουργία πρώιμου σταδίου** — Είναι ανεξάρτητη από οποιοδήποτε μεμονωμένο μάθημα, επομένως μην περιμένετε την ίδια τελειότητα με τα βασικά εργαλεία του Chamilo· επαληθεύστε ότι ταιριάζει στη μορφή κατάρτισής σας πριν βασιστείτε σε αυτήν για μια πραγματική ομάδα
