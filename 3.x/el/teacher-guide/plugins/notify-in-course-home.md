# Ειδοποίηση στην Αρχική Σελίδα του Μαθήματος

Η Ειδοποίηση στην Αρχική Σελίδα του Μαθήματος <img src="../../.gitbook/assets/icons/mdi-bell-ring-outline.svg" alt="Ειδοποίηση στην Αρχική Σελίδα του Μαθήματος" data-size="line"> σάς επιτρέπει να εμφανίζετε ένα αναδυόμενο μήνυμα σε όποιον επισκέπτεται την αρχική σελίδα του μαθήματός σας — χρήσιμο για μια ανακοίνωση, μια ειδοποίηση υποχρεωτικής ανάγνωσης ή μια πύλη τύπου «κάντε κλικ εδώ για να συνεχίσετε».

## Ορισμός ειδοποίησης

Μόλις ενεργοποιηθεί, στις **Ρυθμίσεις** <img src="../../.gitbook/assets/icons/mdi-cog.svg" alt="Ρυθμίσεις" data-size="line"> του μαθήματός σας εμφανίζεται το κουμπί **Ορισμός μίας ειδοποίησης στην αρχική σελίδα**. Ανοίγει μια φόρμα όπου γράφετε την ειδοποίηση (εμπλουτισμένο κείμενο) και προαιρετικά ορίζετε έναν **Σύνδεσμο λήξης**.

* **Με σύνδεσμο λήξης** — Το αναδυόμενο παράθυρο εμφανίζει ένα κουμπί που οδηγεί σε αυτόν τον σύνδεσμο και συνεχίζει να εμφανίζεται μέχρι ο εκπαιδευόμενος να κάνει κλικ σε αυτό
* **Χωρίς σύνδεσμο** — Η ειδοποίηση εμφανίζεται ξανά σε κάθε επισκέπτη, κάθε φορά που ανοίγει την αρχική σελίδα του μαθήματος

Χρησιμοποιήστε την επιλογή **Διαγραφή ειδοποίησης στην αρχική σελίδα του μαθήματος** για να την αφαιρέσετε.

## Συμβουλές

* **Μόνο μία ειδοποίηση ανά μάθημα** — Η δημιουργία νέας αντικαθιστά ό,τι υπήρχε προηγουμένως· δεν υπάρχει τρόπος να τοποθετήσετε πολλές σε ουρά
* **Προεπισκόπηση της μορφοποίησης** — Η ειδοποίηση εμφανίζεται ως ακατέργαστο HTML σε αναδυόμενο παράθυρο, επομένως ελέγξτε ότι το εμπλουτισμένο κείμενο αποδίδεται όπως περιμένετε πριν τη δημοσιεύσετε
* **Χρησιμοποιήστε τον σύνδεσμο λήξης για οτιδήποτε είναι χρονικά ευαίσθητο** — Χωρίς αυτόν, η ίδια ειδοποίηση συνεχίζει να εμφανίζεται επ’ αόριστον, κάτι που μπορεί να γίνει επαναλαμβανόμενο για τους εκπαιδευόμενους που επιστρέφουν
