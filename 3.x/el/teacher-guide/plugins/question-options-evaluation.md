# Αξιολόγηση Επιλογών Ερώτησης

Η Αξιολόγηση Επιλογών Ερώτησης <img src="/.gitbook/assets/icons/mdi-calculator-variant.svg" alt="Αξιολόγηση Επιλογών Ερώτησης" data-size="line"> σας επιτρέπει να εφαρμόσετε έναν τύπο αρνητικής βαθμολόγησης (ποινής) στη βαθμολόγηση ενός τεστ, αντί της προεπιλεγμένης συμπεριφοράς του Chamilo που απλώς αθροίζει τις σωστές απαντήσεις.

## Ορισμός Τύπου

Μόλις ενεργοποιηθεί, εμφανίζεται ένα επιπλέον εικονίδιο δίπλα σε κάθε τεστ στη λίστα του εργαλείου **Τεστ** του μαθήματος. Κάνοντας κλικ σε αυτό ανοίγει μια μικρή φόρμα όπου επιλέγετε ένα από τα εξής:

* **Χωρίς τύπο** — Κανονική βαθμολόγηση του Chamilo (προεπιλογή)
* **Επανυπολογισμός βαθμών ερωτήσεων** — Ανακατανέμει τη στάθμιση των επιλογών χωρίς ποινή
* **Επιτυχίες − Αποτυχίες**
* **Επιτυχίες − Αποτυχίες / 2**
* **Επιτυχίες − Αποτυχίες / 3**

Ο επιλεγμένος τύπος εφαρμόζεται μόνο σε εκείνο το συγκεκριμένο τεστ.

> Αυτή η ρύθμιση δεν αλλάζει τα ίδια τα βάρη των ερωτήσεων ή των απαντήσεων — αλλάζει τον τρόπο υπολογισμού του τελικού βαθμού. Αν το πρόσθετο είναι απενεργοποιημένο ή δεν έχει επιλεγεί τύπος, το Chamilo επιστρέφει στην αρχική του βαθμολόγηση.

## Συμβουλές

* **Δοκιμάστε πρώτα σε αντίγραφο** — Η αλλαγή ενός τύπου μπορεί να αλλάξει τους βαθμούς που λαμβάνουν τελικά οι φοιτητές σε εκείνο το τεστ· δοκιμάστε το σε ένα αντίγραφο του τεστ πριν το εφαρμόσετε σε ένα ενεργό
* **Εξηγήστε την αλλαγή στους φοιτητές** — Ένας τύπος ποινής μπορεί να προκαλέσει έκπληξη αν οι εκπαιδευόμενοι είναι συνηθισμένοι στην απλή βαθμολόγηση σωστών απαντήσεων· αναφέρετέ το στις οδηγίες σας
