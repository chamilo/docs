# Παρακολούθηση Ασκήσεων

Η Παρακολούθηση Ασκήσεων <img src="/.gitbook/assets/icons/mdi-camera.svg" alt="Παρακολούθηση Ασκήσεων" data-size="line"> χρησιμοποιεί την κάμερα web του εκπαιδευόμενου για τη λήψη φωτογραφιών ταυτοποίησης κατά τη διάρκεια μιας προσπάθειας τεστ — μια φωτογραφία εγγράφου ταυτότητας και μια φωτογραφία του προσώπου του εκπαιδευόμενου — για σκοπούς ακεραιότητας εξετάσεων.

## Επισήμανση ενός τεστ

Ανοίξτε τις ρυθμίσεις του τεστ και επιλέξτε την επιλογή **Παρακολούθηση Ασκήσεων**. Μόλις επισημανθεί, οι εκπαιδευόμενοι που επιχειρούν το συγκεκριμένο τεστ βλέπουν ένα μικρό αιωρούμενο γραφικό στοιχείο κάμερας web και καλούνται να τραβήξουν τις δύο φωτογραφίες πριν ή κατά τη διάρκεια της προσπάθειάς τους.

## Επισκόπηση λήψεων

[inferred] Οι ληφθείσες φωτογραφίες εξετάζονται μέσω της οθόνης αναφορών που προστίθεται από το πρόσθετο **[Exercise Focused](exercise-focused.md)**, το οποίο αναπτύχθηκε παράλληλα με αυτό το πρόσθετο — εάν η πλατφόρμα σας έχει ενεργοποιημένη μόνο την Παρακολούθηση Ασκήσεων και όχι το Exercise Focused, ρωτήστε τον διαχειριστή σας πώς προορίζεται να γίνεται η επισκόπηση των ληφθεισών φωτογραφιών στην εγκατάστασή σας.

## Σημεία που πρέπει να γνωρίζετε

* **Διαχειρίζεται ευαίσθητα προσωπικά δεδομένα** — Οι φωτογραφίες εγγράφων ταυτότητας αποτελούν κατηγορία δεδομένων που πολλά ιδρύματα και κανονισμοί προστασίας απορρήτου αντιμετωπίζουν με ιδιαίτερη προσοχή. Επιβεβαιώστε με τον διαχειριστή σας ότι η χρήση αυτού του πρόσθετου συνάδει με τις υποχρεώσεις προστασίας δεδομένων του ιδρύματός σας πριν βασιστείτε σε αυτό
* **Οι φωτογραφίες διατηρούνται προσωρινά** — Ο διαχειριστής σας ορίζει περίοδο διατήρησης, μετά την οποία οι ληφθείσες φωτογραφίες διαγράφονται αυτόματα
* **Πρόκειται για λειτουργία πρώιμου σταδίου** — Αναμένετε ατέλειες· επαληθεύστε ότι η ροή λήψης λειτουργεί όπως αναμένεται σε δοκιμαστική εκτέλεση πριν τη χρησιμοποιήσετε σε πραγματική εξέταση
