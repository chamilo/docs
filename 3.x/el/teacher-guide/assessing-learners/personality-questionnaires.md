# Ερωτηματολόγια προσωπικότητας

Το Chamilo 3.1 περιλαμβάνει ερωτηματολόγια τύπου προσωπικότητας στο σύγχρονο εργαλείο **Έρευνες**. Αυτά τα ερωτηματολόγια παράγουν ένα **προφίλ προτιμήσεων**, όχι μια βαθμολογούμενη άσκηση ή μια κλινική ψυχολογική αξιολόγηση.

## Δημιουργία ερωτηματολογίου

1. Ανοίξτε το εργαλείο Έρευνες και δημιουργήστε μια νέα έρευνα.
2. Στη διαμόρφωσή της, επιλέξτε τον τύπο έρευνας **προσωπικότητας**.
3. Ανοίξτε την **Επεξεργασία ερωτήσεων** ή τον επεξεργαστή ερωτήσεων της έρευνας.
4. Ορίστε τις **Κατηγορίες προσωπικότητας** πριν προσθέσετε ερωτήσεις προσωπικότητας. Κάθε επιλογή απάντησης πρέπει να ανήκει σε μια κατηγορία.
5. Προσθέστε ερωτήσεις, διαμορφώστε τις απαντήσεις τους και τις αναθέσεις κατηγοριών και αποθηκεύστε τις αλλαγές σας.
6. Προεπισκοπήστε την εμπειρία του εκπαιδευόμενου πριν διανείμετε την έρευνα.

Διατίθενται τέσσερις τύποι ερωτήσεων προσωπικότητας:

| Τύπος | Πώς απαντούν οι εκπαιδευόμενοι |
| --- | --- |
| Επιλογή προσωπικότητας | Επιλογή μεταξύ επιλογών που σχετίζονται με κατηγορίες |
| Συμφωνία προσωπικότητας | Δήλωση συμφωνίας με τα παρουσιαζόμενα στοιχεία |
| Κλίμακα προσωπικότητας | Αξιολόγηση στοιχείων σε πεντάβαθμη κλίμακα |
| Σειρά προσωπικότητας | Κατάταξη επιλογών από την περισσότερο στην λιγότερο προτιμώμενη |

Η διαμόρφωση περιλαμβάνει επικύρωση απαντήσεων και βαθμολόγηση προτιμήσεων βάσει κατηγοριών. Ελέγξτε προσεκτικά τις επιλογές και τις αναθέσεις κάθε ερώτησης: μια επιλογή που σχετίζεται με λανθασμένη κατηγορία αλλάζει το προκύπτον προφίλ.

## Προβολή αποτελεσμάτων

Μετά την ολοκλήρωση του ερωτηματολογίου, ένας εκπαιδευόμενος μπορεί να δει το **Προφίλ προσωπικότητάς σας** όταν η έρευνα επιστρέφει δεδομένα προφίλ. Η σελίδα αναφορών έρευνας του διδάσκοντα μπορεί να εμφανίζει **Προφίλ προσωπικότητας — όλοι οι εκπαιδευόμενοι**. Τα αποτελέσματα παρουσιάζονται με οπτικοποιήσεις ράβδων/ραντάρ και βαθμολογίες κατηγοριών. Η αντιγραφή έρευνας διατηρεί τη διαμόρφωση του ερωτηματολογίου προσωπικότητας.

## Βαθμολόγιο και ερμηνεία

Τα ερωτηματολόγια προσωπικότητας δεν μπορούν να βαθμολογηθούν μέσω του Βαθμολογίου ως συνήθεις αξιολογήσεις. Εξηγήστε στους εκπαιδευόμενους ότι τα αποτελέσματα αντικατοπτρίζουν τις απαντήσεις στις διαμορφωμένες κατηγορίες, όχι μια διάγνωση, κατάσταση επιτυχίας/αποτυχίας ή επικυρωμένο τεστ προσωπικότητας. Ελέγξτε τις ρυθμίσεις απορρήτου και ορατότητας αναφορών πριν συλλέξετε προσωπικές απαντήσεις.
