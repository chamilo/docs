# Έρευνες

Το εργαλείο ερευνών σάς επιτρέπει να δημιουργείτε ερωτηματολόγια για τη συλλογή ανατροφοδότησης από τους εκπαιδευόμενούς σας. Οι έρευνες είναι χρήσιμες για αξιολογήσεις μαθημάτων, εκτιμήσεις αναγκών και δημοσκοπήσεις γνώμης.

## Δημιουργία έρευνας

1. Ανοίξτε το εργαλείο **Έρευνες** <img src="../../.gitbook/assets/icons/mdi-form-dropdown.svg" alt="Έρευνες" data-size="line"> από την αρχική σελίδα του μαθήματος
2. Κάντε κλικ στο **Δημιουργία έρευνας**
3. Συμπληρώστε τα στοιχεία της έρευνας:
   * **Κωδικός** — Πρόκειται για έναν μοναδικό κωδικό της έρευνας. Θα χρησιμοποιείται σε μηνύματα ηλεκτρονικού ταχυδρομείου και συνδέσμους.
   * **Τίτλος** — Το όνομα της έρευνας
   * **Υπότιτλος** — Προαιρετική δευτερεύουσα επικεφαλίδα
   * **Ημερομηνία έναρξης** — Από πότε η έρευνα θα είναι ανοιχτή για συμμετοχή
   * **Ημερομηνία λήξης** — Μέχρι πότε η έρευνα θα είναι ανοιχτή για συμμετοχή
   * **Ανώνυμη** — Αν οι απαντήσεις είναι ανώνυμες ή συνδέονται με μεμονωμένους εκπαιδευόμενους
   * **Ορατότητα αποτελεσμάτων** — Ποιος μπορεί να δει τα αποτελέσματα (μόνο ο διδάσκων, διδάσκων και φοιτητές, όλοι)
   * **Εισαγωγή** — Μήνυμα που εμφανίζεται στους εκπαιδευόμενους πριν ξεκινήσουν την έρευνα
   * **Μήνυμα ευχαριστίας** — Μήνυμα που εμφανίζεται μετά την υποβολή
4. Αποθήκευση

### Ρυθμίσεις για προχωρημένους

* **Βαθμολόγηση στο εργαλείο αξιολόγησης** — Αν θα συμπεριληφθεί η κατάσταση απάντησης αυτής της έρευνας στο εργαλείο αξιολόγησης (gradebook). Όποιος έχει ολοκληρώσει την έρευνα λαμβάνει 100%, όλοι οι υπόλοιποι 0%
* **Γονική έρευνα** — Δεν χρησιμοποιείται ουσιαστικά σε αυτό το στάδιο (κληρονομημένη λειτουργία)
* **Μία ερώτηση ανά σελίδα** — Στυλ παρουσίασης των ερωτήσεων
* **Ενεργοποίηση λειτουργίας ανάμειξης** — Αν θα αναμειγνύονται οι ερωτήσεις
* **Εμφάνιση αριθμού ερώτησης** — Αν θα εμφανίζονται (αυτόματα παραγόμενοι) αριθμοί ερωτήσεων

## Προσθήκη ερωτήσεων

Αφού δημιουργηθεί η έρευνα, προσθέστε ερωτήσεις:

1. Επιλέξτε τον τύπο ερώτησης:
   * **Ναι/Όχι** — Απλή δυαδική επιλογή
   * **Πολλαπλή επιλογή** — Επιλογή μίας απάντησης από αρκετές επιλογές
   * **Πολλαπλή απάντηση** — Επιλογή μίας ή περισσότερων απαντήσεων από αρκετές επιλογές
   * **Ανοιχτού τύπου** — Απάντηση ελεύθερου κειμένου
   * **Αναπτυσσόμενη λίστα** — Επιλογή από αναπτυσσόμενη λίστα
   * **Ποσοστό** — Επιλογή τιμής ποσοστού
   * **Βαθμολογία** — Αξιολόγηση σε αριθμητική κλίμακα
   * **Σχόλιο** — Μπλοκ κειμένου (όχι ερώτηση) για προσθήκη οδηγιών μεταξύ ερωτήσεων
   * **Πολλαπλή επιλογή με επιλογή «άλλο»** — Επιλογή μίας απάντησης από αρκετές επιλογές, με εναλλακτική επιλογή
   * **Επιλεκτική εμφάνιση** — Ειδικός τύπος που σας επιτρέπει να προσαρμόζετε τη ροή των ερωτήσεων με βάση προηγούμενες απαντήσεις
   * **Αλλαγή σελίδας** — Προσθήκη αλλαγών σελίδας στη ροή των ερωτήσεων. Χρήσιμο μόνο αν **δεν** είχε επιλεγεί η επιλογή «Μία ερώτηση ανά σελίδα» στο προηγούμενο βήμα
2. Διαμορφώστε το κείμενο της ερώτησης και τις επιλογές απάντησης
3. Αποθήκευση

Κάθε ερώτηση μπορεί να οριστεί ως υποχρεωτική. Αν δεν το κάνετε, η παράλειψη οποιασδήποτε ερώτησης θα θεωρείται αποδεκτή συμπεριφορά.

## Δημοσίευση έρευνας

Αφού προσθέσετε όλες τις ερωτήσεις:

1. Κάντε κλικ στο **Δημοσίευση**
2. Επιλέξτε τους παραλήπτες — Επιλέξτε συγκεκριμένους εκπαιδευόμενους ή ομάδες (τους επιλέγετε εσείς). Το κουμπί **Προσθήκη εκπαιδευομένων** προσθέτει όλους τους εκπαιδευόμενους με μία ενέργεια και αφήνει πίσω τους διδάσκοντες
3. Προσθήκη επιπλέον χρηστών — Σας επιτρέπει να προσκαλέσετε χρήστες εκτός του Chamilo να συμμετάσχουν στην έρευνα. Θα λάβουν μήνυμα ηλεκτρονικού ταχυδρομείου με σύνδεσμο και θα εμφανίζονται με τη διεύθυνση ηλεκτρονικού ταχυδρομείου τους στις λεπτομέρειες της έρευνας
4. Θέμα μηνύματος
5. Κείμενο μηνύματος — Εξηγήστε τι αφορά η έρευνα και πότε/πώς να απαντήσουν
6. Διατίθενται διάφορες επιλογές για επανάληψη προσκλήσεων
7. Επιβεβαίωση

Οι εκπαιδευόμενοι λαμβάνουν πρόσκληση (ως μήνυμα ηλεκτρονικού ταχυδρομείου) για να συμπληρώσουν την έρευνα.

Στο κάτω μέρος της σελίδας δημοσίευσης υπάρχει σύνδεσμος για να προσκαλέσετε ακόμη περισσότερους εξωτερικούς χρήστες να συμμετάσχουν. Οι συμμετέχοντες που χρησιμοποιούν αυτόν τον σύνδεσμο δεν θα ταυτοποιούνται και θα εμφανίζονται ως ανώνυμοι στα αποτελέσματα της έρευνας.

## Προβολή αποτελεσμάτων

![Αποτελέσματα έρευνας με γραφήματα και ανάλυση ποσοστών για κάθε ερώτηση](../../.gitbook/assets/survey-results-charts.png)

Αφού έχουν απαντήσει οι εκπαιδευόμενοι:

1. Ανοίξτε την έρευνα
2. Κάντε κλικ στο **Αποτελέσματα** ή **Αναφορά**
3. Δείτε συνοπτικά τις απαντήσεις:
   * Γραφήματα και ποσοστά για τις κλειστές ερωτήσεις
   * Μεμονωμένες απαντήσεις κειμένου για τις ερωτήσεις ανοιχτού τύπου
   * Ποσοστό ολοκλήρωσης (πόσοι προσκεκλημένοι απάντησαν)

Μπορείτε να εξαγάγετε τα αποτελέσματα σε υπολογιστικό φύλλο για περαιτέρω ανάλυση.

## Συμβουλές

* **Κρατήστε την σύντομη** — Οι εκπαιδευόμενοι είναι πιο πιθανό να ολοκληρώσουν συντομότερες έρευνες
* **Χρησιμοποιήστε ανώνυμη λειτουργία** — Για ειλικρινή ανατροφοδότηση, ενεργοποιήστε τις ανώνυμες απαντήσεις
* **Επιλέξτε τη σωστή στιγμή** — Στείλτε έρευνες στη μέση του μαθήματος για να κάνετε προσαρμογές, όχι μόνο αξιολογήσεις στο τέλος του μαθήματος
