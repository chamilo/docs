# Εργασίες

Το εργαλείο εργασιών (ονομάζεται επίσης «δημοσιεύσεις μαθητών») σας επιτρέπει να συλλέγετε εργασίες από τους εκπαιδευόμενους — δοκίμια, έργα, εκθέσεις ή οποιαδήποτε υποβολή βάσει αρχείου — και να τις βαθμολογείτε.

## Δημιουργία εργασίας

1. Ανοίξτε το εργαλείο **Εργασίες** <img src="/.gitbook/assets/icons/mdi-inbox-full.svg" alt="Εργασίες" data-size="line"> από την αρχική σελίδα του μαθήματος
2. Κάντε κλικ στο **Δημιουργία εργασίας**
3. Συμπληρώστε τα στοιχεία:
   * **Όνομα εργασίας** — Το όνομα της εργασίας (π.χ. «Τελική έκθεση έργου»)
   * **Περιγραφή** — Οδηγίες για τους εκπαιδευόμενους, συμπεριλαμβανομένου του τι να υποβάλουν και πώς θα αξιολογηθεί (υποστηρίζει εμπλουτισμένο κείμενο)
   * **Μέγιστη βαθμολογία** — Σε ποιο σύνολο θα βαθμολογηθεί η εργασία
   * **Προσθήκη στο βαθμολόγιο** — Προσθήκη ως αξιολογούμενου στοιχείου στο εργαλείο αξιολόγησης (βαθμολόγιο), ώστε να μπορεί να αποτελεί μέρος της επίτευξης των στόχων του μαθήματος
   * **Προθεσμία** — Η επίσημη (δημοσιευμένη) ημερομηνία και ώρα μετά την οποία οι υποβολές επισημαίνονται ως καθυστερημένες (οι μεταφορτώσεις εξακολουθούν να γίνονται δεκτές)
   * **Λήγει στις (πλήρως κλειστό)** — Η αυστηρή ημερομηνία και ώρα αποκοπής μετά την οποία δεν είναι δυνατή καμία μεταφόρτωση
   * **Προσθήκη στο ημερολόγιο** — Δημιουργία συμβάντος για αναφορά στην ημερομηνία υποβολής αυτής της εργασίας
   * **Τύπος υποβολής** — Επιλέξτε μεταξύ **Να επιτρέπεται μόνο κείμενο**, **Να επιτρέπονται μόνο αρχεία** ή **Να επιτρέπονται αρχεία ή διαδικτυακό κείμενο**
4. Αποθήκευση

Αφού δημιουργήσετε μια εργασία, μπορείτε επίσης:
* Να μεταφορτώσετε έγγραφα προτύπου από τη σελίδα λεπτομερειών της εργασίας
* Να αναθέσετε την εργασία σε συγκεκριμένους χρήστες (αντί σε όλους τους χρήστες του μαθήματος)

Και αφού οι εκπαιδευόμενοι έχουν υποβάλει τις εργασίες τους, μπορείτε:
* Να εξαγάγετε λίστα υποβολών σε PDF
* Να εμφανίσετε λίστα μόνο των εκπαιδευομένων που δεν έχουν υποβάλει την εργασία τους
* Να κατεβάσετε όλες τις εργασίες σε ένα μεγάλο ZIP
* Να μεταφορτώσετε όλες τις διορθώσεις σε ένα μεγάλο ZIP
* Να διαγράψετε όλες τις διορθώσεις που υποβάλατε (αυτό δεν διαγράφει τις υποβολές των εκπαιδευομένων)

## Πώς υποβάλλουν οι εκπαιδευόμενοι

Οι εκπαιδευόμενοι ανοίγουν την εργασία και:

1. Κάνουν κλικ στο **Μεταφόρτωση αρχείου** ή στο κουμπί υποβολής
2. Επιλέγουν ένα αρχείο από τον υπολογιστή τους (ή γράφουν κείμενο απευθείας, ανάλογα με τη διαμόρφωση)
3. Προσθέτουν προαιρετικό σχόλιο
4. Υποβάλλουν

Οι εκπαιδευόμενοι μπορούν να δουν αν έχουν ήδη υποβάλει και, αν επιτρέπεται, να ενημερώσουν την υποβολή τους.

## Εξέταση υποβολών

![Η λίστα υποβολών εργασίας που εμφανίζει ονόματα μαθητών, ημερομηνίες, αρχεία και κατάσταση βαθμολόγησης](/.gitbook/assets/assignments-submissions-list.png)

Ως εκπαιδευτής, ανοίξτε μια εργασία για να δείτε τη λίστα όλων των υποβολών:

* **Όνομα μαθητή** — Ποιος υπέβαλε
* **Ημερομηνία υποβολής** — Πότε υποβλήθηκε η εργασία
* **Αρχείο** — Λήψη του υποβληθέντος αρχείου
* **Κατάσταση** — Αν η υποβολή έχει βαθμολογηθεί
* **Σχόλια** — Οποιαδήποτε σχόλια άφησε ο εκπαιδευόμενος ή εσείς

### Βαθμολόγηση υποβολής

![Η προβολή βαθμολόγησης εργασίας με πεδίο εισαγωγής βαθμολογίας, πεδίο ανατροφοδότησης και μεταφόρτωση διορθωμένου αρχείου](/.gitbook/assets/assignment-grading-view.png)

1. Κάντε κλικ σε μια υποβολή για να την ανοίξετε
2. Εξετάστε το υποβληθέν αρχείο
3. Εισαγάγετε μια **βαθμολογία**
4. Γράψτε **σχόλια ανατροφοδότησης** για τον εκπαιδευόμενο
5. Προαιρετικά μεταφορτώστε ένα **διορθωμένο αρχείο** ως συνημμένο
6. Αποθήκευση

### Βαθμολόγηση με υποστήριξη ΤΝ

Αν τα εργαλεία ΤΝ είναι διαμορφωμένα στην πλατφόρμα σας, ενδέχεται να δείτε μια επιλογή **Βαθμολόγηση ΤΝ** κατά την εξέταση υποβολών. Αυτό χρησιμοποιεί ένα μοντέλο ΤΝ για να προτείνει βαθμολογία και ανατροφοδότηση για εργασίες ανοιχτού τύπου. Δείτε [Βαθμολόγηση ΤΝ](../ai-tools/ai-grading.md) για λεπτομέρειες.

## Διαχείριση υποβολών

Ομαδικές ενέργειες:
* **Λήψη πακέτου εργασιών** — Λήψη όλων των υποβολών ως ενιαίου αρχείου ZIP για εξέταση εκτός σύνδεσης
* **Μεταφόρτωση πακέτου διορθώσεων** — Αν κατεβάσατε όλες τις υποβολές σε ένα ενιαίο αρχείο ZIP, επεξεργαστήκατε τα αρχεία επί τόπου στον υπολογιστή σας και τα συμπιέσατε ξανά, μπορείτε να στείλετε το zip ως πακέτο διορθώσεων. Μην αλλάξετε τα ονόματα αρχείων διαφορετικά δεν θα λειτουργήσει.
* **Καθυστερημένες υποβολές** — Οι υποβολές μετά την προθεσμία επισημαίνονται αλλά ενδέχεται να γίνουν δεκτές ανάλογα με τις ρυθμίσεις σας

Ενέργειες μεμονωμένης υποβολής:
* **Μεταφόρτωση διόρθωσης** — Μεταφόρτωση διόρθωσης για έναν εκπαιδευόμενο 
* **Λήψη** — Λήψη της υποβολής ενός εκπαιδευόμενου
* **Διόρθωση και βαθμολόγηση** — Προσθήκη διόρθωσης και βαθμού στην υποβολή του εκπαιδευόμενου 
* **Επεξεργασία** — Επεξεργασία του τίτλου του εγγράφου ή της προηγούμενης ανατροφοδότησης στην υποβολή
* **Μετακίνηση** — Μεταφορά υποβολής μεταξύ φακέλων εργασιών (π.χ. αν ο μαθητής υπέβαλε στη λάθος εργασία)
* **Ορατότητα** — Έλεγχος του αν οι εκπαιδευόμενοι μπορούν να βλέπουν τις υποβολές ο ένας του άλλου

## Σύνδεση με το βαθμολόγιο

Οι βαθμολογίες εργασιών μπορούν να συμπεριληφθούν στο βαθμολόγιο του μαθήματος (εργαλείο «Αξιολογήσεις»). Αυτό επιτρέπει στους βαθμούς εργασιών να συνεισφέρουν στον συνολικό βαθμό μαθήματος του εκπαιδευόμενου και στην επιλεξιμότητα για πιστοποιητικό. Δείτε [Βαθμολόγιο](gradebook.md) για λεπτομέρειες.

## Συμβουλές

* **Να είστε συγκεκριμένοι στις οδηγίες** — Περιγράψτε με σαφήνεια τι πρέπει να υποβάλουν οι εκπαιδευόμενοι, την αναμενόμενη μορφή και τα κριτήρια αξιολόγησης
* **Ορίστε ρεαλιστικές προθεσμίες** — Χρησιμοποιήστε το εργαλείο Agenda ώστε οι προθεσμίες να είναι ορατές στο ημερολόγιο του μαθήματος
* **Χρησιμοποιήστε τη λειτουργία διορθωμένου αρχείου** — Ανεβάστε σχολιασμένες εκδόσεις της εργασίας των εκπαιδευομένων ώστε να μπορούν να δουν τις συγκεκριμένες διορθώσεις σας
* **Ενεργοποιήστε με προσοχή την ορατότητα μεταξύ ομοτίμων** — Το να επιτρέπετε στους εκπαιδευόμενους να βλέπουν ο ένας την εργασία του άλλου μπορεί να ενθαρρύνει τη μάθηση, αλλά μπορεί να μην είναι κατάλληλο για όλες τις εργασίες
