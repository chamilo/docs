# Κάδοι ανακύκλωσης για ασκήσεις και μαθησιακές διαδρομές

Το Chamilo 3.1 μπορεί να αρχειοθετεί διαγραμμένες προσπάθειες ασκήσεων και δεδομένα παρακολούθησης μαθησιακών διαδρομών, ώστε οι εξουσιοδοτημένοι διδάσκοντες να μπορούν να τις επαναφέρουν, σύμφωνα με τις ρυθμισμένες πολιτικές διατήρησης και τους ελέγχους πρόσβασης. Οι κάδοι ανακύκλωσης προστατεύουν τα δεδομένα παρακολούθησης· δεν υποκαθιστούν τα αντίγραφα ασφαλείας της βάσης δεδομένων.

## Επαναφορά προσπάθειας άσκησης

1. Ανοίξτε τη σελίδα **Αναφορών** της επηρεαζόμενης άσκησης, με επιλεγμένο το σωστό μάθημα ή συνεδρία.
2. Επιλέξτε **Κάδος ανακύκλωσης** για να εμφανιστούν οι αρχειοθετημένες προσπάθειες.
3. Εντοπίστε τον εκπαιδευόμενο και την προσπάθεια που πρέπει να ανακτήσετε.
4. Επιλέξτε **Επαναφορά**, επιβεβαιώστε και ανανεώστε την αναφορά για να επαληθεύσετε τις απαντήσεις και τις βαθμολογίες.

Πρέπει να έχετε δικαίωμα διαχείρισης των αποτελεσμάτων ασκήσεων. Η επαναφορά ενδέχεται να αποκλειστεί όταν η άσκηση είναι κλειδωμένη από το Gradebook ή όταν η πλατφόρμα περιορίζει την πρόσβαση των διδασκόντων στα αποτελέσματα.

## Επαναφορά προόδου μαθησιακής διαδρομής

1. Ανοίξτε την οθόνη αναφορών της σχετικής μαθησιακής διαδρομής για το επιθυμητό μάθημα/συνεδρία.
2. Ανοίξτε τον **Κάδο ανακύκλωσης**.
3. Επιλέξτε την αρχειοθετημένη πρόοδο του εκπαιδευόμενου και κάντε **Επαναφορά**.
4. Ελέγξτε την επαναφερθείσα πρόοδο του μαθήματος και τις σχετικές προσπάθειες ασκήσεων.

Όταν μια προσπάθεια άσκησης αποτελεί μέρος εκκρεμούς αρχείου μαθησιακής διαδρομής, επαναφέρετε πρώτα το αρχείο της μαθησιακής διαδρομής. Η μεμονωμένη επαναφορά αποκλείεται σκόπιμα, ώστε να αποτρέπεται ασυνεπής πρόοδος.

## Διατήρηση και εκκαθάριση (διαχειριστές)

Η ρύθμιση `tracking.recycle_bin_retention_hours` ελέγχει για πόσο χρόνο τα αρχεία παραμένουν επιλέξιμα για ανάκτηση. Η αρχική προεπιλογή είναι **30 ημέρες** (720 ώρες). Οι υπάρχουσες εγκαταστάσεις πρέπει να συγχρονίσουν τη νέα ρύθμιση μέσω της μετάβασης settings-upsert του έργου, πριν αναμένουν να εμφανιστεί στη διεπαφή διαχείρισης.

Προεπισκόπηση εκκαθάρισης χωρίς διαγραφή:

```bash
php bin/console chamilo:recycle-bin:purge
```

Η οριστική διαγραφή απαιτεί ρητή επιλογή:

```bash
php bin/console chamilo:recycle-bin:purge --execute
```

Η εντολή υποστηρίζει τις επιλογές `--hours` (παράκαμψη διατήρησης), `--scan-limit`, `--after-lp-id` και `--after-exercise-id` για ελεγχόμενη επεξεργασία. Προγραμματίστε την μόνο αφού επαληθεύσετε την πολιτική διατήρησης και τις ρυθμίσεις αντιγράφων ασφαλείας. **Δεν υπάρχει σιωπηρό αυτόματο χρονοδιάγραμμα εκκαθάρισης** απλώς και μόνο επειδή η λειτουργία είναι ενεργοποιημένη.
