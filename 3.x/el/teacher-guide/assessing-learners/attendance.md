# Παρουσίες

Το εργαλείο παρουσιών σάς επιτρέπει να καταγράφετε την παρουσία των εκπαιδευομένων σε προγραμματισμένες συνεδρίες μαθήματος, είτε δια ζώσης είτε διαδικτυακά.

## Δημιουργία φύλλου παρουσιών

1. Ανοίξτε το εργαλείο **Attendance** από την αρχική σελίδα του μαθήματος
2. Κάντε κλικ στο **Add attendance** για να δημιουργήσετε ένα φύλλο παρουσιών
3. Εισαγάγετε έναν **Title** για το φύλλο παρουσιών (π.χ. «Εβδομάδα 1 - Εισαγωγή»)
4. Εισαγάγετε μια **Description** (αυτό είναι κυρίως για δική σας χρήση - οι εκπαιδευόμενοι δεν θα βλέπουν την περιγραφή)
5. Αποθηκεύστε

### Προηγμένες ρυθμίσεις

1. Το **Require unique presence** σάς επιτρέπει να θεωρείτε έναν εκπαιδευόμενο πλήρως παρόντα εάν συμμετείχε έστω και σε μία μόνο ημερομηνία του φύλλου παρουσιών
2. Οι **Gradebook options** σάς επιτρέπουν να αποφασίσετε να βαθμολογήσετε το φύλλο παρουσιών στο εργαλείο αξιολόγησης (gradebook).

## Προσθήκη ημερομηνιών

Κάθε φύλλο παρουσιών περιέχει μία ή περισσότερες ημερομηνίες (συνεδρίες) στις οποίες καταγράφετε την παρουσία:

1. Ανοίξτε ένα φύλλο παρουσιών ή συνεχίστε με τη διαδικασία δημιουργίας
2. Κάντε κλικ στο **Add a date** <img src="/.gitbook/assets/icons/mdi-calendar-plus.svg" alt="Προσθήκη ημερομηνίας" data-size="line">
3. Επιλέξτε την ημερομηνία και την ώρα
4. Προαιρετικά, επιλέξτε **Repeat date** για να ορίσετε λογική επανάληψης
5. Δώστε μια **Duration** σε λεπτά για το γεγονός (προεπιλογή τα 60 λεπτά)
6. Προαιρετικά, επιλέξτε ένα **Group** εάν αυτή η ημερομηνία παρουσίας ισχύει μόνο για μία ομάδα εκπαιδευομένων
7. Αποθηκεύστε

Μπορείτε να προσθέσετε πολλαπλές ημερομηνίες στο ίδιο φύλλο παρουσιών (π.χ. όλες οι συνεδρίες ενός μήνα).

## Καταγραφή παρουσιών

Για κάθε ημερομηνία, σημειώστε κάθε εκπαιδευόμενο ως:

* **Present** — Ο εκπαιδευόμενος παρευρέθηκε (προεπιλεγμένη τιμή για όλους τους εκπαιδευόμενους)
* **Absent** — Ο εκπαιδευόμενος δεν παρευρέθηκε

Κάντε κλικ στο κελί κατάστασης δίπλα στο όνομα κάθε εκπαιδευόμενου για εναλλαγή μεταξύ παρόντος και απόντος.

Από προεπιλογή, όλοι οι εκπαιδευόμενοι σημειώνονται ως παρόντες, καθώς θεωρούμε ότι είναι πιθανότερο να έχετε περισσότερους παρόντες παρά απόντες.

Σημείωση: Οι διαχειριστές μπορούν να τροποποιήσουν τη διαμόρφωση της πύλης ώστε να σας επιτρέπεται να επιλέγετε πιο εκτεταμένους τύπους παρουσίας (καθυστέρηση, απουσία με δικαιολογία κ.λπ.), που μπορούν να αντικατοπτρίζουν καλύτερα τις διαδικασίες σας. Σε αυτή την περίπτωση, ένα απλό κλικ στο πεδίο παρουσίας εναλλάσσει μεταξύ όλων των τύπων παρουσίας.

## Προβολή αναφορών παρουσιών

![Το φύλλο παρουσιών που εμφανίζει συνοπτικό πίνακα με εκπαιδευόμενους, ημερομηνίες και ενδείξεις παρουσίας](/.gitbook/assets/attendance-sheet.png)

Το εργαλείο παρουσιών εμφανίζει:

* Έναν συνοπτικό πίνακα με όλους τους εκπαιδευόμενους και όλες τις ημερομηνίες
* Το ποσοστό παρουσίας κάθε εκπαιδευόμενου (συνεδρίες παρουσίας / συνολικές συνεδρίες)
* Χρωματικά κωδικοποιημένες ενδείξεις για εύκολη επισκόπηση

## Επιπλέον

Οι παρουσίες διαθέτουν ορισμένες εκτεταμένες λειτουργίες που δεν είναι άμεσα ορατές:
* Οι **Signatures** μπορούν να ενεργοποιηθούν ώστε οι εκπαιδευόμενοι να υπογράφουν την παρουσία τους στην τάξη μέσω tablet που χειρίζεται ο διδάσκων
* **Comments** μπορούν να προστεθούν από τον διδάσκοντα σε κάθε παρουσία εκπαιδευόμενου
* **PDF reports** μπορούν να εξαχθούν για συμμόρφωση με κανονισμούς

## Συμβουλές

* **Σύνδεση με την πρόοδο του μαθήματος** — Χρησιμοποιήστε τα δεδομένα παρουσιών μαζί με το εργαλείο Course Progress για να συσχετίσετε την παρουσία με την κάλυψη θεμάτων
* **Εξαγωγή δεδομένων** — Εξαγάγετε το φύλλο παρουσιών για διοικητικά αρχεία
* **Ορίστε προσδοκίες** — Εάν η παρουσία είναι υποχρεωτική, κοινοποιήστε σαφώς την πολιτική στην εισαγωγή του μαθήματος ή στις ανακοινώσεις
