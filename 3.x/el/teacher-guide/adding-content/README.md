# Προσθήκη περιεχομένου

Αυτή η ενότητα καλύπτει τα εργαλεία που χρησιμοποιείτε για να προσθέσετε μαθησιακό περιεχόμενο στο μάθημά σας. Το Chamilo παρέχει διάφορους τρόπους για να παραδώσετε υλικό στους εκπαιδευόμενούς σας:

* **[Έγγραφα](documents.md)** — Ανεβάστε αρχεία, δημιουργήστε ιστοσελίδες και οργανώστε τη βιβλιοθήκη περιεχομένου σας
* **[Σύνδεσμοι](links.md)** — Μοιραστείτε URL προς εξωτερικούς πόρους, οργανωμένους ανά κατηγορία
* **[Διαδρομές μάθησης](learning-paths.md)** — Δημιουργήστε δομημένες ακολουθίες περιεχομένου με προαπαιτούμενα και παρακολούθηση προόδου
* **[Γλωσσάρι](glossary.md)** — Ορίστε βασικούς όρους στους οποίους μπορούν να ανατρέχουν οι εκπαιδευόμενοι καθ’ όλη τη διάρκεια του μαθήματος
* **[Ανακοινώσεις](announcements.md)** — Στείλτε μηνύματα και ενημερώσεις στους εγγεγραμμένους εκπαιδευόμενούς σας
* **[Περιεχόμενο πολλαπλών γλωσσών](multi-language-content.md)** — Γράψτε διάφορες γλωσσικές εκδοχές του ίδιου περιεχομένου και αφήστε κάθε εκπαιδευόμενο να βλέπει μόνο τη δική του

Κάθε εργαλείο είναι προσβάσιμο από το πλέγμα εργαλείων της αρχικής σελίδας του μαθήματος. Κάντε κλικ στο εικονίδιο του εργαλείου για να το ανοίξετε.
