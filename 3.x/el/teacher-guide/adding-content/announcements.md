# Ανακοινώσεις

Το εργαλείο ανακοινώσεων σάς επιτρέπει να στέλνετε μηνύματα σε όλους τους εκπαιδευόμενους που είναι εγγεγραμμένοι στο μάθημά σας, ή σε συγκεκριμένα άτομα ή ομάδες.

Τα μηνύματα που αποστέλλονται μέσω των ανακοινώσεων φτάνουν στους εκπαιδευόμενους τόσο μέσω ηλεκτρονικού ταχυδρομείου *όσο και* στα εισερχόμενά τους στο Chamilo.

## Δημιουργία ανακοίνωσης

1. Ανοίξτε το εργαλείο **Ανακοινώσεις** <img src="../../.gitbook/assets/icons/mdi-bullhorn.svg" alt="Ανακοινώσεις" data-size="line"> από την αρχική σελίδα του μαθήματος
2. Κάντε κλικ ξανά στο εικονίδιο **Προσθήκη ανακοίνωσης** <img src="../../.gitbook/assets/icons/mdi-bullhorn.svg" alt="Ανακοινώσεις" data-size="line">
3. Συμπληρώστε:
   * **Παραλήπτες** — Επιλέξτε ποιος λαμβάνει την ανακοίνωση:
     * Όλοι οι εγγεγραμμένοι εκπαιδευόμενοι
     * Συγκεκριμένοι εκπαιδευόμενοι
     * Συγκεκριμένες ομάδες
   * **Θέμα** — Μια γραμμή θέματος για την ανακοίνωση
   * **Περιγραφή** — Το σώμα του μηνύματος (υποστηρίζει εμπλουτισμένο κείμενο με μορφοποίηση, συνδέσμους και εικόνες)
   * **Συνημμένο** — Ένα προαιρετικό συνημμένο που αποστέλλεται μαζί με το ηλεκτρονικό μήνυμα
   * **Επιλογές αποστολής** — Οι ανακοινώσεις αποστέλλονται από προεπιλογή μέσω ηλεκτρονικού ταχυδρομείου, αλλά μπορείτε επίσης να επιλέξετε (εάν έχετε τα δικαιώματα) να την αποστείλετε σε όλες τις συνεδρίες που περιλαμβάνουν αυτό το μάθημα, να στείλετε αντίγραφο στον εαυτό σας ή να συνδέσετε αυτή την ανακοίνωση με ένα γεγονός ημερολογίου του μαθήματος.
4. Αποθήκευση

Το κουμπί **Ετικέτες** σάς επιτρέπει να προσδιορίσετε μια σειρά δεικτών που θα αντικατασταθούν δυναμικά στο **Περιεχόμενο** της ανακοίνωσης. Είναι σχετικά διαισθητικοί, οπότε θα σας αφήσουμε να μαντέψετε τι κάνουν.

Το κουμπί **Προεπισκόπηση** δεν είναι ιδιαίτερα διαισθητικό: σας επιτρέπει να δείτε σε ποιους θα αποσταλεί αυτή η ανακοίνωση. Λειτουργεί ως επιβεβαίωση της επιλογής παραληπτών που κάνατε παραπάνω.

## Διαχείριση ανακοινώσεων

* **Επεξεργασία** <img src="../../.gitbook/assets/icons/mdi-pencil.svg" alt="Επεξεργασία" data-size="line"> — Τροποποίηση υπάρχουσας ανακοίνωσης
* **Διαγραφή** <img src="../../.gitbook/assets/icons/mdi-delete.svg" alt="Διαγραφή" data-size="line"> — Αφαίρεση μιας ανακοίνωσης
* **Ορατότητα** <img src="../../.gitbook/assets/icons/mdi-eye.svg" alt="Ορατότητα" data-size="line"> — Απόκρυψη ή εμφάνιση ανακοινώσεων

Οι ανακοινώσεις εμφανίζονται σε αντίστροφη χρονολογική σειρά (οι νεότερες πρώτα).

## Συμβουλές

* **Μήνυμα καλωσορίσματος** — Δημιουργήστε μια ανακοίνωση στην αρχή του μαθήματος για να καλωσορίσετε τους εκπαιδευόμενους και να παρέχετε προσανατολισμό
* **Χρήση παράδοσης μέσω ηλεκτρονικού ταχυδρομείου** — Για ανακοινώσεις με χρονικό περιορισμό, ενεργοποιήστε την επιλογή ηλεκτρονικού ταχυδρομείου ώστε οι εκπαιδευόμενοι να λάβουν το μήνυμα ακόμη και αν δεν είναι συνδεδεμένοι στην πλατφόρμα εκείνη τη στιγμή
* **Στοχευμένες ανακοινώσεις** — Στείλτε συγκεκριμένες ανακοινώσεις σε ομάδες ή άτομα όταν το μήνυμα δεν αφορά ολόκληρη την τάξη
