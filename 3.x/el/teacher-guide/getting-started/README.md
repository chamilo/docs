# Ξεκινώντας

Αυτή η ενότητα σας βοηθά να προσανατολιστείτε στο Chamilo 3.0. Θα μάθετε πώς να συνδεθείτε, να περιηγηθείτε στην κύρια διεπαφή και να διαμορφώσετε το προφίλ σας.

## Σύνδεση

Για να αποκτήσετε πρόσβαση στο Chamilo, ανοίξτε το πρόγραμμα περιήγησής σας και μεταβείτε στη διεύθυνση URL που σας έχει δώσει το ίδρυμά σας (για παράδειγμα, `https://chamilo.yourschool.edu`). Εισαγάγετε το όνομα χρήστη και τον κωδικό πρόσβασής σας στη σελίδα σύνδεσης και κάντε κλικ στο **Sign in**.

Εάν το ίδρυμά σας χρησιμοποιεί εξωτερική πιστοποίηση (όπως Azure, Keycloak ή σύστημα ενιαίας σύνδεσης πανεπιστημίου), ενδέχεται να δείτε πρόσθετα κουμπιά σύνδεσης κάτω από την τυπική φόρμα σύνδεσης. Κάντε κλικ στο κατάλληλο κουμπί για να πιστοποιηθείτε μέσω του παρόχου ταυτότητας του ιδρύματός σας.

> Εάν έχετε ξεχάσει τον κωδικό πρόσβασής σας, κάντε κλικ στον σύνδεσμο **Forgot password?** στη σελίδα σύνδεσης. Θα λάβετε ένα μήνυμα ηλεκτρονικού ταχυδρομείου με οδηγίες για την επαναφορά του.

## Πρώτη ματιά

Μετά τη σύνδεση, θα δείτε την αρχική σελίδα του Chamilo. Η διεπαφή οργανώνεται σε τρεις κύριες περιοχές:

![Η αρχική σελίδα του Chamilo με ανακοινώσεις συστήματος και κάρτες μαθημάτων](../../.gitbook/assets/home-page-teacher.png)

* **Επάνω γραμμή** — Εμφανίζει το λογότυπο της πλατφόρμας, τα εισερχόμενα μηνυμάτων σας (με σήμα που δείχνει τα μη αναγνωσμένα μηνύματα) και το άβατάρ χρήστη σας. Κάντε κλικ στο άβατάρ σας για να αποκτήσετε πρόσβαση στο προφίλ και τις ρυθμίσεις λογαριασμού σας.
* **Πλευρική γραμμή** — Το αριστερό πλαίσιο πλοήγησης σας δίνει γρήγορη πρόσβαση στα μαθήματά σας, τις συνεδρίες, το ημερολόγιο, το κοινωνικό δίκτυο και άλλα. Μπορείτε να το συμπτύξετε κάνοντας κλικ στον διακόπτη στην άκρη του.
* **Κύρια περιοχή περιεχομένου** — Εδώ εμφανίζεται το περιεχόμενο της τρέχουσας σελίδας. Στην αρχική σελίδα θα δείτε ανακοινώσεις συστήματος και τα προτεινόμενα μαθήματά σας.

## Τα μαθήματά σας

Από την πλευρική γραμμή, κάντε κλικ στο **My courses** για να δείτε όλα τα μαθήματα στα οποία είστε εγγεγραμμένοι ως εκπαιδευτής ή εκπαιδευόμενος. Κάθε μάθημα εμφανίζεται ως κάρτα που δείχνει:

![Η σελίδα My Courses με κάρτες μαθημάτων, μικρογραφίες και ενέργειες γρήγορης πρόσβασης](../../.gitbook/assets/my-courses-list.png)

* Την εικόνα ή τη μικρογραφία του μαθήματος
* Τον τίτλο του μαθήματος
* Ενέργειες γρήγορης πρόσβασης

Εάν το ίδρυμά σας χρησιμοποιεί **συνεδρίες** (χρονικά οριοθετημένες περιόδους κατάρτισης), θα δείτε επίσης έναν σύνδεσμο **My sessions** στην πλευρική γραμμή, οργανωμένο σε τρέχουσες, παρελθούσες και επερχόμενες συνεδρίες.

Οι συνεδρίες στο Chamilo είναι ένας τρόπος να παραδώσετε το ίδιο μάθημα σε διαφορετικές ομάδες εκπαιδευομένων σε διαφορετικές χρονικές στιγμές, χωρίς να αντιγράψετε το περιεχόμενο του μαθήματος. Σκεφτείτε μια συνεδρία ως προγραμματισμένη έκδοση ή ομάδα (cohort) ενός μαθήματος. Περισσότερα για αυτό το θέμα αργότερα.
