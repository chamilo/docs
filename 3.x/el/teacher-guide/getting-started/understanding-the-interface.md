# Κατανόηση της διεπαφής

Το Chamilo 3.0 διαθέτει καθαρή, σύγχρονη διεπαφή σχεδιασμένη ώστε η πλοήγηση να παραμένει απλή. Αυτή η σελίδα εξηγεί αναλυτικά κάθε μέρος της διεπαφής.

## Η επάνω γραμμή

![Η επάνω γραμμή με σχολιασμένα στοιχεία, όπως λογότυπο, εισερχόμενα, δελτίο υποστήριξης και άβαταρ χρήστη](../../.gitbook/assets/top-bar-annotated.png)

Η επάνω γραμμή είναι πάντα ορατή στο επάνω μέρος κάθε σελίδας. Περιέχει:

* **Λογότυπο πλατφόρμας** — Κάντε κλικ σε αυτό για να επιστρέψετε στην αρχική σελίδα οποιαδήποτε στιγμή.
* **Εικονίδιο εισερχομένων** <img src="../../.gitbook/assets/icons/mdi-inbox.svg" alt="Inbox" data-size="line"> — Εμφανίζει τα μηνύματά σας. Ένα κόκκινο σήμα υποδεικνύει μη αναγνωσμένα μηνύματα. Κάντε κλικ για να ανοίξετε τα εισερχόμενά σας.
* **Εικονίδιο δελτίου υποστήριξης** <img src="../../.gitbook/assets/icons/mdi-ticket-account.svg" alt="Support" data-size="line"> — Εάν έχει ενεργοποιηθεί από τον διαχειριστή σας, σας δίνει πρόσβαση στο σύστημα δελτίων υποστήριξης.
* **Το άβατάρ σας** — Μια κυκλική εικόνα στην επάνω δεξιά γωνία. Κάντε κλικ σε αυτήν για να ανοίξετε ένα αναπτυσσόμενο μενού με συνδέσμους προς το προφίλ σας, τις ρυθμίσεις λογαριασμού και την αποσύνδεση.

## Η πλευρική γραμμή

Η πλευρική γραμμή στα αριστερά είναι η κύρια πλοήγησή σας. Μπορεί να συρρικνωθεί ώστε να δοθεί περισσότερος χώρος στην περιοχή περιεχομένου. Κάντε κλικ στο βέλος εναλλαγής στη δεξιά της άκρη για να την αναπτύξετε ή να τη συρρικνώσετε. Το Chamilo θυμάται την προτίμησή σας.

Η πλευρική γραμμή περιέχει τους ακόλουθους συνδέσμους (ορισμένοι ενδέχεται να είναι κρυφοί ανάλογα με τη διαμόρφωση της πλατφόρμας σας):

![Ο πίνακας πλοήγησης της πλευρικής γραμμής σε ανεπτυγμένη κατάσταση, με όλα τα στοιχεία μενού](../../.gitbook/assets/sidebar-expanded.png)

| Στοιχείο μενού | Εικονίδιο | Περιγραφή |
|-----------|------|-------------|
| **Αρχική** | <img src="../../.gitbook/assets/icons/mdi-home.svg" alt="Home" data-size="line"> | Επιστρέφει στον κύριο πίνακα ελέγχου |
| **Τα μαθήματά μου** | <img src="../../.gitbook/assets/icons/mdi-book-open-page-variant.svg" alt="Courses" data-size="line"> | Παραθέτει όλα τα μαθήματα στα οποία είστε εγγεγραμμένοι |
| **Οι συνεδρίες μου** | <img src="../../.gitbook/assets/icons/mdi-google-classroom.svg" alt="Sessions" data-size="line"> | Παραθέτει τις εκπαιδευτικές συνεδρίες σας (τρέχουσες, παρελθούσες, επερχόμενες) |
| **Εξερεύνηση περισσότερων μαθημάτων** | <img src="../../.gitbook/assets/icons/mdi-bookmark-multiple.svg" alt="Catalogue" data-size="line"> | Περιηγηθείτε στον κατάλογο μαθημάτων για να βρείτε νέα μαθήματα |
| **Ατζέντα** | <img src="../../.gitbook/assets/icons/mdi-calendar-text.svg" alt="Agenda" data-size="line"> | Το προσωπικό σας ημερολόγιο και το ημερολόγιο μαθημάτων |
| **Αναφορές** | <img src="../../.gitbook/assets/icons/mdi-chart-box.svg" alt="Reporting" data-size="line"> | Πρόσβαση στην παρακολούθηση εκπαιδευομένων και στις αναφορές μαθημάτων |
| **Κοινωνικό δίκτυο** | <img src="../../.gitbook/assets/icons/mdi-sitemap-outline.svg" alt="Social network" data-size="line"> | Συνδεθείτε με άλλους χρήστες, στείλτε μηνύματα, ενταχθείτε σε ομάδες |
| **Τηλεδιάσκεψη** | <img src="../../.gitbook/assets/icons/mdi-video.svg" alt="Video" data-size="line"> | Πρόσβαση σε ζωντανές συνεδρίες βίντεο (εάν έχει διαμορφωθεί) |
| **Διαχείριση** | <img src="../../.gitbook/assets/icons/mdi-cogs.svg" alt="Admin" data-size="line"> | Διαχείριση πλατφόρμας (ορατή μόνο στους διαχειριστές) |

Στο κάτω μέρος της πλευρικής γραμμής θα βρείτε μια επιλογή **Αποσύνδεση** για γρήγορη αποσύνδεση όταν ολοκληρώσετε. Αυτή η επιλογή είναι επίσης διαθέσιμη από το αναπτυσσόμενο μενού του εικονιδίου άβαταρ στην επάνω δεξιά γωνία.
Εάν η πλατφόρμα διαχειρίζεται μέσω εξωτερικών μεθόδων αυθεντικοποίησης, αυτές οι επιλογές αποσύνδεσης ενδέχεται να μην είναι διαθέσιμες.

## Η κύρια περιοχή περιεχομένου

Η κεντρική περιοχή της οθόνης εμφανίζει το περιεχόμενο της τρέχουσας σελίδας. Στο επάνω μέρος θα βλέπετε συχνά μια **διαδρομή ψίχουλων (breadcrumb trail)** που δείχνει την τρέχουσα θέση σας στην πλατφόρμα (για παράδειγμα: Αρχική > Rock music > Έγγραφα). Χρησιμοποιήστε τα ψίχουλα για να επιστρέψετε σε μια γονική σελίδα.

## Η αρχική σελίδα μαθήματος

Όταν εισέρχεστε σε ένα μάθημα, βλέπετε την **αρχική σελίδα μαθήματος**. Αυτό καλύπτεται αναλυτικά στην ενότητα [Δημιουργία του μαθήματός σας](../creating-your-course/), αλλά ακολουθεί μια σύντομη επισκόπηση:

* **Τίτλος μαθήματος** — Εμφανίζεται εμφανώς στο επάνω μέρος
* **Εισαγωγή μαθήματος** — Μια προαιρετική περιγραφή εμπλουτισμένου κειμένου που μπορείτε να επεξεργαστείτε
* **Πλέγμα εργαλείων** — Ένα πλέγμα εικονιδίων που αντιπροσωπεύουν τα εργαλεία του μαθήματος (Έγγραφα, Ασκήσεις, Φόρουμ κ.λπ.)

Ως εκπαιδευτής, θα βλέπετε πρόσθετα στοιχεία ελέγχου:

* **Προβολή εκπαιδευόμενου** <img src="../../.gitbook/assets/icons/mdi-eye.svg" alt="Student view" data-size="line"> — Εναλλάξτε το για να δείτε το μάθημα όπως θα το έβλεπε ένας εκπαιδευόμενος
* **Επεξεργασία εισαγωγής** <img src="../../.gitbook/assets/icons/mdi-pencil.svg" alt="Edit" data-size="line"> — Επεξεργαστείτε το κείμενο εισαγωγής του μαθήματος
* **Εμφάνιση όλων / Απόκρυψη όλων** — Αλλάξτε γρήγορα την ορατότητα όλων των εργαλείων για τους εκπαιδευόμενους
* **Ταξινόμηση** — Ενεργοποιήστε τη μεταφορά και απόθεση για να αναδιατάξετε τα εργαλεία στην αρχική σελίδα

## Χρώματα εικονιδίων

Αυτό είναι ακόμη πειραματικό και όχι πλήρως ολοκληρωμένο στο Chamilo 3.0, αλλά προσπαθούμε να εφαρμόσουμε τους ακόλουθους κανόνες για όλα τα κουμπιά και τα εικονίδια ενεργειών στη διεπαφή:

* **Πράσινο** για ενέργειες δημιουργίας. Αυτό περιλαμβάνει την προσθήκη, τη δημιουργία, την εισαγωγή, τη βαθμολόγηση, την αποθήκευση και την αντιγραφή περιεχομένου.
* **Μπλε** για ενέργειες προβολής. Αυτό περιλαμβάνει την εξαγωγή, την προβολή, την προεπισκόπηση σε λίστες ή σε λεπτομερείς προβολές, την αναζήτηση και τη λήψη.
* **Πορτοκαλί** για ενέργειες επεξεργασίας. Αυτό περιλαμβάνει την επεξεργασία, τη μετακίνηση, τη διαμόρφωση, την ενεργοποίηση/απενεργοποίηση, την απόκρυψη και την εμφάνιση.
* **Κόκκινο** για ενέργειες διαγραφής/αφαίρεσης. Αυτό περιλαμβάνει τη διαγραφή, την αφαίρεση, την απεγγραφή.
* **Γκρι** για ενέργειες ακύρωσης. Απλώς διατήρηση των πραγμάτων ως έχουν.

## Προσαρμοστικός σχεδιασμός

Το Chamilo 3.0 προσαρμόζεται σε διαφορετικά μεγέθη οθόνης. Σε κινητή συσκευή ή σε στενό παράθυρο προγράμματος περιήγησης:

* Η πλευρική γραμμή είναι κρυφή από προεπιλογή και μπορεί να ανοίξει πατώντας το εικονίδιο μενού
* Οι κάρτες μαθημάτων εμφανίζονται σε μία στήλη αντί για πλέγμα
* Οι πίνακες γίνονται οριζόντια κύλισης

Αυτό σημαίνει ότι εσείς και οι εκπαιδευόμενοι σας μπορείτε να αποκτήσετε πρόσβαση στην πλατφόρμα από τηλέφωνο, τάμπλετ ή υπολογιστή, αλλά ενδέχεται να βιώσετε τη διεπαφή ελαφρώς διαφορετικά.
