# Συχνές ερωτήσεις

## Γενικές ερωτήσεις

**Πώς αποκτώ πρόσβαση στο μάθημά μου;**

Κάντε κλικ στο **Τα μαθήματά μου** στην πλαϊνή γραμμή και, στη συνέχεια, κάντε κλικ στο μάθημα που θέλετε να ανοίξετε. Αν το μάθημά σας ανήκει σε μια συνεδρία, κάντε πρώτα κλικ στο **Οι συνεδρίες μου** και, στη συνέχεια, επιλέξτε τη συνεδρία και το μάθημα.

**Μπορούν οι εκπαιδευόμενοι μου να έχουν πρόσβαση στο μάθημα από κινητό τηλέφωνο;**

Ναι. Το Chamilo 3.0 διαθέτει προσαρμοστική διεπαφή που προσαρμόζεται σε όλα τα μεγέθη οθόνης. Οι εκπαιδευόμενοι μπορούν να χρησιμοποιήσουν οποιοδήποτε σύγχρονο πρόγραμμα περιήγησης σε τηλέφωνο, tablet ή υπολογιστή.

**Ποια προγράμματα περιήγησης υποστηρίζονται;**

Το Chamilo 3.0 λειτουργεί με όλα τα κύρια σύγχρονα προγράμματα περιήγησης: Chrome, Firefox, Safari και Edge. Για την καλύτερη εμπειρία, χρησιμοποιήστε την πιο πρόσφατη έκδοση του προγράμματος περιήγησής σας.

## Περιεχόμενο και μαθήματα

**Πώς δημιουργώ αντίγραφο ασφαλείας του μαθήματός μου;**

Μεταβείτε στο εργαλείο **Συντήρηση** στο μάθημά σας (προσβάσιμο από το μενού ρυθμίσεων στην αρχική σελίδα του μαθήματος). Θα βρείτε επιλογές για εξαγωγή του περιεχομένου του μαθήματός σας.

**Μπορώ να αντιγράψω περιεχόμενο από ένα μάθημα σε άλλο;**

Ναι. Χρησιμοποιήστε τις λειτουργίες εισαγωγής/εξαγωγής μαθήματος στο εργαλείο Συντήρηση για να αντιγράψετε περιεχόμενο μεταξύ μαθημάτων. Θα πρέπει πρώτα να δημιουργήσετε ένα κενό μάθημα *προορισμού*.

**Ποιες μορφές αρχείων μπορώ να ανεβάσω;**

Το Chamilo υποστηρίζει τις περισσότερες κοινές μορφές αρχείων: PDF, έγγραφα Word, παρουσιάσεις PowerPoint, εικόνες (PNG, JPG, SVG, GIF), αρχεία ήχου, αρχεία βίντεο και πολλά ακόμη. Ο διαχειριστής σας ενδέχεται να περιορίζει ορισμένους τύπους αρχείων για λόγους ασφαλείας.

**Ποιο είναι το μέγιστο μέγεθος μεταφόρτωσης αρχείου;**

Αυτό εξαρτάται από τη διαμόρφωση του διακομιστή σας. Το όριο μεταφόρτωσης το ορίζει ο διαχειριστής σας. Αν συναντήσετε όριο, επικοινωνήστε με τον διαχειριστή σας.

## Αξιολόγηση

**Μπορούν οι ασκήσεις να βαθμολογούνται αυτόματα;**

Ναι. Οι περισσότεροι τύποι ερωτήσεων (πολλαπλής επιλογής, σωστό/λάθος, συμπλήρωση κενών, αντιστοίχιση) βαθμολογούνται αυτόματα. Οι ανοιχτές ερωτήσεις απαιτούν χειροκίνητη βαθμολόγηση, ή μπορείτε να χρησιμοποιήσετε βαθμολόγηση με υποστήριξη ΤΝ αν έχει διαμορφωθεί.

**Μπορώ να ορίσω χρονικό όριο στις ασκήσεις;**

Ναι. Κατά τη δημιουργία ή την επεξεργασία μιας άσκησης, μπορείτε να ορίσετε χρονικό όριο σε λεπτά. Οι εκπαιδευόμενοι θα βλέπουν χρονομετρητή αντίστροφης μέτρησης.

**Μπορούν οι εκπαιδευόμενοι να επαναλάβουν μια άσκηση;**

Ναι. Εσείς ελέγχετε τον αριθμό των επιτρεπόμενων προσπαθειών στις ρυθμίσεις της άσκησης. Μπορείτε να επιτρέψετε απεριόριστες προσπάθειες ή να ορίσετε συγκεκριμένο μέγιστο, αλλά αυτό το μέγιστο ισχύει για όλους τους χρήστες στο μάθημά σας (μπορείτε να *απελευθερώσετε* νέες προσπάθειες διαγράφοντας τις προηγούμενες, αλλά αυτό δεν συνιστάται καθώς οδηγεί σε άνισες ευκαιρίες μεταξύ των χρηστών και καταγράφεται για έλεγχο σε επίπεδο πλατφόρμας).

## Τεχνικά ζητήματα

**Δεν βλέπω ένα εργαλείο στην αρχική σελίδα του μαθήματός μου. Πού βρίσκεται;**

Ορισμένα εργαλεία ενδέχεται να είναι κρυμμένα. Ως εκπαιδευτής, μπορείτε να εμφανίσετε κρυμμένα εργαλεία αναζητώντας εργαλεία με εικονίδιο ματιού που έχει διαγραφεί. Αν δεν μπορείτε να βρείτε καθόλου ένα συγκεκριμένο εργαλείο, ο διαχειριστής της πλατφόρμας ενδέχεται να το έχει απενεργοποιήσει σε επίπεδο πλατφόρμας.

**Οι εκπαιδευόμενοι μου λένε ότι δεν μπορούν να έχουν πρόσβαση στο μάθημα.**

Ελέγξτε τις ρυθμίσεις ορατότητας του μαθήματος (Ρυθμίσεις μαθήματος > Ορατότητα μαθήματος). Αν έχει οριστεί σε «Μόνο εγγεγραμμένοι», οι εκπαιδευόμενοι πρέπει να έχουν εγγραφεί ρητά. Επίσης επαληθεύστε ότι διαθέτουν ενεργό λογαριασμό στην πλατφόρμα.
