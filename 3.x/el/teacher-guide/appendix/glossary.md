# Γλωσσάρι

Βασικοί όροι που χρησιμοποιούνται σε όλο αυτόν τον οδηγό.

| Term | Definition |
|------|-----------|
| **Αξιολόγηση** | Βλ. **Βαθμολόγιο** παρακάτω |
| **Εργασία** | Μια εργασία στην οποία οι εκπαιδευόμενοι υποβάλλουν αρχεία ή κείμενο για έλεγχο και βαθμολόγηση από τον εκπαιδευτή. Γνωστή επίσης ως «δημοσίευση μαθητή» ή «work». |
| **Αυτόματη εκκίνηση** | Μια λειτουργία που ανοίγει αυτόματα ένα συγκεκριμένο εργαλείο όταν ένας εκπαιδευόμενος εισέρχεται σε ένα μάθημα. |
| **Πιστοποιητικό** | Ένα έγγραφο που δημιουργείται αυτόματα όταν ένας εκπαιδευόμενος επιτυγχάνει την ελάχιστη βαθμολογία που έχει οριστεί στο βαθμολόγιο. |
| **Μάθημα** | Ένα δοχείο για μαθησιακό περιεχόμενο και εργαλεία. Ένα μάθημα μπορεί να περιλαμβάνει έγγραφα, ασκήσεις, φόρουμ, διαδρομές μάθησης και άλλα. |
| **Καθηγητής μαθήματος** | Ένας ρόλος εκπαιδευτή ειδικός για συνεδρίες. Ένας καθηγητής μαθήματος διαχειρίζεται ένα μάθημα εντός μιας συνεδρίας. Ονομαζόταν «course coach» στις εκδόσεις του Chamilo πριν από την 3.0. |
| **Όριο δίσκου** | Ο μέγιστος χώρος αποθήκευσης που διατίθεται σε ένα μάθημα για τα μεταφορτωμένα αρχεία. |
| **Εγγραφή** | Η διαδικασία καταχώρισης ενός χρήστη σε ένα μάθημα ή μια συνεδρία, δίνοντάς του πρόσβαση στο περιεχόμενό του. Γνωστή επίσης ως «subscription». |
| **Άσκηση** | Ένα κουίζ ή τεστ που περιέχει μία ή περισσότερες ερωτήσεις. Σε ορισμένα περιβάλλοντα αναφέρεται επίσης ως «test». |
| **Φόρουμ** | Ένα εργαλείο συζήτησης με νηματικές συνομιλίες οργανωμένες σε κατηγορίες και θέματα. |
| **Βαθμολόγιο** | Ένα εργαλείο που συγκεντρώνει βαθμολογίες από ασκήσεις, εργασίες και άλλες δραστηριότητες σε έναν ενιαίο βαθμό για κάθε εκπαιδευόμενο. |
| **Διαδρομή μάθησης** | Μια δομημένη ακολουθία μαθησιακών δραστηριοτήτων (έγγραφα, ασκήσεις, σύνδεσμοι) που οι εκπαιδευόμενοι ακολουθούν με καθορισμένη σειρά, προαιρετικά με προαπαιτούμενα. |
| **LTI** | Learning Tools Interoperability — ένα πρότυπο που επιτρέπει την ενσωμάτωση εξωτερικών εργαλείων μάθησης στο Chamilo. |
| **SCORM** | Sharable Content Object Reference Model — ένα πρότυπο για πακέτα περιεχομένου ηλεκτρονικής μάθησης. Το Chamilo μπορεί να εισάγει και να αναπαράγει πακέτα SCORM εντός διαδρομών μάθησης. |
| **Συνεδρία** | Μια χρονικά οριοθετημένη έκδοση ενός ή περισσότερων μαθημάτων που ανατίθεται σε μια συγκεκριμένη ομάδα εκπαιδευομένων. Οι συνεδρίες επιτρέπουν την επαναχρησιμοποίηση του ίδιου περιεχομένου μαθήματος για διαφορετικές ομάδες. |
| **Καθηγητής συνεδρίας** | Ένας εποπτικός ρόλος που επιβλέπει όλα τα μαθήματα εντός μιας συνεδρίας. Ονομαζόταν «session coach» στις εκδόσεις του Chamilo πριν από την 3.0. |
| **Δεξιότητα** | Μια ικανότητα που μπορεί να συνδεθεί με επιτεύγματα του βαθμολογίου. Όταν ένας εκπαιδευόμενος αποκτά πιστοποιητικό, οι σχετικές δεξιότητες επικυρώνονται. |
| **Έρευνα** | Ένα εργαλείο ερωτηματολογίου για τη συλλογή ανατροφοδότησης, με διάφορους τύπους ερωτήσεων και επιλογές ανώνυμων απαντήσεων. |
| **Ορατότητα** | Μια ρύθμιση που ελέγχει αν ένα εργαλείο, έγγραφο ή δραστηριότητα είναι ορατό στους εκπαιδευόμενους. Οι εκπαιδευτές μπορούν πάντα να βλέπουν τα κρυφά στοιχεία. |
