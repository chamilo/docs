# Οδηγός Εκπαιδευτή

Καλώς ήρθατε στον Οδηγό Εκπαιδευτή του Chamilo 3.0. Ο οδηγός αυτός απευθύνεται σε διδάσκοντες, εκπαιδευτές και σε όποιον είναι υπεύθυνος για τη δημιουργία και την παράδοση μαθησιακού περιεχομένου μέσω της πλατφόρμας Chamilo.

Είτε δημιουργείτε το πρώτο σας διαδικτυακό μάθημα είτε διαχειρίζεστε ένα σύνθετο πρόγραμμα κατάρτισης, ο οδηγός αυτός θα σας καθοδηγήσει σε κάθε λειτουργία που έχετε στη διάθεσή σας ως εκπαιδευτής.

## Τι μπορείτε να κάνετε με το Chamilo

Ως εκπαιδευτής στο Chamilo, μπορείτε:

* **Να δημιουργείτε και να οργανώνετε μαθήματα** με ευέλικτη αρχική σελίδα και προσαρμόσιμα εργαλεία
* **Να προσθέτετε περιεχόμενο** — να ανεβάζετε έγγραφα, να δημιουργείτε διαδρομές μάθησης, να συντάσσετε γλωσσάρια και να συνδέετε εξωτερικούς πόρους
* **Να αξιολογείτε τους εκπαιδευόμενους** — να σχεδιάζετε ασκήσεις με πολλούς τύπους ερωτήσεων, να συλλέγετε εργασίες, να διεξάγετε έρευνες και να διαχειρίζεστε βαθμούς
* **Να συνεργάζεστε** — να ρυθμίζετε φόρουμ, ομαδική εργασία, wiki, ιστολόγια και ζωντανές συνεδρίες βίντεο
* **Να παρακολουθείτε την πρόοδο** — να εποπτεύετε τη δραστηριότητα των εκπαιδευομένων, να παράγετε αναφορές και να απονέμετε πιστοποιητικά
* **Να χρησιμοποιείτε εργαλεία ΤΝ** — να δημιουργείτε αυτόματα ασκήσεις και διαδρομές μάθησης και να λαμβάνετε βαθμολόγηση με υποστήριξη ΤΝ

## Πώς είναι οργανωμένος αυτός ο οδηγός

Ο οδηγός ακολουθεί τη φυσική ροή εργασίας της δημιουργίας και της διεξαγωγής ενός μαθήματος:

1. **Ξεκινώντας** — Σύνδεση, πλοήγηση στη διεπαφή και ρύθμιση του προφίλ σας
2. **Δημιουργία του μαθήματός σας** — Δημιουργία νέου μαθήματος, διαμόρφωση των ρυθμίσεών του και προσαρμογή της αρχικής σελίδας
3. **Προσθήκη περιεχομένου** — Ανέβασμα εγγράφων, οργάνωση διαδρομών μάθησης και διαχείριση πόρων
4. **Αξιολόγηση εκπαιδευομένων** — Δημιουργία τεστ, συλλογή εργασιών, διεξαγωγή ερευνών και ρύθμιση του βαθμολογίου
5. **Συνεργασία και επικοινωνία** — Ενεργοποίηση φόρουμ, συνομιλίας, ομάδων, wiki και τηλεδιάσκεψης
6. **Παρακολούθηση και αναφορές** — Εποπτεία της προόδου των εκπαιδευομένων και παραγωγή αναφορών
7. **Εργαλεία ΤΝ** — Χρήση λειτουργιών με τεχνητή νοημοσύνη για δημιουργία περιεχομένου και υποστήριξη στη βαθμολόγηση
8. **Πρόσθετα εργαλεία** — Ατζέντα, σημειωματάριο, χαρτοφυλάκιο και άλλα

Ας ξεκινήσουμε.
