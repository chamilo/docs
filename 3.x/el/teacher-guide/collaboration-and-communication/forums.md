# Φόρουμ

Το εργαλείο φόρουμ σάς επιτρέπει να φιλοξενείτε δομημένες συζητήσεις μέσα στο μάθημά σας. Οι εκπαιδευόμενοι μπορούν να δημοσιεύουν μηνύματα, να απαντούν ο ένας στον άλλον και να συμμετέχουν σε συζητήσεις με νήματα.

## Δομή φόρουμ

![Η λίστα κατηγοριών φόρουμ που εμφανίζει κατηγορίες, φόρουμ και πλήθος θεμάτων](../../.gitbook/assets/forum-category-list.png)

Τα φόρουμ στο Chamilo οργανώνονται σε τρία επίπεδα:

1. **Κατηγορίες φόρουμ** — Ομαδοποιήσεις ανώτατου επιπέδου (π.χ. «Γενικές συζητήσεις», «Ερωτήσεις ενότητας 1»)
2. **Φόρουμ** — Μεμονωμένοι πίνακες συζήτησης μέσα σε μια κατηγορία
3. **Θέματα (νήματα)** — Μεμονωμένα θέματα συζήτησης μέσα σε ένα φόρουμ, το καθένα με μια αλυσίδα απαντήσεων

## Δημιουργία κατηγορίας φόρουμ

1. Ανοίξτε το εργαλείο **Φόρουμ** <img src="../../.gitbook/assets/icons/mdi-comment-quote.svg" alt="Forums" data-size="line"> από την αρχική σελίδα του μαθήματός σας
2. Κάντε κλικ στην επιλογή **Προσθήκη κατηγορίας φόρουμ**
3. Εισαγάγετε ένα **Όνομα κατηγορίας** και προαιρετική περιγραφή
4. Αποθηκεύστε

## Δημιουργία φόρουμ

Μπορείτε να προσθέσετε φόρουμ μόνο αφού υπάρχει τουλάχιστον μία κατηγορία.

1. Μέσα σε μια κατηγορία, κάντε κλικ στην επιλογή **Προσθήκη φόρουμ**
2. Συμπληρώστε τα βασικά στοιχεία:
   * **Τίτλος** — Το όνομα αυτού του πίνακα συζήτησης
   * **Περιγραφή** — Προαιρετική περιγραφή του σκοπού του φόρουμ
   * **Δημιουργία στην κατηγορία** — Η κατηγορία στην οποία ανήκει αυτό το φόρουμ
3. Ανοίξτε τις **Προηγμένες ρυθμίσεις** για να διαμορφώσετε:
   * **Ημερομηνία δημοσίευσης** / **Ημερομηνία κλεισίματος** — Προαιρετικό χρονικό παράθυρο κατά το οποίο το φόρουμ είναι ανοιχτό
   * **Εποπτευόμενο φόρουμ** — Απαίτηση έγκρισης των νέων δημοσιεύσεων από εκπαιδευτή πριν γίνουν ορατές
   * **Μπορούν οι εκπαιδευόμενοι να επεξεργάζονται τις δικές τους δημοσιεύσεις;** — Να επιτρέπεται ή να αποτρέπεται η επεξεργασία δημοσιεύσεων από τους εκπαιδευόμενους μετά την υποβολή
   * **Να επιτρέπεται στους χρήστες να ξεκινούν νέα νήματα** — Όταν οριστεί σε Όχι, οι εκπαιδευόμενοι μπορούν μόνο να απαντούν σε υπάρχοντα νήματα
   * **Προεπιλεγμένος τύπος προβολής** — Επιλέξτε πώς εμφανίζονται οι δημοσιεύσεις: **Επίπεδη**, **Με νήματα** ή **Ένθετη**
   * **Για ομάδα** — Να συνδεθεί αυτό το φόρουμ με μια ομάδα μαθήματος
   * **Δημόσια πρόσβαση / Ιδιωτική πρόσβαση** — Για φόρουμ ομάδων, αποφασίστε αν οποιοδήποτε μέλος του μαθήματος μπορεί να το διαβάσει ή μόνο τα μέλη της ομάδας
4. Αποθηκεύστε

Αν η ορατότητα του μαθήματος έχει οριστεί σε «Ανοιχτό στον κόσμο», η φόρμα εμφανίζει επίσης την επιλογή **Να επιτρέπονται ανώνυμες δημοσιεύσεις;**. Αυτή η επιλογή είναι κρυφή σε μαθήματα με περιορισμένη ορατότητα.

## Διαχείριση θεμάτων

Οι εκπαιδευόμενοι (και εσείς) μπορείτε να δημιουργείτε νέα θέματα μέσα σε ένα φόρουμ. Ως εκπαιδευτής, μπορείτε:

* **Καρφίτσωμα θέματος (σταθερό μήνυμα)** — Να επισημάνετε ένα νήμα ως σταθερό όταν το δημιουργείτε ή το επεξεργάζεστε, ώστε να εμφανίζεται πάντα στην κορυφή
* **Κλείδωμα θέματος** — Να αποτρέψετε περαιτέρω απαντήσεις
* **Επεξεργασία ή διαγραφή δημοσιεύσεων** — Να εποπτεύετε τη συζήτηση
* **Μετακίνηση θέματος** — Να μεταφέρετε ένα θέμα σε διαφορετικό φόρουμ

## Βαθμολόγηση φόρουμ

Όταν δημιουργείτε ένα νέο νήμα ως εκπαιδευτής, μπορείτε να ενεργοποιήσετε την επιλογή **Βαθμολόγηση αυτού του νήματος** στις Προηγμένες ρυθμίσεις. Στη συνέχεια ορίζετε μέγιστη βαθμολογία, κεφαλίδα στήλης για το βαθμολόγιο και βάρος στην αναφορά. Μπορείτε επίσης να ενεργοποιήσετε την επιλογή **Νήμα βαθμολογούμενο από ομοτίμους**, η οποία απαιτεί από κάθε εκπαιδευόμενο να αξιολογήσει τουλάχιστον δύο άλλους εκπαιδευόμενους προτού μετρήσει η δική του βαθμολογία.

## Ειδοποιήσεις

Κάθε φόρουμ και νήμα διαθέτει έναν διακόπτη **Να ειδοποιούμαι** που εσείς και οι εκπαιδευόμενοί σας μπορείτε να χρησιμοποιήσετε για να εγγραφείτε σε ειδοποιήσεις μέσω ηλεκτρονικού ταχυδρομείου για νέες δημοσιεύσεις. Οι ειδοποιήσεις είναι συνδρομή ανά χρήστη και δεν διαμορφώνονται κατά τη δημιουργία του φόρουμ.
