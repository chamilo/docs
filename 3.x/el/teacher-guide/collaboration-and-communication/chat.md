# Συνομιλία

Το εργαλείο συνομιλίας παρέχει ανταλλαγή μηνυμάτων κειμένου σε πραγματικό χρόνο εντός ενός μαθήματος. Είναι χρήσιμο για γρήγορη επικοινωνία, ζωντανές συνεδρίες ερωτήσεων και απαντήσεων ή ανεπίσημες συζητήσεις.

## Χρήση της Συνομιλίας

1. Ανοίξτε το εργαλείο **Συνομιλία** από την αρχική σελίδα του μαθήματος
2. Στο πλαίσιο **Χρήστες**, επιλέξτε έναν συγκεκριμένο συνδεδεμένο χρήστη για απευθείας μήνυμα, ή χρησιμοποιήστε την καρτέλα **Όλοι** για να απευθυνθείτε σε όλη την ομάδα
3. Πληκτρολογήστε το μήνυμά σας στο πεδίο κειμένου στο κάτω μέρος και πατήστε **Enter** για αποστολή (**Shift+Enter** για νέα γραμμή χωρίς αποστολή)

Μια επιλογή **Προεπισκόπηση** σας επιτρέπει να ελέγξετε τη μορφοποίηση πριν την αποστολή, και η **Επαναφορά** καθαρίζει το τρέχον προσχέδιο.

## Χαρακτηριστικά Συνομιλίας

* **Μηνύματα σε πραγματικό χρόνο** — Τα μηνύματα εμφανίζονται αμέσως στον/στους παραλήπτη(-ες)
* **Ιστορικό μηνυμάτων** — Τα προηγούμενα μηνύματα είναι ορατά όταν εισέρχεστε στη συνομιλία
* **Παρουσία χρηστών** — Το πλαίσιο Χρήστες δείχνει ποιος είναι αυτή τη στιγμή συνδεδεμένος στο μάθημα
* **Απευθείας ή ομαδικά** — Στείλτε μήνυμα σε έναν εκπαιδευόμενο κάθε φορά, ή μεταδώστε σε όλους μέσω της καρτέλας **Όλοι**

## Ως Εκπαιδευτικός

Ως εκπαιδευτικός του μαθήματος, μπορείτε:

* **Να παρακολουθείτε τις συζητήσεις** — Να εξετάζετε το ιστορικό συνομιλίας για να παρακολουθείτε τη συμμετοχή των εκπαιδευομένων
* **Να βρίσκετε αρχεία συνομιλίας στα Έγγραφα** — Το εργαλείο συνομιλίας αντικατοπτρίζει αυτόματα τα μηνύματα σε αρχεία HTML στο εργαλείο Έγγραφα, οργανωμένα ανά ημέρα και ανά εύρος (μάθημα / συνεδρία / ομάδα), ώστε η συζήτηση να διατηρείται πέρα από τη ζωντανή συνεδρία

Εάν η ρύθμιση πλατφόρμας «Περιορισμός συνομιλίας μαθήματος στους διδάσκοντες» είναι ενεργοποιημένη από τον διαχειριστή, μόνο οι διδάσκοντες μπορούν να συνομιλούν με τους εκπαιδευόμενους· διαφορετικά μπορούν να συμμετέχουν όλοι όσοι είναι εγγεγραμμένοι στο μάθημα.

## Συμβουλές για Αποτελεσματική Χρήση της Συνομιλίας

* **Προγραμματίστε συνεδρίες συνομιλίας** — Ενημερώστε εκ των προτέρων τους εκπαιδευόμενους πότε θα είστε διαθέσιμοι για ζωντανή συνομιλία (χρησιμοποιήστε το εργαλείο Ατζέντα)
* **Ορίστε βασικούς κανόνες** — Καθορίστε προσδοκίες για τον σεβαστικό τρόπο επικοινωνίας
* **Χρησιμοποιήστε την για γρήγορες ερωτήσεις** — Η συνομιλία λειτουργεί καλύτερα για σύντομες ανταλλαγές· χρησιμοποιήστε το Φόρουμ για μεγαλύτερες, δομημένες συζητήσεις

> Εάν η πλατφόρμα σας έχει ρυθμισμένη τηλεδιάσκεψη (BigBlueButton ή Zoom), εξετάστε το ενδεχόμενο να τη χρησιμοποιήσετε για ζωντανές συνεδρίες όπου η φωνή και το βίντεο θα ήταν πιο αποτελεσματικά. Βλ. [Τηλεδιάσκεψη](video-conferencing.md).
