# Ομάδες

Οι ομάδες σάς επιτρέπουν να χωρίσετε τους εκπαιδευόμενους σε μικρότερες ομάδες για συνεργατική εργασία. Κάθε ομάδα μπορεί να διαθέτει τα δικά της κοινόχρηστα εργαλεία, όπως έγγραφα, φόρουμ και wiki.

## Δημιουργία ομάδων

1. Ανοίξτε το εργαλείο **Ομάδες** από την αρχική σελίδα του μαθήματος
2. Κάντε κλικ στο **Δημιουργία ομάδων**
3. Διαμορφώστε τις ρυθμίσεις ομάδας:
   * **Αριθμός ομάδων** — Πόσες ομάδες θα δημιουργηθούν
   * **Μέγιστος αριθμός μελών ανά ομάδα** — Το όριο μεγέθους για κάθε ομάδα (0 για απεριόριστο)
   * **Αυτοεγγραφή** — Αν οι εκπαιδευόμενοι μπορούν να ενταχθούν σε ομάδες μόνοι τους
   * **Αυτοαποχώρηση** — Αν οι εκπαιδευόμενοι μπορούν να αποχωρήσουν από μια ομάδα μόνοι τους

## Εργαλεία ομάδας

![Επισκόπηση ομάδων που εμφανίζει τα διαθέσιμα εργαλεία ομάδας και τον αριθμό μελών](../../.gitbook/assets/groups-overview.png)

Κάθε ομάδα μπορεί να έχει πρόσβαση σε ένα υποσύνολο εργαλείων μαθήματος που είναι κοινόχρηστα μόνο μεταξύ των μελών της ομάδας:

* **Έγγραφα** — Ένας κοινόχρηστος χώρος αρχείων για την ομάδα
* **Φόρουμ** — Ένα φόρουμ συζήτησης ειδικά για την ομάδα
* **Wiki** — Ένα συνεργατικό wiki για την ομάδα
* **Συνομιλία** — Ένας χώρος συνομιλίας για την ομάδα
* **Ημερολόγιο** — Συμβάντα ημερολογίου σε επίπεδο ομάδας
* **Ανακοινώσεις** — Αποστολή ανακοινώσεων μόνο στα μέλη της ομάδας
* **Εργασίες** — Συλλογή εργασίας από την ομάδα

Για κάθε εργαλείο μπορείτε να επιλέξετε το επίπεδο πρόσβασης: **Μη διαθέσιμο**, **Δημόσιο** (οποιοδήποτε μέλος του μαθήματος) ή **Ιδιωτικό** (μόνο μέλη της ομάδας). Αυτές οι ρυθμίσεις μπορούν να εφαρμοστούν σε επίπεδο κατηγορίας ομάδων, ώστε πολλές ομάδες στην ίδια κατηγορία να μοιράζονται την ίδια διαμόρφωση εργαλείων.

## Διαχείριση μελών ομάδας

Μπορείτε να διαχειριστείτε την ιδιότητα μέλους ομάδας με διάφορους τρόπους:

* **Χειροκίνητη ανάθεση** — Προσθήκη συγκεκριμένων εκπαιδευόμενων σε κάθε ομάδα
* **Συμπλήρωση επιλεγμένων ομάδων** — Αυτόματη κατανομή των μη εγγεγραμμένων εκπαιδευόμενων στις επιλεγμένες ομάδες, τηρώντας τη χωρητικότητα κάθε ομάδας και το όριο ομάδων ανά χρήστη
* **Αυτοεγγραφή** — Να επιτρέπεται στους εκπαιδευόμενους να επιλέξουν τη δική τους ομάδα
* **Εισαγωγή από τάξεις** — Αυτόματη δημιουργία ομάδων από τις τάξεις που είναι ήδη εγγεγραμμένες στο μάθημα

Για χειροκίνητη διαχείριση μελών, κάντε κλικ στο όνομα μιας ομάδας και στη συνέχεια χρησιμοποιήστε την ενότητα **Μέλη** για να προσθέσετε ή να αφαιρέσετε εκπαιδευόμενους.

## Καθηγητές ομάδας

Μπορείτε να αναθέσετε **καθηγητές ομάδας** (tutors) στις ομάδες. Ένας καθηγητής ομάδας είναι συνήθως ένας εκπαιδευόμενος ή βοηθός που βοηθά στη διαχείριση της εργασίας της ομάδας. Οι καθηγητές ομάδας ενδέχεται να έχουν πρόσθετα δικαιώματα εντός της ομάδας, όπως η εποπτεία του φόρουμ της ομάδας.

## Παρακολούθηση εργασίας ομάδας

Ως διδάσκων του μαθήματος, μπορείτε να έχετε πρόσβαση σε όλες τις ομάδες και στα κοινόχρηστα εργαλεία τους ανεξάρτητα από την ιδιότητα μέλους. Αυτό σας επιτρέπει να:

* Εξετάζετε έγγραφα που ανέβασε κάθε ομάδα
* Διαβάζετε συζητήσεις στο φόρουμ της ομάδας
* Ελέγχετε συνεισφορές στο wiki
* Αξιολογείτε τη συνεργασία της ομάδας
