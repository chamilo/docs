# Συνεργασία και Επικοινωνία

Το Chamilo παρέχει διάφορα εργαλεία για την αλληλεπίδραση ανάμεσα σε εσάς και τους εκπαιδευόμενούς σας, καθώς και μεταξύ των ίδιων των εκπαιδευόμενων.

* **[Φόρουμ](forums.md)** — Συζητήσεις σε νήματα, οργανωμένες ανά κατηγορία και θέμα
* **[Συνομιλία](chat.md)** — Αποστολή μηνυμάτων κειμένου σε πραγματικό χρόνο εντός ενός μαθήματος
* **[Ομάδες](groups.md)** — Διαχωρισμός των εκπαιδευόμενων σε ομάδες εργασίας με τα δικά τους κοινόχρηστα εργαλεία
* **[Wiki](wiki.md)** — Συνεργατική επεξεργασία εγγράφων
* **[Ιστολόγιο](blog.md)** — Κοινό ιστολόγιο εντός του μαθήματος
* **[Τηλεδιάσκεψη](video-conferencing.md)** — Ζωντανές συνεδρίες βίντεο με χρήση BigBlueButton ή Zoom

Αυτά τα εργαλεία είναι διαθέσιμα από την αρχική σελίδα του μαθήματος. Ορισμένα ενδέχεται να είναι κρυφά από προεπιλογή — μπορείτε να τα εμφανίσετε από το πλέγμα εργαλείων (βλ. [Αρχική σελίδα μαθήματος](../creating-your-course/course-homepage.md)).
