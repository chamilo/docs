# Ιστολόγιο

Το εργαλείο ιστολογίου σάς επιτρέπει να δημιουργήσετε ένα κοινόχρηστο ιστολόγιο μέσα στο μάθημά σας. Οι εκπαιδευόμενοι μπορούν να γράφουν αναρτήσεις, να αφήνουν σχόλια και να συμμετέχουν σε δομημένες δραστηριότητες γραφής.

## Δημιουργία ιστολογίου

1. Ανοίξτε το εργαλείο **Ιστολόγιο** από την αρχική σελίδα του μαθήματος (κάτω από το εικονίδιο γραναζιού στην κορυφή)
2. Κάντε κλικ στο **Νέο έργο**
3. Εισαγάγετε έναν **τίτλο** και προαιρετικό υπότιτλο
4. Αποθηκεύστε
5. Αποφασίστε πότε θέλετε να το διαθέσετε στους εκπαιδευόμενους κάνοντας κλικ στο εικονίδιο **Εμφάνιση** (μάτι)

Μπορείτε να δημιουργήσετε πολλά ιστολόγια μέσα σε ένα μόνο μάθημα (π.χ. ένα ανά θέμα ή ένα ανά ομάδα).

## Συγγραφή αναρτήσεων ιστολογίου

1. Ανοίξτε ένα ιστολόγιο
2. Κάντε κλικ στο **Νέα ανάρτηση**
3. Εισαγάγετε έναν **τίτλο** και γράψτε το περιεχόμενο της ανάρτησης χρησιμοποιώντας τον επεξεργαστή εμπλουτισμένου κειμένου
4. Αποθηκεύστε

Τόσο οι εκπαιδευτικοί όσο και οι εκπαιδευόμενοι (ανάλογα με τα δικαιώματα) μπορούν να δημιουργούν αναρτήσεις.

## Σχόλια και αξιολογήσεις

Οι αναγνώστες μπορούν να αλληλεπιδρούν με τις αναρτήσεις ιστολογίου μέσω:

* **Σχόλια** — Αφήστε ανατροφοδότηση ή ξεκινήστε μια συζήτηση κάτω από μια ανάρτηση (τα σχόλια μπορούν επίσης να είναι νηματοειδή ως απαντήσεις σε άλλα σχόλια)
* **Αξιολογήσεις** — Αξιολογήστε αναρτήσεις για να αναδείξετε τις πιο αξιόλογες συνεισφορές
* **Συνημμένα** — Τόσο οι αναρτήσεις όσο και τα σχόλια μπορούν να φέρουν συνημμένα αρχεία

## Εργασίες ιστολογίου

Μπορείτε να δημιουργήσετε **εργασίες** μέσα σε ένα ιστολόγιο — συγκεκριμένες αναθέσεις γραφής που οι εκπαιδευόμενοι πρέπει να ολοκληρώσουν ως αναρτήσεις ιστολογίου. Αυτό είναι χρήσιμο για:

* Αναστοχαστικά ημερολόγια
* Εβδομαδιαίες αναθέσεις γραφής
* Αναφορές ενημέρωσης έργου

## Διαχείριση του ιστολογίου

Ως εκπαιδευτικός, μπορείτε:

* **Να επεξεργαστείτε ή να διαγράψετε** αναρτήσεις και σχόλια (η διαγραφή ανάρτησης περιορίζεται στον συντάκτη της ανάρτησης ή στους εκπαιδευτικούς)
* **Να εναλλάξετε την ορατότητα του ιστολογίου** ώστε να εμφανίζεται ή να αποκρύπτεται το ιστολόγιο από τους εκπαιδευόμενους
* **Να ορίσετε εργασίες** — Προσθέστε συγκεκριμένες αναθέσεις γραφής που οι εκπαιδευόμενοι αναμένεται να ολοκληρώσουν ως αναρτήσεις. Οι εργασίες μπορούν να χρωματιστούν για ευκολότερη οπτική ομαδοποίηση.
