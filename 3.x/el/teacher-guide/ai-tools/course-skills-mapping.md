# Χαρτογράφηση δεξιοτήτων μαθήματος με υποβοήθηση AI

Το Chamilo 3.1 μπορεί να προτείνει δεξιότητες που σχετίζονται με ένα μάθημα και να επιτρέπει σε εξουσιοδοτημένους χρήστες να εξετάζουν και να εφαρμόζουν αυτές τις προτάσεις στο αναφορικό δεξιοτήτων και στο Gradebook. Μια πρόταση AI **δεν εφαρμόζεται αυτόματα**· πρέπει να επιλεγεί και να εγκριθεί.

## Δημιουργία προτάσεων

1. Ανοίξτε τη σελίδα **Χαρτογράφηση δεξιοτήτων με υποβοήθηση AI** του σχετικού μαθήματος. Η διαδρομή της εφαρμογής είναι `/course/{courseId}/skills`, με το πραγματικό αναγνωριστικό μαθήματος να αντικαθιστά το `{courseId}`.
2. Εάν το μάθημα ανήκει σε μια συνεδρία, ανοίξτε τη σελίδα στο σωστό πλαίσιο συνεδρίας.
3. Επιλέξτε έναν διαθέσιμο **πάροχο AI**.
4. Επιλέξτε **Πρόταση δεξιοτήτων για αυτό το μάθημα** και εξετάστε τα επιστρεφόμενα αποτελέσματα.

Οι πάροχοι AI πρέπει να είναι διαθέσιμοι και ρυθμισμένοι από τη διαχείριση της πλατφόρμας. Οι προτάσεις μπορούν να αναφέρονται σε καταχωρίσεις **Υπάρχουσας δεξιότητας** ή να προτείνουν μια **Νέα δεξιότητα** κάτω από μια γονική δεξιότητα. Κάθε καταχώριση μπορεί να περιλαμβάνει την περιγραφή της, τα κριτήρια και μια εξήγηση της πρότασης.

## Εξέταση και έγκριση

1. Διαβάστε κριτικά κάθε πρόταση και συγκρίνετέ την με τους στόχους και το περιεχόμενο του μαθήματος.
2. Επιλέξτε μόνο τις έγκυρες δεξιότητες χρησιμοποιώντας τα πλαίσια ελέγχου τους.
3. Εάν διαθέτετε την απαιτούμενη εξουσιοδότηση, επιλέξτε **Προσθήκη επιλεγμένων δεξιοτήτων στο αναφορικό και στο Gradebook**.
4. Επαληθεύστε τις προκύπτουσες δεξιότητες και τις συσχετίσεις Gradebook στο μάθημα.

Οι χρήστες χωρίς δικαιώματα ανάθεσης μπορούν να εξετάζουν τις προτάσεις αλλά δεν μπορούν να τις επισυνάψουν. Η δημιουργία νέων δεξιοτήτων απαιτεί δικαιώματα διαχειριστή πλατφόρμας. Οι προτάσεις μπορεί να λήξουν· δημιουργήστε ένα νέο σύνολο εάν η εφαρμογή αναφέρει ότι οι προηγούμενες δεν είναι πλέον έγκυρες.

## Ορθή πρακτική

Οι δεξιότητες που δημιουργούνται από AI είναι υποψήφιες, όχι αυθεντικές απαιτήσεις προγράμματος σπουδών. Εξετάστε τη διατύπωση, τις διπλοεγγραφές, την τοποθέτηση γονικής δεξιότητας και τα κριτήρια πριν από την έγκριση. Αποφύγετε την εισαγωγή εμπιστευτικών πληροφοριών εκπαιδευομένων σε προτροπές AI.
