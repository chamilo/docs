# Βαθμολόγηση με Τεχνητή Νοημοσύνη

Η Βαθμολόγηση με Τεχνητή Νοημοσύνη σάς βοηθά να αξιολογείτε ανοιχτές υποβολές φοιτητών — δοκίμια, γραπτές απαντήσεις και αναρτημένες εργασίες — παρέχοντας προτάσεις βαθμολογίας και ανατροφοδότηση που παράγονται από τεχνητή νοημοσύνη.

## Πού εμφανίζεται η Βαθμολόγηση με Τεχνητή Νοημοσύνη

Η Βαθμολόγηση με Τεχνητή Νοημοσύνη είναι διαθέσιμη σε δύο περιβάλλοντα:

* **Ερωτήσεις ασκήσεων ανοιχτού τύπου** — Όταν βαθμολογείτε χειροκίνητα ερωτήσεις ελεύθερης απάντησης σε μια άσκηση
* **Υποβολές εργασιών** — Όταν εξετάζετε και βαθμολογείτε δημοσιεύσεις φοιτητών στο εργαλείο Εργασίες

Αναζητήστε το κουμπί **Βαθμολόγηση με ΤΝ** (υποδεικνύεται από εικονίδιο ρομπότ <img src="/.gitbook/assets/icons/mdi-robot.svg" alt="ΤΝ" data-size="line">) στη διεπαφή βαθμολόγησης.

## Πώς λειτουργεί

![Η διεπαφή βαθμολόγησης με ΤΝ που εμφανίζει υποβολή φοιτητή με προτεινόμενη βαθμολογία και ανατροφοδότηση](/.gitbook/assets/ai-grading-interface.png)

1. Ανοίξτε μια υποβολή ή απάντηση που χρειάζεται βαθμολόγηση
2. Κάντε κλικ στο κουμπί **Βαθμολόγηση με ΤΝ**
3. Η ΤΝ αναλύει την απάντηση του φοιτητή και παράγει:
   * Μια **προτεινόμενη βαθμολογία** με βάση την ποιότητα και τη συνάφεια της απάντησης
   * **Σχόλια ανατροφοδότησης** που εξηγούν τα δυνατά και τα αδύνατα σημεία της απάντησης
4. Εξετάστε τις προτάσεις της ΤΝ
5. **Αποδεχτείτε, τροποποιήστε ή απορρίψτε** τη βαθμολογία και την ανατροφοδότηση
6. Αποθηκεύστε τον τελικό βαθμό σας

## Σημαντικές σημειώσεις

* **Η βαθμολόγηση με ΤΝ είναι πρόταση** — Εσείς έχετε πάντα τον τελευταίο λόγο. Η ΤΝ παρέχει ένα σημείο εκκίνησης που μπορείτε να προσαρμόσετε με βάση την επαγγελματική σας κρίση.
* **Η εξέταση είναι απαραίτητη** — Η ΤΝ μπορεί να παρερμηνεύσει το πλαίσιο, να χάσει αποχρώσεις ή να βαθμολογήσει λανθασμένα. Εξετάζετε πάντα τον προτεινόμενο βαθμό πριν την επιβεβαίωση.
* **Λειτουργεί καλύτερα με σαφή κριτήρια** — Όσο πιο συγκεκριμένες είναι οι οδηγίες της εργασίας και η ρουμπρίκα βαθμολόγησης, τόσο καλύτερες θα είναι οι προτάσεις της ΤΝ.

## Γνωστοποίηση περιεχομένου που παράγεται από ΤΝ

Τα σχόλια που παράγονται από ΤΝ επισημαίνονται με ειδοποίηση γνωστοποίησης, που δηλώνει ότι δημιουργήθηκαν με χρήση τεχνητής νοημοσύνης. Αυτή η διαφάνεια βοηθά τους εκπαιδευόμενους να κατανοήσουν την προέλευση της βαθμολόγησης.

## Συμβουλές

* **Χρήση σε μεγάλα τμήματα** — Η βαθμολόγηση με ΤΝ είναι πιο πολύτιμη όταν έχετε πολλές υποβολές προς εξέταση, καθώς επιταχύνει την αρχική αξιολόγηση
* **Παρέχετε λεπτομερείς περιγραφές εργασιών** — Οι σαφείς οδηγίες βοηθούν την ΤΝ να κατανοήσει πώς μοιάζει μια καλή απάντηση
* **Ρυθμίστε τις προσδοκίες** — Βαθμολογήστε πρώτα μερικές υποβολές χειροκίνητα για να καθορίσετε τα πρότυπά σας και στη συνέχεια χρησιμοποιήστε τη βαθμολόγηση με ΤΝ για τις υπόλοιπες
* **Χρησιμοποιήστε την ανατροφοδότηση** — Η ανατροφοδότηση που παράγεται από ΤΝ μπορεί να αποτελέσει χρήσιμο σημείο εκκίνησης για τα σχόλιά σας, ακόμη και αν προσαρμόσετε τη βαθμολογία
