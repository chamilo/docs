# Γεννήτρια Ασκήσεων

Η Γεννήτρια Ασκήσεων ΤΝ σάς βοηθά να δημιουργείτε αυτόματα ερωτήσεις κουίζ χρησιμοποιώντας τεχνητή νοημοσύνη. Παρέχετε ένα θέμα ή περιεχόμενο και η ΤΝ παράγει ερωτήσεις τις οποίες μπορείτε να ελέγξετε, να επεξεργαστείτε και να προσθέσετε στις ασκήσεις σας.

## Πρόσβαση στη Γεννήτρια Ασκήσεων

Η Γεννήτρια Ασκήσεων είναι διαθέσιμη κατά τη δημιουργία ή την επεξεργασία μιας άσκησης, εφόσον:

1. Οι βοηθοί ΤΝ είναι ενεργοποιημένοι σε επίπεδο πλατφόρμας
2. Έχει ρυθμιστεί τουλάχιστον ένας πάροχος κειμένου ΤΝ

Αναζητήστε το κουμπί ή την ενότητα **AI Generator** στη διεπαφή δημιουργίας άσκησης.

## Πώς να δημιουργήσετε ερωτήσεις

![Η φόρμα της γεννήτριας ασκήσεων ΤΝ με πεδία για θέμα και αριθμό ερωτήσεων](../../.gitbook/assets/ai-exercise-generator.png)

Η γεννήτρια προσφέρει δύο λειτουργίες, διαθέσιμες ως καρτέλες:

* **Test from topic** — Δημιουργία ερωτήσεων από μια κειμενική περιγραφή θέματος
* **Test from document** — Δημιουργία ερωτήσεων από ένα έγγραφο μαθήματος (διαθέσιμο μόνο όταν έχει ρυθμιστεί πάροχος με δυνατότητα εγγράφων). Όταν χρησιμοποιείται αυτή η λειτουργία, το πεδίο θέματος γίνεται προαιρετικό και αντιμετωπίζεται ως επιπλέον υπόδειξη.

1. Ανοίξτε τη φόρμα AI Generator μέσα σε μια άσκηση και επιλέξτε τη λειτουργία
2. Ρυθμίστε τις παραμέτρους δημιουργίας:
   * **Quiz title** — Ο τίτλος της προκύπτουσας άσκησης
   * **Questions topic** — Περιγράψτε το αντικείμενο των ερωτήσεων (ή, στη λειτουργία εγγράφου, μια προαιρετική υπόδειξη)
   * **Number of questions** — Πόσες ερωτήσεις θα δημιουργηθούν (ανώτατο όριο 100)
   * **Question type** — Προς το παρόν προσφέρεται μόνο **Multiple answer**
   * **AI provider** — Επιλέξτε ποιον πάροχο ΤΝ θα χρησιμοποιήσετε (εμφανίζεται μόνο όταν έχουν ρυθμιστεί περισσότεροι από ένας)
3. Κάντε κλικ στο **Generate**
4. Η ΤΝ παράγει ένα σύνολο ερωτήσεων με επιλογές απαντήσεων και σημειωμένες τις σωστές απαντήσεις. Όταν είναι ενεργοποιημένη η γνωστοποίηση ΤΝ, οι δημιουργημένες ερωτήσεις έχουν πρόθεμα **\[AI-assisted\]**.

## Έλεγχος και επεξεργασία

![Ερωτήσεις που δημιουργήθηκαν από ΤΝ, εμφανιζόμενες για έλεγχο, με επιλογές επεξεργασίας, αποδοχής ή αφαίρεσης καθεμιάς](../../.gitbook/assets/ai-exercise-generator-results.png)

Οι δημιουργημένες ερωτήσεις παρουσιάζονται ως **προτάσεις**. Θα πρέπει:

* **Να ελέγχετε κάθε ερώτηση** ως προς την ακρίβεια και τη συνάφεια
* **Να επεξεργάζεστε τη διατύπωση** αν χρειάζεται — να προσαρμόζετε ερωτήσεις, επιλογές απαντήσεων και ανατροφοδότηση
* **Να επαληθεύετε τις σωστές απαντήσεις** — να βεβαιώνεστε ότι η ΤΝ έχει εντοπίσει τις σωστές απαντήσεις
* **Να αφαιρείτε ακατάλληλες ερωτήσεις** — να διαγράφετε όσες δεν πληρούν τα πρότυπά σας
* **Να προσαρμόζετε τη βαθμολόγηση** — να ορίζετε κατάλληλες τιμές μονάδων για κάθε ερώτηση

Όταν είστε ικανοποιημένοι, προσθέστε τις ερωτήσεις στην άσκησή σας.

Σημειώστε ότι, παρά τα συγκεκριμένα αιτήματά μας ως προς τη μορφή, ορισμένα μοντέλα επιστρέφουν τίτλους ερωτήσεων με αριθμητικό πρόθεμα. Δεν συνιστούμε να αφήνετε αυτόν τον αριθμό, καθώς θα εμποδίζει την ανάμειξη ερωτήσεων σε τεστ με τυχαία επιλεγμένες ερωτήσεις. Επίσης, μερικές φορές δεν λαμβάνετε τόσες ερωτήσεις όσες ζητήσατε, οπότε βεβαιωθείτε ότι το ελέγχετε και ενδεχομένως δημιουργήστε περισσότερες ερωτήσεις ή αλλάξτε μοντέλο αν έχετε αυτή τη δυνατότητα.

## Γνωστοποίηση περιεχομένου που δημιουργήθηκε από ΤΝ

Το περιεχόμενο που δημιουργείται από ΤΝ επισημαίνεται με ειδοποίηση γνωστοποίησης, που υποδεικνύει ότι δημιουργήθηκε με χρήση τεχνητής νοημοσύνης. Αυτή η διαφάνεια βοηθά τους εκπαιδευόμενους να κατανοήσουν την προέλευση του υλικού.

## Συμβουλές

* **Δώστε συγκεκριμένα θέματα** — Όσο πιο συγκεκριμένη είναι η περιγραφή του θέματός σας, τόσο πιο συναφείς θα είναι οι δημιουργημένες ερωτήσεις.
* **Να ελέγχετε πάντα** — Το περιεχόμενο που δημιουργείται από ΤΝ μπορεί να περιέχει σφάλματα. Μην δημοσιεύετε ποτέ ερωτήσεις χωρίς προηγούμενο έλεγχο.
* **Χρησιμοποιήστε τις ως αφετηρία** — Οι δημιουργημένες ερωτήσεις εξοικονομούν χρόνο, δεν είναι τελικό προϊόν. Επεξεργαστείτε τις ώστε να ταιριάζουν στο διδακτικό σας ύφος και στο περιεχόμενο του μαθήματος.
* **Συνδυάστε με χειροκίνητες ερωτήσεις** — Συνδυάστε ερωτήσεις που δημιουργήθηκαν από ΤΝ με χειροκίνητα δημιουργημένες για τα καλύτερα αποτελέσματα.
* **Δοκιμάστε διαφορετικούς παρόχους** — Αν είναι διαθέσιμοι πολλοί πάροχοι ΤΝ, δοκιμάστε διαφορετικούς για να δείτε ποιος παράγει τις καλύτερες ερωτήσεις για το γνωστικό σας αντικείμενο.
