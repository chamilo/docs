# Τεκμηρίωση Chamilo 3.0

Καλώς ήρθατε στην επίσημη τεκμηρίωση του **Chamilo 3.0**, της πλατφόρμας ηλεκτρονικής μάθησης ανοιχτού κώδικα.

Η τεκμηρίωση αυτή οργανώνεται σε τρεις οδηγούς, καθένας προσαρμοσμένος σε συγκεκριμένο κοινό:

* [**Οδηγός εκπαιδευτή**](teacher-guide/) — Για διδάσκοντες και εκπαιδευτές: δημιουργία μαθημάτων, προσθήκη περιεχομένου, αξιολόγηση εκπαιδευομένων και παρακολούθηση προόδου.
* [**Οδηγός διαχείρισης**](admin-guide/) — Για διαχειριστές πλατφόρμας: εγκατάσταση, διαμόρφωση και διαχείριση της πλατφόρμας Chamilo.
* [**Οδηγός προγραμματιστή**](developer-guide/) — Για προγραμματιστές: κατανόηση της αρχιτεκτονικής, δημιουργία πρόσθετων, χρήση του API και συνεισφορά στο έργο.

## Τι νέο υπάρχει στο Chamilo 3.0

Το Chamilo 3.0 είναι μια μείζονα έκδοση με πλήρως επανασχεδιασμένη διεπαφή και πολλά νέα χαρακτηριστικά:

* **Σύγχρονη διεπαφή** — Υλοποιημένη με Vue 3 και PrimeVue για ταχύτερη, πιο αποκριτική εμπειρία
* **Εργαλεία με τεχνητή νοημοσύνη** — Δημιουργία ασκήσεων, μαθησιακών διαδρομών και βαθμολόγηση με υποστήριξη AI
* **REST API** — Πλήρες REST API βασισμένο στο API Platform με πιστοποίηση JWT
* **Νέες επιλογές πιστοποίησης** — OAuth2 (Azure, Keycloak, Facebook), παροχή χρηστών SCIM
* **LTI 1.3** — Απρόσκοπτη σύνδεση εξωτερικών εργαλείων μάθησης
* **Αποθήκευση στο νέφος** — Εγγενής υποστήριξη για Azure Blob, AWS S3 και Google Cloud Storage
* **Χρωματικά θέματα** — Προσαρμόσιμη εταιρική ταυτότητα πλατφόρμας με υποστήριξη θεμάτων
* **Ενσωμάτωση OnlyOffice** — Συνεργατική επεξεργασία εγγράφων εντός της πλατφόρμας
