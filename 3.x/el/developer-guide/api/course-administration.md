# API διαχείρισης μαθημάτων

Το Chamilo 3.1 επιτρέπει στις ενσωματώσεις διαχειριστή να ενημερώνουν τα μεταδεδομένα μαθημάτων και να διαγράφουν μαθήματα μέσω του πόρου API `Course`. Αυτές οι λειτουργίες προστέθηκαν για συγχρονισμό με εξωτερικά συστήματα διαχείρισης, όπως ένα ERP.

## Δικαιώματα

| Λειτουργία | Μέθοδος και τελικό σημείο | Απαιτούμενος ρόλος |
|-----------|---------------------|---------------|
| Λίστα μαθημάτων | `GET /api/courses` | Διδάσκων ή διαχειριστής πλατφόρμας |
| Προβολή μαθήματος | `GET /api/courses/{id}` | Δικαίωμα προβολής του συγκεκριμένου μαθήματος |
| Δημιουργία μαθήματος | `POST /api/courses` | Διδάσκων ή διαχειριστής πλατφόρμας |
| Ενημέρωση μαθήματος | `PATCH /api/courses/{id}` | **Διαχειριστής πλατφόρμας (`ROLE_ADMIN`)** |
| Διαγραφή μαθήματος | `DELETE /api/courses/{id}` | **Διαχειριστής πλατφόρμας (`ROLE_ADMIN`)** |

Το `PUT` δεν έχει ρυθμιστεί ως λειτουργία σε αυτόν τον πόρο. Οι διδάσκοντες πρέπει να συνεχίσουν να επεξεργάζονται τα δικά τους μαθήματα μέσω της διεπαφής ρυθμίσεων μαθήματος· οι νέες λειτουργίες εγγραφής του API προορίζονται αποκλειστικά για διαχειριστές.

Χρησιμοποιήστε έναν πιστοποιημένο λογαριασμό ή διαπιστευτήριο ενσωμάτωσης με τα απαραίτητα δικαιώματα. Δείτε [Πιστοποίηση API](authentication.md).

## Ενημέρωση μεταδεδομένων μαθήματος

Στείλτε ένα αίτημα JSON Merge Patch του API Platform για να αλλάξετε μόνο τις ιδιότητες που παρέχονται στο σώμα:

```http
PATCH /api/courses/42
Authorization: Bearer <admin-token>
Content-Type: application/merge-patch+json
Accept: application/ld+json
```

```json
{
  "title": "Introduction to Accounting - 2026"
}
```

Το αίτημα ενημερώνει το υπάρχον μάθημα αντί να δημιουργεί νέο. Το API αποδέχεται εγγράψιμες ιδιότητες που ορίζονται από την ομάδα σειριοποίησης `course:write`, υπό την επιφύλαξη της επικύρωσης οντότητας. Παραδείγματα περιλαμβάνουν τα `title`, `visibility`, `categories`, `departmentUrl`, `videoUrl`, `sticky` και `duration`. Ιδιότητες σχέσεων, όπως το `categories`, απαιτούν την αναπαράσταση πόρου που αναμένει το API· συμβουλευτείτε την τεκμηρίωση OpenAPI αντί να στέλνετε αυθαίρετα αναγνωριστικά βάσης δεδομένων.

**Σημαντικό:** ο εσωτερικός `code` του μαθήματος **δεν** είναι εγγράψιμος μέσω αυτής της λειτουργίας PATCH. Μην επιχειρήσετε να μετονομάσετε τον εσωτερικό κωδικό ενός μαθήματος στέλνοντας πεδίο `code` ή `visualCode`.

## Διαγραφή μαθήματος

```http
DELETE /api/courses/42
Authorization: Bearer <admin-token>
```

Πρόκειται για **καταστροφική** λειτουργία διαχείρισης. Το Chamilo καλεί τον ίδιο βοηθητικό μηχανισμό διαγραφής μαθήματος που χρησιμοποιείται από τη συντήρηση μαθημάτων, αντί να διαγράφει απευθείας την οντότητα Doctrine. Καθαρίζει τις σχετικές εγγραφές, τους συνδέσμους συνεδριών και τάξεων, τα δεδομένα παρακολούθησης και τη σχετική ευρετηρίαση αναζήτησης, κατά περίπτωση.

Σε εγκατάσταση **πολλαπλών URL**, η διαγραφή ενδέχεται μόνο να αποσυνδέσει το μάθημα από το τρέχον URL πρόσβασης αντί να το διαγράψει παντού. Τα έγγραφα του μαθήματος δεν διαγράφονται με χρήση της ξεχωριστής επιλογής *διαγραφή αποκλειστικών εγγράφων* από τη διεπαφή συντήρησης. Μην ερμηνεύετε μια διαγραφή μέσω API ως εγγύηση ότι κάθε έγγραφο αφαιρείται φυσικά.

Εάν μια ενεργή εξάρτηση εμποδίζει τη διαγραφή (για παράδειγμα, μια ακολουθία πόρων), το τελικό σημείο μπορεί να απαντήσει με `409 Conflict`. Ελέγξτε τις εξαρτήσεις και τα αντίγραφα ασφαλείας του μαθήματος πριν στείλετε αιτήματα DELETE, ιδίως σε μαζικές ενσωματώσεις.

## Σφάλματα και λειτουργικές σημειώσεις

* Ένας καλών χωρίς τον απαιτούμενο ρόλο διαχειριστή απορρίπτεται· χρησιμοποιήστε έναν σωστά εξουσιοδοτημένο λογαριασμό αντί για διαπιστευτήριο διδάσκοντα για PATCH ή DELETE.
* Μη έγκυρα δεδομένα αιτήματος μπορεί να αποτύχουν στην επικύρωση οντότητας. Ανακτήστε το τρέχον μάθημα πριν το ενημερώσετε με patch και στείλτε μόνο τις ιδιότητες που σκοπεύετε να αλλάξετε.
* Αυτές οι λειτουργίες εκτίθενται από το API Platform· συμβουλευτείτε την τεκμηρίωση OpenAPI της εγκατεστημένης παρουσίας για το ακριβές σχήμα απόκρισης και τις αποδεκτές μορφές πεδίων.
* Δοκιμάστε τη διαγραφή μαθήματος σε ένα αναλώσιμο μάθημα, όχι σε μάθημα που περιέχει παραγωγικά αρχεία εκπαιδευομένων.

Για τη διαχείριση μαθημάτων στη διεπαφή, δείτε [Διαχείριση μαθημάτων](../../admin-guide/courses/managing-courses.md). Για ενσωματώσεις εγγραφής σε συνεδρίες, δείτε [Εγγραφή φοιτητών σε συνεδρία](session-students.md).
