# Διπλασιασμός συνεδρίας

Το `POST /api/sessions/{id}/duplicate` δημιουργεί μια νέα συνεδρία από μια υπάρχουσα **συνεδρία-πρότυπο**. Αποτελεί την αντικατάσταση στο Chamilo 3 της ενέργειας `create_session_from_model` της υπηρεσίας ιστού `webservices/api/v2.php` της έκδοσης 1.11.x και προορίζεται για ενσωματώσεις που ανοίγουν μια νέα εκπαιδευτική περίοδο από μια συνεδρία-πρότυπο.

## Πρόσβαση

| Καλών | Επιτρέπεται |
|--------|---------|
| `ROLE_ADMIN` | Οποιαδήποτε συνεδρία |
| `ROLE_SESSION_MANAGER` | Μόνο συνεδρίες που διαχειρίζονται (είναι διαχειριστές συνεδρίας του προτύπου), εκτός εάν είναι ενεργοποιημένη η ρύθμιση **Να επιτρέπεται στους διαχειριστές συνεδρίας να βλέπουν όλες τις συνεδρίες** |
| Οποιοσδήποτε άλλος | `403 Forbidden` |

Πραγματοποιήστε έλεγχο ταυτότητας με JWT ή με εξωτερικό κλειδί API, όπως περιγράφεται στην ενότητα [Έλεγχος ταυτότητας](authentication.md).

## Αίτημα

```http
POST /api/sessions/42/duplicate
Authorization: Bearer <token>
Content-Type: application/json
```

```json
{
  "title": "Accounting basics - October 2026",
  "startDate": "2026-10-01T09:00:00+02:00",
  "endDate": "2026-12-15T18:00:00+01:00",
  "extraFields": { "my_session_field": "value" },
  "copySessionContent": false
}
```

| Πεδίο | Υποχρεωτικό | Περιγραφή |
|-------|----------|-------------|
| `title` | Ναι | Τίτλος της νέας συνεδρίας. Δεν πρέπει να χρησιμοποιείται ήδη από άλλη συνεδρία (μέγ. 150 χαρακτήρες). |
| `startDate` | Ναι | Ημερομηνία και ώρα κατά ISO 8601. Χρησιμοποιείται ως ημερομηνία έναρξης πρόσβασης, εμφάνισης και πρόσβασης εκπαιδευτή. |
| `endDate` | Ναι | Ημερομηνία και ώρα κατά ISO 8601, όχι προγενέστερη του `startDate`. Χρησιμοποιείται ως ημερομηνία λήξης πρόσβασης, εμφάνισης και πρόσβασης εκπαιδευτή. |
| `extraFields` | Όχι | Τιμές πρόσθετων πεδίων συνεδρίας, με κλειδί τη μεταβλητή του πεδίου. Αντικαθιστούν τις τιμές που αντιγράφονται από το πρότυπο. Κάθε μεταβλητή πρέπει να αντιστοιχεί σε υπάρχον πρόσθετο πεδίο συνεδρίας. |
| `copySessionContent` | Όχι | `false` από προεπιλογή. Όταν είναι `true`, το ειδικό για τη συνεδρία περιεχόμενο κάθε μαθήματος (έγγραφα, μαθησιακές διαδρομές, τεστ, συμβάντα ημερολογίου, ανακοινώσεις, βαθμολόγιο…) διπλασιάζεται στη νέα συνεδρία. Το βασικό περιεχόμενο του μαθήματος είναι πάντα κοινόχρηστο και δεν αντιγράφεται ποτέ. Αυτή η σημαία είναι ανεξάρτητη από τη ρύθμιση πλατφόρμας **Ενεργοποίηση της αντιγραφής περιεχομένου ειδικού για τη συνεδρία σε άλλη συνεδρία**. |

## Τι αντιγράφεται

| Αντιγράφεται από το πρότυπο | Δεν αντιγράφεται |
|-----------------------|------------|
| Κατηγορία, ορατότητα, διάρκεια, περιγραφή και «εμφάνιση περιγραφής» | Εκπαιδευτές μαθημάτων |
| Τιμές πρόσθετων πεδίων συνεδρίας | Υπεύθυνοι ανθρώπινου δυναμικού (DRH) |
| Μαθήματα, με την ίδια σειρά | Εκπαιδευόμενοι |
| Γενικοί εκπαιδευτές | |
| Διαχειριστές συνεδρίας (εάν το πρότυπο δεν έχει κανέναν, ο καλών γίνεται διαχειριστής συνεδρίας) | |
| Επιλογή «Αποστολή ειδοποίησης εγγραφής» | |
| Προώθηση | |
| Περιεχόμενο μαθήματος ειδικό για τη συνεδρία, μόνο όταν το `copySessionContent` είναι `true` | |

Οι εκπαιδευόμενοι παραλείπονται σκόπιμα: κάθε περίοδος αποκτά τους δικούς της εκπαιδευόμενους. Εγγράψτε τους στη συνέχεια με το `POST /api/course-sessions/actions/subscribe-users`.

Η νέα συνεδρία συσχετίζεται με την τρέχουσα διεύθυνση URL πρόσβασης.

## Απόκριση

`201 Created` με τη νέα συνεδρία:

```json
{
  "id": 57,
  "title": "Accounting basics - October 2026",
  "nbrCourses": 3,
  "visibility": 1,
  "generalCoachesSubscriptions": [{ "user": "/api/users/7" }]
}
```

## Σφάλματα

| Κατάσταση | Πότε |
|--------|------|
| `401` | Απουσία ή μη έγκυρα διαπιστευτήρια |
| `403` | Ο καλών δεν επιτρέπεται να διαχειριστεί τη συνεδρία-πρότυπο |
| `404` | Η συνεδρία-πρότυπο δεν υπάρχει |
| `422` | Ελλιπές ή μη έγκυρο πεδίο, `endDate` προγενέστερο του `startDate`, τίτλος που χρησιμοποιείται ήδη ή άγνωστη μεταβλητή πρόσθετου πεδίου |

Όλοι οι έλεγχοι εκτελούνται πριν δημιουργηθεί οτιδήποτε, ώστε ένα απορριφθέν αίτημα να μην αφήνει ποτέ πίσω του μερική συνεδρία.

## Υλοποίηση

* Λειτουργία: `duplicate_session` στον πόρο `Session` (`src/CoreBundle/Entity/Session.php`)
* Είσοδος: `src/CoreBundle/Dto/SessionDuplicateInput.php`
* Επεξεργαστής: `src/CoreBundle/State/Session/SessionDuplicateProcessor.php`, ο οποίος καλεί το `SessionManager::copy()` (χρησιμοποιείται επίσης από την ενέργεια **Αντιγραφή** της λίστας συνεδριών) και στη συνέχεια εφαρμόζει τον ζητούμενο τίτλο, τις ημερομηνίες και τα πρόσθετα πεδία, καθώς και την προώθηση του προτύπου, τους διαχειριστές συνεδρίας, την επιλογή ειδοποίησης και τη σειρά των μαθημάτων.
