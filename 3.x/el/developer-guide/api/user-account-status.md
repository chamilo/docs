# Κατάσταση λογαριασμού χρήστη

Το πεδίο `active` ενός χρήστη είναι η κατάσταση του λογαριασμού. Ένας διαχειριστής αποκλείει ή ξεμπλοκάρει έναν λογαριασμό αλλάζοντάς το με `PATCH /api/users/{id}`. Αυτό αντικαθιστά το πεδίο `active` της υπηρεσίας ιστού `webservices/api/v2.php` της έκδοσης 1.11.x.

## Τιμές

| `active` | Σημασία |
|----------|---------|
| `1` | Ενεργός: ο χρήστης μπορεί να συνδεθεί |
| `0` | Ανενεργός: ο λογαριασμός είναι αποκλεισμένος |
| `-1` | Απενεργοποιήθηκε αυτόματα από την πλατφόρμα |
| `-2` | Διαγραμμένος (στον κάδο απορριμμάτων) |

Το API μπορεί να ορίσει μόνο `1` ή `0`. Η διαγραφή γίνεται μέσω `DELETE /api/users/{id}`, και η επαναφορά ενός διαγραμμένου λογαριασμού μέσω του κάδου απορριμμάτων της διαχείρισης.

## Ανάγνωση της κατάστασης

Το `active` επιστρέφεται από το `GET /api/users/{id}` και από το `GET /api/users?username=...`.

```http
GET /api/users/42
Authorization: Bearer <token>
Accept: application/json
```

```json
{ "id": 42, "username": "jdupont", "active": 1 }
```

## Αλλαγή της κατάστασης

```http
PATCH /api/users/42
Authorization: Bearer <token>
Content-Type: application/merge-patch+json
Accept: application/json

{ "active": 0 }
```

Η απόκριση είναι ο ενημερωμένος χρήστης. Στείλτε `{ "active": 1 }` για να ξεμπλοκάρετε τον λογαριασμό. Το `active` μπορεί να σταλεί μαζί με άλλα πεδία του χρήστη.

## Πρόσβαση

| Καλών | Επιτρέπεται |
|--------|---------|
| `ROLE_ADMIN` | Οποιονδήποτε χρήστη που μπορεί να επεξεργαστεί, εκτός από τον δικό του λογαριασμό |
| Οποιοσδήποτε άλλος χρήστης | Δεν επιτρέπεται, ακόμη και στον δικό του λογαριασμό |

Η αποστολή της τρέχουσας τιμής δεν απορρίπτεται ποτέ, ώστε ένας πελάτης που επιστρέφει ολόκληρο τον χρήστη να μην αποκλείεται.

## Σφάλματα

| Κατάσταση | Πότε |
|--------|------|
| `400` | Τιμή διαφορετική από `0` ή `1` |
| `401` | Απουσία ή μη έγκυρα διαπιστευτήρια |
| `403` | Ο καλών δεν είναι διαχειριστής ή αλλάζει τη δική του κατάσταση |
| `404` | Ο χρήστης δεν υπάρχει |
