# Αναφορά Τελικών Σημείων (Endpoints)

Το API Platform δημιουργεί αυτόματα τελικά σημεία REST για οντότητες με την επισημείωση `#[ApiResource]`. Το Chamilo εκθέτει περισσότερους από 100 πόρους.

## Τυπικές Λειτουργίες

Για κάθε πόρο API, οι ακόλουθες λειτουργίες είναι συνήθως διαθέσιμες:

| Μέθοδος | Διαδρομή | Περιγραφή |
|--------|------|-------------|
| `GET` | `/api/{resources}` | Λίστα (συλλογή) |
| `POST` | `/api/{resources}` | Δημιουργία |
| `GET` | `/api/{resources}/{id}` | Ανάγνωση (μεμονωμένο στοιχείο) |
| `PUT` | `/api/{resources}/{id}` | Πλήρης ενημέρωση |
| `PATCH` | `/api/{resources}/{id}` | Μερική ενημέρωση |
| `DELETE` | `/api/{resources}/{id}` | Διαγραφή |

Δεν είναι ενεργοποιημένες όλες οι λειτουργίες για κάθε πόρο — ισχύουν περιορισμοί ασφαλείας.

## Φιλτράρισμα και Σελιδοποίηση

Το API Platform υποστηρίζει:

* **Σελιδοποίηση**: `?page=2&itemsPerPage=30`
* **Φιλτράρισμα**: `?title=Introduction` (εξαρτάται από τα διαμορφωμένα φίλτρα)
* **Ταξινόμηση**: `?order[title]=asc`
* **Αναζήτηση**: Πλήρης αναζήτηση κειμένου στα διαμορφωμένα πεδία

## Διαπραγμάτευση Περιεχομένου

Το API υποστηρίζει πολλαπλές μορφές:

* `application/ld+json` (προεπιλογή — JSON-LD)
* `application/json`
* `text/html` (τεκμηρίωση API)

Ορίστε την κεφαλίδα `Accept` για να επιλέξετε τη μορφή απόκρισης.

## Ασφάλεια

Κάθε τελικό σημείο επιβάλλει ασφάλεια μέσω:

* Αυθεντικοποίησης JWT (απαιτείται για τα περισσότερα τελικά σημεία)
* Symfony security voters (δικαιώματα σε επίπεδο πόρου)
* Ελέγχου πρόσβασης βάσει ρόλων (π.χ. τελικά σημεία μόνο για διαχειριστές)
