# Δημιουργία χρήστη

Το `POST /api/access_urls/{id}/user` δημιουργεί έναν χρήστη της πλατφόρμας και τον προσθέτει στη διεύθυνση πρόσβασης `{id}`. Αποτελεί την αντικατάσταση στο Chamilo 3 της ενέργειας `save_user_json` της υπηρεσίας ιστού `webservices/api/v2.php` της έκδοσης 1.11.x και προορίζεται για ενσωματώσεις που δημιουργούν λογαριασμούς εκπαιδευομένων (καταστήματα, συστήματα ανθρώπινου δυναμικού, πύλες εγγραφής).

## Πρόσβαση

| Καλών | Επιτρέπεται |
|--------|---------|
| `ROLE_ADMIN` | Ναι |
| `ROLE_SESSION_MANAGER` | Ναι |
| Οποιοσδήποτε άλλος | `403 Forbidden` |

Πραγματοποιήστε έλεγχο ταυτότητας με JWT ή με εξωτερικό κλειδί API, όπως περιγράφεται στην ενότητα [Έλεγχος ταυτότητας](authentication.md).

## Αίτημα

```http
POST /api/access_urls/1/user
Authorization: Bearer <token>
Content-Type: application/json
```

```json
{
  "username": "jdoe-20261022",
  "email": "jane.doe@example.com",
  "firstname": "Jane",
  "lastname": "Doe",
  "password": "S3cret!pass",
  "sendEmail": true,
  "extraFields": { "my_user_field": "value" }
}
```

| Πεδίο | Υποχρεωτικό | Περιγραφή |
|-------|----------|-------------|
| `username` | Ναι | Όνομα σύνδεσης του νέου χρήστη. Δεν πρέπει να χρησιμοποιείται ήδη από άλλον λογαριασμό (η σύγκριση γίνεται χωρίς διάκριση πεζών-κεφαλαίων). |
| `email` | Ναι | Έγκυρη διεύθυνση ηλεκτρονικού ταχυδρομείου. Πολλοί λογαριασμοί μπορούν να μοιράζονται την ίδια διεύθυνση, εκτός εάν το `checkEmailDuplicates` είναι `true`. |
| `firstname`, `lastname` | Όχι | Όνομα και επώνυμο. |
| `password` | Όχι | Αρχικός κωδικός πρόσβασης. Όταν είναι κενός και το `sendEmail` είναι `true`, το μήνυμα ηλεκτρονικού ταχυδρομείου περιέχει σύνδεσμο για τον ορισμό κωδικού πρόσβασης. |
| `locale` | Όχι | Γλώσσα διεπαφής, π.χ. `fr_FR`. Από προεπιλογή χρησιμοποιείται η γλώσσα της πλατφόρμας. |
| `timezone` | Όχι | Από προεπιλογή χρησιμοποιείται η ζώνη ώρας της πλατφόρμας. |
| `status` | Όχι | `5` (εκπαιδευόμενος) από προεπιλογή· `1` για διδάσκοντα. |
| `sendEmail` | Όχι | `true` από προεπιλογή. Αποστέλλει στον χρήστη μήνυμα και μήνυμα ηλεκτρονικού ταχυδρομείου με τα στοιχεία πρόσβασής του. |
| `checkEmailDuplicates` | Όχι | `false` από προεπιλογή. Όταν είναι `true`, το αίτημα απορρίπτεται με `409 email_already_exists` εάν οποιοσδήποτε λογαριασμός χρησιμοποιεί ήδη αυτή τη διεύθυνση ηλεκτρονικού ταχυδρομείου (η σύγκριση γίνεται χωρίς διάκριση πεζών-κεφαλαίων). Ίδια συμπεριφορά με την παράμετρο `check_email_duplicates` του `save_user_json`. |
| `extraFields` | Όχι | Τιμές πρόσθετων πεδίων χρήστη, με κλειδί τη μεταβλητή του πεδίου. Κάθε μεταβλητή πρέπει να αντιστοιχεί σε υπάρχον πρόσθετο πεδίο χρήστη. |

### Κοινές διευθύνσεις ηλεκτρονικού ταχυδρομείου

Το Chamilo δεν απαιτεί οι διευθύνσεις ηλεκτρονικού ταχυδρομείου να είναι μοναδικές: η φόρμα δημιουργίας χρήστη του διαχειριστή αποδέχεται διεύθυνση που χρησιμοποιείται ήδη από άλλον λογαριασμό, η εισαγωγή χρηστών την απορρίπτει μόνο όταν είναι επιλεγμένη η επιλογή **Έλεγχος μοναδικού ηλεκτρονικού ταχυδρομείου**, και δεν υπάρχει ρύθμιση πλατφόρμας για την αλλαγή αυτής της συμπεριφοράς. Συνηθισμένη περίπτωση είναι ένας εκπαιδευόμενος που εγγράφεται εκ νέου με νέο αναγνωριστικό και διατηρεί την ίδια διεύθυνση. Στείλτε `checkEmailDuplicates: true` μόνο όταν η ενσωμάτωσή σας θέλει να αντιμετωπίζει μια υπάρχουσα διεύθυνση ως σφάλμα.

Όταν είναι ενεργοποιημένη η ρύθμιση **Η σύνδεση είναι το ηλεκτρονικό ταχυδρομείο**, το όνομα χρήστη είναι η διεύθυνση ηλεκτρονικού ταχυδρομείου, οπότε ο έλεγχος του ονόματος χρήστη απορρίπτει ήδη τα διπλότυπα.

## Απόκριση

`201 Created` με τον νέο χρήστη (ομάδα σειριοποίησης `user:read`), συμπεριλαμβανομένου του `id` του.

## Σφάλματα

| Κατάσταση | Σώμα | Πότε |
|--------|------|------|
| `401` | | Απουσία ή μη έγκυρα διαπιστευτήρια |
| `403` | | Ο καλών δεν είναι ούτε διαχειριστής ούτε διαχειριστής συνεδρίας |
| `409` | `{"error": "username_already_exists"}` | Το όνομα χρήστη χρησιμοποιείται ήδη |
| `409` | `{"error": "email_already_exists"}` | Το `checkEmailDuplicates` είναι `true` και η διεύθυνση ηλεκτρονικού ταχυδρομείου χρησιμοποιείται ήδη |
| `422` | | Λείπει το `username` ή το `email`, ή η διεύθυνση ηλεκτρονικού ταχυδρομείου δεν είναι έγκυρη |

## Υλοποίηση

* Λειτουργία: ο πόρος `AccessUrlUser` που δηλώνεται στο `src/CoreBundle/Entity/User.php`
* Είσοδος: `src/CoreBundle/Dto/CreateUserOnAccessUrlInput.php`
* Ελεγκτής: `src/CoreBundle/Controller/Api/CreateUserOnAccessUrlAction.php`
* Η σελίδα **Εγγραφή φοιτητή** του διαχειριστή συνεδρίας (`/admin-dashboard/register/{courseId}`) χρησιμοποιεί αυτό το τελικό σημείο με `checkEmailDuplicates: true`, ώστε να προειδοποιεί όταν η διεύθυνση χρησιμοποιείται ήδη.
