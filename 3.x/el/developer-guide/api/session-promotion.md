# Προαγωγή συνεδρίας

Μια συνεδρία μπορεί να ανήκει σε μια **προαγωγή** (μια κοόρτη μιας σταδιοδρομίας, η οποία διαχειρίζεται από τη διαδρομή **Διαχείριση > Σταδιοδρομίες και προαγωγές**). Οι ενσωματώσεις την ορίζουν με την τυπική λειτουργία `PATCH /api/sessions/{id}`, η οποία αντικαθιστά την παράμετρο `promotion_id` της υπηρεσίας ιστού `update_session` της έκδοσης 1.11.x.

Μην συγχέετε μια προαγωγή με μια κατηγορία συνεδρίας (`/api/session_categories`), η οποία αποτελεί διαφορετική ομαδοποίηση.

## Πρόσβαση

Μόνο οι διαχειριστές της πλατφόρμας (`ROLE_ADMIN`) μπορούν να διαβάζουν προαγωγές και να αλλάζουν την προαγωγή μιας συνεδρίας. Οι υπόλοιποι χρήστες λαμβάνουν `403 Forbidden`.

## Εύρεση προαγωγής

Οι προαγωγές εκτίθενται μόνο για ανάγνωση. Εξακολουθούν να δημιουργούνται και να επεξεργάζονται από τη διαχείριση.

```http
GET /api/promotions
GET /api/promotions/{id}
```

```json
{
  "@id": "/api/promotions/3",
  "id": 3,
  "title": "Accounting 2026",
  "status": 1
}
```

Η τιμή `status` είναι `1` για ενεργή προαγωγή και `0` για ανενεργή.

## Ορισμός της προαγωγής μιας συνεδρίας

```http
PATCH /api/sessions/42
Authorization: Bearer <token>
Content-Type: application/merge-patch+json
```

```json
{ "promotion": "/api/promotions/3" }
```

Στείλτε `{ "promotion": null }` για να αποσυνδέσετε τη συνεδρία από την προαγωγή της.

Η προαγωγή πρέπει να δίνεται ως IRI. Ένα αριθμητικό id, ή ένα IRI που δεν αντιστοιχεί σε καμία προαγωγή, απορρίπτεται με `400 Bad Request`.

## Ανάγνωση της προαγωγής μιας συνεδρίας

Το `GET /api/sessions/{id}` επιστρέφει το IRI της προαγωγής ή παραλείπει το πεδίο όταν η συνεδρία δεν έχει προαγωγή:

```json
{
  "@id": "/api/sessions/42",
  "title": "Accounting basics - October 2026",
  "promotion": "/api/promotions/3"
}
```

Μια συνεδρία που δημιουργείται με την [Αντιγραφή συνεδρίας](session-duplication.md) διατηρεί την προαγωγή της πρότυπης συνεδρίας της.
