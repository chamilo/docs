# Γλωσσάριο

Όροι με έμφαση στον προγραμματιστή που χρησιμοποιούνται σε όλο αυτόν τον οδηγό.

| Όρος | Ορισμός |
|------|-----------|
| **API Platform** | Ένα πλαίσιο PHP για τη δημιουργία REST και GraphQL API, ενσωματωμένο με το Symfony. Το Chamilo το χρησιμοποιεί για αυτόματη δημιουργία τελικών σημείων API από οντότητες Doctrine. |
| **Bundle** | Οργανωτική μονάδα του Symfony, παρόμοια με πρόσθετο ή μονάδα. Το Chamilo διαθέτει τρία: CoreBundle, CourseBundle, LtiBundle. |
| **Composable** | Μοτίβο του Vue 3 για εξαγωγή και επαναχρησιμοποίηση αντιδραστικής λογικής. Αποθηκεύεται στο `assets/vue/composables/`. |
| **Doctrine ORM** | Ο αντικειμενοσχεσιακός χαρτογράφος PHP που χρησιμοποιεί το Chamilo. Αντιστοιχίζει κλάσεις οντοτήτων PHP σε πίνακες βάσης δεδομένων. |
| **Entity** | Κλάση PHP με επισημειώσεις Doctrine που αντιστοιχεί σε πίνακα βάσης δεδομένων. |
| **Encore** | Symfony Webpack Encore — περιτύλιγμα γύρω από το Webpack που απλοποιεί τη διαμόρφωση της κατασκευής του frontend. |
| **Flysystem** | Βιβλιοθήκη αφαίρεσης συστήματος αρχείων σε PHP. Το Chamilo τη χρησιμοποιεί για υποστήριξη αποθήκευσης local, S3, Azure και GCS. |
| **JWT** | JSON Web Token — ο μηχανισμός αυθεντικοποίησης για το REST API. |
| **Pinia** | Η συνιστώμενη βιβλιοθήκη διαχείρισης κατάστασης για το Vue 3. Χρησιμοποιείται για νέα stores στο Chamilo· τα παλαιότερα Vuex stores παραμένουν παράλληλα. |
| **PrimeVue** | Η βιβλιοθήκη στοιχείων διεπαφής Vue 3 που χρησιμοποιεί το Chamilo. Παρέχει κουμπιά, πίνακες, διαλόγους κ.λπ. |
| **ResourceNode** | Η κεντρική οντότητα στο σύστημα πόρων του Chamilo. Κάθε στοιχείο περιεχομένου μαθήματος διαθέτει ένα ResourceNode. |
| **ResourceFile** | Οντότητα που αντιπροσωπεύει αρχείο συνδεδεμένο με ResourceNode. Αποθηκεύεται μέσω Flysystem. |
| **ResourceLink** | Οντότητα που ελέγχει την ορατότητα και την πρόσβαση ανά πλαίσιο μαθήματος/συνεδρίας/ομάδας. |
| **SCORM** | Sharable Content Object Reference Model. Πρότυπο ηλεκτρονικής μάθησης για τη συσκευασία περιεχομένου. |
| **Settings Schema** | Κλάση PHP που ορίζει μια κατηγορία ρυθμίσεων πλατφόρμας (π.χ. SecuritySettingsSchema). |
| **Voter** | Στοιχείο ασφαλείας του Symfony που αποφασίζει αν ένας χρήστης μπορεί να εκτελέσει μια ενέργεια σε έναν πόρο. |
| **Webpack** | Ο συσκευαστής μονάδων JavaScript που μεταγλωττίζει στοιχεία Vue, SCSS και TypeScript σε πακέτα έτοιμα για τον περιηγητή. |
