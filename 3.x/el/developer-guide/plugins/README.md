# Πρόσθετα

Το σύστημα προσθέτων του Chamilo σάς επιτρέπει να επεκτείνετε την πλατφόρμα χωρίς να τροποποιείτε τον πυρήνα του κώδικα. Ένα σύνολο προσθέτων συνοδεύει τη διανομή στον κατάλογο `public/plugin/`.

* **[Αρχιτεκτονική προσθέτων](plugin-architecture.md)** — Πώς είναι δομημένα τα πρόσθετα
* **[Δημιουργία προσθέτου](creating-a-plugin.md)** — Οδηγός βήμα προς βήμα για την κατασκευή ενός προσθέτου
* **[Πρόσθετα εργαλείων μαθήματος](course-tool-plugins.md)** — Πρόσθετα που προσθέτουν εργαλεία στα μαθήματα
