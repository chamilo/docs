# Frontend

Το frontend του Chamilo 3.0 είναι μια εφαρμογή μίας σελίδας (SPA) σε Vue 3 που επικοινωνεί με το backend μέσω του REST API.

* **[Συστατικά Vue](vue-components.md)** — Τα επαναχρησιμοποιήσιμα συστατικά στο `assets/vue/components/`
* **[Προβολές και δρομολόγηση](views-and-routing.md)** — Προβολές σελίδων στο `assets/vue/views/` και η ρύθμιση του Vue Router
* **[Διαχείριση κατάστασης](state-management.md)** — Αποθήκες Pinia για την κατάσταση της εφαρμογής
* **[Σύστημα κατασκευής](build-system.md)** — Webpack Encore, Tailwind και η διοχέτευση κατασκευής
