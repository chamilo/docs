# Εργαλεία συστήματος

Αυτή η σελίδα καλύπτει τα βοηθητικά προγράμματα συντήρησης και επιθεώρησης του μπλοκ System.

## Καθαρισμός προσωρινών αρχείων

Το **System > Clean temporary files** εμφανίζει πόσα προσωρινά αρχεία μεταφόρτωσης υπάρχουν και πόσο χώρο καταλαμβάνουν, και στη συνέχεια σας επιτρέπει να τα εκκαθαρίσετε — είτε όλα, είτε μόνο αρχεία παλαιότερα από μια ρυθμιζόμενη ηλικία. Μια λειτουργία dry-run σας επιτρέπει να προεπισκοπήσετε πρώτα τι θα διαγραφόταν. Η ίδια ενέργεια εκκαθαρίζει επίσης παρωχημένα αρχεία παλαιών εκδόσεων (legacy build) και αναδημιουργεί τα μεταγλωττισμένα CSS assets.

Αυτή η ενέργεια παραλείπει σκόπιμα τους καταλόγους cache του ίδιου του Symfony (`var/cache/dev`, `var/cache/prod`, `var/cache/test`, και cache pools) — καθαρίζει μόνο αδέσποτα αρχεία που κατέληξαν αλλού κάτω από το `var/cache/`. **Δεν** θα εντοπίσει μια αλλαγή που κάνατε στο `.env` ή κάτω από το `config/` (για παράδειγμα, την ενεργοποίηση της τεκμηρίωσης API — βλ. [Ενεργοποίηση της τεκμηρίωσης API](../installation/configuration.md#enable-the-api-documentation)). Για αυτό χρειάζεστε πρόσβαση στο κέλυφος ώστε να εκτελέσετε `php bin/console cache:clear`.

## Ενημέρωση συστήματος

Το **System > System update** εκτελεί τη ροή αυτοενημέρωσης του Chamilo απευθείας από τον πίνακα διαχείρισης, ως ακολουθία διακριτών, επαναλήψιμων βημάτων:

1. **Status** — Αναφέρει την εγκατεστημένη έκδοση και πού βρίσκονται οι κατάλογοι ενημέρωσης/staging/αντιγράφων ασφαλείας, μαζί με το αξιόπιστο κλειδί υπογραφής που χρησιμοποιείται
2. **Check** — Ελέγχει αν υπάρχει νεότερη έκδοση από την ρυθμισμένη πηγή ενημερώσεων
3. **Verify** — Λήψη του πακέτου ενημέρωσης και της υπογραφής του, και έλεγχος έναντι του checksum του manifest και του αξιόπιστου δημόσιου κλειδιού
4. **Preflight** — Επικυρώνει τις απαιτήσεις συστήματος και τη συμβατότητα πριν αγγιχτεί οτιδήποτε
5. **Stage** — Εξάγει το επαληθευμένο πακέτο σε απομονωμένο κατάλογο staging· τίποτα στη ζωντανή εγκατάσταση δεν αλλάζει ακόμη
6. **Apply plan** — Δημιουργεί ένα diff αρχείων προς προσθήκη, αντικατάσταση ή αφαίρεση, βάσει του σταδιοποιημένου πακέτου
7. **Apply files** — Αντιγράφει αρχεία στη θέση τους. Απαιτεί ρητή επιβεβαίωση και δημιουργεί αντίγραφο ασφαλείας κάθε αρχείου που αντικαθιστά, καθώς και αρχείο κλειδώματος που εμποδίζει την ταυτόχρονη εκτέλεση δεύτερης ενημέρωσης
8. **Migration safety / post-apply checks** — Επικυρώνει εκκρεμείς μεταναστεύσεις βάσης δεδομένων και την κατάσταση μετά την εγκατάσταση
9. **Run post-apply** — Εκτελεί εντολές κονσόλας μετά την εφαρμογή (όπως μεταναστεύσεις βάσης δεδομένων), αλλά μόνο αν η διαμόρφωση του διακομιστή επιτρέπει την εκτέλεσή τους από το UI, και μόνο αφού πληκτρολογήσετε ρητή φράση επιβεβαίωσης και επιβεβαιώσετε ότι έχει ληφθεί αντίγραφο ασφαλείας

Τα βήματα μεγάλης διάρκειας αναφέρουν πρόοδο ώστε η σελίδα να μπορεί να μείνει ανοιχτή με ασφάλεια όσο ολοκληρώνονται. Ο συνδυασμός επαλήθευσης υπογραφής, σταδιοποίησης πριν την εφαρμογή, αντιγράφων ασφαλείας πριν την αντικατάσταση, κλειδώματος ταυτοχρονισμού και πληκτρολογημένων επιβεβαιώσεων πριν από αλλαγές στη βάση δεδομένων έχει σχεδιαστεί ώστε αυτή η ροή να είναι ασφαλής χωρίς πρόσβαση στο κέλυφος — ωστόσο ένα χειροκίνητο αντίγραφο ασφαλείας πριν την έναρξη εξακολουθεί να αποτελεί καλή πρακτική· βλ. [Αντίγραφα ασφαλείας](../maintenance/backups.md).

## Πληροφορίες αρχείων

Το **System > File info** παραθέτει κάθε μεταφορτωμένο αρχείο πόρου, με δυνατότητα αναζήτησης κατά όνομα, εμφανίζοντας τη φυσική του διαδρομή, αν είναι ορφανό (μη συνδεδεμένο με κανένα μάθημα ή συνεδρία) και σε πόσα σημεία γίνεται αναφορά σε αυτό. Από εδώ μπορείτε να συνδέσετε ένα ορφανό αρχείο σε έναν πόρο, να το αποσυνδέσετε ή να το διαγράψετε — χρήσιμο για τον εντοπισμό και τον καθαρισμό αποθηκευτικού χώρου που δεν ανήκει πλέον σε κανένα μάθημα.

## Πόροι ανά τύπο

Το **System > Resources by type** σας επιτρέπει να επιλέξετε έναν τύπο πόρου και να δείτε, σε όλα τα μαθήματα και τις συνεδρίες, συγκεντρωτικό πλήθος και λίστα στοιχείων αυτού του τύπου, πότε δημιουργήθηκαν και (όπου ισχύει) ποιοι χρήστες σχετίζονται με αυτά. Χρησιμοποιήστε το για να απαντήσετε σε ερωτήσεις όπως «πόσα φόρουμ υπάρχουν σε όλη την πλατφόρμα» ή «ποια μαθήματα έχουν τα περισσότερα έγγραφα».

## Κατάλογος εικονιδίων

Το **System > List icons** είναι ένας περιηγήσιμος κατάλογος του ενσωματωμένου συνόλου εικονιδίων του Chamilo, ομαδοποιημένος κατά κατηγορία. Είναι κυρίως χρήσιμο κατά την ανάπτυξη προσθηκών ή θεμάτων όταν χρειάζεται να επιβεβαιώσετε το ακριβές όνομα ενός εικονιδίου, αλλά εκτίθεται εδώ ως γενική αναφορά.

## Εργαλεία μόνο για ανάπτυξη

Δύο ακόμη στοιχεία μπορούν να εμφανιστούν σε αυτό το μπλοκ, αλλά μόνο όταν ο διακομιστής διαθέτει κατάλογο `tests/` — κάτι που κανονικά συμβαίνει μόνο σε εγκατάσταση ανάπτυξης ή QA, ποτέ στην παραγωγή:

* Το **Data filler** δημιουργεί μεγάλους όγκους ψεύτικων χρηστών, μαθημάτων και εγγραφών διαδικτυακών χρηστών, για δοκιμές φόρτου ή QA.
* Το **E-mail tester** στέλνει ένα πραγματικό δοκιμαστικό e-mail μέσω του διαμορφωμένου mailer της πλατφόρμας, για να επιβεβαιώσει ότι οι ρυθμίσεις SMTP/αλληλογραφίας λειτουργούν πραγματικά, και εμφανίζει πρόσφατες αποτυχίες αποστολής αν υπάρχουν.

Αν δεν βλέπετε αυτούς τους δύο συνδέσμους, αυτό είναι αναμενόμενο — σημαίνει ότι η εγκατάστασή σας δεν έχει κατάλογο `tests/`, που είναι η κανονική, σωστή κατάσταση για μια πλατφόρμα παραγωγής.
