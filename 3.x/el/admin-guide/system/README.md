# Σύστημα

Το μπλοκ **Σύστημα** στον πίνακα διαχείρισης συγκεντρώνει εργαλεία συντήρησης σε επίπεδο διακομιστή, τη ροή εργασίας αυτοενημέρωσης, βοηθητικά προγράμματα επιθεώρησης αποθήκευσης/πόρων και την επωνυμία της πλατφόρμας.

![Το μπλοκ Σύστημα στον πίνακα διαχείρισης, με τις επιλογές Καθαρισμός προσωρινών αρχείων, Κατάσταση συστήματος, Ενημέρωση συστήματος, Χρώματα, Πληροφορίες αρχείων, Πόροι ανά τύπο και Λίστα εικονιδίων](../../.gitbook/assets/admin-system-block.png)

## Πρόσβαση στο μπλοκ Σύστημα

Από τον πίνακα διαχείρισης, το μπλοκ **Σύστημα** εμφανίζεται δίπλα στα υπόλοιπα μπλοκ του πίνακα. Κάντε κλικ σε οποιονδήποτε από τους συνδέσμους του για να ανοίξετε το αντίστοιχο εργαλείο.

## Τι περιλαμβάνει το μπλοκ

* **[Εργαλεία συστήματος](system-tools.md)** — Καθαρισμός προσωρινών αρχείων, εκτέλεση της ροής εργασίας αυτοενημέρωσης, επιθεώρηση αποθηκευμένων αρχείων και πόρων, και περιήγηση στο ενσωματωμένο σύνολο εικονιδίων
* **Κατάσταση συστήματος** — Καλύπτεται στην ενότητα [Κατάσταση συστήματος](../maintenance/system-status.md), στην Συντήρηση
* **[Επωνυμία](branding/README.md)** — Θέματα χρωμάτων (ο σύνδεσμος «Χρώματα» του μπλοκ ανοίγει την ίδια σελίδα Θεμάτων χρωμάτων), προσαρμογή πύλης και πρότυπα

Δύο επιπλέον στοιχεία — **Data filler** και **E-mail tester** — εμφανίζονται μόνο όταν στον διακομιστή υπάρχει κατάλογος `tests/`, που αποτελεί διάταξη ανάπτυξης/QA και όχι παραγωγής. Δεν εμφανίζονται σε μια τυπική εγκατάσταση παραγωγής· δείτε [Εργαλεία συστήματος](system-tools.md#development-only-tools) για το τι κάνουν όταν είναι παρόντα.
