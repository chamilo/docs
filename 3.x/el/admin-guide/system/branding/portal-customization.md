# Προσαρμογή Πύλης

Προσαρμόστε την εμφάνιση της πλατφόρμας Chamilo και τις πληροφορίες που εμφανίζονται στους χρήστες.

## Ταυτότητα Πλατφόρμας

![Η σελίδα προσαρμογής πύλης που εμφανίζει ρυθμίσεις ταυτότητας πλατφόρμας για όνομα, λογότυπο και ίδρυμα](/.gitbook/assets/admin-portal-customization.png)

Διαμορφώστε τη βασική ταυτότητα της πύλης σας:

* **Όνομα πλατφόρμας** — Το όνομα που εμφανίζεται στον τίτλο του προγράμματος περιήγησης και σε όλη τη διεπαφή
* **Όνομα ιδρύματος** — Το όνομα του οργανισμού σας
* **URL ιδρύματος** — Ένας σύνδεσμος προς τον ιστότοπο του οργανισμού σας
* **Λογότυπο πλατφόρμας** — Ανεβάστε το λογότυπο του οργανισμού σας (εμφανίζεται στην επάνω γραμμή)

## Συμβουλές

* **Διατηρήστε την αρχική σελίδα καθαρή** — Υπερβολικό περιεχόμενο στην αρχική σελίδα μπορεί να είναι κατακλυσμικό. Εστιάστε σε ουσιώδεις ανακοινώσεις και πρόσβαση σε μαθήματα.
* **Ενημερώνετε τακτικά** — Διατηρείτε τις ανακοινώσεις συστήματος επίκαιρες και αφαιρείτε τις παρωχημένες
* **Ανεβάστε λογότυπο υψηλής ποιότητας** — Το λογότυπο είναι ένα από τα πιο ορατά στοιχεία επωνυμίας. Χρησιμοποιήστε μια ευκρινή εικόνα κατάλληλου μεγέθους.
