# Χρωματικά Θέματα

Το Chamilo 2.0 εισάγει ένα σύστημα χρωματικών θεμάτων που σας επιτρέπει να προσαρμόσετε την οπτική εμφάνιση της πλατφόρμας.

## Πώς Λειτουργούν τα Θέματα

Τα χρωματικά θέματα ορίζουν την παλέτα που χρησιμοποιείται σε όλη τη διεπαφή του Chamilo — κύρια χρώματα, χρώματα έμφασης, φόντα και χρώματα κειμένου. Ένα θέμα συνδέεται με ένα URL πρόσβασης: σε μια πύλη με ένα μόνο URL γίνεται ουσιαστικά το καθολικό θέμα, ενώ σε μια εγκατάσταση πολλαπλών URL κάθε URL μπορεί να έχει το δικό του.

## Εφαρμογή Θέματος

![Η σελίδα χρωματικών θεμάτων που εμφανίζει τα διαθέσιμα θέματα με δείγματα προεπισκόπησης και ένα κουμπί Εφαρμογή](../../../.gitbook/assets/admin-color-themes.png)

1. Από τον πίνακα διαχείρισης, μεταβείτε στα **Χρωματικά θέματα**
2. Περιηγηθείτε στα διαθέσιμα θέματα
3. Επιλέξτε ένα θέμα και κάντε κλικ στο **Εφαρμογή**
4. Το θέμα εφαρμόζεται αμέσως στην πλατφόρμα

## Θέματα ανά URL

Σε μια εγκατάσταση πολλαπλών URL, κάθε URL πρόσβασης μπορεί να έχει το δικό του χρωματικό θέμα. Αυτό επιτρέπει σε διαφορετικές πύλες να έχουν διακριτές οπτικές ταυτότητες, ενώ μοιράζονται την ίδια εγκατάσταση Chamilo.

## Συμβουλές

* **Ταιριάξτε την επωνυμία σας** — Επιλέξτε ή προσαρμόστε ένα θέμα που ταιριάζει με τα χρώματα της επωνυμίας του οργανισμού σας
* **Ελέγξτε την αναγνωσιμότητα** — Μετά την εφαρμογή ενός θέματος, ελέγξτε ότι το κείμενο είναι ευανάγνωστο σε σχέση με τα χρώματα φόντου, ιδίως σε καταστάσεις υψηλής αντίθεσης
* **Λάβετε υπόψη την προσβασιμότητα** — Διασφαλίστε επαρκή χρωματική αντίθεση για χρήστες με προβλήματα όρασης
