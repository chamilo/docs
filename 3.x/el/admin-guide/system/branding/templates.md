# Πρότυπα

Το Chamilo χρησιμοποιεί πρότυπα για πιστοποιητικά, έγγραφα και μηνύματα ηλεκτρονικού ταχυδρομείου. Μπορείτε να προσαρμόσετε αυτά τα πρότυπα ώστε να ανταποκρίνονται στην εταιρική ταυτότητα και τις απαιτήσεις του οργανισμού σας.

## Πρότυπα πιστοποιητικών

Τα πρότυπα πιστοποιητικών καθορίζουν τη διάταξη και το περιεχόμενο των πιστοποιητικών που απονέμονται σε εκπαιδευόμενους οι οποίοι πληρούν τα όρια του βαθμολογίου.

### Προσαρμογή προτύπου πιστοποιητικού

Τα πρότυπα πιστοποιητικών χρησιμοποιούν HTML και CSS με μεταβλητές κράτησης θέσης:

| Μεταβλητή | Αντικαθίσταται με |
|----------|-------------|
| Student name | Το πλήρες όνομα του εκπαιδευόμενου |
| Course name | Το όνομα του μαθήματος |
| Date | Η ημερομηνία απόκτησης του πιστοποιητικού |
| Score | Η τελική βαθμολογία του εκπαιδευόμενου |
| Barcode | Κράτηση θέσης γραμμωτού κώδικα (`((certificate_barcode))`) που χρησιμοποιείται για επαλήθευση |

### Ανέβασμα προτύπου

1. Μεταβείτε στη διαχείριση προτύπων πιστοποιητικών
2. Ανεβάστε ή επεξεργαστείτε το πρότυπο HTML
3. Χρησιμοποιήστε τις μεταβλητές κράτησης θέσης όπου πρέπει να εμφανίζεται δυναμικό περιεχόμενο
4. Αποθηκεύστε

## Πρότυπα εγγράφων

Οι εκπαιδευτές μπορούν να χρησιμοποιούν πρότυπα εγγράφων κατά τη δημιουργία περιεχομένου στο εργαλείο Documents. Τα πρότυπα παρέχουν μια αρχική διάταξη για συνηθισμένους τύπους εγγράφων.

### Διαχείριση προτύπων εγγράφων

1. Μεταβείτε στη διαχείριση προτύπων στον πίνακα διαχείρισης
2. Προσθέστε νέα πρότυπα ανεβάζοντας αρχεία HTML
3. Τα πρότυπα γίνονται διαθέσιμα στους εκπαιδευτές όταν δημιουργούν νέα έγγραφα

## Συμβουλές

* **Συμπεριλάβετε το λογότυπό σας** — Προσθέστε το λογότυπο του οργανισμού σας στα πρότυπα πιστοποιητικών για επαγγελματική εμφάνιση
* **Δοκιμάστε με πραγματικά δεδομένα** — Προεπισκοπήστε τα πιστοποιητικά με πραγματικά δεδομένα εκπαιδευόμενων πριν από την ανάπτυξη του προτύπου
* **Διατηρήστε τα πρότυπα απλά** — Οι απλές σχεδιάσεις εκτυπώνονται καλύτερα και έχουν επαγγελματική εμφάνιση
