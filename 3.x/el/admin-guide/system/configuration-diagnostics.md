# Ασφαλής εξαγωγή διαγνωστικών ρυθμίσεων

Το Chamilo 3.1 παρέχει μια αναφορά JSON προς λήψη για τη διάγνωση προβλημάτων διαμόρφωσης, χωρίς να εξάγει σκόπιμα εμπιστευτικές τιμές ρυθμίσεων. Η αναφορά περιορίζεται στο **τρέχον URL πρόσβασης** και απαιτεί ρόλο διαχειριστή.

## Λήψη της αναφοράς

1. Ανοίξτε **Διαχείριση > Ρυθμίσεις** στην πύλη που θέλετε να επιθεωρήσετε.
2. Επιλέξτε **Λήψη διαμόρφωσης για αποσφαλμάτωση**.
3. Αποθηκεύστε με ασφάλεια το παραγόμενο αρχείο `chamilo-configuration-dump.json`.
4. **Ελέγξτε ολόκληρο το αρχείο πριν το στείλετε σε οποιονδήποτε**, ακόμη και αν φαίνεται ότι έχει εξυγιανθεί.

Η αναφορά περιλαμβάνει χρονική σήμανση εξαγωγής, εύρος URL πρόσβασης, εξυγιασμένες ρυθμίσεις πλατφόρμας, καθώς και την κατάσταση εγκατάστασης/ενεργοποίησης των προσθέτων μαζί με την εξυγιασμένη διαμόρφωσή τους. Πρόκειται για εξαγωγή μόνο για ανάγνωση· η λήψη της δεν μεταβάλλει τις ρυθμίσεις του συστήματος.

## Εμπιστευτικότητα και όρια URL πρόσβασης

Οι ευαίσθητες τιμές αποκρύπτονται από το επίπεδο εξυγίανσης. Οι ρυθμίσεις προσθέτων αντιμετωπίζονται ως εμπιστευτικές από προεπιλογή, εκτός εάν έχουν ταξινομηθεί ρητά για ασφαλή εξαγωγή. Παρόλα αυτά, τα ονόματα ρυθμίσεων, τα ονόματα προσθέτων και άλλα διαγνωστικά μεταδεδομένα ενδέχεται να αποκαλύψουν λεπτομέρειες υλοποίησης, επομένως διανέμετε το αρχείο μόνο σε έμπιστο προσωπικό υποστήριξης.

Σε εγκαταστάσεις με πολλαπλά URL, το backend ελέγχει ότι το επιλυμένο URL πρόσβασης αντιστοιχεί στον κεντρικό υπολογιστή του αιτήματος, αντί να εξάγει σιωπηρά τη διαμόρφωση άλλης πύλης. Επιβεβαιώστε τη διεύθυνση της πύλης πριν από τη λήψη.

## Αντιμετώπιση προβλημάτων

Εάν η εξαγωγή δεν είναι διαθέσιμη, βεβαιωθείτε ότι ο λογαριασμός διαθέτει δικαιώματα διαχειριστή και ότι η ζητούμενη πύλη επιλύεται στο δικό της URL πρόσβασης. Ελέγξτε τα αρχεία καταγραφής του διακομιστή ιστού και της εφαρμογής χωρίς να αντιγράφετε διαπιστευτήρια ή προσωπικά δεδομένα σε αιτήματα υποστήριξης.
