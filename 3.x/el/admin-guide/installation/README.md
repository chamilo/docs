# Εγκατάσταση

Αυτή η ενότητα καλύπτει όλα όσα χρειάζεστε για να εγκαταστήσετε και να διαμορφώσετε το Chamilo 3.0 στον διακομιστή σας.

Το Chamilo 3.0 είναι μια εφαρμογή PHP βασισμένη στο πλαίσιο Symfony. Μπορεί να εκτελεστεί στους περισσότερους διακομιστές που βασίζονται σε Linux, έχει εγκατασταθεί και εκτελείται σε Windows Server με IIS και υποστηρίζει βάσεις δεδομένων MySQL και MariaDB.

## Βήματα εγκατάστασης

1. **[Απαιτήσεις διακομιστή](server-requirements.md)** — Επαληθεύστε ότι ο διακομιστής σας πληροί τις ελάχιστες απαιτήσεις
2. **[Οδηγός εγκατάστασης](installation-wizard.md)** — Εκτελέστε τον διαδικτυακό οδηγό εγκατάστασης
3. **[Διαμόρφωση](configuration.md)** — Διαμορφώστε τις μεταβλητές περιβάλλοντος και τις ρυθμίσεις Symfony
4. **[Αποθήκευση στο νέφος](cloud-storage.md)** — Ρυθμίστε υποσυστήματα αποθήκευσης στο νέφος (προαιρετικό)
5. **[Διαμόρφωση ηλεκτρονικού ταχυδρομείου](email-configuration.md)** — Διαμορφώστε την παράδοση ηλεκτρονικού ταχυδρομείου
6. **[Αναβάθμιση](upgrading.md)** — Αναβαθμίστε από προηγούμενη έκδοση

## Σύντομη επισκόπηση

Η βασική διαδικασία εγκατάστασης είναι:

1. Λήψη ή κλωνοποίηση του πηγαίου κώδικα του Chamilo
2. Εγκατάσταση των εξαρτήσεων PHP με Composer εάν προετοιμάζετε από τον πηγαίο κώδικα
3. Εγκατάσταση των εξαρτήσεων JavaScript με npm/yarn και δημιουργία των πόρων του frontend
4. Δημιουργία ενός κενού αρχείου `.env` για την αποθήκευση των διαπιστευτηρίων βάσης δεδομένων και άλλων ρυθμίσεων αργότερα
5. Αλλαγή δικαιωμάτων (εγγράψιμα από τον διακομιστή ιστού) στα *var/*, *config/* και *.env*
6. Εκτέλεση του διαδικτυακού οδηγού εγκατάστασης
7. Σύνδεση με τον πρώτο λογαριασμό διαχειριστή
8. Επαναφορά των δικαιωμάτων στα *config/* και *.env*

Λεπτομερείς οδηγίες για κάθε βήμα βρίσκονται στις σελίδες που συνδέονται παραπάνω.
