# Απαιτήσεις Διακομιστή

Πριν εγκαταστήσετε το Chamilo 3.0, επαληθεύστε ότι ο διακομιστής σας πληροί τις ακόλουθες απαιτήσεις.

## Απαιτήσεις Λογισμικού

### PHP

| Απαίτηση | Ελάχιστο | Συνιστώμενο |
|-------------|---------|-------------|
| **Έκδοση PHP** | 8.3 | 8.5 |

### Απαιτούμενες Επεκτάσεις PHP

| Επέκταση | Σκοπός |
|-----------|---------|
| **bcmath** | Μαθηματικά αυθαίρετης ακρίβειας |
| **ctype** | Έλεγχος τύπου χαρακτήρων |
| **curl** | Αιτήματα HTTP (ενσωματώσεις API, εξωτερικές υπηρεσίες) |
| **dom**, **libxml**, **simplexml**, **xml**, **xmlreader** | Ανάλυση XML και χειρισμός DOM (SCORM, RSS, SOAP, LTI) |
| **exif** | Ανάγνωση μεταδεδομένων εικόνας (π.χ. αυτόματος προσανατολισμός μεταφορτωμένων φωτογραφιών) |
| **fileinfo** | Ανίχνευση τύπου MIME για μεταφορτωμένα αρχεία |
| **gd** | Επεξεργασία εικόνας (μικρογραφίες, CAPTCHA) |
| **iconv** | Μετατροπή συνόλου χαρακτήρων |
| **intl** | Διεθνοποίηση (μορφοποίηση ημερομηνίας, αριθμών και συμβολοσειρών) |
| **json** | Κωδικοποίηση/αποκωδικοποίηση JSON |
| **ldap** | Συνδέτης LDAP. Αν και πιθανότατα δεν θα χρησιμοποιήσετε LDAP, το Chamilo το απαιτεί |
| **mbstring** | Χειρισμός συμβολοσειρών πολλαπλών byte (υποστήριξη UTF-8) |
| **openssl** | Κρυπτογραφικές λειτουργίες (HTTPS, κατακερματισμός κωδικών πρόσβασης, διακριτικά JWT) |
| **pdo**, plus **pdo_mysql** or **pdo_pgsql** | Συνδεσιμότητα βάσης δεδομένων (εγκαταστήστε τον οδηγό που αντιστοιχεί στη βάση δεδομένων σας) |
| **soap** | Χειρισμός υπηρεσιών ιστού SOAP |
| **zip** | Χειρισμός αρχείων ZIP (πακέτα SCORM, μαζικές εισαγωγές/εξαγωγές) |
| **zlib** | Συμπίεση που χρησιμοποιείται εσωτερικά από διάφορες εξαρτήσεις |
| **apcu** | Προσωρινή αποθήκευση σε επίπεδο χρήστη (συνιστάται, ελέγχεται αλλά δεν επιβάλλεται από τον εγκαταστάτη) |
| **opcache** | Προσωρινή αποθήκευση opcode (συνιστάται έντονα για απόδοση, ελέγχεται αλλά δεν επιβάλλεται από τον εγκαταστάτη) |
| **xapian** | Αναζήτηση πλήρους κειμένου (προαιρετικό, μόνο εάν χρησιμοποιείτε αναζήτηση) |

### Βάση Δεδομένων

| Βάση δεδομένων | Ελάχιστη έκδοση | Συνιστώμενη |
|----------|-----------------|-------------|
| **MariaDB** | 10.0 | 10.4 ή νεότερη |
| **MySQL** | 5.7 | 8.0 ή νεότερη |

Οι εκδόσεις MariaDB παλαιότερες από 10.2.2 (και οι εκδόσεις MySQL παλαιότερες από 5.7) χρειάζονται ενεργοποιημένη χειροκίνητα την υποστήριξη μεγάλων ευρετηρίων/προθεμάτων στη διαμόρφωση του διακομιστή πριν από την εγκατάσταση του Chamilo.

### Διακομιστής Ιστού

| Διακομιστής | Σημειώσεις |
|--------|-------|
| **Apache** | Απαιτεί ενεργοποιημένα τα `mod_rewrite` (και `ssl`, `headers`, `expires`). Το Chamilo περιλαμβάνει δείγμα vhost στο `public/main/install/apache.dist.conf`. |
| **Nginx** | Απαιτεί χειροκίνητη διαμόρφωση για επανεγγραφή URL — το Chamilo δεν περιλαμβάνει δείγμα διαμόρφωσης Nginx. Δείτε την τεκμηρίωση Nginx του Symfony για μια διαμόρφωση αναφοράς. |

### Εργαλεία Δόμησης

| Εργαλείο | Σκοπός |
|------|---------|
| **Composer** (^2.8) | Διαχείριση εξαρτήσεων PHP. Απαιτείται για την εγκατάσταση των βιβλιοθηκών PHP του Chamilo. |
| **Node.js** (20+ LTS) | Περιβάλλον εκτέλεσης JavaScript. Απαιτείται για τη δόμηση των πόρων του frontend. |
| **Yarn** (^4, via Corepack) | Διαχειριστής πακέτων JavaScript που χρησιμοποιείται για τη δόμηση των πόρων του frontend (`yarn install`, `yarn encore production`). |

## Απαιτήσεις Υλικού

| Πόρος | Ελάχιστο | Συνιστώμενο |
|----------|---------|-------------|
| **RAM** | 4 GB | 8 GB ή περισσότερο (η δόμηση των πόρων του frontend από τον πηγαίο κώδικα χρειάζεται τουλάχιστον 4 GB από μόνη της) |
| **CPU** | 2 vCPUs | 2+ πυρήνες |
| **Χώρος δίσκου** | 4 GB (μόνο εφαρμογή) | 20+ GB (συμπεριλαμβανομένου του μεταφορτωμένου περιεχομένου)· η δόμηση από τον πηγαίο κώδικα χρειάζεται ~10 GB ελεύθερα κατά τη διάρκεια της δόμησης |
| **Τύπος δίσκου** | HDD | SSD (βελτιώνει σημαντικά την απόδοση της βάσης δεδομένων και της προσωρινής αποθήκευσης) |

Αυτά είναι βασικά μεγέθη από τον οδηγό εγκατάστασης του ίδιου του Chamilo. Οι πραγματικές απαιτήσεις εξαρτώνται από τον αριθμό των ταυτόχρονων χρηστών και τον όγκο του φιλοξενούμενου περιεχομένου.

## Λειτουργικό Σύστημα

| ΛΣ | Σημειώσεις |
|----|-------|
| **Linux** | Συνιστάται. Ubuntu 24.04 LTS+, Debian 12+, AlmaLinux 9+, ή ισοδύναμο. |
| **Windows** | Δυνατό, αλλά δεν έχει δοκιμαστεί διεξοδικά. Χρησιμοποιήστε WSL2 για ανάπτυξη. |
| **macOS** | Μόνο για ανάπτυξη / μη δοκιμασμένο. |

## Απαιτήσεις Δικτύου

* Ένα όνομα τομέα που δείχνει στον διακομιστή σας.
* Πιστοποιητικό SSL/TLS για HTTPS (το Let's Encrypt παρέχει δωρεάν πιστοποιητικά).
* Εξερχόμενη πρόσβαση SMTP εάν αποστέλλετε μηνύματα ηλεκτρονικού ταχυδρομείου απευθείας (ή χρησιμοποιήστε υπηρεσία ηλεκτρονικού ταχυδρομείου τρίτου μέρους).
* Θύρα 443 (HTTPS) και προαιρετικά θύρα 80 (HTTP, για ανακατεύθυνση σε HTTPS).

## Έλεγχος Απαιτήσεων

Αφού τοποθετήσετε τον πηγαίο κώδικα του Chamilo στον διακομιστή σας, μπορείτε να ελέγξετε απευθείας τη διαμόρφωση PHP:

```bash
php -m          # List installed extensions
php -i          # Full PHP info
```

## Συμβουλές

* **Χρησιμοποιήστε PHP-FPM** με Apache ή Nginx για καλύτερη απόδοση από το mod_php.
* **Διαχωρίστε τη βάση δεδομένων σας** σε αποκλειστικό διακομιστή για πλατφόρμες που αναμένουν περισσότερους από 500 ταυτόχρονους χρήστες.
* **Χρησιμοποιήστε αποθήκευση SSD** -- Οι εφαρμογές με έντονη χρήση βάσης δεδομένων όπως το Chamilo επωφελούνται σημαντικά από γρήγορο I/O δίσκου.
