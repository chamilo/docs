# Οδηγός εγκατάστασης

Το Chamilo 3.0 περιλαμβάνει έναν διαδικτυακό οδηγό εγκατάστασης που σας καθοδηγεί στην αρχική ρύθμιση. Ο οδηγός εκτελείται αυτόματα όταν αποκτάτε πρόσβαση στην πλατφόρμα για πρώτη φορά.

## Πριν ξεκινήσετε

Βεβαιωθείτε ότι πληρούνται οι ακόλουθες προϋποθέσεις:

1. Ο διακομιστής σας πληροί όλες τις [απαιτήσεις διακομιστή](server-requirements.md).
2. Έχετε κατεβάσει μια συσκευασμένη έκδοση (zip ή tar.gz) του Chamilo.
3. Ο διακομιστής ιστού σας είναι ρυθμισμένος ώστε να εξυπηρετεί τον κατάλογο `public/` ως ρίζα εγγράφων (document root).
4. Το αρχείο `.env` υπάρχει και είναι κενό (ο οδηγός θα καθοδηγήσει τη ρύθμιση της βάσης δεδομένων).

## Βήμα 1: Γλώσσα εγκατάστασης

![Οδηγός εγκατάστασης Βήμα 1 — επιλογή γλώσσας](../../.gitbook/assets/install-step1-language.png)

Το πρώτο βήμα σάς επιτρέπει να επιλέξετε τη γλώσσα για τη διαδικασία εγκατάστασης. Επιλέξτε την προτιμώμενη γλώσσα από το αναπτυσσόμενο μενού.

Εάν το Chamilo εντοπίσει υπάρχουσα εγκατάσταση (για αναβάθμιση), θα εμφανίσει την κατάσταση μετεγκατάστασης και θα προσφέρει διαδρομή αναβάθμισης αντί για νέα εγκατάσταση.

## Βήμα 2: Έλεγχος απαιτήσεων

![Οδηγός εγκατάστασης Βήμα 2 — έλεγχος απαιτήσεων που εμφανίζει έκδοση PHP, επεκτάσεις και δικαιώματα καταλόγων](../../.gitbook/assets/install-step2-requirements.png)

Ο οδηγός ελέγχει το περιβάλλον του διακομιστή σας:

* Η **έκδοση PHP** είναι 8.3, 8.4 ή 8.5
* Οι **απαιτούμενες επεκτάσεις PHP** είναι εγκατεστημένες (intl, gd, curl, zip, mbstring, xml κ.λπ.)
* **Προτεινόμενες ρυθμίσεις PHP** — το `date.timezone` είναι ρυθμισμένο, επαρκή όρια μεταφόρτωσης/μνήμης
* **Δικαιώματα καταλόγων και αρχείων** — οι `var/`, `config/` και `public/upload/` είναι εγγράψιμοι από τον διακομιστή ιστού

Εάν δεν πληρούνται ορισμένες απαιτήσεις, ο οδηγός εμφανίζει προειδοποιήσεις ή σφάλματα. Επιλύστε τα πριν συνεχίσετε.

## Βήμα 3: Άδεια χρήσης

![Οδηγός εγκατάστασης Βήμα 3 — αποδοχή άδειας χρήσης](../../.gitbook/assets/install-step3-license.png)

Αυτό το βήμα εμφανίζει την άδεια GNU/GPLv3. Πρέπει να επιλέξετε το πλαίσιο **"I accept"** για να συνεχίσετε.

Προαιρετικά, μπορείτε να αναπτύξετε την ενότητα **Contact information** για να δώσετε στοιχεία σχετικά με τον οργανισμό σας (όνομα, email, εταιρεία, χώρα). Αυτό είναι εθελοντικό και βοηθά την κοινότητα του Chamilo να κατανοήσει ποιος χρησιμοποιεί την πλατφόρμα, αλλά θα μας επιτρέψει επίσης να επικοινωνήσουμε μαζί σας *πολύ σπάνια* για εκδηλώσεις που πραγματοποιούνται κοντά σας.

## Βήμα 4: Ρυθμίσεις βάσης δεδομένων

![Οδηγός εγκατάστασης Βήμα 4 — διαμόρφωση σύνδεσης βάσης δεδομένων](../../.gitbook/assets/install-step4-database.png)

Εισαγάγετε τα στοιχεία σύνδεσης της βάσης δεδομένων:

| Πεδίο | Περιγραφή |
|-------|-------------|
| **Database host** | Το όνομα κεντρικού υπολογιστή ή η IP του διακομιστή βάσης δεδομένων (π.χ. `localhost` ή `127.0.0.1`) |
| **Database port** | Προεπιλογή: 3306 για MySQL/MariaDB |
| **Database name** | Το όνομα της βάσης δεδομένων που θα χρησιμοποιηθεί (μόνο αλφαριθμητικοί χαρακτήρες και κάτω παύλες) |
| **Database user** | Χρήστης βάσης δεδομένων με πλήρη δικαιώματα στην καθορισμένη βάση |
| **Database password** | Ο κωδικός πρόσβασης του χρήστη βάσης δεδομένων |

Κάντε κλικ στο **Check database connection** για δοκιμή. Ο οδηγός δεν θα σας επιτρέψει να συνεχίσετε έως ότου η σύνδεση είναι επιτυχής. Εάν η βάση δεδομένων υπάρχει ήδη, εμφανίζεται προειδοποίηση.

## Βήμα 5: Ρυθμίσεις διαμόρφωσης

![Οδηγός εγκατάστασης Βήμα 5 — λογαριασμός διαχειριστή, ρυθμίσεις πύλης και διαμόρφωση email](../../.gitbook/assets/install-step5-config.png)

Αυτό το βήμα συνδυάζει τη δημιουργία λογαριασμού διαχειριστή, τις ρυθμίσεις πύλης και τη διαμόρφωση email.

### Λογαριασμός διαχειριστή

| Πεδίο | Περιγραφή |
|-------|-------------|
| **Login** | Το όνομα χρήστη του διαχειριστή |
| **Password** | Επιλέξτε ισχυρό κωδικό πρόσβασης — αυτός ο λογαριασμός έχει πλήρη πρόσβαση στην πλατφόρμα |
| **First name** | Το όνομα του διαχειριστή |
| **Last name** | Το επώνυμο του διαχειριστή |
| **Email** | Χρησιμοποιείται για ειδοποιήσεις συστήματος και επαναφορά κωδικού πρόσβασης |
| **Phone** | Προαιρετικός αριθμός επικοινωνίας |

Αυτά τα στοιχεία διαχειριστή θα χρησιμοποιηθούν επίσης από το Chamilo για τη συμπλήρωση των στοιχείων επικοινωνίας υποστήριξης, επομένως φροντίστε να τα επαναδιαμορφώσετε στις ρυθμίσεις μετά την ολοκλήρωση της εγκατάστασης.

### Ρυθμίσεις πύλης

| Πεδίο | Περιγραφή |
|-------|-------------|
| **Language** | Η προεπιλεγμένη γλώσσα διεπαφής |
| **Portal name** | Το όνομα της πλατφόρμας σας (π.χ. "My Organization LMS") |
| **Company short name** | Η συντομογραφία του οργανισμού σας |
| **Company URL** | Ο ιστότοπος του οργανισμού σας |
| **Encryption method** | Αλγόριθμος κατακερματισμού κωδικών — συνιστάται το **bcrypt** |
| **Allow self-registration** | Yes / No / After approval |
| **Allow self-registration as trainer** | Yes / No |

### Διαμόρφωση email

Η ενότητα ρυθμίσεων email σάς επιτρέπει να διαμορφώσετε τη μεταφορά αλληλογραφίας (SMTP, Amazon SES, Mailjet κ.λπ.) και να δοκιμάσετε την παράδοση email. Δείτε τη [Διαμόρφωση email](email-configuration.md) για λεπτομέρειες.

Όλες αυτές οι ρυθμίσεις μπορούν να αλλάξουν αργότερα από τον πίνακα διαχείρισης.

## Βήμα 6: Τελικός έλεγχος πριν την εγκατάσταση

![Οδηγός εγκατάστασης Βήμα 6 — επισκόπηση όλων των ρυθμίσεων πριν την εγκατάσταση](../../.gitbook/assets/install-step6-review.png)

Αυτό το βήμα εμφανίζει μια σύνοψη όλων όσων εισαγάγατε για έλεγχο:

* Διαπιστευτήρια διαχειριστή (ο κωδικός πρόσβασης είναι κρυμμένος από προεπιλογή — κάντε κλικ στο εικονίδιο ματιού για εμφάνιση)
* Ρυθμίσεις πύλης
* Λεπτομέρειες σύνδεσης βάσης δεδομένων

Ελέγξτε προσεκτικά και, στη συνέχεια, κάντε κλικ στο **Install Chamilo** για να εκτελεστεί η εγκατάσταση. Ο οδηγός δημιουργεί όλους τους πίνακες της βάσης δεδομένων, συμπληρώνει τα αρχικά δεδομένα και διαμορφώνει την πλατφόρμα.

## Βήμα 7: Η εγκατάσταση ολοκληρώθηκε

![Οδηγός εγκατάστασης Βήμα 7 — ολοκλήρωση με συμβουλές ασφαλείας και σύνδεσμο προς την πύλη](../../.gitbook/assets/install-step7-complete.png)

Μετά την επιτυχή ολοκλήρωση της εγκατάστασης, ο οδηγός εμφανίζει:

* **Συμβουλές για τα πρώτα βήματα** — Προτείνει τη δημιουργία του πρώτου σας μαθήματος για εξερεύνηση της πλατφόρμας (ως διαχειριστής, πρέπει να το κάνετε αυτό από τον πίνακα διαχείρισης)
* **Συστάσεις ασφαλείας**:
  * Κάντε τον κατάλογο `config/` μόνο για ανάγνωση (`chmod 0555`)
  * Διαγράψτε τον κατάλογο `public/main/install/`
* Έναν **σύνδεσμο προς την πύλη σας** για σύνδεση με τα διαπιστευτήρια διαχειριστή που μόλις δημιουργήσατε

## Μετά την εγκατάσταση

Μετά την ολοκλήρωση του οδηγού:

* **Αφαιρέστε ή περιορίστε την πρόσβαση στον εγκαταστάτη** -- Ο οδηγός δεν πρέπει να είναι προσβάσιμος μετά την εγκατάσταση. Το Chamilo συνήθως τον κλειδώνει αυτόματα, αλλά επαληθεύστε ότι η εκ νέου επίσκεψη στο URL εγκατάστασης ανακατευθύνει στη σελίδα σύνδεσης.
* **Διαμορφώστε την παράδοση email** -- Δείτε [Διαμόρφωση email](email-configuration.md).
* **Ρυθμίστε αντίγραφα ασφαλείας** -- Πριν προσθέσετε περιεχόμενο, διαμορφώστε αυτοματοποιημένα αντίγραφα ασφαλείας βάσης δεδομένων και αρχείων (το Chamilo δεν παρέχει λύση για αυτό, αλλά η αντιγραφή του φακέλου var/ και της βάσης δεδομένων είναι τα 2 σημαντικότερα στοιχεία).
* **Ελέγξτε τις ρυθμίσεις ασφαλείας** -- Δείτε [Ρυθμίσεις ασφαλείας](../platform-settings/security-settings.md).

## Αντιμετώπιση προβλημάτων

| Πρόβλημα | Λύση |
|---------|----------|
| Κενή σελίδα στο URL εγκατάστασης | Ελέγξτε τα αρχεία καταγραφής σφαλμάτων PHP. Αλλάξτε προσωρινά σε `APP_ENV=dev` στο .env για να δείτε τα σφάλματα στο πρόγραμμα περιήγησης. |
| Αποτυχία σύνδεσης βάσης δεδομένων | Επαληθεύστε τα διαπιστευτήρια, επιβεβαιώστε ότι η βάση δεδομένων υπάρχει, ελέγξτε ότι ο διακομιστής βάσης δεδομένων επιτρέπει συνδέσεις από τον κεντρικό υπολογιστή του διακομιστή ιστού. |
| Σφάλματα άρνησης δικαιωμάτων | Βεβαιωθείτε ότι ο `var/` είναι εγγράψιμος από τον χρήστη του διακομιστή ιστού. |
| Τα στοιχεία δεν φορτώνονται (χωρίς CSS/JS) | Εκτελέστε `yarn install && yarn build` για μεταγλώττιση των στοιχείων του frontend. |
