# Διαχείριση Χρηστών

Αυτή η σελίδα καλύπτει τις καθημερινές εργασίες δημιουργίας, επεξεργασίας και διαχείρισης λογαριασμών χρηστών.

## Λίστα χρηστών

![Η λίστα χρηστών που εμφανίζει λογαριασμούς με στήλες ονόματος, email, ρόλου και κατάστασης](/.gitbook/assets/admin-user-list.png)

Από τον πίνακα διαχείρισης, κάντε κλικ στο **Λίστα χρηστών** για να δείτε όλους τους χρήστες της πλατφόρμας. Η λίστα εμφανίζει:

* Avatar
* Όνομα
* Όνομα χρήστη
* Διεύθυνση email
* Ρόλοι
* Κατάσταση ενεργού/ανενεργού
* Ημερομηνία εγγραφής
* Ημερομηνία τελευταίας σύνδεσης

Χρησιμοποιήστε το εργαλείο **Σύνθετη αναζήτηση** για να βρείτε συγκεκριμένους χρήστες κατά όνομα, email, ρόλο ή άλλα κριτήρια.

## Δημιουργία χρήστη

![Η φόρμα δημιουργίας χρήστη με πεδία για όνομα, email, όνομα χρήστη, κωδικό πρόσβασης, ρόλο και γλώσσα](/.gitbook/assets/admin-user-create-form.png)

1. Κάντε κλικ στο **Προσθήκη χρήστη** από τον πίνακα διαχείρισης
2. Συμπληρώστε τα υποχρεωτικά πεδία:
   * **Όνομα** και **Επώνυμο**
   * **Email** — Πρέπει να είναι μοναδικό στην πλατφόρμα
   * **Username** — Το όνομα σύνδεσης (πρέπει να είναι μοναδικό)
   * **Password** — Ορίστε έναν αρχικό κωδικό πρόσβασης
   * **Roles** — Επιλέξτε τον/τους ρόλο/ους του χρήστη στην πλατφόρμα (student, teacher, admin κ.λπ.)
   * **Language** — Η προτιμώμενη γλώσσα διεπαφής του χρήστη
3. Προαιρετικά συμπληρώστε πρόσθετα πεδία:
   * Επίσημος κωδικός (π.χ. μοναδικό αναγνωριστικό στον οργανισμό)
   * Αριθμός τηλεφώνου
   * Ημερομηνία λήξης — Αυτόματη απενεργοποίηση του λογαριασμού μετά από μια ημερομηνία
   * Κατάσταση ενεργού/ανενεργού
   * Επιπλέον πεδία προφίλ (εάν έχουν ρυθμιστεί)
4. Αποθήκευση

## Εισαγωγή χρηστών

![Η διεπαφή εισαγωγής χρηστών για μεταφόρτωση αρχείων CSV ή XML με δεδομένα χρηστών](/.gitbook/assets/admin-user-import.png)

Για μαζική δημιουργία χρηστών, μπορείτε να εισαγάγετε χρήστες από αρχείο:

1. Κάντε κλικ στο **Εισαγωγή χρηστών** από τον πίνακα διαχείρισης
2. Μεταφορτώστε ένα αρχείο **CSV** ή **XML** με δεδομένα χρηστών
3. Αντιστοιχίστε τις στήλες του αρχείου στα πεδία χρήστη του Chamilo
4. Επιλέξτε πώς θα χειριστείτε τους υπάρχοντες χρήστες (ενημέρωση ή παράλειψη)
5. Εισαγωγή

Το αρχείο εισαγωγής πρέπει να περιέχει στήλες τουλάχιστον για: όνομα, επώνυμο, email, όνομα χρήστη και κωδικό πρόσβασης.

Σημείωση: Η στήλη **Status** είναι η παλαιά ονομασία για τον **Role** και δέχεται μόνο λίγες τιμές, όπως 1 για teacher, 5 για student. Περαιτέρω ρύθμιση των ρόλων μπορεί να γίνει μόνο χειροκίνητα αργότερα, με επεξεργασία του χρήστη.

## Εξαγωγή χρηστών

Κάντε κλικ στο **Εξαγωγή χρηστών** για να κατεβάσετε τη λίστα χρηστών ως αρχείο CSV ή XML. Μπορείτε να φιλτράρετε ποιους χρήστες θα εξαγάγετε κατά ρόλο, ημερομηνία εγγραφής ή άλλα κριτήρια.

## Επεξεργασία χρήστη

Κάντε κλικ στο όνομα ενός χρήστη στη λίστα χρηστών για να επεξεργαστείτε τον λογαριασμό του. Μπορείτε να τροποποιήσετε:

* Προσωπικά στοιχεία (όνομα, email, τηλέφωνο)
* Ρόλους
* Κωδικό πρόσβασης (επαναφορά)
* Κατάσταση ενεργού/ανενεργού
* Ημερομηνία λήξης
* Επιπλέον πεδία προφίλ

## Διαγραφή χρήστη

Κατά τη διαγραφή χρηστών (συνήθως εκπαιδευτών) που έχουν δημιουργήσει περιεχόμενο στην πλατφόρμα, το σύστημα ενδέχεται να σας εμποδίσει να διαγράψετε οριστικά τους χρήστες και θα εμφανίσει προειδοποιητικό μήνυμα που εξηγεί ότι ο χρήστης εξακολουθεί να είναι συνδεδεμένος με ορισμένους πόρους. Εάν επιβεβαιώσετε τη διαγραφή, το σύστημα δεν θα διαγράψει το ίδιο το περιεχόμενο αλλά θα το επισυνάψει σε έναν ουδέτερο χρήστη (τον αποκαλούμε «Fallback user») για λόγους συνέπειας δεδομένων.

Για να το αποφύγετε αυτό, ελέγξτε τα στοιχεία του χρήστη, διαγράψτε ένα προς ένα τα μαθήματά του και στη συνέχεια διαγράψτε τον χρήστη.

## Ενέργειες χρήστη

| Ενέργεια | Περιγραφή |
|--------|-------------|
| **Απενεργοποίηση** | Απενεργοποίηση του λογαριασμού ενός χρήστη χωρίς διαγραφή του. Ο χρήστης δεν μπορεί να συνδεθεί αλλά τα δεδομένα του διατηρούνται. |
| **Ενεργοποίηση** | Επανενεργοποίηση ενός προηγουμένως απενεργοποιημένου λογαριασμού. |
| **Σύνδεση ως** | Σύνδεση στην πλατφόρμα ως αυτός ο χρήστης (υποκατάσταση). Χρήσιμο για αντιμετώπιση προβλημάτων. |
| **Ανωνυμοποίηση** | Διαγραφή όλων των προσωπικών πληροφοριών του λογαριασμού, όπως ορίζεται από τον GDPR της ΕΕ. |
| **Διαγραφή** | Ήπια διαγραφή του λογαριασμού χρήστη. Χρησιμοποιήστε την καρτέλα **Διαγραμμένοι χρήστες** για οριστική διαγραφή του λογαριασμού και των σχετικών δεδομένων. |

> Το **Σύνδεση ως** είναι ένα ισχυρό χαρακτηριστικό. Χρησιμοποιήστε το υπεύθυνα και μόνο για νόμιμους σκοπούς υποστήριξης.

## Μαζικές λειτουργίες

Επιλέξτε πολλούς χρήστες στη λίστα χρηστών για να εκτελέσετε μαζικές ενέργειες:

* Ενεργοποίηση ή απενεργοποίηση πολλών χρηστών ταυτόχρονα
* Διαγραφή πολλών χρηστών
* Ανάθεση χρηστών σε μάθημα ή συνεδρία

## Συμβουλές

* **Χρησιμοποιήστε εισαγωγή CSV για μεγάλες εγγραφές** — Κατά την ένταξη πολλών χρηστών στην αρχή ενός προγράμματος κατάρτισης, προετοιμάστε ένα αρχείο CSV και εισαγάγετε μαζικά
* **Ορίστε ημερομηνίες λήξης** — Για προσωρινούς χρήστες (συμμετέχοντες σε εργαστήρια, δοκιμαστικοί χρήστες), ορίστε ημερομηνία λήξης ώστε να απενεργοποιούνται αυτόματα οι λογαριασμοί τους
* **Απενεργοποιήστε αντί να διαγράψετε** — Όταν ένας χρήστης αποχωρεί, απενεργοποιήστε πρώτα τον λογαριασμό του. Αυτό διατηρεί τα αρχεία κατάρτισής του. Διαγράψτε μόνο εάν είστε βέβαιοι ότι τα δεδομένα δεν χρειάζονται πλέον.
