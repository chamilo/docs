# Ρόλοι Χρηστών

Το Chamilo χρησιμοποιεί σύστημα δικαιωμάτων βάσει ρόλων. Σε κάθε χρήστη ανατίθεται ένας ρόλος που καθορίζει τι μπορεί να βλέπει και να κάνει στην πλατφόρμα.

## Ρόλοι σε Επίπεδο Πλατφόρμας

Αυτοί οι ρόλοι ελέγχουν την πρόσβαση σε λειτουργίες σε επίπεδο πλατφόρμας:

| Ρόλος |  Περιγραφή |
|------|------------|
| **Learner (Student)** | Ο προεπιλεγμένος ρόλος. Μπορεί να εγγράφεται σε μαθήματα, να έχει πρόσβαση σε εκπαιδευτικό περιεχόμενο, να υποβάλλει εργασίες και να συμμετέχει σε ασκήσεις. |
| **Teacher (Trainer)** | Μπορεί να δημιουργεί και να διαχειρίζεται μαθήματα, να προσθέτει περιεχόμενο, να βαθμολογεί εκπαιδευόμενους και να βλέπει αναφορές σε επίπεδο μαθήματος. |
| **Sessions Administrator** | Μπορεί να δημιουργεί και να διαχειρίζεται συνεδρίες (δηλαδή πακέτα μαθημάτων με χρονικό ορίζοντα), να εγγράφει χρήστες σε συνεδρίες και να αναθέτει tutors. Δεν έχει πρόσβαση στις γενικές ρυθμίσεις της πλατφόρμας. |
| **Human Resources Manager (HRM)** | Μπορεί να βλέπει δεδομένα παρακολούθησης και αναφορών για τους ανατεθειμένους χρήστες. Χρησιμοποιείται για προϊσταμένους που χρειάζεται να παρακολουθούν την κατάρτιση των εργαζομένων χωρίς να διαχειρίζονται περιεχόμενο ούτε την πλατφόρμα. |
| **Portal Administrator** | Πλήρης πρόσβαση σε όλες τις λειτουργίες διαχείρισης της πλατφόρμας. Μπορεί να διαχειρίζεται χρήστες, μαθήματα, συνεδρίες, πρόσθετα και όλες τις ρυθμίσεις. |
| **Global Administrator** | Ίδιος με τον Portal Administrator, αλλά με πρόσβαση σε όλα τα URL πρόσβασης σε εγκατάσταση πολλαπλών URL (δηλαδή multi-tenant) — ή, αν είναι εγγεγραμμένος σε μη ριζικό URL, περιορισμένος στον κλάδο αυτού του URL. Βλ. [Subtree Administrators](../multi-url/access-urls.md#subtree-administrators). |
| **Anonymous** | Ειδικός ρόλος για επισκέπτες που δεν έχουν συνδεθεί. Μπορεί να έχει πρόσβαση σε δημόσια μαθήματα και περιεχόμενο, εφόσον αυτό είναι ενεργοποιημένο. |

## Ρόλοι σε Επίπεδο Μαθήματος

Εντός ενός μαθήματος, οι χρήστες έχουν συγκεκριμένους ρόλους:

| Ρόλος | Περιγραφή |
|------|-------------|
| **Student** | Προεπιλεγμένος ρόλος μαθήματος. Μπορεί να έχει πρόσβαση σε περιεχόμενο, να συμμετέχει σε ασκήσεις και να υποβάλλει εργασίες. |
| **Course assistant** | Διαθέτει περιορισμένα δικαιώματα διαχείρισης εντός του μαθήματος. Μπορεί να βοηθά στη διαχείριση περιεχομένου και στη εποπτεία των φόρουμ. |
| **Teacher** | Πλήρης έλεγχος του μαθήματος: διαχείριση περιεχομένου, εργαλείων, ρυθμίσεων και εγγραφών. |

## Ρόλοι σε Επίπεδο Συνεδρίας

Εντός μιας συνεδρίας υπάρχουν πρόσθετοι ρόλοι:

| Ρόλος | Περιγραφή |
|------|-------------|
| **Session tutor** | Εποπτεύει όλα τα μαθήματα εντός μιας συνεδρίας. Μπορεί να βλέπει την παρακολούθηση σε όλα τα μαθήματα της συνεδρίας. |
| **Course tutor** | Διδάσκει ένα συγκεκριμένο μάθημα εντός μιας συνεδρίας. Μπορεί να διαχειρίζεται περιεχόμενο και να παρακολουθεί τους εκπαιδευόμενους για το συγκεκριμένο μάθημα σε εκείνη τη συνεδρία. |

Σημείωση: Αυτός ο ρόλος ονομαζόταν «coach» στις εκδόσεις του Chamilo πριν από την 3.0. Από το Chamilo 3.0 και μετά, το «coach» έχει αντικατασταθεί από το «tutor» παντού στη διεπαφή και στην τεκμηρίωση της πλατφόρμας — tutor είναι το πρόσωπο που βοηθά τους εκπαιδευόμενους σε ένα μάθημα, όχι προσωπικός προπονητής. Τα υποκείμενα ονόματα ρυθμίσεων στο `Configuration settings` εξακολουθούν να περιέχουν «coach» για λόγους συμβατότητας προς τα πίσω (για παράδειγμα `add_users_by_coach`), αλλά οι ετικέτες τους πλέον αναγράφουν «tutor».

## Ανάθεση Ρόλων

Κατά τη δημιουργία ή την επεξεργασία λογαριασμού χρήστη στον πίνακα διαχείρισης, επιλέγετε τον ρόλο σε επίπεδο πλατφόρμας. Οι ρόλοι μαθήματος και συνεδρίας ανατίθενται κατά την εγγραφή χρηστών σε μαθήματα ή συνεδρίες.

## Ιεραρχία Ρόλων

Οι ρόλοι με υψηλότερα προνόμια κληρονομούν τις δυνατότητες των ρόλων με χαμηλότερα προνόμια:

* Ένας διαχειριστής μπορεί να κάνει ό,τι μπορεί να κάνει ένας εκπαιδευτής
* Ένας εκπαιδευτής μπορεί να κάνει ό,τι μπορεί να κάνει ένας εκπαιδευόμενος
* Οι ρόλοι σε επίπεδο συνεδρίας (tutor) παρέχουν πρόσθετες δυνατότητες μόνο εντός της ανατεθειμένης συνεδρίας

## Συμβουλές

* **Εφαρμόστε την αρχή του ελάχιστου προνομίου** — Αναθέστε στους χρήστες τον ελάχιστο ρόλο που χρειάζονται για να εκτελέσουν τα καθήκοντά τους
* **Χρησιμοποιήστε Sessions Administrators για αποκεντρωμένη διαχείριση** — Αν έχετε προσωπικό που πρέπει να διαχειρίζεται εκπαιδευτικές συνεδρίες αλλά όχι ολόκληρη την πλατφόρμα, δώστε του τον ρόλο Sessions Administrator αντί για πλήρη πρόσβαση διαχειριστή
* **Χρησιμοποιήστε HRM για προϊσταμένους** — Οι Human Resources Managers μπορούν να παρακολουθούν την πρόοδο της κατάρτισης χωρίς να έχουν πρόσβαση για τροποποίηση μαθημάτων ή ρυθμίσεων της πλατφόρμας
* **Δημιουργία ρόλων** — Το Chamilo 3.x διαθέτει την εσωτερική δομή έτοιμη για τη δημιουργία νέων ρόλων, αλλά η λειτουργία χρειάζεται περισσότερες δοκιμές για ευρεία διάθεση. Μπορεί να ενεργοποιηθεί μέσω των [Official providers of Chamilo](https://chamilo.org/providers).
