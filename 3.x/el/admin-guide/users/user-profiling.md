# Προφίλ Χρηστών

Το Chamilo σας επιτρέπει να ορίσετε προσαρμοσμένα πεδία προφίλ (extra fields) για την καταγραφή πρόσθετων πληροφοριών σχετικά με τους χρήστες, πέρα από το τυπικό όνομα, το email και τον ρόλο.

## Extra πεδία προφίλ

![Η λίστα extra πεδίων προφίλ που εμφανίζει προσαρμοσμένα πεδία με όνομα, τύπο και ρυθμίσεις ορατότητας](/.gitbook/assets/admin-extra-fields-list.png)

Τα extra πεδία σας επιτρέπουν να αποθηκεύετε μεταδεδομένα ειδικά για τον οργανισμό σας, όπως:

* Αριθμός μητρώου εργαζομένου
* Τμήμα
* Τίτλος θέσης
* Τοποθεσία/γραφείο
* Αριθμός τηλεφώνου
* Προσαρμοσμένα αναγνωριστικά

## Δημιουργία extra πεδίων

1. Από τον πίνακα διαχείρισης, μεταβείτε στα **Extra fields** ή **Profile fields**
2. Κάντε κλικ στο **Add**
3. Διαμορφώστε το πεδίο:
   * **Name** — Ο τίτλος του πεδίου που εμφανίζεται στους χρήστες
   * **Description** — Προαιρετική περιγραφή
   * **Helper text** — Κείμενο που εμφανίζεται κάτω από το πεδίο σε οποιαδήποτε φόρμα το περιλαμβάνει
   * **Field type** — Κείμενο, αναπτυσσόμενη λίστα, ημερομηνία, πλαίσιο ελέγχου κ.λπ.
   * **Field label** — Το εσωτερικό όνομα του πεδίου, για ενσωμάτωση με πρόσθετα 
   * **Possible values** — Εάν το πεδίο είναι επιλογέας μεταξύ αυτών των τιμών 
   * **Default value** — Μια προαιρετική προεπιλογή
   * **Visible to self** — Εάν το πεδίο είναι ορατό στο προφίλ χρήστη από τον ίδιο τον χρήστη
   * **Visible to others** — Εάν το πεδίο είναι ορατό σε άλλους χρήστες της πλατφόρμας
   * **Can change** — Εάν ο χρήστης μπορεί να αλλάξει μόνος του το δικό του πεδίο (ή εάν μπορούν μόνο οι διαχειριστές)
   * **Filter** — Εάν πρόκειται για πεδίο τύπου επιλογέα, εάν θα συμπεριληφθεί ως φίλτρο στις σελίδες διαχείρισης (π.χ. για εγγραφή χρηστών σε μαθήματα ή συνεδρίες)
   * **Order** — Εάν θέλετε να διαχειριστείτε τη σειρά εμφάνισης των πεδίων, θα πρέπει να δώσετε αριθμητική σειρά σε κάθε πεδίο
   * **Remove on anonymization** — Σημαντικό για κανόνες και νόμους περί απορρήτου: Εάν ο χρήστης ανωνυμοποιηθεί αλλά δεν διαγραφεί, θα πρέπει αυτό το πεδίο να θεωρείται πιθανός κάτοχος δεδομένων προσωπικής ταυτοποίησης; 
4. Αποθηκεύστε

## Τύποι πεδίων

Η μηχανή extra πεδίων υποστηρίζει ένα ευρύ σύνολο τύπων εισόδου. Οι συνηθισμένοι περιλαμβάνουν:

| Type | Description |
|------|-------------|
| **Text** | Εισαγωγή κειμένου μίας γραμμής |
| **Textarea** | Εισαγωγή κειμένου πολλαπλών γραμμών |
| **Radio** | Ομάδα κουμπιών επιλογής μίας επιλογής |
| **Dropdown / Dropdown multiple** | Λίστα προκαθορισμένων επιλογών (μονή ή πολλαπλή επιλογή) |
| **Double select** | Δύο εξαρτώμενες αναπτυσσόμενες λίστες (π.χ. χώρα → πόλη) |
| **Checkbox** | Εναλλαγή ναι/όχι |
| **Date / Date and time** | Επιλογέας ημερομηνίας ή ημερομηνίας+ώρας |
| **Integer** | Αριθμητική εισαγωγή |
| **Tag** | Πολλαπλές ελεύθερες τιμές ετικετών |
| **File** | Πεδίο μεταφόρτωσης αρχείου |
| **Video URL** | URL που οδηγεί σε βίντεο |
| **Mobile phone number** | Πεδίο μορφοποιημένου αριθμού τηλεφώνου |
| **Timezone** | Επιλογέας ζώνης ώρας |
| **Social profile** | Σύνδεσμος προς προφίλ κοινωνικού δικτύου |
| **Divider** | Οπτικός διαχωριστής μέσα στη φόρμα (χωρίς τιμή) |

Το ακριβές σύνολο χρησιμοποιήσιμων τύπων εξαρτάται από την έκδοση του Chamilo· η αναπτυσσόμενη λίστα τύπου πεδίου στη σελίδα διαχείρισης **Extra fields** αποτελεί την πηγή αλήθειας.

## Χρήση extra πεδίων

Τα extra πεδία εμφανίζονται:

* Στις φόρμες δημιουργίας (εάν είναι ορατά στον ίδιο) και επεξεργασίας χρήστη
* Στις σελίδες προφίλ χρήστη (εάν είναι ορατά στον ίδιο)
* Στις εισαγωγές χρηστών (μπορείτε να συμπεριλάβετε τιμές extra πεδίων σε εισαγωγές CSV)
* Στις εξαγωγές και τις αναφορές (φιλτράρισμα ή ομαδοποίηση κατά τιμές extra πεδίων)

## Συμβουλές

* **Σχεδιάστε πριν δημιουργήσετε** — Ορίστε ποιες πληροφορίες χρειάζεστε πριν δημιουργήσετε πεδία, καθώς η αλλαγή τύπων πεδίων μετά την εισαγωγή δεδομένων μπορεί να είναι προβληματική
* **Χρησιμοποιήστε αναπτυσσόμενες λίστες για συνέπεια** — Όταν ένα πεδίο έχει γνωστό σύνολο πιθανών τιμών, χρησιμοποιήστε αναπτυσσόμενη λίστα αντί για ελεύθερο κείμενο ώστε να διασφαλιστεί η συνέπεια των δεδομένων
* **Χρήση για αναφορές** — Τα extra πεδία είναι χρήσιμα για το φιλτράρισμα αναφορών (π.χ. «εμφάνιση όλων των χρηστών στο Τμήμα X που ολοκλήρωσαν την Κατάρτιση Y»)
