# Τάξεις / Ομάδες χρηστών

Οι τάξεις στον πίνακα διαχείρισης είναι ομάδες σε επίπεδο πλατφόρμας που χρησιμοποιούνται για την οργάνωση των χρηστών για σκοπούς διαχείρισης. Διαφέρουν από τις ομάδες σε επίπεδο μαθήματος (τις οποίες δημιουργούν οι εκπαιδευτές εντός ενός μαθήματος).

> Οι ομάδες χρηστών και οι [Τάξεις](../../admin-guide/sessions/classes.md) μοιράζονται την ίδια διεπαφή. Η μόνη διαφορά είναι η ρύθμιση **τύπου ομάδας**: επιλέξτε «Class» για να δημιουργήσετε μια τάξη (χρησιμοποιείται για μαζική εγγραφή σε συνεδρίες), ή «User group» για πιο κοινωνικές ομάδες που μπορούν να έχουν τον δικό τους χώρο στο εσωτερικό κοινωνικό δίκτυο. Δείτε τις [Τάξεις](../../admin-guide/sessions/classes.md) για λεπτομέρειες σχετικά με την εγγραφή σε συνεδρίες.

## Δημιουργία ομάδας

![Η λίστα ομάδων χρηστών που εμφανίζει τις διαθέσιμες ομάδες με όνομα, περιγραφή και αριθμό μελών](/.gitbook/assets/admin-user-groups-list.png)

1. Από τον πίνακα διαχείρισης, μεταβείτε στις **Τάξεις**
2. Κάντε κλικ στο **Add classes**
3. Εισαγάγετε έναν **τίτλο** και προαιρετικά μια **περιγραφή**
4. Επιλέξτε **Social group** αν πρόκειται για κοινωνική ομάδα. Αφήστε το χωρίς επιλογή αν πρόκειται για τάξη.
5. Προσθέστε προαιρετικά μια διεύθυνση URL αναφοράς και εικόνα/λογότυπο.
6. Επιλέξτε τα **δικαιώματα** της ομάδας:
   * **Open** — Οποιοσδήποτε χρήστης μπορεί να ενταχθεί
   * **Closed** — Οι χρήστες πρέπει να προστεθούν από έναν διαχειριστή
7. Επιλέξτε αν θέλετε τα μέλη να μπορούν να αποχωρήσουν μόνα τους από την τάξη.
8. Αποθηκεύστε.

## Προσθήκη μελών

1. Ανοίξτε τη λίστα τάξεων/ομάδων χρηστών
2. Κάντε κλικ στο εικονίδιο χρήστη **Subscribe users to class**
3. Αναζητήστε χρήστες κατά όνομα, όνομα χρήστη ή email
4. Επιλέξτε τους χρήστες προς προσθήκη, χρησιμοποιώντας τα βέλη στη δεξιά πλευρά
5. Κάντε κλικ στο κουμπί επιβεβαίωσης για αποθήκευση

## Περιπτώσεις χρήσης

* **Οργάνωση τμημάτων** — Ομαδοποίηση χρηστών ανά τμήμα ή ομάδα εργασίας
* **Μαζική εγγραφή** — Προσθήκη όλων των μελών μιας ομάδας σε ένα μάθημα ή μια συνεδρία ταυτόχρονα
* **Στοχευμένη επικοινωνία** — Αποστολή ανακοινώσεων σε συγκεκριμένες ομάδες
* **Αναφορές** — Προβολή προόδου κατάρτισης με φίλτρο ανά ομάδα

## Διαχείριση ομάδων

* **Edit** — Αλλαγή ονόματος, περιγραφής ή ορατότητας της ομάδας
* **Manage members** — Προσθήκη ή αφαίρεση μελών
* **Delete** — Διαγραφή της ομάδας (δεν διαγράφει τους λογαριασμούς των μελών)
