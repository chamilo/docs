# Σύνδεσμοι Chamilo.org

Το μπλοκ **Chamilo.org** είναι ένας στατικός κατάλογος εξερχόμενων συνδέσμων προς επίσημους πόρους του Chamilo — τίποτα περισσότερο. Δεν αποστέλλει δεδομένα πουθενά· κάθε σύνδεσμος ανοίγει είτε έναν εξωτερικό ιστότοπο του Chamilo είτε μια τοπική σελίδα τεκμηρίωσης που συνοδεύει την εγκατάστασή σας.

## Τι Περιλαμβάνει το Μπλοκ

| Σύνδεσμος | Προορισμός |
|------|-------------|
| Αρχική σελίδα Chamilo | `chamilo.org` |
| Οδηγοί χρήστη | `docs.chamilo.org` |
| Φόρουμ Chamilo | GitHub Discussions για το chamilo-lms |
| Οδηγός εγκατάστασης | Τοπικά, `/documentation/installation_guide.html` |
| Αλλαγές στην τελευταία έκδοση | Τοπικά, `/documentation/changelog.html` |
| Κατάλογος συντελεστών | Τοπικά, `/documentation/credits.html` |
| Οδηγός ασφαλείας | Τοπικά, `/documentation/security.html` |
| Οδηγός βελτιστοποίησης | Τοπικά, `/documentation/optimization.html` |
| Επίσημοι πάροχοι υπηρεσιών Chamilo | `chamilo.org/providers` |

Οι «τοπικοί» σύνδεσμοι παραπέμπουν σε αρχεία τεκμηρίωσης που περιλαμβάνονται στην ίδια την εγκατάσταση του Chamilo, επομένως φορτώνονται από τον δικό σας διακομιστή και όχι από το chamilo.org.

## Σκοπός

Αυτό το μπλοκ υπάρχει αποκλειστικά για ευκολία — γρήγορη πρόσβαση στην επίσημη τεκμηρίωση του έργου, στον χώρο συζήτησης της κοινότητας και στον κατάλογο ελεγμένων παρόχων υπηρεσιών, χωρίς να χρειάζεται να τους αναζητήσετε.
