# Έλεγχος Έκδοσης

Ο Έλεγχος Έκδοσης σάς ενημερώνει αν η εγκατάσταση του Chamilo είναι ενημερωμένη και — αν επιλέξετε να συμμετάσχετε — καταχωρίζει την πλατφόρμα σας στο έργο Chamilo ώστε να προσμετράται στις συγκεντρωτικές στατιστικές χρήσης.

## Δύο Επίπεδα Ελέγχου

**Μη καταχωρισμένη (προεπιλεγμένη κατάσταση):** Το Chamilo εξακολουθεί να προσπαθεί να επικοινωνήσει με το `version.chamilo.org` για να συγκρίνει την εγκατεστημένη έκδοση με την τελευταία κυκλοφορία, χρησιμοποιώντας μόνο το ίδιο το αίτημα — δεν αποστέλλονται λεπτομέρειες της πλατφόρμας. Το μπλοκ εμφανίζει μια φόρμα καταχώρισης που εξηγεί τι προσθέτει η καταχώριση, καθώς και ένα κουμπί **"Enable version check"** και ένα πλαίσιο ελέγχου **"Hide campus from public platforms list"**.

**Καταχωρισμένη:** Το κλικ στο "Enable version check" αλλάζει μόνο δύο τοπικές ρυθμίσεις — από μόνο του δεν αποστέλλει τίποτα. Από εκεί και πέρα, κάθε φορά που φορτώνεται αυτό το μπλοκ του πίνακα ελέγχου, η πλατφόρμα σας στέλνει αίτημα στο `version.chamilo.org` που περιλαμβάνει:

| Δεδομένα που αποστέλλονται | Δηλωμένος σκοπός |
|-----------|-----------------|
| Το URL και το όνομα ιστοτόπου της πλατφόρμας σας | Προσδιορίζει ποια πύλη κάνει check-in |
| E-mail επικοινωνίας διαχειριστή | Ρητά ώστε η ομάδα του Chamilo να μπορεί να επικοινωνήσει με διαχειριστές για κρίσιμα ζητήματα ασφαλείας |
| Εγκατεστημένη έκδοση | Για να διαπιστωθεί αν είστε ενημερωμένοι |
| Αριθμοί μαθημάτων, χρηστών, ενεργών χρηστών και συνεδριών | Συγκεντρώνονται σε μη προσωπικές συγκεντρωτικές στατιστικές στο `stats.chamilo.org` |
| Όνομα οργανισμού και γλώσσα διεπαφής | Μόνο για δημογραφική συγκέντρωση |
| Όνομα διαχειριστή | Αποστέλλεται, αν και ο σκοπός του δεν τεκμηριώνεται σαφώς στον ίδιο τον κώδικα |
| Η διεύθυνση IP του διακομιστή σας | Χρησιμοποιείται για κατά προσέγγιση εντοπισμό της θέσης της πλατφόρμας σε έναν παγκόσμιο χάρτη εγκαταστάσεων |
| Σημαία "Do not list campus", packager και μοναδικό αναγνωριστικό παρουσίας | Ελέγχει αν εμφανίζεστε στον δημόσιο κατάλογο και προσδιορίζει επαναλαμβανόμενα check-in από την ίδια εγκατάσταση |

Αν αφήσετε το **"Hide campus from public platforms list"** μη επιλεγμένο, η πλατφόρμα σας εμφανίζεται επίσης στη δημόσια λίστα κοινότητας στο `version.chamilo.org/community.php`.

## Πρόσβαση στον Έλεγχο Έκδοσης

Αυτό το μπλοκ εμφανίζεται απευθείας στον πίνακα ελέγχου διαχείρισης — δεν υπάρχει ξεχωριστή σελίδα για επίσκεψη.

## Πρέπει να τον Ενεργοποιήσετε;

Πρόκειται για ρητή συμμετοχή (opt-in) και το αντιστάθμισμα είναι απλό: σε αντάλλαγμα για την κοινοποίηση των παραπάνω λεπτομερειών, λαμβάνετε αυτόματη ειδοποίηση όταν είναι διαθέσιμη νέα έκδοση (συμπεριλαμβανομένων διορθώσεων ασφαλείας) και συμβάλλετε στις δημόσιες στατιστικές υιοθέτησης του Chamilo. Αν προτιμάτε να μην κοινοποιείτε λεπτομέρειες της πλατφόρμας, απλώς μην κάνετε κλικ στο "Enable version check" — ο βασικός έλεγχος ενημέρωσης εξακολουθεί να εκτελείται χωρίς καταχώριση. Αν θέλετε την ειδοποίηση ενημέρωσης αλλά όχι τη δημόσια καταχώριση, καταχωριστείτε και επιλέξτε "Hide campus from public platforms list."
