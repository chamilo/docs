# Νέα από το Chamilo

Τα Νέα από το Chamilo είναι ένα μικρό πάνελ μόνο για ανάγνωση που αντλεί επίσημες ανακοινώσεις από την Chamilo Association — εκεί θα ενημερωθείτε για μια νέα έκδοση ή, σημαντικότερα, για μια ενημέρωση ασφαλείας που πρέπει να εφαρμόσετε.

## Τι εμφανίζει και από πού προέρχεται

Το πάνελ ανακτά περιεχόμενο από το `version.chamilo.org/c/news/latest.php`, ζητώντας το στη γλώσσα διεπαφής της πλατφόρμας σας. Το μόνο που στέλνει η πλατφόρμα σας είναι αυτός ο κωδικός γλώσσας — κανένα στοιχείο της πλατφόρμας, δεδομένα χρήσης ή στοιχεία επικοινωνίας δεν φεύγουν από τον διακομιστή σας για αυτή τη λειτουργία.

## Σκοπός

Αυτό είναι το κανάλι του Chamilo για να ενημερώνει απευθείας τους διαχειριστές για θέματα που έχουν λειτουργική σημασία: νέες εκδόσεις και — το σημαντικότερο — **ενημερώσεις ασφαλείας**. Επειδή η έγκαιρη εφαρμογή ενημερώσεων ασφαλείας είναι ένα από τα πιο αποτελεσματικά μέτρα για την προστασία της πλατφόρμας σας (βλ. τον [Οδηγό ασφαλείας](../appendix/security-guide.md)), αξίζει να ρίχνετε μια ματιά σε αυτό το πάνελ περιοδικά, αντί να το ελέγχετε μόνο όταν το θυμηθείτε.

Αυτή η ροή φορτώνεται ανεξάρτητα από τον [Έλεγχο έκδοσης](version-check.md) — δεν χρειάζεται να καταχωρίσετε την πλατφόρμα σας για να τη βλέπετε.
