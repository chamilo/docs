# Άλλα Μπλοκ Διαχείρισης

Ο πίνακας ελέγχου διαχείρισης περιλαμβάνει μερικά ακόμη μπλοκ που δεν αποτελούν τόσο διαμορφώσιμες λειτουργίες όσο πληροφοριακά γραφικά στοιχεία: μια σελίδα εξερχόμενων συνδέσμων, μια εγγραφή ελέγχου έκδοσης και δύο μικρά πάνελ που αντλούν περιεχόμενο από το chamilo.org. Αυτό το κεφάλαιο εξηγεί τι είναι το καθένα, από πού προέρχεται το περιεχόμενό του και — εφόσον ορισμένα το κάνουν — αν οποιαδήποτε δεδομένα αποχωρούν από την πλατφόρμα σας.

## Τι Καλύπτεται

* **[Σύνδεσμοι Chamilo.org](chamilo-org-links.md)** — Μια λίστα σελιδοδεικτών προς επίσημους πόρους του Chamilo· δεν αποστέλλει τίποτα
* **[Έλεγχος Έκδοσης](version-check.md)** — Προαιρετική εγγραφή που αναφέρει την έκδοση και τη χρήση της πλατφόρμας σας στο chamilo.org και σας ενημερώνει αν χρειάζεστε ενημέρωση
* **[Επαγγελματική Υποστήριξη](professional-support.md)** — Ένα πάνελ μόνο για ανάγνωση που περιγράφει τους επίσημους παρόχους υποστήριξης του Chamilo
* **[Νέα από το Chamilo](news-from-chamilo.md)** — Μια ροή μόνο για ανάγνωση με επίσημες ανακοινώσεις, συμπεριλαμβανομένων ενημερώσεων ασφαλείας και νέων εκδόσεων

Κάθε σελίδα παρακάτω δηλώνει με σαφήνεια τι, αν κάτι, αποστέλλεται στο chamilo.org και γιατί.
