# Tickets

Η καταχώριση **Tickets** στο μπλοκ Analytics αποτελεί συντόμευση προς το σύστημα δελτίων υποστήριξης του Chamilo — ανοίγει απευθείας στη λίστα δελτίων και όχι σε σελίδα ρυθμίσεων.

## Accessing Tickets

Από τον πίνακα διαχείρισης, κάντε κλικ στο **Analytics > Tickets**.

## What It Shows

Η λίστα δελτίων όπου παρακολουθούνται και απαντώνται τα αιτήματα υποστήριξης — το ίδιο σύστημα δελτίων που καλύπτεται από την οπτική γωνία του υπεύθυνου υποστήριξης στη σελίδα [Support Tickets](../../teacher-guide/tickets.md) του Teacher Guide.

Για τη διαμόρφωση του ίδιου του συστήματος δελτίων (κατηγορίες, προτεραιότητες, ορισμένο προσωπικό), ανατρέξτε στο [Ticket Settings](../platform-settings/ticket-settings.md) στις Configuration Settings.
