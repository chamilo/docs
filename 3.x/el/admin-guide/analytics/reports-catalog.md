# Κατάλογος Αναφορών

Ο Κατάλογος Αναφορών δεν αποτελεί αναφορά από μόνος του — είναι ένας κατάλογος κάθε αναφοράς που έχει καταχωριστεί στην πλατφόρμα, χρήσιμος για την κατανόηση του τι είναι διαθέσιμο και ποιος μπορεί να το δει.

## Πρόσβαση στον Κατάλογο Αναφορών

Από τον πίνακα διαχείρισης, κάντε κλικ στο **Analytics > Reports catalog**.

## Τι Εμφανίζει

* **Λίστα αναφορών** — Ο τίτλος, η περιγραφή και τόσο το κανονικό όσο και το παλαιού τύπου URL κάθε καταχωρισμένης αναφοράς
* **Πίνακας ρόλων** — Μια προβολή που δείχνει ποιοι ρόλοι (Portal Administrator, Global Administrator, Session Administrator, Teacher, Human Resources Manager, Student Boss...) μπορούν να έχουν πρόσβαση σε κάθε αναφορά
* **Κατηγορίες δικαιωμάτων** — Οι ομάδες δικαιωμάτων στις οποίες οργανώνονται οι αναφορές (για παράδειγμα `reports.platform`, `reports.learning_analytics`, `reports.export`, `reports.security`)

Χρησιμοποιήστε αυτή τη σελίδα όταν προσπαθείτε να εντοπίσετε πού βρίσκεται μια συγκεκριμένη αναφορά, ή αν ένας δεδομένος ρόλος (για παράδειγμα, ένας Human Resources Manager) έχει πρόσβαση σε αυτήν, χωρίς να χρειάζεται να ελέγξετε κάθε αναφορά ξεχωριστά.
