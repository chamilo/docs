# Εταιρικές Αναφορές

Αυτή η σελίδα καλύπτει τέσσερις σχετικές καταχωρίσεις του πίνακα ελέγχου που απευθύνονται στην οργανωτική αναφορά και όχι στην καθημερινή διδασκαλία: τριμηνιαίες συνοπτικές εκθέσεις, φόρτος εργασίας εκπαιδευτών, αναφορά μαθημάτων προσανατολισμένη στο ανθρώπινο δυναμικό και μαζικές εξαγωγές εγγράφων.

## Τριμηνιαία Αναφορά

**Analytics > Quarterly report** παρουσιάζει ένα σύνολο καρτών σύνοψης για ένα δεδομένο τρίμηνο: εγγεγραμμένοι και συνδεδεμένοι χρήστες, μαθήματα που υπάρχουν έναντι μαθημάτων που χρησιμοποιούνται πραγματικά, ώρες παρεχόμενης κατάρτισης, πιστοποιητικά που έχουν εκδοθεί, συνεδρίες ανά διάρκεια και συνολική χρήση δίσκου (η χρήση δίσκου εμφανίζεται μόνο στην κύρια πύλη σε εγκατάσταση πολλαπλών URL). Κάθε κάρτα φορτώνεται ανεξάρτητα, ώστε η σελίδα να παραμένει αποκριτική ακόμη και σε πλατφόρμα με μεγάλο ιστορικό.

## Αναφορά Χρόνου Εκπαιδευτών

**Analytics > Teachers time report** σας επιτρέπει να φιλτράρετε ανά μάθημα, συνεδρία, εκπαιδευτή και εύρος ημερομηνιών για να δείτε πόσο χρόνο έχει αφιερώσει κάθε εκπαιδευτής. Προορίζεται για την παρακολούθηση του διδακτικού φόρτου εργασίας και των ωρών — φιλτράρετέ την σε ένα μόνο μάθημα ή συνεδρία, ή αφήστε την χωρίς φίλτρο για μια εικόνα σε επίπεδο πλατφόρμας.

## Εταιρική Αναφορά

**Analytics > Corporate report** έχει σχεδιαστεί ειδικά για κοινό ανθρώπινου δυναμικού — είναι η μοναδική αναφορά σε αυτό το κεφάλαιο που είναι επίσης διαθέσιμη στους ρόλους **Human Resources Manager** και **Student Boss**, όχι μόνο στους διαχειριστές. Παραθέτει, ανά μάθημα και ανά χρήστη: διεύθυνση ηλεκτρονικού ταχυδρομείου, ώρες που αφιερώθηκαν, αν εκδόθηκε πιστοποιητικό, ολοκληρωμένες διαδρομές μάθησης και πρόοδο μαθήματος. Μπορεί να περιοριστεί σε μία συνεδρία ή να μείνει σε επίπεδο πλατφόρμας.

## Ειδικές Εξαγωγές

**Analytics > Special exports** είναι εργαλείο μαζικής εξαγωγής, όχι αναφορά: συμπιέζει σε zip τα έγγραφα μαθημάτων σε επίπεδο πλατφόρμας, ή για ένα επιλεγμένο υποσύνολο μαθημάτων (συμπεριλαμβανομένων των εγγράφων που είναι ειδικά για συνεδρία). Πρόκειται για βαριά λειτουργία σε πλατφόρμα με πολύ περιεχόμενο μαθημάτων — είναι καλύτερο να εκτελείται εκτός ωρών αιχμής.
