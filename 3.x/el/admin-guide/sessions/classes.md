# Τάξεις

Οι τάξεις στο Chamilo είναι προκαθορισμένες ομάδες χρηστών που μπορούν να εγγραφούν σε συνεδρίες ως ενιαία μονάδα. Απλοποιούν τη διαδικασία εγγραφής όταν εκπαιδεύετε τακτικά τις ίδιες ομάδες ανθρώπων.

> Οι τάξεις και οι [Ομάδες χρηστών](../../admin-guide/users/user-groups.md) μοιράζονται την ίδια διεπαφή. Η μόνη διαφορά είναι η ρύθμιση **τύπου ομάδας**: επιλέξτε «Τάξη» κατά τη δημιουργία της ομάδας. Όλα τα υπόλοιπα — διαχείριση μελών, ορατότητα και η ίδια η διεπαφή — λειτουργούν πανομοιότυπα.

## Δημιουργία τάξης

1. Από τον πίνακα διαχείρισης, μεταβείτε στις **Τάξεις** (ή στις Ομάδες χρηστών και επιλέξτε τον τύπο «Τάξη»)
2. Κάντε κλικ στην επιλογή **Δημιουργία τάξης**
3. Εισαγάγετε ένα **όνομα** (π.χ. «Ομάδα Μηχανικών», «Νέες προσλήψεις Μάρτιος 2026»)
4. Προσθέστε **μέλη** — αναζητήστε και επιλέξτε χρήστες
5. Αποθηκεύστε

## Χρήση τάξεων για εγγραφή

Κατά τη δημιουργία ή την επεξεργασία μιας συνεδρίας, μπορείτε να εγγράψετε ολόκληρη την τάξη ταυτόχρονα αντί να προσθέτετε χρήστες μεμονωμένα:

1. Ανοίξτε τις ρυθμίσεις εγγραφής της συνεδρίας
2. Κάντε κλικ στην επιλογή **Προσθήκη τάξης**
3. Επιλέξτε την τάξη
4. Όλα τα μέλη της τάξης εγγράφονται στη συνεδρία

## Διαχείριση τάξεων

* **Επεξεργασία** — Αλλαγή του ονόματος της τάξης ή ενημέρωση της σύνθεσης των μελών
* **Προσθήκη/αφαίρεση μελών** — Διατηρήστε ενημερωμένο τον κατάλογο της τάξης
* **Διαγραφή** — Αφαίρεση της τάξης (δεν επηρεάζει τους λογαριασμούς των μελών ούτε τις υπάρχουσες εγγραφές τους)

## Συμβουλές

* **Δημιουργήστε τάξεις για επαναλαμβανόμενες ομάδες** — Αν διεξάγετε την ίδια εκπαίδευση για διαφορετικές ομάδες, δημιουργήστε μία τάξη για κάθε ομάδα
* **Ενημερώστε πριν από κάθε συνεδρία** — Ελέγξτε τη σύνθεση της τάξης πριν την εγγράψετε σε νέα συνεδρία, ώστε ο κατάλογος να είναι επίκαιρος
* **Συνδυάστε με εισαγωγή CSV** — Εισαγάγετε τη σύνθεση της τάξης από αρχείο CSV για μεγάλες ομάδες
