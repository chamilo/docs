## Κατανόηση των συνεδριών

Οι συνεδρίες είναι **προαιρετικές**. Μπορείτε να λειτουργήσετε την πύλη σας χρησιμοποιώντας μόνο μαθήματα, αλλά **συνιστούμε ιδιαίτερα** να εξετάσετε την επιπλέον πολυπλοκότητα των συνεδριών ως τρόπο εξοικονόμησης διαχειριστικής εργασίας μακροπρόθεσμα.

Ένα **μάθημα** περιέχει το περιεχόμενο (έγγραφα, ασκήσεις, διαδρομές μάθησης). Μια **συνεδρία** αναθέτει αυτό το μάθημα (ή πολλαπλά μαθήματα) σε μια συγκεκριμένη ομάδα εκπαιδευόμενων *για μια συγκεκριμένη χρονική περίοδο*.

Αυτή η αρχιτεκτονική σημαίνει ότι:

* Οι εκπαιδευτές δημιουργούν το περιεχόμενο μία φορά στο μάθημα
* Οι διαχειριστές δημιουργούν συνεδρίες για να παρέχουν αυτό το περιεχόμενο σε διαφορετικές κοόρτες
* Κάθε συνεδρία έχει τη δική της εγγραφή, δεδομένα παρακολούθησης και αποτελέσματα
* Το βασικό περιεχόμενο του μαθήματος είναι κοινό, αλλά οι καθηγητές της συνεδρίας μπορούν να προσαρμόσουν ορισμένα στοιχεία

## Πότε να χρησιμοποιείτε συνεδρίες

Χρησιμοποιήστε συνεδρίες όταν:

* Παρέχετε την ίδια κατάρτιση πολλές φορές (π.χ. μηνιαίες συνεδρίες ένταξης)
* Έχετε προγράμματα βάσει κοόρτης (π.χ. τάξεις ανά εξάμηνο)
* Χρειάζεστε ξεχωριστή παρακολούθηση ανά ομάδα εκπαιδευόμενων
* Θέλετε διαφορετικοί καθηγητές να διαχειρίζονται διαφορετικές εκδόσεις του ίδιου μαθήματος
