# Κατηγορίες Συνεδριών

Οι κατηγορίες συνεδριών βοηθούν στην οργάνωση των συνεδριών σας, ιδίως όταν εκτελούνται ταυτόχρονα πολλές συνεδρίες.

## Δημιουργία Κατηγορίας

1. Από τον πίνακα διαχείρισης, μεταβείτε στις **Κατηγορίες συνεδριών**
2. Κάντε κλικ στην επιλογή **Προσθήκη κατηγορίας**
3. Εισαγάγετε ένα **όνομα** και προαιρετικές ημερομηνίες έναρξης/λήξης
4. Αποθηκεύστε

## Περιπτώσεις Χρήσης

* **Ανά πρόγραμμα** — "Leadership Development", "Technical Training", "Onboarding"
* **Ανά περίοδο** — "Q1 2026", "Spring Semester", "July Batch"
* **Ανά τμήμα** — "Engineering", "Sales", "Human Resources"

## Διαχείριση Κατηγοριών

* **Επεξεργασία** — Αλλαγή του ονόματος ή των ημερομηνιών της κατηγορίας
* **Ανάθεση συνεδριών** — Κατά τη δημιουργία ή την επεξεργασία μιας συνεδρίας, επιλέξτε την κατηγορία της
* **Διαγραφή** — Αφαίρεση μιας κατηγορίας (οι συνεδρίες της κατηγορίας γίνονται χωρίς κατηγορία)
