# Διαχείριση Συνεδριών

## Δημιουργία Συνεδρίας

![Η φόρμα δημιουργίας συνεδρίας με πεδία για όνομα, ημερομηνίες, επιβλέποντα, κατηγορία και ορατότητα](../../.gitbook/assets/admin-session-create-form.png)

1. Από τον πίνακα διαχείρισης, κάντε κλικ στο **Create a session**
2. Συμπληρώστε τα στοιχεία της συνεδρίας:
   * **Session name** — Ένα περιγραφικό όνομα (π.χ. "Spring 2026 Onboarding")
   * **Start and end dates** — Πότε εκτελείται η συνεδρία (προαιρετικό — οι συνεδρίες μπορούν να είναι ανοιχτής διάρκειας). Υπάρχουν 3 σύνολα ημερομηνιών: Ημερομηνίες εμφάνισης, ημερομηνίες περιορισμού πρόσβασης εκπαιδευομένων και ημερομηνίες περιορισμού πρόσβασης επιβλεπόντων
   * **Session tutor** — Το άτομο που επιβλέπει ολόκληρη τη συνεδρία
   * **Category** — Ανάθεση σε κατηγορία συνεδρίας για οργάνωση
   * **Visibility** — Έλεγχος πρόσβασης και συμπεριφοράς εμφάνισης στη λίστα
3. **Add courses** — Επιλέξτε ένα ή περισσότερα μαθήματα για συμπερίληψη στη συνεδρία
4. **Enroll learners** — Προσθέστε μεμονωμένους χρήστες ή τάξεις χρηστών
5. **Assign course tutors** — Για κάθε μάθημα, αναθέστε έναν διδάσκοντα (επιβλέποντα μαθήματος)
6. Αποθήκευση

## Ημερομηνίες Συνεδρίας

Οι συνεδρίες υποστηρίζουν ευέλικτη διαμόρφωση ημερομηνιών:

| Ημερομηνία | Σκοπός |
|------|---------|
| **Display start/end** | Πότε εμφανίζεται η συνεδρία στις λίστες των εκπαιδευομένων |
| **Access start/end** | Πότε οι εκπαιδευόμενοι μπορούν πραγματικά να έχουν πρόσβαση στο περιεχόμενο της συνεδρίας |
| **Tutor access start/end** | Πότε οι επιβλέποντες μπορούν να έχουν πρόσβαση στη συνεδρία (συχνά ξεκινά πριν και τελειώνει μετά την πρόσβαση των εκπαιδευομένων) |

Αυτό σας επιτρέπει να προετοιμάσετε τη συνεδρία πριν φτάσουν οι εκπαιδευόμενοι και να διατηρήσετε ανοιχτή την πρόσβαση των επιβλεπόντων μετά τη λήξη της συνεδρίας για βαθμολόγηση και αναφορές.

## Λίστα Συνεδριών

![Η λίστα συνεδριών που εμφανίζει όλες τις συνεδρίες με όνομα, ημερομηνίες, πλήθος μαθημάτων, πλήθος εκπαιδευομένων και κατάσταση](../../.gitbook/assets/admin-session-list.png)

Η λίστα συνεδριών εμφανίζει όλες τις συνεδρίες με:

* Όνομα συνεδρίας
* Ημερομηνίες έναρξης και λήξης
* Κατάσταση (ενεργή, επερχόμενη, παρελθούσα)

Χρησιμοποιήστε αναζήτηση και φίλτρα για να βρείτε συνεδρίες κατά όνομα, ημερομηνία, κατηγορία ή κατάσταση.

## Επεξεργασία Συνεδρίας

Κάντε κλικ σε μια συνεδρία για επεξεργασία:

* Αλλαγή ημερομηνιών, ονόματος ή κατηγορίας
* Προσθήκη ή αφαίρεση μαθημάτων
* Αλλαγή επιβλεπόντων μαθημάτων
* Προσθήκη ή αφαίρεση εκπαιδευομένων
* Προβολή δεδομένων παρακολούθησης για τη συνεδρία

## Εγγραφή Χρηστών

![Το περιβάλλον εγγραφής συνεδρίας για προσθήκη μεμονωμένων χρηστών, τάξεων ή εισαγωγή μέσω CSV](../../.gitbook/assets/admin-session-enrollment.png)

Μπορείτε να εγγράψετε χρήστες σε μια συνεδρία με:

* **Individual enrollment** — Αναζήτηση και προσθήκη μεμονωμένων χρηστών
* **Class enrollment** — Προσθήκη ολόκληρης τάξης (ομάδας προκαθορισμένων χρηστών) με μία ενέργεια
* **CSV import** — Μεταφόρτωση αρχείου με αναθέσεις χρηστών-συνεδριών

## Πρόσβαση στη Συνεδρία

Οι εκπαιδευόμενοι έχουν πρόσβαση στις συνεδρίες τους μέσω του **My sessions** στην πλαϊνή γραμμή. Οι συνεδρίες οργανώνονται σε:

* **Current sessions** — Τρέχουσες ενεργές
* **Past sessions** — Ολοκληρωμένες
* **Upcoming sessions** — Που δεν έχουν ξεκινήσει ακόμη

## Συμβουλές

* **Plan dates carefully** — Βεβαιωθείτε ότι οι ημερομηνίες πρόσβασης των επιβλεπόντων επεκτείνονται πέρα από τις ημερομηνίες των εκπαιδευομένων, ώστε οι επιβλέποντες να μπορούν να προετοιμάσουν και να κάνουν παρακολούθηση
* **Use classes for recurring enrollment** — Αν εγγράφετε συχνά τις ίδιες ομάδες, δημιουργήστε τάξεις και αναθέστε τις σε συνεδρίες
* **Keep sessions organized** — Χρησιμοποιήστε κατηγορίες και σαφείς συμβάσεις ονοματοδοσίας για εύκολη διαχείριση
