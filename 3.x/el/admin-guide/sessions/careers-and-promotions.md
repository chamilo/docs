# Καριέρες και Προαγωγές

Το Chamilo περιλαμβάνει ένα σύστημα διαχείρισης καριέρων που σας επιτρέπει να ορίζετε διαδρομές κατάρτισης και να παρακολουθείτε την πρόοδο των εκπαιδευόμενων μέσα από δομημένα προγράμματα.

## Καριέρες

![Η λίστα καριέρων που εμφανίζει τις ορισμένες διαδρομές καριέρας με όνομα και περιγραφή](/.gitbook/assets/admin-careers-list.png)

Μια **καριέρα** αντιπροσωπεύει μια δομημένη διαδρομή κατάρτισης — μια ακολουθία βημάτων κατάρτισης που ακολουθεί ένας εκπαιδευόμενος για να επιτύχει έναν επαγγελματικό στόχο.

### Δημιουργία καριέρας

1. Από τον πίνακα διαχείρισης, μεταβείτε στις **Καριέρες**
2. Κάντε κλικ στην επιλογή **Create a career**
3. Εισαγάγετε ένα **όνομα** και μια **περιγραφή**
4. Αποθηκεύστε

## Προαγωγές

Μια **προαγωγή** αντιπροσωπεύει μια κοόρτη ή μια ομάδα εκπαιδευόμενων που προχωρούν μέσα από μια καριέρα. Σκεφτείτε την ως μια ομάδα ανθρώπων που ακολουθούν την ίδια διαδρομή καριέρας την ίδια χρονική περίοδο.

### Σύνδεση με συνεδρίες

Αφού δημιουργήσετε μια προαγωγή, συνδέετε συνεδρίες με αυτήν. Αυτό ορίζει την ακολουθία κατάρτισης που πρέπει να ολοκληρώσει ένας εκπαιδευόμενος.

Μπορείτε αργότερα να αναπαραγάγετε προαγωγές ώστε να διευκολύνετε τη δημιουργία της επόμενης προαγωγής με αντίγραφα των ίδιων συνεδριών, ώστε η επόμενη προαγωγή να μπορεί να δημιουργηθεί αμέσως.

### Δημιουργία προαγωγής

1. Μεταβείτε στις **Προαγωγές**
2. Κάντε κλικ στην επιλογή **Create a promotion**
3. Εισαγάγετε ένα **όνομα** και μια **περιγραφή**
4. Συνδέστε την με μια **καριέρα**
5. Αντιστοιχίστε **συνεδρίες** στην προαγωγή
6. Αποθηκεύστε

## Πώς συνδέονται μεταξύ τους

* Μια **καριέρα** ορίζει τη διαδρομή (π.χ. «Πιστοποίηση Junior Developer»)
* Μια **προαγωγή** αντιπροσωπεύει μια κοόρτη (π.χ. «Τάξη Μαρτίου 2026»)
* Οι **συνεδρίες** εντός της προαγωγής παρέχουν το πραγματικό περιεχόμενο κατάρτισης

## Συμβουλές

* **Χρήση για δομημένα προγράμματα** — Οι καριέρες και οι προαγωγές είναι πιο χρήσιμες για πολυεπίπεδα προγράμματα κατάρτισης όπου οι εκπαιδευόμενοι προχωρούν μέσα από μια καθορισμένη ακολουθία
* **Παρακολούθηση ολοκλήρωσης** — Χρησιμοποιήστε τα εργαλεία αναφορών για να παρακολουθείτε πώς προχωρούν οι προαγωγές στις διαδρομές καριέρας τους
