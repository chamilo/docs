# Εκκαθάριση αρχείου

Με την πάροδο του χρόνου, το Chamilo συσσωρεύει προσωρινά αρχεία στους καταλόγους cache και archive. Η τακτική εκκαθάριση αποτρέπει προβλήματα χώρου δίσκου.

## Τι μπορεί να εκκαθαριστεί

* **Προσωρινά αρχεία μεταφόρτωσης** — Αρχεία που δημιουργούνται κατά την εξαγωγή, την εισαγωγή και άλλες λειτουργίες, καθώς και παρωχημένα αρχεία κατασκευής του παλαιού frontend
* **Cache εφαρμογής Symfony** — Μεταγλωττισμένο container, αποθηκευμένη διαμόρφωση και δεδομένα δρομολόγησης. Αυτό *δεν* καλύπτεται από την ενέργεια του πίνακα διαχείρισης παρακάτω — βλ. [Από τη γραμμή εντολών](#from-the-command-line).
* **Δεδομένα συνεδρίας** — Ληγμένα αρχεία συνεδρίας PHP
* **Αρχεία καταγραφής** — Παλαιά αρχεία καταγραφής που δεν χρειάζονται πλέον

## Εκτέλεση εκκαθάρισης

### Από τον πίνακα διαχείρισης

Μεταβείτε στο **Σύστημα > Εκκαθάριση προσωρινών αρχείων** στον πίνακα διαχείρισης (βλ. [Εργαλεία συστήματος](../system/system-tools.md#clean-temporary-files)). Αναφέρει πόσα προσωρινά αρχεία υπάρχουν και πόσο χώρο καταλαμβάνουν, και στη συνέχεια σας επιτρέπει να διαγράψετε τα πάντα ή μόνο αρχεία παλαιότερα από μια επιλεγμένη ηλικία, με προεπισκόπηση δοκιμαστικής εκτέλεσης. Επίσης εκκαθαρίζει παρωχημένα αρχεία κατασκευής του παλαιού συστήματος και αναδημιουργεί τα μεταγλωττισμένα στοιχεία CSS.

Αυτή η ενέργεια αποκλείει σκόπιμα τους καταλόγους cache του ίδιου του Symfony (`var/cache/dev`, `var/cache/prod`, `var/cache/test` και τις δεξαμενές cache), οπότε δεν θα κάνει μια αλλαγή στο `.env` ή στο `config/` να τεθεί σε ισχύ — χρησιμοποιήστε τη γραμμή εντολών για αυτό.

### Από τη γραμμή εντολών

Για μεγαλύτερο έλεγχο, και για να εκκαθαρίσετε πραγματικά την cache εφαρμογής του Symfony, χρησιμοποιήστε εντολές κονσόλας Symfony:

```bash
# Clear the Symfony cache
php bin/console cache:clear

# Clear only the production cache
php bin/console cache:clear --env=prod
```

## Συμβουλές

* **Προγραμματίστε τακτικές εκκαθαρίσεις** — Ρυθμίστε μια εβδομαδιαία ή μηνιαία εργασία cron για την εκκαθάριση προσωρινών αρχείων
* **Παρακολουθήστε τη χρήση δίσκου** — Παρακολουθήστε το μέγεθος του καταλόγου `var/`, καθώς αυξάνεται με τα αρχεία cache και καταγραφής
* **Προσοχή με τα αρχεία καταγραφής** — Πριν διαγράψετε αρχεία καταγραφής, ελέγξτε αν περιέχουν πληροφορίες που μπορεί να χρειαστείτε για την αντιμετώπιση προβλημάτων
