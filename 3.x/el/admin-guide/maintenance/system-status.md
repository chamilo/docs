# Κατάσταση συστήματος

Η σελίδα κατάστασης συστήματος σάς βοηθά να επαληθεύσετε ότι ο διακομιστής Chamilo είναι σωστά ρυθμισμένος και να εντοπίσετε πιθανά προβλήματα.

## Πρόσβαση στην κατάσταση συστήματος

Από τον πίνακα διαχείρισης, κάντε κλικ στην επιλογή **Κατάσταση συστήματος** (ή **Πληροφορίες συστήματος**).

## Τι εμφανίζει

![Η σελίδα κατάστασης συστήματος που εμφανίζει τη διαμόρφωση PHP, την κατάσταση βάσης δεδομένων, τα δικαιώματα αρχείων και τις πληροφορίες διακομιστή](/.gitbook/assets/admin-system-status.png)

### Διαμόρφωση PHP

* **Έκδοση PHP** — Το Chamilo 3.0 υποστηρίζει PHP 8.3, 8.4 και 8.5
* **Απαιτούμενες επεκτάσεις** — Ελέγχει ότι έχουν εγκατασταθεί όλες οι απαραίτητες επεκτάσεις PHP
* **Ρυθμίσεις PHP** — Επαληθεύει σημαντικές ρυθμίσεις PHP όπως το όριο μνήμης, τα όρια μεταφόρτωσης και τον χρόνο εκτέλεσης

### Κατάσταση βάσης δεδομένων

* **Σύνδεση βάσης δεδομένων** — Επιβεβαιώνει ότι η βάση δεδομένων είναι προσβάσιμη
* **Έκδοση βάσης δεδομένων** — Εμφανίζει την έκδοση του διακομιστή βάσης δεδομένων

### Δικαιώματα αρχείων

* **Κατάλογοι με δικαίωμα εγγραφής** — Ελέγχει ότι το Chamilo μπορεί να γράψει στους απαιτούμενους καταλόγους (cache, uploads, logs)

### Πληροφορίες διακομιστή

* **Λειτουργικό σύστημα** — Λεπτομέρειες λειτουργικού συστήματος του διακομιστή
* **Διακομιστής ιστού** — Apache, Nginx ή άλλος
* **Χώρος δίσκου** — Διαθέσιμος χώρος αποθήκευσης

## Συνιστώμενοι έλεγχοι

Εκτελέστε αυτούς τους ελέγχους τακτικά:

* **Μετά την εγκατάσταση** — Επαληθεύστε ότι πληρούνται όλες οι απαιτήσεις
* **Μετά από αναβαθμίσεις** — Βεβαιωθείτε ότι η έκδοση PHP και οι επεκτάσεις παραμένουν συμβατές
* **Όταν προκύπτουν προβλήματα** — Ελέγξτε πρώτα την κατάσταση συστήματος κατά την αντιμετώπιση προβλημάτων
