# Αντίγραφα ασφαλείας

Τα τακτικά αντίγραφα ασφαλείας είναι απαραίτητα για την προστασία των δεδομένων του Chamilo. Αυτή η σελίδα καλύπτει τι πρέπει να δημιουργείτε αντίγραφο ασφαλείας και πώς.

## Τι να δημιουργείτε αντίγραφο ασφαλείας

### 1. Βάση δεδομένων

Η βάση δεδομένων του Chamilo περιέχει όλα τα δεδομένα της πλατφόρμας: χρήστες, μαθήματα, παρακολούθηση, βαθμούς, μηνύματα και ρυθμίσεις. Αυτό είναι το πιο κρίσιμο στοιχείο για αντίγραφο ασφαλείας.

**Πώς να δημιουργήσετε αντίγραφο ασφαλείας:**

```bash
mysqldump -u username -p chamilo_database > chamilo_backup_$(date +%Y%m%d).sql
```

### 2. Αρχεία

Το Chamilo αποθηκεύει τα μεταφορτωμένα αρχεία (έγγραφα, εικόνες, πακέτα SCORM) στο σύστημα αρχείων. Οι βασικοί κατάλογοι για αντίγραφο ασφαλείας:

* `var/` — Μεταφορτωμένα αρχεία και πόροι
* `public/plugin/` — Αρχεία προσθηκών (μόνο εάν έχετε προσθέσει προσαρμοσμένες προσθήκες)

Εάν χρησιμοποιείτε αποθήκευση στο νέφος (S3, Azure Blob), βεβαιωθείτε ότι είναι ενεργοποιημένο το αντίγραφο ασφαλείας/η εκδοχή του παρόχου νέφους σας.

### 3. Ρύθμιση παραμέτρων

* `.env` — Η ρύθμιση παραμέτρων περιβάλλοντος σας
* `config/` — Τυχόν προσαρμοσμένα αρχεία ρύθμισης παραμέτρων

## Πρόγραμμα αντιγράφων ασφαλείας

| Στοιχείο | Συνιστώμενη συχνότητα |
|-----------|---------------------|
| Βάση δεδομένων | Καθημερινά |
| Αρχεία | Καθημερινά ή εβδομαδιαία (ανάλογα με τη δραστηριότητα μεταφορτώσεων) |
| Ρύθμιση παραμέτρων | Μετά από οποιαδήποτε αλλαγή ρύθμισης παραμέτρων |

## Επαναφορά

Για επαναφορά από αντίγραφο ασφαλείας:

1. Επαναφέρετε τη βάση δεδομένων από το SQL dump
2. Επαναφέρετε τους καταλόγους αρχείων
3. Επαναφέρετε τα αρχεία ρύθμισης παραμέτρων
4. Εκκαθαρίστε την προσωρινή μνήμη του Symfony: `php bin/console cache:clear`

## Συμβουλές

* **Αυτοματοποιήστε τα αντίγραφα ασφαλείας** — Χρησιμοποιήστε εργασίες cron για αυτόματη εκτέλεση αντιγράφων ασφαλείας
* **Αποθηκεύστε εκτός εγκατάστασης** — Διατηρήστε αντίγραφα σε ξεχωριστό διακομιστή ή σε αποθήκευση νέφους
* **Δοκιμάστε την επαναφορά** — Ελέγχετε περιοδικά ότι μπορείτε να επαναφέρετε επιτυχώς από αντίγραφο ασφαλείας
* **Τεκμηριώστε τη διαδικασία σας** — Διατηρήστε γραπτές οδηγίες για τη διαδικασία επαναφοράς ώστε οποιοσδήποτε στην ομάδα να μπορεί να την εκτελέσει
