# Ολοκλήρωση κολλημένων τελικών στοιχείων διαδρομής μάθησης

Το τελευταίο βήμα μιας διαδρομής μάθησης — η σελίδα «Συγχαρητήρια» που περιέχει τα μπλοκ πιστοποιητικού και δεξιότητας — μετρά ως ολοκληρωμένο μόνο όταν ο εκπαιδευόμενος το ανοίξει πραγματικά. Ένας εκπαιδευόμενος που ολοκληρώνει κάθε άλλο βήμα αλλά δεν κάνει ποτέ κλικ για να φτάσει σε αυτή την τελευταία σελίδα παραμένει κολλημένος λίγο κάτω από το 100% για πάντα, και επειδή η επιλεξιμότητα για πιστοποιητικό επίτευξης (και η απονομή δεξιότητας) εξαρτάται από το να φτάσει η διαδρομή μάθησης στο 100%, δεν λαμβάνει ποτέ πιστοποιητικό ή δεξιότητα που κατά τα άλλα έχει κερδίσει.

```bash
php bin/console chamilo:learning-path:complete-final-items [options]
```

Για κάθε διαδρομή μάθησης στην πλατφόρμα της οποίας το τελευταίο βήμα είναι τύπου **Final item**, η εντολή ελέγχει κάθε εκπαιδευόμενο με προσπάθεια σε εξέλιξη (κάτω από 100%) που έχει ολοκληρώσει κάθε άλλο βήμα — σε κάθε μάθημα και κάθε συνεδρία που επαναχρησιμοποιεί τη διαδρομή μάθησης. Αν ισχύει αυτό, ολοκληρώνει το τελικό στοιχείο για εκείνον ακριβώς σαν να το είχε ανοίξει ο ίδιος: καταγράφει την ίδια προβολή στοιχείου, εκτελεί τον ίδιο επανυπολογισμό προόδου και ενεργοποιεί την ίδια δημιουργία πιστοποιητικού και απονομή δεξιότητας που θα ενεργοποιούσε μια πραγματική επίσκεψη.

Όπως η `chamilo:gradebook:process-achievement-certificates` (βλ.
[Πιστοποιητικά επίτευξης](achievement-certificates.md)), λειτουργεί σε οριοθετημένες παρτίδες, υποστηρίζει δοκιμαστική εκτέλεση και μπορεί να συνεχιστεί με ασφάλεια αν διακοπεί — ένας εκπαιδευόμενος του οποίου το τελικό στοιχείο έχει ήδη ολοκληρωθεί δεν αγγίζεται ποτέ ξανά σε μεταγενέστερη εκτέλεση.

## Επιλογές

| Option                 | Purpose                                                                                                            |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------- |
| `--dry-run`             | Αξιολογεί και αναφέρει χωρίς να ολοκληρώνει τίποτα. Να εκτελείται πάντα πρώτα.                                           |
| `--sender-id=<id>`      | Αναγνωριστικό ενεργού διαχειριστή πλατφόρμας, που χρησιμοποιείται ως δημιουργός πόρου όταν η ολοκλήρωση ενός τελικού στοιχείου ενεργοποιεί δημιουργία πιστοποιητικού ή απονομή δεξιότητας. Απαιτείται για πραγματική εκτέλεση (όχι dry-run). |
| `--limit=<n>`           | Μέγιστος αριθμός τελικών στοιχείων που ολοκληρώνονται (ή, σε dry-run, αναφέρονται) σε μία εκτέλεση. `0` = απεριόριστο. Προεπιλογή `500`.              |
| `--scan-limit=<n>`      | Μέγιστος αριθμός εγγραφών προόδου εκπαιδευομένων που σαρώνονται σε μία εκτέλεση, σε κάθε διαδρομή μάθησης. `0` = απεριόριστο. Προεπιλογή `5000`. |
| `--batch-size=<n>`      | Εγγραφές προόδου εκπαιδευομένων που φορτώνονται ανά παρτίδα βάσης δεδομένων, εντός μίας διαδρομής μάθησης. Προεπιλογή `50`.                       |
| `--lp-batch-size=<n>`   | Διαδρομές μάθησης που φορτώνονται ανά παρτίδα βάσης δεδομένων. Προεπιλογή `50`.                                                            |
| `--after-lp-id=<id>`    | Συνέχιση σάρωσης μετά από αυτό το αναγνωριστικό διαδρομής μάθησης.                                                                       |

## Παραδείγματα

Πρώτα δοκιμαστική εκτέλεση σε ολόκληρη την πλατφόρμα, για να δείτε ποιοι θα ολοκληρώνονταν:

```bash
php bin/console chamilo:learning-path:complete-final-items --dry-run
```

Πραγματική εκτέλεση, με τον διαχειριστή με αναγνωριστικό 1 ως δημιουργό πόρου:

```bash
php bin/console chamilo:learning-path:complete-final-items --sender-id=1
```

Συνέχιση μιας διακοπείσας εκτέλεσης μετά τη διαδρομή μάθησης 480:

```bash
php bin/console chamilo:learning-path:complete-final-items --sender-id=1 --after-lp-id=480
```

## Κωδικοί εξόδου

Η εντολή τερματίζει με κατάσταση αποτυχίας αν τουλάχιστον ένα τελικό στοιχείο απέτυχε πραγματικά να ολοκληρωθεί κατά τη διάρκεια μιας πραγματικής εκτέλεσης — ο συνοπτικός πίνακας κατονομάζει τη διαδρομή μάθησης και τον εκπαιδευόμενο και τον λόγο· το αρχείο καταγραφής της εφαρμογής περιέχει την πλήρη εξαίρεση. Ένας εκπαιδευόμενος που αποκλείεται ορθά (το τελικό στοιχείο έχει ήδη ολοκληρωθεί, ή κάποιο άλλο βήμα παραμένει ημιτελές) δεν αποτελεί σφάλμα και δεν προκαλεί ποτέ κωδικό εξόδου αποτυχίας.

## Βαθμολογία Gradebook μετά την ολοκλήρωση

Η βαθμολογία που εμφανίζεται για μια διαδρομή μάθησης στον πίνακα Gradebook δεν αποθηκεύεται ποτέ — υπολογίζεται ζωντανά από την τρέχουσα πρόοδο του εκπαιδευομένου κάθε φορά που φορτώνει η σελίδα, οπότε αντικατοπτρίζει αμέσως το 100%, χωρίς επιπλέον βήμα.

Το **πιστοποιητικό** ενός εκπαιδευομένου, αν υπήρχε ήδη πριν φτάσει στο 100% (με παλαιότερη, χαμηλότερη βαθμολογία ενσωματωμένη σε αυτό), ανανεώνει την αποθηκευμένη βαθμολογία και το αποδοθέν HTML μόνο αν η ίδια η αναδημιουργία πιστοποιητικού επιτύχει όταν αυτή η εντολή ολοκληρώνει το τελικό στοιχείο του — η ίδια κλήση που θα ενεργοποιούσε μια πραγματική επίσκεψη. Αν η δημιουργία πιστοποιητικού αποτύχει για οποιονδήποτε λόγο (βλ.
[Πιστοποιητικά επίτευξης](achievement-certificates.md) για συνήθεις αιτίες, π.χ. δικαιώματα αποθήκευσης αρχείων), η πρόοδος του εκπαιδευομένου εξακολουθεί να φτάνει σωστά στο 100% και ο πίνακας Gradebook εξακολουθεί να το εμφανίζει — μόνο το πιστοποιητικό του παραμένει να δείχνει την παλιά βαθμολογία, και επειδή η εντολή δεν επανεξετάζει ποτέ έναν εκπαιδευόμενο που βρίσκεται ήδη στο 100%, δεν θα το επαναλάβει σε μεταγενέστερη εκτέλεση. Αναδημιουργήστε αυτό το πιστοποιητικό χειροκίνητα (η ενέργεια **Generate** στη λίστα Certificates) μόλις διορθωθεί το υποκείμενο πρόβλημα.

Το `--sender-id` υπάρχει ειδικά για να αποφεύγεται μία συνήθης αιτία αυτής της αποτυχίας: η ολοκλήρωση ενός τελικού στοιχείου εκτός πραγματικού αιτήματος δεν έχει συνδεδεμένο χρήστη ώστε ο πόρος πιστοποιητικού να τον καταγράψει ως δημιουργό του, και η δημιουργία αποτυγχάνει εντελώς χωρίς αυτόν.
