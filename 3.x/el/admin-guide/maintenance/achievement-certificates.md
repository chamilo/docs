# Πιστοποιητικά επίτευξης (μαζική δημιουργία)

Το Chamilo μπορεί να δημιουργεί αυτόματα το πιστοποιητικό επίτευξης ενός μαθήματος για κάθε φοιτητή που το έχει ολοκληρώσει — εντός ενός βασικού μαθήματος και εντός οποιασδήποτε συνεδρίας που το επαναχρησιμοποιεί — χωρίς ο διδάσκων να χρειάζεται να ανοίγει κάθε μάθημα ξεχωριστά. Δύο εντολές κονσόλας καλύπτουν αυτή τη λειτουργία, μία για ένα μεμονωμένο μάθημα και μία για ολόκληρη την πλατφόρμα, και καμία από τις δύο δεν είναι μια βαριά για τη βάση δεδομένων λειτουργία που πρέπει να επιβλέπετε συνεχώς: και οι δύο λειτουργούν σε οριοθετημένες παρτίδες, υποστηρίζουν δοκιμαστική εκτέλεση και μπορούν να συνεχιστούν με ασφάλεια αν διακοπούν.

## Εντολή σε επίπεδο πλατφόρμας

```bash
php bin/console chamilo:gradebook:process-achievement-certificates [options]
```

Για κάθε μάθημα που διαθέτει επιλέξιμη ριζική κατηγορία βαθμολογίου — ανώτατου επιπέδου, όχι υποκατηγορία, με ενεργοποιημένη την επιλογή **Generate certificates** — η εντολή αξιολογεί κάθε εγγεγραμμένο φοιτητή που δεν διαθέτει ήδη πιστοποιητικό για τη συγκεκριμένη κατηγορία και δημιουργεί ένα για όποιον έχει εκπληρώσει την απαίτηση ολοκλήρωσης. Ένα μάθημα μπορεί να συνεισφέρει **περισσότερα από ένα** πλαίσια: την βασική εγγραφή του και, χωριστά, ένα πλαίσιο ανά συνεδρία που το επαναχρησιμοποιεί, καθώς μια συνεδρία μπορεί να έχει τη δική της ριζική κατηγορία και το δικό της όριο επιτυχίας.

Ένα μάθημα, ή ένα από τα πλαίσια συνεδρίας του, παραλείπεται — δεν αντιμετωπίζεται ως σφάλμα — όταν δεν είναι επιλέξιμο για αυτοματοποιημένη επεξεργασία: δεν έχει ρυθμιστεί κανόνας ολοκλήρωσης, υπάρχουν περισσότερες από μία επιλέξιμες ριζικές κατηγορίες για το συγκεκριμένο πλαίσιο (ασαφές, απαιτείται χειροκίνητη επιλογή) ή λείπει το περιεχόμενο ειδοποίησης πιστοποιητικού. Η σύνοψη εκτέλεσης στο τέλος αναφέρει πόσα πλαίσια ενέπεσαν σε κάθε περίπτωση, ώστε τίποτα να μην παραλείπεται χωρίς να εμφανίζεται.

### Πηγή ολοκλήρωσης

* `--completion-mode=course-rule` (προεπιλογή): χρησιμοποιεί τον κανόνα ολοκλήρωσης που έχει ρυθμιστεί για το μάθημα.
* `--completion-mode=gradebook`: χρησιμοποιεί απευθείας την εγγενή βαθμολογία του βαθμολογίου για το συγκεκριμένο πλαίσιο. Μόνο ένα πλαίσιο με ακριβώς μία επιλέξιμη ριζική κατηγορία πληροί τις προϋποθέσεις σε αυτή τη λειτουργία — ένα πλαίσιο με περισσότερες παραλείπεται και αναφέρεται, ώστε να υποβληθεί σε επεξεργασία ξεχωριστά (βλ. παρακάτω).

### Επιλογές ασφάλειας

| Επιλογή                     | Σκοπός                                                                                                                                 |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `--dry-run`                 | Αξιολογεί και αναφέρει χωρίς να δημιουργεί πιστοποιητικά ή να αποστέλλει ειδοποιήσεις. Να εκτελείτε πάντα πρώτα αυτή την επιλογή.                                      |
| `--send-notification`       | Απαιτείται για πραγματική εκτέλεση (όχι δοκιμαστική). Αποστέλλει το εσωτερικό μήνυμα και το ηλεκτρονικό μήνυμα που έχουν ρυθμιστεί για το μάθημα μετά τη δημιουργία κάθε πιστοποιητικού. |
| `--sender-id=<id>`          | Ενεργός διαχειριστής πλατφόρμας που χρησιμοποιείται ως αποστολέας της ειδοποίησης. Απαιτείται μαζί με το `--send-notification`.                            |
| `--limit=<n>`                | Μέγιστος αριθμός πιστοποιητικών που δημιουργούνται (ή, σε δοκιμαστική εκτέλεση, αναφέρονται) σε μία εκτέλεση. `0` = απεριόριστο. Προεπιλογή `100`.                                    |
| `--scan-limit=<n>`           | Μέγιστος αριθμός φοιτητών που αξιολογούνται σε μία εκτέλεση, σε όλα τα μαθήματα και τις συνεδρίες. `0` = απεριόριστο. Προεπιλογή `1000`.                                 |
| `--batch-size=<n>`           | Φοιτητές που φορτώνονται ανά παρτίδα βάσης δεδομένων εντός ενός πλαισίου μαθήματος/συνεδρίας. Προεπιλογή `25`.                                                     |
| `--course-batch-size=<n>`    | Μαθήματα που φορτώνονται ανά παρτίδα βάσης δεδομένων. Προεπιλογή `50`.                                                                                         |
| `--after-course-id=<id>`     | Συνέχιση της σάρωσης μετά από αυτό το αναγνωριστικό μαθήματος. Ασφαλές για επαναχρησιμοποίηση μετά από διακοπείσα εκτέλεση — ένα μάθημα δεν αναδημιουργεί ποτέ πιστοποιητικό για φοιτητή που διαθέτει ήδη ένα. |
| `--user-id=<id>`             | Περιορίζει την εκτέλεση σε έναν φοιτητή, ο οποίος ελέγχεται σε κάθε επιλέξιμο μάθημα και συνεδρία — χρήσιμο για την επικύρωση της συμπεριφοράς πριν από μια εκτέλεση σε επίπεδο πλατφόρμας. |
| `--regenerate-empty`         | Επεξεργάζεται επίσης φοιτητές των οποίων η εγγραφή πιστοποιητικού υπάρχει αλλά δεν διαθέτει αποθηκευμένο αρχείο πιστοποιητικού — για παράδειγμα μετά από δημιουργία που απέτυχε εν μέρει — και δημιουργεί ξανά το πιστοποιητικό. Οι φοιτητές με πλήρες πιστοποιητικό δεν επηρεάζονται ποτέ. |

### Παραδείγματα

Εκτελέστε πρώτα δοκιμαστική εκτέλεση (dry-run) σε ολόκληρη την πλατφόρμα, για να δείτε τι θα παραγόταν:

```bash
php bin/console chamilo:gradebook:process-achievement-certificates --dry-run
```

Πραγματική εκτέλεση, με ειδοποίηση των φοιτητών και τον διαχειριστή με ID 1 ως αποστολέα:

```bash
php bin/console chamilo:gradebook:process-achievement-certificates \
  --send-notification --sender-id=1
```

Συνέχιση μιας διακοπείσας εκτέλεσης μετά το μάθημα 480:

```bash
php bin/console chamilo:gradebook:process-achievement-certificates \
  --send-notification --sender-id=1 --after-course-id=480
```

Εκ νέου δημιουργία των πιστοποιητικών των οποίων η εγγραφή υπάρχει αλλά το αρχείο δεν αποθηκεύτηκε ποτέ (πρώτα dry-run
για να τα καταγράψετε):

```bash
php bin/console chamilo:gradebook:process-achievement-certificates \
  --regenerate-empty --dry-run
php bin/console chamilo:gradebook:process-achievement-certificates \
  --regenerate-empty --send-notification --sender-id=1
```

### Προγραμματισμός ως εργασία cron

```cron
# Every night at 2 AM
0 2 * * * php /path/to/chamilo/bin/console chamilo:gradebook:process-achievement-certificates --send-notification --sender-id=1 -e prod --no-interaction >> /path/to/chamilo/var/log/achievement-certificates.log 2>&1
```

## Επεξεργασία ενός μαθήματος μεμονωμένα

Η εντολή `chamilo:migration:process-achievement-certificates --course-id=<id>` προσφέρει τις ίδιες επιλογές dry-run,
ειδοποίησης και σελιδοποίησης με την εντολή σε επίπεδο πλατφόρμας, περιορισμένη μόνο στο βασικό μάθημα
(όχι στις συνεδρίες του), με ρητό `--category-id` για αποσαφήνιση όταν ένα μάθημα έχει περισσότερες από
μία επιλέξιμες ριζικές κατηγορίες:

```bash
php bin/console chamilo:migration:process-achievement-certificates \
  --course-id=42 --category-id=7 --dry-run
```

Χρησιμοποιήστε την για να δοκιμάσετε ένα μεμονωμένο μάθημα πριν από μια εκτέλεση σε επίπεδο πλατφόρμας, ή για να επεξεργαστείτε ένα μάθημα που η εκτέλεση σε επίπεδο πλατφόρμας
ανέφερε ως παραλειφθέν λόγω ασαφούς κατηγορίας.

## Κωδικοί εξόδου

Και οι δύο εντολές τερματίζουν με κατάσταση αποτυχίας εάν τουλάχιστον μία δημιουργία πιστοποιητικού απέτυχε πραγματικά
κατά τη διάρκεια μιας πραγματικής εκτέλεσης (ελέγξτε το `var/log/dev.log` — ή το αντίστοιχο αρχείο καταγραφής παραγωγής — για το υποκείμενο
σφάλμα). Τα πλαίσια που παραλείπονται για δομικούς λόγους (χωρίς κανόνα, ασαφής κατηγορία, ελλιπής ρύθμιση
ειδοποιήσεων) δεν προκαλούν κωδικό εξόδου αποτυχίας· αναφέρονται αντίθετα στη σύνοψη.

## Σχετικό: εκπαιδευόμενοι που παραμένουν κάτω από το 100% σε μια προαπαιτούμενη διαδρομή μάθησης

Εάν ο κανόνας ολοκλήρωσης ενός μαθήματος απαιτεί μια διαδρομή μάθησης να φτάσει το 100%, ένας εκπαιδευόμενος που ολοκλήρωσε κάθε
βήμα αλλά δεν άνοιξε ποτέ την τελική σελίδα «Συγχαρητήρια» της διαδρομής παραμένει λίγο κάτω από το 100% και δεν
καθίσταται ποτέ επιλέξιμος εδώ. Δείτε
[Ολοκλήρωση κολλημένων τελικών στοιχείων διαδρομής μάθησης](learning-path-final-items.md) — εκτελέστε το πρώτα εάν
φοιτητές δεν έχουν πιστοποιητικά που θα περιμένατε να έχουν αποκτήσει.

## Αντικαταστάθηκε: το παλαιό σενάριο cron

Το `public/main/cron/add_gradebook_certificates.php` δεν συνιστάται πλέον. Φορτώνει κάθε
αποτέλεσμα βαθμολογίου της πλατφόρμας στη μνήμη με ένα μόνο απεριόριστο ερώτημα και δεν το απελευθερώνει ποτέ
κατά τη διάρκεια του βρόχου, οπότε μπορεί να εξαντλήσει τη μνήμη σε μια εγκατάσταση με μη αμελητέο αριθμό μαθημάτων ή
ασκήσεων, και δεν αποστέλλει ποτέ την ειδοποίηση «αποκτήσατε πιστοποιητικό». Χρησιμοποιήστε αντ' αυτού την
`chamilo:gradebook:process-achievement-certificates`.
