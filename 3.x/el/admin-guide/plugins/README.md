# Πρόσθετα

Τα πρόσθετα επεκτείνουν τη λειτουργικότητα του Chamilo χωρίς τροποποίηση του βασικού κώδικα. Το Chamilo 3.0 συνοδεύεται από περισσότερα από 50 πρόσθετα που μπορούν να ενεργοποιηθούν ανάλογα με τις ανάγκες.

## Το μπλοκ Πρόσθετα

Ο πίνακας ελέγχου διαχείρισης διαθέτει επίσης το δικό του μπλοκ **Πρόσθετα**, ξεχωριστό από τη γενική διαχείριση προσθέτων αυτού του κεφαλαίου. Δεν εμφανίζει κάθε εγκατεστημένο πρόσθετο — μόνο εκείνα των οποίων η διαμόρφωση δηλώνει ότι πρέπει να εμφανίζονται στην περιοχή του μενού διαχείρισης, δίνοντας σε καθένα από αυτά μια άμεση συντόμευση προς τη δική του σελίδα διαχείρισης ακριβώς στον πίνακα ελέγχου.

![Το μπλοκ Πρόσθετα στον πίνακα ελέγχου διαχείρισης, με συντομεύσεις προς εγκατεστημένα πρόσθετα που έχουν ρυθμιστεί να εμφανίζονται στο μενού διαχείρισης](/.gitbook/assets/admin-plugins-block.png)

Αν ένα πρόσθετο που έχετε ενεργοποιήσει δεν εμφανίζεται εδώ, αυτό είναι αναμενόμενο — σημαίνει ότι το συγκεκριμένο πρόσθετο δεν έχει δηλώσει τον εαυτό του για την περιοχή του μενού διαχείρισης, όχι ότι κάτι έχει χαλάσει. Δείτε το [Διαχείριση προσθέτων](managing-plugins.md) για την πλήρη λίστα των εγκατεστημένων προσθέτων, ανεξάρτητα από το αν εμφανίζονται στον πίνακα ελέγχου.
