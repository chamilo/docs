# Κρυπτογράφηση σε κατάσταση ηρεμίας για πεδία προφίλ χρήστη

Το Chamilo 3.1 μπορεί προαιρετικά να κρυπτογραφεί επιλεγμένα προσωπικά πεδία προφίλ πριν από την αποθήκευσή τους στη βάση δεδομένων. Αυτή η πρώτη υλοποίηση καλύπτει τη **βιογραφία**, το **τηλέφωνο** και τη **διεύθυνση**. Η κρυπτογράφηση είναι **απενεργοποιημένη από προεπιλογή** και απαιτεί ιδιωτικό κλειδί κρυπτογράφησης. Δεν κρυπτογραφεί όλες τις πληροφορίες χρήστη ούτε αντικαθιστά την ασφάλεια δίσκου, βάσης δεδομένων, μεταφοράς ή αντιγράφων ασφαλείας.

## Πριν από την ενεργοποίηση της κρυπτογράφησης

Μόνο ένας διαχειριστής πλατφόρμας με πρόσβαση στον διακομιστή πρέπει να εκτελέσει την ανάπτυξη. Πρώτα, επιβεβαιώστε ότι η εγκατάσταση περιλαμβάνει τις μεταναστεύσεις του Chamilo 3.1 για αποθήκευση κρυπτογραφημένων πεδίων, λάβετε ανακτήσιμο αντίγραφο ασφαλείας της βάσης δεδομένων και σχεδιάστε ένα ασφαλές αντίγραφο ασφαλείας του κλειδιού κρυπτογράφησης **ξεχωριστά από τη βάση δεδομένων**. Δοκιμάστε τις διαδικασίες επαναφοράς πριν από την τροποποίηση δεδομένων παραγωγής.

Το κλειδί αποθηκεύεται στη διαδρομή `var/data-at-rest/master.key`, εκτός του δημόσιου ριζικού καταλόγου ιστού. Μην το δημοσιεύετε ποτέ, μην το επικολλάτε σε αίτημα υποστήριξης και μην το υποβάλλετε στο Git. Η απώλεια του αρχικού κλειδιού μπορεί να καταστήσει τα κρυπτογραφημένα δεδομένα μη αναγνώσιμα. Μην δημιουργείτε κλειδί αντικατάστασης εάν οποιαδήποτε δεδομένα χρήστη είναι ήδη κρυπτογραφημένα.

## Αρχικοποίηση του κλειδιού

Εκτελέστε την εντολή μία φορά σε λειτουργία προεπισκόπησης:

```bash
php bin/console chamilo:security:initialize-at-rest-key
```

Εάν αναφέρει ότι δεν υπάρχουν κρυπτογραφημένα δεδομένα και ότι το κλειδί μπορεί να παρασχεθεί, αρχικοποιήστε το ρητά:

```bash
php bin/console chamilo:security:initialize-at-rest-key --apply
```

Εάν η εντολή αναφέρει υπάρχον συμβατό κλειδί, δεν εκτελείται αντικατάσταση. Εάν υπάρχουν κρυπτογραφημένες γραμμές αλλά το κλειδί λείπει ή δεν ταιριάζει, **σταματήστε** και ανακτήστε το αρχικό κλειδί.

## Επιλογή προστατευμένων πεδίων

Ανοίξτε **Διαχείριση > Ρυθμίσεις > Ασφάλεια** και επιλέξτε **Βιογραφία**, **Τηλέφωνο** και/ή **Διεύθυνση** στη ρύθμιση κρυπτογραφημένων πεδίων χρήστη. Επιλέξτε μόνο τα πεδία που σκοπεύετε να προστατεύσετε. Οι νέες εγγραφές στα επιλεγμένα πεδία χρησιμοποιούν επαληθευμένη κρυπτογράφηση (libsodium XChaCha20-Poly1305)· οι παλαιές εγγραφές σε απλό κείμενο παραμένουν αναγνώσιμες μέχρι να συμπληρωθούν ρητά εκ των υστέρων.

## Επιθεώρηση και εκ των υστέρων συμπλήρωση υπαρχόντων δεδομένων

Οι εντολές εκ των υστέρων συμπλήρωσης δεν τροποποιούν εγγραφές χωρίς το `--apply`. Προτιμήστε έναν μόνο χρήστη διασφάλισης ποιότητας πριν από μια ευρύτερη δέσμη:

```bash
php bin/console chamilo:security:encrypt-user-biographies --user-id=102
php bin/console chamilo:security:encrypt-user-profile-fields --field=phone --user-id=102
php bin/console chamilo:security:encrypt-user-profile-fields --field=address --user-id=102
```

Αφού επαληθεύσετε τη διαθεσιμότητα του κλειδιού, την επιλογή πεδίων, τα αντίγραφα ασφαλείας και τον λογαριασμό διασφάλισης ποιότητας, εκτελέστε μια σκόπιμη πιλοτική εφαρμογή:

```bash
php bin/console chamilo:security:encrypt-user-biographies --user-id=102 --apply
php bin/console chamilo:security:encrypt-user-profile-fields --field=phone --user-id=102 --apply
```

Αντικαταστήστε το `102` με ένα πραγματικό αναγνωριστικό δοκιμαστικού χρήστη. Για μεγαλύτερα σύνολα δεδομένων, χρησιμοποιήστε το προαιρετικό όρισμα `--batch-size` (1–500), εξετάστε την έξοδο της εντολής και τη συμπεριφορά της εφαρμογής, και προγραμματίστε τις δέσμες κατά τη διάρκεια παραθύρου συντήρησης. Μην εκτελείτε εκ των υστέρων συμπλήρωση ολόκληρης της βάσης δεδομένων χωρίς δοκιμασμένη στρατηγική επαναφοράς.

## Λειτουργικοί περιορισμοί

- Αυτή είναι η πρώτη φάση κρυπτογράφησης σε επίπεδο πεδίου, όχι κρυπτογράφηση ολόκληρης της βάσης δεδομένων.
- Παλαιότερες άμεσες ενσωματώσεις SQL και εξαγωγές ενδέχεται να μην γνωρίζουν πώς να διαβάζουν κρυπτογραφημένες τιμές· επαληθεύστε τις πριν από την ανάπτυξη.
- Ένα αντίγραφο ασφαλείας βάσης δεδομένων **χωρίς** αντίστοιχο ανακτήσιμο κλειδί είναι ανεπαρκές.
- Μην καταγράφετε ακατέργαστα περιεχόμενα πεδίων και μην συμπεριλαμβάνετε υλικό κλειδιού σε διαγνωστικά.
- Η επαναφορά μόνο του κώδικα της εφαρμογής δεν αποκρυπτογραφεί τις αποθηκευμένες τιμές.

Δείτε τις [Ρυθμίσεις ασφαλείας](../platform-settings/security-settings.md) για γενικές επιλογές ασφάλειας πλατφόρμας. Υλοποίηση: [Chamilo LMS PR #9491](https://github.com/chamilo/chamilo-lms/pull/9491).
