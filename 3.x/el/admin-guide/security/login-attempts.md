# Προσπάθειες σύνδεσης

Η αναφορά Προσπάθειες σύνδεσης εμφανίζει αρχείο αποτυχημένων προσπαθειών σύνδεσης, με γραφήματα που βοηθούν στον εντοπισμό μοτίβων ωμής βίας ή credential stuffing.

## Πρόσβαση στις Προσπάθειες σύνδεσης

Από τον πίνακα διαχείρισης, κάντε κλικ στο **Ασφάλεια > Προσπάθειες σύνδεσης**.

## Τι εμφανίζει

![Η σελίδα Προσπάθειες σύνδεσης με γραφήματα για προσπάθειες ανά ημέρα, κορυφαίες IP, αποτυχημένες προσπάθειες ανά μήνα, επιτυχείς έναντι αποτυχημένων συνδέσεων, προσπάθειες ανά ώρα και μοναδικές IP ανά ημέρα, ακολουθούμενα από πίνακα αποτυχημένων προσπαθειών σύνδεσης](/.gitbook/assets/admin-security-login-attempts.png)

* **Προσπάθειες ανά ημέρα (τελευταίες 7 ημέρες)** — Ημερήσιος αριθμός αποτυχημένων προσπαθειών
* **Κορυφαίες IP (τελευταίες 30 ημέρες)** — Ποιες διευθύνσεις IP δημιούργησαν τις περισσότερες προσπάθειες
* **Αποτυχημένες προσπάθειες ανά μήνα (τελευταίοι 12 μήνες)** — Μακροπρόθεσμη τάση
* **Επιτυχείς έναντι αποτυχημένων (τελευταίες 30 ημέρες)** — Ημερήσια ανάλυση επιτυχών έναντι αποτυχημένων συνδέσεων
* **Προσπάθειες ανά ώρα (τελευταίες 7 ημέρες)** — Κατανομή ανά ώρα της ημέρας, χρήσιμη για τον εντοπισμό αυτοματοποιημένων/σεναριακών προσπαθειών
* **Μοναδικές IP ανά ημέρα (τελευταίες 30 ημέρες)** — Πόσες διακριτές IP επιχείρησαν συνδέσεις κάθε ημέρα
* **Πίνακας αποτυχημένων προσπαθειών σύνδεσης** — Κάθε αποτυχημένη προσπάθεια, με ημερομηνία, διεύθυνση IP και όνομα χρήστη που δοκιμάστηκε

Χρησιμοποιήστε τα πεδία **Όνομα χρήστη**, **IP** και εύρος ημερομηνιών πάνω από τα γραφήματα για να φιλτράρετε την αναφορά.

## Σχετικές ρυθμίσεις

Αυτή η αναφορά είναι εργαλείο παρακολούθησης· οι πραγματικές προστασίες έναντι ωμής βίας ρυθμίζονται στις [Ρυθμίσεις ασφαλείας](../platform-settings/security-settings.md):

* **Μέγιστες προσπάθειες σύνδεσης πριν από το κλείδωμα** (`login_max_attempt_before_blocking_account`) — Κλειδώνει έναν λογαριασμό μετά από υπερβολικά πολλές αποτυχημένες προσπάθειες
* **CAPTCHA** (`allow_captcha`) και **Επιτρεπόμενα λάθη CAPTCHA** (`captcha_number_mistakes_to_block_account`) — Επιβραδύνει τις αυτοματοποιημένες προσπάθειες και κλειδώνει λογαριασμούς που συνεχίζουν να αποτυγχάνουν στο CAPTCHA

Δείτε επίσης τον [Οδηγό ασφαλείας](../appendix/security-guide.md) για προστασία ωμής βίας σε επίπεδο διακομιστή (fail2ban).
