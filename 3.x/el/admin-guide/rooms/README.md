# Αίθουσες

Το μπλοκ **Αίθουσες** στον πίνακα ελέγχου διαχείρισης διαχειρίζεται τις φυσικές τοποθεσίες που μπορεί να παρακολουθεί το Chamilo για δια ζώσης ή μικτή εκπαίδευση: παραρτήματα (τοποθεσίες), τις αίθουσες εντός αυτών, καθώς και ένα εργαλείο για την εύρεση ποιες αίθουσες είναι ελεύθερες σε δεδομένη χρονική στιγμή.

![Το μπλοκ Αίθουσες στον πίνακα ελέγχου διαχείρισης, με τις ενότητες Παραρτήματα, Αίθουσες και Εύρεση διαθεσιμότητας αιθουσών](../../.gitbook/assets/admin-rooms-block.png)

Το παρόν κεφάλαιο καλύπτει τη διαχείριση παραρτημάτων και αιθουσών από την πλευρά του διαχειριστή. Για την πλευρά του εκπαιδευτή — την ανάθεση αίθουσας σε συνεδρία μαθήματος — βλ. [Παραρτήματα και Αίθουσες](../../teacher-guide/branches-and-rooms.md) στον Οδηγό Εκπαιδευτή.

## Πρόσβαση στο μπλοκ Αίθουσες

Από τον πίνακα διαχείρισης, το μπλοκ **Αίθουσες** εμφανίζεται δίπλα στα υπόλοιπα μπλοκ του πίνακα ελέγχου. Κάντε κλικ σε οποιονδήποτε από τους συνδέσμους του για να ανοίξετε το αντίστοιχο εργαλείο.

## Τι περιλαμβάνει το μπλοκ

* **[Διαχείριση αιθουσών](managing-rooms.md)** — Δημιουργία και οργάνωση παραρτημάτων (τοποθεσιών) και των αιθουσών εντός καθενός
* **[Εύρεση διαθεσιμότητας αιθουσών](room-availability-finder.md)** — Έλεγχος ποιες αίθουσες είναι ελεύθερες για δεδομένο εύρος ημερομηνίας και ώρας

## Σημείωση για Multi-URL

Σε εγκατάσταση multi-URL (multi-tenant), τα παραρτήματα και οι αίθουσες περιορίζονται σε ένα μόνο URL πρόσβασης το καθένα — δεν κοινοποιούνται ποτέ μεταξύ πυλών.
