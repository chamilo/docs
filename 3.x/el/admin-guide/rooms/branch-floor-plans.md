# Κατόψεις ορόφων παραρτημάτων και χάρτες αιθουσών

Το Chamilo 3.1 μπορεί να συσχετίσει μια εικόνα κάτοψης ορόφου με ένα παράρτημα και να σημειώσει τις θέσεις των αιθουσών σε αυτή την εικόνα με διαδραστικά πολύγωνα. Η λειτουργία βοηθά τους εκπαιδευόμενους να εντοπίζουν τις ανατεθειμένες αίθουσες· **δεν** είναι γεωγραφικός χάρτης GPS.

## Επισύναψη κάτοψης ορόφου παραρτήματος

1. Ανοίξτε την περιοχή διαχείρισης για τα **Παραρτήματα** και επεξεργαστείτε το επιθυμητό παράρτημα.
2. Εντοπίστε τον πίνακα **Κάτοψη ορόφου**.
3. Επιλέξτε ή μεταφορτώστε την εικόνα και επιλέξτε **Επισύναψη κάτοψης ορόφου** (ή **Αλλαγή κάτοψης ορόφου** εάν υπάρχει ήδη).
4. Αποθηκεύστε ή επιβεβαιώστε τις αλλαγές του παραρτήματος όπως απαιτείται και, στη συνέχεια, επαληθεύστε ότι φορτώνεται η εικόνα της κάτοψης ορόφου.

Εάν μια κάτοψη δεν είναι πλέον έγκυρη, χρησιμοποιήστε την επιλογή **Αφαίρεση κάτοψης ορόφου** αφού ελέγξετε ποιες αίθουσες αναφέρονται σε αυτήν. Μεταφορτώνετε μόνο αξιόπιστο περιεχόμενο και ακολουθήστε τα δικαιώματα της οθόνης διαχείρισης παραρτημάτων.

## Περίγραμμα αιθουσών

1. Επεξεργαστείτε μια αίθουσα που έχει ανατεθεί σε αυτό το παράρτημα.
2. Βρείτε την επιλογή **Αίθουσα στην κάτοψη ορόφου** στη φόρμα της αίθουσας.
3. Χρησιμοποιήστε το εργαλείο πολυγώνου για να χαράξετε το περίγραμμα της αίθουσας. Χρησιμοποιήστε την επιλογή **Επεξεργασία** για να προσαρμόσετε τις κορυφές· όλα τα σημεία πρέπει να παραμένουν εντός της εικόνας.
4. Επιλέξτε **Αποθήκευση περιοχής αίθουσας** και, στη συνέχεια, αποθηκεύστε τη φόρμα της αίθουσας για να διατηρηθούν οι αλλαγές.
5. Ανοίξτε ένα πρόγραμμα προβολής αίθουσας για να επιβεβαιώσετε τη σωστή θέση. Χρησιμοποιήστε την επιλογή **Εκκαθάριση περιοχής αίθουσας** εάν η αντιστοίχιση πρέπει να αφαιρεθεί.

Μια αίθουσα διαθέτει ένα επεξεργάσιμο πολύγωνο κάθε φορά. Η αντιστοίχιση αιθουσών είναι ξεχωριστή από την εικόνα σε επίπεδο παραρτήματος, επομένως η ενημέρωση της εικόνας ενδέχεται να απαιτεί έλεγχο των υφιστάμενων ορίων αιθουσών.

## Πού εμφανίζονται οι χάρτες

Οι εξουσιοδοτημένοι χρήστες μπορούν να προβάλλουν τις κατόψεις ορόφων των αιθουσών όταν οι αίθουσες επιλέγονται ή εμφανίζονται στις πληροφορίες μαθήματος, στα συμβάντα ημερολογίου και στις ροές που σχετίζονται με την παρακολούθηση. Επαληθεύστε την ορατότητα χρησιμοποιώντας τους ρόλους που θα προβάλλουν πραγματικά τις πληροφορίες, ιδίως τους φοιτητές και τους συμμετέχοντες σε συνεδρίες.

Τα δικαιώματα πρόσβασης σε παραρτήματα και αίθουσες ισχύουν επίσης για τους πόρους κατόψεων ορόφων. Σε εγκαταστάσεις με πολλαπλά URL, επαληθεύστε τη σωστή απομόνωση πύλης/παραρτήματος πριν από τη δημοσίευση χαρτών.
