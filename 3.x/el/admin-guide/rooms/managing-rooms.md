# Διαχείριση Αιθουσών

Οι αίθουσες στο Chamilo οργανώνονται κάτω από παραρτήματα: ένα παράρτημα είναι ένας φυσικός χώρος και κάθε αίθουσα ανήκει σε ακριβώς ένα παράρτημα.

## Παραρτήματα

**Αίθουσες > Παραρτήματα** διαχειρίζεται τους φυσικούς χώρους του οργανισμού σας — ένα κτίριο, μια πανεπιστημιούπολη ή ένα γραφείο. Τα παραρτήματα μπορούν να είναι ένθετα (ένα παράρτημα μπορεί να έχει θυγατρικά παραρτήματα), ώστε να μπορείτε να μοντελοποιήσετε κάτι όπως «Κεντρική Πανεπιστημιούπολη > Κτίριο Α».

Πεδία που μπορείτε να ορίσετε για ένα παράρτημα:

* **Τίτλος** και **Περιγραφή**
* **Γονικό παράρτημα** — Για την ιεραρχική οργάνωση των παραρτημάτων
* **Διεύθυνση IP** — Προαιρετικό, για αναγνώριση βάσει δικτύου
* **Γεωγραφικό πλάτος / Γεωγραφικό μήκος** — Για χαρτογράφηση
* **Ταχύτητα λήψης / αποστολής** και **Καθυστέρηση** — Προαιρετικά μεταδεδομένα ποιότητας δικτύου
* **Ηλεκτρονικό ταχυδρομείο, όνομα και τηλέφωνο διαχειριστή** — Στοιχεία επικοινωνίας του υπευθύνου του χώρου

## Αίθουσες

**Αίθουσες > Αίθουσες** διαχειρίζεται τους πραγματικούς χώρους κράτησης εντός ενός παραρτήματος — συνήθως μια αίθουσα διδασκαλίας ή εκπαίδευσης. Κάθε αίθουσα πρέπει να ανήκει σε ένα παράρτημα.

Πεδία που μπορείτε να ορίσετε για μια αίθουσα:

* **Τίτλος** και **Περιγραφή**
* **Παράρτημα** — Σε ποιο παράρτημα ανήκει αυτή η αίθουσα (υποχρεωτικό)
* **Αριθμός ορόφου**
* **Χωρητικότητα** — Πρέπει να είναι θετικός αριθμός
* **Γεωεντοπισμός**, **Διεύθυνση IP** και **Μάσκα IP** — Προαιρετικά προηγμένα πεδία

Κάθε αίθουσα διαθέτει επίσης προβολή ημερολογίου «Κατάληψη» που εμφανίζει τις κρατήσεις της, καθώς και πλήθος των μαθημάτων που τη χρησιμοποιούν.

## Σχετικά

Για να βρείτε μια ελεύθερη αίθουσα για συγκεκριμένο χρονικό διάστημα αντί να περιηγείστε στη λίστα, δείτε τον [Εντοπιστή Διαθεσιμότητας Αιθουσών](room-availability-finder.md).
