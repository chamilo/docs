# Κατηγορίες μαθημάτων

Οι κατηγορίες μαθημάτων βοηθούν στην οργάνωση του καταλόγου μαθημάτων σας, διευκολύνοντας τους εκπαιδευόμενους να βρίσκουν σχετικά μαθήματα.

## Δημιουργία κατηγορίας

1. Από τον πίνακα διαχείρισης, μεταβείτε στις **Κατηγορίες μαθημάτων**
2. Κάντε κλικ στην **Προσθήκη κατηγορίας**
3. Εισαγάγετε:
   * **Κωδικός κατηγορίας** — Ένα σύντομο μοναδικό αναγνωριστικό
   * **Όνομα κατηγορίας** — Το εμφανιζόμενο όνομα (π.χ. «Πληροφορική», «Δεξιότητες διοίκησης»)
   * **Να επιτρέπεται η προσθήκη μαθημάτων σε αυτή την κατηγορία;** — Αν επιτρέπει στα μαθήματα να την ορίσουν ως κατηγορία, ή αν λειτουργεί απλώς ως ενδιάμεσο επίπεδο σε μια ιεραρχία 
   * **Γονική κατηγορία** — (Προαιρετικό) Τοποθετήστε αυτή την κατηγορία κάτω από άλλη κατηγορία για να δημιουργήσετε ιεραρχία
   * **Περιγραφή** — (Προαιρετικό)
   * **Εικόνα** — (Προαιρετικό) Θα αντιπροσωπεύει αυτή την κατηγορία, αν και σχεδόν δεν εμφανίζεται πουθενά
4. Πατήστε *Προσθήκη κατηγορίας*

Το Chamilo δημιουργεί από προεπιλογή 3 κατηγορίες: *Language skills*, *PC Skills* και *Projects*. Αυτές μπορούν να μετονομαστούν, να αφαιρεθούν ή να διατηρηθούν, ανάλογα με τις ανάγκες σας.

## Ιεραρχία κατηγοριών

![Η σελίδα διαχείρισης κατηγοριών μαθημάτων που εμφανίζει ένα ένθετο δέντρο κατηγοριών](../../.gitbook/assets/admin-course-categories.png)

Οι κατηγορίες μπορούν να ένθετονται ώστε να δημιουργείται δομή δέντρου:

* Business
  * Management
  * Marketing
  * Finance
* Technology
  * Programming
  * Networking
  * Cybersecurity

Οι εκπαιδευόμενοι που περιηγούνται στον κατάλογο μαθημάτων μπορούν να πλοηγηθούν σε αυτή την ιεραρχία για να βρουν μαθήματα.

## Διαχείριση κατηγοριών

* **Επεξεργασία** — Αλλαγή του ονόματος, του κωδικού ή της γονικής κατηγορίας
* **Μετακίνηση** — Αλλαγή της θέσης μιας κατηγορίας στη λίστα
* **Διαγραφή** — Αφαίρεση μιας κατηγορίας. Τα μαθήματα μιας διαγραμμένης κατηγορίας μετακινούνται στα «χωρίς κατηγορία».

## Συμβουλές

* **Κρατήστε το απλό** — Χρησιμοποιήστε ευρείες κατηγορίες που οι εκπαιδευόμενοι κατανοούν με μια ματιά
* **Περιορίστε το βάθος** — Αποφύγετε βαθιά ένθετες κατηγορίες. Δύο ή τρία επίπεδα είναι συνήθως επαρκή.
* **Αναθέστε κατηγορίες κατά τη δημιουργία μαθήματος** — Ενθαρρύνετε τους εκπαιδευτές να επιλέγουν κατηγορία κατά τη δημιουργία μαθημάτων, ώστε ο κατάλογος να παραμένει οργανωμένος
