# Καθολικές πολιτικές ρυθμίσεων μαθημάτων

Οι διαχειριστές της πλατφόρμας μπορούν να ορίσουν κεντρικές προεπιλογές για τις ρυθμίσεις μαθημάτων και να ελέγχουν αν οι διδάσκοντες επιτρέπεται να τις παρακάμπτουν. Οι πολιτικές εφαρμόζονται στην υπάρχουσα λειτουργικότητα των μαθημάτων, διατηρώντας παράλληλα συμβατές ρυθμίσεις ειδικές για κάθε μάθημα.

## Άνοιγμα της σελίδας πολιτικών

Στο **κύριο URL πρόσβασης**, ανοίξτε **Διαχείριση > Ρυθμίσεις > Ρυθμίσεις μαθημάτων** ή μεταβείτε στο `/admin/settings/course-settings` στην εγκατάστασή σας. Αυτή η σελίδα διαχείρισης προορίζεται αποκλειστικά για εξουσιοδοτημένους διαχειριστές της πλατφόρμας στο κύριο URL πρόσβασης. Μην χρησιμοποιείτε δευτερεύουσα πύλη για την επεξεργασία καθολικών πολιτικών.

## Ρύθμιση μιας πολιτικής

1. Χρησιμοποιήστε το πεδίο **Αναζήτηση** αν χρειάζεστε ένα συγκεκριμένο κλειδί ρύθμισης μαθήματος.
2. Για κάθε ρύθμιση, ελέγξτε το ακριβές όνομα μεταβλητής που εμφανίζεται κάτω από την επικεφαλίδα της.
3. Επιλέξτε ή αποεπιλέξτε το **Επεξεργάσιμο στο μάθημα** για να ελέγξετε αν οι συντάκτες του μαθήματος μπορούν να αλλάξουν τη συγκεκριμένη ρύθμιση.
4. Επιλέξτε ή εισαγάγετε μια **Προεπιλεγμένη τιμή πλατφόρμας**. Ορισμένες ρυθμίσεις προσφέρουν αναπτυσσόμενη λίστα επιτρεπόμενων τιμών· άλλες δέχονται κείμενο.
5. Αποθηκεύστε τις αλλαγές και επαληθεύστε την πραγματική συμπεριφορά σε ένα δοκιμαστικό μάθημα.

Ρυθμίσεις που επαναχρησιμοποιούν το ίδιο όνομα μεταβλητής σε διαφορετικές κατηγορίες εμφανίζονται ξεχωριστά όπου είναι απαραίτητο. Μην υποθέτετε ότι δύο οπτικά παρόμοια ονόματα ελέγχουν την ίδια λειτουργία μαθήματος.

## Επαλήθευση με δύο ρόλους

Ως διαχειριστής, επιβεβαιώστε την αποθηκευμένη προεπιλογή και αν είναι επεξεργάσιμη. Ως διδάσκων του μαθήματος, ανοίξτε την αντίστοιχη ρύθμιση μαθήματος και ελέγξτε ότι η πραγματική τιμή και ο περιορισμός επεξεργασίας συμφωνούν με την πολιτική. Δοκιμάστε, όπου είναι δυνατόν, τόσο ένα υπάρχον όσο και ένα νέο μάθημα.

Η αλλαγή μιας καθολικής προεπιλογής μπορεί να επηρεάσει πολλά μαθήματα. Εξετάστε τον αντίκτυπό της πριν απενεργοποιήσετε τις παρακάμψεις των διδασκόντων και καταγράψτε τις προηγούμενες τιμές της πολιτικής, ώστε να μπορούν να αποκατασταθούν αν χρειαστεί.
