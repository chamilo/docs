# Μαθήματα

Η ενότητα αυτή καλύπτει τη διαχείριση μαθημάτων από τη σκοπιά του διαχειριστή: εποπτεία του καταλόγου μαθημάτων, διαχείριση κατηγοριών και χειρισμός εισαγωγών και εξαγωγών.

* **[Κατηγορίες μαθημάτων](course-categories.md)** — Οργάνωση του καταλόγου μαθημάτων με κατηγορίες
