# Διαχείριση Μαθημάτων

Ως διαχειριστής, μπορείτε να διαχειρίζεστε όλα τα μαθήματα στην πλατφόρμα, ανεξάρτητα από το ποιος τα δημιούργησε.

## Λίστα μαθημάτων

![Η λίστα μαθημάτων που εμφανίζει όλα τα μαθήματα με τίτλο, κωδικό, κατηγορία, εγγεγραμμένους χρήστες και κατάσταση ορατότητας](/.gitbook/assets/admin-course-list.png)

Από τον πίνακα διαχείρισης, κάντε κλικ στην επιλογή **Course list** για να δείτε όλα τα μαθήματα. Η λίστα εμφανίζει:

* Τίτλο και κωδικό μαθήματος
* Γλώσσα
* Κατηγορίες
* Κατάσταση ορατότητας

Χρησιμοποιήστε το εργαλείο **Advanced search** για να βρείτε συγκεκριμένα μαθήματα.

## Δημιουργία μαθήματος

Ως διαχειριστής, μπορείτε να δημιουργείτε μαθήματα και να τα αναθέτετε σε οποιονδήποτε εκπαιδευτή:

1. Κάντε κλικ στην επιλογή **Add course** από τον πίνακα διαχείρισης
2. Συμπληρώστε τα στοιχεία του μαθήματος (τίτλος, κωδικός, κατηγορία, γλώσσα)
3. Αναθέστε έναν εκπαιδευτή στο μάθημα
4. Αποθηκεύστε

Σημείωση: Στο Chamilo 1.11.x, ο κωδικός μαθήματος εμφανιζόταν ως μέρος του URL του μαθήματος και ήταν αδύνατο να αλλάξει μετά τη δημιουργία του μαθήματος. Αυτή η συμπεριφορά άλλαξε ξεκινώντας από την έκδοση 2.x. Ο κωδικός μαθήματος δεν είναι πλέον ορατός στο URL και μελλοντικές εκδόσεις ενδέχεται να επιτρέπουν στους εκπαιδευτές να τροποποιούν τον κωδικό μαθήματος εκ των υστέρων, καθώς γίνεται λιγότερο ουσιώδης για την πλατφόρμα.

## Διαχείριση υπάρχοντος μαθήματος

Βρείτε ένα μάθημα στη λίστα για να αποκτήσετε πρόσβαση στις επιλογές διαχείρισης στη στήλη *Actions*:

* **Information** — Εμφάνιση πληροφοριών σχετικά με το μάθημα 
* **Course home** — Σας μεταφέρει απευθείας στην αρχική σελίδα του μαθήματος 
* **Reporting** — Προβολή δεδομένων συμμετοχής και επίδοσης
* **Edit** — Αλλαγή τίτλου μαθήματος, κατηγορίας, ορατότητας και άλλων ρυθμίσεων
* **Create a backup** — Μετάβαση στην ενότητα συντήρησης του μαθήματος, όπου μπορείτε να δημιουργήσετε αντίγραφα και να κάνετε άλλα πράγματα
* **Add to catalogue** — Προσθήκη αυτού του μαθήματος στον κατάλογο μαθημάτων
* **Delete** — Οριστική διαγραφή του μαθήματος και όλου του περιεχομένου του

> Η διαγραφή ενός μαθήματος αφαιρεί οριστικά όλο το περιεχόμενο, τα δεδομένα εκπαιδευομένων, τους βαθμούς και τις πληροφορίες παρακολούθησης. Εξετάστε το ενδεχόμενο να εξαγάγετε πρώτα το μάθημα ως αντίγραφο ασφαλείας.

## Μαζικές ενέργειες

Επιλέξτε πολλαπλά μαθήματα στη λίστα για να εκτελέσετε μαζικές ενέργειες, όπως τη διαγραφή τους. Για να εξαγάγετε ένα μάθημα, εισέλθετε στο μάθημα και χρησιμοποιήστε το εργαλείο **Maintenance** — δεν υπάρχει μαζική ενέργεια εξαγωγής στη λίστα μαθημάτων του διαχειριστή.

## Ρυθμίσεις ορατότητας μαθήματος

Οι διαχειριστές μπορούν να παρακάμψουν την ορατότητα που έχει ορίσει ο εκπαιδευτής:

| Ορατότητα | Αποτέλεσμα |
|-----------|--------|
| **Public** | Προσβάσιμο σε όλους, συμπεριλαμβανομένων ανώνυμων επισκεπτών |
| **Open** | Προσβάσιμο σε όλους τους συνδεδεμένους χρήστες |
| **Private** | Μόνο οι εγγεγραμμένοι χρήστες μπορούν να έχουν πρόσβαση στο μάθημα |
| **Closed** | Κανείς δεν μπορεί να έχει πρόσβαση στο μάθημα (εκτός από τον εκπαιδευτή και τους διαχειριστές) |
| **Hidden** | Κανείς δεν μπορεί να δει ή να έχει πρόσβαση στο μάθημα (εκτός από τους διαχειριστές) |
