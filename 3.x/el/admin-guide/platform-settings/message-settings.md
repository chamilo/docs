# Ρυθμίσεις μηνυμάτων

Συμπεριφορά του συστήματος **Μηνύματα / Εισερχόμενα**.

Πρόσβαση σε αυτές τις ρυθμίσεις από **Διαχείριση > Ρυθμίσεις διαμόρφωσης > Μηνύματα**. Αυτή η κατηγορία περιέχει **7 ρυθμίσεις**, που παρατίθενται παρακάτω με τον τίτλο και το σχόλιο που περιλαμβάνονται στα fixtures ρυθμίσεων της πλατφόρμας (`SettingsCurrentFixtures.php`).

> Το όνομα της μεταβλητής στον κώδικα εμφανίζεται σε μονοδιάστημα. Χρησιμοποιήστε το κατά τη συγγραφή σεναρίων μέσω του API ή όταν χρειάζεται να αλλάξετε αυτές τις ρυθμίσεις σε καθολικό επίπεδο επεξεργάζοντας το [`config/settings_override.yaml`](https://github.com/chamilo/chamilo-lms/wiki/Configurations#configsettings_overridesyaml).

## Ρυθμίσεις

### `allow_message_tool`

**Εσωτερικό εργαλείο μηνυμάτων**

Η ενεργοποίηση του εσωτερικού εργαλείου μηνυμάτων επιτρέπει στους χρήστες να στέλνουν μηνύματα σε άλλους χρήστες της πλατφόρμας και να διαθέτουν εισερχόμενα μηνυμάτων.

*Προεπιλογή: `true`*

### `allow_send_message_to_all_platform_users`

**Να επιτρέπεται η αποστολή μηνυμάτων σε οποιονδήποτε χρήστη της πλατφόρμας**

Σας επιτρέπει να στέλνετε μηνύματα σε οποιονδήποτε χρήστη της πλατφόρμας, όχι μόνο στους φίλους σας ή στα άτομα που είναι αυτή τη στιγμή συνδεδεμένα.

*Προεπιλογή: `false`*

### `allow_user_message_tracking`

**Οι διαχειριστές μπορούν να βλέπουν προσωπικά μηνύματα**

Να επιτρέπεται στους διαχειριστές να βλέπουν προσωπικά μηνύματα μεταξύ ενός εκπαιδευτή και ενός εκπαιδευόμενου. Βεβαιωθείτε ότι συμπεριλαμβάνετε σχετική σημείωση στους όρους και τις προϋποθέσεις σας, καθώς αυτό ενδέχεται να επηρεάσει την προστασία της ιδιωτικότητας.

*Προεπιλογή: `false`*


### `filter_interactivity_messages`

**Οι εκπαιδευτές μπορούν να έχουν πρόσβαση στα μηνύματα των εκπαιδευομένων μόνο εντός του χρονικού πλαισίου της συνεδρίας**

Φιλτράρισμα μηνυμάτων μεταξύ εκπαιδευτή και εκπαιδευόμενου μεταξύ των ημερομηνιών έναρξης και λήξης της συνεδρίας

*Προεπιλογή: `false`*


### `message_max_upload_filesize`

**Μέγιστο μέγεθος αρχείου μεταφόρτωσης στα μηνύματα**

Μέγιστο μέγεθος για μεταφορτώσεις αρχείων στο εργαλείο μηνυμάτων (σε Bytes)

*Προεπιλογή: `20971520`*

### `private_messages_about_user`

**Να επιτρέπονται ιδιωτικά μηνύματα μεταξύ εκπαιδευτών σχετικά με έναν εκπαιδευόμενο**

Να επιτρέπεται η ανταλλαγή μηνυμάτων από εκπαιδευτές/προϊσταμένους σχετικά με έναν χρήστη από τη σελίδα παρακολούθησης αυτού του χρήστη.

*Προεπιλογή: `false`*


### `private_messages_about_user_visible_to_user`

**Να επιτρέπεται στους εκπαιδευόμενους να βλέπουν μηνύματα σχετικά με αυτούς μεταξύ εκπαιδευτών**

Εάν είναι ενεργοποιημένη η ανταλλαγή μηνυμάτων σχετικά με έναν χρήστη, αυτή η επιλογή θα επιτρέπει στον αντίστοιχο χρήστη να βλέπει τα μηνύματα. Αυτό γίνεται για συμμόρφωση με κανόνες διαφάνειας στους οποίους ενδέχεται να πρέπει να συμμορφώνεται ο οργανισμός.

*Προεπιλογή: `false`*
