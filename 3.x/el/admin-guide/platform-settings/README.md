# Ρυθμίσεις πλατφόρμας

Το Chamilo διαθέτει ένα εκτεταμένο σύστημα διαμόρφωσης με ρυθμίσεις οργανωμένες σε κατηγορίες. Το πλήρες σύνολο κατηγοριών παρακάτω αντικατοπτρίζει τη σελίδα **Ρυθμίσεις διαμόρφωσης** στον πίνακα διαχείρισης — καθώς και το υποκείμενο `SettingsCurrentFixtures.php` στον πηγαίο κώδικα, που αποτελεί την πηγή αλήθειας για ονόματα μεταβλητών, τίτλους και περιγραφές.

Αποκτήστε πρόσβαση στις ρυθμίσεις πλατφόρμας από τον πίνακα διαχείρισης κάνοντας κλικ στο **Ρυθμίσεις διαμόρφωσης**.

## Πώς λειτουργούν οι ρυθμίσεις

* Οι ρυθμίσεις αποθηκεύονται στη βάση δεδομένων (πίνακας `settings`) και διαχειρίζονται μέσω της διεπαφής ιστού
* Ορισμένες ρυθμίσεις είναι **κλειδωμένες ως προς το URL** σε ρυθμίσεις πολλαπλών URL (η τιμή τους ισχύει σε επίπεδο πλατφόρμας και δεν μπορεί να παρακαμφθεί ανά URL - δείτε τις στήλες `access_url_locked` και `access_url_changeable` στον πίνακα `settings`)· άλλες (οι περισσότερες) μπορούν να παρακαμφθούν ανά URL πρόσβασης
* Οι αλλαγές ισχύουν αμέσως (δεν απαιτείται επανεκκίνηση διακομιστή), αν και η συνεδρία χρήστη σας ενδέχεται να διατηρεί ορισμένες από αυτές στη μνήμη. Εάν οι αλλαγές δεν εμφανίζονται αμέσως, αποσυνδεθείτε και συνδεθείτε ξανά για να εκκαθαρίσετε τη συνεδρία σας.
* Ορισμένες ρυθμίσεις έχουν εξαρτήσεις — η αλλαγή μίας μπορεί να επηρεάσει τη συμπεριφορά άλλων
* Τα ονόματα μεταβλητών που εμφανίζονται σε κάθε σελίδα (π.χ. `2fa_enable`) αντιστοιχούν στη γραμμή στον πίνακα βάσης δεδομένων `settings` (στήλη `variable`) και στα κλειδιά που χρησιμοποιούνται στις παρακάμψεις (`config/settings_overrides.yaml`) όπου ισχύει.

Για περισσότερες πληροφορίες, δείτε τις [Διαμορφώσεις](https://github.com/chamilo/chamilo-lms/wiki/Configurations) στο wiki μας.

## Συμβουλές

* **Τεκμηριώστε τις ρυθμίσεις σας** — Διατηρήστε αρχείο των ρυθμίσεων που δεν είναι οι προεπιλεγμένες και του λόγου για τον οποίο τις αλλάξατε
* **Αλλάζετε ένα πράγμα κάθε φορά** — Κατά την αντιμετώπιση προβλημάτων, τροποποιείτε μία ρύθμιση κάθε φορά ώστε να μπορείτε να εντοπίσετε το αποτέλεσμα
* **Δοκιμάστε σε περιβάλλον σταδιοποίησης** — Για σημαντικές αλλαγές ρυθμίσεων, δοκιμάστε πρώτα σε διακομιστή σταδιοποίησης
