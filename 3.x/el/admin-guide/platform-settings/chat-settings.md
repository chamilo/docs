# Ρυθμίσεις Chat

Συμπεριφορά του εργαλείου **Chat** του μαθήματος.

Αποκτήστε πρόσβαση σε αυτές τις ρυθμίσεις από **Διαχείριση > Ρυθμίσεις παραμετροποίησης > Chat**. Αυτή η κατηγορία περιέχει **5 ρυθμίσεις**, οι οποίες παρατίθενται παρακάτω με τον τίτλο και το σχόλιο που περιλαμβάνονται στα fixtures ρυθμίσεων της πλατφόρμας (`SettingsCurrentFixtures.php`).

> Το όνομα της μεταβλητής στον κώδικα εμφανίζεται με μονοδιάστημα. Χρησιμοποιήστε το όταν γράφετε σενάρια μέσω του API ή όταν χρειάζεται να αλλάξετε αυτές τις ρυθμίσεις σε καθολικό επίπεδο επεξεργάζοντας το [`config/settings_override.yaml`](https://github.com/chamilo/chamilo-lms/wiki/Configurations#configsettings_overridesyaml).

## Ρυθμίσεις

### `allow_global_chat`

**Να επιτρέπεται το καθολικό chat**

Οι χρήστες μπορούν να συνομιλούν μεταξύ τους

*Προεπιλογή: `false`*

### `course_chat_restrict_to_coach`

**Περιορισμός του chat μαθήματος στους εκπαιδευτές**

Να επιτρέπεται στους εκπαιδευόμενους να μιλούν μόνο με τους εκπαιδευτές του μαθήματος (όχι με άλλους εκπαιδευόμενους).

*Προεπιλογή: `false`*

### `hide_chat_video`

**Απόκρυψη της επιλογής βιντεοσυνομιλίας στο καθολικό chat**

Όταν είναι ενεργοποιημένη, η λειτουργικότητα βιντεοσυνομιλίας απενεργοποιείται και δεν είναι διαθέσιμη στο εργαλείο καθολικού chat.

*Προεπιλογή: `true`*

### `save_private_conversations_in_documents`

**Αποθήκευση ιδιωτικών συνομιλιών στα έγγραφα**

Αν είναι ενεργοποιημένη, τα μηνύματα ιδιωτικού chat 1:1 θα αντιγράφονται στα έγγραφα ιστορικού του chat του μαθήματος. Συνιστάται να παραμένει απενεργοποιημένη για λόγους ιδιωτικότητας.

*Προεπιλογή: `false`*

### `show_chat_folder`

**Εμφάνιση του φακέλου ιστορικού των συνομιλιών chat**

Αυτό θα εμφανίζει στον εκπαιδευτή τον φάκελο που περιέχει όλες τις συνεδρίες που έχουν πραγματοποιηθεί στο chat· ο εκπαιδευτής μπορεί να τις κάνει ορατές ή όχι στους εκπαιδευόμενους και να τις χρησιμοποιεί ως πόρο

*Προεπιλογή: `true`*
