# Ρυθμίσεις εμφάνισης

Πώς εμφανίζεται η πλατφόρμα στους χρήστες — διάταξη αρχικής σελίδας, gravatar, μενού, συμπεριφορά επωνυμίας και παρόμοιες οπτικές προτιμήσεις.

Πρόσβαση σε αυτές τις ρυθμίσεις από **Διαχείριση > Ρυθμίσεις διαμόρφωσης > Εμφάνιση**. Αυτή η κατηγορία περιέχει **28 ρυθμίσεις**, που παρατίθενται παρακάτω με τον τίτλο και το σχόλιο που περιλαμβάνονται στα fixtures ρυθμίσεων της πλατφόρμας (`SettingsCurrentFixtures.php`).

> Το όνομα της μεταβλητής στον κώδικα εμφανίζεται με μονοδιάστημα. Χρησιμοποιήστε το όταν γράφετε σενάρια μέσω του API ή όταν χρειάζεται να αλλάξετε αυτές τις ρυθμίσεις σε καθολικό επίπεδο επεξεργάζοντας το [`config/settings_override.yaml`](https://github.com/chamilo/chamilo-lms/wiki/Configurations#configsettings_overridesyaml).

## Ρυθμίσεις

### `accessibility_font_resize`

**Λειτουργία προσβασιμότητας αλλαγής μεγέθους γραμματοσειράς**

Ενεργοποιήστε αυτή την επιλογή για να εμφανίζεται ένα σύνολο επιλογών αλλαγής μεγέθους γραμματοσειράς στην επάνω δεξιά πλευρά της πανεπιστημιούπολής σας. Αυτό θα επιτρέψει σε άτομα με προβλήματα όρασης να διαβάζουν ευκολότερα το περιεχόμενο των μαθημάτων τους.

*Προεπιλογή: `false`*

### `display_categories_on_homepage`

**Εμφάνιση κατηγοριών στην αρχική σελίδα**

Αυτή η επιλογή θα εμφανίσει ή θα αποκρύψει τις κατηγορίες μαθημάτων στην αρχική σελίδα της πύλης

*Προεπιλογή: `false`*

### `enable_help_link`

**Ενεργοποίηση συνδέσμου βοήθειας**

Ο σύνδεσμος Βοήθεια βρίσκεται στο επάνω δεξιό μέρος της οθόνης

*Προεπιλογή: `true`*

### `gravatar_enabled`

**Εικόνες χρηστών Gravatar**

Ενεργοποιήστε αυτή την επιλογή για αναζήτηση στο αποθετήριο Gravatar για εικόνες του τρέχοντος χρήστη, εάν ο χρήστης δεν έχει ορίσει εικόνα τοπικά. Αυτό είναι ιδανικό για αυτόματη συμπλήρωση εικόνων στον ιστότοπό σας, ιδιαίτερα εάν οι χρήστες σας είναι ενεργοί χρήστες του διαδικτύου. Οι εικόνες Gravatar μπορούν να διαμορφωθούν εύκολα, με βάση τη διεύθυνση ηλεκτρονικού ταχυδρομείου ενός χρήστη, στη διεύθυνση http://en.gravatar.com/

*Προεπιλογή: `false`*

### `gravatar_type`

**Τύπος άβαταρ Gravatar**

Εάν η επιλογή Gravatar είναι ενεργοποιημένη και ο χρήστης δεν έχει διαμορφωμένη εικόνα στο Gravatar, αυτή η επιλογή σας επιτρέπει να επιλέξετε τον τύπο άβαταρ που θα δημιουργήσει το Gravatar για κάθε χρήστη. Ελέγξτε το <a href='http://en.gravatar.com/site/implement/images#default-image'>http://en.gravatar.com/site/implement/images#default-image</a> για παραδείγματα τύπων άβαταρ.

*Προεπιλογή: `mm`*

### `hide_complete_name_in_whoisonline`

**Απόκρυψη του πλήρους ονόματος χρήστη στο «ποιος είναι συνδεδεμένος»**

Η σελίδα «ποιος είναι συνδεδεμένος» (εάν είναι ενεργοποιημένη) θα εμφανίζει εικόνα και όνομα για κάθε χρήστη που είναι αυτή τη στιγμή συνδεδεμένος. Ενεργοποιήστε αυτή την επιλογή για να αποκρύψετε τα ονόματα.

*Προεπιλογή: `false`*

### `hide_home_top_when_connected` **v3**

**Απόκρυψη του επάνω περιεχομένου στην αρχική σελίδα όταν ο χρήστης είναι συνδεδεμένος**

Στην αρχική σελίδα της πλατφόρμας, αυτή η επιλογή σας επιτρέπει να αποκρύψετε το μπλοκ εισαγωγής (ώστε να μείνουν μόνο οι ανακοινώσεις, για παράδειγμα), για όλους τους χρήστες που είναι ήδη συνδεδεμένοι. Το γενικό μπλοκ εισαγωγής θα εξακολουθεί να εμφανίζεται στους χρήστες που δεν είναι ήδη συνδεδεμένοι.

*Προεπιλογή: `false`*

### `hide_logout_button`

**Απόκρυψη κουμπιού αποσύνδεσης**

Απόκρυψη του κουμπιού αποσύνδεσης. Αυτό είναι συνήθως ενδιαφέρον μόνο όταν χρησιμοποιείται εξωτερική μέθοδος σύνδεσης/αποσύνδεσης, για παράδειγμα όταν χρησιμοποιείται κάποιας μορφής Single Sign On.

*Προεπιλογή: `false`*

### `hide_main_navigation_menu`

**Απόκρυψη κύριου μενού πλοήγησης**

Όταν χρησιμοποιείτε το Chamilo για συγκεκριμένο σκοπό (όπως μία μαζική διαδικτυακή εξέταση), μπορεί να θέλετε να μειώσετε ακόμη περισσότερο τους περισπασμούς αφαιρώντας το πλευρικό μενού.

*Προεπιλογή: `false`*

### `hide_social_media_links`

**Απόκρυψη συνδέσμων κοινωνικών δικτύων**

Ορισμένες σελίδες σας επιτρέπουν να προωθήσετε την πύλη ή ένα μάθημα στα κοινωνικά δίκτυα. Ενεργοποιήστε αυτή τη ρύθμιση για να αφαιρέσετε τους συνδέσμους.

*Προεπιλογή: `false`*

### `order_user_list_by_official_code`

**Ταξινόμηση χρηστών κατά επίσημο κωδικό**

Χρησιμοποιήστε τον «επίσημο κωδικό» για την ταξινόμηση των περισσότερων λιστών φοιτητών στην πλατφόρμα, αντί του επωνύμου ή του ονόματός τους.

*Προεπιλογή: `false`*

### `pdf_logo_header`

**Λογότυπο κεφαλίδας PDF**

Εάν θα χρησιμοποιείται η εικόνα στο var/themes/[your-theme]/images/pdf_logo_header.png ως λογότυπο κεφαλίδας PDF για όλες τις εξαγωγές PDF (αντί του κανονικού λογότυπου της πύλης)

### `show_admin_toolbar`

**Εμφάνιση γραμμής εργαλείων διαχειριστή**

Εμφανίζει μια καθολική γραμμή εργαλείων στο επάνω μέρος της σελίδας στους καθορισμένους ρόλους χρηστών. Αυτή η γραμμή εργαλείων, πολύ παρόμοια με τις μαύρες γραμμές εργαλείων του Wordpress και της Google, μπορεί πραγματικά να επιταχύνει σύνθετες ενέργειες και να βελτιώσει τον διαθέσιμο χώρο για το μαθησιακό περιεχόμενο, αλλά μπορεί να προκαλέσει σύγχυση σε ορισμένους χρήστες

*Προεπιλογή: `do_not_show`*

### `show_administrator_data` **v3**

**Πληροφορίες διαχειριστή πλατφόρμας στο υποσέλιδο**

Να εμφανίζονται οι πληροφορίες του διαχειριστή της πλατφόρμας στο υποσέλιδο;

*Προεπιλογή: `true`*

### `show_back_link_on_top_of_tree`

**Εμφάνιση συνδέσμων επιστροφής από κατηγορίες/μαθήματα**

Εμφάνιση συνδέσμου για επιστροφή στην ιεραρχία των μαθημάτων. Ένας σύνδεσμος είναι διαθέσιμος ούτως ή άλλως στο κάτω μέρος της λίστας.

*Προεπιλογή: `false`*

### `show_closed_courses`

**Εμφάνιση κλειστών μαθημάτων στη σελίδα σύνδεσης και στην αρχική σελίδα της πύλης;**

Να εμφανίζονται τα κλειστά μαθήματα στη σελίδα σύνδεσης και στην αρχική σελίδα μαθημάτων; Στην αρχική σελίδα της πύλης θα εμφανίζεται ένα εικονίδιο δίπλα στα μαθήματα για γρήγορη εγγραφή σε κάθε μάθημα. Αυτό θα εμφανίζεται μόνο στην αρχική σελίδα της πύλης όταν ο χρήστης είναι συνδεδεμένος και όταν ο χρήστης δεν είναι ακόμη εγγεγραμμένος στην πύλη.

*Προεπιλογή: `false`*

### `show_email_addresses`

**Εμφάνιση διευθύνσεων ηλεκτρονικού ταχυδρομείου**

Εμφάνιση των διευθύνσεων ηλεκτρονικού ταχυδρομείου στους χρήστες

*Προεπιλογή: `false`*

### `show_empty_course_categories`

**Εμφάνιση κενών κατηγοριών μαθημάτων**

Εμφάνιση των κατηγοριών μαθημάτων στην αρχική σελίδα, ακόμη και αν είναι κενές

*Προεπιλογή: `true`*

### `show_hot_courses`

**Εμφάνιση δημοφιλών μαθημάτων**

Η λίστα δημοφιλών μαθημάτων θα προστεθεί στην αρχική σελίδα

*Προεπιλογή: `true`*

### `show_number_of_courses`

**Εμφάνιση αριθμού μαθημάτων**

Εμφάνιση του αριθμού μαθημάτων σε κάθε κατηγορία στις κατηγορίες μαθημάτων στην αρχική σελίδα

*Προεπιλογή: `false`*

### `show_tabs`

**Καταχωρίσεις κύριου μενού**

Επιλέξτε τις καταχωρίσεις που θέλετε να εμφανίζονται στο κύριο μενού

*Προεπιλογή:*
```json
{"menu":{"campus_homepage":true,"my_courses":true,"reporting":true,"platform_administration":true,"my_agenda":true,"social":true,"videoconference":false,"diagnostics":false,"catalogue":true,"session_admin":true,"search":true,"question_manager":false},"topbar":{"topbar_my_certificates":true,"topbar_my_custom_certificate":false,"topbar_skills":true}}
```

### `show_tabs_per_role`

**Καταχωρίσεις κύριου μενού ανά ρόλο**

Ορισμός της ορατότητας των καρτελών κεφαλίδας ανά ρόλο.

*Προεπιλογή: `{}`*

### `show_teacher_data` **v3**

**Εμφάνιση πληροφοριών εκπαιδευτή στο υποσέλιδο**

Να εμφανίζεται η αναφορά του εκπαιδευτή (όνομα και ηλεκτρονικό ταχυδρομείο, εφόσον είναι διαθέσιμα) στο υποσέλιδο;

*Προεπιλογή: `true`*

### `show_tutor_data` **v3**

**Τα δεδομένα του επιβλέποντα της συνεδρίας εμφανίζονται στο υποσέλιδο.**

Να εμφανίζεται η αναφορά του επιβλέποντα της συνεδρίας (όνομα και ηλεκτρονικό ταχυδρομείο, εφόσον είναι διαθέσιμα) στο υποσέλιδο;

*Προεπιλογή: `true`*

### `showonline`

**Ποιος είναι συνδεδεμένος**

Να εμφανίζεται ο αριθμός των ατόμων που είναι συνδεδεμένα;

*Προεπιλογή: `world`*

### `table_default_row`

**Προεπιλεγμένος αριθμός γραμμών πίνακα**

Πόσες γραμμές πρέπει να εμφανίζονται σε όλους τους πίνακες από προεπιλογή.

*Προεπιλογή: `20`*

### `table_row_list`

**Προεπιλεγμένοι αριθμοί σελιδοποίησης που προσφέρονται στους πίνακες**

Ορίστε τις επιλογές που θέλετε να εμφανίζονται στην πλοήγηση γύρω από έναν πίνακα για εμφάνιση λιγότερων ή περισσότερων γραμμών σε μία σελίδα. π.χ. [50, 100, 200, 500].

*Προεπιλογή: `[10,20,50,100]`*

### `time_limit_whosonline`

**Χρονικό όριο στο Ποιος είναι συνδεδεμένος**

Αυτό το χρονικό όριο ορίζει για πόσα λεπτά μετά την τελευταία ενέργειά του ένας χρήστης θα θεωρείται *συνδεδεμένος*

*Προεπιλογή: `30`*
