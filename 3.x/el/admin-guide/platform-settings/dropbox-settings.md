# Ρυθμίσεις Dropbox

Συμπεριφορά του εργαλείου ανταλλαγής αρχείων **Dropbox**.

Αποκτήστε πρόσβαση σε αυτές τις ρυθμίσεις στην ενότητα **Διαχείριση > Ρυθμίσεις διαμόρφωσης > Dropbox**. Αυτή η κατηγορία περιέχει **8 ρυθμίσεις**, οι οποίες παρατίθενται παρακάτω με τον τίτλο και το σχόλιο που περιλαμβάνονται στα fixtures ρυθμίσεων της πλατφόρμας (`SettingsCurrentFixtures.php`).

> Το όνομα της μεταβλητής στον κώδικα εμφανίζεται με monospace. Χρησιμοποιήστε το όταν γράφετε σενάρια μέσω του API ή όταν χρειάζεται να αλλάξετε αυτές τις ρυθμίσεις σε καθολικό επίπεδο επεξεργάζοντας το [`config/settings_override.yaml`](https://github.com/chamilo/chamilo-lms/wiki/Configurations#configsettings_overridesyaml).

## Ρυθμίσεις

### `dropbox_allow_group`

**Dropbox: allow group**

Οι χρήστες μπορούν να στέλνουν αρχεία σε ομάδες

*Προεπιλογή: `true`*

### `dropbox_allow_just_upload`

**Dropbox: Upload to own dropbox space?**

Να επιτρέπεται σε εκπαιδευτές και χρήστες να ανεβάζουν έγγραφα στο dropbox τους χωρίς να στέλνουν τα έγγραφα στον εαυτό τους

*Προεπιλογή: `true`*

### `dropbox_allow_mailing`

**Dropbox: Allow mailing**

Με τη λειτουργία αλληλογραφίας μπορείτε να στείλετε σε κάθε εκπαιδευόμενο ένα προσωπικό έγγραφο

*Προεπιλογή: `false`*

### `dropbox_allow_overwrite`

**Dropbox: Can documents be overwritten**

Μπορεί το αρχικό έγγραφο να αντικατασταθεί όταν ένας χρήστης ή εκπαιδευτής ανεβάζει ένα έγγραφο με το όνομα ενός εγγράφου που υπάρχει ήδη; Αν απαντήσετε ναι, χάνετε τον μηχανισμό εκδόσεων.

*Προεπιλογή: `true`*

### `dropbox_allow_student_to_student`

**Dropbox: Learner <-> Learner**

Να επιτρέπεται στους χρήστες να στέλνουν έγγραφα σε άλλους χρήστες (peer 2 peer). Οι χρήστες ενδέχεται να χρησιμοποιήσουν αυτό και για λιγότερο σχετικά έγγραφα (mp3, λύσεις τεστ, ...). Αν το απενεργοποιήσετε, οι χρήστες μπορούν να στέλνουν έγγραφα μόνο στον εκπαιδευτή.

*Προεπιλογή: `true`*

### `dropbox_hide_course_coach`

**Dropbox: hide course tutor**

Απόκρυψη του εκπαιδευτή συνεδρίας του μαθήματος στο Dropbox όταν ένα έγγραφο αποστέλλεται από τον εκπαιδευτή στους εκπαιδευόμενους

*Προεπιλογή: `false`*

### `dropbox_hide_general_coach`

**Hide general tutor in Dropbox**

Απόκρυψη του ονόματος του γενικού εκπαιδευτή στο εργαλείο Dropbox όταν ο γενικός εκπαιδευτής ανέβασε το αρχείο

*Προεπιλογή: `false`*


### `dropbox_max_filesize`

**Dropbox: Maximum file size of a document**

Πόσο μεγάλο (σε MB) μπορεί να είναι ένα έγγραφο dropbox;

*Προεπιλογή: `100000000`*
