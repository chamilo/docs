# Ρυθμίσεις CAS

Κληρονομημένη διαμόρφωση CAS (Central Authentication Service) που μεταφέρθηκε από το Chamilo 1.x. Δείτε το [CAS](../authentication/cas.md) για την τρέχουσα κατάσταση του authenticator CAS στο Chamilo 3.x.

Πρόσβαση σε αυτές τις ρυθμίσεις από **Διαχείριση > Ρυθμίσεις διαμόρφωσης > CAS**. Αυτή η κατηγορία περιέχει **7 ρυθμίσεις**, που παρατίθενται παρακάτω με τον τίτλο και το σχόλιο που περιλαμβάνονται στα fixtures ρυθμίσεων της πλατφόρμας (`SettingsCurrentFixtures.php`).

> Το όνομα της μεταβλητής στον κώδικα εμφανίζεται με monospace. Χρησιμοποιήστε το όταν γράφετε σενάρια μέσω του API ή όταν χρειάζεται να αλλάξετε αυτές τις ρυθμίσεις σε καθολικό επίπεδο επεξεργάζοντας το [`config/settings_override.yaml`](https://github.com/chamilo/chamilo-lms/wiki/Configurations#configsettings_overridesyaml).

## Ρυθμίσεις

### `cas_activate`

**Ενεργοποίηση πιστοποίησης CAS**

Η ενεργοποίηση της πιστοποίησης CAS θα επιτρέψει στους χρήστες να πιστοποιούνται με τα διαπιστευτήρια CAS τους.<br/>Μεταβείτε στο <a href='settings.php?category=CAS'>Plugin</a> για να προσθέσετε ένα διαμορφώσιμο κουμπί «CAS Login» για την πανεπιστημιούπολη Chamilo σας. Εναλλακτικά μπορείτε να επιβάλετε την πιστοποίηση CAS ορίζοντας cas[force_redirect] στο app/config/auth.conf.php.

### `cas_add_user_activate`

**Ενεργοποίηση προσθήκης χρηστών CAS**

Ενεργοποίηση προσθήκης χρηστών CAS. Για τη δημιουργία του λογαριασμού χρήστη από τον κατάλογο LDAP, οι πίνακες extldap_config και extldap_user_correspondance πρέπει να συμπληρωθούν στο app/config/auth.conf.php

### `cas_port`

**Θύρα κύριου διακομιστή CAS**

Η θύρα στην οποία γίνεται σύνδεση με τον κύριο διακομιστή CAS

### `cas_protocol`

**Πρωτόκολλο κύριου διακομιστή CAS**

Το πρωτόκολλο με το οποίο συνδεόμαστε στον διακομιστή CAS

### `cas_server`

**Κύριος διακομιστής CAS**

Αυτός είναι ο κύριος διακομιστής CAS που θα χρησιμοποιείται για την πιστοποίηση (διεύθυνση IP ή όνομα κεντρικού υπολογιστή)

### `cas_server_uri`

**URI κύριου διακομιστή CAS**

Η διαδρομή προς την υπηρεσία CAS

### `update_user_info_cas_with_ldap`

**Ενημέρωση πληροφοριών λογαριασμού χρήστη πιστοποιημένου μέσω CAS από LDAP**

Διασφαλίζει ότι το όνομα, το επώνυμο και η διεύθυνση ηλεκτρονικού ταχυδρομείου του χρήστη είναι τα ίδια με τις τρέχουσες τιμές στον κατάλογο LDAP
