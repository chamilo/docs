# Ρυθμίσεις παρακολούθησης

Προεπιλογές σχετικές με την παρακολούθηση — τι καταγράφεται, ποιες αναφορές εμφανίζονται, κανόνες υπολογισμού χρόνου.

Πρόσβαση σε αυτές τις ρυθμίσεις από **Διαχείριση > Ρυθμίσεις διαμόρφωσης > Παρακολούθηση**. Αυτή η κατηγορία περιέχει **10 ρυθμίσεις**, οι οποίες παρατίθενται παρακάτω με τον τίτλο και το σχόλιο που περιλαμβάνονται στα fixtures ρυθμίσεων της πλατφόρμας (`SettingsCurrentFixtures.php`).

> Το όνομα της μεταβλητής στον κώδικα εμφανίζεται σε monospace. Χρησιμοποιήστε το όταν γράφετε σενάρια μέσω του API ή όταν χρειάζεται να αλλάξετε αυτές τις ρυθμίσεις σε καθολικό επίπεδο επεξεργάζοντας το [`config/settings_override.yaml`](https://github.com/chamilo/chamilo-lms/wiki/Configurations#configsettings_overridesyaml).

## Ρυθμίσεις

### `block_my_progress_page`

**Αποτροπή πρόσβασης στην «Η πρόοδός μου»**

Σε συγκεκριμένες υλοποιήσεις όπως οι διαδικτυακές εξετάσεις, ενδέχεται να θέλετε να αποτρέψετε την πρόσβαση των χρηστών στη σελίδα «Η πρόοδός μου».

*Προεπιλογή: `false`*

### `footer_extra_content`

**Επιπλέον περιεχόμενο στο υποσέλιδο**

Μπορείτε να προσθέσετε κώδικα HTML όπως meta tags

### `header_extra_content`

**Επιπλέον περιεχόμενο στην κεφαλίδα**

Μπορείτε να προσθέσετε κώδικα HTML όπως meta tags

### `meta_description`

**Meta description**

Αυτό θα εμφανίσει ένα meta OpenGraph Description (og:description) στις κεφαλίδες του ιστότοπού σας

### `meta_image_path`

**Διαδρομή εικόνας meta**

Αυτή η διαδρομή εικόνας Meta είναι η διαδρομή προς ένα αρχείο μέσα στον κατάλογο του Chamilo (π.χ. home/image.png) που θα πρέπει να εμφανίζεται σε μια κάρτα Twitter ή σε μια κάρτα OpenGraph όταν εμφανίζεται σύνδεσμος προς το LMS σας. Το Twitter συνιστά εικόνα 120 x 120 pixel, η οποία ενδέχεται μερικές φορές να περικόπτεται σε 120x90.

### `meta_title`

**Τίτλος meta OpenGraph**

Αυτό θα εμφανίσει ένα meta OpenGraph Title (og:title) στις κεφαλίδες του ιστότοπού σας

### `meta_twitter_creator`

**Λογαριασμός Twitter Creator**

Το Twitter Creator είναι ένας λογαριασμός Twitter (π.χ. @ywarnier) που αντιπροσωπεύει το *πρόσωπο* που δημιούργησε τον ιστότοπο. Αυτό το πεδίο είναι προαιρετικό.

### `meta_twitter_site`

**Λογαριασμός Twitter Site**

Το Twitter site είναι ένας λογαριασμός Twitter (π.χ. @chamilo_news) που σχετίζεται με τον ιστότοπό σας. Συνήθως είναι πιο προσωρινός λογαριασμός από τον λογαριασμό Twitter creator, ή αντιπροσωπεύει μια οντότητα (αντί για πρόσωπο). Αυτό το πεδίο είναι υποχρεωτικό αν θέλετε να εμφανίζονται τα πεδία meta της κάρτας Twitter.

### `my_progress_course_tools_order`

**Σειρά εργαλείων στη σελίδα «Η πρόοδός μου»**

Αλλάξτε τη σειρά των εργαλείων που εμφανίζονται στη σελίδα «Η πρόοδός μου» για τους εκπαιδευόμενους. Οι επιλογές περιλαμβάνουν 'quizzes', 'learning_paths' και 'skills'.

### `tracking_skip_generic_data`

**Παράλειψη γενικών δεδομένων στη σελίδα αυτοπαρακολούθησης του εκπαιδευόμενου**

Αν η σελίδα «Η πρόοδός μου» αργεί πολύ να φορτώσει, ενδέχεται να θέλετε να αφαιρέσετε την επεξεργασία γενικών στατιστικών για τον χρήστη. Σε αυτή την περίπτωση ενεργοποιήστε αυτή τη ρύθμιση.

*Προεπιλογή: `false`*
