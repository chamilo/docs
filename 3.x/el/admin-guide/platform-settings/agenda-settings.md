# Ρυθμίσεις Ημερολογίου

Προεπιλογές και συμπεριφορά του εργαλείου **Agenda** (ημερολόγιο / εκδηλώσεις).

Προσπελάστε αυτές τις ρυθμίσεις στην ενότητα **Διαχείριση > Ρυθμίσεις διαμόρφωσης > Agenda**. Αυτή η κατηγορία περιέχει **11 ρυθμίσεις**, οι οποίες παρατίθενται παρακάτω με τον τίτλο και το σχόλιο που περιλαμβάνονται στα fixtures ρυθμίσεων της πλατφόρμας (`SettingsCurrentFixtures.php`).

> Το όνομα της μεταβλητής στον κώδικα εμφανίζεται με μονοδιάστατη γραμματοσειρά. Χρησιμοποιήστε το όταν γράφετε σενάρια μέσω του API ή όταν χρειάζεται να αλλάξετε αυτές τις ρυθμίσεις σε καθολικό επίπεδο επεξεργάζοντας το [`config/settings_override.yaml`](https://github.com/chamilo/chamilo-lms/wiki/Configurations#configsettings_overridesyaml).

## Ρυθμίσεις

### `agenda_colors`

**Χρώματα ημερολογίου**

Ορίστε χρώματα σε κωδικό HTML για κάθε τύπο εκδήλωσης ώστε να αλλάζει το χρώμα κατά την εμφάνιση της εκδήλωσης.

### `agenda_legend`

**Υπομνήματα χρωμάτων ημερολογίου**

Προσθέστε ένα σύντομο κείμενο ως υπόμνημα που περιγράφει τα χρώματα που χρησιμοποιούνται για τις εκδηλώσεις.

### `agenda_on_hover_info`

**Πληροφορίες ημερολογίου κατά την αιώρηση**

Προσαρμόστε το ημερολόγιο κατά την αιώρηση του δρομέα. Εμφάνιση σχολίου και/ή περιγραφής του ημερολογίου.

### `agenda_reminders_sender_id`

**ID του χρήστη που αποστέλλει επίσημα τις υπενθυμίσεις ημερολογίου**

Ορίζει ποιος χρήστης εμφανίζεται ως αποστολέας των μηνυμάτων ηλεκτρονικού ταχυδρομείου υπενθύμισης ημερολογίου.

*Προεπιλογή: `0`*

### `allow_agenda_edit_for_hrm`

**Να επιτρέπεται στον ρόλο HRM να επεξεργάζεται ή να διαγράφει εκδηλώσεις ημερολογίου**

Αυτό δίνει στον HRM λίγο περισσότερη εξουσία, επιτρέποντάς του να επεξεργάζεται/διαγράφει εκδηλώσεις ημερολογίου στο course-session.

*Προεπιλογή: `false`*

### `allow_careers_in_global_agenda`

**Σύνδεση καθολικών εκδηλώσεων ημερολογίου με καριέρες και προαγωγές**

Όταν είναι ενεργοποιημένο, οι καθολικές εκδηλώσεις ημερολογίου μπορούν να συσχετιστούν με καριέρες και προαγωγές, επιτρέποντας στοχευμένο προγραμματισμό.

*Προεπιλογή: `false`*

### `allow_personal_agenda`

**Προσωπικό ημερολόγιο**

Μπορεί ο εκπαιδευόμενος να προσθέτει προσωπικές εκδηλώσεις στο Ημερολόγιο;

*Προεπιλογή: `true`*

### `default_calendar_view`

**Προεπιλεγμένη λειτουργία εμφάνισης ημερολογίου**

Ορίστε την τιμή σε dayGridMonth, basicWeek, agendaWeek ή agendaDay για να αλλάξετε την προεπιλεγμένη προβολή του ημερολογίου.

*Προεπιλογή: `month`*

### `fullcalendar_settings`

**Προσαρμογή ημερολογίου**

Επιπλέον ρυθμίσεις για το ημερολόγιο, που σας επιτρέπουν να διαμορφώσετε τη συγκεκριμένη βιβλιοθήκη ημερολογίου που χρησιμοποιούμε.

### `personal_agenda_show_all_session_events`

**Εμφάνιση όλων των εκδηλώσεων ημερολογίου στο προσωπικό ημερολόγιο**

Να μην αποκρύπτονται εκδηλώσεις από ληγμένες συνεδρίες.

*Προεπιλογή: `false`*

### `personal_calendar_show_sessions_occupation`

**Εμφάνιση απασχολήσεων συνεδριών στο προσωπικό ημερολόγιο**

Όταν είναι ενεργοποιημένο, τα προγράμματα και οι απασχολήσεις των συνεδριών εμφανίζονται στα προσωπικά ημερολόγια των χρηστών.

*Προεπιλογή: `false`*
