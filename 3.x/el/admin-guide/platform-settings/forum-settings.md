# Ρυθμίσεις φόρουμ

Συμπεριφορά του εργαλείου **Forums** του μαθήματος.

Πρόσβαση σε αυτές τις ρυθμίσεις από **Διαχείριση > Ρυθμίσεις διαμόρφωσης > Forums**. Αυτή η κατηγορία περιέχει **9 ρυθμίσεις**, οι οποίες παρατίθενται παρακάτω με τον τίτλο και το σχόλιο που περιλαμβάνονται στα fixtures ρυθμίσεων της πλατφόρμας (`SettingsCurrentFixtures.php`).

> Το όνομα της μεταβλητής στον κώδικα εμφανίζεται με μονοδιάστημα. Χρησιμοποιήστε το κατά τη συγγραφή σεναρίων μέσω του API ή όταν χρειάζεται να αλλάξετε αυτές τις ρυθμίσεις σε καθολικό επίπεδο επεξεργάζοντας το [`config/settings_override.yaml`](https://github.com/chamilo/chamilo-lms/wiki/Configurations#configsettings_overridesyaml).

## Ρυθμίσεις

### `allow_forum_category_language_filter`

**Φίλτρο γλώσσας κατηγοριών φόρουμ**

Προσθέτει φίλτρο γλώσσας στην προβολή του φόρουμ ώστε να εμφανίζονται μόνο κατηγορίες που έχουν ρυθμιστεί σε συγκεκριμένη γλώσσα. Απαιτεί τη χρήση του επιπλέον πεδίου 'language' στην οντότητα 'forum_category'.

*Προεπιλογή: `false`*

### `allow_forum_post_revisions`

**Αναθεώρηση ανάρτησης φόρουμ**

Ενεργοποιήστε αυτή την επιλογή για να επιτρέπεται η αίτηση αναθεώρησης ή μετάφρασης μιας ανάρτησης σε φόρουμ. Με εκτεταμένη διαμόρφωση, μπορεί να χρησιμοποιηθεί για συνεργασία με άλλους χρήστες σε φόρουμ εκμάθησης γλωσσών.

*Προεπιλογή: `false`*

### `community_managers_user_list`

**Λίστα διαχειριστών κοινότητας**

Παρέχετε έναν πίνακα αναγνωριστικών χρηστών που θα θεωρούνται διαχειριστές κοινότητας στο ειδικό μάθημα που έχει οριστεί ως καθολικό φόρουμ. Οι διαχειριστές κοινότητας έχουν πρόσθετα προνόμια στο καθολικό φόρουμ.

### `default_forum_view`

**Προεπιλεγμένη προβολή φόρουμ**

Ποια πρέπει να είναι η προεπιλεγμένη επιλογή κατά τη δημιουργία νέου φόρουμ. Κάθε εκπαιδευτής μπορεί ωστόσο να επιλέξει διαφορετική προβολή για κάθε μεμονωμένο φόρουμ

*Προεπιλογή: `flat`*

### `display_groups_forum_in_general_tool`

**Εμφάνιση φόρουμ ομάδων στο γενικό φόρουμ**

Εμφάνιση των φόρουμ ομάδων στο εργαλείο φόρουμ σε επίπεδο μαθήματος. Αυτή η επιλογή είναι ενεργοποιημένη από προεπιλογή (σε αυτή την περίπτωση, οι μεμονωμένες ορατότητες των φόρουμ ομάδων εξακολουθούν να λειτουργούν ως πρόσθετο κριτήριο). Αν απενεργοποιηθεί, τα φόρουμ ομάδων θα είναι ορατά μόνο μέσω του εργαλείου ομάδων, είτε είναι δημόσια είτε όχι.

*Προεπιλογή: `true`*

### `forum_fold_categories`

**Αναδίπλωση κατηγοριών φόρουμ**

Οπτικό εφέ για ενεργοποίηση αναδίπλωσης/ξεδιπλώματος των κατηγοριών φόρουμ.

*Προεπιλογή: `false`*

### `global_forums_course_id`

**Χρήση μαθήματος ως καθολικό φόρουμ**

Ορίστε το αναγνωριστικό μαθήματος (αριθμητικό) ενός μαθήματος που προορίζεται για χρήση ως καθολικό φόρουμ. Αυτό αντικαθιστά τον σύνδεσμο «Κοινωνικές ομάδες» στο κοινωνικό δίκτυο με σύνδεσμο προς το φόρουμ αυτού του μαθήματος.

*Προεπιλογή: `0`*

### `hide_forum_post_revision_language`

**Απόκρυψη γλώσσας αναθεώρησης ανάρτησης φόρουμ**

Απόκρυψη της δυνατότητας αντιστοίχισης γλώσσας σε αναθεώρηση ανάρτησης φόρουμ.

*Προεπιλογή: `false`*

### `subscribe_users_to_forum_notifications_also_in_base_course`

**Ειδοποιήσεις φόρουμ και από το βασικό μάθημα**

Ενεργοποιήστε αυτή την επιλογή για να ενεργοποιηθούν ειδοποιήσεις που προέρχονται από το φόρουμ του βασικού μαθήματος, ακόμη και αν το μάθημα παρακολουθείται μέσω συνεδρίας.

*Προεπιλογή: `false`*
