# Ρυθμίσεις συνεδριών

Προεπιλογές και συμπεριφορά για τις **Συνεδρίες** — κύκλος ζωής συνεδρίας, παράθυρα πρόσβασης καθηγητών, ορατότητα μαθημάτων εντός συνεδρίας και συναφή.

Πρόσβαση σε αυτές τις ρυθμίσεις από **Διαχείριση > Ρυθμίσεις διαμόρφωσης > Συνεδρίες**. Αυτή η κατηγορία περιέχει **68 ρυθμίσεις**, οι οποίες παρατίθενται παρακάτω με τον τίτλο και το σχόλιο που περιλαμβάνονται στα fixtures ρυθμίσεων της πλατφόρμας (`SettingsCurrentFixtures.php`).

> Το όνομα της μεταβλητής στον κώδικα εμφανίζεται σε monospace. Χρησιμοποιήστε το κατά τη συγγραφή σεναρίων μέσω του API ή όταν χρειάζεται να αλλάξετε αυτές τις ρυθμίσεις σε καθολικό επίπεδο επεξεργάζοντας το [`config/settings_override.yaml`](https://github.com/chamilo/chamilo-lms/wiki/Configurations#configsettings_overridesyaml).

## Ρυθμίσεις

### `add_users_by_coach`

**Να επιτρέπεται στους καθηγητές να εγγράφουν χρήστες**

Οι καθηγητές μπορούν να δημιουργούν χρήστες στην πλατφόρμα και να εγγράφουν χρήστες σε συνεδρία.

*Προεπιλογή: `false`*

### `allow_career_diagram`

**Ενεργοποίηση διαγραμμάτων σταδιοδρομίας**

Τα διαγράμματα σταδιοδρομίας επιτρέπουν την εμφάνιση διαγραμμάτων σταδιοδρομιών, δεξιοτήτων και μαθημάτων.

*Προεπιλογή: `false`*


### `allow_career_users`

**Ενεργοποίηση διαγραμμάτων σταδιοδρομίας για χρήστες**

Εάν τα διαγράμματα σταδιοδρομίας είναι ενεργοποιημένα, οι χρήστες μπορούν να τα βλέπουν (και μόνο τα διαγράμματα που αντιστοιχούν στις σπουδές τους) μόνο αν ενεργοποιήσετε αυτή την επιλογή.

*Προεπιλογή: `false`*

### `allow_coach_to_edit_course_session`

**Να επιτρέπεται στους καθηγητές να επεξεργάζονται εντός των συνεδριών μαθημάτων**

Να επιτρέπεται στους καθηγητές να επεξεργάζονται εντός των συνεδριών μαθημάτων

*Προεπιλογή: `true`*

### `allow_delete_user_for_session_admin`

**Οι διαχειριστές συνεδριών μπορούν να διαγράφουν χρήστες**

Οι διαχειριστές συνεδριών μπορούν να αφαιρούν χρήστες από την πλατφόρμα κατά τη διαχείριση της/των συνεδρίας/συνεδριών τους.

*Προεπιλογή: `false`*


### `allow_disable_user_for_session_admin`

**Οι διαχειριστές συνεδριών μπορούν να απενεργοποιούν χρήστες**

Οι διαχειριστές συνεδριών μπορούν να απενεργοποιούν λογαριασμούς χρηστών ώστε να αποτρέπεται η σύνδεση, διατηρώντας παράλληλα τα αρχεία εγγραφής στη/στις συνεδρία/συνεδρίες τους.

*Προεπιλογή: `false`*


### `allow_edit_tool_visibility_in_session`

**Να επιτρέπεται η επεξεργασία ορατότητας εργαλείων στις συνεδρίες**

Όταν χρησιμοποιούνται συνεδρίες, η προεπιλεγμένη συμπεριφορά είναι να χρησιμοποιείται η ορατότητα εργαλείων που έχει οριστεί στο βασικό μάθημα. Αυτή η ρύθμιση το αλλάζει ώστε να επιτρέπεται στους καθηγητές στα μαθήματα συνεδρίας να προσαρμόζουν τις ορατότητες εργαλείων στις ανάγκες τους.

*Προεπιλογή: `true`*

### `allow_redirect_to_session_after_inscription_about`

**Ανακατεύθυνση στη συνεδρία μετά την εγγραφή από τη σελίδα «Σχετικά» της συνεδρίας**

Αυτόματη ανακατεύθυνση των νέων χρηστών στη σελίδα της συνεδρίας τους αφού ολοκληρώσουν την εγγραφή μέσω της σελίδας «Σχετικά» μιας συνεδρίας.

*Προεπιλογή: `false`*


### `allow_search_diagnostic`

**Ενεργοποίηση διάγνωσης αναζήτησης συνεδριών**

Να επιτρέπεται στους καθηγητές να λαμβάνουν μια διάγνωση που θα τους επιτρέπει να αναζητούν τις καταλληλότερες συνεδρίες για τους εκπαιδευόμενους.

*Προεπιλογή: `false`*


### `allow_session_admin_extra_access`

**Ο διαχειριστής συνεδρίας μπορεί να έχει πρόσβαση σε μαζική εισαγωγή, ενημέρωση και εξαγωγή χρηστών**

Οι διαχειριστές συνεδριών μπορούν να έχουν πρόσβαση στη λειτουργικότητα μαζικής εισαγωγής, ενημέρωσης και εξαγωγής χρηστών, επιπλέον των τυπικών δικαιωμάτων τους.

*Προεπιλογή: `false`*


### `allow_session_admin_login_as_teacher`

**Οι διαχειριστές συνεδριών μπορούν να «συνδέονται ως» εκπαιδευτές**

Οι διαχειριστές συνεδριών μπορούν να υποδύονται λογαριασμούς εκπαιδευτών για προεπισκόπηση του περιεχομένου του μαθήματος και της εμπειρίας του εκπαιδευόμενου εντός της/των συνεδρίας/συνεδριών τους.

*Προεπιλογή: `false`*


### `allow_session_admin_read_careers`

**Οι διαχειριστές συνεδριών μπορούν να βλέπουν σταδιοδρομίες**

[inferred] Οι διαχειριστές συνεδριών μπορούν να βλέπουν και να έχουν πρόσβαση σε διαδρομές σταδιοδρομίας και ροές εργασίας προαγωγής που συνδέονται με τις συνεδρίες που διαχειρίζονται.

*Προεπιλογή: `false`*


### `allow_session_admins_to_manage_all_sessions`

**Να επιτρέπεται στους διαχειριστές συνεδριών να βλέπουν όλες τις συνεδρίες**

Όταν αυτή η επιλογή δεν είναι ενεργοποιημένη (προεπιλογή), οι διαχειριστές συνεδριών μπορούν να βλέπουν μόνο τις συνεδρίες που έχουν δημιουργήσει. Αυτό προκαλεί σύγχυση σε ένα ανοιχτό περιβάλλον όπου οι διαχειριστές συνεδριών ενδέχεται να χρειάζεται να μοιράζονται χρόνο υποστήριξης μεταξύ δύο συνεδριών.

*Προεπιλογή: `false`*

### `allow_session_course_copy_for_teachers`

**Να επιτρέπεται αντιγραφή από συνεδρία σε συνεδρία για εκπαιδευτές**

Ενεργοποιήστε αυτή την επιλογή ώστε οι εκπαιδευτές να αντιγράφουν το περιεχόμενό τους από ένα μάθημα σε μια συνεδρία σε ένα μάθημα σε άλλη συνεδρία. Από προεπιλογή, αυτή η επιλογή είναι διαθέσιμη μόνο στους διαχειριστές της πλατφόρμας.

*Προεπιλογή: `false`*

### `allow_teachers_to_create_sessions`

**Να επιτρέπεται στους εκπαιδευτές να δημιουργούν συνεδρίες**

Οι εκπαιδευτές μπορούν να δημιουργούν, να επεξεργάζονται και να διαγράφουν τις δικές τους συνεδρίες.

*Προεπιλογή: `false`*

### `allow_tutors_to_assign_students_to_session`

**Οι καθηγητές μπορούν να αναθέτουν εκπαιδευόμενους σε συνεδρίες**

Όταν είναι ενεργοποιημένη, οι καθηγητές μαθημάτων στις συνεδρίες μπορούν να εγγράφουν νέους χρήστες στη συνεδρία τους. Διαφορετικά αυτή η επιλογή είναι διαθέσιμη μόνο σε διαχειριστές και διαχειριστές συνεδριών.

*Προεπιλογή: `false`*

### `allow_user_session_collabsable`

**Να επιτρέπεται στον χρήστη να συμπτύσσει συνεδρίες στο Οι συνεδρίες μου**

Οι χρήστες μπορούν να συμπτύσσουν κάρτες ή ομάδες συνεδριών στη σελίδα Οι συνεδρίες μου ώστε να μειώνεται η οπτική ακαταστασία και να βελτιώνεται η πλοήγηση.

*Προεπιλογή: `false`*


### `assignment_base_course_teacher_access_to_all_session`

**Ο εκπαιδευτής του βασικού μαθήματος μπορεί να βλέπει εργασίες από όλες τις συνεδρίες**

Εμφάνιση όλων των δημοσιεύσεων εκπαιδευομένων (από το βασικό μάθημα και από όλες τις συνεδρίες) στη σελίδα work/pending.php του βασικού μαθήματος.

*Προεπιλογή: `false`*

### `career_diagram_disclaimer`

**Εμφάνιση αποποίησης ευθύνης κάτω από το διάγραμμα σταδιοδρομίας**

Προσθέτει μια αποποίηση ευθύνης κάτω από το διάγραμμα σταδιοδρομίας. Πρέπει να υπάρχει μια γλωσσική μεταβλητή με όνομα 'Career diagram disclaimer' στην υπογλώσσα σας.

*Προεπιλογή: `false`*

### `career_diagram_legend`

**Εμφάνιση υπομνήματος κάτω από το διάγραμμα σταδιοδρομίας**

Προσθέτει ένα υπόμνημα σταδιοδρομίας κάτω από το διάγραμμα σταδιοδρομίας. Πρέπει να υπάρχει μια γλωσσική μεταβλητή με όνομα 'Career diagram legend' στην υπογλώσσα σας.

*Προεπιλογή: `false`*

### `courses_list_session_title_link`

**Τύπος συνδέσμου για τον τίτλο συνεδρίας**

Στη σελίδα μαθημάτων/συνεδριών, ο τίτλος συνεδρίας μπορεί να είναι ένα από τα εξής: 0 = χωρίς σύνδεσμο (απόκρυψη τίτλου συνεδρίας) · 1 = σύνδεσμος τίτλου σε ειδική σελίδα συνεδρίας · 2 = σύνδεσμος στο μάθημα αν υπάρχει μόνο ένα μάθημα · 3 = ο τίτλος συνεδρίας καθιστά τη λίστα μαθημάτων αναδιπλούμενη · 4 = χωρίς σύνδεσμο (εμφάνιση τίτλου συνεδρίας).

*Προεπιλογή: `1`*

### `default_session_list_view`

**Προεπιλεγμένη προβολή λίστας συνεδριών**

Επιλέξτε την προεπιλεγμένη καρτέλα που θέλετε να βλέπετε κατά το άνοιγμα της λίστας συνεδριών ως διαχειριστής.

*Προεπιλογή: `all`*


### `drh_can_access_all_session_content`

**Πρόσβαση διευθυντών ανθρώπινου δυναμικού σε όλο το περιεχόμενο συνεδρίας**

Αν ενεργοποιηθεί, οι διευθυντές ανθρώπινου δυναμικού θα έχουν πρόσβαση σε όλο το περιεχόμενο και τους χρήστες των συνεδριών που παρακολουθούν.

*Προεπιλογή: `true`*

### `duplicate_specific_session_content_on_session_copy`

**Ενεργοποίηση αντιγραφής περιεχομένου ειδικού για συνεδρία σε άλλη συνεδρία**

Επιτρέπει τον διπλασιασμό πόρων που δημιουργήθηκαν στη συνεδρία κατά τον διπλασιασμό της συνεδρίας.

*Προεπιλογή: `false`*


### `email_template_subscription_to_session_confirmation_lost_password`

**Προσθήκη συνδέσμου επαναφοράς κωδικού στην ειδοποίηση e-mail εγγραφής σε συνεδρία**

Συμπεριλαμβάνει σύνδεσμο επαναφοράς κωδικού στα μηνύματα επιβεβαίωσης εγγραφής που αποστέλλονται στους χρήστες όταν εγγράφονται σε συνεδρία.

*Προεπιλογή: `false`*


### `email_template_subscription_to_session_confirmation_username`

**Προσθήκη ονόματος χρήστη στην ειδοποίηση e-mail εγγραφής σε συνεδρία**

Συμπεριλαμβάνει το όνομα χρήστη στα μηνύματα επιβεβαίωσης εγγραφής που αποστέλλονται όταν εγγράφονται σε συνεδρία.

*Προεπιλογή: `false`*


### `enable_auto_reinscription`

**Ενεργοποίηση αυτόματης επανεγγραφής**

Ενεργοποιεί ή απενεργοποιεί την αυτόματη επανεγγραφή όταν λήγει η ισχύς του μαθήματος. Πρέπει επίσης να ενεργοποιηθεί η σχετική εργασία cron.

*Προεπιλογή: `false`*


### `enable_session_replication`

**Ενεργοποίηση αναπαραγωγής συνεδρίας**

Ενεργοποιεί ή απενεργοποιεί την αυτόματη αναπαραγωγή συνεδρίας. Πρέπει επίσης να ενεργοποιηθεί η σχετική εργασία cron.

*Προεπιλογή: `false`*


### `extend_rights_for_coach`

**Επέκταση δικαιωμάτων για τους tutors**

Ενεργοποιήστε αυτή την επιλογή για να δώσετε στους tutors τα ίδια δικαιώματα με τους εκπαιδευτές στα εργαλεία συγγραφής

*Προεπιλογή: `false`*

### `hide_courses_in_sessions`

**Απόκρυψη λίστας μαθημάτων στις συνεδρίες**

Κατά την εμφάνιση του μπλοκ συνεδρίας στη σελίδα μαθημάτων σας, αποκρύπτει τη λίστα μαθημάτων εντός αυτής της συνεδρίας (τα εμφανίζει μόνο στην ειδική οθόνη συνεδρίας).

*Προεπιλογή: `false`*

### `hide_reporting_session_list`

**Απόκρυψη λίστας συνεδριών στο εργαλείο αναφορών**

Οι συνεδρίες που περιλαμβάνουν το μάθημα εμφανίζονται στο εργαλείο αναφορών εντός του ίδιου του μαθήματος, γεγονός που μπορεί να προσθέσει σημαντικό βάρος αν το ίδιο μάθημα χρησιμοποιείται σε εκατοντάδες συνεδρίες. Αυτή η επιλογή αφαιρεί αυτή τη λίστα.

*Προεπιλογή: `false`*


### `hide_search_form_in_session_list`

**Απόκρυψη φόρμας αναζήτησης στη λίστα συνεδριών**

Αφαιρεί το πεδίο εισαγωγής αναζήτησης από την προβολή λίστας συνεδριών στη διεπαφή διαχείρισης.

*Προεπιλογή: `false`*


### `hide_session_graph_in_my_progress`

**Απόκρυψη γραφήματος συνεδρίας στην Πρόοδό μου**

Αποκρύπτει γραφήματα και οπτικοποιήσεις προόδου συνεδρίας από τη σελίδα Πρόοδός μου στους πίνακες ελέγχου εκπαιδευομένων.

*Προεπιλογή: `false`*


### `hide_tab_list`

**Απόκρυψη καρτελών στη σελίδα συνεδρίας**

Αφαιρεί τις καρτέλες πλοήγησης από τη σελίδα λεπτομερειών συνεδρίας για απλοποίηση της διεπαφής.

### `limit_session_admin_list_users`

**Απαγόρευση πρόσβασης των διαχειριστών συνεδρίας στη λίστα χρηστών**

Εμποδίζει τους διαχειριστές συνεδρίας να έχουν πρόσβαση στην καθολική λίστα χρηστών στη διεπαφή διαχείρισης.

*Προεπιλογή: `false`*


### `limit_session_admin_role`

**Περιορισμός δικαιωμάτων διαχειριστών συνεδρίας**

Αν ενεργοποιηθεί, οι διαχειριστές συνεδρίας θα βλέπουν μόνο το μπλοκ Χρήστης με την επιλογή «Προσθήκη χρήστη» και το μπλοκ Συνεδρίες με την επιλογή «Λίστα συνεδριών».

*Προεπιλογή: `false`*

### `my_courses_session_order`

**Αλλαγή της προεπιλεγμένης ταξινόμησης συνεδρίας στα Μαθήματά μου**

Από προεπιλογή, οι συνεδρίες ταξινομούνται κατά ημερομηνία έναρξης. Αλλάξτε το παρέχοντας έναν πίνακα τύπου ['field' => 'end_date', 'order' => 'desc'].

### `my_courses_view_by_session`

**Προβολή των μαθημάτων μου ανά συνεδρία**

Ενεργοποιεί μια πρόσθετη σελίδα «Τα μαθήματά μου» όπου οι συνεδρίες εμφανίζονται ως μέρος των μαθημάτων, αντί για το αντίστροφο.

*Προεπιλογή: `false`*

### `my_progress_session_show_all_courses`

**Πρόοδός μου: εμφάνιση λεπτομερειών μαθήματος στη συνεδρία**

Εμφανίζει όλες τις λεπτομέρειες κάθε μαθήματος στη συνεδρία κατά το κλικ στις λεπτομέρειες συνεδρίας.

*Προεπιλογή: `false`*


### `prevent_session_admins_to_manage_all_users`

**Αποτροπή διαχείρισης όλων των χρηστών από τους διαχειριστές συνεδρίας**

Με την ενεργοποίηση αυτής της επιλογής, οι διαχειριστές συνεδρίας θα μπορούν να βλέπουν, στη σελίδα διαχείρισης, μόνο τους χρήστες που δημιούργησαν οι ίδιοι.

*Προεπιλογή: `false`*

### `remove_session_url`

**Απόκρυψη συνδέσμου προς τη σελίδα συνεδρίας**

Απόκρυψη του συνδέσμου προς τη σελίδα συνεδρίας από τη λίστα συνεδριών.

*Προεπιλογή: `false`*


### `session_admins_access_all_content`

**Οι διαχειριστές συνεδρίας μπορούν να έχουν πρόσβαση σε όλο το περιεχόμενο μαθημάτων**

Οι διαχειριστές συνεδρίας μπορούν να προβάλουν όλο το περιεχόμενο μαθημάτων εντός των συνεδριών τους, συμπεριλαμβανομένων περιορισμένων ή αρχειοθετημένων υλικών.

### `session_admins_edit_courses_content`

**Οι διαχειριστές συνεδρίας μπορούν να επεξεργάζονται το περιεχόμενο μαθημάτων**

Οι διαχειριστές συνεδρίας μπορούν να τροποποιούν το περιεχόμενο μαθημάτων (έγγραφα, ασκήσεις, εργαλεία) σε μαθήματα που έχουν ανατεθεί στις συνεδρίες τους.

*Προεπιλογή: `false`*

**Αναγνωριστικό δημιουργού αυτόματα δημιουργημένης συνεδρίας**

Ορίστε τον χρήστη που θα χρησιμοποιείται ως δημιουργός των αυτόματα δημιουργημένων συνεδριών (για να αποφεύγεται η ανάθεση κάθε συνεδρίας στον χρήστη «1», ο οποίος συχνά είναι ο διαχειριστής της πύλης).

### `session_classes_tab_disable`

**Απενεργοποίηση προσθήκης τάξης σε μάθημα συνεδρίας για μη διαχειριστές**

Απενεργοποίηση καρτέλας για προσθήκη τάξεων σε μάθημα συνεδρίας για μη διαχειριστές.

Διαφορετικά, οι επιβλέποντες συνεδρίας έχουν πρόσβαση σε συνεδρίες βάσει διάρκειας μόνο κατά την ενεργή διάρκεια.

*Προεπιλογή: `false`*


### `session_course_ordering`

**Χειροκίνητη ταξινόμηση μαθημάτων συνεδρίας**

Ενεργοποιήστε αυτή την επιλογή για να επιτρέπετε στους διαχειριστές συνεδρίας να ταξινομούν χειροκίνητα τα μαθήματα εντός μιας συνεδρίας. Εάν είναι απενεργοποιημένη, τα μαθήματα ταξινομούνται αλφαβητικά κατά τίτλο μαθήματος.

Περιορισμός της λίστας σπουδαστών προς εγγραφή στο μάθημα της συνεδρίας. Και απενεργοποίηση εγγραφής χρηστών σε όλα τα μαθήματα από τη σελίδα Περίληψη συνεδρίας.
