# Ρυθμίσεις καταλόγου μαθημάτων

Συμπεριφορά του καταλόγου μαθημάτων (η δημόσια λίστα όπου οι χρήστες μπορούν να περιηγηθούν και να εγγραφούν μόνοι τους).

Πρόσβαση σε αυτές τις ρυθμίσεις από **Διαχείριση > Ρυθμίσεις διαμόρφωσης > Κατάλογος μαθημάτων**. Αυτή η κατηγορία περιέχει **13 ρυθμίσεις**, που παρατίθενται παρακάτω με τον τίτλο και το σχόλιο που παρέχονται στα fixtures ρυθμίσεων της πλατφόρμας (`SettingsCurrentFixtures.php`).

> Το όνομα της μεταβλητής στον κώδικα εμφανίζεται με μονοδιάστημα. Χρησιμοποιήστε το κατά τη συγγραφή σεναρίων μέσω του API ή όταν χρειάζεται να αλλάξετε αυτές τις ρυθμίσεις σε καθολικό επίπεδο επεξεργάζοντας το [`config/settings_override.yaml`](https://github.com/chamilo/chamilo-lms/wiki/Configurations#configsettings_overridesyaml).

## Ρυθμίσεις

### `allow_session_auto_subscription`

**Αυτόματη εγγραφή σε συνεδρία**

Ενεργοποίηση αυτόματης εγγραφής χρηστών σε συνεδρίες.

*Προεπιλογή: `false`*

### `allow_students_to_browse_courses`

**Να επιτρέπεται η περιήγηση στους φοιτητές**

Να επιτρέπεται στους φοιτητές να περιηγούνται και να φιλτράρουν τον κατάλογο μαθημάτων.

*Προεπιλογή: `true`*

### `course_catalog_display_in_home`

**Εμφάνιση καταλόγου στην αρχική σελίδα**

Εμφάνιση του μπλοκ καταλόγου μαθημάτων στην αρχική σελίδα της πλατφόρμας.

*Προεπιλογή: `false`*

### `course_catalog_hide_private`

**Απόκρυψη ιδιωτικών μαθημάτων**

Εξαίρεση των ιδιωτικών μαθημάτων από την εμφάνιση στον κατάλογο.

*Προεπιλογή: `true`*

### `course_catalog_published`

**Δημοσίευση καταλόγου μαθημάτων**

Διαθεσιμότητα του καταλόγου μαθημάτων σε ανώνυμους χρήστες (το ευρύ κοινό) χωρίς ανάγκη σύνδεσης.

*Προεπιλογή: `false`*

### `course_catalog_settings`

**Ρυθμίσεις καταλόγου μαθημάτων**

Διαμόρφωση JSON για τον κατάλογο μαθημάτων: ρυθμίσεις συνδέσμων, φίλτρα, επιλογές ταξινόμησης και άλλα.

### `course_subscription_in_user_s_session`

**Εγγραφή στην προβολή συνεδρίας**

Να επιτρέπεται στους χρήστες να εγγράφονται σε μαθήματα απευθείας από τη σελίδα συνεδρίας τους.

*Προεπιλογή: `false`*

### `hide_public_link`

**Απόκρυψη δημόσιου συνδέσμου**

Αφαίρεση του δημόσιου συνδέσμου URL από τις κάρτες μαθημάτων.

*Προεπιλογή: `false`*

### `only_show_course_from_selected_category`

**Εμφάνιση μόνο των αντίστοιχων κατηγοριών στον κατάλογο μαθημάτων**

Όταν δεν είναι κενό, στον κατάλογο μαθημάτων θα εμφανίζονται μόνο τα μαθήματα από τις δεδομένες κατηγορίες.

### `only_show_selected_courses`

**Μόνο επιλεγμένα μαθήματα**

Εμφάνιση στον κατάλογο μόνο των μαθημάτων που έχουν επιλεγεί χειροκίνητα.

*Προεπιλογή: `false`*

### `session_catalog_settings`

**Ρυθμίσεις καταλόγου συνεδριών**

Διαμόρφωση JSON για τον κατάλογο συνεδριών: φίλτρα και επιλογές εμφάνισης.

### `show_courses_descriptions_in_catalog`

**Εμφάνιση περιγραφών μαθημάτων**

Εμφάνιση των περιγραφών μαθημάτων μέσα στη λίστα του καταλόγου.

*Προεπιλογή: `false`*

### `show_courses_sessions`

**Εμφάνιση μαθημάτων και συνεδριών**

Συμπερίληψη τόσο μαθημάτων όσο και συνεδριών στα αποτελέσματα του καταλόγου.

*Προεπιλογή: `0`*
