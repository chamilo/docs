# Ρυθμίσεις γλωσσών

Διαθέσιμες γλώσσες, προεπιλεγμένη γλώσσα και ο τρόπος με τον οποίο το Chamilo επιλύει ποια γλώσσα θα εμφανίσει.

Πρόσβαση σε αυτές τις ρυθμίσεις από **Διαχείριση > Ρυθμίσεις διαμόρφωσης > Γλώσσες**. Αυτή η κατηγορία περιέχει **13 ρυθμίσεις**, οι οποίες παρατίθενται παρακάτω με τον τίτλο και το σχόλιο που παρέχονται στα fixtures ρυθμίσεων της πλατφόρμας (`SettingsCurrentFixtures.php`).

> Το όνομα της μεταβλητής στον κώδικα εμφανίζεται με μονοδιάστημα. Χρησιμοποιήστε το κατά τη συγγραφή σεναρίων μέσω του API ή όταν χρειάζεται να αλλάξετε αυτές τις ρυθμίσεις σε καθολικό επίπεδο επεξεργάζοντας το [`config/settings_override.yaml`](https://github.com/chamilo/chamilo-lms/wiki/Configurations#configsettings_overridesyaml).

## Ρυθμίσεις

### `allow_course_multiple_languages`

**Μαθήματα πολλαπλών γλωσσών**

Ενεργοποίηση μαθημάτων που διαχειρίζονται σε περισσότερες από μία γλώσσες. Αυτή η επιλογή προσθέτει έναν επιλογέα γλώσσας στη σελίδα του μαθήματος ώστε οι χρήστες να μπορούν να αλλάζουν εύκολα, και προσθέτει ένα επιπλέον πεδίο 'multiple_language' στα μαθήματα που επιτρέπει διαδικασίες απομακρυσμένης διαχείρισης.

*Προεπιλογή: `false`*


### `allow_use_sub_language`

**Να επιτρέπεται ο ορισμός και η χρήση υπογλωσσών**

Ενεργοποιώντας αυτή την επιλογή, θα μπορείτε να ορίσετε παραλλαγές για καθέναν από τους όρους γλώσσας που χρησιμοποιούνται στη διεπαφή της πλατφόρμας, με τη μορφή μιας νέας γλώσσας που βασίζεται σε και επεκτείνει μια υπάρχουσα γλώσσα. Θα βρείτε αυτή την επιλογή στην ενότητα γλωσσών του πίνακα διαχείρισης.

*Προεπιλογή: `false`*

### `auto_detect_language_custom_pages`

**Ενεργοποίηση αυτόματης ανίχνευσης γλώσσας σε προσαρμοσμένες σελίδες**

Αν χρησιμοποιείτε προσαρμοσμένες σελίδες, ενεργοποιήστε το αν θέλετε να υπάρχει ανιχνευτής γλώσσας που παρουσιάζει τη σελίδα στη γλώσσα του προγράμματος περιήγησης του χρήστη, ή απενεργοποιήστε το για να επιβάλετε τη γλώσσα να είναι η προεπιλεγμένη γλώσσα της πλατφόρμας.

*Προεπιλογή: `true`*


### `language_by_resource` **v3**

**Γλώσσα ανά πόρο**

Να επιτρέπεται η ανάθεση συγκεκριμένης γλώσσας σε μεμονωμένους πόρους.

*Προεπιλογή: `false`*

### `language_flags_by_country`

**Σημαίες γλωσσών**

Χρήση σημαιών χωρών για τις γλώσσες. Δεν είναι ενεργοποιημένο από προεπιλογή επειδή ορισμένες γλώσσες δεν συνδέονται αυστηρά με μία χώρα, κάτι που μπορεί να προκαλέσει απογοήτευση σε ορισμένους χρήστες.

*Προεπιλογή: `false`*


### `language_priority_1`

**Γλώσσα υψηλότερης προτεραιότητας**

Κύρια γλώσσα που επιλέγεται όταν έχουν οριστεί πολλαπλά περιβάλλοντα γλώσσας.

*Προεπιλογή: `course_lang`*


### `language_priority_2`

**Δευτερεύουσα γλώσσα προτεραιότητας**

Δευτερεύουσα γλώσσα εναλλακτικής λύσης αν η πρώτη προτεραιότητα δεν είναι διαθέσιμη ή εκτός πλαισίου.

*Προεπιλογή: `user_profil_lang`*


### `language_priority_3`

**Τρίτη γλώσσα προτεραιότητας**

Τριτογενής γλώσσα εναλλακτικής λύσης αν αποτύχουν οι υψηλότερες προτεραιότητες.

*Προεπιλογή: `user_selected_lang`*


### `language_priority_4`

**Τέταρτη γλώσσα προτεραιότητας**

Τελευταία επιλογή γλώσσας εναλλακτικής λύσης κατά σειρά προτεραιότητας.

*Προεπιλογή: `platform_lang`*


### `platform_language`

**Προεπιλεγμένη γλώσσα πλατφόρμας**

Κύρια γλώσσα, που χρησιμοποιείται από προεπιλογή όταν δεν έχει οριστεί γλώσσα χρήστη.

*Προεπιλογή: `en`*


### `show_different_course_language`

**Εμφάνιση γλωσσών μαθημάτων**

Εμφάνιση της γλώσσας κάθε μαθήματος, δίπλα στον τίτλο του μαθήματος, στη λίστα μαθημάτων της αρχικής σελίδας

*Προεπιλογή: `true`*


### `show_language_selector_in_menu`

**Εναλλάκτης γλώσσας στο κύριο μενού**

Εμφάνιση επιλογέα γλώσσας στο κύριο μενού που ενημερώνει αμέσως την προτίμηση γλώσσας του χρήστη. Αυτό μπορεί να είναι χρήσιμο σε πολύγλωσσες πύλες όπου οι εκπαιδευόμενοι πρέπει να εναλλάσσονται από μία γλώσσα σε άλλη για τη μάθησή τους.

*Προεπιλογή: `true`*


### `template_activate_language_filter`

**Πρότυπα εγγράφων πολλαπλών γλωσσών**

Ενεργοποίηση προτύπων εγγράφων (σε επίπεδο πλατφόρμας ή μαθήματος) ώστε να διαμορφώνονται για συγκεκριμένες γλώσσες.

*Προεπιλογή: `false`*
