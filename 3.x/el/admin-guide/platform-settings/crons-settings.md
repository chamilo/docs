# Ρυθμίσεις εργασιών cron

Διαμόρφωση των προγραμματισμένων εργασιών (εργασίες cron) που περιλαμβάνονται στο Chamilo.

Πρόσβαση σε αυτές τις ρυθμίσεις από **Διαχείριση > Ρυθμίσεις διαμόρφωσης > Εργασίες cron**. Αυτή η κατηγορία περιέχει **5 ρυθμίσεις**, οι οποίες παρατίθενται παρακάτω με τον τίτλο και το σχόλιο που περιλαμβάνονται στα fixtures ρυθμίσεων της πλατφόρμας (`SettingsCurrentFixtures.php`).

> Το όνομα της μεταβλητής στον κώδικα εμφανίζεται με μονοδιάστημα. Χρησιμοποιήστε το όταν γράφετε σενάρια μέσω του API ή όταν χρειάζεται να αλλάξετε αυτές τις ρυθμίσεις σε καθολικό επίπεδο επεξεργάζοντας το [`config/settings_override.yaml`](https://github.com/chamilo/chamilo-lms/wiki/Configurations#configsettings_overridesyaml).

## Ρυθμίσεις

### `cron_remind_course_expiration_activate`

**Cron υπενθύμισης λήξης μαθήματος**

Ενεργοποίηση του cron υπενθύμισης λήξης μαθήματος

*Προεπιλογή: `false`*

### `cron_remind_course_expiration_frequency`

**Συχνότητα για το cron υπενθύμισης λήξης μαθήματος**

Αριθμός ημερών πριν από τη λήξη του μαθήματος που λαμβάνεται υπόψη για την αποστολή μηνύματος υπενθύμισης

### `cron_remind_course_finished_activate`

**Αποστολή ειδοποίησης ολοκλήρωσης μαθήματος**

Αν θα αποστέλλεται μήνυμα ηλεκτρονικού ταχυδρομείου στους εκπαιδευόμενους όταν ολοκληρωθεί το μάθημά τους (συνεδρία). Αυτό απαιτεί να έχουν διαμορφωθεί εργασίες cron (βλ. κατάλογο main/cron/).

*Προεπιλογή: `false`*

### `cron_certificate_expiry_reminder_activate`

**Cron υπενθύμισης λήξης πιστοποιητικού**

Ενεργοποίηση του cron `app:send-certificate-expiry-reminders`, το οποίο υπενθυμίζει στους εκπαιδευόμενους των οποίων τα πιστοποιητικά έχουν λήξει ή πρόκειται να λήξουν.

*Προεπιλογή: `false`*

### `cron_certificate_expiry_reminder_days`

**Παράθυρο υπενθύμισης λήξης πιστοποιητικού (ημέρες)**

Προεπιλεγμένος αριθμός ημερών εκ των προτέρων για σάρωση πιστοποιητικών που πρόκειται να λήξουν, που χρησιμοποιείται εκτός αν το cron εκτελεστεί με `--days-ahead`.

*Προεπιλογή: `30`*

## Υπενθυμίσεις λήξης πιστοποιητικών

Στα πιστοποιητικά βαθμολογίου μπορεί να δοθεί περίοδος ισχύος (σε ημέρες), διαμορφωμένη ανά κατηγορία βαθμολογίου — βλ. [Πιστοποιητικά και δεξιότητες](../../teacher-guide/tracking-and-reporting/certificates-and-skills.md). Μόλις ένα πιστοποιητικό έχει ημερομηνία λήξης, το Chamilo μπορεί να υπενθυμίσει στον εκπαιδευόμενο με μήνυμα ηλεκτρονικού ταχυδρομείου και εσωτερικό μήνυμα καθώς πλησιάζει (ή αφού περάσει) αυτή η ημερομηνία λήξης.

Η ενεργοποίηση του `cron_certificate_expiry_reminder_activate` παραπάνω ενεργοποιεί μόνο τη *λειτουργία*· η υπενθύμιση αποστέλλεται στην πραγματικότητα από εντολή κονσόλας που πρέπει ακόμη να προγραμματίσετε σε επίπεδο λειτουργικού συστήματος (π.χ. μέσω `crontab`), καθώς το Chamilo δεν εκτελεί δικό του χρονοπρογραμματιστή παρασκηνίου:

```bash
php bin/console app:send-certificate-expiry-reminders
```

Χρήσιμες επιλογές:

| Επιλογή | Αποτέλεσμα |
|--------|--------|
| `--days-ahead=N` | Πόσες ημέρες πριν από τη λήξη να συμπεριληφθούν (προεπιλογή το `cron_certificate_expiry_reminder_days`) |
| `--force` | Πραγματική αποστολή των υπενθυμίσεων. Χωρίς αυτήν, η εντολή αναφέρει μόνο τι *θα* απέστελλε — ασφαλές να εκτελεστεί για έλεγχο πριν τη σύνδεση στο cron |
| `--resend` | Επανάληψη αποστολής υπενθυμίσεων ακόμη και για ζεύγος πιστοποιητικού/ημερομηνίας λήξης που έχει ήδη ειδοποιηθεί |
| `--access-url-id=N` | Περιορισμός της σάρωσης σε μία πύλη (εγκαταστάσεις πολλαπλών URL) |
| `--include-unsubscribed-users` | Ειδοποίηση και εκπαιδευόμενων που έχουν διαγραφεί από τα μηνύματα ηλεκτρονικού ταχυδρομείου της πλατφόρμας |

Οι εκπαιδευτές μπορούν να στείλουν τις ίδιες υπενθυμίσεις χειροκίνητα, χωρίς να χρειάζονται αυτό το cron — βλ. [Πιστοποιητικά και δεξιότητες](../../teacher-guide/tracking-and-reporting/certificates-and-skills.md#certificate-validity-and-expiry).
