# Ρυθμίσεις Ασκήσεων (Τεστ)

Προεπιλογές και συμπεριφορά του εργαλείου **Ασκήσεις (Τεστ)** — εμφάνιση ερωτήσεων, βαθμολόγηση, προσπάθειες και συναφή.

Προσπελάστε αυτές τις ρυθμίσεις στο **Διαχείριση > Ρυθμίσεις διαμόρφωσης > Ασκήσεις (Τεστ)**. Αυτή η κατηγορία περιέχει **64 ρυθμίσεις**, οι οποίες παρατίθενται παρακάτω με τον τίτλο και το σχόλιο που περιλαμβάνονται στα fixtures ρυθμίσεων της πλατφόρμας (`SettingsCurrentFixtures.php`).

> Το όνομα της μεταβλητής στον κώδικα εμφανίζεται σε monospace. Χρησιμοποιήστε το όταν γράφετε σενάρια μέσω του API ή όταν χρειάζεται να αλλάξετε αυτές τις ρυθμίσεις σε καθολικό επίπεδο επεξεργάζοντας το [`config/settings_override.yaml`](https://github.com/chamilo/chamilo-lms/wiki/Configurations#configsettings_overridesyaml).

## Ρυθμίσεις

### `add_exercise_best_attempt_in_report`

**Ενεργοποίηση εμφάνισης της προσπάθειας με την καλύτερη βαθμολογία**

Παρέχετε μια λίστα μαθημάτων και αναγνωριστικών τεστ που θα εμφανίζουν την προσπάθεια με την καλύτερη βαθμολογία για οποιονδήποτε εκπαιδευόμενο στις αναφορές.

### `allow_coach_feedback_exercises`

**Να επιτρέπεται στους καθηγητές να σχολιάζουν κατά την ανασκόπηση ασκήσεων**

Να επιτρέπεται στους καθηγητές να επεξεργάζονται την ανατροφοδότηση κατά την ανασκόπηση ασκήσεων

*Προεπιλογή: `true`*

### `allow_edit_exercise_in_lp`

**Να επιτρέπεται στους εκπαιδευτές να επεξεργάζονται τεστ σε μαθησιακές διαδρομές**

Από προεπιλογή, το Chamilo σας εμποδίζει να επεξεργάζεστε τεστ που περιλαμβάνονται μέσα σε μια μαθησιακή διαδρομή. Αυτό γίνεται για να αποφεύγονται αλλαγές που θα επηρέαζαν διαφορετικά τους εκπαιδευόμενους (παρελθόντες και μελλοντικούς) ως προς τα αποτελέσματα ή/και την πρόοδο στη μαθησιακή διαδρομή. Αυτή η επιλογή επιτρέπει στους εκπαιδευτές να παρακάμπτουν αυτόν τον περιορισμό.


### `allow_exercise_categories`

**Ενεργοποίηση κατηγοριών τεστ**

Οι κατηγορίες τεστ δεν είναι ενεργοποιημένες από προεπιλογή επειδή προσθέτουν ένα επίπεδο πολυπλοκότητας. Ενεργοποιήστε αυτή τη λειτουργία ώστε να εμφανιστούν όλα τα εικονίδια διαχείρισης που σχετίζονται με τις κατηγορίες τεστ.

*Προεπιλογή: `false`*

### `allow_mandatory_question_in_category`

**Ενεργοποίηση επιλογής υποχρεωτικών ερωτήσεων**

Ενεργοποιήστε την επιλογή υποχρεωτικών ερωτήσεων σε ένα τεστ όταν χρησιμοποιούνται τυχαίες κατηγορίες.

*Προεπιλογή: `false`*

### `allow_notification_setting_per_exercise`

**Ρυθμίσεις ειδοποιήσεων τεστ σε επίπεδο τεστ**

Ενεργοποιήστε τη διαμόρφωση ειδοποιήσεων υποβολής τεστ σε επίπεδο τεστ αντί σε επίπεδο μαθήματος. Αν δεν έχουν οριστεί σε επίπεδο τεστ, εφαρμόζονται οι ρυθμίσεις επιπέδου μαθήματος.

*Προεπιλογή: `false`*

### `allow_quick_question_description_popup`

**Γρήγορη προσθήκη εικόνας στην ερώτηση**

Ενεργοποιήστε ένα επιπλέον εικονίδιο στη λίστα ερωτήσεων του τεστ για προσθήκη εικόνας ως περιγραφή ερώτησης. Αυτό επιταχύνει σημαντικά την επεξεργασία ερωτήσεων όταν οι ερωτήσεις βρίσκονται στον τίτλο και η περιγραφή περιλαμβάνει μόνο μια εικόνα.

*Προεπιλογή: `false`*

### `allow_quiz_question_feedback`

**Προσθήκη ανατροφοδότησης ερώτησης σε περίπτωση λανθασμένης απάντησης**

Από προεπιλογή, το Chamilo σας επιτρέπει να εμφανίζετε ανατροφοδότηση σε κάθε απάντηση μιας ερώτησης. Με αυτή την επιλογή δημιουργείται ένα επιπλέον πεδίο για προκαθορισμένη ανατροφοδότηση σε ολόκληρη την ερώτηση. Αυτή η ανατροφοδότηση εμφανίζεται μόνο αν ο χρήστης απάντησε λανθασμένα.

*Προεπιλογή: `false`*

### `allow_quiz_results_page_config`

**Ενεργοποίηση διαμόρφωσης σελίδας αποτελεσμάτων τεστ**

Ορίστε έναν πίνακα ρυθμίσεων που θέλετε να εφαρμόζονται σε όλες τις σελίδες αποτελεσμάτων τεστ. Οι ρυθμίσεις μπορεί να είναι ‘hide_question_score’, ‘hide_expected_answer’, ‘hide_category_table’, ‘hide_correct_answered_questions’, ‘hide_total_score’ και ενδεχομένως περισσότερες στο μέλλον. Αναζητήστε το ‘getPageConfigurationAttribute’ στον κώδικα για να δείτε τι χρησιμοποιείται.

*Προεπιλογή: `false`*

### `allow_quiz_show_previous_button_setting`

**Εμφάνιση κουμπιού «προηγούμενο» στο τεστ για πλοήγηση στις ερωτήσεις**

Ορίστε το σε false για να απενεργοποιήσετε το κουμπί «προηγούμενο» κατά την απάντηση ερωτήσεων σε ένα τεστ, αναγκάζοντας έτσι τους χρήστες να προχωρούν πάντα μπροστά.

*Προεπιλογή: `false`*

### `allow_teacher_comment_audio`

**Ηχητική ανατροφοδότηση στις υποβληθείσες απαντήσεις**

Να επιτρέπεται στους εκπαιδευτές να παρέχουν ανατροφοδότηση στους χρήστες μέσω ήχου (εναλλακτικά του κειμένου) σε κάθε ερώτηση ενός τεστ.

*Προεπιλογή: `true`*

### `allow_time_per_question`

**Ενεργοποίηση χρόνου ανά ερώτηση στα τεστ**

Από προεπιλογή, είναι δυνατός μόνο ο περιορισμός του χρόνου ανά τεστ. Ο περιορισμός ανά ερώτηση προσθέτει ένα επιπλέον επίπεδο δυνατοτήτων και μπορείτε (με προσοχή) να συνδυάσετε και τα δύο.

*Προεπιλογή: `false`*

### `block_category_questions`

**Κλείδωμα ερωτήσεων προηγούμενων κατηγοριών σε ένα τεστ**

Όταν χρησιμοποιείτε αυτή την επιλογή, θα εμφανιστεί μια επιπλέον επιλογή στη διαμόρφωση του τεστ. Όταν χρησιμοποιείτε τεστ με πολλαπλές κατηγορίες ερωτήσεων και ζητάτε κατανομή ανά κατηγορία, αυτό θα επιτρέπει στον χρήστη να πλοηγείται στις ερωτήσεις ανά κατηγορία. Μόλις ολοκληρωθεί μια κατηγορία, μεταβαίνει στην επόμενη και δεν μπορεί να επιστρέψει στην προηγούμενη κατηγορία.

*Προεπιλογή: `false`*

### `block_quiz_mail_notification_general_coach`

**Αποκλεισμός αποστολής ειδοποιήσεων τεστ στον γενικό καθηγητή**

Όταν οι εκπαιδευόμενοι ολοκληρώνουν ένα τεστ, συνήθως αποστέλλονται ειδοποιήσεις στους καθηγητές, συμπεριλαμβανομένου του γενικού καθηγητή συνεδρίας. Ενεργοποιήστε αυτή την επιλογή για να εξαιρείται ο γενικός καθηγητής από αυτές τις ειδοποιήσεις.

*Προεπιλογή: `false`*

### `configure_exercise_visibility_in_course`

**Ενεργοποίηση παράκαμψης της ρύθμισης «Άσκηση αόρατη στη συνεδρία» σε επίπεδο βασικού μαθήματος**

Για να ενεργοποιηθεί η ρύθμιση της αορατότητας της άσκησης στη συνεδρία στο βασικό μάθημα, ώστε να παρακαμφθεί η καθολική ρύθμιση. Αν δεν οριστεί, χρησιμοποιείται η καθολική παράμετρος.

*Προεπιλογή: `false`*

### `disable_clean_exercise_results_for_teachers`

**Απενεργοποίηση της «εκκαθάρισης αποτελεσμάτων» για τους εκπαιδευτές**

Απενεργοποιεί την επιλογή διαγραφής αποτελεσμάτων τεστ από τη λίστα τεστ. Χρησιμοποιείται συχνά όταν μαθήματα διαχειρίζονται λιγότερο προσεκτικοί εκπαιδευτές, ώστε να αποφεύγονται κρίσιμα λάθη.

*Προεπιλογή: `true`*

### `email_alert_manager_on_new_quiz`

**Προεπιλεγμένη ρύθμιση ειδοποίησης μέσω e-mail για νέο κουίζ**

Αν θέλετε οι διαχειριστές μαθήματος (εκπαιδευτές) να ειδοποιούνται μέσω e-mail όταν ένας σπουδαστής απαντά σε ένα κουίζ. Αυτή είναι η προεπιλεγμένη τιμή που δίνεται σε όλα τα νέα μαθήματα, αλλά κάθε εκπαιδευτής μπορεί να την αλλάξει στο δικό του μάθημα.

*Προεπιλογή: `true`*

### `enable_quiz_scenario`

**Ενεργοποίηση σεναρίου κουίζ**

Από εδώ θα μπορείτε να δημιουργείτε ασκήσεις που προτείνουν διαφορετικές ερωτήσεις ανάλογα με τις απαντήσεις του χρήστη.

*Προεπιλογή: `true`*

### `exercise_additional_teacher_modify_actions`

**Επιπλέον σύνδεσμοι για εκπαιδευτές στη λίστα τεστ**

Ρυθμίστε στοιχεία callback για τη δημιουργία νέων εικονιδίων ενεργειών για εκπαιδευτές στη δεξιά πλευρά της λίστας τεστ, με μορφή πίνακα, π.χ. ['myplugin' => ['MyPlugin', 'urlGeneratorCallback']]

### `exercise_attempts_report_show_username`

**Εμφάνιση ονόματος χρήστη στη σελίδα αποτελεσμάτων τεστ**

Εμφανίζει το όνομα χρήστη (αντί ή μαζί με τα στοιχεία χρήστη) στη σελίδα αποτελεσμάτων τεστ.

*Προεπιλογή: `false`*

### `exercise_category_report_user_extra_fields`

**Προσθήκη επιπλέον πεδίων χρήστη στην αναφορά κατηγορίας άσκησης**

Ορίστε έναν πίνακα με τη λίστα των επιπλέον πεδίων χρήστη που θα προστεθούν στην αναφορά.

### `exercise_category_round_score_in_export`

**Στρογγυλοποίηση βαθμολογίας στις εξαγωγές τεστ**

Όταν είναι ενεργοποιημένο, οι βαθμολογίες τεστ στρογγυλοποιούνται στον πλησιέστερο ακέραιο κατά την εξαγωγή αναφορών ασκήσεων.

*Προεπιλογή: `false`*

### `exercise_embeddable_extra_types`

**Τύποι ερωτήσεων που μπορούν να ενσωματωθούν**

Από προεπιλογή, μόνο οι ερωτήσεις μοναδικής και πολλαπλής απάντησης λαμβάνονται υπόψη όταν αποφασίζεται αν ένα τεστ μπορεί να ενσωματωθεί σε βίντεο ή όχι. Με αυτή την επιλογή μπορείτε να αποφασίσετε ότι είναι διαθέσιμοι περισσότεροι τύποι ερωτήσεων. Λάβετε υπόψη ότι δεν ταιριάζουν όλοι οι τύποι ερωτήσεων άνετα στον χώρο που διατίθεται για βίντεο. Οι τύποι ερωτήσεων είναι διαθέσιμοι στον κώδικα στο question.class.php.

### `exercise_hide_ip`

**Απόκρυψη IP χρήστη από τις αναφορές τεστ**

Από προεπιλογή εμφανίζουμε πληροφορίες χρήστη και τη διεύθυνση IP του, αλλά αυτό μπορεί να θεωρηθεί προσωπικό δεδομένο, οπότε αυτή η επιλογή σας επιτρέπει να αφαιρέσετε αυτές τις πληροφορίες από όλες τις αναφορές τεστ.

*Προεπιλογή: `false`*

### `exercise_hide_label`

**Απόκρυψη κορδέλας ερώτησης (σωστό/λάθος) στα αποτελέσματα τεστ**

Στα αποτελέσματα τεστ εμφανίζεται από προεπιλογή μια κορδέλα που υποδεικνύει αν η απάντηση ήταν σωστή ή λάθος. Ενεργοποιήστε αυτή την επιλογή για να αφαιρέσετε την κορδέλα καθολικά.

*Προεπιλογή: `false`*

### `exercise_invisible_in_session`

**Άσκηση αόρατη στη συνεδρία**

Αν μια άσκηση είναι ορατή στο βασικό μάθημα, τότε εμφανίζεται αόρατη στη συνεδρία. Αν μια άσκηση είναι αόρατη στο βασικό μάθημα, τότε δεν εμφανίζεται στη συνεδρία.

*Προεπιλογή: `false`*

### `exercise_max_editors_in_page`

**Μέγιστος αριθμός επεξεργαστών στην οθόνη αποτελεσμάτων άσκησης**

Λόγω του μεγάλου αριθμού ερωτήσεων που μπορεί να εμφανίζονται σε μια άσκηση, η οθόνη διόρθωσης, που επιτρέπει στον εκπαιδευτή να προσθέτει σχόλια σε κάθε απάντηση, μπορεί να φορτώνει πολύ αργά. Ορίστε αυτόν τον αριθμό σε 5 για να ζητήσετε από την πλατφόρμα να εμφανίζει επεξεργαστές WYSIWYG μόνο μέχρι έναν ορισμένο αριθμό απαντήσεων στην οθόνη. Αυτό θα επιταχύνει σημαντικά τον χρόνο φόρτωσης της σελίδας διόρθωσης, αλλά θα αφαιρέσει τους επεξεργαστές WYSIWYG και θα αφήσει μόνο έναν επεξεργαστή απλού κειμένου.

*Προεπιλογή: `0`*


### `exercise_max_score`

**Μέγιστη βαθμολογία ασκήσεων**

Ορίστε μια μέγιστη βαθμολογία (συνήθως 10, 20 ή 100) για όλες τις ασκήσεις στην πλατφόρμα. Αυτό θα καθορίσει πώς εμφανίζονται τα τελικά αποτελέσματα σε χρήστες και εκπαιδευτές.

*Προεπιλογή: `20`*


### `exercise_min_score`

**Ελάχιστη βαθμολογία ασκήσεων**

Ορίστε μια ελάχιστη βαθμολογία (συνήθως 0) για όλες τις ασκήσεις στην πλατφόρμα. Αυτό θα καθορίσει πώς εμφανίζονται τα τελικά αποτελέσματα σε χρήστες και εκπαιδευτές.

*Προεπιλογή: `0`*


### `exercise_result_end_text_html_strict_filtering`

**Παράκαμψη φιλτραρίσματος HTML στα μηνύματα τέλους τεστ**

Θεωρήστε ότι τα μηνύματα στο τέλος των τεστ είναι πάντα ασφαλή. Η αφαίρεση του φίλτρου καθιστά δυνατή τη χρήση JavaScript εκεί.

*Προεπιλογή: `false`*


### `exercise_score_format`

**Μορφή βαθμολογίας τεστ**

Επιλέξτε μεταξύ των ακόλουθων μορφών για την εμφάνιση της βαθμολογίας των χρηστών σε διάφορες αναφορές: 1 = SCORE_AVERAGE (5 / 10); 2 = SCORE_PERCENT (50%); 3 = SCORE_DIV_PERCENT (5 / 10 (50%)). Χρησιμοποιήστε το αριθμητικό αναγνωριστικό της μορφής που θέλετε να χρησιμοποιήσετε.

*Προεπιλογή: `0`*

### `exercises_disable_new_attempts`

**Απενεργοποίηση νέων προσπαθειών τεστ**

Απενεργοποιεί καθολικά τις νέες προσπάθειες τεστ. Συνήθως χρησιμοποιείται όταν υπάρχει πρόβλημα με τα τεστ γενικά και θέλετε χρόνο για ανάλυση χωρίς να μπλοκάρετε ολόκληρη την πλατφόρμα.

*Προεπιλογή: `false`*

### `hide_free_question_score`

**Απόκρυψη βαθμολογίας ανοικτών ερωτήσεων**

Απόκρυψη του γεγονότος ότι οι ανοικτές ερωτήσεις (συμπεριλαμβανομένων ήχου και σχολιασμών) έχουν βαθμολογία, με απόκρυψη της εμφάνισης της βαθμολογίας σε όλες τις αναφορές που απευθύνονται στους εκπαιδευόμενους.

*Προεπιλογή: `false`*


### `hide_user_info_in_quiz_result`

**Απόκρυψη στοιχείων χρήστη στη σελίδα αποτελεσμάτων τεστ**

Η προεπιλεγμένη σελίδα αποτελεσμάτων τεστ εμφανίζει ένα φύλλο δεδομένων χρήστη (φωτογραφία, όνομα κ.λπ.) το οποίο, σε ορισμένα περιβάλλοντα, ενδέχεται να θεωρηθεί ότι υπερβαίνει τα όρια επεξεργασίας προσωπικών δεδομένων. Ενεργοποιήστε αυτή την επιλογή για να αφαιρέσετε τα στοιχεία του χρήστη από τα αποτελέσματα του τεστ.

*Προεπιλογή: `false`*


### `limit_exercise_teacher_access`

**Περιορισμός δικαιωμάτων εκπαιδευτών στα τεστ**

Όταν είναι ενεργοποιημένη, οι εκπαιδευτές δεν μπορούν να διαγράψουν τεστ ούτε ερωτήσεις, να αλλάξουν την ορατότητα των τεστ, να κατεβάσουν σε QTI, να καθαρίσουν αποτελέσματα κ.λπ.

*Προεπιλογή: `false`*


### `my_courses_show_pending_exercise_attempts`

**Καθολική λίστα εκκρεμών τεστ**

Ενεργοποιήστε για να εμφανίζεται στον τελικό χρήστη μια σελίδα με τη λίστα των εκκρεμών τεστ σε όλα τα μαθήματα.

*Προεπιλογή: `false`*


### `question_exercise_html_strict_filtering`

**Παράκαμψη φιλτραρίσματος HTML στις ερωτήσεις τεστ**

Θεωρήστε ότι το κείμενο των ερωτήσεων στα τεστ είναι πάντα ασφαλές. Η αφαίρεση του φίλτρου καθιστά δυνατή τη χρήση JavaScript εκεί.

*Προεπιλογή: `false`*


### `question_pagination_length`

**Μήκος σελιδοποίησης ερωτήσεων για εκπαιδευτές**

Αριθμός ερωτήσεων που εμφανίζονται σε κάθε σελίδα όταν χρησιμοποιείται η επιλογή σελιδοποίησης ερωτήσεων για εκπαιδευτές.

*Προεπιλογή: `20`*


### `quiz_answer_extra_recording`

**Ενεργοποίηση επιπλέον καταγραφής απαντήσεων τεστ**

Ενεργοποίηση καταγραφής όλων των απαντήσεων (ακόμη και προσωρινών) στον πίνακα track_e_attempt_recording. Αυτή η λειτουργία είναι πειραματική και μπορεί να δημιουργήσει προβλήματα στις σελίδες αναφορών κατά την προσπάθεια βαθμολόγησης ενός τεστ.

*Προεπιλογή: `false`*


### `quiz_check_all_answers_before_end_test`

**Έλεγχος όλων των απαντήσεων πριν την υποβολή του τεστ**

Εμφάνιση αναδυόμενου παραθύρου με τη λίστα των απαντημένων/αναπάντητων ερωτήσεων πριν την υποβολή του τεστ.

*Προεπιλογή: `false`*


### `quiz_check_button_enable`

**Προσθήκη ελέγχου διαδικασίας αποθήκευσης απαντήσεων πριν το τεστ**

Βεβαιωθείτε ότι οι χρήστες είναι έτοιμοι να ξεκινήσουν το τεστ παρέχοντας μια προσομοίωση της διαδικασίας αποθήκευσης ερωτήσεων πριν την είσοδο στο τεστ. Αυτό επιτρέπει την έγκαιρη ανίχνευση ορισμένων προβλημάτων σύνδεσης και μειώνει τις τριβές στην εμπειρία χρήστη.

*Προεπιλογή: `false`*


### `quiz_confirm_saved_answers`
