# Ρυθμίσεις ροών εργασίας

Διατομεακοί διακόπτες ροών εργασίας — δημιουργία μαθημάτων, επικύρωση εγγραφής, ροές εργασιών εργασιών και παρόμοια.

Πρόσβαση σε αυτές τις ρυθμίσεις από **Διαχείριση > Ρυθμίσεις διαμόρφωσης > Ροές εργασίας**. Αυτή η κατηγορία περιέχει **23 ρυθμίσεις**, οι οποίες παρατίθενται παρακάτω με τον τίτλο και το σχόλιο που περιλαμβάνονται στα fixtures ρυθμίσεων της πλατφόρμας (`SettingsCurrentFixtures.php`).

> Το όνομα της μεταβλητής στον κώδικα εμφανίζεται με μονοδιάστημα. Χρησιμοποιήστε το όταν γράφετε σενάρια μέσω του API ή όταν χρειάζεται να αλλάξετε αυτές τις ρυθμίσεις σε καθολικό επίπεδο επεξεργάζοντας το [`config/settings_override.yaml`](https://github.com/chamilo/chamilo-lms/wiki/Configurations#configsettings_overridesyaml).

## Ρυθμίσεις

### `allow_user_course_subscription_by_course_admin`

**Να επιτρέπεται η εγγραφή χρηστών σε μάθημα από τον διαχειριστή μαθήματος**

Η ενεργοποίηση αυτής της επιλογής θα επιτρέψει στον διαχειριστή μαθήματος να εγγράφει χρήστες μέσα σε ένα μάθημα

*Προεπιλογή: `true`*


### `allow_users_to_create_courses`

**Να επιτρέπεται σε μη διαχειριστές να δημιουργούν μαθήματα**

Να επιτρέπεται σε μη διαχειριστές (εκπαιδευτές) να δημιουργούν νέα μαθήματα στον διακομιστή

*Προεπιλογή: `false`*


### `allow_working_time_edition`

**Ενεργοποίηση επεξεργασίας χρόνου εργασίας μαθήματος**

Ενεργοποιήστε αυτή τη λειτουργία ώστε οι εκπαιδευτές να μπορούν να ενημερώνουν χειροκίνητα τον χρόνο που αφιερώνουν οι εκπαιδευόμενοι στο μάθημα.

*Προεπιλογή: `false`*


### `course_visibility_change_only_admin`

**Αλλαγές ορατότητας μαθήματος μόνο για διαχειριστές**

Αφαίρεση της δυνατότητας των μη διαχειριστών να αλλάζουν την ορατότητα του μαθήματος. Η ορατότητα μπορεί να αποτελεί πρόβλημα όταν υπάρχουν πάρα πολλοί εκπαιδευτές για άμεσο έλεγχο. Η επιβολή ορατοτήτων επιτρέπει στον οργανισμό να διαχειρίζεται καλύτερα τους καταλόγους μαθημάτων.

*Προεπιλογή: `false`*


### `default_menu_entry_for_course_or_session`

**Προεπιλεγμένη καταχώριση μενού για μαθήματα**

Ορίστε τα προεπιλεγμένα υποστοιχεία της καταχώρισης «Μαθήματα» που θα εμφανίζονται εάν ο χρήστης δεν είναι εγγεγραμμένος σε κανένα μάθημα ούτε σε καμία συνεδρία.

*Προεπιλογή: `my_courses`*


### `disable_user_conditions_sender_id`

**Εσωτερικό αναγνωριστικό του χρήστη που χρησιμοποιείται για την αποστολή ειδοποιήσεων απενεργοποιημένου λογαριασμού**

Αποφύγετε την υπερβολικά προσωπική επικοινωνία με τους χρήστες χρησιμοποιώντας έναν λογαριασμό «bot» για την αποστολή μηνυμάτων ηλεκτρονικού ταχυδρομείου στους χρήστες όταν ο λογαριασμός τους απενεργοποιείται για κάποιον λόγο.

*Προεπιλογή: `0`*


### `disabled_edit_session_coaches_course_editing_course`

**Απενεργοποίηση της δυνατότητας επεξεργασίας των εκπαιδευτών μαθήματος**

Όταν είναι απενεργοποιημένη, οι διαχειριστές δεν έχουν σύνδεσμο για γρήγορη ανάθεση εκπαιδευτών σε μαθήματα συνεδρίας στη σελίδα επεξεργασίας μαθήματος.

*Προεπιλογή: `false`*


### `drh_allow_access_to_all_students`

**Ο HRM μπορεί να έχει πρόσβαση σε όλους τους εκπαιδευόμενους από τις σελίδες αναφορών**

[συμπερασματικά] Παραχώρηση στους διαχειριστές HR/DRH πρόσβασης στις σελίδες αναφορών για όλους τους εκπαιδευόμενους σε όλη την πλατφόρμα.

*Προεπιλογή: `false`*


### `gamification_mode`

**Λειτουργία παιχνιδοποίησης**

Ενεργοποίηση του επιτεύγματος αστεριών στα μονοπάτια μάθησης

### `go_to_course_after_login`

**Μετάβαση απευθείας στο μάθημα μετά τη σύνδεση**

Όταν ένας χρήστης είναι εγγεγραμμένος σε ένα μάθημα, μετάβαση απευθείας στο μάθημα μετά τη σύνδεση

*Προεπιλογή: `false`*


### `load_term_conditions_section`

**Φόρτωση ενότητας όρων και προϋποθέσεων**

Η νομική συμφωνία θα εμφανίζεται κατά τη σύνδεση ή κατά την είσοδο σε ένα μάθημα.

*Προεπιλογή: `login`*


### `multiple_url_hide_disabled_settings`

**Απόκρυψη απενεργοποιημένων ρυθμίσεων σε υπο-URL**

Ορίστε σε ναι για πλήρη απόκρυψη ρυθμίσεων σε ένα υπο-URL εάν η ρύθμιση είναι απενεργοποιημένη στο κύριο URL (όπου το πεδίο access_url_changeable = 0)

*Προεπιλογή: `false`*


### `plugin_redirection_enabled`

**Ενεργοποίηση πρόσθετου ανακατεύθυνσης**

Ενεργοποιήστε μόνο εάν χρησιμοποιείτε το πρόσθετο Redirection

*Προεπιλογή: `false`*


### `redirect_index_to_url_for_logged_users`

**Ανακατεύθυνση του index.php σε δεδομένο URL για πιστοποιημένους χρήστες**

Εάν δεν θέλετε να χρησιμοποιείτε τη σελίδα ευρετηρίου (ανακοινώσεις, δημοφιλή μαθήματα κ.λπ.), μπορείτε να ορίσετε εδώ το σενάριο (από τη ρίζα εγγράφων) όπου θα ανακατευθύνονται οι χρήστες όταν προσπαθούν να φορτώσουν το ευρετήριο.

### `send_all_emails_to`

**Αποστολή όλων των μηνυμάτων ηλεκτρονικού ταχυδρομείου προς**

Δώστε μια λίστα διευθύνσεων ηλεκτρονικού ταχυδρομείου στις οποίες θα αποστέλλονται *όλα* τα μηνύματα ηλεκτρονικού ταχυδρομείου που αποστέλλονται από την πλατφόρμα. Τα μηνύματα αποστέλλονται σε αυτές τις διευθύνσεις ως ορατός προορισμός.

### `session_admin_user_subscription_search_extra_field_to_search`

**Επιπλέον πεδίο χρήστη που χρησιμοποιείται για αναζήτηση και ονομασία συνεδριών**

Αυτή η ρύθμιση ορίζει το κλειδί επιπλέον πεδίου χρήστη (π.χ. "company") που θα χρησιμοποιείται για την αναζήτηση χρηστών και για τον ορισμό του ονόματος της συνεδρίας κατά την εγγραφή εκπαιδευομένων από το /admin-dashboard/register.

### `teacher_can_select_course_template`

**Ο εκπαιδευτής μπορεί να επιλέξει μάθημα ως πρότυπο**

Να επιτρέπεται η επιλογή μαθήματος ως προτύπου για το νέο μάθημα που δημιουργεί ο εκπαιδευτής

*Προεπιλογή: `true`*


### `update_student_expiration_x_date`

**Ορισμός ημερομηνίας λήξης στην πρώτη σύνδεση**

Πίνακας που ορίζει τις «ημέρες» και τους «μήνες» για τον ορισμό της ημερομηνίας λήξης του λογαριασμού όταν ο χρήστης συνδέεται για πρώτη φορά.

### `user_edition_extra_field_to_check`

**Ορισμός επιπλέον πεδίου ως εναύσματος για εγγραφή ως πρώην εκπαιδευόμενος**

Δώστε εδώ μια ετικέτα επιπλέον πεδίου. Εάν αυτό το επιπλέον πεδίο ενημερωθεί για οποιονδήποτε χρήστη, ενεργοποιείται μια διαδικασία ελέγχου της πρόσβασης αυτού του χρήστη σε μαθήματα με το ίδιο δεδομένο επιπλέον πεδίο.

### `user_number_of_days_for_default_expiration_date_per_role`

**Προεπιλεγμένες ημέρες λήξης ανά ρόλο**

Ένας πίνακας role => number που αντιπροσωπεύει τον αριθμό ημερών που έχει ένας λογαριασμός πριν από τη λήξη, ανάλογα με τον ρόλο.

### `usergroup_do_not_unsubscribe_users_from_course_nor_session_on_user_unsubscribe`

**Απενεργοποίηση απεγγραφής χρήστη από μάθημα/συνεδρία κατά την απεγγραφή χρήστη από ομάδα/τάξη**

[inferred] Κατά την αφαίρεση ενός χρήστη από μια ομάδα/τάξη, μην τον απεγγράφετε αυτόματα από τα συσχετισμένα μαθήματα ή τις συνεδρίες.

*Προεπιλογή: `false`*


### `usergroup_do_not_unsubscribe_users_from_course_on_course_unsubscribe`

**Απενεργοποίηση απεγγραφής χρήστη από μάθημα κατά την αφαίρεση μαθήματος από ομάδα/τάξη**

[inferred] Όταν αφαιρείται ένα μάθημα από μια ομάδα/τάξη, μην απεγγράφετε αυτόματα τους χρήστες από αυτό το μάθημα.

*Προεπιλογή: `false`*


### `usergroup_do_not_unsubscribe_users_from_session_on_session_unsubscribe`

**Απενεργοποίηση απεγγραφής χρήστη από συνεδρία κατά την αφαίρεση συνεδρίας από ομάδα/τάξη**

[inferred] Όταν αφαιρείται μια συνεδρία από μια ομάδα/τάξη, μην απεγγράφετε αυτόματα τους χρήστες από αυτή τη συνεδρία.

*Προεπιλογή: `false`*
