# Ρυθμίσεις Γλωσσαρίου

Συμπεριφορά του εργαλείου **Γλωσσάριο** του μαθήματος.

Αποκτήστε πρόσβαση σε αυτές τις ρυθμίσεις στο **Διαχείριση > Ρυθμίσεις διαμόρφωσης > Γλωσσάριο**. Αυτή η κατηγορία περιέχει **3 ρυθμίσεις**, οι οποίες παρατίθενται παρακάτω με τον τίτλο και το σχόλιο που περιλαμβάνονται στα fixtures ρυθμίσεων της πλατφόρμας (`SettingsCurrentFixtures.php`).

> Το όνομα της μεταβλητής στον κώδικα εμφανίζεται με μονοδιάστατη γραμματοσειρά. Χρησιμοποιήστε το κατά τη δημιουργία σεναρίων μέσω του API ή όταν χρειάζεται να αλλάξετε αυτές τις ρυθμίσεις σε καθολικό επίπεδο επεξεργάζοντας το [`config/settings_override.yaml`](https://github.com/chamilo/chamilo-lms/wiki/Configurations#configsettings_overridesyaml).

## Ρυθμίσεις

### `allow_remove_tags_in_glossary_export`

**Αφαίρεση ετικετών HTML στην εξαγωγή γλωσσαρίου**

Όταν είναι ενεργοποιημένη, οι ετικέτες HTML αφαιρούνται από τους ορισμούς των όρων του γλωσσαρίου κατά την εξαγωγή.

*Προεπιλογή: `false`*

### `default_glossary_view`

**Προεπιλεγμένη προβολή γλωσσαρίου**

Επιλέξτε ποια προβολή ('table' ή 'list') θα χρησιμοποιείται από προεπιλογή στο εργαλείο γλωσσαρίου.

*Προεπιλογή: `table`*

### `show_glossary_in_extra_tools`

**Εμφάνιση των όρων του γλωσσαρίου σε επιπλέον εργαλεία**

Από εδώ μπορείτε να ρυθμίσετε τον τρόπο προσθήκης των όρων του γλωσσαρίου σε επιπλέον εργαλεία, όπως το εργαλείο μαθησιακής διαδρομής και το εργαλείο ασκήσεων
