# Ρυθμίσεις Παρουσιών

Προεπιλογές και συμπεριφορά του εργαλείου **Attendance**.

Αποκτήστε πρόσβαση σε αυτές τις ρυθμίσεις στο **Administration > Configuration settings > Attendance**. Αυτή η κατηγορία περιέχει **5 ρυθμίσεις**, οι οποίες παρατίθενται παρακάτω με τον τίτλο και το σχόλιο που περιλαμβάνονται στα fixtures ρυθμίσεων της πλατφόρμας (`SettingsCurrentFixtures.php`).

> Το όνομα της μεταβλητής στον κώδικα εμφανίζεται με μονοδιάστημα. Χρησιμοποιήστε το όταν γράφετε σενάρια μέσω του API ή όταν χρειάζεται να αλλάξετε αυτές τις ρυθμίσεις σε καθολικό επίπεδο επεξεργάζοντας το [`config/settings_override.yaml`](https://github.com/chamilo/chamilo-lms/wiki/Configurations#configsettings_overridesyaml).

## Ρυθμίσεις

### `allow_delete_attendance`

**Παρουσίες: ενεργοποίηση διαγραφής**

Η προεπιλεγμένη συμπεριφορά στο Chamilo είναι να αποκρύπτονται τα φύλλα παρουσιών αντί να διαγράφονται, σε περίπτωση που ο διδάσκων το κάνει κατά λάθος. Ενεργοποιήστε αυτή την επιλογή για να επιτρέψετε στους διδάσκοντες να διαγράφουν *πραγματικά* τα φύλλα παρουσιών.

*Προεπιλογή: `true`*

### `attendance_allow_comments`

**Να επιτρέπονται σχόλια στα φύλλα παρουσιών**

Οι διδάσκοντες και οι εκπαιδευόμενοι μπορούν να σχολιάζουν κάθε μεμονωμένη παρουσία (για αιτιολόγηση).

*Προεπιλογή: `false`*

### `attendance_calendar_set_duration` **v3**

**Διάρκεια γεγονότων παρουσίας**

Επιλογή ορισμού της διάρκειας για ένα γεγονός στο φύλλο παρουσιών.

*Προεπιλογή: `false`*

### `enable_sign_attendance_sheet`

**Υπογραφή παρουσιών**

Ενεργοποίηση λήψης υπογραφών για επιβεβαίωση της παρουσίας.

*Προεπιλογή: `false`*

### `multilevel_grading`

**Ενεργοποίηση βαθμολόγησης παρουσιών πολλαπλών επιπέδων**

Επιτρέπει τη βαθμολόγηση της παρουσίας με πολλαπλά επίπεδα αντί για ένα απλό σύστημα παρών/απών.

*Προεπιλογή: `false`*
