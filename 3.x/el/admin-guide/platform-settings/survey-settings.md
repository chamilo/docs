# Ρυθμίσεις ερευνών

Προεπιλογές και συμπεριφορά του εργαλείου **Surveys**.

Πρόσβαση σε αυτές τις ρυθμίσεις από **Administration > Configuration settings > Surveys**. Αυτή η κατηγορία περιέχει **12 ρυθμίσεις**, οι οποίες παρατίθενται παρακάτω με τον τίτλο και το σχόλιο που περιλαμβάνονται στα fixtures ρυθμίσεων της πλατφόρμας (`SettingsCurrentFixtures.php`).

> Το όνομα της μεταβλητής στον κώδικα εμφανίζεται με μονοδιάστημα. Χρησιμοποιήστε το κατά τη δημιουργία σεναρίων μέσω του API ή όταν χρειάζεται να αλλάξετε αυτές τις ρυθμίσεις σε καθολικό επίπεδο επεξεργάζοντας το [`config/settings_override.yaml`](https://github.com/chamilo/chamilo-lms/wiki/Configurations#configsettings_overridesyaml).

## Ρυθμίσεις

### `extend_rights_for_coach_on_survey`

**Επέκταση δικαιωμάτων για τους tutors στις έρευνες**

Ενεργοποιήστε αυτή την επιλογή για να επιτρέψετε στους tutors να δημιουργούν και να επεξεργάζονται έρευνες

*Προεπιλογή: `true`*


### `hide_survey_edition`

**Αποτροπή επεξεργασίας ερευνών**

Αποτροπή επεξεργασίας ερευνών για όλες τις έρευνες που παρατίθενται εδώ (κατά κωδικό). Χρησιμοποιήστε * για να αποτρέψετε την επεξεργασία όλων των ερευνών.

### `hide_survey_reporting_button`

**Απόκρυψη κουμπιού αναφορών έρευνας**

Επιτρέπει στους διαχειριστές να αποκρύπτουν το κουμπί αναφορών έρευνας όταν οι έρευνες χρησιμοποιούνται για αξιολόγηση διδασκόντων.

*Προεπιλογή: `false`*


### `show_pending_survey_in_menu`

**Εμφάνιση «Εκκρεμείς έρευνες» στο μενού**

Εμφάνιση στοιχείου μενού που επιτρέπει στους χρήστες να έχουν πρόσβαση στις εκκρεμείς έρευνές τους.

*Προεπιλογή: `false`*


### `show_surveys_base_in_sessions`

**Εμφάνιση ερευνών του βασικού μαθήματος σε όλα τα μαθήματα συνεδρίας**

[inferred] Να καθίστανται οι έρευνες του βασικού μαθήματος ορατές και διαθέσιμες στους εκπαιδευόμενους σε όλα τα σχετικά μαθήματα συνεδρίας.

*Προεπιλογή: `false`*


### `survey_additional_teacher_modify_actions`

**Προσθήκη πρόσθετων ενεργειών (ως συνδέσμων) στις λίστες ερευνών για διδάσκοντες**

Προσθήκη ενεργειών (συνήθως συνδεδεμένων με πρόσθετα) στη λίστα ερευνών. Χρησιμοποιήστε σύνταξη πίνακα ['myplugin' => ['MyPlugin', 'urlGeneratorCallback']].

### `survey_allow_answered_question_edit`

**Να επιτρέπεται στους διδάσκοντες να επεξεργάζονται ερωτήσεις έρευνας αφού έχουν απαντήσει οι φοιτητές**

[inferred] Να επιτρέπεται στους διδάσκοντες να τροποποιούν ερωτήσεις έρευνας ακόμη και αφού οι εκπαιδευόμενοι έχουν υποβάλει απαντήσεις.

*Προεπιλογή: `false`*


### `survey_anonymous_show_answered`

**Να επιτρέπεται στους διδάσκοντες να βλέπουν ποιος απάντησε σε ανώνυμες έρευνες**

Να επιτρέπεται στους διδάσκοντες να βλέπουν ποιοι εκπαιδευόμενοι έχουν ήδη απαντήσει σε ανώνυμη έρευνα. Αυτό εμφανίζεται μόνο αφού έχει απαντήσει περισσότερος από ένας χρήστης, ώστε να παραμένει δύσκολο να ταυτοποιηθεί ποιος απάντησε τι.

*Προεπιλογή: `false`*


### `survey_backwards_enable`

**Ενεργοποίηση κουμπιού «προηγούμενη ερώτηση» στις έρευνες**

[inferred] Ενεργοποίηση κουμπιού πλοήγησης «προηγούμενη ερώτηση» ώστε οι εκπαιδευόμενοι να μπορούν να επανεξετάζουν προηγούμενες ερωτήσεις έρευνας.

*Προεπιλογή: `false`*


### `survey_duplicate_order_by_name`

**Ταξινόμηση κατά όνομα φοιτητή κατά τη χρήση της δυνατότητας αντιγραφής έρευνας**

Η δυνατότητα αντιγραφής έρευνας απευθύνεται σε διδάσκοντες και προορίζεται να ζητά από τους διδάσκοντες να δώσουν την εκτίμησή τους για κάθε φοιτητή με σειρά. Αυτή η επιλογή θα ταξινομεί τις ερωτήσεις κατά το επώνυμο του εκπαιδευόμενου.

*Προεπιλογή: `true`*


### `survey_email_sender_noreply`

**Αποστολέας e-mail έρευνας (no-reply)**

Θα πρέπει οι προσκλήσεις έρευνας να χρησιμοποιούν τη διεύθυνση e-mail του tutor ή τη διεύθυνση no-reply που ορίζεται στην κύρια ενότητα διαμόρφωσης;

*Προεπιλογή: `coach`* (η επιλογή «Course tutor email sender» — η αποθηκευμένη τιμή παραμένει αμετάβλητη από προηγούμενες εκδόσεις του Chamilo, αλλά η επιλογή επισημαίνεται ως «tutor» στη διεπαφή)


### `survey_mark_question_as_required`

**Σήμανση όλων των ερωτήσεων έρευνας ως «υποχρεωτικών» από προεπιλογή**

[inferred] Αυτόματη σήμανση όλων των νεοδημιουργημένων ερωτήσεων έρευνας ως υποχρεωτικών απαντήσεων από προεπιλογή.

*Προεπιλογή: `false`*
