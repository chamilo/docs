# Ρυθμίσεις αλληλογραφίας

Πώς κατασκευάζεται η εξερχόμενη αλληλογραφία — ταυτότητα αποστολέα, διάταξη, υπογραφή και διευθύνσεις ειδικού σκοπού.

Πρόσβαση σε αυτές τις ρυθμίσεις από **Διαχείριση > Ρυθμίσεις διαμόρφωσης > Αλληλογραφία**. Αυτή η κατηγορία περιέχει **17 ρυθμίσεις**, που παρατίθενται παρακάτω με τον τίτλο και το σχόλιο όπως παρέχονται στα fixtures ρυθμίσεων της πλατφόρμας (`SettingsCurrentFixtures.php`).

> Το όνομα της μεταβλητής στον κώδικα εμφανίζεται σε μονοδιάστημα. Χρησιμοποιήστε το όταν γράφετε σενάρια μέσω του API ή όταν χρειάζεται να αλλάξετε αυτές τις ρυθμίσεις σε καθολικό επίπεδο επεξεργάζοντας το [`config/settings_override.yaml`](https://github.com/chamilo/chamilo-lms/wiki/Configurations#configsettings_overridesyaml).

## Ρυθμίσεις

### `allow_email_editor_for_anonymous`

**Επεξεργαστής e-mail για ανώνυμους**

Επιτρέπει σε ανώνυμους χρήστες να στέλνουν e-mail από την πλατφόρμα. Στην εποχή της ασφάλειας πληροφοριών αυτή δεν είναι συνιστώμενη επιλογή.

*Προεπιλογή: `true`*


### `cron_notification_help_desk`

**Διευθύνσεις e-mail για αποστολή αναφορών εκτέλεσης cronjobs**

Δίνεται ως πίνακας διευθύνσεων e-mail. Δεν λειτουργεί ακόμη για όλα τα cronjobs.

### `mail_content_style`

**Επιπλέον χαρακτηριστικά HTML σώματος e-mail**

Επιπλέον χαρακτηριστικά HTML που εφαρμόζονται στην ετικέτα body των παραγόμενων e-mail ειδοποιήσεων.

### `mail_header_style`

**Επιπλέον χαρακτηριστικά HTML κεφαλίδας e-mail**

Επιπλέον χαρακτηριστικά HTML που εφαρμόζονται στην ενότητα κεφαλίδας των παραγόμενων e-mail ειδοποιήσεων.

### `mailer_debug_enable`

**Αλληλογραφία: Εντοπισμός σφαλμάτων**

Επιλέξτε αν θέλετε να ενεργοποιήσετε τα αρχεία καταγραφής εντοπισμού σφαλμάτων αποστολής e-mail. Αυτά θα σας δώσουν περισσότερες πληροφορίες για το τι συμβαίνει κατά τη σύνδεση στην υπηρεσία αλληλογραφίας, αλλά δεν είναι κομψά και ενδέχεται να χαλάσουν τη σχεδίαση της σελίδας. Χρησιμοποιήστε τα μόνο όταν δεν υπάρχει δραστηριότητα χρηστών.

*Προεπιλογή: `false`*


### `mailer_dkim`

**Αλληλογραφία: Κεφαλίδες DKIM**

Εισαγάγετε έναν πίνακα JSON με τις ρυθμίσεις διαμόρφωσης DKIM (βλ. παράδειγμα).

### `mailer_dsn`

**DSN αλληλογραφίας**

Το DSN περιλαμβάνει πλήρως όλες τις παραμέτρους που απαιτούνται για σύνδεση στην υπηρεσία αλληλογραφίας. Μπορείτε να μάθετε περισσότερα στη διεύθυνση https://symfony.com/doc/7.4/mailer.html#using-built-in-transports. Ακολουθούν μερικά παραδείγματα υποστηριζόμενων συντάξεων DSN: https://symfony.com/doc/7.4/mailer.html#using-a-3rd-party-transport. Για το Microsoft 365, όπου το SMTP με βασικό έλεγχο ταυτότητας αποσύρεται, στείλτε μέσω του Microsoft Graph API με `microsoftgraph+api://CLIENT_ID:CLIENT_SECRET@default?tenantId=TENANT_ID` (κωδικοποιήστε URL οποιονδήποτε ειδικό χαρακτήρα στο μυστικό πελάτη). Αυτό απαιτεί καταχώριση εφαρμογής Entra ID με εκχωρημένη την άδεια εφαρμογής `Mail.Send` — βλ. [Διαμόρφωση e-mail](../installation/email-configuration.md).

*Προεπιλογή: `null://null`*


### `mailer_exclude_json`

**Αλληλογραφία: Αποφυγή χρήσης LD+JSON**

Ορισμένοι πελάτες e-mail δεν κατανοούν τη περιγραφική μορφή LD+JSON, εμφανίζοντάς την ως χαλαρή συμβολοσειρά JSON στον τελικό χρήστη. Αν αυτή είναι η περίπτωσή σας, ίσως θέλετε να ορίσετε την παρακάτω μεταβλητή σε 'false' για να απενεργοποιήσετε αυτή την κεφαλίδα.

*Προεπιλογή: `false`*


### `mailer_from_email`

**Αποστολή όλων των e-mail από αυτή τη διεύθυνση e-mail**

Ορίζει την προεπιλεγμένη διεύθυνση e-mail που χρησιμοποιείται στο πεδίο "from" των e-mail.

### `mailer_from_name`

**Αποστολή όλων των e-mail ως προερχόμενα από αυτό το (οργανωσιακό) όνομα**

Ορίζει το προεπιλεγμένο εμφανιζόμενο όνομα που χρησιμοποιείται για την αποστολή e-mail της πλατφόρμας. π.χ. "Ομάδα υποστήριξης".

### `mailer_mails_charset`

**Αλληλογραφία: σύνολο χαρακτήρων**

Σε περίπτωση που χρειάζεται να ορίσετε το σύνολο χαρακτήρων που θα χρησιμοποιείται κατά την αποστολή αυτών των e-mail. Αφήστε κενό αν δεν είστε βέβαιοι.

*Προεπιλογή: `UTF-8`*


### `messages_hide_mail_content`

**Απόκρυψη περιεχομένου e-mail για να φέρετε τους χρήστες στην πλατφόρμα**

Προτιμήστε σύντομες εκδόσεις e-mail με σύνδεσμο προς τον χώρο μηνυμάτων στην πλατφόρμα για αύξηση της εμπλοκής βάσει πλατφόρμας.

*Προεπιλογή: `false`*


### `notifications_extended_footer_message`

**Εκτεταμένο υποσέλιδο ειδοποιήσεων**

Προσθέστε προσαρμοσμένο επιπλέον υποσέλιδο για e-mail ειδοποιήσεων για συγκεκριμένη γλώσσα, για παράδειγμα για ανακοινώσεις πολιτικής απορρήτου. Μπορούν να προστεθούν πολλαπλές γλώσσες και παράγραφοι.

### `send_notification_score_in_percentage`

**Αποστολή βαθμολογίας σε ποσοστό στην ειδοποίηση αποτελεσμάτων τεστ**

Στέλνει τις βαθμολογίες ασκήσεων ως ποσοστά αντί για βαθμούς στα e-mail ειδοποίησης αποτελεσμάτων τεστ.

*Προεπιλογή: `false`*


### `send_two_inscription_confirmation_mail`

**Αποστολή 2 e-mail εγγραφής**

Αποστολή δύο ξεχωριστών e-mail κατά την εγγραφή. Ένα για το όνομα χρήστη, άλλο ένα για τον κωδικό πρόσβασης.

*Προεπιλογή: `false`*


### `show_user_email_in_notification`

**Εμφάνιση διεύθυνσης e-mail αποστολέα στις ειδοποιήσεις**

Περιλαμβάνει τη διεύθυνση e-mail του αποστολέα μαζί με το όνομά του σε προσωπικά μηνύματα και e-mail ειδοποιήσεων.

*Προεπιλογή: `false`*


### `update_users_email_to_dummy_except_admins`

**Ενημέρωση e-mail χρηστών σε εικονική τιμή κατά τις εισαγωγές**

Κατά τη διάρκεια ειδικών εισαγωγών χρηστών μέσω CSV cron, αντικατάσταση αυτόματα των e-mail με εικονικό e-mail username@example.com.

*Προεπιλογή: `false`*
