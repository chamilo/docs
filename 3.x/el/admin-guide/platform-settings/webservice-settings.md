# Ρυθμίσεις Υπηρεσιών Ιστού

Διαμόρφωση των παλαιού τύπου υπηρεσιών ιστού SOAP / REST (ξεχωριστά από τα σύγχρονα endpoints του API Platform).

Πρόσβαση σε αυτές τις ρυθμίσεις από **Διαχείριση > Ρυθμίσεις διαμόρφωσης > Υπηρεσίες ιστού**. Αυτή η κατηγορία περιέχει **7 ρυθμίσεις**, που παρατίθενται παρακάτω με τον τίτλο και το σχόλιο που περιλαμβάνονται στα fixtures ρυθμίσεων της πλατφόρμας (`SettingsCurrentFixtures.php`).

> Το όνομα της μεταβλητής στον κώδικα εμφανίζεται με μονοδιάστημα. Χρησιμοποιήστε το κατά τη δημιουργία σεναρίων μέσω του API ή όταν χρειάζεται να αλλάξετε αυτές τις ρυθμίσεις σε καθολικό επίπεδο επεξεργάζοντας το [`config/settings_override.yaml`](https://github.com/chamilo/chamilo-lms/wiki/Configurations#configsettings_overridesyaml).

## Ρυθμίσεις

### `allow_download_documents_by_api_key`

**Να επιτρέπεται η λήψη εγγράφων μαθήματος με κλειδί API**

Λήψη εγγράφων με επαλήθευση του κλειδιού REST API για έναν χρήστη

*Προεπιλογή: `false`*


### `disable_webservices`

**Απενεργοποίηση υπηρεσιών ιστού**

Εάν δεν χρησιμοποιείτε υπηρεσίες ιστού, ενεργοποιήστε αυτή την επιλογή για να αποφύγετε κάθε περιττό κίνδυνο ασφαλείας.

*Προεπιλογή: `false`*


### `messaging_allow_send_push_notification`

**Να επιτρέπονται οι ειδοποιήσεις Push στην εφαρμογή κινητού Chamilo Messaging**

Αποστολή ειδοποιήσεων Push μέσω της Κονσόλας Firebase της Google

*Προεπιλογή: `false`*


### `messaging_gdc_api_key`

**Κλειδί διακομιστή της Κονσόλας Firebase για Cloud Messaging**

Κλειδί διακομιστή (παλαιό token) από τα διαπιστευτήρια του έργου

### `messaging_gdc_project_number`

**Sender ID της Κονσόλας Firebase για Cloud Messaging**

Πρέπει να καταχωρίσετε ένα έργο στην <a href='https://console.firebase.google.com/'>Google Firebase Console</a>

### `webservice_enable_adminonly_api`

**Ενεργοποίηση υπηρεσιών ιστού μόνο για διαχειριστές**

Ορισμένες υπηρεσίες ιστού REST είναι χαρακτηρισμένες μόνο για διαχειριστές και είναι απενεργοποιημένες από προεπιλογή. Ενεργοποιήστε αυτή τη λειτουργία για να δώσετε πρόσβαση σε αυτές τις υπηρεσίες ιστού (σε χρήστες με διαπιστευτήρια διαχειριστή, προφανώς).

*Προεπιλογή: `false`*

### `webservice_return_user_field`

**Πεδίο χρήστη που επιστρέφουν οι υπηρεσίες ιστού**

Ζητήστε από τις υπηρεσίες ιστού REST (v2.php) να επιστρέφουν ένα άλλο αναγνωριστικό για πεδία που σχετίζονται με το αναγνωριστικό χρήστη. Αυτό είναι χρήσιμο εάν το εξωτερικό σύστημα δεν διαχειρίζεται πραγματικά τα αναγνωριστικά χρηστών όπως είναι στο Chamilo, καθώς βοηθά το εξωτερικό σύστημα να αντιστοιχίσει τα δεδομένα χρήστη που επιστρέφονται με κάποια εξωτερικά δεδομένα που είναι γνωστά στο Chamilo. Για παράδειγμα, εάν χρησιμοποιείτε εξωτερικό σύστημα αυθεντικοποίησης, μπορείτε να επιστρέψετε το επιπλέον πεδίο που χρησιμοποιείται για την αντιστοίχιση του χρήστη με το εξωτερικό σύστημα αυθεντικοποίησης αντί για το user.id.

*Προεπιλογή: `oauth2_id`*
