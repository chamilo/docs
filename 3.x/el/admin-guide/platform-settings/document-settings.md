# Ρυθμίσεις εγγράφων

Συμπεριφορά του εργαλείου **Έγγραφα** του μαθήματος — μεταφορτώσεις, επιτρεπόμενες επεκτάσεις, κοινή χρήση και πρότυπα.

Πρόσβαση σε αυτές τις ρυθμίσεις από **Διαχείριση > Ρυθμίσεις διαμόρφωσης > Έγγραφα**. Αυτή η κατηγορία περιέχει **29 ρυθμίσεις**, οι οποίες παρατίθενται παρακάτω με τον τίτλο και το σχόλιο που περιλαμβάνονται στα fixtures ρυθμίσεων της πλατφόρμας (`SettingsCurrentFixtures.php`).

> Το όνομα της μεταβλητής στον κώδικα εμφανίζεται σε μονοδιάστημα. Χρησιμοποιήστε το όταν γράφετε σενάρια μέσω του API ή όταν χρειάζεται να αλλάξετε αυτές τις ρυθμίσεις σε καθολικό επίπεδο επεξεργάζοντας το [`config/settings_override.yaml`](https://github.com/chamilo/chamilo-lms/wiki/Configurations#configsettings_overridesyaml).

## Ρυθμίσεις

### `access_url_specific_files`

**Ενεργοποίηση αρχείων ειδικών ανά URL**

Όταν αυτή η λειτουργία είναι ενεργοποιημένη σε διαμόρφωση πολλαπλών URL, μπορείτε να μεταβείτε στο κύριο URL και να παρέχετε εκδόσεις ειδικές ανά URL για οποιοδήποτε αρχείο (στο εργαλείο εγγράφων). Το αρχικό αρχείο θα αντικαθίσταται από την εναλλακτική έκδοση όποτε το βλέπετε από διαφορετικό URL. Αυτό σας επιτρέπει να προσαρμόσετε περαιτέρω κάθε URL, απολαμβάνοντας παράλληλα το πλεονέκτημα της επαναχρησιμοποίησης των ίδιων μαθημάτων πολλές φορές.

*Προεπιλογή: `false`*

### `default_document_quotum`

**Προεπιλεγμένος χώρος σκληρού δίσκου**

Ποιος είναι ο διαθέσιμος χώρος δίσκου για ένα μάθημα; Μπορείτε να παρακάμψετε το όριο για συγκεκριμένο μάθημα μέσω: διαχείριση πλατφόρμας > Μαθήματα > τροποποίηση

*Προεπιλογή: `1000`*


### `default_group_quotum`

**Διαθέσιμος χώρος δίσκου ομάδας**

Ποιος είναι ο προεπιλεγμένος διαθέσιμος χώρος σκληρού δίσκου για το εργαλείο εγγράφων μιας ομάδας;

*Προεπιλογή: `250`*


### `documents_custom_cloud_link_list`

**Ορισμός αυστηρής λίστας κεντρικών υπολογιστών για συνδέσμους cloud**

Το εργαλείο εγγράφων μπορεί να ενσωματώνει συνδέσμους προς αρχεία στο cloud. Η λίστα υπηρεσιών cloud περιορίζεται σε μια ενσωματωμένη λίστα, αλλά μπορείτε να ορίσετε τον πίνακα ‘links’ που θα περιέχει μια λίστα με τις δικές σας υπηρεσίες/URL. Η λίστα που ορίζεται εδώ θα αντικαταστήσει την προεπιλεγμένη λίστα.

### `documents_default_visibility_defined_in_course`

**Ορατότητα εγγράφων ορισμένη στο μάθημα**

Η προεπιλεγμένη ορατότητα εγγράφων για όλα τα μαθήματα

*Προεπιλογή: `false`*

### `documents_hide_download_icon`

**Απόκρυψη εικονιδίου λήψης εγγράφων**

Στο εργαλείο εγγράφων, απόκρυψη του εικονιδίου λήψης από τους χρήστες.

*Προεπιλογή: `false`*


### `enable_x_sendfile_headers`

**Ενεργοποίηση κεφαλίδων X-sendfile**

Ενεργοποιήστε το εάν έχετε ενεργοποιημένο το X-sendfile σε επίπεδο διακομιστή ιστού και θέλετε να προσθέσετε τις απαιτούμενες κεφαλίδες ώστε τα προγράμματα περιήγησης να το εντοπίσουν.

*Προεπιλογή: `false`*

### `group_category_document_access`

**Ενεργοποίηση επιλογών κοινής χρήσης για έγγραφα εντός κατηγορίας ομάδας**

Όταν είναι ενεργοποιημένο, οι διαχειριστές μπορούν να ορίσουν πρόσβαση εγγράφων και δικαιώματα κοινής χρήσης για ομάδες εγγράφων ανά κατηγορία.

*Προεπιλογή: `false`*


### `group_document_access`

**Ενεργοποίηση επιλογών κοινής χρήσης για έγγραφα ομάδας**

Όταν είναι ενεργοποιημένο, η κοινή χρήση εγγράφων και τα δικαιώματα πρόσβασης μπορούν να διαμορφωθούν σε επίπεδο ομάδας.

*Προεπιλογή: `false`*


### `pdf_export_watermark_by_course`

**Ενεργοποίηση ορισμού υδατογραφήματος ανά μάθημα**

Όταν αυτή η επιλογή είναι ενεργοποιημένη, οι εκπαιδευτές μπορούν να ορίσουν το δικό τους υδατογράφημα για τα έγγραφα στα μαθήματά τους.

*Προεπιλογή: `false`*


### `pdf_export_watermark_enable`

**Ενεργοποίηση υδατογραφήματος στην εξαγωγή PDF**

Ενεργοποιώντας αυτή την επιλογή, μπορείτε να μεταφορτώσετε μια εικόνα ή ένα κείμενο που θα προστίθεται αυτόματα ως υδατογράφημα σε όλες τις εξαγωγές PDF εγγράφων στο σύστημα.

*Προεπιλογή: `false`*

### `pdf_export_watermark_text`

**Κείμενο υδατογραφήματος PDF**

Αυτό το κείμενο θα προστίθεται ως υδατογράφημα στις εξαγωγές εγγράφων ως PDF.

### `permanently_remove_deleted_files`

**Τα διαγραμμένα αρχεία δεν μπορούν να ανακτηθούν**

Η διαγραφή ενός αρχείου στο εργαλείο εγγράφων το διαγράφει οριστικά. Το αρχείο δεν μπορεί να ανακτηθεί

*Προεπιλογή: `false`*

### `permissions_for_new_directories`

**Δικαιώματα για νέους καταλόγους**

Η δυνατότητα ορισμού των ρυθμίσεων δικαιωμάτων που θα αποδίδονται σε κάθε νεοδημιουργημένο κατάλογο σας επιτρέπει να βελτιώσετε την ασφάλεια έναντι επιθέσεων από χάκερ που μεταφορτώνουν επικίνδυνο περιεχόμενο στην πύλη σας. Η προεπιλεγμένη ρύθμιση (0770) θα πρέπει να αρκεί για να προσφέρει στον διακομιστή σας ένα εύλογο επίπεδο προστασίας. Η δεδομένη μορφή χρησιμοποιεί την ορολογία UNIX Ιδιοκτήτης-Ομάδα-Άλλοι με δικαιώματα Ανάγνωσης-Εγγραφής-Εκτέλεσης.

*Προεπιλογή: `0770`*


### `permissions_for_new_files`

**Δικαιώματα για νέα αρχεία**

Η δυνατότητα ορισμού των ρυθμίσεων δικαιωμάτων που θα αποδίδονται σε κάθε νεοδημιουργημένο αρχείο σας επιτρέπει να βελτιώσετε την ασφάλεια έναντι επιθέσεων από χάκερ που μεταφορτώνουν επικίνδυνο περιεχόμενο στην πύλη σας. Η προεπιλεγμένη ρύθμιση (0550) θα πρέπει να αρκεί για να προσφέρει στον διακομιστή σας ένα εύλογο επίπεδο προστασίας. Η δεδομένη μορφή χρησιμοποιεί την ορολογία UNIX Ιδιοκτήτης-Ομάδα-Άλλοι με δικαιώματα Ανάγνωσης-Εγγραφής-Εκτέλεσης. Εάν χρησιμοποιείτε Oogie, φροντίστε ώστε ο χρήστης που εκκινεί το LibreOffice να μπορεί να γράφει αρχεία στον φάκελο του μαθήματος.

*Προεπιλογή: `0660`*


### `send_notification_when_document_added`

**Αποστολή ειδοποίησης στους εκπαιδευόμενους όταν προστίθεται έγγραφο**

Κάθε φορά που κάποιος δημιουργεί ένα νέο στοιχείο στο εργαλείο εγγράφων, αποστολή ειδοποίησης στους χρήστες.

*Προεπιλογή: `false`*

### `show_default_folders`

**Εμφάνιση στο εργαλείο εγγράφων όλων των φακέλων που περιέχουν πολυμεσικούς πόρους που παρέχονται από προεπιλογή**

Φάκελοι πολυμεσικών αρχείων που περιέχουν αρχεία παρεχόμενα από προεπιλογή, οργανωμένα σε κατηγορίες βίντεο, ήχου, εικόνας και κινούμενων σχεδίων flash για χρήση στα μαθήματά τους. Ακόμη και αν τους καταστήσετε αόρατους στο εργαλείο εγγράφων, μπορείτε να συνεχίσετε να χρησιμοποιείτε αυτούς τους πόρους στον επεξεργαστή ιστού της πλατφόρμας.

*Προεπιλογή: `true`*

### `show_documents_preview`

**Εμφάνιση προεπισκόπησης εγγράφων**

Η εμφάνιση προεπισκοπήσεων των εγγράφων στο εργαλείο εγγράφων αποφεύγει τη φόρτωση νέας σελίδας μόνο για την εμφάνιση ενός εγγράφου, αλλά μπορεί να είναι ασταθής σε ορισμένα παλαιότερα προγράμματα περιήγησης ή σε οθόνες μικρότερου πλάτους.

*Προεπιλογή: `false`*

### `show_users_folders`

**Εμφάνιση φακέλων χρηστών στο εργαλείο εγγράφων**

Αυτή η επιλογή σας επιτρέπει να εμφανίζετε ή να αποκρύπτετε από τους εκπαιδευτές τους φακέλους που δημιουργεί το σύστημα για κάθε χρήστη που επισκέπτεται το εργαλείο εγγράφων ή αποστέλλει ένα αρχείο μέσω του επεξεργαστή ιστού. Αν εμφανίσετε αυτούς τους φακέλους στους εκπαιδευτές, μπορούν να τους καταστήσουν ορατούς ή όχι στους εκπαιδευόμενους και να επιτρέψουν σε κάθε εκπαιδευόμενο να έχει έναν συγκεκριμένο χώρο στο μάθημα όπου όχι μόνο αποθηκεύει έγγραφα, αλλά μπορεί επίσης να δημιουργεί και να επεξεργάζεται ιστοσελίδες και να εξάγει σε pdf, να κάνει σχέδια, να δημιουργεί προσωπικά πρότυπα ιστού, να αποστέλλει αρχεία, καθώς και να δημιουργεί, να μετακινεί και να διαγράφει καταλόγους και αρχεία και να κάνει αντίγραφα ασφαλείας από τους φακέλους του. Κάθε χρήστης του μαθήματος διαθέτει έναν πλήρη διαχειριστή εγγράφων. Επίσης, να θυμάστε ότι οποιοσδήποτε χρήστης μπορεί να αντιγράψει ένα αρχείο που είναι ορατό από οποιονδήποτε φάκελο στο εργαλείο εγγράφων (είτε είναι ιδιοκτήτης είτε όχι) στα χαρτοφυλάκιά του ή στην περιοχή προσωπικών εγγράφων του κοινωνικού δικτύου, τα οποία θα είναι διαθέσιμα ώστε να μπορεί να τα χρησιμοποιήσει σε άλλα μαθήματα.

*Προεπιλογή: `true`*

### `students_download_folders`

**Να επιτρέπεται στους εκπαιδευόμενους η λήψη καταλόγων**

Να επιτρέπεται στους εκπαιδευόμενους να συσκευάζουν και να κατεβάζουν έναν πλήρη κατάλογο από το εργαλείο εγγράφων

*Προεπιλογή: `true`*


### `students_export2pdf`

**Να επιτρέπεται στους εκπαιδευόμενους η εξαγωγή εγγράφων ιστού σε μορφή PDF στα εργαλεία εγγράφων και wiki**

Αυτή η λειτουργία είναι ενεργοποιημένη από προεπιλογή, αλλά σε περίπτωση κατάχρησης που προκαλεί υπερφόρτωση του διακομιστή, ή σε συγκεκριμένα μαθησιακά περιβάλλοντα, ενδέχεται να θέλετε να την απενεργοποιήσετε για όλα τα μαθήματα.

*Προεπιλογή: `true`*

### `thematic_pdf_orientation`

**Προσανατολισμός PDF για την πρόοδο μαθήματος**

Στο εργαλείο προόδου μαθήματος, μπορείτε να εκτυπώσετε ένα PDF των διαφόρων στοιχείων. Ορίστε ‘portrait’ ή ‘landscape’ (τεχνικοί όροι) για να το αλλάξετε.

*Προεπιλογή: `landscape`*


### `upload_extensions_blacklist`

**Μαύρη λίστα - ρύθμιση**

Η μαύρη λίστα χρησιμοποιείται για το φιλτράρισμα των επεκτάσεων αρχείων αφαιρώντας (ή μετονομάζοντας) οποιοδήποτε αρχείο του οποίου η επέκταση εμφανίζεται στην παρακάτω μαύρη λίστα. Οι επεκτάσεις πρέπει να εμφανίζονται χωρίς την αρχική τελεία (.) και να διαχωρίζονται με ερωτηματικό (;) όπως το ακόλουθο:  exe;com;bat;scr;php. Τα αρχεία χωρίς επέκταση γίνονται αποδεκτά. Η πεζότητα των γραμμάτων (κεφαλαία/πεζά) δεν έχει σημασία.

### `upload_extensions_list_type`

**Τύπος φιλτραρίσματος στις μεταφορτώσεις εγγράφων**

Αν θέλετε να χρησιμοποιήσετε φιλτράρισμα μαύρης λίστας ή λευκής λίστας. Δείτε την περιγραφή μαύρης λίστας ή λευκής λίστας παρακάτω για περισσότερες λεπτομέρειες.

*Προεπιλογή: `blacklist`*


### `upload_extensions_replace_by`

**Επέκταση αντικατάστασης**

Εισαγάγετε την επέκταση που θέλετε να χρησιμοποιήσετε για την αντικατάσταση των επικίνδυνων επεκτάσεων που εντοπίζει το φίλτρο. Απαιτείται μόνο αν έχετε επιλέξει φίλτρο με αντικατάσταση.

*Προεπιλογή: `dangerous`*


### `upload_extensions_skip`

**Συμπεριφορά φιλτραρίσματος (παράλειψη/μετονομασία)**

Αν επιλέξετε παράλειψη, τα αρχεία που φιλτράρονται μέσω της μαύρης ή της λευκής λίστας δεν θα μεταφορτωθούν στο σύστημα. Αν επιλέξετε να τα μετονομάσετε, η επέκτασή τους θα αντικατασταθεί από αυτήν που ορίζεται στη ρύθμιση αντικατάστασης επέκτασης. Προσοχή: η μετονομασία δεν σας προστατεύει πραγματικά και μπορεί να προκαλέσει σύγκρουση ονομάτων αν υπάρχουν πολλά αρχεία με το ίδιο όνομα αλλά διαφορετικές επεκτάσεις.

*Προεπιλογή: `true`*


### `upload_extensions_whitelist`

**Λευκή λίστα - ρύθμιση**

Η λευκή λίστα χρησιμοποιείται για το φιλτράρισμα των επεκτάσεων αρχείων αφαιρώντας (ή μετονομάζοντας) οποιοδήποτε αρχείο του οποίου η επέκταση *ΔΕΝ* εμφανίζεται στην παρακάτω λευκή λίστα. Θεωρείται γενικά ασφαλέστερη αλλά πιο περιοριστική προσέγγιση φιλτραρίσματος. Οι επεκτάσεις πρέπει να εμφανίζονται χωρίς την αρχική τελεία (.) και να διαχωρίζονται με ερωτηματικό (;) όπως το ακόλουθο:  htm;html;txt;doc;xls;ppt;jpg;jpeg;gif;sxw. Τα αρχεία χωρίς επέκταση γίνονται αποδεκτά. Η πεζότητα των γραμμάτων (κεφαλαία/πεζά) δεν έχει σημασία.

### `users_copy_files`

**Να επιτρέπεται στους χρήστες η αντιγραφή αρχείων από ένα μάθημα στην προσωπική περιοχή αρχείων**

Επιτρέπει στους χρήστες να αντιγράφουν αρχεία από ένα μάθημα στην προσωπική περιοχή αρχείων τους, ορατή μέσω του Κοινωνικού Δικτύου ή μέσω του επεξεργαστή HTML όταν βρίσκονται εκτός μαθήματος

*Προεπιλογή: `true`*


### `video_features`

**Δυνατότητες βίντεο**

Πίνακας επιπλέον δυνατοτήτων που μπορείτε να ενεργοποιήσετε για τον αναπαραγωγέα βίντεο στο Chamilo. Οι επιλογές περιλαμβάνουν το 'speed', το οποίο σας επιτρέπει να αλλάξετε την ταχύτητα αναπαραγωγής ενός βίντεο.
