# Ρυθμίσεις εισιτηρίων

Συμπεριφορά του συστήματος **Tickets** (helpdesk).

Πρόσβαση σε αυτές τις ρυθμίσεις από **Διαχείριση > Ρυθμίσεις διαμόρφωσης > Tickets**. Αυτή η κατηγορία περιέχει **7 ρυθμίσεις**, που παρατίθενται παρακάτω με τον τίτλο και το σχόλιο που περιλαμβάνονται στα fixtures ρυθμίσεων της πλατφόρμας (`SettingsCurrentFixtures.php`).

> Το όνομα της μεταβλητής στον κώδικα εμφανίζεται σε monospace. Χρησιμοποιήστε το κατά τη δημιουργία σεναρίων μέσω του API ή όταν χρειάζεται να αλλάξετε αυτές τις ρυθμίσεις σε καθολικό επίπεδο επεξεργάζοντας το [`config/settings_override.yaml`](https://github.com/chamilo/chamilo-lms/wiki/Configurations#configsettings_overridesyaml).

## Ρυθμίσεις

### `show_link_bug_notification`

**Εμφάνιση συνδέσμου αναφοράς σφάλματος**

Εμφάνιση συνδέσμου στην κεφαλίδα για αναφορά σφάλματος στην πλατφόρμα υποστήριξής μας (http://support.chamilo.org). Όταν γίνεται κλικ στον σύνδεσμο, ο χρήστης μεταφέρεται στην πλατφόρμα υποστήριξης, σε μια σελίδα wiki που περιγράφει τη διαδικασία αναφοράς σφαλμάτων.

*Προεπιλογή: `false`*


### `show_link_ticket_notification`

**Εμφάνιση συνδέσμου δημιουργίας εισιτηρίου**

Εμφάνιση του συνδέσμου δημιουργίας εισιτηρίου στους χρήστες στη δεξιά πλευρά της πύλης

*Προεπιλογή: `false`*


### `ticket_allow_category_edition`

**Να επιτρέπεται η επεξεργασία κατηγοριών εισιτηρίων**

Να επιτρέπεται η επεξεργασία κατηγοριών από τους διαχειριστές.

*Προεπιλογή: `false`*

### `ticket_allow_student_add`

**Να επιτρέπεται στους χρήστες να προσθέτουν εισιτήρια**

Επιτρέπει σε όλους τους χρήστες να προσθέτουν εισιτήρια, όχι μόνο στους διαχειριστές.

*Προεπιλογή: `false`*

### `ticket_project_user_roles`

**Πρόσβαση ανά ρόλο σε έργα εισιτηρίων**

Να επιτρέπεται η πρόσβαση σε έργα εισιτηρίων από συγκεκριμένους ρόλους χρηστών. Παράδειγμα: ['permissions' => [1 => [17]] όπου project_id = 1, STUDENT_BOSS = 17.

> Αυτή η ρύθμιση είναι υποχρεωτική για μη διαχειριστές χρήστες: χωρίς ορισμένη αντιστοίχιση ρόλων εδώ, μόνο οι διαχειριστές μπορούν να έχουν πρόσβαση στα εισιτήρια υποστήριξης. Για να δώσετε σε οποιονδήποτε άλλο ρόλο πρόσβαση σε ένα έργο εισιτηρίων, προσθέστε το αναγνωριστικό ρόλου του στα δικαιώματα αυτής της ρύθμισης για το συγκεκριμένο έργο.

### `ticket_send_warning_to_all_admins`

**Αποστολή μηνυμάτων προειδοποίησης εισιτηρίων στους διαχειριστές**

Αποστολή μηνύματος εάν δημιουργήθηκε εισιτήριο χωρίς κατηγορία ή εάν μια κατηγορία δεν έχει ανατεθειμένο διαχειριστή.

*Προεπιλογή: `false`*


### `ticket_warn_admin_no_user_in_category`

**Αποστολή ειδοποίησης στους διαχειριστές εάν η κατηγορία εισιτηρίων δεν έχει υπεύθυνο**

Αποστολή μηνύματος προειδοποίησης (e-mail και μήνυμα Chamilo) σε όλους τους διαχειριστές εάν δεν έχει ανατεθεί χρήστης σε μια κατηγορία.

*Προεπιλογή: `false`*
