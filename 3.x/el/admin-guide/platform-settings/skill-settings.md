# Ρυθμίσεις δεξιοτήτων

Συμπεριφορά του συστήματος **Skills** — δέντρο δεξιοτήτων, κανόνες απονομής, ενσωμάτωση προφίλ.

Πρόσβαση σε αυτές τις ρυθμίσεις από **Διαχείριση > Ρυθμίσεις διαμόρφωσης > Skills**. Αυτή η κατηγορία περιέχει **13 ρυθμίσεις**, που παρατίθενται παρακάτω με τον τίτλο και το σχόλιο όπως παρέχονται στα fixtures ρυθμίσεων της πλατφόρμας (`SettingsCurrentFixtures.php`).

> Το όνομα της μεταβλητής στον κώδικα εμφανίζεται με monospace. Χρησιμοποιήστε το όταν κάνετε scripting μέσω του API ή όταν χρειάζεται να αλλάξετε αυτές τις ρυθμίσεις σε καθολικό επίπεδο επεξεργάζοντας το [`config/settings_override.yaml`](https://github.com/chamilo/chamilo-lms/wiki/Configurations#configsettings_overridesyaml).

## Ρυθμίσεις

### `allow_hr_skills_management`

**Να επιτρέπεται η διαχείριση δεξιοτήτων από HR**

Επιτρέπει στο HR να διαχειρίζεται τις δεξιότητες

*Προεπιλογή: `true`*


### `allow_private_skills`

**Απόκρυψη δεξιοτήτων από τους εκπαιδευόμενους**

Αν ενεργοποιηθεί, οι δεξιότητες είναι ορατές μόνο σε διαχειριστές, εκπαιδευτές (που σχετίζονται με έναν χρήστη μέσω μαθήματος) και χρήστες HRM (αν σχετίζονται με έναν χρήστη).

*Προεπιλογή: `false`*


### `allow_skill_rel_items`

**Ενεργοποίηση σύνδεσης δεξιοτήτων με στοιχεία**

Ενεργοποιεί μια σημαντική λειτουργία που επιτρέπει σε οποιοδήποτε στοιχείο να συνδεθεί με (και συνεπώς να επιτρέψει την απόκτηση) μιας δεξιότητας. Η λειτουργία εξακολουθεί να απαιτεί επιβεβαίωση της απόκτησης της δεξιότητας από τον εκπαιδευτή, επομένως η απόκτηση δεν είναι αυτόματη.

*Προεπιλογή: `false`*


### `allow_skills_tool`

**Να επιτρέπεται το εργαλείο Skills**

Οι χρήστες μπορούν να βλέπουν τις δεξιότητές τους στο κοινωνικό δίκτυο και σε ένα μπλοκ στην αρχική σελίδα.

*Προεπιλογή: `true`*

### `allow_teacher_access_student_skills`

**Να επιτρέπεται στους εκπαιδευτές η πρόσβαση στις δεξιότητες των εκπαιδευόμενων**

[inferred] Να επιτρέπεται στους εκπαιδευτές να βλέπουν και να παρακολουθούν τις δεξιότητες που αποκτούν οι εκπαιδευόμενοι στα μαθήματά τους.

*Προεπιλογή: `false`*


### `badge_assignation_notification`

**Αποστολή ειδοποίησης στον εκπαιδευόμενο όταν έχει αποκτηθεί δεξιότητα/σήμα**

[inferred] Αποστολή ειδοποιήσεων στους εκπαιδευόμενους όταν αποκτούν νέα δεξιότητα ή επίτευγμα σήματος.

*Προεπιλογή: `false`*


### `hide_skill_levels`

**Απόκρυψη της λειτουργίας επιπέδων δεξιοτήτων**

[inferred] Απόκρυψη της ιεραρχίας επιπέδων δεξιοτήτων και των ετικετών επιπέδων στις προβολές που σχετίζονται με δεξιότητες.

*Προεπιλογή: `false`*


### `manual_assignment_subskill_autoload`

**Ανάθεση δεξιοτήτων σε χρήστη: αυτόματη φόρτωση υποδεξιοτήτων**

Κατά τη χειροκίνητη ανάθεση δεξιοτήτων σε έναν χρήστη, η φόρμα μπορεί να ρυθμιστεί ώστε να σας προτείνει αυτόματα την ανάθεση μιας υποδεξιότητας αντί της δεξιότητας που επιλέξατε.

*Προεπιλογή: `false`*


### `openbadges_backpack`

**URL backpack OpenBadges**

Το URL του διακομιστή backpack OpenBadges που θα χρησιμοποιείται από προεπιλογή για όλους τους χρήστες που θέλουν να εξάγουν τα σήματά τους. Η προεπιλογή είναι το ανοιχτό και δωρεάν αποθετήριο backpack του Mozilla Foundation: https://backpack.openbadges.org/

### `show_full_skill_name_on_skill_wheel`

**Εμφάνιση πλήρους ονόματος δεξιότητας στον τροχό δεξιοτήτων**

Στον τροχό δεξιοτήτων, εμφανίζει το όνομα της δεξιότητας όταν αυτή έχει σύντομο κωδικό.

*Προεπιλογή: `false`*


### `skill_levels_names`

**Ονόματα επιπέδων δεξιοτήτων**

Ορίστε ονόματα για τα επίπεδα δεξιοτήτων ως πίνακα id => name.

### `skills_hierarchical_view_in_user_tracking`

**Εμφάνιση δεξιοτήτων ως ιεραρχικός πίνακας**

[inferred] Εμφάνιση των δεξιοτήτων του εκπαιδευόμενου ως ιεραρχική δομή δέντρου στις σελίδες προόδου και αναφορών.

*Προεπιλογή: `false`*


### `skills_teachers_can_assign_skills`

**Να επιτρέπεται στους εκπαιδευτές να ορίζουν ποιες δεξιότητες αποκτώνται μέσω των μαθημάτων τους**

Από προεπιλογή, μόνο οι διαχειριστές μπορούν να αποφασίσουν ποιες δεξιότητες μπορούν να αποκτηθούν μέσω ποιου μαθήματος.

*Προεπιλογή: `false`*
