# Ρυθμίσεις Ομάδων

Συμπεριφορά του εργαλείου **Ομάδες** του μαθήματος.

Αποκτήστε πρόσβαση σε αυτές τις ρυθμίσεις στην ενότητα **Διαχείριση > Ρυθμίσεις διαμόρφωσης > Ομάδες**. Αυτή η κατηγορία περιέχει **3 ρυθμίσεις**, οι οποίες παρατίθενται παρακάτω με τον τίτλο και το σχόλιο που περιλαμβάνονται στα fixtures ρυθμίσεων της πλατφόρμας (`SettingsCurrentFixtures.php`).

> Το όνομα της μεταβλητής στον κώδικα εμφανίζεται με monospace. Χρησιμοποιήστε το όταν γράφετε σενάρια μέσω του API ή όταν χρειάζεται να αλλάξετε αυτές τις ρυθμίσεις σε καθολικό επίπεδο επεξεργάζοντας το [`config/settings_override.yaml`](https://github.com/chamilo/chamilo-lms/wiki/Configurations#configsettings_overridesyaml).

## Ρυθμίσεις

### `allow_group_categories`

**Κατηγορίες ομάδων**

Να επιτρέπεται στους διδάσκοντες να δημιουργούν κατηγορίες στο εργαλείο Ομάδες;

*Προεπιλογή: `false`*


### `hide_course_group_if_no_tools_available`

**Απόκρυψη ομάδας μαθήματος αν δεν υπάρχει εργαλείο**

Αν δεν υπάρχει διαθέσιμο εργαλείο σε μια ομάδα και ο χρήστης δεν είναι εγγεγραμμένος στην ίδια την ομάδα, απόκρυψη της ομάδας πλήρως από τη λίστα ομάδων.

*Προεπιλογή: `false`*


### `show_groups_to_users`

**Εμφάνιση τάξεων στους χρήστες**

Εμφάνιση των τάξεων στους χρήστες. Οι τάξεις είναι μια λειτουργία που σας επιτρέπει να εγγράφετε/διαγράφετε ομάδες χρηστών σε μια συνεδρία ή ένα μάθημα απευθείας, μειώνοντας τον διοικητικό φόρτο. Όταν επιλέξετε αυτή την επιλογή, οι εκπαιδευόμενοι θα μπορούν να βλέπουν σε ποια τάξη ανήκουν μέσω της διεπαφής κοινωνικού δικτύου τους.

*Προεπιλογή: `false`*
