# Ρυθμίσεις πιστοποιητικών

Προεπιλογές που εφαρμόζονται όταν ένας εκπαιδευόμενος αποκτά πιστοποιητικό από το βαθμολόγιο.

Πρόσβαση σε αυτές τις ρυθμίσεις από **Διαχείριση > Ρυθμίσεις διαμόρφωσης > Πιστοποιητικά**. Αυτή η κατηγορία περιέχει **11 ρυθμίσεις**, που παρατίθενται παρακάτω με τον τίτλο και το σχόλιο όπως παρέχονται στα fixtures ρυθμίσεων της πλατφόρμας (`SettingsCurrentFixtures.php`).

> Το όνομα της μεταβλητής στον κώδικα εμφανίζεται σε μονοδιάστημα. Χρησιμοποιήστε το όταν γράφετε σενάρια μέσω του API ή όταν χρειάζεται να αλλάξετε αυτές τις ρυθμίσεις σε καθολικό επίπεδο επεξεργάζοντας το [`config/settings_override.yaml`](https://github.com/chamilo/chamilo-lms/wiki/Configurations#configsettings_overridesyaml).

## Ρυθμίσεις

### `add_certificate_pdf_footer`

**Προσθήκη υποσέλιδου στις εξαγωγές πιστοποιητικών σε PDF**

Όταν είναι ενεργοποιημένο, προστίθεται υποσέλιδο στις εξαγωγές πιστοποιητικών σε PDF.

*Προεπιλογή: `false`*

### `add_gradebook_certificates_cron_task_enabled` **v3**

**Αυτόματη δημιουργία πιστοποιητικών κατά κλήση WS**

Όταν είναι ενεργοποιημένο και χρησιμοποιείται η υπηρεσία ιστού WSCertificatesList, αυτή η επιλογή διασφαλίζει ότι όλα τα πιστοποιητικά έχουν δημιουργηθεί από τους χρήστες εφόσον έχουν επιτύχει επαρκή βαθμολογία σε όλα τα στοιχεία που ορίζονται στα βαθμολόγια για όλα τα μαθήματα και τις συνεδρίες (αυτό ενδέχεται να καταναλώσει σημαντικούς πόρους επεξεργασίας στον διακομιστή σας).

*Προεπιλογή: `false`*

### `allow_certificates_search` **v3**

**Να επιτρέπεται η αναζήτηση πιστοποιητικών**

Να επιτρέπεται σε χρήστες και επισκέπτες να αναζητούν τα δημιουργημένα πιστοποιητικά από το μενού της επάνω γραμμής.

*Προεπιλογή: `false`*

### `allow_general_certificate`

**Ενεργοποίηση γενικού πιστοποιητικού**

Ένα γενικό πιστοποιητικό είναι πιστοποιητικό που συγκεντρώνει όλα τα επιτεύγματα του χρήστη στα μαθήματα που παρακολούθησε.

*Προεπιλογή: `false`*

### `allow_public_certificates`

**Να επιτρέπονται δημόσια πιστοποιητικά**

Τα πιστοποιητικά χρηστών μπορούν να προβάλλονται από μη εγγεγραμμένους χρήστες.

*Προεπιλογή: `false`*

### `certificate_filter_by_official_code`

**Φίλτρο πιστοποιητικών κατά επίσημο κωδικό**

Προσθήκη φίλτρου με βάση τον επίσημο κωδικό των σπουδαστών στη λίστα πιστοποιητικών.

*Προεπιλογή: `false`*

### `certificate_pdf_orientation`

**Προσανατολισμός PDF για πιστοποιητικά**

Ορίστε «portrait» ή «landscape» (τεχνικοί όροι) για τα πιστοποιητικά PDF.

*Προεπιλογή: `landscape`*

### `hide_certificate_export_link`

**Πιστοποιητικά: απόκρυψη συνδέσμου εξαγωγής PDF για όλους**

Ενεργοποιήστε για να αφαιρέσετε πλήρως τη δυνατότητα εξαγωγής πιστοποιητικών σε PDF (για όλους τους χρήστες). Αν είναι ενεργοποιημένο, περιλαμβάνει και την απόκρυψη από τους σπουδαστές.

*Προεπιλογή: `false`*

### `hide_certificate_export_link_students`

**Πιστοποιητικά: απόκρυψη συνδέσμου εξαγωγής από τους σπουδαστές**

Αν είναι ενεργοποιημένο, οι σπουδαστές δεν θα μπορούν να εξάγουν τα πιστοποιητικά τους σε PDF. Αυτή η επιλογή είναι διαθέσιμη επειδή, ανάλογα με την ακριβή δομή HTML του προτύπου πιστοποιητικού, η εξαγωγή PDF ενδέχεται να είναι χαμηλής ποιότητας. Σε αυτή την περίπτωση, είναι προτιμότερο να εμφανίζεται στους σπουδαστές μόνο το πιστοποιητικό HTML.

*Προεπιλογή: `false`*

### `hide_my_certificate_link`

**Απόκρυψη συνδέσμου «το πιστοποιητικό μου»**

Απόκρυψη της σελίδας πιστοποιητικών για μη διαχειριστές.

*Προεπιλογή: `false`*

### `session_admin_can_download_all_certificates`

**Να επιτρέπεται στους διαχειριστές συνεδρίας η λήψη ιδιωτικών πιστοποιητικών**

Αν είναι ενεργοποιημένο, οι διαχειριστές συνεδρίας μπορούν να κατεβάζουν πιστοποιητικά ακόμη και αν δεν έχουν δημοσιευτεί δημόσια.

*Προεπιλογή: `false`*

## Δείτε επίσης

Στα πιστοποιητικά μπορεί πλέον να δοθεί περίοδος ισχύος και ημερομηνία λήξης, με αυτοματοποιημένες ή χειροκίνητες υπενθυμίσεις λήξης. Αυτό δεν ρυθμίζεται εδώ — η περίοδος ισχύος είναι ρύθμιση βαθμολογίου που απευθύνεται στον εκπαιδευτή, και ο διακόπτης ενεργοποίησης/απενεργοποίησης του cron υπενθυμίσεων βρίσκεται στην κατηγορία **Εργασίες Cron**. Δείτε [Πιστοποιητικά και δεξιότητες](../../teacher-guide/tracking-and-reporting/certificates-and-skills.md#certificate-validity-and-expiry) και [Ρυθμίσεις εργασιών Cron](crons-settings.md#certificate-expiry-reminders).
