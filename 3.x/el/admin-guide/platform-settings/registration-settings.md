# Ρυθμίσεις εγγραφής

Πολιτική αυτοεγγραφής και ανακατευθύνσεις μετά την εγγραφή — τι ζητείται από τους νέους χρήστες και πού καταλήγουν.

Προσπελάστε αυτές τις ρυθμίσεις στο **Διαχείριση > Ρυθμίσεις διαμόρφωσης > Εγγραφή**. Αυτή η κατηγορία περιέχει **21 ρυθμίσεις**, οι οποίες παρατίθενται παρακάτω με τον τίτλο και το σχόλιο που περιλαμβάνονται στα fixtures ρυθμίσεων της πλατφόρμας (`SettingsCurrentFixtures.php`).

> Το όνομα της μεταβλητής στον κώδικα εμφανίζεται με μονοδιάστημα. Χρησιμοποιήστε το όταν γράφετε σενάρια μέσω του API ή όταν χρειάζεται να αλλάξετε αυτές τις ρυθμίσεις σε καθολικό επίπεδο επεξεργάζοντας το [`config/settings_override.yaml`](https://github.com/chamilo/chamilo-lms/wiki/Configurations#configsettings_overridesyaml).

## Ρυθμίσεις

### `allow_double_validation_in_registration`

**Διπλή επικύρωση για τη διαδικασία εγγραφής**

Απλώς εμφανίζει αίτημα επιβεβαίωσης στη σελίδα εγγραφής πριν προχωρήσει η δημιουργία του χρήστη.

*Προεπιλογή: `false`*


### `allow_fields_inscription`

**Περιορισμός των πεδίων που εμφανίζονται κατά την εγγραφή**

Αν θέλετε να εμφανίζονται μόνο ορισμένα από τα διαθέσιμα πεδία προφίλ, μπορείτε να συμπληρώσετε τον πίνακα εδώ με τα υποστοιχεία 'fields' και 'extra_fields' που περιέχουν πίνακες με λίστα των πεδίων προς εμφάνιση.

### `allow_invitation_registration` **v3**

**Να επιτρέπεται η εγγραφή μέσω συνδέσμων πρόσκλησης μαθήματος**

Όταν ενεργοποιηθεί, ένας εκπαιδευτής/διαχειριστής μπορεί να στείλει έναν σύνδεσμο πρόσκλησης μίας χρήσης από το εργαλείο Χρήστες ενός μαθήματος, ώστε ένα μη εγγεγραμμένο άτομο να φτάσει στη φόρμα εγγραφής και να εγγραφεί ακόμη και όταν η γενική αυτοεγγραφή (`allow_registration`) είναι απενεργοποιημένη.

*Προεπιλογή: `false`*

Δείτε το [Εγγραφή χρηστών](../../teacher-guide/assessing-learners/subscribing-users.md#inviting-users-by-email) για την πλευρά αυτής της δυνατότητας που απευθύνεται στον εκπαιδευτή.

### `allow_lostpassword`

**Χαμένος κωδικός πρόσβασης**

Επιτρέπεται στους χρήστες να ζητούν τον χαμένο κωδικό πρόσβασής τους;

*Προεπιλογή: `true`*

### `allow_registration`

**Εγγραφή**

Επιτρέπεται η εγγραφή ως νέος χρήστης; Μπορούν οι χρήστες να δημιουργούν νέους λογαριασμούς;

*Προεπιλογή: `false`*

### `allow_registration_as_teacher`

**Εγγραφή ως εκπαιδευτής**

Μπορεί κάποιος να εγγραφεί ως εκπαιδευτής (με δυνατότητα δημιουργίας μαθημάτων);

*Προεπιλογή: `false`*

### `allow_terms_conditions`

**Ενεργοποίηση όρων και προϋποθέσεων**

Αυτή η επιλογή θα εμφανίσει τους Όρους και Προϋποθέσεις στη φόρμα εγγραφής για νέους χρήστες. Πρέπει πρώτα να ρυθμιστεί στη σελίδα διαχείρισης της πύλης.

*Προεπιλογή: `false`*


### `drh_autosubscribe`

**Αυτόματη εγγραφή διευθυντή ανθρώπινου δυναμικού**

Αυτόματη εγγραφή διευθυντή ανθρώπινου δυναμικού - δεν είναι ακόμη διαθέσιμη

### `extendedprofile_registration`

**Πεδία χαρτοφυλακίου κατά την εγγραφή**

Ποια από τα ακόλουθα πεδία του χαρτοφυλακίου πρέπει να είναι διαθέσιμα στη διαδικασία εγγραφής χρήστη; Απαιτείται να είναι ενεργοποιημένη η επιλογή χαρτοφυλακίου (βλ. παραπάνω).

### `extendedprofile_registrationrequired`

**Υποχρεωτικά πεδία χαρτοφυλακίου στην εγγραφή**

Ποια από τα ακόλουθα πεδία του χαρτοφυλακίου είναι *υποχρεωτικά* στη διαδικασία εγγραφής χρήστη; Απαιτείται να είναι ενεργοποιημένη η επιλογή χαρτοφυλακίου και το πεδίο να είναι επίσης διαθέσιμο στη φόρμα εγγραφής (βλ. παραπάνω).

### `extldap_config`

**Διαμόρφωση σύνδεσης LDAP**

Πίνακας που ορίζει τον κεντρικό υπολογιστή και τη θύρα για τον διακομιστή LDAP.

### `hide_legal_accept_checkbox`

**Απόκρυψη του πλαισίου αποδοχής νομικών όρων στη σελίδα Όρων και Προϋποθέσεων**

Αν οριστεί σε true, αφαιρεί το πλαίσιο ελέγχου «Έχω διαβάσει και αποδέχομαι» στη ροή της σελίδας Όρων και Προϋποθέσεων.

*Προεπιλογή: `false`*


### `platform_unsubscribe_allowed`

**Να επιτρέπεται η απεγγραφή από την πλατφόρμα**

Ενεργοποιώντας αυτή την επιλογή, επιτρέπετε σε οποιονδήποτε χρήστη να αφαιρέσει οριστικά τον δικό του λογαριασμό και όλα τα σχετικά δεδομένα από την πλατφόρμα. Πρόκειται για αρκετά ριζική ενέργεια, αλλά είναι απαραίτητη για πύλες ανοιχτές στο κοινό όπου οι χρήστες μπορούν να αυτοεγγραφούν. Θα εμφανιστεί μια πρόσθετη καταχώριση στο προφίλ του χρήστη για απεγγραφή μετά από επιβεβαίωση.

*Προεπιλογή: `false`*


### `redirect_after_login`

**Ανακατεύθυνση μετά τη σύνδεση (ανά προφίλ)**

Ορίστε ανακατεύθυνση ανά προφίλ μετά τη σύνδεση χρησιμοποιώντας ένα αντικείμενο JSON όπως {"STUDENT":"", "ADMIN":"admin-dashboard"}

*Προεπιλογή:*
```json
{
  "COURSEMANAGER": "courses",
  "STUDENT": "courses",
  "DRH": "",
  "SESSIONADMIN": "admin-dashboard",
  "STUDENT_BOSS": "main/my_space/student.php",
  "INVITEE": "courses",
  "ADMIN": "admin"
}
```

### `required_extra_fields_in_inscription`

**Υποχρεωτικά επιπλέον πεδία κατά την εγγραφή**

Πίνακας αναγνωριστικών επιπλέον πεδίων που πρέπει να συμπληρωθούν κατά την εγγραφή χρήστη.

### `required_profile_fields`

**Υποχρεωτικά πεδία κατά την εγγραφή**

Πίνακας ονομάτων πεδίων προφίλ (email, phone, language, official_code) που πρέπει να παρέχονται κατά την εγγραφή.

### `send_inscription_msg_to_inbox`

**Αποστολή του μηνύματος καλωσορίσματος στο e-mail και στα εισερχόμενα**

Από προεπιλογή, το μήνυμα καλωσορίσματος (με τα διαπιστευτήρια) αποστέλλεται μόνο μέσω e-mail. Ενεργοποιήστε αυτή την επιλογή για να το στείλετε επίσης στα εισερχόμενα Chamilo του χρήστη.

*Προεπιλογή: `false`*


### `sessionadmin_autosubscribe`

**Αυτόματη εγγραφή διαχειριστή συνεδρίας**

Αυτόματη εγγραφή διαχειριστή συνεδρίας - δεν είναι ακόμη διαθέσιμη

### `student_autosubscribe`

**Αυτόματη εγγραφή εκπαιδευόμενου**

Αυτόματη εγγραφή εκπαιδευόμενου - δεν είναι ακόμη διαθέσιμο

### `teacher_autosubscribe`

**Αυτόματη εγγραφή εκπαιδευτή**

Αυτόματη εγγραφή εκπαιδευτή - δεν είναι ακόμη διαθέσιμο

### `user_hide_never_expire_option`

**Απόκρυψη της επιλογής «χωρίς λήξη» για χρήστες**

Αφαίρεση της επιλογής «χωρίς λήξη» κατά τη δημιουργία/επεξεργασία λογαριασμού χρήστη.

*Προεπιλογή: `false`*
