# Ρυθμίσεις Ανακοινώσεων

Συμπεριφορά του εργαλείου **Ανακοινώσεις** του μαθήματος — πώς αποστέλλονται και προγραμματίζονται οι ανακοινώσεις.

Πρόσβαση σε αυτές τις ρυθμίσεις από **Διαχείριση > Ρυθμίσεις διαμόρφωσης > Ανακοινώσεις**. Αυτή η κατηγορία περιέχει **10 ρυθμίσεις**, οι οποίες παρατίθενται παρακάτω με τον τίτλο και το σχόλιο που περιλαμβάνονται στα fixtures ρυθμίσεων της πλατφόρμας (`SettingsCurrentFixtures.php`).

> Το όνομα της μεταβλητής στον κώδικα εμφανίζεται με monospace. Χρησιμοποιήστε το όταν γράφετε σενάρια μέσω του API ή όταν χρειάζεται να αλλάξετε αυτές τις ρυθμίσεις σε καθολικό επίπεδο επεξεργάζοντας το [`config/settings_override.yaml`](https://github.com/chamilo/chamilo-lms/wiki/Configurations#configsettings_overridesyaml).

## Ρυθμίσεις

### `allow_careers_in_global_announcements`

**Σύνδεση καθολικών ανακοινώσεων με καριέρες και προαγωγές**

Όταν είναι ενεργοποιημένο, οι καθολικές ανακοινώσεις μπορούν να συσχετιστούν με καριέρες και προαγωγές για στοχευμένη διανομή.

*Προεπιλογή: `false`*

### `allow_coach_to_edit_announcements`

**Να επιτρέπεται πάντα στους tutors να επεξεργάζονται ανακοινώσεις**

Να επιτρέπεται πάντα στους tutors να επεξεργάζονται ανακοινώσεις εντός ενεργών ή παρελθουσών συνεδριών.

*Προεπιλογή: `false`*

### `allow_scheduled_announcements`

**Ενεργοποίηση προγραμματισμένων ανακοινώσεων στις συνεδρίες**

Επιτρέπει στους διαχειριστές συνεδριών να ορίζουν ανακοινώσεις που θα ενεργοποιούνται σε συγκεκριμένες ημερομηνίες ή μετά/πριν από έναν αριθμό ημερών από την έναρξη/λήξη της συνεδρίας. Η ενεργοποίηση αυτής της λειτουργίας απαιτεί τη ρύθμιση μιας εργασίας cron.

*Προεπιλογή: `false`*

### `announcements_hide_send_to_hrm_users`

**Απόκρυψη επιλογής αποστολής ανακοινώσεων σε χρήστες HR**

Αφαίρεση του πλαισίου ελέγχου για την ενεργοποίηση αποστολής ανακοινώσεων σε χρήστες με ρόλους HR (εξακολουθεί να απαιτείται επιβεβαίωση στο εργαλείο ανακοινώσεων).

*Προεπιλογή: `true`*

### `course_announcement_scheduled_by_date`

**Ανακοινώσεις βάσει ημερομηνίας**

Να επιτρέπεται στους εκπαιδευτές να διαμορφώνουν ανακοινώσεις που θα αποστέλλονται σε συγκεκριμένες ημερομηνίες. Αυτό απαιτεί τη ρύθμιση μιας εργασίας cron στο cron/course_announcement.php που εκτελείται τουλάχιστον μία φορά ημερησίως.

*Προεπιλογή: `false`*

### `disable_announcement_attachment`

**Απενεργοποίηση συνημμένων στις ανακοινώσεις**

Παρόλο που σε αυτή την έκδοση τα συνημμένα αντιμετωπίζονται με κομψό τρόπο και δεν πολλαπλασιάζονται στον δίσκο, ενδέχεται να θέλετε να απενεργοποιήσετε εντελώς τα συνημμένα εάν θέλετε να αποφύγετε υπερβολές.

*Προεπιλογή: `false`*

### `disable_delete_all_announcements`

**Απενεργοποίηση κουμπιού διαγραφής όλων των ανακοινώσεων**

Επιλέξτε «Ναι» για να αφαιρέσετε το κουμπί διαγραφής όλων των ανακοινώσεων, καθώς μπορεί να χρησιμοποιηθεί κατά λάθος από εκπαιδευτές.

*Προεπιλογή: `false`*

### `hide_announcement_sent_to_users_info`

**Απόκρυψη του «στάλθηκε σε» στις ανακοινώσεις**

Επιλέξτε «Ναι» για να αποφύγετε την εμφάνιση σε ποιον έχει σταλεί μια ανακοίνωση.

*Προεπιλογή: `false`*

### `hide_global_announcements_when_not_connected` **v3**

**Απόκρυψη καθολικών ανακοινώσεων για ανώνυμους**

Απόκρυψη των ανακοινώσεων της πλατφόρμας από ανώνυμους χρήστες και εμφάνισή τους μόνο σε πιστοποιημένους χρήστες.

*Προεπιλογή: `false`*

### `hide_send_to_hrm_users`

**Απόκρυψη της επιλογής αποστολής αντιγράφου ανακοίνωσης στον HRM**

Στη φόρμα ανακοινώσεων εμφανίζεται κανονικά μια επιλογή που επιτρέπει στους εκπαιδευτές να στείλουν αντίγραφο της ανακοίνωσης στον HRM του χρήστη. Ορίστε το σε «Ναι» για να αφαιρέσετε την επιλογή (και *να μην* σταλεί το αντίγραφο).
