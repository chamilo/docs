# FAQ

Συχνές ερωτήσεις για διαχειριστές του Chamilo 3.0.

## Installation and Setup

**Q: Ποια έκδοση PHP απαιτεί το Chamilo 3.0;**
A: PHP 8.3, 8.4 ή 8.5. Δείτε [Απαιτήσεις διακομιστή](../installation/server-requirements.md).

**Q: Μπορώ να εκτελέσω το Chamilo σε shared hosting;**
A: Είναι δυνατό αλλά δεν συνιστάται. Το Chamilo 3.0 απαιτεί Composer, Node.js σε λειτουργία ανάπτυξης και πρόσβαση γραμμής εντολών για εγκατάσταση και συντήρηση. Ένας VPS ή αποκλειστικός διακομιστής παρέχει πολύ καλύτερη εμπειρία.

**Q: Ποια βάση δεδομένων πρέπει να χρησιμοποιήσω;**
A: MySQL 8.0+ ή MariaDB 10.4+ είναι οι πιο συχνά χρησιμοποιούμενες και οι καλύτερα δοκιμασμένες.

**Q: Μπορώ να εγκαταστήσω το Chamilo χωρίς γραμμή εντολών;**
A: Ναι, αν χρησιμοποιήσετε την πακεταρισμένη έκδοση (.zip ή .tar.gz). Διαφορετικά, θα χρειαστείτε τη γραμμή εντολών για την εγκατάσταση εξαρτήσεων Composer, τη δημιουργία των frontend assets και την εκτέλεση των μεταναστεύσεων βάσης δεδομένων. Ο οδηγός μέσω ιστού χειρίζεται τη ρύθμιση της βάσης δεδομένων και την αρχική διαμόρφωση, αλλά τα περιβάλλοντα βήματα απαιτούν πρόσβαση στο κέλυφος σε λειτουργία ανάπτυξης.

## Users and Authentication

**Q: Πώς επαναφέρω τον κωδικό πρόσβασης ενός χρήστη;**
A: Μεταβείτε στο **Administration > User list**, βρείτε τον χρήστη, κάντε κλικ στην επεξεργασία και ορίστε νέο κωδικό πρόσβασης. Εναλλακτικά, ο χρήστης μπορεί να χρησιμοποιήσει τον σύνδεσμο «Forgot password» στη σελίδα σύνδεσης (αν έχει ρυθμιστεί το email).

**Q: Μπορώ να εισαγάγω χρήστες μαζικά;**
A: Ναι. Μεταβείτε στο **Administration > Import users** και ανεβάστε αρχείο CSV ή XML με δεδομένα χρηστών. Η εισαγωγή υποστηρίζει τη δημιουργία νέων χρηστών και την ενημέρωση υπαρχόντων.

**Q: Πώς ενσωματώνω LDAP ή Active Directory;**
A: Ρυθμίστε τις παραμέτρους LDAP στη διαμόρφωση πιστοποίησης. Δείτε [LDAP](../authentication/ldap.md). Οι χρήστες συγχρονίζονται κατά τη σύνδεση ή μέσω προγραμματισμένου συγχρονισμού.

**Q: Μπορούν οι χρήστες να ανήκουν σε πολλαπλές συνεδρίες ταυτόχρονα;**
A: Ναι. Οι χρήστες μπορούν να εγγραφούν σε οποιονδήποτε αριθμό συνεδριών ταυτόχρονα. Κάθε συνεδρία παρακολουθεί την πρόοδο ανεξάρτητα.

## Courses and Content

**Q: Πώς δημιουργώ αντίγραφο ασφαλείας ενός μεμονωμένου μαθήματος;**
A: Μέσα στο μάθημα, μεταβείτε στο **Maintenance > Create a backup**. Αυτό δημιουργεί ένα αρχείο αρχειοθέτησης με το περιεχόμενο και τις ρυθμίσεις του μαθήματος, έτοιμο για λήψη. Μπορείτε να το επαναφέρετε στην ίδια ή σε διαφορετική εγκατάσταση Chamilo.

**Q: Μπορώ να αντιγράψω ένα μάθημα;**
A: Ναι. Χρησιμοποιήστε **Administration > Copy course** ή το εργαλείο συντήρησης μαθήματος μέσα στο μάθημα. Μπορείτε να αντιγράψετε περιεχόμενο μεταξύ μαθημάτων ή να δημιουργήσετε νέο μάθημα από υπάρχον.

**Q: Ποιες εκδόσεις SCORM υποστηρίζονται;**
A: Το Chamilo υποστηρίζει SCORM 1.2. Τα πακέτα SCORM εισάγονται ως διαδρομές μάθησης.

**Q: Πώς περιορίζω ποιος μπορεί να δημιουργεί μαθήματα;**
A: Μεταβείτε στο **Administration > Configuration settings > Course** και απενεργοποιήστε το **Allow non administrators (teachers) to create new courses** (`allow_users_to_create_courses`). Όταν είναι απενεργοποιημένο, μόνο οι διαχειριστές μπορούν να δημιουργούν μαθήματα. Εναλλακτικά, μπορείτε να ορίσετε όριο στον αριθμό μαθημάτων που μπορεί να δημιουργήσει οποιοσδήποτε εκπαιδευτής.

## Performance and Maintenance

**Q: Η πλατφόρμα είναι αργή. Τι πρέπει να ελέγξω πρώτα;**
A: Με σειρά επίδρασης: (1) Βεβαιωθείτε ότι `APP_ENV=prod` και `APP_DEBUG=0` στο `.env`. (2) Επαληθεύστε ότι το PHP OPcache είναι ενεργοποιημένο. (3) Ελέγξτε την απόδοση της βάσης δεδομένων. (4) Δείτε [Βελτιστοποίηση απόδοσης](../platform-settings/performance-tuning.md).

**Q: Πώς καθαρίζω την προσωρινή μνήμη;**
A: Εκτελέστε `php bin/console cache:clear --env=prod` από τη γραμμή εντολών. Μην διαγράφετε χειροκίνητα τον κατάλογο `var/cache/` ενώ η εφαρμογή εκτελείται.

**Q: Πόσο χώρο δίσκου χρειάζεται το Chamilo;**
A: Η ίδια η εφαρμογή χρειάζεται περίπου 2 GB ασυμπίεστη. Ο συνολικός χώρος εξαρτάται από το ανεβασμένο περιεχόμενο (έγγραφα, βίντεο, πακέτα SCORM). Παρακολουθήστε τη χρήση δίσκου και σχεδιάστε ανάλογα.

**Q: Πώς ρυθμίζω αυτοματοποιημένα αντίγραφα ασφαλείας;**
A: Δείτε [Αντίγραφα ασφαλείας](../maintenance/backups.md). Τουλάχιστον, προγραμματίστε ημερήσιο dump βάσης δεδομένων και τακτικά αντίγραφα σε επίπεδο αρχείων του καταλόγου μεταφορτώσεων.

## Email

**Q: Οι χρήστες δεν λαμβάνουν email. Τι πρέπει να ελέγξω;**
A: (1) Επαληθεύστε το `MAILER_DSN` στο `.env`. (2) Εκτελέστε `php bin/console mailer:test someone@example.com` για δοκιμή. (3) Ελέγξτε τους φακέλους ανεπιθύμητης αλληλογραφίας. (4) Επαληθεύστε τις εγγραφές DNS SPF/DKIM. Δείτε [Διαμόρφωση email](../installation/email-configuration.md).

**Q: Μπορώ να χρησιμοποιήσω το Gmail για αποστολή email;**
A: Ναι, για μικρές πλατφόρμες ή ανάπτυξη. Χρησιμοποιήστε App Password και λάβετε υπόψη τα ημερήσια όρια αποστολής του Gmail (500 email/ημέρα για κανονικούς λογαριασμούς).

## Security

**Q: Πώς επιβάλλω HTTPS;**
A: Ρυθμίστε τον διακομιστή ιστού ώστε να ανακατευθύνει το HTTP σε HTTPS. Επιπλέον, ενεργοποιήστε τη ρύθμιση «Force HTTPS» στο **Administration > Configuration settings > Security**. Δείτε [Ρυθμίσεις ασφαλείας](../platform-settings/security-settings.md).

**Q: Πώς αποκλείω επιθέσεις brute-force στη σύνδεση;**
A: Ρυθμίστε τον μέγιστο αριθμό προσπαθειών σύνδεσης και το CAPTCHA στις ρυθμίσεις ασφαλείας. Εξετάστε επίσης τη χρήση fail2ban σε επίπεδο διακομιστή για επιπλέον προστασία.

**Q: Ένας χρήστης ξέχασε τον κωδικό του και το email δεν λειτουργεί. Πώς τον βοηθώ;**
A: Ως διαχειριστής, επεξεργαστείτε απευθείας τον λογαριασμό χρήστη και ορίστε νέο κωδικό πρόσβασης. Μεταβείτε στο **Administration > User list**, βρείτε τον λογαριασμό και ενημερώστε το πεδίο κωδικού πρόσβασης.

## Αναβαθμίσεις

**Ε: Μπορώ να αναβαθμίσω απευθείας από το Chamilo 2.x στην έκδοση 3.0;**
**Α:** Ναι, αλλά πρόκειται για σημαντική μετεγκατάσταση, όχι για απλή ενημέρωση. Δείτε [Αναβάθμιση](../installation/upgrading.md). Πάντα να δοκιμάζετε πρώτα σε διακομιστή δοκιμών (staging).

**Ε: Θα λειτουργούν τα πρόσθετά μου μετά την αναβάθμιση στην έκδοση 3.0;**
**Α:** Όχι. Τα πρόσθετα από την έκδοση 2.x δεν είναι συμβατά με την 3.0 και πρέπει να ξαναγραφτούν ή να αντικατασταθούν με ισοδύναμη λειτουργικότητα της 3.0.
