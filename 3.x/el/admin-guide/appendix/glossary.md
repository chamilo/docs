# Γλωσσάριο

Βασικοί όροι που χρησιμοποιούνται στη διαχείριση του Chamilo 3.0.

## Έννοιες πλατφόρμας

| Term | Definition |
|------|------------|
| **Access URL** | Σε εγκατάσταση πολλαπλών URL, κάθε access URL αποτελεί ξεχωριστή εικονική πύλη που μοιράζεται την ίδια εγκατάσταση και βάση δεδομένων του Chamilo. Κάθε URL μπορεί να έχει δική του ταυτότητα (branding), χρήστες, μαθήματα και ρυθμίσεις. |
| **Course** | Το θεμελιώδες δοχείο περιεχομένου στο Chamilo. Ένα μάθημα περιέχει εκπαιδευτικό υλικό, ασκήσεις, φόρουμ και άλλα εργαλεία. Τα μαθήματα μπορούν να υπάρχουν ανεξάρτητα ή να αντιστοιχίζονται σε συνεδρίες. |
| **Session** | Μια χρονικά οριοθετημένη εμφάνιση ενός ή περισσότερων μαθημάτων. Οι συνεδρίες επιτρέπουν την παράδοση του ίδιου περιεχομένου μαθήματος σε διαφορετικές ομάδες εκπαιδευομένων, με χωριστή παρακολούθηση και ανεξάρτητους tutores. |
| **Learning path** | Μια δομημένη ακολουθία στοιχείων περιεχομένου (έγγραφα, ασκήσεις, σύνδεσμοι, ενότητες SCORM) που καθοδηγεί τους εκπαιδευόμενους μέσα στο υλικό με καθορισμένη σειρά. |
| **Gradebook** | Εργαλείο συγκέντρωσης που συνδυάζει βαθμολογίες από ασκήσεις, εργασίες και άλλες δραστηριότητες σε έναν σταθμισμένο τελικό βαθμό για ένα μάθημα. |
| **Skill** | Μια ικανότητα ή σήμα (badge) που μπορεί να απονεμηθεί στους εκπαιδευόμενους μετά την ολοκλήρωση συγκεκριμένων μαθημάτων, ασκήσεων ή την επίτευξη ορίων του gradebook. |
| **Extra field** | Προσαρμοσμένο πεδίο δεδομένων που προσθέτουν οι διαχειριστές σε χρήστες, μαθήματα ή συνεδρίες για την καταγραφή μεταδεδομένων ειδικών για τον οργανισμό. |
| **Plugin** | Επέκταση που προσθέτει λειτουργικότητα στο Chamilo χωρίς τροποποίηση του πυρήνα. Τα πρόσθετα μπορούν να προσθέσουν σελίδες, εργαλεία ή ενσωματώσεις. |
| **Catalog** | Περιηγήσιμος κατάλογος διαθέσιμων μαθημάτων όπου οι χρήστες μπορούν να δουν περιγραφές και να εγγραφούν μόνοι τους. |

## Ρόλοι χρηστών

| Term | Definition |
|------|------------|
| **Learner (Student)** | Ο προεπιλεγμένος ρόλος χρήστη. Μπορεί να εγγραφεί σε μαθήματα και να καταναλώσει περιεχόμενο. |
| **Teacher (Trainer)** | Μπορεί να δημιουργεί και να διαχειρίζεται μαθήματα, να προσθέτει περιεχόμενο και να βαθμολογεί εκπαιδευόμενους. |
| **Session administrator** | Μπορεί να δημιουργεί και να διαχειρίζεται συνεδρίες και εγγραφές. |
| **Human Resources Manager (HRM)** | Μπορεί να βλέπει δεδομένα παρακολούθησης και αναφορών για τους αντιστοιχισμένους χρήστες. |
| **Portal administrator** | Πλήρης πρόσβαση σε όλες τις λειτουργίες διαχείρισης της πλατφόρμας. |
| **Global administrator** | Διαχειριστής πύλης με πρόσβαση σε όλα τα access URL σε εγκατάσταση πολλαπλών URL. |
| **Tutor** | Ρόλος σε επίπεδο συνεδρίας. Οι tutores συνεδρίας εποπτεύουν όλα τα μαθήματα μιας συνεδρίας· οι tutores μαθήματος διαχειρίζονται ένα συγκεκριμένο μάθημα εντός συνεδρίας. Ονομάζονταν «coach» στις εκδόσεις του Chamilo πριν από την 3.0. |

## Πρότυπα και πρωτόκολλα

| Term | Definition |
|------|------------|
| **SCORM** | Sharable Content Object Reference Model. Πρότυπο συσκευασίας ηλεκτρονικής μάθησης που επιτρέπει την εισαγωγή και την παρακολούθηση μαθημάτων. Το Chamilo υποστηρίζει SCORM 1.2 και 2004. |
| **xAPI (Tin Can API)** | Προδιαγραφή ηλεκτρονικής μάθησης για την παρακολούθηση μαθησιακών εμπειριών. Ευρύτερη από το SCORM, μπορεί να καταγράφει δραστηριότητες που συμβαίνουν εκτός του LMS. Οι δηλώσεις xAPI αποθηκεύονται σε Learning Record Store (LRS). |
| **LTI** | Learning Tools Interoperability. Πρότυπο IMS Global που επιτρέπει την ενσωμάτωση εξωτερικών εργαλείων και περιεχομένου εντός ενός LMS. Το Chamilo υποστηρίζει LTI 1.1 και 1.3 τόσο ως καταναλωτής όσο και ως πάροχος. |
| **SCIM** | System for Cross-domain Identity Management. Πρότυπο για την αυτοματοποίηση της παροχής και ανάκλησης λογαριασμών χρηστών μεταξύ παρόχων ταυτότητας και εφαρμογών. |
| **OAuth2** | Πλαίσιο εξουσιοδότησης που επιτρέπει σε εφαρμογές τρίτων να έχουν πρόσβαση στο Chamilo εκ μέρους ενός χρήστη χωρίς κοινοποίηση κωδικών πρόσβασης. Χρησιμοποιείται για πρόσβαση API και ενσωματώσεις SSO. |
| **LDAP** | Lightweight Directory Access Protocol. Πρωτόκολλο πρόσβασης σε υπηρεσίες καταλόγου (π.χ. Active Directory) για αυθεντικοποίηση χρηστών και συγχρονισμό δεδομένων λογαριασμών. |
| **CAS** | Central Authentication Service. Πρωτόκολλο ενιαίας σύνδεσης που επιτρέπει στους χρήστες να αυθεντικοποιούνται μία φορά και να έχουν πρόσβαση σε πολλαπλές εφαρμογές. |
| **JWT** | JSON Web Token. Συμπαγής, υπογεγραμμένη μορφή διακριτικού που χρησιμοποιείται για αυθεντικοποίηση API και διαχείριση συνεδριών. |
| **SAML** | Security Assertion Markup Language. Πρότυπο βασισμένο σε XML για την ανταλλαγή δεδομένων αυθεντικοποίησης μεταξύ παρόχου ταυτότητας και παρόχου υπηρεσίας. |

## Τεχνικοί Όροι

| Όρος | Ορισμός |
|------|------------|
| **Symfony** | Το πλαίσιο PHP πάνω στο οποίο βασίζεται το Chamilo 3.0. Το Symfony παρέχει δρομολόγηση, έγχυση εξαρτήσεων, ORM (Doctrine), πρότυπα (Twig) και άλλη υποδομή. |
| **Doctrine** | Ο αντιστοιχιστής αντικειμένων-σχεσιακής βάσης (ORM) που χρησιμοποιεί το Chamilo για την αλληλεπίδραση με τη βάση δεδομένων. Το Doctrine αντιστοιχίζει αντικείμενα PHP σε πίνακες βάσης δεδομένων. |
| **Twig** | Η μηχανή προτύπων που χρησιμοποιείται από το Symfony και το Chamilo για την απόδοση HTML. |
| **Flysystem** | Ένα επίπεδο αφαίρεσης συστήματος αρχείων PHP. Το Chamilo χρησιμοποιεί το Flysystem για να υποστηρίζει εναλλάξιμα τοπική αποθήκευση, Amazon S3, Azure Blob και Google Cloud Storage. |
| **Composer** | Ο διαχειριστής εξαρτήσεων PHP. Χρησιμοποιείται για την εγκατάσταση και ενημέρωση των βιβλιοθηκών PHP του Chamilo. |
| **Mailer DSN** | Data Source Name για τη μεταφορά ηλεκτρονικού ταχυδρομείου. Μια συμβολοσειρά σύνδεσης που ενημερώνει το Symfony πώς να στέλνει μηνύματα (π.χ. μέσω SMTP, Amazon SES ή Mailjet). |
| **OPcache** | Η ενσωματωμένη κρυφή μνήμη opcode της PHP. Μεταγλωττίζει σενάρια PHP σε bytecode και τα αποθηκεύει στη μνήμη, βελτιώνοντας σημαντικά την απόδοση. |
| **APCu** | Μια επέκταση PHP που παρέχει κρυφή μνήμη σε επίπεδο χρήστη στη μνήμη. Χρησιμοποιείται από το Symfony για την αποθήκευση μεταδεδομένων και ρυθμίσεων. |

## Ακρωνύμια

| Ακρωνύμιο | Πλήρης μορφή |
|---------|-----------|
| **LMS** | Learning Management System (Σύστημα Διαχείρισης Μάθησης) |
| **LRS** | Learning Record Store (για δηλώσεις xAPI) |
| **SSO** | Single Sign-On (Ενιαία σύνδεση) |
| **CSV** | Comma-Separated Values (χρησιμοποιείται για εισαγωγές χρηστών/μαθημάτων) |
| **API** | Application Programming Interface |
| **REST** | Representational State Transfer (στυλ αρχιτεκτονικής API) |
| **GDPR** | General Data Protection Regulation (κανονισμός προστασίας δεδομένων της ΕΕ) |
| **HSTS** | HTTP Strict Transport Security |
| **CDN** | Content Delivery Network |
| **DNS** | Domain Name System |
| **SPF** | Sender Policy Framework (πιστοποίηση ηλεκτρονικού ταχυδρομείου) |
| **DKIM** | DomainKeys Identified Mail (πιστοποίηση ηλεκτρονικού ταχυδρομείου) |
| **DMARC** | Domain-based Message Authentication, Reporting, and Conformance |
