# Ξεκινώντας

Αυτή η ενότητα παρουσιάζει το περιβάλλον διαχείρισης του Chamilo 3.0 και σας βοηθά να προσανατολιστείτε.

## Ποιος είναι Διαχειριστής;

Το Chamilo διαθέτει διάφορα επίπεδα ρόλων διαχείρισης:

| Ρόλος | Πρόσβαση |
|------|--------|
| **Administrator** | Πλήρης πρόσβαση σε όλες τις λειτουργίες διαχείρισης της πλατφόρμας. Γνωστός και ως **Portal Administrator** |
| **Global Administrator** | Ίδιος με τον Portal Administrator, με πρόσβαση σε όλα τα URL πρόσβασης σε εγκατάσταση πολλαπλών URL (πολλαπλών μισθωτών) |
| **Sessions Administrator** | Μπορεί να διαχειρίζεται συνεδρίες, να εγγράφει χρήστες σε συνεδρίες και να έχει πρόσβαση σε ρυθμίσεις σχετικές με τις συνεδρίες |
| **Human Resources Manager** | Μπορεί να βλέπει την πρόοδο των εκπαιδευομένων και δεδομένα παρακολούθησης για τους ανατεθειμένους χρήστες |
| **Questions Manager** | Λιγότερο διαχειριστής και περισσότερο επιμελητής περιεχομένου· οι διαχειριστές ερωτήσεων έχουν πρόσβαση σε μια καθολική τράπεζα ερωτήσεων για τον έλεγχο της ποιότητας των ερωτήσεων |

Ο παρών οδηγός εστιάζει κυρίως στον ρόλο **Portal Administrator**, ο οποίος διαθέτει την ευρύτερη πρόσβαση.

## Σύνδεση

Οι διαχειριστές συνδέονται μέσω της ίδιας σελίδας σύνδεσης με όλους τους άλλους χρήστες. Μετά την εισαγωγή των διαπιστευτηρίων σας, θα μεταφερθείτε (εφόσον δεν υπάρχει άλλη διαμόρφωση) στη σελίδα **Administration**. Μια αξιοσημείωτη διαφορά σε σχέση με άλλους ρόλους χρηστών είναι η ενότητα **Administration** στην πλαϊνή γραμμή (μη ορατή σε άλλους ρόλους).
