# Multi-URL

Η λειτουργία multi-URL του Chamilo (γνωστή και ως multi-tenant) σας επιτρέπει να εκτελείτε πολλαπλές εικονικές πύλες από μία μόνο εγκατάσταση Chamilo. Κάθε πύλη έχει το δικό της URL, επωνυμία, χρήστες, μαθήματα και ρυθμίσεις, αλλά όλες μοιράζονται την ίδια βάση δεδομένων και τον ίδιο κώδικα.

* **[URL πρόσβασης](access-urls.md)** — Διαμόρφωση και διαχείριση πολλαπλών URL πρόσβασης
