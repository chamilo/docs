# Σελίδες

Οι Σελίδες είναι το ενσωματωμένο, τύπου CMS εργαλείο του Chamilo για τα μπλοκ περιεχομένου που συνθέτουν τις δημόσιες περιοχές της πύλης σας — την αρχική σελίδα, το υποσέλιδο, τα μενού πλοήγησης και παρόμοιες θέσεις — χωρίς να χρειάζεται να επεξεργαστείτε αρχείο προτύπου.

## Πρόσβαση στις Σελίδες

Από τον πίνακα διαχείρισης, κάντε κλικ στο **Πλατφόρμα > Σελίδες**.

## Πώς λειτουργούν οι Σελίδες

Κάθε σελίδα έχει:

* **Τίτλο** και εμπλουτισμένο κείμενο **περιεχομένου**
* Ένα **slug**, που δημιουργείται αυτόματα από τον τίτλο
* **Ενεργοποιημένη** — αν η σελίδα είναι αυτή τη στιγμή ορατή
* **Θέση** — ταξινόμηση με μεταφορά και απόθεση εντός της κατηγορίας της
* **Τοπική ρύθμιση (Locale)** — το περιεχόμενο είναι ανά γλώσσα: η ίδια θέση μπορεί να φιλοξενεί μία σελίδα ανά γλώσσα, και ο ιστότοπος επιστρέφει στη προεπιλεγμένη γλώσσα της πλατφόρμας αν δεν υπάρχει σελίδα για τη γλώσσα του επισκέπτη
* Μια **κατηγορία** — αυτό καθορίζει *πού* αποδίδεται η σελίδα (για παράδειγμα `index`, `home`, `footer_public` ή `menu_links`)· το Chamilo δημιουργεί αυτόματα τις κατηγορίες που χρειάζεται

Σε εγκατάσταση πολλαπλών URL (πολλαπλών πυλών), οι σελίδες περιορίζονται επίσης ανά URL πρόσβασης, ώστε κάθε πύλη να διαχειρίζεται το δικό της περιεχόμενο.

## Η εισαγωγική σελίδα εγγραφής

Το **Πλατφόρμα > Ρύθμιση της σελίδας εγγραφής** είναι μια συντόμευση στο ίδιο σύστημα Σελίδων για μία συγκεκριμένη θέση: το εισαγωγικό κείμενο που εμφανίζεται πάνω από τη δημόσια φόρμα εγγραφής. Περιορίζεται στους Διαχειριστές Πύλης. Κάνοντας κλικ είτε:

* Ανοίγει την υπάρχουσα εισαγωγική σελίδα για επεξεργασία, αν υπάρχει ήδη για το URL πρόσβασης και τη γλώσσα σας, είτε
* Δημιουργεί τη θέση επί τόπου και σας μεταφέρει απευθείας στη δημιουργία του περιεχομένου της

Ό,τι αποθηκεύσετε εδώ αποδίδεται ως πλαίσιο πληροφοριών απευθείας πάνω από τη φόρμα εγγραφής — ένα φυσικό σημείο για οδηγίες, όρους ειδικούς για τον οργανισμό σας ή πλαίσιο που οι υποψήφιοι χρήστες θα πρέπει να διαβάσουν πριν εγγραφούν. Αφήστε την απενεργοποιημένη (ή μην τη δημιουργήσετε ποτέ) για να εμφανίζεται η απλή φόρμα εγγραφής χωρίς εισαγωγικό κείμενο.
