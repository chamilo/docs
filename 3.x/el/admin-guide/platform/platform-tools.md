# Εργαλεία πλατφόρμας

Αυτή η σελίδα καλύπτει τα υπόλοιπα, μικρότερα στοιχεία στο μπλοκ διαχείρισης πλατφόρμας.

## Extra Fields

Το **Platform > Extra fields** είναι επιλογέας τύπου, όχι η ίδια η λίστα πεδίων — εμφανίζει κάθε τύπο αντικειμένου που υποστηρίζει προσαρμοσμένα πεδία και η επιλογή ενός τύπου οδηγεί στον αντίστοιχο επεξεργαστή πεδίων. Οι διαθέσιμοι τύποι περιλαμβάνουν: user, course, session, question, learning path (και learning path item/view), skill, assignment (work), career, user certificate, survey, terms and conditions, forum category, forum post, exercise, exercise tracking, course announcement, message, document, attendance calendar, glossary, work correction comment, calendar event και portfolio (καθώς και scheduled announcements, αν είναι ενεργοποιημένη αυτή η λειτουργία).

Για την πιο συνηθισμένη περίπτωση — προσαρμοσμένα πεδία προφίλ χρήστη — δείτε το [Προφίλ χρηστών](../users/user-profiling.md), που καλύπτει την ίδια υποκείμενη λειτουργία από την πλευρά της διαχείρισης χρηστών.

## Πρότυπα αλληλογραφίας

Το **Platform > Mail templates** επιτρέπει την αντικατάσταση της διατύπωσης συγκεκριμένων μηνυμάτων ηλεκτρονικού ταχυδρομείου του συστήματος (επιβεβαίωση εγγραφής, ειδοποιήσεις εγγραφής σε μαθήματα και παρόμοια) χωρίς τροποποίηση αρχείων διακομιστή. Κάθε πρότυπο έχει τίτλο, έναν **τύπο** που αντιστοιχεί στο συγκεκριμένο ενσωματωμένο μήνυμα που αντικαθιστά, το ίδιο το σώμα του προτύπου (απλό κείμενο/Twig, όχι εμπλουτισμένος επεξεργαστής) και μια σημαία «ορισμός ως προεπιλογή» — μόνο ένα πρότυπο ανά τύπο μπορεί να είναι η ενεργή προεπιλογή. Τα πρότυπα έχουν εύρος ανά URL πρόσβασης· δεν υπάρχει ξεχωριστό πεδίο ανά γλώσσα, επομένως ο χειρισμός γλώσσας για αυτά τα μηνύματα είναι ό,τι ήδη κάνει ο περιβάλλον κώδικας.

Τα πρότυπα αποδίδονται μέσω ενός **απομονωμένου (sandboxed)** περιβάλλοντος Twig για λόγους ασφαλείας: επιτρέπεται μόνο ένα μικρό σύνολο ετικετών και φίλτρων, και τα μόνα διαθέσιμα δεδομένα είναι το αντικείμενο `User` του παραλήπτη, με αναφορές όπως `user.getEmail()`, `user.getFirstname()` και παρόμοιους getters (`getId`, `getUsername`, `getLastname`, `getStatus`, `getOfficialCode`, `getPhone`). Οτιδήποτε εκτός αυτής της λίστας επιτρεπόμενων δεν προκαλεί έντονο σφάλμα — αποδίδεται σιωπηλά κενό, οπότε γίνεται επαναφορά στο αρχικό ενσωματωμένο πρότυπο. Διατηρήστε τα προσαρμοσμένα πρότυπα απλά και δοκιμάστε τα (με πραγματική εγγραφή ή ενεργοποίηση ειδοποίησης) μετά την επεξεργασία.

## Κατηγορίες φόρμας επικοινωνίας

Το **Platform > Contact form categories** διαχειρίζεται το αναπτυσσόμενο μενού που εμφανίζεται στη δημόσια φόρμα **Contact us** της πύλης σας. Κάθε κατηγορία είναι απλώς ένας τίτλος και μια διεύθυνση ηλεκτρονικού ταχυδρομείου προορισμού — όποια κατηγορία επιλέξει ο επισκέπτης καθορίζει σε ποια θυρίδα δρομολογείται το μήνυμά του. Χρησιμοποιήστε το για να δρομολογείτε διαφορετικά θέματα (υποστήριξη, πωλήσεις, εισαγωγές) σε διαφορετικές ομάδες χωρίς να δημιουργείτε ξεχωριστές φόρμες.

## Συντομεύσεις κατηγοριών ρυθμίσεων

Ορισμένα στοιχεία του μπλοκ είναι απλώς άμεσοι σύνδεσμοι προς συγκεκριμένες κατηγορίες των [Ρυθμίσεων πλατφόρμας](../platform-settings/README.md), και όχι ξεχωριστά εργαλεία:

* Τα **Plugins** και **System templates** ανοίγουν τις Ρυθμίσεις διαμόρφωσης προφιλτραρισμένες σε αυτές τις κατηγορίες
* Το **Regions** κάνει το ίδιο, για τις ρυθμίσεις περιοχών της πλατφόρμας

## Στοιχεία που εμφανίζονται περιστασιακά

Ορισμένα στοιχεία εμφανίζονται μόνο όταν είναι ενεργή η σχετική ρύθμιση ή το πρόσθετο, επομένως ενδέχεται να μην τα βλέπετε στην εγκατάστασή σας:

* **Terms and Conditions** — εμφανίζεται όταν είναι ενεργοποιημένο το **Allow terms and conditions**, για τη διαχείριση του κειμένου που πρέπει να αποδεχτούν οι χρήστες
* **Notifications** — εμφανίζεται όταν είναι ενεργοποιημένη η λειτουργία συμβάντων ειδοποιήσεων της πλατφόρμας
* **CMS**, **Dictionary**, **Justification** — καθένα συνδέεται με το δικό του προαιρετικό πρόσθετο που έχει εγκατασταθεί και ενεργοποιηθεί
