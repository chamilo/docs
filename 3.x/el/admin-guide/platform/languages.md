# Γλώσσες

Αυτό το εργαλείο διαχειρίζεται ποιες γλώσσες διεπαφής μπορούν να επιλέξουν οι χρήστες — δεν διαχειρίζεται τα ίδια τα αλφαριθμητικά μετάφρασης (αυτά προέρχονται από τα πακέτα γλωσσών που συνοδεύουν το Chamilo, όχι από κάτι επεξεργάσιμο εδώ).

## Πρόσβαση στις γλώσσες

Από τον πίνακα διαχείρισης, κάντε κλικ στο **Πλατφόρμα > Γλώσσες**.

## Τι μπορείτε να κάνετε

* **Εναλλαγή διαθεσιμότητας** — Ενεργοποιήστε ή απενεργοποιήστε καθεμία από τις συνοδευτικές γλώσσες ως επιλογή στη σελίδα σύνδεσης και στις ρυθμίσεις προφίλ χρήστη, με έναν απλό διακόπτη ενεργοποίησης/απενεργοποίησης ανά γραμμή
* **Ορισμός προεπιλογής πλατφόρμας** — Επιλέξτε ποια γλώσσα χρησιμοποιείται όταν δεν ισχύει προτίμηση χρήστη· η τρέχουσα προεπιλογή επισημαίνεται με δικό της εικονίδιο και δεν μπορεί να αποκρυφθεί
* **Απενεργοποίηση όλων εκτός της προεπιλογής** — Μια ενιαία μαζική ενέργεια για να περιορίσετε τον επιλογέα γλώσσας μόνο στην προεπιλεγμένη γλώσσα της πλατφόρμας σας
* **Επεξεργασία της εγγενούς ονομασίας** — Προσαρμόστε τον τρόπο εμφάνισης της ίδιας της ονομασίας μιας γλώσσας (το «πρωτότυπο όνομά» της) στον επιλογέα

## Απενεργοποίηση γλώσσας που χρησιμοποιείται

Εάν απενεργοποιήσετε μια γλώσσα που ενεργοί χρήστες έχουν ήδη επιλέξει ως γλώσσα διεπαφής τους, το Chamilo ζητά επιβεβαίωση και — εάν επιβεβαιώσετε — μεταφέρει κάθε επηρεαζόμενο χρήστη στην προεπιλεγμένη γλώσσα της πλατφόρμας. Δεν υπάρχει μερική κατάσταση όπου ένας χρήστης μένει με επιλεγμένη μια πλέον κρυφή γλώσσα.

## Γλώσσες από δεξιά προς τα αριστερά

Οι γλώσσες από δεξιά προς τα αριστερά (όπως τα αραβικά, τα εβραϊκά ή τα περσικά) αλλάζουν αυτόματα τη διεπαφή σε διάταξη από δεξιά προς τα αριστερά όταν επιλέγονται — δεν υπάρχει τίποτα να ρυθμίσετε εδώ ή αλλού για να συμβεί αυτό. Η υποστήριξη RTL έχει βελτιωθεί σημαντικά στις πρόσφατες εκδόσεις.

## Υπογλώσσες

Εάν είναι ενεργοποιημένη η ρύθμιση **Allow sub-languages**, εμφανίζονται πρόσθετες ενέργειες για τη δημιουργία «υπογλωσσών» — μερικές παρακάμψεις μιας γονικής γλώσσας, που ιστορικά χρησιμοποιούνταν για περιφερειακές διαλέκτους ή προσαρμογές ορολογίας συγκεκριμένης οργάνωσης. Πρόκειται για λειτουργία παλαιού τύπου· οι περισσότερες εγκαταστάσεις δεν θα τη χρειαστούν.
