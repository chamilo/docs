# OnlyOffice

Η ενσωμάτωση **OnlyOffice** επιτρέπει στους χρήστες να επεξεργάζονται έγγραφα (Word, Excel, PowerPoint) απευθείας στο πρόγραμμα περιήγησης εντός του Chamilo, χωρίς να τα κατεβάζουν.

## Τι παρέχει το OnlyOffice

* **Επεξεργασία εγγράφων** — Επεξεργασία αρχείων .docx, .xlsx, .pptx στο πρόγραμμα περιήγησης
* **Συμβατότητα μορφών** — Πλήρης συμβατότητα με τις μορφές Microsoft Office
* **Χωρίς ανάγκη λογισμικού επιφάνειας εργασίας** — Όλα εκτελούνται στο πρόγραμμα περιήγησης

> Η συνεργατική επεξεργασία σε πραγματικό χρόνο εξαρτάται από τον ίδιο τον OnlyOffice Document Server· το πρόσθετο του Chamilo ανοίγει και αποθηκεύει έγγραφα μέσω του διακομιστή, αλλά δεν προσθέτει ούτε περιορίζει αυτή τη δυνατότητα.

## Ρύθμιση

1. Εγκαταστήστε τον **OnlyOffice Document Server** στον διακομιστή σας (ή χρησιμοποιήστε την υπηρεσία cloud του OnlyOffice)
2. Στις ρυθμίσεις πλατφόρμας του Chamilo, διαμορφώστε:
   * **OnlyOffice Document Server URL** — Η διεύθυνση του διακομιστή OnlyOffice σας
   * **Secret key** — Για ασφαλή επικοινωνία μεταξύ Chamilo και OnlyOffice
3. Ενεργοποιήστε την ενσωμάτωση

## Πώς λειτουργεί

Μόλις ρυθμιστεί, οι χρήστες βλέπουν μια επιλογή **Επεξεργασία με OnlyOffice** όταν προβάλλουν υποστηριζόμενους τύπους εγγράφων στο εργαλείο Έγγραφα. Κάνοντας κλικ ανοίγει το έγγραφο στον επεξεργαστή OnlyOffice εντός της διεπαφής του Chamilo.

Οι αλλαγές αποθηκεύονται αυτόματα πίσω στον χώρο αποθήκευσης εγγράφων του Chamilo.

## Συμβουλές

* **Συνιστάται ξεχωριστός διακομιστής** — Όπως και το BigBlueButton, ο OnlyOffice Document Server θα πρέπει να εκτελείται σε δικό του διακομιστή για καλύτερη απόδοση
* **Απαιτείται HTTPS** — Τόσο το Chamilo όσο και το OnlyOffice θα πρέπει να εξυπηρετούνται μέσω HTTPS ώστε να λειτουργεί η ενσωμάτωση
* **Ελέγξτε τις μορφές** — Το OnlyOffice λειτουργεί καλύτερα με μορφές Office (.docx, .xlsx, .pptx). Άλλες μορφές ενδέχεται να έχουν περιορισμένη υποστήριξη επεξεργασίας.
