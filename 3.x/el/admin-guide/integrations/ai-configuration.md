# Διαμόρφωση Τεχνητής Νοημοσύνης

Το Chamilo 3.0 περιλαμβάνει λειτουργίες με τεχνητή νοημοσύνη που απαιτούν διαμόρφωση προτού καταστούν διαθέσιμες σε εκπαιδευτές και εκπαιδευόμενους.

## Υποστηριζόμενοι πάροχοι ΤΝ

Το Chamilo υποστηρίζει πολλούς παρόχους ΤΝ:

| Πάροχος | Δυνατότητες |
|----------|-------------|
| **DeepSeek** | Παραγωγή κειμένου |
| **Google Gemini** | Παραγωγή κειμένου, εικόνας, βίντεο |
| **Grok** | Παραγωγή κειμένου, εικόνας, βίντεο |
| **Mistral** | Παραγωγή κειμένου |
| **OpenAI** | Παραγωγή κειμένου, εικόνας, βίντεο |

Κάθε πάροχος μπορεί να διαμορφωθεί για διαφορετικούς τύπους εργασιών ΤΝ:

* **Κείμενο** — Χρησιμοποιείται για παραγωγή ασκήσεων, παραγωγή μαθησιακών διαδρομών, βαθμολόγηση με ΤΝ και τον βοηθό ΤΝ
* **Εικόνα** — Χρησιμοποιείται για παραγωγή εικόνων με ΤΝ
* **Βίντεο** — Χρησιμοποιείται για παραγωγή βίντεο με ΤΝ (όπου υποστηρίζεται)
* **Έγγραφο** — Χρησιμοποιείται για ανάλυση εγγράφων με ΤΝ

## Βήματα διαμόρφωσης

### 1. Απόκτηση κλειδιών API

Εγγραφείτε για λογαριασμό στον πάροχο ΤΝ της επιλογής σας και αποκτήστε ένα κλειδί API:

* **DeepSeek**: [platform.deepseek.com](https://platform.deepseek.com/)
* **Google Gemini**: Google AI Studio ή Google Cloud
* **Grok**: [console.x.ai](https://console.x.ai/)
* **Mistral**: [console.mistral.ai](https://console.mistral.ai/)
* **OpenAI**: [platform.openai.com](https://platform.openai.com/)

### 2. Διαμόρφωση παρόχων στο Chamilo

![Η σελίδα διαμόρφωσης βοηθών ΤΝ που εμφανίζει ρυθμίσεις παρόχου με πεδία κλειδιού API, μοντέλου και τελικού σημείου](/.gitbook/assets/admin-ai-helpers-config.png)

Στις ρυθμίσεις της πλατφόρμας, μεταβείτε στην ενότητα **Βοηθοί ΤΝ**:

1. **Ενεργοποίηση βοηθών ΤΝ** — Ενεργοποιήστε τις λειτουργίες ΤΝ σε παγκόσμιο επίπεδο
2. **Διαμόρφωση παρόχων ΤΝ** — Προσθέστε έναν ή περισσότερους παρόχους με:
   * **Όνομα παρόχου** (deepseek, gemini, grok, mistral, openai)
   * **Κλειδί API** — Το κλειδί API σας για τον πάροχο
   * **Μοντέλο** — Το συγκεκριμένο μοντέλο που θα χρησιμοποιηθεί (π.χ. `gpt-4`, `gemini-pro`, `mistral-large`)
   * **URL API** — Η διεύθυνση URL του τελικού σημείου (προδιαμορφωμένη για τυπικούς παρόχους)

Μπορείτε να διαμορφώσετε πολλούς παρόχους. Ο πρώτος πάροχος στη διαμόρφωση γίνεται ο προεπιλεγμένος.

### 3. Ενεργοποίηση λειτουργιών ανά μάθημα

Οι λειτουργίες ΤΝ μπορούν να ενεργοποιηθούν ή να απενεργοποιηθούν σε επίπεδο μαθήματος. Οι εκπαιδευτές μπορούν να εναλλάσσουν:

* **Chatbot βοηθού ΤΝ** — Ο βοηθός ΤΝ για τους εκπαιδευόμενους
* **Βαθμολογητής εργασιών** — Σύσταση βαθμολόγησης που παράγεται από ΤΝ
* **Γεννήτρια ασκήσεων** — Ερωτήσεις κουίζ που παράγονται από ΤΝ
* **Γεννήτρια μαθησιακής διαδρομής** — Μαθησιακές ακολουθίες που παράγονται από ΤΝ
* **Γεννήτρια εικόνας/βίντεο** — Εικόνες και βίντεο που παράγονται από ΤΝ στα έγγραφα

Αυτό επιτρέπει σε διαφορετικά μαθήματα να χρησιμοποιούν διαφορετικές διαμορφώσεις ΤΝ ανάλογα με τις ανάγκες τους.

## Ζητήματα κόστους

Οι κλήσεις API ΤΝ έχουν σχετικό κόστος. Λάβετε υπόψη:

* **Ορισμό ορίων χρήσης** — Παρακολουθήστε και περιορίστε τη χρήση του API ΤΝ για έλεγχο του κόστους
* **Σοφή επιλογή μοντέλων** — Μικρότερα, λιγότερο δαπανηρά μοντέλα μπορεί να επαρκούν για πολλές εκπαιδευτικές εργασίες
* **Παρακολούθηση χρήσης** — Το Chamilo καταγράφει τα αιτήματα ΤΝ για να σας βοηθήσει να παρακολουθείτε την κατανάλωση

## Συμβουλές

* **Ξεκινήστε με έναν πάροχο** — Διαμορφώστε και δοκιμάστε έναν πάροχο πριν προσθέσετε περισσότερους
* **Δοκιμή με ένα μάθημα** — Ενεργοποιήστε πρώτα τις λειτουργίες ΤΝ σε ένα δοκιμαστικό μάθημα για να επαληθεύσετε ότι λειτουργούν όπως αναμένεται
* **Επικοινωνία με τους εκπαιδευτές** — Ενημερώστε τους εκπαιδευτές ποιες λειτουργίες ΤΝ είναι διαθέσιμες και πώς να τις χρησιμοποιούν
* **Παρακολούθηση ποιότητας** — Ελέγχετε τακτικά το περιεχόμενο που παράγεται από ΤΝ ώστε να διασφαλίζετε ότι πληροί τα εκπαιδευτικά σας πρότυπα
