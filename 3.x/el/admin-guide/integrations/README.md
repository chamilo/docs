# Ενσωματώσεις

Το Chamilo ενσωματώνεται με διάφορες υπηρεσίες τρίτων για την επέκταση της λειτουργικότητάς του.

Οι περισσότερες από αυτές ενεργοποιούνται μέσω πρόσθετων. Ελέγξτε την αντίστοιχη ενότητα λίγο πιο κάτω σε αυτόν τον οδηγό.

* **[Τηλεδιάσκεψη](video-conferencing.md)** — BigBlueButton και Zoom
* **[LTI 1.3](lti.md)** — Σύνδεση εξωτερικών εργαλείων μάθησης
* **[xAPI](xapi.md)** — Παρακολούθηση μαθησιακής εμπειρίας
* **[OnlyOffice](onlyoffice.md)** — Συνεργατική επεξεργασία εγγράφων
* **[Διαμόρφωση AI](ai-configuration.md)** — Ρύθμιση παρόχων AI για λειτουργίες με τεχνητή νοημοσύνη
