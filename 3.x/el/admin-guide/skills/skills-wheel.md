# Τροχός Δεξιοτήτων

Ο Τροχός Δεξιοτήτων είναι ένα διαδραστικό, μεγεθυνόμενο διάγραμμα σε σχήμα τροχού ολόκληρου του δέντρου δεξιοτήτων — μια οπτική εναλλακτική στην περιήγηση της επίπεδης λίστας στο [Διαχείριση Δεξιοτήτων](managing-skills.md).

## Πρόσβαση στον Τροχό Δεξιοτήτων

Από τον πίνακα διαχείρισης, κάντε κλικ στο **Skills > Skills wheel**.

![Η σελίδα του Τροχού Δεξιοτήτων, με την πλαϊνή γραμμή αναζήτησης, το υπόμνημα και ολόκληρο το δέντρο δεξιοτήτων ως τμηματοποιημένο τροχό](../../.gitbook/assets/admin-skills-wheel.png)

## Τι Εμφανίζει

Κάθε τμήμα του τροχού είναι μια δεξιότητα, επεκτάσιμη στις θυγατρικές της δεξιότητες. Ένα τμήμα υποδεικνύει αν η δεξιότητα έχει συνδεδεμένο βαθμολόγιο (βλ. [Δεξιότητες και Αξιολογήσεις](skills-assessments.md)) και, κατά την προβολή συγκεκριμένου χρήστη, αν ο χρήστης την έχει ήδη αποκτήσει.

Κάντε κλικ σε ένα τμήμα για μεγέθυνση και εμφάνιση των θυγατρικών δεξιοτήτων· κάντε κλικ στον κεντρικό κύκλο για σμίκρυνση.

![Ο τροχός μεγεθυμένος στον κλάδο «Idiomas», με τις υποδεξιότητες γλωσσών](../../.gitbook/assets/admin-skills-wheel-zoom.png)

Κάντε δεξί κλικ σε ένα τμήμα για να ανοίξετε τις λεπτομέρειές του: περιγραφή, γονική δεξιότητα και τα μαθήματα (αν υπάρχουν) που την απονέμουν. Από αυτό το παράθυρο διαλόγου, οι διαχειριστές μπορούν επίσης να επεξεργαστούν τη δεξιότητα, να δημιουργήσουν μια θυγατρική δεξιότητα κάτω από αυτήν ή να την προσθέσουν στην αναζήτηση προφίλ που περιγράφεται παρακάτω.

![Το παράθυρο λεπτομερειών δεξιότητας για το «Conflict Management», με την περιγραφή και τις ενέργειες Επεξεργασία, Δημιουργία θυγατρικής δεξιότητας και Προσθήκη δεξιότητας στο προφίλ αναζήτησης](../../.gitbook/assets/admin-skills-wheel-detail.png)

Οι διαχειριστές και οι χρήστες με ρόλο Human Resources Manager έχουν επίσης εδώ αναζήτηση προφίλ: οι δεξιότητες μπορούν να ομαδοποιηθούν σε «προφίλ» (σύνολα δεξιοτήτων που αναμένονται για έναν δεδομένο ρόλο ή περιγραφή θέσης εργασίας) και αυτή η σελίδα επιτρέπει την αναζήτηση χρηστών των οποίων οι αποκτημένες δεξιότητες ταιριάζουν με ένα δεδομένο προφίλ — χρήσιμο για τον εντοπισμό όσων είναι έτοιμοι για έναν ρόλο ή των κενών σε μια ομάδα.
