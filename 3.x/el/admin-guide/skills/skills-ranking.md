# Κατάταξη Δεξιοτήτων

Η Κατάταξη Δεξιοτήτων είναι ένας πίνακας κατάταξης χρηστών με βάση το πλήθος των δεξιοτήτων που έχουν αποκτήσει.

## Πρόσβαση στην Κατάταξη Δεξιοτήτων

Από τον πίνακα διαχείρισης, κάντε κλικ στο **Δεξιότητες > Κατάταξη δεξιοτήτων**.

## Τι εμφανίζει

Για κάθε ενεργό χρήστη, η κατάταξη εμφανίζει:

* **Αποκτημένες δεξιότητες** — Συνολικός αριθμός εκδοθεισών δεξιοτήτων, που χρησιμοποιείται για την ταξινόμηση του πίνακα κατάταξης (υψηλότερος πρώτος)
* **Σε εκμάθηση** — Ο αριθμός των δεξιοτήτων που συνδέονται, μέσω του βαθμολογίου, με μαθήματα στα οποία ο χρήστης είναι εγγεγραμμένος αυτή τη στιγμή (άμεσα ή μέσω συνεδρίας)

Χρησιμοποιήστε αυτή τη σελίδα για να εντοπίσετε με μια ματιά τους πιο καταξιωμένους εκπαιδευόμενους σας, ή για να αξιολογήσετε τη συνολική δραστηριότητα απόκτησης δεξιοτήτων στην πλατφόρμα.
