# Δεξιότητες

Το μπλοκ **Δεξιότητες** στον πίνακα διαχείρισης συγκεντρώνει τα εργαλεία για τον ορισμό, την οργάνωση και την παρακολούθηση σημάτων επάρκειας («δεξιοτήτων») σε όλη την πλατφόρμα. Μια δεξιότητα μπορεί να απονέμεται αυτόματα όταν ένας εκπαιδευόμενος φτάσει ένα όριο βαθμολογίου, ολοκληρώσει συγκεκριμένα μαθήματα, ή χειροκίνητα από έναν εκπαιδευτή, και μπορεί να φέρει εικονίδιο τύπου σήματος και ένα επίπεδο (για παράδειγμα Χάλκινο/Ασημένιο/Χρυσό).

Ολόκληρο το μπλοκ εμφανίζεται μόνο εάν η ρύθμιση **Enable skills tool** (`skill.allow_skills_tool`, στην ενότητα Configuration Settings > Skills) είναι ενεργοποιημένη — είναι ενεργοποιημένη από προεπιλογή.

## Πρόσβαση στο μπλοκ Δεξιότητες

Από τον πίνακα διαχείρισης, το μπλοκ **Δεξιότητες** εμφανίζεται δίπλα στα υπόλοιπα μπλοκ του πίνακα. Κάντε κλικ σε οποιονδήποτε από τους συνδέσμους του για να ανοίξετε το αντίστοιχο εργαλείο.

## Τι περιλαμβάνει το μπλοκ

* **[Διαχείριση δεξιοτήτων](managing-skills.md)** — Δημιουργία δεξιοτήτων, μαζική εισαγωγή τους και αντιστοίχιση καθεμιάς σε μια κλίμακα επιπέδων
* **[Τροχός δεξιοτήτων](skills-wheel.md)** — Ένας οπτικός χάρτης ολόκληρου του δέντρου δεξιοτήτων με δυνατότητα μεγέθυνσης
* **[Κατάταξη δεξιοτήτων](skills-ranking.md)** — Πίνακας κατάταξης χρηστών βάσει των δεξιοτήτων που έχουν αποκτήσει
* **[Δεξιότητες και αξιολογήσεις](skills-assessments.md)** — Σύνδεση κατηγοριών βαθμολογίου με τις δεξιότητες που απονέμουν

## Σχετικές ρυθμίσεις

Ορισμένες άλλες ρυθμίσεις στην ενότητα Configuration Settings > Skills αλλάζουν ποιος μπορεί να κάνει τι με αυτό το μπλοκ:

* **Allow HR skills management** (`allow_hr_skills_management`) — Επιτρέπει στους χρήστες Human Resources Manager να διαχειρίζονται δεξιότητες μαζί με τους διαχειριστές
* **Allow private skills** (`allow_private_skills`)
* **Teachers can assign skills** (`skills_teachers_can_assign_skills`)
* **Hide skill levels** (`hide_skill_levels`)
* **Show full skill name on skill wheel** (`show_full_skill_name_on_skill_wheel`)
