# Δεξιότητες και Αξιολογήσεις

Εδώ συνδέονται οι δεξιότητες με το βαθμολόγιο: είναι η γέφυρα μεταξύ των αποτελεσμάτων αξιολόγησης και της αυτόματης απονομής δεξιοτήτων.

## Πρόσβαση στις Δεξιότητες και Αξιολογήσεις

Από τον πίνακα διαχείρισης, κάντε κλικ στην επιλογή **Skills > Skills and assessments**.

## Τι εμφανίζει

Μια λίστα κατηγοριών βαθμολογίου, με στοιχεία ελέγχου για τη σύνδεση καθεμιάς με μια δεξιότητα. Μόλις συνδεθεί, κάθε εκπαιδευόμενος που φτάνει το όριο επιτυχίας της συγκεκριμένης κατηγορίας βαθμολογίου απονέμεται αυτόματα την αντίστοιχη δεξιότητα — χωρίς να απαιτείται χειροκίνητο βήμα.

Αυτός είναι ο συνιστώμενος τρόπος απονομής δεξιοτήτων σε μεγάλη κλίμακα: αντί να αντιστοιχίζετε δεξιότητες σε χρήστες έναν προς έναν, συνδέστε μία φορά τη σχετική κατηγορία βαθμολογίου και αφήστε την να εφαρμοστεί σε κάθε εκπαιδευόμενο που πληροί τις προϋποθέσεις. Δείτε [Βαθμολόγιο (Αξιολογήσεις)](../platform-settings/gradebook-settings.md) για το πώς ρυθμίζονται εξαρχής οι κατηγορίες βαθμολογίου και τα όρια.
