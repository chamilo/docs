# Διαχείριση Δεξιοτήτων

Αυτή η σελίδα καλύπτει τις τρεις καταχωρίσεις του πίνακα ελέγχου που χρησιμοποιούνται για τη δημιουργία του καταλόγου δεξιοτήτων της πλατφόρμας: μαζική εισαγωγή δεξιοτήτων, διαχείριση των ίδιων των ορισμών δεξιοτήτων και αντιστοίχιση κάθε δεξιότητας σε μια κλίμακα επιπέδων.

## Skills Import

**Skills > Skills import** σας επιτρέπει να δημιουργήσετε μαζικά μια ιεραρχία δεξιοτήτων από αρχείο CSV ή XML, αντί να δημιουργείτε τις δεξιότητες μία προς μία. Κάθε γραμμή χρειάζεται τουλάχιστον ένα `id`, ένα `parent_id` (για τη δημιουργία του δέντρου) και έναν `title`. Διατίθεται ένα δείγμα προτύπου στο οποίο μπορείτε να βασίσετε το αρχείο σας.

## Manage Skills

**Skills > Manage skills** είναι ο κύριος κατάλογος δεξιοτήτων: δημιουργία, επεξεργασία, ενεργοποίηση/απενεργοποίηση και διαγραφή δεξιοτήτων. Κάθε δεξιότητα έχει τίτλο, σύντομο κωδικό, περιγραφή, εικονίδιο και προαιρετική περιγραφή κριτηρίων (τι πρέπει να κάνει ένας εκπαιδευόμενος για να την αποκτήσει). Οι δεξιότητες μπορούν να είναι ένθετες — μια δεξιότητα μπορεί να έχει θυγατρικές δεξιότητες — κάτι που απεικονίζει ο [Τροχός Δεξιοτήτων](skills-wheel.md).

## Manage Skills Levels

**Skills > Manage skills levels** είναι μια ξεχωριστή, μικρότερη οθόνη: εμφανίζει τις υπάρχουσες δεξιότητες και σας επιτρέπει να αντιστοιχίσετε καθεμία σε ένα **προφίλ επιπέδων** — ένα επώνυμο, διατεταγμένο σύνολο επιπέδων (για παράδειγμα Χάλκινο/Ασημένιο/Χρυσό) βάσει του οποίου μετράται η δεξιότητα. Εν συντομία: χρησιμοποιήστε το **Manage skills** για να ορίσετε τι *είναι* μια δεξιότητα και το **Manage skills levels** για να ορίσετε σε ποια κλίμακα μετράται.

## Πώς Απονέμονται οι Δεξιότητες

Μια δεξιότητα απονέμεται σε έναν χρήστη (καταγράφεται ως εκδοθείσα δεξιότητα, με ημερομηνία) μέσω μίας από τις ακόλουθες διαδρομές:

* Αυτόματα, όταν ένας εκπαιδευόμενος πληροί το όριο μιας κατηγορίας βαθμολογίου — ρυθμίζεται στη σελίδα [Δεξιότητες και Αξιολογήσεις](skills-assessments.md)
* Αυτόματα, με την ολοκλήρωση συγκεκριμένων μαθημάτων με τα οποία συνδέεται η δεξιότητα
* Χειροκίνητα, από έναν εκπαιδευτή (εάν είναι ενεργοποιημένο το **Teachers can assign skills**) ή από έναν διαχειριστή
