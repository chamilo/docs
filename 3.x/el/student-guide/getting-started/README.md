# Ξεκινώντας

Αυτή η ενότητα σας βοηθά να προσανατολιστείτε στο Chamilo 3.0 ως εκπαιδευόμενος. Θα μάθετε πώς να δημιουργήσετε λογαριασμό (αν χρειάζεται), να συνδεθείτε και να περιηγηθείτε στην κύρια διεπαφή.

## Σύνδεση

Για να αποκτήσετε πρόσβαση στο Chamilo, ανοίξτε το πρόγραμμα περιήγησής σας και μεταβείτε στη διεύθυνση URL που σας έχει δώσει το ίδρυμά σας (για παράδειγμα, `https://chamilo.yourschool.edu`). Εισαγάγετε το όνομα χρήστη και τον κωδικό πρόσβασής σας στη σελίδα σύνδεσης και κάντε κλικ στο **Σύνδεση**.

Αν το ίδρυμά σας χρησιμοποιεί εξωτερική πιστοποίηση (όπως Azure, Keycloak ή σύστημα ενιαίας σύνδεσης του πανεπιστημίου), ενδέχεται να δείτε πρόσθετα κουμπιά σύνδεσης κάτω από την τυπική φόρμα σύνδεσης. Κάντε κλικ στο κατάλληλο κουμπί για να πιστοποιηθείτε μέσω του παρόχου ταυτότητας του ιδρύματός σας.

Αν δεν έχετε ακόμη λογαριασμό, δείτε [Δημιουργία λογαριασμού](creating-an-account.md).

> Αν έχετε ξεχάσει τον κωδικό πρόσβασής σας, κάντε κλικ στον σύνδεσμο **Ξεχάσατε τον κωδικό σας;** στη σελίδα σύνδεσης. Δείτε [Επαναφορά του κωδικού σας](../account-and-security/resetting-your-password.md) για την πλήρη διαδικασία.

## Πρώτη ματιά

Μετά τη σύνδεση, θα δείτε την αρχική σελίδα του Chamilo, οργανωμένη σε τρεις κύριες περιοχές: μια επάνω γραμμή, μια πλευρική γραμμή και μια κύρια περιοχή περιεχομένου. Αυτές περιγράφονται λεπτομερώς στο [Κατανόηση της διεπαφής](understanding-the-interface.md).

Από την πλευρική γραμμή, κάντε κλικ στο **Τα μαθήματά μου** για να δείτε όλα τα μαθήματα στα οποία είστε εγγεγραμμένοι. Κάθε μάθημα εμφανίζεται ως κάρτα που δείχνει την εικόνα του, τον τίτλο και ενέργειες γρήγορης πρόσβασης.

Αν το ίδρυμά σας χρησιμοποιεί **sessions** (χρονικά οριοθετημένες περιόδους κατάρτισης), θα δείτε επίσης έναν σύνδεσμο **Οι συνεδρίες μου** στην πλευρική γραμμή, οργανωμένο σε τρέχουσες, παρελθούσες και επερχόμενες συνεδρίες. Μια συνεδρία (session) είναι μια προγραμματισμένη έκδοση ή ομάδα ενός ή περισσότερων μαθημάτων — το ίδιο περιεχόμενο μαθήματος που παραδίδεται σε μια συγκεκριμένη ομάδα εκπαιδευομένων για μια συγκεκριμένη περίοδο.
