# Κατανόηση της διεπαφής

Το Chamilo 3.0 διαθέτει μια καθαρή, σύγχρονη διεπαφή σχεδιασμένη ώστε η πλοήγηση να παραμένει απλή. Αυτή η σελίδα εξηγεί κάθε μέρος της διεπαφής από την οπτική γωνία του εκπαιδευόμενου.

## Η επάνω γραμμή

Η επάνω γραμμή είναι πάντα ορατή στην κορυφή κάθε σελίδας. Περιέχει:

* **Λογότυπο πλατφόρμας** — Κάντε κλικ σε αυτό για να επιστρέψετε στην αρχική σελίδα ανά πάσα στιγμή.
* **Εικονίδιο εισερχομένων** <img src="/.gitbook/assets/icons/mdi-inbox.svg" alt="Inbox" data-size="line"> — Εμφανίζει τα μηνύματά σας. Ένα κόκκινο σήμα υποδεικνύει μη αναγνωσμένα μηνύματα. Κάντε κλικ για να ανοίξετε τα [Εισερχόμενα](../inbox.md).
* **Εικονίδιο δελτίου υποστήριξης** <img src="/.gitbook/assets/icons/mdi-ticket-account.svg" alt="Support" data-size="line"> — Εάν έχει ενεργοποιηθεί από τον διαχειριστή σας, σας δίνει πρόσβαση στο σύστημα δελτίων υποστήριξης. Δεν το ενεργοποιεί κάθε πλατφόρμα, επομένως μπορεί να βλέπετε μόνο το εικονίδιο εισερχομένων και το avatar σας.
* **Το avatar σας** — Μια κυκλική εικόνα στην επάνω δεξιά γωνία. Κάντε κλικ σε αυτήν για να ανοίξετε ένα αναπτυσσόμενο μενού:

![Το μενού του avatar σας, με συνδέσμους προς Το προφίλ μου, Τα πιστοποιητικά μου, Οι δεξιότητές μου και Αποσύνδεση](/.gitbook/assets/student-avatar-menu.png)

* **Το προφίλ μου** — Επεξεργαστείτε τα προσωπικά σας στοιχεία, αλλάξτε τον κωδικό πρόσβασης και (εάν είναι ενεργοποιημένο) ρυθμίστε τον έλεγχο ταυτότητας δύο παραγόντων
* **Τα πιστοποιητικά μου** — Κάθε πιστοποιητικό που έχετε αποκτήσει, σε όλα τα μαθήματά σας
* **Οι δεξιότητές μου** — Σήματα ικανοτήτων που σας έχουν απονεμηθεί
* **Αποσύνδεση**

## Η πλευρική γραμμή

Η πλευρική γραμμή στα αριστερά είναι η κύρια πλοήγησή σας. Μπορεί να συρρικνωθεί ώστε να δοθεί περισσότερος χώρος στην περιοχή περιεχομένου. Κάντε κλικ στο βέλος εναλλαγής στη δεξιά της άκρη για να την αναπτύξετε ή να τη συρρικνώσετε. Το Chamilo απομνημονεύει την προτίμησή σας.

Η πλευρική γραμμή περιέχει τους ακόλουθους συνδέσμους (ορισμένοι μπορεί να είναι κρυφοί ανάλογα με τη διαμόρφωση της πλατφόρμας σας):

| Στοιχείο μενού | Εικονίδιο | Περιγραφή |
|-----------|------|-------------|
| **Αρχική** | <img src="/.gitbook/assets/icons/mdi-home.svg" alt="Home" data-size="line"> | Επιστρέφει στον κύριο πίνακα ελέγχου |
| **Τα μαθήματά μου** | <img src="/.gitbook/assets/icons/mdi-book-open-page-variant.svg" alt="Courses" data-size="line"> | Παραθέτει όλα τα μαθήματα στα οποία είστε εγγεγραμμένοι |
| **Οι συνεδρίες μου** | <img src="/.gitbook/assets/icons/mdi-google-classroom.svg" alt="Sessions" data-size="line"> | Παραθέτει τις συνεδρίες κατάρτισής σας (τρέχουσες, παρελθούσες, επερχόμενες) |
| **Εξερευνήστε περισσότερα μαθήματα** | <img src="/.gitbook/assets/icons/mdi-bookmark-multiple.svg" alt="Catalogue" data-size="line"> | Περιηγηθείτε στον κατάλογο μαθημάτων για να βρείτε και να εγγραφείτε μόνοι σας σε νέα μαθήματα |
| **Ατζέντα** | <img src="/.gitbook/assets/icons/mdi-calendar-text.svg" alt="Agenda" data-size="line"> | Το προσωπικό σας ημερολόγιο και το ημερολόγιο μαθημάτων |
| **Αναφορές** | <img src="/.gitbook/assets/icons/mdi-chart-box.svg" alt="Reporting" data-size="line"> | Αναπτύσσεται σε **Πρόοδος** — τη δική σας επισκόπηση [Η πρόοδός μου](../my-progress.md) |
| **Κοινωνικό δίκτυο** | <img src="/.gitbook/assets/icons/mdi-sitemap-outline.svg" alt="Social network" data-size="line"> | Αναπτύσσεται στο [Κοινωνικό δίκτυο](../social-network.md) και σε σχετικούς συνδέσμους, εάν είναι ενεργοποιημένο |
| **Τηλεδιάσκεψη** | <img src="/.gitbook/assets/icons/mdi-video.svg" alt="Video" data-size="line"> | Πρόσβαση σε ζωντανές συνεδρίες βίντεο (εάν έχει διαμορφωθεί) |

Τα **Αναφορές** και **Κοινωνικό δίκτυο** δεν είναι απλοί σύνδεσμοι — κάνοντας κλικ σε αυτά αναπτύσσεται μια μικρή λίστα υποστοιχείων ακριβώς στην πλευρική γραμμή:

![Η πλευρική γραμμή με τα Αναφορές και Κοινωνικό δίκτυο αναπτυγμένα, εμφανίζοντας τα υποστοιχεία τους](/.gitbook/assets/student-sidebar-expanded.png)

* Κάτω από **Αναφορές**: μόνο **Πρόοδος**, που σας οδηγεί στην [Η πρόοδός μου](../my-progress.md).
* Κάτω από **Κοινωνικό δίκτυο**: **Αρχική** (ο κοινωνικός τοίχος), **Μηνύματα** (μια συντόμευση προς τα [Εισερχόμενα](../inbox.md)), **Οι φίλοι μου**, **Κοινωνικές ομάδες** — και, κάπως απροσδόκητα ομαδοποιημένα και εδώ, **Τα αρχεία μου** (ο προσωπικός σας χώρος αποθήκευσης αρχείων) και **Προσωπικά δεδομένα** (μια εξαγωγή των προσωπικών δεδομένων που διατηρεί η πλατφόρμα για εσάς). Αυτά τα δύο τελευταία δεν είναι πραγματικά «κοινωνικά» χαρακτηριστικά· απλώς βρίσκονται σε αυτό το μέρος της πλευρικής γραμμής.

Εάν ο λογαριασμός σας έχει πρόσθετους ρόλους (για παράδειγμα, διδάσκετε επίσης ένα μάθημα), μπορεί να δείτε επιπλέον στοιχεία πλευρικής γραμμής — όπως **Διαχείριση** — που ένας λογαριασμός μόνο εκπαιδευόμενου δεν βλέπει ποτέ.

Στο κάτω μέρος της πλευρικής γραμμής θα βρείτε μια επιλογή **Αποσύνδεση** για να αποσυνδεθείτε γρήγορα όταν τελειώσετε. Αυτή η επιλογή είναι επίσης διαθέσιμη από το αναπτυσσόμενο μενού του εικονιδίου avatar στην επάνω δεξιά γωνία.
Εάν η πλατφόρμα διαχειρίζεται μέσω εξωτερικών μεθόδων ελέγχου ταυτότητας, αυτές οι επιλογές αποσύνδεσης ενδέχεται να μην είναι διαθέσιμες.

## Η κύρια περιοχή περιεχομένου

Η κεντρική περιοχή της οθόνης εμφανίζει το περιεχόμενο της τρέχουσας σελίδας. Στην κορυφή θα βλέπετε συχνά μια **διαδρομή πλοήγησης (breadcrumb)** που δείχνει την τρέχουσα θέση σας στην πλατφόρμα (για παράδειγμα: Αρχική > Rock music > Documents). Χρησιμοποιήστε τα breadcrumbs για να επιστρέψετε σε μια γονική σελίδα.

## Η Αρχική Σελίδα του Μαθήματος

Όταν εισέρχεστε σε ένα μάθημα, βλέπετε την **αρχική σελίδα του μαθήματος**:

* **Τίτλος μαθήματος** — Εμφανίζεται εμφανώς στο επάνω μέρος
* **Εισαγωγή μαθήματος** — Μια προαιρετική περιγραφή εμπλουτισμένου κειμένου που έχει συντάξει ο διδάσκων σας
* **Πλέγμα εργαλείων** — Ένα πλέγμα εικονιδίων που αντιπροσωπεύουν τα διαθέσιμα εργαλεία σε αυτό το μάθημα (Documents, Exercises, Forums κ.λπ.)

Μόνο τα εργαλεία που ο διδάσκων έχει καταστήσει ορατά εμφανίζονται σε αυτό το πλέγμα — δείτε [Προσανατολισμός σε ένα μάθημα](../courses/course-tools-overview.md) για το τι κάνει το καθένα. Τα στοιχεία ελέγχου για την επεξεργασία του ίδιου του μαθήματος (προεπισκόπηση ως εκπαιδευόμενος, εμφάνιση/απόκρυψη εργαλείων, αναδιάταξή τους) εμφανίζονται μόνο σε διδάσκοντες και διαχειριστές μαθημάτων — δεν θα τα δείτε σε ένα μάθημα στο οποίο είστε εγγεγραμμένοι ως εκπαιδευόμενος.

## Χρώματα εικονιδίων

Αυτό εξακολουθεί να είναι πειραματικό και δεν είναι πλήρως ολοκληρωμένο στο Chamilo 3.0, αλλά προσπαθούμε να εφαρμόζουμε τους ακόλουθους κανόνες για όλα τα κουμπιά και τα εικονίδια ενεργειών στη διεπαφή:

* **Πράσινο** για ενέργειες δημιουργίας. Περιλαμβάνει την προσθήκη, τη δημιουργία, την εισαγωγή, την αποθήκευση και την αντιγραφή περιεχομένου.
* **Μπλε** για ενέργειες προβολής. Περιλαμβάνει την εξαγωγή, την προβολή, την προεπισκόπηση σε λίστες ή σε λεπτομερείς προβολές, την αναζήτηση και τη λήψη.
* **Πορτοκαλί** για ενέργειες επεξεργασίας. Περιλαμβάνει την επεξεργασία, τη μετακίνηση, τη διαμόρφωση, την ενεργοποίηση/απενεργοποίηση, την απόκρυψη και την εμφάνιση.
* **Κόκκινο** για ενέργειες διαγραφής/αφαίρεσης. Περιλαμβάνει τη διαγραφή, την αφαίρεση, την απεγγραφή.
* **Γκρι** για ενέργειες ακύρωσης. Απλώς διατήρηση των πραγμάτων στην υπάρχουσα κατάσταση.

## Προσαρμοστικός σχεδιασμός

Το Chamilo 3.0 προσαρμόζεται σε διαφορετικά μεγέθη οθόνης. Σε κινητή συσκευή ή σε στενό παράθυρο προγράμματος περιήγησης:

* Η πλευρική στήλη είναι κρυφή από προεπιλογή και μπορεί να ανοίξει πατώντας το εικονίδιο μενού
* Οι κάρτες μαθημάτων εμφανίζονται σε μία στήλη αντί για πλέγμα
* Οι πίνακες γίνονται οριζόντια κύλισης

Αυτό σημαίνει ότι μπορείτε να αποκτήσετε πρόσβαση στα μαθήματά σας από τηλέφωνο, tablet ή υπολογιστή, αν και η διεπαφή μπορεί να φαίνεται ελαφρώς διαφορετική ανάλογα με τη συσκευή.
