# Εισερχόμενα

Τα **Εισερχόμενα** είναι το σύστημα ιδιωτικών μηνυμάτων του Chamilo — ασύγχρονα μηνύματα τύπου ηλεκτρονικού ταχυδρομείου μεταξύ εσάς και άλλων χρηστών της πλατφόρμας, ανεξάρτητα από οποιοδήποτε συγκεκριμένο μάθημα.

## Πρόσβαση στα Εισερχόμενά σας

Κάντε κλικ στο εικονίδιο **Εισερχόμενα** <img src="../.gitbook/assets/icons/mdi-inbox.svg" alt="Εισερχόμενα" data-size="line"> στην επάνω γραμμή. Ένα κόκκινο σήμα δείχνει πόσα μη αναγνωσμένα μηνύματα έχετε. Αν αυτό το εικονίδιο δεν εμφανίζεται καθόλου, ο διαχειριστής σας έχει απενεργοποιήσει τα μηνύματα της πλατφόρμας.

## Ανάγνωση και απάντηση

Τα εισερχόμενά σας εμφανίζουν τα ληφθέντα μηνύματα, δείχνοντας ποια είναι μη αναγνωσμένα. Ανοίξτε ένα για να το διαβάσετε και χρησιμοποιήστε την **Απάντηση** για να απαντήσετε — μπορείτε να συμπεριλάβετε πολλούς παραλήπτες σε μία απάντηση ταυτόχρονα, κάτι χρήσιμο για να κρατάτε ενήμερη μια μικρή ομάδα ατόμων χωρίς να δημιουργείτε επίσημο μάθημα ή κοινωνική ομάδα.

![Τα Εισερχόμενα, με καρτέλες Εισερχόμενα / Μη αναγνωσμένα / Απεσταλμένα και πίνακα ληφθέντων μηνυμάτων](../.gitbook/assets/student-inbox.png)

## Σύνταξη νέου μηνύματος

Κάντε κλικ στο κουμπί **νέο μήνυμα** <img src="../.gitbook/assets/icons/mdi-email-plus-outline.svg" alt="Νέο μήνυμα" data-size="line">, επιλέξτε έναν ή περισσότερους παραλήπτες, γράψτε θέμα και σώμα και στείλτε. Όπως και στην απάντηση, ένα νέο μήνυμα μπορεί να σταλεί σε πολλά άτομα ταυτόχρονα.

## Καρτέλες και ενέργειες

Εκτός από τα **Εισερχόμενά** σας, μια καρτέλα εμφανίζει μόνο τα **Μη αναγνωσμένα** μηνύματά σας και μια άλλη τα **Απεσταλμένα** — όσα έχετε στείλει, για δική σας αναφορά. Ένα πλαίσιο αναζήτησης σας επιτρέπει να βρείτε ένα μήνυμα με λέξη-κλειδί. Τα κουμπιά πάνω από τη λίστα σας επιτρέπουν να συντάξετε νέο μήνυμα, να ανανεώσετε, να διαγράψετε επιλεγμένα μηνύματα και να επισημάνετε επιλεγμένα μηνύματα ως αναγνωσμένα.

## Ετικέτες μηνυμάτων

Αν η πλατφόρμα σας χρησιμοποιεί ετικέτες μηνυμάτων, θα δείτε μια λίστα ετικετών στα εισερχόμενά σας στην οποία μπορείτε να κάνετε κλικ για να φιλτράρετε τα μηνύματα κατά αυτή την ετικέτα — πρακτικό για να εντοπίζετε εύκολα σχετικές συνομιλίες καθώς τα εισερχόμενά σας μεγαλώνουν.

## Σχέση με άλλες δυνατότητες μηνυμάτων

Τα Εισερχόμενα είναι ανεξάρτητα από το εργαλείο [Συνομιλία](courses/using-the-chat-tool.md) του μαθήματος και από το αιωρούμενο πλαίσιο συνομιλίας που χρησιμοποιείται για άμεσα μηνύματα και τον [AI Tutor](courses/ai-tutor.md) — το καθένα είναι πραγματικά ξεχωριστή δυνατότητα, παρόλο που όλα αφορούν ανταλλαγή μηνυμάτων. Το [Κοινωνικό δίκτυο](social-network.md), αν είναι ενεργοποιημένο, χρησιμοποιεί τα ίδια Εισερχόμενα για ιδιωτικά μηνύματα αντί να έχει δικά του.

## Συμβουλές

* **Ελέγξτε το σήμα στο εικονίδιο Εισερχόμενα** — είναι ο ταχύτερος τρόπος να παρατηρήσετε νέα μηνύματα χωρίς να ανοίξετε τη σελίδα.
* **Χρησιμοποιήστε τα Εισερχόμενα για οτιδήποτε δεν συνδέεται με ένα μόνο μάθημα** — η συζήτηση που αφορά συγκεκριμένο μάθημα ανήκει γενικά στο Φόρουμ ή τη Συνομιλία εκείνου του μαθήματος.
* **Ο σύνδεσμος «Μηνύματα» του Κοινωνικού δικτύου οδηγεί στα ίδια Εισερχόμενα** — δεν χάνετε κάποιο ξεχωριστό γραμματοκιβώτιο αν φτάσετε εκεί από εκεί αντί από την επάνω γραμμή.
