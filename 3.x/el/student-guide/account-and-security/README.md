# Λογαριασμός και Ασφάλεια

Ο λογαριασμός σας στο Chamilo δίνει πρόσβαση στα μαθήματά σας, στους βαθμούς σας και στα προσωπικά σας δεδομένα — αξίζει να τον διατηρείτε ασφαλή. Αυτή η ενότητα καλύπτει τις λειτουργίες προστασίας λογαριασμού που ενδέχεται να συναντήσετε ως εκπαιδευόμενος.

* **[Επαναφορά του κωδικού πρόσβασής σας](resetting-your-password.md)** — Τι να κάνετε αν ξεχάσετε τον κωδικό πρόσβασής σας ή θέλετε να τον αλλάξετε
* **[Έλεγχος ταυτότητας δύο παραγόντων](two-factor-authentication.md)** — Προσθέστε ένα δεύτερο επίπεδο προστασίας στον λογαριασμό σας, εάν ο διαχειριστής σας το έχει ενεργοποιήσει
* **[CAPTCHA](captcha.md)** — Γιατί ενδέχεται να σας ζητηθεί να αποδείξετε ότι είστε άνθρωπος στις φόρμες σύνδεσης, εγγραφής ή απώλειας κωδικού πρόσβασης

Δεν είναι απαραίτητα ενεργή κάθε λειτουργία που περιγράφεται εδώ στην πλατφόρμα σας — οι διαχειριστές μπορούν να ενεργοποιούν ή να απενεργοποιούν καθεμία από αυτές. Αν κάτι που περιγράφεται σε αυτή την ενότητα δεν εμφανίζεται για εσάς, πιθανότατα δεν έχει ενεργοποιηθεί.
