# Μαθήματα

Μόλις αποκτήσετε λογαριασμό, το επόμενο βήμα είναι να εισέλθετε σε ένα μάθημα και να εξοικειωθείτε με αυτό.

* **[Εγγραφή σε μάθημα](subscribing-to-a-course.md)** — Οι διαφορετικοί τρόποι με τους οποίους μπορείτε να εγγραφείτε σε ένα μάθημα
* **[Πλοήγηση σε ένα μάθημα](course-tools-overview.md)** — Τι σημαίνει κάθε εργαλείο στην αρχική σελίδα του μαθήματος για εσάς ως εκπαιδευόμενο
* **[Ακολουθώντας μια διαδρομή μάθησης](following-a-learning-path.md)** — Μετάβαση μέσα από μια καθοδηγούμενη ακολουθία δραστηριοτήτων
* **[Διεξαγωγή τεστ](taking-tests.md)** — Τι να περιμένετε όταν ο εκπαιδευτής σας αναθέτει ένα κουίζ ή μια εξέταση
* **[Υποβολή εργασίας](submitting-an-assignment.md)** — Παράδοση αρχείων ή κειμένου για βαθμολόγηση
* **[Χρήση του φόρουμ](using-the-forum.md)** — Δημοσίευση και απάντηση σε συζητήσεις μαθήματος με νήματα
* **[Χρήση του εργαλείου συνομιλίας](using-the-chat-tool.md)** — Μηνύματα σε πραγματικό χρόνο εντός ενός μαθήματος
* **[Chatbot εκπαιδευτή AI](ai-tutor.md)** — Λήψη βοήθειας από έναν βοηθό AI, εφόσον η πλατφόρμα σας τον έχει ενεργοποιήσει

Αυτές οι σελίδες προϋποθέτουν ότι διαθέτετε ήδη λογαριασμό Chamilo. Αν δεν διαθέτετε, δείτε [Δημιουργία λογαριασμού](../getting-started/creating-an-account.md).
