# Γλωσσάρι

Βασικοί όροι που χρησιμοποιούνται σε όλο αυτόν τον οδηγό.

| Term | Definition |
|------|-----------|
| **Αξιολόγηση** | Βλ. **Βαθμολόγιο** παρακάτω |
| **Εργασία** | Μια εργασία στην οποία υποβάλλετε αρχεία ή κείμενο ώστε ο διδάσκων να τα εξετάσει και να τα βαθμολογήσει. Γνωστή και ως «δημοσίευση σπουδαστή» ή «work». |
| **CAPTCHA** | Μια πρόκληση (συνήθως πληκτρολόγηση παραμορφωμένων γραμμάτων από εικόνα) που χρησιμοποιείται για να επιβεβαιωθεί ότι είστε πραγματικό πρόσωπο, εμφανίζεται σε ορισμένες φόρμες σύνδεσης, εγγραφής και απώλειας κωδικού. |
| **Κατάλογος** | Η δημόσια λίστα μαθημάτων (και συνεδριών) που μπορείτε να περιηγηθείτε και, σε ορισμένες περιπτώσεις, να εγγραφείτε μόνοι σας. Πρόσβαση μέσω **Εξερεύνηση περισσότερων μαθημάτων**. |
| **Πιστοποιητικό** | Έγγραφο που δημιουργείται αυτόματα όταν επιτυγχάνετε την ελάχιστη βαθμολογία που ορίζεται στο βαθμολόγιο ενός μαθήματος. |
| **Μάθημα** | Ένα δοχείο για μαθησιακό περιεχόμενο και εργαλεία. Ένα μάθημα μπορεί να περιλαμβάνει έγγραφα, ασκήσεις, φόρουμ, μαθησιακές διαδρομές και άλλα. |
| **Εγγραφή** | Η εγγραφή σας σε ένα μάθημα ή μια συνεδρία, που σας δίνει πρόσβαση στο περιεχόμενό του. Γνωστή και ως «συνδρομή». |
| **Άσκηση** | Ένα κουίζ ή τεστ που περιέχει μία ή περισσότερες ερωτήσεις. Σε ορισμένα πλαίσια αναφέρεται και ως «τεστ». |
| **Φόρουμ** | Εργαλείο συζήτησης με νηματοειδείς συνομιλίες οργανωμένες σε κατηγορίες και θέματα. |
| **Βαθμολόγιο** | Εργαλείο που συγκεντρώνει τις βαθμολογίες σας από ασκήσεις, εργασίες και άλλες δραστηριότητες σε έναν ενιαίο βαθμό. |
| **Πρόσκληση** | Ένας σύνδεσμος μίας χρήσης που αποστέλλεται από διδάσκοντα στη διεύθυνση e-mail σας, ώστε να εγγραφείτε και να εγγραφείτε αυτόματα σε ένα μάθημα, ακόμη και αν η γενική εγγραφή είναι κλειστή. |
| **Μαθησιακή διαδρομή** | Μια δομημένη ακολουθία μαθησιακών δραστηριοτήτων (έγγραφα, ασκήσεις, σύνδεσμοι) που ακολουθείτε με καθορισμένη σειρά, ενίοτε με προαπαιτούμενα. |
| **Αυτοεγγραφή** | Η δυνατότητα δημιουργίας του δικού σας λογαριασμού μέσω δημόσιας φόρμας εγγραφής, εφόσον την έχει ενεργοποιήσει ο διαχειριστής της πλατφόρμας. |
| **Συνεδρία** | Μια χρονικά οριοθετημένη έκδοση ενός ή περισσότερων μαθημάτων που ανατίθεται σε συγκεκριμένη ομάδα εκπαιδευομένων, όπως ένα εξάμηνο ή μια κοόρτη. |
| **Δεξιότητα** | Μια ικανότητα συνδεδεμένη με επιτεύγματα του βαθμολογίου. Η απόκτηση πιστοποιητικού μπορεί να επικυρώσει τις σχετικές δεξιότητες. |
| **Έλεγχος ταυτότητας δύο παραγόντων (2FA)** | Ένα επιπλέον βήμα σύνδεσης με χρονικά βασισμένο κωδικό από εφαρμογή αυθεντικοποίησης, επιπλέον του κωδικού πρόσβασης. |
| **Ορατότητα** | Ρύθμιση που ελέγχει αν ένα εργαλείο, έγγραφο ή δραστηριότητα εμφανίζεται στους εκπαιδευόμενους. Οι διδάσκοντες βλέπουν πάντα τα κρυφά στοιχεία. |
