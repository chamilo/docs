# Samarbeid og kommunikasjon

Chamilo tilbyr flere verktøy som gjør det mulig å samhandle mellom deg og dine lærende, og mellom de lærende innbyrdes.

* **[Forum](forums.md)** — Trådede diskusjoner organisert etter kategori og emne
* **[Chat](chat.md)** — Sanntids tekstmeldinger innenfor et kurs
* **[Grupper](groups.md)** — Del lærende inn i arbeidsgrupper med egne delte verktøy
* **[Wiki](wiki.md)** — Samarbeidende dokumentredigering
* **[Blogg](blog.md)** — Delt blogging innenfor kurset
* **[Videokonferanse](video-conferencing.md)** — Direkte videoøkter med BigBlueButton eller Zoom

Disse verktøyene er tilgjengelige fra kursets startsidе. Noen kan være skjult som standard — du kan gjøre dem synlige fra verktøyrutenettet (se [Kursets startsidе](../creating-your-course/course-homepage.md)).
