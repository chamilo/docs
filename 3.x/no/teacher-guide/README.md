# Lærerveiledning

Velkommen til lærerveiledningen for Chamilo 3.0. Denne veiledningen er laget for instruktører, opplæringsansvarlige og alle som har ansvar for å lage og levere læringsinnhold gjennom Chamilo-plattformen.

Enten du setter opp ditt første nettkurs eller administrerer et komplekst opplæringsprogram, vil denne veiledningen ta deg gjennom alle funksjonene som er tilgjengelige for deg som lærer.

## Hva du kan gjøre med Chamilo

Som lærer i Chamilo kan du:

* **Opprette og organisere kurs** med en fleksibel hjemmeside og tilpassbare verktøy
* **Legge til innhold** — laste opp dokumenter, opprette læringsstier, bygge ordlister og lenke til eksterne ressurser
* **Vurdere dine lærende** — utforme øvelser med flere spørsmålstyper, samle inn innleveringer, gjennomføre undersøkelser og administrere karakterer
* **Samarbeide** — sette opp forum, gruppearbeid, wikier, blogger og live videoøkter
* **Følge fremgang** — overvåke aktivitet hos de lærende, generere rapporter og tildele sertifikater
* **Bruke AI-verktøy** — generere øvelser og læringsstier automatisk, og få AI-assistert karaktersetting

## Hvordan denne veiledningen er organisert

Denne veiledningen følger den naturlige arbeidsflyten for å bygge og drive et kurs:

1. **Komme i gang** — Logg inn, naviger i grensesnittet og sett opp profilen din
2. **Opprette kurset ditt** — Opprett et nytt kurs, konfigurer innstillingene og tilpass hjemmesiden
3. **Legge til innhold** — Last opp dokumenter, organiser læringsstier og administrer ressurser
4. **Vurdere lærende** — Bygg tester, samle inn innleveringer, gjennomfør undersøkelser og sett opp karakterboken
5. **Samarbeid og kommunikasjon** — Aktiver forum, chat, grupper, wiki og videokonferanse
6. **Sporing og rapportering** — Overvåk fremgangen til de lærende og generer rapporter
7. **AI-verktøy** — Bruk AI-drevne funksjoner til å generere innhold og bistå med karaktersetting
8. **Ytterligere verktøy** — Agenda, notatbok, portefølje og mer

La oss komme i gang.
