# Legge til innhold

Denne delen omhandler verktøyene du bruker for å legge til læringsinnhold i kurset ditt. Chamilo tilbyr flere måter å formidle materiale til dine lærende:

* **[Dokumenter](documents.md)** — Last opp filer, opprett nettsider og organiser innholdsbiblioteket ditt
* **[Lenker](links.md)** — Del URL-er til eksterne ressurser, organisert etter kategori
* **[Læringsstier](learning-paths.md)** — Bygg strukturerte innholdssekvenser med forutsetninger og fremdriftssporing
* **[Ordliste](glossary.md)** — Definer nøkkelbegreper som lærende kan slå opp gjennom hele kurset
* **[Kunngjøringer](announcements.md)** — Send meldinger og oppdateringer til innskrevne lærende
* **[Flerspråklig innhold](multi-language-content.md)** — Skriv flere språkversjoner av det samme innholdet og la hver lærende bare se sin egen

Hvert verktøy er tilgjengelig fra verktøyrutenettet på kursets startside. Klikk på verktøyets ikon for å åpne det.
