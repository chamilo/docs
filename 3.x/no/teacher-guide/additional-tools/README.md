# Tilleggsverktøy

Utover kjerneverktøyene for innhold, vurdering og samarbeid tilbyr Chamilo flere tilleggsverktøy som kan berike kurset ditt.

* **[Agenda](agenda.md)** — Planlegg hendelser, frister og påminnelser for kurset ditt
* **[Notatbok](notebook.md)** — Et personlig notatverktøy for lærende
* **[Dropbox](dropbox.md)** — Et enkelt verktøy for filutveksling mellom deg og de lærende
* **[Portefølje](portfolio.md)** — La lærende bygge og vise frem en portefølje av arbeidet sitt
* **[Kursfremdrift](course-progress.md)** — Definer tematiske seksjoner og følg kursgjennomføringen
