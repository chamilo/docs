# Frontend

Chamilo 3.0-frontenden er en Vue 3-applikasjon av typen single-page application (SPA) som kommuniserer med backend via REST API.

* **[Vue-komponenter](vue-components.md)** — De gjenbrukbare komponentene i `assets/vue/components/`
* **[Visninger og ruting](views-and-routing.md)** — Sidevisninger i `assets/vue/views/` og oppsettet av Vue Router
* **[Tilstandsadministrasjon](state-management.md)** — Pinia-lagre for applikasjonstilstand
* **[Byggesystem](build-system.md)** — Webpack Encore, Tailwind og byggepipelinen
