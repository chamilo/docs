# API

Chamilo 3.0 eksponerer et REST API bygget på **API Platform 4**. API-et gir programmatisk tilgang til plattformressurser og er det samme API-et som brukes av Vue-frontend.

* **[Autentisering](authentication.md)** — JWT-tokenbasert autentisering
* **[Endepunktreferanse](endpoints-reference.md)** — Oversikt over tilgjengelige API-ressurser
* **[Tilpassede handlinger](custom-actions.md)** — Spesialiserte endepunkter utover standard CRUD
* **[Webhooks](webhooks.md)** — Hendelsesdrevne varsler til eksterne systemer
