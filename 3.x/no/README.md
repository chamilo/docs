# Chamilo 3.0-dokumentasjon

Velkommen til den offisielle dokumentasjonen for **Chamilo 3.0**, den åpne e-læringsplattformen.

Dokumentasjonen er organisert i fire veiledninger, hver tilpasset en bestemt målgruppe:

* [**Lærerveiledning**](teacher-guide/) — For instruktører og trenere: opprett kurs, legg til innhold, vurder lærende og følg fremgang.
* [**Administrasjonsveiledning**](admin-guide/) — For plattformadministratorer: installer, konfigurer og administrer Chamilo-plattformen.
* [**Studentveiledning**](student-guide/) — For lærende: bli med i kurs, følg læringsstier, ta tester og følg din egen fremgang.
* [**Utviklerveiledning**](developer-guide/) — For utviklere: forstå arkitekturen, bygg plugins, bruk API-et og bidra til prosjektet.

## Hva er nytt i Chamilo 3.0

Chamilo 3.0 er en større utgivelse med fokus på KI-assistert undervisning, sikkerhetsherding og et fullt modernisert plugin-økosystem:

* **KI-drevne undervisningsverktøy** — En kurskvalitetsanalysator, en KI-veileder som svarer på spørsmål om plattformen, en Student Success Coach med anbefalinger per lærende, KI-genererte kursillustrasjoner og hurtigtester, og KI-assistert karaktersetting
* **Model Context Protocol (MCP)-server** — Lar KI-klienter opprette og administrere kurs, tester, læringsstier, undersøkelser og mer direkte
* **Sikkerhetsherding** — Innebygd File Integrity Monitoring pluss dusinvis av tilgangskontrollrettinger på tvers av kurs, økter og API-et
* **Full modernisering av plugin-økosystemet** — Alle plugins fra 1.11.x er reaktivert, med et redesignet grensesnitt for plugin-administrasjon
* **Hierarkiske URL-er og flersideadministrasjon** — Et globalt fler-URL-panel pluss visuell geografisk kartadministrasjon for avdelinger og rom
* **Forbedrede læringsstier og øvelser** — Progressiv adaptiv testing, OnlyOffice-redigering i kjøretid, adaptiv hotspot-avgrensning og utvidet SCORM 2004-støtte
* **Karakterbok og sertifikater** — Utløpsdatoer for sertifikater med påminnelser og tilpassbare karaktersettingsmoduser
* **Mobilklart REST API** — En modernisert backend bygget for mobilapper og tredjepartsintegrasjoner
