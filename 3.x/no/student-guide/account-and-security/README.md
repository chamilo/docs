# Konto og sikkerhet

Chamilo-kontoen din gir tilgang til kursene dine, karakterene dine og dine personopplysninger — det er verdt å holde den sikker. Denne delen dekker funksjonene for kontobeskyttelse du kan møte som lærende.

* **[Tilbakestille passordet ditt](resetting-your-password.md)** — Hva du skal gjøre hvis du glemmer passordet, eller vil endre det
* **[Tofaktorautentisering](two-factor-authentication.md)** — Legg til et ekstra beskyttelseslag på kontoen din, hvis administratoren har aktivert det
* **[CAPTCHA](captcha.md)** — Hvorfor du kan bli bedt om å bevise at du er et menneske på innloggings-, registrerings- eller glemt-passord-skjemaene

Ikke alle funksjonene som beskrives her er nødvendigvis aktive på plattformen din — administratorer kan slå hver av dem av eller på. Hvis noe som beskrives i denne delen ikke vises for deg, er det sannsynligvis ikke aktivert.
