# Andre adminblokker

Administrasjonsoversikten har noen flere blokker som ikke er konfigurerbare funksjoner, men snarere informative widgeter: en side med utgående lenker, en versjonskontrollregistrering og to små paneler som henter innhold fra chamilo.org. Dette kapitlet forklarer hva hver av dem er, hvor innholdet kommer fra, og — siden noen av dem gjør det — om noen data forlater plattformen din.

## Hva som dekkes

* **[Lenker til Chamilo.org](chamilo-org-links.md)** — En bokmerkeliste til offisielle Chamilo-ressurser; sender ingenting
* **[Versjonskontroll](version-check.md)** — Valgfri registrering som rapporterer plattformens versjon og bruk til chamilo.org, og forteller deg om du bør oppdatere
* **[Profesjonell støtte](professional-support.md)** — Et skrivebeskyttet panel som beskriver offisielle Chamilo-støtteleverandører
* **[Nyheter fra Chamilo](news-from-chamilo.md)** — En skrivebeskyttet strøm av offisielle kunngjøringer, inkludert sikkerhetsoppdateringer og nye utgivelser

Hver side nedenfor angir tydelig hva, om noe, som sendes til chamilo.org, og hvorfor.
