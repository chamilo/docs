# Chamilo.org-lenker

Blokken **Chamilo.org** er en statisk liste over utgående lenker til offisielle Chamilo-ressurser — ingenting mer. Den sender ingen data noe sted; hver lenke åpner enten et eksternt Chamilo-nettsted eller en lokal dokumentasjonsside som følger med installasjonen din.

## Hva blokken inneholder

| Lenke | Destinasjon |
|------|-------------|
| Chamilo-hjemmeside | `chamilo.org` |
| Brukerveiledninger | `docs.chamilo.org` |
| Chamilo-forum | GitHub Discussions for chamilo-lms |
| Installasjonsveiledning | Lokal, `/documentation/installation_guide.html` |
| Endringer i siste versjon | Lokal, `/documentation/changelog.html` |
| Bidragsyterliste | Lokal, `/documentation/credits.html` |
| Sikkerhetsveiledning | Lokal, `/documentation/security.html` |
| Optimaliseringsveiledning | Lokal, `/documentation/optimization.html` |
| Offisielle Chamilo-tjenesteleverandører | `chamilo.org/providers` |

De «lokale» lenkene peker til dokumentasjonsfiler som følger med selve Chamilo-installasjonen, slik at de lastes fra din egen server, ikke fra chamilo.org.

## Formål

Denne blokken finnes utelukkende for bekvemmelighet — rask tilgang til prosjektets offisielle dokumentasjon, fellesskapets diskusjonsområde og listen over godkjente tjenesteleverandører, uten at du trenger å lete etter dem.
