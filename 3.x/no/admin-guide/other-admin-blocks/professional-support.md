# Profesjonell støtte

Profesjonell støtte er et lite skrivebeskyttet panel som beskriver offisielle Chamilo-støttetjenester — nyttig hvis organisasjonen din trenger betalt hjelp utover fellesskapsstøtte.

## Hva det viser og hvor det kommer fra

Panelet henter innhold fra `version.chamilo.org/c/support/latest.php`, og ber om det på plattformens grensesnittspråk. Det eneste plattformen sender er den språkkoden — ingenting om plattformens bruk eller konfigurasjon.

## Formål

Dette panelet er informativt og promotert: det peker administratorer mot Chamilos offisielle tjenesteleverandører (rådgivning, hosting, tilpasset utvikling og sertifisert støtte) for organisasjoner som ønsker en avtalebundet, sertifisert partner i stedet for å stole utelukkende på fellesskapsfora. Se også [Chamilo.org-lenker](chamilo-org-links.md), som lenker direkte til den offisielle listen over leverandører.
