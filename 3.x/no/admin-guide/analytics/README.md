# Analyse

**Analyse**-blokken på administrasjonspanelet samler plattformomfattende statistikk, læringsanalyse, bedrifts-/HR-rapportering og verktøy for masseeksport. Avhengig av Chamilo-versjonen kan denne blokken merkes **"Tracking"** på selve panelet — det er den samme blokken uansett. Denne veiledningen kaller den Analyse gjennomgående for å unngå forveksling med [Sporingsinnstillinger](../platform-settings/tracking-settings.md), den separate innstillingskategorien som styrer hva som registreres, og ikke selve rapportene.

## Tilgang til Analyse

Fra administrasjonspanelet vises **Analyse**-blokken sammen med de andre blokkene på panelet. Klikk på en av lenkene for å åpne den tilhørende rapporten.

## Hva som finnes i blokken

* **[Global statistikk](global-statistics.md)** — Plattformomfattende statistikk: kurs, brukere, innlogginger, økter og diskbruk
* **[Rapportkatalog](reports-catalog.md)** — Bla gjennom alle registrerte rapporter, hvem som har tilgang, og hvorfor
* **[Læringsanalyse](learning-analytics.md)** — Det klassiske sporingspanelet: nedbrytning på bruker, kurs og økt med tidsbruk og gjennomsnittlige skårer
* **[Bedriftsrapporter](corporate-reports.md)** — Kvartalsvise sammendrag, sporing av lærertid og HR-orientert kurs-/brukerrapportering
* **[Tickets](tickets.md)** — Gå direkte til listen over support-tickets

## Hvem som har tilgang

De fleste av disse rapportene krever tilgang som **Portal Administrator**. Bedriftsrapporten er unntaket — den er også åpen for rollene **Human Resources Manager** og **Student Boss**, siden den er laget spesielt for dette publikummet.
