# Læringsanalyse

Læringsanalyse er Chamilos klassiske sporingsdashbord (historisk kjent som «MySpace» eller «Reporting»). Det er det primære drill-down-verktøyet for å følge prestasjoner hos lærende, i kurs og i økter.

## Tilgang til læringsanalyse

Fra administrasjonspanelet klikker du **Analytics > Learning analytics**.

## Hva det viser

* **Oversiktstall** — Antall studenter, lærere og HR-brukere; tildelte kurs og økter
* **Drill-downs** — Separate visninger for brukere, kurs og økter, som hver viser gjennomsnittlig tidsbruk, gjennomsnittlig poengsum og fremdrift
* **CSV-eksport** — Eksporter gjeldende visning for analyse utenfor systemet

I motsetning til Global Statistics tilpasses denne visningens omfang visningsbrukerens rolle: en global administrator ser data for hele plattformen, mens en lærer eller øktveileder som åpner den tilsvarende visningen i sitt eget kurs, bare ser sine egne kurs og økter. Som administrator som bruker denne dashbordoppføringen, får du visningen for hele plattformen.

## Relatert

For rapportering med fokus på arbeidsbelastning i stedet for prestasjoner hos lærende, se [Corporate Reports](corporate-reports.md), som inkluderer Teachers Time Report.
