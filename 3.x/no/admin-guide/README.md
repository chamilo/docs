# Administrasjonsveiledning

Velkommen til administrasjonsveiledningen for Chamilo 3.0. Denne veiledningen er beregnet på plattformadministratorer som er ansvarlige for å installere, konfigurere og administrere en Chamilo-instans.

## Hva du kan gjøre som administrator

Som Chamilo-administrator administrerer du:

* **Installasjon og konfigurasjon** — Sett opp Chamilo på serveren din, konfigurer lagring, e-post og miljøinnstillinger
* **Brukere** — Opprett, importer og administrer brukerkontoer, roller og tillatelser
* **Kurs og sesjoner** — Overvåk kursopprettelse, administrer kurskatalogen og konfigurer opplæringssesjoner
* **Plattform** — Språk, portalnyheter, den globale agendaen og CMS-verktøyet Sider
* **Plattforminnstillinger** — Konfigurer portalens atferd, sikkerhet, ytelse og tilgjengelighet av funksjoner
* **Analyse** — Plattformstatistikk, læringsanalyse og bedrifts-/HR-rapportering
* **Ferdigheter** — Definer kompetansebadges og knytt dem til resultater i karakterboken
* **System** — Verktøy for servervedlikehold, selvoppdatering, lagringsinspeksjon og merkevarebygging
* **Rom** — Administrer fysiske steder og bookbare opplæringsrom
* **Sikkerhet** — Overvåk innloggingsforsøk, gjennomgå flaggede inntrengingsforsøk, sjekk passordstyrke og verifiser filintegritet
* **Plugins** — Installer, konfigurer og administrer plattformutvidelser
* **Autentisering** — Sett opp eksterne innloggingssystemer (OAuth2, LDAP, CAS, SCIM)
* **Integrasjoner** — Koble Chamilo til videokonferanse, LTI-verktøy, AI-leverandører og mer
* **Vedlikehold** — Utfør sikkerhetskopiering, overvåk systemhelse og administrer lagring

## Hvordan denne veiledningen er organisert

1. **Komme i gang** — En oversikt over administrasjonsgrensesnittet
2. **Installasjon** — Serverkrav, installasjonsveiviser og innledende konfigurasjon
3. **Brukere** — Administrasjon av brukerkontoer, roller, grupper og profiler
4. **Kurs** — Administrasjon av kurs, kategorier og import/eksport
5. **Sesjoner** — Organisering av tidsavgrensede opplæringskohorter
6. **Plattform** — Språk, portalnyheter, den globale agendaen og CMS-verktøyet Sider
7. **Plattforminnstillinger** — Konfigurering av alle aspekter ved plattformen
8. **Analyse** — Statistikk, læringsanalyse og bedrifts-/HR-rapportering
9. **Ferdigheter** — Kompetansebadges og utmerkelser styrt av karakterboken
10. **System** — Serververktøy, selvoppdatering, lagringsinspeksjon og merkevarebygging
11. **Rom** — Avdelinger og bookbare opplæringsrom
12. **Sikkerhet** — Verktøy for sikkerhetsovervåking og revisjon
13. **Plugins** — Administrasjon av plattformutvidelser
14. **Helsesjekk** — Sanntidskontroller av konfigurasjonen
15. **Andre administrasjonsblokker** — Lenker til Chamilo.org, versjonskontroll, støtte og nyheter
16. **Autentisering** — Oppsett av eksterne autentiseringsleverandører
17. **Integrasjoner** — Tilkobling av tredjepartstjenester
18. **Multi-URL** — Drift av flere portaler fra én enkelt installasjon
19. **Ytelsesjustering** — Optimalisering av plattformen for hastighet og skalering
20. **Vedlikehold** — Sikkerhetskopier, systemstatus og opprydding
