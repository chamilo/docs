# Komme i gang

Denne delen introduserer administrasjonsgrensesnittet i Chamilo 3.0 og hjelper deg med å orientere deg.

## Hvem er en administrator?

Chamilo har flere nivåer av administrative roller:

| Rolle | Tilgang |
|------|--------|
| **Administrator** | Full tilgang til alle administrasjonsfunksjoner for plattformen. Også kjent som **Portal Administrator** |
| **Global Administrator** | Samme som Portal Administrator, med tilgang på tvers av alle tilgangs-URL-er i et oppsett med flere URL-er (flere leietakere) |
| **Sessions Administrator** | Kan administrere økter, melde brukere på økter og få tilgang til øktrelaterte innstillinger |
| **Human Resources Manager** | Kan se læringsfremgang og sporingsdata for tildelte brukere |
| **Questions Manager** | Mindre en administrator enn en innholdskurator; spørsmålsansvarlige har tilgang til en global spørsmålsbank for å vurdere spørsmålenes kvalitet |

Denne veiledningen fokuserer primært på rollen **Portal Administrator**, som har den bredeste tilgangen.

## Innlogging

Administratorer logger inn via den samme innloggingssiden som alle andre brukere. Etter at du har skrevet inn påloggingsinformasjonen, sendes du (dersom ingen annen konfigurasjon er satt) til siden **Administration**. En merkbare forskjell fra andre brukerroller er delen **Administration** i sidemenyen (ikke synlig for andre roller).
