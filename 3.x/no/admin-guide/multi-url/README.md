# Multi-URL

Chamilos multi-URL-funksjon (også kalt multi-tenant) lar deg kjøre flere virtuelle portaler fra én enkelt Chamilo-installasjon. Hver portal har sin egen URL, merkevareprofil, brukere, kurs og innstillinger, men de deler alle samme database og kodebase.

* **[Tilgangs-URL-er](access-urls.md)** — Konfigurer og administrer flere tilgangs-URL-er
