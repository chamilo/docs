De fleste av disse aktiveres via programtillegg. Se den tilhørende seksjonen litt lenger ut i denne veiledningen.

* **[Videokonferanse](video-conferencing.md)** — BigBlueButton og Zoom
* **[LTI 1.3](lti.md)** — Koble til eksterne læringsverktøy
* **[xAPI](xapi.md)** — Sporing av læringsopplevelser
* **[OnlyOffice](onlyoffice.md)** — Samarbeidende dokumentredigering
* **[AI-konfigurasjon](ai-configuration.md)** — Sett opp AI-leverandører for AI-drevne funksjoner
