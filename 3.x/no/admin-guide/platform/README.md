# Plattform

Blokken **Plattformadministrasjon** på administrasjonsoversikten samler konfigurasjons- og kommunikasjonsverktøy for hele portalen — alt fra det komplette innstillingspanelet til språk, offentlige kunngjøringer, den globale kalenderen og det CMS-lignende Pages-systemet som bygger deler av portalens offentlige innhold.

![Blokken Plattformadministrasjon på administrasjonsoversikten, med oppføringene Konfigurasjonsinnstillinger, Språk, Plugins, Regioner, Portalnyheter, Global agenda, Sider, Angi registreringssiden, Ekstra felt, Konfigurer flere tilgangs-URL-er, E-postmaler, Eksterne verktøy (LTI), Kategorier for kontaktskjema og Systemmaler](../../.gitbook/assets/admin-platform-block.png)

## Tilgang til plattformblokken

Fra administrasjonspanelet vises blokken **Plattformadministrasjon** sammen med de andre oversiktsblokkene. Klikk på en av lenkene for å åpne det tilhørende verktøyet.

## Hva som finnes i blokken

* **[Plattforminnstillinger](../platform-settings/README.md)** — Det komplette konfigurasjonsinnstillingspanelet (portal, kurs, økter, brukere, sikkerhet med mer). Lenken «Konfigurasjonsinnstillinger» i denne blokken er bare inngangspunktet til det separate kapitlet.
* **[Språk](languages.md)** — Velg hvilke grensesnittspråk som er tilgjengelige for brukerne, og angi plattformens standard
* **[Portalnyheter](portal-news.md)** — Kunngjøringer for hele plattformen (systemkunngjøringer), planlagt og målrettet etter rolle
* **[Global agenda](global-agenda.md)** — Kalenderhendelser for hele plattformen, synlige for alle brukere uavhengig av kurs eller økt
* **[Sider](pages.md)** — Det CMS-lignende verktøyet bak portalens hjemmeside, bunntekst og andre offentlige innholdsblokker, inkludert introduksjonsteksten på registreringssiden
* **[Plattformverktøy](platform-tools.md)** — Ekstra felt, e-postmaler, kategorier for kontaktskjema og noen færre, betinget viste elementer
* **Konfigurer flere tilgangs-URL-er** — Dekkes i [Tilgangs-URL-er](../multi-url/access-urls.md), under Multi-URL
* **Eksterne verktøy (LTI)** — Dekkes i [LTI 1.3](../integrations/lti.md), under Integrasjoner
