# API

Chamilo 2.0 提供了一个基于 **API Platform 3.0** 构建的 REST API。该 API 为平台资源提供了程序化访问接口，并且与 Vue 前端使用的是同一个 API。

* **[认证](authentication.md)** — 基于 JWT 令牌的认证
* **[端点参考](endpoints-reference.md)** — 可用 API 资源的概述
* **[自定义操作](custom-actions.md)** — 超出标准 CRUD 的专用端点
* **[Webhooks](webhooks.md)** — 向外部系统发送事件驱动的通知
