# API

Chamilo 2.0 expose une API REST construite sur **API Platform 3.0**. L'API offre un accès programmatique aux ressources de la plateforme et est la même API utilisée par l'interface frontend Vue.

* **[Authentification](authentication.md)** — Authentification basée sur des tokens JWT
* **[Référence des points de terminaison](endpoints-reference.md)** — Aperçu des ressources API disponibles
* **[Actions personnalisées](custom-actions.md)** — Points de terminaison spécialisés au-delà des opérations CRUD standard
* **[Webhooks](webhooks.md)** — Notifications basées sur des événements vers des systèmes externes
