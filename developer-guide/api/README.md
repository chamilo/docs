# API

O Chamilo 2.0 disponibiliza uma API REST construída com base no **API Platform 3.0**. A API oferece acesso programático aos recursos da plataforma e é a mesma API utilizada pelo frontend em Vue.

* **[Autenticação](authentication.md)** — Autenticação baseada em token JWT
* **[Referência de Endpoints](endpoints-reference.md)** — Visão geral dos recursos de API disponíveis
* **[Ações Personalizadas](custom-actions.md)** — Endpoints especializados além do CRUD padrão
* **[Webhooks](webhooks.md)** — Notificações orientadas a eventos para sistemas externos
