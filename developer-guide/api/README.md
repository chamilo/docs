# API

Chamilo 3.0 expose une API REST construite sur **API Platform 4**. L’API offre un accès programmatique aux ressources de la plateforme et constitue la même API que celle utilisée par le frontend Vue.

* **[Authentification](authentication.md)** — Authentification basée sur des jetons JWT
* **[Référence des points de terminaison](endpoints-reference.md)** — Vue d’ensemble des ressources API disponibles
* **[Actions personnalisées](custom-actions.md)** — Points de terminaison spécialisés au-delà du CRUD standard
* **[Webhooks](webhooks.md)** — Notifications événementielles vers des systèmes externes
