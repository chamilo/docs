# API

Chamilo 2.0 stellt eine REST-API bereit, die auf **API Platform 3.0** basiert. Die API ermöglicht den programmgesteuerten Zugriff auf Plattformressourcen und ist dieselbe API, die vom Vue-Frontend verwendet wird.

* **[Authentifizierung](authentication.md)** — JWT-Token-basierte Authentifizierung
* **[Endpunkte-Referenz](endpoints-reference.md)** — Übersicht über verfügbare API-Ressourcen
* **[Benutzerdefinierte Aktionen](custom-actions.md)** — Spezialisierte Endpunkte jenseits von Standard-CRUD
* **[Webhooks](webhooks.md)** — Ereignisgesteuerte Benachrichtigungen an externe Systeme
