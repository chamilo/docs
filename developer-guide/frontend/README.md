# الواجهة الأمامية

تُعد واجهة Chamilo 2.0 الأمامية تطبيق صفحة واحدة (SPA) مبنيًا بـ Vue 3 يتواصل مع الخلفية عبر REST API.

* **[Vue Components](vue-components.md)** — المكونات القابلة لإعادة الاستخدام في `assets/vue/components/`
* **[Views and Routing](views-and-routing.md)** — عرض الصفحات في `assets/vue/views/` وإعداد Vue Router
* **[State Management](state-management.md)** — مخازن Pinia للحالة التطبيقية
* **[Build System](build-system.md)** — Webpack Encore، و Tailwind، وخط أنابيب البناء
