# Frontend

Το frontend του Chamilo 2.0 είναι μια εφαρμογή single-page (SPA) με Vue 3 που επικοινωνεί με το backend μέσω του REST API.

* **[Vue Components](vue-components.md)** — Τα επαναχρησιμοποιήσιμα components στο `assets/vue/components/`
* **[Views and Routing](views-and-routing.md)** — Οι προβολές σελίδων στο `assets/vue/views/` και η ρύθμιση του Vue Router
* **[State Management](state-management.md)** — Pinia stores για την κατάσταση της εφαρμογής
* **[Build System](build-system.md)** — Webpack Encore, Tailwind, και η αλυσίδα κατασκευής
