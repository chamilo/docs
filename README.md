# Documentation de Chamilo 3.0

Bienvenue dans la documentation officielle de **Chamilo 3.0**, la plateforme e-learning open source.

Cette documentation est organisée en trois guides, chacun destiné à un public spécifique :

* [**Guide de l'enseignant**](teacher-guide/) — Pour les formateurs et les enseignants : créer des cours, ajouter du contenu, évaluer les apprenants et suivre la progression.
* [**Guide d'administration**](admin-guide/) — Pour les administrateurs de la plateforme : installer, configurer et gérer la plateforme Chamilo.
* [**Guide du développeur**](developer-guide/) — Pour les développeurs : comprendre l'architecture, créer des plugins, utiliser l'API et contribuer au projet.

## Nouveautés de Chamilo 3.0

Chamilo 3.0 est une version majeure, avec une interface entièrement redessinée et de nombreuses nouvelles fonctionnalités :

* **Interface moderne** — Conçue avec Vue 3 et PrimeVue pour une expérience plus rapide et plus réactive
* **Outils assistés par l'IA** — Générer des exercices, des parcours d'apprentissage et obtenir une notation assistée par l'IA
* **REST API** — REST API complète basée sur API Platform, avec authentification JWT
* **Nouvelles options d'authentification** — OAuth2 (Azure, Keycloak, Facebook), provisionnement des utilisateurs SCIM
* **LTI 1.3** — Connecter des outils d'apprentissage externes de manière transparente
* **Stockage cloud** — Prise en charge native d'Azure Blob, AWS S3 et Google Cloud Storage
* **Thèmes de couleurs** — Personnalisation de l'identité visuelle de la plateforme grâce à la prise en charge des thèmes
* **Intégration OnlyOffice** — Éditer des documents de manière collaborative au sein de la plateforme
