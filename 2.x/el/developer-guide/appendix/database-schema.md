# Σχήμα Βάσης Δεδομένων

Το Chamilo 2.0 αντιστοιχίζει ένα μεγάλο σύνολο οντοτήτων Doctrine σε πίνακες βάσης δεδομένων. Οι ακριβείς αριθμοί ποικίλλουν μεταξύ εκδόσεων — διαβάστε τους καταλόγους οντοτήτων που παρατίθενται παρακάτω για την τρέχουσα κατάσταση.

## Τοποθεσίες Οντοτήτων

| Bundle | Πού | Πρόθεμα |
|--------|-----|---------|
| CoreBundle | `src/CoreBundle/Entity/` | Κανένα (π.χ., `user`, `course`, `session`) |
| CourseBundle | `src/CourseBundle/Entity/` | `c_` (π.χ., `c_document`, `c_quiz`, `c_lp`) |
| LtiBundle | `src/LtiBundle/Entity/` | `lti_` |

## Κύριοι Πίνακες

### Χρήστης και Πιστοποίηση

| Πίνακας | Σκοπός |
|---------|--------|
| `user` | Λογαριασμοί χρηστών |
| `access_url` | Πολλαπλές πύλες URL |
| `access_url_rel_user` | Αντιστοιχίσεις χρηστών-πυλών |
| `usergroup` | Ομάδες χρηστών σε επίπεδο πλατφόρμας |

### Μαθήματα

| Πίνακας | Σκοπός |
|---------|--------|
| `course` | Μαθήματα |
| `course_category` | Κατηγορίες μαθημάτων |
| `course_rel_user` | Εγγραφές μαθημάτων |

### Συνεδρίες

| Πίνακας | Σκοπός |
|---------|--------|
| `session` | Συνεδρίες εκπαίδευσης |
| `session_rel_user` | Εγγραφές συνεδριών |
| `session_rel_course` | Μαθήματα σε συνεδρίες |
| `session_rel_course_rel_user` | Εγγραφή χρήστη ανά συνεδρία-μάθημα |

### Σύστημα Πόρων

| Πίνακας | Σκοπός |
|---------|--------|
| `resource_node` | Ενιαία αφαίρεση περιεχομένου |
| `resource_file` | Συνημμένα αρχείων |
| `resource_link` | Ορατότητα/πρόσβαση ανά πλαίσιο |
| `resource_type` | Μητρώο τύπων πόρων |

### Περιεχόμενο Μαθήματος (πρόθεμα c_)

| Πίνακας | Σκοπός |
|---------|--------|
| `c_document` | Έγγραφα |
| `c_quiz` | Ασκήσεις/εξετάσεις |
| `c_quiz_question` | Ερωτήσεις κουίζ |
| `c_quiz_answer` | Απαντήσεις ερωτήσεων |
| `c_lp` | Μονοπάτια μάθησης |
| `c_lp_item` | Αντικείμενα μονοπατιού μάθησης |
| `c_forum_category` | Κατηγορίες φόρουμ |
| `c_forum_forum` | Φόρουμ |
| `c_forum_thread` | Συνέχειες φόρουμ |
| `c_forum_post` | Δημοσιεύσεις φόρουμ |
| `c_student_publication` | Αναθέσεις/υποβολές |
| `c_survey` | Έρευνες |
| `c_glossary` | Όροι γλωσσαρίου |
| `c_calendar_event` | Γεγονότα ημερολογίου |
| `c_attendance` | Φύλλα παρουσίας |

### Παρακολούθηση

| Πίνακας | Σκοπός |
|---------|--------|
| `track_e_login` | Παρακολούθηση σύνδεσης |
| `track_e_online` | Παρακολούθηση συνδεδεμένων χρηστών |
| `track_e_default` | Γενική παρακολούθηση δραστηριότητας |
| `gradebook_category` | Κατηγορίες βαθμολογίου |
| `gradebook_result` | Βαθμοί |

### Ρυθμίσεις

| Πίνακας | Σκοπός |
|---------|--------|
| `settings` | Ρυθμίσεις πλατφόρμας |
| `settings_options` | Ορισμοί επιλογών ρυθμίσεων |

## Μεταφορτώσεις

Οι αλλαγές σχήματος βάσης δεδομένων διαχειρίζονται μέσω Doctrine Migrations στο `src/CoreBundle/Migrations/`. Εκτελέστε μεταφορτώσεις με:

```bash
php bin/console doctrine:migrations:migrate
```
