# KI-MedienGenerierung

Beim Bearbeiten eines Dokuments im **Dokumente**-Tool ermöglicht die Funktion zur KI-MedienGenerierung die Erstellung eines **Bildes** oder eines **kurzen Videos**, um einen Absatz zu illustrieren — direkt im Rich-Text-Editor (WYSIWYG), ohne das Dokument zu verlassen.

## Voraussetzungen

* KI-Helfer sind auf Plattformebene aktiviert
* Mindestens ein KI-Medienanbieter (Bild oder Video) ist vom Administrator konfiguriert
* Die Funktion ist in Ihrem Kurs erlaubt (Kursberechtigung muss aktiviert sein)

## So generieren Sie ein Bild oder Video

1. Öffnen Sie ein Dokument im **Dokumente**-Tool <img src="/.gitbook/assets/icons/mdi-bookshelf.svg" alt="Dokumente" data-size="line"> (erstellen Sie ein neues oder bearbeiten Sie ein bestehendes)
2. Platzieren Sie im Rich-Text-Editor den Cursor in oder nahe dem Absatz, den Sie illustrieren möchten
3. Öffnen Sie den Dialog **KI-Medien generieren** über die Symbolleiste des Editors
4. Beschreiben Sie, was das Medium zeigen soll, oder verwenden Sie den ausgewählten Absatz als Eingabeaufforderung
5. Wählen Sie aus, ob Sie ein **Bild** oder ein **Video** generieren möchten
6. Klicken Sie auf **Generieren** und warten Sie, bis die KI das Ergebnis erstellt hat
7. Sehen Sie sich das generierte Medium in der Vorschau an und klicken Sie, wenn Sie zufrieden sind, auf **Einfügen**, um es in das Dokument einzubetten

## Tipps

* **Schreiben Sie eine klare Eingabeaufforderung** — Je spezifischer Ihre Beschreibung, desto relevanter das Ergebnis. Fügen Sie Stilhinweise hinzu (z. B. "Diagramm", "Illustration", "realistisches Foto"), wenn der Anbieter diese unterstützt
* **Überprüfen Sie immer vor dem Einfügen** — Generierte Medien entsprechen möglicherweise nicht genau Ihrer Absicht; generieren Sie erneut oder passen Sie die Eingabeaufforderung bei Bedarf an
* **Beachten Sie die Dateigrößen** — Generierte Bilder und Videos werden auf das Speicherkontingent des Kurses angerechnet. Entfernen Sie ungenutzte Medien aus der Dokumentbibliothek, wenn der Speicherplatz begrenzt ist
* **Videogenerierung dauert länger** — Die Generierung kurzer Videos kann deutlich mehr Zeit in Anspruch nehmen als die Bildgenerierung; planen Sie entsprechend, wenn Sie sich einer Frist nähern
