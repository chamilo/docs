# Enquêtes

L'outil d'enquête vous permet de créer des questionnaires pour recueillir les retours de vos apprenants. Les enquêtes sont utiles pour les évaluations de cours, les analyses de besoins et les sondages d'opinion.

## Créer une enquête

1. Ouvrez l'outil **Enquêtes** <img src="/.gitbook/assets/icons/mdi-form-dropdown.svg" alt="Enquêtes" data-size="line"> depuis la page d'accueil du cours
2. Cliquez sur **Créer une enquête**
3. Remplissez les détails de l'enquête :
   * **Code** — Il s'agit d'un code unique pour l'enquête. Il sera utilisé dans les courriels et les liens.
   * **Titre** — Le nom de l'enquête
   * **Sous-titre** — Un sous-titre optionnel
   * **Date de début** — À partir de quand cette enquête sera ouverte à la participation
   * **Date de fin** — Jusqu'à quand cette enquête sera ouverte à la participation
   * **Anonyme** — Si les réponses sont anonymes ou liées à des apprenants individuels
   * **Visibilité des résultats** — Qui peut voir les résultats (seulement le formateur, le formateur et les étudiants, tout le monde)
   * **Introduction** — Un message affiché aux apprenants avant qu'ils ne commencent l'enquête
   * **Message de remerciement** — Un message affiché après la soumission
4. Enregistrez

### Paramètres avancés

* **Note dans l'outil d'évaluation** — Indique si l'état de réponse de cette enquête doit être inclus dans l'outil d'évaluation (bulletin de notes). Toute personne ayant complété l'enquête obtient 100 %, les autres obtiennent 0 %
* **Enquête parente** — Pas vraiment utilisé pour le moment (fonctionnalité héritée)
* **Une question par page** — Style de présentation des questions
* **Activer le mode aléatoire** — Indique si les questions doivent être mélangées
* **Afficher le numéro de la question** — Indique si les numéros de question (générés automatiquement) doivent être affichés

## Ajouter des questions

Une fois l'enquête créée, ajoutez des questions :

1. Choisissez le type de question :
   * **Oui/Non** — Un choix binaire simple
   * **Choix multiple** — Sélectionner une réponse parmi plusieurs options
   * **Réponse multiple** — Sélectionner une ou plusieurs réponses parmi plusieurs options
   * **Question ouverte** — Réponse en texte libre
   * **Liste déroulante** — Sélectionner dans une liste déroulante
   * **Pourcentage** — Choisir une valeur en pourcentage
   * **Score** — Évaluer sur une échelle numérique
   * **Commentaire** — Un bloc de texte (pas une question) pour ajouter des instructions entre les questions
   * **Choix multiple avec option "autre"** — Sélectionner une réponse parmi plusieurs options, avec un choix alternatif
   * **Affichage sélectif** — Type spécial permettant d'adapter le flux de questions en fonction des réponses précédentes
   * **Saut de page** — Ajouter des sauts de page dans le flux des questions. Utile uniquement si "Une question par page" n'a **pas** été sélectionné à l'étape précédente
2. Configurez le texte de la question et les options de réponse
3. Enregistrez

Chaque question peut être marquée comme obligatoire. Si vous ne le faites pas, ignorer une question sera un comportement acceptable.

## Publier une enquête

Après avoir ajouté toutes les questions :

1. Cliquez sur **Publier**
2. Choisissez les destinataires — Sélectionnez des apprenants ou des groupes spécifiques (vous les sélectionnez). Le bouton **Ajouter des apprenants** ajoute tous les apprenants en une seule action et laisse les enseignants de côté
3. Ajoutez des utilisateurs supplémentaires — Permet d'inviter des utilisateurs extérieurs à Chamilo à participer à l'enquête. Ils recevront un courriel avec un lien et apparaîtront par leur adresse e-mail dans les détails de l'enquête
4. Sujet du courriel
5. Texte du courriel — Expliquez de quoi parle l'enquête et quand/comment y répondre
6. Différentes options pour les invitations répétées sont disponibles
7. Confirmez

Les apprenants reçoivent une invitation (par courriel) pour répondre à l'enquête.

Un lien est disponible en bas de la page de publication pour inviter encore plus d'utilisateurs externes à participer. Les participants utilisant ce lien ne seront pas identifiés et apparaîtront comme anonymes dans les résultats de l'enquête.

## Consulter les résultats

![Résultats de l'enquête avec des graphiques et des pourcentages pour chaque question](/.gitbook/assets/survey-results-charts.png)

Après que les apprenants ont répondu :

1. Ouvrez l'enquête
2. Cliquez sur **Résultats** ou **Rapport**
3. Consultez les résumés des réponses :
   * Graphiques et pourcentages pour les questions fermées
   * Réponses textuelles individuelles pour les questions ouvertes
   * Taux de complétion (combien d'invités ont répondu)

Vous pouvez exporter les résultats vers une feuille de calcul pour une analyse plus approfondie.

## Conseils

* **Soyez bref** — Les apprenants sont plus susceptibles de compléter des enquêtes courtes
* **Utilisez le mode anonyme** — Pour des retours honnêtes, activez les réponses anonymes
* **Choisissez le bon moment** — Envoyez des enquêtes en milieu de cours pour effectuer des ajustements, pas seulement des évaluations de fin de cours
