# Documentation de Chamilo 2.0

Bienvenue dans la documentation officielle de **Chamilo 2.0**, la plateforme d'apprentissage en ligne open-source.

Cette documentation est organisée en trois guides, chacun adapté à un public spécifique :

* [**Guide de l'enseignant**](teacher-guide/) — Pour les formateurs et enseignants : créer des cours, ajouter du contenu, évaluer les apprenants et suivre leur progression.
* [**Guide de l'administrateur**](admin-guide/) — Pour les administrateurs de la plateforme : installer, configurer et gérer la plateforme Chamilo.
* [**Guide du développeur**](developer-guide/) — Pour les développeurs : comprendre l'architecture, créer des plugins, utiliser l'API et contribuer au projet.

## Nouveautés de Chamilo 2.0

Chamilo 2.0 est une version majeure avec une interface entièrement repensée et de nombreuses nouvelles fonctionnalités :

* **Interface moderne** — Construite avec Vue 3 et PrimeVue pour une expérience plus rapide et réactive
* **Outils alimentés par l'IA** — Générer des exercices, des parcours d'apprentissage et bénéficier d'une correction assistée par l'IA
* **REST API** — API REST complète basée sur API Platform avec authentification JWT
* **Nouvelles options d'authentification** — OAuth2 (Azure, Keycloak, Facebook), provisionnement d'utilisateurs SCIM
* **LTI 1.3** — Connecter des outils d'apprentissage externes de manière transparente
* **Stockage cloud** — Support natif pour Azure Blob, AWS S3 et Google Cloud Storage
* **Thèmes de couleur** — Personnalisation de l'image de marque de la plateforme avec support des thèmes
* **Intégration OnlyOffice** — Éditer des documents de manière collaborative au sein de la plateforme
