# Multi-URL

O recurso de multi-URL do Chamilo (também chamado de multi-tenant) permite que você execute vários portais virtuais a partir de uma única instalação do Chamilo. Cada portal possui sua própria URL, identidade visual, usuários, cursos e configurações, mas todos compartilham o mesmo banco de dados e base de código.
