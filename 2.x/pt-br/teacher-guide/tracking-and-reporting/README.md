# Acompanhamento e Relatórios

O Chamilo acompanha a atividade dos alunos em toda a plataforma, fornecendo insights detalhados sobre o progresso dos seus alunos.

* **[Acompanhamento de Alunos](learner-tracking.md)** — Monitore a atividade individual dos alunos: horários de login, tempo gasto, páginas visitadas e uso de ferramentas
* **[Relatórios de Curso](course-reports.md)** — Visualize dados agregados de todos os alunos em um curso
* **[Certificados e Habilidades](certificates-and-skills.md)** — Conceda certificados com base nas pontuações do livro de notas e valide habilidades adquiridas

## Acessando Relatórios

Dentro do seu curso, clique na ferramenta **Acompanhamento** <img src="../../.gitbook/assets/icons/mdi-chart-box.svg" alt="Acompanhamento" data-size="line"> na página inicial do curso. Você também pode acessar os relatórios pelo link **Relatórios** na barra lateral para uma visão geral entre cursos.

Professores visualizam dados de relatórios dos cursos que ministram. Treinadores de sessão visualizam dados de todos os cursos dentro de sua sessão.
