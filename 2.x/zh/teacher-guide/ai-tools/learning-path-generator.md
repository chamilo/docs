# 学习路径生成器

AI学习路径生成器帮助您自动创建结构化的学习序列。您提供主题和目标，AI会生成一个学习路径大纲，包含章节和内容项，您可以对其进行审查和自定义。

## 访问学习路径生成器

学习路径生成器在创建新的学习路径时可用，前提是：

1. 平台层面已启用AI助手
2. 课程设置中已激活学习路径生成器
3. 至少配置了一个AI文本提供商

在学习路径创建界面中查找 **AI生成器** 部分。

## 如何生成学习路径

![AI学习路径生成器表单，包含主题、目标和章节数量字段](/.gitbook/assets/ai-learning-path-generator.png)

1. 打开AI生成器表单
2. 配置参数：
   * **主题** — 学习路径的主题
   * **项目数量** — 学习路径应包含的内容页面数量
   * **每页字数** — 每页内容的大致长度
   * **每页后添加测试** — 选中后，AI会在每页后创建一个小型多选题测验（默认2个问题，最多限制为5个）
3. 点击 **生成**
4. AI会生成一个学习路径，每页包含一个文档项目，并可选地在每个页面后添加一个测验项目

## 审查和自定义

生成的学习路径是一个 **起点**。您应该：

* **审查结构** — 检查章节是否按逻辑顺序排列
* **编辑内容** — 修改生成文本，添加您自己的材料，删除不相关的章节
* **添加资源** — 插入您自己的文档、练习、链接和其他内容
* **设置前提条件** — 配置哪些章节必须在其他章节之前完成
* **添加评估** — 在适当的位置加入练习以检查理解情况

## AI生成内容的披露

AI生成的内容会标有披露声明，表明其使用人工智能创建。这种透明度帮助学生了解材料的来源。

## 小贴士

* **先从广泛开始，然后细化** — 首先生成一个高层次的结构，然后手动添加具体细节和资源
* **用于课程规划** — 即使您不直接使用生成的内容，AI建议的结构也可以作为有用的规划工具
* **结合练习生成器使用** — 在生成学习路径后，使用练习生成器为每个章节创建评估内容
