# API

Chamilo 2.0 espone un'API REST basata su **API Platform 3.0**. L'API fornisce accesso programmatico alle risorse della piattaforma ed è la stessa API utilizzata dal frontend Vue.

* **[Autenticazione](authentication.md)** — Autenticazione basata su token JWT
* **[Riferimento agli Endpoint](endpoints-reference.md)** — Panoramica delle risorse API disponibili
* **[Azioni Personalizzate](custom-actions.md)** — Endpoint specializzati oltre le operazioni CRUD standard
* **[Webhook](webhooks.md)** — Notifiche guidate da eventi a sistemi esterni
