# Aggiungere Contenuti

Questa sezione tratta gli strumenti che utilizzi per aggiungere contenuti didattici al tuo corso. Chamilo offre diversi modi per fornire materiale ai tuoi studenti:

* **[Documenti](documents.md)** — Carica file, crea pagine web e organizza la tua libreria di contenuti
* **[Link](links.md)** — Condividi URL di risorse esterne, organizzate per categoria
* **[Percorsi di Apprendimento](learning-paths.md)** — Costruisci sequenze strutturate di contenuti con prerequisiti e monitoraggio dei progressi
* **[Glossario](glossary.md)** — Definisci termini chiave che gli studenti possono consultare durante il corso
* **[Annunci](announcements.md)** — Invia messaggi e aggiornamenti agli studenti iscritti

Ogni strumento è accessibile dalla griglia degli strumenti nella homepage del corso. Fai clic sull'icona dello strumento per aprirlo.
