# API

Chamilo 2.0 は **API Platform 3.0** 上に構築された REST API を公開しています。この API はプラットフォームのリソースへのプログラムによるアクセスを提供し、Vue フロントエンドでも使用されているものと同じ API です。

* **[認証](authentication.md)** — JWT トークンベースの認証
* **[エンドポイントリファレンス](endpoints-reference.md)** — 利用可能な API リソースの概要
* **[カスタムアクション](custom-actions.md)** — 標準的な CRUD を超えた特殊なエンドポイント
* **[Webhook](webhooks.md)** — 外部システムへのイベント駆動型通知
