# 課程的建立

本節說明如何在 Chamilo 中建立新課程，並根據需求進行設定。

## 建立新課程

要建立課程，請執行以下步驟：

1. 點擊側邊欄的 **My courses**
2. 點擊 **Create course** 按鈕（通常為綠色的書本 <img src="/.gitbook/assets/icons/mdi-book-open-page-variant.svg" alt="課程" data-size="line"> 圖示，帶有 + 符號）
3. 在課程建立表單中輸入必要資訊：

![課程建立表單，包含課程名稱、類別、代碼、語言欄位](/.gitbook/assets/course-creation-form.png)

| 欄位 | 必填 | 說明 |
|------|------|------|
| **課程名稱** | 是 | 課程的簡短且易懂標題（例如：「創新管理」） |
| **課程類別** | 否 | 選擇類別以在平台上組織課程 |
| **課程代碼** | 否 | 僅使用字母和數字的簡短代碼（最多 40 個字元）。若留空，則會自動從課程名稱產生 |
| **語言** | 否 | 課程的主要語言。預設為目前語言 |

若啟用相關功能，您可能會看到 **預設房間** 設定，或使用 **課程範本** 的選項，以省去從頭建立課程的麻煩。

4. 點擊 **Create this course**

系統會將您重新導向新課程的主頁，並顯示確認訊息：「課程已成功建立。」

## 課程主頁

課程建立後，您會進入主頁。這是課程的中心樞紐，您和學習者皆可從此存取所有工具和內容。

![課程主頁的工具格線，顯示可用課程工具的圖示與顯示切換](/.gitbook/assets/course-homepage-tool-grid.png)

主頁會顯示以下內容：

* **課程標題** — 課程名稱顯示於上方。
* **課程簡介** — 可選的說明或歡迎訊息。點擊 **+ Course introduction** 按鈕新增，或點擊上方的 **Edit introduction** <img src="/.gitbook/assets/icons/mdi-pencil.svg" alt="編輯" data-size="line"> 按鈕變更。支援包含圖片、連結和格式設定的富文本。
* **工具格線** — 所有可用課程工具以圖示和名稱的卡片形式顯示於格線中。

### 管理工具顯示

身為教師，您可以控制學習者看到的工具：

* 點擊任意工具旁的 **眼睛圖示** <img src="/.gitbook/assets/icons/mdi-eye.svg" alt="顯示" data-size="line">，即可對學習者隱藏該工具。隱藏的工具會顯示 **帶斜線的眼睛圖示** <img src="/.gitbook/assets/icons/mdi-eye-off.svg" alt="隱藏" data-size="line">，但您仍可存取。
* 使用 **Show all** 和 **Hide all** 按鈕，一次變更所有工具
* 點擊 **Sort**，即可啟用工具格線的拖曳排序功能

### 學生檢視

點擊 **Student view** 按鈕，即可檢視與學習者完全相同的課程主頁。這有助於確認隱藏工具或未發佈內容不會顯示。再點擊一次按鈕，即可返回教師檢視。
