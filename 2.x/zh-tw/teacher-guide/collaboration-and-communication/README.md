# 協作與溝通

Chamilo 提供各種工具，以方便您與學生之間，以及學生之間的互動。

* **[論壇](forums.md)** — 依類別和主題組織的討論
* **[聊天室](chat.md)** — 課程內的即時文字訊息
* **[群組](groups.md)** — 將學生分組至工作群組，每群組擁有各自的共享工具
* **[Wiki](wiki.md)** — 協作式文件編輯
* **[部落格](blog.md)** — 課程內的共享部落格
* **[視訊會議](video-conferencing.md)** — 使用 BigBlueButton 或 Zoom 進行即時視訊會議

這些工具可在課程首頁找到。有些工具預設可能隱藏 — 您可以透過工具網格設定使其顯示（請參閱 [課程首頁](../creating-your-course/course-homepage.md)）。
