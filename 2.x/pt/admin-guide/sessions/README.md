# Sessões

As sessões são uma das funcionalidades mais poderosas do Chamilo. Elas permitem que você ofereça os mesmos cursos a diferentes grupos de alunos em momentos distintos, sem duplicar o conteúdo do curso.

* **[Gerenciando Sessões](managing-sessions.md)** — Criar, configurar e gerenciar sessões de treinamento
* **[Categorias de Sessões](session-categories.md)** — Organizar sessões em categorias
* **[Carreiras e Promoções](careers-and-promotions.md)** — Definir caminhos de carreira e fluxos de promoção
* **[Turmas](classes.md)** — Gerenciar turmas de alunos para matrículas em massa

## Entendendo Sessões

As sessões são **opcionais**. Você pode fazer seu portal funcionar apenas usando cursos, mas **realmente** recomendamos que considere a complexidade adicional das sessões como uma forma de economizar trabalho de gerenciamento a longo prazo.

Um **curso** contém o conteúdo (documentos, exercícios, caminhos de aprendizagem). Uma **sessão** atribui esse curso (ou vários cursos) a um grupo específico de alunos *por um período de tempo específico*.

Essa arquitetura significa:

* Os professores criam o conteúdo uma vez no curso
* Os administradores criam sessões para entregar esse conteúdo a diferentes grupos
* Cada sessão tem sua própria matrícula, dados de acompanhamento e resultados
* O conteúdo base do curso é compartilhado, mas os tutores da sessão podem personalizar certos elementos

## Quando Usar Sessões

Use sessões quando:

* Você oferece o mesmo treinamento várias vezes (por exemplo, sessões mensais de integração)
* Você tem programas baseados em grupos (por exemplo, turmas semestrais)
* Você precisa de acompanhamento separado por grupo de alunos
* Você deseja que diferentes tutores gerenciem diferentes edições do mesmo curso
