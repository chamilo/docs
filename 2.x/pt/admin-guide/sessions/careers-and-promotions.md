# Carreiras e Promoções

O Chamilo inclui um sistema de gestão de carreiras que permite definir caminhos de formação e acompanhar a progressão dos alunos através de programas estruturados.

## Carreiras

![Lista de carreiras mostrando os caminhos de formação definidos com nome e descrição](/.gitbook/assets/admin-careers-list.png)

Uma **carreira** representa um caminho de formação estruturado — uma sequência de etapas de treinamento que um aluno segue para alcançar um objetivo profissional.

### Criando uma Carreira

1. No painel de administração, navegue até **Carreiras**
2. Clique em **Criar uma carreira**
3. Insira um **nome** e uma **descrição**
4. Salve

## Promoções

Uma **promoção** representa uma coorte ou grupo de alunos que progride através de uma carreira. Pense nisso como um grupo de pessoas seguindo o mesmo caminho de carreira ao mesmo tempo.

### Vinculando a Sessões

Após criar uma promoção, você a vincula a sessões. Isso define a sequência de treinamentos que um aluno deve completar.

Posteriormente, você pode replicar promoções para ajudar a criar a próxima promoção com cópias das mesmas sessões, permitindo que a próxima promoção seja construída instantaneamente.

### Criando uma Promoção

1. Navegue até **Promoções**
2. Clique em **Criar uma promoção**
3. Insira um **nome** e uma **descrição**
4. Vincule-a a uma **carreira**
5. Atribua **sessões** à promoção
6. Salve

## Como Tudo se Encaixa

* Uma **carreira** define o caminho (por exemplo, "Certificação de Desenvolvedor Júnior")
* Uma **promoção** representa uma coorte (por exemplo, "Turma de Março de 2026")
* **Sessões** dentro da promoção entregam o conteúdo de treinamento real

## Dicas

* **Use para programas estruturados** — Carreiras e promoções são mais úteis para programas de treinamento de várias etapas, onde os alunos progridem por uma sequência definida
* **Acompanhe a conclusão** — Utilize as ferramentas de relatórios para monitorar como as promoções estão progredindo em seus caminhos de carreira
