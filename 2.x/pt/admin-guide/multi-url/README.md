# Multi-URL

A funcionalidade Multi-URL do Chamilo (também chamada de multi-tenant) permite que você execute vários portais virtuais a partir de uma única instalação do Chamilo. Cada portal possui sua própria URL, marca, usuários, cursos e configurações, mas todos compartilham o mesmo banco de dados e base de código.

* **[URLs de Acesso](access-urls.md)** — Configurar e gerenciar múltiplas URLs de acesso
