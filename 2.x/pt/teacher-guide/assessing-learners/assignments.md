# Trabalhos

A ferramenta de trabalhos (também chamada de "publicações dos alunos") permite que você colete trabalhos dos alunos — ensaios, projetos, relatórios ou qualquer submissão baseada em arquivos — e os avalie.

## Criando um Trabalho

1. Abra a ferramenta **Trabalhos** <img src="/.gitbook/assets/icons/mdi-inbox-full.svg" alt="Trabalhos" data-size="line"> na página inicial do curso
2. Clique em **Criar um trabalho**
3. Preencha os detalhes:
   * **Nome do trabalho** — O nome do trabalho (por exemplo, "Relatório do Projeto Final")
   * **Descrição** — Instruções para os alunos, incluindo o que enviar e como será avaliado (suporta texto formatado)
   * **Pontuação máxima** — Sobre qual total o trabalho será avaliado
   * **Adicionar ao boletim de notas** — Adicionar como um item avaliado na ferramenta de avaliação (boletim de notas), para que possa fazer parte dos objetivos do curso
   * **Prazo final** — A data e hora oficiais (publicadas) após as quais as submissões são marcadas como atrasadas (envios ainda são aceitos)
   * **Termina em (fechado completamente)** — A data e hora limite após as quais nenhum envio é possível
   * **Adicionar ao calendário** — Criar um evento para referenciar a data de submissão deste trabalho
   * **Tipo de submissão** — Escolha entre **Permitir apenas texto**, **Permitir apenas arquivos** ou **Permitir arquivos ou texto online**
4. Salvar

Depois de criar um trabalho, você também pode:
* Fazer upload de documentos modelo a partir da página de detalhes do trabalho
* Atribuir o trabalho a usuários específicos (em vez de todos os usuários do curso)

E, uma vez que os alunos tenham enviado seus trabalhos, você pode:
* Exportar uma lista de submissões em PDF
* Mostrar uma lista apenas dos alunos que não enviaram seus trabalhos
* Baixar todos os trabalhos em um único arquivo ZIP
* Fazer upload de todas as correções em um único arquivo ZIP
* Excluir todas as correções que você enviou (isso não exclui as submissões dos alunos)

## Como os Alunos Enviam

Os alunos abrem o trabalho e:

1. Clicam em **Enviar arquivo** ou no botão de submissão
2. Selecionam um arquivo do computador (ou escrevem texto diretamente, dependendo da configuração)
3. Adicionam um comentário opcional
4. Enviam

Os alunos podem ver se já enviaram e, se permitido, atualizar sua submissão.

## Revisando Submissões

![Lista de submissões de trabalhos mostrando nomes dos alunos, datas, arquivos e status de avaliação](/.gitbook/assets/assignments-submissions-list.png)

Como professor, abra um trabalho para ver a lista de todas as submissões:

* **Nome do aluno** — Quem enviou
* **Data de submissão** — Quando o trabalho foi enviado
* **Arquivo** — Baixar o arquivo enviado
* **Status** — Se a submissão foi avaliada
* **Comentários** — Quaisquer comentários deixados pelo aluno ou por você

### Avaliando uma Submissão

![Visão de avaliação do trabalho com entrada de pontuação, campo de feedback e upload de arquivo corrigido](/.gitbook/assets/assignment-grading-view.png)

1. Clique em uma submissão para abri-la
2. Revise o arquivo enviado
3. Insira uma **pontuação**
4. Escreva **comentários de feedback** para o aluno
5. Opcionalmente, faça upload de um **arquivo corrigido** como anexo
6. Salve

### Avaliação Assistida por IA

Se ferramentas de IA estiverem configuradas na sua plataforma, você poderá ver uma opção de **avaliação por IA** ao revisar submissões. Isso utiliza um modelo de IA para sugerir uma pontuação e feedback para trabalhos abertos. Veja [Avaliação por IA](../ai-tools/ai-grading.md) para mais detalhes.

## Gerenciando Submissões

Ações em grupo:
* **Baixar pacote de trabalhos** — Baixar todas as submissões como um único arquivo ZIP para revisão offline
* **Enviar pacote de correções** — Se você baixou todas as submissões em um único arquivo ZIP, editou os arquivos diretamente no seu computador e os compactou novamente, você pode enviar o ZIP como um pacote de correções. Não altere os nomes dos arquivos, ou isso não funcionará.
* **Submissões atrasadas** — Submissões após o prazo são sinalizadas, mas ainda podem ser aceitas dependendo das suas configurações

Ações de submissão individual:
* **Enviar correção** — Enviar uma correção para um aluno
* **Baixar** — Baixar a submissão de um aluno
* **Corrigir e avaliar** — Adicionar uma correção e uma nota à submissão do aluno
* **Editar** — Editar o título do documento ou o feedback anterior na submissão
* **Mover** — Transferir uma submissão entre pastas de trabalhos (por exemplo, se o aluno enviou no trabalho errado)
* **Visibilidade** — Controlar se os alunos podem ver as submissões uns dos outros

## Vinculando ao Boletim de Notas

As pontuações dos trabalhos podem ser incluídas no boletim de notas do curso (ferramenta "Avaliações"). Isso permite que as notas dos trabalhos contribuam para a nota geral do curso do aluno e para a elegibilidade ao certificado. Veja [Boletim de Notas](gradebook.md) para mais detalhes.

## Dicas

* **Seja específico nas instruções** — Descreva claramente o que os alunos devem enviar, o formato esperado e os critérios de avaliação
* **Estabeleça prazos realistas** — Utilize a ferramenta Agenda para tornar os prazos visíveis no calendário do curso
* **Use o recurso de arquivo corrigido** — Faça upload de versões anotadas do trabalho dos alunos para que eles possam ver suas correções específicas
* **Habilite a visibilidade entre pares com cuidado** — Permitir que os alunos vejam o trabalho uns dos outros pode incentivar o aprendizado, mas pode não ser apropriado para todas as tarefas
